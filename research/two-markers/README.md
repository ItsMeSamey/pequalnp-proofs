# Two simultaneous parity markers on alternating guard matrices

Over GF(2), let A be a symmetric zero-diagonal matrix and L have two rows. There is a deterministic polynomial-time algorithm to find x with xᵢ(Ax)ᵢ=0 for every i and Lx=z, or certify its absence. View A as the adjacency matrix of a simple graph and label vertex i by the two-bit column Lᵢ. A support is feasible precisely when it induces an even-degree graph. The requested vector z is the XOR of the selected labels.

The empty support realizes zero. A singleton of color z realizes any nonzero target z present as a label. Otherwise the labels lie in {0,a,b} for the two other nonzero labels, with a+b=z. A valid support must include odd counts of both a and b. Two nonadjacent vertices with labels a,b form a valid support. Assume henceforth that the two label classes are completely adjacent.

Search for a connected component of the zero-label vertices touching both classes. If one exists, choose endpoints from the two classes touching that component. In the subgraph on the endpoints and the zero vertices remove their direct edge and find a shortest path. It has nonempty zero interior, and is induced. Restoring the endpoint edge gives an induced cycle with the desired label. If no such component exists, partition the graph into an a side and a b side. Place each zero component on the side it touches, choosing either side when it touches neither. The only crossing edges are the complete bipartite graph between a and b vertices. Any support of the requested label cuts an odd number of edges in its induced graph because both selected label counts are odd. Even-degree graphs have an even number of edges across every cut. This certifies impossibility. The executable uses BFS for each eligible endpoint pair, which is polynomial. It passed 16,933 exhaustive graph-label instances through four vertices and 800 further seeded random instances.

## A symmetric diagonal that can be removed

Write d for the diagonal of any symmetric A. Summing the guards forces d·x=0. If d=eᵢ then xᵢ=0 and deleting the coordinate leaves an alternating system. If d equals a nonzero row Aᵢ, make the row a coordinate by a principal pivot. Choose J={i} when Aᵢᵢ=1. Otherwise choose J={i,j} for an adjacent j. The principal block A[J] is invertible in either case. Exchange the two entries of (xⱼ,(Ax)ⱼ) at each j in J. The new first coordinates z give an invertible linear change of coordinates and the new second coordinates equal A′z for a symmetric A′. To see this directly, write A as blocks B,C,Cᵀ,D with J first. The pivoted blocks are B⁻¹,B⁻¹C,CᵀB⁻¹,D+CᵀB⁻¹C and are symmetric. Transform each marker by the inverse coordinate change. The product of each pair is preserved, while the sum of all products becomes d·x=(Ax)ᵢ=zᵢ. Thus the new diagonal is eᵢ and its coordinate can be deleted. Apply the reduction to each connected component separately if its own diagonal is zero, a unit vector, or one of its rows; combine the feasible labels of components by XOR.

For general symmetric A, adding an apex adjacent to every diagonal-one vertex and forcing it to be selected converts the system to a zero-diagonal system with one more marker. The old guards on a selected vertex have their required parity adjusted by the apex. The apex guard holds exactly when the number of selected marked vertices is even, which follows by summing the original guards. This gives a relation between the general and alternating cases, while the two-marker algorithm above leaves general nonremovable diagonals at two markers unresolved.
