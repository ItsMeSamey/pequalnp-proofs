# An exceptional lift bit in a signed-graph presentation

The nonterminal binary columns are the edges of a supplied signed multigraph on n vertices: edge ij with label σ has column (e_i+e_j,σ). Loops and parallel edges are allowed. Suppose u=(0,1), K is any k-dimensional binary subspace containing u, and w is arbitrary. There is a deterministic n^{k+1} poly(input) algorithm that outputs X with u in span X and w outside K+span X or reports infeasibility. In fact the exponent can be lowered to k because the equation for u is automatic.

There exists a separating linear form f annihilating span X+K and taking value one on w exactly when the exclusion holds. As u belongs to K, f annihilates the final coordinate. Write f as a vertex coloring. On an edge, f vanishes exactly when its endpoints have the same color. For this coloring, all monochromatic edges can be selected. Their span contains u precisely when some monochromatic connected component has an odd-sign cycle. Indeed an edge subset with boundary zero is Eulerian and is a sum of cycles, so a nonzero aggregate sign requires one cycle of nonzero sign. Conversely such a cycle sums to u. All vertices of a cycle in these retained edges have one common color.

If a witness exists, fix one witnessing cycle C and its common color c. Start from the constant coloring c and permit changes only at vertices outside C. Enforcing f(K)=0 and f(w)=1 is a binary linear system in those changes. The original coloring is a solution. After using u as one basis vector of K, at most k equations remain (k−1 from K, one from w). A basis of the correction columns contains at most k columns and spans the required right hand side. Thus there is a solution flipping at most k vertices, all outside C. Enumerate the two constant colors and all sets of at most k exceptional vertices. For each coloring, check all terminal constraints and test for an odd signed cycle in its monochromatic edges. An inconsistent edge in the vertex-potential equations h_i+h_j=σ_{ij}, recovered by a spanning forest, returns such a cycle and hence a valid witness.

This applies to nonregular column matroids. On three vertices include both signs for each pair, then add a fourth vertex joined to vertex 1 by a pair of opposite signs. Contracting the positive edge to vertex 4 makes the negative parallel edge an odd loop. The six signed triangle columns plus that odd loop are all seven nonzero vectors in a 3-dimensional binary subspace, giving a Fano minor. There is no nonterminal pure-sign column before contraction. The argument requires the supplied signed-graph presentation and a distinguished u equal to its pure sign direction.

If the nontrivial terminal constraints are graphic pair columns or singleton vertex coordinates, the coloring constraints involve at most 2k vertices. Enumerating colors on just those vertices, testing the equations, and deleting those with color opposite to c leaves a signed graph in which an odd cycle is necessary and sufficient. An odd cycle found there extends to a coloring assigning c to its vertices and respecting the enumerated terminals. This gives 2^{O(k)} poly(input) time for that subclass.
