# Consistent continuations for bipartite matching

For a consistent prefix p reaching node v of an acyclic binary decision branching program, let S(p) be the set of accepting suffix edge paths jointly consistent with p. Let K_v count distinct nonempty S(p). An edge derivative e⁻¹S(p), if nonempty, equals S(pe). Therefore each residual determines successor residuals independently of its representative. Replace a query at a residual by G₀ OR (xᵢ AND G₁) on the successor residuals, setting absent derivatives to false and an accepting sink to true. The resulting circuit has at most 2 sum_v K_v+O(1) monotone gates. It accepts exactly when a consistent accepting path requires positive literals only from the input. Setting exactly the required positives to one satisfies all its negative tests, and any accepting assignment below the input gives such a path. This proves that the computed function is the upward closure, hence the same function for a monotone target.

More generally each edge derivative of a generator language can be given as a union of successor generators. These decompositions, correct sink values, and a union at the root suffice by the same induction, charging all unions. The nonempty join-irreducibles of the union-closure of residuals are a guaranteed choice because derivatives preserve unions. Local covers by themselves do not specify the transition circuits.

Rao's revision 5 proves bipartite perfect matching on v total vertices requires exp(Ω(√v)) monotone gates. Thus every size-S program for matching has a node with at least exp(Ω(√v))/S distinct nonempty residuals, up to absolute constants. Fenner, Gurjar and Thierauf give uniform bounded-fanin depth O(log² v) circuits. Unrolling gives quasipolynomial formulas, which yield linear-in-formula-size branching programs by short circuit evaluation: on an AND continue from the left operand's true exits to the right operand, and use the dual rule for OR. Thus this residual lower applies to existing quasipolynomial programs. Computing the residual partition efficiently is not required for the size bound.

The conjecture that at most one shared variable per AND in a literal NNF gives a polynomial-size monotone simulation for monotone targets is false. Replace every branching program query by ((NOT xᵢ) AND G₀) OR (xᵢ AND G₁) with shared successors. Each AND has a literal child and hence at most one shared variable. Applying this to matching gives quasipolynomial NNF size versus exp(Ω(√v)) monotone size, excluding even quasipolynomial overhead in the input circuit size. On a single AND, independent assignment witnesses can indeed be glued if no shared variable allows inconsistent choices. This local gluing test does not control global consistency costs.

Even an O(k)-node program for TRUE can have 2^k residuals at its midpoint: query the same k variables twice and merge both outgoing edges after each query. At the midpoint each first-pass assignment allows just its own second-pass edge sequence. Hence large residual multiplicity can coexist with small ordinary programs.

Primary sources: [Rao, revision 5](https://eccc.weizmann.ac.il/report/2026/129/) and [Fenner, Gurjar and Thierauf](https://arxiv.org/abs/1601.06319).

An explicit intermediate Boolean matrix shows why *chosen* optimal local bases need not compose. Let B=M be the symmetric matrix with rows 011,110,100. Boolean factorizations M=BI=IBᵀ have optimal width three, witnessed by the fooling set (3,1),(2,2),(1,3). Yet M≠BTBᵀ for every Boolean T. To cover (2,2) both chosen supports must be either {2,3} or {1,2}. Each of their four products contains a zero, respectively (3,3),(3,2),(2,3),(1,1). Other bases can compose, so this falsifies a claim about independently selected optimal bases.
