# Sparse labels and connected dominating sets for cographic quotient traces

For a connected host graph with binary vertex labels summing to zero, an h-dimensional trace H has a realizing partition with b=h+1 connected blocks if it is attainable. For H=0 take the empty edge set.

**Sparse labels.** Suppose only t vertices have nonzero labels. For h>0, the only relation on the b part sums of a minimum partition is the all-ones vector. Thus each part contains a nonzero label. Enumerate partitions of the t labelled vertices into b nonempty blocks. Retain those whose block sums span H. For each, query the rooted graph minor problem with a b-vertex edgeless pattern whose branch sets respectively contain the prescribed blocks. This disjoint connected sets query takes f(t)m^{1+o(1)} time where m counts all graph vertices and edges, by [Korhonen, Pilipczuk and Stamoulis](https://arxiv.org/abs/2404.03958). The number of queries depends only on t. To recover a witness with a decision oracle, greedily drop edges while the query stays positive. Take any disjoint tree model in the final graph. Minimality implies the union of its trees contains every remaining edge. Each component containing a block is therefore its branch set, including isolated singleton roots. In the original graph grow these branch sets along a frontier until they cover the graph. Every added vertex has label zero. The crossing edges of the final partition form the witness. This recovery costs polynomial overhead.

**Dense labels.** Suppose b disjoint nonempty connected dominating cores are supplied and every vertex in their union has label in S≤W. Outside them suppose b−1 disjoint vertex sets each give a label basis of S. Given the cores one may enumerate S and use linear matroid union on the remaining vertices whose labels lie in S, checking whether a union of b−1 independent sets has size (b−1)dim S.

Every unrestricted assignment to b parts can be converted into a connected partition with the same ordered part sums. Force the cores into their respective parts and initially move every basis vertex to the last part. Every part sum changes by an element of S. For each i<b correct its deficit with a subset of its private basis taken from the last part. The last deficit is then zero by total parity. Each resulting part is connected because it contains its connected dominating core. Use DP over unrestricted assignments keeping ordered part sums, then test their span against H. This takes O(bn2^{rb}) updates where r=dim W. Traceback and the preceding corrections give the edge witness. If S spans all labels, any H≤S is attainable by prescribing a basis of H as the first h part sums and using the private bases to realize it. Finding arbitrary cores is outside the hypothesis.

On K_{b,n} the b disjoint edges of a matching are connected dominating sets. Sufficient copies of bases outside them certify the result for dense nonzero labellings whenever the core labels belong to S. The graph complement degree grows with n.
