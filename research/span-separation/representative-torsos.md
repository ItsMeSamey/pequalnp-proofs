# Finite representative torso compiler

Fix a finite abelian group Γ, b ordered colours, adhesion size a and simple torso maximum degree Δ. In a rooted tree decomposition store each region's b-colour extension table: colouring of the ordered interface, required partition into connected blocks of each interface colour, per-colour interior sum excluding the interface, and which interface-absent colours form a single closed component (all others absent). Every component of an interface colour must touch the interface. Additional same-colour connections are permitted. Honour prescribed colours. These finite records compose by matching colours, adding interior sums, taking connection closure and forbidding overlaps with a closed colour. Extra connections can only help an extension. Save witness backpointers.

Group all children of a bag having identical adhesion, first computing their union table by ordinary joins. Assume each group's whole region, including its ordered roots, is connected. Record the full extension table, ordered root labels and fixed colours. Enumerate finite connected Γ-labelled rooted graphs with optional pins until finding an exact match, computing each candidate table by exhaustive colourings. The original union witnesses existence. For every fixed parameter tuple finitely many realizable types occur, so the maximum representative size and search time are finite. No computable FPT dependence on the tuple is inferred. Replacing groups by their representatives preserves the parent's complete b-table by gluing. The real colouring is reconstructed from its matching original child records. Real boundary edges may be included in both sides without changing semantics.

Let T contain actual bag edges and all child adhesion cliques, omitting parent-only fill. Suppose T has bounded degree and external neighbourhood at least f(k)=α k^β for k≤|T|/2, where 1/2<β≤1. Bounded-size or bounded-treewidth torsos can be permitted separately. Build P on the bag from all its actual representatives. Every root participates in at most 2^Δ distinct groups since all other roots lie in its torso neighbourhood. Thus P has bounded degree. Grow disjoint connected regions in each representative from its roots and merge regions with the same root. These fibres partition P, have uniformly bounded size F, and every torso edge has a physical path in P of uniformly bounded length L.

For a shore of size k≤|P|/2, each mixed fibre contributes a distinct external neighbour. If fewer than k/(2F) fibres are mixed, each shore has at least k/2 vertices in pure fibres, hence at least ceil(k/(2F)) roots. The torso cut has at least f(ceil(k/(2F))) crossing edges. On the path for each edge choose its first exterior vertex. Its first endpoint lies within L steps in bounded-degree P, and each root has at most Δ incident torso edges, giving bounded congestion. Thus P inherits a positive constant times k^β external neighbours. Bounded-treewidth T instead gives bounded-treewidth P: for each adhesion clique use a leaf bag containing its roots and representative vertices, attached to an existing bag containing the clique.

A weak boundary row is tested inside P by guessing a coarsening of its required blocks and allocating one auxiliary colour per such block, one per closed colour. Use at most a+b connected classes. Enumerate their group sums with the prescribed merged sums after restoring root contributions. Pin interface vertices to their assigned class. An existing pin of an original colour may be in any auxiliary class of that colour: enumerate choices for the bounded number of genuine user pins and handle any artificial representative pins as below. After merging auxiliary colours additional connections do not spoil the row. Conversely use the actual component partition of a witness when guessing the coarsening. Child representatives only preserve b-colour rows; auxiliary colours are used wholly within P, then merged BEFORE requesting rows from the children.

**Pin-free representatives for unpinned groups.** A group with no original internal hard pins must be replaced by a representative without internal pins: restrict enumeration to pin-free graphs to match this type. Groups with original hard pins can be replaced by bounded representatives with boundedly many pins. Since at most p groups at any single node can contain one of the original p genuine hard pins off the bag, the resulting graph P has only a bounded number of pins from those representatives. Root pins shared by multiple groups are inherited from actual bag vertices and are counted only once. The maintained signature does not itself create hard pins in the group interior. Hence assigning eligible auxiliary classes to all pins uses bounded enumeration. The appropriate physical solver is expander-arbitrary-labels.md and isoperimetric-profiles.md, with finite-abelian corrections, or ordinary bounded-treewidth dynamic programming. Run this process bottom-up; the number of original colours in stored tables does not grow with depth.

**Constructive decomposition example.** Use a block-cut tree and standard SPQR decomposition in each nontrivial biconnected block. The adhesion of a hanging block is one vertex; SPQR child sides are joined at two poles and link those poles, so their regions are connected. Series and parallel nodes have bounded-treewidth torsos. For the class where every remaining rigid torso has uniformly bounded degree and the stated profile, this yields a deterministic decomposition and solver. A parent-only virtual edge may be omitted: deleting a single such edge from a 3-connected torso preserves connectedness, and subtracts at most one from the old neighbourhood bound, giving a positive constant times k^β (use connectedness for small k). Intermediate block nodes can be identified with a root SPQR bag containing their attachment, and each pendant block subtree attached at a chosen SPQR occurrence of its cutvertex. This yields unbounded-depth graph families with true low-order separations and no required global expansion. For general supplied decompositions with parent-only fill test the hypothesis on the torso after omitting unsupported parent fill. No result here requires that an arbitrary torso clique edge simultaneously preserve colours for every colouring.
