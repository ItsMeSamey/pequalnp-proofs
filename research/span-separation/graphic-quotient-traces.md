# Exact binary traces when the quotient is graphic

Let $E$ be a binary column family and $W$ a specified subspace of fixed dimension $d$. Suppose that the columns projected modulo $W$ represent a graphic matroid. For every prescribed $H\le W$, one can find $X\subseteq E$ satisfying $\operatorname{span}X\cap W=H$, or decide infeasibility, in deterministic polynomial time. This applies to the four-dimensional interface without any restriction on the size, rank, or connectivity of its graphic quotient.

**Graph representation.** Split the ambient space as a direct sum with $W$ and record each column's $W$ component $\sigma_e$. Realize the projected columns as the cycle matroid of a graph $G$, retaining their element labels. A realization can be computed by reducing the quotient matrix to basis form $[I\mid A]$ and applying a binary graph-realization algorithm to $A$. The fundamental circuits specify its columns in tree coordinates. Zero columns and parallel columns allow loops and parallel edges. Binary dependence vectors in a graphic representation are precisely even edge sets. Consequently the trace of $X$ equals the image under $\sigma$ of the binary cycle space of $G[X]$, where $\sigma$ sums the labels of the chosen edges. [Bixby and Wagner, *An Almost Linear-Time Algorithm for Graph Realization*](https://pubsonline.informs.org/doi/10.1287/moor.13.1.99).

**A bounded pattern.** Choose an inclusion-minimal edge set $X$ realizing $H$. Its cycle-space label map is injective. Otherwise take a nonempty even edge set of label zero and an edge $e$ in it. Every cycle-space vector using $e$ can be added to this zero-label vector to remove $e$ without changing its label. Deleting $e$ would therefore preserve the image. Likewise a bridge could be deleted without affecting any cycle. Discarding isolated vertices, the resulting graph has minimum degree two and cycle rank $b=\dim H$.

There is an empty witness for $b=0$. For $b>0$ mark every vertex of degree at least three and one vertex on each component that is a cycle. Suppress all unmarked degree-two vertices, retaining loops and parallel edges. If there are $c$ components, the sum of $\deg(v)-2$ was $2(b-c)$, so the suppressed graph has at most $2b$ vertices and $3b$ edges. Each resulting edge carries the sum of the labels along its original segment. Subdivision preserves the cycle space and its edge-label sums.

**Algorithm.** Enumerate the finitely many such multigraphs and the assignments of labels in $W$ to their edges. Discard those whose cycle-space image differs from $H$, a binary linear-algebra test. For each remaining pattern, test for a homeomorphic embedding in $G$ with the required label on each subdivided segment. Corollary 1.4 of Liu and Yoo provides this algorithm for fixed patterns and prescribed coordinate constraints. Use $d$ copies of $\mathbb Z_2$ and forbid the other bit in each coordinate. A returned subdivision realizes $H$, and the bounded-pattern argument guarantees detection whenever a witness exists. For fixed $d$ the running time is polynomial, with exponent allowed to depend on $d$. If a simple pattern or host is desired, subdivide each host edge twice using fresh vertices, assign the old label to one of the three edges, and give the other two label zero. Subdivide each pattern edge twice as well and enumerate the three segment labels with the prescribed sum. This also handles a one-loop pattern. Any union of cycles in the subdivided host uses either all or none of each old edge path. [Liu and Yoo, *Disjoint Paths Problem with Group-Expressable Constraints*, Corollary 1.4](https://people.tamu.edu/~yyoo/stoc25.pdf#page=3).

If a supplied bounded-dimensional space $W'\supseteq W$ has graphic quotient, enumerate traces $H'\le W'$ with $H'\cap W=H$ and apply the algorithm to $W'$. For span separation with $0\ne u\in K$ and $w\notin K$, take $W=K+\langle w\rangle$ and test the traces $H$ with $u\in H\subseteq K$.

## Complete graphic quotients with opposite answers

Let the quotient be the cycle matroid of the complete graph on $n\ge7$ vertices labelled from zero. It has no vertical separation. If one part of an edge partition fails to span, its spanning subgraph is disconnected. The other part contains every edge between distinct components and therefore spans. Take $W$ with basis $b_1,b_2,b_3,b_4$. Assign these labels to four distinguished edges in order and give every other edge label zero. The neutral graph is connected because deleting four edges cannot disconnect $K_n$. The full set of columns therefore has trace $W$. Define $u=b_1+b_2+b_3+b_4$, $w=b_1$, and $K$ as the kernel of the linear functional $a$ with basis values $(1,0,0,1)$.

Every representation of $u$ uses all four distinguished edges. In the NO instance they are $01,12,02,03$. The first three make a triangle of label $b_1+b_2+b_3$ outside $K$. Any subset spanning $u$ therefore also spans an element of $w+K$. In the YES instance the distinguished edges are $01,02,03,04$. Choose them together with edges $14,23$. The subgraph consists of two triangles meeting only at vertex zero. Their labels $b_1+b_4$ and $b_2+b_3$ both lie in $K$ and sum to $u$. Hence the chosen trace is a subspace of $K$ containing $u$. The two instances have identical labelled projected columns and the same total interface trace.

The checker graphic_trace_check.py enumerates edge subsets in 250 seeded small labelled multigraphs, including loops and parallel edges. All 2,114 inclusion-minimal carriers had cycle rank equal to the dimension of their trace. It also checks the full trace and both separation outcomes for $7\le n\le10$ by enumerating all separating vertex colorings. It does not implement the topological-minor subroutine.
