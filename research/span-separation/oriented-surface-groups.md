# Connected partitions with finite abelian sums on orientable surfaces

Fix a closed orientable surface of genus g, finite abelian label group Γ, part count b and a bounded number of prescribed vertex colours. For a connected cellularly embedded graph G there is a deterministic polynomial-time algorithm for a connected partition with given ordered sums for arbitrary Γ. Check conservation first. Guess distinct roots r_0,…,r_(b−1), one per part; normalize the total vertex label sum to zero by subtracting it at r_0 and in target 0. The one-part case is immediate. Use a modulus L≥2 divisible by exp Γ.

Orient primal edges; orient their duals consistently so the boundary of the primal-vertex potentials p on dual faces has coefficient p(v)−p(u) at the edge dual to u→v. This uses orientability. Choose a Γ-valued primal edge flow σ with incoming-minus-outgoing divergence equal to the normalized vertex labels; one exists by solving along a spanning tree. For a dual gradient z associated with p its evaluation sum_e z(e)σ(e) equals sum_v p(v)γ(v). Multiplication by residue classes modulo L is well-defined on Γ.

Fix a primal spanning tree T and a dual spanning tree T* disjoint from it; after contracting T the dual on the remaining edges is connected (equivalently no nonempty tree edge set is a primal cycle separating dual components). The leftover set K has size 2g by Euler's formula. For a dual flow z modulo L compute along T a potential p_T with p_T(r_0)=0 and edge differences agreeing with z on T. Keep one homology coordinate z(e)−(p_T(v)−p_T(u)) for every e∈K. If these vanish, z−gradient(p_T) is a dual circulation supported on the dual tree T*, and hence zero; the converse is immediate. These homology coordinates, p_T evaluated on each other root and pinned vertex, and evaluation against σ are linear edge functionals on a dual circulation. They therefore give signed gains for dual edges in one fixed finite abelian group.

For a subset X of dual edges let c be the component count after deleting the corresponding primal edges, and β its dual graph cycle rank. The nullhomologous circulations supported on X are precisely gradients of potentials constant on each of these c components and normalized at r_0. Their number is L^(c−1), whereas there are L^β dual circulations on X in total (the fundamental cycles of a spanning forest form a free basis even for composite L). The ratio is the size of a homology image in (Z/L)^(2g), giving β≤2g+c−1. For a valid partition take all crossing edges as X: each such edge has a nonzero coefficient in a component indicator gradient and cannot be a dual bridge. Suppress degree-two vertices, retaining one marked vertex on each cyclic component. This gives finitely many loop/multiedge shapes of size O(g+b).

Enumerate a shape and the signed gain of each oriented segment. Enumerate all its modular circulations using a spanning forest. In its list of circulations with zero homology require exactly L^(b−1) entries (count multiplicity, even for repeated gain tuples). For each i≥1 require a nullhomologous flow with nonbase root potentials the standard vector e_i. All b roots thereby lie in distinct components, so each component has exactly one root. Such a flow is uniquely the gradient of the i-th component indicator. Require its Γ-evaluation equal to the i-th desired sum and its pinned potentials to equal the required indicators. The remaining sum follows by conservation. These tests are sufficient even if a realized support X has superfluous edges.

To realize accepted gain-labelled shapes guess the branch vertices, endpoint ports and orientations, then use the oriented finite-abelian prescribed-gain disjoint paths algorithm of [Huynh](https://arxiv.org/abs/2611.34307). This tests oriented signed path gains. Subdivide dual edges twice with signed gain distributed along the path to allow distinct ports for loops and short segments. For branch vertices choose original dual vertices; every degree-two subdivision witness ultimately corresponds to a union of whole original dual edges. Delete all branches before finding mutually disjoint paths between their selected distinct neighbouring ports, adjusting the requested gains by the endpoint-edge contributions. Restore those edges afterwards. In particular the algorithm actually finds the selected X and its primal connected components. The earlier mod-two result permits nonorientable surfaces; this extension to arbitrary Γ presently assumes an orientable surface.

## Integral auxiliary graph

More generally, suppose we are given an oriented graph H on the same indexed edge set as connected G and signs identifying each primal edge coordinate with its H coordinate. Verify that every signed primal vertex cut vector is an integral circulation of H by matrix multiplication. Let d be the integer cycle rank of H minus the rank |V(G)|−1 of the primal cut lattice. The latter is primitive in the integral edge lattice: if an integer vector times a nonzero integer is a signed gradient, its own signed coordinates integrate consistently along every primal cycle and hence along a spanning tree to an integer potential. It therefore remains primitive inside H's integral cycle lattice. The quotient is a free abelian group of rank d. In fundamental cycle coordinates for H apply integer Smith normal form to the signed primal gradients; the d free coordinates give a homology map whose kernel after reduction modulo L is precisely the signed primal gradient module. H-circulations modulo L have the ordinary fundamental-cycle basis. A linear form on this module can be supplied by assigning its values to nontree edges and zero gains to the spanning forest. Root differences integrate signed primal coordinates along T, and evaluation against σ includes the supplied signs.

All preceding support-size, signature and realization arguments now apply with d in place of 2g. This yields a polynomial algorithm at fixed d,b,Γ,p for the supplied integral auxiliary-graph certificate. Only the signs and auxiliary graph are supplied; verifying the chain identity, ranks and primitivity consequences above is constructive. No method for finding such an auxiliary graph from an arbitrary host is asserted.
