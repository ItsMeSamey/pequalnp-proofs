# Original-input circuit SAT

Run `python portfolio.py circuit.json` or call `portfolio.solve(n, gates, output)`. For example, `{"n":2,"gates":[[2,4]],"output":8}` is one AND and has witness 3. The low bit of a witness is the first raw input. In an affine mask bit zero contributes constant one, bits 1 through n select raw inputs, and bit n+1+j selects earlier AND j (zero-based). Selected terms combine by XOR. Each gate multiplies its two affine operands.

The solver captures the original presentation, removes dead gates, and tries up to `rewrite_budget` conditional cofactors (default 8). Under a chosen AND operand's true branch it substitutes a pivot from that operand and freezes other selected antecedent signals. Under the false branch the AND vanishes. A rewrite is accepted only when fewer live ANDs remain. The raw variables keep their original positions.

An affine output is decided directly. Other routes run in order of increasing numerical estimate, with names breaking ties. With default `budget=4096`, the cap applies separately in each route's own units. Backward bank counts candidate transitions. Affine quotient counts image patterns or Gauss sums. Grouped mask counts grouped mask evaluations, including witness recovery. Reachable span charges symbolic and vector operations, and can decline after its initial estimate. Planning time is recorded separately. The cap does not bound wall time. Eligible but untried routes remain marked eligible after an earlier decision.

Passing `routes=[]` or CLI `--routes` disables the four optional solvers. If all decline, the solver evaluates the original netlist on successive raw words until it finds a witness or exhausts all 2^n words. Each SAT witness passes a final independent evaluation of the original netlist. UNSAT records which exact algorithm decided the instance. The verified flag specifically denotes SAT witness replay. The cost record includes raw input count, original and retained AND counts, bytes for a canonical positional JSON triple using hexadecimal strings, attempted rewrites, route budgets and estimates, fallback evaluations and elapsed nanoseconds. Run `python check_portfolio.py` and the four backend checkers for differential tests. The signed-CNF adapter preserves the original variables and also supplies a direct clause evaluator.
