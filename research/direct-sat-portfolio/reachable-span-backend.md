# Reachable physical states

The backend consumes the portfolio affine-mask AND netlist, with raw input 0 at mask bit 1 and the constant at bit 0. Its estimate is a dispatch hint. Solve enforces a hard budget on counted symbolic operations and vector steps, not on wall time or individual bit operations. It reports the charged work, largest reachable basis, and number of certified layers. A skip is inconclusive. Each charged operation has polynomial bit cost in netlist size for the default fixed degree; integer words are not assumed unit cost for asymptotic bit complexity.

The default schedule follows the given topological order with one gate per layer; optional exclusive endpoints certify consecutive banks. Introduce each original input only at its first use; carry it as a named physical state bit until its last use. Optional fresh declarations are compared with this schedule and illegal reintroduction returns skip. A final synthetic affine bank evaluates the output and handles inputs first used there. Unused input bits in witnesses are zero.

Compile the actual wire expressions in squarefree Boolean ANF, retaining polynomials affine in incoming state with fresh-control degree ≤2 (or the supplied degree bound). Both operands of each gate use the same raw variables. Rejection at an unsupported intermediate is conservative. For a bank map on augmented state, collect all monomial supports in the fresh-control coefficients, including the empty set. Evaluating at the indicator of each collected support gives actual transition matrices spanning their whole family: the subset zeta matrix restricted to those supports is triangular with ones on its diagonal, in inclusion order.

During search keep original reachable augmented vectors forming a linear basis; elimination residues are used only for independence tests. Each generated vector stores a physical raw-bit word agreeing with its full history. Fresh variables are disjoint, so assigning the current setting never alters the past. Final acceptance is linear on augmented state. Either some retained vector accepts (direct raw-word replay before return), or none accepts (certified NO). This procedure does not estimate counts.

For layer i let d be augmented-state width, s the number of active fresh monomial supports, L total output ANF size, and h≤d the reachable basis size. There are sh genuine transitions tested, costing polynomial in the widths and L, plus charged symbolic compilation. Default degree two bounds s quadratically in fresh arity. No enumeration of all original assignments is required. The separate bounded checker tests both default and whole-circuit candidate charts against brute force on small original circuits. It additionally verifies repeated physical inputs, illegal fresh reuse, nonlinear chart rejection, grouped recovery and a budget skip.
