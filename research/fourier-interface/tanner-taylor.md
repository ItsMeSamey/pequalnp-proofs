Fix a retained Tanner graph and its permanent local binary checks. Each retained edge occurs in a check because the shortened kernel has minimum distance >1. Assume m even and m≫d_G. Pair the m retained edges so each pair consists of edges with disjoint endpoints. For example the compatibility graph has minimum degree at least m−2d_G; a maximum matching must be perfect when its minimum degree is at least m/2 (two unmatched vertices with that many neighbors have an augmenting path through a matched edge). Give each pair a private logical bit x_i, and each edge e its own guard h_e. The sign-adjustable 2-clause at e has violation ANF h_e x_i or h_e+h_e x_i. All monomials with h_e belong only to e. The free logical and guard variables suffice; a dummy assignment anchor can also be taken from an inactive logical bit.

Use the first greedy-stage candidate having zero appended row, so the actual query uses the same permanent rows at every signing. Before any restriction, a row scope consists of the guard and logical variables of precisely the edges represented (with repeated logical variables deduplicated). It is independent of clause signs. The high-incidence set S is accordingly sign-independent. On the all-zero branch remove pairs touched by S (at most |S|), leaving Θ(m) pairs. On the graph of retained pairs, two pairs conflict if their edges share a Tanner endpoint. The maximum degree is at most 4d_G. A greedy independent set thus gives k=Ω(m/d_G) pairs with all 2k edges vertex-disjoint. Reserve an additional untouched inactive logical bit b as anchor and set every inactive clause to negative logical polarity (violation h_e x_i). Scope invariance after restriction follows for active rows; for inactive clauses signs are fixed. All free variables include neutral singleton scopes in the manuscript.

For each selected edge choose one permanent row containing it. All 2k chosen rows are distinct and none contains a different selected edge. In the parity-lift algebra, the constant V coefficient of each factor is 1−L, by reducing the indicator modulo Y(Y−1) at Y=0,1. Give all inputs identity replacement rows except the following occurrences. In each chosen row its selected guard uses e_h+T e_b. In the second chosen row for each pair the logical input uses (1−T)e_i. At t=1 fix all actual and auxiliary guards to zero, and fix the actual anchor to one and auxiliary anchor to zero. Then the selected guard's jet input is exactly one. The first logical input in each pair has jet x_i, the second has jet −zY_i. Nonselected guards vanish throughout, and in every unchosen row all guards vanish, including guards of selected edges. These identities hold for full Taylor series. In particular every unchosen row has constant-V factor one even when it contains sign-tuned clauses.

For support S'⊆[k], tune the second clauses to h+h x on S', h x otherwise. Their constant-V product is z^|S'| Y_{S'} times ∏_{i∉S'}(1+zY_i). Tune each first clause for 1−x_i or −x_i. Its joint product is ±δ_a(x) for arbitrary a∈{0,1}^k. Therefore [V^0 z^|S'|] on the indicated face is precisely ±δ_a(x)Y_{S'}. These are exact function witnesses in an actual fixed permanent Tanner query at identical scopes and fixed replacement rows, over the family of signings. The rows have degree one, satisfy restoration and have integral coefficients. They satisfy an admissible layout, for example r=2 with one part containing all variables and every factor assigned there. Q=2 supplies enough Taylor orders with the manuscript degree budget. One may choose larger Q subject to the order bound floor(dR/Q). This does not assert that the canonical layout realizes this rank or forces exponential runtime, and form-dependent computations are outside a single common diagonal mask claim.
