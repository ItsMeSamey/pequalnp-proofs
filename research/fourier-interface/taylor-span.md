# Tight separable Taylor query count on a normalized 2-CNF family

Let n be divisible by four, with at least two blocks of four variables. In each block choose two distinct perfect matchings, for example {12,34} and {13,24}. Put one binary clause on each matching edge and vary all literal signs independently. All normalized formulas share their scopes, and none has a subsumed or repeated clause. For every occurrence in the first matching use the constant replacement row e_i. In the second matching use (1−T)e_i. Assign the four-variable block to a single group and its clauses to that group, at every point. With one group per block this gives balanced groups, no measurements, and valid direct-product layout for R=1, Q≥2. At t=1 the first matching's clause inputs are ordinary x_i, whereas the second matching's inputs are −zY_i. The source's direct clause product has separate-incidence degree d=2n, so Q=2 yields q=n. Other admissible node counts and smaller retained jet orders give corresponding intermediate bounds.

The four literal-sign choices for a binary clause span the full four-dimensional multilinear polynomial space on its inputs over Q and over fields of characteristic other than 3. Indeed their Boolean evaluation matrix is J−I, determinant −3. Evaluation on the Boolean cube is an isomorphism on multilinear polynomials by Möbius inversion, so these are formal polynomial identities even when a substituted input is not Boolean. Since signs vary independently across clauses, the linear span of actual truncated Taylor products includes, for every Boolean a and every |S|≤min(q,n), the test

    δ_a(x) (−z)^|S| Y_S.

Use the first matching's clause spans to choose local Boolean point indicators whose product is δ_a. Use the second matching's clause spans to choose distinct monomials whose variable sets partition S. No variables or normalization steps are changed.

Suppose L sign-independent queries return jets sum_x w_j(x)G_x(y_j,z), with scalar weights and points fixed across the family, and a common linear map reconstructs the diagonal jet. By linearity it works on every test above. On that test the jth query answers w_j(a)(−z)^|S| y_j^S. The diagonal answer's coefficient at that order is (−1)^|S|a^S. Thus each function a↦a^S lies in the linear span of the SAME L weights w_j, even when the reconstruction mixes different input/output jet coefficients. Boolean monomials are independent, so

    L ≥ sum_{i=0}^{min(q,n)} binom(n,i).

The Hamming-marker procedure in taylor-regroup.md computes exactly this many separated weighted sums, with polynomial overhead on any supplied layout. Therefore this query number is sharp for the stated oracle model. It measures neither total SAT running time nor arbitrary marker-valued queries returning multiple independent x-weights. The disjoint blocks admit direct polynomial-time counting, and input-dependent weights or data-dependent reconstruction are outside the claim. The layout is a legal choice, not necessarily what the published swap compiler constructs.

In characteristic three, instead use blocks of six with triple partitions {123,456} and {124,356}. The signed ternary clauses have Boolean evaluation matrix J−I of size eight and determinant −7, nonzero in characteristic three. This gives an analogous exact bound on a normalized 3-CNF family. In every characteristic one needs a field with sufficiently many distinct interpolation points. In particular, over characteristic two one may use an extension containing t=1 and another nonzero point. The Hamming-marker identity itself requires no such restriction.
