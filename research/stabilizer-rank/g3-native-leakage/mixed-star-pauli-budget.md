# Mixed-rank stars and a Pauli support test for the remaining core

Fix a connected component of the remote cross-map graph on one G3 block. Remote orthogonal projection isolates its total T=h g^T. Independence ensures h≠0, hence T†T has the Pauli support of |g><g|. This consists of I and 28 nonidentity labels. Indeed in g's sign-flipped-plus amplitude formula each nonzero X shift gives nonzero twisted expectation on precisely four Z labels, those orthogonal to the shift, all magnitude 1/2. Nontrivial pure Z expectations vanish.

A normalized stabilizer parent of Schmidt rank r has self Gram proportional to its input code projector, supported on 8/r Paulis including I. For each original degree-one vertex of rank r≥2, the cross map to its unique neighbor is a scalar times that same input projector by the native mixed-leaf or full-leaf lemma. Its contribution and its adjoint therefore add no labels beyond the self Grams.

In particular, a mixed-rank star with all leaves of rank ≥2 is impossible. The center must have rank at least each leaf by the leaf identity. Every node thus has at most three nonidentity labels in its self Gram. All cross maps are leaf maps, so the complete T†T uses at most 7·3=21 nonidentity labels, contradicting 28. This gives a mixed-rank exclusion without assuming the result of a mixed fold is a stabilizer. It applies also to smaller components independently of other ranks outside them.

More generally form D, the union of the nonidentity Pauli supports of all node self Grams and of all cross maps on edges not already covered by an original rank≥2 leaf, including rank-one leaves if present. Every one of the 28 target labels must belong to D. For a mixed tree whose nonleaf core is a single edge and whose leaves have rank≥2, the sole core cross map must contain every target label missed by the node projectors (at least seven labels if both endpoints have rank≥2). This is a necessary test on the original physical matrices, not a sufficiency statement or a solution of all heterogeneously ranked trees.
