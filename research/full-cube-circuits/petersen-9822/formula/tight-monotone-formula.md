# Graph 9822 has monotone formula complexity eighteen

Alice holds one of the 13 positive edges. Bob holds one of the 16 maximal independent sets. They must output a vertex on the edge outside the independent set. Any monotone binary formula gives a protocol with at most as many leaves as the formula: start at the output, where Alice's assignment is true and Bob's false. At an OR Alice selects a true child; at an AND Bob selects a false child. Both assignments retain their respective truth values down to the raw leaf. Duplicate occurrences of any variable in the formula count separately. A formula of 17 gates would thus partition the 208 cells using at most 18 monochromatic rectangles, recursively splitting either the row set or the column set.

The rational cell weights in kw-exact.json sum to 18. For each label v and every nonempty subset R of edges incident to v, compute the column sums for that row set on maximal independent sets omitting v. The greatest weight of any such monochromatic rectangle is the sum of the positive column sums. The verifier checks all these bounds using exact half-integer units and verifies the independent-set list directly. No LP solver is needed for this lower bound. Since all rectangles weigh at most one, an 18-leaf protocol must use weight-one rectangles exclusively.

Each possible weight-one leaf is given by one of 54 templates. Its row set is exactly R and its columns include every strictly positive column sum and may include any zero-sum eligible columns. Other columns are forbidden. For a current submatrix, retain for each cell all templates fitting inside that submatrix and capable of containing this cell. If none remain the submatrix is impossible. If a first split is horizontal, every row appearing in all these templates must stay together with the cell's row. The analogous vertical constraint uses all columns mandatory in every such template. Take the transitive closure of these constraints separately on rows and columns. Every admissible first horizontal or vertical split is a union of the resulting blocks. The recursion tries every nonempty proper union up to exchanging children, and accepts a split exactly when both submatrices accept. Its base case recognizes precisely a single fitting template with the requested row and column sets. Thus failure is conclusive. No assumption of disjointness between different possible templates enters the recursion.

The standalone standard-library checker tight_protocol.py accepts 332 ordered two-leaf positive controls and rejects the full domain after 14,603 distinct subproblems. Run it from this directory with kw-exact.json alongside. The LP generator kw-exact.py separately checks a rational dual certificate attaining 18; this verifies optimality of the weight bound and is unnecessary for the formula proof. The eighteen-gate upper uses the six stars certified in graph-controls.py. Each star contributes one center leaf and its assigned neighbor leaves, for 6+13=19 leaves; the circuit is a formula, and the full-cube checker verifies all 1,024 inputs. This gives the exact monotone formula minimum. Arbitrary shared gates need a different lower-bound argument.
