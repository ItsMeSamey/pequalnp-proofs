# Four paid gate losses

Delete vertices 4,3,0,9 successively by setting them false. Their surviving neighbors at deletion include respectively 0,8,5,6. Thus each raw variable is essential before its deletion. Each resulting graph retains the final six-cycle, so no zero pin makes the output vanish identically. In a trimmed circuit choose a path from the deleted raw to the output. Every wire on an initial AND-only portion becomes zero after the pin; a path containing only ANDs would force the output zero. The first non-AND on this path therefore folds to a wire or a constant, for either an OR or a NOT. Trim again after restriction and repeat. This gives four distinct paid losses plus the lower bound for the terminal C6 in that same basis.

The monotone OR floor is consequently 9. For unrestricted NOT/OR paid and free AND, the auxiliary checker c6signed.cpp uses exact signatures on the 11 extremal probes, without discarding dominated signatures. Matching these probes remains necessary even when the tested function is nonmonotone. It starts with the AND closure of the inputs including true. At each paid step it tries the complement of any available signature or the union of any two, skipping old or repeated outputs; each new output h extends the bank by all old signatures intersected with h. At the last step, intersect every old signal that includes the target positive coordinates. A new paid output suffices exactly when its intersection with that combined filter equals the target. Only the first gate is quotiented by the dihedral symmetries of the cycle; the code constructs these permutations on the 11 tests and canonicalizes only the new signature. Complement-of-literal/conjunction control is checked directly.
