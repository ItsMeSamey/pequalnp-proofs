# A five- or six-gate shared helper for L-meta-9822

Run python3 -B replay.py from this directory. The target is the ten-variable graph edge function specified by graph.py. Every live fan-in-two monotone circuit with exactly one shared internal gate cuts into an inner formula H and an outer formula J. If the inner formula has l leaves, a 17-gate circuit has at most 19−l exterior leaves.

On the 13 edges record where H is true. On the 16 maximal independent sets record where H is false. Replacing H with a formula that adds good bits and costs no more preserves correctness at every extremum by monotonicity, hence everywhere. The recurrence enumerates both binary connectives and all leaf splits, retaining maximal signatures. Empty good sets on either shore can be discarded since at any useful parent the other child alone dominates, or the parent again has an empty shore. Earlier, singleton-hot, and safe cases use the sources in GLOBAL.md. For a subset P of accepted edges, a vertex cover of size k yields a star formula with |P|+k−1 gates. Where this costs no more than H, clamp its uses to zero and append that star formula. This eliminates the shared producer. 

For every remaining explicit helper representative, the full 1,024-point table forces an exterior raw occurrence whenever its change is pivotal and the helper value stays fixed. Holding the exterior helper at zero forces all supersets of uncovered positive edges true and every independent input false. Holding it at one forces all positive inputs true and all subsets of accepted maximal independent sets false. If two raw variables realize both AND and OR sections under these constraints, one must repeat as a leaf because the least common ancestor of two unique leaves has a fixed connective. Minimum vertex cover counts jointly required repetitions. Two further helper leaves are necessary or the whole circuit is a formula. replay.log gives all counts and a deterministic interface digest.
