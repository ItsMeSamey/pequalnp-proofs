# Direct labels under a common conditional activation

Take any number of always-reached outer AND switches and any positive number of conditionally reached switches. Suppose the latter all use the same proper nonempty activation A, a disjunction of ordinary signed literals on always-reached axes. The extra inverter receiver Z can be any union of branch masks. Its intended input is the complement of an arbitrary monotone guard. Let D be any raw labels represented by single branches on distinct switches. If G[D] contains an edge, then G[D] is a complete bipartite graph plus isolated vertices.

The direct labels can all be omitted in a single direction (choose all their bits opposite their signs). Thus K0(D)=0, and the assumed edge forces H(D)=0. On subsets of D, K1 therefore agrees with G[D]; in particular its empty set and every direct singleton are rejected.

An active collection of receiver masks covers the direction cube if and only if it includes an ordinary complementary pair, or else contains both a literal opposing a term of A and the two opposite conditional signs on some single switch. Indeed, if no conditional sign pair is collected, choose the freely variable conditional bits to avoid all active conditional rays. If a pair is collected these rays fill precisely A; any other conditional rays are subsets thereof. The ordinary literal union alone is tautological exactly when it contains an ordinary complementary pair; adjoining A otherwise makes it full exactly when it contains an ordinary literal opposite to a term of A.

On any subset of D with Z present, ordinary complementary pairs cannot arise. A pair inside Z accepts the empty input, one involving a direct and Z accepts a singleton, and two different directs use different axes. If Z already contains a conditional sign pair then any opposing ordinary term from Z or one of D would accept the empty set or that singleton; if none exists D has no edge. So Z contains no conditional opposite pair. Some direct conditional sign must pair with its opposite in Z to obtain an edge, since distinct directs use different axes. If Z contains an opposing ordinary literal, that paired direct alone would be accepted. Therefore all opposing ordinary literals come from directs.

Write T for direct conditional vertices paired by Z, and O for ordinary directs opposing a term of A. It follows that the induced positive predicate on subsets of D is precisely “meets T and meets O.” This gives the assertion with every edge between T and O present. In a four-cycle-free target this is one star plus isolated vertices. In particular the ten-vertex target has independence number four, so every set of six direct raws has vertex-cover number at least two. No six-direct profile with a common conditional activation can realize the target. The argument does not price the inverter receiver or require a bound on reverse unions. It also excludes five-direct sets containing two vertex-disjoint edges under the same activation hypothesis.
