# Exact OR cost for ordered physical operand scopes

Give each raw and each preceding AND result its own formal source label. Every actual input to a fixed ordered AND slot, and optionally the output, specifies a disjunction of such labels. Allow unrestricted fanout and count binary ORs. Empty supports are internal zero and singletons are aliases. Compute identical targets once. This prices the specified labeled operands; agreement on a test set or a semantic containment between hidden Boolean signals never licenses changing them. Even if a cheaper equivalent circuit exists, the formula prices the original formal scope family. Formal zero is available if a promised scope is empty; without an available zero, an actual nonempty-only instance simply omits it.

Let T be the distinct targets of size at least two. A library L consists of supports of size at least two, each contained in the intersection of two distinct members of T. Every library support must be the union of two proper smaller supports from L or raw singleton labels (including preceding AND result labels). For S in T let c(S,L) be the fewest singleton or library supports whose union is S. The empty library is admissible. If a target support also serves a larger target, its own output port counts as one of the two distinct descendants, so this support may itself be a library member. Multiple ports requesting the same scope may all use the earliest copy. The exact minimum OR count equals

    min_L ( |L| + sum_S (c(S,L) - 1) ).

For the lower bound delete unused gates; an OR with the support of an operand is an alias. Equal-support gates can be merged into the earlier instance, also when two target occurrences were originally implemented separately. Call an OR public if at least two distinct deduplicated target ports are reachable by OR-only paths. Its support lies in the intersection of their target scopes. All its OR ancestors are public by reachability, so the distinct supports of public ORs give a buildable L. Every remaining live OR reaches exactly one distinct target. Stop the private cone of that target at singleton sources and public gates. Its m distinct boundary signals cover S. A connected binary DAG joining m distinct sources to one outlet needs at least m−1 other vertices, even with reconvergence. A public target already has c=1. Summing counts each private gate once.

Conversely construct each library signal once, then join a minimum cover of each target. To restore AND chronology, tag every OR gate with the index of its latest primitive (raw sources precede the AND slots). Tags are nondecreasing on dependencies; schedule each group after its latest primitive, topologically inside each group. A library support lies in every target it serves. Its latest primitive is therefore born strictly before the earliest AND slot observing it. At equal latest-birth index put proper-subset public gates before supersets (increasing support size suffices), then construct private target joins. Library and private nodes scheduled this way leave the original AND order unchanged. Every target operand is required strictly after all its primitive labels. No shared signal uses a later AND prematurely. If a collector cut was used, its gate-count refund must be proved separately. The uncut version can include the collector as an additional target.

If every pair of distinct targets intersects in at most two labels, L is just a set E of shared pairs, costing one OR per pair. Then c(S,L)=|S|−ν(E[S]), with ν the maximum matching size. A matching plus the remaining singletons attains this. In any cover by edges and singletons, each nontrivial connected component of chosen edges on t vertices costs at least t−1 edges; each isolated vertex costs a singleton. A matching can take a disjoint edge in each nontrivial component, yielding the reverse inequality. Thus this regime admits an exact cost formula; no polynomial-time library search for arbitrary targets is asserted.
