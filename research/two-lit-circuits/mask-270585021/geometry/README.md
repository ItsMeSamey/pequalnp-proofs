# Exact ten-gate minimum on the singleton/pair target 270585021

There are 21 promised inputs. Input (i,j), with 0≤i≤j<6, sets bits i and j; the diagonal sets exactly one bit. The physical target uses bit 6i+j in integer 270585021. In lexicographic triangular order the same truth function is 302717.

Every raw bit is essential. For bits x0 through x5, respective singleton indices 1,0,1,1,2,2 witness this: adding the chosen bit to that singleton flips the target. A live normalized circuit using six raws must have at least five binary gates. Indeed binary gates can merge at most two source components in the transitive output DAG; unary gates merge none. For any circuit of size at most nine the five budgets (binary, NOT) are therefore (5,4), (6,3), (7,2), (8,1), (9,0), allowing unused budget. Nullary, out-of-range, ignored and copying operands may be normalized by evaluating constants or bypassing an identity; a nonconstant result needs no constant gate. Dead or semantically redundant gate outputs can likewise be removed, as fanout is unrestricted.

independent.py searches sets of simultaneous live truth signatures. Choose one signature for NOT or two distinct ones for AND/OR, append the new value and optionally retain each input operand for a later use. An operand at its last read is removed. This includes forks at either raw or internal wires. Reusing a live identical value cannot require a new gate; constants need no gates in a minimum circuit. With b binary gates left and a current live set of size s, at most b+1−s retained-operand events are possible, since each binary gate can lower the set size by at most one and each extra read offsets one such decrease. All other current features must be used eventually in a live realization. If two cells with different targets have identical live features, reject. With only monotone operations remaining, each positive-negative pair must have some live feature that is true on the positive and false on the negative. Sorting feature values and bounded memoization preserve future realizability.

All five budget decisions rejected (lower.log). The independent C++ counterpart reports the same five outcomes. For a matching ten-gate circuit set A=x0, B=x1, C=x2∨x3, D=x4 and E=x5. The required output is ¬[(B∧(A∨C))∨(C∧D)∨(E∧¬(A∨B))]. The merged C accounts for one gate and the displayed expression accounts for nine. Bypassing A∨C to C gives a size-nine control, changing only (0,1), dense target 302719. The script evaluates both circuits on all 21 physical inputs. Its search also independently accepts the neighboring target with seven binary gates and two NOTs, and the original target with eight binary gates and two NOTs (positive.log).

Run python independent.py and python independent.py --positive from this directory. This is a reproducible finite lower bound plus an explicit upper bound. No official desk mutation or kernel-checked Lean lower-bound theorem is included.
