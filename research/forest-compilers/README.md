# What exact forest and matching compilers can preserve

## Explicit and succinct yes/no reductions

An adaptive deterministic solver using explicit polynomial-time forest or matching oracles costs O(R+∑T(m_i)), where R covers query construction and control, m_i are actual query lengths and T is the chosen oracle solver's time. Polynomial R and query bounds put the original language in P. Conversely a polynomial-time SAT decider could output fixed yes/no forest instances. No bound on exact model *representations* alone resolves this decision question.

A succinct encoding gives a sharply different result even on a predetermined path. For a CNF F on n bits set N=2^n. Use path variables y₀,…,y_N, units y₀ and ¬y_N, and one binary clause on each edge. Edge i has clause (¬y_i ∨ y_{i+1}) if assignment i falsifies F, and (¬y_i ∨ ¬y_{i+1}) otherwise. If there is a satisfying index, assign ones through the first such index and zeros thereafter. If every edge has the first sign, implications contradict the units. Every clause-variable incidence graph is literally a path, regardless of the sign sequence. A polynomial-size circuit specifying the sign on binary index i just evaluates F(i). The restricted succinct problem is NP-complete: a sign-changing index is its certificate. The explicit path costs Θ(2^n) clauses.

For a fixed-width source CNF and b free suffix bits, replace each edge by the corresponding prefix test: change its sign when its residual b-variable formula is satisfiable. This gives 2^{n−b} explicit edges. Using the fixed-width counting theorem, compiling those bits costs poly(input) times 2^{n−b+O(b log log b/√log b)}, with the small logarithms truncated. Thus making the output polynomial in the input size can leave the expensive work in compilation. This is an upper bound on this construction. [Fixed-width counting theorem](https://github.com/openai/math/tree/main/preprints/The-Exponential-Time-Hypothesis-is-False-October-25-2026)

## Exact disjunctions of projected forests

For bounded-degree expander G the positive vertex-cover CNF F_G=∧_{ij∈E}(x_i∨x_j) has strongly exponential DNNF size. A polynomial-sized Boolean bounded-arity forest CSP compiles to polynomial-sized DNNF by rooted messages conditioned on the shared boundary variable. At a variable branch on its Boolean value; once fixed, factor branches use disjoint remaining variables. At a factor enumerate its constant number of compatible tuples, and conjoin child messages after instantiating their boundary variables. Cache each conditioned message. Existential forgetting in DNNF replaces the forgotten literals by true and preserves the represented projection, because each AND has disjoint variable scopes. Disjoining any polynomial list of such projected forest representations would therefore contradict the expander bound. The disjuncts may use different forest layouts and auxiliary variables. Every such F_G is satisfiable. [Bova et al.](https://arxiv.org/abs/1411.1995)

## Matching images and code distance

A gadget graph has optional terminals and mandatory internal vertices. A terminal deletion pattern is feasible when the graph remaining after deletion admits a perfect matching. Feasible patterns are connected by moves of Hamming distance two. In fact the symmetric difference of matchings for two patterns consists of alternating cycles and paths. Flip the paths one at a time; only each path's endpoints change covered status, and both endpoints are terminals. Existential omission of hidden terminal coordinates preserves connectivity by moves of distance at most two. This is the usual matching-realizable delta-matroid exchange argument. [Kazda, Kolmogorov and Rolínek](https://arxiv.org/abs/1602.03124)

More generally, let a total decoder from terminal patterns to Boolean outputs be Δ-Lipschitz in Hamming distance. Any two decoded feasible patterns can be joined within the image by steps of distance at most 2Δ. If the image is contained in a code of minimum distance exceeding 2Δ then the image is empty or a singleton. Thus an exact disjunction representing that code needs at least its cardinality in images, irrespective of gadget sizes. The conclusion requires *every* feasible pattern to decode soundly; restricting to an independently specified promise subset beforehand can destroy the connectivity.

For coordinate projection take the binary Hamming code with parity-check columns all nonzero m-bit vectors. With n=2^m−1 it has dimension n−m and distance three, since the columns are nonzero and distinct and some three sum to zero. This forces 2^n/(n+1) matching disjuncts. The code is the visible solution set of a linear-size bounded-degree width-three CNF. Compute all syndrome parities recursively by splitting column labels on their high bit. Combine corresponding lower syndrome bits by XOR, take the right half total parity as the high syndrome, and maintain the block total by XOR. A block on 2^m positions takes 2T(m−1)+O(m) binary gates, hence O(2^m). Label zero is a pinned dummy zero. Each gate value has bounded fanout (COPY aliases may be used); imposing XOR gates by their four constant-width clauses gives constant variable occurrence and unique extension. Pin the final syndrome to zero.

For a general Δ, use 2Δ+1 equal copies per message bit instead; chains of equalities define a bounded-degree CNF with 2^{floor(n/(2Δ+1))} codewords (pin surplus coordinates if necessary). The bound excludes polynomially many total matching images for Δ=o(n/log n).

A single family obstructs a heterogeneous disjunction. Repeat each vertex-cover bit of F_G precisely 2Δ+1 times and impose equality chains, with the original edge constraints on representatives. For fixed Δ this has linear size and bounded degree. Distinct visible solutions have distance greater than 2Δ. Each sound matching image contributes at most one solution, expressible as a linear-size conjunction. If an exact union of polynomially many such images and polynomially many polynomial-sized projected forests existed, compiling them to DNNF and forgetting repetitions would contradict the expander bound. The forest part uses coordinate projection, not arbitrary functional decoding. The family has the all-ones solution and is easy to decide.

## Arbitrary polynomial-time total decoders

Any satisfiable F has a small exact image under an unrestricted total circuit decoder. Take a forest of n free bits z. Hardwire one satisfying witness w and output z when F(z) holds, w otherwise. An equivalent matching source uses n disjoint edges with both endpoints optional; deleting neither or both encodes an arbitrary bit. Unsatisfiable formulas have an empty source. Hardwiring w establishes existence of a polynomial-size description for each F without giving a uniform compiler. A polynomial-time uniform compiler with easy source feasibility exists exactly if P=NP. In the forward direction decide source feasibility. In the converse direction use a SAT decider and self-reduction to find w. For matching sources, checking feasibility with optional deletions amounts to finding a matching covering all mandatory vertices, which is polynomial-time by weighted matching.

If the decoder can emit a failure symbol which is discarded, F itself supplies an immediate uniform decoder from free bits: emit z if valid and failure otherwise. In that model testing whether the retained image is nonempty recovers SAT. For global affine decoders even ordinary linear codes already have a small image via their generator matrix. These observations explain why locality and total soundness matter to the matching-image lower bound.
