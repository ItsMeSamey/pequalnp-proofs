# Marked directed systems with certified binary-clause relaxations

Eliminate the parity equality by Gaussian parametrization x(v). Substitute into all g_i=x_i(Mx)_i using Boolean squarefree polynomials. Start H as the empty ordinary 2-CNF. Invariant: every original solution satisfies H.

If H is inconsistent return NO. Fix a model a; flip supports in z=v+a are closed under intersection by taking coordinatewise majority with a. For each set F of at most two flip indices with a model extending F, compute C_F, the intersection of all model supports extending F. This is obtainable by asking which coordinates are forced in the pinned 2-CNF and is itself a model. On any achievable S the monomial z_F equals the inclusion test C_F subset S; an infeasible F gives zero. On the distinct closures the matrix of these tests (one column per closure) is inclusion triangular with diagonal ones. Thus evaluating degree-two functions on these <=1+n+binom(n,2) representative models computes the entire quadratic vanishing space I_2(H) by elimination. Mastrolilli already proved polynomial-time fixed-degree ideal membership for majority-invariant (bijunctive) systems; this translated-intersection proof supplies explicit representative solutions for this use. See https://doi.org/10.1137/1.9781611975482.29 .

Compute span(g_i)+I_2(H). If it contains 1, reject. Add ordinary unit or binary clauses whose falsifier polynomials lie in that span: all original solutions still satisfy H. A model of H satisfying all g_i lifts to an actual witness. If every g_i vanishes on H any model works. Return UNKNOWN at a stable relaxation otherwise; failure of this sufficient syntactic proof is not a NO. Each strict iteration adds one of polynomially many clauses and all vector spaces have O(n²) coordinates. Optional Gaussian propagation restricts to all affine forms in the certified span and restarts on an injectively parameterized smaller data space. Every original solution is preserved and every strict restart drops dimension. Verify positive outputs on the original nonsymmetric input.
