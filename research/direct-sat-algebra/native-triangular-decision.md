# Ordered low-rank correction for marked decision

In an ordered binary matrix G prescribe every strictly lower entry of a matrix L, leaving diagonal and upper entries free. The minimum rank completion makes D=G+L triangular off diagonal. Working from the last row upward, a row can be chosen in the span of completed later rows exactly when its prescribed prefix belongs to their restriction to that prefix. If not, every completion incurs a rank increase there (all later entries in that prefix are prescribed). Thus this greedy construction simultaneously attains all compulsory increments. This is a scalar specialization of Woerdeman's arbitrary-field triangular matrix completion formula, https://arxiv.org/pdf/math/0608130#page=3 . Use a supplied order or the input order; optimizing over permutations is not claimed.

Factor L=UV^T with rank r and enumerate v=V^T x. Its contribution Uv shifts the required diagonal parities in acyclic D. Impose the r equations V^T x=v plus the original mark. A topological pass generates every feasible DAG support: process vertices whose dependency inputs are already assigned; either set that vertex zero or set it to its affine enable bit. Each alternative is an affine update, so its pullback preserves polynomials of degree at most r+1. Track a linearly independent set of degree-(r+1) squarefree evaluation vectors of reachable Boolean states, retaining actual states. After each layer the images of the previous retained states under both updates span every reachable evaluation vector by linearity. The final parity-system indicator has degree at most r+1; if it is nonzero on any solution it is nonzero on a retained state. Check the recovered state in the original matrix. Cost 2^r poly(n, sum_{j<=r+1}binom(n,j)); complete decision/search, no full count claimed. The native exact counter can be hard on an acyclic dependency graph with isolated marked vertex; it measures a different task.

Separation of specific structural hypotheses: take L,R disjoint ordered groups of even size m. Orient all edges forward within each group and both directions across groups. Start from the complete forward tournament on L then R and add the one outer product for the backward cross arcs. Give all rows loops and mark odd total population. Two consecutive selected vertices within a group see predecessor counts differing by one, with common cross contribution, so there is at most one per group. A singleton fails and a cross pair has the wrong parity, hence NO. The native digraph is strongly connected with at least m disjoint directed 2-cycles; the skew defect has two full-rank binary off-diagonal-all-ones blocks, giving rank 2m. Thus the order-rank-one solver succeeds beyond bounded feedback and marked-slice rank-two symmetric repair. No claim that all other structural solvers abstain.
