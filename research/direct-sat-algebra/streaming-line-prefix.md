# Polynomial-space prefix search

Assume the supplied field chart and original trace-self-adjoint columns of sparse-line-prefix.md. Store only the h selected affine trace factors. On the nonzero half-field line an exponent is a residue modulo H=2^a−1. Enumerate residues of Hamming weight at most h via combinations. For each residue r compute its prefix coefficient independently.

For each subset T of the h factors, form the elementary symmetric polynomials E_n of the digit weights indexed by T separately at every digit i. The weights are the coefficients of the corresponding T^(2^i) monomial, with the indeterminate distinguished from the subset T. Use another bin of elementary symmetric polynomials for the optional constant terms. The digit dynamic program counts exactly h picks, and updates carry to (carry+n−bit_i(r))/2 only for nonnegative integral results. The constant bin contributes picks and no exponent. Require the final carry to equal the initial carry and try all initial values 0 through h. Each allocation of exponent sum e in the required residue has unique cyclic start (e−r)/H, even for residue zero. Repeated occurrences across bins are temporarily allowed.

An allocation using factor set U is counted for 2^(h−|U|) supersets. In characteristic two it survives exactly if U contains every factor, in which case exactly h picks mean every factor is used once. This proves the exact coefficient modulo the torus relation. It covers repeated trace factors, zero constants, and wrapped exponents without ordering the factors inside a bin. Each subset costs polynomially many bit operations; its temporary state has polynomial size.

For h=floor(3a/25), generating all these coefficients costs O*(2^((H_2(.12)+.12)a)) below 2^(.65a). The transfer bound for the independently streamed moments remains O*(2^(.88a)) per prefix step. The suffix scan has the same bound. Polynomially many prefix steps and original rank replay preserve O*(2^(11d/25)) bit time. There is no subset- or residue-indexed cache. Digit states use polynomially many keys and the moment traversal has an explicit stack. Total bit space is polynomial; the time guarantee uses the default prefix depth.
