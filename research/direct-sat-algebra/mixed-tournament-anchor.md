# Unbounded supports and the single-mark boundary

Here, bit j in off-diagonal row i means i sees j (the outgoing-degree convention). Transposing the tournament exchanges this with the incoming-degree convention of uniform-tournament-four-witness.md without changing that theorem.

On n vertices let i see i+1, and on nonconsecutive pairs let the larger vertex see the smaller. Set d_i=(max(i-1,0) mod 2) XOR [i+1<n] and mark vertex 0. Once vertices 0,...,i are selected, row i sees max(i-1,0) earlier selected vertices and its sole possible future neighbor i+1. The loop setting forces x_{i+1}=1 for i<n-1, and the last gate holds. Thus there is exactly one witness, of size n. This family is strongly connected for n>=3.

A mixed-loop instance reduces disjointly to three uniform-loop-one tournament instances with the original mark and at most three additional pins. Introduce a selected vertex p; each old i sees p exactly when d_i=0. Then old rows simulate the original. Write delta=d*x and t=sum x mod 2. With p alone its row requires delta=1. Alternatively add selected q seeing all old vertices and make p see q: the two rows require delta=0 and t=1. Finally with p and two selected pads, each pad seeing all old bits, orient the three anchors in a directed triangle. Their rows require delta=t=0. These cases partition original witnesses. If n is 2 or 3 mod 4 in the unique-witness construction, delta equals binom(n,2) mod 2 =1 by summing the tournament degrees. Its first uniform extension therefore has two named pins (old 0 and new p) and unique support of size n+1, unbounded. This refutes extending the single-mark four-vertex size bound to two pins.

One-open-row augmentation is additionally insufficient. Let the off-diagonals be [14,20,24,18,1], diagonal-included rows [15,20,24,18,17], and mark=16. Proper nonempty feasible words are exactly 2,3,4,5,8,9. Only the full five bits meet the mark. In a path augmentation with only the last selected row still failing, a new vertex must be seen by the previous last row and no earlier selected row, hence the induced order has consecutive-forward, all-other-backward orientation. None of the 120 orders of this five-tournament does. It is strongly connected. An infinite extension adds a fresh marked p seeing only the old marked vertex and sets d_p=1. Flip each old diagonal when its row sees p; with p pinned, old equations are restored and its row forces the old mark. The old strong five-core persists. Every induced strong subtournament of a consecutive-forward/backward order occupies a consecutive interval (a missing intermediate vertex makes the later selected segment dominate the earlier one). Thus these extensions do not admit the one-open-row path certificate either. More general multi-frontier methods remain possible.
