# A deterministic Gram obstruction to a target fiber

For the supplied list of d distinct binary characters write v(y)_s=(−1)^(s·y). The unnormalized rational Gram matrix G sums v(q(x))v(q(x))ᵀ over inputs. Each entry is one quadratic character sum at s XOR t, so the code queries at most binom(d,2) distinct nonzero masks and uses the known value 2^n at zero. The default dictionary is the constant plus all singleton signs. A supplied phase budget preflights these queries before any elimination.

If v(t) lies outside the column span of G, symmetry provides a rational null vector w with wᵀv(t)≠0. The identity wᵀGw=Σ_x(wᵀv(q(x)))² proves w vanishes on the whole image. The code returns its primitive integer coefficients. Otherwise solve Gz=v(t) with free coordinates zero. Put E=zᵀv(t)=Σ_x(zᵀv(q(x)))². For true target fiber size C, the target inputs alone contribute C E². Hence C≤floor(1/E) if E>0; E=0 can occur only for an empty dictionary. The code returns UNSAT if that integral upper bound is zero. For positive bounds it checks whether the interpolant is an exact target indicator. These are exact rational tests and require no floating-point rank threshold.

Biases and signs have at most n+2 signed bits. By Hadamard, all minors of the augmented integer matrix [G|v(t)] have O(d(n+log(d+1))) bits. During sequential pivot elimination, reduced entries are ratios of pivot minors and bordered minors (permuting pivot rows/columns as needed); the temporary products or differences of two such reduced fractions have the same asymptotic bit bound. The free-column null vector and basic solution have a common pivot determinant denominator, so clearing denominators and summing for E preserve polynomial bit complexity. Gram elimination takes cubic rational arithmetic after constructing d² entries. The phase budget limits Gauss calls, including subsequent pinning, independently of the cost of rational arithmetic.

On two input bits the four indicators of 00,10,01,11 are explicit quadratics with one-hot joint image. The weight-three target 0111 is absent, but every single parity observation at that target occurs on an attained word: constant masks and all-ones agree by odd weight, and every other mask takes both values. All singleton signs together have the exact rational identity Σ_j v_j=2 on the image, violated by the target. Appending p independently attainable AND outputs on fresh disjoint input pairs gives image size 4·2^p while preserving this certificate and failure of every single parity probe. Any parity using a padding output takes both values. The common polar radical is zero: the x₀x₁ monomial supplies a nondegenerate pair on the original bits, and the p new monomials separately cover the remaining pairs. Discarding two indicator outputs instead gives a three-point image with masses (2,1,1) on (00,01,10). The target 11 lies in the feature span, but E=1/2+1+1 gives a zero integral upper bound.

Conversely the singleton dictionary may miss absent points. On m≥3 output coordinates use an even-parity image with uniform multiplicities (the last coordinate is the XOR of m−1 independent bits). Singleton signs and the constant are mutually orthogonal except when m≤2. G=2^(m−1) I, so all targets have the same E=(m+1)/2^(m−1)≤1, including odd-parity targets. A richer dictionary can exploit known relations, whereas the default rule makes no completeness claim.

## Positive target counting by certification on the actual image

If E>0, set g(y)=zᵀv(y) and p(y)=g(y)/E, so p(t)=1. For each output bit j, compute Σ_x g(q(x))² χ_j(t)χ_j(q(x)). It can never exceed E=Σ_x g(q(x))². Equality for every j means each mismatch supports zero squared mass. Thus p vanishes on every attained output other than t; on t it is one. This proves C=Σ_x p(q(x))²=1/E exactly. The positivity of E ensures a witness exists. Restrict each successive input bit to zero and test its unnormalized squared norm; on zero norm choose one, otherwise keep zero. Positivity is inherited at each step, and the solver verifies the final assignment against the input forms.

Expand g² in characters by XOR convolution of the d rational coefficients of z; after collecting masks this uses D≤1+binom(d,2) terms. At most mD additional unrestricted biases and nD pinned biases suffice, sharing cached unrestricted entries with the original Gram calculation. Each restriction uses a fresh cache; the constant bias on any slice is known without a Gauss call. Products of solution coefficients have a common squared determinant denominator, so their sums and bias-weighted moments still have polynomial bit length. Exhaustion at any point, including after indicator verification but before witness recovery, returns UNKNOWN. A positive result always contains the exact count and a checked witness.

The map (h,hx₁,…,hx_p) has 1+2^p outputs, and its all-zero target fiber has size 2^p. Its target indicator (1+χ_h)/2 belongs to the default span. In general when the true indicator on the attained image lies in this span and the target occurs, minimum-norm interpolation agrees with that indicator: every interpolant equals one on that fiber and incurs a nonnegative squared cost off it; the indicator attains the minimum. The even-parity example above illustrates the opposite case. For m=4 and an absent odd target, the target vector belongs to the span, E=5/8, and the integer upper bound is one. The coordinate mismatch test cannot pass because E>0 while the target fiber is empty. This yields UNKNOWN.
