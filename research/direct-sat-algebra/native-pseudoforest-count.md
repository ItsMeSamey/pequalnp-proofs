# Native binary-clause components have at most two independent cycles

On beta*x=1 choose only this mark as an affine restriction; beta=0 has no witness. The linear parts v_i of all k original coordinates on the resulting k-1 data bits have exactly one linear dependency, since the annihilator of the direction space is span(beta). Each nontrivial physical rank-two row forbids one affine codimension-two flat. In the selected pair of normal directions it contributes one binary exclusion; those two directions span its original v_i. For every edge set J its incident normal vertices therefore span rank >=|J|-1. Consequently |J|<=#incident vertices+1 and each connected multigraph component has cyclomatic number <=2. Parallel edges counted separately; unary, constant and trivial exclusions do not add nonloop edges. Extra restrictions beyond the mark require paying their added nullity. Unspecialized 2-CNF inputs lack the native rank bound.

On selected normal bits B enforce their h=|B|-rank(B) code checks by 2^h binary characters. In each component take a spanning tree; at most two residual edges remain. Condition one endpoint per residual edge (at most four possibilities) and run ordinary exact signed two-spin tree DP with all original unary/edge factors. Multiply components and normalize the Walsh sum by 2^h. Multiply by 2^(k-1-rank(B)) for free original data coordinates. The result counts original marked words, not independent choices of external controls. Pinning normal bits by unary factors preserves graph and h; recover a positive word, Gaussian-lift, and verify original equations. Bit lengths are O(k+h+|B|); runtime 2^h poly(k) and polynomial space after layout selection. Any polynomial-cost choice of two generators per plane is valid; optimal layouts can require extra search which is charged separately. h may be linear. Generic affine flats do not inherit this FPT result.

The checker verifies 4096 exhaustive raw counts and 450 random count/witness outputs, a bicyclic component and the six-row control with unique witness 55 for each of six pivots. The signed triangle route remains available for general 2-CNF plus linear checks; this source-specific solver has the stronger clock for small native defects.
