The separate successor consumes the original affine/AND mask API or signed CNF via solve_cnf. Every positive root AND is trimmed to its two operand cones, retaining original raw IDs. Raw-affine readouts are decided directly. Other shapes can return skip.

The peel_steps guard is a polynomial planning metric in raw dimension and cone lengths, not an instruction counter; the actual elimination, pivot sorting and gate validation carry polynomial bit overhead. One remaining gate index decreases per live iteration. cell_pairs bounds actual Cartesian branch count of the two explicit accepting affine-cell lists. If this route proves no answer, each cone can be compiled once under its disjoint share of cell_cap and its own rank_cap. The compiled programs remain in memory for both fixed-order tests, both any-order tests, and the final joint test. The default uses the first independently proposed order in each cone; explicit orders are also accepted. linear_work limits analytic bounds on candidate scans, rather than elapsed time, Gaussian operations, or memory. The any-order bound uses at most n(n+1)/2 cofactor tests, n layers per test, and 2(2w+1) candidate paired rows per layer (including the affine coordinate). The joint test uses at most n+1 last-reset cases. If all admissible stages decline or exceed budget, status is skip. SAT witnesses replay on the native original circuit; CNF witnesses also replay on the source clauses.

Source modules are the sibling two-order-native factor compiler, two-order-proposer proposer, compression fixed/any-order recognizers and last-reset solver, direct-sat-algebra backward_reset_peel, and direct-sat-portfolio original_cnf. No external theorem or exponential general SAT speedup is assumed. Run python check_successor.py for the changed paths.
