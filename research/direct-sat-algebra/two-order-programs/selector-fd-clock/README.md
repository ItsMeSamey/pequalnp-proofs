# Structural preflight for original guarded CNF

Materialize original input and clause iterators once, then build the existing proxy chart. For each grouped prefix scope of at most three sites, use its at most eight local assignments to test each functional dependency X→y. Close the processed selector names under these dependencies. Two prefix models sharing a selector history agree on this closure by induction, so the number c of remaining undetermined frontier names bounds the nonfixed sites for every nonempty prefix relation.

Compute the joint translation kernel of all remaining grouped physical factors, freezing all processed selectors but allowing unprocessed selectors in its physical lift. If its projection on the b crossing names has rank r, d=b−r is exact for this verified symmetry group. Both parameters are computed without prefix enumeration, in polynomial time in the input and declared dimension.

For each of the at most c nonfixed names choose its position; on a chosen h-set the residual 2CNF has at most 2^{2h+4 binom(h,2)} descriptions, by its unary and binary forbidden patterns. Full frontier translations can move every other pinned bit to zero, and each such full orbit splits into at most 2^d projected-kernel orbits. Summing over h yields the implemented K=2^d sum_h binom(b,h) 2^{2h+4 binom(h,2)}. A partial positive sum already above the cap suffices to skip, not to reject. All preflight stages precede any binary probe or candidate generation.

Every actual orbit key comprises the locally canonical projection tables and their simultaneous phase syndrome modulo the physical tail kernel. The scopes and their order are constant at a given cut. One byte per table plus a fixed-width phase of at most two bits per scope encodes this key without collisions. The fixed-alphabet trie has polynomial per-key lookup cost regardless of how many prefixes reached the cut. The implementation keeps one real selector prefix per key; final 2SAT solves and original CNF replay recover the actual witness. This is an equality-only solver, separate from the pairwise proper-containment wrapper.

At most 1+2 sum_i K_i candidates are generated, summing over nonterminal cuts. Each candidate needs polynomial time in source size. Fixed c and d logarithmic in source size certify polynomial time on this recognizable class even at unbounded frontier width. The tests include a source attaining 2^d states and a source with a loose structural upper bound but only one actual key. Only the tests use exhaustive small truth tables.
