# Polynomial reordering and an original-circuit application

A complete two-state read-once program on n bits has GF(2) weighted width at most 2(n+1) in *every* other bit order. Use the last-reset partition from two-order-width-two.md. Each branch membership indicator is a product of unary permissions and an affine parity indicator, computed by width two in any order. The branches are disjoint, so XOR of their indicators is the same Boolean predicate. Take the block direct sum of those n+1 reordered programs, with concatenated initial/final vectors. At fixed n the result has O(n^2) nonzero matrix entries in all layers, or O(n^3) bits if emitted dense. For a rejecting/accepting final set of zero or two labels the same conclusion holds by constant output.

Consequently an original final AND whose first factor has a *certified* complete width-two presentation and whose second factor has a compact weighted presentation can always use the second factor's order as a common weighted order. The gain available from separate compilation is a bound on the cost of building the first factor's representation in that order. There is no lower bound on the final product's best weighted width from conflicting orders on this class. A measured first-presentation decline at a given budget has to be distinguished from a lower bound on all compiler schedules or existential decision.

A direct, efficiently recognized original presentation consists of an acyclic chain of affine two-state updates s_i = a_i(x_i) s_{i-1} + b_i(x_i) on distinct single-bit raw inputs, where the coefficients are arbitrary unary affine forms. Recognize it by parsing the actual gate operands and comparands in the normalized XOR-AND netlist, verifying all recurrences including initial and final constants; a supplied certificate is equally checkable by local identities. In a different raw order even the weighted representation of each *prefix* of this chain has width O(n) by the same argument, so a straightforward common-order compiler with polynomial local rank bounds already suffices for literal syntactic chains if their intermediate wires are just these prefixes and unary forms. Search for stronger empirical gains must therefore include more elaborate original presentations or actual resource differences.
