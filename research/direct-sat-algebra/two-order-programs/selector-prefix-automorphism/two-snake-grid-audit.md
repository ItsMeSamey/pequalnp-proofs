# Constant whole-clock state bound on a raw grid-minor family

Use one site per grid vertex. Each site has triples x,u,v,w, and for each color the five physical mux clauses from private-swap-frontier.md. In the first phase traverse the sites in horizontal snake order. At each site put the one-hot coloring clauses on its w triple, the three conflicts with the preceding site's w triple (if present), then its nine private/boundary variables' mux constraints. In the second phase traverse the sites in vertical snake order; impose the one-hot x triple and three preceding-edge conflicts per site. All physical scopes are distinct here, so first-occurrence grouping preserves the specified order.

Every pair of proper path colorings w and x lifts uniquely by u_i=w_i x_i, v_i=w_i(1−x_i). At the phase boundary x is still unrestricted: pick a proper row-path coloring and orient according to any of its 3m Boolean bits. True prefix XOR translations fix every bit of x, since the local projected (w,u,v) relation has odd cardinality three, fixes those private coordinates under translation, and a true w forces an orientation. Old offsets there number 2^(3m). In contrast flipping one x-coordinate and exchanging its two private literals is a signed automorphism of the actual clause set. All 3m flips are independent, giving one cut state.

During the first phase all live x bits at sites strictly earlier than the current site have the same certified flips: both private variables are retired, and no x-color constraint has been read yet. All other live data are confined to the preceding and current w triples and the current x,u,v triples, at most 15 coordinates. During the second phase every site after the current one has untouched x bits with independent flips. A processed x site has no future occurrence except on its next column-path edge, leaving at most the preceding and current triples (six exceptions). Private bits have retired. Thus every actual layer has at most 2^15 permutation offsets, an absolute bound. The candidate search tests every private transposition and pure translations. Any one valid lift returned for a named transposition suffices, since any two lifts with the same permutation differ by a pure translation already included in the discovered span. The implementation only needs generator-span recovery, not the choice of exactly the named shift for each transposition. The number of layers and polynomial generator checks give polynomial total time on this supplied family.

The primal graph is connected. Within each site the w and x one-hot clauses connect their respective triples, and the physical mux edges connect these to each other and to u,v. Contract each connected site. The row snake contains all horizontal grid edges and the column snake all vertical grid edges, producing a grid minor of unbounded treewidth. This is compatible with the elementary independent path-coloring algorithm on this particular construction; it is a separation between structural measures, not hardness.

Full models project to exactly the one-hot triple at any site, since each of its colors extends. Three one-hot words have bitwise majority zero and their ternary XOR is 111, both excluded. Projections of 2SAT model sets preserve majority and projections of affine model sets preserve ternary XOR, ruling out an exact existential encoding in either class over these physical coordinates.

The executable checks all 36 and 576 pairs of proper path colorings on two and four sites. On both raw instances the signed-permutation solver peaks at 21 states and has one state at the phase boundary. These are finite controls for the proved all-size bound.
