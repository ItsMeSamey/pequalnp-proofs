# Frontier flips lifted by signed private swaps

The stored prefix relation and one-witness invariant are as in selector-prefix-union. Here a frontier flip may lift by permuting retired variables. In swaps.py try each of O(n²) transpositions of retired indices and the identity. Group original clauses by equal sorted scope. Permute each table to its new named scope. If that scope occurs and a local translation identifies the two tables, all identifying translations are one coset of the destination table stabilizer. Impose its annihilator equations, with the local offset, on a single physical shift. Perform Gaussian elimination. An accepted permutation followed by this shift permutes the grouped factors and preserves the conjunction. All solutions for a fixed permutation differ by a pure simultaneous translation. This check covers a prescribed transposition and searches all such transpositions in polynomial time. More general automorphisms can go undetected.

Each stored generator is an explicit permutation of n indices with n shift bits. It fixes frontier index names and translates the frontier. Therefore its projection is a homomorphism into a binary vector space, even if its lifts fail to commute. On adding a factor, reduce the generator images on the shared sites. Every dependent column gives a basis relation and a composable signed-permutation lift that fixes those sites. These lifts extend by identity on the fresh coordinates and preserve the enlarged prefix. Inherit their new-frontier images as well as newly discovered generators. Keeping only the old individual generators that happened to fix the shared sites would miss combinations. Gaussian-solve the shared tuple for every old orbit and each allowed new tuple. Apply the chosen lift to the entire stored original word, then extend it on fresh sites. The possible results occupy one new orbit because their differences on the new frontier have inherited lifts. Every point of that orbit is genuinely reachable. Retired-only kernel elements do not change this projected equality.

For m distinct scopes and maximum population C, at most 8mC tuple tests take place. Recognition tests at most mn² private swaps over all layers, each on O(m) bounded tables followed by polynomial binary elimination. A loose full bit bound O(m²(n+1)^6 + m(C+1)(n+1)^5) covers sorting pivots, composing explicit maps and per-word backsubstitution. The implementation returns skip on state overflow. Treat an explicit n-variable input (or first compress used names) when applying a bound polynomial in n. Signed symmetries of SAT formulas have a substantial prior literature, e.g. [Aloul et al.](https://www.aloul.net/Papers/faloul_sat02_sym.pdf).

## A connected family with a polynomial full clock

Number r² grid sites. At each site give the three indicators w_c exactly-one constraints. Between successive sites on the row-snake Hamiltonian path forbid equal colors. For each c use private rails u_c,v_c, require w_c = (u_c OR v_c), and impose (x_c OR NOT u_c) and (NOT x_c OR NOT v_c). The clauses imply that a true w uses exactly one rail. The signed operation swapping u,v and flipping x preserves the complete site gadget and leaves w fixed. Process the row path by sites, consuming each preceding edge at the new site. At the cut after this first stage, every one of the 3r² bits x is live. Every x word is feasible, since any row-path coloring extends by a choice of rails.

In the suffix give x at each site exactly-one constraints and require proper coloring along the column-snake path. Process this stage by sites in column order. At each cut of the first stage every finished x admits an independent private swap; only the current site's variables and the adjacent path color can add other live bits. In the second stage every as-yet untouched x retains the corresponding swap, and at most a constant number of touched bits remain live. Thus every layer has bounded orbit population, including partial gadgets. Original vertices in a site form one connected gadget; contracting these pairwise disjoint gadgets retains all grid edges via the two snake paths. Consequently the input primal treewidth is at least r up to the usual grid-width convention.

At the center the pure factor-translation solver instead needs exactly 2^(3r²) states. The ternary clause encoding (u OR v OR NOT w) kills shifts on all three names and each remaining selector clause then kills its x shift. Even a semantic full-history translation cannot flip an x: the (w,u,v) projection is the three-element set {000,110,101} up to coordinate convention and hence has zero stabilizer. Each site color can occur by permuting the row coloring, and the occupied rail then fixes x. The full solution set projects to exactly-one on each site's three indicators. That relation is neither affine nor closed under bitwise majority (apply majority to the three unit vectors), so a plain affine or bijunctive projection cannot give its exact physical word set. Fixing two adjacent column-path sites to the same color gives a NO variant; process these unit pins at the corresponding sites. Once the independent frontier lifts are understood the relation decomposes into two ordinary path-coloring problems. No unrestricted SAT bound follows.

Separate recognition tests covered 181 four-variable inputs. The checks covered original prefix witnesses, exact disjoint orbit coverage, and the final raw SAT/UNSAT decision.

Ordinary Davis–Putnam elimination of each private rail pair also discovers this separation in polynomial time. Those two names occur only in the five-clause gadget on (w,x,u,v), whose projection onto (w,x) is the full square. For w=0 take both rails zero; for w=1 set u=x and v=1+x. Eliminating both private names by local resolution uses constant work per pair and leaves only the independent two path colorings. Thus the exponential improvement concerns the two specified catalog implementations.
