# Commuting reset programs and a three-label reordering obstruction

Consider an explicit complete deterministic width-d read-once program on distinct bits. Each transition option must be constant or a permutation. Pick a reference permutation P_i at each layer if available, an arbitrary bijection otherwise; g_i=P_i g_(i-1), g_0=id. Relabel every transition T as g_i^-1 T g_(i-1), and the final accepting set by g_n^-1. Test whether all permutation options at distinct layers commute. This is a sufficient polynomially checkable condition.

Split on the last constant transition and its raw value (or none); the requirement that all later selected options be permutations is unary. The branch fixes the initial state for the remaining computation. Its permutation options can run in any supplied bit order by commutation. Enforce all unary restrictions in the new order, ignoring earlier bits except the last reset's pin. These disjoint branches number at most 2n+1. Their direct sum realizes the original predicate in weighted width O(nd) in every order, and separate synchronous intersections with any other weighted program return a common original word in polynomial bit time by actual-prefix bases. The d=1 case is immediate.

Three labels already permit exponential order sensitivity using only permutations. In Z/3 start r=0. On x_i add x_i, then on y_i negate r if y_i=1. Accept zero. The natural order is x_1,y_1,...,x_m,y_m. Partition all x before all y. Final r=sum s_i x_i, with s_i=(-1)^(sum of y_j from i to m); all sign vectors occur. Over GF(4) choose a primitive cube root w. The column for s in the binary evaluation matrix is 1+E_s+E_(-s), with E_s(x)=w^(sum s_i x_i). The E_s form a basis by tensoring independent length-two vectors (1,w),(1,w^-1). Choose one s per antipodal pair. The resulting 2^(m-1) pair sums are independent, and adding the fixed constant vector to all of them reduces rank by at most one. The original binary matrix therefore has rank at least 2^(m-1)-1 (extension of scalars preserves rank). This suffices for an exponential weighted-width lower bound in the specified second order. No joint decision lower bound follows. The permutations can be compiled with constant Boolean-gate overhead per bit using a two-bit encoding of three labels.
