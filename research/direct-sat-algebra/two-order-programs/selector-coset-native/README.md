# Tail-translation keys for projected 2CNFs

At a cut of the guarded original clause stream, R is the exact feasible binary relation on named crossing data bits. Let T be the raw translations preserving each remaining local truth table grouped by equal variable scope and fixing protected bits. Enumerate at most eight translations per ternary scope to obtain its stabilizer; lift orthogonal equations to the raw coordinates and take the joint kernel. T is sufficient and checkable, not necessarily the entire semantic symmetry group of the conjunction.

The prefix streamer obtains nonemptiness and every unary/binary projection of R by 2SAT. These tables determine R because existential projection of a 2CNF is a 2CNF. For each table select the least translated table C. Every shift delta realizing that table lies in one coset of Stab(C), so its evaluations against an orthogonal basis give a unique phase. Concatenate phases and reduce by the image of T. The named canonical tables and reduced phase constitute a complete equivalence key for translation under T. Row elimination carries raw directions: XOR of two reduction witnesses yields a single full raw shift taking one equal-key relation to the other. The future selector assignment may shift too. Keeping an actual selector prefix per class and re-solving its binary system at the end gives an original witness. This does not preserve counts.

Computing a key uses polynomial work in source size and n: O(n²) constant-arity projection tables and binary elimination. The solver never enumerates the full truth table or all elements of T. Total state count remains a parameter. The incumbent streamer supports a pairwise callback; dictionary key lookup can be used for equality alone. General translated containment is outside the scope of this procedure.

The fixture uses prefix x_i=s_i and (s_i OR u_i OR v_i) with private u_i,v_i. The tail has x_i XOR z_i XOR w=0 and one future selector w. The completed prefix gives 2^m incomparable singleton x-relations, all in one suffix orbit via simultaneous shifts of x_i,z_i. Yet for each s the full model fiber has size 2 times 4^{number of ones} times 3^{number of zeros}, uniquely maximized at all ones. A global raw translation preserving the whole model set therefore has zero s-shift and hence zero x-shift. This is a strict separation from global model-set translations on the original coordinates, without any claim about all possible circuit encodings. The fixture labels let the streamer's first-variable heuristic discover the displayed selector partition.
