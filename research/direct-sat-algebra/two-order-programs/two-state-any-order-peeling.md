# Recover a complete two-state order from a weighted program in any supplied order

For a Boolean function f write f_0,f_1 for the cofactors of a raw bit x. Allow peeling x if (a) either cofactor is constant, (b) f_0=f_1, or (c) f_0=1+f_1. In case (a), choose the other cofactor as the smaller problem (if both constant any choice works). For cases (b,c) use f_0. Record the corresponding two maps on one state bit: identity on the retained branch, constant on the other in case (a); identity or bit complement on the other in cases (b,c). These maps reconstruct the entire function from the smaller one for both choices of x.

This is an exact greedy characterization of functions recognizable by a complete deterministic two-state read-once program in *some* order. If f has one, consider its last variable, with the terminal accepting predicate folded into its two transition maps. On the two possible preceding states each map is either constant or a permutation; when both are permutations they are equal or complementary. A peel therefore exists. Any restriction of such a program has another complete width-two program on the remaining variables: fix that variable's layer and compose its single transition into a neighboring transition or into the initial/final state. Thus *every* successful choice of peel leaves a smaller function still possessing the property, irrespective of order. Induction proves completeness and reconstructs an order by reversing the recorded peels. Constant functions and unused variables are covered.

Given an explicit GF(2) weighted read-once program in an arbitrary supplied order, the tests and greedy reconstruction run in polynomial bit time. Pinning a variable fixes one layer matrix (or multiply its fixed transfer into a neighboring layer to drop it). Cofactors of the remaining program have the same remaining order. Test equality and complementation via the zero test on their XOR with possible constant-one summand, direct-summing the two cofactors and computing a forward reachable basis. Test individual constants similarly. Keep only the chosen restriction of the original weighted program; never retain the amplified direct sum as next input. There are O(n^2) variable examinations, and each zero test acts on at most 2w+1 states per layer. Record initial surviving scalar and all unary state tables. Optionally verify the recovered program in the original weighted order using its last-reset O(n)-width sum and one more same-order zero test. No search over permutations is required.

Consequently two arbitrary differently ordered weighted programs have a deterministic polynomial joint-decision procedure if either input function has complete two-state width in ANY order. Rejecting all possible peels certifies failure of that recognition promise only. A native circuit first needs a charged construction of its weighted description in some order or a separate certified identity test. This distinction matters even for a zero circuit output, because arbitrary intermediate wires may be expensive to compile. The last-reset direct sum also ensures the final peeled function has polynomial weighted width in all orders, so the other factor's bit order may be reused during final checking.
