# Binary selector conflicts on a raw 3CNF

Call conflicts.solve(n, clauses) with the raw count and signed physical clauses. No grouping, selector coordinate, helper role, variable order or source assignment is supplied.

The implementation extracts ternary affine hulls from equal-scope tables, finds selector lines as common intersections of blocks of triple normal spaces, and chooses one shared data chart. It seeds the chart with selector normals, whole unary/binary exterior normals, then ternary normals. After substitution it checks every falsifying indicator. Exterior predicates must be binary on data alone. Each remaining predicate may involve at most one selector and two data bits. It generates the corresponding forbidden data patterns and retains both inverse affine maps.

For every partial selector assignment of size zero, one or two, activate the unconditional data clauses and only clauses with a specified matching guard. An inconsistent data 2CNF proves that no valid extension exists. Add its forbidden selector assignment as a clause. Unsatisfiability of the learned selector 2CNF proves raw UNSAT. Otherwise check the full activation of the returned selector word. A consistent solution lifts to a replayed raw witness. An inconsistent full check returns skip. All decisions are sound without a promise. If every infeasible selector word has a partial conflict explanation of size at most two, the final skip cannot occur after successful chart discovery. With b selectors there are 1+2b+4 binom(b,2) partial data probes and at most one full probe. Reported elapsed time includes original-clause discovery.

Run python check.py with sibling mixed-ternary-native and selector-variable-compiler available. Path and odd-cycle source formulas are compiled, then all physical sites and clauses are shuffled. Selector metadata serves only to check decoded witnesses after solving. At b=15 the 1053-bit path gave SAT in 452 data solves and the 1125-bit odd cycle gave UNSAT in 451. Each took about 0.7 s on one run. The source paths/cycles are ordinary 2CNF and already have a polynomial algorithm.

A 3CNF forbidding all eight assignments to three variables gives a 441-bit physical UNSAT example requiring ternary explanations. Every partial selector assignment of size at most two is consistent. The selected full activation fails. The executable returns skip, as required.
