# Common-class source tables

route.solve(n,clauses,*,arity=3,max_cells=65536) handles signed one-based DIMACS on declared source bits. The result gives status, route, original witness, number of scopes and materialized cells, original clauses/literals and emitted constraints for the chosen backend. Drop tautological rows and repeated literals. Each surviving clause on S forbids one full tuple there. Group all equal-scope rows before analysis. Too-large arity or summed table cells sum_S 2^|S| yields SKIP before table materialization. Parsing/validation still reads the untouched source.

For affine tables span all differences from one allowed tuple; size exactly 2^rank certifies equality to its affine hull. Orthogonal vectors yield equations on physical variables, solved jointly by Gaussian elimination. For Horn tables compute the meet of all allowed supersets of each forbidden b by superset dynamic programming, tracking empty families. If the meet equals b, closure fails. Otherwise the support of b implies an extra bit from the meet or false when the family is empty. These Horn implications exclude every forbidden pattern and preserve all allowed ones. Forward chaining produces the least global model or discovers a false head. For majority tables derive every entailed unary/binary clause from the tuple projections. Test directly whether each forbidden tuple violates at least one derived clause. This exactly recognizes majority closure: pairwise-extendible target bits extend to every larger coordinate set by taking the majority of extensions omitting three different coordinates, inductively. SCC solves the shared raw binary relations. An empty table gives UNSAT. Otherwise a common class across all tables is required; mixed cases with no common class decline. All SAT witnesses are replayed against the complete original CNF. No #SAT or unrestricted SAT claim.

For arity a and K charged truth-table cells the local work is O(K poly(a)) operations on local words and raw-coordinate masks. Source reading, sorting and grouping are polynomial in the input size independently of K. Up to O(aK) generated Horn literal occurrences, O(sum_S |S|²) binary clauses, or O(sum_S |S|) Gaussian equations are sent to the chosen solver. Gaussian elimination, SCC initialization, replay and integer bit costs add polynomial dependence on the declared source dimension and length. This implements classical Horn/affine/bijunctive common-class tractability after grouping; it does not try signed Horn or mixed residual search.

check.py compared all ternary relations with their defining closure operations; among the 255 nonempty relations 51 were affine, 121 meet-closed and 165 majority-closed. On 500 additional small mixed CNFs 421 decisions agreed with original assignment enumeration and 79 declined. On the separately frozen 28-case holdout, 12 affine decisions (6 SAT/6 UNSAT) agreed, 12 declined for no common class and 4 for arity. No holdout routed through meet or majority. Both completed pipelines were correct on all 28. See /workspace/scratch/cnf-grouped-holdout/README.md for the independent protocol and results; no prior frozen entry was modified.
