# Sharp width thresholds for differently ordered binary programs

A complete deterministic program with at most two states per layer has a bit state s. Pad any singleton layer with an unreachable state to use two labels. For each layer i and input bit x its transition is s'=a_i(x)s+b_i(x) over GF(2), where b_i(x) is the destination of state zero and a_i(x) is the XOR of the two destinations. Both a_i and b_i are unary affine functions of the tested raw bit.

Enumerate the last layer j with a_j(x)=0, also allowing no such layer. For that branch impose a_j=0 and every later a_i=1; omit the first condition in the no-reset branch. These are unary affine restrictions on the original bits. At the end the state equals b_j(x_j)+sum_(i>j)b_i(x_i), or the initial state plus the sum of every b_i if no reset occurs. Accepting exactly one state imposes one affine parity condition; accepting both or neither is immediate. Thus the accepting set is the disjoint union of at most n+1 systems of unary constraints and one parity. All data and case witnesses refer to the original raw bits.

Intersect ANY one explicit GF(2) weighted program in an arbitrary other variable order with this complete deterministic two-state program. In each last-reset case process unary pins and one parity in the OTHER order; parity is tracked by a two-state deterministic program and forbidden unary input branches have zero transition. Tensor synchronously with the supplied weighted program, test whether the scalar output is nonzero on a word by forward basis elimination, and replay the joint witness. This costs polynomial time in n and the two explicit programs without an ordering parameter. For width-one weighted on one side, its scalar acceptance condition is just a conjunction of unary permissions, so it works as well.

In contrast the two width-three deterministic programs in two-order-program-sat.md have a persistent rejecting zero, and only TWO live labels per layer. Delete the dead label, represent the two live states as independent unit vectors in GF(2)^2, and send a rejected transition to the zero vector. The two destinations of the unit rows determine a binary 2-by-2 transition matrix. Every word follows a single live path or becomes zero; contract with the column accepting the permitted live labels. Empty clauses may use zero start vector. This gives the same parsimonious general-SAT encoding using two width-two weighted programs in different orders, even with each transition row having at most one nonzero entry. It also preserves the width-one-final-product isolation implication. Thus individual weighted widths one versus two and complete deterministic widths two versus three give distinct algorithmic thresholds. Identifying partial deterministic width with complete deterministic width would erase the absorbing-zero distinction.
