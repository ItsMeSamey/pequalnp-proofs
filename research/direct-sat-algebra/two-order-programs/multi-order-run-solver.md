# Shared-word evaluation across fragmented orders

Use p supplied GF(2) weighted programs in arbitrary orders on the same n bits. On a supplied binary tree of subsets partitioning those bits, split each node U into maximal runs in each order. Let b be the maximum total number of runs at any node and w the maximum program width. For a physical word on U form one transfer matrix per run and tensor them all together. Ambient dimension is at most w^{2b}.

At each leaf test both bit values simultaneously in all programs. At each internal node enumerate one actual basis representative per child. Multiply their run matrices wherever they become adjacent in the parent, retaining each program's own order, then tensor the parent's run matrices. Retain a basis of actual tensors with their factors and child choices. Each child run occurs exactly once in the parent products. Expansion of entries proves the operation bilinear in the two complete child tensors regardless of interleaving. Actual child words combine on disjoint variables. Thus these tensors span all physical words. Root endpoint contraction is a linear functional equal to the product of all desired scalar outputs. Nonzero yields a common original word by tracing an actual basis representative; replay it. Empty input is evaluated directly.

On a supplied tree time and space are n w^{O(b)} times a polynomial in explicit input and p, counting tensor construction, pair enumeration and elimination. Number of runs is visible directly. In the variable multigraph formed by the union of the p order paths, if every tree cut has at most c crossing edges then b≤p+c: the number of runs along each path is at most one plus its crossing edges. A binary common-interval tree specializes to b=p. This bound does not need an optimal tree recognition theorem.
