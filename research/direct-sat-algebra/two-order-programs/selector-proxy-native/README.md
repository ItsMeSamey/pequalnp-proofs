# Raw guarded 3-CNF with overlapping selector roles

Normalize clauses by removing duplicate literals and tautologies. Choose the least original ID per ternary clause and delete redundant hits, producing an inclusion-minimal hitting set S. Build the graph joining co-occurring members of S in every binary and ternary row. Use the smaller of a greedy vertex cover and the endpoints of a maximal matching. The latter gives the factor-two guarantee for this fixed graph.

Place original selectors first in the new numbering. Add one high-ID data copy for each covered selector, plus the two binary clauses asserting equality. In each ternary row designate its sole uncovered selected member if present, otherwise any selected member, as the master. Use data versions elsewhere and throughout the binary and unary clauses. The cover ensures at most one master per clause. Inclusion-minimality makes each master a sole hit of at least one ternary, so the original minimum-ID chart recognizer discovers precisely these masters. The number of extra variables is at most |S| and the number of extra clauses over the normalized source is twice the copy count. Source recognition and chart construction are polynomial; the state cap remains explicit.

Every original assignment has a unique equality-consistent extension, and every satisfying recoded word decodes by inverse renaming. The solver checks proxy equalities and the raw original clauses before returning SAT. There is no guarantee of a runtime improvement or of finding globally optimal selectors.

Each accepted translated containment uses an actual full physical shift. It is tested against the remaining grouped tail equations, including the frozen past selectors, and each actual translated unary/binary projection must be included. The essential_strict counter requires proper inclusion after translation and failure of unshifted inclusion. Example full shifts use recoded coordinates. The solver does not enumerate original assignment tables; the bounded checker does so only to verify the bijection.
