# Projecting guarded binary components from a physical CNF

Call `projection.solve(n, clauses, scope_cap=4, table_cap=65536, fallback_limit=0)`. Input consists of the declared raw variables and ordinary signed clauses. The solver discovers the affine chart, selector spaces and data coordinates by the reviewed source preprocessing in selector-conflict-native. It checks the binary scope of every data constraint before projection. No compiler metadata enters the solver.

Join two data sites when they occur in a binary clause, ignoring its selector guard. Handle each data-free clause separately as a contradiction or forbidden selector value. For each resulting component, enumerate all assignments on its distinct incident selectors. The SCC-based 2SAT test on the active data clauses decides membership in its exact projection. Tables on identical selector scopes are intersected. No independent choice of selector values across components is assumed.

A Cartesian product of unary projections is recognized first. Otherwise the existing table dispatcher checks common affine, meet-closed, and majority-closed classes. The latter yields a 2SAT join. An unrecognized join can enumerate at most fallback_limit global selector assignments. With default zero the solver abstains. A boundary exceeding scope_cap or total component tables exceeding table_cap also abstains. These caps do not limit wall time. A positive result triggers a fresh local 2SAT traceback per component, at one shared global selector word, followed by both affine lifts and untouched raw CNF replay. The output reports all table and traceback probes separately, the generated forbidden rows, the join route, bounded enumerations and time from raw validation to replay.

Run python check.py and python classes.py with the sibling mixed-ternary-native, guard-cap-review, direct-sat-portfolio and selector-variable-compiler directories present. The tests scramble the physical inputs before solving, and use compiler metadata only for external validation. Late sign-flipped formulas on five, six and eight selectors produced the prescribed unique words 31, 37 and 219. On the eight-selector input the solver examined 32 data components using 256 table probes and 32 traceback calls, then replayed the witness on all 1752 raw variables. Additional controls exercise affine, meet and majority joins, UNSAT from an empty grouped projection, a genuinely unrecognized mixed join, bounded enumeration, width caps, and table caps. General projected joins at boundary width three can still express 3SAT.
