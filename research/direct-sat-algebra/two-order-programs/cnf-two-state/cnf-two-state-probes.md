# Source CNF cofactor probes without weighted compilation

Normalize the current restricted CNF F by dropping tautological rows. At candidate bit x let A=F[x=0], B=F[x=1]. Test constant cofactors by SAT and syntactic tautology (empty conjunction after normalization). Test A=B by ruling out A AND NOT B and vice versa: for each clause D of B, check A with the literals of D pinned false, and symmetrically for the other implication. Test A=1+B by ruling out A=B=1 and A=B=0. The former takes a SAT call on A AND B; the latter requires only deciding whether some clause from each formula can be falsified simultaneously by compatible unary pins. Empty clauses and empty conjunctions obey the same rules.

A AND B can be represented by deleting x from every non-tautological F-row and retaining all other literals: each row containing x survives in exactly one cofactor, and each unaffected row is duplicated. Thus every SAT instance is obtained by restrictions, plus at most one variable deletion in the currently tested formula. If the input was 3CNF with t ternary rows, each SAT query has at most t ternary rows. Branch on a true literal of each remaining ternary clause and solve 2SAT at leaves, costing O(3^t poly(input)) time and polynomial space across the entire recognition: at most O(n^2(m+1)) SAT queries and O(n^2 m^2) elementary pair checks of length at most six. In particular arbitrary 2CNF admits exact polynomial recognition and order extraction without constructing a weighted program in any order. If the 2CNF factor is recognized, intersect its recovered program with an explicit weighted factor in any other order via the last-reset algorithm. A declined factor is inconclusive for joint feasibility. This is a way to avoid potentially expensive intermediate circuit-to-weighted compilation when the original CNF is given. Majority on three bits shows some 2CNFs genuinely lack any such order.
