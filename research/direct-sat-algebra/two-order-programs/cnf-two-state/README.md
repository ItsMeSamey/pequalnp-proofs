# Original 3CNF two-state factor discovery

recognizer.py exposes recognize(n,rows,cap,max_ternary) and discover(n,rows,candidates=...,cap=...,max_ternary=...). Literals are signed one-based DIMACS integers; word bit v-1 is the value of original variable v. An original raw source clause can be supplied more than once, include repeated literals, or be tautological or empty. Program.layers retains all n variable names exactly once in execution order; maps encode the outputs on incoming states 0 and 1 as low/high bits. Program.evaluate replays any original word.

Recognition implements cnf-two-state-probes.md and two-state-any-order-peeling.md from direct-sat-algebra. For x compare the two restricted CNFs to constants, to one another by mutual implication, and to complements by ruling out common acceptance and simultaneous falsification of one clause from each. Queries split at most t ternary clauses, solving 2CNF with iterative SCC; the common-acceptance query erases the two literals on x in the normalized existing formula rather than doubling its ternary count. Any successful cofactor peel records its two unary transition maps; reverse the peels to recover an original variable order. A complete deterministic two-state presentation always admits a final-variable peel, and any restriction of a representable function stays representable. NO_ORDER is exact failure of this representation on the requested factor, never a decision that the formula is unsatisfiable.

discover tries each supplied subset of original clause indices, then automatically chooses all remaining nonbinary source clauses as one factor (all original binary clauses form its exterior). Candidate choices are independent; no clauses are silently dropped. When a factor is recognized and its exterior is binary, enumerate its disjoint last-reset cases. Each gives raw unary pins and one parity. The exterior solver finds a baseline 2SAT model after pins. For mismatched parity translate the clauses by that model. They become implications and negative units/conflicts. Test every principal implication closure and flip it if feasible and odd. If a feasible odd union exists, some feasible principal closure is odd by bottom-up induction on its implication SCC DAG. The backend exhausts all last-reset branches before returning UNSAT and replays every SAT word on all untouched input clauses. A declined split, format, or resource bound yields SKIP_FACTOR, SKIP_FORMAT or SKIP_BUDGET as appropriate and carries no UNSAT implication. The dispatcher is callable independently as an optional raw-CNF backend; it does not rewrite existing frozen circuit portfolio dispatchers.

The recognizer examines O(n²) variables, O(n²(m+1)) SAT queries and O(n²m²) clause pairs, each SAT search having O(3^t) nodes and polynomial work per node. Space is polynomial because only a depth-first ternary frontier is stored. Reset/exterior completion uses at most n+1 2SAT instances and O(n) singleton closures per branch. With P proposed partitions add at most P+1 recognitions. Binary input has polynomial complexity even when no order exists. max_ternary sets the maximum allowed number of distinct ternary factor clauses (default 8). Budget is an aggregate cap (default 100000) charging a unit for each candidate, tested variable, ternary decision-tree node including binary-SCC calls, compatible-false pair probe, last-reset branch, baseline exterior call and singleton closure. Each unit costs polynomial time in the declared input size. Input parsing, normalization, iteration over a supplied finite candidate description and witness replay are additional polynomial work. The cap is a charged-probe bound, not a wall-clock or byte cap.

check.py compares all 256 three-bit functions to independent exhaustive orders and fixed-order residual counts. It recovers the parity programs and rejects three-bit majority presented as 2CNF. The even K4 Tseitin system is satisfiable but not two-state in any original order; the inconsistent charge system is constant zero and recognized. Both skip with budget two. Four hundred additional small original-CNF dispatches yielded 380 exact answers and 20 declines. A final test exercises ternary parity with a shared raw majority exterior that independently has no complete two-state order.
