# First routes for explicit incidence sources

first.fast accepts original sparse signed DIMACS clauses. first.dense accepts dimension D, D positive and D negative D-bit incidence row masks, and two D-bit allowed-domain masks (0 and 1). This layout has exactly 2D²+2D logical input bits, not the Python object allocation. It checks dimensions, detects empty domains, drops only tautological clauses, and enforces singleton domains as original units. fast first dispatches binary clauses directly to SCC. Otherwise it propagates unit clauses to quiescence using queued literals, occurrence lists, and deletion of satisfied clauses. It replays positive results on the untouched original clauses; dense additionally replays against every original polarity mask and domain. A remaining binary residual is solved by SCC and merged with the fixed values. A general residual can abstain or optionally invoke a supplied source backend such as recognizer.discover on the untouched clauses, preserving its original indexing. If the backend abstains, this routine also abstains. Only positive answers are verifier-replayed; direct SCC/propagation negative decisions are trusted algorithmic deductions. Dense consumer indices after tautology removal and singleton insertion refer to decoded rows, not the raw D rows.

The decoded propagation and SCC loops use linear graph/occurrence work in an ordinary RAM model, plus hash tables for active rows. Python normalization sorts and deduplicates and its big-integer operations are explicitly polynomial in the raw bit size; no linear bit bound is asserted. The optional later backend is charged separately; neither first route uses two-state recognition, weighted compilation, layout, gate provenance or a satisfying-input promise.

The realized grid of side 4 had 16 variables and 24 clauses, D=32, 2,112 dense bits. The simple side-4 Margulis–Gabber–Galil graph (four forward modular maps, loop removal, undirected deduplication) had 16 variables and 40 clauses, D=64, 8,320 dense bits. Both unpinned formulas passed SCC, and pinning endpoints of an edge true gave SCC UNSAT. Padding bits were fixed zero and padded rows tautologies.

In the realized batch the four-input square grid has four edges. Each of 16 original words had its own four NAND edge gates and three AND accumulation gates, using three equivalence clauses each. That gives 176 active variable slots, 336 native nonpadding clauses, 64 input domain pins and 336 zero-pinned dummy variable slots in D=512, totaling 525,312 raw bits. There are 176 tautological padding rows. Unit propagation set all gate values and returned the exact unique original 512-bit word, validated against independently evaluated gates. An extra contrary output pin was rejected. A fallback raising an exception proved no later backend was consulted. A seeded additional 300 small mixed-width cases compared every conclusive first-route answer against exhaustive assignments; general cases could decline.

Analytically for k input vertices, e>=1 edges and 2^k copies, the explicit construction uses k+2e-1 active tags and 6e-3 clause rows per copy. Choose D=2^k times the least power of two at least max(k+2e-1,6e-3); the output address is (k+2e-2,z). Unused tags are pinned zero; padding rows are tautologies. No larger batch was generated. Arbitrary additional 2CNF or original pins preserve the binary route on grid/expander inputs. The batch guarantee concerns the fixed deterministic circuit with every primary input pinned. These examples concern decision route selection, not an all-input weighted-width bound or a speedup claim over all other solvers.
