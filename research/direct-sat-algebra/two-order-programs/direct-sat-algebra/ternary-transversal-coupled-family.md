# A one-dimensional semantic cover with a linear syntactic 2CNF backdoor

Use original coordinates h and disjoint pairs a_i,b_i, i=1..m, m≥2. For each pair add distinct d_i,c_i. Enforce d_i=a_i XOR b_i and c_i=h XOR d_i using the four width-three parity-equivalence clauses per relation. Add one signed main clause on (a_i,b_i,c_i) per i with arbitrary choice of signs. Additional arbitrary signed binary clauses may be placed on the a,b,h core. This describes m individually named constrained ternaries and arbitrary cross-pair coupling through that binary exterior. Put c_i,d_i after all core variables in the input order, use highest-index pivots in affine Gaussian elimination, and keep the other raw names as free coordinates. For the simplest sharp-parameter subfamily take no exterior or one row per distinct binary scope (whose three satisfying tuples have full affine hull).

For each parity group the local table equals its affine hull; the single main row has seven solutions, is nonaffine, and has full affine hull. Thus initial grouping recovers the exact helper equations. After substitution each main clause has normal span U_i=span(a_i,b_i,h). These spaces have common intersection exactly span(h) for m≥2. No nonzero S of dimension less than one covers them and the one-dimensional transversal is uniquely span(h). In each h-coset, c_i reduces to a_i XOR b_i plus a constant. Consequently the entire violating indicator for main clause i depends on only the two coordinates a_i,b_i. Extract its binary forbidden tuples by four evaluations. All exterior clauses remain binary or unary after the h pin. The complete original 3CNF is therefore decided, and a raw witness produced, in polynomial time using grouping, b=1 search, and two 2SAT calls. All original helpers lift uniquely by their defining equations. If exterior rows imply extra affine equations, preserve the displayed core chart by retaining those binary rows as residual constraints rather than pre-eliminating them; affine-hull extraction may be limited to ternary groups without affecting correctness. In this family the helper identities and common cover are inferred from local input tables and Gaussian elimination; no encoded gate definitions or supplied common selector is needed.

Compare direct syntactic strong backdoors to clause-width two on the original CNF. Every set of variables whose every assignment leaves a 2CNF, after simple assignment restriction, must hit each of the m disjoint main clauses. Thus any such set has at least m coordinates, even though the semantic rank-drop computation uses one. Plain uniform grouped affine/meet/majority criteria also fail: the parity table on three variables is neither meet- nor majority-closed, and the main seven-point table is nonaffine. This is a strict class separation for these tests, not a lower bound against Gaussian preprocessing, general polynomial solvers, or optimized universal clocks.
