# Preserve the original variable clock in the hidden-selector reduction

Any nonconstant CNF on n variables and total L literal occurrences maps to the hidden-selector block family with exactly b=n directions and O(n+L) groups. Allocate one block per x_i and decode x_i=h_i=p_i+q_i+r_i. In each group C=a+b+h_i. The main clause forbidding (a,b,C)=(0,0,t) enforces “if h_i=t, require a OR b”. Source state literals of either sign are supplied by signed equality stars between physical occurrence sites. Repeating a state literal at a and b gives a guarded unit.

For each nonempty original clause with literals l_1 to l_k introduce path states z_0,...,z_k and enforce z_0=1, z_k=0. For position j put three groups in the block of the variable of l_j. When l_j is false require both (!z_(j-1) OR z_j) and (z_(j-1) OR !z_j); when l_j is true require !z_j. The appropriate active h value follows the sign of the literal. Thus z_j is uniquely the indicator that all of the first j literals were false. Every path state has a physical occurrence; use one as representative and wire all others directly by signed equalities. Put each endpoint unary pin on its physical representative with correct polarity. This uses the arbitrary signed binary/unary exterior of the preceding theorem.

Pad each variable block to at least three groups by pinning its a true and b to a chosen constant, and using a positive a literal in its main row. Unused declared source variables also get a block. For a source empty clause use incompatible unit pins on a dedicated dummy group and otherwise retain n blocks; constant inputs with n=0 can be evaluated directly. For a CNF with no clauses all blocks can be padded. All physical helpers are deterministic. Each original satisfying assignment has exactly 4^n physical lifts: choose p,q per block, determine r from h, and every path state, occurrence and helper is fixed. Conversely physical h values give a genuine original word. Alternatively pin p=q=0 in each block for a parsimonious variant, identifying original x_i with the physical r_i. The unpinned non-coordinate lower bound should not be inferred after these optional pins.

Pairwise normal-space intersections still recover all blocks, since exterior rows are retained separately. A uniform O((2-epsilon)^b poly(explicit size)) deterministic algorithm for this entire family would give the same base on ordinary CNF in the ORIGINAL n, including k-CNF for all fixed k with one epsilon. The encoding and original witness recovery have polynomial bit cost. This implication does not assume a time lower bound, or conflict with any theorem having a k-dependent saving. The O(2^b poly) search currently matches original exhaustive search through this transfer.
