# Tractable one-sided translated inclusion with an explicit affine projection

For satisfiable boundary 2CNFs R,S, seek one t in the certified tail translation space G with R+t contained in S. Normalize repeated literals and discard tautologies in S. For a binary clause forbidding the word w on i,j, the allowed shifts t_ij are exactly those for which w+t_ij is outside the pair projection of R. Obtain this projection by four pinned 2SAT tests. If its size is 4 reject, if 3 impose one affine point, if 2 impose an affine line, and if 1 retain a binary clause on the two shift bits. Unary tests similarly reject or impose pins. The only genuinely nonlinear constraints involve coordinates BOTH fixed in every R-model. Thus translated inclusion is polynomial when R has no fixed coordinates, irrespective of tail rank or boundary width. Empty relations are handled separately.

Intersect all affine tests with G by Gaussian elimination, retaining variables for physical suffix lifts. If consistent, project that affine solution coset to the shift coordinates occurring in the leftover clauses, obtaining K. Parametrize K using dim(K) independent parameters. Its coordinates are fixed or affine; group the nonconstant ones by equality of their linear parts. The implied pins and signed equalities within groups define a binary affine hull of dimension g, the number of distinct nonzero linear parts. It equals K exactly when g=dim K because these forms span the parameter dual and K is contained in that hull. In this recognized case solve the residual binary clauses plus those pins/equalities by ordinary 2SAT, obtain a full shift by backsolving, and verify each S clause against shifted R. Tail translations must fix all required observables. This can certify a proper inclusion and hence retain only the weaker prefix for existential search; witnesses from the retained branch use its actual history.

In general substituting one signed variable per group preserves binarity, and K is defined within the binary affine hull by d=g−dim(K) independent additional parity equations. One exact option enumerates the dim(K) parameters. An alternative uses the existing degree-d representative theorem for 2CNF on the product of d affine satisfaction indicators, taking (g+1)^{O(d)} times polynomial input work, with an actual witness. Unbounded parity-triple blocks on singleton R realize the NP-complete obligation in selector-translation-containment.md. These are recognition/merge bounds, not a bound on the number of histories in a complete SAT search.
