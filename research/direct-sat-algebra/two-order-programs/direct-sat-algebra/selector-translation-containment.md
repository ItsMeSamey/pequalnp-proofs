# One-sided inclusion under tail translations

Given two satisfiable boundary 2CNFs R,S and a linear translation group G, deciding whether some t in G has R+t contained in S is NP-complete, even with R a singleton and G the locally computed stabilizer of a single-guard 3CNF suffix. A witness is the shift and its tail lift. Membership in G is linear; for each clause of S test R+t with the falsifying pins by 2SAT. This is complexity of one sufficient pruning test, not of every solver.

Given any 3CNF of three literal positions per clause, use boundary names X for its original bits and z_ci for each literal position. Let u be zero on X with exactly the first z bit 1 per clause. Set R={u}. Let S contain implications z_ci implies the corresponding signed original literal. It always admits z=0. Let G allow every X shift and exactly the even shifts in every triple of z bits. Some translate of R lies inside S iff S admits odd parity in every triple, equivalent to source satisfaction: odd selects a nonempty set of true occurrences; one may choose exactly one true occurrence per clause. Repeated or complementary literals are harmless.

Both histories and the group are physical. One initial selector b activates the unit pins defining R at b=0, and the binary implications defining S at b=1. The native guarded rows have arity two or three. Each triple has a fresh future selector s_c, a binary equality s_c=z_c3, and an even ternary parity on z_c1,z_c2,s_c encoded by four signed rows. Every original boundary X stays visible via binary equality to a fresh private copy. Each ternary row contains exactly one selector. The simultaneous ternary/equality table stabilizer projects onto the boundary as precisely G. Its parity restriction concerns translations; the odd coset in the membership test is supplied by u. Thus exact equality under a common shift (computable by global linear consistency of local table orbits) and exact unshifted implication do not combine into an efficient complete translated-inclusion test unless P=NP.
