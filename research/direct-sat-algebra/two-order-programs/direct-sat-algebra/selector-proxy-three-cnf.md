# One guarded group per ternary input clause

Use one hidden-selector block per source bit h_i, and create one ordinary logical data proxy X_i, encoded in physical occurrences. In block i use two guarded units (h_i=0 implies !X_i) and (h_i=1 implies X_i), representing each unit by two separate equally signed sites. For each ternary source clause pick the first literal as guard; when it is false enforce the OR of the other two signed X proxies with one main group. Wire all signed proxy occurrences to a single physical occurrence representative per variable using disjoint stars. Source unary/binary rows use proxy representatives directly. Neutral padding to three groups per block pins each of its two data bits. Thus X_i=h_i physically in every satisfying word, and each original assignment has exactly 4^n lifts when accepted, one if p,q per block are pinned to zero. Decode h for the original witness. Empty clauses reject. No arbitrary-width claim is required.

For m ternary clauses and u variables never used as a guard, g=m+2n+u groups. Exact physical bits N=3n+6g=6m+15n+6u. The 17g parity/main rows, 2(2m+3n) signed equality rows (2m+4n active sites, n proxies), and 2u dummy pins total 21m+40n+19u rows, plus optional 2n for p,q pins. If present, source lower-arity exterior rows must be added separately. On all-ternary input M<4N. On dense ternary sources the coefficient of m in N drops from 54 to 6 relative to the prior literal-path compiler; relative to direct ordinary 3SAT the new representation still expands the input. No new asymptotic complexity claim.

Shared X proxies connect different source clauses, so the private-clause component theorem is no longer automatic. At a partial guard assignment, active proxy units force those X values, and active original binary requirements can interact beyond one clause. The previous path-specific characterization of rejecting partial guard probes must not be carried over to this compiler. With all h fixed every proxy is determined.
