# Minimum copies for a fixed selector cover

Normalize signed 3CNF by deleting tautologies and repeated literals. Choose an inclusion-minimal set S hitting every ternary scope; greedy covering and deletion suffice. Every s has a ternary where it is the only S name. Build the graph on S whose edges are pairs of distinct selected names occurring in any normalized row, including binaries. For the occurrence-preserving compilation below the fewest extra bits is precisely the minimum vertex cover p of this graph.

Use one selector name per member of S. A copied member also gets one data name tied to the selector by two binary implications. All other variables get one name. Retain each source row with its original literal signs, using either the selector or its own data copy per occurrence. Demand exactly one selector per ternary and at most one per shorter row. Any two uncopied selected names occurring together violate this, so the copied set must be a vertex cover. Conversely in each ternary use the unique uncopied selected member if present, otherwise choose any selected member as guard, and use copies for every other selected occurrence. In shorter clauses use uncopied selected variables as guards and copied ones as data. Every s gets a guard occurrence by minimality of S. Number all selector names first in the desired order, then data names; the least-ID proposer recovers exactly the desired selectors. Every old assignment has a unique equality-consistent extension, preserving all original rows and allowing raw replay. The size is n+p variables, at most m+2p clauses. This optimum fixes S and the literal-occurrence compilation; arbitrary rewrites need not pay it.

A maximal matching gives a cover of size at most 2p in polynomial preprocessing. Branch on an uncovered edge to find an optimal cover by iterative deepening in O(2^p poly(input)) time and polynomial space. Charge any search explicitly. Smaller copy count need not imply fewer retained histories or faster SAT. The construction universally addresses the observed multiple-guard recognition failure.
