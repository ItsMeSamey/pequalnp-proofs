# Mixed raw 3CNF decision on affine charts

Call `solver.solve(n, clauses, b=1, extract_arities=(3,), orient=True, exponent_cap=12, detect_blocks=True)` using signed, one-based literals. This receives only the original clauses, declared variable count and numerical/algorithm options. It never receives roles, a wire order, or a candidate selector. The lower-level defaults extract all arities without reorientation or block detection. A cap can return skip. With complete=True, any unresolved case calls ordinary enumeration on original raw words. Every SAT word is independently replayed.

Equal-scope tables have at most eight entries. Extract the complete affine hull at selected arities. Remove a group if its table equals that hull; otherwise retain every original restriction it imposes. On the affine solution chart, an uncovered independent triple of normals has seven nonzero linear combinations. Every eventual cover must contain a nonzero member of its span, so the depth-b search is complete for this rank-drop criterion with O(7^b poly(input+n)) preprocessing. With detect_blocks=True, first find connected components of the graph of triple spaces with nonzero overlaps. If each component has a one-dimensional common intersection and those lines are independent and within budget, they give a verified cover. Otherwise use the seven-way search.

On every resulting coset, orient=True first collects independent literal normals from unary/binary clauses, then adds independent normals from the remaining clauses and completes a basis. Retain the coordinate transformation for witness recovery. When all violation indicators use at most two actual chart variables, emit their binary forbidden patterns and call the SCC-based 2SAT solver. Otherwise row-reduce quadratic equations, substitute derived affine constraints, and use either residual enumeration or quadratic Gauss sums, according to the smaller of free dimension and number of independent equations. The exponent cap applies to that minimum. Internal Gauss counts enable witness recovery. The public API returns decision and a physical witness on SAT, not a model count. Coset tables are processed one at a time, but logged receipts consume space proportional to the number of visited cosets.

The alternate coupled_order.py recognizes the specific coupled parity-helper family using intersections of active ternary scopes, puts the inferred helpers last and maps answers back. The generic oriented method also handles classes where the selector is not an existing physical wire.

## Reproduction

- Run python check.py for 1500 randomized outcomes, eight coupled SAT/UNSAT controls through 161 raw variables, and explicit partial-hull, Gauss, skip and complete-fallback tests.
- Run python check_permuted.py for 48 relabelings with shuffled clauses and literals and signed binary constraints across pairs. Both role-free methods find 24 SAT and 24 UNSAT cases using only 2SAT on visited cosets.
- Run python hidden.py for 64 original/permuted cases in which each hidden form is an XOR of three raw variables. Every test verifies equality of the discovered cover space with an independently computed target space. It checks all single/pair raw normals, original witness replay, and failure of the depth-b search at one fewer dimension.
- Run python growth.py for one through seven hidden blocks with signed exterior rows. On the seven-block, 147-variable UNSAT instance, scope intersections found the cover with zero search nodes and 128 2SAT calls gave UNSAT. The matched SAT control used one 2SAT call. Unbounded block count permits NP-completeness; this enumeration budget remains relevant.
- Run python compare.py for prior complete-CNF-source in bounded mode, capped at 128 raw assignments and a two-second process timeout. At four and twelve groups it proved simple pinned contradictions via unit propagation. It declined both SAT and inconsistent odd-cycle exterior controls, all decided by this transversal route. A bounded decline carries no UNSAT meaning.

Dependencies are the sibling guard-cap-review/cnf-common-tables and cnf-two-state Gaussian and SCC utilities, plus direct-sat-portfolio's Gauss evaluator and raw-clause checker. Proofs of rank-drop and hidden-family guarantees are in the sibling direct-sat-algebra notes.
