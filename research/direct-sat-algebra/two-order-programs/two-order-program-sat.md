# Two supplied orders and a semantically small product

Two deterministic layered binary programs of width at most three, each reading every original occurrence bit once in a supplied order, have an NP-complete simultaneous acceptance problem when the orders may differ. Use a fresh raw bit for each variable occurrence of a signed CNF, storing its original variable value. Add one free dummy occurrence for each declared unused variable to preserve counts. The first program reads by clause, remembering whether the current clause already has a true literal, with a persistent rejecting state after any completed false clause; the end-of-clause transition resets the local flag. The second reads by variable, remembering the first bit in its current group, with a persistent rejecting state on disagreement. Group-start layers may overwrite any surviving old value. Unused dummy positions impose no checks. Empty formulas and clauses admit constant branches. Each original assignment extends uniquely by copying its bits, and every accepting common word decodes to an original assignment. The size including explicit orders and names is polynomial and linear in the number of occurrences up to index bits. Encoding each transition by its 0/1 transition matrix produces same-width GF(2) weighted programs because each word has exactly one deterministic path.

Even promising that the pointwise product has a width-one GF(2) weighted program in EVERY order does not yield a known polynomial algorithm on the two different-order inputs. For the zero-or-one-solution SAT promise the common accepted set is empty or a singleton by the parsimonious map. A singleton word is a product of literal indicators, and zero is constant zero. Both have width one in every order. The Valiant–Vazirani randomized isolation reduction sends NO only to zero-solution instances and hits a unique solution with inverse-polynomial probability on YES inputs. The independent random affine equations can be encoded using deterministic gates with unique extensions if a bounded-width CNF frontend is desired. A fixed polynomial-clock solver correct on these promised inputs, allowed arbitrary answers on other inputs, would give RP=NP. If only a promised-input clock is specified, truncate at that polynomial. Search can validate the returned original word. [Valiant and Vazirani, 1986](https://ics.uci.edu/~vazirani/ValVaz.pdf)

This is a direct input-model boundary. The shared-order synchronous tensor and implicit-product algorithms require the same variable at each layer. Permuting matrices without rebuilding their semantics does not implement a variable reordering. Small product width as an existence statement omits the cost of constructing its representation. These statements give no unconditional lower bound on the time to solve SAT.
