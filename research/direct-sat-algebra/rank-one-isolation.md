# Isolating a consistent control setting

All linear algebra is over the binary field. Input is an explicit presentation of A,U,V,b,c, with k independently selectable controls. The system is (A + U diag(x) V^T)y = b + U diag(x)c. A supplied parsimonious XOR/AND gate encoding preserves the reasoning and the recovered original assignment.

Compute maximum attainable ranks r of the left matrix and s of the augmented matrix. Both matrix spaces have rank-one generators. Ivanyos, Karpinski and Saxena, https://doi.org/10.1137/090781231, give deterministic maximum rank and a maximizing matrix. If r=s, every maximizing control setting is consistent. Choose one, fix controls, and fix the n-r Gaussian free coordinates of y to zero. The resulting source instance has exactly one witness if its gate extensions are unique. For a square matrix an invertible specialization suffices even if the right side is computed by an arbitrary circuit.

For all inputs introduce w_i=x_i((V^Ty)_i+c_i). Exactly the pairs y,w with Ay+Uw=b and w_i implies (V^Ty)_i+c_i lift. Choose x=w for a canonical lift. Eliminate the linear equations first, stopping if inconsistent. The remaining forbidden sets are affine flats of codimension at most two. Empty forbidden sets can be discarded, an all-space forbidden set is a rejection. Only the dimension of the image of the joint tested forms in the Gaussian parameter space is needed; a witness pulls back via a linear solve. The number of possible x extensions depends on y,w; this is a decision and search equivalence.

Conversely each affine implication l_i(y) implies q_i(y) is l_i(y)=x_i q_i(y) with one private control. The update is supported in row i and has rank at most one. NAE(a,b,c) is (1+a+b) implies (b+c), with signed literal bits. Thus even row-local rank-one control consistency includes hypergraph two-colorability. The rank difference s-r is always 0 or 1. To force difference 1 in every instance, adjoin an independent private control t with equation 0=t as an extra zero row. Its left matrix is identically zero. At a maximizing old control choose t=1, so the augmented column is independent. The original system is feasible precisely when the extension is, by choosing t=0. If a nonzero update per control is required, instead append t z=t and a separate equation z=0: the left column on these two rows is (t,1), always rank one. At t=1 the new RHS (1,0) is independent of this column and t=0 gives a feasible new block. Hence the gap-one decision restriction itself is NP-hard, even using only nonzero generators for nonconstant source predicates. Polynomial recognition of a supplied encoding does not supply one for an arbitrary formula.
