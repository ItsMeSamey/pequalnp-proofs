# Positive separator and terminal algorithms for controlled pencils

Write q=V^T y+c, Uw=Ay+b. Eliminate y by Gaussian elimination to obtain the affine code of realizable pairs (q,w), expressed as sum_i (a_i q_i+d_i w_i)=h; reject if the affine linear system is inconsistent. Each codeword lifts to precisely 2^s data strings, where s=dim ker stack(V^T,A). Each pair has a number of private controls x solving w=xq given by f(0,0)=2, f(0,1)=0, f(1,0)=f(1,1)=1. Thus the original count is 2^s times a positive partition sum. Any associated gate encoding must have unique extensions.

For a region I in a supplied binary tree compute E_I=span(a_i,d_i:i in I). Possible interface syndromes belong to S_I=E_I intersect (h+E_complement), empty or a coset of dimension w_I=dim(E_I intersect E_complement). Store each local weighted count indexed by its syndrome in S_I. Join by iterating all pairs of child entries, adding their product to the entry for their sum when that sum is in S_I. Each feasible split has a unique syndromic pair. Singletons use four assignments. Positive backpointers recover the pairs, followed by a solve for y and controls. The clock is poly(input) times the sum of 2^(w_left+w_right) over joins plus leaf costs. Subtree counts fit 2|I|+1 bits and the full count fits n+k+1. Check a given tree by elimination or try input-order trees and select the least expensive; no general optimal-tree claim.

A region can be one terminal irrespective of its internal interface widths. For every permitted syndrome g its local equation is sum d_i x_i q_i=g+sum a_i q_i with independent data q_i. This is itself an aligned control pencil. If D_I=rank span(d_i:i in I), controlled-character-precision.md gives exact terminal cost 2^(w_I+D_I) poly(input), including any required q-pinning. Dense interior columns a_i can have arbitrary rank. Joins stay nonnegative. Boolean OR/AND joins plus exact terminal positivity suffice for decision. For any fixed full binary candidate tree, a bottom-up dynamic program chooses the cheapest certified subtree between a single such terminal and a split.

For controlled-radius-controls.md each (q_e,w_e)=(y_u+y_v,y_u) gives both endpoint data by an invertible binary map. The dimension of the edge-code projection on any subset is its count of incident vertices. Cut width equals the number of vertices incident on both sides: the kernel of a side parity-check matrix counts full codewords supported entirely on that side, one dimension per vertex exclusive to that side. Rank-nullity on both side matrices gives the claim. Group edges by triangle and then join consecutive intervals. Triangle intervals expose at most two vertices; a proper subset of one triangle exposes at most three. The exact count and a witness follow in polynomial time on this connected family despite its normalized valuation at least the chain length.
