# Deterministically discovering the joint image of explicit Boolean quadratics

For m explicit Boolean quadratics q on an affine input domain, let K be the number of distinct attained m-bit vectors. In deterministic time polynomial in explicit input length and K, list the vectors, their exact integer fiber sizes, and an original input attaining each. Neither a support list nor an upper bound on K is required. A predicate on the outputs can then be evaluated once per listed signature. A Gaussian solve first handles the affine input equations, either returning an empty domain or a bijective free parametrization. Substitution and squarefree reduction preserve degree at most two.

**Unknown-support construction in quadratic_image.py.** For B=1,2,4,… use the smallest binary field size Q≥2 strictly larger than (m−1)binom(B,2) (an empty output has one possible value). Construct a field deterministically by enumerating monic binary degree-log₂Q candidates and trial-dividing by monic factors through half the degree. Even this exhaustive construction takes polynomial time in Q. For each field element α use the binary linear hash h(y)=Σ_j y_j α^j, with j starting at zero. Each pair of distinct signatures has at most m−1 colliding α by the root bound for a nonzero formal polynomial. When B≥K one α therefore separates every pair.

For r binary quadratic observables g, integer Fourier inversion gives the exact mass at z as 2^(−r) times the sum over s of (−1)^(s·z) Σ_x (−1)^(s·g(x)). In a quadratic phase write any cross-term as uv+uA+vB+C with A,B affine on remaining bits. Summing u,v gives 2(−1)^(AB+C), preserving degree at most two. Repeat and finish with an affine character sum. Intermediate transform integers take O(d+r+1) bits on d free coordinates. For each h(q) bucket compute its mass N and also its signed count for each output coordinate. A positive bucket contains a unique signature iff every signed count has absolute value N. The signs identify the bits. This purity check makes early acceptance sound before B reaches K.

Trying all α requires O((m+1)Q²) quadratic phase calls per round, with polynomial additional bit work in d,m,Q and input length. There are O(1+log K) rounds, ending by Q=O(1+mK²). For each final bucket pin a free input bit to zero if its exact mass after doing so is positive, otherwise pin it to one. At most dKQ additional phase evaluations produce preimages. Input pins preserve quadracity, and Gaussian substitution recovers original coordinates. Running time is output-sensitive; polynomial-time recognition of an arbitrarily large image is not asserted.

**Algebra obtained.** The pointwise unital GF(2) algebra generated by the port bits on the input domain is GF(2)^K: for each realized signature the product of its corresponding literals is its bucket idempotent. The algorithm discovers these atoms without expanding the products. Their multiplication table is diagonal, and the integer histogram gives the counting functional. Unlike a promise only supplying a table or access to each port as a general circuit, explicit quadratic presentation permits uniform synthesis. No claim that arbitrary lifted October packet weights have this presentation follows.

**Affine target and radical.** For Aq=b form f=Aq. If R is the common radical of the polar forms of f and U={f(r)+f(0):r∈R}, then f(z+r)=f(z)+f(r)+f(0). Parametrize the domain by a complement C of R and by R. Project output modulo U, with quotient π. Each hit at πb in the image of πf on C lifts by solving the linear equation f(r)+f(0)=b+f(z). The target multiplicity is the quotient target count times 2^(dim R−dim U). All spaces follow by Gaussian elimination. The quotient image has exactly |image f|/|U| points. For a general predicate of all output bits, distinct translates need not have the same truth value.

**Scope.** On a connected graph the colour determinants q_uv=a_u b_v+b_u a_v realize at least 2^(n−1) outputs, since on a≡1 they are precisely b_u+b_v. Even the quotient by the full graph cut space retains exponential size on every six-regular simple graph, by colour-quotient-audit.md; this quotient is not an automatic lifting rule. Conversely taking all pair products on O(log N) bits and one additional full-rank quadratic on N other inputs gives a polynomial image even with quadratically many (in log N) independent outputs and linearly many influential input bits.

The exact counting result is degree-sensitive. Parsimoniously encode any CNF by Boolean quadratic gate equations f_i(x)=0, with deterministic gate values and a pinned output. A single cubic Q(x,z)=Σ z_i f_i(x) has at most two values, but its signed mass is 2^m times the original model count by orthogonality on the m fresh bits z. Polynomial exact fiber histograms for even one such cubic would put #SAT in FP. Presence of a one in a single explicitly supplied cubic is much easier: its squarefree representation identifies nonzeroness directly.
