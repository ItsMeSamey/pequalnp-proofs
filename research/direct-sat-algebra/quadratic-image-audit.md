# Audit of exact output-sensitive quadratic image enumeration

For explicit Boolean ANF quadratics q=(q₀,…,q_{m−1}), let K be the true number of different outputs. For a trial bound B=1,2,4,… choose a binary extension field of size Q, the smallest power of two strictly exceeding max(1,(m−1) binom(B,2)). For every α in that field try Hα(y)=Σ_j y_j α^j. Distinct binary words define distinct *formal* polynomials over the extension; each difference has at most m−1 roots, even if the field is too small for that bound to be informative at an early stage. When B≥K a good α exists. For m=0 return the unique empty vector and count 2^n directly. At m=1 this rule always uses F₂, which suffices.

For each α, for every coordinate j compute the exact histogram of (Hα(q(x)),q_j(x)). In a fixed polynomial basis the former has k=log₂ Q binary components. Every binary character of these k+1 components is the sign of an explicit Boolean quadratic; sum over x by symplectic elimination including the radical linear term and the constant sign. The integer Walsh inverse yields the exact nonnegative counts, dividing by 2Q only at the end. If a nonempty hash bucket has both coordinate values present for any j, reject this α. Otherwise all outputs in the bucket agree coordinatewise and therefore coincide. Its count is the total bin mass. All buckets and all coordinates must be checked: agreement for just one representative does not certify injectivity. Accepting a trial with B<K is sound and terminates early. At B≥K one candidate passes.

At termination B<2K except for K=B=1. One may construct a polynomial basis deterministically by enumerating at most Q monic binary degree-k polynomials, testing irreducibility in poly(k) operations per polynomial. Each α involves O(mQ) quadratic character evaluations and O(mQ log Q) additions for inverse transforms. There are at most Q candidates at that stage. Coefficients and signs in each quadratic are binary; each character sum has magnitude ≤2^n, inverse-transform temporaries ≤2Q·2^n, so n+k+2 signed magnitude bits suffice. Field arithmetic costs poly(k), and constructing each character quadratic from the explicit ANFs takes polynomial time in the input size and k. Overall bit complexity is polynomial in the explicit input size and K, including all doubling stages; for n given in binary with unused variables not listed, these bounds charge n explicitly for full witnesses and integer multiplicities. A verified α remains injective on every restriction. For a given output bucket and an input prefix, use only its k-character inverse sum for the trial prefix with next bit zero; take that bit when the count is positive, else take one. Here “k-character” means the k-bit hash, requiring Q characters. There are at most nK prefix trials, and pin substitution preserves degree two. Multiplicities and one witness per output are therefore available at the same polynomial scale. This concerns explicit binary quadratics, with no general exact SAT oracle assumed.

## Common-radical affine quotient

For a target A y=b first replace q by f=Aq, of output dimension p. Its common polar radical R may strictly enlarge under this projection. D:R→F₂^p given by D(r)=f(r)+f(0) is linear and f(c+r)=f(c)+D(r). Compute a complement C to R, put U=D(R), choose a quotient map π with kernel U, and run joint enumeration only on πf restricted to C. Every representative c contributes either zero solutions if πf(c)≠πb or precisely 2^(dim R−dim U) solutions otherwise. Thus the target count is that multiplier times the enumerated multiplicity of πb on C. Lift a witness by solving D(r)=b−f(c). The quotient image size equals |im f|/2^dim U, so the improvement can be exponential. For example f(z,x)=(z,g(x)) for d independent free z bits and one nonconstant quadratic g: at least the z-space is in R and removes the 2^d factor. The result extends to listing all image cosets with multiplicities per element, but explicitly listing all original images still costs their output length. Polynomial preprocessing uses intersections of polar nullspaces, binary elimination and quadratic substitution. For singleton targets in the quotient one need only keep its certified bucket count.

The connected quadratic-batch.md supplies the individual phase evaluator; its full truth-table tabulation bound includes 2^n. The construction here instead queries characters of a deterministic separating family on the unknown image. Arbitrary finite-algebra contraction is not required; this audit makes no bibliographic priority claim.

## Prefix-support variant without extension fields or doubling

Begin with the known empty output prefix. At stage j the actual set S of attained j-coordinate prefixes is known. With s=|S|, choose k≥0 minimal with 2^k>binom(s,2). There is a deterministic binary linear hash H:F₂^j→F₂^k separating S. For a uniform random matrix H each of the binom(s,2) differences collides with probability 2^(−k). Fix entries by conditional expectation of the number of collisions. Given a partial fixing, the collision probability for a given difference is the product across rows of 0, 1, or 1/2 according as its dot product is forced nonzero, forced zero, or still uniform. Greedily choose the bit value with smaller conditional expectation (represented with denominator 2^k). The initial expectation is below one, hence the final integer collision count is zero. For s=1 take the empty hash.

One exact joint histogram of (H q_prefix,q_next) then identifies all (prefix,next bit) pairs and their multiplicities using the stored inverse on H(S). Induction enumerates the full image with O(mK²) phase evaluations and polynomial additional input/K bit work, never guessing K. Conditional-expectation integers need O(k+log(s+1)) bits. A final separating hash on the stored full outputs supports the same pin witness recovery. This alternative avoids relying on finite-field construction and treats m=0 without a separate transform.
