# Exact signed maximal-cone score for the single-output SAT reduction

Use exactly the physical construction of [the hard-core note](noncontiguous-nand-hard-core.md), with C≥1 strict three-literal clauses, pairwise distinct variable names within each clause, and only the designated positive root pin. Interpret u as the number of occurring master variables appearing in exactly one literal slot. The signed canonicalizer and cone scorer return exactly 7C−1−u bad blocks. With repeated copies of each source clause, u=0 and both original verdict and source model set are preserved. Use fresh clause-private primaries and gates per copy as prescribed.

Every original NAND core t=NAND(p,q) survives, since its private primary operands have different base IDs. The tied gate s=NOT(t) becomes the signed alias (t,1). The positive-third-literal inverter and final inverters on negative copy checks also become aliases. In the binary conjunction tree each NAND on two child outputs survives and its trailing NOT becomes an alias; the children are distinct produced gate IDs. The XOR check retains all four gates h,j,k,w: each reads different base IDs. No constant propagation or equal-base case applies to any surviving gate. The retained graph has C core gates, C clause-test gates, 8C XOR gates, and 3C−1 tree gates, for 13C−1 gates. Distinct check and clause gates retain distinct bases even if two source clauses coincide.

The closure of the two private primaries p,q contains only their core t. Each first gate of a copy check additionally needs its master X, and the clause test additionally needs its third master. Thus the cone containing t is an actual singleton, with both primaries exported to their first mixed checks and t exported to the clause test. Its ports are exactly p,q,t. Four local input assignments give the ordinary NAND truth graph.

For a copy check, closure from its two entries p,X contains exactly its four XOR gates. No other private primary or outside check output can be generated from these entries, and the clause test needs t. For the clause-test operand pair (t,X_c), closure contains only the test, since no other component reads t and all remaining source checks also need their distinct private primaries. For each tree gate, closure from its two child-output bases contains only that gate: each child is a distinct produced wire used only at its parent, and no other child is generated. These cones partition all retained gates. To verify their maximality directly, the only remaining seed types are operand pairs of interior XOR gates. Starting from (p,h) or (X,h) can produce just j or k, respectively; (j,k) produces just w. No such pair reaches outside its own XOR cone. Thus this is exactly the maximal partition on the normalized topology, independent of legal gate ordering.

Both computed child entries of every tree gate are visible under the gate-output-entry rule; the resulting output feeds its parent or the translated root pin. Its four rows form a signed NAND graph. Each XOR block exposes its private primary because that bit also feeds t, and its output because it feeds the conjunction. Its master is exposed precisely if it occurs elsewhere. In that event its three-port XOR graph is nonbijunctive; otherwise its projection has only two ports and is bijunctive. At a clause-test block t is an exposed computed entry, the test output feeds the tree, and its third master is exposed precisely if it has another occurrence. Again the full ternary signed NAND graph is nonbijunctive and the two-port projection is bijunctive. The three distinct names per clause are used here. Exactly one block loses a necessary master port per singly occurring variable. Together these counts give the claimed score.

For signed NAND or its complement, primary corners 01,10,11 witness failed majority closure in the ordinary NAND coordinates; flips transport this counterexample. For XOR the corners 00,01,10 suffice. Each bad table has four distinct port words because both entries are visible. The actual backend stores the first two and the last two separately, taking the exact binary hull of each. Both halves are proper, nonempty, disjoint relations. Materialized signed reads are private tied NANDs inside their chosen blocks and preserve these four rows. The raw reconstruction still returns precisely the original master and clause-private primary bits; every source model has the unique extension described in the original hard-core note. A local split can be globally inconsistent. A successful search may stop early, and another solver may recognize the source; the score is not a lower bound for general SAT.
