# Exact integer counts on original paired flags

The count is computed before quotienting by universal orientation directions. After compacting the linear span of the input columns to rank r, sum over all 2^r binary characters. For a disjoint conflict biclique with two shores L and R, its factor is the product of (1+character(column)) over L, plus that product over R, minus one for the shared empty selection. Free flags have their individual (1+character(column)) factors. Multiply by the target character and divide the signed integer total by 2^r. Orthogonality gives exactly the number of permitted original failure words with that target. Equal columns and zero columns retain multiplicity. Under pins, omit the empty overlap precisely when it is no longer possible. Sequentially count the zero extension of each next original bit, taking the one extension only if needed. The original full count is retained; the positive witness is lexicographically first in flag order.

Numerators have at most n+r+O(1) signed bits for n flags. Up to n+1 passes with polynomial work per character give O*(2^r) deterministic time and polynomial space. On indexed signed comparisons, integrate each failure word and multiply its count by 2^c for c connected components including declared isolated vertices. Raw copy pins must first be contracted onto actual equivalence classes; unused nonroot coordinate names do not supply physical choices. Restore the pin offsets and verify all indexed shells. Raw counts differ from counts of compiled netlist guards if the latter supply additional choices.

The two-bit test has original fibers 1,2,2,4 despite a full universal direction space. Quotienting that space gives nine quotient solutions and changes multiplicities. That quotient is used only for decision and witness elsewhere.
