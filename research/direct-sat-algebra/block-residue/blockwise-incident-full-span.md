# Independent branching budgets for graphic blocks

Keep the original fundamental cycle basis H and chord set Q. For U the intersection of all oriented column spans, U^⊥ is generated by the incidence vectors of compatible simple cycles restricted to Q. Each simple cycle lies in one graphic-matroid component B. A forbidden pair crossing different blocks therefore excludes no individual cycle and can be ignored when computing this span. Linear combinations of generators may use both members.

Let k_B be the number of internal pairs in B whose edges have no common endpoint. Branch on one deletion from each of these pairs, treating their surviving mates as unpaired. Every compatible cycle survives at least one choice, obtained by deleting an avoided member from each pair. Conversely every cycle surviving the deletions respects all the branched pairs. The remaining internal pairs are incident. Apply the deterministic matching-hull construction in [the incident-pair proof](incident-pair-full-span.md) on the residual graph. Bridges contribute zero and singleton loops contribute independent unit vectors.

For each branch project the matching-hull vectors directly onto the designated outer readouts of surviving edges in the **original** chord set Q and pad with zeros elsewhere. The gadget has a readout for every residual edge, irrespective of whether it is a chord in a residual forest. Alternatively lift residual-chord vectors to full residual cycle vectors before restricting to Q. Taking the linear sum of branch and block spaces now gives U^⊥ exactly, by the union of the compatible cycle families. Return the annihilator in the original syndrome coordinates, changing row basis if required. A separating cycle found in one branch also gives a global orientation: choose an off-cycle edge in every original pair, including crossing pairs.

The deterministic bit cost is (1+Σ_B 2^{k_B})·poly(N) for N indexed vertices plus edges. Streaming branches and reducing into a running basis uses polynomial space. No Cartesian product of branch choices across blocks is needed. This statement is about universal span membership. Primal signed-shell satisfaction can still be NP-complete even when all pairs are incident, by the signed NAE-3SAT encoding.
