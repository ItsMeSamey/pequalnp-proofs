# Matching signed state indicators from exact original NAND block tables

For each checked block retain one state per distinct projected port word, and save an actual input trace for lifting. The state bits satisfy one exactly-one demand per block. If every observed port column on these states is constant, a single state indicator, or its complement, store that expression for the physical port. With two states an expression may be nonunique; select a representation and verify the resulting degree condition, rather than assuming all such choices are equivalent for recognition. An empty local relation rejects. With one state all port columns are constant.

Identify expressions for the same physical wire, and impose all exterior signed equalities and unit pins. A general binary exterior clause needs its own exact representation, for example a three-state table of its satisfying assignments when its variables are distinct. It cannot be dropped. Propagate constant constraints by signed equivalence classes, rejecting incompatible parities. Preserve every state occurrence in its original demand, including occurrences with the same underlying variable and opposite signs. When a demand has a forced true literal, require every other occurrence to be false and discharge it. Delete forced false occurrences, reject empty unsatisfied demands, and repeat as needed. The degree promise for this backend counts remaining occurrences in demands, not the number of port references made to a state. Each variable occurs at most twice with arbitrary signs.

Use one required graph vertex per demand. For a two-occurrence variable with the same sign at both occurrences, add a selectable edge between their demand vertices. Selecting it makes both occurrences true; leaving it unselected makes both false. When both belong to the same demand they can never be true together, so suppress the edge and set their common literal false. For opposite signs exactly one occurrence must be true: add a required vertex for the variable with one incident edge to each demand occurrence. If both occurrences belong to the same demand, keep distinct indexed parallel edges or choose either occurrence when lifting the collapsed edge. A one-occurrence variable gives an edge to a fresh optional leaf and is free to be false. Unconstrained classes have arbitrary bit values.

A matching saturating all required vertices is equivalent to an assignment making exactly one occurrence true per demand. Decode each bit from its selected occurrence and sign, including the false choices for unselected same-sign and singleton variables. To use ordinary perfect matching instead, make all optional vertices a clique, adding one optional vertex if the total order was odd. Every required-saturating matching extends because the residual optional order is even. Removing the clique edges from a perfect matching gives a required-saturating solution. The clique can cost quadratic explicit size. With simple-graph parallel-edge coalescing retain a particular original label when reversing the matching. After reconstructing all exactly-one states, lift the saved traces, restore private primary inputs, then evaluate the original NANDs and check all physical exterior rows. This is decision and witness recovery, without a matching-count identity.

There is a concrete nonbijunctive NAND example. For fresh x,g compute O=NAND(x,g), E=NAND(O,g), T=NAND(E,NOT g). Its triples (E,O,T) range over 110,101,011. When only those three taps are exposed, each zero is a unique state indicator. Use a private copy per vertex of a cubic graph and equate the taps for the two endpoints of each graph edge, using the same sign. The projected selections are precisely perfect matchings of that graph. The raw NAND entrances exist and exact local lifts are available, including two choices on one row. The wiring hypothesis here includes the physical exterior equalities.

For the all-input local-table rule, two distinct exposed entering base wires preclude eligibility: the four physical input combinations yield four distinct projected words, and each entering wire has two ones and two zeros. More generally one exposed entry already rules out a four-state table. This is independent of signs. In the normalized distinct-base topology the earliest gate of any nonempty two-entry group reads both its entries, so any imported computed wire is produced before that first gate. At most one such imported wire is possible on an eligible table, and if it is imported the other entry cannot be a shared primary. For a sole designated output with no separately coupled exterior, following its block's computed input backwards therefore follows at most one predecessor at each step. Blocks may fan out, but two predecessor blocks cannot reconverge within that output's ancestry in an eligible all-input chart. A composed NAND suffix implementing many exterior equality checks must itself satisfy the port criterion if claimed as part of this backend. A positive-output pin imposed after making the full tables does not remove a two-ones column from such a table. Procedures that soundly condition local tables first have a different eligibility test.
