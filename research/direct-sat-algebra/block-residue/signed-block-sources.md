# Signed blocks, balanced edge sets and pins

An edge with sign bit (d) prescribes the binary difference (d) between its endpoints. An edge set is balanced exactly when its prescriptions have a common solution. Its minimal obstructions are cycles with odd sign sum. This is the central-set interpretation of a system of affine equations. Zaslavsky's frame and lift matroids both take positive cycles as circuits and allow a single negative cycle as an independent set. [Ardila, Proposition 2.2](https://fardila.com/Articles/semimat.pdf) · [Zaslavsky, *Biased graphs II*](https://doi.org/10.1016/0095-8956(91)90005-5)

The recognition criterion follows from circuit elimination. If an unbalanced block contains more than a negative cycle, that cycle has an ear in the block. The ear and the two arcs form a theta containing two negative cycles. Removing an edge of their common path leaves only a positive cycle, violating elimination. Conversely, when each unbalanced block is a single cycle of length r, that block contributes the uniform matroid of rank r−1. Edges in balanced blocks are free. This includes loops as singleton blocks and parallel-edge cycles of length two. A block decomposition and sign propagation recognize the class in linear time. The implementation in [balanced_block.py](balanced_block.py) instead traces fundamental paths and can spend quadratic time on that step. The criterion here is a deduction. Related work characterizes edges in unique signed cycles. [Behr, *Edges and vertices in a unique signed circle in a signed graph*](https://doi.org/10.1016/j.akcej.2017.03.004)

## Pin audit

In `balanced_block_witness`, a raw pin `(a,b,s)` imposes `raw[a] XOR raw[b] = s`. Propagation gives one unfixed bit per connected pin component and one offset per raw vertex. Contradictory pin cycles, including sign-one self-pins, return infeasible. Substituting `raw[a] = value[root[a]] XOR offset[a]` changes the desired difference for each shell comparison to `1 XOR offset[a] XOR offset[b]`. Each original comparison keeps its edge identity and its paired shell, even when contraction creates loops or parallel edges. A loop with desired difference zero is always met. A loop with desired difference one consumes the shell's one permitted failed comparison.

The final substitution returns all original raw bits and satisfies every consistent pin. An unbalanced block outside the recognized class raises `UnsupportedBlock`; that outcome makes no feasibility claim. This audit uses the source definitions and leaves execution verification to the package checks.
