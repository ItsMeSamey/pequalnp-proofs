# General unweighted matching backend

The implementation uses Edmonds' single-root alternating-tree search and odd-blossom shrinking. It restarts from the first exposed root after each augmentation and stops after a complete unsuccessful scan of the exposed roots. Parallel indexed edges can be coalesced here because this interface returns endpoints. A caller needing a particular indexed parallel edge must preserve that information separately. Loops cannot be used in an ordinary matching and are dropped.

In a search, an outer base has an even alternating route from the exposed root. A tree edge to a previously unseen vertex extends that route by an unmatched edge and then, if available, the vertex's matched edge. An outer-to-outer edge between different bases closes an odd alternating blossom at their common outer ancestor. Only the base may be matched outside that blossom. Shrinking preserves existence of an augmenting path from this root; to lift a contracted path an entering edge can be joined to the base by the correctly alternating one of the two cycle routes. Scan newly outer original vertices to expose all exits. Predecessor rewrites along both sides record those routes for implicit expansion, including previously contracted blossoms. On reaching a distinct exposed endpoint, following predecessor then old mate flips a simple augmenting path on original vertices. With no augmenting path from any exposed root, Berge's criterion gives maximum cardinality.

An individual search scans at most twice the input edge count and performs at most n strict contractions. Each contraction uses O(n) ancestor, route and base operations. A conservative bound with this restart policy is O(n²(m+n²)) indexed operations and O(n+m) working storage, apart from label lookup and initial sorting. Fixed input vertex order determines all choices, independent of input edge order.

Original algorithm: Jack Edmonds, “Paths, Trees, and Flowers,” Canadian Journal of Mathematics 17 (1965), 449–467. [Paper](https://doi.org/10.4153/CJM-1965-045-4).
