# NP-hard joint fixed point for path projection and supported-block peeling

Start from three-literal SAT. For each source variable x add the two tautologies (x or not x or x) and (not x or x or not x), counting positions separately. Each used polarity now has at least three opposing occurrences. For each clause make a separate triangle and give its three oriented Boolean comparisons flags f_i equal to the endpoint xor plus a fixed offset a_i. Choose the three offsets to have odd xor. The attainable triples are exactly the odd triples. Identify one vertex from each triangle to form a common articulation; independent global flips of each triangle permit any tuple of locally attainable flags to glue at that vertex.

For each complementary pair of literal occurrences i,j add a paired shell requiring f_i=0 or f_j=0. It uses fresh indexed copies of their respective triangle edges. A source satisfying assignment selects one true occurrence per clause, sets only those flags to one, and lifts through each triangle. Conversely odd parity selects at least one occurrence per clause, and no complementary selected pair is possible. Assign variables according to the selected literals and complete untouched variables arbitrarily. Thus both verdicts and original witnesses transfer in polynomial time. For signed-copy raw input allocate distinct edge endpoints per request and tie occurrences of a graph vertex by a path of copy pins with the appropriate stored offsets. Each copy position has at most two incident copy pins.

Every triangle link has at least three indexed requests. Every triangle is consequently one complex graphic-matroid block. Meeting all its requests would set all three flags to zero, violating odd parity. The supported-block autarky peels nothing. All graph vertices have indexed degree at least six; hence every maximal comparison path is a singleton. Its incidence components are exactly clauses with singleton leaves, so path projection returns all starting shells. Repetition cannot change the result. Each triangle contributes two automatic branch guesses. Replacing parallel edges by one edge would invalidate the proof and the solver.

This specializes the disjoint-triangle reduction supplied by the literature reviewer. It is a hardness result for the residual image under these two specified operations; more general preprocessing can exploit features they leave behind. Tautologies are added in constructing the physical input and never restrict a source assignment.
