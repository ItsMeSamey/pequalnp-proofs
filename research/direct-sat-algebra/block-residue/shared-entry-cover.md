# Shared-entry branching for signed NAND cones

Use the normalized signed-wire representation, translated exterior and maximal cone partition in signed-cone-normalization.md. Compute each block's original visible-port relation on all assignments to its entering base wires. For every non-majority-closed block insert its unordered pair of distinct canonical entries into a graph (fewer than two entries give at most two rows and cannot fail). Repeated pairs may be merged. A minimum vertex cover S with size k meets every bad block. Find it by iterative deepening over endpoint branches of an uncovered edge. Every cover must contain one endpoint; an unsuccessful depth below k is exhausted, and the geometric sum of search-tree nodes through depth k is O(2^k). This optimizes only the stated edge-covering criterion.

Enumerate the 2^k assignments to S. Post the corresponding global unit on every chosen canonical wire, including computed gate outputs. Evaluate all four entering choices per block, keeping the input choices even when their visible port words agree. Filter rows by selected entry values before merging equal visible words. Every bad block now has at most two rows and thus has an exact 2CNF description. For an originally good block any pinned entry that occurs in it was already visible: a computed entry is always visible, and a primary selected by an incident bad block has another reader if used by a different good block. Restricting visible coordinates of a majority-closed relation preserves closure. A pinned output produced in a block for another block is always an exposed port there. Thus the filtered tables' binary hulls with the units and translated exterior give one exact 2SAT per global assignment. A hidden primary local to a bad block is handled by filtering its entry witnesses even if it has no port coordinate.

Lift a satisfying assignment by choosing one saved compatible entry row per projected word. A hidden primary occurs in only one block; shared primary rows agree on visible values, and computed entries agree with their external producers. For a topological induction, a block's chosen trace may span nonconsecutive gates, but each original gate has only earlier operands. Recompute all gates from the recovered primary bits, verify global units and hull rows, compare every original wire with its signed alias, and replay the actual original exterior and asserted output. Exhausting the cover words proves UNSAT.

The two stages use O*(2^k) total time and polynomial space (candidate covers are found before any truth assignment is enumerated). This parameter can be one on arbitrarily many bad cones: share one primary pilot across independent single NANDs, exposing their private inputs, outputs and pilot via exterior constraints. Their bad-entry graph is a star. Runtime still charges the original gate list, numeric primary count, exterior input and polynomial cone construction. No execution is claimed without an 04 receipt.
