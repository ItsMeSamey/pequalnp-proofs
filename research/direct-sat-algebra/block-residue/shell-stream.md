# Whole-shell sparse signed program

Shell reads both physical bits of each named vertex consecutively, low first. Each bit independently belongs to the observed word or is summed. Ordinary edges carry arbitrary four-bit lists of allowed endpoint XORs. Each supplied complete bipartite constraint has such a list shared by its cross pairs; different constraints can overlap. Unary lists are physical, while unary signed weights can vanish. Affine conditions are given by packed original-bit syndrome columns and a target. These are explicit shell inputs, with no claim of discovering a small shell from a general NAND circuit.

For each reachable prefix store its partial syndrome, the pending low bit if inside a vertex, four forbidden-future-vertex masks from ordinary edges, and the exact used colors on every biclique side with a processed member and unread opposite member. Other palette slots carry zero. When completing a vertex, test the ordinary mask and all opposite palettes, update future masks and side palettes, then discard every palette with no unread opposite member. An internal membership can be shared among several constraints without conflating their palettes. Multiply by the unary weight exactly once. Discard a new syndrome when target XOR syndrome lies outside the remaining column span. Prefix-span membership holds by construction, so its number of possible values at a cut is at most two to the dimension of the prefix/suffix span intersection. A surviving state can still be a dead end via the color constraints.

The sparse output transitions retain the physical bit and its modular coefficient, including zero-weight physical paths. Histories that agree on state have identical continuations with the same additional weights. Summing contributions after merging computes the exact weighted count. For an observed word, fiber also keeps an independent predecessor for each physically reachable state even if its accumulated value is zero. It replays the reconstructed named colors on the original unary, edge, biclique and syndrome constraints and the observed bits. It gives a physical coloring of the supplied shell; the caller must separately replay any originating circuit or raw-permutation chart.

The nonidentity adapter sums both physical choices at hidden layers into the matrix for dummy input 0 and uses a zero matrix for dummy 1. Thus true observed words have one contributing padded input each; other padded words yield zero. Previous modular_support.nonzero returns a real nonzero padded input or certifies identity; the adapter projects off the dummy bits and replays the result through fiber. No division by two occurs.

For actual layer widths W_i there are at most 2 W_i physical transitions from layer i. Construction charges polynomial input and state-key work per considered transition, including storing the reachable layers and the emitted program. At a cut with ordinary bans potentially on f unread vertices and a active side palettes, a coarse width is twice 2^lambda times 16^(f+a), where lambda is the syndrome span intersection dimension. Constants for the pending bit and inactive slots can be omitted when appropriate. Evaluating one word streams its modular vector and stores predecessors when a witness is requested. The adapter additionally materializes two W_i-by-W_(i+1) dense matrices per layer and pays the explicit previous module-test clock. These costs may be exponential in the physical input. An identically zero modular function does not imply that all physical fibers are empty.
