# Deterministic block-residue support

Split n original inputs into h prefix bits u and b suffix bits y. Inspect C(u,0) for all prefixes. After all anchors fail, every suffix count belongs to [0,2^b−1]; a prefix with nonzero count mod 2^b has a physical witness. A final scan of its 2^b suffixes returns one. Charge both the 2^h anchor checks and that final scan. If C is independent of y, the anchors alone decide it.

For each signed term in ../and-count-low-precision.md write its equations as A v+B u=d with v the suffix and named gate bits. Put r=rank A, R=rank[A B], nu=dim(v)−r, c=R−r. The projected support is empty or an affine flat of codimension c. A suffix sign cancels unless its character belongs to the row span of A. Otherwise the projected term is 2^nu times an affine sign on that flat; elimination retains the actual offset. Drop nu≥b. The cost of finding all candidates is separate from processing an already supplied list.

## Testing the joint function

Use a layered weighted program over Z/2^b on a single physical prefix-bit order. Its output is a start row times one transition matrix per bit times a terminal column. One projected flat Hu=t has a program recording its partial syndrome; keep only states in the span of read columns that can be completed to t by unread columns. At most 2^lambda states survive, with lambda the dimension of the intersection of those spans. Each bit also multiplies its sign character; include the overall sign offset and dyadic coefficient once. Take a block-direct sum for the full sum. Charge all projected terms and all program construction. Other verified common-order programs may be used directly.

At each layer retain actual row vectors of actual original prefixes generating the module of all attainable rows. Apply both next matrices to each retained row. At the new layer keep the resulting actual prefix only if its row is outside the span of the previously kept rows. Linearity gives the invariant. With maximum width W at most bW strict enlargements occur per layer: each at least doubles a subgroup of the additive group of size 2^{bW}. Test membership by adjoining 2^b I to integer row representatives and computing integer-lattice membership using Hermite normal form. This avoids division by nonunits. At termination the function is zero exactly when the final column annihilates all retained rows. A failing generator is itself an original prefix, so no formal linear combination has to be decoded. [Polynomial bit-time HNF](https://doi.org/10.1137/0208040).

Let H(L) be the polynomial bit cost of HNF membership on L input bits. For positive h,b,W a loose explicit clock for the joint test is O(h bW (H(O((b+1)^2(W+1)^2))+poly(b,W,h))). Add the charged circuit/program construction, both original scans, and source evaluation. Storage is polynomial in the explicit program, not necessarily in source circuit length. If the term sum has a supplied Walsh numerator with K different frequencies over denominator 2^c, instead use one K-dimensional diagonal sign action per bit and modulus 2^{b+c}; verify pointwise exact division by 2^c. Charge expansion to K distinct terms. This is the ring version of a reachable-span test, with a physical witness.

The randomized archive handles dense solutions by sampling and smaller sets by random affine isolation; its unpinned rank cutoff cannot simply be reused after pinning h bits. A deterministic test for bounded-width compiled programs does not prove small width for original circuits. A modular sum of squares cannot certify identity over this ring, and Walsh division without retaining the denominator precision is invalid.

## Other falsification and prior algorithms

For arbitrary G(u), C(u,y)=G(u) AND parity(y) has no anchor hit, every positive fiber has size 2^{b−1}, and every precision below b gives the zero function. At full precision the support question still asks whether G has a model. This uses O(b) added NAND gates. Point-query-only deterministic tests need all 2^h prefixes on the all-zero transcript to distinguish a singleton; circuit inspection is outside that lower bound.

The matching-flats.md family defeats enumerating all surviving canonical projected terms even after exact same-flat aggregation. It does not defeat alternative algebraic identities or a formula-aware compiler. The general target of a deterministic saving at near-linear or arbitrary gate counts remains unresolved.

The Chan–Williams bounded-arity CSP counting algorithm charges every introduced gate variable if applied to the ordinary Tseitin encoding. [Theorem 1.6 and proof](https://people.csail.mit.edu/rrw/derand-apsp-ov-cr-talg.pdf). Dinur gives a randomized algorithm on the total variable count of quadratic systems. [Theorem 1.1](https://arxiv.org/pdf/2005.04800). Deterministic algorithms for sparse original circuits predate this note; pure NAND circuits of sufficiently low linear density must be compared with existing U2 algorithms, not only the affine-gate expansion. [Golovnev, Kulikov, Smal and Tamaki](https://eccc.weizmann.ac.il/report/2016/022/). No priority or all-input clock improvement is claimed.

### Direct modular membership

modular_support.py chooses a minimum-valuation nonzero entry in the entire generator matrix. Normalize that pivot row by an odd inverse so its pivot equals 2^s. Each row entry is divisible by 2^s. Reject if the target pivot is not divisible; otherwise clear the target and all remaining rows at that position using a canonical multiple of the pivot row. Any alternative multiple clearing the pivot differs by an annihilator of the entire pivot row. Drop the row and column, recursing until the residual target is zero or no further reduction is possible. With at most bW generators this costs O(bW³) ring operations per candidate. A conservative O(b³) bit allowance per modular operation or inverse yields O(h b^5 W^4) arithmetic bit operations for the full support test, plus input parsing, program acquisition and index bookkeeping. This implementation handles an explicit weighted program, not compilation from an arbitrary NAND circuit.
