# Selecting one original input cofactor

For each original input bit actually read by a gate or the exterior, raw_lookahead.solve computes both signed-cone partition costs after fixing that input. It also computes the unconditional cost. It performs normalization, cone construction, exposure checks and majority testing during candidate selection; it never solves a candidate SAT instance merely to rank it. It compares 2^b with all sums 2^b0+2^b1 as exact integers. Ties prefer no split, then the lowest input index. Each threshold has at most g+2 bits for g original NAND gates. An unused input cannot improve the sum.

The implementation prepends three physical NAND gates producing both constants from the candidate input. Every original use of that input, including any exterior observation or designated output literal, is redirected to the selected constant. Shifting gate IDs preserves original dependency order. The signed normalization removes the constant prefix. Each cofactor therefore agrees with the original circuit on its named slice, for every valuation of all remaining inputs. The dummy value on the candidate input is unconstrained during residual solving and is set to the requested value on recovery. The solver then replays every original gate and every exterior row. It returns UNSAT only after all selected slices have no witness.

For H distinct occurring input bits there are exactly 2H+1 polynomial scoring calls. Let W be declared input count plus gates plus exterior length plus one. The frozen cone evaluator uses at most O(W^2) gate scans and O(W²) comparisons on bit masks of O(W) bits per call. A conservative uniform deterministic bit bound is poly(W) times (2H+1+B), where B is the selected minimum budget. Storing and comparing a budget charges its bit length, not its numerical value; exponential work occurs only if the selected feasible-region search calls require it. Only one score/slice is kept at a time and all procedures have polynomial space. The formula controls the number of 2SAT trials; unconditional discovery can be cheaper on a particular input, and a SAT branch can terminate early. This comparison does not establish a uniformly faster total clock or a subexponential worst-case for arbitrary circuits.
