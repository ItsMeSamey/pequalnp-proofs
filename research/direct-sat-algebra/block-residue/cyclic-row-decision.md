# From an original NAND output to a certified cyclic row problem

The methods use the signed cone and promotion frontends from the joint row decision package. The circuit input consists of indexed original NAND gates, original raw input count and the required positive output wire. Each surviving site has at most four feasible exposed rows. Compatibility is tested on every pair against the common 2-CNF base. Unit pins make pair compatibility exact, so solving the resulting binary constraint network recovers a common physical assignment. The implementations replay the recovered raw bits on every original wire and exterior condition.

The ordered solver offers two proposed total orders per site for each of its min and median modes. It tests every pair of choices on each recovered relation and solves the resulting order-selection 2SAT instance. A min-closed network is solved by arc consistency followed by taking the least surviving value at each site. If the left and right minima have possibly different witnesses on an edge, the componentwise minimum of those two witness pairs equals the pair of minima and is allowed. For a median-preserving selection, threshold bits in chain order preserve coordinatewise majority and expose every row as a Boolean string. The binary Boolean projections then suffice, and a single 2SAT instance determines consistent rows. Failure of the proposed charts returns skip. It does not certify that no other ordering works.

The indexed variant accelerates the feasibility probes without changing their semantics. It computes reachability on the strongly connected components of the physical implication graph. Against a feasible base, additional pins are jointly consistent exactly when no pin implies the negation of another (including itself). Promotions can be collected against a fixed base and appended together before rebuilding. Each promotion preserves all original solutions and every row removed was already infeasible. The final index also answers all row-pair probes. If there are s components, bit-mask storage can be quadratic in s even if many implications are absent. Computation of every bitwise union charges the full mask length; it is not constant-bit work. For W including all input bits, gates, exterior data and recovered tables, these procedures have deterministic polynomial bit time and space. A returned raw word explicitly writes all N input bits.

The more general majority module decides whether the full family of site relations has suitable local majority operations, subject to an explicit limit on the indicator network. Repeated arguments fix their operation-table entry. Ordered triples of all-distinct arguments remain independent. Constraints on triples of allowed pairs require their chosen outputs to form an allowed pair. Under the existence of majority, this indicator CSP is itself majority-preserved; strong path consistency and greedy extension construct the operations, which the implementation verifies. Missing operations and explicit caps are different from an UNSAT verdict for the physical NAND instance. The uncapped algorithm is polynomial in the explicit network and tables, with a much larger polynomial than the two-order test. The majority-recognition method is classical; the original NAND frontend, certified row extraction, implementation and witness replay are the contributions here.

In the unbounded-width control the recovered graph includes K_{n,n} on four-state sites and a path of four comparisons on one shore. Both the SAT and UNSAT variants retain every one of the four states before the resulting ordered CSP is solved. There are 2n surviving nonbijunctive tables. The width is at least n, despite the polynomial ordered decision. This compares against forest and bounded-width approaches on the recovered graph; an explicitly supplied ordered CSP would already be tractable by classical propagation. The static source comparison and physical high-width fixture give the exact construction and sources.
