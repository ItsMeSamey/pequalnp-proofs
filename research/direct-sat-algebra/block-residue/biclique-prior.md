One orientation per complete bipartite conflict is bounded variable addition. See Automated Reencoding Meets Graph Theory (https://doi.org/10.4230/LIPIcs.SAT.2026.29). The physical solver additionally retains signed cycle equations and replays the reconstructed original bits. For general affine subspace constraints with binary clauses see Arvind and Guruswami (https://doi.org/10.4230/LIPIcs.IPEC.2021.5).

An independent prior hardness source is Nguyen, Lemma 5.6 (https://arxiv.org/pdf/1901.07028#page=17). Undirected rainbow path is NP-complete even with one edge or two nonincident edges per color. Adding a return edge gives a marked cycle and the color pairs are disjoint. Singleton edges and the return edge can receive private zero-syndrome bridge partners. This gives the same coNP universal membership statement as the self-contained marked-cycle proof. No priority claim is made.

For the standard polynomial-calculus derivation rules see Clegg, Edmonds and Impagliazzo, Using the Groebner Basis Algorithm to Find Proofs of Unsatisfiability (https://doi.org/10.1145/237814.237860). The implementation only combines its given reduced quadratic generators linearly; the separate calculus comparison gives the precise scope.
