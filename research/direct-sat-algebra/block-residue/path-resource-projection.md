# Projecting paired signed comparisons along degree-two paths

Start after consistent signed copy contractions. Each indexed edge e requests x_u XOR x_v=d_e; a shell owns two distinct indexed edges and requires at least one request to hold. An already discharged shell can leave an unpaired free comparison. Count a loop twice toward vertex degree. Retain every vertex of degree other than two, together with any additional physical terminals whose potentials must remain visible. In each remaining connected component consisting entirely of degree-two vertices, retain one arbitrary root. Isolated vertices can be kept as free bits. Trace unused edge incidences from the retained vertices across degree-two interiors. This partitions the graph into nonempty paths. A path can return to its start; a singleton loop and a parallel digon are included. Retaining a pure-cycle root ensures it is represented as a closed path. The internal vertices of distinct paths are disjoint.

For each such path P with endpoints u,v let D_P be the XOR of its edge targets. For assigned retained potentials, P is good if x_u XOR x_v=D_P. Otherwise P is bad. A closed path's truth is a known constant. Good paths can realize all requests; a bad path can realize all except any single designated edge. Both facts follow by integrating the adjusted differences from one endpoint to the other. Conversely every bad path must contain an odd number of failed comparisons.

Make a resource multigraph J with one vertex per path and one edge per paired shell, joining the owner paths of its two comparisons. Keep parallel edges, and make a loop when both comparisons belong to the same path. Record the original comparison index at each incidence. An unpaired free comparison is a private resource at its owner. For every connected component of J that is a tree and has no private resource, emit exactly the clause
[
          \bigvee_{P\text{ in the component}} (x_{u(P)}\oplus x_{v(P)}=D_P).
]
All other components emit no clause. A loop counts as a cycle, as do two parallel edges. A constant true literal discharges its tree, and false constants can be deleted. An empty disjunction rejects.

For necessity, any extending assignment gives a distinct shell or private resource to each bad path: pick one of its failed comparisons; a shell cannot have two failures. A resource-free tree of k path vertices has only k−1 shell edges, so at least one vertex must be good. For sufficiency, in each such tree root at any good vertex and give every other vertex its parent edge. In a component with a private resource root at its owner, assign that resource to the root and parent edges to the others. In a cyclic component assign one distinct cyclic edge per cycle vertex and attach all other vertices by edges of a spanning forest rooted on this selected cycle. This works also on a loop or digon. Discard resources assigned to good vertices. For each bad vertex fail its single assigned comparison; if a loop has two owned incidences pick either one. All other comparisons meet their requests. Integration on each path then agrees at all retained endpoints and preserves all shell constraints. Restore signed copy offsets for the original physical bits and replay the original pairs. This is exact existential projection; it does not preserve multiplicities of eliminated bits.

With adjacency lists and edge IDs, compute degrees and components, trace every original edge once, and build J in linear time. Its component searches, spanning forests, selection of one cycle per cyclic component (one nontree edge and its tree path), clause emission, and conditional witness lifting each take total O(V+E) word operations and storage. The total emitted literal count is bounded by the number of paths. If starting with raw signed-copy pins, add their input size for propagation and offset reconstruction. Solving the emitted conjunction is separate from these linear bounds.

In a tree component without private resources having k paths, the sum of physical path lengths is 2(k−1). Each length is positive. Consequently each such tree has at least two paths of length one. With s singleton paths there are at most floor(s/2) emitted clauses. In particular when every path has length at least two, all retained assignments extend even if the original comparison graph has large unbalanced biconnected blocks. More generally each clause forbids a single affine flat of the retained potentials. If the offending equations are inconsistent, the clause is vacuous; otherwise Gaussian elimination gives its codimension r. When the sum of 2^(−r) over nonvacuous clauses is below one, conditional expectation, using the same exact Gaussian probabilities under pins, finds a feasible retained assignment in polynomial time. Alternatively inclusion–exclusion over the forbidden flats and repeated Gaussian dimension counts decide feasibility in O*(2^floor(s/2)) time with witness recovery by conditional counting. These counts concern retained assignments, not raw shell multiplicities.
