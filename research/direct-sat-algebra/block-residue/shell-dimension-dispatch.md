# Dimension and codimension of indexed two-comparison shells

For m shells, use all 2m signed comparison occurrences after consistent signed copy contraction. Include loops, parallel edges and repetitions. Let v be the graph order and c the number of components including isolated vertices. Root each component. Assigning its nonroot vertices gives d=v−c independent bits for all realizable edge differences. The binary vertex-to-edge difference map has kernel exactly the component constants. Its image has codimension r=2m−d, the number of independent cycle equations.

For the affine branch, impose the root gauges and express each of the two differences as a linear form on the d bits. The simultaneous failure of the pair specifies one forbidden affine flat by at most two equations. Inconsistent flat equations forbid no points. The unchanged archive solver in scratch/compression/affine_cover_solver.py with kernels=False and separator=False supplies a witness in deterministic time (3/2)^d times 2^{O(d log log(d+3)/log(d+2))} times an input polynomial, using polynomial space. Its degree-two covering argument and block-size analysis appear in scratch/compression/affine-cover-decision.md. The fixed-rank greedy small-block covers and depth-first enumeration are the only exponential search used on this branch.

For the Fourier branch, use all original failure flags and the r cycle equations. The two single-flag shores of every shell have joint empty choice counted once. The original Fourier solver streams the characters and conditionally counts to reconstruct a legal flag vector in 2^r times an input polynomial, using polynomial space. Integrating the resulting signed differences recovers vertex bits. Both branches restore earlier signed offsets for physical four-bit shells.

Set a=log₂(3/2). The exact integer comparison 3^d ≤ 2^{d+r} chooses the affine branch, otherwise Fourier. Up to the affine subexponential overhead the binary exponent is min(ad,2m−d), maximized at d=2m/(1+a). Thus the deterministic time is an input polynomial times 2^{(2a/(1+a))m+o(m)}, where 2a/(1+a) is approximately 0.738140493. Polynomial space holds on either branch. The guarantee concerns decision with an original witness. Exact original counts remain available from Fourier alone. Existing syndrome DP may use exponential workspace, while the biclique orientation and universal-direction routes exploit different instance structure. This dispatcher does not invoke those routes.
