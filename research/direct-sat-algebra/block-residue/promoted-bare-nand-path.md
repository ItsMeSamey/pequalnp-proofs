# Four-state binary constraints in a single positive-output NAND circuit

Give each site i two independent raw bits. Compute its four state indicators I(i,s), s=0,1,2,3, as the AND of the two appropriately signed raw literals. Realize every AND and NOT with ordinary NAND gates and tied-input NANDs. A forbidden pair of values at distinct sites i,j contributes the leaf NAND(I(i,s),I(j,t)). A forbidden list value contributes the leaf NOT(I(i,s)). Conjoin all leaves by a left fold of ordinary NAND/NOT ANDs and designate the one positive output. Pair restrictions solely on one site can be reduced to list restrictions, and repeated identical forbidden pairs or list exclusions can be deduplicated. Actual raw assignments realize exactly one indicator per site, so acceptance is equivalent to the given four-state binary CSP. Conversely a CSP solution supplies all original raw bits.

For general binary CSPs a state might not appear in any constraint. To force every indicator to be a visible port, add a fresh raw guard g, a test NAND(I(i,s),g) for every state of every site, and the final unary leaf NOT(g). Order all binary verifier leaves, including guards, first in the fold; append list leaves and NOT(g) last. For at least one site this gives at least four distinct verifier leaves. The root forces g=0, so the padding contributes no pair or list restriction and no witness multiplicity. These guard leaves connect the original NAND graph even for a disconnected input CSP. The empty-site instance can be decided directly. The number of gates is linear in the number of sites and explicit exclusions. The encoding claim does not require polynomial-time solution on general graphs.

After signed alias normalization the four indicator-producing NANDs at a site have the same two raw bases as entrances and compute four distinct signed minterms up to complementation. Their maximal cone contains exactly those four gates: every verifier depending on this site also needs a foreign indicator or g, and no partial conjunction of the test leaves can be generated from local raws. Its two raw inputs are private. All four output rails are used externally, so its table in logical coordinates is exactly the four one-hot words. Signed port changes preserve majority closure and binary satisfiability. Each verifier has a unique unordered operand pair of exported indicators (or of an indicator and g), and supplies one distinct leaf. Starting from those operands reaches only this verifier: the initial fold needs two different verifier outputs, and subsequent fold steps require a prior partial conjunction. Each retained conjunction gate is likewise alone in its cone. Its inputs are distinct, and no new verifier can be produced from a partial conjunction and the next leaf. In particular unary leaves appended after the verifiers do not cause two local indicators to be joined within their site.

In the common binary hull of a logical AND z=x AND y the implications z→x and z→y hold. The positive root therefore forces both children recursively, making every verifier output true, every disallowed list indicator false, and the optional g false. A verifier with its output fixed true is exactly the relation forbidding simultaneous ones on its two operands. Any further row deletions still give a relation on two bits, hence a majority-closed table; each conjunction has just its all-one logical row. Promotion consequently installs the verifier incompatibilities and retires all verifier and conjunction tables. No additional valid site row is inadvertently deleted: choose any locally allowed one-hot value at one site and use all-zero indicators at every other site. The empty indicator vector is a ghost satisfying each site's at-most-one binary hull. With the guard zero and every verification and conjunction output true, this extends to the shared binary base, even with the exact verifier tables already imposed. The same construction works for two selected site rows precisely when their pair is allowed and both list checks hold. For arbitrary lists, sites with at most two surviving rows can themselves promote, permitting additional propagation; the assertion of an arbitrary CSP *encoding* is independent of that behavior.

All four exposed rails matter. When a fourth state is merely unobserved, projecting four one-hot words onto three rails retains 000 as a genuine fourth possibility. That projection is majority-closed. In contrast, exposing the fourth rail and forcing it false by a leaf removes its row; the surviving three one-hot words have absent all-zero majority. The ghost belongs to their binary hull only.

## Growing connected YES and NO paths

Take n≥3 sites in a path. Define c(s)=[s=3]. On edge i require c(sᵢ) XOR c(sᵢ₊₁)=δᵢ and create exactly the forbidden-pair NAND tests for that rule. Ban state 3 at each endpoint with its own unary leaf. Use all binary test leaves first, followed by the two unary leaves. Every state at every site participates in a forbidden pair since both classes are nonempty. The unpadded circuit therefore already has all four rails visible, two raw bits per site, only the one positive output, and connected physical wiring. Different tests have distinct unordered input pairs. There are F tests, six per δ=0 edge and ten per δ=1 edge, and F+1 ANDs in the fold.

Initially the n one-hot tables, F verifier NAND graphs and F+1 fold AND graphs are all non-majority-closed. For each three-coordinate gate both inputs are exported or computed, and its output is observed or consumed. Promotion retires all 2F+1 verifier/fold tables. Its fixed point has n bad site tables: each endpoint retains three actual one-hot rows and each interior site retains four. Any surviving single row extends against the base by ghosts. For any two sites, ghost completion works iff their pair is locally allowed; every edge remains a proper, nonempty compatibility relation since n≥3 and at least one endpoint of each edge has both classes available. Nonadjacent site pairs have full compatibility. Thus the implementation's row interaction graph is exactly the path, including on NO instances, before the forest dynamic program.

Choose all δ=0 for YES: there are 3^n raw words, e.g. every site in state zero. Flip exactly one δ for NO: propagating classes between the two endpoints forces opposite endpoint bits although both are pinned to zero by their lists. Promotion alone does not detect this contradiction, whereas the forest algorithm resolves it without cyclic tuple trials. Forest solving and normalization, repeated SAT checks during promotion, pair construction, and final physical witness replay all have polynomial bit cost and polynomial workspace. The path also admits an elementary class-parity scan or ordinary bounded-domain path dynamic programming. These examples demonstrate the promoted solver's behavior on original single-output wiring; they do not yield a general SAT bound.
