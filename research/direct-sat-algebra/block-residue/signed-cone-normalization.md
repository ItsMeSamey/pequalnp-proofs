# Signed canonical wires and the two-entry block optimum

Assign each original primary its own canonical base. Working in topological order, assign each wire a base and flip, with a distinguished zero base for constants. A zero NAND operand yields one, and a one operand complements its partner. Two reads of the same signed base yield its complement; opposite reads of the same base yield one. Otherwise retain the NAND with two distinct bases and its actual read signs. Separately produced gates are not merged merely because their functions coincide. Induction proves that each alias equals its original wire on every primary assignment.

Substitute aliases and constant literals in the exterior 2CNF, pins, equalities and optional asserted original output. Discard true rows, remove false literals, collapse duplicate literals and discard complementary-literal tautologies. Preserve empty clauses. The normalized observable bases are exactly those occurring in the remaining rows.

After forgetting read signs, the retained topology has distinct physical operand IDs at every gate. Its maximal two-entry cones are laminar by the tied-free theorem. Its partition cost proof uses exact block tables: if all original pieces of a cone were majority-closed, their join and existential projection remain majority-closed. A merged block otherwise costs at most one. Signed evaluations do not change this argument; all pieces use the same canonical bit on a shared port. Thus the maximal cone partition achieves the global minimum number of bad blocks for the specified **normalized signed representation** among partitions with at most two entering base IDs per block. Other rewrites and original tied-wire partitions have different optimization domains.

The [implementation](signed_cone_nand.py) constructs the signed partition before materializing reads. For each complemented input of each retained gate, a private tied NAND is placed inside the selected block. This temporary wire has exactly one local user and no exterior observation. Physical entries and exposed ports are the canonical IDs with the same values, so the existing four-trace projection computes the signed table exactly. Original primary inputs stay in their original order. After solving, the adapter checks every original gate output against its alias and checks all original exterior rows, including the asserted output. Conversely any original model satisfies all translated rows by the wire induction. This also covers an empty retained gate set and contradictory constant rows.

The normalized and temporarily materialized netlists have linear size. Partition construction and scoring cost polynomial time; the exact witness solver branches over at most two alternatives for each bad table. This is a representation-specific optimum, with no uniform bound on the number of bad tables.
