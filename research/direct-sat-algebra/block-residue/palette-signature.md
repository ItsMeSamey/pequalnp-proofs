# Streaming a weighted complete-bipartite coloring signature

Use the named two-track colors 0,1,2,3 of the proper-coloring source. Let a supplied K_{d,d} block have an ordered set T of t distinct physical terminals. Include every vertex incident to the exterior in T. At each vertex v let A_v be the physically allowed unary list and w_v(c) an arbitrary signed integer weight, reduced modulo 2^b, b≥1. Lists and weights are separate inputs. Arbitrary weight zero or cancellation need not mean a physical prohibition. The signature at a terminal coloring τ sums the products of unary weights of all physically proper block colorings extending τ.

For each τ stream both sides separately. On side S, initialize F[empty]=1 and the other 15 entries to zero. At vertex v take each old palette P and color c in A_v (also requiring c=τ(v) at a terminal) and add F[P] w_v(c) to the new entry at P union {c}. Use a fresh table for each update. The invariant is the exact set of colors used by the processed vertices, so coloring multiplicity is counted once even when a new occurrence repeats a color. Write F_L and F_R for the two results. The signature entry is the sum of F_L[P] F_R[Q] over disjoint P,Q. This is exactly the complete-bipartite edge predicate; each of the 4 colors has three possibilities across the two palettes, yielding 81 disjoint pairs. Integer signed addition and multiplication remain valid at every b.

There are 4^t assignments, taking O(4^t (128d+81)) ring operations up to constant factors. Enumerate and emit entries one at a time using constant-size working ring tables plus the physical input and terminal assignment. If the user needs the entire output table in memory, charge its 4^t entries. Products of block entries and exterior weights sum correctly over shared terminal colors if every original unary factor is owned exactly once. Unowned copies use weight one. Binary bridge predicates are separate exterior factors. Intermediate boundary size or arbitrary exterior solving is an additional cost. For the source variant requiring all z_e equal, branch on the one common z, paying the all-equal endpoint branch separately; all-equal components have just four candidate colors. Include the affine suffix's actual count or reconstruct its unique bits as prescribed.

For an original SAT witness carry a separate Boolean table with OR/AND instead of sum/product and with transitions based on physical lists. Choose a feasible disjoint final palette pair. Save a predecessor per reachable palette per side and step, or reconstruct by rerunning feasibility with actual vertex pins. A nonzero signed residue also allows reconstruction by repeatedly pinning a color whose conditional residue is nonzero, since the four disjoint children sum to the parent. A zero residue proves no such claim: for example an unpinned single edge with unit weights has twelve proper colorings and count zero modulo four. When lifting through a core, first choose a compatible tuple using these Boolean signatures, and then expand each block under its actual shared terminal colors. Assign X_v,Y_v from each chosen physical color, assign the source's actual suffix (including t), and evaluate all original gate outputs and pins. For a canonical raw orbit instead, use the color-to-word conjugations and replay the raw permutations. Counts here are for named color assignments; a global translation can preserve a raw orbit point, and fixing an anchor changes a weighted named count unless the quotient semantics justify it.

Native vertex_union.py already decides arbitrary zero-difference pin patterns in a given vertex order and replays a raw word. For ordinary K_{d,d} with one side first, its future bans already record the used palette; this block argument asserts no asymptotic decision improvement on that case. The extension here is the exact signed boundary count and the factorized two-side streaming interface. The published vertex_union solver retains one predecessor per reachable key and fixes the first color by translation, so its stored history multiplicities do not provide these signed named counts. The recurrence acts on the original block constraints. It does not enumerate matching flats in the signed expansion.
