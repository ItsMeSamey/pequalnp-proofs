# Recognizing a majority operation on physical row domains

For a finite relational structure, Chen and Larose's Theorem 4.7 gives polynomial-time construction of operations satisfying an idempotent strong linear Maltsev condition when the condition has a uniform polynomial CSP algorithm. Corollary 4.9 gives the decision consequence. Ternary majority satisfies this hypothesis: the three repeated-argument identities define the operation, and uniform (2,3)-consistency solves the majority-preserved CSP. This is the ternary near-unanimity case of strict width two. The construction does not prescribe an order or require conservative choices on triples of three different inputs. [Chen–Larose, Lemma 3.8 and Theorem 4.7](https://arxiv.org/pdf/1604.00932#page=12) · [Feder–Vardi, strict width](https://doi.org/10.1137/S0097539794266766)

Give each site i a disjoint tagged copy of its row domain D_i. On their union include one unary relation for each D_i and one separately named relation for every measured compatibility table R_ij. A global majority operation preserving these relations restricts to a family of operations m_i on the original sites. Conversely, a compatible family extends to the tagged union: on a mixed-sort triple with a repeated element return that element, and on any other mixed-sort triple return the first input. Each coordinate of three tuples from a fixed R_ij is homogeneous in sort, so this extension preserves every named relation. Keeping the relations separately named matters for this argument.

The specialized indicator instance uses one variable for each ordered triple in each D_i, with output domain D_i. Pin repeated-argument triples to the repeated element. For every three ordered pairs in R_ij, put the same relation R_ij between the two corresponding output variables. Its solutions are exactly preserving majority tables. It has at most the sum of |D_i| cubed variables and a sum of |R_ij| cubed preservation constraints. The exponent is fixed, including for heterogeneous row domains. If a majority exists, the indicator constraints and any further singleton pins preserve that majority. Use the uniform consistency solver with successive trial pins to build an operation table, then explicitly verify its identities and all preservation conditions. On a negative instance consistency alone can leave unsupported choices; only a fully verified table certifies existence. If the construction fails, a true majority could not have been present, since all pinned extension queries would then be exact. If arbitrary list constraints are part of a different application, include those unary relations in the template as well.

The physical step identifies the actual row domains and binary tables from the circuit, then lifts a solution to the original wires. Their having a majority polymorphism is a sufficient structural certificate. Failure to find one does not decide feasibility of the physical circuit. This test concerns arbitrary sitewise majority operations; the ordered-row method certifies median operations in its tested orders.
