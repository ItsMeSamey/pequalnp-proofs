# Original NAND decision by exact block interfaces

For inputs 0 through N−1 and gate i writing N+i, the ordinary single-output query is interval_witness(N, gates, pins=[(output,1)]). It returns the minimum number of bad intervals, their boundaries, and a complete input word or None. No grouping certificate is required on this entry point. The separate solve_compiled entry point checks supplied groups and checks the entire generated exterior-constraint suffix and designated output for exact agreement with the supplied NAND circuit. Its branch cap can return skip. Neither entry point counts satisfying assignments.

An admissible group has at most two distinct incoming wires. Evaluate all at most four inputs to obtain concrete wire traces. Expose all observations, each gate-output entry, each exported gate output, and each primary input shared outside the group. Equalities among occurrences are enforced by using original wire identities. If every projected table is closed under majority, its unary/binary coordinate projections characterize it. To see this, any word passing every binary test agrees with a table row on each set of two sites. Inductively for a larger site set take three rows agreeing except possibly at three distinct respective sites. Their majority agrees on the full set. Empty and singleton site sets follow directly since each table is nonempty.

Each failed majority test costs one Boolean choice: partition the at most four words into two nonempty parts of at most two words. Both pass majority closure. Each global branch therefore has an exact 2SAT instance, including the exterior clauses and output pin. The solver keeps a concrete choice of incoming bits per projected word. After assembling the shared ports, it assigns private primary inputs from those choices, then evaluates the whole circuit in original topological order. Induction along individual gates proves agreement with every selected trace, including when the quotient of noncontiguous groups contains cycles. Repeated operands refer to the same original bit.

For contiguous groups, boundary visibility depends on the interval alone. Each singleton is admissible. A shortest path over all interval ends therefore minimizes the number b of failed tables among all partitions of the supplied order. With g gates and L explicitly listed exterior occurrences, let W=N+g+L+1. There are at most g(g+1)/2 candidates. A direct scan and four traces take O(g) indexed operations per candidate. In the final groups at most 3g total port occurrences are possible. With at most four local words, the emitted hull equates equal column patterns and writes pair constraints on at most 16 representatives. Thus each complete 2SAT branch uses O(W) indexed operations and each exposed result needs N output bits. Allocator, sorting, hashing and variable-address costs need separate charging. A conservative deterministic bit bound is (g^3+2^b W+W) poly(W), polynomial space. This bound charges the numerical primary count, which may exceed the binary header length. A direct input enumeration remains available when N<b.

The closure criterion is classical Boolean constraint theory. The scope here is extraction from actual gate traces, complete original input reconstruction, and optimization among contiguous cuts. A private four-NAND block (including one materialized NOT) can expose exactly the three words 110,101,011. Gluing such blocks solely by equality already represents arbitrary positive exact-one-in-three constraints. Hence the method provides no bound on b that resolves arbitrary SAT.
