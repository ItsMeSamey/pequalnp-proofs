# Computing the entire universal target subspace for incident shell pairs

Let H have as rows the fundamental cycles relative to a spanning forest of an undirected multigraph. There is one row per chord, including each loop. Its restriction to chord columns is the identity. For an orientation O choosing one indexed edge of each disjoint shell pair write U_O=span{h_i : i∈O}. Assume the edges in each pair share an endpoint. One can compute a basis of U=⋂_O U_O deterministically in polynomial bit time.

For a coefficient vector λ the edge vector λᵀH is Eulerian and its chord restriction equals λ. The annihilator U_O^⊥ consists of the λ for Eulerian supports avoiding O. Every such support decomposes into simple cycles avoiding O. Conversely a simple cycle taking at most one member per pair can be avoided by some O. Thus U^⊥ is exactly the span of the chord restrictions of these compatible simple cycles. This uses (⋂_O U_O)^⊥=Σ_O U_O^⊥ in the finite-dimensional binary space. It suffices to span the compatible cycles, rather than enumerate them. If a different full cycle-row basis H' is supplied, H'=AH for the invertible matrix A read from its chord columns; the desired target subspace is AU.

Each loop by itself is compatible, even when its mate is another loop. Its independent loop coordinate belongs to U^⊥. Delete all loops and release their surviving mates from the pair constraints. Every compatible loop-free simple cycle in the residual graph is compatible in the original, and no nonloop simple cycle contains any loop. Hence the cycle span is the direct sum of the loop coordinate space and the lifted residual span. This decomposes the span, without asserting that arbitrary combinations are themselves feasible cycles.

For the remaining graph, assign each still-paired pair to one common endpoint, grouping those two incidences as a local color there only. Other incidences have separate colors. At each vertex introduce two adjacent centers. Each local color gets a port and a mate, joined to one another; join the mate to both centers. For each original edge use a fresh length-three path between its two ports, with two private interior vertices. In a perfect matching either both outer edges of this path are selected or only its middle edge is selected. Read one fixed *outer* edge as the original selection bit; this readout is linear on the full matching vector. Distinct paths eliminate even hypothetical duplicate external edges while preserving indexed parallel-edge selections. The gadget is simple.

Unoccupied ports must match their own mates. Occupied ports expose their mates to the centers, which can absorb exactly zero or two. Therefore the projected perfect matchings are vertex-disjoint unions of compatible simple cycles. Every compatible single cycle lifts, leaving all unused vertices internally matched. These two inclusions give equality of the span of the projected matching vectors with the desired residual cycle span. They do not require a disjoint union presentation for every vector of that span.

Apply the deterministic perfect-matching linear-hull algorithm over GF(2) to this single gadget graph. Its output can be an arbitrary linear basis; its basis rows need not themselves be matchings. Project each row by selecting the designated outer-edge coordinate for every residual chord. Append unit vectors for the deleted loops, row-reduce, then compute the right nullspace. The resulting basis spans U and answers every subsequent target query by ordinary elimination. The matching-hull algorithm is Lovász's result as stated in Section 4, Theorem 20 of [El Maalouly, Steiner and Wulf, ISAAC 2023, p. 28:15](https://drops.dagstuhl.de/storage/00lipics/lipics-vol283-isaac2023/LIPIcs.ISAAC.2023.28/LIPIcs.ISAAC.2023.28.pdf).

If an explicit separating orientation is needed for t outside U, a nonzero loop component of t gives an immediate singleton cycle. Otherwise color the outer edges corresponding to nonzero chord coordinates of t. A nonzero functional on the projected matching span implies some actual perfect matching has odd color parity. It can be recovered by deleting edges greedily while the matching hull still has an odd vector; this property only decreases on deletion, and any edges surviving in a minimal such graph form the desired matching. Its external cycles have odd total parity, so one constituent cycle pairs oddly with t. Choosing one off-cycle member per pair yields the separating orientation. With a different input basis, first transform t by A inverse.

For N=|V|+|E| on the indexed graph, the simple matching gadget has O(N) edges and vertices. Let P_PM denote the deterministic binary matching-hull bit-time polynomial on an adjacency-list encoding. Basis construction uses one call on O(N log(N+2)) input bits plus O(N³ log(N+2)) elementary bit work for forest bookkeeping, dense binary elimination, and optional basis conversion. The theorem used here supplies polynomial time; no explicit exponent for P_PM is needed. Witness self-reduction uses O(N) such calls if requested. Raw copy-pin contraction and checks are additional polynomial work in the original explicit input size.

The result concerns targets lying in every oriented span. A signed NAE-3SAT clause on distinct literal variables is encoded by two comparisons incident at its center: request the center literal to differ from either of the other literals. Meeting every such shell is equivalent to membership of the signed instance syndrome in some oriented span. This existential query remains NP-complete on incident pairs; computing U decides the universal query.
