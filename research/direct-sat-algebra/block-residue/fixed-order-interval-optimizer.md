# Minimum number of nonbijunctive intervals in a fixed NAND order

Fix the supplied topological order of binary NAND gates. An interval [i,j) is admissible if its gates read at most two distinct physical wire IDs produced outside [i,j). This charge includes every raw input read, even one later hidden. A singleton is always admissible. The exterior can reference physical signals through Boolean pins, signed equalities or clauses of width at most two. A requested output value is a pin.

Evaluate the interval on every assignment to its outside reads, at most four. Retain every produced gate output used outside the interval or observed by the exterior. Retain every incoming gate wire and every incoming raw wire used outside or observed by the exterior. An incoming gate wire is an interface to its producer even if no other gate reads it. Hide an incoming raw wire only when no exterior observation or outside gate read needs it. Unused observed raw inputs are available directly to the exterior. Project onto the retained wire IDs and deduplicate. Save one preimage per projected word or reconstruct it from the four evaluations.

Give the interval cost zero if its projected relation is closed under coordinatewise majority, and one otherwise. Test the majority of each triple of distinct projected words for membership; repeated words cannot violate closure. Costs depend only on the two endpoints and global uses and observations, including any earlier gate use of a raw bit. For each admissible interval insert an arc i→j with its cost in the DAG of gate positions. A shortest path gives the minimum number b of bad blocks over precisely these fixed-order partitions. Store predecessors to recover a minimizing partition. For a fixed start, the set of outside reads only grows as the end advances: later gates cannot produce an earlier operand. One can stop extending an interval after its third distinct outside read. An arc that cannot strictly improve the destination even at cost zero can be skipped. The empty gate list has minimum cost zero.

For a good block forbid each absent unary or binary assignment by a clause. This gives the whole table. Indeed, if a candidate is compatible with all unary and binary projections, every pair of coordinates can be matched by some row. Inductively, for k≥3 chosen coordinates take witnesses matching the k−1 subsets obtained by omitting each of three distinct coordinates in turn. Their majority belongs to the table and matches all k. Empty interfaces follow from nonemptiness of every unconditioned block table. For a bad block split its at most four distinct rows into at most two sets of at most two rows. Each set is majority-closed. Enumerate a choice of one set per bad block and solve the conjunction of the resulting 2CNFs and the exterior constraints. This requires at most 2^b polynomial-time trials. The interval optimizer evaluates at most quadratically many candidate intervals, each using polynomial bit work, including wire indexing and all row comparisons. The resulting deterministic bit bound is 2^b times a polynomial in the explicit circuit, raw output length and exterior size. Trials are enumerated sequentially in polynomial workspace.

Given a satisfying 2CNF assignment, select a row for each interval matching its visible bits. Recover private raw bits from those rows. No other block or exterior clause uses them; visible raw bits agree by physical ID. Give unused unobserved raw inputs any value. Inducting in topological order, entrance values agree with predecessor outputs since both incident blocks retained every crossing gate signal. Recompute the original NAND trace and check all pins, signed equalities and clauses. Conversely every original witness induces projected words and at least one valid trial. The result is decision with a physical raw witness, not a counting bound.

The implementation is interval_optimizer.py. Its minimum_partition returns the cost and half-open intervals. Its interval_witness also returns the raw witness, or None for UNSAT. Projection, majority classification, case splitting and physical replay use corridor_nand.py on the same port convention. The optimization fixes the supplied gate order and visibility rules.
