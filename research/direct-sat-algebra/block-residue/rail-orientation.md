# Orientation obstructions in the two-row rail gadget

In the signed comparison multigraph the two controller spokes have opposite target parities on the same pair rail,x. The output contributes a third spoke rail,z and the passive comparison is y,z. Complementing a name switches the incident signs and preserves whether the controller digon is unbalanced.

In the clean unsigned AND gadget without collapsed or pinned names and without extra exterior comparisons, an orientation passing the balanced-or-simple-cycle block test exists exactly when every gate has a private primary input (one input occurrence in the entire circuit). To see necessity, a controller that is an earlier gate output already has its producer's output spoke. The additional opposite pair forms three parallel edges in one unbalanced nonsimple block. A controller used again as a controller gives four parallel edges. A controller used passively at a different gate has a path from itself through that gate's output to the rail. With its own two spokes this forms a theta with an unbalanced cycle. The DAG and distinct-wire hypotheses keep the path internal vertex separate. Conversely, make a private input of each gate its controller. These controller vertices have no further incidence, so their opposite digons are isolated cycle blocks.
