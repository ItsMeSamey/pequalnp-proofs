# Physical row compatibility and the limits of selector conflicts

Consider an admissible original NAND partition with binary exterior clauses, including pins and signed equalities. For each block its finite table lists the values of all exposed physical ports attainable by varying its at most two actual entering bits. Keep one local preimage for each distinct row. The good tables are closed under coordinatewise majority and their unary/binary hulls represent them exactly. Put those hulls, the full unary/binary hull of each bad table, and all exterior clauses into a common 2-CNF B. If B is unsatisfiable the original instance is unsatisfiable. For a bad block, a side selector chooses one of two groups of at most two rows. Each group is itself bijunctive. A physical row instead pins every exposed port of the block to its specified Boolean value.

## Exact reduction to a binary row problem

For satisfiable B, a finite set of literal pins P extends to a model of B if and only if every subset of P of size at most two extends. To see this, take the actual set of physical variables mentioned in P; contradictory requested values on one variable already give a two-pin obstruction. Eliminate other variables from B by resolving clauses containing opposite literals of each eliminated variable, keeping the resolvents and the clauses independent of that variable. Each resolvent has width at most two, and elimination is exact existential quantification. The resulting 2-CNF on the pinned variables has a clause falsified by any nonextending assignment. Its one or two requested values already fail. An empty resolvent cannot occur since B is satisfiable. This proof concerns existence; queries can be answered directly with ordinary 2-SAT without constructing a projected formula.

Prune each bad block's row domain by testing B together with that row's pins. Reject an empty domain. Between distinct blocks retain a pair of surviving rows precisely when B extends both simultaneously. A full selection of one row per bad block is globally realizable exactly when all selected pairs are retained. In fact, if the joint pins fail, the preceding lemma finds a violating pair of pins in one row or in two rows, contradicting pruning or retained-pair compatibility. The reverse direction follows by restricting a global witness.

Build a graph on the bad blocks, joining a pair only if its compatibility table omits some pair from the product of the two surviving domains. Components are independent for row selection, even when their pins mention a common physical wire or their interactions are mediated by good blocks. For a forest component, root each tree. Retain a parent row if and only if each child has a retained compatible row supporting its subtree. Keep one supporting child row per parent choice; tracing these back recovers a complete selection. On arbitrary components one may enumerate rows separately in each component. With b bad blocks, domains have size at most four. Preprocessing uses O((b+1)^2) 2-SAT tests, with polynomial length for each test. After preprocessing a forest costs O(16(b+1)) table operations; general component enumeration costs a polynomial factor times the sum of 4 to the power of the component size.

Join the selected pins from all components and run 2-SAT on B once to produce one *common* assignment. Each good table is exact and each bad table has its chosen row. Recover any private primary entries from saved preimages. Shared or observed primary coordinates have the SAT model's values; gate-output entries are exposed. Evaluating the original gates in topological order gives the recorded rows and exterior conditions, including for noncontiguous partitions. Replay on the original raw inputs. ## Empty side-conflict graph on an NP-complete family

For every vertex of a simple graph without isolates, give one NAND block two private primary bits. The block computes four Boolean minterms for its four input words; expose only those four output indicators. Original gates can produce the two complemented input literals by tied NANDs, then each minterm by a NAND of the appropriate two literals and a private output inverter. All internal wires and raw inputs remain private. For each graph edge and each color, impose the binary exterior clause forbidding both corresponding endpoint indicators to be one. Every final minterm is externally observed. The actual four rows are the four unit vectors; the majority of any three distinct rows is all-zero, so the block is bad. Its full physical unary/binary hull says precisely that at most one color is used. Partitioning the four rows into two pairs gives two choices with two colors each.

After fixing any two selectors on different blocks, choose distinct permitted colors for these two blocks (two colors are available on both sides). Put all-zero indicators on every unselected block. This satisfies B and the two selected-side relations even for adjacent vertices. The same construction works for one side. Hence the pairwise side-incompatibility graph between distinct selectors has no edges. In contrast, a complete selection of actual rows satisfying the exterior is exactly a proper four-coloring. The clique on five vertices is an explicit negative instance. For NP-hardness add a universal vertex to any nonempty input graph for 3-colorability; its color is unavailable to all original vertices, giving the equivalence and removing isolates. The two bits encoding each selected color form a raw witness.

With signed alias normalization, the four complementary NAND outputs are produced from the same two distinct private bases per vertex. Their observed polarities translate the unit-vector table coordinatewise. Distinct vertices have disjoint source pairs and no connecting gates in the binary-exterior representation. Their maximal computed cones are the individual vertex blocks.

The construction applies directly to a circuit supplied with the stated binary exterior. A canonical compiler may append a verified NAND objective computing the conjunction of those exact clauses and expose one designated output: its semantic SAT verdict and raw witnesses coincide by evaluating the compiler's gates. Applying this particular selector-graph statement to that input requires recognizing the canonical objective and recovering the same exterior and data blocks. Treating an arbitrary single-output NAND DAG as a bare netlist instead changes the gates, their exposed ports, the cone partition and the 2-CNF base. The construction makes no claim that such a bare circuit has an empty selector graph after generic partitioning.
