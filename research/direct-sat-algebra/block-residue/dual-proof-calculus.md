# Degree scope of the dual calculation

The calculation uses the Boolean coordinate ring over GF(2), reduced by lambda_i^2=lambda_i. Opposite-shore products are homogeneous as products of linear forms before reduction; diagonal terms become linear. The code takes the binary linear span of the reduced generators. A vector obtained after canceling all quadratic terms is therefore an ordinary degree-at-most-two polynomial-calculus consequence: form the same linear combination of original products and add square axioms to remove squares. The code does not multiply generators by variables or perform the entire bounded-degree polynomial-calculus closure. One must not infer a degree lower bound for polynomial calculus from a missed direction.

Every valid covector vanishes on all generators, hence on any such derived linear form. This suffices to quotient in the primal problem. For an original complete orientation, its annihilator consists of valid covectors; taking a second annihilator shows its column sum contains each derived direction. After repeated gains or removed orientations, solve the requested syndrome against original columns, integrate signed comparisons, undo copy offsets, and replay. The certificate does not itself supply a witness for an arbitrary target outside the permitted orientation sums.

With arbitrary Boolean multipliers the ideal gives all consequences of the finite zero set: for any function vanishing on it, express it as a sum of characteristic point indicators at other points; at each such point some generator equals one, and multiplying that generator by the point indicator gives the same indicator. This observation can require exponential work. Full common-span membership already has the marked-cycle coNP-completeness obstruction. The explicit strict example for the implemented linear span appears in dual-shore-directions.md.
