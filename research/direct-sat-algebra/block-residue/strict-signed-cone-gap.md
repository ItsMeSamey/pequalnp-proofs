# Exact live single-output gap under signed local normalization

Use the original two-entry block definition: all consumed externally or observed produced outputs are exposed, every entering gate wire is exposed, and an entering primary is exposed if read outside the block or observed. Cost is one if the exposed local relation fails ternary majority closure, otherwise zero. Inputs to a block range independently over assignments to its distinct physical entering wires. Only the designated positive output pin is observed. We minimize the sum over arbitrary, possibly disconnected and noncontiguous, admissible partitions. All names below are globally fresh unless explicitly reused.

For k≥1 take free primaries a,q,p_1,…,p_k. Use two actual gates for One(x): u=NAND(x,x) and z=NAND(x,u). Construct h=One(a), w_0=One(q), and g_i=NAND(h,p_i) for every i. Put x_(2i−1)=p_i and x_(2i)=g_i. In increasing j=1,…,2k append three original gates
[
 v_j=\operatorname{NAND}(w_{j-1},x_j),\quad
 t_j=\operatorname{NAND}(v_j,v_j),\quad
 w_j=\operatorname{NAND}(v_j,t_j).
]
The YES netlist designates w_(2k); the NO netlist appends and designates NAND(w_(2k),w_(2k)). Require that single designated bit to be one in each case. The netlists have respectively 7k+4 and 7k+5 gates on k+2 inputs. Both One circuits feed designated-output ancestors. Each g_i enters module 2i; both gates producing its shared h feed this path. Each module's first gate feeds both later gates, its final gate feeds the next module (or the designated output), and every p_i enters an odd module directly as well. Thus even the NO member has no dead original gates, secondary observations, or tautological exterior clauses.

**Original lower bound.** Suppose an admissible block contains g_i and omits the gate producing h. It necessarily has both h and p_i as distinct entering wires, exhausting its budget. No such block can include v_(2i−1) or v_(2i). Indeed, the other operand of either proposed gate is its physically separate accumulator wire w_(j−1). There is an original path from q to that operand through w_0 and, for each preceding stage, through its v and w gates; it uses neither h nor p_i. Appending the edge into v_j gives a raw path into the block from primary q avoiding both allowed entries h and p_i. The first entry along this path would be a distinct third entering wire, whether the block starts at w_(j−1) or contains some earlier subpath. It follows that p_i is externally read by the odd module and g_i by the even module. Together with the gate-produced entry h this exposes h,p_i,g_i, and on these three ports the projected table is exactly the independent-input NAND graph. In port order (h,p_i,g_i), the valid rows 011,101,110 have majority 111, which is invalid. A majority-closed full table cannot project to that graph. Each such block therefore costs one. Two different g_i cannot share a block omitting the h producer, because they require h,p_i,p_j. Even the block containing the producer can contain at most one g_i, since directly consumed primary a and distinct p_i,p_j would be three entries. This proves at least k−1 bad blocks for every partition, regardless of gate order or interleaving.

**Matching upper bound.** Group One(a) and g_1, group One(q) separately, leave g_2,…,g_k single, and make each entire accumulator module a separate group. Attach the NO inverter to the last module. The first group has only entries a,p_1. Its only possible exposed coordinates are p_1, g_1=NOT p_1, and h=1 (h is exported when k>1); a is private, and including it would only add an independent input. This table is majority-closed. The One(q) table exposes only its constant output. For each module the two entering wires are free w_(j−1),x_j. Its only possible exposed coordinates besides some or all entries are the constant output 1, or the constant designated inverter output 0 at the NO endpoint. Intermediate v_j,t_j are read only internally, and the final inverter has no outside consumer. Each such table is majority-closed. This leaves exactly k−1 bad singleton NAND graphs. In particular the exact original optimum is k−1 on both verdicts.

**Normalized optimum.** The only simplifications required are same-literal NAND to negation, complementary-literal NAND to one, and NAND with one to negation. Both One outputs fold to one. Every g_i folds to NOT p_i. Inductively v_j folds to NOT x_j, t_j to x_j, and w_j to one. The optional inverter folds to zero. There is no surviving nonlinear gate and the normalized optimum is zero for both members. With the positive output pin the YES source accepts every original input while the NO source accepts none. No equivalence testing, common-subexpression elimination or cross-gate semantic shortcut is needed.
