# Exact side-model count on the promoted NO path

Use the positive-output NAND path and left-fold suffix of promoted-bare-nand-path.md with n≥3, only δ₁=1, and all later δᵢ=0. Both endpoint lists exclude state 3. Let B denote the actual shared 2CNF after promotion. This fixes all forbidden-pair verifiers and conjunction outputs to true, forces the endpoint bans, and enforces the negative clauses between site indicators. The residual tables have three rows at each endpoint and four at each interior site. The complete path CSP is UNSAT.

Compare two methods on precisely this residual instance and the same B. For binary selector learning split each residual table in its preserved projection order into its first two rows and its remaining one or two rows. Add unary and binary nogoods for each infeasible test of B with the respective one or two chosen side tables. These tables of size at most two equal their binary hulls. Signed complemented physical ports simply relabel the coordinates. The conclusion holds for any ordering within the endpoint and interior tables.

Call the three states 0,1,2 the large class, and state 3 the singleton class. Each side at each site contains a large-class state. At interior site 2 exactly one side also contains state 3, since both sides have two distinct rows. Both sides are individually possible relative to B, even the pure-large side of site 2: choose a concrete allowed state on that side, and give every other site the ghost with all logical indicators zero. Every binary test and every positive fold signal can then take its required value. This logical ghost is the valid relaxation pattern on the actual signed physical ports, not a fifth raw state.

Every side pair on a nonedge passes by choosing any one row on each side and using ghosts elsewhere. Every side pair on a normal edge passes by choosing one large-class state at each site. On the defect edge 1–2 both endpoint-1 sides contain only large-class rows. Site 2 must supply state 3, which works for exactly its mixed side. Ghosts at all unselected sites again realize the complete common base. For its pure-large side no such pair is possible: both side tables are exact, and the verifier for every large-large state pair on the defect edge forbids it.

Thus the only rejected binary tests pair either endpoint-1 side with the pure-large side of site 2. Together those two nogoods force site 2 mixed and constrain none of the other n−1 selector bits. Exactly 2^(n−1) complete selector words survive. No surviving full word extends to a raw model; such a model would choose one row per site and contradict the endpoint class parity. A method enumerating all models of this learned formula and checking them individually therefore checks 2^(n−1) words on NO, whereas the promoted row forest propagates full states on the path in polynomial time. The mismatch is that site 2 can use its singleton row for the defect and a different, large-class row for the next normal edge in separate pair probes.

This is a comparison after promotion. An unpromoted implementation may introduce additional selector bits for the verifier and conjunction tables, and a learner that adds larger nogoods or propagates full row domains has different guarantees. The construction is also directly decided by a class-parity scan on its original CSP.
