# Joint decisions on exposed original NAND rows

The public promoted_row_csp.solve call takes original topologically indexed NAND gates and a positive designated output. Its preprocessing performs signed alias simplification and partitions the remaining gates into maximal two-input cones. Each cone has at most four attainable rows on its physical interface, with a stored choice of entering bits for each row. All binary projections of all tables and all exterior conditions give the initial 2-CNF base B. Every satisfying original trace satisfies B.

The implementation queries B under the unit pins for each row. It eliminates infeasible rows. Whenever the remaining rows of a table are closed under coordinatewise majority, its binary hull describes the table exactly, so it can be conjoined to B and the table can be retired. Repeating this step preserves all original models. In a pass without any promotion the base remains unchanged and a new pass cannot eliminate another row. There are at most b+1 passes for b initial bad tables. An empty surviving table or incompatible base proves infeasibility.

On the remaining tables, compute the compatibility of every two individual rows by testing B under both sets of unit pins. An infeasible family of pins against a satisfiable 2-CNF contains one incompatible pin or an incompatible pair. This follows by eliminating all unpinned coordinates from B: the projected relation is still bijunctive and determined by its unary and binary projections. Thus the resulting finite-domain binary constraint problem is exact. Discard a pair relation if it is the complete product of its surviving domains. Components become independent for decision, even though their final physical assignment will be computed jointly. A tree component uses bottom-up compatibility tables and top-down row selection. A cyclic component falls back to checking tuples of its current domains. After choosing all rows, one final 2SAT solve supplies a shared physical assignment. Local entering-bit witnesses fill private raw inputs, and the implementation evaluates every original NAND and pin again.

Use W for the number of declared original inputs, gates, explicit exterior occurrences and a constant unit. All table sizes in rows are at most four. The number of local pruning and compatibility 2SAT calls is O((b+1)^2). Each call has polynomial bit cost in W. For cyclic components C let q(C) be the product of their current domain sizes. Total deterministic bit time is bounded by poly(W) times (1+sum_C q(C)); space is polynomial in W. The forest case is polynomial and uses no cyclic tuple enumeration. A true output pin is needed when solving an original single-output circuit. Caps yield skip and do not certify UNSAT.

The ordinary 2SAT oracle, binary decomposability of majority-closed relations, and tree CSP propagation have classical proofs. The result here is a constructive reduction on original wire IDs, semantic promotion of verifier tables, and reconstruction of one common original assignment. The bare path family recovers exactly the input path without a supplied graph, width bound, or chart. It is tractable by standard tree CSP once this representation has been extracted. The two-way selector relaxation has a different proof obligation: complete side choices are binary clauses, not unit pins, so their pair compatibility does not imply global extendibility. The four-color example gives a connected single-output counterfamily.
