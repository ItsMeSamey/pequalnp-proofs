# Maximal one-sided peeling of signed comparison cycles

Each matching shell compares two two-bit colors. A shell is proper when at least one of its two raw-coordinate comparisons differs. First propagate every signed copy pin on physical bits. An inconsistent pin component is unsatisfiable. Otherwise write each raw bit as its class bit XOR its recorded offset. A comparison becomes a multigraph edge e=uv with offset s, with raw difference d(e)=X(u) XOR X(v) XOR s. Each shell pairs two distinct edge occurrences, even when they have the same endpoints.

Take the vertex-biconnected edge blocks of this multigraph, with bridges as singleton blocks, loops as separate singleton blocks, and parallel edges distinguished. Call a block clean if all its comparisons can have difference one. Test this by propagating X(u) XOR X(v)=1 XOR s in that block. A clean block can have arbitrarily many cycles. Call an unclean block eligible if it is a simple cycle, including a loop or two parallel edges. Keep all other blocks outside the candidate set.

A one-sided peel is a union of candidate blocks with an assignment satisfying every shell entirely inside and making the inside comparison of every crossing shell differ. Thus every shell touched by the peel can be discharged regardless of its exterior mate. The assignment need only specify relative class bits inside each selected block. Global compatibility follows from the block forest argument below.

**Theorem.** There is a unique largest one-sided peel among unions of these candidate blocks. It, its relative witness, and a residual instance with equivalent satisfiability can be constructed in time linear in the numbers of raw bits, pins, and shell comparisons.

Include all clean blocks and set their differences to one. Form an auxiliary multigraph with one vertex per eligible cycle. For a shell whose comparisons lie on two eligible cycles, insert an edge, allowing a loop if the cycles coincide. A shell pairing an eligible comparison with a clean comparison furnishes a private resource at that eligible vertex. A shell pairing it with an outside block furnishes no resource. For a residual representation permitting comparisons with already discharged shells, each such unpaired eligible comparison also furnishes a private resource.

Include exactly the auxiliary components that contain a private resource or a graph cycle. In a component with a private resource, choose its vertex as root, assign the resource to that root, and assign each other vertex its parent edge in a spanning tree. In a component with a graph cycle, one can instead assign the cyclically outgoing edge to each cycle vertex and grow a forest from those vertices, assigning each remaining vertex its parent edge. The rule covers a one-edge loop or a two-edge cycle. Each eligible vertex receives a distinct resource. Set the corresponding comparison on its cycle to zero and all other differences to one. For an auxiliary loop either occurrence may be chosen. Each eligible block was unbalanced at all ones and has just one independent cycle equation. Flipping exactly one difference makes that equation consistent, so the block lifts by propagation. No shell receives two zeros, and each selected zero has a discharged or selected mate.

For maximality, any peel of an eligible cycle must set at least one comparison to zero since all ones is inconsistent. Choose one such comparison per selected eligible cycle. Its shell must be internal or already discharged, and the chosen shell resources must be distinct. In a component without a private resource or graph cycle, any nonempty set of k selected vertices induces a forest with at most k−1 edges. Crossing edges cannot supply a zero on the selected side. Thus even a proper subset of such a component cannot appear in a one-sided peel. All remaining candidates occur in the construction, proving maximality. The maximality statement fixes the candidate set and the one-sided crossing requirement.

**Residual and reconstruction.** Keep any shell with neither comparison in the peel and discard each shell that the peel touches. Retain the identifiers and block incidences of all original comparisons, including a surviving block's comparison whose mate discharged its shell. Such a comparison imposes no residual clause. A full witness restricts to a residual witness. Conversely, obtain relative labels on every unpeeled block from a residual witness and on every peeled block by the propagation above. For each original connected component, root its block–vertex incidence tree. One may include all vertices as incidence nodes, with nonarticulation vertices as leaves except when they belong to several singleton loop blocks. Assign the root vertex a bit and process each child block away from the root. Flip all labels of that block, if necessary, to agree at its parent vertex, then pass its other labels to descendant blocks. A loop has no other vertex to process. Isolated classes are free. Blockwise flips preserve every comparison difference and therefore all shells, including shells coupling distinct retained blocks. The forest allows independent adjustments on the two sides of a peeled interior block with several articulations. Finally restore each physical bit from its assembled class label and recorded pin offset.

Use adjacency lists throughout. Signed component propagation, multigraph biconnected decomposition using edge identities, block consistency tests, spanning trees, construction of the labels, and the final forest traversal all take linear total time and space. The reduction preserves existence and supports raw witness recovery. The chosen local peel witnesses need not preserve original witness counts.
