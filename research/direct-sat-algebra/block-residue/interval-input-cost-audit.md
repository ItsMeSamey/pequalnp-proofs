# Physical input size, contiguous objective, and witness length

Let N be the declared number of primary bits, g the number of explicitly listed two-input gates, L the number of exterior clauses, pins, equalities and literal occurrences, and p_i the number of visible physical wires in selected block i. Declared input N can be exponentially larger than the binary encoding of N. The current optimizer allocates first/last reader arrays of length N+g, the backend allocates implication-graph arrays of that order, and a successful call returns an explicit tuple of N primary bits. Even for no gates and no exterior conditions, N=2^h gives a header of O(h) bits and this SAT witness has 2^h entries. Use a complexity parameter containing N or an explicit list of inputs. This code does not implement sparse defaults or a compact witness. Compressing active IDs would improve decision preprocessing on sparse descriptions, but expanding a requested complete witness still costs at least N bit writes.

For a fixed contiguous partition that covers all gates, the ports determined by minimum_partition agree with the backend. A gate-output entry into a later block is retained. A primary entry is retained exactly when observed by the exterior or read outside the block. An internal output is retained exactly when observed or read later outside the block. Internal outputs cannot have earlier readers because the gate list is topological. Entries grow monotonically as the right endpoint increases. The search may stop as soon as a third distinct incoming wire occurs. Each singleton interval is admissible, including tied-input NAND. The DP charges one exactly when the physical port relation fails coordinatewise-majority closure, and zero otherwise. Its shortest path minimizes that sum among full contiguous admissible partitions. A previously attained cost at most cost[start] cannot improve by considering another outgoing interval from that start to that stop. The optimum need not minimize the number of groups, the number of distinct shared branch bits, or runtime on arbitrary noncontiguous groupings.

Every admissible block has at most four distinct traces. Computing each candidate's ports and tracing the gates takes O(g) indexed operations, for O(g³) across all O(g²) intervals. With first/last allocation include O(N+g+L) time and linear peak preprocessing storage. For selected disjoint intervals, total visible port occurrences is at most 3g. A two-CNF hull may enumerate O(p_i²) wire pairs. For b bad intervals, the backend visits at most 2^b orientation choices, each with an implication graph of size O(N+g+L+Σ p_i²). The resulting search is polynomial space with those arrays and quadratic hull tables. These are index-model estimates: account for the bit lengths of wire IDs, addresses and explicit exterior data, and Python container overhead when pricing an actual run. For manually supplied groups also charge their supplied sizes, including empty groups.

An observed wire participates in an interface; observation alone asserts no Boolean value. To ask whether designated output o can be one, include an explicit pin (o,1) or the positive unit clause (o+1,). No output pin is added automatically. With no exterior constraints every well-formed NAND netlist has an assignment. The manual backend's max_bad cap returns skip when exceeded, as it also does for an unsupported grouping. The automatic solver passes its computed optimum as that cap; its public entry has no cutoff on search. Neither the optimum nor a skipped manual call certifies a rejecting original output.
