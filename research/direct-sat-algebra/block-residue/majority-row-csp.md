# Complete multisorted majority charts on physical row domains

For each site i seek M_i:D_i³→D_i with majority outputs on repeated arguments. On distinct arguments do not assume symmetry, conservativity or a common order. Put an indicator variable at each ordered all-distinct triple in each sort. For every ordered triple of allowed tuples in relation R_ij, require that the resulting two output variables are themselves an allowed pair. Repeated input arguments give fixed outputs and hence unary fibers, or direct constant checks. Indicator solutions are exactly the desired full operation tables. When a chart exists the indicator is preserved by associating the same M_i with each of its variables of sort i, since R_ij is preserved and fixed partners in unary fibers remain fixed by idempotence. This specializes the classical majority indicator construction. [IJCAI 2013, Section 3.1, Theorem 1](https://ijcai.org/proceedings/2013/77)

Initialize omitted pair relations to full products. Enforce unary arc consistency and path consistency on all pairs to a fixed point. Each elimination preserves solutions, and consists of joins, intersections and projections, so preservation by majorities is maintained. Every pairwise-compatible partial assignment in a nonempty closed majority network extends to any additional variable t. For zero, one or two assigned variables this is nonemptiness, arc or path consistency. For a larger partial assignment, omit in turn three different assigned indices, obtaining by induction three target witnesses b₁,b₂,b₃ each supporting all but its one omitted index. At each i make three allowed pairs using these target values. Use the fixed value at i whenever its witness covers it, and use any arc-consistent partner for the one possible omission. A majority of these pairs recovers the fixed value at i, paired with M_t(b₁,b₂,b₃). This works simultaneously at every i. Consequently the greedy extension after closure never fails under the promise.

On the indicator, failure therefore proves absence of a chart and is a skip, not source UNSAT. Independently validate recovered table identities and preservation on all ordered triples before solving the actual row network. Failure on the certified original network proves UNSAT. Empty original relations/domains are direct UNSAT certificates independently of recognition. Recover selected base 2CNF row units, restore private physical bit traces, and replay every materialized and original NAND wire and exterior constraint.

For s sites of maximum size d≤4, I=Σ_i |D_i|(|D_i|−1)(|D_i|−2)≤24s free indicator entries. Construction scans Σ|R_ij|³≤|E|d⁶ triples. For each Q=I and Q=s the dense source routine stores O(Q²d²+Qd) entries. A sweep takes O(Q³d³+Q²d²) indexed operations, and there are O(1+Q²d²+Qd) sweeps. Add physical preparation, operation validation and witness replay. Sparse input can still generate a dense closure; no bound on interaction degree is required for polynomial time. The default max_pc_vars=96 caps both networks, with an early cap on original residual site count before the pairwise 2SAT queries. None requests uncapped recognition. A cap skip is a resource outcome, independent of chart absence or source satisfiability. Large label storage and bit-address operations incur further polynomial factors. No native execution is asserted.
