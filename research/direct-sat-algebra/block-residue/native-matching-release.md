# Deterministic matching hulls for original signed comparisons

matching_hull.matching_hull returns a binary basis with one bit per indexed matching edge plus a final homogenizing bit. A basis vector can be a sum of matchings. It uses the bundled ordinary blossom implementation and a deterministic tight-cut finder. The proof and conservative bit-cost analysis are in matching-hull-package.md.

incident_port.incident_directions returns a basis for the exact intersection of all committed orientation spans in the original fundamental-chord coordinates. Select method="hull" to force the matching algorithm. Loops are handled separately and duplicate edge IDs retain their coordinates. For nonincident pairs the cost is polynomial times the sum, over graphic blocks, of 2 to the number of internal nonincident pairs. The full proof and matching-literature sources are in incident-pair-full-span.md and blockwise-incident-full-span.md.

incident_total.incident_block_witness(shells,pins) accepts original signed-copy coordinates and returns an original assignment or None. On nonincident inputs its default retains the previous total solver. method="blockwise" requests the exact blockwise guarantee and uses it in the original solver. The quotient choice still has to satisfy the remaining orientation system. A quotient witness determines a single original orientation; its available column span contains every discarded direction, so one original solve and sign integration reconstruct the actual raw word. All original shell pairs and signed pins are replayed. The worst-case orientation search is exponential, even though the complete common span is polynomial-time computable for incident pairs.

Under scheduler 04, the matching backend passed exact augmented binary span comparisons against independently enumerated perfect matchings, including both Petersen variants and disconnected inputs. The integrated run exercised original indexed edges, four blockwise tests and five physical NAND truth tables. The two manifests and receipts pin the executions. These native checks implement no proof-assistant formalization.
