# Mixed activator and output ranks

In an aligned independent control pencil enforce the affine target in the full output span, obtaining data domain D. Let v_i be each activator's linear part on D, and u_i its output column. By Edmonds' matroid intersection theorem the maximum common independent cardinality m equals min over partitions S,T of rank U_S+rank V_T. The executable finds both witnesses and directly checks their ranks.

Enumerate realizable T activator patterns (2^rank V_T) and restrict D. Active T columns span H. Every required residual in H has 2^(|T|-dim H) T-control preimages, including inactive bits. Quotient by H, impose the projected target in the residual output span, and use the exact native character counter at rank <=rank U_S. Restore the T multiplicity and sum over disjoint patterns. Positive branches recover data by exact pinning at the same projected rank and recover all original controls by Gaussian solve. Thus deterministic exact count/search costs 2^m poly(input) time and polynomial space, including partition discovery. This matches or improves both individual rank bounds. Combine with charged CNF compilation or layout/policy clocks by dovetailing; there is no unrestricted worst-case exponent improvement.

Strict family: on independent bits z_1,...,z_h,t use maps e0 z_i and e_i t. Both global ranks equal h+1 and all 2h maps are independent; partitioning the two types gives optimum two (one of each witnesses the lower bound). No nonzero constant output is universally reachable since all maps vanish at zero. Arbitrary affine target in the total output span is allowed.

Conversely exact counting with m=k is #P-hard even in always-feasible pencils. On an n-vertex simple graph use y_u and reference y0. For each edge uv form the triangle (y_u,y_v,y0). For every one of its three comparisons y_a+y_b use n+2 fresh pairs of independent data t and control x satisfying x t=y_a+y_b. U=I and all activators t are independent, so m=k. Fixed original y yields three extensions per copy for each equal comparison, one otherwise. The digits of Z in base 3^(n+2) count original assignments by total equal comparisons; all coefficients <=2^(n+1). A nonmonochrome triangle gives one equality, a monochrome triangle three. Digit |E| equals twice the number of independent sets, selecting vertices equal to the reference. A private unique XOR bit per comparison yields a parsimonious width-three bounded-density encoding. Rank claims apply to the original pencil. The decision instance is always feasible.
