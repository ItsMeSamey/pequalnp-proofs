# Ordinary modular nonzero testing for a one-field native scalar

Input to Exact Cover by 3-Sets is a ground set of 3d elements and k triples, with d≥1. Let P be their binary incidence matrix. Every y with Py=1 selects triples covering each element an odd positive number of times, so its Hamming weight is at least d. Equality occurs precisely for exact covers. If the affine system is inconsistent output a trivial zero instance. Otherwise find y0 and an independent binary generator L of its solution direction, dimension r, by Gaussian elimination.

Choose m≥max(1,r) polynomial in the instance size and K=GF(2^m). A deterministic construction if field arithmetic is needed is a tower of quadratic extensions taking m to the next power of two: each time choose an element of absolute trace one by scanning a binary basis and adjoin a root of X²+X+α. Every binary linear coordinate of L(s), s uniform in K, is Tr(α_j s) by trace duality, padding surplus directions by zero. Add a constant of trace one to the defining affine polynomial wherever y0_j=1. The joint image is exactly the affine solution set of Py=1 with fiber size 2^{m−r}. No nonlinear trace map or high numerical degree is needed.

Use the compatible Boolean tensor layout in trace-histogram.md with one field coordinate, complementary rail bits encoding s, and the k ordinary trace output bits. At the native target W(0)=I the paired-bit prefactor is one, and ordinary unaries [1,λ] supply integer weight λ to a true output. Take λ=2^{m+1}, p₀=(m+1)(d+1), working in the ordinary scalar ring modulo 2^{p₀}. λ fits the canonical input lift since d≥1. The exact target is
   Σ_{s∈K} λ^{wt(y0+L(s))} ≡ λ^d·2^{m−r}·(#exact covers)  modulo 2^{p₀}.
The last unsigned multiplier is at most 2^m<λ. Consequently the residue is nonzero precisely when a cover exists; integer division by λ^d and then 2^{m−r} recovers the exact count. All sizes here, including p₀ and the Boolean tensor's explicit entry-evaluation circuit, are polynomial. The source size bound and its allowed precision and arity bounds can be met by polynomial padding as in trace-histogram.md. The computation at W(0)=I depends only on the given tensor wiring and is independent of a repacking for intermediate nodes.

This is a reduction for nonzero testing of a native weighted modular contraction, already with a single fixed field coordinate, linear trace polynomials, no variety restriction, and no nilpotent variable. A positive INTEGER value can vanish modulo the prescribed power of two. The reduction does not convert a general SAT formula to unweighted SAT with this structure, prove a lower bound for the subexponential counting algorithm, or resolve P versus NP.
