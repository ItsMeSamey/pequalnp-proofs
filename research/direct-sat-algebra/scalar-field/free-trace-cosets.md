# Free trace directions and exact weighted cosets

Use the aligned canonical tensor family of trace-histogram.md, with field variables split into free s∈K^b and restricted t∈V₀. Let the k unpaired row bits be H(s,t)=L(s)+g(t), where the supplied F₂-linear L has image C of rank r. Its binary matrix is computable by evaluating L on a field-coordinate basis. Let P have kernel C and full row rank q=k−r. Calculate it by binary Gaussian elimination. The complement-coded input bits contribute the same baseline factor as in the preceding note.

For each t and each H in its translated code, there are exactly 2^(bm−r) free inputs s yielding H. It suffices to learn the integer histogram n_η of η=P g(t). These bits are traces of sums of the supplied rational functions. The signed Artin–Schreier cover queries on t alone and the prefix histogram reconstruction of trace-histogram.md cost polynomial time in q, the number of realized syndromes, numerical degrees and m at fixed arity. When q is small one can instead use all 2^q characters and the exact integer inverse Walsh transform. No division is needed in the source ring.

Set A_j=a_j+b_j(1−w) and B_j=b_j w from the original canonical column weights. The contribution apart from the baseline is

    2^(bm−r) ∑_η n_η ∑_{h:P h=η} ∏_{j:h_j=0} A_j ∏_{j:h_j=1} B_j.

For a fixed syndrome, start the ring-valued state at syndrome 0 with value 1. At port j add the weight A_j to the stay branch multiplicatively, and multiply the branch toggling column P_j by B_j; sum into destination states. Keep a reached state x only if η−x is spanned by the remaining columns. Exact Gaussian tests suffice. All feasible prefix states form the affine intersection of the prefix span and the translated suffix span; its size is 2^λ_j where λ_j=rank(prefix)+rank(suffix)−rank(P). Thus processing each realized η costs polynomial overhead in the input, k and source ring bit parameters times 2^(max_j λ_j). This is the standard minimal syndrome-trellis state count for a fixed order. In particular q=O(log s_size) suffices for a polynomial bound; large q is also allowed under logarithmic trellis width and polynomially many realized syndromes. If r=k, summing all H simply multiplies the terms A_j+B_j=a_j+b_j. In that case all interpolation dependence from these k ports cancels identically.

## A full scalar with exponentially many realized words

Take s∈K, t∈K* with K=GF(2^m), m≥2, let θ=Tr(1/t), and write the basis bits of s as s₀,…,s_(m−1), with s_m=0. Use k=2m, with successive pairs (s_i,s_i+s_(i+1)+θ). Field-coordinate bits are trace-linear functionals via the dual basis. The m free directions have rank m; the m parity checks each add the two bits of pair i and the first bit of pair i+1 if it exists. Their syndrome is identically the length-m vector of copies of θ. Since reciprocal is a permutation of K*, θ=0 occurs 2^(m−1)−1 times and θ=1 occurs 2^(m−1) times. The corresponding signed point count can also be obtained from the curve t(y²+y)=1. There are exactly 2^(m+1) distinct output words, but just two syndrome classes. In paired order, after reading either bit in pair i, the prefix check columns span a subspace of coordinates 0,…,i, and future columns lie in coordinates i,…,m−1. Thus λ_j≤1 and at most two states are needed for each target.

At the actual interpolation t_source=ζ=1, w=W_xx has valuation a+1. Indeed w=C(2L+1)/(C′(0)(2L+1)), where 2L+1 is odd and the source grid gives valuation a+1 for C(2L+1)/C′(0). Set canonical gate column weights to [2,1], obtaining [3−w,w]. Only the all-zero output word contributes an odd term after removing the common baseline. It occurs for s=0 and θ=0, with odd multiplicity. Thus the complete deformed scalar has valuation exactly 2m(a+2), from its 2m complementary pairs. With polynomial padding large enough this is below p_t. Each individual pattern's unnormalized contribution also survives: after the baseline its valuation is at most 2m(a+1)+m, which still fits. At W(0)=I the scalar is the original weighted integer when P₀ is chosen to exceed its O(m)-bit size. This example uses a supplied legal layout as in trace-histogram.md.

The checker free_trace_cosets.py compares weighted coset sums to direct summation at every residue w modulo 8, 32 and 128 over GF(4), obtains the quotient histogram with the native bivariate carry counter, and tests the two-state bound through 100 free bits. It tests the DP against all residues rather than claiming those residues all arise as source nodes.
