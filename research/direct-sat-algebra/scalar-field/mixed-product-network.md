# One quadratic bit across product-network components of unequal field degrees

Use the quadratic-compatible binary centroid on the full packed target map. Its simultaneous input/output decomposition makes the centered target fiber a Cartesian product in the recovered bases. Restrict the zero-constant map to each input factor and express its values in the corresponding output basis. Independently recognize a field-product network in each factor, allowing different extension degrees. If the centroid prerequisites or recognition fail, the solver returns UNKNOWN. The scalar side condition is separately supplied in the original raw coordinates.

Request one point per factor using a constant-true side condition. If any factor is empty there is no solution. Otherwise assemble baseline b. Check it, then restrict the original side bit to each single moving factor by degree-two interpolation with all other factors at baseline. An exact local witness oracle settles all one-factor variations.

When these tests fail, the side bit is constant on each one-factor slice. Let D_i be the differences between all points in local fiber i and its chosen base point. To obtain a basis of span(D_i) composed of actual differences, begin with an empty list. Compute a basis of its binary annihilator, and test each normal a by asking the local oracle for a point y with a·y≠a·b_i. A returned point strictly enlarges the independent list of differences; if every normal test fails, the list spans every actual difference. Each local dimension d takes O(d²) exact linear-side witness queries. Keep the witnessed directions rather than arbitrary formal span combinations.

For differences on distinct factors, the polarized mixed term of the original bit is bilinear. On any full assignment, the difference from the baseline bit is the sum of one-factor differences and all pairwise mixed terms. The first sum vanishes after the one-factor tests. A nonzero remaining value implies some pair has nonzero bilinear interaction; bilinearity then detects it on two of the stored basis directions. Both directions are independently attainable on their respective factors. Testing their simultaneous substitution into the original bit therefore gives an actual witness. If no pair passes, the desired bit is absent everywhere on the target fiber. Every successful return re-evaluates both the vector map and the bit on the original raw coordinates.

The dense F2/F4 control combines two hidden five-cycles under full binary affine coordinate changes. Separate side predicates require zero, one and two deviations from the deterministic baseline. Two further decisions are checked against the complete 15-bit input space. The algorithm does not require a common field, a supplied component partition or factorization of the side bit across the factors.
