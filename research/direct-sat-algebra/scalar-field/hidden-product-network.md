# Recovering field products on an unknown graph

Input is one explicit binary vector quadratic ANF and its target. Assume an unknown invertible affine domain and output change hides a simple graph whose vertex spaces and edge outputs each have dimension m≥2 over GF(2). Each edge map in some vertex and output field charts is a product of independently Frobenius-twisted arguments. Require for every ordered pair of distinct vertices i,k a neighbor j of k outside {i}∪N(i). Minimum degree two and girth at least five suffice. Neither the graph, field charts, extension degree nor coordinate transformations are supplied.

Compute the input matrices S admitting a binary output matrix T with B(Sx,y)+B(x,Sy)=T B(x,y) for the polar bimap B. This is a binary linear kernel. For x at i and y at the separating j the right side is zero. Its kj output on the left is B_kj(S_ki x,y); the term involving Sy cannot contribute to kj because its other input is at i. Nondegeneracy forces S_ki=0. At an edge remove the two twists and transport the local maps U,V,T to the same field, where U(x)y+xV(y)=T(xy). Substituting 1 in turn shows that U(x)+U(1)x and V(x)+V(1)x both equal T(x)+T(1)x and satisfy Leibniz. This field derivation kills all squares and vanishes by perfectness. Conversely arbitrary scalar multipliers at each vertex work with the corresponding edge-output multiplier. The space of input matrices S is therefore the commuting algebra K^V. Only the projected input matrices are multiplied.

Find the kernel of S²+S on that commuting space and split the raw input by simultaneous zero/one eigenspaces of its basis. The resulting blocks are exactly the hidden vertices. Their common binary dimension is m. On a vertex choose a nonzero vector v and use the evaluation isomorphism S_i↦S_i v to get a field multiplication law on that block with v as unit. Construct a polynomial field basis and verify its multiplication table. To use one field model at every vertex, find a root of the first block's irreducible modulus in each other field via trace splitting. For each edge choose the output frame B(x,1) as x ranges over the first vertex's field basis. The residual bilinear operation is x y^(2^t); test all m exponents on all binary basis pairs. Verify independence of the edge outputs, and find a single raw input shift accounting for the remaining degree-one discrepancy by Gaussian elimination. Check the proposed map's constant, all linear coefficients, and all quadratic coefficients in raw coordinates. Failure to fit returns UNKNOWN. All operations have polynomial bit cost in the explicit raw input size.

A separately designated Boolean quadratic inequality expands in recovered coordinates by evaluating each coordinate bit as Tr(a x_i). Its representation uses polynomially many field monomials even after arbitrary binary affine input change, because its Boolean degree is two. Thus a target fiber and this side inequality reduce to affine binomials plus one sparse inequality; their feasibility can be decided deterministically without constructing a general large-field witness. This uses the entire vector target, including zero edge values. Rank-one scalar-field charts handle a different signature with a single output field; this network may have arbitrarily many edges but no supplied chart.

For ordinary six-regular graph coloring via two-bit determinants, simultaneous E12 and E21 endomorphisms on all vertex planes are input derivations with output map zero (both matrices have trace zero). Their commutator is nonzero. No invertible binary re-encoding can turn this model into a multiplication network meeting the separating-neighbor hypothesis. This test does not rule out other chart families.

Using derivations to recognize structure in a tensor is established methodology. See [Brooksbank, Maglione and Wilson, Tensor isomorphism by conjugacy of Lie algebras](https://doi.org/10.1016/j.jalgebra.2022.04.014). The argument here computes the input projection explicitly for this graph family and checks the affine binary refinement independently of that polar invariant.
