# A particular solution of twisted product edge equations

The field has size 2^m and F denotes squaring. Fix the exact nonzero vertex support. An edge x_i F^s(x_j)=b is immediately inconsistent if b is nonzero without both endpoints present or zero with both present. Discard satisfied zero edges. In each remaining connected component, start with one root parameter t and propagate along a spanning tree. Every vertex becomes a F^s(t)^e with a nonzero, s modulo m, e in {1,−1}. Traversing an edge x_u F^k(x_v)=b from u to v substitutes F^(−k)(b/x_u); traversing backwards substitutes b/F^k(x_v).

Substitution into any remaining edge, then applying the inverse Frobenius of its first vertex and inverting if necessary, gives F^k(t)=d t or t F^k(t)=d. The homogeneous ratio group on a satisfiable component has order gcd(2^m−1, 2^k−1 for quotient rows, 2^k+1 for product rows), because each constraint on the ratio is a power equation in a cyclic group. With no cycle rows the order is 2^m−1.

Quotient rows are homogeneous binary-linear equations. If any product rows exist, select a pivot t F^r(t)=c. Replace each other product row t F^s(t)=d by F^s(t)=(d/c)F^r(t), and add the necessary equation F^(2r)(t)=(F^r(c)/c)t. Solve the binary-linear system; without a nonzero vector the fiber is empty. Choose any nonzero kernel vector t₀. The added equation guarantees δ=c/(t₀ F^r(t₀)) is fixed by F^r. For a feasible instance write a true solution as t₀h. Ratios of nonzero linear-kernel elements lie in the subfield fixed by all Frobenius differences of the linear rows, because each row has the form F^s(t)=d F^u(t); multiplying a kernel vector by an element of that subfield preserves the kernel. Consequently h and F^r(h) lie in the subfield, so δ=hF^r(h) and its square root lie there as well. Thus t₀ sqrt(δ) still meets all linear equations and has pivot product c, since sqrt(δ) is fixed by F^r. Verifying the resulting candidate against the original rows distinguishes the unsatisfiable cases without assumptions about δ outside that promise. If there are no product rows, any nonzero linear-kernel vector suffices.

Each returned component lists its vertices, signed Frobenius powers e_v, and subgroup order d. At a particular solution x*, all solutions on the fixed support are given uniquely by x_v=x*_v h^e_v for one h^d=1 per component. The root has exponent one, ensuring injectivity. All calculations use polynomially many binary field operations and bit operations in the explicit graph and field degree; no generator, discrete log, factorization of 2^m−1 or enumeration of a multiplicative subgroup is needed to produce this parameterization. The controls expand the charts independently and compare the complete sets with brute force over F4, F8, and F16.
