# Comparing two projection-pair polynomials

For binary decomposable Plücker covectors f,g, append the two projection rows defining f and g separately to the common private matrix, yielding M_f and M_g. The Cauchy–Binet polynomial D_fg=det(M_f diag(X) M_gᵀ) has binary coefficient f(p_B)g(p_B) for each (r+2)-element set B. This includes the zero vector for a rank-deficient B. A sufficient equality test for this example is bundled in xor_plane_scc.py. Find a common basis J of the first pair. If it is not common for the second pair, the coefficients differ. If the first pair has no common basis, compare zero against the second by ordinary intersection. Otherwise normalize all four matrices in their respective basis J. Translating X by the 0/1 indicator of J turns each determinant into det(I+diag(X)K) for its normalized binary cross Gram K. Form the arc union of the two K matrices and compute its strongly connected components. If on each component the two restricted matrices are equal or transposes, all corresponding principal minors agree, because each induced submatrix is block triangular across the fixed components and determinants are invariant under transpose. This check is polynomial and sufficient; a failed check can request the published general PME routine or return UNKNOWN. On the explicit instance the ordinary common-basis search finds J=(0,2,3,4,6), and this SCC test certifies absence without exhaustive subset enumeration.
