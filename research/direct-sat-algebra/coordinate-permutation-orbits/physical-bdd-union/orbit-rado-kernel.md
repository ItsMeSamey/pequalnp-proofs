# Deciding a pinned canonical orbit by contracting a maximum-deficiency core

Use the labelled canonical two-permutation four-color orbit of four-color-orbit-boundary.md with arbitrary zero and one pins. Check the raw permutations, order, start and labels against the public construction in polynomial time. Unlabelled conjugates need not be recognized. D=4 binom(m,2) for odd m, and a marked site records the difference between two F2² vertex colors. Graph four-colorability reduces to this family.

Compute the permitted difference list at each pair. An empty list rejects; four values impose nothing; two or one values give affine equations. Three values exclude one point. Gaussian-parameterize the affine equations and carry all offsets. If the image of a remaining pair misses its forbidden point, drop it. A constant image equalling the forbidden point rejects. A one-dimensional image containing the point gives a new affine equation excluding it; restart. At most 2m dimension reductions occur. Remaining constraints i exclude one point of a surjective two-bit affine map with two-dimensional normal plane P_i.

Write r(S)=dim(sum of its normal planes) and δ(J)=max_{S⊆J}(|S|−r(S)). By Rado's rank formula, δ(J)=|J|−ν(J), where ν is the maximum number of independent representatives of distinct planes. Compute ν by deterministic linear/partition matroid intersection on the three tagged nonzero vectors per plane using Gaussian independence tests. Supermodularity makes the maximizing sets closed under intersection and union. Let U be the intersection of all maximizers on the full ground set I. Scan each row once, deleting it from the working J if δ(J−i)=δ(I). U is always retained and witnesses the successful deletion of every row outside it. At most |I|+1 polynomial intersection calls suffice.

For each S outside U, r(U∪S)−r(U)≥|S|. A final matroid intersection therefore finds one representative per outside plane independent modulo span(U). Preserve its original two coefficients and offsets; force the corresponding linear combination of the two observed bits opposite its value on the excluded pair. All these equations together extend EVERY assignment to a basis of span(U), since the representatives are independent in the quotient. Only the core remains to search. Select any successful core basis assignment and solve the resulting linear system for original colors. If no core basis assignment passes, the original pins are infeasible.

For a finer clock split core planes into direct-sum components. On two indexed generators per plane select a column basis, join each nonbasis generator to its supporting basis columns, and join each row's own two generators. Distinct resulting components have disjoint basis supports. Enumerate each component of rank r_j independently, at most 2^r_j basis assignments. Overall deterministic time is polynomial in the explicit input times (1+Σ_j 2^r_j), and space is polynomial by sequential enumeration. The single original witness is recovered by a full Gaussian solve after choosing successful component assignments. Apply at most 2m conjugates R^j F R^(−j), using j mod m for the vertex and j mod 2 for its bit, inverse rotation first. Each j<2m; repeated squaring gives a polynomial SLP, or expand the rotations directly using R^(2m)=identity. Replay physical pins on the resulting word. The avoiding equations select sufficient extensions; they do not count all extensions.

With no core this takes polynomial time. In the ordinary graph representation r(S)=2(|V(S)|−components(S)) on the touched vertices. Graphs decomposable into two forests have empty core, with arbitrary forbidden offsets. K5 has core rank eight and deficiency two (every proper edge subset has deficiency at most one). Arbitrarily many rows independent modulo its span can be attached without changing its smallest core. Zero prohibited differences on all K5 edges give genuine NO; a fixed nonzero prohibited difference on each admits all colors equal. A disjoint family of such cores has growing total rank but bounded component ranks. Unrestricted connected cores may remain exponentially costly. The additive deficiency alone does not bound their ranks.

This is a decision/witness algorithm on an NP-complete orbit family. Rado selection and deficiency are classical. The prior affine literal deficiency computation is in /workspace/scratch/tensor-gaussian/affine-literal-deficit.md; matching autarkies and clausal deficiency kernels have been studied by [Kullmann](https://doi.org/10.3233/FI-2011-428). No priority claim for the matroid principle is needed.
