# A fixed NP-complete orbit problem with two coordinate permutations

The input consists of two explicit permutations of D coordinates, a D-bit start vector p, and a set Z of coordinates. Decide whether the orbit of p meets the coordinate subcube of vectors zero on Z. This fixed language is in NP: guess a straight-line program giving a group element over the two listed permutations, their inverses, and composition. The Babai–Szemerédi reachability lemma gives O((1+log |G|)^2) instructions for each element; |G|≤D!, so this is polynomial in the explicit input length. Verify every permutation multiplication/inversion, apply the result to p, and check Z. See [the reachability lemma and statement with the explicit bound](https://drops.dagstuhl.de/storage/00lipics/lipics-vol102-ccc2018/LIPIcs.CCC.2018.25/LIPIcs.CCC.2018.25.pdf).

Reduce 3SAT with n≥1 input variables. Delete tautologies and repeated occurrences within a clause; an empty clause may instead go to a fixed NO instance. For every set S of 1 to 3 distinct variable indices and every Boolean pattern a on S, make one coordinate (S,a). D is at most 2n+4 binom(n,2)+8 binom(n,3). For assignment x let v(x) be the indicator vector containing precisely (S,x restricted to S) for every S. Use p=v(0). Rotating the n variable names cyclically merely permutes the D coordinates, with pattern bits carried along and reordered on the sorted triple. Flipping variable zero also permutes the D coordinates, toggling its pattern bit exactly when it belongs to S. These two explicit permutations depend only on n. Conjugating the flip by powers of the rotation makes every individual flip available. Hence the orbit of p is exactly the 2^n encoded assignments, with no spurious states. For each original clause on S add its sole falsifying pattern coordinate to Z. Now v(x) is zero on Z precisely when x satisfies the original formula. The reduction uses polynomial time and O(D log D) bits for permutation lists. The positive orbit certificate on the image can equally be the original satisfying assignment. These claims allow repetitions across clauses, unit clauses, empty conjunctions and unused input variables.

Equivalently, take exponentially many Boolean variables X_t indexed by all D-bit vectors t. For j=0,1 require X_t=X_{π_j(t)} universally; add the unit X_p and units NOT X_t on the entire zero-subcube. The equalities mean exactly that X is constant on each orbit. The resulting succinct 2CNF is UNSAT iff the answer to the orbit problem is YES. Membership does not depend on a chosen assignment to the X variables. The clause decoder requires D address bits and three type bits for the four implication families, one positive unit, one negative-unit family and harmless repetitions. Inside each type every variable-label bit copies one address bit or is a fixed constant: generate the negative units by forcing Z positions to zero and leave other address bits unchanged. Original clause signs are constants per type. The negative pin is one subcube, not a free list of arbitrary subsets.

For a more general coNP upper bound on succinct satisfiability, take explicit invertible affine g_i and affine phases ℓ_i on D-bit addresses and impose X_{g_i(t)}=X_t+ℓ_i(t) over F2 throughout. Pins can prescribe a bit on explicitly given affine domains (in particular subcubes). On doubled addresses the signed actions (t,b)→(g_i(t),b+ℓ_i(t)) are invertible affine maps. UNSAT means either a group element maps (t,0) to (t,1) for some t, or one maps a pinned literal to the complement of another pinned literal. Conversely when neither obstruction exists complementary orbits are distinct; choose one from each complementary pair according to the pins and arbitrarily on the rest. Guess the addresses/pins and a straight-line program for the group element. Its length is O(D^4) because an affine map on D+1 bits has O(D²) bits. This verifier supplies a constructive way to bypass long explicit refutations for this syntax. It supplies no superpolynomial time lower bound for the fixed NP-complete problem.
