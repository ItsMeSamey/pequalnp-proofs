# Endpoint-local field equations on arbitrary graphs

Over a supplied binary field K, each edge prescribes axy+bx+cy+d=0, with arbitrary coefficients per edge and one field variable on each endpoint. The graph may contain repeated edges and loops. The following algorithm produces a witness or decides emptiness in deterministic polynomial bit time, without any bound on vertex degree, overlap, or cycles.

If ad+bc is nonzero, this edge is the graph of the invertible projective transformation y=(bx+d)/(ax+c), restricted to finite x and y. In each component of these edges use a spanning tree to express every vertex as a projective transformation of one root t. Forbid infinity at the root and at every transported vertex. Each nontree edge asks that an invertible transformation with entries A,B,C,D fix t, equivalently Ct²+(A+D)t+B=0 at finite t. A nonidentity cycle supplies at most two roots, found by deterministic trace splitting; test these against the remaining cycles and poles. If every cycle gives the zero polynomial, the root may take any finite value except the forbidden poles. There are at most as many distinct forbidden values as vertices, so a default root can be selected or its absence proved with polynomial work even when K is exponentially large.

If ad+bc=0 and a is nonzero, the equation factors as (x+c/a)(y+b/a)=0. If a=0 the edge is a unary equation, a tautology, or a contradiction. Transport each finite equality through its vertex's inverse transformation, discarding a choice if its root value is inadmissible. Use a Boolean atom for each distinct admissible (component,required root value). Each surviving edge contributes one disjunction of at most two atoms. Add pairwise at-most-one clauses within components. Any field solution satisfies this 2-CNF. Conversely assign the selected root in each component, or its admissible default when none was selected. Every positive edge clause already has a selected equality; giving defaults to unselected components cannot break it. This avoids enumerating root values and does not require long at-least-one clauses. Evaluate all original edge equations on reconstruction.

The raw adapter accepts a supplied invertible binary input chart and offset, specified endpoint pairs, and an invertible binary output basis. Each field output is fitted as a K-linear combination of 1,x,y,xy in precisely those supplied coordinates. The candidate has binary degree at most two. Comparing every squarefree raw ANF coefficient after the chart translation certifies its identity on all binary inputs. Returned witnesses are checked against the original raw map and target. No recovery from unprovided frames or claim for arbitrary cross-vertex or arbitrary binary-linear drift is needed.

Unconditional target attainability fails already for the four-vertex path with xy=1, yz=0, zw=1. All smaller simple trees are stars of degree at most two, hence universally attainable over K of size at least four for the tagged-product star model. If every edge is projectively invertible, a tree with at most |K| vertices is always feasible: at most one point per vertex is excluded in the root projective line, which has |K|+1 points. Sharpness holds even for a path on |K|+1 vertices. Start with identity root transport and its pole infinity. At each step choose an as-yet-unexcluded finite root value p; its current image b is finite, and the next edge y=1/(x+b) excludes p. Cycling through all remaining root values makes the final path inconsistent.

The implementation is projective_edge_drift.py. Its controls cover 280 mixed-rank instances compared with brute force over GF(4) and GF(8), all 256 targets on a dense translated GF(4) cycle, a rejected off-endpoint linear term, and both path obstructions.
