# Output-polynomial enumeration of physical tag lifts

A tag lift predicts each binary tag by a linear functional on the private column span. Count distinct predictions on that span, excluding predictions whose agreement set has less than full private rank. Equivalently these are precisely the lifts induced by common physical private bases. Each eligible agreement set determines its full predictions uniquely. The implementation returns original-index agreement masks and predicted global tag rows; it need not enumerate bases or every possible functional.

For one tag, append the observed bit to each private column and include the vertical element e=(0,1). Within this represented matroid, a hyperplane missing e is the graph of a linear functional on the private span. Its ground-set complement is a cocircuit containing e. Conversely any such cocircuit gives an agreement set spanning the private space: the augmented ambient space has dimension r+1, the hyperplane is spanned by its physical points and its projection along e is injective. Dependency rows for one greedy basis of the lifted columns form a binary representation of the dual after transposition. Thus it suffices to enumerate its circuits through e.

The code specializes the circuit-closure algorithm to packed binary vectors. Restrict attention to the component of e by merging intersecting fundamental circuits. Start with its fundamental circuits. For every distinct pair C,D already found, and each j in their intersection, seek a known circuit contained in (C∪D)−j. If none exists, Gaussian elimination produces one there. Queue all newly found circuits. Processing each pair once suffices because an existing witness for its elimination persists. At closure the circuit axioms give a matroid on this component containing the original fundamental circuits and having the same bases' rank. Any original basis is independent in the new matroid, hence is a basis in it. Uniqueness of each fundamental circuit then gives all original circuits. Coloop and loop singleton components are covered. Lehman's connected-matroid bound, as used by Khachiyan and coauthors, bounds total circuits by k(k+1)/2 for k circuits through e (the singleton coloop has no circuits). Every closure operation costs polynomial time in this count and the binary input size. The theorem also gives a stronger incremental algorithm via self-reduction; the implemented plain component filter claims total output-polynomial time only. [Khachiyan et al., SIAM Journal on Discrete Mathematics](https://doi.org/10.1137/S0895480103428338)

For multiple tags, restrict the physical columns to each previous agreement set and enumerate the next scalar cells. Each scalar child still has full private rank. Its predicted functional on the restricted columns extends uniquely to the entire private span. Its conjunction with earlier tag tests agrees exactly on that child. Every partial cell has a descendant by interpolation on any private basis within it. Different nodes at a fixed level cannot share a final cell because the latter has full private rank and fixes all earlier predictions. Hence there are at most (number of tags + 1) times the final number of lifts many enumeration nodes. Total time and space are polynomial in input size and final lift count. This bound allows exponentially many genuine lifts.

For an original compatible support, tag values factor through its private span and extend to the ambient private span using a physical basis extension. Its entire support therefore lies in an enumerated full-rank cell. On each such cell tag tests vanish on every private relation. Apply the physical alternating GIM solver on that cell for each named anchor pair. The recovered square physical support already has ambient private rank and cardinality r+2, and its private/tag annihilation and indexed alternating value are replayed on the original words. This decides the physical query while preserving shared physical indices.
