# Decision boundary for the rank-one locus test

Given a basis of a binary linear subspace of d-by-d symmetric matrices, deciding whether it contains a nonzero matrix of rank one is NP-complete.

Reduce a CNF to a binary quadratic system using one Boolean wire for each circuit gate. AND is a quadratic equality, and NOT and the final output test are affine; Boolean solutions project exactly to satisfying source assignments. Homogenize with bit w. For every wire x_i impose the additional linear matrix equality X_ii=X_0i. Translate each polynomial equality into a homogeneous linear equation on X, sending x_i x_j to X_ij, x_i to X_0i and the constant one to X_00. Supply the kernel basis, computed by binary Gaussian elimination.

Every nonzero symmetric rank-one matrix over the binary field is vvᵀ. If its leading bit w is zero, then the diagonal equalities force all remaining bits of v to vanish. Hence w=1, and every such matrix gives a source solution. Conversely any source solution with w=1 gives a nonzero matrix in the kernel of rank one. Verification is polynomial. The linear dimension of the ambient subspace and the number of matrix entries are polynomial in circuit size.

This reduction concerns discovery of even one nonzero rank-one point in an arbitrary symmetric matrix space. It does not settle the separate problem with a promise that the space is spanned by such points or that their diagonal vectors span the leaf space. It explains why the Boolean minor product-reduction certificate need not succeed on general input spaces.

## The full-axis variant is also NP-complete

Use the same translation of the quadratic Boolean equations but omit every auxiliary constraint X_ii=X_0i. In the original ANFs first replace x_i² by x_i, so every genuine quadratic term is squarefree. Regardless of satisfiability, every vector v=(0,e_i) gives a permissible rank-one matrix: all cross products, all w-linear terms and the constant w² vanish. Their directions already span the codimension-one hyperplane w=0. Outside that hyperplane, w=1 and the original SAT equations hold exactly. Consequently the binary span of the diagonals of all rank-one matrices in the supplied space is the entire d-dimensional leaf space if and only if the input CNF is satisfiable. Indeed the baseline directions can themselves be supplied to the algorithm. Existence of d independent rank-one directions is in NP by listing their vectors. Thus recognizing existence of a full diagonal section generated by rank-one varying matrices is NP-complete, even when d−1 independent axes are already given.

This concerns the certificate search in an arbitrary symmetric matrix space. It still does not settle a promised rank-one-generated-space problem, the search behavior of the explicit overlap families, or SAT decision for a full symmetric pencil already certified by the independent-diagonal parity criterion.

One can simultaneously promise that the ordinary diagonal map from the input matrix space onto F₂^d is surjective. In the second reduction no equality ever uses X_ii for i>0, so these entries are free. Test linear feasibility with X_00=1. If feasible, unrestricted diagonal rank follows. If infeasible, the original formula has no solution; return the fixed no-instance on basis coordinates w,x,y with matrix constraints X_xy=X_00, X_0x=0. This space has arbitrary diagonals and the promised baseline coordinate axes. A rank-one element with w=1 would have x=0 and xy=1, impossible. Thus the strengthened recognition problem remains NP-complete even inside the independent-diagonal class for which every target of the private pencil is guaranteed a lift. Hardness of finding a rank-one frame and ease of deciding the image can coexist on the very same promised inputs.
