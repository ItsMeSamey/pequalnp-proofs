# Deterministic fixed-parameter principal-minor search by class parity

Reduce the binary XOR constraints H·1_S=u to w independent rows, rejecting inconsistent u; group identical label columns into k≤2^w nonempty classes (including zero when present). By the sharp 2w radius theorem, it suffices to guess profiles with at most 2w odd classes and with their labels adding to u. There are at most Σ_{j≤2w} binom(k,j)=2^{O(w²)} such profiles. Each intersection subproblem enforces class parities but does not constrain cardinality.

For a binary symmetric W let d=diag W and A be W+ddᵀ bordered by a new vertex b with column d and zero diagonal. It is alternating. For even |S|, det W[S]=det A[S]; for odd |S|, det W[S]=det A[S∪{b}]. The rank-one determinant identity supplies the correction d_Sᵀ adj((W+ddᵀ)[S])d_S. For even alternating matrices this vanishes since their adjugates are alternating (odd principal minors vanish). For odd alternating matrices the original determinant is zero and the scalar is exactly the bordered determinant. Thus the first delta-matroid D(A) encodes unrestricted symmetric W with one extra bit.

On the augmented ground set take a second alternating matrix C with block I+J for each nonempty label class and a zero singleton at b. A clique block restricted to m vertices has determinant 1+m modulo two, so it accepts exactly even sizes. Twist D(C) by one representative of each odd class and by b iff the profile has odd total parity. This family enforces precisely the required class parities and dummy membership. A common feasible set gives a desired S after dropping b, and conversely.

Geelen, Iwata and Murota give a deterministic polynomial algorithm for unweighted linear delta-matroid parity. Their intersection reduction uses the direct sum of the two copies with corresponding vertices paired: discrepancy zero means a feasible union of whole pairs, which is exactly a common feasible set. The general parity algorithm accommodates the specified twists. A query uses O(n) indices and binary matrices; polynomial bit cost suffices. Over all profiles this yields deterministic 2^{O(w²)}poly(input) time and an original witness, including for even-cardinality solution fibers. This bound invokes their algorithm. The separate typed-compression solver gives an elementary native algorithm with a larger parameter function. [Geelen, Iwata and Murota, Sections 3–5](https://www.math.uwaterloo.ca/~jfgeelen/Publications/deltamatroidparity.pdf)

For diagonal completion begin with any invertible A₀=D+diag(t₀) of the fixed symmetric matrix D, found by successive diagonal choices; use W=I+A₀⁻¹, shift the desired syndrome by Ht₀, and return t₀+1_S. Failure to find an invertible slope does not exclude target attainment through a singular slope.
