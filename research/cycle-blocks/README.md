# Parity markers on graphs with sparse cyclic blocks

Let G be any finite simple graph with vertex labels in GF(2)^t. Seek an induced subgraph in which every vertex has even degree and the selected labels sum to a prescribed target. These are exactly the guards of the alternating adjacency matrix with t parity markers. Write b for the maximum of |E(B)|−|V(B)|+1 over biconnected edge blocks B, counting a bridge as its own block. Take b=0 if there are no edges. The algorithm reconstructs a witness for every attainable target in time 2^b 4^t (n+1)^{t+O(1)}. In particular, three markers are polynomial-time solvable for bounded b, including cactus graphs with arbitrarily many cycles.

Form the incidence forest of blocks and vertices and root each component at a vertex. A vertex sends two attainable-label tables, according to its selection bit. Its table includes the contribution of its own label. Each child block sends two tables for the parent bit, excluding the parent's label. Independent child tables combine by XOR convolution. Root tables of disconnected components combine in the same way.

An edge set of even degree at every vertex decomposes into simple cycles, each contained in a block. Its restriction to each block therefore has even degrees. Conversely, even degrees in every block yield even degrees in the whole graph. To compute a block table, enumerate the members F of its binary cycle space by a fundamental cycle basis. Force every endpoint of F to be selected and honor the parent bit. Reject conflicting choices and any extra induced edge among forced vertices. Further selected vertices must be isolated within the selected block.

For a fixed F and parent bit, it suffices to enumerate sets of at most t further selected vertices. To prove this, take any feasible choice and label each further selected vertex by the XOR contribution from its entire descendant subtree including itself. If these vectors are dependent, take a nonempty zero-sum subfamily and discard those vertices with all their descendants. The discarded vertices were isolated in the selected block. All other block selections and the total label stay feasible. Repetition yields the asserted bound. For every enumerated set whose selected vertices induce exactly F, combine the corresponding child vertex tables, including those with unselected roots. These latter tables can have nonzero labels from selected descendants.

The reference solver uses integer masks to retain actual witnesses. Run python -B check.py. It compares all attainable labels and returned witnesses to exhaustive search on every graph through four vertices at four marker widths and on 400 further seeded graphs. The recursive reference implementation is intended for small instances and uses Python's default recursion limit.
