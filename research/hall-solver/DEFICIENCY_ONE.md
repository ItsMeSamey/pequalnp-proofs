# Maximum deficiency one

Stefan Szeider's [JCSS paper](https://ac.tuwien.ac.at/files/pub/szeider-jcss-2004.pdf), Theorem 1 (credited there to Fleischner and coauthors) characterizes SAT by a partial assignment of size at most the maximum deficiency whose residual has a clause-covering matching. Lemma 11 gives a model-finding time bound of O(nl) for maximum deficiency at most one. Theorem 4 proves fixed-parameter tractability in the general maximum deficiency. The local implementation covers only zero and one.

The parameter is m minus maximum incidence matching size, equivalently the maximum of |S|−|N(S)| over clause subsets S, including the empty subset. It can exceed m−n. The program removes tautologies and duplicate clauses before measuring the parameter. Each variable occurring only in a tautology receives an arbitrary value in the returned model.

## Correctness of the one-variable test

Here is a direct proof of completeness in the single-exposed-clause case. Fix a satisfying assignment A. Among maximum matchings choose M maximizing the number of matched clauses whose representative literal A makes true. There is exactly one exposed clause C. Choose a literal of C made true by A and call its variable v. It must already represent a clause D, since otherwise adding C–v increases the matching size. If A made D's literal on v false, swapping D–v for C–v would preserve size and increase the number of true representative literals. Thus fixing v according to A satisfies both C and D. Every surviving clause still has its distinct representative in M outside v. Consequently trying each occurring literal and checking its residual for a covering matching finds a model whenever one exists. Conversely any such matching extends the tried literal to a full model by setting its representatives. If the deficiency is zero the initial matching already gives a model. An empty clause is handled by the same tests.

The proof uses A and an optimal M only for existence. The program starts with any maximum matching. Restrict it on each trial by dropping satisfied clauses and the trial variable. At most two surviving clauses lose coverage: the initially exposed clause and the previous owner of the trial variable. Each can be matched by a single augmenting-path search if a covering matching exists. A failed search certifies impossibility of that trial by the alternating reachable set.

With n occurring variables, m normalized clauses, and L normalized literal incidences, the initial matcher takes O(m(1+m+L)) operations, and each of at most 2n trials takes O(1+m+L). In the promised regime m≤n+1. These are expected-time Python dictionary/set operation bounds, plus input normalization time. The implementation does not recurse into formulas of deficiency greater than one. The unit chain and perfect binary-tree examples that required 2^n core assignments now take polynomial time. Deficiency is unbounded on unrestricted CNF.

Run 'python check_deficiency_one.py'. This checks all 512 normalized formulas on two variables and 5,000 reproducible samples on five variables against exhaustive SAT, including witness validation and rejection outside the promise. The parameter classification in these tests uses the local incidence matcher. The suite separately checks the full binary-tree family through depth seven (127 variables), satisfiable single-clause deletions, duplicate clauses and tautology handling. These are executable checks, not a machine-checked proof of the implementation.
