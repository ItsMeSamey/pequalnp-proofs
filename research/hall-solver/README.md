# Hall-core SAT solver

Run `python hall_sat.py` with a JSON object on stdin. Pass clauses as lists of nonzero signed variable IDs. Optionally pass a list of variables as `core`. A null model denotes UNSAT. An invalid supplied core raises ValueError.

The automatic algorithm finds a maximum matching between clauses and variables. Starting from all unmatched clauses it visits each neighboring variable and follows its matched edge back to a clause. Every reached variable must be matched, as an unmatched one would end an augmenting path. Every reached clause has all its variables reached. Every unreached clause is matched outside the reached variables, because a reached variable's matched clause is reached. Thus every unreached clause has a distinct representative outside the core, while every reached clause is entirely inside. With a supplied core the solver checks the same outside-matching certificate directly.

After tautology removal and literal deduplication, the solver enumerates assignments to the core and satisfies each outside clause by setting its representative. Different representatives never conflict. Restricting any full model satisfies every core clause, so exhausting all core assignments proves unsatisfiability. The witness also assigns variables occurring only in tautologies.

For m clauses, L literal occurrences and k core variables, matching takes O(m(L+m)) operations and exact enumeration takes O(2^k poly(input size)). A logarithmic core gives polynomial time. For every n≥1, the formulas consisting of (y₁), (¬yₙ), and (¬yᵢ∨yᵢ₊₁) for 1≤i<n have an incidence graph that is a path on alternating clause and variable vertices with clause endpoints. Every maximum matching misses exactly one clause, from which alternating paths extend to both ends. Hence k=n, and the solver tests exactly 2ⁿ assignments despite matching deficiency one. Unit propagation would solve this particular family immediately. The example concerns this implementation.

Run `python verify.py` for exhaustive checks on every subset of the nine normalized clauses on two variables (including the empty clause), random comparisons with brute force, witness validation, supplied-core checks and exponential examples.

A second deficiency-one family survives initial unit propagation and pure-literal elimination. Label each internal node of a perfect binary tree of depth d≥2 with a distinct variable. Give each leaf the clause of signed choices on its path, positive on left and negative on right. Any assignment falsifies exactly one leaf clause by descending along the false literals. Conversely deleting any leaf clause makes the formula satisfiable by following that leaf. The formula has n=2ᵈ−1 variables, n+1 clauses, width d and both signs of every variable. A matching missing just one leaf is obtained recursively by matching both subtrees except one leaf each and assigning one of these two leaves to the root variable. Since the whole formula is minimally unsatisfiable, its exact projection cannot have a proper subset of the clauses as its unsatisfiable core formula. Consequently all variables are in the automatic core. The solver again tests 2ⁿ assignments. The tests cover depths two through four.

## The unique least matching core

Call a set B feasible if the clauses with a variable outside B admit distinct representatives outside B. The automatic core is feasible by the alternating-path construction above. To see why it is contained in every feasible B, first note that the reached clauses are intrinsic to the incidence graph. For any maximum matching M, these are exactly the clauses that some maximum matching leaves unmatched. Flipping the matched and unmatched edges on an even alternating path from an unmatched clause exposes its reached endpoint while preserving cardinality. Conversely, if another maximum matching exposes a clause matched by M, the symmetric-difference path starting there ends at a clause exposed by M. An odd path with one matching having an extra edge would augment the other matching, contradicting maximal cardinality. The reached variables are precisely the neighborhood of the reached clauses, so they too are independent of M.

For a feasible B, combine its outside representatives with a maximum matching of clauses contained in B to variables in B. This matching is maximum globally because no matching can cover more internal clauses or more than all external clauses. Every exposed clause is internal. Starting there, alternating walks stay among internal clauses and B variables, since the outside representatives avoid B. The canonical reached variables thus lie in B. This proves that the algorithm computes the unique least feasible core under inclusion and hence also the unique minimum-cardinality core.

Any formula can be padded to force all its variables into this core. For each original variable x, introduce a distinct fresh variable y and add the clauses (y), (x ∨ y), (¬x ∨ y). Every original model extends by setting each y true. Omitting both gadget variables leaves three clauses competing for two representatives. Omitting only x leaves the two binary clauses competing for x. Omitting only y leaves all three clauses competing for y. Thus both variables are forced independently of the original clauses. This obstruction applies to the matching certificate on the padded input. Unit propagation can simplify the gadget.
