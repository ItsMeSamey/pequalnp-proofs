# Counting across a promised hidden interface

Let F be a CNF and C a hidden subset of clauses. Assume that deleting C leaves components admitting the desired split and that g, satisfaction of C, admits a pointwise degree-d certificate in its width-k violation bits. Let M be any polynomial-time recognizable terminal class of residual formulas that contains all further restrictions of the split formulas in question. Supply an exact terminal counter, possibly an oracle. Component size bounds measured against the original problem give such a hereditary criterion. Ratios measured against the current residual length need a separate argument.

**Explicit recognition.** Guess the relevant assignment variables of g and its complete truth table using the junta bound. Collect the clauses D of F implied by g. Checking a clause only requires checking compatible assignments on the guessed support, since all remaining literals could be falsified unless the clause is tautological. For the true g, C is contained in D, and g is equivalent to the conjunction of D. Test whether 1−g lies in the span of nonempty intersection monomials through order d of the violation bits of D. Solve exact rational normal equations for the unweighted squared residual. Every Gram entry counts a subcube, and inner products with 1−g follow by enumerating support pins and counting compatible subcubes. Zero residual gives pointwise equality at every assignment. At a point satisfying D every monomial vanishes, so the representation implies g. The reverse implication follows from construction. Deleting D can only refine the components after deleting C. Free and isolated variables need the same bookkeeping as for the original split. Thus this verifies an actual decomposition even outside the promise.

**Counting without recognition.** For budget b and a restricted input H, compute L(H,b) as follows. Return the exact count if H belongs to M. Return zero if b is exhausted. Otherwise maximize, over unassigned variables x, the sum L(H restricted to x=0,b−1) + L(H restricted to x=1,b−1). A variable-free input is directly decidable. Counts refer to the current unassigned universe, including isolated variables. Each value lower-bounds the true count, by induction and the disjointness of the two branches. The algorithm may use zero also for syntactically contradictory formulas.

Take b=k²d. There exists a depth-b assignment-query decision tree for g by the clause-query argument in the fixed-width note. At each accepting leaf every clause of C is forced true, so after removing tautologies and satisfied clauses the residual belongs to M. At each rejecting leaf no assignment satisfies F, so even the lower bound is exact. Inductively following this tree establishes equality at the root. The search requires at most (2n)^{O(b)} polynomial-time steps or terminal oracle calls for n variables. Arbitrary terminal instances need a separate running-time bound. The search avoids enumerating junta supports, truth tables, or Gram matrices, and relies on the promise for completeness.
