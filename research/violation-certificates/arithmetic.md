# Exact arithmetic

Let L include input length and n, m the clause count, and K the number of explicitly supplied nonempty clause-subset features. Every Gram and RHS entry sums m intersection counts. Find inconsistent variable pins or count the unfixed variables to compute each intersection. Construction costs O((K+1)^2 m poly(L)) bit operations for clause-index lists of length at most m. Entries have at most H=n+ceil(log2(m+1))+1 bits.

The normal equations are consistent. Choose a maximal independent collection I of columns of G. Positive semidefiniteness implies G[I,I] nonsingular, because G is a Gram matrix. Solve the corresponding subsystem and set other coefficients zero. The zero-rank case takes w=0. Symmetric pivoting can select any positive residual diagonal; if all vanish then the residual positive semidefinite block vanishes by Cauchy–Schwarz.

By Hadamard's inequality every minor of the K by (K+1) augmented matrix has at most B=O((K+1)(H+log(K+2))) bits. Fraction-free Bareiss elimination stores signed minors, and uses O((K+1)^3) exact arithmetic operations with intermediate products of O(B) bits. Cramer numerators and denominators have O(B) bits. Back substitution with a common determinant denominator keeps solution numerators bounded by these minors, while intermediate sums have O(B+log(K+2)) bits. Schoolbook arithmetic suffices for O((K+1)^3 B^2) bit operations beyond Gram assembly. Residual testing and count evaluation have polynomial bit cost. For all degree-d features K=sum_{i=1}^{min(d,m)}binom(m,i), giving m^{O(d)}poly(L) for m>=2. The formula with no clauses is counted directly.
