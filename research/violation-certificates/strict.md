# Connected separation for conditioning, factoring, and certificates

For integers r≥2 and t≥3 use one selector s and 2r disjoint blocks of t variables. For each block introduce t clauses, indexed by its coordinates. Clause i contains a selector literal and all t block variables, with the ith variable negated and every other variable positive. The selector literal is s on the first r blocks and ¬s on the last r. Thus an active block forbids precisely the t unit vectors.

The primal and incidence graphs are connected. Every block gives a clique of size t in the primal graph and a complete bipartite subgraph K_{t,t} in the incidence graph, so both widths grow with t, including after either selector restriction on the active blocks. The input has no units, pure variables, duplicates, tautologies, subsumed clauses, or pairs of equal-width clauses differing in a single literal sign. Every clause is indispensable, as an assignment can violate it alone.

Fix s=0, so the first r blocks are active. Within each active block restrict the allowed assignments to the all-zero vector and its first unit vector independently. Only the first clause in each active block can be violated, and its violation bit is an independent Boolean coordinate. All remaining violation bits are zero. Any pointwise satisfaction certificate consequently represents the product of the r terms (1−v_i) on the full Boolean r-cube. Uniqueness of multilinear representation gives degree at least r. This lower bound holds on either selector branch before factoring.

After branching on s, each connected active block has mutually exclusive violations, so one minus the sum of its t violation bits is an exact degree-one satisfaction certificate. Every inactive variable is free. The model count equals 2 × (2^t)^r × (2^t−t)^r. The selector is the unique variable occurring in all 2rt clauses. Taking r=t grows both obstructions at once in a polynomial-size input family. These lower bounds concern the presented formulas and the specified certificate model.
