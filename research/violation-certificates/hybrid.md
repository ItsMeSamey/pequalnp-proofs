# Conditioning and independent factors extend violation certificates

Fix d ≥ 1. A degree-d leaf certificate represents the indicator that at least one clause is violated by a multilinear polynomial of degree at most d in the clause-violation bits, pointwise on assignments. It can be found or rejected in polynomial time for fixed d by the Gram-matrix test in affine.md.

For a supplied set S of at most k variables, enumerate its assignments. In each restriction, delete true clauses and false literals, immediately returning zero for an empty clause. Partition the remaining clauses by connectivity through shared variables. Compute each component count by a degree-d certificate. Multiply the component counts and a factor of two for each free unassigned variable absent from all components. Sum the products over assignments to S. Correctness follows because the assignments to S partition the model set, and each restricted model set is a Cartesian product on disjoint variable sets. The cost is 2^k times a polynomial in the input length for fixed d. This is polynomial for a supplied k=O(log(input length)); for fixed k one may also search all candidate sets in polynomial time. Finding a logarithmic-size set by exhaustive subset search has no such guarantee.

This hybrid strictly contains the class recognized by componentwise degree-d certificates applied directly to the input CNF. Every input accepted by the direct test is accepted with S empty. For strictness take F_m = AND_i (s OR x_i) on m+1 variables, with m>d. All clauses belong to one component. Restricting s=0 realizes every Boolean vector of violation bits, since v_i=1-x_i. On the full cube, the violation indicator is 1-product_i(1-v_i), whose unique multilinear representation has degree m (the coefficient on the full monomial is nonzero). Thus the direct test fails. With S={s}, the s=1 branch has 2^m models and the s=0 branch splits into m units, each with a degree-one certificate and a single satisfying assignment. The count is 2^m+1. A suitable selector can be found by trying every variable. This separation concerns the named certificate tests, with the input clauses as given.

Even without conditioning, componentwise certification strictly extends a single global degree-d test: m independent unit clauses have full-cube violation patterns and hence require global degree m, while each unit has degree one. Repeating any fixed satisfiable or unsatisfiable component also admits exact products as long as the component counts are available.

One-sided certificates can use the same machinery when pointwise bounds have already been certified. For polynomials L ≤ 1[any violation] ≤ U on all realizable patterns, the model count lies between 2^n-sum_x U(x) and 2^n-sum_x L(x). All required expectations are sums of clause-intersection counts. Clamp each count interval to [0,2^n], take integer ceilings of lower endpoints and floors of upper endpoints, and combine nonnegative component intervals by endpoint multiplication and disjoint branches by endpoint addition. Equal resulting integer endpoints certify the exact count. The arithmetic is valid given the pointwise inequalities; checking arbitrary proposed inequalities is a separate obligation. Interval equality alone gives no general tractability guarantee.
