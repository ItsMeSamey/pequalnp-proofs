# An exact-budget predictor can give the sparse forecast

Assume a uniform deterministic predictor A that makes at most k mistakes on every realizable stream of k-input NAND circuits at every public numeric gate cap. Suppose it has a uniform polynomial per-round clock. One can construct another predictor with those same properties that violates the density condition on the explicit positive instances of the [two-error reduction](two-error-density-prediction.md).

Use the notation of that proof with φ the canonical constant-one circuit on r declared inputs. Its masked source G, its first threshold U and its final threshold T then have fixed computable NAND presentations at width h=12r+20. Test these presentations by exact syntactic comparison. If the width is outside this progression or the initial probe differs from G, run a fresh A at the original width and cap, forwarding that first probe too. Write S for the fixed original public gate cap. Each raw probe has its own gate count s≤S.

1. On the special first probe G forecast zero. If its true bit is zero, restart A at width h on subsequent probes, with no mistake spent. If it is one, a single mistake has been spent and every decoded guard is one.
2. On the next probe, if it differs from U, delegate that probe and the rest to the guard substitution below. On U forecast zero. If correct, delegate subsequent probes to the same guard substitution. If the label is one, two mistakes have been spent, and every surviving raw word has zero mask prefix.
3. If the next probe is T, forecast zero, then delegate regardless of its true label. For any different probe, delegate immediately, including that probe. This last delegation fixes the 3m high bits to zero and runs a fresh A on the m remaining raw tail bits.

For the guard substitution, keep every mask bit and the tail of every nonguard block. For a guard block insert the wire expression t_i=1 XOR a_i XOR (c_i AND e_i). This describes every raw word satisfying the g decoded guard equations and uniquely extends each choice of the other h−g bits. A source-positive word always belongs to this set. Supply the same reconstruction circuit at each delegated round, sharing its O(g) gates within the new query. Start the delegated A once at width h−g and fixed cap S+Cg+D, where C and D are absolute NAND compilation constants. Each transformed query uses at most s+Cg+D gates. For the zero-prefix substitution, start A once at width m and fixed cap S. Each transformed query then uses only input pins, constants and at most s gates. All later rows use that same delegated state and cap. The hidden compressed word is fixed throughout that run. The controller's comparisons, substitutions, and state operations take uniform polynomial time.

The branches using the original A spend at most h mistakes. Guard delegation spends at most 1+(h−g)≤h, including the branch where U was correctly forecast. Zero-prefix delegation spends at most 3+m≤h. These bounds also cover streams that stop early, arbitrary intervening queries, and rounds answered correctly. Only one delegated run occurs on each branch. The predictor is exact-budget in the usual worst-case sense: coordinate queries can force h mistakes on any learner with capacity for all h coordinates, by assigning each fresh bit opposite its forecast.

On the displayed all-positive history (G,1),(U,1), both forecasts were genuinely wrong and the planted word realizes both labels. The next zero forecast on T has actual support 1/(1+2^b 2^r), strictly below 2^(−h/16). The controller can afford even an additional mistake on that probe for a different surviving seed. The construction is conditional on existence of A. It establishes that the mistake guarantee does not compel every efficient exact-budget predictor to meet the trajectory's density requirement. Existence of some predictor with a density guarantee remains a separate question.
