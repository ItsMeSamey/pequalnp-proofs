# The cost of a common model for clause and affine repairs

Suppose an algorithm stores globally valid binary clauses Γ and affine equations Λ on the original variables. A shared satisfying assignment of these two caches is needed for a constant-fallback retraction. Finding one is NP-complete even when their separate constraint graphs consist of constant-size components.

Start with ordinary 3CNF. Give every literal occurrence its own variable copy; enforce equality among copies of each original variable by a cycle of binary implication clauses. Such a cycle forces identical Boolean values. Omit a vacuous singleton cycle. Every copy now appears in at most three clauses. For EACH expanded clause, including a cycle implication, create a private selector for every position. In Λ impose odd parity on its two or three selectors. In Γ put only the binary implications from each selector to its corresponding signed literal. No direct copy-to-copy implication is retained. Each selector appears once in each cache. The binary graph is a disjoint union of stars of maximum degree three and has a public model with every selector zero. The affine checks have disjoint supports of size two or three, each solved by one selected bit.

A joint assignment selects at least one true literal in each expanded clause, giving consistency of the copies and an original satisfying assignment. In the other direction, extend a satisfying word by copying variables and selecting one true literal in each expanded clause. Variables absent from the source can be set arbitrarily. The numbers of variables and constraint incidences are linear in the input occurrences, with logarithmic-size addresses. The number of valid selector choices depends on the source truth pattern; this is a decision and witness reduction. Joint membership is in NP. This recovers an NP-complete constraint combination in a restricted physical arrangement; it does not separate P and NP.

The archived affine-image 2CNF route finds a model in time poly(input) times the sum of binom(m,i) for i≤h using h independent checks on m literal normals. Its Multicolored Clique reduction precludes an unrestricted FPT conclusion in h unless FPT=W[1]. Two alternative explicitly computable interfaces pay for shared variables in different coordinates. One first eliminates variables private to the linear system, nominates all but two sites in each long projected row, and branches on the p distinct nominations. All remaining affine checks have width ≤2 and can join the 2SAT solver. The second parametrizes the solutions of Λ, nominates an affine literal in every binary clause with two nonconstant entries, and branches on a basis of the nominated linear parts, of rank q. Each residual clause becomes a single affine equation or is discharged. Units, constants, empty rows and clauses are included. Both routes restore original variables and verify the shared assignment. Compute the interfaces before enumerating, and select the smaller, giving a 2^min(p,q)poly(input) model search. For Λ empty choose direct 2SAT; for Γ empty choose Gaussian elimination. There is an actual global repair potential. A new entailed affine equation violated by the current joint model is independent of the old augmented rows. At most n+1 such rows can be added. Every certified binary clause violated at that joint model is new as well. Thus the sum of the unused binary-clause allowance U=1+2n+4 binom(n,2) and unused augmented rank strictly decreases at each certified repair. Compile R(x)=x if x satisfies both caches and the shared anchor otherwise. It fixes every satisfying assignment, and testing the O(n) stored affine rows costs O(n²) gates. For the bundled predictor and an explicitly charged polynomial-time sound certificate finder, the total clock is O((U+n+2)(2^ρ+(B+2)2^k)poly(input)), where ρ is the maximum selected interface size across phases and k counts unresolved two-child forks along a phase path. The common model is computed once per phase, outside the fork tree. The reference driver computes both interfaces and searches the cheaper one on every restart. Its pass over the original NAND DAG makes a linear number of gate visits, uses O(n) bit work per dense affine-mask operation, and recognizes input bits, negations and a fixed four-gate XOR pattern. It visits each reachable top conjunct once and retains recognized affine equations even when another conjunct is opaque. At a false lifted point the driver first tries these equations, then tests the original zero cubes of width at most two. It checks every returned witness on the original circuit. With L nonzero coefficients in r learned rows and m clauses, the compiled retraction adds at most 3n+3m+4L+3r NAND gates. The bundled canonical-threshold predictor has B=n. Other predictors require an explicit, valid bound on the queries actually asked. Charge the runtime of each custom forecast, including history replay, and of computing the bound. The stated polynomial factor extends to such a predictor when both its bound and that runtime are polynomial in the original input length and n. The search can still incur exponential costs through k or ρ.
