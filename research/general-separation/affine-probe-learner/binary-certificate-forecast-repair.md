# A polynomial potential for certified binary repairs

The interval search can expose the same reason for F(j)=0 at many assignments. Maintain a 2CNF Γ of original-variable implicates. Reject if Γ has no model. Otherwise obtain a model a by the implication-graph algorithm, preferring zero when possible, and compile R(u)=u if Γ(u), else a. This total retraction fixes every satisfying assignment of F. For m clauses the implementation uses at most s+3n+3m NAND gates for F∘R. Reinitialize the interval learner on that explicit source. Lift an accepting index by R and verify on F.

At a false crossing j put x=R(j). It satisfies Γ and F(x)=0. Fix at most two original inputs to their values in x and leave the others unknown. Evaluate the original NAND DAG: a zero operand forces one, two one operands force zero, and undetermined cases stay unknown. If this forward propagation forces the output zero, cache the clause excluding the tested cube and discard every pending state of the current phase. Otherwise use the original interval fork. This is a sufficient certificate check; finding every semantically valid clause is unnecessary.

There are U=1+2n+4 binom(n,2) possible exclusions. Every certified clause excludes a model of Γ, so it is new and not implied by the cache. Thus U−|Γ| strictly decreases across every certified repair, including restarts. Each certificate scan costs O((1+n+binom(n,2))(s+n+1)) Boolean operations. Let k be the maximum number of remaining two-child forks on a path of any phase, and B the largest valid per-phase mistake bound. There are O((U+1)(B+2)2^k) visited interval nodes, with polynomial work per node and polynomial space. For the supplied canonical-prefix backend B=n unconditionally. A custom backend requires its own explicit bound. [Interval solver](state-dependent-interval-repair.md)

The explicit AND chain accepting only the all-ones input now admits a unit repair at every false point: fixing one zero coordinate forces zero on that original circuit. At most n unit repairs occur. The syntactic a AND NOT a control admits two contradictory unit repairs. Neither needs a two-child unresolved fork, whereas the former interval-only program checked 2^n−1 median points on each.

For a limit of this mechanism take n=2^d−1, d≥3. Use d message coordinates and one tail coordinate for every remaining nonzero column c of length d; constrain its bit to 1+c·message over the binary field. Every pair of coordinates realizes all four patterns. Hence not even a semantically perfect search can find a nontrivial globally valid binary exclusion. The leftmost interval of size L=2^(n−d) has a single witness at L−1. Each of the d preceding median ancestors, a power of two with a one-bit message and zero tail, fails because some tail column has support disjoint from the message bit. The specified median search takes L+d−1 original crossing evaluations before success, excluding its separate anchor check. It learns no clause. This concerns global binary repairs; branch-conditional implicates may be stronger. [Independent precise count](affine-code-median-audit.md)

These displayed constraints are affine. Recognition of the explicit NAND XOR, inverter and top-level AND macros recovers them from the original gate graph, and Gaussian elimination supplies a witness. This is a diagnostic for binary certification, not a hard input for the complete direct-SAT portfolio.

Clause learning, propagation and restarts are established techniques. Here a global implicate comes from forward partial evaluation with at most two original inputs fixed, and the learned formula becomes a retraction before restarting the online search. CDCL can derive consequences via unit propagation in directions that this raw gate pass omits. The bounded-width resolution analysis of Atserias, Fichte and Thurley has a different hypothesis and clock. Gaussian processing alongside clauses also predates this construction. No priority claim is made.
