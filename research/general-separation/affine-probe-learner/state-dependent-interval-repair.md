# Charging a forecast repair to every surviving branch

An equivalent pair of circuits at a false prefix crossing can have opposite forecasts. This procedure changes learner state at every repair while preserving all satisfying assignments across its children.

Let A be a deterministic polynomial-time predictor on n-bit circuit queries under public gate cap S, with a known bound B on mistakes on every stream evaluated by one assignment. Define Q(−1)=0, Q(2^n−1)=F, and otherwise Q(j)=F(x) AND [x≤j] for the original circuit F. A linear-size comparator suffices, so S=|F|+O(n+1) in NAND gates. The published dyadic query constructor instead admits its own conservative polynomial cap.

Start with [l,r] equal to the full assignment interval and an empty labeled history. Maintain that every satisfying assignment in this interval realizes all committed labels, and each was forecast incorrectly. Discard empty intervals. At B+1 committed errors discard the branch since it cannot contain any satisfying assignment under the mistake promise.

At each live node, all satisfying seeds in [l,r] give Q(l−1)=0 and Q(r)=1. If either forecast is wrong, append that query and its indicated label and revisit the interval. Otherwise bisect indices l−1,…,r with frozen clones, preserving opposite endpoint forecasts. At the resulting upper index j evaluate F(j). If it is 1 return the verified assignment. If it is 0 then Q(j−1),Q(j) agree pointwise and have forecasts 0,1. In the nonempty left interval [l,j−1], append Q(j−1) with label 1. In the nonempty right interval [j+1,r], append Q(j) with label 0. Each child consumes one mistake for every satisfying seed it retains. The children partition the remaining solutions. No knowledge of either unknown bit is needed when both branches are explored. If search exhausts, report UNSAT conditional on A's stated bound.

Every path has at most B+1 charged transitions. Let k be the maximum number of binary forks along any visited path, counting only forks with two nonempty intervals. Suppressing unary chains gives at most 2^k leaves, hence O((B+2)2^k) nodes. Independently the false crossing points are distinct across all explored intervals, so there are at most 2^n branching nodes. The node count is O((B+2)min(2^k,2^n+1)). Each node costs at most n+2 cloned predictions on a history of at most B earlier queries. Source construction and the predictor on the actual input and history are additional polynomial costs. Complete depth-first search takes O((B+2)min(2^k,2^n+1)poly(n+S+B+1)) time and polynomial space for the current stack. The algorithm needs no advance knowledge of k. The unrestricted exact-n premise has no established small k guarantee.

At a strict disagreement of the efficient opaque-bit learner, deciding whether one particular feedback preserves all satisfying assignments is coNP-complete even with a public satisfying assignment and a public crossing certificate. Separately a tagged dyadic learner realizes 2^d genuine and distinguishable mistake histories after d fork levels; every explicit cover by histories charged at least d genuine errors needs at least 2^d members. Neither bound excludes implicit state representations. The deterministic N−1 point-query bound for an opaque unknown singleton applies even when the schedule is adaptive.
