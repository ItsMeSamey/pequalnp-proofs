# Disjoint histories amplify one-sided forecast support

The positive-threshold SAT reduction still works when some forecasts lack support. It suffices to bound how many of their surviving assignment sets can be disjoint. The solver need not identify any unsupported forecast.

Fix one deterministic learner at width h and NAND cap S. It has an h-mistake bound on every realizable stream of permitted circuits. Start a fresh trial by committing label one after a prediction zero on an arbitrary source. Every subsequent commitment predicts zero and receives one on a proper threshold [z≤j]. For each such realizable history H let V(H) be the nonempty set satisfying all committed labels. A state is deficient if its forecast is one on some proper threshold false on every member of V(H). Provisional queries on clones do not change this history.

**Equivalence.** P=NP holds if and only if there exists a uniform polynomial-time deterministic exact-h learner whose deficient sets V(H) have polynomially bounded packing number. The packing number is the maximum number of pairwise disjoint sets among these histories across all source presentations at the same h and S. A polynomial clock is required on inconsistent transcripts as well. Under P=NP the two-wise learner using retained mistakes has packing zero. For the reverse implication the constants of one fixed polynomial majorant p(h+S) can be built into a uniform SAT algorithm. [Forecast feasibility theorem](local-forecast-consistency.md)

## One defect per failed satisfiable copy

The [single-history procedure](positive-threshold-repair.md) remains sound on UNSAT sources with any exact-h learner. A positive initial prediction on a semantically zero source would cost one error while leaving the whole cube available for another h opposite coordinate responses. Its other affirmative exit evaluates a word satisfying the source.

If the procedure returns NO on a satisfiable source, consider its first loss of every model. Immediately after the initial error at least one remains. It cannot accumulate h+1 wrong labels while retaining a witness. At a false crossing j, failure at j=0 or a new commitment [z≤j−1]=1 removing every model implies the preceding state is deficient. Those models satisfy the source and none equals j. Any surviving model ≤j would have satisfied the lower commitment. The positive endpoint therefore cannot be the synthetic top, which would contain all these models. It was an actual unsupported positive forecast. This identifies a nonempty set before any unrealizable commitment, without an algorithm testing deficiency.

## Paid construction of disjoint trials

Given F on n inputs with s gates, introduce k tag bits and form G_i=F(x) AND [tag=i] at h=n+k. Use one common cap S=O(s+n+k+1). Polarity choices can be padded so the circuits have the same gate count. For a satisfiable F all copies are satisfiable. Charges from different tags are disjoint in the same h-bit cube.

Choose the least k with 2^k>p(h+S), doing the integer comparisons before materializing the tag instances. For each fixed majorant p, k=O(log(n+s+2)): choose a large enough constant multiple of log(n+s+2), then increase the constant for finitely many small inputs. Exponentiation in k dominates the fixed polynomial in n+s+k. Run the 2^k trials sequentially. If all fail on a satisfiable source, their charged sets violate the packing bound. On an unsatisfiable input no copy accepts. Witness search uses the **amplified decision** on the original restrictions with fresh histories, since unamplified trials can return false negatives. Verify the final word on F. [Implementation](packed_forecast_consistency_search.py)

There are at most n+1 amplified decisions, 2^k trials per decision, O((h+1)^2) forecast requests per trial and at most h+1 committed labels per replay. Workspace is reused across tags. All circuits, counters and arithmetic have polynomial bit length. The code accepts p(t)=C(t+1)^d, and its polynomial bound is for fixed C,d. No exponent or advice is chosen separately for each input. A small set meeting every deficient survivor set implies the packing promise, but the solver does not need that set.

## The ordinary mistake bound permits exponential packing

Positive packing is genuinely weaker than zero packing. An exact halving learner at h≥2 may predict zero on a designated singleton [z=w] at reset. After label one, it can predict one on all queries at that state, then evaluate every subsequent query on w. For w>0 its forecast on [z≤0] is unsupported. Confine this modification to one designated w at each width and use ordinary full-feedback halving elsewhere (resetting or conditioning after a correct first answer). Its deficient sets have packing number one. This example is information theoretic.

More generally let A be a uniform exact-n learner on arbitrary circuits at all arities and caps, or use unbounded exact halving. At widths h=4m, m≥2, consider the [four-site decoder](sat-without-global-affine-or-binary-exclusions.md). For every nonzero i let G_i be a canonical circuit for [D(z)=i]. After its 10m-gate decoder, the m polarities use at most m gates and the conjunction at most 2m additional gates. Use one linear public cap covering all these sources and thresholds. An algorithm reads the polarities, reconstructs the circuit template for that i and compares it to the source. It does not enumerate 2^m candidates.

Define B at reset to predict zero on these G_i. If label zero is received, start A fresh at h bits, having paid no mistake. Otherwise the surviving assignments form the whole fiber of i. In that state predict one on the next query. Thereafter run A fresh at 3m free bits. For any future circuit Q of cap S, simulate its evaluation via the section keeping the free prefix and reconstructing t_j=i_j+a_j+c_j e_j. This costs at most 7m additional NAND gates, shared across all original occurrences of each reconstructed tail. Give A cap S+7m. Every surviving original assignment has a unique prefix, so all subsequent labels remain realizable by one 3m-bit assignment. Other initial presentations use A directly. The positive special branch costs at most 1+1+3m≤4m errors. B is uniform and efficient whenever A is.

Taking the next query to be [z≤0] produces a deficient state for every i≠0, since D(0)=0. The 2^m−1 sets are disjoint fibers across different histories of the same learner at the same cap. Thus the ordinary mistake guarantee allows exponential packing. This establishes a distinction between learner properties and leaves open which efficient learners exist.
