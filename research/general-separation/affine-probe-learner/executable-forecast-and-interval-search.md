# Executable forecast reductions

In Python's standard library, invoke threshold_interval_solver.py with a JSON record such as {"n":2,"F":[[[0,1],[2,2]],3]} for x₀ AND x₁. Inputs are MSB first, gate i has address n+i, and constants zero and one have addresses −1 and −2. At large n launch with PYTHONINTMAXSTRDIGITS=0 for unrestricted decimal assignment serialization. The decision program returns an original witness or UNSAT unconditionally. Its running time can be exponential.

The built-in predictor omits (0,1−F(0)) from the 2^(n+1) virtual pairs (u,b). The two fibers are counted by intervals. Every realizable (x,F(x)) survives genuine feedback; each wrong majority forecast halves population, giving a proved bound n on the actual prefix-query class. For an interior normalized row, strip the repeated-input NAND and inner ordered NAND, locate the threshold operand's transition by bisection, and regenerate the entire ordered NAND description to validate it. Foreign rows are rejected. Handle both endpoint representations separately, with coincident sentinels interpreted as zero (then the actual F is zero). Empty counterfactual populations default to zero after validation. Per row there are O(n+1) circuit evaluations and one regeneration; the solver supplies at most n+1 rows per forecast. Run primitive_forecast_extractor.py --learner module:callable with public JSON fields n,F,S,bound for the separate three-outcome diagnostic. Its deterministic callback takes n,S, immutable history, and circuit. On arbitrary F the outcomes are an original verified assignment, B+1 incorrect forecasts on endpoint labels that every satisfying assignment would realize, implying UNSAT under the supplied mistake guarantee, or an explicit equivalent pair whose forecasts disagree. An arbitrary plugin has no automatic guarantee, and the built-in prefix backend does not answer arbitrary primitive-rewrite queries. Invalid backend outputs and insufficient caps are errors.

The producer constructs shared-DAG contexts and both substitutions. The independent checker matches a named rule and a common metavariable binding, reconstructing both complete ordered roots, including repeated uses of a single placeholder. The extractor checks both selected forecasts at the same state. verify_primitive_forecast_result.py --learner module:callable reads a JSON record containing independently supplied expected n,F,S,bound and a serialized result. It replays all committed errors, checks original witnesses, and independently validates the chain, endpoints and opposite forecasts for a fault. The UNSAT conclusion still requires the external bound. Reported cost fields are diagnostic. [Primitive rewrite theorem](primitive-gate-forecast-diagnostic.md)

With K=1+s+n² the O(K) steps use O(K) live nodes each. The global shared table has O(K²) bounded-arity records and the certificate uses O(K² log(K+2)) bits. The query cap is 256K NANDs, checked on every forwarded query. Indexed traversal and balanced-map interning give O(K² polylog(K+2)) random-access bit work. Charging a whole-table scan per interning operation gives a conservative O(K⁴ polylog(K+2)) bound for Python on producer-generated certificates. Add replay and learner costs. With m committed errors and L chain steps the program makes at most 2m+n+ceil(log₂(max(1,L)))+4 forecast calls, each with at most m previous rounds. It reports compact ASCII JSON input bits and charged replay lengths. These clocks are polynomial in numeric n and S.

For n≥1 the positive singleton formula F=[x=2^n−1] and syntactically distinct all-false a AND NOT a have the same exact traversal with the bundled predictor. After one committed F=1 the virtual population is 1,…,2^n−1 with b=1. At every false median the children are the two intervals strictly on either side of that median. A parent with 2^(n−d)−1 virtual points leaves children of 2^(n−d−1)−1 each. Only the far-left physical interval also contains the excluded anchor, and its final anchor-only child is pruned at budget exhaustion. Left-first traversal checks exactly 2^n−1 original nonanchor points. The singleton witness is the last one, with genuinely realizable feedback along its path. The all-false source exhausts the tree in either child order. The ambiguity depth is n−1. Finite controls exercised both sources through n=5, aliases at n=0, foreign rows, malformed and partially applied rewrite certificates, all three forecast outcomes and serialized-result tampering.
