# A short Boolean certificate for adjacent dyadic prefixes

Let F be a NAND DAG with s gates on n bits in most-significant-first order. Write N=2^n. For a binary word p let D(p) be the conjunction fixing the initial |p| coordinates to p, with D(empty)=1. Let B(t) be the disjunction of maximal aligned binary blocks in [0,t), each represented by its prefix cube, for 0≤t≤N. The empty disjunction is zero. Use Q(j)=F AND B(j+1), with the endpoints Q(−1)=0 and Q(N−1)=F simplified. Given 0≤j<N and F(j)=0, the following constructs a certificate of Q(j−1)=Q(j) with O(n+s+1) Boolean proof steps.

**Certificate model.** Use named Boolean DAG nodes and shared derived equations or implications. A step applies a fixed Boolean identity, transitivity, or substitution in one named gate. The implications below use only fixed truth-table tautologies of at most a constant number of Boolean metavariables per step. Prefix nodes split as D(p0)=D(p) AND NOT x and D(p1)=D(p) AND x for the next bit x. Names and shared steps matter for the size claim.

**Guarded evaluation.** Form the n+1 prefix nodes along the path to j, and let G=D(j). From G⇒G derive G⇒D(p) for every ancestor by projecting one conjunction at a time upward. Also project the bit literal from each nonroot node under this same guard. Thus each input wire has its value at j under G. Evaluate F at j in gate order. If the two predecessors have guarded values a,b, their NAND has guarded value NAND(a,b) by one of four fixed rules. This derives G⇒NOT F, hence F AND G=0. Constants, direct input outputs, and complemented outputs have the same constant-cost rules. At n=0 the guard is one.

**Prefix increment.** List the blocks of B(j) from left to right. They are the left siblings along the path to j for which that path takes a right edge, starting at the root. Associate their disjunction to the right, with a terminal zero. Replacing that terminal zero by G gives the disjunction of the old blocks followed by G; Boolean associativity and the identity for zero certify its equality with B(j) OR G in O(n+1) steps. For each trailing one of j, the immediately preceding block is the left sibling of the current rightmost cube. Replace D(p0) OR D(p1) by D(p), using the split identities. The changed subtree remains at the right end; the remaining outer disjunction can be rebuilt once from its shared prefix of block names. Concretely, first prove equality for the innermost two leaves, then for the next sibling joined to that suffix, proceeding outward. When the trailing-one run ends, propagate equality through each unused outer block once. The resulting list is precisely B(j+1): addition clears the trailing ones and makes the next zero a one; if all bits were one, the result is the root. No carry is needed at a zero final bit. The block lists, cube nodes, and proof use O(n+1) nodes and steps in all cases.

Substitute B(j+1)=B(j) OR G into F AND B(j+1), distribute the outer conjunction once, and use F AND G=0. This proves Q(j)=Q(j−1), including both simplified endpoints. With indexed wire references the certificate occupies O((n+s+1) log(n+s+2)) bits. A deterministic producer and checker take O(n+s+1) word operations with random access and O(log(n+s+2))-bit indices; a sequential bit-machine implementation by rescanning prior records takes polynomial bit time. The gate count uses shared prefix nodes along one path and its siblings. Writing each cube from scratch or expanding the NAND DAG into a formula has different costs.

This certificate concerns the specified dyadic circuit encodings. A state-wise forecast that respects these guarded identities and their substitutions through the whole derivation gives equal forecasts at this adjacent pair. An unrestricted predictor may distinguish even circuits connected by such a certificate. The construction assumes the public index j and decides only the point value F(j); it does not find a satisfying assignment or enforce forecast invariance.
