# Semantic circuit prediction characterizes P = NP

Give a deterministic online machine n and a public numeric gate cap s. Each query is an explicit at-most-s NAND circuit on one fixed hidden n-bit assignment, with literal and constant wires and fixed finite binary encoding. Its bit clock is polynomial in n+s+1 and the encoded query sizes, with a common exponent at all lengths. A statewise semantic machine gives the same forecast on two circuits at the same state whenever their functions on all n-bit assignments agree. Equivalently strong conclusions below hold if an additional polynomial in the encoded history is allowed in the per-round clock: all histories used for SAT recovery have polynomial length.

The following assertions are equivalent.

1. P = NP.
2. There is one uniform statewise semantic machine making at most n mistakes on every realizable stream for every n,s.
3. Such a machine exists with a known polynomial mistake bound B(n,s).

A witness is recovered from assertion 3 by the adjacent-prefix procedure on the original input formula, using s=|F|+O(n+1). Thus CircuitSAT is in P. This direction needs only the equality of adjacent prefix forecasts at false assignments in the states used by the procedure. Prediction requests on cloned states require at most O((B+1)(B+n+1)) elementary online invocations even if every transcript is replayed from initialization. Assertion 2 immediately implies 3. ## A deterministic semantic counter in a fixed polynomial hierarchy level

Here is an explicit forward construction. For a polynomial-time predicate on d bits with accepting set S and size M>0, define a score as follows. For k from zero through d ask whether some r=d+1 affine maps from the binary d-dimensional space to the binary k-dimensional space have images of S whose union is the entire target space. The quantifier string is existential over the r maps, universal over a target y, existential over an index i and input u in S with map i sending u to y. The witness lengths, including O((d+1)^3) map bits, and the deterministic predicate clock are polynomial. This is a uniform Σ₃ decision predicate. Under P=NP, every fixed level of the polynomial hierarchy equals P, by induction using closure under complement and replacement of an inner P predicate. No randomized subroutine is used to evaluate this decision predicate.

Take the largest accepted k and let the score be 2^k. Empty S is detected separately by an existence test and has score zero. For M>0, k=0 always qualifies. An accepted k has 2^k≤rM, because one map covers at most M targets. If 2^k≤M, a random affine map hits any fixed y with probability at least one half. Indeed, its indicators on distinct inputs are pairwise independent, their sum X has mean μ=M/2^k≥1 and variance at most μ, and Cauchy–Schwarz gives Pr[X>0]≥μ²/E[X²]≥1/2. For r independent maps, the chance some target is missed is at most 2^(k−r)<1. Consequently M/2 < score ≤rM (with the harmless lower weak inequality also sufficient). The yes/no map-cover property depends on S as a subset of the fixed binary domain. Equivalent predicate descriptions have exactly the same score, even when several approximations to M would be allowable. Existence by random maps suffices; no map has to be found.

At most n mistaken rows need to be stored on a realizable stream. Given the current candidate assignments implied by all stored rows and the new circuit C, let S_i be the candidates with C(x)=i, N_i=|S_i|. Set h=n+1, t=64h² and d=nt. Score the two t-fold powers S_i^t in d bits and predict the greater score with fixed ties. On error store the new circuit and its label. If an inconsistent history empties both bins or exceeds n errors, a persistent semantic default is allowed. The property is statewise semantic even if the current circuit encoding changes: the same feasible set and the same pointwise output yield identical sets S_i^t in the very same coordinates. The past transcript need not be canonicalized.

On a realizable error the true bin is nonempty. Its score is positive, so the predicted bin is also nonempty. Comparing scores gives N_true^t≤2r N_pred^t. On an error the surviving fraction is at most (2r)^(1/t)/2, because N_true/N_pred≤(2r)^(1/t) with right-hand side at least one. After h errors the mass would therefore be at most (1/2)(2r)^(h/t), strictly less than one. In detail r=d+1≤65h³ and log₂(2r)≤8+3 log₂h≤11h for h≥1, so h log₂(2r)/t≤11/64<1. The true assignment survives. Input probes reading n fresh coordinates can force n mistakes, so the coefficient one is exact.

The n+s+1 clock is uniform. Only n+1 evaluation rows on each of t explicit n-bit inputs need be checked; d+1 map-cover tests per bin, each on polynomial-length inputs, suffice. Counts need at most d+1 bits. No circuit minimization, advice, or stochastic choice of correct answers is required. The construction works also for n=0.

There is an alternative using Stockmeyer's theorem that a #P function has a deterministic fixed-factor approximation in Δ₃. To remove arbitrary dependence of a gap algorithm on syntax, choose the shortest encoded equivalent circuit of size at most s and then the lexicographically first of that length. Testing whether a fixed description prefix has a legal completion of a given length equivalent to the input has an existential circuit description followed by a universal n-bit assignment; under P=NP this is uniformly in P. Enumerate lengths up to the input's encoding length, and select each bit by this test under one fixed injective encoding. This uses polynomially many polynomial-time tests including syntax and gate-cap validation. Apply the same deterministic approximate counter and fixed ties to these canonical current descriptions, with canonical past descriptions or a fixed past state. The t=4(n+1) amplification in the earlier learner proof gives the same exact n bound. [Stockmeyer's primary paper](https://doi.org/10.1137/0214060) [Product amplification proof](affine-probe-online-prediction.md)

This characterization concerns statewise semantic forecasts on arbitrary circuit descriptions. It does not establish that a learner for the three-literal evaluator makes congruent predictions after different adaptive gate registrations. The eight-bit finite example distinguishes those requirements.
