# A semantic converse for prediction with bounded mistakes

Fix one uniform deterministic polynomial-time predictor for n-bit circuit queries with public NAND cap s and a known polynomial mistake bound B on streams evaluated at one common original assignment. A state can be cloned by replaying its labeled history. Take s equal to the source formula's normalized NAND size plus O(n+1) comparator gates. The signed-literal gate transfer gives B=n under its local all-wrong premise. This section identifies a separate property of the transferred predictor. [Gate transfer](forced-gate-mistake-transfer.md)

## Witness or conflicting forecasts on equivalent circuits

Order the N=2^n assignments as integers. Set Q(−1) to the constant zero circuit, Q(N−1) to the supplied formula F, and Q(j)=F AND [x≤j] at interior indices. At any reached state write P(C) for the prediction on description C. Assume initially only the mistake bound.

Read P(0) and P(F) on separate clones. If P(0)=1, commit the query 0 with label 0. Otherwise if P(F)=0, commit F with label 1. On a satisfiable input these committed steps are genuine errors on the same fixed satisfying assignment. If neither case holds then the forecasts at the two endpoint indices differ. Bisect the interval, reading each middle forecast on a new clone and keeping endpoints with different values. After n bisections the endpoints are j−1 and j. Their forecasts differ. Evaluate F(j). If it is 1, return the verified witness. If it is 0, return the two queried descriptions and current transcript: the descriptions compute the same function because they could differ only at j. This last statement includes the two endpoint conventions. Reject after B+1 committed errors.

Thus on each satisfiable F the procedure returns a witness or finds an explicitly certified violation of representation invariance. Sufficient for deterministic SAT decision and witness search is the following forecast congruence: on satisfiable F, in states reached above, P(Q(j−1))=P(Q(j)) whenever F(j)=0. Under this hypothesis reject on a failed witness check. Full extensionality of each reached state's forecasts implies congruence. Voting over assignments is an example of an extensional rule even where its predictions cannot be represented by evaluation at one assignment. Monotonicity along the indices is unnecessary. At most 2(B+1)+n+O(1) predictions are needed and their replay histories have at most B+1 supplied circuit/label pairs. Public gate and transcript encoding costs are polynomial in n+s+B+1. The procedure includes n=0.

For the fixed local evaluator write T for a committed local transcript at length H=n+(n+1)s. Let R(T,C) be the ordered fresh-register queries and opposite feedback obtained when the transfer compiles the precise NAND circuit C, including its prediction-dependent polarities. Write out(T,C) for its corrected output-literal query. The needed condition on the original machine is equality of its predictions at (T R(T,Q(j−1)), out(T,Q(j−1))) and (T R(T,Q(j)), out(T,Q(j))) whenever F(j)=0, for the committed T constructed above. This formulation compares trials with possibly different lengths and different numbers of unused registers. Each trial extends every original assignment compatible with T by one unique choice of the newly used registers and has the same output function of x at equal circuit semantics. The machine is free to inspect the raw histories. Canonical truth tables for each single literal-slot probe do not identify these different triangular extensions.

## An efficient predictor blind to the unknown truth table

Check a public anchor z first; if F(z)=1 a witness is already available. Assume F(z)=0. A query on a secret x now accesses F only through b=F(x). Its description lists n-bit cutoffs t and a Boolean circuit which takes b and the comparisons [x≤t], outputs an (n+1)-bit affine form description, and returns that form evaluated on x. Constant-form outputs include arbitrary Boolean circuits of the comparisons and b. Queries can also read individual coordinates and parity, and their order is unrestricted.

Use all virtual pairs (u,b) except (z,1). There are 2^(n+1)−1 possible pairs, including every genuine (x,F(x)). Predict a majority of surviving pairs with fixed ties and condition only on mistakes. After n+1 mistakes fewer than one pair would survive. Define persistent default 0 for counterfactual histories that empty the family. The procedure uses no description of F and all transcripts, even on restarts and invented labels, are identical across predicates with this anchor.

For each prediction collect the thresholds in the at most n stored mistaken queries and the current query. Partition the integer domain at the cutoffs plus one. For each interval and b, evaluate the public query circuits to get explicit affine forms. Impose all stored labels and the proposed new label as affine equations. Each interval is the disjoint union of O(n+1) binary-prefix cylinders. On each cylinder count by Gaussian elimination: a consistent joint system of rank r has 2^(n−r) solutions. Test (z,1) against the constraints and subtract it once if counted. Counts use O(n+1) bits. The full bit clock is polynomial in n and the total size of these at most n+1 queries.

In particular a deterministic extractor allowed any such predictor transcripts plus direct point evaluations of the opaque predicate requires N−1 worst-case evaluations to decide identically zero versus a singleton away from z: run on zero, then choose an unqueried nonanchor as the singleton. This concerns opaque predicates. A SAT solver can inspect the input circuit. Without any excluded pair, the blind learner for the union over all predicates must endure n+1 mistakes on some realizable stream: query the n coordinates and b with opposite feedback, then choose the resulting u and any F with that value of F(u).

## A false adjacent crossing after canonical local gate registration

Here is a literal failure of bisection under a legal local predictor when forecast congruence is dropped. Let n=2, s=2, H=8. Name the original high and low bits a,b and take F=b. The initial client state has no committed queries. Use the zero-gate F and the following explicit normalized interior circuits, allowing a complemented output wire. Q(1)=b AND (NOT a) uses one NAND then complements its output. Q(2)=b AND NAND(a,b) uses two NANDs then complements the final output. They compute the same function, accepting only 01.

At length eight use exact halving of the genuine physical words, conditioning on every label. On ties predict one for a nonconstant literal query and zero otherwise. Modify only this node, specified by the Boolean functions of the raw probes so local spellings are treated identically. Write r,t for the first two reserve bits. The first two probes from reset must be r XOR (a AND b), then t XOR (b AND r), both with feedback 1. At their successor predict 1 on NOT t. Use ordinary halving after that answer. A physically impossible history can default.

Both prefix probes halved the words and were mistakes. After both labels 64 genuine words remain, with NOT t equal to 1 on exactly 16. The alternative prediction costs at most one error on a zero label, leaving 48 words and at most five more halving errors. A one label leaves 16 words with room for four more errors. All branches stay within eight mistakes. Q(1)'s first probe differs even semantically from Q(2)'s.

The transferred initial forecasts on zero and F are 0 and 1. Q(1)'s one gate gets forced feedback 1 and its output is predicted 0. Q(2)'s two gates get forced feedback 1,1 and its output is predicted 1. Bisection reads indices 1 and 2 and reports the false crossing at 10. The source is satisfiable and every individual raw forecast is canonical under local truth-function equality. Extending the finite rule by exact halving at other lengths gives an information-theoretic local learner. If a uniform polynomial local learner satisfying the all-wrong premise exists, using that learner at lengths other than eight gives a uniform polynomial example satisfying the same premise. Canonicalize each query given to the latter learner by its function on its at most three variables, retaining an equivalent literal-slot spelling; realizability is unchanged. Finite splicing disproves automatic congruence without settling the unrestricted premise.

More generally a publicly designated fresh-register prefix registering F with at least one NAND output consumes g coordinates and at most g mistakes, leaving n original coordinates and r unused coordinates at H=n+g+r. Predict zero at each designated gate. Given its feedback, each original and remaining free assignment extends uniquely. An early departure can switch to exact halving of the true remaining words, of size 2^(H−i) after i labels. At the end let the final corrected register encode b freely, retain the actual earlier registers, exclude (z,1) and allow all r remaining bits. The resulting (2^(n+1)−1)2^r virtual physical words cover all genuinely possible words. Halving thereafter has at most n+r mistakes, including on probes of old registers. Extra publicly identified fresh gates on (u,b) can consume one independent coordinate and one forced error each before their output is queried. This is an information-theoretic strategy for designated registration phases; arbitrary raw continuations have no established polynomial fallback clock. The efficient opaque-threshold counter uses the supplied threshold syntax.

After conditioning on a positive label for exactly-one on three bits, ordinary exact majority predicts coordinate values 000 while predicting one on the predicate. Such an improper majority rule is extensional. The raw finite splice instead breaks representation invariance across gate registrations. Unrestricted polynomial local avoidance and the general syntax-sensitive converse remain unresolved.
