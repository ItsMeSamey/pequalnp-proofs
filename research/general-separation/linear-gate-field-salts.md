# Linear-gate salt evaluations and constant-probability witness recovery

Let C have n≥1 binary inputs and s bounded-fanin Boolean gates. Fix the prime p to be 2 or 3, and let q=p^k be the least such power at least 8(n+1). Hence 8(n+1)≤q<24(n+1). In the field F of this size write

    P_C(z)=Σ_{x:C(x)=1} ∏_{i:x_i=1}z_i.

The coefficients are all one on distinct monomials; there is no cancellation between distinct witnesses at the level of formal polynomials. On independent uniform z_i in F× the chance P_C(z)≠0 for satisfiable C is at least (1−1/(q−1))^n≥1−n/(q−1)>7/8. This follows by induction on variables, conditioning on a nonzero coefficient of the final univariate polynomial, which has degree at most one. The same success holds for the two-weight version in dense-parity-verifier-code.md on uniform unrestricted points by its total degree bound. For strict bounded random time, pick a uniform integer in a power-of-two range ≥2n²(q−1) independently per exponent and reduce modulo q−1. Each salt tuple has probability at least (1−1/(2n²))^n times its exactly uniform probability, giving constant success including small n. Field representation, primitive element, exponent tables and all gate descriptions can be computed in poly(n+s) bit time by direct enumeration since q=O(n).

## A weighted sum with hardwired coefficients

For m=O(n) and integers a_i of O(log(n+2)) bits, the unsigned sum Σ_i a_i x_i has an O(n)-gate circuit for the stated constant bit-width multiplier. In particular the implicit constant is absolute when m=n and 0≤a_i<q. Use b=max(1,floor(log₂(n+2)/2)). Divide the padded binary representations into O(1) blocks of b bits. For each block and every b-bit value t, collect all x_i whose hardwired block has that value. These groups partition the inputs for this block. Compute all their population counts with O(n) total gates: for each group of size g a carry-save network replaces triples in each bit column with a sum and carry, reducing the total wire count by one per full adder. Finish the at most two remaining rows by a ripple adder on O(log(g+2)) columns. Each nonempty group costs O(g) gates; empty groups contribute zero.

There are O(sqrt(n)) block values. Each group count is multiplied by its fixed b-bit value, shifted to the block position, and accumulated in a word of O(log(n+2)) bits, the maximum sum being n^{O(1)}. Schoolbook binary multiplication and addition on these widths cost O(log²(n+2)) gates per value. Thus all postprocessing totals O(sqrt(n) log²(n+2))=O(n), over all O(1) blocks. Constant-size cases can be hardwired. Reducing the result modulo the fixed q−1 by binary long division costs O(log²(n+2)) gates. Fanout is unrestricted. This is a circuit with hardwired weights, uniformly constructible from their values; the proof does not treat arbitrary coefficient inputs as free gates.

## Counting and search

For fixed z, write z_i=β^{a_i} using a fixed generator. Every selected product is β^j where j is the modular sum above. For each one of the k base-p coordinates of that power, compute its digit by lookup on the binary bits of j. Each one-bit output costs O(q) gates by a full binary multiplexer tree (pad the list to a power of two). At p=2 intersect the digit with C(x), count modulo two, and obtain the respective P_C(z) coordinate. This test has the original n primary inputs and s+O(n) gates. At p=3, two output bits encode a ternary digit 0,1,2. Use one additional witness bit w, allowing respectively zero, one or both choices; then count modulo three. This test has n+1 primary inputs and s+O(n) gates. Applying the prior paired cubic reduction gives one exact residue query with O(s+n) variables and gates and known invertible scalar. For the two-weight version, separately forbid assignments selecting any zero factor and replace those zero weights by 1 when forming logs. The nonzero products contribute a fixed exponent offset plus Σ_i a_i x_i modulo q−1; the offset and guard cost O(n) extra gates.

All k field digits give the exact field value. If nonzero, successively restrict the original assignments by pinning a bit of x to 0 or 1, while using the same weights in every query. The two child weighted sums add to the parent. Query the first child; when it is zero retain the other, and otherwise retain the first. Pins cost at most O(n) gates. With correct counts, after n steps the resulting x is satisfying and can be verified directly. This works for even or three-divisible original witness counts. It gives an O((n+1)log(n+2))-query one-sided randomized search reduction with poly(n+s) construction overhead and constant success on every satisfiable input. The initial digit queries are nonadaptive, while the search queries use the branch decisions. It does not require deriving an NP witness from a bare YES response of the original predicate, or changing salt after restriction.

For a hypothetical deterministic parity-CircuitSAT solver on n inputs and ≤B n log n gates, any fixed smaller input gate coefficient leaves room for O(n) extra gates. A 2^{n−ω(log n)} solver retains a superpolynomial saving under these polynomially many calls with s=O(n log n); stronger savings retain their order whenever they dominate logarithms. For the paired modulo-three model the oracle size parameter is the number Q=O(n+s) of variables in the compiled instance, not n; for example a poly(Q)2^{A Q/log Q} solver would give a randomized constant-fraction saving at a sufficiently small fixed B. October's actual fixed-density #3SAT bound after ordinary Tseitin compilation gives the existing 2^{O((n+s)/sqrt(log(n+s)))} size-based clock. These reductions do not establish the stronger oracle solvers, and a randomized witness algorithm with possible false negatives is insufficient for the deterministic hierarchy simulation.
