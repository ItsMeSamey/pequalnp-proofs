# A connected strict source with a private guard gadget

Start from a simple cubic graph on N vertices with a packing of disjoint triangles covering its vertices (for instance a triangle replacement of a cubic base). Use N comparable to the full bit-variable and occurrence counts of any strict 3SAT core C, which may itself be disconnected. Ignore undeclared positions in numbering and densify the core. Orient every graph edge uv arbitrarily. Give it three private variables a,b,c. Write each listed binary clause first, followed by the specified graph guard as its third literal:

| guard | first two literals, as disjunctions |
|---|---|
| −x_u | (−a,b), (−b,c), (a,c) |
| −x_v | (a,−b), (b,−c), (−a,−c) |

U, the six unguarded rows together, enforces a=b=c and a≠c. The u half has model 111 and the v half has model 000. Thus 11 on the endpoints is impossible; on 00,10,01 respectively set the private triple to 000,111,000. These choices also define a section in which all three private bits equal x_u. Other feasible choices need not be unique.

For every w add a row (−x_u,−x_v,x_w), choosing w-v-u a simple graph path with all three vertices distinct. These rows hold for every independent set, and ensure both polarities of each graph variable. Add three fresh marker variables t with one clause (t1,t2,t3). For each marker or core variable y add (−x_u,−x_v,y) and (−x_s,−x_h,−y) on two different graph edges uv,sh. Spread attachments so the number per edge is bounded. These rows are implied by independence and make every variable occur in both polarities. Every clause has width exactly three. The incidence graph is connected because each edge gadget links its graph endpoints and the attachments link every other variable. Core SAT iff combined SAT: project to the core in one direction, and take x=0, private bits zero, markers 111 in the other. If C is satisfiable, the full projection onto graph variables is exactly IS(G). Arbitrary decision preprocessing can still isolate C or project out the constant-size gadgets; the theorem concerns representation parameters, not a time lower bound.

No edge gadget has duplicate scopes. No assignment to one external shared guard simultaneously deactivates them as in a shared-pad construction. No renaming makes the formula Horn: deletion of the graph literals from any Horn-renamed gadget would leave six Horn clauses on the private variables. A pair excluding complementary corners is Horn only if its two excluded corners are 01 and 10; thus all three parity relations would become equalities, contradicting their inconsistency. For the exact source-coordinate chart, the marker clause's untouched support has a singleton forbidden ternary. More generally, on SAT inputs fix one core solution, x=0 and all private bits zero. The marker 3-flat has exactly seven feasible points. Each nonempty exclusion induced by a width-two clause of affine forms has codimension at most two on that flat and hence size at least two. Affine seed equations also cannot omit just one point. This rules out *every* conjunction of affine-coordinate 2-clauses on this cube, even with unboundedly many affine forms; it makes no claim about existential lifts or branch-conditioned charts.

The projected active-rank and private-pair codimension arguments of paired-source-coupled-obstruction.md apply unchanged on YES because the positive-record readouts attain exactly IS(G). For the signed dictionary, take graph edges pairwise at graph distance at least five, of which there are Ω(N) by cubic bounded-degree greedy packing. Freeze graph variables outside these edges to zero, one core solution, a legal marker assignment and canonical physical dummies. On legal matched corners use the private section above. Each single equality triple reads at most one live bit. An edge-gadget OR sees two initial signed private bits depending only on x_u, followed by one guard bit. For a matched edge the last physical marker retains the guard bit; its three legal corners have either pairwise distinct records, or a repeated record at equal final bit, or (when the guard is x_u) dependence only on x_u. For nonmatched gadgets at most one bit is active. Each attachment or path row sees variables from at most one live edge. On this section each literal reads a constant, a live coordinate, or its complement. The fixed DFA buffers both earlier signs until the third marker. Its macro and first-byte records expose the buffered signs and the current marker bit; the remaining marker bytes retain the current bit after the reset at the third sign. Accordingly a record retains an identifiable subset of signed coordinates. This holds even when the first two negatives already guarantee satisfaction. Core rows are constant. On legal corners 00,10,01 each injectively encoded record is thus constant, depends on one axis, or distinguishes all three corners. Its unique affine interpolation to the fourth corner has respectively full/empty, axis-aligned or singleton fibers: in the last case the two code differences are linearly independent over the binary field. These fibers are rectangles across the two axes. The affine section through all legal assignments belongs to the base since legal points affinely span the parameter cube; a forbidden corner cannot be a feasible completion, by the source projection and graph-variable equality readouts. Each intersection in the canonical whole-record dictionary restricts to a rectangle, giving the tensor rank bound 2^Ω(N). With graph size chosen linearly in core occurrences, all source variables and rows remain O(N). Dense names cost logarithmically many bits per occurrence.

The planar matching frontend on this same source has one explicit demand per input row. Its cycle-cactus construction therefore has Ω(N) such demands, all with three distinct phase variables. This counts the parameter charged by the direct inclusion-exclusion upper bound, without claiming a lower bound for all FKT algorithms or optimizations. Any full-portfolio conclusion must independently account for the centered algebra solver's precise transforms and preprocessing, search costs, output witness shortcuts and residual branching.
