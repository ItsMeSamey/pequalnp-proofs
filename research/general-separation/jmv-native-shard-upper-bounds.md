# Constructive upper bounds for parts of a native unary JMV witness

Fix the native labels and right-zero padding in the [unary prefix analysis](jmv-native-unary-prefix-cover.md). The source input is the known string 1^n, the reduction uses a fixed machine, r=2, and log₂ T=n+O(log n). An ordinary circuit for a shard takes the suffix of a variable label after a fixed prefix and returns its assigned bit. Separate three resources: gates computing an address, access to the value at that address, and gates implementing the value lookup. The bounds below are for a compatible extension of any supplied satisfying computation and routing settings. They make no claim about the lexicographically first assignment under a different naming convention. [Jahanjou, Miles and Viola, revision 3, Theorems 5, 7, 11, 12 and proof of Theorem 1](https://eccc.weizmann.ac.il/report/2013/099/revision/3/download/)

## The entire fetch region has a polynomial-size bit circuit

Theorem 11 uses only Copy and the two constant gate types. Its native address has fields (t,p,k,d,i,c). The p string has about n/2 bits; k selects the segment. The counter-machine configuration c has O(log n) bits, including its timestep. On a nonfinal Copy transition the counter update depends on c, not on p or k. The counter may request a cyclic shift, which updates p and the segment k. At a final counter in the rightward phase the update masks the data by the selected segment of the fixed input, sets the direction to left and reinitializes the counter from i. At the next final counter it chooses a terminal constant from the data. These distinguished direction changes are tested by the control fields, independently of whether the p string is one-hot. Use the pinned finite-tag and dummy conventions also on malformed labels.

Fix i. Within either direction, there are at most K=2^|c|=poly(n) counter states. If a walk does not reach a final state or terminal within K+1 steps of this phase then a counter repeats, so it cannot reach a final state later in that phase. Repetition of the **whole** p string is unnecessary. There is at most one right-to-left reset. Thus every terminating fetch walk reaches its constant within 2K+O(1) steps; this includes malformed starting counter or data fields. A circuit unrolls that many applications of the actual child map, tests type, and latches the first terminal value. It returns zero on an unterminated walk. In that case the child also has an infinite nonterminating Copy walk, so this convention satisfies each Copy equality; JMV additionally rules out cycles with its timestep encoding. The two distinguished constants retain their prescribed values, and all designated out_i terminate at the prescribed input bit by Theorem 11. This total extension does not treat a non-one-hot data field as an input bit.

The transition map and designated addresses are uniformly constructible in poly(n) by Theorem 11. At r=2 its output bits have constant-depth decision trees, and the complete label has O(n) bits. Construct the unrolling in deterministic polynomial time and then hardwire any shard prefix. Padding tests, segment padding for rounding, and dummy constants cost polynomial size. No witness table, accepting path or sorting controls enter this construction.

## Local checks given their actual records

For a row indexed by i and a fixed checker family j, provide the actual two records z_i and the jth routing network's ith output record. Each has O(log T)=O(n) bits. A valid routing sends the latter to the specified partner z_{π_j(i)}. Theorem 12 supplies fixed logspace-uniform local circuits of size polylog(T), and the local labeling in the proof of Theorem 1 uses only O(log log T) bits for the within-copy gate identifier. Consequently a row has poly(n) possible gate names, including the local-uniform conversion's extra gates. Enumerate those names and their child relations. Treat the named input records and fetch outputs as boundary values; evaluate the acyclic local graph in topological order and select the requested gate by its identifier. Theorem 5 treats off-computation local labels in the acyclicity proof. Where a primary is genuinely free, fix it consistently, for example to zero when it is not an underlying record or routing control. Use the actual type and child rules for wired Input and x-Oracle gates. This is a polynomial-time uniform circuit construction with the two records as additional inputs. The local output of a satisfied check is one, but that fact alone does not determine its internal wires.

If two addressable circuits supply the records at row i, the local shard composes with them at their actual sizes. If the data are supplied instead as unit-cost dictionary accesses, the conclusion is a polynomial-size *oracle* procedure until that dictionary is implemented. Even knowledge of z_i alone does not determine a verifier row whose second input comes from an unknown routing decision.

For the sorter itself, given actual switch settings and initial records, one ordinary valid output bit can be recovered by tracing the selected incoming edge through the O(log T) columns of the fixed network. Each internal bit switch is constant size. A query inside such a switch needs at most two incoming data bits, each tracing a single selected predecessor path, besides the local control. A dummy path returns zero. This costs polynomially many address operations and dictionary queries; it yields polynomial gate size if the dictionaries themselves have polynomial-size circuits. It does not compute a valid routing setting from its row index or from the network topology. The same distinction applies if the routed output records are provided directly instead of switch settings.

## Unconditional table ceiling and its scope

Fix 0<β<1/2 and b=floor(βn). In a configuration, sorting or local region shard, after the constant tags the b-bit prefix fixes b−O(1) high bits of the first long row identifier. The remaining row bits and all short fields together have length at most (1−β)n+O(log n). For any fixed compatible assignment, an ordinary binary multiplexer tree on the remaining relevant address bits with hardwired data therefore has size 2^((1−β)n)poly(n) per shard. For a local shard one may equivalently store the two actual records per addressed row and compose the polynomial verifier above. A generic sorter shard can store its own gate values directly: a traced path might visit switches in other prefix buckets, and a small local control table alone gives no such global access. The shorter fetch labels already have the stronger uniform upper bound. Right-zero padding and reserved labels are checked separately with polynomial overhead; unused names may be set to zero and any required true dummy is set to one. There is no exponential penalty from treating right-padding bits as additional table dimensions.

This fallback counts hardwired bits or gates, not the time to discover their settings. It requires an existing accepting computation and compatible routing to instantiate witness data. Neither polynomial-time record evaluation nor a uniform polynomial-size implementation of arbitrary accepting switch settings follows from the local reductions or the small number of shard-prefix triples.
