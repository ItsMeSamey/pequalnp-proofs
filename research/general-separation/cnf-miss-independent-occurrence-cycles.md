# Full failure-column rank on a parsimonious bounded-occurrence SAT family

Start with a strict 3-CNF on n declared variables, with m clauses of exactly three literals on distinct variables. In this construction the variable universe is listed explicitly, or its arity is charged in unary. Preserve unused declarations. With only a binary arity header, use the modified construction below. For variable i with t_i occurrences put h_i=max(3,t_i), introduce h_i distinct copies in a directed cycle, and add each implication from a copy to its successor as a binary clause. Use a separate copy for each literal occurrence in the original ternaries, retaining its polarity. Surplus copies have no ternary occurrence. This use of implication cycles is the standard bounded-occurrence variable-splitting construction; the rank conclusion here follows directly from the actual clause supports. [Tovey, A simplified NP-complete satisfiability problem](https://doi.org/10.1016/0166-218X(84)90081-7).

There are N=Σh_i variables and M=m+N clauses. Since Σt_i=3m, max(3n,3m)≤N≤3m+3n. The literal count is exactly 3m+2N. Each copy has one incoming and one outgoing implication and at most one ternary occurrence. Every directed cycle enforces a common bit: once any bit is one the implications force all its successors to one. Choosing that bit independently for every variable, including unused ones, gives a bijection of satisfying assignments, with the original witness recovered from any designated copy per cycle. This includes the empty declared-variable case whenever the strict syntax permits it.

Associate to each clause its failure indicator over F₂. In the unique multilinear polynomial on the Boolean cube, a width-d clause on distinct variables has precisely one degree-d monomial, the product of its d variables, with coefficient one regardless of polarity. In a linear relation among failure indicators, the degree-three monomial of each rewritten ternary forces its coefficient to zero: different occurrence triples have disjoint variable sets, and binary implications cannot contribute degree three. Among the remaining binary columns each unordered edge of a cycle has a unique quadratic monomial. The minimum cycle length of three excludes the opposite directed edges on the same unordered pair that a two-cycle would introduce. Different variable cycles are disjoint. Every binary coefficient is therefore zero. Thus the raw failure columns have rank M on every output, whether satisfiable or unsatisfiable. All same-width supports are distinct. A binary implication's two copies belong to one original variable, so its support cannot lie in a strict ternary either.

**Binary arity convention.** If the declared universe is [n] with only n written in binary, n may be exponentially larger than the bit length. Collect and sort the s distinct occurring source indices. Build cycles only for these s variables, retaining surplus cycle positions where t_i<3. Use consecutive output labels for the N_live=Σ_{t_i>0}max(3,t_i) cycle vertices. Set the output binary arity to N_live+(n−s); the trailing n−s labels are declared but occur in no clause. This construction emits m+N_live clauses and has polynomial bit size and construction time in the original binary encoding. Pair the jth unused original variable in increasing order with trailing output label N_live+j. This mathematical bijection preserves the exact factor 2^{n−s} without writing exponentially many declarations, assignments, or clauses. Even random-access translation of a named unused original index uses only its rank among the sorted occurring indices. Rank of the failure columns remains the emitted clause count because the indicators ignore the trailing variables. Verification can guess just the occurring bits for SAT or for an evaluation minor; unused bits may be fixed to zero for decision. If the target instead requires every variable to occur and forbids implicit unused coordinates, this compressed variant does not apply. In that model an explicitly written polynomial-size bounded-width target has too few occurring variables to preserve 2^n models of an empty source with exponentially large binary arity.

For ordinary decision hardness use the standard NP-complete exact-three-distinct-variable source (shorter clauses can be expanded by all polarities of fresh variables for decision purposes). The reduction from that source above is parsimonious with respect to the declared original variables. No parsimony claim for the preliminary width-padding step is needed. SAT remains NP-complete on the image as a promise restriction distinguishing its YES from NO instances, and the broader restricted language of satisfiable width-at-most-three, occurrence-at-most-three, full-rank formulas is NP-complete as well: independence has a polynomial certificate consisting of M Boolean assignments giving an invertible M-by-M evaluation minor. This is an obstruction to clause-rank compression on these inputs and makes no claim separating P from NP.
