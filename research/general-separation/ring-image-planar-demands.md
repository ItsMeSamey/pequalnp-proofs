# Planar perfect matchings with additional positive demands

[decide](ring_image_planar_demands.py) accepts the four ordered physical fields of the selector-free image. It reconstructs the source, recognizes negative binary conflicts, and checks the named-edge inverse of their line graph using the [matching backend](ring_image_clique_matching.py). Other clauses must be positive. Its domain requires a simple bipartite planar reconstructed root and an explicit positive clause for each vertex star. A single-edge component has two identical stars, satisfied by the same clause. Recognition uses this particular certified root, including the claw realization of a triangular conflict component when returned by the inverse algorithm. An unsupported source returns unknown; malformed ordered images return off_image.

The conflicts make each source model a matching, and all stars make it perfect. Each positive demand contained in a star requires the matching edge at that vertex to belong to the demand. Delete the other incident edges. A singleton forces its edge at both endpoints. In a bipartite simple graph every nonempty pairwise-intersecting set of edges has a common endpoint: if two meet at v, an edge intersecting both away from v would complete a triangle. Delete simultaneously for all these demands, retaining the original vertex set. For the other demands intersect each with the surviving edge set, remove duplicates and supersets, and call their number d. An empty demand makes the count zero. A matching satisfies all remaining demands precisely when it misses none. Inclusion–exclusion over all subsets of these d demands calls a perfect-matching counter on graphs obtained by deleting all edges in the selected demands. Clauses may overlap or cross components.

## Signed matrices

Compute a combinatorial planar embedding separately for each connected root component. Enumerate faces as orbits of directed edges in this embedding. A bridge is traversed twice on the same facial boundary. Prescribe the product of signs around every face except a chosen outer face to be (−1)^(l+1) for boundary walk length 2l, counting repetitions. Form the face dual, omitting self-loops from bridges. Its underlying graph is connected, including the case of one face. Choose a rooted spanning tree, give all primal edges initial sign +1, and process leaves before parents, flipping the edge to the parent when the current face equation requires it. That flip toggles exactly these two faces. This satisfies all the prescribed equations; on a tree no flips are needed.

For a simple cycle C of length 2l, multiply equations on the faces inside C (the chosen outer face lies outside). Interior edges occur twice, including bridges. The aggregate sign exponent is l plus the number of interior edges plus the number of interior faces. Euler's disk formula makes the latter two counts sum modulo two to one plus the number of strictly interior vertices. When C alternates between two perfect matchings, its boundary vertices are matched along the cycle and its interior vertex count is even by planarity. The sign product on C is then (−1)^(l+1), exactly the sign of changing the determinant permutation by that cyclic exchange. The symmetric difference of two perfect matchings is a union of such alternating cycles, so all perfect matchings have the same determinant sign. This argument is componentwise and requires no nonzero reference determinant. [Kenyon, Lectures on Dimers](https://arxiv.org/abs/0910.3129)

Choose the two color classes as matrix indices. If their total sizes differ there is no perfect matching. In a square matrix the determinant expansion enforces every vertex even if different disconnected components have opposite color imbalances. The absolute determinant counts perfect matchings, including zero. Removing edges on this same vertex set only removes permutation terms, hence reuses the original signs. Use exact fraction-free elimination with pivot row swaps; the absolute value discards the permutation factor from the swaps. The zero-dimensional determinant is one.

## Witness, physical residue and cost

Compute the exact integer model count C. If positive, consider each surviving edge once and permanently delete it whenever the inclusion–exclusion count stays positive. At the end every retained edge is necessary and at least one feasible matching exists, so the retained set itself is a feasible perfect matching. Check its bit assignment against every recovered source clause. Return that assignment, C and the actual physical residue (−15)^E C modulo 3^k, where E=k−a−1 and a is source arity. The ring reduction's precision guarantees this residue is nonzero. If the count vanishes return both count and residue zero.

With h allowed edges before witness extraction, the preflight bound is (1+h)2^d determinant calls. An insufficient nonnegative max_determinants yields unknown with this reserved worst-case bound and the available cap. Elementary zero tests may return before preflight. With the default uncapped setting the recognized class is decided exactly. The cap prices calls, not elapsed time or scratch memory. Computing a planar embedding, signing it and recognizing the physical image take polynomial time. Each determinant takes O(v³) fraction-free integer steps on at most v root vertices. Hadamard bounds minors by exp(O(v log(v+1))), and exact products/dividends have polynomial bit length. The inclusion–exclusion sum has O(d+v log(v+1)) bits. All masks and matrices are processed sequentially in polynomial space. Thus total bit time is 2^d poly(B) for physical input bit length B including full reconstruction, witness extraction and physical arithmetic. In particular d=O(log B) gives a deterministic polynomial bound independent of demand widths. Python 3.10+ and NetworkX are required.
