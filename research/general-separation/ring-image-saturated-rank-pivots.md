# Decision by saturation and rooted rank pivots

The [adapter](ring_image_saturated_rank_pivots.py) exports solve_source_sparse(arity, signed_clauses) for signed one-based source rows and decide(n, clauses, point, k) for the four original ordered physical fields. On the image, zero and nonzero denote vanishing and nonvanishing physical value. This equivalence uses the selector-free compiler's normalization and precision. A nonzero result includes original true_ids (all others false); the physical entry also supplies the complete source assignment. The adapter checks it on every input source row, before simplification. It returns neither an exact number of models nor a physical residue. For both, use the [complete saturation counter](ring_image_binary_saturation.py).

For normalized width at most three, run [binary span saturation](cnf_binary_span_saturation.py) on the original source. On each current binary-background assignment a newly admitted short miss is a GF(2) combination of residual misses. Hence no original model can falsify the new row. All batches preserve the exact set of models. Drop tautologies, repeated literals and duplicate rows; otherwise send the **entire** original formula plus every derived row to the [compression donor](source_remote_pivot_rank.py). Restricting this input to a previously chosen rank basis could erase candidate row-to-pivot associations and change the donor's choices. The strengthened short rows become the donor's mandatory binary background.

The donor obtains a binary-background model as its root. Its discovery phase tests the three singleton-true assignments of each triple using binary feasibility. A missing singleton permits one common binary projection. Otherwise it explores implications from all three singleton choices: opposite forced values of a named pivot on two distinct singleton choices yield a possibly different binary projection in each pivot branch. The rank phase expresses triple misses using degree-at-most-three monomials in root-relative flip bits on the binary-background models. Pivot scoring uses GF(2) gain in this restricted span. Branches assign the selected pivots and use the corresponding owned binary projections, common binary rows and mandatory background in each binary feasibility test. A satisfying branch yields a witness; exhausting all branches proves unsatisfiability. Assignments to different chosen pivot bits are disjoint, but their binary feasibility answers alone do not encode branch cardinalities.

Saturation preprocessing is polynomial in the explicit source encoding and is outside the three terminal quotas. After saturation the donor reports its actual rooted discovery fee (feasibility calls, implication vertices/edges visited and candidate records), rank_work for closure and elimination, the selected pivots and the number of branch calls. Each branch charges one complete pivot word and has a polynomial binary-SAT cost. With g selected pivots the uncapped branch bound is 2^g. Root construction and rooted rank discovery must be charged even when g=0. The caps discovery_cap, rank_cap and branch_cap are separate nonnegative integer ceilings, or None for unrestricted. Refusal in any charged stage yields unknown with the donor's specific reason and spent metrics, never zero merely due to a ceiling.

On a wider surviving source row the adapter uses the complete unrestricted [clause-miss solver](cnf_miss_span.py), passing branch_cap as max_terms. Its assignment or inclusion–exclusion trials include witness work. Root discovery and rooted rank quotas are inapplicable on this path. The sparse interface never expands the declared arity into a dense witness; ordered-image recognition bounds that expansion polynomially for the physical interface. Malformed source encodings raise ValueError; words outside the ordered image return off_image. With every cap unset both entry points decide all their respective well-formed inputs.
