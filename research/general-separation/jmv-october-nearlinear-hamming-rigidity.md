# Near-linear witness circuits must make exponentially many errors on occurring JMV addresses

Fix the [October unary nondeterministic hierarchy language H](https://raw.githubusercontent.com/openai/math/42907c9e999cc00d6abe7a50bfc1023250edd1b9/preprints/The-Exponential-Time-Hypothesis-is-False-October-25-2026/build/quantitative-circuits.tex) and the canonically right-padded typed [Jahanjou–Miles–Viola reduction, revision 3](https://eccc.weizmann.ac.il/report/2013/099/revision/3/download/). At input 1^n the time allowance is 2^n poly(n), the clause index has q=n+O(log n) bits, and a variable address has Dn bits for a fixed D. Count a variable once if any actual indexed clause mentions its address. Count repeated occurrences, signs and duplicate index encodings only once in this distance.

**Theorem, using the October fixed-density counting theorem.** For every fixed 0≤κ<1/2 there is η>0 such that at infinitely many YES lengths n, every satisfying assignment differs on more than floor(2^(κn)) distinct occurring variable addresses from every ordinary circuit of at most floor(η n sqrt(log₂ n)) bounded-fanin-two Boolean gates on the full address. This uses no NP-versus-coNP assumption. The lengths and η may depend on κ. The conclusion concerns witnesses for the specified native naming; it is not an unrestricted lower bound for the decision language H.

## Sparse explicit corrections with a linear-size decoder

Use [the native variable-depth overlay lemma](jmv-variable-shard-hamming-rigidity.md), whose relevant hypotheses and counting argument are restated below. Use one constant tag/header per native region and finite subtype preceding the first long identifier; the selected header fixes all field widths. Preserve that region's typed fields, then right-pad its label with zeros. In particular reconstruct the parent variable's address from these fields instead of echoing meaningless bits of the indexing word. Ignore unused index fillers, retaining at least one index for every typed clause. Unused finite gadget tags may select a tautological dummy clause on a reserved canonical variable; regular fields have the native transitions even on unvisited or malformed states. This names each typed variable injectively and merely repeats indexed clauses or introduces tautologies. Satisfiability is preserved. Do not perform a general test of semantic reachability of machine configurations.

Here this canonical decoder costs O(n) fan-in-two gates, not merely poly(n). At locality parameter r=2 the source constructs the decoder uniformly and each of its O(n) raw output bits has a constant-support truth table (equivalently constant bounded decision-tree depth). Compile each such bit with O(1) ordinary gates; the tables and supports can be constructed in poly(n) time from the explicit local rule descriptions. To serialize, each finite region/subtype chooses a fixed projection of its field positions plus constant-zero outputs for padding. Decoding its constant number of header bits and selecting among constantly many per-position alternatives costs O(1) gates per output bit; there are three labels and three signs. The parent serialization uses the same rule on index positions directly. No validity check over an arbitrary list of variable names is part of the circuit. Even a test that a specified fixed filler segment is zero can be a single shared O(n)-gate AND and a constant number of choices per output position, but ignoring redundant index fillers suffices here.

Suppose a satisfying assignment agrees with a baseline C of s gates away from a list of at most t occurring full labels. Supply C and the listed full addresses together with their corrected bits. Interpret this as a *single* total Boolean assignment: use a listed bit at that exact full address and C elsewhere. Only agreement on occurring names matters. There is no need to check that every listed address actually occurs, or that its corrected bit differs from C. On every guess enforce the list cap, the record length, strict address ordering (hence uniqueness), the header/field format and circuit syntax including the gate cap.

In each region build a complete binary trie splitting along each listed address. First stop at the end of the first long identifier, then refine its leaf down to the complete label for each listed exception at that identifier, with default off-path siblings. A singleton header can simply be flagged. The two-stage interpretation includes arbitrary-depth off-path leaves, and complete sibling partitions on every split. It can be built by emitting the path prefixes with sibling keys from each listed word and sorting/deduplicating them. Internal nodes take precedence over generated default markers; corrected markers occur only at full endpoints. There are O(1+nt) nodes, B=O(1+nt) leaves and at most O(n) levels. The record at a terminal leaf is just a prefix and either a constant replacement bit or a baseline flag. Tests never receive a table of all suffix exceptions.

## Number of realized refined triples

Before the suffix refinement, K₀=O(nB) ordered triples of leaves are realized. For completeness, inside a local verification copy the row i is preserved even when a wire leads to a sorter output or configuration bit. The x-oracle case has at most n fixed fetch-output choices. Inside a sorter choose the finite network/subtype/edge cases. Each relevant row is either fixed, w, or a single cyclic shift with the indicated possible leading-bit flip. For one clause choose both AND children simultaneously. Partition w by its two end bits. In each class the copy and all the indicated one-position shift/flip operations preserve lexicographic order of the common moving middle word. Thus the three variable-depth leaf partitions pull back to interval partitions of a single order: their overlay has at most one plus the sum of their internal cut counts. Restrictions imposed by late counters can only remove possible triples. The reasoning includes full-depth identifiers and the wrapped end bit. For the fetch string p, native gates have at most one child, with a finite choice of copy, left/right cyclic shift, fixed constant, or mask by one of the two segments of 1^n. Unary segment masks are all ones apart from any stipulated trailing-zero padding; truncating a suffix to zeros preserves lexicographic order. Very short identifiers can be handled separately. Forced outputs, dummy gates, configuration inputs, wired-input clauses, and repeated labels or permutations add only the cases just described or singleton interactions. Distinct finite headers need not have equal length: they are decoded before their independently sized identifier tries. This argument uses no reachability promise on the indexed data.

Only a leaf containing a complete first identifier can be further split. For that fixed header and identifier, at most n^c distinct *occurring canonical* variable labels have that row, for one uniform fixed c after adjusting finite lengths: local (i,j,ℓ) has O(log n) suffix bits; sorter (w,I,s,d) has O(log n) variable bits after w; configurations have O(log n) bit-position information after i; and fetch (t,p,k,d,i,c) has fixed-size segment/direction plus O(log n) counter/configuration fields after p. The padding is fixed and contributes zero choices. Thus each old triple gives at most max(1,n^c)^3 distinct realized refined triples even if the syntactic trie contains very deep off-path padding leaves. Writing K for their total gives K≤poly(n)(1+t). The fact all three labels share one index can only decrease this number. This is where using the actual canonical occurring names is essential.

## Uniform clock

Fix computable caps t₀= floor(2^(κn)), s₀ asymptotic to η n sqrt(log₂ n) (rounding below). Guess and validate at most these many exception records and baseline gates; never wait for an unbounded end marker. Generate the tries deterministically. Enumerate refined triples by breadth-first search of the three decoded address prefixes, advancing unresolved components and retaining finished components. A feasibility test asks whether any original q-bit index has precisely the specified headers and prefix bits. The comparison to each fixed query prefix uses O(n) gates, irrespective of trie size or depth. Including the shared canonical decoder costs O(n) gates. The deterministic counting test below therefore costs 2^o(n) per feasibility query. At a fixed generation every feasible cursor tuple has a realized descendant terminal tuple, and these sets of descendants are disjoint. There are at most O(n(K+1)) feasibility tests including failing children (at most eight proposals per tuple). Use batched sorted tape joins against the node records at each generation so a traversal request never scans the whole tree on its own; scanning the whole tree once per generation costs (1+t)poly(n). Include headers as constant initial branching choices.

For each realized ordered triple form Bad on the *same* q-bit index. It checks the three specified prefix memberships and that all three decoded signed literals are false. For each constant leaf use its bit; for each default leaf use an independent copy of the already guessed C evaluated on that decoded full label. Only the three leaf records and C enter this circuit. There are at most 3s₀+O(n) binary gates; fanout and pinning decoded labels are wires. Checking a full Dn-bit address costs O(n) gates just as for a short prefix; no variable-sized lookup remains. Sort requests by leaf to attach records, then by triple to assemble its Bad. Copying C per triple costs K(s₀+1)poly(n) on sequential tapes. Trie building, sorting and all other record costs are (1+t₀+K)poly(n) for these near-linear s₀.

For any such g-gate Bad use a Tseitin encoding with V=q+g declared variables, one per binary gate, at most 4g+1 clauses of width at most three, and a unit output assertion. Each gate's truth table gives the at most four forbidden local triples; constants, literals and unused inputs cause no problem. The number of satisfying extensions is exactly the number of accepted index words. Use the [October fixed-width, fixed-density deterministic counting theorem](https://raw.githubusercontent.com/openai/math/92b516ef8e/preprints/The-Exponential-Time-Hypothesis-is-False-October-25-2026/build/main_full_version.tex) at density five. Fix A for a multitape bit-clock poly(V)2^(A V/sqrt(log₂(V+2))), enlarged once for any fixed polynomial implementation slowdown in a subcall. V≥q=n+O(log n) and V≤3s₀+O(n), so the per-triple cost is at most 2^((3Aη+o(1))n). Feasibility uses g=O(n) instead, with the same density and resulting 2^o(n) cost. Reject on the first positive Bad count; accept if every count is zero.

A valid close witness supplies an accepting guess. A NO input rejects every guess because the single total assignment defined by that guess violates an actual clause, whose triple is enumerated. All guesses, successful and failing, fit the same bound: reject nonunary inputs directly; enforce encoding caps before scanning records; the list induces O(1+nt₀) well-formed nodes regardless of its honesty; deterministic feasible enumeration skips empty triples on every branch; and all count calls have the stated cap. The total nondeterministic multitape time is at most 2^((κ+3Aη)n+o(n)). Choose strict slack κ+3Aη<1/2. If every sufficiently large YES length admitted a close witness, hardwiring the finite exceptions would put H in NTIME(2^(n/2)), contradicting its choice. Hence infinitely many YES lengths have the asserted simultaneous rigidity.

For arbitrary real κ<1/2 take a slightly larger rational κ' still below 1/2, set t₀ using integer roots, and choose a positive rational η' with κ'+3Aη'<1/2. A public integer gate cap such as floor(η' n floor(sqrt(floor(log₂ n))))) is asymptotic to η'n sqrt(log₂ n), and at all sufficiently large lengths dominates floor(η n sqrt(log₂ n)) for any fixed 0<η<η'. This removes noncomputable parameters and rounding issues. Taking κ=0 allows one erroneous label. No assertion is made about an exponential gate lower bound, arbitrary address renamings, or a separation of P from NP.
