# A fixed single-missing reservoir carries every three-readout instance

Given a simple graph G on m vertices with binary three-vector colors v_i, consider selecting z with only even induced degrees and color sum 4 (third coordinate one). An invertible relabeling handles any nonzero target; target zero uses the empty set. There is a deterministic polynomial-time reduction to the literal three-pin induced-even problem using G's original vertices, three new named pins, and six new reservoir sites. Every host witness restricts to an actual input witness; every input witness extends by one fixed reservoir selection. The same six-site reservoir realizes precisely 35 of its 36 compatible transfer states in every instance.

Start with the [nine-site NO graph](single-missing-rank-three-state.md) with its original three-pin interface numbered 0,1,2 and its six inner sites. Let B be the 6-by-3 incidence matrix of inner sites to pins. It has rank three. With respect to B the missing port state is w₀=(3,7), all others with q(s,t)=s·t=0 being present. This can also be checked directly via the 64 inner selections. Each old vertex i becomes an exterior site, with port column (R_i,V_i) equal to the following binary linear image L of its original color v_i:

    1 ↦ (1,0),    2 ↦ (0,1),    4 ↦ (4,2).

Connect i to the new pins according to R_i, and to inner sites according to B V_i. Between two distinct old vertices i,j take the original adjacency and toggle it by v_i1 v_j1 + v_i2 v_j2, where the indices 1 and 2 denote the first and second bits. The host is simple. It has m+9 vertices and can be written in quadratic bit-matrix size. The six inner sites, all their internal edges, and their original incident pin edges are fixed.

Write x=Σ v_i z_i. In the auxiliary graph matching three virtual ports to the three new pins, the fixed pin symbols give w=w₀+Lx, since the exclusive pair of adjacent pins has input-degree pattern 3. For any legal exterior, q(w)=0 by collective handshaking. With the displayed columns a direct calculation gives

    q(w₀+Lx) = x₁+x₂+x₁x₂.

Thus only x=0 and x=4 are possible. The former asks for exactly the missing inner state and cannot extend. When x=4 the required state is (7,5), which has zero dot product and is present. For this fixed port input 7 an old site receives extra degree parity R_i·7+V_i·7 from the named pins and the reservoir. Evaluating on the three color basis vectors gives respectively 1,1,0, hence this parity equals v_i1+v_i2. The edge toggles inside the old graph, at a selected i, also add v_i1+v_i2 because the first two bits of x vanish and the omitted diagonal contributes those bits. The additions cancel. The old selected degrees are therefore even in the host exactly when they were even in G. The stored representative of (7,5) supplies the extension, regardless of which particular input witness was chosen.

To encode three specified original pins, give them the three unit colors and give all other sites zero, then relabel (a,b,c) as (a+c,b+c,c) to send target 7 to target 4. The three old pinned sites remain as actual payload vertices. The three new interface pins are separate named vertices. Intersecting any witness with the original vertex set restores the requested pins and original graph. In the chart using original payload inputs as independent z, only the three old pinned sites have nonzero columns in C, and they are independent. The baseline link exists by deleting the whole payload and keeping the identity pin-port matching.

There is also a reduction to a single troublesome strongly connected component. Compute the [linked exterior SCCs](linked-scc-port-reduction.md) in this particular chart. If the three active sites lie in distinct components or split between components, every component has port rank at most two and the polynomial-time table algorithm solves the input. Otherwise all three belong to one SCC and all other sites outside it are port-neutral. An SCC with C=0 never changes the syndrome and can always use z=0. Its influence on a later different SCC is zero by H+Hᵀ=CᵀJC and the topological order. Such components can be deleted without changing the table, with zero inputs giving a lift. Deleting their vertices from the actual host realizes the principal submatrix in the same input chart; it preserves all three active sites and their internal strong connectivity. Thus a general solver for a single rank-three SCC on this family, even with all but three site columns zero, would solve every literal three-pin input in polynomial time if its own time were polynomial. In the direct-solvable case an explicit source witness or NO is already available.

This reduction establishes neither NP-hardness nor a relation between the unrestricted three-pin language and every NP language. It explains exactly what an all-graph extension of the 35-state reservoir rule would need to decide beyond the rank-two transitions.
