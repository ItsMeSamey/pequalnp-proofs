# Rank witnesses for cyclic single-bit existential query programs

Take a valid feedback vertex set F of size h in the union graph of both query outcomes. Check the guessed vertex list, its cardinality and that the remaining graph admits a topological order. This is polynomial-time witness checking. It asks for no minimum FVS. Retain every F vertex, as well as all live queries and starts, while bypassing paths of fixed queries. Every residual cycle disjoint from F would lift by concatenation to a positive-length raw closed walk disjoint from F. Retained self-loops have to be kept as positive-length returns; never classify the starting point as its own successor by a length-zero path. Thus each per-assignment residual graph has F as a feedback vertex set. All retained edges represent finite paths with the same assignment, so existential source acceptance is preserved. The construction is unaffected by unreachable states.

For a fixed complete input, set the cost of an edge leaving u to 1 when u belongs to F and zero otherwise. Accept terminals have rank zero and rejecting terminals infinity. Use the ordered ranks 0,...,h,infinity and saturate additions beyond h to infinity. Any reachable accepting terminal has a simple path, hence cost at most h. The true minimum cost (infinity when unreachable) satisfies d_u<=sat(c_u+d_v) on every enabled edge, and has a tight edge at every finite nonterminal u. Conversely, any satisfying rank vector lies below the cost of each accepting path by chaining inequalities, in particular below the actual minimal simple path cost whenever finite. From any finite u, follow a tight edge; its successor remains finite. Continuing indefinitely in the finite graph would produce a cycle of equal initial/final rank with positive total departure cost, since every cycle meets F. Saturation never occurs on a tight edge of a finite vertex. This contradiction forces arrival at an accepting terminal, by a path of cost d_u. It forces every rank to the unique canonical value, including in graph parts inaccessible from the start. Infinite nodes need no tight successor.

With a fixed digit dimension e, choose U>=1 minimally such that U^e>=h+2. One-hot digits, pairwise exclusion and uniquely defined OR chains force one represented tuple; forbid codes outside the rank set. Each retained nonterminal contributes O_e((h+2)^(1/e)) fresh variables. For an enabled edge, each forbidden endpoint rank-pair yields one clause forbidding simultaneous selection of both tuples and the relevant query outcome, width at most 2e+1. Fixed query guards and terminals are simpler. For every retained nonterminal give one Boolean marker z_u. Forbid z_u and the infinity code together. Forbid z_u simultaneously with the guard and each tight rank pair on any outgoing enabled edge. Width at most 2e+2 suffices. In any valid rank assignment satisfying all edge inequalities, the free markers correspond exactly to finite nonterminals missing tight successors. Sum with sign (-1)^(sum z), realized as ordinary even-minus-odd parity-chain counts. A free marker cancels its entire contribution; otherwise all markers are zero. Thus ranks are unique among surviving assignments and acceptance pins recover one per accepting input. With repeated atoms, fresh rank/marker variables give product semantics (a single joint parity chain implements the product sign). Explicit syntax and FVS validation ensure that every accepted guessed atom really has the canonical Boolean semantics; term-specific restrictions then preserve that Boolean function independently of the details of intermediate rank values.

Rank pairs, edges and one-hot exclusions add clauses, not per-edge variables. If a product has Q=O(nL+h+1) retained nonterminals and h<=O((log log M)^b), the number of declared variables is O_e(n+Q(h+2)^(1/e)). The number of clauses is polynomial in n for fixed b,e, because O(Q²(h+2)²) pair checks suffice up to constants and additional digit constraints. With M<=2^O(n) and L=O((log n)^a), the final dimension is O_e(n(log n)^(a+b/e)) for fixed a,b>=0. Taking e sufficiently large that a+b/e<1/2 permits the fixed-width October arbitrary-density exponent to be o(n). For constant h the small-c boundary clock instead survives with a constant depending on h and the chosen fixed width. The density and digit budgets must be accounted separately: the preceding o(n) calculation does not substitute a growing h into the small-c boundary for free.

This argument is distinct from assuming a promise of pointwise global termination; feasible cycles are permitted. The positive departure cost at F and the checked feedback certificate guarantee termination only of a path forced to witness a finite rank.
