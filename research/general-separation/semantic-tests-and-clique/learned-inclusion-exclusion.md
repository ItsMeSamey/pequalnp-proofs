# Learning an exact inclusion-exclusion formula from intersection counts

Let C₁,…,C_m be literal subcubes, or affine flats, on a Boolean space. Intersections are again flats of the same family or empty. Their sizes and descriptions are computable in polynomial time by literal compatibility or GF(2) elimination. Put U=1_{∪ C_i}. For any d, seek an exact real linear combination of indicators of nonempty-index intersections of at most d original sets, agreeing with U pointwise. The classical inclusion-exclusion-vector criterion is linear equality on the nonempty Venn regions. We implement that test and learn coefficients without enumerating those regions. [Goaoc et al., Lemma 2.1](https://arxiv.org/pdf/1207.2591#page=5)

Start with the independent span basis of the nonzero original indicators. Retain actual intersection indicators, never the empty product (constant one), unless an original set itself is the whole space. To pass one degree, add products of each current basis element with each original indicator and retain a maximally independent subset including the old basis. This spans the full positive-degree product space up to the new cutoff: products of the old span with one generator give all degree-increased products, and linearity permits replacing the old candidates by their basis. A product with contradictory literals or inconsistent affine equations is the zero vector and may be omitted. An unweighted Gram matrix has entry |C_S∩C_T|, so exact rational rank tests implement independence directly from intersections.

For a basis T₁,…,T_r solve Gα=b where G_{ij}=|T_i∩T_j| and b_i=|T_i|. The Gram matrix is positive definite, and b_i=⟨U,1_{T_i}⟩ because every candidate is contained in the union. The resulting g=Σ_i α_i 1_{T_i} is the orthogonal projection of U. Test it by computing, for each original set C_j,

    Σ_{x∈C_j} (1−g(x))²
      = |C_j| − 2 Σ_i α_i |C_j∩T_i| + Σ_{i,h} α_i α_h |C_j∩T_i∩T_h|.

All residuals vanish exactly when g=1 throughout the union; outside the union both g and U are zero. This certifies equality pointwise and completeness of the test for membership in the chosen span. On success the union size is Σ_i α_i |T_i| and the complement count follows. With no nonempty original set return zero union size directly. If the span stabilizes under all multiplications, it contains every nonempty product occurring in ordinary inclusion-exclusion; success must then occur. This also provides an exact unpromised algorithm, whose eventual dimension can be exponential. [Finite adaptive-basis checks](adaptive_cube_gram_check.py)

To test through degree d with dimension r_d, each round tests O(m(r_d+1)) candidates, takes polynomially many intersection and exact linear-algebra operations, and uses space polynomial in input size and r_d. Gram integers have O(n+1) bits, and basis linear systems have a common denominator and numerators of O(r_d(n+log(r_d+2))) bits by determinants. All intermediate intersections can be represented by their normalized flat. For fixed d this gives time (m+1)^{O(d)}poly(input). For larger d a low-dimensional span can still terminate early. The same weighted-normal-equations argument works on the union measure with density Σ_j1_{C_j}; the explicit residual version suffices.

A connected-input structural algorithm need not build these truth-table vectors. For example, on the pair violation cubes C_i=[x_i=y_i=1], the union matrix is J−DISJ_n. The second matrix has full rank 2^n and the first is rank one; the union's zero empty-set row gives rank exactly 2^n−1. Every subcube intersection is a rank-one rectangle. Hence any exact representation of this union by these terms uses at least 2^n−1 nonzero coefficients; ordinary inclusion-exclusion attains that with signs ±1, while the scalar union count is simply 4^n−3^n. The obstruction is to a pointwise representation. [Disjointness support and rank](disjoint-score-tradeoff.md)

The hierarchy of candidate subspaces is more general than supplying a scalar score: if the set of attained values of a known weighted sum together with zero has size ≤d+1 and its table indicates the union with value zero at score zero, interpolation with zero constant term yields such a combination after idempotence. Whether a particular family has a short scalar encoding or a short unrestricted inclusion-exclusion vector is a separate structural question.
At depth zero, handle the zero span and the empty union directly before generating any degree-one products.
