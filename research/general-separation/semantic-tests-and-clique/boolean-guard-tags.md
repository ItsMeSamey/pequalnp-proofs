# A small Boolean interface with exponentially large counting rank

On the two sides of a cut let x,y be d-bit strings. The guard asks for a nonempty bit set z satisfying z_i≤x_i and z_i≤y_i. A Boolean interface uses only d possible tags: tag i certifies x_i=y_i=1. These are d accepting rectangles, and no accepting rectangle contains two different diagonal singleton pairs (e_i,e_i),(e_j,e_j), because their cross pair is false. Thus d is optimal on this cut.

The number of witnesses is 2^(x·y)−1. Its matrix has real rank 2^d−1: it is ZZᵀ, where the columns of Z are indexed by nonempty subsets S and Z[x,S] tests S⊆supp(x). The subset-incidence matrix has independent columns by triangularity; over the reals rank(ZZᵀ)=rank Z. Thus large rank of the numeric witness tensor is compatible with an exact small Boolean interface. Equality z=x=y gives the opposite control on the same variable partition: its support is the identity and requires 2^d tags, though a direct equality test is linear time.

There is a graph version on 3d+2 vertices. Use d independent two-vertex classes representing z_i=0 or 1, one independent selector class J of size d, and two singleton anchors. Join all distinct z classes and the two anchors. The anchors join every zero vertex, every selector, and join each 1_i precisely according to x_i and y_i respectively. Selector j requires z_i=0 for i<j, z_j=1, and allows either choice at i>j via its edges to the classes. Every (d+3)-clique picks exactly one from each class and both anchors. The selector is the least chosen coordinate, giving exactly 2^(x·y)−1 cliques. All nonconstant edge labels are positive coordinates.

For a tree of guard pieces, if each edge has at most r explicit tags and each local predicate checks jointly which tuple of incident tags and private choices is feasible in time T_local, bottom-up Boolean message passing decides global feasibility in O(|V| r^Δ T_local) time for maximum tree degree Δ. A subtree sends a tag precisely when some compatible local tuple extends it and all child messages allow the tuple. Induction proves correctness. The interface and a tractable local test are hypotheses: an unrestricted SAT formula placed in one piece has no external interface at all but retains the full local decision problem. This supplies an algorithm for actual instances with the stated decomposition and no implication for arbitrary 3-CNF.

On a full one-hot square-grid consistency check, a rectangle across a slot cut fixes every shared edge label: otherwise the two independent partial assignments could be mixed into an inconsistent pair. Across a balanced r×r cut at least ceil(r/3) edges cross, so even varying-cut Boolean covers require q^ceil(r/3) rectangles for q labels. A serial conjunction of individual edge checks shares only the two endpoint slots at each new conjunction, showing why small overlap at each individual gate does not produce a small global interface. Repeated squaring also leaves every Boolean predicate unchanged. The rectangle bound on physical HC arc inputs in the companion note uses no slot grouping, gate-degree charge, or arithmetic folding.
