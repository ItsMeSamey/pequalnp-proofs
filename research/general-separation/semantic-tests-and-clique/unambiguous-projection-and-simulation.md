# Unambiguous projection and the deterministic simulation exponent

Let E_D(k,C) and E_N(k,C) be the [nonuniform simulation exponents](nonuniform-simulation-exponents.md) for exact real SUM term count at the same near-linear cap C, over deterministic or existential circuits of size n^k respectively. If SAT on its standard indexed CNF encoding has deterministic circuits of size M^b at every sufficiently large input length M, b≥1, then for every fixed integer k≥1, fixed C and η>0 one has

    E_N(k,C) ≤ E_D(ceil((b+η)k),C).

For each size-n^k existential circuit encode its gate definitions by bounded-width Tseitin clauses and its output and n raw input bits by unit clauses. The length is O_k(n^k log(n+2)) with fixed-width binary indices. Only the n unit polarities vary with the raw inputs. Hardwiring this layout in the SAT circuit gives a deterministic circuit on the original n bits of size at most n^ceil((b+η)k) eventually. Thus the function itself belongs to the deterministic comparison class and the atom cap need not change. Violating the inequality for every candidate b, allowing k,C,η to depend on b, would imply SAT outside P/poly. A gap at equal k alone is insufficient. The ISA estimates establish no such unrestricted gap and a circuit separation would be stronger than a uniform P versus NP separation.

## A failure of low-weight witness elimination

The [all-length balanced lookup language](independent-isa-all-lengths.md) has uniform O(N)-gate deterministic circuits. Gate definitions with both directions encoded give one O(N)-leaf 3-CNF with O(N) auxiliary trace bits and exactly one accepting extension on YES inputs and none on NO inputs. Make occurrences bounded with binary trees of equality-copy variables, including input fanout; there are O(N) wires after this change and their values remain uniquely determined. Thus the verifier is one formula before existential projection. Its trace on YES inputs is computable in polynomial time.

After projection every exact real sum for the same balanced target with N polylog N leaves per atom has absolute coefficient weight at least 2^(N^(1−o(1))) on every large length. This follows by its correlation 1/2 with the addressed sign and the cited single-atom correlation bound. For near-linear existential query atoms the weight bound is 2^(N^(1/2−o(1))). Thus a shared, unique and efficiently generated witness does not enable polynomial-loss elimination into a bounded-weight SUM. The target lies in P, so the example does not distinguish deterministic from nondeterministic circuits or establish unrestricted signed sparsity.

Alternatively guess the resolved t-bit pointer address per bank. Verify it by t independent O(P)-leaf primary multiplexers and compare their outputs to the guess. Look up the guessed payload using O(m) leaves, conjoin all address checks, and evaluate the desired AND or XOR. This gives one O(rm)-leaf unambiguous verifier with rt witness bits for one bank product. Any restricted verifier for the AND target with h witness bits whose pinning gives a W-size atom induces a sound cover of ≤2^h atoms. The sound-cover lower therefore also charges witness length in this model even though the ordinary shared deterministic circuit needs none.

On unit formulas specifying each possible n-bit assignment, any length-only pool containing a valid raw witness for every instance needs all 2^n strings. A shared witness generator merely copies the specified polarities, and the decision for the family is constant. A small fixed pool and a shared algorithm are different requirements.
