# Independent audit of the two-count signed reduction

**GO for the mathematical reduction and the indicated little-o density.** Consider a CNF on b original variables plus q previously introduced node-value or formula-gate variables. The inherited graph construction has polynomially many width-at-most-three clauses B and p=O(q+1) marked reverse/start clauses D_i of possibly larger width. Those node bits are forced by backward recursion once all original constraints hold. Retain B unchanged in both oracle calls.

Allocate a fresh switch t_i for every marked clause. For every literal l in D_i insert the binary clause (not t_i OR not l). For p>=1 compute the parity of t_1,...,t_p with p−1 prefix XOR outputs, treating t_1 itself as the first prefix. Encode each binary XOR by all four width-three clauses forbidding its invalid input/output triples. Pin the final parity to zero in one call and one in the other. For p=0 return the count of B directly. All retained but absent original variables remain declared; no switch needs to be introduced for the possibly quadratic number of short forward clauses.

For each assignment to all original and node variables that violates B both counts contribute zero. Otherwise let T be the set of marked clauses falsified by this assignment. The possible switch supports are precisely the subsets of T; each has exactly one parity-chain extension. Empty T contributes one to the even count and zero to the odd. For nonempty T toggle one distinguished member to get a parity-reversing bijection, so the two contributions cancel. Thus count(even) minus count(odd) equals the original product count, pointwise before aggregation or multiplication by an outside coefficient. Empty clauses, repeated clauses/literals, and tautologies obey the same identity. The forward graph constraints alone need not force unique node values. Cancellation is applied to each tentative node vector; exactly the vectors satisfying all reverse clauses survive.

Each call uses V=b+q+2p−1 declared variables when p>=1 (plus any optional free padding). Binary switch clauses number at most the total length of marked clauses, O((n+q+1)^2) here. Additional XOR clauses cost O(p). Each exact count uses at most V+1 bits; its difference can be computed by ordinary signed subtraction. The parity computation concerns the number of marker bits selected, not parity counting modulo two. Multiplication by the external bounded-bit coefficients and summation over terms retains the base verifier's polynomial-in-M bit overhead. The reduction uses ordinary nonnegative integer model counts; its correctness comes from signed subtraction.

Write g(t)=sqrt(log log t)/log log log t on its eventual positive domain. We have M>=n and log M=O(epsilon n+log n), giving log log M<=log n+O(1). The function sqrt(u)/log u is eventually increasing. For K=o(g), for all sufficiently large ambient sizes K(M)=o(sqrt(log n)/loglog n) uniformly through this range. The residual query and gate count q=O(n(1+K(M))). With free padding if needed to make V>=n and its known factor removed after counting, V=O(n(1+K(M))), log V=Theta(log n), and loglog V=O(loglog n). Therefore V loglog V/sqrt(log V)=o(n). The arbitrary-density, fixed-width-three theorem gives two deterministic 2^o(n)-time counts at each product and heavy assignment. The outer clock remains 4delta n+O_d(epsilon n)+o(n). For stated computable density bounds the usual syntactic caps can be enforced directly or via an integer envelope. This proof uses no truncation or first-true witness.
