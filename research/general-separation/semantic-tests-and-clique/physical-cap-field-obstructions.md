# Field size and pivot obstructions for the three-pin cap

Even-terminal projection of a physical instance can fail to admit any symmetric representation over the field of four elements. Use three original terminals and seven other elements. Let B be the binary 3-by-7 matrix whose columns are all nonzero three-bit vectors. In the binary matrix K use zero diagonal blocks and the cross blocks B and Bᵀ. The product BBᵀ is zero because each diagonal counts four ones and each off-diagonal counts two common ones. Thus I+K is nonsingular by Schur complementation. Take M₀=(I+K)⁻¹ and A its diagonal-cleared physical adjacency. This realizes K as I+M₀⁻¹ for the named original sites.

A feasible principal set of K uses equally many rows and columns of B and gives a nonsingular square minor. Projecting with even terminal cardinality gives exactly the empty set and all 21 exterior pairs. Every pair is independent. Since the empty set is feasible, any twisted symmetric representation of this family can be normalized at the empty set by a feasible principal pivot. In characteristic two, the absence of feasible singletons forces this matrix to be alternating. No principal subset of size greater than two is feasible, so its rank is two: choose a nonsingular pair, eliminate it, and any nonzero symmetric residual would have a nonsingular one- or two-element principal block. Every rank-two alternating matrix can be expressed as (uᵢvⱼ+vᵢuⱼ) by splitting off a nonsingular pair and absorbing its scalar. The seven coordinate vectors (uᵢ,vᵢ) must be nonzero and pairwise nonproportional. The projective line over the four-element field has only five points. This rules out every such symmetric representation, including those obtained by replacing the supplied matrix. The eight-element field suffices on this example by choosing seven distinct projective points. Extension fields of characteristic two have sizes 2, 4, 8, ...; eight is the smallest for this example. The proof does not establish that sixteen is necessary for some instance.

## Testing the structural algorithm after every feasible pivot

The [three-pin cap](even-odd-extension-cap.md) uses a specified common border over the field of sixteen elements. One [tractable class](extension-toggle-binary-exterior.md) requires, in each connected component of the exterior matrix's off-diagonal support, either a diagonal congruence to a binary matrix or proportionality of the dummy border to the square-root diagonal. The following two original graphs both fall outside this class for every normalization tested below. Bit i of each displayed integer indicates adjacency to vertex i, starting at zero. The original pins are vertices 0,1,2.

| NO | 116,56,41,86,75,71,57 | none | 67 | 1,876 |

Both graphs have pin-cut rank three and vertex connectivity three. The [finite checker](physical_cap_all_charts_check.py) tests all original diagonal choices producing nonsingular M₀, each permutation of the three cap positions, and every feasible pivot set containing the mandatory pins, including pivots at the dummy. After removing the mandatory border, it tests each component in the resulting chart. For binary scaling, a root has fifteen possible nonzero scales; each nonzero edge then forces the adjacent scale, and loop and cycle consistency can be tested directly. For proportionality, squaring reduces the test to a fixed scalar times the diagonal. No chart qualifies on either graph. This statement fixes the common cap coefficients. It does not rule out other algorithms, boundary weights, or representations.
