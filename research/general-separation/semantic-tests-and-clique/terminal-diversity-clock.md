# A clock from distinct successful terminal states

Put N=2^n. A deterministic controller with s mutable state bits and a binary Boolean step circuit takes the current output address i in {0,…,N−1} and state z. A tick either stays at i and updates z, or emits one bit, updates z and advances to i+1. Time and previous outputs are inaccessible unless the controller stores them in its state. Initial states may vary. There is no requirement of invertibility, injective emissions, or finite delay on unsuccessful starts.

Fix any collection of complete successful runs, for example those whose N-bit transcripts differ from a prescribed table on at most pN positions. Let K≥1 be the number of *distinct terminal states* among these runs. Some successful run takes at most N·2^s/K ticks in total. More generally, on that same run the number of addresses taking more than D ticks is at most floor(N·2^s/(KD)) for D≥1. Choose one representative for every distinct terminal state. A given address-state pair can occur at most once within a completed run, since repetition before emission would cause infinite silence. If it occurred on two representatives, determinism would give identical future trajectories and terminal states. Charging ticks to their address-state pairs proves that the sum of all K run lengths is at most N·2^s. Averaging proves both bounds. The prefix already emitted can differ on different runs.

The scale is sharp up to the first output address. Preserve h bits of the state, and use its t=s−h other bits as a binary counter. At address zero immediately emit zero and reset the counter, preserving the h bits. At each later address advance the counter until it visits its all-ones value, then emit zero and reset it. All seeds emit the zero table. There are K=2^h terminal states and every run takes 1+(N−1)2^t ticks. For h=0 the fraction of successful initial states is one even though every run has repeated exponential gaps. This controls the distinction between many starts and many distinct ends. The zero table itself has an immediate printer.

**Conditional E bound.** Fix C≥0 beforehand. For the constants α,p of the [stream avoidance theorem](sequential-stream-avoidance.md), assume SAT∈P and take its E language for the fixed polynomial deadline N^{ceil(C)+2}. At every sufficiently large n, every deterministic controller with n≤s≤αN/n and at most αN/n gates has strictly fewer than 2^s/N^C distinct terminal states on runs with at most pN output disagreements. Otherwise the clock bound supplies a successful run with total time at most N^{C+1}, hence every interoutput gap fits the avoidance deadline. No exceptional resets are needed. The language may depend on C. This conclusion applies to arbitrary nonlinear transitions with unlimited native delay.

For a reversible stream driven by one permutation on states, with an address-independent emission set E₀, take starts in E₀ and emit at each successive visit. The first return acts bijectively on E₀ by stepping along each permutation cycle. The terminal-state count for successful starts measured after N such returns equals their number, so inverse-polynomial density of successful emitting seeds relative to the entire state cube suffices. The general argument permits irreversible maps by measuring terminal diversity directly.

**Catalytic computation.** If c of the initial state bits have prescribed values and each string in the remaining s−c positions yields a successful transcript and is restored there at completion, then K≥2^{s−c}. It suffices that these final borrowed strings are distinct. The clock is N·2^c even if the dirty part is almost N bits. If only a fraction δ of the borrowed strings give successful runs with distinct restored values, replace 2^c by 2^c/δ. This is the configuration-counting argument behind the classical upper on the expected time of catalytic machines, applied to approximate whole-table streams, with a terminal-image parameter. [Buhrman, Cleve, Koucký, Loff and Speelman, Theorem 19](https://iuuk.mff.cuni.cz/~koucky/papers/catalytic.pdf)

A sufficient condition for P≠NP would be a common constant C such that every E language admits such simulations at infinitely many lengths with at most Cn clean bits, s and gate count within the displayed caps, and restoration on all borrowed strings. Here success means at most pN errors across one transcript. The class inclusion asserting this simulation is unproved. A standard catalytic machine on individual addresses can supply a controller if its complete mutable configuration fits the budget, its per-address initialization and reset use the stated circuit size, and it returns the borrowed string so the controller can reuse it on subsequent addresses. A small time bound alone supplies no restoration guarantee. The usual catalytic-logspace class allows an unspecified polynomial number of borrowed bits in the explicit input length, which by itself does not give the particular catalyst and circuit budgets here. In particular the target language depends on the chosen clean-space coefficient C, so a machine-dependent unbounded coefficient in the sufficient hypothesis would leave a quantifier gap.
