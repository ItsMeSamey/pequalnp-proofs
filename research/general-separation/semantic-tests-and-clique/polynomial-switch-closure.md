# Polynomial-size closure and the evaluator target

With arbitrary fixed polynomial sizes for atoms and number of terms, exact Boolean-valued real SUMs of undirected switched component-table atoms give exactly L/poly. The same equality already holds when each graph realizes at most two component counts. Adding arbitrary ambiguous acyclic nondeterministic binary query branching programs gives exactly NL/poly. These direct standard closures clarify the tighter near-linear atom budgets of the hierarchy results. [Boppana and Sipser, section 6](https://www.cs.umd.edu/~gasarch/BLOGPAPERS/boppana_sipser.pdf)

Supply polynomial-size graph descriptions and tables as advice. Count components in deterministic logspace by scanning each vertex v, testing whether it connects to any smaller vertex, and counting those with no such predecessor. Enabled adjacency can be evaluated by scanning the input labels. Reingold's logspace undirected reachability supplies the test. Read the table entry indexed by that count. [Reingold](https://omereingold.wordpress.com/wp-content/uploads/2014/10/sl.pdf)

For S Boolean bottom functions and a Boolean-valued exact real sum, keep independent truth-table columns spanning its output and solve on independent rows by Cramer's rule. Common-denominator integer weights with O(S log(S+2)) bits exist by 0/1 determinant bounds; take the denominator positive and supply these weights as advice. To decide if the numerator is zero, stream its positive and negative summands from low bit to high. At each position scan all S terms and evaluate their bottom bits again. Each carry is at most S. Record if the two emitted bits ever differ and process sufficient high zeros for both carries to vanish. All workspace and counters are logarithmic. [Williams, normalization of real SUM coefficients](https://arxiv.org/abs/1802.09121)

Conversely an L/poly computation has a polynomial-size complete acyclic deterministic branching program with two sinks. On a fixed input, forgetting directions leaves two weak components: each vertex reaches one sink and enabled edges preserve that destination. Retain both sinks even if unreachable. Add a permanent start-to-accept edge; the resulting graph has two components exactly on acceptance and one otherwise. A single two-entry table suffices.

For the nondeterministic class perform column accumulation while guessing and verifying each atom answer. The uniform evaluation problem on an explicit acyclic program and input and its complement are both in NL by NL=coNL. The program advice can be treated as ordinary read-only data; sequential tests reuse space. Every successful path has the correct answers, and a successful path exists. Conversely an NL/poly computation has a polynomial-size acyclic nondeterministic query program. [Immerman](https://doi.org/10.1137/0217058) · [Boppana and Sipser](https://www.cs.umd.edu/~gasarch/BLOGPAPERS/boppana_sipser.pdf)

If a fixed polynomial SUM upper in the undirected model computes the padded gate evaluator at every sufficiently large ambient length, then P/poly=L/poly. Hardwire a circuit and gate index, retaining one original bit in each parity block and zeroing the other slots. For polynomial-size circuits the ambient length is polynomial in the original input length, so restricting the resulting L/poly computation gives an L/poly decision for every circuit family. In the mixed model with nondeterministic atoms the analogous equality is P/poly=NL/poly. The implications already allow arbitrary polynomial atom sizes, while the hierarchy verifier requires the near-linear budgets. Neither equality follows from the component-count results.
