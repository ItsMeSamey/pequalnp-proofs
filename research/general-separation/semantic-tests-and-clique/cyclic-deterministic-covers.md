# All cyclic deterministic query programs via signed path counting

For some absolute c>0 and each fixed d≥1, some language in NP lacks, infinitely often, an exact real sum of at most M^d atoms, each either a binary Boolean formula with ≤MK(M) leaves or a deterministic single-bit query program with ≤MK(M) nodes, where K(M)=ceil(c sqrt(loglog M)) at large lengths. The program may have any directed cycles. Each query outcome has a unique successor; acceptance means eventually reaching accept, and infinite runs reject. This proof uses the internal [October Boolean tensor contraction theorem](https://github.com/openai/math/blob/92b516ef8e/preprints/The-Exponential-Time-Hypothesis-is-False-October-25-2026/build/quantitative-reduction.tex#L15-L48).

Perform the common-slot projection and heavy-bit branching from the [formula proof](np-sum-formula-projection.md). Follow each fixed deterministic chain until a live node, a terminal or a repeated fixed state. In the last case its run never escapes; redirect to reject. A fixed start is treated by the same rule. Each remaining state has at most two genuine outgoing arcs, one per query-bit value, omitting rejecting destinations. Keep these arc guards even when their destinations coincide. Across up to four factors there are O(nL) residual nodes or formula leaves at threshold L=ceil(CK(M)). On every guessed deterministic description this contraction preserves its ordinary Boolean value.

## Pointwise cancellation

Add fresh sentinels s and t, an arc from s to the compressed start and the compulsory arc t→s. Use s→t for immediate acceptance; omit the outgoing source arc for immediate rejection. Add one artificial unguarded filler self-loop at each query state, distinct from any genuine traversal self-loop. Neither sentinel has a filler. For a given input, admit a genuine traversal arc precisely when its literal guard holds.

A spanning cycle cover chooses exactly one incoming and one outgoing arc at each vertex. Mark any union of genuine cycles other than the cycle containing t. Enforce incoming and outgoing marks equal at each vertex, and forbid marks at t and on every filler. For marked vertices S and their permutation pi the weight is (−1)^|S| sign(pi). A marked cycle of length k contributes (−1)^k (−1)^{k−1}=−1. Consequently marking sums to zero if the cover has any nonroot genuine cycle, including a genuine self-loop, and to one otherwise. In a surviving cover the compulsory t→s closes one simple enabled path s→t, and unused states all take their artificial fillers. Conversely every simple enabled path extends to exactly one surviving cover. Under a fixed input there is at most one such path by determinism. The signed total equals its Boolean acceptance bit, including in the presence of arbitrary disconnected cycles. [Finite signed cover checks](functional_cover_check.py)

## Contraction clock

Use the [rectangle construction for signed directed cycle covers](directed-signed-rectangle.md), including its prior sparse-tour comparison to Tulsyan. With m=O(q+1) arcs for q retained states, partition the tail and head orderings into O(m^{1/3}+1) chunks, each of O(m^{2/3}+1) arcs. The certified construction computes the marked permutation sign with local reorderings and one bundle-parity tensor. Each tail chunk gets at most one extra input port per genuine conditional arc and rejects selection if the guard fails. Forbid filler marks in the local arc codes. This adds O(q+1) wires and preserves the chunk degree bound. Distinguish parallel arc IDs. Empty source incidence yields zero directly.

For a product, each factor gets independent cover or gate variables. Share the unbranched original input variables across guard occurrences and formula leaves with bounded-degree equality trees, with one extension for each chosen input value. A variable with no occurrences supplies its free factor of two. Formula factors use one bounded-arity Boolean gate relation per surviving binary gate and an output pin with unique gate evaluations. Subdivide every wire by equality to make a bipartite Boolean tensor network. For size parameter s_0 a sufficiently large constant times n plus the total retained states/leaves plus one, there are O(s_0) edges and maximum degree O(s_0^{2/3}), below the source limit ceil(s_0^{9/10}) at large sizes. Port lists and exact local entry evaluations cost polynomial time. Use ell=1 and precision P0=n+1; all final product counts are nonnegative and at most 2^n. Only final residues are decoded, so canceled intermediate signs need no magnitude bound.

The internal theorem gives poly(s_0)·2^{O(s_0/sqrt(log(s_0+2)))} bit time and polynomial space per product after the heavy branches. In particular s_0=O(n+nL). Fix δ>0 with 4δ<1/4, then the absolute common-slot threshold factor C. For M≤2^{O(n)}, L≤O(Cc sqrt(log n))+O(C+1), so choosing c sufficiently small bounds this count's exponent by n/4 eventually. For fixed d choose ε for the descriptor scans, quartic moment expansion and common-slot union bound exactly as in the [formula hierarchy proof](np-sum-formula-projection.md). This supplies the required nondeterministic 2^{(1−ε)n} gap-UNSAT algorithm under the negated assertion. Original cyclic deterministic reachability has ordinary polynomial-size circuits by unrolling at most the number of states on a given assignment. The same [Murray–Williams hierarchy contradiction](https://people.csail.mit.edu/rrw/easy-witness-nqp.pdf) follows. The hard language may depend on d.
