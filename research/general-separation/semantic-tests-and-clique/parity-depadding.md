# Depadding exact sums and the single-language question

Let an n-bit function f be evaluated on parities of n disjoint R-bit blocks with N=nR+o(nR) raw positions including fixed headers. Suppose the ambient function has an exact real sum of S≤N^d atoms, each with at most NK(N) occurrences counted as arbitrary binary Boolean formula leaves or acyclic existential single-bit query nodes. After hardwiring the header, f has an exact real sum of at most S(SN)^{O_eta(1)} atoms of the same kind, each with at most (1+eta)nK(N)+O_eta(log(SN)) occurrences, for any fixed eta>0 and all sufficiently large lengths. The claim permits repeated input variables, arbitrary signs and arbitrary branching-program successor sets.

Let w_ij be a raw position's occurrence count in one atom. Choose one uniformly random slot in each block independently, set all other slots to zero and use the chosen slot as its logical input. Write M0=NK(N)/R=(1+o(1))nK(N). For each atom call a position heavy if its count exceeds T=M0/(A log(SN+2)) with A a sufficiently large constant depending only on eta. The number of selected heavy positions has mean at most M0/T=A log(SN+2). A Chernoff bound puts it below a constant times A log(SN+2) simultaneously in all S atoms. The selected light occurrence mass is a sum of independent nonnegative variables bounded by T and with mean at most M0, giving variance at most T M0. Bernstein's inequality makes the probability of exceeding (1+eta/2)M0 at most exp(−c_eta M0/T). Choosing A large enough, a union bound gives a common choice satisfying both controls. Empty or tiny T does not compromise the bounds; in the polynomial padding regime M0 is at least order n.

For each atom separately expand on its own selected heavy logical bits via a disjoint sum over all assignments to them. Prepend a conjunction of those O_eta(log(SN)) literals to each residual. Constancy folding on trees or first-live endpoint contraction on acyclic existential programs leaves at most the selected light occurrences. Binary AND adds the guard to a formula. A deterministic chain implementing the guard connects to the root of a residual program. Dense successor lists do not count as separate tests. Each original atom splits into at most (SN)^{O_eta(1)} atoms. The whole sum preserves the original weights on each disjoint piece. This argument requires no averaging of the function itself or exponential number of parity-slot maps.

## A conditional single uniform language

Fix 0<a<a'<1/2. Suppose L_j in NTIME(n^{t_j}) has infinitely many input lengths where every exact sum with bottom cap n·ceil((loglog(n+16))^{a'}) exceeds n^{s_j} atoms, of the formula or acyclic existential branching-program types above. Assume sup_j s_j/(t_j+1) is infinite. Then one fixed explicit NP language has infinitely-often hardness against EVERY fixed polynomial sparsity exponent at bottom cap N·ceil((loglog(N+16))^a).

Use a bounded universal nondeterministic verifier whose raw input contains a machine description, n and R in a self-delimiting header, followed by n disjoint R-bit parity blocks. It accepts if the named machine has an accepting computation on the n parity bits within N simulated steps. Compute parities first and use a fixed polynomial-time universal simulation for N steps. This is a single language in NP. No effective enumeration of the hypothesized L_j is needed. For each fixed machine witnessing L_j, take an integer p_j=t_j+O(1) (round up and leave enough slack to absorb its multiplicative clock constant). Put R=n^{p_j−1} and hardwire its description and header. The full length N=n^{p_j}+O_j(log n), so the simulation covers its entire verifier time for large n. The hardwired raw language on these blocks equals L_j composed with parity.

If the universal language has a fixed N^d sparse representation at every sufficiently large length, the first result yields n^{O((d+1)p_j)} atoms after depadding at each original length. The hidden constant is universal after fixing eta. For each fixed p_j, O(n(loglog N)^a+log N) is eventually below n(loglog n)^{a'}. Select j with s_j greater than the transferred exponent, contradicting its infinitely many hard lengths. Therefore the universal language escapes every fixed polynomial sparsity along some infinitely many lengths (which may depend on that exponent).

The [original NP theorem](np-sum-formula-projection.md) does not prove the needed unbounded sparsity-exponent to verifier-clock ratio. The [Murray–Williams hierarchy statement](https://people.csail.mit.edu/rrw/easy-witness-nqp.pdf) supplies ordinary size n^k hardness with a verifier allowance n^{O(k^4/epsilon)}. This upper allowance does not rule out faster verification, but it does not establish the required ratio. Moreover the original contradiction is existential over NP languages and supplies no uniform family meeting this quantitative assumption. Ordinary polynomial padding on its own also changes an N^d sparsity limit to n^{p_j d}. The depadding proof controls the bottom budget while retaining this separate exponent loss. Neither the conditional packing theorem nor the previous lower bounds resolve whether one such NP language exists.
