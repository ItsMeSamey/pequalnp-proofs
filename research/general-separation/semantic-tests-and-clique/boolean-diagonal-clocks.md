# What a negation gadget must do in the Hamiltonian diagonal

## A genuine complement gadget exists conditionally

A polynomial-time many-one map from UNSAT to directed Hamiltonian cycle exists exactly when NP=coNP. In one direction the map puts UNSAT in NP. In the other, HC is NP-complete. Under the stronger P=NP assumption there is even a constant-output gadget: decide the N-bit formula in at most cN^d steps and output a fixed three-vertex directed cycle on UNSAT or a fixed directed path on SAT. It uses O(1) graph bits and cN^d+O(N+1) construction time, with one fixed, unspecified d for that decider. This is true Boolean negation. It cannot be charged at constant cost simply because its graph is constant-sized.

A correct complement map on graphs needs no fixed point. On the two three-vertex examples it can interchange them and return to the starting graph after two applications. Equal output and input lengths give no contradiction. Even the polynomial-time unary predicate B(1^n)=n mod 2 satisfies B(1^n)=1−B(1^(n+1)) at every length. A diagonal contradiction needs the evaluator and the machine whose acceptance is reversed to refer to the very same computation on the same description and clock.

## The two input lengths in the arithmetic proof

In the November batch proof, 0<σ<ρ<b<1/20 are small fixed constants, δ<b/2, 1≤k≤2^(n^σ), R=k·2^ceil(n^ρ), and w=ceil(20 log₂(nR)). The smaller public time cap is T₋=floor(Rn^(1−b)); the larger one is T₊=ceil(Rn^(1+b)). A T₋ program can send ≤√n-bit jobs to one fixed nondeterministic private machine with n^20 steps per path. It pays for each job and each bit. Private outputs do not return data; any public value is guessed and verified. The genuine representation uses R universal n-bit processors. The same wiring realizes the smaller computation for every padded description D at those parameters, by setting its literal pins appropriately. Generating the explicit wiring costs Rn·poly(w) public ticks.

D contains its actual program, parameters and one hypothetical k-batch network of O(kn^(1+δ)) words. The active fields fit inside R/10 words. The much larger substituted network uses R/k copies, generated rather than stored in D. Its evaluator takes O(Rn^(1+δ)poly(w))≤T₊ public ticks. The source simulates this evaluator's weighted count in o(T₋), leaving time to copy the description and add an accepting branch. Its contradiction is in a field. [Clock theorem](https://raw.githubusercontent.com/openai/math/main/preprints/Circuit-lower-bounds-for-Hamiltonian-cycle-and-the-permanent-November-24-2026/build/gap.tex) · [Batch proof](https://raw.githubusercontent.com/openai/math/main/preprints/Circuit-lower-bounds-for-Hamiltonian-cycle-and-the-permanent-November-24-2026/build/batch.tex)

A Boolean version needs a uniform smaller-clock existential computation that succeeds iff the entire substituted computation has **no** successful completion. It must work on the description containing this very Boolean program and the candidate representation, use the same literal-pin and private-job interface, and fit all construction and execution costs below T₋. Guessing a failed completion proves a different predicate. The supplied compression preserves weighted sums and makes no such Boolean guarantee.

Consider two ways of invoking a hypothetical P decision procedure. On a padded explicit input of length L≥R, a bound cL^d with any fixed d>1 gives no smaller-clock guarantee: R^(d−1)/n^(1−b)→∞. An explicitly generated graph or circuit also incurs its writing time; an ordinary bit-level bound must be compared to RAM ticks with the stated word length. Conversely, any fixed polynomial in O(kn^(1+δ)w+n) active bits is o(R), since σ<ρ. This would leave ample time, but a short description of a long computation is a succinct instance. A decision procedure for explicitly presented SAT/HC cannot simply use that active length as its time parameter. Supplying a succinct graph whose decoding costs R or more changes the input problem.

## A universal succinct complement is provably too strong

Fix k=1 and a small rational ρ as above. Define A on active inputs (1^n,e) to accept iff the stored nondeterministic program e has an accepting run within T₋ on the description containing (n,e) as active fields. Allow constant-length programs to read their stored code, as in the source; no private jobs are required. Interpreting descriptions outside the valid length range arbitrarily has no effect on the argument. There is no fixed nondeterministic polynomial-time verifier for the complement of A on all valid inputs. In particular there is no uniform polynomial-time reduction of that complement, measured in active length, to ordinary polynomial-size SAT or HC.

Suppose such a verifier V exists. Install a constant-length program Q that reads its own stored code e and n, writes (1^n,e), guesses V's polynomially bounded witness and simulates V. On the active input (1^n,Q) the preparation, guesses and simulation take a fixed polynomial in n, even with polynomial interpretation overhead. For all sufficiently large n this is within T₋, since R=2^ceil(n^ρ) here. Q therefore has an accepting path at that very description iff the verifier accepts some proof that Q has no accepting path there. This is impossible. The proof concerns a universal evaluator on all such programs. It does not refute a conditional gadget supplied only with a distinct, hypothetical fast batch representation; the burden there is deriving that representation and its same-clock properties from an ordinary Boolean assumption.

The distinction between universal nondeterministic and deterministic diagonal targets is important. For the latter, encode deterministic machines by self-delimiting codes with arbitrary ignored zero padding. Define H(x)=1 iff the machine encoded in x fails to accept x within 2^|x| steps, and fix a default value on invalid inputs. H is in EXP and outside P. For any candidate polynomial-time decider D, its runtime on all sufficiently long padded encodings of D is below the cutoff, so H(x)=1−D(x) at those x. A polynomial-time map taking these active strings to ordinary polynomial-size SAT/HC instances would place H in NP and genuinely separate P from NP. The replay tableau has exponential written length. This is an open compression requirement, unlike the impossible universal nondeterministic complement above.

## Finite falsification of a black-box substitute

Let 2^m oracle bits record independently whether possible witnesses are valid, under the promise of zero or one marked witness. Every sound, complete existential verifier for emptiness must inspect every bit on each accepting transcript for the all-zero input. Otherwise flip an unqueried bit and keep the same proof and transcript. Arbitrary proof length, signed bit queries and adaptive behavior do not help. If a preprocessing routine asks Q bit queries and a k-clique certificate tests binom(k,2) adjacency predicates requiring at most q queries each, then Q+q binom(k,2)≥2^m. This measures queries rather than vertices in isolation. Ordinary succinct transition rules need not contain 2^m independent bits, so this finite result supplies no unconditional SAT lower bound.

Finally, negating an existential bit does not repair formal parsing: x²−x is zero in the Boolean quotient but its formal coefficient of x is −1. A binary parse tree's formal leaf multiplicities can collapse under x²=x. The November proof transfers its signed-count witnesses through formal-polynomial projections; a complement gadget changes neither this quotient nor the absence of a small formal HC polynomial. [Parse tables](https://raw.githubusercontent.com/openai/math/main/preprints/Circuit-lower-bounds-for-Hamiltonian-cycle-and-the-permanent-November-24-2026/build/parse.tex)

Under the effective padded encoding just specified, H is EXP-complete under polynomial-time many-one reductions. For any deterministic exponential-time language L, hardwire x into a machine that simulates its complement on x, ignores the new input, and pad its code to polynomial length with 2^|code| above the simulation bound. H of that code equals L(x). Thus ordinary polynomial SAT compression for this particular H is equivalent to EXP=NP, which would indeed separate P from NP by the deterministic time hierarchy but is stronger than that separation. This quantifier distinction prevents the deterministic example from being mistaken for a necessary condition for P≠NP.
