# A reachability representation inside the bounded controller budget

Let N=2^n. For each n let a Boolean circuit A_n(x,u,v) give the adjacency matrix of a directed graph on V vertices, whose distinguished source and sink are fixed. The address x has n bits, the endpoint labels have ceil(log₂ V) bits, and V and distinguished labels can be hardwired. Gates have bounded fan-in, unrestricted fanout and a finite Boolean basis. No algorithm for constructing A_n is assumed. The length-n target is the bit of source-to-sink reachability. Parallel edges are unnecessary.

There are absolute η>0 and C_* such that if V≤N·2^{η√n} and the adjacency circuit uses at most αN/(4n) gates, this predicate has an exact catalytic stream controller at each sufficiently large n. Here α is the fixed counting constant of the [stream theorem](sequential-stream-avoidance.md). It uses at most C_*n initialized bits, o(N/n) borrowed bits, and at most αN/n gates. All borrowed bits are restored after each output. The constants do not depend on the graph family or its adjacency circuits.

Apply the polynomial-time directed s-t connectivity algorithm of Chmel, Dudeja, Koucký, Mertz and Rajgopal on V vertices. It takes O(log V) clean space and O(V·2^{−c√log₂ V}) catalytic space for some constant c>0. Pad a small graph by isolated vertices up to max(V,N), and choose η<c/2. Then log₂ V after padding is at least n and at most n+η√n+O(1). Its catalytic space is at most O(N·2^{−(c−η)√n}), hence o(N/n). Ordinary clean work bits, input/tape head addresses, finite control and the addresses of the borrowed tape fit C_*n bits for a constant belonging to this fixed simulation. Padding checks and start/target constants take O(n) gates. [Frontier Space-Time Algorithms Using Only Full Memory](https://drops.dagstuhl.de/storage/00lipics/lipics-vol383-ccc2026/html/LIPIcs.CCC.2026.29/LIPIcs.CCC.2026.29.html)

Use an implicit graph input with bits computed from x,u,v by A_n. A canonical adjacency-matrix encoding of polynomial length in V suffices, with ordinary logspace conversion to any standard explicit graph encoding expected by the connectivity machine. For instance to produce an indexed adjacency-list symbol one may scan all endpoint pairs with O(log V)-bit counters. This conversion uses a fixed polynomial number of microsteps per symbol and adds O(n) clean bits. The adjacency circuit is reused as one combinational block whenever an entry is requested. It incurs no mutable state charge for storing its internal wire values between ticks. Binary-address tape access for a bits tape costs O(a+log(a+2)) gates per tick: read through a binary multiplexer and write using all address-indicator wires obtained by successively splitting prefix indicators. For a fixed number of tapes with a total of o(N/n) bits beyond the linear clean term, the total circuit overhead is o(N/n). Halt and capture the answer bit, reset clean fields to their designated start configuration, and advance x in the external address stream. The original connectivity algorithm restores the borrowed string for every initial value. The combined machine thus also has the claimed restoration property. Extra ignored borrowed bits may pad its state up to n. [Terminal-state diversity bound](terminal-diversity-clock.md)

Under SAT∈P take the E language in the terminal-diversity bound for C=C_*. At every sufficiently large n its truth table has greater than pN disagreements with every graph representation above, because the stream of reachability bits is identical on all restored borrowed strings. No fixed graph or adjacency description can depend on the initial catalyst in this conclusion.

The catalytic graph algorithms themselves are prior results. For a separately specified layered program with polynomial length and width w≤N^{1−ε}, the analogous near-linear-in-width catalytic register implementation is also prior work. In particular Chakraborty, Datta and Shandilya give an explicit work-space/catalyst tradeoff for weighted path sums. [Theorem 3.4](https://arxiv.org/html/2610.41723v1#S3.SS2)

The significance of the vertex estimate here is admission to one previously defined controller budget. If the only desired conclusion is conditional existence of an E table avoiding short descriptions of graphs with V≤N^B for a fixed B, direct validation is easier and permits much larger graphs: materialize or query their adjacency matrix and decide reachability in polynomial time in N, with a fixed exponent depending on B. Count the short circuit descriptions and run the same collapse-based prefix search. This latter avoiding language may depend on B. A reduction of all E languages to reachability within the displayed stream budgets has not been established. Generic polynomial-workspace verifiers can have exponentially more than N·2^{η√n} configurations.
