# Exact duals for a supplied dictionary and the uniform construction problem

Let a polynomial-time generator on 1^n supply S=poly(n) Boolean predicates A_i on n inputs, each having a polynomial-time evaluator. For example these may be the near-linear formula or explicit acyclic query-program predicates used in the [lookup bounds](independent-isa-all-lengths.md). Fix a language L in NP and its verifier. Suppose the membership column f_n lies in the real span of the supplied features. Whenever the dictionary is known, finding exact rational coefficients on hard lengths is a linear interpolation and counterexample-search problem, even for forced high magnitudes.

Maintain an independent set of labelled rows, solve their linear equations and set free coordinates to zero. Rational solutions have polynomial bit length by integer minors and Hadamard. Ask whether any x has sum_i c_i A_i(x) unequal to L(x). For L in P this is an NP search, and for L in NP it is in Σ₂^P: a non-Boolean score is immediately wrong; score zero with a YES witness has an NP check; score one with a NO input has a universal witness check after guessing x. Prefix restrictions use the same predicate to recover such an x by self-reduction. Query its true label and add the row. Under the span promise any counterexample is independent of the previous rows: otherwise any exact coefficient vector and the current one would agree there. Thus at most S new rows and one final successful verification suffice. This is an FP^NP construction for a P target, or FP^(Σ₂^P) for an NP target. If P=NP both searches run in polynomial time. A directly P-constructible spanning row basis with P-known target labels would remove the oracle unconditionally. The theorem supplies no generator for an appropriate feature dictionary.

Without a span promise, failure for one fixed dictionary is witnessed by at most S+1 labelled input rows: take independent rows of the [A|f] matrix certifying that adjoining f increases rank. Gaussian elimination checks the obstruction given correct labels. Finding distinguishing rows generically would be powerful: a one-atom input dictionary A(x)=φ(x) has a nonzero row exactly when φ is satisfiable; generating such a row under the promise of satisfiability solves search SAT. For a unary preselected sequence of atom lists this reduction does not follow. Exponential coefficient magnitudes need not obstruct computation; the layered triangular example in [the normalization note](sparse-dictionary-weight-normalization.md) has a direct polynomial-bit recurrence.

## A static sample cannot replace a dictionary-specific witness

Any t distinct n-bit inputs with arbitrary bit labels can be matched by one decision tree with at most t leaves. Recursively split a nonhomogeneous set on a coordinate that distinguishes two differently labelled points. Both children are nonempty and no coordinate is tested twice on a path; stop at homogeneous sets. The tree gives a Boolean function everywhere, agreeing with all t sampled labels.

Moreover for W≥C(n+1), some absolute C, such a sample can be matched everywhere on the sample by a disjoint SUM with O(1+t/W) binary-formula atoms of at most W leaves each. Cut the tree bottom-up into connected pieces. Each node collects the leftover connected pieces of its children plus itself, marking the result as finished once it has at least B nodes, for B a sufficiently small constant times W. Every finished piece except possibly the root has at least B and at most 2B+1 nodes, so the number of pieces is O(1+t/B). In each piece replace edges entering other pieces by rejecting leaves. Guard entry by the root-to-piece path in the full tree: it contains at most n literals. Implement each branching node by a constant-size two-input multiplexer formula (a selector occurs twice and each child formula once). This gives O(B)+n+O(1) leaves, within W. On any assignment only the piece containing the original terminal can accept: earlier pieces reject when traversal exits and off-path pieces fail their guards. Summing the disjoint accepting indicators gives a globally Boolean function. Deterministic query programs work as well at the same scale.

In particular a common proposed test set of at most c S W inputs, for a sufficiently small fixed c and S≥2, can be fitted with at most S unit-weight atoms; for small S one can use the original single tree. The per-dictionary witness of size ≤S+1 cannot simply be exchanged for a single test set refuting all such dictionaries. This does not rule out adaptive or larger tests. None of these uniform-search and fixed-dictionary lemmas supplies the missing unrestricted P versus NP separation.
