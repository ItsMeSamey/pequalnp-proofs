# Exact real sums of near-linear nondeterministic branching programs

For every fixed rational 0<a<1/2 and fixed integer d≥1, some language in NP, at infinitely many lengths M, has no exact real linear combination of at most M^d atoms of the following types. Set K(M)=ceil((log log(M+16))^a). Each atom may be a Boolean formula of arbitrary binary gates with at most MK(M) leaves, or an acyclic nondeterministic branching program with at most MK(M) query nodes. Each node queries one named input bit and offers an arbitrary set of successors for each answer. An enabled accepting path means acceptance. Width, input order, repeated queries, fanout and path ambiguity are unrestricted under the total query-node budget. With two canonical terminal nodes, distinct arcs have an explicit description of at most quadratic size times an index length.

Use the [formula projection and hierarchy proof](np-sum-formula-projection.md), including common-denominator rationalization, the universal padded evaluator, a common slot choice, quartic Booleanity and the ordinary-circuit upper under negation. For a branching program count occurrences by nodes bearing a given query label. The same heavy-position averaging and guessing lemma applies to mixed atoms. In each verification product, branch on ≤4δn heavy selected bits and pin the appropriate gate indices. Across the at most four atoms there are now O(nL) live query nodes or live formula leaves, where L=ceil(CK(M)). The following exact counting construction handles the remaining nondeterminism.

For each still-live node u and query value b, compute the set S_{ub} of first-live or terminal endpoints reached after an outgoing enabled edge and any intervening fixed-query nodes. At each fixed node use every successor allowed by its fixed value. Compute the analogous unguarded prefix set from a virtual source. An originally live source itself can be a prefix endpoint. The residual relation is strictly forward and takes polynomial time in the original guessed description. A path exists precisely when the resulting recurrence accepts, by concatenation of enabled path segments.

Give each live node a bit y_u for its acceptance. Conditional on query bit b require y_u to equal the OR of the y_v over S_{ub}, with terminal values treated as constants. The individual implications from each successor use clauses of width at most three. The other direction uses one potentially long clause. Impose the unguarded virtual-source recurrence and pin its answer to one. The empty disjunction is zero. All node values are uniquely determined by reverse topological induction on every original assignment before output pinning, including unreachable nodes. Multiple accepting paths create no extra assignments. Formula factors use ordinary full Tseitin equivalences. The product gives v=O(nL+n) variables, O(v²) width-three clauses and p=O(v) potentially long clauses. Unused original variables remain declared.

Set h=ceil(log₂(n+2)). Remove repeated literals and tautologies. If a clause is wider than h, branch on its first h distinct literals. The first branch replaces it by their disjunction. The second fixes them all false and simplifies. These solution sets partition the satisfying assignments. Each first step permanently removes an over-wide clause. Each second step fixes h fresh variables. The Pascal recurrence bounds the leaves by binom(p+floor(v/h),floor(v/h)), with logarithm O(v log(h+1)/h). This is Schuler's width reduction as analyzed by [Calabro, Impagliazzo and Paturi](https://cseweb.ucsd.edu/~paturi/myPapers/pubs/CalabroImpagliazzoPaturi_2006_ccc.pdf).

At a leaf only p formerly long clauses need attention and each now has width at most h. Choose a fixed integer e>1/(1/2−a) and U the least positive integer with U^e≥h. Encode a clause of length w>3 by the index of its first true literal. Represent the index with e groups of U one-hot bits. Enforce at most one per group by pairwise negative clauses and at least one by a fully defined OR chain with pinned root. For each digit tuple encoding i≥w forbid simultaneous selection of its e digit indicators. For each tuple encoding i<w condition on its e indicators and require by separate clauses that the i-th literal be true and every earlier literal be false. The resulting width is max(3,e+1). A satisfied clause forces its unique first true index, indicators and chain values. A false clause has no extension. Per clause this costs O_e(h^{1/e}) fresh variables and O_e(h²) clauses. Each gadget has private auxiliaries. Empty clauses reject and original clauses of width at most three require no gadget.

The declared dimension is now O_e(v h^{1/e}); the number of clauses is polynomial in n. Do not count split-fixed variables as free. Keep disappeared but unassigned variables free. If necessary pad to at least n variables and divide the exact count by the resulting known power of two. Since s≤2^{εn} implies L=O((log n)^a), the width reduction overhead has logarithm O(n(log n)^a loglog n/log n)=o(n). The arbitrary-density bound of the [October 25 manuscript, Theorem 1.1](https://github.com/openai/math/blob/92b516ef8e/preprints/The-Exponential-Time-Hypothesis-is-False-October-25-2026/build/main_full_version.tex#L68-L82) gives each leaf time

    poly(n) · 2^{O_e(n (log n)^{a+1/e−1/2} loglog n)} = 2^{o(n)}.

All uses of the counter have fixed width for each fixed a. The dense short clauses only affect its polynomial factor.

The complete nondeterministic verification costs 2^{4δn+O_d(εn)+o(n)} as in the [formula proof](np-sum-formula-projection.md). Even an ambiguous syntactically valid guess defines a Boolean atom. For the ordinary circuit upper under the opposing common-exponent assumption, evaluate each original program's backward existential recurrence with O((MK)^2) bounded-fanin gates and then add the rationalized weights. [Williams's moment method](https://arxiv.org/abs/1802.09121) and the [Murray–Williams hierarchy consequence](https://people.csail.mit.edu/rrw/easy-witness-nqp.pdf) give the same contradiction.
