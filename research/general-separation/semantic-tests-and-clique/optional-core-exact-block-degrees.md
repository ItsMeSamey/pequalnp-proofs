# Computing the exact omission radius needed by the degree test

Use the [two-port core theorem](two-port-optional-parity-core.md), its optional components C and k independent aggregate Boolean quadratics q. The omitted-site variables are the nonpins. First test the aggregate system for feasibility by the quadratic counter. An inconsistent system certifies NO. Otherwise let Q be its nonzero unique squarefree indicator. The near-full witness proof needs resilience in C only for up to δ_C deletions, where δ_C is the maximum number of variables from C in one monomial of Q. This is a sufficient radius; an arbitrary instance may succeed even if this resilience test fails.

There is a basis-independent inexpensive upper bound. Restrict the coefficient vector of each row-span polynomial to terms using at least one free variable from C. Let e_C be the rank of this restriction on the row span. Choose a row basis adapted to its kernel. Only e_C factors then depend on C, and each is block-affine, so δ_C≤e_C. The indicator Q is independent of the chosen row basis because it specifies simultaneous vanishing, so this argument gives all block bounds simultaneously even when the adapted bases differ. This bound preserves the 2^k poly(n) solver clock.

The exact δ_C can be computed for every component in deterministic 2^{O(k²)} poly(n) bit operations and polynomial space. Write y for the omission bits in C and w for the exterior bits. The constraints are M_C(w)y=t_C(w). Entries of the k-by-|y| matrix M_C are affine in w since every aggregate monomial has total degree at most two and block degree at most one. For a fixed feasible w the Boolean indicator in y has exact degree rank M_C(w). To see this, perform an invertible affine change of input coordinates expressing the independent equations as the first rank-many affine coordinates. The indicator in those coordinates is the product of independent coordinate-literal indicators. Invertible affine changes preserve algebraic degree: a substitution and its inverse both cannot increase it. Infeasible exteriors give zero. Expanding first in y, the coefficient of each y-monomial is itself a Boolean function of w, and a nonzero coefficient is nonzero for some w. Hence δ_C is exactly the maximum local row rank attained at an exterior admitting a solution.

To compute the attainable ranks enumerate the subspaces U of the binary k-space, for example as reduced row echelon bases. For each U count full aggregate solutions (w,y) for which U lies in the left kernel of M_C(w). This adds only affine constraints on w. Parameterize their solution space or return zero for inconsistency; all remaining k equations are still quadratic under that substitution. Apply the character counter to them on the independent variables. Accumulate these full-solution counts in totals T_i indexed by i=dim U. If N_j counts full solutions whose left-kernel dimension is exactly j, then T_i is the sum over j≥i of N_j times the number of i-dimensional subspaces of a binary j-space. These integer coefficients are computable from Gaussian binomial coefficients and their diagonal entries are one. Downward substitution recovers all N_j with no division. The answer is the largest k−j with N_j positive. Every feasible exterior contributes at least one full solution; its multiplicity need not be normalized. At most 2^{O(k²)} subspaces are enumerated, and outer counters use O(n+k²) bits. The procedure can process subspaces and components sequentially.

For a strict example, take three optional components. C is a four-cycle with no pins and contains a designated free bit u. The others are triangles with free bits a and b, carrying respectively one and two pins on sites distinct from those bits. The only physical core edges connect u to a and u to b. Realize every optional edge by a private length-two path. In selection bits the aggregate equations have independent basis ua,ub. Changing to omission bits preserves the degree in each block. The two dependencies involving C are linearly independent as coefficient vectors, so e_C=2; but the block coefficient matrix has only one potentially nonzero column, and attains rank one at u=0,a=1. Thus δ_C=1. The four-cycle stays connected after any one deletion but splits on two opposite deletions. The other two optional components are cliques and satisfy all their required tests. This illustrates a strict gain in certified graph inputs, without any claim of hardness for the instance itself.
