# Adaptive weight queries and the constructor query boundary

A computation receives q unknown primary bits x. Given only the previous integer answers, a supplied uniform polynomial-time procedure selects a list of at most q affine forms on x and receives their Hamming weight. After at most h queries, another polynomial-time constructor depending only on the transcript supplies a polynomial-size system of XORs of products of affine forms on x. The answer is acceptance by that system. The procedures may use other fixed instance data such as a gate description; in branch enumeration they get no further direct access to x. The following uses the companion theorem for arbitrary dependent lists. [Arbitrary affine weight counting](arbitrary-affine-weight-count.md)

**Counting adaptive computations.** For 1≤h≤q^{1/4}/L⁴ with L=log₂(q+2), the exact count takes deterministic time 2^{q−Ω(√q/(hL⁶))}. Pad early termination by zero queries. For each of the (q+1)^h possible transcripts v construct the corresponding fixed h lists and terminal system S_v. The vector-dependent system for this call is S_v on vector v and the constant false system on all other vectors. A primary input has exactly one truthful transcript by induction, regardless of the behavior on unreachable histories. Summing the counts is exact. In this range A=min(√q,q/h²)=√q, and the added exponent O(hL) is o(√q/(hL⁶)) since h²L⁷/√q≤1/L. All polynomial construction and summation costs are absorbed. This applies to transcript-dependent repetitions, linear dependencies and arbitrary negative correlations between successive lists.

**An explicit universal simulation at larger query counts.** Put k=floor(log₂(q+1)) and split the primary bits into h₀=ceil(q/k) blocks of at most k bits. For one block make a fixed list with 2^j copies of the j-th bit, starting at j=0. Its length is at most 2^k−1≤q and its Hamming weight is the block's binary value. All 2^q distinct inputs therefore give different vectors, and a nonadaptive constructor can recover x exactly and evaluate any supplied polynomial-size circuit C. It returns a constant system giving C(x). This is a uniform polynomial-size construction. For a circuit of size Bq log q it preserves the q inputs and its decision answer. An algorithm running in 2^{q−ω(log q)} at this h₀, including the full cost of this representation, would yield the same infinitely-often E^NP gate lower bound of Ω(t log t) by the unary hierarchy argument. **Why a black-box constructor cannot achieve that extension.** With the fixed lists just built, give the algorithm only oracle access to the constructor on arbitrary transcript vectors, including unrealizable vectors. The constant-false constructor and a constructor returning true only at one reachable vector are indistinguishable until that vector is queried. On the all-false transcript a deterministic exact decision procedure must query all 2^q reachable vectors. Each alternative has polynomial-size code comparing its argument with one hardwired vector. On fewer full blocks the same argument requires at least 2^{min(q,hk)} queries by using zero lists past the last block and ignoring unencoded input bits. This lower bound concerns access to the constructor as a black box. The representation is explicitly given in a putative white-box CircuitSAT algorithm, so it might analyze the code directly. The present positive solver covers a smaller h regime, and gives no unrestricted circuit separation.
