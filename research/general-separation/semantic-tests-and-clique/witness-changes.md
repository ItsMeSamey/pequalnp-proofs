# Stable clique witnesses under edge insertion

Fix the uniform language CLIQUE. A memoryless selector on an N-vertex labeled graph returns a k-clique if one exists and null otherwise. A random seed is drawn once and reused. On an increasing chain count the first nonnull witness and every subsequent change. The chain is fixed independently of the seed. Put M=binom(N,k) and H_t=Σ_{i=1}^t 1/i, with H_0=0.

**Theorem.** If CLIQUE has polynomial-size ordinary circuits on all inputs, polynomial-size seeded circuits select witnesses with at most 9H_M expected changes per fixed chain. Uniform polynomial-time decision implies a uniform randomized polynomial-time selector. Nonuniformly, a polynomial-size menu of seeds per (N,k) can have average at most 9H_M+1 simultaneously on every chain.

Hash each k-set's N-bit characteristic vector into {0,…,2^N−1} with uniform five-wise independent outputs. One uniform construction samples N independent Boolean polynomials, with fair independent coefficients for every squarefree monomial of degree at most four. On at most five distinct vectors the evaluation map of each polynomial is a surjective binary linear map. A product of at most four coordinate or complemented-coordinate tests isolates each vector from the others. This uses O(N^5) random bits.

Select the feasible set minimizing (hash, characteristic vector) lexicographically. Existence of a clique extending a prefix of the concatenated key is in NP: check the proposed vertices, edges and hash. By NP-completeness, the polynomial sequence of prefix queries reduces to ordinary CLIQUE. Small circuits for that language implement the composite computation, handling the polynomially many possible query lengths with padding or multiplexing. Return null if the initial query fails. This implication uses exact decision on all reduced inputs.

Each member of any fixed family of t candidates has selection probability ≤9/t. For t≥2 condition on its hash z, and put Q=2^N. The indicators that the other candidates hash below z are four-wise independent with mean z/Q. Their sum Z has mean μ=(t−1)z/Q. Expanding the fourth central moment gives E[(Z−μ)^4]≤μ+3μ². Thus P[Z=0]≤min(1,μ^(-3)+3μ^(-2)) for μ>0. The z=0 term costs 1/Q. Bound the remaining decreasing sum by the integral. On [0,2] integrate one; on [2,∞) the two reciprocal powers integrate to 1/8+3/2. This gives ≤1/Q+4/(t−1)≤9/t. Selection still requires Z=0 when hashes tie. This constant-factor min-wise estimate is related to Indyk's approximate min-wise constructions. The exact uniform-priority argument uses the familiar one-sample replacement probability. [Indyk](https://doi.org/10.1006/jagm.2000.1131) · [Vitter](https://ittc.ku.edu/~jsv/Papers/Vit85.Reservoir.pdf)

When Δ new cliques make the family size t, a change must select a new one, with probability at most 9Δ/t. Charge Δ/t to the sum of the Δ reciprocals ending at t. This proves the harmonic bound including batches. With m=binom(N,2) there are m! saturated chains; every chain is a subsequence of one and taking a subsequence cannot increase its count. Each seed's count is in [0,m+1]. Hoeffding and a union bound show that O((m+1)^2 log(2m!)) independent seeds have positive probability of giving average ≤9H_M+1 on every chain. Round the menu size up to a power of two if needed. The conclusion is simultaneous for the list average.

## Tight falsification on a slice surviving the theta tests

Join a fixed (k−2)-clique to a bipartite graph on parts of sizes a,b. All core and join edges are present. Activate any subset S of the q=ab bipartite edges. Every k-clique consists of the entire core and one active edge's endpoints. For k≥11 add a disjoint k-clique-free component that passes every depth-h vertex-conditioning theta test: join K_(k−11) to h+1 disjoint copies of the complete join of five pentagons. Its clique number is k−1. One five-pentagon block remains untouched by any h queried vertices. Choose the queried core vertices for inclusion to leave an upper bound of at least k−11+5√5>k after accounting for them. The component changes none of the actual k-cliques. On this slice the decision function is OR and the empty active set is the theta test's one false positive.

**Exact counts.** Every deterministic memoryless selector has a chain forcing q selections. Start with all q edges, remove the selected one and repeat; reversing the order changes the choice at every step. For randomized memoryless selection the minimax expected count on fixed edge permutations equals H_q. On a uniformly random permutation, conditional on the first i edges as a set and on the independent seed, the latest edge is uniform among them. With probability 1/i it is the selected edge, forcing a new selection. Conversely a uniform random priority order on the q edges chooses a new minimum with probability 1/i on every fixed order. This easy exact decision slice rules out deterministic subquadratic memoryless stabilization based solely on exact clique selection when a,b grow proportionally to N. A stateful selector can retain the first edge.
