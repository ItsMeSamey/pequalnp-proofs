# Capped distances for cyclic existential programs after private pinning

Fix the same size, sparsity, b and a<1/2 as in the [feedback-rank result](feedback-rank-programs.md). Replace the feedback-set assumption by an edge-cost promise. Let h=ceil((loglog(M+16))^b). Each displayed edge carries a nonnegative integer cost at most h+1, with larger costs equivalently replaced by h+1. On every complete raw assignment:

1. Each enabled directed cycle has positive total cost.
2. Every state from which acceptance is reachable has an enabled accepting path of total cost at most h.

The acceptance function is ordinary existential reachability. The costs are a nonuniform structural certificate. Arc costs need O(log(h+2)) description bits each, and total description size remains polynomial in M. These hypotheses hold with cost one on departures from a supplied feedback set and zero elsewhere in the preceding result. They also allow arbitrarily many disjoint reachable positive-cost loops, each with a cost-zero exit to acceptance. For instance, a root can branch to any of k separate self-loop states with such exits. The feedback-set size grows with k while every state has an accepting path of cost zero.

Pin each atom privately as in the [global termination note](semantic-halting-programs.md). Retain the live query nodes and the original start. For every retained state u, its designated query value, and a first retained or terminal endpoint v, precompute the minimum nonnegative cost of a path taking at least one enabled edge and having no intermediate retained state. An endpoint u reached again after nonzero length counts as a self-loop. Compute these costs with ordinary shortest paths in the pinned subgraph while stopping at first retained endpoints. Allow an originally fixed source to use its known row. Omit missing segments and cap costs larger than h at h+1. This calculation is polynomial in the displayed graph and works for all guesses, including those with zero-cost cycles.

For every full input x a zero-cost cycle in the reduced graph would lift, by concatenating cost-zero segments, to an enabled raw closed walk with a zero-cost cycle. Each genuine accepting state still has an accepting path costing at most h, because projection replaces its segments by minima. Conversely, every accepting reduced path of cost at most h lifts with its costs intact. Hence the rank labels of the retained nodes are the genuine minimum accepting costs, or infinity. The [capped Bellman proof](feedback-rank-programs.md) applies verbatim to costs in [0,h+1]. Upper inequalities give candidate ranks at most the genuine ones by following a shortest path, and a chain of finite tight edges cannot include a cycle. Every true finite rank fits in the cap.

The private signed compilation from that proof uses O(nL+1) retained states per atom and O_e(n+(nL+1)(h+2)^{1/e}) total variables at fixed width max(3,2e+2), with e chosen so a+b/e<1/2. To preserve soundness on malformed guesses, fix once for each atom, gate index and full live input the private heavy-bit contraction used to form its weighted graph. Its pointwise guessed value is the number of capped rank tables with finite start satisfying the Bellman equations. This is a consistent nonnegative integer even if the semantic cost conditions fail. The switches enforce exactly those equations by cancellation. Pins from other factors are unit conditions or literal substitutions on the original inputs only. Do not change an atom's private first-endpoint graph in response to those pins. Use distinct rank tables per factor occurrence and exact signed parity counts. On valid descriptions the value is precisely the promised Boolean bit. On any descriptions the final quartic moment verifies its weighted sum, so no semantic promise test is required. The rationalization and ordinary polynomial-size circuit upper in the hierarchy contradiction use the genuine Boolean reachability functions. Counts and rational arithmetic have polynomially many bits in the raw descriptions.

Thus the same fixed-exponent NP lower for exact real sums holds for this weighted class and formula atoms, infinitely often for an NP language depending on a,b,d. The proof uses the [October arbitrary-density exact counter](https://github.com/openai/math/blob/92b516ef8e/preprints/The-Exponential-Time-Hypothesis-is-False-October-25-2026/build/main_full_version.tex#L68-L82). The costs certify a restriction. Positive cost on every enabled cycle alone does not place a polyloglog bound on the minimum cost of all accepting paths.
