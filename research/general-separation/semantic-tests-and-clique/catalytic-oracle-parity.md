# An oracle test for a common clean-space coefficient

Let N=2^n and let an oracle return one bit per ordinary query. For each fixed integer D≥1 define a language by
     
    L_D^A(x) = XOR over y in {0,1}^{D n} of A(encode(D,x,y)).

Choose a single injective self-delimiting encoding of triples. For fixed D this is in E^A, since a deterministic machine can enumerate N^D strings with polynomial-in-n cost per query. Draw all oracle bits independently and uniformly once, for the full oracle.

**Conditional uniformity.** Fix n,D and a deterministic adaptive algorithm, possibly nonuniform, whose description and initial state were fixed before drawing A. Suppose it outputs one N-bit string after making fewer than N^D oracle queries, or produces a failure symbol within the same budget. Conditional on any transcript, the vector (L_D^A(x): |x|=n) is uniform on the Boolean cube of dimension N. Indeed at least one bit in each x-block of N^D coordinates is unqueried, even if all queries hit the same block. Conditional on the transcript every unqueried bit is still independent and fair. This applies to adaptive queries to arbitrary oracle coordinates, and to adaptive stopping, by viewing the transcript as a leaf of the query decision tree.

Consequently, for any fixed collection of at most 2^{κN} algorithms of this kind and any p with 0≤p<1/2 and κ+H₂(p)<1, the probability that some output has at most pN disagreements with the true table is at most 2^{−(1−κ−H₂(p))N}. Include all possible advice, initial words, family indices, and fixed decoding data in the enumeration. The union bound is valid even though a selected description may depend on the oracle. The probability bound is summable over n, so with probability one there is no such approximation for all sufficiently large n. One may simultaneously take countably many fixed collections of this form (e.g. each resource-bounded universal machine scheme), and countably many fixed D. No oracle-dependent uncharged advice is allowed.

**Terminal diversity.** Fix C≥0 and b≥0, and one controller encoding whose number of descriptions *with specified initial states* at each n is at most 2^{κN}. Allow deterministic address-dependent oracle transitions with at most N^b queries per tick and arbitrary nonlinear gate operations. Bounded-fanin ordinary controllers with s,g≤αN/n and at most one additional oracle call per tick fit such an encoding for sufficiently small α, provided all its query-address input selectors, including their order, cost O((s+g+n)log(s+g+n)) bits in total. The numerical description bound, rather than a free arbitrary oracle gate of uncharged arity, is the hypothesis.

Suppose a controller has K≥2^s/N^C distinct terminal states on runs successful to pN disagreements. For fixed A the [terminal-diversity clock](terminal-diversity-clock.md) supplies one such initial state with at most N^{C+1} total ticks. Truncate every enumerated initialized controller at floor(N^{C+1}) ticks, marking incomplete outputs as failures. It queries at most N^{C+1+b} bits. Taking integer D>C+1+b gives the conditional uniformity bound above. Therefore for almost every oracle, for each fixed C,b and every sufficiently large n, L_D^A has no controller with the specified terminal diversity, even allowing nonuniform choice of controller and initial state at each n. It suffices to take all integer ceilings of C,b to get simultaneous failure of every fixed common exponent for the indicated encodings. Controller families may instead be bounded intrinsically by a fixed grammar and description length without needing an enumerator to be time efficient.

This falsifies an oracle-preserving argument that all E computations can be compiled with a common amount Cn of initialized state, a sufficiently short description, and distinct restored borrowed states on every successful seed, with all seeds successful (or enough seeds to give the stated K). It rules out the black-box upper even at infinitely many favorable lengths. It leaves the ordinary E simulation question open. The languages here depend on D, which is appropriate for testing one coefficient asserted to work for all languages. The construction does not give a single fixed D defeating arbitrarily large clean-space coefficients. The direct exhaustive algorithm uses O(Dn) initialized bits for its counter and time polynomial in N for fixed D.

**A single-input sharpness test.** To compute the parity of T arbitrary provided bits, suppose a deterministic oracle machine with s state bits starts with c designated bits fixed and the others uniformly arbitrary. Allow ≤1 query per tick. For every oracle require that at least (1/2+γ)·2^{s−c} seeds output the correct parity and have mutually distinct terminal states within this chosen set, for γ>0. There need be no guarantee on remaining executions. Among these representatives at most 2^s/T can take T or more ticks, by the disjoint-state charge for a single output. Truncate all runs after T−1 ticks, outputting a fixed answer on timeout. Its success on each oracle is at least 1/2+γ−2^c/T. A deterministic algorithm with fewer than T queries has success exactly 1/2 under uniformly random data, and random dirty initialization independent of the data preserves that average. Hence 2^c≥γ T. A clean binary index counter, parity bit and constant control attain log₂ T+O(1) initialized bits, independent of how much borrowed storage is available. Counting ticks and representing input addresses in the state are part of this model.
