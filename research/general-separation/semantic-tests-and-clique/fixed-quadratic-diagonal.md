# One fixed quadratic-time question equivalent to P versus NP

Enumerate all explicitly polynomial-clocked deterministic SAT candidates M_i and all explicitly quadratic-clocked deterministic machines A_i, in a fixed multitape model. Include arbitrary multiplicative clock constants. Use a conventional length-ordered enumeration of programs and unary clock parameters so entry i is available in time polynomial in i. In the following computations, simulations of the clocked interpreter itself are capped, so no expensive individual clock must be run to completion at small lengths.

At epoch t assign all input lengths with floor(log₂(max(1,N)))=t one common stage, recording this assignment forever. Initially the stage is even 0. Even stage 2i assigns the empty language. Odd stage 2i+1 assigns ordinary SAT, including its usual malformed-input rejection convention. After assigning epoch t, perform a bounded search to decide whether to increment the stage for epoch t+1. One explicit implementation for t≥8 considers all binary strings z of length at most floor(log₂ t). Their own length epochs are strictly below t and are already recorded. In an even stage compare M_i(z) with brute force SAT(z); in an odd stage compare A_i(z) with the value of the constructed language at z using the recorded epoch for |z| and brute force SAT if required. Simulate at most t elementary interpreter steps per candidate computation, skipping unsettled cases. The SAT truth can also be computed by a fixed brute-force algorithm capped at t steps and unsettled cases skipped. Advance if any completed comparison differs. Before epoch 8 leave the stage unchanged. At a permanent stage every finite input disagreement is eventually examined with adequate simulation and truth-computation time. The rule never changes any previously examined length.

The resulting total language L has a fixed NP verifier. Count N and replay the t+1 epoch assignments, taking only polynomial time in log(N+2) beyond counting the input. There are at most O(t) test strings per epoch, a fixed polynomial simulation overhead, and the stage index never exceeds t. On an even stage reject. On an odd stage run the standard SAT assignment verifier. The construction makes no same-input simulation of an unrestricted polynomial-time machine by the NP verifier.

If SAT is outside P, a stage cannot be permanent. At an even stage a permanent stay would mean M_i correctly decides SAT. At an odd stage a permanent stay would mean A_i correctly decides L, which agrees with SAT except on finitely many input lengths. Both contradict the assumption. Hence every quadratic-clocked machine fails on an actual input of L, forever assigned before the advance.

If SAT is in P, the stage sequence must stop by the even stage for the first correct SAT machine, or at an earlier stage. A permanent even stage makes L finite. At a permanent odd stage A_i agrees everywhere with L, or the search would eventually advance. Either way L is in DTIME(N²). Thus a quadratic-time lower bound for this one total NP language is equivalent to P≠NP. The construction does not prove that lower bound.

## A control entirely inside P

There is even a fixed unary language Q in deterministic polynomial time such that Q is outside DTIME(N²) exactly when SAT is outside P. Run a fixed external scheduler sequentially searching for a SAT counterexample to M_0, then M_1, and so on. Each time it finds the next counterexample, it emits a single event targeting the next A_i; wait if necessary until the current elementary tick N exceeds the description length, number of tapes and clock constant of A_i. The scheduler can implement a conservative explicit delay larger than these fixed values before the event. Never emit more than one event per tick. This mechanism does not evaluate Q.

On unary input 1^N replay the first N scheduler steps, and reject if there is no event at precisely tick N. At an event tick return the complement of A_i(1^N). Reject nonunary strings. This is a fixed polynomial-time machine: the replay is polynomial in N, and at the selected event the clocked raw simulation has at most N(N+2)^2 steps and machine description and tape count at most N. An ordinary universal multitape simulator with fixed polynomial overhead suffices. These are actual input lengths and actual machine answers, with no presumed universal clock covering all polynomial degrees: the targeted clocks are quadratic only. If SAT is in P there are finitely many events and Q is finite. Otherwise every quadratic machine gets its own diagonal input, yet Q stays in P by its larger fixed clock.

Both constructions are variants of delayed diagonalization. Equivalence to the open question does not itself establish a new complexity lower bound or imply that a fixed-degree target is outside P.
