# Directed signed covers for unrestricted cyclic deterministic branching programs

For each query node there is at most one enabled outgoing transition on a fixed complete input. Under a restriction, follow each fixed query according to that unique choice until reaching the first live query or a terminal. An all-fixed deterministic cycle has no accepting exit and can be redirected to reject. The same operation on the initial state handles terminal starts and fixed prefixes. A compressed live query has at most two labelled transitions; arcs with equal endpoints can have distinct query guards. For every completion the compressed deterministic walk accepts iff the original walk reaches acceptance. Consequently any product-specific extra heavy pins preserve the Boolean function even when cycles are enabled. Syntax validation enforces deterministic outcomes but requires no semantic termination promise.

Convert the residual program to genuine arcs to query states and the accepting terminal t, dropping rejecting transitions, plus a new root s with sole outgoing arc to the start and forced closure t->s. If the start is already accepting the root cycle uses s->t; a rejecting start contributes zero. Add one private filler loop at each query vertex. Distinguish a genuine self-loop from its filler. A selected cycle cover chooses exactly one outgoing and one incoming arc at every vertex. Disallow marking filler arcs and the root. Equal incoming and outgoing vertex marks allow arbitrary unions of selected nonroot genuine cycles to be marked. Each such cycle of length l contributes (-1)^l times (-1)^(l−1)=-1 to the signed factor relative to leaving it unmarked. Thus all covers with any nonroot genuine cycle have net weight zero. In every remaining cover the root component consists of a simple path from start to acceptance closed by the forced arc; all outside vertices use their unique filler. This is a bijection to enabled simple accepting paths. Determinism gives at most one such path, including with equal target vertices on the two opposite bit outcomes. Selected genuine arcs must pass their query guard even when unmarked; filler arcs are independent of the input. For arbitrary nondeterminism the same argument can return path multiplicity, not Boolean acceptance.

The marked sign is the sign of the selected permutation restricted to marked vertices, since the marked tails and marked heads form the identical vertex subset. Chunk tail and head orders by vertex then arc ID, with at most O(m^(1/3)) chunks of at most O(m^(2/3)) ports. Within each tail chunk sort marked IDs by destination chunk then ID and take its permutation sign. Within each head chunk sort from source chunk then ID to actual head order and take its sign. Between these sorts, bundles (source chunk,destination chunk) are transposed with order preserved in each bundle. Inverted bundle pairs contribute the product of their multiplicities mod 2, computed at one O(m^(2/3))-degree tensor from bundle parities. This proves the claimed sign. Arc status bits distinguish absent/unmarked/marked and forbid the fourth state. Exactly-one incidence is enforced by local vertex-run scans with unique interchunk accumulators. Query guard ports increase local degrees by at most O(chunk length). One equality-tree per original input identifies all uses across all factor occurrences, with unique internal assignments. Private cover bits prevent correlation of different factors; the same input still feeds every occurrence. Unused original bits supply their factor two by a free tensor wire or by exact outside multiplication. Formula factors can be encoded with constant-arity local truth tables, equality wires for atom inputs and output-one pins. Extra isolated inputs and initial constants need no large tensors.

The [pinned October Boolean tensor contraction theorem, lines 21–44](https://raw.githubusercontent.com/openai/math/92b516ef8e/preprints/The-Exponential-Time-Hypothesis-is-False-October-25-2026/build/quantitative-reduction.tex) assumes a bipartite multigraph, O(s) Boolean wires, degree <=ceil(s^0.9), poly(s) vertices, ring (Z/2^P0 Z)[V]/(V^ell) with P0,ell<=Cs and uniform entry evaluation within poly(s+description length) 2^O(s^0.9) time and polynomial space. Here local entry functions compute the described tests, sums and permutation parities by polynomial-time scans of explicit residual incidence data. The descriptions fit polynomial size after relabeling compressed states. Wire count is O(n+q), q=O(nL) across at most four factors: two status bits per arc, one guard use per genuine transition, mark bits per vertex, one state per split run, at most O(m^(2/3)) bundle bits, equality trees linear in occurrences, and polynomially many local ports but only linearly many total wires. Subdividing all wires with equality tensors gives a bipartite graph and only doubles their number. The maximum degree O(s^(2/3)) is <=ceil(s^0.9) for all large s. Take ell=1 and P0=b+1 where b is the number of free original inputs, or n+1 throughout. Final true counts are nonnegative and <=2^b, so the least nonnegative residue recovers the integer even if intermediate signed multiplicities are enormous. External moment coefficients need not fit this modulus. They multiply recovered exact counts outside the tensor call.

With s=Theta(n+q+1), the counter's bit-time exponent is O(n(1+L)/sqrt(log n)); there is no arbitrary-density-CNF loglog n factor because the construction has linearly many wires. A small absolute c in K(M)=ceil(c sqrt(loglog M)) gives O(C c)n+o(n), with C the fixed heavy-threshold multiplier. Choose delta, C, c and then d-dependent epsilon to preserve the hierarchy clock. Each candidate cyclic deterministic atom is already Boolean and ordinary finite-graph reachability has polynomial-size circuits. No assumption about weighted distances or all-state termination is required.
