# Which strongly connected components survive a change of linked chart?

Fix the physical pin symbols and allow both coordinates on the virtual ports to vary. Project the resulting affine linear solution space onto the coordinate pairs of the remaining real sites F, before imposing their zero-product constraints. Suppose a linked chart expresses this projection as (z,Hz+h), with one independently variable binary coordinate per site. Either member of a site's physical pair can serve as its first coordinate. For every subset A of F,
    
    rank H[A,F∖A] = dim proj_A(L_real) − |A|.

Indeed the first coordinates on A vary freely; once fixed, the second coordinates range over a translate of the indicated matrix image. Swapping coordinates at individual sites changes none of the projection dimensions. Thus all directional cut ranks, including the zero cuts, agree in any such chart for the same physical relation. With an arc i→j when row i reads j, a set is successor-closed precisely when its outgoing cut rank is zero. The smallest successor-closed set containing i is its reachability set, including i itself. The SCC partition and its reachability order are consequently intrinsic. This proof does not apply to changes that discard solutions, alter the physical pin symbols, or mix coordinates of different real sites.

There are physical examples at both extremes. Take independent triples P,Q connected by an identity matching. Each real i∈F connects to P and Q according to rows R_i,V_i of length three. Fix the physical pin input to 111 and output to zero. The chart with free real input z gives virtual input Rᵀz, virtual output 111+Vᵀz, and real output R111+(A_F+VRᵀ)z. Repeat the six types R1,R2,R3,V1,V2,V3 cyclically, where each denotes the corresponding standard row on six coordinates. After the first six sites the port response has full rank six. Every consecutive pair in this linear ordering has zero symplectic pairing. To obtain singleton SCCs, set A_ij=V_i·R_j for i>j and symmetrize, with zero diagonal. This makes H upper triangular. To obtain a single SCC, flip each of those off-diagonal edges. All lower triangular entries of H are then one, and each consecutive pair has reverse entry one as well. In both cases the direct P–Q matching remains after deleting F. Taking three actual outside vertices with independent labels realizes the virtual cross block in a simple graph.

For completeness the six-bit dynamic program uses the order in which a component's external dependencies have already been assigned. For i in the new component and j in a processed one, H_ji=0, so H_ij=C_iᵀJC_j whenever H+Hᵀ=CᵀJC. Their total effect on row i is C_iᵀJσ with σ=Σ_processed C_j z_j. Try assignments inside the new component, test all its zero products, and update σ. The terminal port pair is w₀+σ. Earlier equations are independent of all subsequent bits. Keeping one predecessor per reachable state recovers witnesses, with at most 64 states per stage and time 2^{max SCC size} poly(|F|). The connected examples bound the reach of changing chart for this particular algorithm; they do not bound other algorithms.
