# A unique valid dictionary can still encode adaptive SAT queries

In the [selectable dictionary model](selectable-dictionary-quantifiers.md), allow all choices of a fixed polynomial bit length, but require exactly one valid choice index on every x. Its designated coefficient is a forced Boolean value. The resulting total languages are precisely

    UP^SAT ∩ co(UP^SAT).

Here UP^SAT means a polynomial-time nondeterministic machine with an ordinary SAT oracle and at most one accepting computation path on every input. Only the outer machine is required to be unambiguous. In particular the class contains P^SAT. No strict containment is assumed. Work on multiple notions of unambiguity stresses the significance of the chosen oracle model. [Spakowski and Tripathi](https://arxiv.org/abs/cs/0702047)

For the upper bound, guess the choice index using one nondeterministic bit per position and check deterministically with SAT whether its system is consistent at the requested coordinate value. The coNP check uses the augmented-row certificate in the linked note. The unique-index and forced-bit promises ensure at most one accepting nondeterministic computation on either side. This is unambiguity of the choice index, regardless of how many coefficient vectors or rank certificates a valid list has.

For the lower bound, take unambiguous SAT-oracle polynomial-time machines for L and its complement. A choice contains the side b and a full encoding of one proposed accepting computation of that machine on x. Record every nondeterministic choice, oracle reply, and for each positive SAT reply the lexicographically first satisfying assignment in a fixed-length assignment convention. Fill unused slots and unused assignment bits canonically with zeros. The transition sequence must reconstruct exactly, the terminal state must accept, and each positive witness must satisfy its query. Reject malformed strings, including gratuitous padding choices or incorrect computation lengths.

Correctness of the resulting record is a coNP predicate: a false negative reply is refuted by one satisfying assignment, and an alleged positive witness which is satisfying but not first is refuted by a smaller satisfying assignment. All other defects are checked deterministically in polynomial time. Queries are reconstructed from the proposed transcript, so this applies to adaptive queries. A record passing all the checks agrees inductively with the real SAT oracle. Every genuine accepting computation has exactly one correct record because each positive witness and each unused bit has been fixed canonically. Exactly one of the two machines accepts and it has only one such computation. Hence exactly one index satisfies the coNP predicate.

Use the two-feature construction from the linked note. At index (b,y), use common target t and features 1−t and t AND NOT Φ_bad(x,b,y,z), ordered by b. Here Φ_bad is the bounded-occurrence, width-three accepting-trace encoding for an NP refutation of the proposed record. The index is valid exactly when no refutation exists; otherwise one row has target one and both features zero. Both features have near-linear binary formula size in the padded raw row length, and the valid coefficient bit equals b.

Already for ordinary SAT, a more direct unique choice is the lexicographically least satisfying assignment on the YES side, or a fixed dummy on the NO side if the input formula has no satisfying assignment. Both validity conditions are coNP predicates. Thus unique global selection does not give the same certificate property as uniqueness of a coefficient in one supplied valid list. The explicit enumeration bound and the existential upper bounds survive. No polynomial-time method for finding the unique index follows.
