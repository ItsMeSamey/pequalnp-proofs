# The ambient parity-block evaluator and shared-gate compilation

Let E be the P language on a circuit description, gate index and parity blocks from the frozen base theorem. Its specializations realize every fan-in-two Boolean circuit C on n variables at ambient length M polynomial in n+|C|.

**A necessary class collapse.** If a single fixed polynomial bounds both the sparsity and each atom's leaf count for exact real SUM representations of E at all sufficiently large lengths, then P/poly equals nonuniform NC1. Indeed, polynomial-leaf formulas have bounded-fan-in circuits of logarithmic depth and polynomial size by formula balancing. Replace the weights at that length by the bounded common-denominator integers furnished by the Boolean evaluation matrix and Cramer's rule. Select the signed numerator or zero using each atom bit. Width B=O(S log(S+1)+log S+1) suffices for summing the S signed integers with no ambiguity. In two's-complement representation, constant-depth bitwise carry-save layers replace triples of words by pairs of equal sum modulo 2^B. O(log S) layers leave two words; parallel prefix carries add these in depth O(log B). Test equality to the positive denominator to read out the Boolean result. This is a polynomial-size logarithmic-depth circuit for E. Specializing to any sequence C_n of polynomial-size circuits and pinning all but one slot in each block yields polynomial-size depth O(log M)=O(log n) circuits for that sequence. The inverse containment is immediate. Constant-width polynomial-length branching programs for E also imply the same collapse. [Barrington's theorem](https://people.cs.umass.edu/~barring/publications/bwbp.pdf) · [Formula balancing and circuit/formula separation](https://eccc.weizmann.ac.il/report/2013/169/download/)

**A partial-cutset obstruction.** For each r take 2r logical inputs x_i,y_j; each has a disjoint R-leaf parity tree. Use a gate for each x_i OR y_j and a conjunction tree over all r² gates. This is the direct evaluator specialized to the indicated fixed circuit and output gate, using its natural implementation. The original circuit has size Theta(r²); with R=(2r+s+2)² the ambient length M is Theta(rR). For an arbitrary partial internal cutset Q, let h count the x-parity trees containing a cut gate. For each of the r−h untouched trees, each of its r outgoing incidences reaches a separate occurrence of that whole R-leaf tree in the unfolded defining components or output tree. To see this, each consumer appears at least once in a component, whether or not it itself is cut. Its occurrence expands the selected x-tree without encountering a cut. Hence W >= r(r−h)R. If W <= MK(M), then r−h = O(K(M)). Set every y parity to one. Every input on this slice is accepted. In each touched x-block choose one cut gate; its parity on a nonempty subset of freely variable private input bits attains both values. Their joint outputs range over all 2^h combinations, forcing at least 2^(r−O(K(M))) accepting signatures. Since M is polynomial in r, this exceeds every fixed polynomial in M. No cutset meets both transfer budgets for this realization. The same circuit function has a simple equivalent expression (AND_i x_i) OR (AND_j y_j); this explicitly separates compiler failure from function lower bounds.

**A restricted constructive upper.** With the circuit C hardwired, expand its specified gate into disjoint accepting-assignment indicators. Each indicator conjoins n signed block-parity tests and uses nR leaves (for large n). For a fixed circuit but variable gate index, do this separately for each gate and conjoin its index test. The upper bounds on the term counts are 2^n and s2^n respectively. At lengths with log_2 M >= alpha n the first bound is M^(1/alpha), yet alpha shrinks with the gap algorithm's epsilon. Listing all 2^n patterns costs at least 2^n and does not achieve the fractional time saving. Moreover, separate hardwiring does not construct one sum valid on all ambient descriptions. The general E upper remains open in this audit.
