# Common seeds for bits of a hierarchy witness

Use the unary H and the fixed local clause decoder of the October 25, 2026 manuscript (quantitative-circuits.tex, proof of the quantitative circuits corollary). H belongs to NTIME(2^n) and lies outside NTIME(2^(n/2)). On 1^n, the decoder constructs an exponentially long 3CNF implicitly. A clause index has n+O(log n) bits. Each variable label has dn bits for fixed d; every index decodes in polynomial time in n. The encoded formula is satisfiable exactly on the YES lengths of H.

The manuscript's bit language W takes a single label of length dn. It expands the clause list, queries SAT, and recovers the lexicographically first assignment through at most 2^(dn) satisfying-extension queries with exponential input length. This establishes E with an NP oracle. Under P=NP those queries run in deterministic exponential time measured in the bit-address length. A seed-based substitute need never establish lexicographic minimality.

Fix a total Boolean bit predicate B(1^n,s,i) in PH with its usual fixed machine, alternation count, and polynomial clock in the total query length. Suppose for every sufficiently large YES length there exists one string s of length at most 2^o(n) for which i ↦ B(1^n,s,i) satisfies every decoded clause. The little-o bound is uniform across these YES lengths. Every s and every NO length can otherwise behave arbitrarily. These assumptions imply NP≠coNP and hence P≠NP.

Indeed BAD(1^n,s) guesses one clause index and tests whether the three B values violate it. This language is in PH by closure under complement, constant Boolean combinations and an outer existential quantifier of polynomial length. GOOD, the complement of BAD, also lies in PH. Under NP=coNP, PH=NP, so GOOD has a nondeterministic algorithm running in time O((n+|s|+2)^c) for a fixed c≥1. On 1^n guess a seed of variable length up to 2^floor(n/(4c+4)), with time polynomial in n per guessed bit for bookkeeping, then run the nondeterministic GOOD algorithm and accept on an accepting path. On every NO length each seed gives a total assignment and some clause is violated. On all sufficiently large YES lengths there is an eligible seed. Hardwire finite exceptions. The nondeterministic runtime is O(2^(n/2)), contradicting the hierarchy language. For polynomial-length seeds the same argument places H in PH directly. Addresswise existential choice of separate seeds fails, for example on an exactly-one-of-two-bits constraint where both coordinates individually can equal one.

The hypothesis is unproved. Supplying the entire satisfying assignment gives an unconditional evaluator reading one indexed seed bit, but its full 2^(dn)-bit seed exceeds the bound. No circuit-size conjecture occurs in the implication. For the separate source gate estimate, if seed length k is a fixed explicit function of n and arguments use a unique length B=dn+k+O(n), hardwiring one successful seed into the circuit at that length gives a circuit on dn free inputs for some satisfying assignment, which suffices for the source clause-violation test. The source argument forces Ω(n sqrt(log n)) gates infinitely often. Linear seed length preserves Ω(B sqrt(log B)); k=o(n sqrt(log n)) preserves a superlinear bound. If fixed bits or constants introduce a constant gate overhead, the asymptotic bound persists.

## Why a separate evaluator for each exponential rate is insufficient

Fix any constant ε>0. Let an evaluator on (1^n,s,i) simulate the source E-with-NP-oracle machine for W(i), cutting it off after (n+|s|+|i|+2)^k steps for a fixed k. Return zero on cutoff or malformed input. Since |i|=dn and the source runs in 2^{O(n)} time, choose k large enough that |s|=ceil(2^{εn}) supplies enough time for all sufficiently large n. This gives an unconditional P-with-NP-oracle evaluator for each fixed ε, with the all-zero seed at that length. Under NP=coNP that evaluator language is in NP; under P=NP it is deterministic polynomial time on its actual tuple input. The fixed constant k may grow without bound as ε decreases. The construction supplies neither one fixed evaluator with subexponential seed length nor an NP evaluator without the class-collapse assumption.
