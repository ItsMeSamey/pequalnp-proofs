# Modular weight reduction introduces an extra threshold layer

For an exact real Boolean SUM on S specified Boolean atoms, selecting independent columns and a nonsingular evaluation minor gives integer numerators and a common nonzero denominator H with O(S log(S+2)) bits. [Williams](https://arxiv.org/pdf/1802.09121) For each prime p not dividing H, reduce the same representation modulo p. A polynomial-size prime suffices since the log of the primorial through x grows as Θ(x), while log |H|=O(S log(S+2)). A prescribed prime can fail. On p+1 active row labels let the atom matrix be J−I with target one; add an all-zero row with target zero. Real weights 1/p work. Summing the active equations modulo p gives 0=p+1, impossible. Conversely XOR is linear on two input bits modulo two but has no real affine expression in those same bits.

Lifting the reduced coefficients to 0,…,p−1 gives an integer T between zero and Sp. Test the desired residue using the sum of [T≥j]−[T≥j+1] over relevant integers j. The result is a bounded-weight sum of polynomially many threshold gates on the original atoms. It does not give a bounded-weight real sum on the original features. A more general weighted threshold gate also has a polynomial-size depth-two majority simulation. [Goldmann and Karpinski](https://doi.org/10.1137/S0097539794274519)

For the [balanced independent lookup target](independent-isa-all-lengths.md), let G count all accepting banks. G equals the sum of the bank/primary-row lookup predicates, each an O(m)-leaf formula in its bank. Parity(G)=sum_(j=1)^r(−1)^(j−1)[G≥j]. Thus only r thresholds suffice at this extra layer, with unit coefficients and an optional constant for complemented parity. Under uniform inputs G is binomial(r,1/2). The correlation E[(−1)^G [G≥j]]=(−1)^j binomial(r−1,j−1)/2^r by Pascal cancellation. This has magnitude Θ(1/sqrt(r)) at a central j. The primitive-atom correlation bound therefore fails across an extra threshold layer. These fixed-dictionary and layer-change controls give no unrestricted signed sparsity conclusion.
