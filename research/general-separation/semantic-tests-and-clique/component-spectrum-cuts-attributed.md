# Arbitrary switched graphs with few component-count values

Let nonempty undirected graph H have literal-switched or constant edges. All vertices remain present. Suppose the number κ(x) of enabled spanning components takes at most B distinct values over inputs x. The atom applies an arbitrary supplied Boolean table f to κ. There is no topological restriction. The coloring identity used below is the zero-field Potts component expansion. [Random-cluster expansion](https://arxiv.org/abs/1005.5470)

For each integer j≥1 anchor one distinguished vertex to color 1, give every vertex one of j colors and impose equal colors across enabled edges. The extension count at fixed x is j^{κ(x)−1}. If possible counts are a₁<…<a_t with t≤B, the integer matrix V[i,j]=j^{a_i−1}, j=1,…,t, is nonsingular. A nonzero left-kernel vector would give a polynomial with ≤t monomials vanishing at t distinct positive numbers, against Descartes' rule of signs. Solve Vα=(f(a_i)) exactly. The entries have O(|V|log(B+2)) bits and determinant bounds and rational elimination have polynomial ambient bit complexity. Then Φ_H(x)=Σ_j α_j j^{κ(x)−1} agrees with f(κ(x)) on the promise. Every guessed list defines one rational Φ_H on every input even if that list is wrong.

A j-coloring tensor uses O((|V|+|E|)log(B+2)) Boolean wires, plus input bits. Use canonical binary colors with unused codes rejected, bounded-degree copies and one conditional equality per edge. Each coloring extends uniquely. Under pinning, contract fixed-enabled edges and delete fixed-disabled edges and self-loops. Keep the distinguished anchor class even if isolated, and discard all other isolated quotient vertices, counting h discards. At most 2q+1 vertices remain for q live edges. Multiply each residual coloring count by j^h outside the contraction to restore its raw meaning on every input, including for wrong spectrum guesses. This external scalar has polynomial ambient bit length.

## Direct counting and exact discovery of the support

For n free input bits let m_j=Σ_x j^{κ(x)−1}. Each m_j uses one sparse coloring tensor with size parameter s=O(n+(m+v)log(B+2)) and bit precision O(s), since its integer count is ≤2^n j^v. The October contraction theorem gives deterministic poly(description)·2^{O(s/sqrt(log(s+2)))} bit time and polynomial space. Compute m_j for j=1,…,2B+1. These are exact nonnegative integers. [October tensor theorem](https://github.com/openai/math/blob/92b516ef8e/preprints/The-Exponential-Time-Hypothesis-is-False-October-25-2026/build/quantitative-reduction.tex)

This LP uniqueness is a finite-grid specialization of the published nonnegative sparse-measure theorem for Chebyshev systems; the palette functions j^e are exponentials with distinct real exponents in e. An elementary proof follows here for the integer grid. [Eftekhari, Tanner, Thompson, Toader and Tyagi](https://arxiv.org/abs/1804.01490) · [de Castro and Gamboa](https://arxiv.org/abs/1103.4951)

Find any rational nonnegative vector H indexed by e=0,…,v−1 such that Σ_e H_e j^e=m_j for all these j, using polynomial-time rational linear programming. The true histogram is feasible. If one feasible vector has at most B nonzero entries, any other differs by a polynomial with negative coefficients at ≤B positions (subtract the sparse vector from the other). It has ≤2B sign changes yet vanishes at 2B+1 positive arguments. By Descartes the vectors coincide. Therefore a sparse solution obtained by the LP is exactly the histogram, and if the LP returns a nonsparse solution then the true histogram is nonsparse as well. This tests the promise without prior knowledge of the support. On promised graphs, taking the table-weighted sum of the recovered histogram gives the exact answer. Bounds B≤v can be imposed without loss. Coefficient and measurement bit sizes are polynomial; the LP overhead fits the stated algorithm. This nonnegative moment argument concerns histogram support, not arbitrary signed input weights.

For each fixed d, some language in NP lacks at infinitely many lengths M a pointwise exact real SUM of M^d such promised atoms, also when mixed with earlier binary formula and cyclic deterministic query-program atoms at the clean sparse endpoint. This proof uses the sparse contraction theorem for its inner counts.

Its sum is nonnegative ≤2^n times the product of j^{2q+1} over the chosen factors, regardless of the guessed supports. Thus O(n+Σ(q+1)log(B+2)) bits suffice for exact integer decoding, within the linear wire-parameter precision cap. Multiply the j^h factors and α_j rationals outside the contraction. Each malformed guess still has one fixed raw Φ_H in all products, so the quartic range and gate-consistency tests retain soundness. ## Unrestricted modular connectivity at a small palette

For any integer polynomial F(X), the w-th forward difference Δ^wF(0) is divisible by w!, by Δ^w X^e at zero = w! S(e,w). Taking w least with ν₂(w!)≥p gives

    F(0) = Σ_{j=1}^w (−1)^{j−1} binom(w,j) F(j)   modulo 2^p.

This applies to F(X)=Σ_x X^{κ(x)−1} with no promise on its support. F(0) counts connected enabled graphs, with each x counted once. Each F(j) uses rooted ordinary j-color counts: dividing an even unrooted value modulo 2^p would be invalid. Thus O(p) palettes and O((m+v)log(p+2)+n) wires suffice per direct modular count. The least consecutive maximum palette is necessary for universal linear reconstruction: the polynomial ∏_{j=1}^{w−1}(X−j) vanishes at smaller positive palettes but its constant term has valuation <p. Rooted edgeless graphs with e+1 vertices realize each monomial X^e. This does not bound graph-specific algorithms. To recover the exact count of up to 2^n inputs by this route requires p≥n+1, incurring a log n factor at every color interface. [Factorial connectivity separators](growing-apex-precision.md)
