# Certifying conditional surjectivity by eliminating local gate inputs

Consider a Boolean DAG with outer part H(z,y), where z are retained input bits and y are designated wires. The remaining primary bits are to be eliminated. Cut the inner DAG into supplied local gate subcircuits; every signal crossing a cell boundary is a named port, including shared wires with any fanout. Keep primary bits used in several cells as shared ports too. The other private primary bits belong to only one cell. Check gate ownership, port wiring, and the cut to the outer DAG. For each cell compute the relation on its ports by eliminating its private primary bits: a row is feasible exactly when some local assignment gives the prescribed outputs on its specified inputs. Retain one such assignment for each feasible row. This costs polynomial gate-evaluation time times 2^{w_i+p_i} for a cell of port count w_i and private primary count p_i. For instance cells with w_i+p_i=O(log q) and polynomially many gates fit a polynomial preprocessing clock on q inputs.

The join of the local relations on named ports describes the realizable assignments exactly. In the reverse direction unite the stored witnesses, which agree on every shared wire and use disjoint private primary bits, then apply topological induction to the original gates. A port can be complemented globally before the following tests; all its occurrences use the same sign. The orientation is supplied or taken to be the identity. This theorem need not find an orientation when only its existence is promised.

**Meet-closed projected cells.** Suppose every local port relation is closed under bitwise AND in that orientation. Equivalently it is Horn. The accepting rows of a Horn formula are closed under meets. Conversely, to exclude an infeasible row t, let A be its 1-positions. If no feasible row contains A, use the negative clause forbidding that conjunction. Otherwise the meet of all rows containing A is feasible. It differs from t in a coordinate j outside A, so impose the Horn implication A⇒j. Doing this for every infeasible row yields an exact local Horn formula. The construction and equivalence check cost polynomial time in the explicit table size. An empty relation is covered by the false clause.

Put d=|z|+|y| and regard t=(z,y) as a single requested vector. The inner DAG is conditionally surjective, meaning every z admits every y, exactly when the joined Horn system has extensions of 1^d and each of the d vectors with a single zero, in oriented coordinates. Necessity is immediate. For sufficiency, solve the d+1 pinned Horn instances and store their entire port assignments. For any requested t take the meet of the stored solutions for its zero positions, using the all-ones-target solution when t has no zeros. This solves every local relation and realizes exactly t. Undo the port orientation, retrieve each local witness, and obtain original private primaries. The meet applies to projected port solutions; privately stored witness rows can use quite different gate assignments. Horn feasibility here can be tested by forward chaining from positive units until no further implication applies, checking negative clauses. No enumeration of the 2^d target vectors is required.

**Binary-clause variant.** If each projected cell instead admits a 2-CNF, construct it by taking all entailed unary and binary clauses and checking the resulting table; use an explicit contradiction for an empty relation. The whole join is 2-CNF. Test every assignment to each pair of distinct coordinates of t, using pinned 2-SAT. Use individual pins when d=1 and an unpinned feasibility test when d=0. These O((d+1)²) tests are necessary and sufficient. For a fixed target, any prescribed subset of at most two coordinates has a matching full port solution. Induct on subset size: for a larger subset omit each of three distinct coordinates in turn and take the coordinatewise majority of the three matching full solutions. Each target coordinate is correct at least twice, and every binary clause is preserved under majority. Thus there is a full extension. To lift a particular target efficiently, solve the joined 2-CNF with that entire target pinned and use the stored local witnesses. The closure principles used here are elementary Horn and bijunctive facts; the application is to projected cells and the SAT frontier.

**An overlapping original DAG where controls must change.** For r≥3 arrange r shared private controls cᵢ on a ring, give each cell one further private primary pᵢ, and compute

    yᵢ=(cᵢ AND pᵢ) OR (cᵢ AND cᵢ₋₁).

The gate DAG has 3r binary gates, the cᵢ feed adjacent cells, and the final OR graph relation alone is not meet-closed. Distributivity rewrites the output to cᵢ AND (pᵢ OR cᵢ₋₁). Eliminating pᵢ gives exactly yᵢ⇒cᵢ and (cᵢ AND cᵢ₋₁)⇒yᵢ, both Horn. Every target has the explicit lift c=y, p=1. No single fixed c allows every target by varying p: the all-ones output requires c=1, which forces every output to one. Nor are fibers uniform. The all-ones target has 2^r preimages, while all-zero has at least 2^r+1 (take c=0 with arbitrary p, or exactly one cᵢ=1 and p=0). Thus the rule can strip 2r private bits to r selected outputs even when no fixed controls route independent pivots. A uniform rule that only checks the d+1 extreme targets without a closure certificate would fail, for example on the three-bit image consisting of all tuples except 000.

Once either certificate passes, solve H on q−p+r inputs, where p counts all removed primary bits and r=|y|. The gate subcircuits and all semantic table sizes are charged in the preprocessing; a residual witness lifts in polynomial time in those sizes. The transformation preserves decision.
