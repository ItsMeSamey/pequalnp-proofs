# A computable repair compiler for signed literal interfaces

Convert any bounded-fanin ordinary Boolean circuit to a binary negation-normal DAG of size O(s), using complementary gates where needed. For a node g let P_g,N_g contain the variables appearing below it as positive and negative literals and let V_g=P_g∪N_g. For an AND with children u,v set Γ_g=(P_u∩N_v)∪(N_u∩P_v). For an OR use Γ_g=∅. Initialize all B_g=∅ and process parents before children. For every child u of g insert (B_g∪Γ_g)∩V_u into B_u. Unite the insertions from all parents before processing u. Define w=max_g|B_g|. All sets can be computed by bitset operations on the original DAG including shared nodes.

**Theorem.** This circuit admits a deterministic construction of a monotone circuit of size O(s 4^w) for its upward closure U_C(x)=OR_{y≤x} C(y), counting all original nodes in s. For a monotone target the result computes the target exactly. The running time is polynomial in the original description and 4^w.

A parse selects one child at each OR and both at each AND in the formal unfolding. For each gate g and assignment a on B_g construct a monotone function accepting x precisely if there is a consistent parse term whose positive variables lie in x and whose literals on B_g agree with a. A positive leaf i gives x_i unless a fixes i to zero. A negative leaf gives one unless a fixes i to one. In either excluded case return zero. Constants keep their values. At g enumerate joint assignments b on B_u∪B_v. Use each child's entry for the corresponding restriction of b, apply the original gate and OR its result into the parent entry indexed by b restricted to B_g. Here B_g⊆B_u∪B_v because each variable present at the parent propagates to each child mentioning it.

At AND, two internally consistent terms disagree only on a variable in Γ_g, present in both child interfaces. A joint assignment rules out every such conflict. Conversely a consistent pair can extend its literals and the parent assignment to a joint assignment, since each parent variable used by either term was propagated to that child. At OR, interface variables unused by the selected child can be assigned freely subject to the parent assignment. Different occurrences of a shared node can select different parse witnesses, exactly as in a formal distributive expansion, while the table for that gate is computed only once. A consistent root term with positive support P is satisfied by setting exactly P to one. Conversely each satisfying subassignment yields such a term, proving the root identity. There are at most 4^w joint assignments per gate and each contributes a constant number of gates.

Formal DNF terms and the link between contradictory terms and hazards have prior treatment. Jukna and Lingas give a different reduction parametrized by the negative literals needed in extensions of minterms. The present bound uses syntactically computed, per-gate consistency interfaces. [Jukna on hazards](https://arxiv.org/abs/2012.10976) · [Jukna and Lingas on bounded negation width](https://doi.org/10.1016/j.jcss.2022.05.003)

**Forcing and falsification.** A circuit accepting all single k-cliques and rejecting all (k−1)-colorable graphs has upward closure separating the clique and coloring promises. For N=(k−1)v graph vertices and 5≤k≤v^(1/4), padding the v-vertex tests with isolates transfers the standard promise lower bound. Thus s 4^w ≥ v^(Ω(√k)) up to constants. Every polynomial-size implementation correct on those promises has some gate of width Ω(√k log v) at k=floor(v^(1/4)). The polynomial-time theta separator meets precisely the correctness assumptions here and, for fixed h, can also be made exact on every graph within h vertex deletions of perfection. Thus promise correctness cannot force a cheap interface redesign even if one may replace the entire circuit. No bound for ordinary CLIQUE circuit size follows. [Krajíček and Oliveira](https://arxiv.org/pdf/1704.06241)

A fixed-set variant is input-sensitive. For a negative graph B whose subgraphs are all rejected, consider each parse with positive support P⊆B and negative support Q. Its conflict set P∩Q is nonempty. If some H of t variables hits every conflict set, condition the circuit on all assignments to H. In each cofactor replace remaining negative literals by one, AND the result with the positive inputs demanded by the assignment, then OR the branches. The resulting monotone filter accepts all original positive inputs and rejects B, with size O(2^t(s+t)). Conversely a conflict set disjoint from H permits a consistent branch for that term and makes the filter accept B. AND-ing all filters for sets of size at most t works even when the chosen H depends on B, at cost O((2m)^(t+1)(s+t)) for m input bits. A fixed small decision tree can improve repair depth. If d address bits select one of 2^d contradictions y_j AND NOT y_j, its formal conflict sets at the all-ones input are 2^d singletons. Reading the address and then the selected y_j uses d+1 queries per path and O(2^d) tree nodes.
