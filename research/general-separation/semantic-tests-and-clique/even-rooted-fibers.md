# Even minors on prescribed terminals

Let A be any simple graph over the binary field, P its named pins, and F the other vertices. Write f(d)=det(A+diag d). The [constructive diagonal completion](three-fragile-diagonal-completion.md) says that an induced-even vertex set containing P exists exactly when some f(d)=1 has f(d+e_i)=0 for every i in P. Its witness is diag((A+diag d)⁻¹).

Fix any exterior bits d_F with at least one feasible pin choice z. Set M=A+diag(d_F,z). For S⊆P the determinant-update lemma gives

    f(d_F,z+1_S) = det((I+M⁻¹[P,P])[S,S]).

If z is isolated, then the matrix on the right has zero diagonal. An odd-order alternating matrix is singular. Thus every feasible pin choice has the same Hamming parity as z. Conversely, a nonempty pin fiber of constant parity has every feasible point isolated in every pin direction. This works for any number of named pins. With three pins, an entire successful fiber is a nonempty subset of one of two four-element parity classes. This criterion permits replay from any feasible pin choice in that fiber.

For a global nonsingular base M₀ choose K=I+M₀⁻¹. One can find the base starting at A, flipping a position on some kernel vector whenever the matrix is singular, thus increasing rank. Principal feasible subsets of K now index all feasible d by symmetric difference from the base. Fixing inclusion of exterior elements followed by their removal, and deleting the other exterior elements, gives an ordinary minor of this binary delta-matroid whenever that fiber is nonempty. Conversely every such sequence on F with a nonempty result is a nonempty fiber for some exterior assignment. The latter statement allows the usual convention for loops or coloops, since one can instead fix their forced choice. Success means obtaining any even minor on exactly the original labels P. A twist on the retained labels preserves whether every feasible set has the same parity. If E and O denote the exterior sets admitting an even and an odd pin extension respectively, the problem is exactly finding a member of the symmetric difference E△O. Any such exterior gives an original witness by checking its pin choices and using the inverse. This pin enumeration takes constant time times the matrix evaluation cost when |P|=3.

## A projection obstruction on original graph instances

Even-terminal projection need not be binary representable. Take the symmetric block matrix K with zero diagonal blocks, whose 3-by-4 cross block B has columns e₁,e₂,e₁+e₂,e₁+e₃. Principal feasibility with an even number of the three terminals selects either the empty exterior or any exterior pair. The columns are nonzero and pairwise distinct, so each pair has an invertible row minor. In a normal binary symmetric representation of this projected family the diagonal would be zero and all off-diagonal entries one. But four-by-four loopless complete adjacency is nonsingular over the binary field, contradicting infeasibility of the four-set. Because the empty set is feasible, any twisted binary representation can be put in normal form by pivoting on its feasible twist set. This K is already of the required physical form. I+BBᵀ has rows 011,110,100 when written as rows (0,1,1), (1,1,0), (1,0,0) and is invertible. Thus M₀=(I+K)⁻¹ exists, and removing its diagonal yields the physical graph. The usual delta-matroid projection retains subsets with some feasible extension. Projection across a prescribed parity and equality of two such supports require further arguments. [Koana and Wahlström, STACS 2025](https://doi.org/10.4230/LIPIcs.STACS.2025.62)

## Deterministic elimination for small physical cuts

Write B=A[P,F], b=A[P,P]1, and c=Bᵀ1. Setting every pin to one leaves Bx=b on the free bits, and selected free vertices must have degree parity c in the selected free subgraph. Reject b outside im B. For c=0 and rank B≤2, apply the [constructive two-readout solver](two-readout-even-p3.md). For c≠0, handshaking on the free subgraph implies cᵀx=0 for every permitted support. This is a nonzero linear combination of the equations Bx=b and its required right side is indeed 1ᵀb=0. When rank B≤2 at most one further independent affine equation remains. Use the [constructive mixed-parity one-readout solver](symmetric-single-row-p3.md). In each case append the original pins to the constructed free support. The deterministic polynomial bound holds for any number of pins at physical cut rank at most two.
