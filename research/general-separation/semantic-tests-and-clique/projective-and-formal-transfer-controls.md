# Formal coefficient extraction and projective incidence on Boolean promises

The seven-terminal [permanent-to-grove reduction](../../arithmetic-groves/seven-terminal/permanent-to-grove.md) uses the local weighted signature I+x(1−x)D, with x respectively L X_ij, M, or R. Its Nth host requires 3N active gadgets for an accepted gluing, and its formal coefficient [L^N M^N R^N] is c_N Per_N(X) with c_N positive in characteristic zero. On Boolean inputs to the matrix and the three tags, every x is zero or one, so every active contribution vanishes. In particular at X equal to the identity the formal coefficient is nonzero while all Boolean tag evaluations are zero. An algorithm supplied only the Boolean-cube evaluation oracle for an unspecified polynomial therefore cannot recover this coefficient in general: even the zero polynomial has the same oracle. Other encodings or direct access to the graph structure are outside this obstruction. [Formal arithmetic manuscript](https://raw.githubusercontent.com/openai/math/main/preprints/Circuit-lower-bounds-for-Hamiltonian-cycle-and-the-permanent-November-24-2026/build/intro.tex)

For classical PG(2,q) put N=q²+q+1 and promise exactly one marked point and one marked line. Its ordinary Boolean incidence predicate has O(N) gates for every prime power q. Normalize each homogeneous triple by making its first nonzero coordinate one, giving chart sizes q²,q,1. Encode the remaining field elements in ceil(log₂q) bits in each coordinate, padding unused cells with zero flags. The padded arrays have O(N) entries. On each shore form complete binary OR trees over the chart flags. The OR of the right-child flags at a depth gives that bit of the occupied chart address and zero for an empty chart. The total number of these child flags over all levels is O(N), so extracting all coordinate bits and selecting the chart costs O(N). Check the dot product in the field on the recovered homogeneous coordinates. For q=p^e, binary arithmetic modulo p and schoolbook polynomial arithmetic modulo a fixed irreducible degree-e polynomial use poly(log q) Boolean gates. This is a nonuniform size upper bound; a relabeling permutes input wires.

On this same one-hot promise, the complement of a flag is the OR of the other flags on its shore. All complementary rails can be built in total O(N) shared prefix/suffix OR gates. Computing both rails of each two-input Boolean gate from its four truth-table rows costs O(1) monotone gates. Thus ordinary size s yields monotone total size O(s+N) on the promise. Its input preprocessing can itself branch Θ(N) wires. The [projective branching-wire theorem](../../one-hot-circuits/fork-graph/projective-plane-basins.md) concerns minimum branching wires near N, compatible with the displayed linear ordinary total size. This resource obligation and the one-hot promise must be retained when comparing to unrestricted circuit results.
