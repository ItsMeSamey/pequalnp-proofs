# Exact quadratic solver across flexible components of the original graph

Use the direct edges H and the flexible chain graph L on branch sites B from [Selecting the branch vertices](native-flexible-chains.md). That construction works on every input and preserves all feasibility tests for an occupied branch set. The following algorithm permits arbitrarily many direct edges across distinct flexible components, with arbitrary binary interaction matrices.

Form the connected components C of L using all branch sites. In each C accept either of two certificates.

* The simple graph underlying L[C] is complete, including the one-vertex case.
* There is a connected set T in L[C] that dominates C. Each member is either mandatory or has no neighbor outside C by a direct edge. To recognize the certificate, take the connected components on the allowed sites and test if one dominates C. Enlarging a connected dominating set inside its allowed component preserves domination.

Impose occupation of all old pins and all chosen T. Let x_i be the branch occupancies, substituting one at every imposed site. For each C impose a Boolean-field equation f_C=0: sum x_i x_j over all direct edges with one endpoint in C and the other outside. Every assignment satisfying the equations yields an original witness. In a complete component the selected sites form one connected set in L or are empty. In a dominated component they contain T and are connected. Each equation gives exactly the required parity on the sole occupied flexible component in C. The spanning-forest construction on the selected sites recovers actual chain interiors.

Conversely suppose W was a feasible original branch set. Add all imposed T sites. Any newly added site has no crossing direct edge since mandatory sites were already selected. Every crossing direct-edge contribution stays unchanged. Summing the previous valid parity tests over the components of L[W] inside C proves f_C=0 at the enlarged set.

Collect the coefficient vectors of the squarefree degree-at-most-two polynomials f_C, including constants. Compute a basis f_1,...,f_r by binary elimination. The number of feasible assignments on the b free branch sites with the imposed equalities is the sum over all r-bit z and b-bit x of (-1) raised to the power sum_j z_j f_j(x), divided by 2^r. Each inner quadratic sum over x takes polynomial bit time. If the polar form has a pair of directions with pairing one, split off that symplectic pair orthogonally to the complement. A term uv+au+bv contributes 2(-1)^{ab}, with the global constant retained once. On the residual radical a nonzero linear part gives zero and the zero linear part contributes its full cardinality. Partial sums have O(b+r+1) bits. Repeatedly set a free bit to zero and test positivity, retaining that bit as one only if needed. Substitution never raises the span rank. This reconstructs an original witness in deterministic 2^r poly(|V|+|E|+1) bit time and polynomial space. The formula counts the imposed branch patterns once each, without counting different interior assignments giving the same pattern.

The rank is at most the number of flexible components minus one whenever B is nonempty, since every crossing term appears twice. This gives polynomial time for O(log(|V|+2)) components meeting the certificates. It also applies after guessing k supplied unpinned branch bits: remove the zero sites, make the one sites mandatory and recompute the two edge systems on surviving branch sites by restriction. Chains ending at a removed site may be left vacant because their only possible contribution at an occupied other endpoint is zero. If all resulting assignments meet the certificates with rank at most r the total is 2^{k+r} poly(|V|+|E|+1). Otherwise a failure to find a witness by certified branches leaves the other branches unresolved.

For example take two disjoint groups each of m≥4 branch sites and add a fresh length-two path for each same-group pair. Put three independent direct edges across the groups. Require both ends of the first and a third site away from all three edges (take m≥5 if needed). Selecting every branch site fails cut parity. Selecting the pins and both ends of the second edge gives a valid support after the forest lift. If the first edge is the only crossing edge, the prescribed endpoints force NO. Both examples have rank at most one. When L has isolated vertices at every original site the equations reduce to the native local guards, and the rank can grow with the input.
