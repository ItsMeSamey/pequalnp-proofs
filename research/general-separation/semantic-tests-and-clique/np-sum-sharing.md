# A sharing-sensitive transfer to exact sums of Boolean circuits

Base result used: the per-formula, per-atom leaf-bound theorem at SHA-256 1d2c693f2fa646b2c78058b09ff86d9ecb21906df5ce24b2ff422b05ade99250. Write A(N) = N ceil((log log(N+16))^(1/3)).

**Lemma.** Trim a single-output fan-in-two Boolean DAG to its output cone. Count each primary-input wire occurrence separately, including repeated arguments in the same gate. A direct input output counts as one occurrence. For any selected set Q of internal gates other than the output, form defining trees for the output and each q in Q: unfold its inputs recursively but stop immediately upon encountering a gate of Q as an argument. Let W be the total number of original-variable leaves of all these trees, with multiplicity; placeholders for Q and constants contribute zero. Let T+ be the collection of joint Q-output vectors actually attained on inputs accepted by the DAG. The DAG function is pointwise the sum of |T+| Boolean formulas, each with at most max(2,W) leaves, with all coefficients one. The empty sum denotes zero. The formulas have pairwise disjoint supports. In particular, when Q contains every internal gate with fanout at least two (counting wires), W equals the number of primary-input wire occurrences of the trimmed DAG.

**Proof.** For t in T+, replace each placeholder in each defining tree by its coordinate of t. Conjoin the output test with one test that the defining tree for q equals t_q, for every q in Q. For fixed x all defining equations hold for exactly the actual joint values: the true values satisfy them and induction through Q in a topological order forces each bit. The final output test gives the claimed disjoint sum. Folding constant subtrees sends gates with one surviving operand to a constant, the identity or a negation. Negations, including the outer consistency-test polarities, can be absorbed into the neighboring binary gate's truth table. Conjoining trees creates binary gates and no variable leaves. A constant output needs at most one leaf; an isolated complemented literal can require two in the strict binary-gate, unsigned-input convention (e.g. NAND(x,x)). This proves the leaf bound. For the final assertion every uncut internal gate has at most one outgoing wire. Consequently its definition belongs to exactly one component and all actual primary-input incidences occur once.

**Transfer.** For every fixed integer k >= 1 the base theorem gives an L_k in NP and infinitely many N at which L_k lacks the following kinds of exact real sums of Boolean DAGs. For each constituent D_i choose Q_i with W_i <= A(N) and require sum_i |T+(D_i,Q_i)| <= N^k. Replace each D_i by its disjoint unit-coefficient expansion and multiply by its original real weight. This would yield the forbidden formula representation. Neither uniform computation of T+ nor verification of a semantic promise is required: this is a representation inclusion at each length. Thus for fixed d>=1 and c>=0, use k=ceil(d+c) to permit N^d constituents with at most c log_2 N shared gates each and at most A(N) primary-input incidences each. More generally polynomially many distinct accepting signatures suffice even for superlogarithmically many shared gates. A conventional gate cap floor(A(N)/2) suffices since each gate has at most two input wires. An arbitrary constant multiple of the gate cap can instead be covered by running the base proof with a constant multiple of K, a distinct direct application of the same estimates. No extra runtime is charged by the representation inclusion. A constructive compiler enumerating every assignment for a fully cut DAG uses 2^|Q| poly(|D|) time and polynomial working space with streamed output. Restricting enumeration to T+ requires an explicit list or a separate procedure.

**Limit of the method.** For i=1,...,m compute q_i=x_i XOR y_i, feed q_i to both (q_i OR u) and (q_i OR v), and conjoin these 2m outputs in a tree. All internal gates have fanout at most two; exactly the q_i have fanout two. With u=v=1 all 2^m joint signatures are accepting signatures. The number of original-variable wire incidences is 4m. If each input is first encoded by its own parity block, leaving one slot live in every block preserves these 2^m signatures for every slot choice. This example refutes a generic signature bound based on maximum fanout or on parity pinning. It does not claim a lower bound on alternate representations of the example's function.

**Comparison.** [Jain et al., Section 12](https://www.cs.cmu.edu/~hjain/papers/sat06-extended.pdf) already isolate shared gates with fresh variables and describe inlining. The additional statement here records the exact weighted-sum transfer, original-variable incidence accounting after conditioning and the restriction to accepting signatures. This comparison does not establish publication priority.
