# Gate cost after a reversible change of private coordinates

Let an original DAG with q primary bits (x,z) contain disjoint private blocks xᵢ. On each block it supplies successive same-width permutations Eᵢ and Tᵢ, with yᵢ=Eᵢ(xᵢ) and wᵢ=Tᵢ(yᵢ). Its remaining output is K(z,w,B(y)), where B lists all signals bypassing the second permutation. Assume bypasses are block-local. This interface and the absence of additional uses are checked on the given DAG. If every block width is O(log q) and each supplied circuit is polynomial size, the full local truth tables of E, T, their inverses, and every block-local bypass after inverse substitution can be computed and checked in polynomial time. Candidate small replacement circuits for the latter may be verified on these same tables; enumerating all small circuits is unnecessary when replacements are supplied or recognized.

Make w the private primary coordinates and retain z. The output in these coordinates is exactly K(z,w,B(T⁻¹(w))). If the translated bypass circuits have joint gate cost d, including shared computations, the new gate count is at most |K|+d. Charge any surviving gates and all consumers of the bypasses. Since the coordinate change is bijective the primary dimension is still q, and all satisfying assignments correspond bijectively. An original witness is recovered by table lookups Tᵢ⁻¹ then Eᵢ⁻¹. This argument can use a literal, parity, or arbitrary locally verified truth function as a bypass. The computational saving comes from the new gate bound.

## Supplied DAGs with a large downstream permutation and live bypasses

For large q split its q private bits into balanced blocks of width b=Θ(log q). In each block use b rounds for E and another b rounds for T. Each round takes disjoint triples, up to two leftover positions, and performs Θ(b) Fredkin controlled swaps, e.g. fixing triples in the cyclic order with round-dependent starting offset. Use the reverse cyclic order for the second network. A swap on (a,u,v) uses gates h=a AND (u XOR v), u′=u XOR h, v′=v XOR h, and passes a unchanged. Rotations for choosing the disjoint triples are wiring only. Each supplied network has Θ(q log q) binary gates, is reversible, and preserves each block's Hamming weight. These are counts of the supplied gates; their semantic minimum need not be this large.

Use a linear-size downstream computation K which reads both every w bit and the parity bᵢ of each y block. For concreteness, on each block use the OR of its w bits and AND the OR with bᵢ; take the XOR of these results over all blocks. To retain bypasses that carry information even given the corresponding local aggregate, one may instead use the OR of all but one w bit per block and XOR the omitted bit into the final result. The general rule works for every O(q)-gate K, including ones with further shared gates. Dropping only E leaves Θ(q log q) supplied gates in T. Under the full substitution, compute bᵢ as the parity of the new block, using O(q) total extra gates. The resulting circuit has O(q) gates, with q private primary bits throughout.

The stipulated fixed-density width-three counter with V variables and O(V) clauses runs in poly(V)·2^{O(V/√log V)}. Tseitin encoding gives V≤q+number of binary gates and a unique auxiliary extension. Thus the original supplied size, or the size after dropping only E, gives an exponent upper bound O(q√log q), which does not certify improvement over 2^q. The recompiled circuit gives exponent O(q/√log q), plus polynomial table preprocessing. This is a comparison of the generic clock applied to specific supplied circuits, with no lower bound on their intrinsic SAT cost. ## A single bypass can consume the whole budget

Let k=floor(log₂q+2log₂log₂q). Some Boolean table f on k bits has bounded-fanin circuit size Θ(2^k/k)=Θ(q log q). For the lower bound, descriptions of size s contain O(s log(s+k)) bits, so taking s a sufficiently small multiple of 2^k/k fails to cover all 2^{2^k} tables. For the upper bound split off l low inputs with k/4≤2^l≤k/2. Precompute all Boolean functions of those l inputs by recursively combining their two cofactors with a constant-gate multiplexer; all levels together use O(2^{2^l}) gates. A multiplexer tree on the k−l other inputs selects the needed low-input table using O(2^{k−l}) gates. This gives the asserted size and polynomial-time synthesis from the supplied table. The hard table choice is nonuniform; no efficient procedure for finding a maximally hard table is asserted.

Take the block permutation T(y₀,u)=(y₀ XOR f(u),u), an involution, together with the bypass y₀. Accept iff y₀ AND w₀ and all remaining independent primaries (outside this block) are one. E may be the identity. The original supplied gate count is O(q log q). In coordinates w the output is w₀ AND (w₀ XOR f(u)) together with the other input pins. Restricting w₀=1 and all other pins to one yields NOT f(u). Any circuit for the *entire downstream predicate in these coordinates* therefore needs Ω(q log q) gates. Charging only the one AND at the old consumer would miss this cost. The truth table of this block is still polynomial in q. This lower bound concerns exact re-encoding in the specified coordinates; decision-only preprocessing can directly inspect the small-block table, and another coordinate choice is allowed to behave differently.
