# Three original pins reduce to a single biconnected block

Consider an undirected simple graph with three specified vertices. A witness is a vertex set containing them and having even degree at every vertex of its induced subgraph. There is a deterministic linear-time algorithm with witness recovery whenever no biconnected block contains all three pins. If one block contains them all, that block alone, with the same three names, is equivalent to the input. Bridge edges count as two-vertex blocks and isolated vertices as singleton blocks. The running time uses the adjacency-list model.

First, a graph with at most two required vertices has an elementary linear-time test. Zero or one required vertex can be selected alone as appropriate. If the required pair is nonadjacent, select the pair. For an adjacent pair uv, an induced even support containing them is possible exactly when uv is not a bridge. Necessity follows because every edge in an even graph belongs to a cycle. For sufficiency delete uv and find a shortest u-v path. The path is induced in the remaining graph and closes with uv to form an induced cycle.

More generally an induced even support restricts to an even support in each ambient block. Indeed its edge set partitions into cycles by the standard even-degree decomposition, and every such cycle belongs to a single ambient block. Conversely if selected vertex sets agree on shared cut vertices and are even inside every block, their union is induced-even: each edge belongs to its unique block and degrees add at shared vertices. The same statement holds when several blocks on one side of a cut vertex have been grouped into one piece. In particular attachments without pins can be omitted. If all three pins belong to one block, the restriction and the inclusion of any witness give the two directions immediately.

Split across graph components first. If no component contains all three pins, each is settled by the two-vertex test. Otherwise discard the components with no pins and form the ordinary block-cut tree of the remaining component by depth-first search. Give each pin a home at its cut-vertex node if it is an articulation, and otherwise in its unique block. The three homes, with repetitions allowed, have a unique tree median M. Every component left after deleting M contains at most one pin home, with multiplicities counted.

If M is a cut-vertex node v, consider each side together with its shared v. If v is not pinned, exclude v and use the at most one distal pin alone in each side. If v is pinned, require v in every side and apply the at-most-two-vertex test there, taking all successful supports together. The shared bit agrees, and each side must have even contribution at v by the cycle decomposition. Return NO if any required side fails.

If M is a block B, group all blocks beyond a cut vertex v of B on its side into one piece including v. A pin at v is a required vertex of B, and comes with no further pin on that side by the median property. The distal part of that side can then be empty. If the side instead contains a distinct pin w outside B, it can always extend the choice v=0 by selecting w alone. For v=1 use the two-vertex test on its piece with required v,w. If that test fails, delete v from B. Keep the witness for the v=1 case when it succeeds. Sides without distal pins allow either value and require no further vertices. In the resulting induced subgraph of B, solve the original pins that actually lie in B. If no block contains all three, there are at most two, so the elementary test applies. Assemble the chosen side witnesses according to their boundary bit. When the test within B fails, no global solution exists by the block restriction. A successful union satisfies all original requirements.

All the side pieces together have disjoint edges, and their repeated cut vertices contribute only linear total size. The central block and its sides use O(|V|+|E|) time and space in total, including a shortest-path reconstruction where needed. This removes single-vertex separations from the unresolved three-pin problem. The reduction supplies no bound for a single biconnected block with all three named vertices.
