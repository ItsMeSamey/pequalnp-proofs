# Cyclic existential query programs with a bounded feedback vertex set

Fix rational 0<a<1/2, a nonnegative integer b and positive integer d. Let K(M)=ceil((loglog(M+16))^a) and H(M)=ceil((loglog(M+16))^b). Some language in NP, infinitely often, has no exact real sum of at most M^d mixed atoms, each either a binary Boolean formula of at most MK(M) leaves or a cyclic existential query program of at most MK(M) nodes with feedback vertex set size at most H(M). Acceptance means existence of a finite enabled path to an accepting sink. Width and path ambiguity are unrestricted within the node cap. A supplied feedback set can be verified by deleting it and checking acyclicity on the original graph at guess time.

Use the common-slot projection and heavy-bit branching from the [acyclic theorem](nondeterministic-program-sum.md). Retain all still-live query nodes, the feedback set and the start. An outgoing enabled edge followed by any fixed nonretained nodes leads to a first retained node or terminal. Record all such endpoints, including a positive-length return to the starting state when present; never add a zero-length transition. The intervening nodes avoid the feedback set. The resulting program has O(nL+H+1) query states. A residual cycle avoiding the set would lift by nonempty segments to a closed walk in the original graph avoiding the set, which is impossible. All retained values still have the same existential reachability as before.

Let h be the atom's feedback-set size. Charge one per departure from a feedback vertex and zero from any other, including edges into terminals. The rank of a state is the minimum charge of an enabled path to acceptance, or ∞ if there is none. A simple accepting path suffices, so each finite rank is ≤h. Order the domain 0,...,h,∞ and saturate every result greater than h to ∞. Adding a charge to ∞ yields ∞. Sink values are zero for accept, ∞ for reject. The equation at each state takes the minimum capped successor rank plus its departure charge, with empty minimum ∞.

These equations have a unique solution. Upper inequalities along a true simple shortest path show that a candidate is at most the true rank. From any finite candidate choose a tight successor. Following tight edges cannot repeat a state, as finite equalities would force zero total charge around a cycle. The resulting path ends at an accepting terminal, so true distance is at most the candidate. The actual distances satisfy the equations by shortest paths. This proves uniqueness without assuming that the enabled graph itself terminates.

Take a fixed integer e with a+b/e<1/2. Represent each rank by e one-hot radix digits of alphabet size U, the least integer with U^e≥h+2. Pairwise negative clauses and a fully defined OR chain enforce exactly one per digit. Forbid unused tuples. The number of variables per rank is O_e((h+2)^{1/e}). For each residual edge forbid every pair of tuples violating its upper inequality when the source query enables the edge. This costs O_e((h+2)^2) clauses per edge, width at most 2e+1. Sink ranks are constants.

Give each nonterminal a switch z_u. It may be one only when the candidate rank is finite and no enabled edge is tight. Forbid it on the infinity tuple. For each tight tuple pair and enabled edge forbid the pair jointly with z_u=1 and the enabling query value, using width at most 2e+2. Fixed-query rows have no guard. On rank assignments satisfying all upper inequalities the signed sum over switch settings, weighted by (−1) to the number of ones, is exactly one when every finite node has a tight successor and zero otherwise. At infinite rank the upper inequalities already force every capped edge value to be infinite. A feedback departure of cost one from a successor rank h also saturates to infinity. Pin the start to be finite. Hence each accepted original assignment has one canonical surviving rank table in the signed count and rejecting inputs contribute zero. One shared even-minus-odd parity computation suffices for all switches across independent copies of the factors. [Prior and exact signed construction](signed-joint-clauses-attributed.md)

The dimension of the count, including formula factors and free inputs, is O_e(n+(nL+H+1)(H+2)^{1/e}). For s≤2^{εn}, L=O((log n)^a) and H=O((log n)^b). Thus the dimension is O_e(n(log n)^{a+b/e}+polylog(n)), clause count is polynomial and width max(3,2e+2) is fixed. The [October arbitrary-density theorem](https://github.com/openai/math/blob/92b516ef8e/preprints/The-Exponential-Time-Hypothesis-is-False-October-25-2026/build/main_full_version.tex#L68-L82) gives 2^{o(n)} per heavy assignment. The outer nondeterministic clock and hierarchy argument are those in the [acyclic proof](nondeterministic-program-sum.md). Ordinary polynomial circuits compute finite-graph reachability by unrolling as many rounds as there are nodes. The conclusion concerns the stated representations with a language depending on the fixed parameters. [Finite rank checks](feedback_rank_sign_check.py)
