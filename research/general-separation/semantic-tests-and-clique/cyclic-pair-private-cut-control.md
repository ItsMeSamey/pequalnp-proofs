# A raw gate graph with no saving surjective quadratic cut

For n≥4 arrange the n primary variables on a cycle. Make one AND gate x_i x_{i+1} per edge and combine all these distinct gate outputs by any binary AND tree. It computes the n-way conjunction using 2n−1 gates.

Allow an arbitrary private linear subspace W of the original input bits; outside assignments are its cosets. Call a coordinate active if it varies on W. In a raw private cut, every directed path from each active primary to the output must hit a selected wire. Wires may be primary variables or original gate outputs. Demand that the selected r bits are jointly surjective on every coset and each has private Boolean degree at most two there. This includes cuts requiring the stronger universal affine-perturbation property. There is no such cut with dim W>r.

Each wire computes the monomial on a nonempty vertex set S. If this wire can attain 1 on every coset of W, the restriction map W→F₂^S is onto: given any input x, some w∈W must satisfy (x+w)|_S=1. On W the coordinates in S consequently induce independent linear bits and can be extended to a coordinate basis. The monomial has private degree exactly |S|, including after affine translation. Thus only singleton primaries and the original pair gates can qualify; every subsequent tree gate involves at least two distinct edges and therefore at least three vertices.

Suppose an edge gate is selected. Each endpoint is active. Neither endpoint primary can be selected since its value zero is inconsistent with the selected edge value one. At either endpoint follow the path through its other incident edge. That edge gate must be selected as no later wire on this path qualifies. Connectedness propagates selection to all edges. Their joint image omits an output with exactly one zero: the two adjacent edge values one force both endpoints of the purported zero edge to be one. Thus no edge gate can be selected. If only primaries are selected, all active primaries must be selected. The dimension of W is at most their number and no saving results.

For even n, reexpressing the same function as an AND over products on a disjoint perfect matching gives a surjective n/2-bit quadratic cut, with the whole input private. It also passes the mixed-Pfaffian test. This is an obstruction to cut selection on the specified original DAG even with affine input directions, not a semantic lower bound for the function or a barrier to circuit reassociation.
