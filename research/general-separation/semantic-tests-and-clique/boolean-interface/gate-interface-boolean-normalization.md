# Shared-DAG normalization with bounded variable interfaces

Compute the syntactic variable sets S(g) bottom-up. Start E(output)=empty. In parent-before-child order, for each binary gate g with children u,v, insert in E(u) both E(g) intersect S(u) and S(u) intersect S(v), symmetrically for v. Union contributions from every parent. Let b=max |E(g)|. Computing b uses polynomial time on the actual DAG.

For each gate and each partial assignment on E(g) cache the canonical multilinear representative over GF(2) under this restriction. There are ≤3^b entries. For a gate g fix one such entry and enumerate assignments to its as yet unrestricted variables K shared by the two children. Fetch their restricted entries, passing the assigned bits on their respective variable sets (top-down propagation ensures these entries exist). Their remaining variable supports are disjoint. Apply the two-input gate's canonical bilinear truth polynomial to them (for OR, a+b+ab); the result is already multilinear. Multiply by the multilinear indicator of the K assignment (variables x or 1+x) and sum over assignments. No K variable still occurs inside a branch, so the result is multilinear and agrees with the gate on all inputs. All caches use partial assignments, so extra interface variables contributed by other parents can remain free. Leaves, constants, and unary gates are handled directly, with interface propagation to the unary child.

Each entry takes ≤2^b branches and O(b+1) gates per branch. Total O(|C|(b+1)6^b) arithmetic gates with arbitrary sharing and all binary Boolean gates allowed. Construction time is polynomial in allocated size and raw variable count. For b=O(log |C|) this actually normalizes a circuit in polynomial size, allowing overlapping AND and OR and nonmonotone gates.

For the uniform polynomial-time relaxation R in grid-local-consistency-rewrite-obstruction.md, Möbius inversion identifies the degree-d component of its canonical GF(2) representative with the hard grid polynomial, since all smaller true supports are absent. Under the manuscript theorem every polynomial-size Boolean circuit computing R therefore requires b=Ω((log n)^(13/12)) at all sufficiently large n. Indeed homogeneous extraction is polynomial overhead and the translation costs exp(O(b)). This parameter lower applies to nonmonotone rewrites as well. R still has polynomial-size monotone formulas.
