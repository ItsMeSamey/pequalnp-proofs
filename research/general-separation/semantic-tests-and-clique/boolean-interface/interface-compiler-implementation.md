# Boolean interface compiler and verification

Source and proof: gate-interface-boolean-normalization.md. The earlier exact-context DAG compiler supplies the general idea of caching cofactors. This implementation computes a sufficient context from ordinary source wiring, unions contributions from every parent, and generates only requests reachable from the unrestricted output. Its local truth interpolation works over prime fields, including odd characteristic. There is no claim of a new general knowledge-compilation framework.

Run python interface_compiler.py input.json --prime 5 to emit a JSON arithmetic DAG. Input is an object with distinct string inputs, a topologically ordered gates array, and an integer output index. Valid gate arrays are ["var",name], ["const",0 or 1] and ["gate",mask,left,right]; bit 2a+b of the integer mask is the gate value at (a,b). Repeated children and unused inputs are allowed. Output var/const/add/mul nodes are topological; read the indicated output node. The --eager flag builds every interface cofactor for comparison. The default schedules only requested cofactors before building the output bottom-up. The final pass removes unused arithmetic nodes and remaps indices. No input circuit or source data is modified.

For s gates, k variable names, maximum interface b, at most s3^b cached states and s6^b branch entries are processed. Shannon pairwise interpolation charges constant arithmetic gates per branch, so the emitted and allocated circuits have O(s6^b) gates. The implementation makes two passes over branch enumerations, uses explicit variable sets and sorted pin tuples, and does not claim bit time equal to its arithmetic gate count. With interned or bounded-length names and a word holding an index, set storage is O(sk), cached contexts use O(sb3^b) words up to additive O(s3^b), temporary lists use O(2^b) IDs, and hash-consed arithmetic nodes plus the output remap use O(s6^b) words. Hash-table operations assume usual expected time. The modulus check by trial division costs O(sqrt(p)) trial divisions; field elements require O(log p) bits and gate indices O(log(s6^b)) bits. For arbitrary-length strings additionally charge input names and their hashing/comparison. These are upper bounds rather than measured memory bytes.

Independent test command: python interface_compiler_audit.py interface_compiler_cases.json. It compares exact monomial exponent vectors against independently computed Boolean truth-table Möbius coefficients, then evaluates the emitted DAG on each Boolean input. All 236 formal comparisons and 1,536 evaluations on 59 small DAGs passed across GF(2), GF(5), eager and demand modes. The separate x²-for-x negative control failed formal agreement in both fields despite Boolean agreement. Fixtures were frozen before the backend was implemented. These are bounded tests, not exhaustive over DAGs.

The three fixed fixtures used 35,13,44 cached contexts eagerly versus 18,10,22 on demand; branch counts fell from 34,10,50 to 16,7,20. In GF(5) the third fixture allocated 46 arithmetic operations eagerly, 15 on demand and emitted 10 after live-output pruning. At fixed prime these are operation counts. No runtime speedup extrapolation is claimed.
