# Exact compilation of overlapping affine Boolean features

Propagate linear coefficient bitsets and constants through syntactically affine binary truth-table gates on raw Boolean inputs. Traverse from the output, stopping at recognized affine forms. Arbitrary Boolean gates may remain above this frontier. Eliminate its linear parts over GF(2), recording coordinates in a pivot basis of rank r. Evaluate the upper DAG on all 2^r basis syndromes, accounting for the affine offsets. If elimination exceeds the configured cap, dispatch to the generic interface compiler with its own parameter-dependent cost.

Each raw variable has a column c recording its effect on the r syndrome coordinates. Group the raw variables by identical nonzero columns. For a new group's parity y update every state F_s to F_s+y(F_(s XOR c)−F_s). Emit state zero after all groups. Build y by folding the exact XOR polynomial u+v−2uv on fresh variables. The two parity-fold factors have disjoint raw supports at every step, as do y and the old state polynomials. Hence ordinary formal multilinearity holds over every prime field; no reduction modulo x²=x is used. Directly substituting the overlapping forms in (x XOR y) AND (y XOR z) would instead create a nonzero y² term over both tested fields.

For k raw bits, s gates and g≤min(k,2^r−1) nonempty groups, arithmetic allocation is O(k+g2^r), in addition to O(s2^r) Boolean truth operations and polynomial bitset preprocessing. Two state arrays use O(2^r) node IDs beyond the growing output DAG. Stored source bitsets require O(sk) bits plus runtime-object overhead. Only live arithmetic nodes are returned. The rank is that of the recognized frontier, not a semantic optimum.

The direct-sat-algebra degree-two AND compiler maintains squarefree quadratic representatives over retained AND coordinates, simplifying a Boolean circuit. This algorithm returns an ordinary multilinear arithmetic polynomial over the requested prime. Disjoint-block symmetric compilation is relevant after preprocessing: the new front end derives disjoint groups from overlapping affine features, then tracks at most 2^r combined syndromes.

Precommitted affine_interface_cases.py (792ccbcf) defines reversed duplicate parities, overlapping parity windows, and cancellation at the root. At eight raw bits generic compilation takes respectively 1272, 378, 634 branch evaluations versus 2, 12, 2 syndrome updates plus group/initialization costs. Emitted GF(2) arithmetic operations are 28→7, 77→12, 83→0; GF(5) gives 53→28, 112→29, 121→0. These are operation counts, not wall-clock speedups. The independent audit on affine_interface_compiler.py (2b800638) passed 346 formal coefficient comparisons and 4560 Boolean evaluations on both fields, covering all outer masks, overlapping/duplicate forms, and fallback. No unrestricted Boolean lower bound is implied.
