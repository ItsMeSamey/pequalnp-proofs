# Which circuit sizes the October counting bound covers

The revised October 25, 2026 preprint states a deterministic exact count for fixed-width CNF using polynomial space. With V declared variables and M clauses its bit-operation bound is (V+M)^{O_k(1)} times 2^{O_k(V log log V / sqrt(log V))}. At fixed density M ≤ DV the log log factor disappears, with constants depending on k,D. These are uniform algorithms for each fixed width. The stronger density statement is essential at the boundary below. This audit checked the source statements and the transfer's arithmetic, without independently verifying the contraction proof. [October main theorem](https://raw.githubusercontent.com/openai/math/main/preprints/The-Exponential-Time-Hypothesis-is-False-October-25-2026/build/main_full_version.tex) · [Contraction proof](https://raw.githubusercontent.com/openai/math/main/preprints/The-Exponential-Time-Hypothesis-is-False-October-25-2026/build/quantitative-contraction.tex)

## Direct transfer to exact circuit counting

For an acyclic circuit with n primary inputs and s gates of fan-in at most two, introduce one bit per gate. For each pair of input values, one width-three clause forbids the inconsistent gate output. There are at most four clauses per gate and one unit clause for the required output, so V=n+s and M≤4s+1≤5V for V≥1. Each primary assignment has a unique consistent extension. Thus the same construction preserves the exact count for any binary Boolean gate basis, including XOR. With base-two logarithms there are fixed constants A,b such that the runtime is at most V^b 2^{AV/sqrt(log V)} for V sufficiently large, including polynomial encoding and multitape overhead. The paper's appendix gives the same accounting. [Quantitative circuit proof](https://raw.githubusercontent.com/openai/math/main/preprints/The-Exponential-Time-Hypothesis-is-False-October-25-2026/build/quantitative-circuits.tex)

* At s=o(n sqrt(log n)), the algorithm takes 2^{o(n)} time. For an unbounded choice of s in this regime, this is a SAT and exact-count saving measured in primary input bits.
* At s≤c n sqrt(log n) for a fixed positive c, the exponent bound is (Ac+o(1))n, so any fixed c<1/A yields a constant fractional saving. At a larger constant the stated upper bound alone can cease to improve on enumeration. For n² gates its guaranteed exponent AV/sqrt(log V) is polynomially larger than n. More precisely, the displayed runtime certifies a Williams-style 2^n/n^{ω(1)} bound when n−AV/sqrt(log V)−b log V=ω(log n). The boundary constant c=1/A alone does not determine the saving without subleading information.
* For the hierarchy construction the algorithm verifies a guessed witness circuit through three copies and O(n) local decoder gates. Running this test within the unary nondeterministic time hierarchy gap gives an E^NP language with circuit size at least c' t sqrt(log t) for infinitely many input lengths t, for some fixed c'>0. This is the October paper's own corollary. Its complexity class and its infinitely-often size conclusion both matter. The separate SUM note treats exact sums of many atoms while retaining a near-linear bound on each atom. ## The stronger transfer hypotheses

Williams’s Theorem 1.1 requires a superpolynomial saving factor over exhaustive search for unrestricted polynomial-size circuits, specifically time 2^n poly(n^k)/h(n) on n^k gates for all fixed k and a common superpolynomial h. It concludes NEXP is outside P/poly. The Tseitin calculation above covers linear and certain mildly superlinear sizes. Already the size class s=n² lies outside its guaranteed saving. Theorem 1.2 requires O(2^{(1−δ)n} poly(s)) for some fixed δ>0 across gate counts and yields an E^NP language requiring exponential circuit size infinitely often. The fixed-density bound only attains that fractional time saving on a narrower size range. [Williams, Theorems 1.1–1.2](https://people.csail.mit.edu/rrw/improved-algs-lbs2.pdf)

Murray and Williams's Theorems 1.1 and 1.2 concern typical circuit classes, including general circuits. For a constant 0<ε<1, the NP consequence needs nondeterministic gap-UNSAT on 2^{εn}-size circuits in O(2^{(1−ε)n}) time. The conclusion is that for each fixed k, some NP language needs more than n^k gates at infinitely many lengths. The related NQP consequence needs 2^{n^ε}-size circuits in O(2^{n−n^ε}) time and yields a separate lower bound for each fixed quasipolynomial exponent. Exact counting decides either promise when the input sizes are covered. General circuits in both required size ranges are well outside the direct conversion's guaranteed saving. Even the NP conclusion quantifies the language after the exponent k, so it would not alone separate NP from P/poly or P from NP. [Murray and Williams, Theorems 1.1–1.2](https://people.csail.mit.edu/rrw/easy-witness-nqp.pdf)

## Consequence for the original question

An independent transfer putting a single superpolynomial circuit lower bound in NP, for instance for an NP-complete problem, would separate P from NP. The faster-SAT hypotheses above alone supply no such transfer. In particular, a uniform polynomial-time CircuitSAT decision procedure would also satisfy the polynomial-size Williams speed hypothesis and would prove P=NP. This logic concerns a decision-time premise; exact counting is the stronger property supplied on the sparse range.
