# Conditional hard truth tables for sequential circuits with shared state

Put N=2^n and use fixed finite binary Boolean gates, unrestricted fanout and free constants/wires. One controller C(i,z) takes the n-bit output index and s state bits and returns the next state and output bit. Reuse C for N positions, starting at an arbitrary s-bit state. At at most q exceptional indices replace its bit and next state by arbitrary prescribed values. Initial state and exceptions may depend on the full intended table.

There are absolute α,p>0 such that, if SAT∈P, one E language has error greater than p on uniform n-bit input at each sufficiently large n for all controllers with

    n ≤ s ≤ αN/n,     g ≤ αN/n,     q ≤ αN/s,

where g is the gate count. The model may also allow up to N^d silent transitions per emission for any predetermined constant d, and arbitrarily many when s≤c n for a predetermined c. During silence C sees the same index, updating the state with an emission flag. An exceptional address bypasses C and gives its prescribed output and next state. A controller exceeding its cap or failing to finish defines no table. The constants c,d are fixed outside the construction of the language.

Gate descriptions and all s+1 output selectors use O((g+s+1)log(g+s+n+2)) bits. Add s initial state bits; a silence flag changes only a constant. Encode each exceptional record using n+s+1 bits and store the record count. Since s≥n this costs O(qs+log N). The total number of descriptions summed over the allowed parameters is at most 2^(KαN+O(n)) for absolute K and all sufficiently large n. Take Kα<1/4. Choose p with H₂(p)<1/2. The Hamming balls of radius pN around their outputs cover fewer than 2^N tables.

Test whether an explicitly supplied prefix extends to a table outside the union. Guess the N-bit completion, universally quantify over all bounded descriptions, then simulate to check completion status and agreement. At the fixed N^d delay bound simulation costs polynomial time in N. For s≤c n, after 2^s silent transitions at a fixed address a state has repeated and silence continues forever. This also gives polynomial simulation time. The prefix question is therefore in Σ₂^P on explicit length, with unary N padding even for short prefixes. Under SAT∈P, greedy prefix search constructs the first avoiding table in poly(N) time, giving its bit language in E. Without this collapse its bit language is in E with a Σ₂^P oracle. This is the classical hard-table search argument applied to a sequential model.

The exception scale is attained for arbitrary tables up to constants. A wire-only shift register emits its first s chosen bits from the initial state. Each exception then gives one chosen bit and preloads up to s subsequent bits. At most max(0,ceil((N−s)/(s+1))) exceptions suffice. Ordinary approximate decision circuits are subsumed by ignoring state, suppressing silence and never overriding. The representations in this theorem can in addition share a long sequential computation and receive occasional new state information. A sufficient P≠NP target is that for some fixed c,d every E language has, at infinitely many lengths, one controller within the displayed budget with error ≤p. No such upper is established.

Native-state application: a deterministic sequential printer with a serialized complete mutable configuration of at most s bits and computable transition circuitry of g gates can use its native transitions as the silent controller, provided output-position-independent transitions see no extra uncharged clock or memory. If all but q interoutput segments obey the deadline, the exceptions store the exact output and state after each such segment. When the state has at most c n bits, unlimited native interoutput delay is already covered. This supplies a time bound from state count at a fixed c. It does not cover all polynomial-space-in-N printers.

The computational obstacle to removing the cap at large s is concrete. Given a TQBF instance, hardwire a halting deterministic polynomial-space decider for it into a one-step transition circuit over its polynomial-length configuration and make the first emission its answer. After that emit zero at every remaining position. The decider's finite control, head indices and tape update cost polynomial in the TQBF instance length. Use unary N of polynomial size in that length, a sufficiently large power of two, so these s,g fall below αN/n; pad s up to n if necessary. The controller is total on the supplied initial state. Computing even its first bit with unlimited silent delay is PSPACE-hard, despite q=0. Thus a polynomial-time validation algorithm on all such descriptors would put PSPACE in P. This is a limitation of direct simulation as a prefix-test predicate, not an impossibility proof for constructing a hard table differently. The collapse-based start belongs to the prior work of [Kannan](https://www.sciencedirect.com/science/article/pii/S0019995882903825) and [Miltersen, Vinodchandran and Watanabe](https://www.brics.dk/RS/99/46/BRICS-RS-99-46.pdf).
