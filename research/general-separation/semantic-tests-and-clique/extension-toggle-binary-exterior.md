# A deterministic single-dummy toggle test on mixed-field charts

Consider a normalized symmetric matrix over a fixed finite characteristic-two field, with exterior principal block K, one dummy e, border vector r and dummy diagonal a. Seek S of exterior sites for which precisely one of K[S] and the e-bordered K[S] is nonsingular. A preliminary feasible twist does not change existence of an e-toggle failure, since symmetric difference commutes with toggling e. The [common-cap representation](even-odd-extension-cap.md) supplies such a one-dummy question; its exterior need not meet the following additional condition.

For each connected component D of the off-diagonal support of K, suppose either (i) K[D] can be diagonally scaled by congruence into a binary matrix, or (ii) rᵢ=λ_D√Kᵢᵢ throughout D for a field scalar λ_D. Then toggle failure and a distinguishing mask are computable deterministically in polynomial time. The condition and scales are checkable. For (i), require gᵢgⱼKᵢⱼ=1 on each nonzero entry, including loops. Try each nonzero g at a component root, propagate along a spanning tree, and verify all remaining equations. Scale the border by the same gᵢ. All principal nonsingularity patterns remain unchanged, and property (ii) is invariant under this rescaling.

**Gains.** A gain means singular without the dummy and nonsingular with it. On a component satisfying (ii), every kernel vector x on a principal submatrix is killed by the border, because (Σᵢ√Kᵢᵢ xᵢ)²=xᵀK[S]x=0 there. For a binary-scaled component, expand r in a binary basis of the field. Look for a binary vector x on a principal S with K[S]x=0 and some binary component of r[S]·x equal to one. Its own support is a feasible support for the original off-diagonal graph with parity prescription c=diag K. Conversely such a feasible support supplies its indicator as a kernel vector. The [one-readout span and path algorithm](symmetric-single-row-p3.md) detects this test and provides the vector. There is no loss in using a binary kernel vector since the binary matrix's field kernel is generated by its binary kernel.

If a gain candidate was found on a binary component, shrink to its actual support. As long as the binary kernel has dimension at least two, take a nonzero kernel vector orthogonal to the detected binary readout. Adding it to the all-ones support vector preserves that readout and drops at least one coordinate. Restrict to the smaller support and repeat. At termination the principal matrix has corank one and r pairs nontrivially with its kernel generator, so the bordered matrix is invertible regardless of a. This gives a distinguishing mask without exterior enumeration. If all the one-row tests fail, the span theorem says r_D=λ_D c_D on every binary component (zero c forces zero r). Components of type (ii) already have the corresponding square-root formula. Any singular exterior now has a kernel direction orthogonal to r, hence remains singular on bordering.

**Losses.** It remains to test nonsingular K[S]. Each N=K[S∩D] is nonsingular. Write qᵢ=√Nᵢᵢ. Then qᵀN⁻¹q=Σ Nᵢᵢ(N⁻¹)ᵢᵢ=tr(NN⁻¹)=dim N mod 2: both equalities use cancellation of paired off-diagonal contributions in characteristic two. Thus the Schur complement at e is a+Σ_D λ_D² (|S∩D| mod 2). Every component permits an empty intersection. A looped component permits an odd intersection by selecting any singleton with nonzero diagonal; a loopless component is alternating and has no odd nonsingular principal minor. So a loss exists exactly when a belongs to the binary linear span of λ_D² from the looped components. Solve that system and select the corresponding singletons. This construction includes a=0, where the empty exterior already distinguishes.

**Distance from the empty exterior.** Over GF(4) take a free path 1,…,m, m≥2, with all edges one, endpoint diagonals one and other diagonals zero. The dummy has diagonal one and is adjacent only to site 1 with edge weight b satisfying 1+b²=ω, ω∉GF(2). Bordering is exactly equivalent to changing the first diagonal from one to ω, by Schur complementation on the dummy. A proper exterior either omits the first site or its component starting at that site is a proper prefix. On such a prefix scalar pivots alternate between the initial nonzero diagonal and its inverse; both choices yield nonsingularity. Other components coincide in the two tests. On the full path the final pivot is 1+1=0 in the original and 1+ω^{±1}≠0 in the modified path. Only the full exterior distinguishes. This example actually falls *inside* the binary-exterior algorithm: it is outside the simpler proportional-border criterion before the gain test. It disproves a bounded-distance-from-empty witness guarantee even when the underlying decision admits this polynomial algorithm. No claim is made that this particular path is a normalized image of the physical cap.
