# A local feedback bound for cyclic existential programs

In the [feedback-rank theorem](feedback-rank-programs.md), verify a separate feedback set H_C of size at most H for each strongly connected component C of the raw graph. Their total size is unrestricted. All other size and hierarchy quantifiers remain as in that theorem.

After slot selection and heavy branching, call the still-live query nodes and the program start the initial anchors. Let k_C be their number in C. For k_C>H, retain H_C as extra anchors and charge one for leaving a member of H_C. For 1≤k_C≤H, retain and charge all the initial anchors in C and no others. Empty components retain no nodes. There are at most twice as many retained nodes as initial anchors and at most H charged nodes in one component.

Connect each retained node and query value to its first retained or terminal endpoints via a nonempty enabled segment through fixed interiors. Use graph reachability even when fixed-only components have cycles. A segment from C to C cannot leave the component. In large components any residual cycle lifts to a walk hitting a charged retained feedback vertex. In small components every retained node is charged.

In C rank measures the minimum number of charged departures until acceptance or the first exit into an accepting downstream component, with infinity for impossibility. An internal edge contributes its successor rank plus source charge, capped above H to infinity. An exit into a finite downstream rank contributes only its source charge; exit to infinity gives infinity. A simple successful local path pays at most H and every local cycle pays positively. The [tight-edge proof](feedback-rank-programs.md) yields unique ranks once the downstream acceptance bits are known. Reverse induction on the condensation graph proves unique ranks on all input assignments. All comparators still concern two bounded rank tuples and a query bit. For fixed 0<a<1/2, integer b≥0, K=(loglog M)^a and H=(loglog M)^b with the previous rounding, choose e so a+b/e<1/2. There are O_e(n+(nL+1)(H+2)^{1/e}) variables. The fixed-width counting clock is 2^{o(n)} per heavy assignment. For each d some NP language therefore lacks an exact M^d-term sum of the resulting MK-node programs and MK-leaf binary formulas infinitely often.

For a program separating the local and global cost bounds, each stage i uses a fresh control bit to enter A_i or B_i. A_i goes to B_i if x_i=0 and to the next stage otherwise. B_i goes to A_i if y_i=0 and to the next stage otherwise. After the final stage exit at accept. Every local feedback number is one. Since the cycle is enabled on x_i=y_i=0, a fixed nonnegative integer edge costing that makes all enabled cycles positive must charge one of its two orientations. At every stage set the entry and bits so the unique path takes that positive edge and then exits. Its global cost grows with the number of stages. The function is nevertheless just the conjunction of the x_i OR y_i conditions. [Finite local-rank checks](component_rank_reset_check.py)
