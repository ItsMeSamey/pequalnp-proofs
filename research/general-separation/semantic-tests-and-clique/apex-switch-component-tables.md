# Component-count tables on switched graphs with a bounded planar deletion set

Fix k. A literal-switched undirected graph H carries a specified set A of at most k vertices with H−A planar. Each edge is enabled by one input literal or a constant. One atom uses an arbitrary supplied Boolean table f on the number κ of components of the enabled spanning subgraph, including isolated vertices. Another tests connectivity of two specified vertices. Both admit ordinary signed pointwise Boolean tensors with O_k(|V|+|E|+1) wires and bounded arity apart from a logarithmic-arity table. This includes nonplanar hosts such as K5 with one apex.

The planar random-cluster/vertex-model equivalence is classical. One apex is the Potts ghost-vertex construction and conditioning apex spins produces vertex-dependent external fields on the plane base. The derivation uses these precedents and the [finite planar tensor](plane-switch-connectivity.md) with a regular specialization at component weight zero. [Baxter, Kelland and Wu](https://doi.org/10.1088/0305-4470/9/3/009) · [Grimmett](https://www.statslab.cam.ac.uk/~grg1000/papers/gks.pdf) · [Ellis-Monaghan and Moffatt](https://arxiv.org/abs/1005.5470)

Assume H and A nonempty, designating any vertex as an apex for a planar instance if needed. For a partition τ of A into r blocks fix a canonical order. Reject this τ when an enabled intra-apex edge joins different blocks. Give each base vertex one tag from the r named blocks or OTHER. Enforce equal tags across enabled base edges. Each active edge to an apex requires the tag of its base endpoint to match that apex block. Equality trees copy the tags; each assignment of one tag per compatible base component has a unique extension.

Give named-tag components weight 1 and OTHER components weight U−r. In the unpunctured plane each black base component has one counterclockwise exterior boundary; every hole is clockwise, even around other nested components. In the black-left orientation, carry a three-state index around each loop. For tag a use the companion A_a of X³−w_a X²+X−1 with w_OTHER=U−r and named weights 1. Its trace is w_a, determinant 1 and inverse trace 1. The trace of the product of local matrices A_a^e for local turns e gives w_a on an exterior loop and 1 on a hole. The controlling tag is supplied by the adjacent disk or an enabled strip's endpoint, whose tags agree across that strip. Every base component thus gets its assigned weight once, including an isolated disk. An empty base contributes 1.

Multiply each τ term by (U−1)(U−2)…(U−r+1), taking 1 for r=1, and sum. For every integer U≥|A| there are (U−1)…(U−r+1) ways to assign distinct actual colors to the apex blocks with one fixed apex color anchored. An unattached base component may choose r named colors or U−r other colors. An attached component has its color forced or is incompatible. The weighted grouping counts precisely the U^{κ−1} full colorings constant on each enabled edge with the anchor fixed. Polynomial agreement gives this identity also at U=0, where the value is the spanning-connectivity indicator. No division occurs in the network. The Bell(k) branches can be evaluated independently, or selected by a shared constant-size partition index with unused tag codes forbidden. [Finite apex-color checks](apex_color_group_check.py)

## Coefficient lookup

Since det A_a=1 also A_a^{-1} has entries in Z[U]. Every local turn is bounded, so each local matrix entry is a polynomial of bounded degree and coefficient size for fixed k, as is the partition prefactor. Expand each entry into signed monomials through a local bounded-size choice. That choice supplies its coefficient as scalar weight and its degree as a constant number of bits. Inactive pieces have a single unit monomial of degree zero. A balanced tree adds all these degrees using uniquely defined ripple-carry Boolean gates: at level j there are O((m+v)/2^j) adders on O(j) bits, for O_k(m+v+1) gates total. One logarithmic-arity tensor maps the resulting degree h to f(h+1), extended by zero for irrelevant h. This applies a linear functional to the polynomial, preserving all signed cancellations within each degree. Because the polynomial is U^{κ−1}, the integer scalar is exactly f(κ), without interpolation, modular divisions or large integer evaluation. [Local signed-monomial checks](local_loop_degree_check.py)

For two-terminal connectivity use [s connected to t]=1+κ(H+st)−κ(H). Add s to the supplied apex set if necessary to keep the base planar after inserting unconditional st. Use the degree lookup h↦h+1 for each component count. It takes O(log(m+v+2)) bits per result before cancellaton, and the signed pointwise total is Boolean. One may combine these three alternatives with unique dummy states when bypassing a branch, or distribute them and the constant partition choices across the at-most-four-factor moment expansions. Modulo 2^{n+1} decode only the final Boolean product count.

After pinning, contract fixed-enabled edges and delete fixed-disabled edges and self-loops. The quotient classes meeting A form a new deletion set of size at most k: removing them leaves a planar minor of H−A. Each discarded isolated quotient vertex adds one to κ. Record the number b of such classes. The remaining graph with q live edge tests has ≤2q vertices. Use the shifted table on b+h+1; if no vertices remain, return f(b). An isolated apex may be retained or a new one designated if none survive and the graph is planar. Keep terminal offsets separately in the component-count difference. Construct the residual O_k(q)-argument lookup table in time polynomial in the ambient description.

For each fixed k there is c_k>0 such that, for every fixed d≥1, some L_{k,d} in NP fails at infinitely many lengths M to have an exact real SUM of ≤M^d mixed atoms after adding the above predicates to the larger sparse-atom budget of the [mixed hierarchy theorem](mixed-dense-sparse-tensors.md). Count vertices plus edges plus table bits inside the cap M ceil(c_k sqrt(loglog M)); standard incidence encodings have polynomial description length. After common-slot projection and heavy branching, the new tensors use O_k(n+nL) wires. They share all original bit ports with the other sparse and dense factors. Ordinary polynomial-size circuits evaluate component count, graph connectivity and table access. The hierarchy clock absorbs the polynomial-in-M construction and fixed partition factors just as before, choosing c_k small for its fixed-k constants. The hard language can depend on k and d. No implication to unrestricted P versus NP follows from this restricted representation theorem.
