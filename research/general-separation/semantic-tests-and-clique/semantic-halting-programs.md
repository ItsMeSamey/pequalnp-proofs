# Globally terminating descriptions and consistent private folding

The mixed exact-SUM lower bound in the [signed boundary note](signed-joint-clauses-attributed.md) extends to cyclic existential query descriptions whose enabled graph is acyclic from every state on every input. Semantic global termination includes unreachable states. The underlying union of possible transitions need not be acyclic. Acceptance means an enabled path to an accepting terminal.

For a genuine program each input determines all node acceptance values uniquely by reverse topological induction. After pinning, form the first-live or terminal endpoint relation through pinned nodes by ordinary graph reachability. Any closed walk enabled in the resulting graph under a complete assignment lifts by concatenation to an enabled raw closed walk. Consequently the promised program also has a unique acceptance valuation after compression.

Arbitrary guessed programs need not meet this semantic promise. Define a separate pointwise function for every atom j and gate index i. Given a complete live input x, define its private compressed description by hardwiring i, the common slot embedding, the input circuit description and the values on ONLY atom j's heavy positions. Use exactly this first-live reachability relation even if the resulting graph has cycles. Define phi_{j,i}(x) as the number of assignments to the complete set of its compressed node-value variables satisfying the ordinary backward OR equations and pinning the virtual source to one. This is a fixed nonnegative integer for each x, even when spurious fixed points exist. Reachability through pinned vertices uses finite paths to a first retained endpoint. Empty endpoint sets contribute zero.

In each moment term branch on the union of the heavy sets of all occurrences, as usual. Each copy must compile using only its OWN heavy pins and index. Values fixed by other factors are assignment restrictions on the original input variables. Keep the private graph and every private node variable; use extra unit clauses on the original inputs or substitute these values into the Boolean constraints without deleting node variables or recomputing reachability. Thus the same phi_{j,i}(x) appears in every verification product. Independent private state variables per occurrence give the correct powers when factors repeat. One parity switch calculation for all wide clauses gives the exact sum of products of these phi functions. Guessed phi values and all moment counts have polynomially many bits in the raw descriptions.

On genuine descriptions each phi is the intended Boolean bit. On any guessed descriptions the final weighted sum is a real function; the quartic range identity forces that sum to be Boolean, after which the gate-consistency equalities force the correct evaluator on all inputs. Individual bad guesses need not define Boolean phi. Genuine 0/1 atoms alone are used for the coefficient bound in completeness. Polynomial ordinary circuits for a genuine cyclic graph follow by unrolling reachable sets for as many steps as it has nodes. No hierarchy exponent changes since each private graph still has at most nL live query nodes, even if some queries are fixed additionally for a different factor.

Halting from the designated start alone does not prove uniqueness in this argument. An unreachable live query node whose two outcomes both loop to itself contributes the optional solution of y=y even if the start accepts immediately. A compiler that prunes nodes, merges equal branches, or contracts pins from other factors can change its fixed-point count on such invalid descriptions; the private convention above avoids that inconsistency.
