# Downward self-reduction with a hidden singleton

Use the recursive oracle A of [the coefficient construction](oracle-uniform-coefficient-gap.md). At each length n it has at most one word. For every deterministic machine computing the bit a_n indicating whether such a word exists on unary input 0^n, the machine uses at least 2^n native steps infinitely often. To preserve the exact numerical time bound when changing the input encoding, include one additional type of stage in that construction as specified below.

Encode 0, 1 and a wildcard by 00, 01 and 10 respectively. Reject odd lengths and strings containing a pair 11. The language B accepts a valid partial word if it has a completion in A. A designated wildcard splits into its zero and one restrictions, and the disjunction of their B-values equals the original B-value. The decreasing parameter is the number of wildcards. A fully specified valid word is decided by a single query on its decoded bits. This is a restriction self-reduction on a fixed encoding length.

The verifier scans pairs left to right, writes every specified bit and guesses one bit per wildcard. It rejects malformed encodings and otherwise queries the resulting n-bit string. There is exactly one path for each completion and at most one accepting path. This takes O(n+1) time on a multitape oracle machine. At length 2n, advice gives one presence bit and, when present, the n-bit oracle word. Empty slices have a constant-zero formula. For a present slice let h be the advised word. For bit pair (u_i,v_i), the permitted patterns are 10 and 0h_i. If h_i=0 this is the literal ¬v_i. If h_i=1 it is u_i XOR v_i. An AND of these n tests checks the complete encoded input including malformation, using O(n+1) leaves even over AND, OR and NOT. Odd lengths use constant zero. The empty word uses its presence bit.

For every deterministic oracle machine M, schedule infinitely many fresh stages simulating M directly on (10)^n for 2^n−1 native transitions. If it halts rejecting, insert an unqueried n-bit word. Otherwise leave length n empty. Finalize through the maximum queried length as in the linked construction. No previous stage constrained length n. Thus a machine correct on every valid input must time out at every one of its stages. This proves a lower bound of 2^n steps infinitely often on all-wildcard inputs, or 2^(N/2) for binary input length N. Direct simulation on that encoding avoids charging for an input conversion. Interleaving these stages with the earlier ones preserves every earlier bound for the resulting single recursive oracle. The model permits one individual oracle membership query per native step.

The example tests whether restriction self-reduction alone yields uniform deterministic generation from a short formula and a unique witness in a relativizing argument. Completeness for NP relative to A is an additional hypothesis that this construction does not establish. The oracle argument specializes [Baker, Gill and Solovay (1975)](https://doi.org/10.1137/0204037).

## Strictly shorter binary restrictions

In every stage choose n a fresh power of two above the current cutoff. In further stages simulate each machine directly on 0^(3n), using the same timeout and insertion rule. Distinct powers give disjoint intervals [2n,3n]. Define a second language on input strings of length N in such an interval by setting j=3n−N and reading the first j bits as a prefix. Require every subsequent input bit to be zero and require the prefix to extend to a length-n member of A. Reject outside the intervals. At j<n a valid padded prefix p has children p0 and p1, each padded with zeros to length N−1. At j=n query the decoded n-bit prefix. Malformed inputs reject immediately. Computing the length, the power of two, and the prefix boundary takes linear multitape time, for example by repeated unary halving to obtain the binary length in a geometric total number of scans, binary arithmetic on O(log N) bits, and conversion of j back to unary by repeated doubling in geometric total time. The unique-witness verifier copies the prefix, guesses the missing suffix once and checks membership. At each length with a hidden word the formula is a single conjunction fixing the first j bits to its prefix and all remaining bits to zero. Other lengths use constant zero. Every variable occurs at most once. Each correct deterministic solver requires at least 2^(N/3) native steps at infinitely many roots. All stage types can be interleaved on one recursive oracle.
