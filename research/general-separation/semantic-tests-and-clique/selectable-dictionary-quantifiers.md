# Choosing a dictionary changes the complexity of recovering a forced coefficient

Consider a uniform polynomial-time map from a string x and choice y to a dictionary A_(x,y) with s=poly(|x|) Boolean features on a polynomial-length Boolean row index z. Their values and the common Boolean target f_x(z) are computable in deterministic polynomial time. Each list has a computably designated coefficient, identifiable in polynomial time. A choice is valid when f_x is an exact real linear combination on every row. Promise on every x that at least one choice is valid and that in every representation of every valid choice the designated coefficient is the same bit b(x). The following describes total languages {x:b(x)=1} admitting such presentations.

1. With a nonempty polynomial-time enumerable list of polynomially many choices the languages are exactly NP∩coNP.
2. With all polynomial-length binary choice strings permitted the languages are exactly Σ₂^P∩Π₂^P. The lower construction uses only two features per dictionary and makes the target a single raw row bit.

For b in {0,1}, append row e_j with label b to the system Aw=f to demand w_j=b. Inconsistency has an NP certificate. There is an integer combination of at most s+1 labelled rows giving zero on every feature column and nonzero on the label. Use independent columns and cofactors of a nonzero augmented minor, including rank zero. The multipliers have O(s log(s+2)) bits. Conversely such a relation proves inconsistency. This permits the extra explicit row regardless of the available raw inputs.

Thus consistency for a particular choice at b is in coNP. For polynomially enumerable choices, inconsistency at b for every choice has an NP certificate that lists a row relation for each. Exactly one bit is consistent somewhere. This supplies certificates for either value by refuting all lists at the other bit. With polynomially many choice bits, existence of a consistent choice is in Σ₂^P. Applying this to both bits gives the second upper bound. For m choice bits the concatenation of inconsistency witnesses takes at most 2^m poly(|x|) bits and verification time.

For (1), a single dictionary already works for every NP∩coNP language. One feature recognizes any valid YES-or-NO certificate and its label recognizes a valid YES certificate. Exactly one of the two sides has any witnesses, determining the coefficient. See [the fixed-coordinate theorem and its forced-variable prior art](unique-coordinate-complexity.md).

For (2), let L and its complement both be in Σ₂^P. There are polynomial-time predicates R_b so that x has label b if and only if some y satisfies R_b(x,y,z) on every polynomial-length z. Take a choice consisting of a bit b and y. Add a row bit t and put f_x(t,z)=t. Use the two features 1−t and t R_b(x,y,z), ordered so the first coordinate corresponds to the second feature when b=1 and to the first feature when b=0. When the universal predicate holds the features are complements and the coefficients on the ordered roles (1−t,tR_b) are uniquely (0,1). When it fails there is a row with t=1, both features zero, and label one. Thus the valid choices are precisely the universally correct witnesses on the true side and the first coefficient is their common answer. There are assignments to both values of t at every size. For a nonconstant target a single Boolean atom with a real coefficient could only output that target with coefficient one, so two features suffice at the first nontrivial number for this fixed literal target.

This upper construction for representability of the languages also fits near-linear-size binary formulas per feature, measured in the number N of raw row bits. For a fixed x,b,y compile the polynomial-time counterexample test for NOT R_b into a bounded-fan-in circuit and encode its accepting gate trace with a bounded-occurrence, width-three CNF Φ(z,v). A violating z has some accepting trace v. A nonviolating z has none. For all (z,v) require NOT Φ(z,v) in place of R_b. The choices with universal validity are unchanged. The nonliteral feature is now t AND NOT Φ, an O(N)-leaf formula (equivalently a width-at-most-four DNF after distributing t). Copy gates bound fanout; include a distinct row coordinate for each gate/copy trace or pad to common polynomial row length, so O(N) follows from the linear gate-encoding bound. The labels remain the literal t. The map producing each described list is polynomial-time uniform in (x,b,y). The selector need not find a valid y in polynomial time.

In particular permitting exponentially many proposed dictionaries removes the NP∩coNP limitation even for an NP target bit with two simple features per list. The universal validity test bears the remaining computational cost. This is a quantified characterization for a supplied generator and a designated coefficient. Ordinary minimum term count has no such designation, and this analysis gives no deterministic polynomial-time method for either validity or choice.
