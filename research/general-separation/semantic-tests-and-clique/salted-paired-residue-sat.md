# Detecting Boolean witnesses with paired matching residue queries

For a q-input binary circuit C put P(z)=∑_{x:C(x)=1} ∏_{i:x_i=1} z_i over a field of characteristic three. The polynomial is nonzero exactly when C has a witness, since all displayed monomials are distinct. Fix r≥1 and M=3^r−1. On independent uniform salts z_i in the nonzero elements of F_{3^r}, any nonzero P is nonzero with probability at least (1−1/M)^q. Induct on q: some coefficient polynomial in the final variable is nonzero. On samples where it survives, the remaining nonzero univariate polynomial has at most one root. Repeating gives the claim, including when a variable is absent. For C identically one, P=∏(1+z_i), and equality holds for this sampling rule.

Each one-salt evaluation uses r ordinary mod-three counting queries, compiled by paired-cubic-mod-three.md to simultaneous perfect quadratic and cubic matchings. Let β generate F_{3^r}^× and write z_i=β^{a_i}. Hardwire these sampled integers. On input x, a circuit computes j=∑a_i x_i modulo M with O(q log(2+M)) binary gates by conditional selection and modular addition. A lookup table for β^j returns its r ternary coordinates; for any requested coordinate an O(M log(2+M)) binary circuit suffices. Add one raw bit w to C and the lookup, authorizing exactly zero, one or two values of w according to that coordinate's ternary digit. Its witness count modulo three is the requested field coordinate of P. All construction and gate accounting are uniform and include the known invertible multiplier of the paired reduction. For M polynomially bounded in q one can enumerate irreducible polynomials and primitive elements with polynomial bit cost, or use a fixed field for constant r.

A nonzero evaluation yields a raw witness deterministically using the same salts. For P split the assignments by their next raw bit. The two weighted child sums add to the parent, so one is nonzero. Compute a child's sum by adding primary pins to the original circuit and retaining the full original weights. Choose that branch if nonzero, otherwise the other branch. After q steps evaluate C on the reconstructed assignment. There is no additional sampling error on this self-reduction.

For q≥4 choose r so 3^r−1=Θ(log q), achievable by rounding. Independent repetitions O((1−1/M)^{−q}) suffice for constant success, using 2^{O(q/log q)} times a polynomial number of paired queries. Each has Q=O(s+q loglog q) variables and gates for s original gates. To implement uniform salts with a strict bit-clock, take a per-coordinate power-of-two random range of size at least 2q²M and reduce each sample modulo M. Every salt point has probability at least (1−1/(2q²))^q times its uniform probability, losing only a constant factor. Empty and bounded q are handled by enumeration. A hypothetical deterministic paired-residue solver in poly(Q)·2^{A Q/log Q} would therefore yield a one-sided randomized constant-fraction saving on s≤Bqlog q for sufficiently small fixed B depending on A and construction constants. On a nonempty instance the algorithm returns a verified witness with constant probability; an empty instance never produces a false witness. This random reduction does not furnish the deterministic UNSAT test in the cited hierarchy proof.

## A sharp black-box limit

Suppose a deterministic procedure sees an otherwise arbitrary N=2^q-bit truth table only via scalar F₃-valued polynomial queries in its entries, including ordinary row evaluations. Queries may be adaptive. Follow the path on the zero truth table. If the queried polynomials on this path have degrees d_j and replies a_j, then throughout the Boolean cube of tables

∏_j (1−(Q_j−a_j)²)

is the indicator of exactly the tables following the same path. A deterministic correct emptiness decision requires this set to be the singleton zero table, whose unique multilinear polynomial ∏_{i=1}^N(1−T_i) has degree N. Multilinearizing on Boolean inputs never increases degree, so ∑ d_j≥N/2. In particular at least N/2 scalar queries are required on the zero path for linear weighted counts. Pairing truth entries and counting each pair modulo three attains that number for even N. A degree-d algorithm that folds multiple uses of the table into each scalar query is subject to the same total-degree bound. The linear statement also follows from the elementary-abelian case of the Davenport constant. [Olson](https://doi.org/10.1016/0022-314X(69)90021-3)

A description-aware choice of queries can use C's supplied gates, and their possible truth tables form a constrained family. This is outside the lower bound. A nonuniform salt list also exists for all size-s circuits: multiply the trial count by O((q+s)log(q+s+2)) to union-bound over their ordered binary encodings. Its existence gives neither a uniform construction nor the deterministic hierarchy consequence.

There is also a succinct adversary to short description-oblivious lists. Fix q and a primary prefix of k≤q bits and restrict the truth table to functions depending only on those k bits. Every one of the 2^{2^k} labelings has an ordinary binary circuit with O(2^k/k) gates for large k, with an absolute constant. For completeness split the k bits into k−u prefix bits and u suffix bits, with 2^u between a fixed small multiple of k and k/2. Build all prefix and suffix minterms by shared binary recursions. Build every possible Boolean function on the u suffix bits as an OR of its minterms, costing at most 2^u·2^{2^u} gates altogether. For each of the 2^{k−u} prefix minterms, AND it with the one required precomputed suffix function, then OR across prefixes. The resulting cost is O(2^k/k); none of the other q raw bits is read.

Repeating a k-bit labeling across the ignored input coordinates specializes each original black-box table query to a polynomial of degree no greater than before in 2^k independent Boolean labels. The same zero-path argument gives ∑d_j≥2^{k−1} even for this succinct subfamily. For a fixed gate cap Bq log q, choose 2^k within a factor two of a sufficiently small fixed multiple of Bq(log q)². The total degree required is then Ω_B(q(log q)²) on the zero path. The trivial all-truth-table lower bound cannot be transported to the full 2^q scale under a nearlinear gate promise by this argument. This control permits large polynomial salt lists and still leaves their efficient construction unresolved.
