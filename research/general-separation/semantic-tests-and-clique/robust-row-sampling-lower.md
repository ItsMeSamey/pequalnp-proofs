# Sharp sample dependence for a robust forced coefficient

Suppose an algorithm learns about a Boolean feature matrix and target only by drawing independent rows uniformly, seeing the sampled index, its feature values and its label. A designated coefficient has one forced Boolean value, at least one exact representation exists, and each real vector with the opposite coordinate disagrees with the target on at least an ε fraction of rows. With s+1 features and ε=2^(−h−1), s≥4 and h≥0, there are instances on which every correct zero-error algorithm in this model takes Ω(s/ε) expected samples.

A row index consists of h fair bits g, s fair bits u and one fair bit b. Write I=1[g=0], ρ=2^(−h)=2ε. Let the designated feature and target both equal Ib, and the other features be Iu_j. The designated value one gives an exact representation. At value zero, any linear prediction on the informative rows with I=1 depends only on u. The independent bit b disagrees with that prediction at least half the time. Thus the bit is forced, with the stated error gap.

Pre-draw m=floor(s/(4ρ)) indices. With probability at least 1/2 there are at most floor(s/2) informative samples by Markov's inequality. Conditional on their number k≤s/2, the informative u vectors are linearly independent over F₂ with probability at least 1−2^(−s/2): at step i+1 the span contains at most 2^i of the 2^s vectors and the sum of failure probabilities is less than 2^(k−s). Binary independence implies real independence, so some nuisance coefficients fit all the sampled b values while the designated coordinate is zero. Uninformative rows impose no conditions. This event has probability bounded below by an absolute positive constant.

For each transcript in this event form a second promised instance retaining the original values on the m or fewer observed indices. On all other indices put designated feature one, nuisance features zero and label zero. The sample-fitted vector is now a globally valid representation with designated bit zero. Any vector with designated bit one fails on at least 1−m/2^(h+s+1)>1/2 of all rows, so the alternative completion obeys the gap promise. If an algorithm reports one by sample m with positive probability on such a transcript, it does so on that alternative with positive probability by coupling indices and private coins, even if it stopped early. The transcript range up to m is finite. Zero-error correctness excludes such an output. The displayed event has constant probability, so the expected sample count is Ω(m)=Ω(s/ε).

Conversely, retain the coordinate-equals-b equation for each proposed bit. While its sample equations are consistent, choose any interpolating vector. If b is wrong the next fresh row violates it with probability at least ε. This row's feature vector either increases the current row rank or, when it is in their span, makes the system inconsistent. At most s+2 such events suffice including detection. Thus the expected time until the wrong bit is ruled out is O(s/ε). The true bit remains feasible. See [the robust selection theorem](robust-dictionary-selection.md) for its uniform class and high-probability bounds.

For inverse-polynomial ε each alternative completion on n=s+h+1 relevant bits can be described by explicit Boolean formulas of O(mn+n) leaves, using a disjunction of tests for the exceptional indices with the needed displayed values (or its complement for a default-one feature). If a near-linear formula budget is desired, append O(mn+n) irrelevant row bits, group rows by their original n-bit projection and use the same formula. This preserves both the independent sampling distribution and the adversarial completion argument. The algorithm receives row values through probes only; an algorithm receiving the formulas themselves can inspect them. The lower bound concerns zero-error uniform row sampling and does not claim the same lower bound for a bounded-error test or for adaptively chosen row indices.
