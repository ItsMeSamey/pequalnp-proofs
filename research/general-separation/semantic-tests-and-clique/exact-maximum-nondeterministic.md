# Exact maximizers for circuits with existential witnesses

Let N=2^n. An s-gate binary Boolean circuit receives input x and witness variables w. Its Boolean decision value on x is one exactly when some w makes the output one. Witnesses may depend on x. Size counts gates with unrestricted fan-out and sharing. Witness names that occur can be relabeled consecutively. For s≥1 at most 2s used witness occurrences enter gates, and one further witness variable might be directly designated as output.

Let J_n be the lexicographically first table of maximum minimum existential circuit size. The number of ordered descriptions of size at most s is bounded by (s+1)(n+3s+3)[16(n+3s+3)^2]^s for s≥1, including constants and the output choice. The maximum is therefore at least cN/n for an absolute c>0 eventually. A deterministic multiplexer tree bounds it by O(N).

**Searching under SAT in P.** Given unary N, prefix p and threshold s=O(N), guess an extending table and universally quantify gate descriptions of size less than s. On each fixed row the existential circuit value is SAT on a polynomial-length encoding, so under SAT in P one can check disagreement by explicitly scanning N rows in polynomial time in N. The residual table and description quantifications collapse to P under the same hypothesis. Binary search for the threshold and bit-by-bit prefix search give one polynomial-in-N printer. Thus the bit language of J belongs to E.

**Approximation.** Let g be the decision function of an existential circuit C. If it has at most pN errors relative to a target f, separately encode the false-positive and false-negative indicators D and A by [deterministic sparse correction](exact-maximum-average.md). Each has weight at most pN. The existential circuit with matrix (C(x,w) AND NOT D(x)) OR A(x) computes f exactly. The witness space is nonempty, so adding the false-negative rows imposes no further promise. Choose p sufficiently small that the two mask circuits together cost at most cN/(2n) eventually. Every exact existential maximizer then requires at least cN/(2n)−O(1) existential gates for approximation with uniform error at most p. The result concerns the acceptance value after quantification. It allows witnesses to vary arbitrarily by input.

**Standard sufficient condition.** There exist fixed a,p>0 such that, if for every E language L infinitely many n admit an existential circuit with at most aN/n gates deciding L on at least (1−p)N rows, then SAT is outside P. For example take a=c/4 and choose p with 4Kh(p)<c/4, using the absolute sparse-mask constant K from the linked note. Under SAT in P the one language J violates this approximation bound at every sufficiently large n.

**Fixed quantifier pattern.** Fix k once and for all, and a fixed sequence of k existential or universal Boolean witness blocks. O(s) used witness variables can be renamed within blocks, recording the block tag at O(log(k+1)) bits per variable. Empty blocks may be padded by unused bits. Every domain is nonempty. This preserves gate order and the quantifier pattern. The fixed-k evaluation on each row belongs to PH, so under SAT in P it costs polynomial time in the explicit input size. The two masks are functions only of x. When the mask adds a row the matrix is constantly one for all witness assignments; when it deletes a row it is constantly zero. Otherwise the unchanged matrix is quantified in its original order. Thus maximization, correction and the sufficient condition hold for each fixed pattern separately, with its own canonical language and constants. This does not optimize a single table simultaneously over unboundedly many patterns.

**Comparison for the deterministic maximizer.** The previous H_n maximizes deterministic size. To simulate an existential C on x use one variable per gate, at most 2s+1 witness variables, n input variables, at most four width-three truth-table clauses per gate, at most n pin clauses, and an output unit (constants can be simplified directly). The encoding has O((s+n)log(s+n+2)) bits. With a multitape SAT algorithm running in L^{b+o(1)}, oblivious simulation and hardwiring C yield a deterministic decision circuit of size (s+n)^{b+o(1)}. For varying x only literal signs of pin clauses need vary. This preserves decision error and implies s≥N^{1/b−o(1)} for approximation to H_n at the earlier small constant error. The direct J construction avoids the exponent b.

**Short output projections.** The projection of a d-bit seed generator to d+1 designated output bits has image density at most one half. Every subset of exactly 2^d points can occur as the image of some mapping to d+1 bits. The central binomial coefficient and the same description count give such ranges requiring Ω(2^d/d) existential gates. A small range checker for a particular construction needs a bound on computing its designated outputs or other image structure.

The quantifiers in this argument arise from enumerating and checking explicit descriptions and tables. For historical context on polynomial-hierarchy versus fixed-size-exponent lower bounds see [Kannan](https://www.sciencedirect.com/science/article/pii/S0019995882903825), and for nearly maximum deterministic circuit complexity via explicit constructions see [Korten](https://arxiv.org/abs/2106.00875). The simulation uses [Pippenger and Fischer](https://scholarship.claremont.edu/hmc_fac_pub/597/). No priority claim is made.
