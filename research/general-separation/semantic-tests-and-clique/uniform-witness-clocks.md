# Uniform witness generation with one advice bit per length

A candidate for a uniform separation asks for a deterministic polynomial-time predicate R(1^n,w), for |w|=n, with exactly one valid string w_n at every n≥1, such that no deterministic polynomial-time machine outputs w_n on input 1^n for all n. The verifier runs in a single fixed polynomial in n over the entire sequence. A program for any finite number of exceptional lengths can be hardwired, so the proposed hardness must persist at infinitely many lengths against each polynomial-time generator. The existence of such a predicate is open. Efficiently recognizable unique witnesses alone impose no search lower bound: a full-rank affine system from a uniform family yields its unique witness by polynomial-time elimination.

**Equivalence.** This candidate holds exactly if there is a tally language in UP∩coUP outside P. Such a language has ordinary circuits of linear size and uses at most one advice bit per input length. Thus this target would separate P and NP without providing a nonuniform lower bound.

For the forward direction store bit i of w_n, 0≤i<n, at the unary length n(n−1)/2+i+1. A tally machine recovers n and i in polynomial time. Its accepting witness is the uniquely verified w_n whose bit is one. The complementary machine uses the same predicate and the zero bit; on nonunary inputs it accepts deterministically. A P decider would generate w_n using n calls at lengths O(n²). One ordinary advice bit per length suffices to decide the tally language after checking that the input is unary.

Conversely take unambiguous polynomial-time machines for a tally language L and its complement. On each unary input exactly one of the two has a unique accepting path. Encode that path canonically with its side tag, length and enforced zero padding. Bounded branching and a fixed polynomial clock allow a deterministic verifier to replay it. Reindex the unary lengths n onto an injective polynomial sequence N(n), with efficient inversion and enough room in N(n) witness bits for both the paths and the tag. For example a sufficiently high fixed power of n+2 works. At unoccupied lengths accept the unique all-zero witness. A polynomial-time generator at every length yields the unique tag at N(n) and would decide L on unary inputs. This proves the converse with the claimed equal-length format.

## A recursive oracle realizes the uniform distinction

There exists a recursive oracle O with one marked pair (b,w), |w|=n, across the two tags b∈{0,1} at each n. Its unary language of lengths marked with b=1 lies in UP^O∩coUP^O, has ordinary one-bit advice per length, and is outside P^O. Use an unambiguous encoding such as the literal string bw of length n+1 for an oracle bit. An unambiguous machine guesses w and tests the corresponding oracle entry.

Enumerate deterministic oracle machines with explicit polynomial clocks T_i(n). At stage i choose fresh n beyond the assigned blocks so large that 2^n>T_i(n). Fill gaps below n with default marks. Simulate the clocked machine on 1^n using the fixed oracle bits, answering zero on every fresh query. In block n put one unqueried mark with tag opposite the simulated answer. Every touched block m≥n still has an unqueried position in either tag because at most T_i(n)<2^n≤2^m positions were read. Fill the other blocks up through the maximum touched index, with marks avoiding the transcript. Freeze this entire initial segment including n. All future stages preserve the transcript, so the machine fails at its designated unary input. Fresh choices and finite simulations can be implemented recursively and each block is eventually assigned. This is an oracle construction in the tradition of Baker, Gill and Solovay. Replacing the oracle lookup by a single ordinary polynomial-time verifier with the stipulated hard witness sequence is the unresolved step. [Baker, Gill and Solovay](https://doi.org/10.1137/0204037)

## Why a padded simulation does not supply the ordinary verifier

The padded language of triples (M,x,1^T) for which deterministic M rejects x within T steps is in P under a conventional multitape encoding: direct universal simulation has a fixed polynomial overhead in total input length. Its own decider U correctly complements U(x) on the triple (U,x,1^T) for a sufficiently generous T. These two computations use different inputs. If M instead runs on the whole triple, a clock T no larger than its input length cannot pay arbitrary polynomial running times in that length. At any fixed verifier exponent b, a machine that delays n^(b+1) steps and then returns zero explicitly defeats the requirement to replay every implementation at that exponent, even at very sparse lengths. Its trivial output also shows why one would have to prove a failure of semantic compression, rather than a failure to replay a particular inefficient run.

For a finite black-box check, take T independent oracle bits whose successive XOR determines the endpoint of a one-bit transition system. Every accepting computation of an exact verifier must read all T bits, even with arbitrary proof length: flipping an unread bit preserves the accepting transcript. A randomized verifier with perfect completeness and soundness error ε must read each bit with probability at least 1−ε on a fixed passing input/proof pair, since the flipped input with that same proof would otherwise pass too frequently. It therefore uses at least (1−ε)T expected distinct queries there. This argument uses independently accessible transition bits; it supplies no ordinary lower bound for succinctly specified transitions.

For comparison, a single fixed universal machine can dovetail potential SAT witness-producing programs and stop only after checking a submitted assignment. A deterministic polynomial-time SAT decider would give a polynomial-time producer by self-reduction, so a standard weighted universal search simulation would finish in polynomial time on every satisfiable formula. Conversely, any one polynomial upper bound on that machine over all satisfiable formulas gives a deterministic SAT decider by timeout. Existence of the clock suffices for this implication. Proving that every polynomial clock fails is another formulation of the original open uniform problem. [Levin](https://www.karlin.mff.cuni.cz/~krajicek/levin.pdf)
