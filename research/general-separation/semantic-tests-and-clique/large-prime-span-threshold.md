# A single finite characteristic for all sparse Boolean dictionaries

Fix a finite input domain, a Boolean target f and any class of Boolean features, with sparsity cap S≥1. If p is prime and p>(S+1)^((S+1)/2), a list of at most S features represents f by a linear combination over the reals if and only if the same list represents f over the field of p elements. This holds simultaneously for every target and every list, including lists chosen after seeing p. Include an intercept in the column budget if one is permitted.

Indeed take the evaluation matrix and its augmentation by the target column. Every square minor of order j≤S+1 is an integer of absolute value at most j^(j/2), by the row-norm determinant bound. All nonzero minors survive reduction modulo p and all zero minors remain zero. The two ranks therefore agree with their characteristic-zero values. Equality of the two ranks tests consistency over either field. This argument bounds neither the time to find a list nor the time to form its truth table. For a degree-d feature expression include all squarefree products of at most d features, giving the corresponding test with column cap Σ_{j≤d} binom(S,j), including the constant.

## A dictionary passing prescribed smaller moduli

For every integer H≥1 there is a Boolean target and a fixed list of O(1+log H) Boolean features such that the target is in their linear span modulo M exactly when M divides H, for every integer M≥2. It is outside their real span. The target, feature list and all inputs are independent of M. Each feature is an OR of at most four row-index equality tests.

Use two coefficient columns x and xbar for each logical register, with a private binary row requiring x+xbar=0. An equation listing columns always has coefficient one on each listed column. Start with a register u whose singleton row has target 1. Make as many unit copies as there are 1 bits after the leading 1 in H by a chain: for consecutive unit registers U,Unew insert the row Ubar+Unew=0. Each copy after the first is assigned to one distinct add-one instruction. Use u also as the initial current register. Scan the remaining binary digits of H from most to least significant. For each digit, from current x create a fresh copy z using xbar+z=0, and a fresh doubled register y using x+z+ybar=0. For digit 1 also create a fresh register v with y+Unew+vbar=0 using its allocated unit copy and set the current register to v. For digit 0 set it to y. End with a singleton row pinning the final register to zero. When H=1 the initial and final pins occur on distinct raw inputs with identical activations.

The only target-one row is the initial pin. All logical equalities hold over every indicated ring without division. Induction on the digits forces the final coefficient to be H times its multiplicative identity. Conversely, if H=0 in that ring, the same recurrence supplies a solution. Every signed partner pair consumes one defining row, every update consumes at most a constant number of registers and rows, and the unit chain has at most floor(log₂H) new registers. Each ordinary column participates in its signed partner row, at most one producing row and at most one consuming addition, plus a possible pin. A negative partner also participates in its signed partner row, at most one producing addition and at most one copy row, except the initial negative partner can feed both the initial doubling copy and the unit chain. Thus at most four occurrences per column suffice. The raw input encodes a row number in binary. Unused row numbers designate zero activation and target zero. Each feature consequently has a literal formula of O(log(2+log H)) leaves. If an intercept is free, include an explicit all-zero row with target zero to force it to vanish.

Choosing H as the product of the primes at most L makes this same dictionary pass all those primes. The number of columns is O(L) by the Chebyshev bound on the primorial. One extra feature, supported only on the final pin row, restores real feasibility with weight −H. This example concerns the given dictionary. The target by itself is an easy singleton predicate. The example does not assert necessity of the determinant threshold or a lower bound for unrestricted choices of features.
