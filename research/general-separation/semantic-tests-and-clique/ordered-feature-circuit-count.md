# Counting an arbitrary outer circuit on ordered binary-clause features

Use q original Boolean coordinates in one supplied or verified invertible affine frame. Let each feature G_i be the indicator of a conjunction of ordinary binary clauses and arbitrary affine equations. A circuit H of arbitrary depth, fanout and topology receives these feature values. It has no additional raw ports unless they are explicitly included as features. Additional common binary clauses, affine rows and a dense quadratic sign Q are permitted. The target is the exact signed sum of H over the allowed raw inputs. Syntactic sharing is allowed everywhere, and the displayed input and any extraction costs are charged.

Use any verified partial order P such that feature i being true forces every predecessor of i true. Collapse mutually implying labels and fix the wiring of H accordingly; an empty implication list is always valid. Sufficient edges follow from nested conjunction construction. If desired, exact implication checking tests each atomic conjunct of the consequent separately by enforcing its violation along with the antecedent and the common domain. A violated binary clause pins literals; a violated affine row remains affine. The signed 2-CNF algorithm with sign one tests all k² candidate pairs in O*(ρ^q) time for polynomially displayed data. Here ρ=1.38027757… as in [paired violation counting](paired-violation-gauss-count.md).

For an ideal I in P, let D_I be the conjunction of its positive features with the common domain. Let L be the downward-closed family of ideals with nonempty D_I. Let p(I) count distinct coordinate positions explicitly pinned in this conjunction by any of its unit rows or unit clauses. Counting just these literal pins makes p monotone on L. Conflict or emptiness is handled before interpreting the number of effective free bits. Then the target can be computed deterministically in time

poly(input) · Σ_{I∈L} ρ^{q−p(I)},

with an additional polynomial preprocessing cost, and O(poly(input)(1+|L|)) bits of working memory. If testing all implication edges on an input with many common pins, first substitute the common pins so that its optional clock also respects this bound; return zero immediately for an empty common domain after one ordinary feasibility check. More generally charge that initial feasibility query explicitly even if L is empty.

## The algorithm

Fix a linear extension of P from predecessors to successors. Starting at the empty ideal, try enlarging an admissible ideal only by an index larger than all current indices whose predecessors are present; test each candidate for nonempty D_I. Every feasible ideal is found by adding its indices in order. Children of an infeasible ideal are infeasible. A parent has at most k attempted children, and each feasibility test, including a failed one, costs O*(ρ^{q−p(parent)}) after substituting the parent's pins. Compute z(I), the signed sum of (−1)^Q on D_I, by one additional call per feasible parent with all of its actual pins substituted. The separate feasibility calls are unsigned; a signed cancellation is never used to prune a branch.

For every I∈L evaluate the actual outer gate DAG on the characteristic vector of I to obtain h(I). This value is well defined even when no raw input has exactly this feature pattern. Compute w(I) satisfying h(I)=Σ_{J⊆I}w(J) over ideals in L. The forward transform is a sequence of additions: for each index i in increasing linear-extension order, add the value on I minus i to the value on I whenever i is maximal in I. For J⊆I, the added indices I minus J must enter in precisely this increasing order; every intermediate set is an ideal between J and I and hence belongs to L. Every newly added index is maximal at that stage because an existing successor would already require it. This proves exactly one contribution per comparable pair. Each stage has inverse given by subtraction, since donors do not contain i. Apply those inverses in decreasing order to the array h to obtain w. This uses O*(|L|) time, and coefficients have O(k+1) bits by the k addition/subtraction stages.

The transform uses the classical fast zeta and Möbius method on ordered sets. The preceding argument checks that omitting infeasible upper ideals preserves the unique increasing paths. [Björklund and coauthors, fast lattice transforms](https://doi.org/10.1145/2629429) [Kaski and coauthors, increasing edge labels](https://arxiv.org/abs/1603.03889)

The true pattern Y(x) is an ideal in L on every allowed raw input. The test I⊆Y(x) is precisely D_I within the common domain. Consequently the requested sum is Σ_I w(I)z(I), with no positive-count or independence assumption. All local integer sums have O(q+1) bits and the final accumulation needs polynomially many bits per number. For unsigned SAT one can recover a raw witness by adding external affine pins. To preserve the same enumeration bound one can reuse the original L and w, recomputing only z(I) under each extra pin. An actual truth witness then evaluates through the original H. No string of |P| independent choices is fed to the signed counter.

## Original gate costs and a limit

For a concrete family take t=ceil(q/log₂(q+2)) chains of up to floor(log₂²(q+2)) nested conjunctions. Each prefix extends the previous one by one binary clause on any raw literals; clauses may connect arbitrary raw coordinates from different chains. The original DAG uses O(q log q) gates for the prefixes, including clause gates, and the arbitrary outer H may itself have O(q log q) gates. The chains, shared intermediate gates and inclusion edges are visible in this construction; the explicit flattened conjunct lists remain polynomial in the original input size. Even without credit for pins, |L|≤(1+floor(log₂²(q+2)))^t=2^{o(q)}, giving time ρ^q 2^{o(q)}poly(input) with arbitrary dense quadratic phase supplied separately at its actual representation cost. Smaller constants in chain lengths allow any specified positive constant fraction of q log q gates; the clock charges the actual g.

If the features are all q raw singleton bits, all 2^q patterns are realizable. A black-box procedure for H that scans only its answers on feature patterns must query every pattern on the zero function: an unqueried point can be the sole accepting point of an O(q)-gate circuit. A circuit-aware algorithm can inspect gate descriptions and bypass this oracle obstruction. The theorem supplies a nontrivial class of original DAGs at the q log q size regime but does not provide the required worst-case bound for all DAGs.
