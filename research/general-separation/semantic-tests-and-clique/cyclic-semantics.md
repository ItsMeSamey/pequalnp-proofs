# Soundness under a global per-input termination promise

For fixed guesses and a fixed ambient slot map, define a separate integer-valued g_{j,i}(x) for each atom j and gate index i. Fix the raw circuit and index fields, unselected slots, and exactly the selected positions heavy for j to their values in x. In the resulting program summarize fixed-query paths up to the first live node or terminal; ordinary reachability computes these endpoint sets even for syntactic cycles. Retain an explicit start acceptance rule. For the live graph impose all backwards Boolean existential recurrences and start acceptance. Define g as the number of satisfying assignments to its private node variables with the remaining input fixed to x. This is a function even when a guess violates its semantic promise. It may be zero or larger than one. Distinct occurrences have distinct auxiliary variable names.

If every enabled path from every node halts on each x, the enabled graph on each x is acyclic. Every enabled directed cycle after contraction lifts to a closed enabled walk in the original graph, which contradicts global acyclicity for that x. Thus the complete retained recurrence determines all private variables uniquely before the start test. Reachability through fixed subgraphs is faithful by path concatenation, and g equals the true Boolean value. Global termination itself need not be decided by the verifier. For bad guesses one need only guarantee algebraic consistency of that same g across every moment term. In a product branch, enumerate the union of heavy inputs for up to four atoms, but use only an atom's own heavy tests when determining its private residual graph. If extra assigned inputs from another factor occur as live tests, evaluate them in the CNF by substitution or unit clauses without changing the residual node set or the definition of g. Independent private auxiliary sets then supply the Cartesian-product multiplicity, giving the actual product of the g factors. After signed counting, every quartic term is truly evaluated on the same integer-valued sum. The quartic is nonnegative for all real values; gate checks follow its range verification. Its soundness uses no atom-level Booleanity or size bound on g beyond the polynomial bit count.

An inaccessible free self-cycle can refute start-only termination as a sufficient completeness condition for the all-node recurrence. For an always-accepting start append a separate live query node with both successors equal to itself. The evaluation halts immediately at the start, yet the isolated equation y=y gives two private assignments for each input. Syntactic trimming of nodes unreachable under both outcomes can be defeated by a syntactically accessible path guarded by inconsistent tests of the same variable; only feasible reachability matters. Structural query-dependent contraction must be identical across different occurrences of one malformed atom for the proof to use these counts.
