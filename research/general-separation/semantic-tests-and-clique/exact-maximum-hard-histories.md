# Conditional density of hard proofs and deterministic histories

Write N=2^n. Use the [fixed-pattern maximizers](exact-maximum-nondeterministic.md), with their fixed a,p>0: every circuit of the respective pattern with at most aN/n gates errs on more than pN rows. Under SAT in P each chosen bit language belongs to E.

**A fixed-seed existential verifier.** For the existential maximizer J, suppose a proof verifier has perfect completeness, soundness s<1 against every fixed proof on each NO input, and at most q queries per seed. A representation of a proof as an address circuit with at most g gates can be encoded by at most B=O((g+m)log(g+m+2)) bits, where m is its address length. Use one shared existential description across all queried addresses and all seeds. Invalid settings must either be rejected or represent some total oracle. A fixed universal circuit with bounded fan-in and size O((g+m)log(g+m+2)) suffices; unused slots permit smaller circuits. The usual bounded-fan-out normalization splits all used outgoing occurrences with O(g+m) copy gates. With q adaptive queries one copies this evaluator for each query in order. Write u for the total binary gate cost to run the verifier on x for one fixed seed and the shared represented proof, including all address computation.

For t independent seeds, a NO input and one fixed setting pass all tests with probability at most s^t. Thus if 2^{n+B}s^t<1 there is one list accepting no NO input for any witness. Every YES with a represented perfectly accepting proof survives. The resulting existential circuit has O(t(u+1)) gates with verifier seeds hardwired as nonuniform constants. If this is at most aN/n, more than pN YES inputs have no such perfect proof. With 2^B s^t≤β instead, the expected number of falsely accepted NO rows is at most βN. One list achieves this bound, so more than (p−β)N YES rows have no such proof. For fixed β<p, polynomial verifier cost, m=O(n), bounded q and fixed soundness, g≤2^{(1/2−η)n} suffices for each fixed η>0 and all sufficiently large n. This is conditional on the stated verifier parameters; the efficiency of its address computation cannot be inferred merely from the length of its proof.

**Universal site checks.** Take the maximizer J* for the fixed pattern ∃∀∃. Fix any deterministic E-time one-tape decider M for J* with a conventional padded tableau. A multitape decider can instead be converted to a one-tape decider in squared time; the assertion below then concerns that specified simulation's tableau. Use a standard one-tape local cellular encoding with a finite alphabet, head and state encoded in a tape symbol, permanent end boundaries and absorbing halting states. Return to a designated cell with the decision bit before halting. For a machine-dependent fixed integer b, a tableau of 2^{bn} time rows and a tape interval of length 2^{bn+O(1)} then suffices at all sufficiently large n. The local rule is a total deterministic function of a constant number of adjacent cells on well-formed histories; fix arbitrary rules on illegal neighborhoods. Each valid initial row has exactly one continuation, so the circuit encodes one actual history if all constraints pass. Layout and constant-bit symbol padding are fixed once for M. At one specified site the initial row (including lookup in x), local update, boundary handling and the final decision test can be checked with poly(n) gates using O(n)-bit indices and a constant number of bit-address queries. Unused addresses and indices either encode fixed padding or are ignored. For circuit complexity interpret the tableau with fixed total padding on its bit-address domain.

The test with prefix ∃description ∀site accepts every input having a g-gate accepting history circuit. Every control setting represents a total bit function; some additional larger history circuits may also be represented. Unused padding can be checked via the same universal index. Matrix size is at most K_M(g+n)log(g+n+2)+poly_M(n), by universal circuit evaluation at the required addresses. The verifier forbids accepting histories on NO inputs. For g=floor(κ_M N/n²) with a sufficiently small fixed κ_M>0, this size is at most aN/n eventually. A dummy final existential block embeds it in the target pattern. Thus more than pN YES inputs have unique histories of circuit complexity greater than g. The complement of the programmed rejecting-history test uses ∀description ∃site; prepend an unused existential block. This circuit accepts all YES inputs and rejects every NO input with a g-gate rejecting history. It errs only on NO inputs without such a circuit. It follows separately that more than pN NO inputs also have histories of complexity greater than g. Both bounds hold at every sufficiently large length for each fixed M. Bit-address complexity measures ordinary unrestricted deterministic circuits for the entire padded history. The quantifiers over site use perfect local verification, so no quantitative PCP soundness is needed for this result.

One sufficient standard separation condition is that every E language have some E-time decider, in this common tableau model, with at most pN YES inputs lacking o(N/n²)-gate histories along infinitely many lengths. The maximizer contradicts it if SAT is in P. This compression remains unproved. Requiring the statement for every machine would have an additional consequence: for any F in E a machine recognizing the universal language can first compute and store the entire F_n table in a designated tape interval and then halt. Restrict any small history circuit to the final time and those addresses to obtain a similarly small circuit for F_n. This shows why the existential choice of decider matters.

The connection between succinct witnesses and circuit lower bounds has classical precedents. Impagliazzo, Kabanets and Wigderson relate NEXP circuits and MA using easy witnesses; the density argument above uses the conditional canonical maximizer instead.
