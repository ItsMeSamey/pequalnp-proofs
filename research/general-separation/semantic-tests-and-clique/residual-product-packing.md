# Fractional packing of residual entropies under disjoint products

For a satisfiable Boolean function f on variables X let b_D(f) count its distinct nonzero residual functions when all variables outside D are fixed. Thus b_empty=1. Put h_D=log₂ b_D. For any fixed nonnegative subadditive function φ on the nonnegative reals with φ(0)=0, maximize sum_D λ_D φ(h_D) over all nonempty live sets D, λ_D≥0 and sum_{D containing x}λ_D≤1 for each variable x. Denote this maximum by N_φ(f). It permits arbitrary overlapping blocks and includes ordinary partitions.

For any satisfiable Boolean targets f_i on mutually disjoint banks X_i and F=AND_i f_i, the equality N_φ(F)=sum_i N_φ(f_i) holds exactly. Indeed b_D(F)=product_i b_(D intersect X_i)(f_i) on every D. Restrictions outside D are independent across banks, so every tuple of nonzero residuals gives its product. Its nonempty support is a Cartesian product, whose projections recover all of those supports uniquely. Taking logs gives additivity on D. Subadditivity of φ lets each mixed-block score be split among its nonempty intersections with the banks. Their induced weights form a feasible packing on each bank, proving the upper bound. Combining independent optimal within-bank packings proves the reverse inequality. This reasoning applies as well when the optimization is just over partitions.

Counting all residuals increases h_D by at most one bit, since only the zero function was excluded. For the ordinary linear score or square root this changes a fractional packing optimum by at most the total number of input variables: sum_D λ_D≤|X| follows by charging each nonempty set against its occupied variables. For XOR there is an exact analogue on counting residuals modulo bitwise complement. Normalize each residual by XORing its value at a basepoint. Normalized sums on independent banks are uniquely determined by the normalized individual functions obtained by varying only one bank at a time. This gives the same product of counts and additive packing identity.

For two-level indirect storage access with m payload bits and P=Θ(m/log m) pointer rows, its row partition gives N_linear≥Ω(Pm) and N_sqrt≥Ω(P sqrt(m)) using the 2^m−1 nonzero payload restrictions at each row. Conversely the entire function has a formula of O(Pm) leaves and an acyclic query program of O(P sqrt(m)+m) nodes by the [ISA tradeoff constructions](isa-sparse-range.md). For any single such formula the fixed-skeleton bound on a live set with l≥1 leaves gives log b_D=O(l). If l=0 then b_D=1. For a program the corresponding fixed-node contraction gives log b_D=O(l²). In a fractional packing the weighted sum of l is at most total size, since each occurrence's queried variable has load at most one. Thus the two displayed ISA estimates are tight up to constants, and their values for r independent copies grow by exactly a factor r. Rearranging the blocks even fractionally cannot cause multiplicative amplification of these scores.

Replacing the linear score by an unrestricted superlinear power already violates a per-leaf bound for a single read-once binary formula. In AND_i(x_i OR y_i), varying the y values produces all 2^k distinct nonzero conjunctions on the k live x bits, with only 2k leaves and a deterministic linear-size query program. Any proposed bound φ(log b_D)≤O(total leaves) for every formula therefore forces φ(k)=O(k).

This is an observation about residual measures for unrestricted products, not a direct-sum theorem for minimum sparse SUM size. The individual indirect storage access counts and the underlying Nečiporuk method appear in [Beame, Grosshans, McKenzie and Segoufin](https://arxiv.org/pdf/1608.01932). The companion checker verifies 3,600 four-bit set restrictions each for the AND and XOR count identities.
