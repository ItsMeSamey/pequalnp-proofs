# One language at an arbitrarily slowly superpolynomial nondeterministic clock

Let g(N) be an integer-valued, nondecreasing function tending to infinity, with N^{g(N)} a constructible time bound; for example take g(N)=max(1,log-star N) rounded to an integer. For each such g there is one explicit language U_g in NTIME(N^{O(g(N))}) with the following property. For every fixed d≥1, at infinitely many lengths N its membership predicate has no exact real sum of ≤N^d near-linear atoms of the mixed formula and acyclic existential query-program types in the [signed-boundary result](signed-joint-clauses-attributed.md). The atom cap can be N times ceil(c' sqrt(loglog N)/logloglog N) for a sufficiently small constant c'>0 independent of d. Define the profile positively on small lengths. Hard lengths may differ with d. This is the universal-language mechanism used for related SUM classes by [Williams, Theorem 1.5(2)](https://arxiv.org/pdf/1802.09121).

Use a self-delimiting encoding of a nondeterministic machine V followed directly by x, without a length header for x. At total length N, U_g tests if V has an accepting computation on x within N^{g(N)} simulated steps. A universal nondeterministic simulation of a clocked computation costs at most a fixed polynomial in its description and simulated time, giving the stated class. For any L∈NP, fix a machine for L and its prefix of length h. For all sufficiently large n the time budget (n+h)^{g(n+h)} exceeds the machine's fixed polynomial clock. Thus hardwiring this header in U_g recovers L on n-bit inputs, with N=n+h.

Let c>0 be the absolute boundary constant for the preceding fixed-exponent NP result, and fix 0<c'<c. Suppose U_g had the described d-exponent representation at all sufficiently large lengths. Apply it at length n+h for a verifier of the hard NP language from the fixed-exponent theorem with parameter d+1. Hardwiring the header folds formula constants or bypasses fixed query nodes in an acyclic existential program; a dispatch node, if needed, adds at most one state. The top count (n+h)^d is eventually ≤n^{d+1}. The atom cap at coefficient c' and length n+h is eventually within the hard language's n-bit cap at coefficient c, including rounding and an optional dispatch node. This follows from the density tending to infinity and its ratio at n+h and n tending to one. Thus large hard lengths contradict the proposed representation. The argument also applies to every fixed interior exponent a<1/2 by choosing slack in a. No sparsity-to-verifier ratio is assumed.

For each g, this particular uniform universal language is outside NP. Otherwise fix one polynomial nondeterministic clock n^A for U_g. Every NP language is then decided by simulating U_g on a fixed prefix and x, hardwiring the finitely many exceptional lengths in its own machine. The polynomial exponent can be bounded independently of the prefix; for example, all these languages would belong to NTIME(n^{A+2}). This contradicts the nondeterministic time hierarchy at polynomial clocks. This argument obstructs eventual constant-header universality for all of NP inside a single NP language. It leaves open whether a different NP language can be hard for every sparsity exponent. For a sufficient condition selecting only a restricted family, see [the parity depadding criterion](parity-depadding.md).
