# How many near-linear formulas does indirect addressing force in the padded evaluator?

At infinitely many raw lengths M, an exact real linear combination of Boolean formulas computing EVAL′, with at most MK(M) leaves per atom, requires Ω(M/((log M)^2 K(M))) atoms. Here K(M)≥1. Binary Boolean gates of any truth table, input repetitions and arbitrary signed real weights are allowed. This is unconditional. For the hardwired restriction producing this bound, a matching upper bound holds when K(M) tends to infinity.

Let t=2^k, b=2^{k−ceil(log₂ k)}=Θ(t/k). Use log₂ b primary address bits, b pointer words P_j of k bits each and t data bits. The output is the data bit at the address stored in P_j for the selected j. The number of logical inputs is n=Θ(t). A binary selector tree on b entries for each of the k pointer bits costs O(bk) gates. A final selector on t data bits costs O(t) gates. Thus s=O(t) indexed gates suffice, including the inputs. Use the variable-R format of [the evaluator](np-sum-formula-projection.md) with R=ceil(Ck) for a fixed large C. The full length is M=Θ(tk) since the ordinary description costs O(t log t) bits and the parity-block area is nR. Hardwire the circuit and its output index. Any choice of a single live slot per parity block produces the same ISA decision function.

Fix a slot embedding and one pointer word. In an atom with l≥1 leaf occurrences from that word, the rooted subtree connecting these occurrences to the root has l−1 branching vertices. Preserve them and the l marked leaves, contracting all unary paths including the root stem. After pinning the other inputs, each path acts as one of four one-bit functions. Branching truth tables and marked leaf identities are fixed. There are 2l−1 path positions, hence at most 4^{2l−1} different restrictions on the word. Repeated marked inputs do not affect the bound.

Write L_j for the sum of l over atoms for word P_j. Once the restrictions of atoms with positive l have been chosen, the other atoms supply a scalar shift to a fixed real function on the word. A nonconstant function admits at most one shift making it Boolean, determined by its minimum. A constant function cannot yield a nonconstant result. Consequently there are at most 4^{2L_j} nonconstant Boolean restrictions, irrespective of how many atoms omit the word. Fixing the primary address to j and programming the data realizes all 2^t Boolean functions on P_j. Thus L_j≥log₂(2^t−2)/4. Summing over the b disjoint words gives Ω(bt) live pointer occurrences on every slot embedding.

Choose the slot for each logical input uniformly. Every raw pointer occurrence survives with probability 1/R. The total raw pointer-leaf count is therefore Ω(Rbt). Dividing by MK gives Ω(t/(kK))=Ω(M/((log M)^2 K(M))).

For the ISA restriction, sum the b disjoint predicates that select one primary address j and read the data using P_j. Each predicate uses O(t) logical leaves. Its binary selector tree has t−1 multiplexers that use their selector twice and each child once, plus O(log b) leaves for the primary address guard. Replacing logical variables by R-bit parity trees costs O(Rt)=O(M) leaves. Group any Θ(K) disjoint predicates by ordinary OR, choosing the leading constant small enough for the exact MK cap. When K tends to infinity this yields O(1+b/K) atoms. Consequently the near-linear lower on the number of atoms is tight for this restriction up to constants when b/K is at least a constant. The upper addresses this restricted program only.

This is an application of Nečiporuk's subfunction method and the classical ISA example. The scalar-shift step treats the exact-real top gate and the parity averaging accounts for the original input length. The construction leaves open polynomial sparsity for the full evaluator.
