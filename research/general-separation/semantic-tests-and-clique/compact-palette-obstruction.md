# Indistinguishable color measurements on linear-size switched graphs

For every integer w≥2 there are two explicitly constructed undirected literal-switched graphs on the same n=Σ_{j=2}^w ceil(log₂(j+1))=Θ(w log w) input bits. Each has O(n) edges and vertices and bounded pathwidth. Their rooted-color histogram polynomials H⁺ and H⁻ satisfy

    H⁺(X)−H⁻(X) = ∏_{j=1}^w (X−j),      H(X)=Σ_x X^{κ(x)−1}.

Thus they agree on every palette 1,…,w, but their connected-input counts differ in absolute value by w!. For even w=2B one graph realizes exactly B distinct component counts while the other realizes at least B+1. Consequently certification from 2B+1 consecutive positive moments in the [sparse histogram procedure](component-spectrum-cuts-attributed.md) is sharp for this measurement interface, even on these small constant-pathwidth hosts. This does not bound algorithms that inspect the graph structure.

For each j=2,…,w, a block of ceil(log₂(j+1)) bits has one special word (all zeros), j ordinary words (values 1,…,j) and the remaining words invalid. Let h count special blocks. A star with a persistent root has one leaf per block, joined to the root by parallel edges enabled when the corresponding block bit is one. Exactly h leaves isolate, so the base component count is h+1.

In the plus graph add a Boolean acceptance test: if every block is valid, accept when the ordinary-block count is even, otherwise accept when h is even. In the minus graph flip only the valid-input rule. Each test has a complete deterministic layered one-bit branching program of constant width and O(n) states. Scan each block most-significant-bit first, tracking prefix comparison to hardwired j and whether the prefix is zero. At a block end update the special parity, ordinary parity and any-invalid flag.

Forget the directions of each program's literal-guarded transitions, with one enabled successor at every nonsink on fixed inputs, and keep a separate accepting and rejecting terminal even if one is unreachable. Before attachment, the undirected enabled program has exactly two components: every vertex flows to one sink, and enabled edges preserve the destination sink. Identify the accept sink with the star root and add a permanent start-to-accept edge. This merges the two program components precisely on rejection. Each resulting graph therefore satisfies κ(x)−1=h+[its program accepts]. A path decomposition keeps the root, start, two adjacent constant-width program layers and the current star leaf. Parallel mismatch-edge incidences have endpoints in such a bag. All bags have constant size even if a current input-bit vertex for its occurrences is included.

Invalid assignments give the same exponent in both graphs, always odd. A valid assignment contributes (−1)^{ordinary}(X−1)X^h to the difference. In the product over block choices the special word contributes X and the j ordinary words contribute −j. This proves the displayed identity. At w=2B, the minus graph's valid exponents are all odd from 1 through w−1, and the plus graph's valid exponents include all even integers from 0 to w. Thus the claimed sparsity distinction survives invalid words. At w=4 the two histograms in increasing exponent order are (24,64,35,4,1) and (0,114,0,14,0), on 7 bits, with 45 vertices and 88 edges in each actual constructed graph. [Exhaustive compact checks](compact_histogram_graph_check.py)

For any integer histogram polynomial F, the integer sum Σ_{j=1}^w (−1)^{j−1}binom(w,j)F(j) equals F(0) modulo w! by the finite-difference identity. Consequently w!>2^n suffices to recover an exact connected-input count on n bits using those palettes; w=Θ(n/log n) suffices for large n. Conversely the graphs above require larger than w palettes in this interface at n=Θ(w log w), and padding additional free input bits scales both histograms equally. Hence the consecutive maximum palette for exact connected counts on all linear-size graphs is Θ(n/log n) up to constants. The color alphabet therefore still needs Θ(log n) bits per color even under this sharper exact reconstruction, in this specific counter.
