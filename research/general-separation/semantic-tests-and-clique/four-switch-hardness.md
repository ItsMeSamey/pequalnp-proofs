# A linear compiler from two-out Hamiltonicity to pure four-way switches

For a loopless simple digraph G form the bipartite graph with one tail and one head copy of each vertex, and an edge per arc. Directed Hamiltonicity is NP-complete even when G is exactly two-in/two-out and every component of this bipartite graph is an eight-cycle. The two alternating matchings of each component then differ by a four-cycle on its tails.

This hardness has prior art. Bagheri Gh., Feder, Fleischner and Subi, Corollary 6, crediting Feder and Subi, prove NP-completeness of A-trails on a class of 8-regular plane Eulerian graphs. Color the faces black and white and orient every edge with its black face on its left. Incoming and outgoing edges alternate around every vertex. Each A-trail picks one of the two perfect matchings of adjacent incidences, which differ by a four-cycle between inputs and outputs. Such a decomposition has a consistent orientation because each pair contains an incoming and an outgoing arc. Thus the A-trail problem already supplies four-way-switch hardness. It imposes planarity on the switch host. Here we give a different compilation from the two-out decision problem, with a linear size bound, loopless output and preservation of the number of tours. [Prior A-trail theorem](https://arxiv.org/pdf/1806.06713#page=12)

## Source choices

Directed Hamiltonicity on digraphs with two ones in each adjacency row is NP-complete. Represent each row by an undirected edge joining its two possible heads and labeled by its tail. Different rows may give parallel edges. Choosing a successor orients the edge toward the chosen head. A permutation requires every head to have indegree one, so each component must have the same number of edges and vertices. Such a connected component is unicyclic. Its trees have forced orientations away from the cycle. The cycle has two possible orientations, including for a parallel-edge cycle. Reversing the orientation rotates the chosen heads among its l tail labels. Thus the permutation covers are precisely σ composed on its input side with any subset of disjoint cycles C_j, where σ is a fixed cover and each C_j is one such rotation. All data and any failed component count can be found in polynomial time. [Rusu](https://www.sciencedirect.com/science/article/pii/S0304397522001487)

Implement each optional cycle C_j as l−1 serial transpositions of two data tracks sharing one bit. A two-input cell connects straight if its bit is zero and swaps if it is one. Use the ordinary transposition factorization of a cycle, in the corresponding order. Wire the end of track i to the start of track σ(i). With fixed group bits, the resulting circuits are the orbits of the selected permutation, since each crosses this track boundary. Bypass stretches of deterministic wires. A closed orbit made entirely of deterministic wires is independent of all choices. If present together with other tracks or cells it forces rejection, except that a completely deterministic instance is decided by directly testing σ. Remaining deterministic stretches between cells can be suppressed.

## The four-way switch and its equality constraint

Each physical switch has inputs and outputs 0,1,2,3. Its off configuration sends input j to output j, and its on configuration sends j to j+1 modulo four. For a group of k elementary two-input cells sharing one bit, create k physical switches in any cyclic order. Install the following two wires for each consecutive i,i+1, with indices modulo k.

    out(2,i) → in(0,i+1)       out(0,i+1) → in(1,i)

The external inputs at each switch are 2,3 and its external outputs are 1,3. If i is on and i+1 off, in(1,i) exits via out(2,i), enters in(0,i+1), exits via out(0,i+1), and closes at in(1,i). This two-cycle contains no external track. Every mixed cyclic word has such a descent and therefore gives at least two circuits.

When all switches are off, external input 2 at i reaches output 1 at i by turning back at the successor, and input 3 reaches output 3 directly. When all are on, input 2 reaches output 3 directly, and input 3 reaches output 1 by turning back at the predecessor. The off long path visits internal input 0 of the successor and 1 of the current switch. The on long path visits 1 of the predecessor and 0 of the current switch. Every internal input belongs to exactly one path. Each uniform setting therefore implements the intended simultaneous straight or swap states and makes no extra circuit.

## Looplessness, degree and multiplicity

Before installing the rings, replace every elementary cell by three serial copies on its two tracks. All belong to the same original group. Three swaps have the action of one. Each ring now has at least three switches, so its inner wires join distinct switches. Each external wire runs from first to second, second to third, or third to the first copy of the next original cell. This joins distinct physical switches even when a logical cell was originally wired back to itself.

Let w be the bijection taking physical output ports to wired input ports. Emit a vertex for each input (i,j), with two arcs to w(i,j) and w(i,j+1 mod 4), where the domain of w is the output ports. The two heads are distinct and neither arc is a loop. Each vertex has two predecessors. In any permutation cover let b_j indicate that input j of a switch uses the shifted output. Then output j receives 1−b_j+b_{j−1} incoming arcs. Requiring exactly one gives b_j=b_{j−1} at the four ports of that switch. The resulting bipartite component contains exactly these four tail ports and the four heads reached from its outputs, arranged as an eight-cycle. Distinct such components are disjoint.

Any valid tour uses a uniform configuration in every ring, and those configurations induce the original cycle decomposition. Each original Hamiltonian cycle lifts uniquely, with tours counted as successor maps up to cyclic starting point. The construction uses 12 Σ_j (|C_j|−1)≤12N vertices for a nontrivial N-vertex instance. A fixed four-vertex yes example uses one physical switch with w(j)=j+1 modulo four. Off yields one four-cycle, on yields two two-cycles; both are loopless. Two disjoint copies give a fixed no example. These handle absent covers, isolated deterministic cycles and entirely deterministic source instances while preserving the number of tours. A cyclic vertex order certifies membership in NP.

The [independent checker](four_switch_compiler_check.py) compared source and compiled tour multiplicities on 90 instances including relative cycles of lengths two through five. It enumerated 550 unpadded settings and 91,768 serial-tripled settings, preserving all 45 tours. For the tripled graphs it checked looplessness, both degrees and relative cycles of length four. The [companion algorithm](two-out-switches.md) handles all ambiguity cycles of length at most three deterministically in polynomial time. This classification gives neither a polynomial-time decision algorithm nor a superpolynomial running-time lower bound for the NP-complete side.
