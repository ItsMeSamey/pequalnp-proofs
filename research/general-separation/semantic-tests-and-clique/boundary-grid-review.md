# Scope of the boundary-grid transfer

The binary-grid construction projects the cited formal state-sum polynomial exactly. The circuit lower bound it transfers relies on Theorem 1.1 of the linked preprint as an external premise. Two reviewers checked the projection. The short-trace corollary received one source review and assumes the stated odd parity on each minimal true set. If the source DAG has constants, first simplify both true and false constants to obtain a DAG with variable leaves. The parity assumption must hold on this resulting DAG. Simplification preserves the Boolean function and can change its trace multiplicities. These hypotheses restrict the Boolean circuits covered by the transfer.
