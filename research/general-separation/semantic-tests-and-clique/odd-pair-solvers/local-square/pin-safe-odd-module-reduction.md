# Keeping one site per maximal pin-free module

Let P be any compulsory set. A module M is a set to which every outside vertex is adjacent completely or not at all. If M misses P, replace it by one representative via induced deletion. In any accepting support let m count its selected members in M. Keep the representative for odd m and otherwise keep none. The contribution to every outside selected degree is preserved modulo two. In the odd case the sum of all selected degrees over M is odd, internal edges contributing evenly; its external contribution equals m times the common selected exterior degree. The chosen representative therefore has odd degree as well. This permits arbitrary internal graphs, including ones without twins. Conversely any accepting quotient word lifts by retaining its literal original sites. For disjoint modules the reductions can be successive, since homogeneity persists under other induced deletions, and the full image of the original witness family under the block-parity map equals the quotient witness family.

For an optional pair start with the two sites; iteratively adjoin each outside site seeing some but not all current members. Every module containing the pair must contain the distinguishers, and stabilization is a module. The pair belongs to a common pin-free module exactly when this smallest one avoids P. Overlapping modules have modular union (their common member enforces the same outside adjacencies to both), so the maximal pin-free modules form a partition of the optional vertices. Keep all pins individually and choose one representative of each part. A direct pair loop with up to n iterations of O(n²) adjacency tests per pair costs O(n^5) elementary operations. The [implementation](pin_module_odd_core.py) returns original block masks and both coordinate maps for arbitrary P. On two-pin instances its wrapper runs the [quartic solver](quartic-ladder-first-conflict.md) if the quotient has maximum degree at most four, otherwise returning UNKNOWN. Other certified solvers can use the same explicit quotient.

This includes arbitrary substitutions on unpinned sites of a quartic skeleton. Its maximal pin-free modules may merge original substituted blocks, only removing further representatives. Thus the quotient is an induced subgraph of the skeleton. For example, replacing the two internal sites of a four-site path by two completely joined five-cycles (and preserving incidence to the named ends) yields a twin-free dense graph whose module quotient returns NO. The analogous five-vertex path with all its internal sites inflated returns YES with a literal two-edge original witness.
