# NP lower bounds for exact real sums of binary formulas of slowly growing linear density

Set K(N)=ceil((log log(N+16))^(1/3)). For every fixed integer d≥1 there is a language L_d in NP such that at infinitely many input lengths N its Boolean membership function has no **exact real linear combination of at most N^d Boolean formulas, each with at most N K(N) leaves**. Each formula is a tree of arbitrary two-input Boolean gates, including XOR. Leaves may repeat any input without an individual read limit. We count a Boolean constant as a leaf; it may instead be folded away. The language may depend on d.

The ingredients are Williams's verification of real sums by products of at most four Boolean functions, Murray–Williams's nondeterministic gap-UNSAT implication, and the October 25 fixed-density exact #3SAT manuscript theorem. The additional projection uses parity blocks so that total formula length controls the hardwired evaluator on live inputs. [Williams, Proposition 1 and Section 3](https://arxiv.org/pdf/1802.09121) · [Murray and Williams, Theorem 1.1](https://people.csail.mit.edu/rrw/easy-witness-nqp.pdf) · [October theorem, lines 70–82](https://github.com/openai/math/blob/92b516ef8e/preprints/The-Exponential-Time-Hypothesis-is-False-October-25-2026/build/main_full_version.tex#L70-L82)

## Universal evaluator and representation

Suppose contrariwise that for some fixed d every NP language has this representation at every sufficiently large length. Consider the following fixed P language. Its well-formed input specifies a fan-in-two circuit C with n inputs and s indexed gates (including input nodes), a gate index i, and n disjoint R-bit blocks Z_j. Output the value of gate i on x_j equal to the parity of Z_j. A self-delimiting header specifies n,s,R and the circuit encoding and uses fixed-width fields for i. Reject malformed encodings. For each C choose R so that nR dominates its explicit O((n+s)log(n+s+2)) encoding, index and header. This can be done with R polynomial in n+s, for example R=(n+s+2)^2. The total raw input length M then lies between nR and BnR for one fixed constant B. Fixing C and i preserves this layout for every i. When s≤2^{εn} and n→∞, log M=O(εn+log n), and K(M)=O((log n)^(1/3)).

Since P is contained in NP, the contradiction assumption supplies S≤M^d bottom formulas on this full ambient input and real coefficients. Their weighted sum is Boolean on all raw inputs. Williams's coefficient lemma gives integer numerators a_h and a common positive denominator h0, each with O(S log(S+1)) bits. To see the common denominator, take independent Boolean evaluation columns, select an invertible row minor, apply Cramer's rule to its Boolean target column and apply Hadamard's determinant bound. Padding with zero coefficients is harmless. The whole guess, including binary-tree descriptions and coefficients, has size polynomial in M for fixed d. Enforce all these bounds on nondeterministic branches.

## A common restriction for all summands

A choice of one slot in each block will leave that slot as x_j and pin the others to zero. Every such choice realizes the intended evaluator because it preserves each block's parity. Fix δ>0 small. For each bottom formula independently classify a raw variable position as heavy in that formula if it occurs more than L=ceil(C K(M)) times in its original tree, using the same threshold for all atoms. The count of heavy positions is at most M K(M)/L≤M/C. With a uniform and independent slot choice across blocks the number H of selected heavy positions for this one formula is a sum of n independent Bernoulli variables, of mean μ≤M/(RC)≤Bn/C. Therefore

    Pr(H≥δn) ≤ (eB/(Cδ))^(δn).

Choose C large enough for this to be at most exp(−δn). For fixed d choose ε small enough that M^d exp(−δn)<1 for all sufficiently large n. A single choice then leaves at most δn heavy positions in every formula. Guess such a slot map and verify the counts from the explicit descriptions. The definition precedes the pinning of i, so the same map works for all gate indices.

## Verification on the live variables

After pinning C, the slot map and any gate index i, write z_i(x)=Σ_h a_h F_{h,i}(x). A valid guess must have z_i/h0 in {0,1}. For each i test this by checking the integer sum over all x of z_i²(z_i−h0)² for zero. Next verify the value of every input node by its squared difference from h0 x_j. For each binary node with predecessors a,b, the indicator that a Boolean triple violates its two-input gate relation is a multilinear real polynomial in three bits of degree at most three. Substitute z_i/h0, z_a/h0, z_b/h0 and clear the denominator h0³. Check that the sum over all x vanishes. The established Boolean range makes this sum nonnegative. Finally check that the output is zero on all assignments by summing z_out. Thus every passing guess certifies the actual circuit to be unsatisfiable. On an unsatisfiable circuit the true evaluator representation and a common good embedding give a passing guess. Finite exceptional ambient lengths are immaterial.

Expand the moment and gate checks distributively. There are at most poly(M,S,s) terms, each an integer coefficient times an exact sum over x of a product of at most four bottom formulas at potentially different fixed indices, plus at most a constant number of input literals. Repeated factors are ordinary Boolean values on the same x. For one term branch on the union of heavy live positions of its atoms, at most 4δn Boolean bits. On each of these disjoint branches, each tree has at most nL surviving live leaf occurrences. In a binary formula constant subtrees can be evaluated directly. A gate whose other child is constant induces a constant, identity or negation, and these unary transformations compose and can be absorbed in adjacent gates or input polarities. A nonconstant residual with l surviving leaves consequently has at most l−1 binary gates up to these polarities. This step uses the tree representation. Building and scanning the result takes polynomial time in M for fixed d.

Conjoin the surviving factors. Introduce one variable per binary gate with its full truth-table clauses and pin the output. Retain each unbranched x as a declared variable even if it disappears from the circuit. Every assignment extends uniquely. The resulting fixed-density 3CNF has O(nL+n) declared variables and clauses. The October theorem counts it deterministically in poly(nL)·2^{O(nL/√log(n+2))}=2^{o(n)} bit time. Constant circuits and empty conjunctions can also be counted directly. Sum over all branches; each original x appears exactly once. Signs and coefficients enter only the external exact arithmetic.

The total nondeterministic running time is

    2^{4δn + O_d(εn) + o(n)}.

All descriptor scans, arithmetic on coefficients, gate-index loops, and up-to-quartic expansion lengths are polynomial in M+S+s for the fixed d. The counted formulas have polynomial workspace in n. Scanning the guessed storage on a multitape machine costs at most a further polynomial factor in M+S+s, included above. Fix δ with 4δ<1/2, fix C, and then choose one sufficiently small ε>0 for both the union bound and the time exponent. This yields a nondeterministic O(2^{(1−ε)n}) UNSAT algorithm on circuits of at most 2^{εn} gates, under the contradiction assumption. To match the three-output gap convention of Murray–Williams, a passing UNSAT certificate outputs yes and failed guesses output unknown. A separate branch guesses and directly verifies an ordinary satisfying assignment, outputting no on success and unknown otherwise. The two non-unknown outcomes cannot occur on different branches of the same circuit.

Their theorem gives, for every fixed k, an NP language failing n^k-size ordinary circuits at infinitely many lengths. In contrast, the original common-d assumption implies a fixed polynomial upper bound on ordinary Boolean circuit size for every NP language: evaluate all bottom formulas and add their rationalized, signed, polynomial-bit contributions by bounded-fan-in integer arithmetic. For fixed d all degrees here are bounded by a constant depending only on d. Finite exceptional lengths for an individual language have no effect. Choosing k larger gives the contradiction.

## Scope and controls

The same reasoning works for an efficiently bounded K(M)=o(√loglog M). The concrete choice in the theorem avoids boundary constants. An ordinary DAG can compute each block parity once and then drive an arbitrary circuit from those shared output wires, so fixing one live slot per block can preserve the entire original circuit. Bounding occurrences in the unfolded formula forest is an additional restriction. The fixed-exponent order ∀d ∃L_d and the restricted representation are both essential to the statement.

[The formula-folding checker](read_pin_formula_check.py) tested 27,648 projections with all two-input gate types. [The parity-slot checker](parity_slot_projection_check.py) tested 729 occurrence arrays, 5,832 embeddings and 46,656 assignments. These are finite checks of the component arguments. The theorem uses the cited algorithmic and hierarchy implications.

Prior full-binary-basis formula #SAT algorithms give savings depending on linear formula density, and larger-formula algorithms give additive savings in the exponent. The projection above uses a constant fractional saving even when the live density tends to infinity. This is an application and proof comparison, without a claim of literature-wide priority.
