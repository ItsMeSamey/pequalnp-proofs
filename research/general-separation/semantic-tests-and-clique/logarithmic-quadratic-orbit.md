# Logarithmic horizon for reversible quadratic one-bit escape

Allow a bank link to be one layer of disjoint elementary NOT, CNOT and Toffoli gates. This broadens the single-gate link format. The one-step map and inverse have matching quadratic products, each output depending on at most three inputs. All ancillas below are dirty (arbitrary starting values, restored at the end).

Split repeated variable occurrences in a 3CNF into private variables, enforcing equality around each variable's occurrence cycle by binary implications. Omit self-implications. Each occurrence variable is in at most three clauses, hence the clause-overlap graph has bounded degree. A polynomial-time greedy coloring schedules clauses in constantly many disjoint groups.

Introduce one free bit c_j per clause. Let C toggle c_j by the indicator that clause j is false. This is a signed at-most-three-control NOT. Implement each with constant-size classical NOT and Toffoli circuits, using a restored private borrowed bit where needed. Run clauses in color batches for constant parallel depth. Define A=AND_j c_j and B=AND_j (C(c))_j. Their product is one precisely when c is all ones and every clause is true.

A target toggle by A is an exact multi-controlled NOT. A target toggle by B is C followed by that multi-controlled NOT and then the inverse of C. Khattar and Gidney's §5.5 supplies the multi-controlled gate in O(log m) total depth with two dirty ancillary bits, for m controls. Its reversible toggles and parallel disjoint Toffoli/NOT operations restore those bits; no measurement or clean-ancilla discount is used. Compute the product toggle y←y XOR AB by the four-corner gadget, using fresh distinct controls a,b: toggle y by ab at successive corners (a,b), (a XOR A,b), (a XOR A,b XOR B), (a,b XOR B), then restore b. This costs O(log m) depth, is exact for arbitrary a,b and restores all other state. [Khattar and Gidney, §5.5 and Figure 6](https://arxiv.org/pdf/2407.17966)

Pipeline one parallel layer per bank and pad the depth L to a power of two. After the exact unary time T=L, bank zero applies the constructed circuit to its own original contents. Fixing only its initial y to zero, an escape to y=1 exists exactly for satisfiable formulas. This gives NP-completeness at T=O(log N) in explicit description size N; the two possible full orders L and 2L are preserved. The claimed parallel construction permits elementary affine gates as well as positive Toffoli gates.

## Sublogarithmic horizons and recursive compression

The backward cone of a designated output at exact time T contains at most 1+3+…+3^T nodes, including initial coordinates. Enumerating its initial assignments costs at most 2^(3^T) poly(N) time on descriptions of length N. A stronger consequence comes from extracting the cone before solving it.

For each encountered (time, coordinate), read its explicitly described local truth table or elementary gate and visit its at most three parents. Preserve shared initial coordinates, renumber retained nodes locally, require the output to be one and set the designated initial bit to zero if it occurs. If it is absent any satisfying partial assignment extends by setting it to zero. An unrestricted initial state on all other wires is essential. Rewrite each constant-arity gate as constantly many fan-in-two Boolean gates and encode them by width-three Tseitin clauses. Using binary local indices yields a 3CNF with O((1+3^T) log(2+3^T)) encoding bits. Construction time is polynomial in N plus the explicit cone size. The unary time and explicit dependencies ensure no hidden work to look up the transition rule.

Suppose a deterministic polynomial-time reduction of 3SAT on inputs of bit length s asks only valid queries, all of length N≤poly(s) and all obeying one uniform T=o(log N) promise. Every resulting 3CNF has size s^o(1); bounded N contributes only a constant. For a many-one reduction, recursively apply it to the extracted 3CNF. Each iteration at least halves the input length once s is sufficiently large. Treat the finitely many smaller formulas by truth-table enumeration. This decides 3SAT in polynomial time.

The same conclusion holds for polynomially many adaptive oracle queries, provided the promise holds along every execution used in the simulation. After increasing the constant base threshold, each query compresses to at most sqrt(s) bits. A polynomial bound s^C covers the number of queries, extraction, and reduction overhead. The running time is bounded by s^C(1+max_{u≤sqrt(s)}R(u)), which is polynomial by induction (choose exponent greater than 2C and enlarge the base constant). An implementation can use exhaustive evaluation below a constant size (for instance s≤4) and brute-force the current source formula whenever a query fails the square-root size test. Such failures occur only at bounded source lengths. Conversely P=NP gives a constant-size YES/NO many-one reduction. Thus NP-hardness of this promised sublogarithmic target under either reduction is equivalent to P=NP. The fan-in bound and the single initial restriction are used in extracting the small query. For a reduction whose queries have N=O(s^d), a fixed upper bound T≤c log₂ N still gives power shrink whenever dc log₂ 3<1. This argument is independent of any exponential-time hypothesis.

## Low-order solver controls

On the Boolean cube A·B equals (product of all c_j) times φ(x). If any c_j is zero then A=0; if all are one then B tests every clause. A satisfiable instance thus has exact target coordinate y plus a nonzero polynomial whose extra monomials all contain the m distinct c_j. For an unsatisfiable instance it is y. Truncating to degree below m returns y in either case. Testing starts of Hamming weight below m likewise finds no escape, and the escape probability on a uniform initial hyperplane is 2^(−m) times the original satisfaction probability. These restrictions concern the inspected output or samples; the input transition description remains available to an unrestricted solver.

In the single-gate-per-bank format every backward step of the observed worldline can add at most two initial-coordinate dependencies. The cone has size at most 1+2T, making T=O(log N) tractable there. The logarithmic-horizon NP-hardness uses parallel disjoint layers. In general k active gates per bank layer give a cone bound min(3^T,1+2kT).

## Positive-only version

The companion positive marked-position construction implements an exact many-positive-control toggle in logarithmic disjoint-layer depth and linear size with restored arbitrary borrowed wires, using only ordinary three-distinct-wire positive Toffoli gates. It adapts the cited marked schedule with a three-wire representation; this stronger gate restriction uses the companion proof, not an assertion that the published implementation has no NOTs.

Give each clause gadget its own two untouched enable bits. Replace its NOTs and CNOTs by positive Toffolis controlled by the appropriate local enable(s), allowing the gadget to behave differently when an enable is missing. Call this changed circuit D. It never changes the enable bits, and it implements C when they are all one. Redefine A as the AND of all the c_j and every enable. Implement B by D, the positive multi-controlled test of all c_j into its temporary target, and D inverse. Thus B is always a clean target toggle as a functional map on arbitrary initial states, even if D acts unexpectedly off the enabled subspace. The product A·B is one exactly when all c_j and enables are one and all clauses hold. The four-corner product gadget restores all scratch. Independent clause enables eliminate shared-control scheduling conflicts. The positive-only global one-step map therefore has linear part the bank shift and pairwise disjoint positive quadratic products, at logarithmic horizon. ## An affine-invariant obstruction to sparse Walsh expansion

Take the elementary source φ_m=AND_i (NOT x_i OR NOT z_i) on m disjoint pairs. Its zero assignment is a satisfying assignment. Pin y=0 and all guard and clause bits to one on the designated full-lap output. The resulting restricted output function is the product of m local functions that are one except at pair (1,1). Over the rationals the local Walsh coefficients are 3/4, 1/4, 1/4, −1/4. Thus the tensor product has 4^m nonzero characters. Over a field of characteristic three it still has 3^m; over odd characteristic other than three it has 4^m. Restricting to an affine subspace can only merge or delete characters, so the unrestricted output has at least as many. Applying any invertible binary affine reparameterization to the entire initial state permutes signed characters and cannot reduce this lower bound. Yet one evaluation circuit for the complete output always has polynomial size by ordinary unary unrolling. This rules out universal exact polynomial-sparsity Walsh representations even after affine basis recovery and on satisfiable instances with an immediate witness. It does not rule out operating on a factored Walsh representation.
