# A uniformly named bit decides the hard unary language

The October source at 42907c9e999cc00d6abe7a50bfc1023250edd1b9, quantitative-circuits.tex, fixes unary H in NTIME(2^n) outside NTIME(2^(n/2)). Its selector W on dn-bit labels is the lex-first satisfying assignment on YES and zero everywhere on NO. JMV section 5 page 18 outputs a positive triple repetition of the same variable for s=1 in the checker region. Choose the first checker j and first valid instance i and read its repeated output label from the uniformly constructed decoder on this branch. The local gate-name field, if requiring a valid code, has O(log log T) bits and may be enumerated in poly(n) time here. The output gate name internal to the decoder requires no external advice. Apply the source's fixed uniform label padding. Thus there is a deterministic polynomial-time g with W(g(n))=H(1^n) for every sufficiently large n. See [JMV §5](https://www.khoury.northeastern.edu/home/viola/papers/explicit.pdf).

If a uniform deterministic 2^o(n)-time algorithm recovers even this bit with an NP oracle on queries of length m=n^o(1), simulate each query exhaustively in 2^poly(m)=2^o(n) time for its one fixed verifier. The number of adaptive calls is at most the running time. The resulting unary decision including address generation is eventually within the forbidden 2^(n/2) clock, and finite exceptions can be hardwired. Moreover W itself cannot belong to NP because H polynomial-time reduces to it and H lies outside NP by the same hierarchy. None of this constrains nonuniform length advice.
