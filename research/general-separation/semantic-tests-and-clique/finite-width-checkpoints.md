# Certifying emptiness on a finite-width computation inside the smaller clock

Fix the clock constants of the November 24 preprint, with rational 0<ρ<b<1/20 sufficiently small as in its clock theorem. It suffices here to handle its dyadic batch parameter R, supplied with n to the public machine, with n^ρ≤log₂R≤3n^ρ. Define w=⌈20log₂(nR)⌉, L=⌈Rn^(1+b)⌉ and T₋=⌊Rn^(1−b)⌋. A public tick handles a bounded number of w-bit words. At the smaller clock a private job receives at most ⌊√n⌋ bits and has n^20 multitape steps per path. The public machine pays for every job and every issued bit. [Source clock model and theorem](https://raw.githubusercontent.com/openai/math/main/preprints/Circuit-lower-bounds-for-Hamiltonian-cycle-and-the-permanent-November-24-2026/build/gap.tex)

**Restricted input model.** There are L transitions between layers of W named states, 1≤W≤⌊n^(1/4)⌋. The public host initially has one seed z of at most ⌊n^(1/4)⌋ bits, W, and two W-bit masks I and F for initial and final states. A single fixed deterministic multitape program decides the edge predicate from (n,z,i,u,v) in at most n² steps for 0≤i<L and 0≤u,v<W. State indices and layer addresses have canonical binary encodings; i fits in one w-bit word for all large n. The seed and the masks can be copied directly from known cells. These assumptions give the private machine the whole input to its generator and charge its access cost. Reading arbitrary other public memory would require an additional mechanism.

**Construction.** Split [0,L) into consecutive blocks of B=n² transitions, shortening the last block as needed. Set the current mask to I. For each block the public machine guesses exactly W bits for the next mask. It sends a job with n, W, seed length, block start and length, seed, current mask and next mask. For example, encode the five integers with binary self-delimiting codes of at most twice their binary length plus three bits each. Since each integer fits in w bits, a job has at most 10w+15+3⌊n^(1/4)⌋ bits, below ⌊√n⌋ eventually. The public machine saves the guessed next mask as the current mask. At the end it tests that the current mask and F have empty intersection. Jobs return no data. The only public nondeterminism is the guessed masks.

The fixed private machine loops in binary over layer addresses starting from the transmitted address. At each layer it builds a fresh W-bit mask. For each state pair (u,v), it calls the fixed edge program on that layer, the transmitted seed, and the two indices, and ORs the result into the bit for v if u was reachable. It compares the result at the end of the block with the claimed next mask. Fresh input tapes and output positions can be reset by scanning the at most O(n²) cells used by each call. Even the conservative bound O(n⁴) multitape steps per pair includes copying the seed, maintaining the counters, scanning masks, and resetting the generator. A block takes O(BW²n⁴)=O(n^(13/2)) steps, below n^20 eventually. Fixed finite exceptional values of n can be handled separately outside the asymptotic claim.

For a fixed starting mask the next mask is unique. Induction along the blocks therefore gives exactly one successful completed computation when no initial state reaches a final state, and none when a final state is reachable. This proves emptiness even with many paths merging into a single state. The matching public running time can be bounded by O(poly(w)+(1+L/n²)(W+w²)). Word comparisons, additions and address increments suffice once B and L have been prepared. With fixed rational b the ceiling defining L can be computed once by elementary integer arithmetic in poly(w) time. Each block can serialize W-bit masks and seed bitwise and its five headers in O(W+w²) ticks. Since w=O(n^ρ), the ratio of the block cost to T₋ is O(n^{2b−2}(n^{1/4}+n^{2ρ})), which tends to zero. The additive polynomial in w and the final mask check also cost o(T₋) since R≥2^(n^ρ). The reachable-set update is the classical subset construction. [Rabin and Scott](https://doi.org/10.1147/rd.32.0114)

**Cost of a single split certificate.** In an interface test, independently choose X,Y⊆[W]. A prefix makes exactly X reachable at the middle layer, and a suffix permits exactly Y to reach a final state. A source and a sink in single-state end layers suffice. Emptiness at the join is exactly X∩Y=∅. Suppose a fixed-length shared certificate of c bits is guessed, and each half tests only its own input and this certificate, with unrestricted additional local existential witnesses. Each shared certificate then describes a rectangle of accepted pairs. The 2^W pairs (X,[W]∖X) are disjoint pairs; any two distinct such pairs have at least one intersecting cross-pair. A sound rectangle covers at most one of them, so c≥W. Variable-length strings of maximum length c yield the same integer bound using at most 2^(c+1)−1 certificates. This is a single-interface lower bound. When W satisfies the positive lemma's bound these choices can also be given as initial/final masks with identity transitions. It does not preclude multiple charged messages, or algorithms jointly accessing X and Y. An application to the full arithmetic diagonal would still have to supply the small-width state description and uniformly accessible transitions.
