# Affine encodings of few-score SAT constraints

Consider polynomially described affine bits y_i=a_i·x+b_i over GF(2), i=1,…,N, encoding x∈{0,1}^n. A signed rational sum of conjunctions of local affine-bit values can be counted at any score level in poly(input,B)(m+1)^{O(B)} deterministic time when it has ≤B distinct scores. Apply the [clause-tuple moment algorithm](few-score-sat-clarified.md). Intersecting any tuple of prescribed bit patterns gives one affine system in x; use Gaussian elimination to count exactly 0 or 2^{n−rank} original assignments. The bound does not depend exponentially on the width of one specified pattern. For arbitrary Boolean k-local tables, expand the patterns at a cost of at most 2^{O(kB)} per tuple. All bits may involve dense parities of the original input. [Finite affine tuple and simplex tests](affine_score_simplex_check.py)

Suppose a witness-preserving predicate on x has an accepting auxiliary string z exactly on solutions. For each fixed z suppose acceptance is a table on ≤B attained values of a score of degree ≤k in the encoded bits y. On the attained codewords interpolation gives a polynomial of degree ≤d=k(B−1) in y, with an arbitrary extension off the code. This remains true if the affine map itself depends on the instance (or on the fixed z), though the following mask set must then refer to the selected map.

Let D_d be the sums in GF(2)^n of at most d coordinate masks a_i. Restrictions of all degree-≤d real polynomials in y to the affine image have Walsh Fourier frequencies in D_d. Conversely every frequency in D_d is the restriction of such a polynomial, since (−1)^{a_i·x}=±(1−2y_i). Thus the encoded degree space is exactly the span of those characters, without any bound on description size in this converse.

If a face of dimension t contains T>0 solutions, fix one successful auxiliary string there. Its nonzero accepting function has support ≤T and Fourier support in the restricted-mask set D_d on the face. Fourier uncertainty therefore gives |D_d|≥2^t/T. Indeed for a nonzero function g, Cauchy–Schwarz bounds each unnormalized Fourier coefficient by sqrt(|supp g|)·||g||₂ and Parseval sums their squares to 2^t||g||₂². In particular Σ_{i≤d}binom(N,i)≥2^t/T. If the possible successful x lie in an affine flat a+V, a nonzero coefficient at frequency λ forces nonzero coefficients at every λ+V^⊥, by modulation on that support. [Meshulam, finite Fourier uncertainty](https://arxiv.org/abs/math/0312407)

For a unique original witness, all 2^n Walsh frequencies occur in the delta function obtained after fixing one successful z. Hence D_d must be all of GF(2)^n. If the mask matrix A has full column rank, the minimum degree for a point is precisely the covering radius of ker(Aᵀ): every syndrome must be representable as Aᵀv with wt(v)≤d. In particular, for N=n^{c+o(1)}, c>1 fixed, the volume bound yields d≥(1−o(1))n/((c−1)log₂ n). For N=O(n), it gives d=Ω(n). This is the sphere-covering mechanism of coding theory; the following dimension argument is related to classical few-distance bounds. [Delsarte](https://doi.org/10.1016/S0019-9958(73)80007-5)

The scale is attainable for every point on a shared code. Split x into blocks of length ℓ≈(c−1)log₂ n (with a possibly shorter last block) and list all 2^{ℓ_j}−1 nonzero parity masks of each length-ℓ_j block. The code uses N=n^{c+o(1)} coordinates. Relative to E(a), a differing block contributes exactly 2^{ℓ_j−1} mismatched bits. Weight this block by 2^{1−ℓ_j}. The resulting sum counts mismatching blocks, has B=ceil(n/ℓ)+1 values, and is zero exactly at a. This uses local width one and d=B−1=(1+o(1))n/((c−1)log₂ n). One mask per nonzero block suffices for every target frequency, and some frequencies require a mask in every block.

For any single shared encoding E (even nonlinear) representing every point target by the prescribed score model, fix a successful auxiliary string separately for each target. Its corresponding point function belongs to the span of the same ≤Σ_{i≤d}binom(N,i) restricted monomials. Since the 2^n point functions are linearly independent, the same volume lower bound follows. The common-code condition is essential for this nonlinear argument: an instance-specific nonlinear coordinate may itself be the target point predicate. The arguments concern witness-preserving low-score models; they do not yield a lower bound on general SAT algorithms.
