# A recursive oracle separating coefficient size from generation time

There is a recursive oracle A containing at most one word of each length. Define a_n to be 1 if A contains a length-n word and 0 otherwise. On every x of length n the language L has indicator a_n. Its real coefficient in the fixed one-feature dictionary consisting of the constant function 1 is unique and equals a_n. Thus one advice bit per length suffices. The verifier guesses n bits y and makes the single membership query y. It runs in O(n) oracle time and has exactly a_n accepting paths.

Every deterministic oracle machine that outputs the correct coefficient on every input 0^n takes at least 2^n steps on infinitely many such inputs. Moreover every deterministic explicit-list generator that, on all positive inputs 0^n, prints the witness among its candidates takes more than floor(2^n/3) steps on infinitely many positive inputs. We use a standard multitape oracle machine with at most one membership query per step, and a serial output tape. Candidates are complete explicitly delimited length-n words. The list bound even allows one completed candidate per step.

Enumerate every machine infinitely often for each of two stage types. Choose n strictly above all previously finalized lengths. In a coefficient stage simulate the machine on 0^n for 2^n−1 of its own transitions. Answer previously finalized queries consistently and answer all other queries negatively. If it halts with output zero, insert a length-n word it did not query. In every other case leave length n empty. Any halted answer is now wrong, including malformed outputs. A timeout costs at least 2^n transitions for a correct total machine. In a list stage simulate for T=floor(2^n/3) transitions. Insert a length-n word outside both the at most T length-n queries and the at most T completed candidates. This remains possible since 2T<2^n. Every list stage produces a positive input. On both stage types finalize every length up to the maximum of n and all query lengths seen, retaining earlier decisions and setting unspecified words to absent. The added word preserves the simulated transcript. Increasing cutoffs and finite effective simulations give a decider for A by replaying stages until the requested length is finalized.

The clock counts simulated native transitions. The recursive constructor can spend arbitrarily more time simulating each transition. No universal-machine time bound enters the lower bound. A machine model making up to b individual oracle queries per step instead gives the corresponding factor-b adjustment to the coefficient bound. The argument does not cover a primitive that tests many oracle words in one query.

This is a relativized control for any proposed implication from unique, cheaply verifiable witnesses and short nonuniform coefficients to uniform coefficient generation. The proof uses the classical oracle diagonalization of Baker, Gill and Solovay. The dictionary and explicit-list formulations specialize that method. [Baker, Gill and Solovay, SIAM Journal on Computing (1975)](https://doi.org/10.1137/0204037)
