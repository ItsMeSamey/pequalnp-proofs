# A small controller with maximal short-context uncertainty

For n≥2 set N=2^n. Use the classical modified maximum-length binary shift-register construction, inserting the zero state into the cycle of all nonzero states. Gabric and Sawada study de Bruijn sequences obtained from primitive feedback polynomials in their comparison of discrepancy constructions. The following proof records what this example implies for three specific stream diagnostics. [Gabric and Sawada (2022)](https://doi.org/10.1016/j.disc.2021.112780)

Use the shift (a₁,…,aₙ)↦(a₂,…,aₙ,L(a)), with L a maximum-period linear feedback over the binary field. Such taps exist by taking the companion of a primitive degree-n polynomial. The coefficient of a₁ is one, so 10…0 maps to 0…01 and zero maps to zero. Toggle the feedback bit exactly at those two states. The cycle now traverses every state once. Start at zero and emit the leading bit at each step. Because consecutive states shift by one, the cyclic length-n windows are precisely those N different states.

Every fixed k-bit preceding context for k<n has equally many zero and one successors, each occurring 2^{n−k−1} times per cycle. Thus a fixed next-bit predictor depending only on that context succeeds on exactly half the positions under the uniform cyclic index (in expectation for a random rule independent of the index). The qualifier excludes predictors accessing the address or keeping extra state.

The binary linear complexity of the periodic sequence is strictly greater than N/2. Indeed the monic minimal annihilator for the shift divides X^N−1=(X+1)^N. If it had degree at most N/2 it would divide (X+1)^{N/2}=X^{N/2}−1, forcing period at most N/2, contrary to distinct length-n windows. The same strict bound holds for homogeneous time-independent binary recurrences fitting the finite word of two consecutive periods: for order d≤N/2, the checked positions d through d+N−1 contain every cyclic recurrence test and fit inside the doubled word.

The nonlinear controller has n state bits and O(n) fan-in-two gates, implements both exceptional transitions with one zero test on the trailing n−1 bits, and needs no resets. The linear controller with the same taps instead needs at most four prescribed next-state overrides across two periods, without changing the output bits at their source positions.

There is a uniform choice in E: select the lexicographically first maximum-period tap vector by running each of at most 2^n candidates from state 1 for at most N−1 steps, checking that the first return occurs at N−1 and zero was not reached. The scan and direct bit simulation take O(poly(n)4^n) time. The indexed bit function is also in P/poly. At position zero emit zero; at position j>0 its state is the original linear companion raised to power j−1 and applied to the vector 0…01. Hardwire the n binary matrix powers and select their successive applications by exponent bits, giving O(n³) bounded-fan-in gates. This example defeats suffix predictability and low binary linear recurrence order as necessary consequences of small controllers. It supplies one compressible E stream and does not settle any universal compression claim about E.
