# Monotone finite rank certificates for cyclic reachability

The [weighted-rank theorem](weighted-rank-programs.md) remains valid for the following larger class of edge certificates. Each genuine transition e has a fixed explicit monotone table T_e on the chain D={0,...,H,∞}, with T_e(∞)=∞. For every complete raw input the enabled graph satisfies these two conditions.

- Every state that can reach acceptance has a finite accepting path whose composed map, applied backwards to terminal label zero, yields a finite label.
- There is no nonempty enabled closed walk equipped with finite labels satisfying r_u=T_e(r_v) on every traversed edge. Equivalently the directed graph of enabled state/finite-label pairs with equality edges has no directed cycle.

The Boolean function is ordinary reachability. For fixed a<1/2, b≥0 and d, impose the earlier node budget M ceil((loglog M)^a), table cap H=ceil((loglog M)^b) and M^d exact-real top summands; allow the previous formula atoms too. The result is again one language in NP for these fixed parameters that fails the representation infinitely often. The tables on the polynomial number of possible input-labeled edges have an explicit description polynomial in M. Syntactic monotonicity and the infinity convention can be checked, even though the two displayed semantic conditions need not be.

For each input use the minimum, over finite accepting paths, of the composed transfer applied to terminal zero, taking infinity when all paths yield infinity or none exist. Finite minima are attained since the chain is finite. Monotonicity lets each transfer commute with finite minima. Hence these ranks satisfy the Bellman equations, taking the minimum across enabled edges. Any candidate fixed point is at most the value along each terminal path by unrolling the upper inequalities and monotonicity. From a finite candidate there must be a tight successor, and it has finite label by infinity preservation. A nonterminating tight chain would repeat a state/finite-label pair. Thus some accepting path attains the candidate. This proves uniqueness and, by the coverage promise, identifies finite rank with ordinary acceptance.

When pinning raw bits, privately contract each atom exactly as in the [global termination proof](semantic-halting-programs.md). For each retained source/outcome, first retained endpoint v and candidate target label r, take the minimum of all segment compositions applied to r, allowing all positive-length paths through fixed-query interiors. Retained nodes stop a segment; a nonempty return to its source is allowed. No path gives infinity. Compute all obtainable labels by reverse reachability from (v,r) through the expanded state-label graph, mapping each child label z to T_e(z) on an allowed predecessor edge. Permit only fixed interior states and the designated first edge at the designated retained source. This is polynomial even on invalid guesses with cycles. The pointwise minimum of the segment maps is monotone and preserves infinity. Every finite compressed tight arc at its specified endpoint label lifts to an attaining segment whose intermediate labels stay finite. A finite expanded cycle after compression would lift to an enabled finite-label closed walk before it. Segment decomposition and lifting preserve minimum accepting values, using monotonicity to replace suffixes by minima.

The [fixed-width rank encoding and signed switches](feedback-rank-programs.md) use the stored tuple tables in place of capped addition, with e fixed so a+b/e<1/2. Their dimension remains O_e(n+(nL+1)(H+2)^{1/e}), the width at most max(3,2e+2), and the [October arbitrary-density counter](https://github.com/openai/math/blob/92b516ef8e/preprints/The-Exponential-Time-Hypothesis-is-False-October-25-2026/build/main_full_version.tex#L68-L82) costs 2^{o(n)} per heavy assignment. On invalid tables satisfying the checked syntax define each atom/index function as its number of Bellman tables with finite start after its private compilation, before pins from other factors. Independent copies per occurrence and unit conditions for those other pins keep all moment products consistent. Genuine reachability supplies the assumed Boolean representation and ordinary polynomial circuit upper. [Finite transfer-map tests](monotone_rank_transfer_check.py)

## Certificates from recursively separated components

Suppose the raw graph decomposes in at most t≥1 levels. Split it into its strongly connected components; choose at most k≥1 separator vertices in each, remove them, and repeat on the remaining components, until every vertex belongs to one chosen separator. Components at the same level and different ancestor components are distinguished. Order need not be provided for transitions between distinct components. A tuple of t digits in base B=k+1 gives an integer rank between zero and B^t−1. This class fits the preceding theorem whenever B^t−1≤H. In particular t can be fixed and k bounded by a fixed power of loglog M, or k fixed and t=O(logloglog M), with an appropriate b.

For each state u list its nested components up to the depth j(u) of its owning separator. For an edge u→v let l be the length of the common prefix of the component lists (terminal lists are empty). On a finite r, zero all digits after l, then add B^{t−j(u)} by ordinary scalar addition. Overflow above B^t−1 maps to infinity. Infinity maps to infinity. This is a monotone scalar map on all ranks, including tuples that no genuine path realizes. In particular one must not map an isolated lower digit's overflow directly to infinity before scalar carrying.

Read a simple accepting path backwards from zero. At a state u, digit j counts the departures from level-j separator vertices in u's level-j component up to that path's first exit from it, including a departing source at that separator. Digits for levels absent from u's chain are zero. The prefix reset and source increment give this description inductively. Each counted separator has at most k distinct vertices and simplicity prevents repeats. No digit carries and the path has finite rank. For any directed closed walk take the deepest component, at depth j, containing all its vertices. It touches that component's separator; otherwise the walk lies in a child strongly connected component. The prefix through depth j is kept on every edge. Along its backwards evaluation the numerical prefix through j cannot decrease, and increases at the departure of a vertex in this separator if finite. Thus a finite equality cycle is impossible. Repetition of an entire state with a different label does not affect this argument.

The following separation of the description conditions uses k=1 and at most three levels, counting singleton acyclic states at the bottom. Take the staged [two-cycle example](component-rank.md). Add a hub r that starts the first stage and a choice to return to r from the last dispatch instead of accepting. The nonterminal stages form one strongly connected component with arbitrarily many vertex-disjoint two-cycles. Deleting r leaves the forward chain of local cyclic components, each split by one vertex and then singletons. Thus fixed constant depth and k=1 suffice, while the raw component's feedback number grows. Adding the restart cannot skip a forced expensive stage, so unbounded total additive costs on some accepting inputs persist under any integer edge costing that makes every enabled cycle positive. The example separates certificates on the graph, not the scalar language.
