# Two readouts with incompatible head triggers

Give each directed nonloop box in the overlap multigraph a head whose defect bit is unrestricted. Its tail defect bit is unrestricted except when the tail is selected and its head occupancy equals a specified trigger, in which case it equals the specified forced bit. These two choices are independent subject to the tail rule. Triggers and forced bits may differ on parallel edges. With arbitrary symmetric affine occupancy drift, at most two affine occupancy readouts, and at least one incident box per site, there is a deterministic polynomial witness algorithm.

Initially take as unrestricted sites U all heads. They can correct any drift when selected. Each remaining site i∈S has a nonempty list of release literals on U: for each of its tail incidences the corresponding literal is true exactly when its head misses that edge's trigger. Write y on U and x on S. The site is unguarded if any release literal is true. Otherwise selecting it imposes (Ax)_i=c_i(y), where A is simple symmetric on S and c_i is affine, incorporating all forced defect bits and its drift. This description remains valid after moving any guaranteed unguarded site to U, since its bit simply becomes another affine input to the drift. Readouts are Cx+Hy=d.

If C has rank zero set x=0 and solve for y, respecting any prescribed head bits. In rank one row reduction gives an affine y-slice and one binary readout β·x=b(y). An empty slice rejects; b(y)=0 permits x=0. On the remaining slice b(y)=1. For fixed y the [one-readout component criterion](canonical-fourteen-two-readouts.md) says there is no witness exactly when every component of A containing at least one β-marked site has all its release literals false and c(y)=β there. For clarity, a marked unguarded vertex itself works. If an unguarded vertex occurs in a marked component and none is marked, a guarded subcomponent containing a mark has an unguarded neighbor. Flipping this unmarked neighbor changes a nonzero column of its drift, so one choice yields drift different from the nonzero marked vector. The [prescribed-degree span lemma](symmetric-single-row-p3.md) supplies an odd-readout selection. If the whole marked component is guarded the same lemma applies directly. Conversely when each of those components is guarded with drift β, handshaking rules out the required odd readout. All these simultaneous failure conditions are affine equations on y, even when signed literals conflict. Containment of the permitted slice in their intersection, and a witness to noncontainment, follow by elimination.

At initial rank two, seek two sites with independent C columns whose release literals can both be made true. Check every incidence pair. On success fix the two literals, complete y arbitrarily and use only the two sites to realize the required two-bit syndrome. Otherwise take any independent pair i,j. Every release literal on i conflicts with every release literal on j. Contradictory single literals must be on the same head variable with opposite values, so both sites have uniform release lists on one head h. Any site with a nonzero column independent of i must have j's release literal. Any site with the same column as i is independent of j and has i's literal. A third column value would be independent of both, an impossibility. Split on the two values of h. Each choice makes every site of one of the two column classes unrestricted. Move that whole class into U, fixing h in the permitted slice and retaining its original contributions to the readouts and drifts. The residual rank on S is at most one, already solved. This two-way split retains all occupancy possibilities. In any successful branch choose exposed defects sitewise and recover original private witnesses from the supplied physical box tables.

The argument covers arbitrary signed triggers on rigid fourteen-state boxes. A general fourteen-state table can instead forbid the two off-diagonal defect pairs when both endpoints are occupied, leaving a coupled parity relation with no always-free head. The theorem therefore does not imply a polynomial algorithm for all fourteen-state tables.
