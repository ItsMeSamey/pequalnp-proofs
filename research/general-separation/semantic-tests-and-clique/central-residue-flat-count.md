# Exact counting with affine Hamming-weight summaries

Let q be the number of primary bits, and write L=log₂(q+2). Let 1≤h≤√q/L⁸. An input specifies h lists, each consisting of q affine forms over GF(2) on the primary bits, and a deterministic polynomial-time constructor. For each possible vector of integer counts w, the constructor supplies a polynomial-size system S_w of equations over GF(2), each an XOR of products of affine forms on the original variables. The bounds on the constructor, system and input encoding use fixed polynomial exponents. An input x is accepted when it satisfies S_w with w_i equal to the number of true forms in list i. The constructor can express any polynomial-time predicate on the count vector by returning a constant system. It can also change the actual constraints on x according to that vector.

Assume each list splits into balanced contiguous blocks of target length t=ceil(h√q), with the linear parts within each block independent. Full independence across an entire list is sufficient. Block partitions with the same sizes can instead be supplied. The theorem gives a deterministic exact count in time

    2^{q−Ω(√q/(h L⁶))}.

Polynomial factors are absorbed under the stated upper bound on h. At fixed h a separate choice of parameters improves the saving exponent to Ω(√q/L⁴). No independence between blocks or between lists is required. The interpolation, decoding, and exception correction below use explicit input descriptions. The scope includes a symmetric gate reading an affine basis and a polynomial system depending on its output, with arbitrary chosen target weight and no lower bound on the fraction of accepting inputs.

**Counter used.** Lokshtanov, Paturi, Tamaki, Williams and Yu, Theorem 1.4, deterministically count a system of supplied XORs of products of affine forms over GF(2) on v variables with s product gates and explicit size u in time poly(u) times 2 raised to v minus Ω(v/(1+log₂(max(1,s/v)))). For low s, polynomial padding to at least v product gates suffices. Products can contain many affine forms. The deterministic algorithm counts ordinary assignments. [LPTWY](https://theory.stanford.edu/~yuhch123/files/polyEq.pdf)

**A surrogate with one extension per input.** Split each list into ceil(q/t) almost equal blocks. For sufficiently large q all lengths m are between t/3 and t. The total number of blocks is O(√q). Choose a power of two M between √q/(2L³) and √q/L³. For each block put B=floor(m/2)−M/2. Replace its actual weight w by the unique integer w' in [B,B+M−1] congruent to w modulo M. This interval lies inside [0,m] for sufficiently large q. If w' differs from w, then |w−m/2|≥M/2−1.

For 0≤j<log₂ M the j-th bit of w equals the XOR of all products of 2^j distinct forms in its block. This follows by comparing the coefficient of Z^{2^j} in (1+Z)^w with the binary-digit factorization of that polynomial over GF(2). Make these bits unique auxiliary variables by equality with the stated XORs. Use O(L) two-input gates per block to add a fixed shift modulo M and add B in ordinary binary, thereby forming w'=B+((w−B) mod M). Add the decoded block counts for each list with O(L) gates per summand. Enforce each gate's truth table by a constant-size GF(2) equation, with one additional variable per gate. The entire construction adds b=O(√q L) variables. Every assignment to the primary bits has exactly one extension to these arithmetic bits.

Enumerate all (q+1)^h possible vectors v of final decoded list weights. Pin the h binary sums to v and append S_v. Each x appears in exactly one such call before testing S_v. Summing the exact answers gives the surrogate's count. A malformed or small dimension can be handled by exhaustive enumeration. Evaluating the surrogate directly on one x only requires computing the affine forms, their block weights and integer residues and evaluating its explicit polynomial-size S_v.

**Clock.** Each block requires at most L times the sum of binomial(m,i) over i≤M/2 products. An input description for each product needs at most poly(q) bits for its factors, and the lists and generated equations are uniformly enumerable in time polynomial in their displayed length. Consequently both log₂(s+2) and log₂(u+2) are O(M L+L)=O(√q/L²). With v=q+b variables the counter saves Ω(√q L²) in its exponent measured from v. The variables cost O(√q L), writing and processing the explicit description costs 2^{O(√q/L²)}, and the number of calls costs 2^{O(h L)}. The total main count thus takes at most 2^{q−Ω(√q L²)} for sufficiently large q.

**Exact correction.** Under uniform x, every chosen block has independent, unbiased truth values. For one block the number of assignments where w is outside its interval is at most 2^q times 2 exp(−Ω(M²/t)) by the binary binomial tail bound. To enumerate them, extend the independent linear forms in the block to a basis. Enumerate only m-bit strings of the exceptional weights using combinations, and all q−m remaining coordinates, and invert the affine coordinate change. After polynomial preprocessing this takes polynomial delay per point plus polynomial setup. If the exception singleton lies in many bad blocks, process it only when enumerating its first bad block in a fixed global order. Test earlier blocks and compute both the original and the surrogate predicates directly in polynomial time per visit. On this union add the original acceptance bit minus the surrogate bit to the main count. Outside it the bits agree. The correction is exact even when the source has only one satisfying assignment. Counting duplicates before filtering increases total work by at most the number of blocks. There are O(√q) blocks and M²/t=Ω(√q/(hL⁶)), at least Ω(L²) at the largest allowed h. This proves the stated bound including polynomial overhead. The counter's saving also dominates the correction saving.

When h is fixed choose instead t=ceil(√q) and M a power of two of order √q/L². Now log s and log u are O(M log(et/M)+L)=O(√q log L/L²), since the index i is at most M/2. The counter saves Ω(√q L²/log L), absorbing the same O(√q L) unique-extension cost. The tail exponent is Ω(√q/L⁴).

**Controls and limits.** On a majority test, a false surrogate acceptance and a missed true acceptance both receive the correct signed adjustment. An arbitrary singleton indicator on primary bits is a product of affine literals, and can be toggled in an output equation regardless of whether it lies in the exceptional union. A sum of disjoint cubic monomials is also one permitted equation. No expression of an arbitrary q log q gate DAG by the required lists and conditional systems is supplied. A direct white-box decision-preserving compiler from all circuits in that size range, running within the overall saving, would entail the earlier E^NP infinitely-often gate bound through the unary reduction. This result alone does not imply a lower bound for general circuits or P versus NP.

Williams already gives deterministic counting algorithms for ACC with bottom linear threshold gates, including substantial overlap on symmetric tests of the raw input bits. Here each weight can read a different supplied affine basis and the joint vector may select an input-dependent equation system. Neither a strict model separation from previous algorithms nor a literature-wide novelty claim is made.
