# Counting baskets with shared nonlinear intermediate outputs

Consider q primary bits x and a topologically ordered sequence of m Boolean gates gᵢ. Gate i is given by a truth function of at most a affine forms in x and g₁,…,gᵢ₋₁. A listed gate output may occur in several baskets; let p count membership occurrences over b baskets. Their integer sums select a polynomial-size system of XORs of products of affine forms on x through a uniform polynomial-time constructor. We count satisfying primary assignments. Uniform polynomial input and construction bounds, m,p=poly(q) and a=O(log q) are assumed.

Form a matrix over GF(2) with one row for each gate argument, consisting of its coefficients on g₁,…,gₘ alone. Let r be its rank, Q=q+r, L=log₂(Q+2). Both the matrix and r are computable from the supplied description. All gates whose values are used only as basket entries incur no rank charge for those entries. If h=max(1,ceil(b+p 2^{3a/2}/Q))≤Q^{1/3}/L³, there is a deterministic exact algorithm taking

    poly(q) · 2^{Q−Ω(A/(h L⁶))},    A=min(√Q,Q/h²).

In particular r=o(A/(h L⁶)) gives an exponential saving of Ω(A/(h L⁶)) bits in the exponent relative to primary exhaustive search. This condition charges each shared parity of previous nonlinear outputs once, independent of the number of consumers.

## Global rank with a causal basis

Compute a row-echelon basis with distinct pivots defined as the *largest* nonzero indices. Any argument at gate i is a combination of basis rows with pivot less than i: in any combination the largest pivot used survives, because all other rows vanish there. Introduce one bit z_v for each basis row v. Replacing the gate-output part of every argument by the corresponding linear combination of z bits turns every gate into a local truth function Gᵢ of at most a affine forms on (x,z).

Impose the equation z_v=Σᵢ vᵢ Gᵢ(x,z) over GF(2) for each basis row. A local truth function has a multilinear GF(2) representation with at most 2^a monomials, obtained by the subset transform of its supplied table. Substituting affine forms exhibits each defining equation as an XOR of products of affine forms and takes polynomial description size, even if the row is dense. If v has pivot j then only i≤j occur, and Gᵢ uses state bits of pivots strictly below i. Consequently the equations have exactly one extension for every x by induction on pivots. The extension is the vector of basis parities of the original gate outputs: substituting that vector evaluates every affine argument and gate correctly by gate order. This proves the count is preserved, including when the selected final equation system is inconsistent.

Apply the [local-gate weight compiler](local-gates-affine-weight-count.md) on Q variables to the basket occurrences of Gᵢ. Its affine-list construction costs at most 2^{3a/2} entries per occurrence, followed by chunking by Q. Include the triangular consistency equations in every final selected system. The [arbitrary affine weight counter](arbitrary-affine-weight-count.md) permits arbitrary dependencies among all these forms. This gives the stated clock. It works even if the constructor's output depends jointly on all the basket counts. There is no separate enumeration of intermediate gate transcripts in this reduction.

For example take log-sized or constant arity as allowed by the displayed bound. More explicitly, for fixed arity, p=O(q log q), b=O(1), and r≤q^{0.49}, we have h=O(log q), A=Θ(√q), and the time is at most 2^{q−Ω(√q/log⁷q)} for large q. The interface can include successive parities of many local products, each reused at arbitrarily many later gates within the polynomial description limit. E.g., at each of r stages sum distinct pair-products of primary affine forms gated by the preceding stage bit, and use the new aggregate at the next stage. Only the r aggregate rows (or fewer) enter the rank calculation. Taking a constant number of products in each stage and Θ(q) final uses gives a concrete circuit with this depth and near-linear total gate count.

A supplied decomposition is essential to this clock. Directly exposing one independent prior gate per consumer can give r=Θ(q), even for q disjoint ANDs followed by gates reading them separately. The parameter is syntactic, and equivalent gate presentations can have different ranks. The result neither bounds the minimum rank over all presentations nor provides a conversion for arbitrary near-linear Boolean circuits.
