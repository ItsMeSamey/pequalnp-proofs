# The padding length criterion for rejection certificates

Let g(N) be any integer between zero and N. At length N allow at most 2^(N−g(N)) NO inputs lacking accepted rejection certificates. Use the padded fixed complete language of heads 1^m0 x followed by arbitrary tail, where |x|=m, and malformed inputs default to NO. The head x encodes a fixed NP-complete universal unary-clock bounded acceptance problem.

The following condition governs what counting equivalent paddings can yield.

    There exists an integer d≥1 such that for every sufficiently large s
    there is N≤s^d with g(N)≥s.

Under this condition a fixed sound polynomial checker with polynomial-size proofs for the covered NO inputs implies NP=coNP. For any head x take s=2m+3, guess length N up to s^d and a tail and proof. At a guaranteed good N there are 2^(N−2m−1) copies of this head and at most 2^(N−s) exceptions globally, so at least three quarters of these copies have rejection proofs if x is a NO head. Since g(N)≤N, the good N is large enough for the full head. On YES heads soundness precludes accepting any guess. Finite exceptional source lengths can be decided directly.

If a polynomial-time generator also finds valid proofs on the covered inputs, choose such N at random, without testing g, and then sample a tail uniformly. For example draw ceil(log₂(s^d+1)) fair bits as an integer and discard lengths outside [2m+1,s^d]. The probability per trial is at least a constant divided by s^d on NO heads and zero on YES heads. Polynomial repetition gives the complement of the complete language in RP, hence coNP⊆RP⊆NP. Taking complements yields NP=coNP; now NP=RP=coRP=ZPP. Both implications relativize. The degree d is an existential constant in the constructed machine, just as in other polynomial-time inclusions.

Conversely, if the condition fails, there is an oracle O relative to which the same padded NP^O-complete language has a deterministic polynomial-time rejection generator and sound checker meeting the stated count at *every* length, whereas NP^O differs from coNP^O and is not contained in BPP^O. The oracle can depend on g. No algorithm for g is required. For computable g it may be chosen recursive.

Reserve addresses 0z for free data A(z). Consider N-bit canonical bodies 1^m0 x r in which |x|=m and r is all zeros. For such a body set the status oracle bit at address 10 followed by the body to one exactly if m≤g(N). At address 11 followed by the same body put the truth value of x as an instance of the universal bounded NP^O language when active; return zero when inactive. All other addresses are zero aside from the free data. The job includes machine, input and a unary clock bounded by m, so simulated oracle queries have length at most m, strictly less than N+2. Induction on address length defines the oracle uniquely given A,g. In particular, true/false acceleration answers for jobs of length m only depend on free data at direct-address length at most m.

On an arbitrary padded instance the generator rejects malformed input with a verified flag. For a well-formed head it rewrites the tail to zeros, queries status, and if active looks up the job truth via the second address. It emits a flag only for false jobs. The checker repeats these oracle calls. Both use a fixed polynomial clock including writing the N+2 query bits. Every failed NO input has m>g(N), so its first g(N) bits are ones. Counting this single necessary prefix gives at most 2^(N−g(N)) failures. There is no added factor depending on head length. NP^O-completeness persists since arbitrary tails, including empty, are allowed.

For the separation use L={1^n : some string z of length n has A(z)=1}. This language is in NP^O. At the stage for a clocked machine with polynomial bound p, take fresh arbitrarily large n with g(N)<n for every N≤p(n). Such n exist by failure of the stated condition, absorbing clock coefficients by increasing d. Choose n past all earlier frozen free lengths, also ensuring p(n)/2^n<1/6. All acceleration queries issued in p(n) steps then have either inactive status or underlying job length <n, so their answers are independent of free n-bit data. Simulate on a provisional all-zero extension of the frozen data and freeze all fresh bits through p(n)+n after each stage.

For a nondeterministic complement decider, retain the zero slice if no path accepts. If a path accepts, set one n-bit witness at a free address that path did not query. The path still accepts though the input now lies in L. For a randomized decider of L, retain zero if its acceptance probability is at least 1/2. Otherwise some witness is directly queried with probability at most p(n)/2^n; set it positive. Fewer than one sixth of computation histories change, so acceptance on this positive input stays below 2/3. Interleaving stages handles all machines of both types. All stage decisions are effective if g is computable because only finitely many finite branches and strictly decreasing-length dependencies are explored.

This is a padding implication in standard classes and an oracle counterexample to its unrestricted converse extension when the length condition fails. It gives no unrelativized separation. For monotone regularly growing deficits N^ε is enough. A particular deficit 2^sqrt(log N) fails the condition, as does any N^o(1); sporadic large deficits require the displayed quantifiers.
