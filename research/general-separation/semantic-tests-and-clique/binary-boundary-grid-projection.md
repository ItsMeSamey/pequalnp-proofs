# Fixed binary grid with indeterminates on one outer boundary

Theorem 1.1 of [Paths, trees and grids separate Valiant's hierarchy](https://github.com/openai/math/blob/3344da59991ed94f9ba711217b29c1d760badfa6/preprints/Paths-trees-and-grids-separate-Valiants-hierarchy-November-24-2026/paper.pdf) states a circuit lower bound n^Ω((log n)^(1/12)) for the formal n-square state sum Z with n states per edge over every field, including degree-component border complexity. The projection here needs only this stated theorem.

Use one persistent binary vertical register column for each bit of every source edge label, ceil(log₂ n) bits per label (encoding labels 0 through n−1). A top row guesses the registers with all horizontal edges zero; a bottom row discards them with all horizontal edges zero. Each intermediate row copies register bits north to south. Scan columns with a horizontal flag starting at one. On a specified subset of columns AND it with the test of the column bit against a specified constant; elsewhere pass it unchanged. The 0/1 tensor at the vertex enforces exactly this transition. At the first column hardwire the initial flag instead of receiving it. Extra columns copy the flag and have vertical bits pinned zero. In the outer rightmost column place a sentinel with vertical bits zero: weight one for incoming zero, specified weight for incoming one. Each tensor has at most 16 entries.

Include one row for every edge and every illegal label n,...,2^ceil(log₂ n)−1, testing equality to this label with weight zero. For each vertex and legal tuple α include one row testing all incident labels for that tuple, assigning weight X_(v,α). Exactly one row per vertex matches on a legal global labeling. A fixed register word has a uniquely determined horizontal extension; illegal words contribute zero. Consequently the formal state sum is exactly Z in every field. Each indeterminate occurs once, in one right-boundary entry. There are O(n²log n) columns and O(n^6) rows. Any M≥C n^6 accommodates this network: add neutral rows that propagate registers and determine flags uniquely, and extra zero-register columns before the sentinel. Tables are uniformly constructed in poly(M) time; the only fixed scalars are zero and one.

Set n=floor((M/C)^(1/6)). The reported source lower implies exp(Ω((log M)^(13/12))) exact arithmetic circuit size at every sufficiently large M for this fixed-interior binary-grid family. To transfer a lower bound to the degree-component border model for the unspecialized binary grid, first extract the degree-M² part from a putative approximating circuit using truncated homogeneous gate vectors through degree M², with poly(M) cost per gate. Only then substitute constants and indeterminates as above. This linear coefficient map commutes with specialization/limits of the bounded-degree coefficient vectors. The limit is exactly the homogeneous source Z of degree n². The quantitative exponent absorbs the polynomial overhead. The boundary-specialized family itself is Z of degree n².

The associated ordinary NP language asks whether a supplied Boolean boundary assignment leaves a legal labeling. A parsimonious 3SAT reduction places variables along rows and clauses along columns of a source grid of side n=max(number of variables,number of clauses,2). Horizontal edges carry the same guessed variable bit along each row. At each site the north running clause flag (false at the top) is ORed with whether this row's variable satisfies an occurrence in this clause. Enforce true at the bottom in a real clause column. Unused columns have deterministic flags with no bottom test, and unused row variables are fixed zero. At the left edge read the row bit from the east, at the right from the west, copying at interior vertices. Disallow unused states ≥2. Every satisfying assignment has exactly one surviving labeling, even with repetitions or tautological clauses. Set the binary-grid boundary weights to these 0/1 source entries. The boundary list costs O(n^6) bits; explicitly listing every physical tensor also costs polynomial size. Thus this fixed-interior boundary support is NP-complete and natural-number evaluation is #P-hard under parsimonious reductions. No novelty claim for general tensor contraction hardness. Evaluation in characteristic two gives parity, which can vanish on YES. No Boolean time lower bound follows from the arithmetic lower.
