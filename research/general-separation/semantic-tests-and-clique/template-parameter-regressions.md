# Residual template dimension on the original anchor graphs

Even after optimizing over every raw diagonal b, the parameter in the [best-template algorithm](common-kernel-best-template.md) is at least 2t on the earlier [scalar-only, highly connected YES and NO anchor graphs](high-connectivity-anchor-obstruction.md) for t≥2. This bound uses the original three pins and the original indexed graph.

Recall from the [private-span calculation](private-span-regressions.md) that C_i=0110 on the four nonmarked vertices of each attached pentagon, ordered along their path and zero elsewhere, lies in the span R of private vectors. A C_i is supported on these four sites and equals 1111 there. Indeed each of the four vertices sees one of its selected neighbors, the unselected mark sees zero, the shore contributions to adjacent external vertices cancel, and the YES graph's extra site sees either both selected coordinates or neither. For every b the two endpoints of this path therefore retain output one in (A+diag b)C_i. These 2t nonzero images have disjoint supports across both shores, so rank((A+diag b)|_R)≥2t for every b. Since the kernel of this restricted map is exactly U_b, minimizing its rank gives the asserted bound. It does not establish hardness of deciding these graphs.

On the odd independent-twin blowups in the best-template proof the parameter takes the small values explicitly. For odd t≥3, project any raw private vector to its four clone-class parities. A class of parity zero cannot contain all t sites, so its zero clone enforces the original unselected row. Pin rows are unchanged. Thus the projection is an original private vector. Conversely an original private vector lifts by selecting the entire corresponding classes. The even-within-class kernel has dimension 4(t−1) and lies in U₀. Hence on the blown-up YES graph r=4(t−1) and k*=0. On the blown-up NO graph r=4(t−1)+1. A template supporting every within-class pair must be zero on all clone coordinates, since each such pair has adjacency zero. But the lift of the original private mask 104 has nonzero adjacency on the classes corresponding to 40 and fails that template. Therefore k*=1. These are separate bounded-parameter examples with growing r.
