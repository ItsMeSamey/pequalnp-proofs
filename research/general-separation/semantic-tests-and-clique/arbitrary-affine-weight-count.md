# Counting with arbitrarily dependent affine Hamming-weight summaries

For q primary bits, write L=log₂(q+2). Let 1≤h≤q^{1/3}/L³. The input specifies h lists of at most q affine forms each, with arbitrary repetitions and dependencies. For input x, vector w records the number of true forms in each list. A supplied uniform constructor selects a GF(2) equation system S_w on x in fixed polynomial time and explicit size. Each equation is an XOR of products of affine forms. The target counts the x satisfying S_w. With A=min(√q,q/h²), a deterministic algorithm gives the exact count in

    2^{q−Ω(A/(h L⁶))} time.

The hidden constants can depend on the fixed polynomial time and size bounds.

**Choosing coordinates to condition.** In the dual vector space over GF(2) maintain a subspace U whose values will be fixed. Start with U=0. In the quotient by U delete zero vectors from all lists, retaining the original row indices to recover their slice-dependent constants. Treat every occurrence of a nonzero vector as a distinct matroid element. Test whether each list partitions into K=4h independent sets. Edmonds's matroid partition theorem gives a polynomial algorithm and the criterion that every subset T has |T|≤K rank(T). Here binary elimination provides the independence oracle. On failure greedily delete occurrences as long as the remaining set still fails. In an inclusion-minimal failing set T the violated inequality holds on T itself. Adjoin to U the span of its original rows, increasing dimension by r=rank(T mod U)>0. At least |T|>Kr occurrences are removed next iteration. Across all lists only hq occurrences can be removed. Consequently the final dimension d is at most hq/K=q/4. The partition and U use only the vectors and are found before assigning any conditioned coordinate. [Edmonds, Minimum Partition of a Matroid into Independent Subsets, Theorem 1](https://doi.org/10.6028/jres.069B.004)

**Counting the slices.** Complete a basis of U to a basis of the dual space. Enumerate its 2^d assignments, each leaving n=q−d≥3q/4 free bits. Zero quotient rows contribute a known offset to each appropriate weight. Split each surviving independent set into blocks of at most t=ceil(hA), retaining a final short block when needed. There are at most hq/t+hK=O(q/A) blocks since A≤q/h². Each block's remaining affine forms have jointly uniform values on this slice. The proof only needs these individual marginals.

Choose a power of two M of order A/L³. For a block of length m<M count its weight exactly with the residue modulo M. For m≥M use the representative in the M consecutive integers starting at floor(m/2)−M/2. If the representative is wrong, the weight differs from m/2 by at least M/2−1. The j-th bit of a weight is the elementary symmetric polynomial of order 2^j in the affine forms over GF(2). Supply those products explicitly for j<log₂ M and create unique auxiliary wires for decoding and binary sums, as in the independent-block proof. Include each list's known offset. There are b=O((q/A)L) auxiliary bits. The explicit description size u and number s of product gates satisfy log₂(u+2),log₂(s+2)=O(M L+L)=O(A/L²). At the largest h, A is still at least order q^{1/3}.

Enumerate all (q+1)^h decoded weight vectors, pin the binary sums and append S_w after substituting the affine slice parametrization for x. Substitution preserves affine factors. The deterministic Lokshtanov–Paturi–Tamaki–Williams–Yu counter saves Ω(qL²/A) from n+b in the exponent, with extra factor poly(u). Since A≤√q, this saving absorbs log u, b, and O(hL) for all calls. Unique extension and the unique decoded vector mean their sum is the exact surrogate count. [LPTWY, Theorem 1.4](https://theory.stanford.edu/~yuhch123/files/polyEq.pdf) · [Central interval construction](central-residue-flat-count.md)

For each block with m≥M, enumerate exceptional m-bit patterns by weight, extend its forms to affine coordinates on the slice, then enumerate the remaining coordinates. The binomial tail bounds total visits over all blocks by poly(q)·2^{n−Ω(M²/t)}. Short blocks require no correction. Process each point only for its first exceptional block, adding the original acceptance bit minus the surrogate bit. Evaluate both directly in polynomial time. Since M²/t=Ω(A/(hL⁶)), the correction gives the claimed slice saving. Throughout the range A/h is at least order L⁹ for large q, so polynomial overhead is absorbed. Summing all 2^d disjoint slices replaces n by q in the final exponent. This yields the exact count even if the only witness lies in a region where the surrogate is wrong.

The structure is an explicit conditional equation system driven by integer Hamming weights of affine forms. Its satisfying inputs can have any density. A uniform decision-preserving or counting-preserving conversion of arbitrary q log q gate DAGs to this structure within the required clock remains open.
