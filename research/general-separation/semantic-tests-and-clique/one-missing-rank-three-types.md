# Finding an exterior escape by the type of its port quadratic form

Consider a linked [three-pin exterior](linked-scc-port-reduction.md). Suppose the inner table supplies witnesses for 35 compatible states. If the initial exterior state w₀ is covered, join immediately. Otherwise the other 35 compatible states are covered. It remains to ask whether any legal real selection reaches w≠w₀. A proved negative decides the whole instance if the missing inner state is known impossible. With an incomplete certificate it proves only that every valid join must use the one unverified entry.

It suffices to examine single strongly connected components B in the linked chart, starting from zero syndrome in each. If a legal selection changes the final syndrome, its first component with nonzero syndrome change receives zero accumulated change. Set all other clamp coordinates to zero; the previous components then have no selected clamp coordinates and the later ones impose no equations. The retained component receives precisely its old input and still gives a nonzero change. Conversely any such single component alone realizes an exterior escape. No assumption about local orientations being nonsingular is needed.

On B write M=H[B], x for its chosen real clamp coordinates, d=C_B x, and a for the restricted alternate-coordinate offset. Let V=im C_B and define Q(d)=q(w₀+d), with q(w₀)=0. Its polar on V is denoted by J. A legal selection has Q(d)=0, and, writing c_i for the port columns,

    M_ij+M_ji=J(c_i,c_j),      a_i+M_ii=Q(c_i).

Test the following cases deterministically, returning actual selections. The classification is complete when dim V≤3. The cases in which it gives an algorithm also work as stated in higher dimension.

* If the polar on V is zero, M is symmetric. For each coordinate of d ask if that coordinate can equal one in the physical equations x_i(a+Mx)_i=0. The [symmetric one-readout algorithm](symmetric-single-row-p3.md) supplies a witness if any exists, including arbitrary mixed degree prescriptions. Dimension at most two is already polynomial by the more general all-port table procedure.
* Suppose the polar has rank two. Choose linear forms f,g on V with J=f⊗g+g⊗f. Put p_i=f(c_i), r_i=g(c_i). To test f(d)=1 use the symmetric matrix M+r pᵀ: on pᵀx=1 the required alternate offset becomes a+r. This is one symmetric mixed-parity readout, solved constructively. Similarly test g(d)=1 using M+p rᵀ and offset a+p. Thus one can always find or exclude all escapes outside the radical in polynomial time. If Q has no nonzero zero inside the radical, these two tests suffice. This includes dim V=3 when Q is one on the nonzero radical generator.
* Suppose Q=fg as a function on V, where f,g are independent linear forms. Then all feasible d satisfy f(d)=0 or g(d)=0. In the first branch M+r pᵀ is symmetric and the added matrix is zero on selections with pᵀx=0. Its diagonal is a because a_i+M_ii=p_i r_i. Thus the physical local equations ask for an all-even selection in the corresponding zero-diagonal simple graph. For each output coordinate h, use the [two-readout polynomial solver](two-readout-even-p3.md) with pᵀx=0 and h(d)=1. In the second branch use M+p rᵀ with rᵀx=0. A witness in either branch is physically valid and has nonzero shift.

For dim V=3 the alternating polar has rank zero or two. In the latter case its radical is a line with unique nonzero element v. If Q(v)=0, Q descends to a nondegenerate binary quadratic form on the plane V/⟨v⟩. The split plane has three zeros including zero, so its two nonzero zero vectors form a basis and in dual coordinates Q=fg. The preceding algorithm applies. The anisotropic plane has only the zero vector as a zero. Upstairs the only nonzero admissible escape is then v, and the [shear to three all-even readouts](linked-scc-port-reduction.md) on target v is faithful. These alternatives exhaust the forms, as inspection in any symplectic plane basis gives Q(X,Y)=XY+αX+βY. The three-dimensional types and witness reductions can all be recognized by enumeration of only eight vectors.

In this last type a polynomial transition would already solve the general literal three-pin induced-even problem. The [one-missing reduction](one-missing-reservoir-universality.md) gives Q(X,Y,Z)=X+Y+XY and uses only three port-active sites for a literal input. Either the instance is directly decided by its rank-two components, or deleting neutral components leaves one rank-three component in precisely the anisotropic-quotient case. This is a reduction from the three-pin problem, whose general complexity is unresolved in this investigation; it asserts no NP-hardness.

The polynomial cases concern finding any nonbaseline escape. They do not by themselves compute the entire port table or impose an additional independent target. All formulas use a single physical linked chart and the original six port coordinates.
