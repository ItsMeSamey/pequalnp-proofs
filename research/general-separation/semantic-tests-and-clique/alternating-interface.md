# Branching programs with bounded entries into opposite connectives

The [signed joint-count proof](signed-joint-clauses-attributed.md) also permits alternating acyclic query programs with unrestricted alternation depth under a bound on the number of nodes at which the connective changes. Each nonterminal tests one raw input bit. It is labeled either existential or universal. Given the bit, use its enabled successor set and take its OR or AND, respectively. Empty existential sets have value zero and empty universal sets have value one. Terminals have specified Boolean values.

Fix B>0. Allow as a bottom atom a program with at most MK(M) query nodes, of which at most B log₂(M+2)K(M) distinct nonterminal nodes are the heads of an arc from a nonterminal of the opposite connective. Count heads using the union of both raw-bit outcomes. The other atom type remains an arbitrary binary Boolean formula with at most MK(M) leaves. Then for every fixed d some language in NP has infinitely many lengths M at which it lacks an exact real sum of at most M^d such mixed atoms. One can take K(M) asymptotic to a sufficiently small positive constant times sqrt(loglog M)/logloglog M, with a computably rounded, positive finite extension. The constant may depend on fixed B. The result uses the [October arbitrary-density counting theorem](https://github.com/openai/math/blob/92b516ef8e/preprints/The-Exponential-Time-Hypothesis-is-False-October-25-2026/build/main_full_version.tex#L68-L82).

Follow the same universal-evaluator slot projection and branch on the union of the heavy live bits for at most four factors. Retain nodes with unfixed queries, all heads described above and each start. For each retained u and each allowed bit value, stop each traversal when it first reaches a different retained node or terminal. Every intervening node has a fixed query and the same connective as u, since any type-changing arc must end at a retained head. Flatten the homogeneous computation by associativity and idempotence. A reached absorbing terminal makes the row constant. Neutral terminal values may be discarded. An empty fixed successor set is the identity of the homogeneous connective. The endpoint sets and absorbing flags can be computed by graph search or reverse dynamic programming in polynomial time in the original descriptions. No enumeration of paths is needed.

The retained node values are uniquely determined by reverse topological induction. An existential endpoint OR uses at most one wide clause and short implications; a universal endpoint AND uses their dual. Guard each by the source's queried bit when live, or use the single known row when fixed. Across the product, the total number of retained nodes is

    O(nL + B log(M+2)K(M) + 1),

where L=ceil(CK(M)) is the usual raw-query occurrence threshold. One switch per wide clause and the common parity chain therefore give two width-three counts on O(n+nL+B log(M+2)K(M)) total variables, independently of the number of paths. Explicit arc lists cost polynomial time in M. As log M=O(εn+log n), the added interface cost preserves the small-constant endpoint counting clock for fixed B. Structural head counting on a guessed description is polynomial time. Evaluating the original atom by ordinary bounded-fanin circuits costs at most quadratic size in its query-node budget. All other steps and quantifiers are the hierarchy proof from the [ambiguous-program note](nondeterministic-program-sum.md).

## A single changing tail permits arbitrary functions after projection

The orientation of the interface hypothesis matters. For any Boolean function f on t logical inputs, construct a DNF with one term per accepting assignment. Make its root existential and each term universal; the root and term queries use identical successor sets for both outcomes. Universal deterministic query programs computing the positive and negative parities of t raw blocks can be shared between all terms. A deterministic node with one enabled successor on each outcome is valid with either connective. Hence the only connective-changing arcs run from the single root to the terms. All type-changing arcs have a one-vertex cover. The raw size is O(tR+2^t+1) query nodes, with polynomially many arcs in the raw size. For every choice of one live slot per block the restricted function is exactly f.

For concreteness, take n logical blocks, t=floor(ηn), R=2^t, M=nR, with 0<η<1 fixed. The construction fits MK(M) eventually and ranges over all 2^{2^t} functions of its first t live inputs. For any fixed width r and any fixed polynomial v(n), a CNF on at most v(n) total named variables has only 2^{poly(n)} descriptions after repeated clauses are removed and auxiliaries renamed. This also bounds its possible pointwise extension-count functions on the live inputs. Given any S such functions, their real span contains at most 2^S Boolean truth tables: the rank is at most S, so at most S input coordinates determine every vector in the span. Thus signed real sums of S=2^{o(n)} such projected counts can express at most 2^{S poly(n)} different Boolean tables, smaller than 2^{2^t} eventually. This falsifies the proposed low-complexity pointwise compilation under a small-tail or undirected-vertex-cover substitute. It leaves open direct algorithms for total counts and gives no uniform unrestricted circuit lower bound. [Finite alternating-contraction checker](alternation_interface_check.py)
