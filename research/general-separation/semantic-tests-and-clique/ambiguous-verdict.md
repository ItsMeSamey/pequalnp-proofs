# GO for the fixed-linear-density ambiguous branching-program extension

For fixed d>=1 and fixed c>0, some NP language at infinitely many N has no exact real SUM of N^d or fewer acyclic existential Boolean branching programs, each with at most cN query nodes. A query node tests one coordinate, with an arbitrary set of allowed successors for each bit value, and acceptance means that some allowed path reaches a 1 terminal. Adjacency tables are polynomial in the query-node budget after duplicate edges and terminals are merged. Free input-independent nondeterministic routing in a finite acyclic graph can first be eliminated by first-query closure; the proof can guess the resulting tables. Input-dependent operations each count as query nodes.

Classify labels by their raw query-node multiplicities before any specialization. With threshold L a fixed sufficiently large multiple of c, the simultaneous parity-slot and heavy-assignment argument leaves at most q<=4nL live query nodes across each tested product, after branching on at most 4delta n logical bits. Compute first-hit endpoint sets for the fixed-query subgraphs in reverse topological order: each live query or terminal yields its singleton; each fixed query yields the union of the endpoint sets for its selected successors. Replace each live node's two successor sets by the corresponding unions and use the endpoint set of the start as the new start disjunction. Duplicate paths need no bookkeeping because acceptance is existential. A polynomial raw-description scan suffices even though densification can produce Theta(q²) edges.

For each live node u introduce one bit a_u. For each select bit b with predicate p_b and each compressed successor v, impose (not p_b OR not a_v OR a_u). Also impose (not p_b OR not a_u OR disjunction_{v in targets(u,b)} a_v). Terminals are constants. Empty successor sets force zero when selected. One extra disjunction per start requires an accepting endpoint. By reverse induction the a-bits are forced to the Boolean acceptance status of every live node, whether reachable from the start or not. Hence an x satisfying the product has one extension regardless of accepting-path multiplicity. There are v<=a n variables, O(q²+1) short clauses and at most t<=2q+4<=b n potentially long clauses for constants a,b depending on c and the projection threshold.

Normalize clauses by removing duplicate literals and tautologies before branching. For a clause of width >k, choose k literals with distinct currently unassigned variables. One branch replaces the clause by their disjunction, the other sets all k literals false and restricts the whole CNF. This partitions its satisfying assignments even when chosen literals involve auxiliaries. Do not multiply by a factor for the k fixed variables; retain the original remaining declared variables, including disappearing ones. The first branch removes at least one long clause; the second eliminates k variables, with no increase in the number of long clauses. The recurrence in the budgets t and r=floor(v/k) is bounded by binom(t+r,r): on t=0 the algorithm stops, and on r=0 no clause over distinct unassigned variables can have width >k. For v<=an,t<=bn the base-two exponent is at most (a/k)log2(e(1+bk/a)) n plus O(log n). This coefficient tends to zero as the fixed integer k increases. No enumeration of the dense width-three clauses is needed beyond polynomial-time scanning.

The [October 25 theorem, lines 70–81](https://raw.githubusercontent.com/openai/math/92b516ef8e/preprints/The-Exponential-Time-Hypothesis-is-False-October-25-2026/build/main_full_version.tex) gives deterministic time (v+m)^O_k(1) times 2^O_k(v loglog v/sqrt(log v)) without a density bound. Here m=O(n²), v<=an, k fixed, so every leaf costs 2^o(n). For v<20 use brute force; when v merely tends to infinity slowly, the same o(n) upper bound follows by taking the maximum over v<=an. The fixed-density speedup is unnecessary for this step.

Choose delta small, then the heavy threshold L, then the constant width k giving e.g. branch overhead at most n/8 in the exponent. Choose epsilon last to absorb the fixed polynomial-in-ambient-M terms and the simultaneous slot union bound. Time is 2^(4delta n+n/8+O_{d,c,k}(epsilon n)+o(n)), enough for Murray–Williams. As in the deterministic proof, enforce the Boolean quartic and gate checks, use a separate SAT-witness branch, and compile each original existential DAG backwards to polynomial-size Boolean circuits by OR gates over all selected successors. This preserves the common simulated circuit-size exponent for fixed d,c. This audit is about arbitrary ambiguity at fixed density. At increasing density a and b can grow with n; the displayed argument with one fixed k no longer provides the necessary small branching overhead. No growing-density unambiguous theorem is assumed here.

Finite cross-check: ambiguous_check.py tested 810 restrictions of 30 random branching DAGs against the direct semantics, on 1,920 compatible inputs, enumerating all auxiliary assignments to check uniqueness. These checks supplement the proof by induction.
