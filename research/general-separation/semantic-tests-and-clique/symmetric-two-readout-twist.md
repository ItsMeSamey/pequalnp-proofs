# Two affine readouts for symmetric induced-degree constraints

On a loopless undirected graph with binary adjacency A, seek x with xᵢ=1 implying (Ax)ᵢ=cᵢ and Lx=t for two binary rows L. Absorb constant readout terms into t. Symmetry gives the componentwise handshake constraints Σcᵢxᵢ=0. The [one-readout algorithm](symmetric-single-row-p3.md) constructs a feasible support with any one attainable linear bit.

**All-even prescriptions.** If c=0 the two-readout problem is deterministic polynomial time, on arbitrary dense graphs. For t=0 take x=0. Check the ordinary linear consistency of the readouts and use the one-readout solver when rank L≤1. Otherwise change basis on the two rows so that t becomes (1,1); call the resulting row vectors a,b, written as columns in outer products. Define

    A′=A+abᵀ+baᵀ,     c′=a+b.

The diagonal update vanishes, so A′ defines another simple undirected graph. On assignments satisfying both target bits, A′x=Ax+a+b, making the updated local checks equivalent to the old ones. Conversely every support feasible for (A′,c′) satisfies (a+b)·x=0 by handshake. Hence the single readout a·x=1 on the updated graph automatically enforces both original target bits. Run the constructive one-readout algorithm there. The returned support is already a witness on the original graph. In particular the single-edge counterexample to testing membership in the two-row linear image is decided correctly.

**Component combination.** Compute each component's attainable image, a subset of four labels, with one actual witness per label. A four-state XOR dynamic program then produces witnesses on the whole graph. A component with local readout rank ≤1 needs just the old algorithm for arbitrary c. If its restriction of c is nonzero and belongs to the row space of its local two readouts of rank two, handshake forces a nonzero linear equation on their two output bits. Reject targets off that line; on the line one independent readout determines the target and is handled by the one-row solver. A component with at most one vertex prescribed odd can never select that vertex, again by handshake, so delete it and invoke the all-even result. Thus a disjoint union of components satisfying any of these tests is polynomial-time solvable. Translate supports and leaf inputs as in the [P3 reduction](symmetric-single-row-p3.md), applying the test separately on each supplied exceptional-selector branch.

**Rank-parameter fallback.** On any remaining component let D be a supplied diagonal matrix and K=A+D of binary rank ρ. Set c′=c+diag(D), since Dx adds dᵢ at every selected index i. Enumerate the 2^ρ attainable vectors s in the column space of K. In that branch force xᵢ=0 whenever sᵢ differs from c′ᵢ, then solve the ordinary simultaneous linear system Kx=s, Lx=t with those pins. This is necessary and sufficient for this branch, and elimination produces the witness. The overall time is polynomial in the input times the sum of 2^{ρ} over fallback components, plus polynomial time for the other components. Taking D=0 is always available; no efficient minimization of diagonal-completion rank is assumed.

The twist specifically uses the all-even baseline. For general c the same update gives handshake (a+b)·x=c·x on the modified graph; a single readout does not then force the second one. For example, on two vertices take A=0, c=(1,0), and a,b the two coordinate units with target (1,1). The original target is impossible. On the modified edge with c′=c+a+b=(0,1), the singleton x=(1,0) is feasible and satisfies the first readout. The component and rank criteria make no claim of a polynomial algorithm for arbitrary prescriptions and arbitrary two rows.
