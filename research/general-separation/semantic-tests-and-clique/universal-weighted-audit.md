# Two independent verdicts

**Single-language universal simulation, GO for 6ab351481e1948c3c6d02e7aa224a3c94728f64074e2070c9aa68fc53a787d79.** For each chosen eventually diverging nondecreasing g and constructible T(N)=N^g(N), a universal machine can validate a self-delimiting header and run its named nondeterministic machine for T(N) simulated steps, with an exponent in the interpreter's polynomial overhead independent of the header. Hence U_g lies in NTIME(N^{O(g(N))}). Fixing the header of any one NP machine of polynomial clock gives length n+h and eventually covers its entire clock. Hardwire that header for the NP language resisting exponent d+1. Raw sparsity at most (n+h)^d is eventually below n^{d+1}. The boundary profile tends to infinity and has ratio tending to one under the fixed shift. Hence a strict fixed constant-factor slack c'<c absorbs rounding, plus any extra root or degenerate literal from header contraction. Choosing the hard machine after d does not change U_g; the verifier needs no hard-machine list. This gives infinitely many hard lengths for each d. If U_g were in NP with exponent A, fixed headers and finite exceptions would force all NP into NTIME(n^{A+2}), contradicting the nondeterministic time hierarchy for polynomial clocks. This argument is specific to eventual constant-header universality for every NP language. A different single hard language in NP remains open. [Williams, Theorem 1.5(2)](https://arxiv.org/pdf/1802.09121) gives a comparable slow-clock SUM conclusion for related classes; its stated proof invokes Theorem 2.6.

**Semantic weighted cyclic programs, GO for fc244f1931a7528cc85002d2f5776da367b164a5efcb49f3d704a8af58372ff0.** For one atom, index, and assignment of its own heavy bits, each conditional segment has a minimum over all nonempty enabled paths to the first retained endpoint, with fixed nonretained interior. Minimum finite cost is attained since costs are nonnegative integers. Search initialized from eligible outgoing edges handles self-returns without introducing a zero-length transition. Projecting a true cheap accepting path gives a path of at most the same cost; conversely each residual segment of cost at most h lifts at that cost. Truncation to h+1 preserves both statements through the finite range. Any enabled residual zero-cost cycle would lift to an enabled nonempty raw closed walk of total cost zero. Thus the promised positive-cycle condition guarantees every finite tight-successor walk terminates; the separate global cheap-path promise ensures all accepting-reachable states receive finite ranks. Unreachable states receive infinity as before. On syntax-valid but promise-invalid guesses, rank-table counts still give consistent nonnegative integer functions: preserve each privately constructed segment table under all other factors' heavy pins, and allocate fresh rank/switch variables per occurrence. A common parity chain computes the product sign. Only the genuine atoms need Boolean values for the coefficient rationalization and ordinary-circuit simulation. Per-node radix variables and per-edge tuple clauses give the same previously verified fixed-width clock at a+b/e<1/2. The graph example with many self-loops separates representation conditions, not Boolean functions.
