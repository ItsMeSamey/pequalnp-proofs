# Testing the near-linear gate SAT target by isolation

Fix q primary inputs, small-gate scale q log q, and target saving 2^{Ω(q/√log q)} over exhaustive search. Promise Unique-CircuitSAT must correctly distinguish zero from one satisfying assignment; on instances with two or more its decision bit is unconstrained. Assume its worst-case clock is time-limited on all circuits (or explicitly truncate). This promise already includes a hidden singleton added to the constant zero function. Classical randomized isolation relates SAT to unique witnesses. [Valiant and Vazirani](https://doi.org/10.1016/0304-3975(86)90135-0) · [Ta-Shma's small-palette bound](https://pages.cs.wisc.edu/~cs787-1/TaShma.pdf)

**Gate-budget preserving randomized reduction.** Take M a power of two between log₂ q and 2 log₂ q for large q. Choose independent integer weights w_i uniformly in [M]. For any nonempty family of witness supports, the probability that the minimum-weight support is unique is at least (1−1/M)^q. One proof maps each vector in [M−1]^q to an isolating vector in [M]^q: choose a minimum support S with a fixed tie rule and increase every weight outside S by one. No competing support lies strictly inside S, by positivity. Every other support now costs strictly more. One can recover S from the image as its unique minimum and hence recover the original weight vector. This is the elementary small-palette isolation argument.

For each integer j from 0 to qM ask the promised solver about
     
    F(x) AND [∑_i w_i x_i = j].

The added circuit needs O(q log(M+1)+log(qM+1)) binary gates, not q new primary inputs. Hardwire the weights: at most q·ceil(log₂(M+1)) original bit occurrences enter binary columns. Repeatedly replace three bits in a column by their sum bit in that column and carry bit in the next using a constant-size full adder. Each step reduces the total bit count by one. Reduce the final two O(log(qM+1))-bit rows by a ripple adder, then test equality to j. The maximum structural column can also be bounded by log(qM) since the sum of the original column weights is at most qM and full-adders preserve this maximum formal weight when ignoring correlations. The overhead is o(q log q). Each construction is uniform and polynomial per query.

If F is unsatisfiable every query is a no instance of the promise. If F is satisfiable and the weights isolate, the minimum layer is a yes instance. Accept if any layer accepts. Repeat O((1−1/M)^{-q}) times for success probability at least 2/3 on satisfiable inputs. The random and enumeration overhead is poly(q)·2^{O(q/log q)}. Consequently a deterministic promise solver on ≤B q log q gates in time poly(q)·2^{q−Ω(q/√log q)} gives a one-sided randomized general SAT solver at that same asymptotic saving for any fixed smaller gate coefficient. Its answers on off-promise layers cannot hurt soundness for empty F. If these queries are used to check UNSAT nondeterministically in the Williams verification, an unlucky random choice would wrongly accept a circuit that violates a clause. Thus the randomized reduction alone does not yield the E^NP gate lower bound from the deterministic target.

For each length there is a nonuniform list of at most poly(q)·2^{O(q/log q)} weight vectors isolating every nonempty satisfying set of circuits with ≤Bq log q gates. The count of described circuits is at most 2^{O_B(q log² q)}. A random list with O_B(q log² q) times the inverse isolation probability entries misses any such set with sufficiently small probability for the union bound. If lists with the required guarantee could instead be enumerated uniformly in aggregate time 2^{o(q/√log q)}poly(q), the reduction would be deterministic and the stated promise-solver clock would imply an Ω(t log t) infinitely-often lower bound for one E^NP language. The nonuniform lists cannot simply be supplied as advice to the unary hierarchy proof: one bit of unrestricted length-dependent advice already decides any unary language. [Exact witness transfer](october-next-gate-scale.md)

**An obstruction to fixed point and layer tests.** Fix any h preselected q-bit assignments and K arbitrary weight vectors in [M]^q. Let a=ceil(log₂(h+1)), with a≤q, and suppose 2^{q−a}>K(qM+1). Some a-bit prefix occurs in none of the h assignments. Start with the slice of that prefix. As long as any layer of any vector meets the current set at a single point, delete that point and record the vector and layer. Once emptied a layer stays empty. At most K(qM+1) deletions are possible, so a nonempty set remains. Every prescribed point misses it, and every prescribed weight layer contains either zero or at least two remaining assignments. Thus no scheme relying solely on the given point queries and a guaranteed unique layer for those vectors has the required certificate on this instance.

The residual has a small *ordinary circuit*, even though the tests were selected nonuniformly. It checks the prefix and rejects if any vector weight belongs to that vector's set of recorded levels. Each weight sum costs O(q log(M+1)+log(qM+1)) gates as above. Membership in an arbitrary subset of the O(qM) levels costs O(qM/log(qM+2)+1) gates by the elementary Shannon synthesis bound for log₂(qM+1) inputs (round up to an integer). Thus total size is O(q+K(q log(M+1)+qM/log(qM+2))). For M between log q and 2 log q and K≤c_B log q/log log q with c_B small enough, this fits Bq log q for any fixed B>0 at all large q. The slice condition still holds, for example, when h≤2^{q−γq/√log q} and γ>0 is fixed. This is an existential circuit tailored to a specified family; a white-box solver can exploit its prefix and other structure. It limits fixed lists of the indicated size rather than all uniform derandomizations.

If one asks for guaranteed singleton layers for *every* nonempty subset of the cube, the deletion argument starting from the entire cube gives K(qM+1)≥2^q. This unrestricted set-family obstruction does not apply to the much smaller collection of bounded-gate circuits used for nonuniform isolation above.
