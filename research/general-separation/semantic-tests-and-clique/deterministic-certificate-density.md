# When exception counts force deterministic generation

For the padded bounded-job language of irregular-certificate-density.md, allow an arbitrary integer bound f(N) between zero and 2^N on the number of NO inputs at length N where a deterministic polynomial-time generator fails to return a valid rejection certificate. Its polynomial-time checker must be sound. The deterministic padding criterion is

    There is an integer d such that, for every sufficiently large s,
    some N between 2s and s^d satisfies f(N)≤s^d.

Under this condition the generator implies P=NP. For a head 1^m0 x put s=2m+2. For every N in the given range try the first s^d+1 distinct tails of length N−2m−1 in lexicographic order. These exist for all sufficiently large s. On a NO head, at the promised length at least one attempt works, by counting. On a YES head, soundness prevents all attempts. The generator, checker, number of trials and trial lengths have polynomial bounds in m. No algorithm for f is used, and finite small lengths can be hardwired.

If the condition fails, a single oracle O (depending on f) permits the same exception guarantee for its padded NP^O-complete language, while P^O differs from NP^O. Reserve 0z for free bits A(z). Every well-formed N-bit body b=1^m0 x r now uses its actual tail r. Mark bodies active by default, with some bodies permanently disabled as specified below. The address 10b reports activity and 11b reports the truth of job x in the unary-clock bounded acceptance language U^O if active, zero otherwise. Invalid addresses are fixed zero. Jobs query strings of length at most m<N+2, defining answers by induction on address length once data and activity bits are fixed. The deterministic generator certifies malformed inputs and active false jobs; each possibly missed NO contributes one disabled body, with no multiplicity from other tails. The checker recomputes the answer using the identical body. A verifier for the padded language itself simply runs the bounded nondeterministic job on x, so the language is NP^O-complete by empty-tail reductions.

Consider L={1^n : some n-bit z has A(z)=1}, which is in NP^O. For a deterministic machine with clock p(n), choose d such that n^d≥p(n)+n+3 eventually. Failure of the criterion gives arbitrarily large n for which every N in [2n,n^d] has f(N)>n^d. Choose n beyond prior frozen lengths and with 2^n>p(n). Simulate the machine on 1^n while keeping fresh free bits provisionally zero. For each directly queried activity or truth address of a job with m≥n, disable its body and answer zero. Valid such bodies have N≥2n+1. Smaller jobs can be answered exactly: all their internal queries have length at most m<n, and all nested dependencies are even shorter. None can observe newly disabled bodies or n-bit free data. Disabled bodies from previous stages remain fixed.

If the machine rejects, set one n-bit witness at a directly unqueried free address. Otherwise retain the zero slice. Its run is unchanged in both cases and has the wrong answer. Freeze all free entries and all activity bits up through p(n)+n+3 in length, using defaults for other values. On each stage at most p(n) bodies in total have been disabled. At each affected N this is at most f(N), and the affected length intervals of distinct stages are disjoint. The resulting O has the claimed properties. If f is computable, the finite stage simulations and gap search make O recursive.

For example f(N)=min(2^N,N^ceil(loglog(N+4))) fails the deterministic criterion. Its deficit N−log₂ f(N) satisfies the positive randomized padding criterion in irregular-certificate-density.md. This produces one oracle where NP^O=ZPP^O yet P^O differs from NP^O, even while a deterministic generator fails on only a quasipolynomial number of inputs per length. The example concerns relativized classes. It sharpens the distinction between a random successful tail and a polynomial list of guaranteed successful tails.
