# An alternative of no greater cost for a supplied satisfying assignment

The fixed NP language contains an explicit positive 2CNF, a supplied satisfying assignment C, and positive binary weights, when a distinct satisfying assignment of at most its weight exists. Guess one bit per variable; check each clause, inequality of the bit strings, and the binary weight sum. Direct multitape scanning with binary indices and arithmetic takes O((N+1)^3) time on a conventional encoding of total bit length N. This includes verifying the supplied assignment; malformed inputs reject.

Even with unit weights this problem is NP-complete. Regard a positive clause x_i OR x_j as an edge requiring a vertex cover. Given an Independent Set instance (G,k), 1≤k≤n, join G to a fresh independent set B of size k, and supply the cover V(G). Its complement B is maximal. Any independent set of the join belongs entirely to one shore, so a distinct competitor of at most the baseline cover cost is exactly the complement of an independent set in G of size at least k. Its symmetric difference from the supplied cover is at least 2k. Every other feasible cover within distance 2k−1 costs strictly more. The join has diameter at most two. This establishes coNP-completeness of recognizing a supplied uniquely minimum witness even though satisfiability of all positive clauses is trivial.

There is also a strict comparison with pairwise distinct weights. Set M=(n+k+1)^2 and give the k baseline independent vertices weights M+1 through M+k, the n remaining vertices M+k+1 through M+k+n. An independent set in G of size k strictly outweighs B, and any set of smaller cardinality weighs less because the sum of all residues is less than M. No other independent set ties B. Minimizing the complementary cover gives the strict objective with the same answer. The script check_supplied_cover.py exhaustively compares all covers on all 285 graph/threshold pairs through n=4 with both weight regimes.

This supplied-witness test is a concrete fixed NP language. The reductions do not produce a superpolynomial lower bound for an unrestricted algorithm. Uniqueness of the minimum cover without a supplied candidate and parameterized improving local search are established subjects.
