# Fixed-parameter search by common kernel span

For three named pins in a simple graph let r be the dimension of the span of all binary private kernel vectors over all raw exterior loop choices. These are vectors w≠0 with w_P=0 and (A+diag d)w=0, where the pin loop values are immaterial. The [two cap channels](even-odd-extension-cap.md) on exterior loop choices use the field of order q=16. There is a uniform deterministic algorithm finding an original witness or certifying absence in

    2^{O(4^r+q·2^r)} n^{q+O(1)}

time and polynomial space. No private vectors, value of r, or decomposition is supplied. The parameter can grow on unrestricted graphs. The algorithm improves on [enumerating independent site choices](common-radical-learning.md) by using a restriction on the width of prescribed missing subcubes.

## Testing for another missing assignment

A channel on exterior bits selects the principal determinant of a fixed symmetric matrix over the characteristic-two field of order q, with some mandatory sites and, optionally, a fixed translation of the exterior bits. Call a raw assignment missing if that determinant vanishes. Suppose t subcubes, all certified missing, are given. A subcube fixes a list of bit values, called its width when counted. The following procedure finds another missing point outside their union or certifies that none exists.

First discard any subcube covered by the union of the others. For a particular cube C, this can be tested by inclusion-exclusion over the other cubes: intersect specified cylinders and compute each nonempty intersection size as a power of two. An uncovered point can be constructed by fixing the bits one by one, retaining a positive uncovered count in the subcube C. Each count takes 2^{O(t)}poly(n) time and poly(n+t) space; intermediate signed sums have O(n+t) bits. Sequential removal preserves the union, and one pass suffices because removing other cubes does not make a previously essential term redundant. For every remaining term there is now a point x in it and no other term.

If such a term C has width greater than q+t−1, choose one coordinate witnessing disagreement of x with each other term. Fix those at most t−1 coordinates to x, and also fix all coordinates not specified by C to x. On the resulting face the known missing set consists only of x, and more than q coordinates remain free. This face must have at least one further missing point. Indeed if its antipodal point is missing we are done. Otherwise the antipode specifies a nonsingular principal set including the mandatory border. Pivot at that set and restrict to the free sites of the face. The principal-pivot identity says that the feasible subsets of this symmetric residual record exactly the feasible changes from the antipode, including changes that remove old indices. If x alone is missing, the full set of more than q changes would be an inclusion-minimal singular principal set, contradicting the [sharp size-q theorem](minimal-singular-principal-search.md). To construct the extra point test the faces obtained by forcing one of the remaining coordinates to disagree with x. The short-obstruction prefix oracle on the original channel finds a missing extension in at least one of them. Translation between raw bits and principal selections is a bitwise complement on fixed sites, which preserves all these operations.

Otherwise the union of the remaining terms depends on at most t(q+t−1) bits. Enumerate assignments to these coordinates which lie outside the union. For each use the short-obstruction oracle to find a missing extension on that partial cube. This includes the empty-list case. If all tests fail, the supplied union is exactly the missing set. The running time is 2^{O(t(q+t))} n^{q+O(1)}.

## Learning actual raw private vectors

The exteriors missing in both channels are exactly those admitting a private w as above. To relate this to the binary principal test, let M₀ be the nonsingular raw base and S the exterior coordinates flipped. A common binary kernel v supported on S, annihilated on the retained exterior rows and all pin rows of K=I+M₀⁻¹, gives w=M₀⁻¹v. Then w_P=0 and diag(1_S)w=v=M₀w. Conversely any raw private w at those flips satisfies v=M₀w=diag(1_S)w, giving that same principal-kernel witness. The equivalence between these kernel witnesses and common missingness follows by the bordered nonsingularity test in the [rank learning proof](common-radical-learning.md). In particular the spans in raw and principal coordinates have the same dimension.

With k independent raw vectors learned, enumerate all nonzero vectors w in their binary span. A combination which fails w_P=0 or has (Aw)_i≠0 at any site with w_i=0 cannot certify any exterior. Otherwise its exact raw certificate is a single subcube: set d_i=(Aw)_i at every site in supp w. All remaining exterior bits are unrestricted. These at most t=2^k−1 subcubes are therefore certified missing in both slices.

Apply the subcube procedure to each slice. If both have no new point, they have the same support, so the graph has no solution. If an uncovered point is missing from only one slice, its eight original binary terminal choices yield a witnessing completion and the inverse diagonal gives an actual induced-even support. If the point is missing from both, solve for a nonzero raw private w there by binary linear algebra. This w lies outside the learned span since the point avoids every certificate from that span. Adjoin it and restart. There are at most r increases of k and one final round. This proves the time bound. To keep space polynomial when r is unrestricted, switch to direct enumeration of all exterior bits as soon as 2^k−1≥n, before materializing the vector or subcube list. That branch takes 2^{O(n)}poly(n) time, within the displayed bound since n≤2^r. When t<n, storing the cubes, the inclusion-exclusion counters, and one assignment at a time uses polynomial space.

The path-plus-isolated-site example in the preceding rank-learning proof has r=1 and exponentially many common missing points. Neither their number nor the width of an arbitrary learned raw kernel pattern is assumed bounded.
