# The next gate scale for a SAT-to-lower-bound transfer

For a bounded-fanin acyclic Boolean circuit on q primary bits with s gates, a Tseitin encoding has V=q+s variables and at most 4s+1 clauses of width at most three. For each binary gate forbid each pair of input bits together with the incorrect output. Pin the designated output. Every primary assignment has a unique gate extension before the output pin. Thus the pinned October fixed-density counting theorem gives uniform deterministic time poly(V)·2^{A V/√log V}, also for decision. This is subexponential in q for s=o(q√log q); at s≤c q√log q it gives a constant fractional saving for sufficiently small c. It certifies no saving over 2^q at s=q log q. The primary paper already proves that one E^NP language needs Ω(t√log t) arbitrary fan-in-two gates at infinitely many lengths, allowing unrestricted depth and fan-out. [Pinned circuit theorem and local test](https://github.com/openai/math/blob/92b516ef8e/preprints/The-Exponential-Time-Hypothesis-is-False-October-25-2026/build/quantitative-circuits.tex)

Williams's all-polynomial-size SAT hypothesis needs a uniform superpolynomial saving over exhaustive search for every fixed gate exponent and gives NEXP outside P/poly. Murray–Williams's gap-UNSAT hypothesis for fixed-exponent NP bounds includes exponentially large circuits and gives a potentially different NP language for each exponent. Neither hypothesis follows from that Tseitin calculation. A separate November disjunction places near-Shannon hardness in NE or separates arithmetic classes. An established arithmetic separation does not imply the Boolean branch. **Two intermediate hypotheses.** A uniform decision algorithm taking poly(V)·2^{O(V/log V)} on width-three formulas with ≤5V clauses would improve the same October witness language to Ω(t log t) gates infinitely often. Substitute s=η n log n into V≤3s+O(n) and choose η small so the exponent is below n/2. A weaker route for the same growth needs only CircuitSAT on q inputs and ≤B q log q gates in time poly(q)·2^{q−Ω(q/√log q)} for one fixed B>0. State both clocks for deterministic multitape simulations, or charge their simulation overhead. For this second hypothesis use a different hierarchy witness. By the unary nondeterministic hierarchy there is H∈NTIME(2^n) outside NTIME(2^{n−floor(log₂ n)}) since the smaller time at n+1 is o(2^n). The October local reduction has q=n+O(log n) decoder inputs, O(n) gates and t=dn padded variable labels for a fixed d. The first satisfying assignment on YES lengths, zero otherwise, gives W∈E^NP by explicit SAT prefix queries. Guess a ≤η n log n gate circuit for W and combine three copies with the decoder to test whether any clause is violated. Accept on UNSAT. An honest witness circuit works on YES, and every assignment violates a clause on NO. Choose fixed η small enough to fit the three copies and O(n) overhead in B q log q. Guessing and circuit construction take polynomial time. The hypothesized saving swallows the decoder's O(log n) address overhead and polynomial factors, placing H in its forbidden time class if those witness circuits exist eventually. Thus one W requires Ω(t log t) gates infinitely often. No uniformity assumption is made on the small witness circuits. Neither intermediate SAT algorithm is established. **A falsifiable approach.** Set k=ceil(q/√log q). Enumerate 2^{q−k} branches pinning q−k ordinary input coordinates. If the restricted decision task at every branch reduced uniformly in polynomial time to a k-input circuit of ≤δ k√log k gates, the October solver would take at most 2^{k/2} time per branch for sufficiently small fixed δ. This gives the required saving. The stronger version requiring each circuit to compute the original residual Boolean function is false, including for adaptive coordinate selection and arbitrary nonuniform recircuitization.

**Counterexample.** For each fixed B>0 and all sufficiently large q there is a function using ≤B q log q binary gates all of whose k-free coordinate restrictions need Ω_B(k log q) gates. Write λ=log₂ q. Pick ℓ so 2^ℓ is between b qλ²/2 and b qλ² for small b>0 depending on B. Choose a binary ℓ-by-q matrix M for which every k columns have rank at least r=ℓ−d, with d=ceil(log₂(q/k))+2. A random matrix suffices. A fixed codimension-d subspace contains each column independently with probability 2^{−d}≤k/(4q). The probability it contains k or more columns is at most (e/4)^k by a union bound over k-column subsets. At most 2^{ℓ²} such subspaces exist, and k≫ℓ². A k-column set of rank at most ℓ−d lies in a codimension-d subspace, which proves the claimed weaker rank guarantee.

Choose h:{0,1}^ℓ→{0,1} uniformly. For every affine injection J on r input bits into ℓ bits, h∘J is uniform on 2^r truth values. At most 2^{2^{r−1}} binary circuits on r inputs use ≤c·2^r/r gates for sufficiently small absolute c at large r, by encoding each gate's truth table and two ordered predecessors. At most 2^{ℓ(r+1)} injections exist. Since 2^r=Θ_B(k λ²) and r=Θ(λ), some h needs Ω_B(kλ) gates on every such affine embedding. Let F(x)=h(Mx). After any q−k coordinates are assigned, choose r independent free columns and pin the other free bits to zero. The resulting input map is an affine injection, proving the residual lower bound.

The upper circuit fits even an arbitrarily small fixed B. Group the q bits into blocks of floor(log₂ ℓ) bits. Generate all subset parities per block using O(ℓ) gates, then form each of the ℓ desired outputs by adding one parity per block. This uses O(qℓ/log ℓ)=o(q log q) gates. An arbitrary ℓ-bit truth table has an O(2^ℓ/ℓ)-gate circuit: take u with 2^u∈(ℓ/4,ℓ/2], precompute every function of these u coordinates from their minterms in O(2^{2^u}2^u) gates, generate all minterms of the remaining ℓ−u bits by shared prefix decoding, and OR their products with the selected precomputed functions. Choose b small enough for this table circuit to fit the remaining gate budget.

At the designated k the intended compression budget is Θ(q), whereas each exact residual needs Ω_B(q√log q) gates. The proof uses probabilistic existence for M,h to disprove a sublemma about every circuit. It supplies no uniform NP hard function. Affine changes of variables, equisatisfiable reductions and tests specialized to local decoder consistency need not preserve these exact residual truth tables and remain possible algorithmic routes. The actual October consequence in this audit stays in E^NP at its original scale.
