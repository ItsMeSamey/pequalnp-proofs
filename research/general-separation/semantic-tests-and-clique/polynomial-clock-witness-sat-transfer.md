# Quantitative witness checking at polynomial NP verifier clock

Fix unary H in NTIME(n^4) outside NTIME(n²) by the nondeterministic time hierarchy. Use the JMV construction for the binary-input machine receiving bin(n), expanding the unary input and running this H machine; it costs 2^O(|bin(n)|). Its local formula φ has poly(n) clauses and variables, addresses O(log n), and is satisfiable exactly on YES. The original input to our new verifier is unary, so a complete satisfying assignment is an ordinary polynomial-size witness. One fixed polynomial-clock verifier constructs φ and checks the whole assignment. Making the JMV input binary is important: its uniform decoder construction takes poly(log n) rather than an unspecified polynomial in n. Time allowance can be a fixed sufficiently large power of two in |bin(n)|. With r=2, the source's constant-local decoder directly applies on this exponential scale. Compile its O(log n) output bits to O(log n) ordinary gates by enumerating bounded supports, as in quantitative-circuits.tex.

Suppose that on all but finitely many YES lengths some satisfying assignment of φ has a label-bit circuit with at most η log n sqrt(loglog n) gates. Guess it; compose three copies with the decoder and test for a bad clause by the October manuscript's fixed-density SAT clock. The miter has V≤3η log n sqrt(loglog n)+O(log n) variables after standard gate encoding. Its cost is 2^((3Aη+o(1))log n) for fixed A, with binary logarithms. Choose η small enough to run inside n². Recovering bin(n) on a multitape machine costs O(n log n); minuscule inputs and finitely many exceptions can be hardwired. This contradicts H's hierarchy clock. Thus infinitely many YES inputs force every ordinary accepting witness to need Ω(log n sqrt(loglog n)) gates as a random-access bit function. This uses the manuscript's stated SAT theorem.

Define a concrete NP language B on (1^n,i) asking whether φ has a satisfying assignment with bit i set, using a self-delimiting unary prefix and O(log n)-length address. Its forced-positive output label g(n) recovers H. A deterministic O(N²) solver for B would decide H in O(n²) since N=n+O(log n) and producing g(n) costs O(n log n)+poly(log n). Thus this fixed NP language has a quadratic-time lower bound; that decision bound follows from hierarchy alone. The additional witness-circuit lower bound uses the counting speedup. NP membership does not enforce the same witness across different bit questions. Enlarging the forbidden exponent by changing H changes the verifier.
