# Counting after an injective private code without an input entropy saving

A cut can preserve every original input state and still improve an exact counter by removing internal gate variables. Work with a binary DAG on q raw bits. For example each disjoint pair is represented by its three signed minterms for states 01,10,11. The fourth state maps to zero, so the representation is injective and all four code words are valid raw states. Regard any locally computed code words as functions of their actual raw bits. The outer DAG may share arbitrary signals.

## An explicit partial encoding

Select t internal Boolean gate values as interfaces, in original topological order; include the output among them or enforce it by a separate conjunction. For each interface a_j, suppose its defining function, with earlier interfaces treated as free bits, is one AND of m_j truth-table predicates, up to optional output complementation. Each local predicate depends on at most k distinct raw/earlier interface bits. Let m include the final predicates as well as all m_j. The bounded-arity data and their recognized supports must be obtained from the original gates, or provided by verifiable rewrites. No independence of encoded bits is assumed.

A concrete polynomial-time pass for fixed k≥2 carries small truth tables and signed lists of small predicates. Decode supported primary blocks directly into tables over raw bits. For any binary gate on tables of support ≤k, construct its table on their union (≤2k bits); remove inessential inputs and retain the result if support is at most k. For matching AND/OR orientations, flatten lists of conjunctions using De Morgan and deduplicate common local predicates. For any other gate, name earlier nonlocal list outputs as interface bits; a large union of two table inputs can also be reduced by naming one or both gate outputs. Keep a primary already available as a raw bit. The binary gate then has at most two named arguments. Materialize each interface definition once and preserve pointers on other uses. Flattened lists can be explicitly deduplicated since there are only O(s+q) local gate predicates for an original s-gate DAG if one fixes the representation chosen at each original gate. List memberships may cost quadratic size; charge the actual total m. Giving precedence to valid flattenings or supplying a verified plan can change the measured t,m. Arbitrary predicates on many raw variables must not be hidden in one table. For growing k charge its whole table and support checks.

Let b_j be the required signed interface bit, so the definition is b_j=Π_i P_ji. In integer arithmetic
1[b_j=Π_i P_ji]=(1−b_j)+(2b_j−1)Π_i P_ji.
Use one activity bit h_j. When h_j=0 require b_j=0. When h_j=1 require all corresponding P_ji to hold. Assign a minus sign exactly when h_j=1 and b_j=0. At each fixed raw and interface assignment the signed sum over h_j equals the displayed indicator, including inconsistent interface guesses. The products of indicators follow by independent summation of their activity choices. Enforce the output acceptance. Compute the parity of the minus signs by an O(t)-gate ordinary circuit with unique Tseitin extensions. The exact count is the number of satisfying assignments at even parity minus the number at odd parity, since the original topological definitions have exactly one interface valuation per raw input. An original satisfying witness is recovered by self-reducing on raw bits with the signed counter, adding at most q units in any invocation. A single term in the signed expansion need not certify the guessed raw assignment. The switch and parity mechanism comes from prior weighted encodings. [Bannach et al., Proposition 2.1 and Section 3](https://dbai.tuwien.ac.at/staff/hecher/easy_sharp2sat.pdf) [Meert et al.](https://web.cs.ucla.edu/~guyvdb/papers/MeertStarAI16.pdf)

For each local P, forbid its false table rows under the single activity guard. Width is at most max(k+1,3). Both formulas have n'=q+O(t) variables and O(2^k m+t+q) clauses, accounting for optional units. For fixed k the pinned arbitrary-density counting theorem gives poly(input size)2^{O_k(n' loglog(n'+16)/√log(n'+2))} time and polynomial space. If m=O(q+t) with fixed k and fixed factors, fixed density gives poly(input size)2^{O(n'/√log(n'+2))}. In particular m=Θ(q log q), t=O(q), fixed k gives 2^{o(q)} despite unchanged q. Applying fixed-density Tseitin to the full Θ(q log q)-gate original instead gives exponent O(q√log q), with no guaranteed advantage over 2^q. The savings rely on a verified representation of the suffix; injectivity of the code alone is insufficient. [October exact counting hypotheses](https://github.com/openai/math/blob/92b516ef8e/preprints/The-Exponential-Time-Hypothesis-is-False-October-25-2026/build/main_full_version.tex)

## Positive and hostile original circuits

Give each of q/2 vertices an injectively encoded two-bit label as above. On a simple graph of degree Θ(log q), for every edge and every nonzero label forbid both endpoints having that label. Conjoin all these local predicates. All three code bits of every nonisolated vertex are live. Each of the Θ(q log q) restrictions is essential: put its two endpoints at the prohibited label and all other vertices at zero. Every other restriction is then satisfied. Raw circuit size is Θ(q log q) and its whole layer has no input entropy saving. After substitution all restrictions are width-four clauses over the raw bits, giving the arbitrary-density speedup with no internal interfaces except possibly the output. Extra per-vertex conditions, or O(q) arbitrary shared gate values combining groups of these predicates, can also be encoded when the measured t=O(q). Forbidding the zero label at every vertex specializes to ordinary proper three-colorings; the essentiality example concerns the unrestricted four-label instances. For a fixed small logarithmic budget coefficient one can reduce the graph degree constant.

Here is a barrier specifically for plans naming original gates and compiling each interface and the accepted root as a single AND or complemented AND of k-local predicates for fixed k. Take g disjoint cliques each on even w vertices, q=gw, with g>k, w=Θ(log q). Within each clique encode disjoint pairs as three minterms and recover its two raw bits by OR of the appropriate pairs of minterms. Use these recovered bits for all edge products. Fix one cyclic order of the g cliques and use exactly that order in every round, taking a new distinct edge from each clique. Accumulate their XOR in a linear chain of gates. There are m=g binom(w,2)=Θ(q log q) products and Θ(m) gates, with the budget constant reducible via w. For example choose g growing through powers of two and w an even rounding of c log₂g.

Between consecutive named accumulator gates (also from the chain start and to the final output), consider the function to be defined by a list after cutting earlier named gates. Each traversed clique contributes its own function on disjoint raw coordinates and disjoint clique-local interface bits. This function is nonconstant whenever its interval includes an edge: assigning local interfaces consistently projects it to the XOR of the distinct edge monomials from that clique. This XOR is zero on all-zero inputs and is one when just the endpoints of one included edge are set. Naming additional clique-local gates leaves both evaluations possible. The previous accumulator, if present, is a separate named bit. No other source nonlocal gate exists.

Any interval of more than k edges meets at least k+1 cliques. The XOR of their independent nonconstant functions has no partial assignment on at most k arguments that forces either truth value, since at least one clique remains untouched. A nonconstant conjunction of k-local predicates always has a false certificate on at most k arguments by fixing one violated local test; its complement has a true certificate. The list model therefore requires Ω(m/k) accumulator interfaces, even if local predicates within each list are optimized. At this size its stated density clock gives no worst-case sub-brute guarantee. The full XOR is itself a quadratic form, so a different algebraic pass can count it. Reassociating the accumulator or introducing new internal functions need not respect this lower bound.

Finally at this same injective interface each of the original two raw bits is the OR of two code bits. Consequently any arbitrary raw circuit C is represented by a suffix on the code with O(q) additional gates and exact equality on every raw input. Optimization or a SAT bound for all such suffixes still has to handle C; none is implied by the restricted compiler.
