# Independent review of the formula SUM lower bound

**GO** for SHA-256 `1d2c693f2fa646b2c78058b09ff86d9ecb21906df5ce24b2ff422b05ade99250`, with the published-input caveat that the October counting premise is a manuscript theorem. I checked the stated theorem directly against its original source and audited this application. This is not a fresh verification of the counting manuscript's internal proof.

* The quantifiers negate to a common sparsity exponent and language-dependent finite exceptional lengths. Only one P evaluator must be represented. Gate fields have fixed width, hence every specialized gate uses the identical ambient length and representation. The evaluator can compare the binary header's claimed physical size with its actual input length before processing it. A language-dependent constant length cutoff is harmless: below the induced finite threshold in n use ordinary exhaustive search.
* Independent columns span the evaluator column even after dependent columns are discarded. Equality on a nonsingular row minor suffices because the right-hand side already lies in this span. Cramer's rule yields one shared nonzero denominator and numerators bounded in magnitude by the Hadamard bound for the rank. The zero function is covered by denominator one. For fixed d, signed integer sums have a uniform polynomial bit bound over all languages. A ripple adder and equality test produce the requisite common polynomial ordinary-circuit bound.
* In each block j the heavy-selection probability for an atom equals its number of heavy slots divided by R. Their sum is at most Bn/C. Independence is required across blocks only. The union bound over at most M^d atoms survives for one small positive epsilon. Shared gate-index hardwirings introduce no new heavy variables. Branches for a product of four atoms cost at most 2^(4 delta n), irrespective of dependence among those atoms.
* Nonnegative quartic checks pin each inferred value to zero or the common denominator on every input. Triple gate checks then count exact violations, input squares anchor induction, and the range makes the zero-output sum sound. Different indices of one atom cause no extra occurrence cost. Operationally all malformed descriptors are rejected. For exact machine clocks a binary integer upper envelope for the nested logarithms can replace K in descriptor checks and heavy thresholds, e.g. twice the integer cube root rounded up of twice the bit-length of the bit-length of M+16, plus two. This is O(K) and dominates K for either conventional log base. Soundness of the verification never requires rejecting representations above the original theorem's cap.
* Folding unary chains and constants in a restricted tree gives at most nL leaf occurrences per nonconstant atom. Write b for the number of remaining unbranched inputs and g for the new gate count. There are b+g declared variables and at most 4g+1 clauses. Hence density is bounded by an absolute constant even when g is tiny. Keeping unused inputs preserves unique extensions. As b >= (1-4delta)n and g=O(nL), the October fixed-density estimate has exponent O(nL/sqrt(log n))=o(n). Intermediate signed arithmetic has O(S log(S+1)+n+log M) bits up to a constant. A polynomial slowdown inside an individual subexponential counting call preserves o(n); outer scans are polynomial in M. Choose delta first, then C, then epsilon after the fixed polynomial degrees have been determined.
* The additional SAT-witness branch exactly supplies the opposite nondeterministic output required in the Murray–Williams model. Ordinary bounded fan-in circuits are typical; their theorem supplies an NP counterexample for each fixed ordinary exponent. Taking that exponent strictly bigger than the common simulation exponent absorbs constants and finite exceptions. The conclusion is per atom's total leaf count and allows a different language for each d. No standard P versus NP separation follows.

## Primary-source checks

[OpenAI, October 25 version, Theorem 1.1](https://raw.githubusercontent.com/openai/math/92b516ef8e/preprints/The-Exponential-Time-Hypothesis-is-False-October-25-2026/build/main_full_version.tex) explicitly counts all declared variables deterministically in bit complexity at fixed width and fixed density; short clauses are allowed by repetition. [Murray and Williams, Theorem 1.1](https://people.csail.mit.edu/rrw/easy-witness-nqp.pdf) uses the same epsilon for the circuit size and runtime saving, and gives a polynomial-time nondeterministic class for each fixed exponent. [Williams, CCC 2018](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.CCC.2018.6) already establishes the general SUM verification strategy and fixed-polynomial results for other bottom classes. [Chen, MFCS 2015](https://eccc.weizmann.ac.il/report/2015/099/) gives density-dependent fractional savings for fixed-basis formulas. [Chen et al., circuit mining](https://www.cs.haifa.ac.il/~ronen/online_papers/mining.pdf) emphasizes larger De Morgan formulas; specify the basis when comparing this source. Neither comparison establishes literature-wide priority.
