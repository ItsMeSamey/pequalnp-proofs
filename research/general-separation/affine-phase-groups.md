# Recovering affine phase constraints from physical words

First recover and recompile the signed source from the four untouched ordered-image fields. Certify its binary conflict graph as a line graph, identify all vertex-star clauses, and certify every component left after bridge deletion (retaining all vertices) as a simple even cycle. Any satisfying source word is a perfect matching. A bridge cuts off an even number of vertices since its shore is a union of those even cycles, so no bridge can be selected. On each cycle the matching is determined by one bit. Substituting the bits in all positive demands, removing duplicate literals and tautological rows, therefore preserves existence in both directions.

Use ordinary 2-SAT first whenever all remaining rows have width at most two. Otherwise group the rows by their exact support T. Each reduced clause forbids exactly one tuple on T. Deduplicate forbidden tuples, write q for their number and d for |T|. Each group encountered has q≥1. If 2q<2^d, the allowed set is proper and has strictly more than half the cube, so cannot be affine. Otherwise enumerate at most 2q tuples. An empty allowed set gives an inconsistent group, including the case of an empty clause. For nonempty allowed set A, choose a∈A, row-reduce the differences x+a for all x∈A and write r for their rank. Since A is contained in the affine hull of size 2^r, equality |A|=2^r is necessary and sufficient for affinity. For an affine group generate a basis of the perpendicular space to the differences and impose each global parity equation with its right side evaluated at a. Empty groups in the sense of absent supports impose no constraint. An empty allowed set can be recorded as a contradiction pending completion of the structural checks.

When all groups pass, the union of the generated linear equations has exactly the same solutions as the conjunction of the phase clauses. Gaussian elimination gives inconsistency or an explicit phase tuple, and mapping its alternating cycle edges back verifies the original signed source assignment. A rejected nonaffine group only triggers a budget-independent unknown in this fallback; it does not certify unsatisfiability. Enumerated tuples summed across groups number at most twice the number of input rows. Mask lengths, rank operations and witness validation cost polynomial bit time in input size. No supplied charge vector, proof certificate, oracle, bounded graph width or parity-clause provenance is required.

For a cubic simple graph with distinct incident-edge supports at its vertices (in particular K4), the usual Tseitin encoding on its edge bits includes exactly the four forbidden three-bit tuples for each vertex charge. Encoding each edge-bit variable by an even occurrence cycle and translating the marked demands back may independently permute and complement its phase bit. This preserves the affine groups. For connected K4 the system is consistent exactly when total charge is even: summing vertex equations proves necessity, and assigning non-tree edges zero and eliminating leaves of a spanning tree proves sufficiency. Both parities are therefore decided from the raw words. This argument concerns decision and an original source witness; it makes no claim on the size of refutations in any proof system.
