# Exact NAND counts by the linear information shared between factor groups

Given h raw bits and s ordered NAND gates, the [solver](linear_tap_separator.py) counts original satisfying words and recovers one when the count is positive. It uses the given gate ordering and an optional binary merge schedule. The default merges adjacent factors in balanced rounds. The solver computes the cost parameter of its chosen schedule before allocating exponential tables; it does not need a minimum-width decomposition. A state budget below the computed requirement returns UNKNOWN.

**Extracting actual factors.** Represent every wire by an affine form on the original bits and a growing list of private gate coordinates. Constants, inverters, complementary operands and recognized four-NAND XORs have exact affine descriptions. Every remaining nonlinear NAND introduces a fresh coordinate and records the local relation between its two input forms and that coordinate. Start at the original output pin, walk residual auxiliary dependencies backwards, and discard unused equations and unused auxiliary coordinates. This removes internal NANDs of a recognized XOR macro even when its original description allocates them separately. Any internal value also used elsewhere is kept whenever its defining coordinate is still needed. Every raw assignment extends in exactly one way to the live gate checks, by original topological order. Let a be the number of live gate coordinates, D=h+a, and f=a+1 the factor count including the output pin. Each relation involves at most three linear forms plus explicitly retained affine offsets. Offsets affect leaf truth tables, never their spans.

**Joining factors.** For a tree node X let U_X be the span of all coefficient rows in its factors, and I_X=U_X∩U_out the intersection with the span of all rows in the other factors. Store the number of linear functionals on U_X satisfying its factors for each restriction to I_X. On a leaf enumerate the dual of U_X and check the NAND relation or output pin. For children L,R enumerate the dual of E=I_L+I_R. Restrict each enumerated functional to the two child interfaces, multiply the corresponding counts and add to its I_X entry. The latter restriction exists: writing v∈I_X as l+r with l∈U_L and r∈U_R shows l=v+r belongs to I_L and r=v+l belongs to I_R. Child extensions with the selected restriction agree on U_L∩U_R, since this intersection is contained in both child interfaces. Agreeing functionals extend uniquely to U_L+U_R. Conversely, each successful parent extension determines exactly one enumerated functional on E. Thus no normalization or double counting occurs at a join.

At the root the interface is zero. Multiply its sole count by 2^(D−dim U_root), the number of extensions of each root functional to the augmented space. The unique-extension NAND property then gives the count on the h physical bits. To find a witness, record any nonzero-contribution child key pair at each occupied parent entry and any valid local assignment at each occupied leaf. Backtracking the root choice fixes the values on every leaf basis. The gluing argument proves consistency of their union, so one Gaussian solve produces an augmented word. Drop the auxiliary coordinates and re-evaluate the original NAND circuit. Gaps in the implementation's numerical labels of auxiliary bits are harmless; D counts only live coordinates, and unused label positions can be zero in the witness solve.

With k the maximum of dim U_leaf and dim(I_L+I_R) over all relevant nodes, running time and storage are 2^k·poly(h+s+1). There are at most 2s+1 tree nodes and at most 2^k iterations per node. Row masks have O(h+s+1) bits and every local count has at most D+1 bits; products have O(D+1) bits too. The gate scan, scope construction, top-down outside-span pass, merge validation, and basis intersections all take polynomial bit time before table allocation. Without a promise the computed k can be large. Capping the number of states per node at K tests 2^k≤K exactly.

**A strict padded example.** Let n be a positive multiple of six and add p≥0 padding coordinates. At position i use the tap z_i equal to the XOR of all n+p coordinates except active bit i. The source computes their shared total parity and XORs back each excluded bit. It accepts iff no two adjacent z_i are both one. Each local pair of taps jointly touches every raw coordinate, including every padding coordinate. For each fixed padding assignment the map on active coordinates has matrix I+J, where J is all ones; in even dimension (I+J)²=I over the binary field. Hence every tap word has precisely 2^p original preimages. Every nonzero column of a local pair genuinely affects its NAND under some assignment: the pair is surjective and binary NAND has no nonzero translation period.

The path has F_(n+2) independent sets, by splitting on its first bit, with F_1=F_2=1. The count is odd because Fibonacci residues modulo two repeat 1,1,0 and n is divisible by six. Every full-cube representation with r Boolean syndrome bits and equal fiber cardinality has count divisible by 2^(n+p−r). The original count 2^p·F_(n+2) forces r≥n. This includes the archived permutation and affine-syndrome range engines even if their offsets are nonlinear. On a full-domain positive count their syndrome enumeration therefore has an exponential dimension bound. The separation concerns that full-count method, not the complexity of interval problems in general.

The source constructor interleaves the adjacent NAND factors with a left-to-right AND accumulator. After gate extraction, the factor operands are individual independent tap coordinates, edge NAND results, and signed accumulator coordinates. A prefix cut in this order shares at most three coordinates with the suffix: the next boundary tap, the current accumulator, and an edge result awaiting accumulation. The pin is the last factor. For any two adjacent groups the child interfaces only involve coordinates crossing their left, middle or right cuts. Therefore dim(I_L+I_R)≤9 and the default balanced schedule takes polynomial time, even after arbitrary amounts of the indicated padding. The source has exactly 4(h−1)+4n+3(n−1) NANDs for h=n+p. The argument uses the actual generated gate factors and keeps every required accumulator relation.

**Comparison.** Counting by compatible states on a tree is classical. Kashyap identifies linear state and constraint spaces on tree realizations of codes. Belmonte and Sau obtain single-exponential graph rank-width algorithms for odd induced subgraphs and odd colorings. Here an interface is an intersection of spans of the actual NAND-factor operands in the augmented linear space. It is a different parameter from the binary cut-rank of a supplied graph adjacency matrix. The archived rank-width polynomial-calculus construction, for instance, tracks incoming and outgoing adjacency parity signals to derive refutations. The present source extracts nonlinear factor checks, counts all raw witnesses with the correct kernel multiplicity, and reconstructs a checked raw word. The strict comparison above is with whole-syndrome enumeration. It makes no optimality claim against all earlier tree-based algorithms.
