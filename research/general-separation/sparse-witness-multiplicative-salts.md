# Deterministic salt lists for sparse accepting sets

A binary circuit C has q primary inputs, s gates, and either no satisfying assignment or at most K satisfying assignments (1≤K≤2^q). Equivalently, its number of satisfying assignments is promised to be at most K. There is a deterministically constructible common list of multiplicative salts over a binary field of degree O(log(qK+2)). Every nonempty such circuit gives a nonzero weighted count at some salt, and every query uses the original q primary bits. This concerns the support size, not a witness of low description complexity.

**Isolate a coefficient by a small prime.** Identify x with its binary integer I(x)<2^q. For any marked x*, each nonzero difference |I(x*)−I(x)| has at most q distinct prime factors. Among the first q(K−1)+1 odd primes there is a p isolating x* from all other marked points modulo p. This only separates x*; the other residues need not be distinct. Let P be the last tested prime; P=O((qK+2)log(qK+2)) by the usual bound for the nth prime. For polynomial K the list is obtained by a polynomial-time sieve. In the larger regime below its construction costs poly(P), which is charged explicitly.

Put u=ceil(log₂(P+1)). Split I(x) into nonnegative contiguous u-bit words X_j, using zero padding on the last block. For each test prime use hardwired R_j=2^{ju} mod p and exponent

    E_p(x)=Σ_j R_j X_j ≡ I(x) mod p.

Write J=ceil(q/u). The exponent is less than J·2^{2u}. On the isolating prime, E_p(x*) is therefore distinct from every other marked exponent. The univariate polynomial Σ_{x:C(x)=1}Y^{E_p(x)} over F₂ is nonzero and has degree less than J·2^{2u}. Choose a single field of size 2^h with 2^h−1>J·2^{2u} and h=O(log(qK+2)). Enumerating every nonzero a in this field gives a nonzero evaluation for some a by the elementary root bound. This really is the multiplicative weighted count using salts z_i=a^{R_j 2^t} for the bit at offset t of block j. Enumerating coordinates of the field value reduces detection to scalar parity-CircuitSAT queries. The exponential field of degree q that would inject all q-bit indices is unnecessary.

An equivalent simpler decision procedure enumerates all candidate integers v<J·2^{2u} and tests the parity of C(x) AND [E_p(x)=v]. On an isolating prime some bucket is a singleton. For either procedure there are 2^{O(u+log(q+2))} detection queries. Once an odd scalar query is found, pin one input bit at a time using that same scalar test: the two child parities sum to the odd parent, and inspecting one child suffices. At most q further queries find a witness, which can be checked using C. At most O(q) pin gates are required. Even without the promise a found witness remains valid; absence of a detected witness is conclusive only under the promise.

**Polynomial-support gate budget.** If K≤q^a for a fixed constant a, u,h=O_a(log(q+2)). Each E_p is a sum of q bits with hardwired nonnegative O(log q)-bit coefficients (the binary weights R_j 2^t). It costs O_a(q) gates using the grouped popcount construction in linear-gate-field-salts.md. Its binary encoding uses O(log q) bits. To avoid a full field-sized lookup, compute a^{E_p} by conditional multiplication by the constants a^{2^t} for each exponent bit. In a fixed binary basis each such multiplication is a linear map, costing O(h²) gates plus O(h) multiplexers. The overall O(h³) field-power cost remains o(q), even when the field cardinality is much greater than q. Fields and hardwired constants may be built by exhaustive operations in 2^{O(h)} time. Therefore every query has s+O_a(q) gates and all query generation and list lengths are polynomial in q+s. With coefficient slack an unrestricted parity-CircuitSAT upper bound for Bqlog q gates and a 2^{q−ω(log q)} clock would transfer deterministically at this saving to promised sparse CircuitSAT decision and witness recovery. This is distinct from an algorithm for unrestricted CircuitSAT.

**Larger support at the stronger saving.** Fix two gate coefficients 0<B'<B. There exists a constant ε>0 such that K≤2^{q^ε} can be handled, on s≤B'qlog₂ q primary circuits, using only parity queries with ≤Bqlog₂ q gates at sufficiently large q. In the following bound logarithms have base two. We may plug in an efficiently rounded upper bound on K of size 2^{O(q^ε)}, for example 2^{ceil(q^ε)} with ε chosen rational; its binary representation has polynomial length. Then u≤O(q^ε+log q) and log u≤ε log q+O(1) for fixed ε>0.

Harvey and van der Hoeven give O(u log u) multiplication and state the same result for Boolean circuits. Use one such u-by-u multiplier per block, hardwiring one factor R_j, then add the J products in O(J(2u+log(J+1))) gates. Here u≥Ω(log q) if the bound K is large; for smaller K one can instead use the polynomial-support method or run the advertised rounded bound throughout. The E_p gate budget is at most A q log(u+2)+O(q+u log(u+2)) for an absolute A. If polynomial-time uniformity of the modern circuit synthesis is not assumed, find the multiplier once by enumerating ordinary bounded-fanin circuits in increasing size, verifying each against all 2^{2u} pairs by direct multiplication. The gate existence bound yields preprocessing 2^{O(u log²(u+2))}. This cost is charged independently of the parity oracle. Hardwire the resulting multiplier identically for all primes (with their different constant inputs). Field powering adds O(h³)=o(q) for ε<1/3. Thus choose ε small relative to B−B' and A. All test circuits, including pins, then satisfy the target cap; their true primary-input count is still q.

Full non-oracle construction, number of calls, and polynomial encoding overhead fit within factors 2^{O((q^ε+log q)log²(q+2))}poly(s+q) for this rounded bound. Hence a uniform deterministic parity-CircuitSAT solver on the indicated gate class in 2^{q−Ω(q/sqrt(log q))} time would retain the same order of additive exponent saving for this 2^{q^ε}-support promise. A much weaker superpolynomial saving need not absorb this larger list. The sparse October #3SAT theorem gives a smaller size-parameter range for beating 2^q directly and does not establish the near-qlogq parity hypothesis.

The GF₂ additive fingerprint and odd-bucket decoding in parity-syndrome-exception-sat.md already yield a deterministic promise algorithm at polynomial K by setting the low-degree reference function to zero. The analysis here supplies actual multiplicative salts, accounts for binary-field lookup costs, and extends the gate calculation to much larger support. A hierarchy experiment that guesses a witness circuit and checks for a violated local constraint has no general upper bound of 2^{q^ε} on its number of violations. This deterministic transfer therefore cannot be substituted for the unrestricted UNSAT test in that argument without an additional lemma.
