# NP lower bounds for sums of formulas with private circuit banks

Fix positive integers d,k and a constant 0≤γ<1/4. Put K(N)=ceil((log log(N+16))^(1/3)). There is a language in NP whose membership function, at infinitely many lengths N, has no exact real linear combination of at most N^d atoms of the following kind.

Each atom has its own Boolean DAG of at most N^k binary gates, with arbitrary fanout and designated output wires. Charge the union of all raw inputs named by any supplied bank gate or input interface and all raw wires nominated directly as bank outputs, even unused outputs and outputs that pass through no internal gate. This entire syntactic union together has size at most γN. Raw aliases or auxiliary output identities charge their original named raw inputs. The atom's output is a binary Boolean formula tree of at most N^k nodes. Its leaves can reference any bank outputs, constants and raw input literals. At most NK(N) leaf occurrences are raw literals. Bank-output references can repeat freely within the total tree size bound. Banks may use different raw coordinate sets and may overlap. In particular the theorem allows any fixed polynomial description bounds by increasing k. The hard language may depend on d,k and γ.

## Projecting the representation

Assume the contrary, so every NP language has a representation with these fixed parameters at all sufficiently large lengths. Use the fixed P language that outputs gate i of an explicit bounded-fanin circuit C evaluated on the parities of n disjoint R-bit blocks. Its input includes a self-delimiting header, circuit description and fixed-width gate index. It rejects malformed inputs. Given an n-input circuit with s nodes, choose R=(n+s+2)^2, with a binary header for R. The total input length M satisfies

    M = nR + O((n+s+1) log(n+s+2)),       M/(nR) = 1+o(1).

The latter ratio tends to one uniformly as n grows. For s≤2^(εn), log M=O(εn+log(n+2)). The assumed representation of this one language supplies all indices of C at the same length M. If it uses S≤M^d atoms, replace its real coefficients by integer numerators a_j and a common positive denominator H, each of O(S log(S+1)) bits. Indeed select independent columns of the Boolean atom-evaluation matrix, select an invertible square row minor and solve against its Boolean target; the determinant bound and Cramer's rule give this common denominator. The identically zero case has the empty representation and H=1. Guess these data and the explicit bounded bank and tree descriptions, of total polynomial length in M for the fixed d,k. This uses existence of representations for NP languages only under the contradiction assumption. [Williams, coefficient lemma and sum verification](https://arxiv.org/abs/1802.09121)

Choose constants γ<δ<1/4 and C₀ sufficiently large that γ+1/C₀<δ. Take L=ceil(C₀K(M)). In each atom mark the entire supplied bank footprint just defined, including all nominated raw-wire outputs before gate-index fixing, together with all raw coordinate names occurring more than L times directly in the tree, before fixing the header or gate index. This is at most (γ+1/C₀)M names. Select independently a uniformly random position in each parity block. In a given atom the number X of selected marked positions is a sum of n independent Bernoulli variables of potentially different means. Its expectation is at most (γ+1/C₀)M/R. For some constant η>0 and all sufficiently large n this is at most (δ−η)n. The exponential tail bound for bounded independent variables gives Pr(X>δn)≤exp(−2η²n). A union bound over S≤M^d works for one sufficiently small fixed ε>0. Guess a single qualifying slot in each block and verify each atom's selected marked count directly. Equivalently use rational cutoffs between γ and 1/4 to avoid machine comparisons with a real parameter. The randomness proves existence only.

Now fix C, the header, the selected slots and a desired gate index i. Leave the selected slot of block j equal to x_j and pin the rest of that block to zero. Parity recovers the intended x_j for every slot choice. The marked sets and the same slot map apply to all gate indices.

## Verifying the guess

Let z_i(x) denote the signed integer sum of projected atoms with coefficients a_j. Check the following sums on the n live input bits. First require sum_x z_i²(z_i−H)²=0 for every i, making z_i/H Boolean everywhere. For each input node compare z_i with H x_j by its squared difference, and treat constant nodes likewise. For each binary gate, use the multilinear violation indicator on its three Boolean bits, of degree at most three. Substitute the normalized gate readings, clear H³, and test its sum for zero. After Booleanity is established this quantity is pointwise nonnegative. Finally require the sum of the output readings to be zero. A passing guess computes every actual gate on all inputs and certifies that the given circuit is unsatisfiable. On an unsatisfiable instance the true representation and a qualifying common slot choice pass.

Every expanded term is a scalar times the sum of a product of at most four projected atoms, possibly with raw literals. For that term enumerate assignments to the union of their selected marked positions, at most 4δn bits. In each branch every named bank input is fixed: a raw coordinate outside the selected slots has already been pinned, and every selected bank input was marked in its own atom. Thus every bank output, including a wire referenced repeatedly in the tree, becomes a constant by evaluating the DAG once per required atom and index. Each surviving raw coordinate has at most L direct occurrences per atom, since every heavy selected coordinate was also assigned. The residual tree has at most nL live leaf occurrences irrespective of the original multiplicity of bank references.

Fold constant subtrees. At a gate with one constant child the unary Boolean map is constant, identity or negation; unary maps can be composed and incorporated into the adjacent binary truth table or leaf polarity. A nonconstant residual with l live leaves consequently needs at most l−1 binary gates up to polarities. Conjoin the at most four residual trees and any input literals. Retain all n minus the number of branched inputs as declared bits, even those with no surviving occurrence. Introducing one variable per gate and at most four truth-table clauses per binary gate plus an output requirement preserves the exact count by unique extension. This gives fixed-density width-three CNF with O(nL+n) variables. Constant or small cases may be counted directly. The October fixed-density counting theorem gives 2^o(n) bit time and polynomial space in the size of the resulting CNF since L=O((log(n+2))^(1/3)). Scanning and simplifying the original atom descriptions takes an additional polynomial in M. Summing over disjoint branches counts each live assignment once. [October manuscript, Theorem 1](https://raw.githubusercontent.com/openai/math/42907c9e999cc00d6abe7a50bfc1023250edd1b9/preprints/The-Exponential-Time-Hypothesis-is-False-October-25-2026/build/main_full_version.tex)

Each term has a polynomial-bit coefficient in M and a count at most 2^n. The number of gate checks, quartic expansion terms, and description scans is polynomial in M for fixed d,k. The full nondeterministic bit clock is therefore 2^(4δn+O_(d,k,γ)(εn)+o(n)). Fix ε small enough for the common-slot union bound and the clock O(2^((1−ε)n)); the strict gap 1−4δ makes both possible. Passing UNSAT guesses output yes, failed guesses output unknown. A separate nondeterministic branch tests an ordinary satisfying assignment, returning no if it succeeds and unknown otherwise. These two non-unknown outputs cannot occur on the same instance. This meets the gap-UNSAT convention for ordinary circuits, using exact UNSAT verification even off the gap promise.

Murray and Williams's Theorem 1.1 now gives, for every fixed exponent j, an NP language lacking size-N^j ordinary circuits at infinitely many lengths. Yet the contrary assumption gives all NP languages an ordinary circuit upper bound with one fixed polynomial exponent depending only on d,k: evaluate the bounded DAGs and trees, select the rationalized integer numerators by their output bits, and add and compare their signed polynomial-bit contributions. Choose j larger than this common exponent. This contradiction proves the theorem.
