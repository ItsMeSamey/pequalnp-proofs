# Grammar certificates for a diagonal computation

A straight-line grammar for a two-stack machine's sequence of transitions can be verified in polynomial bit time. For a deterministic machine a canonical certificate makes verification unambiguous. This gives a concrete proposed bound to test on an explicit time-hierarchy machine. Its accepting runs violate the bound even when it simulates polynomial-time candidates.

## Checking a run

Fix a finite-control machine with two typed stacks and protected bottom markers. The input determines the initial stacks explicitly. Each transition name identifies its source and target states, its guards and its updates. Encode a top-symbol test by popping that symbol and immediately replacing it. An empty test peeks at the protected bottom, which cannot appear in the payload. Two stacks simulate a Turing tape with polynomial overhead. A binary straight-line program (SLP) has terminal rules and concatenations of earlier rules. With g rules the single generated word has length at most 2^g.

Given an SLP over complete transition names, check state continuity and acceptance at the first halt with a finite automaton evaluated bottom-up on the grammar. Project the same word onto the push/pop operations of each stack and prepend pushes for its true initial bottom and payload. With the one-directional reduction that erases a push immediately followed by a matching pop, a projected word is valid exactly when its normal form contains only pushes. Mismatched pops cannot be repaired by later pushes. Each projection has bounded output length per transition and the regular test of the reduced alphabet is efficient. Fact 6 and its construction give a compressed normal form in deterministic polynomial bit time. The two projections therefore check one synchronized computation without a universally quantified time address. [Bertoni and Radicioni, §5.2](https://dmtcs.episciences.org/articles/526/download)

If every YES input has an accepting transition word with at most p(n) grammar rules, for one fixed polynomial p, the language is in NP. For a deterministic machine it is in UP, the class with at most one accepting certificate per input. Use the greedy, non-self-referential LZ77 factorization with leftmost source for ties and a literal only at the first occurrence of a symbol. A g-rule binary grammar yields O(g) phrases and each position requires O(g) bits. Guess only the canonical phrase list, in a self-delimiting encoding with no trailing data. Validate backward nonoverlapping references, then deterministically convert the proposed list to a grammar by prefix substring copying. The AVL construction works on any valid sequence of such copies before the greedy condition is checked. Even a nongreedy list has a prefix length that at most doubles per phrase after the first literal.

For each copy, find the first occurrence of its phrase in the preceding prefix. It must equal the claimed source. Unless at the end, its extension by one symbol must have no occurrence there. For a literal verify absence from the preceding prefix. These tests use polynomial-time compressed substring extraction and fully compressed pattern matching. Use a unique code for the empty trace if needed. A deterministic machine has only one transition word ending at its first accepting halt and that word has one canonical parse. If a decider has small grammars for both verdicts its language also lies in coUP. [Rytter, grammar and LZ factorization](https://doi.org/10.1016/S0304-3975(02)00777-6) · [Lifshits, fully compressed pattern matching](https://arxiv.org/abs/cs/0604058)

## Testing the size premise

Fix a deterministic two-stack interpreter D. On length-n input x it parses a self-delimiting program e from the prefix and simulates e on the entire x for at most 2^n simulated steps. It rejects exactly when that simulation accepts. Malformed codes and timeouts cause acceptance. Programs may tag individual transitions by one of three symbols. Implement D so that after every tagged step its finite control passes exactly once through the corresponding designated state. All other work avoids these states. A homomorphism of the native transition alphabet then recovers the simulated tags. The tags do not affect the decision. A standard polynomial-overhead universal simulation and binary timeout counter keep D within 2^{O(n)} time. The bound 2^n counts simulated steps.

If a polynomial-time program decided D's language, on every sufficiently long input consisting of its own code followed by zeros it would halt within the budget. D gives the opposite answer. Its language is outside P. Hence a fixed polynomial bound on all accepting transition grammars of D would yield a language in UP outside P. Here is a direct test of that quantitative premise.

**Delimiter lemma.** If a generated word contains T distinct records between successive occurrences of a delimiter, it needs at least T binary concatenation rules. Take the lowest common ancestor of the two delimiter leaves of any record in the expanded parse tree. The first delimiter is the last one in its left child, and the second is the first one in its right child. Their intervening record is determined by that production. A fixed bounded-output homomorphism preserves linear grammar size, allowing empty outputs and eliminating empty children. A fixed sequential transducer does too, by storing output and exit state for each pair of a grammar rule and an entry state.

Choose a fixed program which determines the full input length n and initializes an m-bit binary counter, m=floor(n/4), on a stack. A reporting sweep pops every bit onto the other stack, low bit first, and peeks at the bottom. Tag these actual operations by the popped bit and the delimiter. Use one initial tagged bottom peek before counter initialization. Restore the bits in reverse transfer order and increment, using the other stack as scratch. On overflow reject. The records are all 2^m distinct m-bit words. Initialization takes polynomial time, and the sweeps take O((m+1)2^m) simulated steps. Preprocessing using ordinary tape arithmetic can be compiled into the two-stack machine before the literal sweeps. Thus the program rejects within 2^n steps for every sufficiently large n.

On every sufficiently long input bearing this code, D accepts. Its native transition grammar needs Ω(2^{floor(n/4)}) rules by projection and the delimiter lemma. Restricting the proposed size bound to simulations of polynomial-time candidates still fails. For each fixed j≥1 use m=j floor(log₂ n) instead. This gives a genuinely polynomial-time rejecting program. At every sufficiently large length its code prefixes yield accepting native traces requiring Ω_j(n^j) rules. The candidate clocks may have different exponents, while the proposed grammar bound on the one fixed interpreter must cover all of them.

The same emitter can accept unary inputs upon overflow and reject malformed inputs. Its language is in P although its literal accepting runs have the exponential lower bound. On the diagonal's padded rejecting-program examples the correct decision bit is constant, and the record at index i is just the low-bit-first expansion of i. The lower bound concerns the chronological trace of this specified interpreter. It leaves open different computations, proofs of the final answer, and random-access descriptions. No ordinary NP language outside P has been demonstrated.
