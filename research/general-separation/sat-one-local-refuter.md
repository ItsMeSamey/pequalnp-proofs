# A single local SAT recurrence refutation

Fix a total deterministic bit predictor A on valid explicit CNF inputs. Start with the actual input F, including its declared arity, raw clause order, repetitions and signs. At a node G having any occurring name, choose the least such name x. Form G_b by dropping every row containing the literal made true by x=b and deleting every occurrence of its opposite from every remaining row. Keep the declared arity and the order of surviving rows and literals. This convention drops a row containing both signs on both branches and preserves empty clauses and duplicate rows. Each child loses x and introduces no names. The root-to-leaf length is therefore at most u, the number of distinct occurring names of F, even when arity is given in binary and unused names are numerous. Every node is a subsequence restriction of F and uses at most its original literal occurrences, rows and name-bit lengths. Counts and headers can be canonically re-encoded in O(|F|) bits at each child; use the original presentation for the root query. At an occurrence-free leaf, the truth value is one iff there are no clauses, because any remaining row is empty. Unused bits can take arbitrary values. At every internal node SAT(G)=SAT(G_0) OR SAT(G_1).

A local certificate gives a node G with either a terminal answer differing from that constant or an internal answer A(G) different from A(G_0) OR A(G_1). Recompute the children and the at most three deterministic answers. To certify that this is a restriction of a specified root, also give F and the chosen-value path of at most u bits. The verifier reconstructs the successive nodes, so the path adds no list of large variable identifiers. The local certificate then has O(|F|) bits, including a chosen node if desired. For fixed A running in time t on inputs of length O(|F|), verification costs poly(|F|)+O(t(O(|F|))) with a fixed implementation of A. Every local discrepancy proves a wrong SAT prediction somewhere among at most three named formulas. It does not in general identify the wrong answer at the original root.

**False negative.** Given A(F)=0 and a verified satisfying model of F, only its bits on occurring names need be written. Follow the model's branch while A at the current node is zero. If the selected child answers one, its zero parent violates the OR recurrence regardless of the sibling. Otherwise descend. If there is no crossing, the final node is satisfied by the model but has answer zero. One can also construct the entire branch ignoring A; if the last answer is one, bisection between the opposite endpoint answers finds an adjacent zero-to-one crossing with O(log(u+1)) additional predictor calls, even if the intermediate answers are nonmonotone. Testing the original model and constructing restrictions take polynomial time in |F|.

**False positive.** Start with A(F)=1. At an internal node query the two children. If neither answers one, output that wrong-OR node. Otherwise descend to a child answering one, choosing deterministically on ties. A false terminal with answer one is a local certificate. A true terminal instead supplies a verified model of the root by the path choices, with arbitrary defaults for names that disappeared; this outcome is impossible if F is unsatisfiable. Consequently a genuine false positive always yields the certificate in at most 2u+1 predictor queries without providing any UNSAT proof. From a merely positive prediction the search yields either a checked root model or a local discrepancy; even a satisfiable root can lead to a discrepancy along the chosen branch.

Induction on remaining occurring names shows that any predictor disagreeing with SAT somewhere has one of these finite local counterexamples. If A is a fixed polynomial-time machine, the local relation has a polynomial verifier with its runtime exponent. No single fixed polynomial bound for all indexed machines, nor a polynomial-time procedure locating a disagreeing root for an arbitrary machine, follows from this lemma.
