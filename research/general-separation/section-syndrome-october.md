# Counting original assignments through chronological multi-output sections

Consider an original ordered NAND DAG on n inputs with s gates. A certificate lists some inputs as public and partitions the others into ordered private banks t_i of dimensions d_i. For each bank it names several raw output wires. The [compiler](section_syndrome_cnf.py) checks the certificate in polynomial time in n, s and its description. A failed certificate is a decline. The following counting clock uses the fixed-density counting theorem in the [pinned October source](https://github.com/openai/math/blob/42907c9e999cc00d6abe7a50bfc1023250edd1b9/preprints/The-Exponential-Time-Hypothesis-is-False-October-25-2026/build/main_full_version.tex). The Python source produces exact CNF instances and lifts witnesses; it does not bundle or invoke that counting engine.

**Section certificate.** With all public bits and earlier private banks fixed, each current cut has the form M_j t_i + g_j, where g_j depends only on that fixed prefix. The verifier certifies this by tracing the actual gate list. An input in the bank has its unit slope, public or earlier inputs have zero slope, and later inputs are initially unavailable. Previously certified ports may be used as zero-slope atoms. Inverters flip the offset, and a recognized four-NAND XOR adds slopes and offsets. An otherwise opaque NAND whose two parents have certified zero slopes introduces a formal offset atom for that particular original wire. Unavailable values remain unavailable. Equal formal tokens always stand for equal bits. No semantic identity between different opaque gates is presumed.

Select independent slopes, of rank r_i, by row elimination. Their actual output wires become r_i freely chosen quotient inputs. When a slope eliminates to zero, apply the *same* row operations to the offsets. The residual may involve a constant, public inputs and previously exposed ports. Reject any other uncancelled offset token. Emit gates for the exact dependent output from its basis values and these residual terms, charging every XOR and inverter. Finally trace the original output backwards, stopping at all exposed ports and public inputs. Copy each remaining NAND once, preserving ordered edges and sharing. Reject any private primary reached without passing through a cut. This verifies the entire output dependency, including fanout. The resulting quotient has N' = number of public bits + Σr_i primary bits and g explicitly constructed gates. Neither g nor verification cost is estimated merely from a section count.

**Exact original count.** For each quotient word fix the public bits and all independent section outputs to its values. Given *any* previously chosen private banks compatible with that prefix, the current bank must solve a consistent rank-r_i affine system and has exactly 2^(d_i−r_i) solutions. In particular a future offset may reread an older private coordinate that was never exposed; the number of next-bank choices remains constant. By induction each quotient word has exactly 2^(n−N') original preimages, on all of which the copied output agrees. Multiply the quotient answer by this integer. To lift, evaluate independent cut wires on the partially fixed original circuit with the current and later banks zero. Subtract those offsets, solve the current bank by Gaussian elimination, and repeat. The returned original word is checked on the raw circuit. This deals with rank-zero banks and unused original inputs.

**October leaves and the branch budget.** Optionally choose b distinct quotient input or gate wires, and enumerate their bit assignments. At a guessed input use the guess. At a guessed NAND output with incoming literals u,v, a one guess contributes the check ¬u∨¬v, and a zero guess contributes both units u and v. Then use the guessed bit downstream. Unguessed gates use constant propagation or a NAND equivalence with three clauses and one auxiliary variable. Pin the final output. Thus raw or reduced verification gates cannot be dropped just because their output was guessed. The declared unguessed primary bits include unused ones. All auxiliaries are functionally determined, and binary search or linear scanning of guessed gate values is unnecessary. Every accepting quotient word belongs to exactly one branch. If density exceeds five clauses per variable, add fresh zero-pinned variables until it does not. Such padding costs polynomial size and has unique extension. Empty clauses can be recognized immediately; width-one and width-two clauses can repeat a literal if exact three-literal syntax is needed.

Write V_β for the actual padded variable count on a branch. The clock, with constant-size instances handled directly, is

    poly(n+s+certificate size) · Σ_β 2^(A V_β / sqrt(log₂(max(2,V_β)))).

Use b=0 when branching offers no smaller leaf. For example b≤n−c n/sqrt(log₂ n) and V_β≤Cn for every branch gives 2^(n−Ω(n/sqrt(log n))) polynomial overhead when fixed c is sufficiently larger than AC. With b=0 and g=O(n), the clock is 2^O(n/sqrt(log n)) times polynomial overhead. One can visit branches sequentially. An accepting quotient assignment can be recovered by fixing its unguessed primary bits one at a time and testing positivity with the same checks. Substitution preserves the variable budget if fixed primary slots are retained and constrained by units; re-pad to fixed density at most a constant factor. At most V_β unguessed primary variables need pins, so this changes only the counting constant in the exponent for witness recovery. The Python branch_cnf emits leaf formulas; the witness self-reduction is part of the counting reduction.

**Two matchings with no reduction in primary dimension.** The function matching_pair_source(d) constructs a NAND source with n=2d² raw bits in d² successive two-bit banks. For each position j it produces three cut wires

    X_j = a_j XOR g_j,  Y_j = b_j XOR h_j,
    Z_j = (a_j XOR b_j) XOR (g_j XOR h_j).

The offsets are separate NAND chains over the nearest min(j, floor(log₂(d²))+1) preceding raw coordinates from each lane. They are computed on actual older primary bits, with arbitrary later reuse. The third wire is produced in a separate circuit; formal cancellation verifies Z_j=X_j XOR Y_j. The quotient pays for this XOR. From the three cuts the core enforces (X_j OR Y_j)=Z_j at every position; this forbids overlapping ones. It checks exactly one one in each row and column of both matrices by recording whether a prior one occurred and rejecting a second. Both tests have linear total cost. The explicitly generated source has Θ(n log(n+1)) NAND gates as d grows, while the quotient has g=O(n) and N'=n. All 2^n joint X,Y matrices occur because the bank map is triangular and bijective. Any representation recovering those joint wires from r Boolean coordinates requires r≥n. The improvement therefore comes from removing the chronological offset circuitry while retaining verified multi-output relations, even with no reduction whatsoever in primary dimension. This is a separation of structural descriptions, not a lower bound on all alternative representations of the matching decision bit.

The exact original answer is d! times the number of derangements of d elements: choose the first permutation matrix, then a second with no common entry. This also gives an independent check when the generated source is run. The argument neither calls the matching-count formula as a subroutine nor assumes a promised answer. The earlier functional-cone construction uses a small leaf after conditioning; here the leaf is obtained from a different, explicit algebraic certificate. No impossibility for other cone partitions is claimed.
