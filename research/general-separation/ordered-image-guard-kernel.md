# Projecting private guards from an ordered-image phase formula

On the strict private-guard family, the source kernel removes every six-row guard and its now-redundant attachments without being told which names belong to the original SAT core. It preserves feasibility and returns a checked original assignment from any residual model. The same implementation accepts general sparse signed CNFs and projects further pieces when it can verify their boundaries and solve every pinned local formula by 2-SAT. An unresolved residual may retain the full difficulty of the input core. ## One exact projection

Given private IDs U, collect **all** current clauses meeting U. Let B be all their other variables and require |B|≤2. For each of the at most four assignments to B, substitute its bits into the collected clauses. Decline this step if any remaining clause has width greater than two. Solve the residual 2-CNF for each tuple. For a feasible tuple store one private model, with unused private bits set to false. For an infeasible tuple add the clause blocking exactly that tuple of boundary bits. At empty boundary this is either a solved component or a contradiction. Retain all untouched clauses and normalize by tautology deletion, deduplication and signed subsumption. At most four clauses are added per successful step.

The retained boundary clauses describe exactly which tuples extend. For any surviving model the matching table entry restores a satisfying assignment to the removed clauses, and the untouched clauses use no removed variable. Later steps can eliminate earlier boundary variables, so the implementation restores steps in reverse order and checks the lifted assignment against its original input rows. Tables store one extension per tuple; they do not give fiber counts. This is the usual separator projection. The source-specific work is recognizing the pieces after renaming and independent sign changes, exposing this particular core, and lifting through both representation changes. ## Candidate discovery and residual size

The first pass counts occurrences on the supplied rows and finds connected components of the normalized primal graph induced by variables occurring four times. It tests size-three components with two external neighbors, then rechecks all incident rows against the six-ternary pattern before projecting. The initial candidates use the initial graph and occurrence counts. On the stated strict family each private variable occurs four times and meets only its two siblings and its graph endpoints; each endpoint occurs in at least nine gadget rows. An attached core or marker variable cannot pass the private-triple check, since an attachment clause contains it and two graph vertices. Thus each genuine triple forms its own candidate. On general inputs the exact projection check still makes a successful step sound.

Each genuine table forbids precisely the signed counterpart of the original endpoint tuple 11. The resulting binary edge clauses subsume the path and attachment rows. The remaining graph component is satisfiable binary, and the three-variable marker clause is independent. The second pass enumerates all cuts of zero, one or two active primal variables and tests each connected component after deleting the cut. The actual boundary is recomputed from clauses. A whole binary component is eligible with empty boundary; the ternary marker is eligible after cutting one of its variables and then simplifying. Successful steps remove at least one active private variable and introduce no new IDs. Core pieces may also be projected. After the family has separated, a core-internal step introduces at most four clauses, and there are at most as many such steps as initially used core variables. Thus the final noncontradictory residual uses at most O(core rows + used core variables) clauses and used IDs. The original declared arity remains available to the lift. This bound concerns the residual, not the cost of solving it.

For V active names one discovery round examines O((V+1)²) candidate cuts and at most V components per cut. Each graph traversal, complete incident-row scan, pinned 2-SAT call and normalization is polynomial in the explicit description. The loop has at most V successful rounds plus one unsuccessful round, and throughout it adds at most 4V clauses in total across successful steps. The initial occurrence-four scan and all witness tables also fit polynomial time and space. The implementation uses exhaustive small cuts; no SPQR running-time bound is required.

## Physical input and witness

For physical ordered-image input F, the adapter first calls the certified phase decoder. It passes through a decline or other noncertified result. On success it takes the actual signed phase clauses Q and applies the source kernel, obtaining a residual on surviving phase IDs. A second view names the same residual variables by positive representative physical edge IDs. A residual model in either namespace first lifts to a complete model of Q. The adapter then evaluates each recorded signed edge literal at that phase assignment and fills the original-edge word, checking all recovered source clauses. The binary-residual decision entry point returns a lifted original word on success, zero on contradiction and unknown on unresolved higher width. The projection entry point also permits an external core solver followed by the same checked lift.
