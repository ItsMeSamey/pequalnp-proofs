# Wide scopes can force actual private auxiliary variables

Let n private row circuits compute the XORs of cyclic windows of length L=floor(beta log2 n) of the n physical bits, beta>0 fixed small. Use a private binary chain for each row. Then there are nL raw occurrences, each physical bit occurring in exactly L windows. An O(n)-gate core can read row outputs; total size fits any specified B n log n by choosing beta small. An exposed-row local compilation must preserve the row behavior for every assignment to its surviving raw bits before the core is attached. It may not share existential auxiliaries between different rows. The following is a restriction on this compilation model.

After pinning n-k raw bits, let r_i be the number remaining in row i, so sum_i r_i=kL regardless of the pinned values and locations. For a uniform fixed width w, independently encoding the parity relation of a row on these r_i bits requires >=r_i/w-1 private auxiliaries even when only existence of an extension matters. Indeed pinning the row output to zero or one yields parity or its complement; for r_i=0 the bound is vacuous. This is the width lower bound of Emdin, Kulikov, Mihajlin and Slezkin, https://doi.org/10.4230/LIPIcs.MFCS.2022.47 . Summing over rows gives >=kL/w-n auxiliaries in any such existential compiler. It is stronger than a lower bound on the lengths of literal truth tables.

The debit persists when b internal row-chain outputs are additionally guessed and their defining constraints retained rather than replaced by unverified independent inputs. In a locally consistent branch, pin the final output of each row to any locally feasible value. Its surviving physical variables are constrained by independent segment parities between consecutive pinned prefix sums (empty segments impose no cost unless contradictory). If b_i interior signals were guessed, this cuts the raw cube by at most b_i+1 parities, yet every single-bit flip in that row violates some parity. Consequently the row has at least 2^{r_i-b_i-1} allowed words, all isolated. Each fixed auxiliary valuation in a width-w encoding gives a width-w CNF with isolated solutions only, at most 2^{r_i-r_i/w} by the satisfiability coding lemma. Covering this row requires at least r_i/w-b_i-1 private existential bits. Summing gives >=kL/w-b-n across rows. If an entire branch is already inconsistent it can be discarded; this lower bound applies on consistent branches to exact individual row semantics. Section 3.2, Lemma 6 of the cited paper states this isolated-solution bound and credits Paturi, Pudlak and Zane, Lemma 2. The coding proof is in the original paper: https://scholar.lib.vt.edu/ejournals/CJTCS/cjtcs-mirror/articles/1999/11/contents.html .

A branch-only argument that consumes n-k+b bits needs k-b=Omega(n/sqrt(log n)) to claim that much saving before the leaf cost. Then k>=Omega(n/sqrt(log n)) and kL/w dominates n+b for fixed w and b<=k; the above lower bound is Omega(k log n). Thus the October fixed-width leaf clock based solely on the resulting variable count is not a certificate of an o(k)-exponent leaf. There is no claim that any particular leaf actually takes that clock, that all guessed branches survive, or that globally shared encodings obey the private-sum lower bound. These parity rows are amenable to Gaussian elimination across the entire circuit when the core permits it; the physical row behavior is not an unrestricted SAT hardness result.
