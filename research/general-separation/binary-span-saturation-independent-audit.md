# Independent audit of binary consequences from the residual miss span

Let B denote the complete normalized binary background on the original variables and R the original normalized ternaries. On Ω=Mod(B), write W for the binary span of the indicator that each row of R is false. The full models are exactly the points where every member of W is zero. The [rank projection](cnf-binary-background-rank.md) evaluates functional rank on Ω rather than on the unrestricted cube.

For an empty, unary or binary candidate D, first test that its false indicator f_D is nonzero on Ω. This is binary satisfiability of B with the negation of every literal of D pinned. Skip Ω empty as an already proved zero. For nonempty Ω and empty D the indicator is identically one. Introduce three distinct new variables, all pinned false by three unit background clauses, and append one residual row consisting of D followed by exactly 3−|D| different positive fresh literals. The padded background has one lift per original model, its old rank is unchanged, and the new ternary miss equals f_D there. Thus exactly one augmented-rank comparison per candidate tests f_D in W. The pins are essential; without them the padded test can gain a rank from variation of new coordinates. The original arity plus three needs only logarithmic identifier overhead. Fresh variables remain entirely within projection calls, with no return through the solution or count interface.

When f_D belongs to W, every original full model satisfies D. Adding all such nonzero D simultaneously to B therefore preserves exactly the original model set on the original coordinates. The dimension of W after the batch is its dimension after restriction to the common zero set of these functions. The kernel of restriction contains each of the admitted nonzero functions. Thus every successful batch drops the rank by at least one; a larger decrease is allowed. Functionally equal candidates, or linearly dependent combinations of them, do not justify a decrease per clause. If the new background is empty, the rank on it is zero. If 1 belongs to W, the empty D can be added immediately and the entire formula is inconsistent. Conversely failure to derive 1 is not evidence of satisfiability. Skipping semantically zero candidates prevents vacuous batches; at rank zero and nonempty Ω no nonzero candidate is admissible. At most initial rank r₀ batches and one unsuccessful final scan are needed. Enumeration on all u mentioned IDs requires 1+2u+4 binom(u,2) trials per scan. A genuinely unmentioned variable cannot occur in a new nonzero dependent miss: toggling it changes that miss somewhere while preserving every old miss and the current background.

**A necessary retest.** With no initial B take ternaries (¬a∨¬b∨¬c), (¬a∨¬b∨c), (¬a∨¬d∨b). Their unrestricted miss span is generated by ab, abc and ad+abd in Boolean multilinear coordinates. Independence of distinct squarefree monomials implies its degree-at-most-two part is exactly the line through ab. So only (¬a∨¬b) is derived on the first scan. On ab=0 the last miss becomes ad and yields (¬a∨¬d), which failed on the first scan. The rank sequence is 3,1,0. These new binary consequences are exact, and the full model set on a,b,c,d is preserved.

**Terminal cost.** Run the binary-background rank solver on the original rows plus derived clauses. Its sparse true IDs assign every absent ID false, so replay against every original row is direct. For the corresponding count backend use *final* active-variable count h, residual rank r and discovered feedback-set size f in the final binary constraint graph. Saturation can increase h or f; rank decrease alone does not promise decreased counting time. The terminal full cost is polynomial preprocessing plus at most min(2^h,(h+1)2^(r+f)) charged terms, including witness recovery as in the [counting note](cnf-binary-background-count.md). Output mantissa and unused-variable exponent are on original IDs because derived clauses add no new declared or used variables beyond the raw input. Higher-width normalized rows are outside this saturation projection. No native run formed part of this audit.
