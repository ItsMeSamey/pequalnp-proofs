# Two clocks for finding SAT self-reduction counterexamples

A total computable cutoff from a polynomially clocked candidate’s index exists exactly when P≠NP. Polynomial-time discovery below a supplied wrong prediction exists exactly when P=NP. These tasks give the searcher different inputs.

## Inputs and local tests

Use explicit ordered CNF with binary declared arity, clause counts, literal counts, and signed one-based variable names. Encode each nonnegative integer j with the Elias gamma code of j+1, which is self-delimiting, has nondecreasing length, and can be parsed and written in linear time in that length. Preserve row and literal order, repetitions, tautologies and empty rows. The SAT language and every candidate wrapper reject malformed strings. At an internal node restrict the least occurring name to each possible bit. Drop satisfied rows, delete falsified literal occurrences and retain the arity. Headers never increase and surviving literals are subsequences, so neither child is longer than the parent. A path has length at most the number u of occurring names, including when the declared arity is exponentially larger. At a leaf no names occur, and the leaf is true exactly when it has no rows.

The test at G compares A(G) with this terminal truth value or with the OR of its two child answers. Induction on remaining names gives equivalence between passing all tests and deciding SAT. To locate G below a supplied root F, output the path bits. Reconstructing and checking it costs polynomial bit work plus at most three candidate evaluations of length at most |F|. A discrepancy at G certifies an error somewhere in its local test. [Local refuter, SHA-256 b1ae9bd35323c11bcd3adf776b8a084a762c89b0a558313a0531abb39443c8e7](sat-one-local-refuter.md)

## Cutoff from an index

Enumerate bit programs e with binary exponent k and clock (L+2)^k at input length L, returning zero on timeout. Every polynomial-time language has a representative. Require a total computable function f(e,k) such that every wrong candidate has a failed local test on a valid formula of length at most f(e,k). The function must terminate on correct candidates, with unrestricted output there.

For any effectively presented candidates and decidable tests indexed by strings, such a cutoff exists precisely when the set of candidates passing all tests is decidable. Given the cutoff, exhaust the finite tests up to its value. Given the decider, return zero on passing candidates and otherwise search by increasing length until the first failure. Without the decider the latter search is always partial computable and always terminates on wrong candidates.

If P≠NP, every candidate is wrong and the search is total. If P=NP, fix a correct polynomial-time SAT decider D. Compile any blank-input machine M into a candidate that simulates M for |x| steps, rejecting if it has halted and returning D(x) otherwise. A nonhalting M yields a correct candidate. A halting M yields a wrong one because satisfiable formulas, for instance repeated positive unit rows, occur at arbitrarily large lengths. Deciding the correct indices would decide nonhalting. The correct-index set is co-r.e.-complete in this case.

One sufficiently large common exponent works across the compiled candidates. On a fixed multitape model use fixed-alphabet source machines, hardwire M’s transition table into finite control, and scan one input symbol per simulated step with a separate simulation tape. The overhead and D’s polynomial bound are uniform. A fixed polynomial tape-model conversion can also be absorbed. Choose k large enough for (L+2)^k to cover constants even on short inputs. This construction avoids an index-dependent interpreter startup. If M first halts after t steps, candidate and D agree at all lengths below t. Child nonexpansion ensures the first local failure has length at least t. This is a delayed-halting specialization of the classical noncomputable cutoff argument. [Radó](https://doi.org/10.1002/j.1538-7305.1962.tb00480.x)

## An unconditional lower bound in the binary index encoding

Fix one program E that deliberately waits at least 2^L steps on every valid word, then decides SAT by full enumeration on the occurring names. It finishes within C·2^L(L+2)^c for fixed C,c by scanning the formula per assignment and using an L-bit delay counter. Clock E at (L+2)^k. For sufficiently large k it is correct at every length L≤floor(k log₂(k)/4). Indeed for L<√k the logarithm of its runtime is at most √k+O(log k)<k. For larger L in the given range, L≤(k/2)log₂(L+2), and the remaining factor C(L+2)^c fits within (L+2)^(k/2). Yet all sufficiently long satisfiable padded formulas time out and receive zero. The first failed local test is therefore longer than floor(k log₂(k)/4). With E fixed and k in binary this exceeds every polynomial in the candidate description length. These are actual wrong candidates under either complexity hypothesis. The result leaves open the growth rates achievable by total recursive cutoffs under separation. The totality argument alone neither yields a primitive-recursive upper bound nor excludes one.

## Discovery below a supplied wrong prediction

Require one deterministic polynomially clocked oracle procedure with explicit input F and query access to A. Whenever A(F) differs from SAT(F), it must output a path from F to a failed local test, without being supplied a model or a certificate of root error. Its output is unrestricted off the promise. A bound promised only on wrong roots can be enforced by truncating at that polynomial on all inputs. Charge ordinary input, query construction and output bit costs separately from unit-cost replies.

If P=NP, use a fixed polynomial-time SAT decider. At a wrong node either the local test fails, or some child is wrong because the two OR values differ. Query A and the SAT decider on the children to choose such a child. A wrong leaf directly fails. This locates the path with polynomial bit work and at most 1+2u candidate queries of length at most |F|. Replacing oracle replies by a fixed candidate implementation of runtime t adds O((u+1) max_{j≤|F|} t(j)) time. Its polynomial exponent may depend on the implementation.

Conversely it suffices that the finder work for the fixed all-zero candidate. Its internal OR tests always pass, and the failed leaf tests are exactly the true leaves. Every satisfiable F is a wrong root and must produce such a path. No unsatisfiable F admits one. Simulate the finder with immediate zero replies, verify the returned path and accept exactly when it passes verification. This decides SAT in P. The existence of short paths and a polynomial checker alone supplies no efficient finder. Neither characterization resolves P versus NP.
