# Exact signed read-twice evaluation over F₃

The entry point in [signed_f3_core.py](signed_f3_core.py) is evaluate(formula, point, max_states=...). Each occurrence (i,p) means the literal satisfied when bit i equals p. Coordinates are integers reduced modulo three. Every occurrence in the original formula counts against the bound of two per variable, including tautologies and within-clause repetitions. Invalid input raises an exception. An empty clause does not short-circuit raw validation. Empty conjunctions evaluate to one. Arbitrarily many duplicate empty clauses are legitimate. Identical nonempty raw clauses repeated more than twice violate the input restriction. After validating raw reads one may collapse repetitions, discard tautologies, specialize Boolean coordinates, drop satisfied clauses and merge identical surviving clauses, since these operations preserve the Boolean predicate on all free inputs. An empty surviving clause yields zero.

For each remaining clause c use a bit a_c indicating that inclusion-exclusion selects its failure, with unary weights (1,−1). Each free variable has interpolation weights (2,2). If it occurs once, multiply the occupied unary by 2. For two occurrences, ordered by clause, the matrix in row order 00,01,10,11 is (1,2,2,2) for equal polarities and (1,2,2,0) for opposite polarities. These are respectively the consistent and contradictory simultaneous false-literal requests. Multiply parallel matrices entrywise. An unused free variable contributes one. These rules cover mixed parallel polarities and matrices or unary products with zeros without any division. Summing the product of all factors over clause bits equals the original interpolation sum.

The code chooses minimum current degree with original clause index as tie-breaker and records each removal with fill edges between every pair of its neighbors. For an elimination with d remaining neighbors it enumerates the 2^(d+1) joint assignments and sums over the eliminated bit. The resulting table on d neighbors preserves the partial contraction at every boundary assignment. An empty boundary contributes a scalar. This gives the following exhaustive cases in each connected component of the simple clause graph.

* An isolated vertex contracts to its unary sum. Leaves transmit two-entry tables to their neighbor, covering all trees.
* A nonempty degree-two core can be a cycle, possibly with previously removed pendant trees. Eliminating a cycle vertex passes a binary table between its surviving neighbors. A triangle combines that table with an existing edge. More generally every degree-two series elimination uses this same rule, including ones along paths joining branching vertices, even if the new table has zero entries.
* When every remaining degree is at least three, the same recurrence uses a table on all neighbors. Repeated elimination returns to the previous cases as degrees permit. No bound of two on clause-graph degrees follows from the read restriction alone. Disconnected components multiply; an exact zero component makes the total zero.

Writing w for the maximum recorded later-neighbor count, a surviving graph needs B=2^(w+1) assignment states for its largest bucket. A budget smaller than B yields status unknown, reason state_budget, required B and available budget before creating any exponential table. Constant answers obtained during normalization need no bucket. This is a per-bucket assignment cap, not an aggregate memory or time limit. Isolates need two states, nontrivial forests at most four, and components of maximum degree two at most eight. In particular raw width at most two gives maximum degree at most two. The simple implementation rescans factors and maintains a dense fill graph; it does not claim linear work on forests.

For input bit length L with explicit coordinate list, at most O(L) factors exist at any stage, with scopes of length O(L), and O(L) elimination steps. Polynomial planning precedes enumeration. Direct word-level accounting gives O(poly(L) B) operations and O(poly(L) B) storage, including Python integers with O(L) bits for addresses. For a sequential bit model without constant-time access to exponential tables, one conservative simulation scans the whole table store for each indexed lookup, yielding O(poly(L) B²) bit time and O(poly(L) B) bits. The planner's refusal path takes polynomial bit work and space in the explicit inputs including budget. This cap does not bound preprocessing of long input, or validate an optimal induced width.

At all-2 the answer is (−1)^n times the number of satisfying assignments modulo three. With Boolean pins the exponent counts every remaining free coordinate including unused coordinates. A zero residue can occur on a satisfiable formula, for instance the single clause x OR y has three models. Nonzero decision is Mod₃P-complete already on the width-three balanced instances of [the exact reduction](f3-balanced-read-twice-point2.md). Here balanced means one occurrence of each polarity per variable. For width two the clause graph has maximum degree two, so the path and cycle cases above apply. The independent [raw oracle](../site-team-01/signed-read2/independent_oracle.py) checks original assignment counts.
