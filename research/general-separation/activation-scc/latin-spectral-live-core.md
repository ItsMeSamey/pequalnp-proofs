# An occupancy interface with live physical stars

Let L be the preimage of an s-dimensional subspace J of G/H. Require exterior H-cosets to be monochromatically saturated. Inside L all physical false masks can vary, including original stars crossing the boundary. The guard saturation bound needs a fixed old guard; this algorithm uses only the stated exterior requirement, or a separate proof that it is forced.

Guess only three permitted-presence bits per H-coset inside L, at cost 2^{3·2^s}. A zero forces the rail/coset empty; a one only allows occupancy. Exact presence bits are among the guesses. Build covering-complement Gallai templates on the exterior as in latin-spectral-saturation.md. These enforce all wholly exterior triples.

Each mixed zero-sum triple has one position inside L. Given j in J and an allowed inside rail, forbid any pair of exterior colors on the other two rails at quotient positions y,y+j. This is one binary clause for each orientation. It is necessary under exact-occupancy bits since both exterior rails are full: for any fixed false site inside and any false site on the first full exterior rail, their sum is false on the second full rail. It is sufficient for all guesses because actual presence is contained in permitted presence. The j=0 case causes no problem. No mixed constraint sees the actual inside masks beyond these bits.

Put exterior conditions, all pins/stars, zero-presence units, and mixed binary clauses into one 2-CNF. Existentially project variables unused by the core onto its physical representatives by resolving on each forgotten variable then deleting its clauses; all resolvents have at most two literals, so at most O(N²) distinct clauses exist per stage. Handle the empty clause as inconsistency. Remaining independent obligations are the actual inside ternary clauses. Solve them TOGETHER with the projected 2-CNF. Given any such core witness, pin retained variables in the original exterior 2-CNF and run 2-SAT again for a compatible exterior witness. Replay all physical constraints. This needs no separate guesses of crossing star representatives.

Per exterior flag skeleton there are 2^{3·2^s} core calls. The cost per call includes polynomial projection plus an exact core solver with binary side constraints: for example use the smaller of 2^v assignments of relevant core representative bits and 3^l choices of a true literal per surviving ternary followed by 2-SAT. Exterior skeleton cost Q^{O(4^s log²(2Q))} for Q=|G/H|. If a mass threshold also applies, enforce it inside the core call (full exterior mass is fixed), e.g. enumerate v bits; plain 2-SAT leaves need not maximize mass. Compared with full inner mask enumeration the interface drops |H| from its exponent and exploits core structure, but still charges hard core decisions. A composed exterior summary is a disjunction of projected binary formulas. Independent joins may multiply the number of alternatives; per-alternative quadratic clause size does not remove that cost.
