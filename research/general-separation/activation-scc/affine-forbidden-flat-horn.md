# Signed Horn recognition for forbidden affine flats in a common bit chart

After solving the given binary affine equalities, write x=x0+Bt using independent parameters. A forbidden combination of specified affine readouts is an affine system Mt=b in this chart. This includes the two false-literal requirements for a binary clause. An inconsistent system excludes nothing; an all-space system rejects every assignment. Discard zero columns only for analyzing that factor. All factors continue to use the same actual t.

Choose a common polarity s, y=t+s. The complement of one flat is closed under bitwise meet if and only if every forbidden assignment has at most one zero among its active columns in y coordinates. Indeed, if a forbidden assignment has two such zeros, switching on either one independently violates an affine equation and yields two allowed words whose meet is the forbidden word. Conversely if two allowed assignments meet in a forbidden word, each must differ from it on at least one active column, since changes on inactive ones alone preserve membership. The two sets of changed active positions are disjoint.

This yields complete polynomial recognition over all polarity flips in a SUPPLIED linear chart. For each factor, each pair of distinct nonzero columns i,j, and each pair of values u,v, test by Gaussian elimination whether Mt=b is consistent with t_i=u,t_j=v. If so forbid the combination s_i=u,s_j=v by one binary clause. Solve the union of these constraints by 2SAT. Failure rules out all common polarity choices which make every individual factor meet closed in this chart. It does not rule out satisfiability or a Horn conjunction resulting from interactions between factors.

On success the forbidden patterns on active columns form an affine set inside the all-ones point and its immediate Hamming neighbors. These points are affinely independent, so the affine set has dimension at most one and at most two patterns. Compute those patterns by elimination, then forbid each by a clause over the active variables in y. Each clause has at most one positive literal. Horn satisfiability with physical traceback gives t=y+s, then x=x0+Bt. The procedure handles arbitrary codimension and does not expand a dense truth table. Affine membership, polarity, and any reconstructed solution are tested on the original coordinates.

For a rank-two constraint this permits three active variables when its affine kernel on the active triple flips two together. For instance the implication t_k=1 implies t_i=t_j has forbidden equations t_k=1 and t_i+t_j=1, producing two Horn clauses in the given chart. It is not bijunctive in these coordinates: the three allowed words (k,i,j)=(1,0,0),(1,1,1),(0,0,1) have forbidden majority (1,0,1). This generalizes ordinary per-clause Horn renaming to affine forbidden flats. No unrestricted linear-chart recognition or unrestricted SAT algorithm follows.
