# What arbitrary shared witnesses buy for a literal 3-CNF

Normalize each clause by removing repeated literals and discarding tautologies. A deletion chart keeps each clause of width at most two, and deletes one literal in each remaining ternary clause. Let C(F) be the minimum number of deletion charts whose union covers the satisfying assignments of F. For nonempty model set, the minimum possible strong 2-CNF backdoor size over all existential CNF extensions preserving the original assignment coordinates is exactly ceil(log₂ C(F)), without a bound on extension size. The minimum is zero when F is unsatisfiable.

Any such extension with k selected backdoor variables gives at most 2^k projected branch relations Q. Each is bijunctive, including fixed values of original coordinates in the backdoor. This follows directly by existentially eliminating private variables from a 2-CNF via resolution, which creates only clauses of width at most two. Consider any nonempty Q and any original ternary clause. The projection of Q onto its three variables is still 2-CNF-definable and excludes the unique falsifying tuple. At least one width-one or width-two clause defining that projection is false at that tuple. All its literals therefore occur in the original ternary clause with the original polarities. Extend a unit to any two-literal subclause of the original containing it; all assignments of Q satisfy this subclause. Perform this choice independently on all clauses. The resulting deletion chart contains Q and is contained in Sat(F). Thus C(F)≤2^k even with shared auxiliaries.

Conversely, choose any covering list of c charts. Use ceil(log₂ c) raw selector bits, map any unused codes to a listed chart and gate the binary clauses of that chart by its code. A conditioned pair can be encoded in width three using the prefix-AND construction of shared-backdoor-cover.md (or directly as a long clause if width three is unnecessary). This construction uses O(c·m·(1+log c)) clauses and preserves all original assignments under projection. In particular covers of polynomial size give polynomial-size extensions; determining whether a proposed chart list covers all original models is a separate task.

Equivalently, each satisfying assignment prescribes one forbidden deletion position at each ternary clause where exactly one literal is true. Its other clauses forbid none. A chart accepts that assignment precisely if it avoids every prescribed position. For disjoint positive triples all ternary singleton patterns occur, so C(F) is exactly the total domination number of the direct graph product of m copies of K3: boxes are its open neighborhoods. [Prior work on domination of direct products](https://arxiv.org/abs/1908.02445). The identification here follows from the cover equivalence.
