# Critical-trio flags on original signed-star instances

Let q=2^d. Use the same false supports A,B,C, physical representant bits and true pins as latin-density-quotient.md. If a model exists with M=|A|+|B|+|C|>q, the following deterministic q^{O(log q)} algorithm returns a physical model (possibly with smaller M on unrestricted inputs). It is an exact ordinary decision algorithm on the checkable class where every boundary-compatible assignment has M>q. Additionally, existence with the explicit threshold M≥q+t, t≥1, is decidable on all inputs in time 2^{O(sqrt(q)+(log q)^2)} poly(input).

Handle empty rails separately as in the quotient solver, including original mass maximization. A nonempty-rail trio with M>q extends by finite inclusion to a maximal nontrivial critical trio, disregarding the stars while extending only its ALLOWED false domains. Physical subsets and their constraints are subsequently reinstated. Theorem 4.5 of Boothby–DeVos–Montejano describes the extension by a descending subgroup chain of impure beats or chords ending in a pure beat or chord. In elementary exponent two every cyclic proper quotient has order two, excluding a pure chord as both nontrivial sequences cover the quotient. For an impure chord both A and B include the entire outside coset, and A includes an inside point; thus A+B covers the outside coset, contradicting the required nonempty outside C. [Primary proof and definitions 4.1–4.5](https://arxiv.org/abs/1301.0095)

Enumerate all chains of nested proper subspaces, including terminal subgroup J, by ordered bases of F₂^d and choices of retained ranks. At each level enumerate the rail permutation and translations of the three active cosets that sum to zero in current coordinates (at most q² choices); track these transformations back to the original physical labels. This enumerates every similarity allowed in the cited theorem in q^{O(log q)} time. In normalized coordinates G' relative to H the distinguished A is contained in H. For an impure beat, for each nonzero coset of H in G' choose one fresh Boolean switch assigning that coset to the B or C allowed domain, forbidding the other. Only the three copies of H recurse. The rule is sound because A is in H, so an outside B contributes only in its own coset on C; it is complete by Definition 4.3 and maximality. For a pure terminal beat relative to J, allow A on all of J only, and assign EACH J-coset to exactly one of B or C by a fresh switch. This includes every pure terminal and remains sound for redundant choices. No test for generating H or having exact stabilizer is needed for soundness. Translation and permutation merely relabel domain entries; they never disconnect physical stars.

Every allowed-site predicate is therefore zero, one, or a single switch literal. Write f_i for the physical signed literal saying rail site i is FALSE and b_i for its allowed predicate. The clauses f_i⇒b_i plus pins are a single 2-CNF across ALL levels, using common star bits. Every lifted solution satisfies the full Latin block, since allowable supersets are sum-free by construction. Enumerate flag skeletons and solve each 2-CNF; a dense feasible model is captured by the maximal-trio argument. This tests containment in a critical template, not unrestricted feasibility or attainment of the threshold in the returned model unless the boundary supplies that promise.

For exact threshold search, set h=|J|. Every switch assignment gives total allowed mass q+h: the terminal contributes |G'|+h; each impure outer layer adds precisely |G'|−|H| outside mass. Also ALL three allowed domains are J-stable, since translations preserve common subspaces and all enclosing subgroups contain J. If h≥sqrt(q), enumerate J of index ≤sqrt(q) and saturated quotient U,V,W as in the earlier algorithm, ignoring flags. This takes 4^{sqrt(q)}q^{O(log q)} time and recovers the best original mass inside each template. For smaller terminal h, skip h<t. Add one labelled soft clause b_i⇒f_i per physical position. Its failure means exactly one allowed-but-absent site. Satisfying the hard clauses and deleting at most h−t soft clauses is exactly attaining M≥q+t inside this template. Solve using single-exponential Almost 2-SAT; repeat each hard clause h−t+1 times, preserving labelled multiplicities. If the solver treats clauses as a set, replace each occurrence of a clause (u OR v) by (u OR z),(NOT z OR v) with a private fresh z; this imposes minimum one deletion precisely when that occurrence is false. Constants and units are simplified or padded. A decision-only solver finds a physical assignment by pinning each representative in turn with protected hard clauses. [Razgon–O'Sullivan](https://arxiv.org/abs/0801.1300)

This gives the stated time by summing the two branches. A simple polynomial-space alternative enumerates ≤h−t hole sites for the small-h branch and takes 2^{O(sqrt(q) log q+(log q)^2)} time. The sparse guarded 3SAT images have only O(sqrt(q)) potentially false sites; the dense-witness guarantee does not cover them.
