# Shared choices on overlapping 2-CNF factors

Take H and all D_i^a explicit 2-CNFs on common variables, with target H AND the conjunction of (D_i^0 OR D_i^1). A model forces a position if it satisfies exactly one branch there. For supplied t, one can find an original model in deterministic 2^{O(t²)}poly(input) time if some model forces at most t positions. Every returned assignment is genuine. Exhaustion implies NO under the promise that a satisfiable input has such a model.

Use the standard universal-set method. For each candidate binary row b solve H together with all D_i^{b_i}, on the same variables. A family realizing each pattern on every set of at most t positions suffices. For m≥2 give each factor a distinct L=ceil(log2 m)-bit label. Any t labels are distinguished by at most t−1 bit positions: successive choices separate two labels from a single cell, increasing the number of cells. Enumerate subsets of at most t−1 bit positions, then mark positive any set of at most t resulting projected label values, and mark all others zero. This realizes the specified pattern on all forced sites. There are at most (L+1)^t times 2^{O(t²)} rows. Maximizing (1+log2 m)^t/m gives (L+1)^t ≤ m·2^{O(t log(t+1))}. Enumerate row-by-row in polynomial space, truncating t to m. Handle t=0 via the zero row and m≤1 directly.

For the narrower architecture assigning each factor one possibly complemented bucket bit, with every original model required to lift, the optimum number of buckets can equal the chromatic number of any graph G. Take D_i^0=(p_i OR u_i), D_i^1=(p_i OR v_i), and include p_i OR p_j in H for each nonedge. False p's form a clique. An independent-set bucket has at most one forced factor, so every proper coloring suffices. For each edge set just its two p's false; using singleton truth patterns of (u_i,v_i) one can force opposite translated bits at its endpoints under any fixed flips. Such a model cannot lift if the endpoints share a bucket. Arbitrary shared global codes remain available.
