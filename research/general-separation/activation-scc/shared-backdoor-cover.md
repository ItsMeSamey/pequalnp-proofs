# Shared witnesses and a 2-CNF backdoor under coordinate projection

The literal-scope plane quotient agrees with the usual ternary-scope hitting set. Changing the factorization can genuinely reduce that parameter. A standard bounded variable addition factors all m² ternary clauses x_i∨y_j∨z_j into (¬s∨x_i) for each i and (s∨y_j∨z_j) for each j. The raw scope hitting number is m by the disjoint diagonal clauses and the cover {x_i}. The extension has ternary hitting number one and preserves every original assignment by forgetting s. It cannot have a zero-bit coordinate-projected 2-CNF encoding: taking the three models supported on all x, all y and all z would force their all-zero majority. The complete rectangle can be detected by grouping identical literal cofactor lists in the explicit terms. Several verified rectangles can overlap; covering every original triple once or more and introducing a separate choice bit per rectangle gives an exact extension under joins on any original variables. Existing binary constraints remain. [Prior BVA construction](https://cca.informatik.uni-freiburg.de/papers/MantheyHeuleBiere-HVC12.pdf) · [Prior biclique treatment](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.SAT.2026.29)

For m disjoint positive ternary clauses, any CNF extension with arbitrary shared auxiliaries that projects onto all and only the original models by reading their coordinates needs at least m log₂(3/2) backdoor bits into 2-CNF. Each assignment to those bits gives a majority-closed projected relation, including constants if the backdoor contains original bits. Its projection onto one triple cannot contain all three singleton words, as they have forbidden majority zero. It covers at most 2^m singleton-product models, of which there are 3^m. Decoding by arbitrary linear maps is outside this bound.

Conversely any explicit 3-CNF with m ternary clauses has a deterministic polynomial-size 3-CNF extension with a strong literal backdoor of size at most m log₂(3/2)+O(m loglog(m+2)/log(m+2)). Keep all original variables and binary clauses. Divide ternary clauses into blocks of b=max(1,floor(log₂(m+1))) (short last block allowed). In a block of length t, greedily cover the 3^t possible strings of designated literal positions by boxes indexed by c∈[3]^t. Box c contains strings differing from c in EVERY coordinate. Each point lies in 2^t boxes, so the largest box covers at least (2/3)^t of remaining points. The greedy cover has O((3/2)^t(t+1)) boxes. Explicit enumeration costs polynomial in m since t≤b. Encode the box index in ceil(log₂(number of boxes)) binary selector bits, assigning unused indices to an existing box.

For a fixed index c, delete literal c_i from each original triple i in that block, obtaining an ordinary pair (a,b'). Every satisfying original assignment extends: choose one true position in each triple, then a box differing from all chosen positions. Conversely each conditional pair implies its original clause. Preserve width three and the promised strong backdoor without treating conditional pair tests as free: implement “if selector=c then a∨b'” with fresh prefix indicators. Start with p0=¬a (as literal); for each selector bit use the three ordinary AND equivalence clauses for p_j=p_(j−1)∧[bit_j=c_j]. Finish with ¬p_last∨b'. Every width-three clause contains a selector bit. The no-selector case uses the pair directly. Use independent prefix auxiliaries for each code and pair. This is polynomial in m, because each block lists polynomially many codes. The sum of per-block selector lengths gives the stated bound. Arbitrary overlap among clause variables leaves original-witness recovery unchanged. General covering-code derandomization is classical; the parameter accounting here concerns this explicit width-three shared-witness extension.
