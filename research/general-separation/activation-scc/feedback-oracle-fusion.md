# Scalar-export modules cannot implement conjunction in a one-readout activation network

The checker has arbitrary fixed binary row activations y_j((By)_j+t_j)=0 with one affine readout. Module i has private row activation variables x_i and exports only b_i=β_i x_i. Its incoming row-right-side values may be affine in checker variables and all exported bits. Checker RHS and its final affine readout may use all exported bits. Cross-module access to private coordinates beyond those bits is excluded. Modules have a fixed NO implementation and a YES implementation. Both can emit zero at every input by taking all private coordinates zero; a YES implementation can emit one at every specified incoming value. A canonical-YES native module has this last property by the canonical RHS theorem. Assume checker and wiring stay fixed while independently choosing module implementations.

Write f(X) for network feasibility with precisely X of the modules in their YES implementation. Feasibility is monotone: retain all exported bits and checker variables at a former witness. A replacement YES module emitting zero can be zeroed, and one emitting one can attain it on the known incoming signals. This remains true with bidirectional feedback, since the only outward signals are retained.

For any feasible X, absorb all modules outside X into the fixed checker. Treat the b_i for i in X as external bits. The resulting checker remains a one-readout native activation system with fixed matrix and RHS affine in b, including a new pinned root to impose the affine readout. Its rejected b form either the empty set or a single affine flat, the preimage of the unique possible rejected reachable RHS from the canonical-RHS path theorem. Since some b is accepted, this rejected flat does not contain zero and every coordinate unit. Hence the checker accepts either zero or a unit e_i. Choose actual checker values at this setting, realize the one active YES signal if present and set all other private modules of X to zero. Their YES implementations can now be replaced by the corresponding NO implementations without changing any signal. Thus f(empty)=1 or f({i})=1 for some i in X. Monotonicity implies f is constant or an OR of a fixed subset of input statuses.

The proof allows arbitrary checker-to-module affine feedback and an affine readout mixing all exported bits. It does not cover outward leakage of multiple private coordinates, shared internal witnesses, data-dependent checker matrices, or a compiler that globally rewrites the source. The statement is about Boolean correctness of black-box composition, not a general reduction lower bound.
