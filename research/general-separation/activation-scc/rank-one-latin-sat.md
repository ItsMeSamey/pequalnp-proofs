# One Latin block with a signed equality forest

Start from 3-CNF with m>=1 nonempty clauses on the active variables. Pad short clauses by repeating literals. Write d=ceil(log2 m), H=F2^d and P=H×H. Use one variable per payload in each of three rails A,B,C. Their distinct global labels concatenate tags 01,10,11, respectively, with their payload. In sorted global label order include all clauses A_x OR B_y OR C_(x+y). All ternaries have positive signs and offset zero. The sole nonzero ternary matrix of the signed convolution compiler is the outer product of the A- and B-tag indicator vectors, hence rank one over every field. There are 3|P| variables and |P|² ternaries; the global alphabet has size 4|P|.

Number the clauses by distinct i in H. Leave live only A_(i,0), B_(0,i), C_(i,i) for these indices, and pin all other variables true. Represent the three source literal values in clause i by these three live variables. For each source variable choose one live occurrence and connect it to each of its remaining occurrences by equality for the same polarity and disequality for the opposite polarity. Encode each edge by two binary clauses. The underlying simple boundary graph is a union of stars plus isolated pinned vertices.

Every Latin clause that lacks a true pin must use x=(i,0), y=(0,j), x+y=(i,j); the third payload is live only when i=j. Hence exactly the source clauses survive. Every assignment to the active source variables has one extension respecting the boundary, and the Latin clauses accept precisely for a source model. Recover each source bit from its representative and polarity. Unused declared source variables can be retained separately as free bits. The construction has O(m^4) clauses and polynomial bit size. Feasibility with one supplied rank-one block and this supplied boundary is NP-complete. The result does not require any convolution-circuit variables.
