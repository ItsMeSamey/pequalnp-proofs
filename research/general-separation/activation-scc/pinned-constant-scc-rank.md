# A parameter of constant-input activation components for one readout

Use the source-component span update in pinned-source-scc-span.md. Process the condensation from sinks to sources, retaining actual feasible assignments that span. For C, if any downstream basis word changes A_CD y, recover the full C projection with paths as in that note; no local matrix rank is required.

Otherwise A_CD y=0 on every feasible downstream y. For this isolated local right side, supply a binary diagonal correction a with M=A_CC+diag(a)=LR of rank r, and put b=t_C+a. For each binary vector z of r bits compute E={i:L_i z=b_i}. All feasible words with Ru=z are precisely the supported solutions of R[:,E] u_E=z. Impose the one additional scalar condition βu=1 when separating a previously found local span. Gaussian elimination returns a feasible physical assignment whenever possible; if every z is inconsistent then that covector vanishes on the entire local family. Reuse the witness-separating basis procedure to recover a basis of actual words. Add zero-downstream extensions because zero is itself feasible. Check the original equations after lifting.

Costs are 2^r poly(n) over the whole condensation, where r is the largest supplied completed local rank only on the constant-input components. The varying status is computed adaptively from true downstream samples. Checking a supplied diagonal and factoring M costs polynomial time, and the unmodified diagonal is always usable. The search for optimal diagonals via pivot skeletons in activation-scc-low-rank.md takes n^{O(r)}, so that search does not share the 2^r bound. Multiple jointly pinned readouts can require joint information beyond first-space spans. No small-rank bound is known on the single strongly connected block of an arbitrary input.
