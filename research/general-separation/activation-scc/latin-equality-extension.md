# Every binary zero-sum-free trio of mass equal to its group order extends

Let G be a finite elementary abelian 2-group. Suppose A,B,C are nonempty, (A+B)∩C is empty, and |A|+|B|+|C|=|G|. There are supersets of the three rails, still zero-sum-free, of strictly larger total size.

Use Grynkiewicz, A Step Beyond Kemperman's Structure Theorem, Theorem 4.1, Corollary 4.2 and the definition of dual pair following Proposition 2.4 (https://www.diambri.org/Mathpdfs/kemperman-revised-draft.pdf). If C is a proper subset of the complement of A+B, add an element to C. Otherwise |A+B|=|A|+|B|.

First suppose A+B aperiodic. In the quasi-periodic alternative of Theorem 4.1, type VI is impossible: a set of three elements has at most four self-sums, fewer than six. Type VII is dual to this impossible type. Type VIII requires a type II pair of nontrivial arithmetic progressions with the same difference in a quotient; lengths are at most two in this group, and two pairs with the same difference have sum of size two instead of three. In type V, the two-element local summand makes the local sum periodic by the difference d of those two elements. All other occupied cosets are full, since they have a representation involving a full input coset, while unique expression singles out the distinguished coset. Thus d is a nonzero global period, a contradiction.

Consequently (17) holds. In ANY elementary binary group under (17) a nonextendible pair would satisfy one of the cases of Corollary 4.2. Case A needs a progression of length at least three. Case C needs a type II pair in a quotient. Case B needs a dual to a type V pair, which by the definition of dual requires the underlying type V pair to be nonextendible. But if the two-element input is {x,x+d}, then the other input B is not d-periodic (otherwise the sum has only |B| elements). Adjoining a missing point of B+d to B leaves the sum unchanged, because the sum already has period d. This rules out case B. Extendibility means some input can be enlarged with unchanged sum.

Finally if the sum has period group H nontrivial, Theorem 4.1 gives (17), already handled, or both inputs are H-periodic with aperiodic quotient pair still satisfying cardinality equality. Extend the quotient pair by the preceding argument and lift its extra coset, preserving the old sum. This proves the claim.

The critical-flag upper templates previously used for mass strictly exceeding |G| therefore also cover every mass-equality solution of the original signed-star Latin instance. Enlarging sets is only a structural argument; no pin or star is required to permit that enlargement. Search verifies actual sites on the original boundary inside the template. An ordinary feasible witness from this search may have smaller mass unless boundary constraints fix the mass. Empty-rail cases need separate treatment.

For exact numeric equality M=q on arbitrary permitted boundaries, small-terminal flag templates (h=|J|<sqrt(q)) allow exactly q+h sites, independent of the switches. Guess exactly h physical holes. Impose allowed and absent on those holes and equality of the physical and allowed predicates elsewhere. All tests remain in 2SAT. For h≥sqrt(q) enumerate the quotient support templates of the existing large-terminal branch, requiring only that actual sites outside be absent. The possible mass contributions of a remaining signed-star component are two integers; standard subset-sum dynamic programming up to 3q with predecessors decides exact equality inside the template and lifts an original witness. Resolve the empty-rail case by forcing the corresponding sites absent and applying the same subset-sum step. Runtime is 2^{O(sqrt(q) log q + (log q)^2)} poly(input); this is separate from the at-least-q guarantee obtained by setting t=0 in the earlier Almost 2SAT threshold solver.
