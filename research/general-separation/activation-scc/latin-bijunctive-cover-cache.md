# Caching unions of bijunctive constraints

Choose any supplied clause tree of arity at most four on the actual signed-star representatives. Each leaf holds at most one ternary clause and any number of addressed binary clauses. Every original clause must be included. A node boundary consists of precisely the variables occurring both inside and outside. Store a list of 2CNFs whose union equals the projection of all models of the node to its boundary.

At a leaf express a ternary clause as the union of a unit clause and a binary clause on its remaining two literals. Conjoin the addressed 2CNF in each alternative. Discard unsatisfiable alternatives, and project each to the boundary. Projection of a satisfiable 2CNF is computed by enumerating all entailed binary and unit clauses on retained variables using 2SAT with pins. Davis–Putnam resolution elimination cannot increase width beyond two, so the resulting list of consequences defines the projection. Handle identically false inputs separately.

At a join choose one alternative per child, conjoin on the SAME representatives, discard unsatisfiable conjunctions, and project each surviving conjunction onto the parent boundary. The union is exact since any name common to distinct children belongs to both boundaries; their interiors can be extended independently once boundaries agree. Deduplicate equivalent projected disjuncts; remove any disjunct implying a strictly weaker disjunct. Pairwise implication tests are polynomial by 2SAT. Keep a child tuple for each surviving disjunct. During traceback, pin the parent assignment into that tuple's unprojected conjunction, solve 2SAT, and pass consistent boundary assignments to its children. At a leaf use the same procedure with the original local clauses. Every original bit is recovered, including when a dominating disjunct has a different internal witness.

Let K be the largest list after subsumption on the supplied tree. Per-node cost is (K+1)^8 times a polynomial in explicit input length: at most K^4 child tuples, one polynomial projection per tuple, then all pairwise implication tests. A supplied cap allows a certified solver to return unknown on first overflow. The lists can depend on the chosen tree. No polynomial recognition of the optimal tree is asserted. This is disjunctive variable elimination specialized to bijunctive relations.

For clauses x_u OR x_v OR p_e on a graph with one private p_e per edge, each leaf's projection is universal after subsumption because its private bit can be set true (use the private literal as the unit disjunct). All joins keep K=1, even when many independent shared names admit every assignment on a separator. This illustrates parameter separation only. On general signed-star inputs K is unbounded a priori.
