# Linear coset cuts with graphic readout reconstruction for the October circuit bound

Represent an acyclic deterministic circuit by n raw bits x and m named producer outputs z. Contract any affine gates symbolically, recording affine functions on (x,z) for all the actual producer arguments and the actual output pin. Each remaining producer is computed in polynomial time from its supplied argument values. Impose one predicate per producer comparing its specified output bit z_i to its value, and impose the final output pin. Each original raw assignment has exactly one extension to all z before pinning, including under fanout.

Supply a linear subspace U of the n+m-dimensional JOINT parameter space, dimension k. Guess the n+m−k complement coordinates so branches are disjoint cosets. On U collect all restricted linear argument normals, every z_i normal used for comparison, and the final readout, preserving repetitions as aliases and treating zeros as constants. Test graphicness of their binary column matroid by constructive recognition. On success, remove one incidence row per connected component of the resulting graph: the actual normals can now all be realized by bits or XORs of at most two bits in ONE common coordinate chart on U. An invertible linear map follows by matching labeled bases and extending through unobserved directions. Coset representatives change affine constants only. This common sparse reconstruction matters: ranks of individual restricted argument lists alone give no sparse circuit for all linear forms.

For each predicate let r_i be the rank of its restricted input-and-output observations. Choose a basis among its actual observations and tabulate its truth function on that basis in each coset. All other arguments are affine combinations of these basis values; use the supplied local evaluator and compare to the actual output value. A Shannon circuit uses O(2^{r_i}) gates; its input basis readouts cost at most one XOR and a possible complemented wire each in the graphic chart. Only distinct observations actually used as table input are constructed. Total leaf circuit size is O(sum_i 2^{r_i}) even if the supplied evaluator's description is larger: producing each table value is charged polynomial time times the explicit input size. No circular interpretation or guessed producer value bypasses its equation. The witness circuit retains all k coordinates, including unobserved free directions. Alternatively count those directions by the explicit 2^{k-rank} multiplicity and fill zero when returning one original witness.

When m=O(n), k≥m+c n/sqrt(log n), and sum_i 2^{r_i}≤C n with C independent of the chosen saving constant c, each leaf gives a fixed-density 3CNF on O(n) Boolean variables with uniquely determined Tseitin gates. Lower-size instances can be padded with uniquely forced variables. The cited October fixed-density count costs poly(input) 2^{O_C(n/sqrt(log n))} per leaf. Choose c greater than this constant. The resulting original count and original witness clock is poly(input) 2^{n−Omega(n/sqrt(log n))}, conditional on the external source theorem and the given layout satisfying the numerical inequalities. Pin the sparse leaf coordinates for self-reduction, then invert the entire coset chart and verify all original gates. When U is the whole joint space, m=O(n), and producers have bounded arity on affine readouts, the same graphic test and leaf construction give a single 2^{O(n/sqrt(log n))} fixed-density call up to polynomial search overhead. There is no demonstrated unrestricted bound for arbitrary n log n-gate circuits.

For ordinary explicit coordinate observations alone, choose any coordinate set P whose restrictions form a basis on U. Each local scope T has rank at least |P intersect T| under this U. Thus for the rank-only table inequality a coordinate live set P of the same k does at least as well as arbitrary linear mixing, when observation lists include the same coordinates on both sides. The new possibility lies in compact shared reconstruction for noncoordinate READOUTS or semantic simplification, not an automatic advantage of replacing every coordinate cut by a subspace.
