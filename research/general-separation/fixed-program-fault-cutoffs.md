# First local SAT faults of one fixed program under varying clocks

Use deterministic bit programs, zero on timeout, and the well-founded local SAT tests of sat-one-local-refuter.md. For C_k(L)=(L+2)^k let S_k be the accepted valid formulas. Write S∞ for all valid formulas on which the unclocked program eventually accepts, including when the program is partial. S_k increases to S∞. Each finite list of predictor answers stabilizes: zero answers in the union are always zero, and each of its finitely many ones eventually appears. Let f(k) be the least local-test length at which the clocked predictor fails, defined only for incorrect predictors.

**Two distinct cutoffs.** For each fixed program a total recursive upper bound depending on k always exists. Indeed the good indices with S_k=SAT form an interval, since between two equal acceptance sets every intermediate set is equal. Every individual interval of natural numbers has a recursive membership test, including empty, finite and infinite intervals. Hardwire its endpoints and, on bad indices only, search increasing finite test lengths until a failure. This is an existence assertion about one program. The endpoints have not been uniformly computed from the program's code.

A single constant independent of k bounds all its defined f(k) exactly when S∞ differs from SAT or some S_k equals SAT. In the former case fix a failed local test of the limit predicate. Once all positive replies at its node and children have appeared, the same test fails for every later k. The finitely many smaller bad k have a finite maximum. If S∞=SAT and some k already gives SAT, all later k give SAT. In the remaining case every k is wrong, yet every bounded collection of tests eventually passes. Consequently f(k) tends to infinity. For a supplied *total* wrong program and a supplied local failure one can calculate when each positive reply appears by simulation. This computes the eventual threshold and witness. It does not classify the earlier indices.

**Other polynomial clock specifications.** The conclusions about recursive per-clock bounds for a fixed program extend to clocks p(L+2) for canonically encoded nonzero polynomials with nonnegative integer coefficients. If S∞ is wrong, a finite limit-fault witness requires only some finite number R of simulation steps per answer. Only finitely many such polynomials have p(2)<R, so one constant bounds every defined first fault. If S∞=SAT, correctness is upward closed under pointwise clock domination. If no polynomial is correct, search succeeds for each. Otherwise fix one correct p. Every polynomial of sufficiently large degree dominates p on all integers ≥2, since t^e≥p(t) there for all sufficiently large e. In the remaining bounded degrees, pad coefficient vectors with zeros. The good vectors are upward closed under coordinatewise order and have finitely many minimal elements by Dickson's lemma (an infinite sequence in finite-dimensional nonnegative integer lattice has a coordinatewise increasing pair, by repeatedly taking an infinite nondecreasing subsequence in one coordinate). Hardwiring these finite bases yields a recursive good-clock test and hence a total per-clock bound. For this whole clock family with S∞=SAT, a uniform constant across all clocks exists exactly if only finitely many clocks are wrong: from infinitely many distinct wrong polynomials take a sequence with p(2) tending to infinity, forcing all bounded tests eventually correct. Having just one correct polynomial need not suffice in the multi-parameter family.

**Nonuniformity persists even with a known raw error.** In the case P=NP fix a polynomial SAT decider D and a specific UNSAT formula F0. Given a blank-input machine M construct a total raw predictor E_M. On F0 it waits beyond a specified common clock C_k0 and then deliberately returns one. Elsewhere simulate M for |F| steps, returning zero if it has halted and D(F) otherwise. Hardwire fixed-alphabet transitions into finite control so a fixed sufficiently large k0 pays for all non-F0 work uniformly; checking the fixed F0 has constant overhead. The exceptional delay is a fixed constant chosen after k0. At that clock F0 times out correctly. Therefore the truncation is correct exactly when M never halts, since there are satisfiable formulas of arbitrarily large length. Every raw predictor is wrong on the *same known* input and this is independent of M. Any computable cutoff from E_M,k0, even on this promise, decides nonhalting by finite local checking. Conversely if P differs from NP all polynomial truncations are wrong and uniform search on (program,clock) terminates. This recovers the distinction between hardwired cutoffs and a uniform extraction algorithm. No unconditional noncomputability for the standard polynomial candidates follows.

For fully arbitrary effectively supplied total clock functions, the pointwise ordering assumptions matter. Even for one fixed raw program deciding SAT by a known exhaustive clock G(L), give a clock that allows G(L) unless a supplied M has halted within L simulated steps, in which case it gives zero steps. These are total computable clocks; zero on timeout gives an incorrect candidate exactly for the halting machines. Thus even for this one architecture no uniform computable per-clock cutoff covers all such specifications. G and these clocks need not be polynomial. This counterexample does not apply to the preceding polynomial clock models.

**Succinct generators with a common polynomial cap.** The encoding of a clock can change even the fixed-program conclusion. Suppose a supplied algorithm generates the numerical budget Q(L), with the promise 0≤Q(L)≤(L+2)^k0 for one fixed k0. Every generator below is total and runs in time polynomial in its description length and L (L may be supplied in unary); it returns the budget in binary. Under P=NP choose one fixed deterministic SAT decider D and k0 large enough that D always finishes within this cap. From a blank-input machine e produce the generator that returns zero if e halts in at most L steps and (L+2)^k0 otherwise. Universal bounded simulation and writing the binary budget have a common polynomial clock. With zero interpreted as immediate rejection, D with this budget is correct iff e never halts: in the halting case all sufficiently long satisfiable formulas are rejected. A uniform computable per-generator cutoff, even specialized to this single fixed D and these generators, would decide nonhalting. Under P≠NP every fixed predictor truncated by one of these generators is a polynomial-time predictor, since both generation and the permitted simulation have polynomial clocks. The unbounded search for a failed local test therefore terminates on every such promised input. The same argument covers total polynomial-time length-only generators with a polynomial numerical bound. It does not require an algorithm certifying the promise. A numerical bound alone does not bound the implementation time of an arbitrary clock-generating algorithm; no totality claim for that wider class is needed here.

For an explicit conditional illustration with coefficient lists, assume P=NP and insert a deliberate delay of at least L² transitions in a fixed polynomial-time SAT decider before it gives any answer. Some large polynomial budget is correct. Yet each linear polynomial p_c(t)=c t for c=1,2,... times out on all sufficiently long satisfiable inputs, and these are infinitely many distinct wrong coefficient lists. Their values at 2 tend to infinity, so every finite test set eventually stabilizes correctly along this sequence while an error remains at each c. This exhibits the failure of a common constant cutoff for this multi-parameter family even though one listed clock is correct.
