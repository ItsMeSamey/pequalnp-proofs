# Existential occupancy of diagonal challenge columns

Fix an effective conventional indexing i≥0 of deterministic machines in which the description from the index costs time polynomial in i+1 (for example, lexicographic binary strings, with invalid descriptions denoting a fixed machine). A challenge row is x(i,m,z)=⟨bin(i),1^m,z⟩ for m≥2, |z|=m. A language B in NP would suffice to separate P from NP if it had both properties below; in fact it would imply a tally NP language outside P.

1. For every index i computing a total polynomial-time decision procedure, B(x(i,m,z))=1 implies that machine i rejects x(i,m,z).
2. For every such i, if for all sufficiently large m machine i rejects all its own rows of length parameter m, then for infinitely many m there exists z with B(x(i,m,z))=1.

The indexing, B, and its polynomial bounds are common to all i. The running-time bound on individual indexed machines is allowed to depend on i. In particular the soundness obligation above is only on polynomial-time indices, not on arbitrary possibly nonhalting ones. No B with those properties is constructed here.

Encode (i,m) as the unary length N=2^i(2m+1). Define T on unary inputs to accept 1^N iff N encodes m≥2 and some m-bit z has B(x(i,m,z))=1. Reject nonunary inputs. This is a single tally language in NP: recover i from the exponent of two in N, guess z and the B certificate, and run the fixed verifier. The length of the B input is polynomial in N. Code extraction uses the specified effective indexing.

Suppose T has a deterministic polynomial decider A. Construct a total polynomial machine D that parses x(i,m,z), ignores the content of z, and returns A(1^N) if N≤m², rejecting otherwise and on malformed inputs. The cap test never materializes an excessive unary integer: compare i with the bit length of m² before performing a bounded shift. Thus D has a single polynomial bound on all inputs. Choose an index j for D. For all sufficiently large m, 2^j(2m+1)≤m². If any challenge at such a column has a B witness, T accepts that length, so D accepts every challenge of the column, including that positive row. This contradicts soundness at polynomial-time index j. Thus every sufficiently large such T input is negative. D rejects all sufficiently large self-challenges, requiring infinitely many positive columns by property 2. Contradiction.

It follows that this explicit T is outside P if B satisfies 1 and 2. Its binary-length encoding on input bin(N), for N≥1, is in NE by nondeterministically expanding the unary input. If the binary-length encoding were in E, T would be in P by evaluating it on bin(N). In particular the sufficient verifier obligation entails E≠NE (and P≠NP), without any assumption on the ability to find a challenge deterministically.

The proof extends to |z|≤m^c for a common fixed c, with D using the same parser; padding checks must remain polynomial. More generally it only needs that the existential occupancy of each column, jointly in (i,m) on the unary encoding above, lies in NP and that D can identify its column in polynomial time. A large number of available challenge strings alone does not remove this obstruction. For an ordinary NP language, merely being outside P does not impose these column soundness and hit conditions. This is a barrier to a proposed proof technique, not an unconditional distinctness result.
