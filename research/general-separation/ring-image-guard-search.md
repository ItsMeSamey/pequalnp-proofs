# Exhaustive fallback for the ordered selector-free image

[decide](ring_image_guard_search.py) accepts the four ordered physical fields. It first uses the certified phase and two-boundary projection, retaining its polynomial binary decisions and verified witnesses. For a wide residual it enumerates exactly the Boolean coordinates occurring in that residual, then passes any model to the projection lift, which validates all phase clauses and the original recovered source. If the raw word belongs to the image but lacks the required phase structure, it searches the recovered signed source instead. This path removes only tautological clauses and omits unused variables from enumeration. It restores a full-length source assignment and checks every clause. Off-image is a separate terminal status.

The max_assignments default is 4096. An explicit None selects unrestricted enumeration, yielding a complete deterministic decision procedure on this ordered image. Before enumeration the wrapper reserves the entire cube, including the single assignment to zero coordinates. With nonnegative integer budget C and d occurring coordinates, C.bit_length()≤d detects exactly C<2^d without constructing 2^d. On refusal the response contains status unknown, reason assignment_budget, available, required_log2=d, tested=0 and the search mode. Exact prior polynomial decisions consume no exhaustive-search budget. The cap does not limit recovery time or memory. On either enumerating path a positive result gives a verified satisfying assignment; zero follows only after all 2^d assignments fail. The wrapper decides nonzeroness of the physical residue by the selector-free compiler's normalization and precision guarantee; it returns no numerical residue.

Given encoded size B, bit cost is 2^d poly(B) and working space is polynomial in B including the witness, plus reading the supplied budget. On the certified phase path d is the number of used residual phase IDs. A family whose private guards project away pays no exponential charge for their phases. Outside that domain d is the number of used original source IDs after dropping tautologies, which can be as large as the source arity. Thus d=O(log B) gives polynomial exhaustive time at a sufficient budget; a fixed cap may still refuse. The [separate controls](check_ring_guard_search.py) exercise both paths on original physical fields, including a five-cycle instance with one width-five demand. No prior adapter or kernel is modified.
