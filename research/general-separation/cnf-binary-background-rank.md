# Restricted ternary miss rank on a binary background

[project and solve](cnf_binary_background_rank.py) take a declared arity and explicit signed clauses. Validate literal IDs before deduplication. Drop tautologies, collapse repeated literals and duplicate normalized rows, recording the first source occurrence of each retained row. All rows of normalized width at most two, including units and the empty clause, form B. The other non-tautological rows must have width three. Keep all distinct B rows in every subsequent decision. On the models of B compute the exact GF(2) rank k of the ternary miss functions and retain k actual ternary clauses. This is an explicit bounded-degree calculation on a bijunctive solution set, related to the Boolean constrained ideal-membership literature. [Mastrolilli](https://arxiv.org/abs/1904.04072)

First find a model of B by implication-graph 2-SAT, or report unsatisfiability. XOR-translate its coordinates so zero is a model, assigning unused coordinates zero. Each translated binary clause is an implication u→v or a denial of simultaneous positive coordinates, including a singleton denial. A feasible true set is precisely implication-closed and contains no denied set. For support S merge the individual forward reachability sets into cl(S). The monomial with support S evaluates on background models to zero if this closure contains a denial, and otherwise equals the principal-upset indicator [cl(S)⊆Y]. Indeed every closed Y containing S contains each successive implication consequence, by induction on path length. Conversely cl(S) contains S, and a consistent closure itself supplies a background model.

For each translated residual clause multiply the three factors specifying its falsification. A negative literal −x contributes x, and a positive literal x contributes 1+x over GF(2). Expand into at most eight monomials. On Boolean inputs, products merge supports by union, with repeated closure keys cancelling in pairs. For the distinct consistent keys that actually occur, evaluate their indicators at the background models whose true sets are those same keys. In increasing order of cardinality this square inclusion matrix is triangular with ones on the diagonal. Hence these functions are linearly independent. Sparse elimination over the closure keys computes the exact functional rank on B. Inductively after each processed row the pivot rows span the processed functions, extending the basis exactly when its new remainder is nonzero. Thus vanishing of all retained **original** miss functions on a B-model forces every ternary miss to vanish there. The choice of translating model changes the coordinates but preserves this rank. Pinned variants can run the same argument with the pins added to B, testing feasibility anew.

For decision choose a set H of variable IDs meeting every retained ternary clause. Add a variable from an unhit clause until none remains. Each addition hits at least one previously unhit clause, so g=|H|≤k. No minimum hitting set is needed. Try assignments on H. Discard satisfied retained clauses, delete falsified literals from the others, and enforce the branch values with unit pins. Each surviving ternary now has at most two literals. Test this formula together with the mandatory binary background, which can equivalently be simplified under the same pins. A full model belongs to one such branch; conversely every successful branch extension meets B and every retained ternary, so all omitted misses vanish. Restore the original labels and verify the sparse true-ID witness against every original clause. Omitted IDs default to false.

At rank zero the projected origin already answers decision without a branch. Otherwise at most 2^g branches are charged, including failed branch tests. A cap smaller than the full cube permits early success; stopping before the next required assignment gives unknown. Sparse IDs are compressed by actual occurrence, and at most eight distinct keys per residual row enter the global dictionary before elimination. Each reachability, elimination, branch test and witness check takes polynomial bit time in the explicit input. Counting requires additional work even when k=0, since the entire model count of an arbitrary B remains. Summing over these disjoint branches would require counting the extensions within each binary leaf.

## A strict comparison on the same connected formulas

For m≥2 name p by ID 1, x_i by i+1, q by m+2 and z by m+3. Use the binary rows (¬p∨¬x_i) for every i and (q∨z). Give each i one ternary row (¬p∨¬q∨x_i). The incidence graph is connected. On B each ternary miss equals pq because p forces all x_i false. It is nonzero on a background model with p=q=1 and all x_i false. Thus k=1. The background is essential: deleting just its ith negative binary row admits p=1,q=0,z=1 with x_i=1 and other x values zero. Deleting (q∨z) admits the all-zero assignment.

On the unrestricted cube the ternary misses pq(1+x_i) have distinct degree-three monomials pqx_i. The negative binary misses px_i and the final binary miss (1+q)(1+z) have independent distinctive quadratic monomials after the cubic coefficients have been forced to zero. By uniqueness of Boolean multilinear expansion, all 2m+1 miss functions are independent. The [unrestricted raw solver](cnf_miss_span.py) therefore keeps all m+3 named variables and all clauses. Its chosen enumeration mode executes exactly 2^{m+3} assignments; even an early-exit decision scan in its increasing word order fails the first 2^{m+1} because both highest coordinates q,z are zero. With g=1 the restricted solver uses at most two branch tests after polynomial projection on these same inputs. With binary names their explicit size is O(m log(m+2)) bits.

The family has 3·2^m+1 models: for p=0 the pair (q,z) has three choices and the x variables are free; for p=1 the only option is q=0,z=1 and all x false. This direct split on p also makes the family easy by other formula-aware methods. The comparison establishes a strict improvement over the specified unrestricted enumeration clock; the general decision argument supplies no free background-counting oracle.
