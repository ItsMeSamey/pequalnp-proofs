# Exact counting on every ordered selector-free image

[count](ring_image_total_count.py) takes (n, clauses, point, k) and two optional independent nonnegative integer caps, max_assignments and max_determinants. Both default to None. It decodes the ordered word once, returning off_image on failure. A successful result gives the integer number of all assignments satisfying the recovered source, the canonical physical residue, zero or nonzero status, and an original source witness for a positive count. It does not count satisfying assignments of the physical positive CNF.

The generic path drops tautological source clauses, computes the d distinct IDs that still occur, and sums the Boolean satisfaction indicator over all 2^d assignments. Each model extends to exactly 2^(a−d) assignments on the a declared source variables. A missing empty clause is never inferred: an explicit empty clause has zero contribution under every word, and an empty conjunction counts 2^a assignments. One surviving word, padded with zero on unused variables, is checked against every original clause. The physical value in either branch is (−15)^(k−a−1) times the full count modulo 3^k.

Before generic enumeration the wrapper tries the [planar affine-demand backend](ring_image_affine_demands.py) on the recovered source. If generic enumeration is affordable it caps the planar run at 2^d determinants or any lower explicit determinant budget. If the planar run stops, the generic path can still finish in its reserved budget. Thus a failed planar attempt, including actual determinants already performed, is included in total cost. When the enumeration cap disallows the cube, the planar attempt receives the explicit determinant cap alone, including None for unlimited. If neither path finishes, unknown includes the planar reason and actual determinant usage, required_log2=d, available assignments and zero assignments tested. The affordability comparison uses integer bit length before forming 2^d. Caps charge assignment trials and determinant calls separately; they do not cap polynomial preprocessing. Both exact routes report actual counts of their charged operations.

**Competitive bound.** With uncapped caller budgets, write B for explicit physical bit length. A polynomially rejected planar input costs 2^d poly(B) including generic completion. On an eligible input let r and u be the independent affine rank and number of residual nonlinear demands after the frozen backend's preprocessing. Its uncapped full loop visits at most (1+h)2^(r+u) terms for h surviving edges, including witness extraction. The scheduling cap controls partial work as well as completed work. Preprocessing either settles the instance or certifies at least one unblocked perfect matching. Then a character query can bypass an actual determinant only through reuse of its positive calibration with no deleted edges and no twist. In that case the independent character rows force the empty character subset. A union of selected distinct demand sets can be empty in at most two ways, since at most one demand set is empty. Thus at most two terms per count invocation incur no determinant after calibration. All witness-deletion invocations delete at least one edge. All remaining calls either consume a determinant or stop the attempt when the next call would exceed the cap. Each term costs poly(B) additional bit work, including loops over masks and construction of deleted edge sets. The signed numerator needs only polynomially many bits. These facts give a partial-attempt clock of poly(B)(1+2^d), including all uncharged query work.

If the internal cap binds, the number of calls needed for a full planar run is at least 2^d+1, and at most 1+(1+h)2^(r+u). Thus the follow-up enumeration still costs at most poly(B)2^(r+u). If it does not bind the planar path returns within both bounds. Together this gives poly(B) min(2^d,2^(r+u)) bit time on eligible inputs and polynomial space. Early polynomial conclusions need no rank parameters. An explicitly restrictive caller cap can force an otherwise unnecessary fallback or refusal. If both user caps are finite, the time is bounded by polynomial input overhead times one plus their sum (as numerical budgets), using the same bound on uncharged terms. Native evidence for this wrapper uses a [separate assignment-oracle checker](check_ring_image_total_count.py).
