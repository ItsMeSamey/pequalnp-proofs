# Sparse verification on native computation wires with the entire fetch region guessed

Fix the unary nondeterministic hierarchy language H* of the [additive correction theorem](bounded-incidence-additive-witness-rigidity.md). Its time bound is 2^n and its excluded nondeterministic clock is 2^{n−ceil(log₂ n)}. Use the native de Bruijn and fetch construction in Jahanjou–Miles–Viola at locality r=2, with the **typed canonical** variable namespace. Child and parent gate names are reconstructed from their declared fields, and unused address bits are zero-filled. Names retain their region tags. Finite checker tags can be padded by a duplicate of a genuine checker. Keep the short local clock and switch states supplied by the theorem, including its off-computation states. Choose syntactically reserved top-level tag and field values to be inactive. Genuine native outputs reached by the low input-index bits keep the concrete values from the actual fetch map of the chosen total reduction. This statement does not identify lex-first tables across different totalizations. [Primary source, Theorems 7, 11, 12 and proof of Theorem 1](https://eccc.weizmann.ac.il/report/2013/099/revision/3/download/)

**Theorem.** There exist fixed eta>0 and integer K such that, at infinitely many YES lengths, every full satisfying table disagrees with every gate circuit of size at most eta n sqrt(log n) on more than floor(2^n/n^K) distinct occurring native local-checker, routing or configuration addresses. The fetch region, global dummy and shared routing constants are excluded from the discrepancy count. There is no added occurrence sorter. The result uses the October fixed-density width-three counting theorem. The physical-address assertion holds also with fixed zero padding to Dn input bits, using constant pinning. The distributional consequence below explicitly defines a separate compact language.

**Fetch table.** Guess all canonical bits of the fetch region in address order. There are F≤2^{ceil(n/2)+O(log n)} such names by Theorem 11. Enumerate every fetch gate obligation, make requests for its own and child bits and verify using two sequential sorts, by address then by clause ID and position. All of its gates are constants or single-child Copy, and there are no external children. Repeated raw IDs producing an identical canonical obligation can be checked once in this zero-violations test. This also gives existentially consistent values for every malformed Copy component without a claim about termination of invalid indices. Read each actual exposed output on the low ceil(log n) bits, at most 2n entries, using another sorted request stream. If two requests have the same address they necessarily get the same value. The source can compute all these lookup addresses in polynomial time. In every outside local gate, access the resulting bit table with an ordinary size-O(n) binary multiplexer tree. Pin the true global dummy and the shared constant-zero gates of the O(1) routing copies. If their constant-zero tag admits additional owners, all of those constant-zero units can likewise be satisfied by zero. This treatment does not assume all low-bit outputs equal one.

Classify each ID by the **output-control bit first**. When that bit is one, the source reparses the address as a local checker output assertion regardless of the outer region. Keep one canonical assertion per designated checker and row; all original duplicates enforce exactly the same unit. For gate constraints likewise choose the canonical owner and the original gate-template clause selectors. Under typed reconstruction an ignored filler creates only repetitions of the same obligation. Include the native bare-input dummy clauses by pinning their separate dummy one. This chooses which duplicate IDs are retained before doing the count. Distinct retained IDs count separately even when their literal triples agree. Other conventions that forward arbitrary filler bits into different child names would require their own proof. Validate syntactic canonical padding by linear gates; all O(log n)-bit clock states are permitted in their declared tag, without a reachability lookup. Native raw decision-tree outputs at r=2 have constant locality and therefore compile into O(n) ordinary gates overall. The active-ID canonicalization here is only finite tagging, fixed fields, equality and padding, not an arbitrary polynomial-size short-field predicate.

**Inverse enumeration on retained names.** Regular children of a local checker share its long row i and checker j, even when its short simulated clock resets. Its wired inputs are the configuration at i or the corresponding routing output at i. The only outside fetch child is the known low-bit-indexed output. In a routing bit switch same-switch gates and the control retain w. A preceding-switch child arises from a fixed cyclic shift of w or a shift after flipping one endpoint bit, with fixed inverse maps. The first-input child names a bit of the configuration at the same w. Shared zero reads have already been substituted. Assertions name a checker output at the reparsed row i. Thus for any retained physical name, enumerate the constant number of possible owner rows by these field maps, all finite tags, and all other O(log n) ID bits. Decode each candidate and compare full name and position in the retained active triple. This permits polynomially many owners for each short-clock state or control and does not attempt to invert the unknown permutation routed by the switches. Every candidate passes a final forward comparison.

**One count.** Guess the candidate circuit C and at most t distinct retained addresses and replacement bits. For each retained canonical clause ID, resolve the fetch, constant and dummy slots as above and the other bits by C. The circuit Bad_C for an active false clause has at most 3|C|+O(n) gates and q=n+O(log n) input bits. Use one parsimonious fixed-density width-three count of its violating IDs. Let the result be N. Apply reverse enumeration to the correction list, sort and deduplicate the affected active IDs, and join on full wire names as in the additive theorem. Let U and U' count their false clauses before and after all replacements. Accept exactly when the fetch/constant checks pass and N−U+U'=0. Every original satisfying table close on the retained names supplies its own entire fetch table and its physical corrections. Conversely an accepting branch gives a simultaneous satisfying assignment on all the native components; unused coordinates are free. In particular this proof does not assume preprocessing preserves a distinguished satisfying assignment.

Write A for the fixed counting constant, choose a computable rounded cap with 3A eta'<1, and use the polynomial exponents in the additive verifier. The all-branch time is at most

    2^{n/2+O(log n)} + 2^{(3A eta'+o(1))n} + (1+t)poly(n).

The first term includes all fetch-tape writes and sorted reads. The second includes the O(n) mux lookup gates using the actual low bits in the emitting row, with no list of n full-address comparisons. Take t=floor(2^n/n^K), with K larger than the last polynomial's degree plus two. Eventual existence of a close circuit and satisfying table on every YES length would put H* in the forbidden time class. [October counting source](https://raw.githubusercontent.com/openai/math/42907c9e999cc00d6abe7a50bfc1023250edd1b9/preprints/The-Exponential-Time-Hypothesis-is-False-October-25-2026/build/main_full_version.tex)

For the single compact language, choose a canonical width ell=n+O(log n) sufficient for every native typed name, and strictly increasing L(n)=n+c ceil(log₂(n+2))+c covering ell. On every YES length, set the retained bits to those of the lex-first **full native** table in the fixed physical ordering, set the others zero and ignore (replicate over) the L−ell extra suffix bits. Other lengths and NO lengths give zero. Explicitly constructing the full formula and successively extending its lexicographic prefix with SAT queries takes deterministic exponential time with an NP oracle, also if the underlying physical ordering uses Dn-bit names. The named language is in E^NP. For each fixed ignored suffix, pinning it in an L-input circuit preserves the physical disagreement lower bound, using zero extension for the other fixed fields or constant renaming as needed. Thus the error under a uniform L-bit word is at least 2^{n−ell}/n^K, an inverse polynomial. A separate language with only its single zero-padded copy in a Dn-bit cube need not have this error density. No NP verifier for the retained satisfying-table bits follows.
