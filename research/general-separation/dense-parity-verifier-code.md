# Local decoding and witness recovery from a dense parity code

Given a Boolean circuit C on n≥1 inputs, let F be the binary field of size Q with 8(n+1)≤Q<16(n+1). Field elements have k=log₂Q bits in a polynomial basis, with unit element represented by the constant 1. Irreducible binary polynomials of prescribed degree can be constructed in deterministic polynomial time in that degree (Shoup); even testing all O(Q) candidates by trial division costs poly(n) here. For vectors u,v in F^n put

    P_C(u,v) = Σ_{x∈{0,1}^n} C(x) · (∏_{i:x_i=0}u_i)(∏_{i:x_i=1}v_i).

For r in {0,1}^k the encoded coordinate is the binary dot product of r with the k-bit representation of P_C(u,v). The target address has (2n+1)k bits. On suitable selector pairs (u_i,v_i) in {(1,0),(0,1)} a single specified assignment survives. At u=v=all ones the answer is the parity of the number of satisfying assignments in the prime subfield.

The displayed monomials are distinct, so distinct source tables produce a nonzero difference polynomial of total degree n. It is nonzero at a uniform field point with probability at least 1−n/Q by the polynomial zero bound (Schwartz–Zippel). Half of all binary dot products distinguish two distinct field elements. Thus relative distance is at least (1−n/Q)/2, even for source tables differing on one input. As a uniform language on (C,u,v,r), exact code-bit evaluation is ⊕P-complete under deterministic polynomial-time many-one reductions. Guess one n-bit x, evaluate C, form the product of its selected field entries, and accept precisely if C(x)=1 and the dot product for that one monomial is one. The parity of these paths is the code bit by linearity. For hardness take u=v=all ones and choose r reading the constant bit; this evaluates parity-CircuitSAT. Standard parsimonious gate encodings allow arbitrary binary gates.

**Fixed-circuit average-case oracle.** Suppose a single bit oracle h agrees with the encoded table on at least 63/64 of coordinates for a fixed C. The following algorithm uses queries to h on this same C to recover P_C(w) at any specified w=(u,v) in randomized polynomial time. It needs the error guarantee for this C; averaging over supplied circuit descriptions would not suffice. For a uniform random direction d in F^{2n}, consider w+td for all nonzero t in F. Each is marginally uniform even if the locations are correlated. At each location query all Q inner masks r and choose a closest binary linear character (enumerate the Q possibilities). At any location with strictly less than one quarter of its masks erroneous, this recovers the correct field value because distinct inner words differ on half of the masks. At most 1/16 of locations can violate the strict bound, by averaging.

Write L=Q−1. The expected count of bad received symbols on the line is at most L/16. Markov gives probability at most 1/4 of more than L/4 such errors. With the complementary probability recover the restriction polynomial of degree ≤n from the L nonzero t locations. In detail choose e=floor((L−n−1)/2), which is at least L/4 for the stated Q. Solve for a monic E of degree e and a polynomial R of degree ≤n+e so E(t)y_t=R(t) at all these positions. When there are at most e errors, the locator polynomial on erroneous positions times extra factors to reach degree e gives a solution with R=E·P_line. For any solution, R−E·P_line vanishes on L−e>n+e correct positions, so it is identically zero. Divide and evaluate the quotient at t=0; return a default if the system or division fails. One trial succeeds with probability at least 3/4. Independent repetition with majority of field outputs reduces failure probability exponentially. The inner scans and field linear systems take polynomial bit time.

This conclusion holds for arbitrary queried w, including the all-ones parity coordinate. Thus a uniform NP predicate that gives such approximate bits for every supplied C would imply ⊕P⊆BPP^NP. Under P=NP, the usual BPP⊆PH inclusion gives ⊕P=P from this additional premise. Conversely ⊕P⊆NP suffices for exact NP verification of this code. These are implications for this specified encoding. They do not assert that P=NP implies a collapse of ⊕P.

**Finding an actual satisfying input.** Start at a uniform w. If C is satisfiable then P_C(w) is nonzero with probability at least 1−n/Q. Decode that value and continue if it is nonzero. At step i, setting v_i to zero keeps only the terms with bit i equal to zero; setting u_i to zero keeps the others. The two corresponding field values sum to the parent. Decode the first and, if it is zero, take the second; a nonzero parent always has a nonzero selected child when decoding succeeds. Keep all earlier pins. After n steps, the single remaining input x has C(x)=1 if the maintained value is nonzero. Verify C(x) before output. Decode with fresh independent repetitions at each point and conditional failure probability at most 1/(10(n+1)); a union bound is valid for these adaptively selected points. This gives constant success probability on any satisfiable C with the promised approximation; it never reports a false witness. It does not require evaluating h for a changed or restricted circuit, nor an odd number of witnesses.

Evaluating from the circuit description bypasses the positive-oracle and sparse-query obstruction in dense-np-table-amplification.md by taking a parity over exponentially many source assignments. This explicit construction identifies the additional counting power used and supplies a positive local recovery theorem. It supplies neither an efficient NP verifier for the dense coordinates nor a deterministic UNSAT algorithm meeting a hierarchy clock.
