# Hamming rigidity on physically occurring JMV witness addresses

Fix the unary language H in NTIME(2^n) outside NTIME(2^(n/2)), the allowance T=2^n poly(n), and the native, right-padded JMV reduction described below. An address occurs if it is one of the three variable labels in at least one actual indexed clause, including any genuine dummy or repeated label. Distance counts distinct such addresses, once each, irrespective of signs or number of occurrences.

**Either NP differs from coNP, or the following holds.** There is a fixed integer e≥1 such that, for every fixed κ≥0 and σ>0 with κ+eσ<1/2, there are infinitely many YES lengths n at which every satisfying assignment and every bounded-fanin Boolean circuit of at most floor(2^(σn)) gates differ on more than floor(2^(κn)) occurring addresses. The hard lengths may depend on κ and σ. In particular every fixed κ<1/2 in this range permits a positive σ. The circuit takes the entire padded address. Values on unmentioned addresses are immaterial.

Use the [unary hierarchy setup](https://raw.githubusercontent.com/openai/math/42907c9e999cc00d6abe7a50bfc1023250edd1b9/preprints/The-Exponential-Time-Hypothesis-is-False-October-25-2026/build/quantitative-circuits.tex) and the internal rules of [Jahanjou, Miles and Viola, Local reductions, revision 3, Theorems 7, 11 and 1](https://eccc.weizmann.ac.il/report/2013/099/revision/3/download/). The source specifies the reduction and the hierarchy supplies H. The proof below uses neither an exact counting premise nor completeness of H. It concerns this naming and the unary input. The [fixed-depth argument](jmv-native-unary-prefix-cover.md) uses a common depth. Here each region has its own complete binary prefix tree and sibling branches can have different depths.

## Variable-depth interaction bound

Use a constant set of headers identifying region and any finite subtype preceding the first long field. Reserve separate leaves for singleton dummy or constant names. Shorter header formats are interpreted according to the selected region; never parse a prefix of one region using the header width of another. For each header, a full binary tree reads successive bits starting at the beginning of its first long field. A leaf may occur at any depth from zero through the entire field, inclusive. It never reads a later field. Let B be the total leaf count across headers, including fixed leaves. For K the number of realized ordered triples of leaves, **K=O(nB)**, uniformly over the tree shapes.

For the overlay argument, fix a native clause case, its finite type choices and the operations applied to each child. On an ordered domain, three interval partitions with b₁,b₂,b₃ nonempty cells have at most 1+Σ(bᵢ−1) nonempty common cells: the union of the internal cuts contains every possible change of the triple. Pullbacks of trie leaves under a nondecreasing map are intervals, even for unequal depths and many-to-one maps. Restricting to cases realized by a decoder can only delete triples from the bound obtained by allowing the entire domain. Thus a case predicate depending on late counter bits need not preserve intervals.

* A local gate has address (i,j,ℓ). Internal children retain i. The raw configuration input for row i has address (i,s); a sorter output reached from that copy uses the same row before bit-position fields. Copying the same long identifier produces O(B) triples. A local x-Oracle edge may request one of at most n fetch outputs. Grouping by that output gives O(nB) pairs including repeated-literal permutations.
* Within the sorter, fix network and input/switch tags. On a switch edge the row w is copied, cyclically left-shifted by one, or left-shifted with a flipped leading bit. External configuration inputs copy their row. Fix the first and last bits of w, using at most four classes and treating lengths zero and one directly. Order each class by its remaining middle bits. All copy, single left/right rotations and specified end-bit flips preserve this common order, since each output is the same moving middle word surrounded by fixed bits. This remains true when the leaf reads the last row bit. The overlay applies jointly to BOTH children of an AND and the parent, even when they choose different operations. Constant children have one-cell partitions.
* In the fetch region (t,p,k,d,i,c), r=2 and each gate has at most one child. Select the finite operation and segment. Copy, one cyclic shift in either direction, a constant output or a coordinatewise AND with the chosen segment of x are the native operations. With x=1^n the mask is all ones on actual input sites. Use right padding if two equal-length segments require a spare position in the last segment; masking a fixed zero suffix is nondecreasing in lexical order, including at full depth. A bounded number of individually exceptional positions can alternatively be fixed in the partition, costing a constant factor. The shifts use the same boundary-bit stratification as the sorter. Digits masked to zero remain actual address digits for trie traversal. No argument assumes a one-hot p, a valid counter, or a reachable gate state.
* The configuration region consists of input labels. Forced-output, constant, dummy and repeated-variable clauses use at most the indicated singleton or two-address interactions and a constant number of orders. Unused finite tags with unspecified transitions use a constant/dummy clause, with explicit canonical naming. For declared regular fields, invalid states are processed by their displayed maps; they introduce no new operation on the first identifier. The native clause selector considers the original shared index, so arbitrary index words and padding bits cannot introduce additional unconstrained address maps. Right padding of variable names is fixed zero; it is distinct from arbitrary bits in a decoder index. An implementation extending the decoder with a new address map on malformed codes would require its own bound.

These cases use the address conventions and native transition audit of the [fixed-depth cover](jmv-native-unary-prefix-cover.md) and its [field-layout companion](jmv-native-bucket-triples.md). Allowing arbitrary coordinate masks or reading past the first identifier can break the overlay argument. A mask 0^a1^a makes a formal parent partition on the first a bits independent of a child partition that follows a fixed zero spine and splits on the final a bits.

## From a close circuit to small shard circuits

Suppose a satisfying assignment A disagrees with a baseline circuit C of size s on at most t occurring addresses. Start with one leaf per header. For each exceptional address in a nonsingleton region, split along the path to the FULL first identifier of that address, leaving every off-path sibling as a leaf unless another exception splits it. This makes at most O(1+nt) leaves. It does not fill the entire layer at the maximum depth. Distinct exceptional addresses with the same header and identifier go to the same leaf.

After the full identifier the remaining variable part of a *canonical occurring address* has O(log n) bits. For local labels the remaining j and inner gate ℓ take O(log log T) bits; for a sorter they are column, bit-position and fixed gadget fields of total O(log log T); for configurations it is the bit position in a configuration of polylog(T) bits. For fetch labels, after p one has the constant-width r=2 segment selector and direction, an input index of O(log n) bits and an O(log n)-bit logspace-machine configuration. Right-padding bits and the fixed header add no possibilities. Each full-row leaf therefore contains only poly(n) distinct canonical occurring addresses. Singleton headers are immediate.

Use C unchanged on leaves without exceptions. On an exceptional leaf evaluate C then toggle its output exactly on the listed exceptional full words. Equality with each complete padded word costs O(n) bounded-fanin gates, including checking the canonical padding. A disjunction of all these equalities and one final XOR suffice. Thus every leaf has a circuit of size s+poly(n), on the full address if convenient. The shard family agrees with A on every actual clause address. It may take other values on unused names. Its existence is what the verifier needs; it does not receive A, the exceptional set or C as advice.

**Canonical indexing detail.** Define the indexed formula by the typed native gate and wire names. At its binary interface parse the gate label according to its header, decode the clause, and serialize *each* of its three variable names from the typed fields with the stipulated zero padding, including the parent gate. Clause indices differing only in unused filler bits may repeat the same clause; alternatively reject noncanonical index fillers to a fixed tautological dummy clause, retaining a canonical index for each typed clause. The dummy clause can be (z OR NOT z OR z). This is an explicit polynomial-size local-index-to-clause algorithm (local here refers to generating one clause, not necessarily NC⁰ after a whole-field validation). It is an injective naming of the variables of the typed formula, up to repetitions of clauses and tautologies. It preserves satisfiability by the two-way assignment correspondence on these names. If unused fillers were instead copied through as fresh variable-name bits, the polynomial full-row population assertion would need a different proof. The argument below requires only polynomial decoder *circuit size*.

## Verification and time on all paths

Assume NP=coNP. Fix an ordinary nondeterministic multitape UNSAT decider with all paths bounded by O((L+1)^e) on an explicit bounded-fanin circuit encoding of length L, rejecting malformed encodings. Enlarge its fixed e≥1 for simulation, certificate reading, and tape resets once for all parameters. Choose rational κ and σ with strict slack κ+eσ<1/2. Allow B₀=O(1+n floor(2^(κn))) leaves and a cap S₀=floor(2^(σn))+poly(n) gates per leaf, with public constants and polynomial covering the fixed constructions above. Rational powers may be rounded using integer roots of explicit O(n)-bit integers. Small lengths can be handled separately.

On a unary length guess all region tries and all shard records once. Enforce their numeric caps and fixed record formats while reading them; reject overlong encodings without scanning an unbounded guess. Check that each tree has one root, every internal node has exactly two children with the prescribed prefix extensions, no cycles or unreachable nodes, and all leaves stop by the declared field length. For example guess nodes with explicit header and prefix strings in lexicographic order, sort the required child/parent records by key and join; duplicate keys, missing children, orphaned nodes and illegal depths reject. The finite singleton leaves require no children. A binary tree with b leaves has 2b−1 nodes. A gate record must reference only original address input bits, Boolean constants or earlier gate addresses. One table record per leaf, sorted by key, ensures that repeated tests cannot choose inconsistent witnesses. Construction and validation have polynomial overhead in n per node or encoded gate, rather than a quadratic scan of the entire guessed collection.

List reachable ordered triples of leaves by a breadth-first traversal of partial decoded output requirements. First split on the constantly many possible three headers. In each subsequent generation advance one next bit of each unresolved identifier, giving at most eight children; freeze finished trie cursors. Accept a child as feasible only if some q=n+O(log n)-bit clause index produces the specified header and prefix in each position. The decoder followed by these equality tests is an explicit poly(n)-size circuit. Guess the feasibility bit and certify YES by a concrete index and NO by the fixed nondeterministic UNSAT checker. Reject this path immediately on a failed certificate. Both answers thus have witnesses, and every continuing branch agrees with the true decoder. Unsatisfiability of H's entire indexed formula is never used as a feasibility test.

At any generation the nonempty states represent disjoint sets of terminal triples. There are at most K such states and O(n) generations. Rejected children and the first failed certificate give only a constant factor in the O(n(K+1)) bound. Batch requests for current trie records by sorting and merging with the ordered tree file; a full tree scan per generation costs O(nB₀ poly(n)) overall. This avoids random-access assumptions and scans of the B₀-record file separately for each request.

For each realized triple (a,b,c) generate a bounded-fanin Bad circuit on the original shared clause index. Check the three header-and-prefix memberships, use the true decoded signs and test that the three literals are simultaneously false using the three already-guessed shard circuits on the decoded full labels. Attach their descriptions by the sorted request/response join used in the [companion proof](jmv-shard-unsat-certificates.md). Record sorting costs the materialized bit volume times poly(n), including bounded-length addresses, even with repeated requests for one large shard. Check Bad is unsatisfiable via one accepting computation of the same clocked machine. Reject the branch immediately if any check fails. Any passing branch defines a single assignment satisfying every indexed clause; NO inputs cannot have a passing branch. On a YES length admitting small shards, some branch chooses their common descriptions and accepting certificates for every finite test.

With shard gate counts s_a, the verification clock includes the sum over realized triples of O(((poly(n)+s_a+s_b+s_c) poly(n))^e); it does not assume that a single shallow leaf has bounded interaction degree. Alternatively upper bound every s_a by S₀. Traversal, guesses and tape joins then fit within

    (n(B₀+K)+1) poly(n) + (B₀+K)(S₀+1) poly(n)
       + (K+1)(S₀+1)^e poly(n) ≤ 2^((κ+eσ)n+o(n)).

This bound applies to unsuccessful paths as well: malformed guesses are cut off while reading them, each failed feasibility attempt is charged only once at its point of rejection, every continuing path follows the same true feasibility answers, and all other submachines are explicitly clocked. The geometric bound applies to every syntactically valid guessed tree, irrespective of whether its guessed shard circuits are honest.

If all sufficiently large YES lengths admitted a satisfying assignment close to a small baseline, the resulting machine, rejecting nonunary inputs and hardwiring the finite exceptions, would decide H within the forbidden nondeterministic time 2^(n/2). This proves the stated quantifiers for rational parameters. For real parameters choose strictly larger rationals preserving the slack and weaken their conclusion on the same hard lengths. The tree may refine a few troublesome rows deeply while leaving others untouched. The gain over the elementary global circuit-size argument is the term κ+eσ: the UNSAT checker never receives a single gate list encoding all t point repairs, whose size alone could incur an eκ exponent. This establishes neither alternative of the disjunction individually.
