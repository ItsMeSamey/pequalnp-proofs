# Distinct affine demand hits at logarithmic rank

For k≥2 index t=2^{k+1} paths by j=(c,s) in F₂^k × F₂. Join opposite-shore terminals U,V by t internally disjoint length-three paths U—a_j—b_j—V. This is a simple planar bipartite graph: parallel arcs in the plane can be subdivided twice to obtain the given paths. A perfect matching uses U—a_j for one j, then b_j—V for the same j; every other path uses its middle edge. Conversely each j gives one matching.

The construction can even have maximum degree three. Replace each degree-t terminal by a path with t port vertices interleaved with t−1 spacer vertices. Connect each old incident edge to its own port in the old cyclic order. Draw the path inside a small disk around the terminal along the port order to retain planarity. Ports have the old terminal color and spacers its opposite. Each matching must use exactly one external port edge per replacement, since all t−1 spacers must be matched to distinct ports. Prescribing that edge leaves two even subpaths with unique perfect matchings, including empty subpaths. The unchanged outer edges at every old path therefore retain the previous bijection. This expanded root has 7t−4 edges. It is connected, simple and bipartite. It is an admissible root for the planar solver's named line-graph check; both its conflict line graph and its root are connected, and the root is neither of the exceptional triangle/claw pair.

Use one Boolean variable per root edge, the star clauses and every pairwise negative incidence conflict. For each nonzero v∈F₂^k add one positive demand D_v containing BOTH outer edges of each path with v·c=0. There are d=2^k−1 demands of equal size t. They are pairwise distinct, since distinct nonzero functionals have distinct kernels over F₂. Each demand contains two disjoint outer edges of a path and cannot be contained in a vertex star. After the degree reduction all outer edges across all paths are actually pairwise disjoint. Vertex stars restrict no edges. The source has no additional clique-contained demand or forced singleton. The residual demands are the full d sets.

On the matching for j every D_v has zero or two selected edges, so the XOR of its own designated edge indicators is identically zero. The genuine hit predicate instead is 1+v·c and is nonconstant. Let x_j be the U-side outer indicator and take L_i to be the XOR of x_j over indices with c_i=1. Exactly one x_j is one, so these k linear functions return the k individual c bits. Thus ALL d distinct hit functions have a common k-dimensional linear representation modulo constants. Rank is exactly k because all c tuples occur and singleton-coordinate functionals occur among the v. If rank instead includes the affine constant as an independent coordinate, rank is at most k+1. Any algorithm measuring rank in the affine span of the matching tuples obtains the same bound independent of the representatives' off-span coefficients. A procedure measuring raw coefficient rank without reducing modulo the common matching identities must be checked separately.

Requiring all hits forces c=0, since each unit vector indexes a demand. The exact source count is two, one for each s. Selecting the two outer edges of the (0,0) path and the middle edge of each other path, then using the unique terminal-path completions, supplies an original feasible edge assignment. Additional unused index bits increase this count by powers of two. The old solver preflights (1+h)2^d determinant calls for h allowed edges (h=7t−4 in the cubic version). All feasibility targets here are nonzero and the initial filters make no deletions. A matching-counter method using 2^rank times polynomial overhead pays only polynomial cost on this family, provided recognition of the affine hit information itself has polynomial cost.

The source has O(t²) literal occurrences and O(t) edge names in the degree-three version. The strict ordered ring compiler has O(t²) physical variables and rows: its incidence expansion is linear in source variables, clauses and literal occurrences. It uses precision O(t²), with each canonical residue of at most O(t²) bits. Thus the explicit physical bit length B is at most O(t⁴+t² log t) and at least d. The logarithmic affine rank is O(log B); the old displayed exponential call reservation is superpolynomial in B. This comparison concerns the two parameterizations on identical inputs.

For exact size accounting on the expanded root write h=7t−4. There are 6t−2 vertices: 2t−4 of degree three and 4t+2 of degree two. The conflict rows number 3(2t−4)+(4t+2)=10t−10. The recovered source on h variables has C=16t−12+d rows and L=34t−28+td literal occurrences, since the stars use 2h occurrences and the conflicts use twice their row count. No clause repeats a literal. For the selector-free compiler the pre-expansion hard-core graph therefore has e=3h+L=55t−40+td edges and v=3h+C=37t−24+d vertices. Applying the compiler's dimension formulas gives exactly 46e+26v+1 physical variables, 45e+27v+2 positive rows, E=13e+6v expanded edges and precision K=E+h+1. The physical multilinear value is 2(−15)^E modulo 3^K. It has valuation E<K, so it is nonzero on every member of the family. The source witness above assigns recovered source edge variables; physical Boolean all-ones satisfaction alone does not establish that residue.
