# A sortable occurrence encoding with efficiently invertible clause incidence

Take the unary JMV instance with q=n+O(log n) index bits and three signed d-bit addresses, d=O(n). Its canonical decoder D has O(n) ordinary binary gates and is generated in poly(n) time. Only these properties are needed. Put h=q+2. The replacement uses h+O(log n) bits per variable name and per clause index. It recognizes exactly the same lengths. [JMV revision 3](https://eccc.weizmann.ac.il/report/2013/099/revision/3/download/) and [canonical forward decoder](jmv-october-nearlinear-hamming-rigidity.md).

Allocate all 2^h occurrence rows r=(i,p). Ports p=0,1,2 have keys equal to the three addresses of D(i) and free one-bit payloads. Port 3 repeats the third key with its own free payload. Row (i,0) owns a clause testing the three free payloads with the signs from D(i). Pin each initial key bit by a separate unit with value supplied by D(i). No variable names are derived from decoded address values.

Sort the records in ascending unsigned key order by a bitonic network. Iterate k=1,...,h and within each k use j=k−1,...,0. Pair r and r XOR 2^j. The lower lane has bit j zero. A comparator sorts ascending if bit k of r is zero and descending otherwise, extending the row by a fictitious zero top bit h. Both lanes read both predecessor records in lower-lane-first order. Each computes its own copy of the strict order comparison in the required direction. Swap only on strict inversion, and apply the same decision to every record bit so ties preserve both payloads. Scan keys from the most significant bit with equal-prefix and less-than-prefix flags and a constant number of binary gates per position. The selector drives a constant-size mux per key or payload bit. These gates belong to the output lane. Each k merges oppositely sorted halves into a sorted 2^k block with direction alternating by block, ending with a single ascending block. This is the standard bitonic merge using successively halved comparison distances. [Batcher, Sorting networks and their applications](https://doi.org/10.1145/1468075.1468121).

For every final row except the last, compare its key with the following row's key by a bitwise equality scan. Enforce the implication from equal keys to equal payloads with binary gates and a unit on the result. No wraparound. All Boolean gates receive definitional width-three clauses. A satisfying original assignment supplies all input payloads and determines all gate bits. Conversely each equal-key run has a common payload. Assign it to its original address and fill absent addresses arbitrarily. The source clauses ensure satisfaction.

**Names and incidence.** Use one h-bit owner row and fixed fields for a finite task type, k, j, bit position, and finite microgate type. Numerical auxiliary fields have O(log n) bits. Absent fields must be zero. Use separate task types for source clauses, initial bits/pins, layer gates, final consistency gates and assertions. Choose fixed finite gate microtemplates per scan cell, boundary and mux. Each real gate has exactly one output name. Wires refer directly to their producing gate names. Initial payloads and key bits supply layer zero. The predecessor layer of (k,j) is (k,j+1) if j<k−1 and (k−1,0) otherwise, with the initial exception. Append a finite forbidden-row selector for the gate's truth-table clauses, only one per input pattern and wrong output bit. Source clauses and units have one selector. Pad short clauses by repeating a literal. The forward decoder returns an active flag, three names and signs. Invalid fields, noncanonical encodings and unused selectors are inactive and Bad is false there. If an ordinary total 3-CNF decoder is preferred, give each inactive index its own tautology on a fresh private variable named by the full index. An additional namespace tag and canonical padding keep widths h+O(log n). Each private variable has at most one incident index.

Auxiliary field comparisons, increments and decrements cost O(log n) gates. Selecting row bit j or k costs O(h) gates. Producing all one-hot indicators of j together costs O(h) via the binary prefix tree, so generating both partners costs O(h) altogether. Adjacent final rows use one ripple increment. Selecting a fixed template takes O(1) gates per output bit. Pin generation runs D(i) once and selects an address and bit by linear-size mux. Remaining tasks copy and select fields. Thus the complete generated forward decoder uses O(n) ordinary binary gates. This is a circuit size bound, irrespective of decoder depth.

For a variable name at row r enumerate candidate owner rows r, r XOR 2^j for every j<h, in-bounds r±1, and the four replacements of its low two bits. For each enumerate every auxiliary clause field tuple and selector, run the forward decoder and keep the active indices containing the exact full name. Deduplicate. This takes poly(n). Source references, pins, layer-local gates, cross-layer predecessors and final adjacent references exhaust all cases. This includes the comparator selector's full fanout. Invalid names have no active incidents.

**Exact patch count.** Count violating active indices for a guessed baseline C once using Bad_C, of size at most 3|C|+O(n) on h+O(log n) bits. Given t distinct full names and replacement bits, enumerate and deduplicate the union of their active incident indices. For each affected clause subtract its baseline violation indicator and add its patched indicator. Sort all literal requests by name, merge against sorted patches, and regroup by index. All multitape work beyond the baseline count is (1+t)poly(n) for polynomial-size C, including evaluating C, sorting, and O(n)-bit signed counters. Reject malformed guesses before counting. Well-formed unused addresses are harmless. The result is exactly the violation count of a single total assignment. Unique-extension Tseitin conversion allows use of the [October fixed-density counting theorem](https://raw.githubusercontent.com/openai/math/42907c9e999cc00d6abe7a50bfc1023250edd1b9/preprints/The-Exponential-Time-Hypothesis-is-False-October-25-2026/build/main_full_version.tex).

For a fixed language known only to be outside NTIME(2^(n/2)), a contradiction requires the combined baseline count and patch work to fit that clock. Inverse-polynomial distance over all h+O(log n) address bits would require paying for up to 2^n/poly(n) patches. This needs a near-tight hierarchy bound for the chosen language or a separately chosen near-tight language with the same transformation. The encoding itself does not strengthen a previously fixed hierarchy gap.
