# One additional bucket triple can force an exponential shard

Assume P=NP. Start with the unary hierarchy language H and its locally decoded formulas Φ_n in the [native prefix note](jmv-native-unary-prefix-cover.md), with clause indices of width n+O(log n), and bucket width b=⌊βn⌋ for fixed 0<β<1/2. There is a different uniformly locally decoded formula family Ψ_n for the same H. Its bucket triples consist of tagged native triples and one additional triple inside a reserved bucket. At all sufficiently large YES lengths, every satisfying assignment for Ψ_n requires a circuit larger than ⌊2^{⌊αn⌋/2}⌋ on that reserved bucket, for a constant α>0. The original Φ_n and its witnesses are not the subject of this construction.

**Predicate on explicit tables.** At a power-of-two input length N, interpret the input Y as a complete truth table on log₂ N bits. Accept Y if no bounded-fanin binary Boolean circuit of size ≤⌊√N⌋ computes it. At other lengths reject. The complementary property on power-of-two lengths has a polynomial verifier: guess the gates, evaluate on all N inputs and compare with Y. Thus under the assumption there is a fixed deterministic polynomial-time decider. For sufficiently large N a hard table exists since circuits of that size have only 2^{O(√N log N)} descriptions and there are 2^N tables. All accepted tables have the required hardness; no canonical choice or witness extraction algorithm is needed.

**Local names for actual table bits.** The fixed decider has logspace-uniform polynomial-size circuits on Y (for example the polynomial-time machine's unrolled local computation), using AND, NOT, constants and input gates. Normalize the original gate labels to a fixed-length type namespace with the primary-input index j in fixed bit positions on each input label. Use a distinguished known output gate of known type, padding by two negations if needed. Fill unused original addresses with constant gates and define their putative child requests to return a fixed constant as well. These conventions are logspace uniform and preserve polynomial size. Apply the construction of Jahanjou, Miles and Viola, Theorem 5. It places the child gate's original label and type at fixed positions on the tape of the connection machine at termination. The machine may copy the normalized j field there before halting within its logarithmic space and polynomial clock. The localizer simulates one step per Copy gate and identifies final configurations using one timestep bit. The type bits sit at fixed tape positions. The localized output has a known address from the normalized output label, type and final timestep. The theorem constructs its local decoder in time polynomial in log N. [JMV revision 3, §2, pp. 8–10](https://eccc.weizmann.ac.il/report/2013/099/revision/3/download/)

Append N distinct fan-in-zero variables with names (port,j); these are the free physical ports Y_j. Replace every localized gate of type Input with a Copy of the port obtained by reading j from the fixed tape field. Each bit of the new child label is a constant or a copied bit, selected using constant-size type information. This applies to every such label, including final configurations not on a valid simulation. Since N is a power of two, every j-field names an existing port. The original proof handles all localized labels: from an arbitrary nonfinal configuration the timestep update eventually reaches a final one; a final AND/NOT transition starts a clean child computation on an original gate label. Uniform padding makes every such label valid. Reserved type codes may be constants. Equivalently, after the first reset, traversing completed valid gate computations descends the acyclic original circuit. Attaching the Input gates to the new sinks cannot create a cycle. Consequently *every* choice of physical table Y extends consistently to all gate clauses by gate evaluation, including labels outside the computed output cone. On the designated output cone, the simulation computes exactly the decider on Y. Enforcing output one therefore admits exactly the hard choices of Y.

**Combining the decoders.** Let L=⌊αn⌋, N=2^L and choose c so both the localized gate name and the gadget clause index (including a constant number of control, subregion and clause-selector bits) have width ≤cL+O(1). This fixed c depends on the decider and its uniform connection machine. Choose rational α>0 with cα<1/2. Add disjoint external tags to the native and gadget names. Form the native address by prefixing a zero and retaining the old address fields, with enough extra fixed right padding to preserve injectivity. Its new first-b-bit prefixes correspond to the old first b−1 bits, so tagging cannot increase the native triple count. Prefix every gadget label by one followed by floor(n/2) zeros. The entire gadget then occupies the single b-bit prefix 10…0 for every fixed real 0<β<1/2 at sufficiently large n, without computing β. After the full reserved prefix use constant-size subregion tags, payload and fixed padding. In particular the suffix of port j is just constants and the bits of j. Increase the common variable-label width by a constant or choose a larger fixed D in Dn if necessary. The inequality floor(n/2)+cL+O(1)≤n holds eventually. Handle finitely many small lengths separately.

An external clause-index tag selects either the old decoder or the gadget on its low index fields. The joint clause-index width is n+O(log n); surplus high bits in a shorter branch are ignored, duplicating existing clauses. Tseitin clauses for any localized gate are emitted using its type, up to two child labels and a constant-size selector; pad short clauses by repeated literals. A control selects the forced output unit. Input-port or unused selector cases can emit a tautology on one gadget port. All output bits of this decoder have constant locality and the description is generated in poly(n) time. Every gadget clause uses the same ordered bucket triple. The disjoint conjunction is satisfiable exactly when Φ_n is, since its added predicate admits a hard table independently. At finitely many small lengths use the native formula alone if needed.

For any satisfying assignment, hardwire its reserved-bucket shard's suffix inputs to the port subregion constants and the bits of j. Wire copying and fixing constants incurs no gates in the stated circuit convention. The restricted circuit computes the entire accepted truth table, so the shard needs more than ⌊2^{L/2}⌋ gates. In particular it cannot have size 2^{o(n)} at these YES lengths. A specified rate 2^{σn} is excluded by this estimate when σ<α/2. The construction does not guarantee that inequality for an independently prescribed σ, and its extra bucket does not change which lengths belong to H.
