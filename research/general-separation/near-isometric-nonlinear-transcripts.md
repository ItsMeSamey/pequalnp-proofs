# Near-isometric witness fibers hitting all low-degree physical tests

Use the Boolean function ring over GF(2), with squarefree algebraic normal forms. Fix B>0 and D=max(1,floor((floor(log2 q))^(1/4))). For each q-input Boolean fanin-two circuit of size <=B q log2 q there is a uniform polynomial-time SAT-equivalent circuit of size <=B N log2 N with N-q=o(q/sqrt(log q)). Every fixed logical witness has a physical fiber meeting the support of EVERY nonzero degree-at-most-D Boolean polynomial on all N physical bits, even when the test depends on the circuit syntax or on the logical word. Equivalently, no nonzero such polynomial vanishes throughout a fiber. The zero set of a nonconstant test is also hit. A full SAT algorithm with the target exponent saving on the compiled image therefore transfers to arbitrary circuits of that gate budget by ordinary composition.

There are D independent seed blocks. Each has ceil(log2 q) pointer bits and D+1 activation bits. For j=1,...,q let h_j(s) be one iff the pointer encodes j-1 and all activation bits are one. The physical data bits y decode by x_j=y_j+sum_i h_j(s_i). Use additional unrestricted padding bits as specified below. Every logical word lifts (take inactive seeds). Over the vector space of all functions of one seed block, the h_j are linearly independent modulo the subspace of degree-at-most-D functions. Every nonempty binary sum is the full activation monomial times a nonzero pointer function, which has ANF degree at least D+1. Thus for each j there is a linear functional that annihilates the entire degree-at-most-D subspace and takes value one on h_j and zero on every other h_l. These analytical functionals need not be constructed by the compiler.

Fix x and a nonzero P(y,s,pad) of degree <=D. In its ANF choose a term y_J M of maximum data degree e=|J| and, subject to that, maximum remaining degree k=deg M. M uses seed and padding bits. There are e distinct seed blocks containing no variable of M since e+k<=D. Assign each of the distinct data indices in J to one of these clean blocks in a fixed bijection. On each clean block apply the preceding linear functional for that index. On all remaining bits apply extraction of the multilinear coefficient of exactly M. These linear maps act on disjoint variable sets and can be applied in any order.

Substitute the expression for y in terms of x and the seeds. Every expanded term from data degree <e leaves at least one clean block without an h factor; its restriction there has degree <=D and is killed. A surviving term from degree e must allocate exactly one h to each clean block and none elsewhere, using no constant x_j choice. Thus all its dependence on variables outside the clean blocks comes exclusively from its original seed/padding monomial. Extraction of M requires at least k such variables; by maximality its full nondata degree is <=k. It follows that its nondata monomial is precisely M, with no clean variables. The clean functionals then force exactly the selected data indices in exactly the assigned order, leaving the chosen original ANF term with coefficient one. The projected result is nonzero, proving the claim. This argument also covers e=0.

In each seed block construct all onehot pointer literals by prefix decoding in O(q) fanin-two gates: ceil(log2 q) bits have <2q complete words. Compute the activation AND and attach it to the q outputs. Taking all q sums across D blocks costs O(qD) further gates. Use an absolute fixed upper constant K on the total decoder gate count KqD for sufficiently large q. With lambda=floor(log2 q), add ceil(C_B qD/lambda) free physical input bits for any fixed integer C_B>K/B. Even if they are ignored by the decoder these bits remain free in all tests, as the coefficient proof allows. This buys the extra gates within the original B N log2 N bound. N-q=O_B(qD/lambda+D(log q+D))=o(q/sqrt(log q)), and all parameters and wires can be built in polynomial time. Fixed small lengths may be handled separately.

For a consistent transcript of polynomial probe outputs multiply their Boolean indicators. Its degree is at most the sum of probe degrees (an implied probe can cost less). If this sum is <=D, the product is a nonzero physical test, so the whole transcript occurs inside each logical fiber. This holds path by path for adaptive probes, and rules out discarding a globally consistent branch on the ground that every logical witness avoids it. It does not bound decisions from inspecting the circuit, parity of intersections, nonlinear reparameterization, or the algorithmic cost once the cumulative degree budget is exceeded. All decoded witness bits refer to a single common physical seed choice.
