# Evaluating positive read-twice CNFs over fixed finite fields

Fix a finite field K of size p^d and its field representation. The input is a positive CNF of width at most three with exactly two occurrences of each variable, and one point over K in its raw variables. Evaluate its unique multilinear extension at that point.

**Theorem.** The full value is computable in deterministic polynomial time when |K| is two or three. For every |K|>3 the problem of deciding whether the value is nonzero is Mod_p P-complete under deterministic polynomial-time many-one reductions. In fact one value-preserving evaluation computes the accepting-assignment count modulo p of an arbitrary Boolean circuit. Conversely, the d base-field coordinates of the value are accepting counts modulo p of polynomial-time nondeterministic machines. The field is fixed. Every formula produced by the reduction has only nonempty clauses and accepts the all-ones word. A supplied formula with an empty clause has value zero.

For the binary field evaluate the Boolean formula. For the ternary field use inclusion–exclusion on the clauses. A raw variable of failure weight 1−x=0 forbids its incident clauses from the inclusion–exclusion subset. Failure weight one contributes no factor. Failure weight minus one contributes a sign raised to the OR of at most two clause bits. This exponent is quadratic over the binary field. The residual sum of signs, including the inclusion–exclusion sign, can be evaluated modulo three by eliminating quadratic pairs. At all coordinates equal to two the value is the number of satisfying assignments modulo three times the sign (−1)^n, where n is the number of raw variables. The algorithm allows arbitrary clause width under the same read bound. [Quadratic elimination and bit clock](positive-read-two-ternary-evaluation.md)

For a larger field choose a fixed t distinct from 0,1,−1. Apply the construction of the [positive CNF projection](read-twice-positive-cnf-projection.md) to the supplied source circuit's gate-equivalence CNF, pinning its output to one. Include a complementary literal pair for each declared input even if it is unused. An accepted original input has exactly one consistent gate assignment. Omit the arc indeterminate selectors because all accepted assignments have weight one. The complementary pairs, one minus-one mediator per pair, and the signed-clause mediators give a hard-core partition sum equal to the number of accepted assignments in K. Its value lies in the prime subfield. The cloned graph, six-edge equality paths, two-edge physical interactions with failure weight t and private activity calibrations implement this sum exactly. The repeated unit clause normalizes by the inverse of the nonzero global scalar. Completing the private variables yields exactly two occurrences and width at most three. All physical weights are elements of K and the output can be written in polynomial bit time. Thus a single field evaluation recovers the source count modulo p. For a polynomial-time nondeterministic machine its accepting paths can be encoded by a polynomial-size Boolean verifier with unique padding after halting and invalid branch encodings rejected; the same construction applies.

For the upper bound, select a raw Boolean assignment nondeterministically. If it satisfies the CNF, compute its interpolation weight by multiplying x_i or 1−x_i according to its bits. On that branch generate exactly as many accepting choices as the representative from 0 to p−1 of any specified coordinate of this weight. Rejected words contribute none. This realizes each output coordinate as a modular count. Sums of counts use a choice between machines, products use sequential guesses, and multiplication by p−1 implements a negative sign. For coordinate residues b_i, the expression 1−∏_i(1−b_i^(p−1)) in the prime field is zero exactly on the zero vector and one otherwise. The constants p,d are fixed, so a single polynomial-time nondeterministic machine realizes this expression modulo p. This proves membership under the nonzero-residue convention for Mod_p P.

The numerical algorithm over the three-element field gives no algorithm for its extension-field points, and the size lower bound for the formal polynomial gives no numerical hardness on that base field. Hrubeš established earlier all-field formal hardness for multilinearizations with less restricted read counts. Valiant studied a distinct planar modular counting regime for positive read-twice CNFs. The classification here concerns arbitrary input graphs and weighted points over a specified finite field.
