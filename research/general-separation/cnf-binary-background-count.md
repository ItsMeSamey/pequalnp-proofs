# Counting on a mandatory binary background

[solve](cnf_binary_background_count.py) accepts a nonnegative declared arity, signed one-based clause rows and optional nonnegative max_terms. It returns a sparse original witness on a positive count and a count pair (mantissa, unused_exponent) representing their product mantissa·2^unused_exponent. The component solver requires no table indexed by the declared arity. An ordered-image consumer can expand this pair after validating the arity against the explicit physical fields. A surviving clause wider than three dispatches the whole original input to the [unrestricted clause-miss counter](cnf_miss_span.py), which uses the same factored-count and cap convention. Arbitrary-width tautologies are removed semantically.

For normalized width at most three the [restricted-rank kernel](cnf_binary_background_rank.py) tests feasibility of the entire binary background B and retains k ternary rows whose simultaneous satisfaction, on B-models, is equivalent to that of all original ternaries. The following computation keeps *every* mandatory B constraint. Infeasible B gives zero by its polynomial test. Let h be the number of distinct variables in B and the selected rows, ignoring tautologies. Build the simple graph of the distinct-variable binary clauses of B, including h-variable isolates. Repeatedly peel a vertex of degree at most one, or else remove a maximum-degree vertex into the feedback set F, breaking ties by ID. A traversal of the original graph with F removed independently verifies acyclicity and records parents. The exponent f is the actual size of this discovered F. No optimality assumption is used.

For a fixed prefix of witness pins and each inclusion–exclusion subset of the k rows, force every literal in the selected rows false. Contradictory pins contribute zero. Otherwise enumerate every assignment to F, reject contradictions with the pins and substitute in B. False empty restrictions contribute zero; an unpinned singleton forbids one vertex state. A surviving binary clause forbids precisely one ordered child/parent state pair. Combine all such forbidden pairs on each forest edge. Initialize both unary counts to one except for forbidden or pinned-out states. In descendant-first order, for each possible parent value multiply by the sum of the child's two compatible counts. Conditional independence of child subtrees proves this recurrence. Multiplying root sums counts all assignments to the remaining free variables. An unpinned isolate pays two; a pinned isolate pays one. Sign each subset by its parity, then sum. This is an integer conditional count, including the empty forest and any disconnected components.

If the unconditional count is positive, greedily keep a false next bit whenever its conditional count is positive and use true otherwise. At most h additional conditional counts suffice. Validate the resulting assignment against every raw source clause, setting unmentioned variables false. If u counts the original variable IDs that occur (even in tautologies), multiply by 2^(u−h) for those dropped from active constraints and return the separate exponent arity−u for never-mentioned variables. Both the mantissa length and the sparse witness depend polynomially on explicit input length per operation. No global #2SAT primitive is used.

The forest mode charges one unit per tested feedback assignment inside a selected subset, whether its pins conflict or its message result vanishes. A subset inconsistent even before the feedback loop costs one unit. All witness calls share the same budget. Thus actual terms are at most (h+1)2^(k+f), including witness recovery. The implementation instead uses the complete 2^h assignment scan when that numerical bound is smaller or tied. Each term and all rank/forest preprocessing cost polynomial bit time in the explicit source. Intermediate signed counts need O(h+k) bits. Workspace is polynomial. Exhausting max_terms returns unknown with terms, available and the number of the next required term. The default is uncapped. Exact zero is distinct from budget refusal.
