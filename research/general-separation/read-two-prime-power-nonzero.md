# Decision and search from nonzero evaluation modulo a power of three

The target takes a positive CNF of width at most three with every raw variable occurring exactly twice, success coordinates modulo 3^k, and a positive precision k charged numerically, for example in unary. It asks whether the canonical multilinear extension has nonzero residue. This problem is polynomial-time many-one equivalent to deciding whether a signed 3-CNF has a model count nonzero modulo a supplied power of three. SAT reduces by a single query. As an oracle the target suffices to compute exact #P functions in deterministic polynomial time.

**Clearing the one forbidden denominator.** Use the [formal projection](read-twice-positive-cnf-projection.md) and [signed frontend](read_two_prime_frontend.py) at rational t=4. Let E be the edge count after incidence splitting. The final normalization variable has success (1−t²)^(−E) and occurs only in two repeated unit clauses. Set that success to one. The pair of units on a fresh variable has multilinear extension equal to its single success coordinate. The remaining value over the rationals is

    (1−4²)^E Z = 3^E (−5)^E Z,

where Z is the original source model count if selectors are omitted, or its selector-weighted sum otherwise. Every remaining parameter has denominator coprime to three. Half-edge successes are 1−4. Both q=4/5 and q⁻¹ are 3-adic units. Each site's baseline −(q^deg) is a unit. A private failure divides a signed activity by a product of such baselines or is an integral selector-related weight. The guards have success one. Replace the old normalization weight before mapping the other parameters to Z/3^kZ by inversion of their denominators. The displayed identity then holds for all k.

For a signed source on n declared variables without selectors take k=E+n+1. A positive count is at most 2^n, less than 3^(n+1); the multiplier (−5)^E is a unit. Nonzero at the supplied point is therefore equivalent to ordinary source satisfiability. First test feasibility, then successively try pinning each source bit to zero by reducing the restricted formula. If its target evaluation is zero, use one instead. At most n+1 decision queries yield an original assignment on satisfiable inputs, which can be verified directly. Even when the source is unsatisfiable the positive target formula admits the all-ones Boolean assignment. A polynomial-time arithmetic decision algorithm at arbitrary precision would put SAT in P.

E and the physical formula size before indexing are linear in the explicit source incidence count including the declared variables. At t=4 the exact rational weights and the discarded scalar have polynomial bit length, because the exponents in baseline products are O(E) plus the number of sites. Each target coordinate costs O(k) bits to write. Integer arithmetic, modular exponentiation and Euclidean inversion take polynomial bit time in the input plus k. The [reference frontend](read_two_ring_nonzero.py) keeps the topology including the final units, uses zero-based target indices and chooses k=E+n+1. The comparison reductions below sometimes choose another precision by reducing the very same unnormalized rational weights modulo that power.

**Modular decision comparison.** Given a signed formula and requested source precision j≥1, choose k=E+j. Divisibility of the target numerator by 3^k is equivalent to divisibility of Z by 3^j, including Z=0. Conversely for arbitrary target points let a_i,b_i denote the least nonnegative residues of p_i,1−p_i. Guess a Boolean assignment satisfying all target clauses, then one independent binary integer u_i of fixed bit length ceil(log₂(3^k)) per coordinate. Accept only when u_i<a_i for assigned ones and u_i<b_i for zeros. The accepting count is the sum of the required products of integer multiplicities, congruent to the interpolation value. Encode deterministic verification by 3-CNF with uniquely determined gate bits, retaining all guess inputs. This proves the converse polynomial-time many-one reduction with the same k.

For two Boolean circuits with h common input bits, use a branch b to accept the first at b=0 and the second at b=1. A deterministic combined verifier has a unique gate extension for every (b,x). A selector −1 on b makes the source sum Z the difference of the counts; its private weights are still integral or have unit denominator. Choose j larger than the bit bound on |Z|. Then the nonzero query tests inequality of the two counts. Canonical fixed-length guess padding gives the same reduction from the nonzero test on any GapP function. This is coC_=P-hardness under many-one reductions; it does not establish membership of the target in that class.

**Exact counting with a decision oracle.** For a circuit C on h inputs maintain a=#C mod 3^(j−1), starting at zero for j=1. For d=0,1 test whether #C is congruent to a+d·3^(j−1) modulo 3^j. To do this with no signed selector, form a fresh disjoint branch accepting exactly c guesses, where c is the least nonnegative residue of −a−d·3^(j−1). A binary test u<c realizes it. Equalize witness lengths by forcing all surplus bits zero in the corresponding branch. The combined formula has count #C+c. The forward reduction at E+j tests the desired congruence; E is taken for the newly combined formula. If neither test gives a zero residue, the next digit is two. After at most two decision queries per digit and 3^j>2^h the maintained count is exact. Every operation is polynomial in the original description and h. Conversely the multiplicity verifier above computes the target with one #P evaluation and a modular reduction. Thus deterministic polynomial time with this nonzero decision oracle equals deterministic polynomial time with a #P oracle. This is a Turing comparison, distinct from the many-one equivalence above.
