# Simultaneous coordinate bases for arbitrary normal spaces

Work in V=GF(2)^n on compressed used variables or on the free coordinates left by affine-hull closure. Given k explicitly based subspaces, decide whether one basis of V induces a basis of each by taking a subset. Start with any ambient basis. Process spaces sequentially, maintaining a compatible basis for the preceding spaces S_i.

Partition this basis by exact membership signature T={i : e belongs to S_i}. At most n blocks occur. For any signature T, including one not realized, put U_T equal to the intersection of S_i over i in T (empty intersection V) and V_T equal to the sum of U_T intersect S_j over j outside T (empty sum zero). In a compatible basis U_T is the span of all blocks with signature containing T. V_T spans all blocks whose signature strictly contains T. Consequently dim(U_T/V_T) counts the axes of exactly signature T and is independent of the maintained basis. No other signatures can appear in any compatible basis.

For an incoming space W and each realized T, take d_T equal to the dimension of the image of W intersect U_T in U_T/V_T. Select d_T representatives in W intersect U_T whose classes span that image, then extend their classes to a full quotient basis using original axes of the T block as needed. Use all these representatives as replacement basis vectors for the T block. Membership in U_T puts nonzero coordinates only in blocks containing T, and the diagonal block is invertible by construction. In a linear extension of subset order this is an invertible block triangular change. All S_i remain coordinate: replacements of every block containing i stay in S_i, are independent and preserve their total count. The selected W vectors are therefore independent. If their count equals dim W, they span W and we have a new compatible basis. Otherwise reject. Indeed, in any basis compatible with W and all S_i, the number of axes in W having old signature T must equal d_T, by the same coordinate intersection and projection identities. Summing these intrinsic values would give dim W. This establishes exactness, including zero/full/duplicate input spaces. The n=0 case uses the empty basis.

One implementation works in the current basis coordinates, computing U_T and V_T via containment among at most n bit-signatures of length k. For each block use Gaussian elimination to intersect W with the coordinate subspace U_T, project to its T block, and select independent projected rows retaining original lifts. Extend by standard block coordinates. Reconstruct the ambient basis matrix and update the signatures of the replacement vectors by membership in W (or directly by their assigned W/non-W labels after a successful count test). Dense scalar bit complexity O(k n^4 + k^2 n^2 + input length) suffices for n>=1 using ordinary cubic elimination within each block and explicit signature comparisons, up to harmless indexing overhead. Keeping original ambient representatives allows direct output of the basis.

## Source use and two tractable signed fragments

Each explicit group of forbidden assignments with affine shape yields a normal space with an affine offset, after projecting to reachable support as needed. Obtain its basis by taking the normal rows. A common chart represents it by one clause of width equal to its codimension: each included chart row v has a unique expression in the input normal basis, and the dot product of those expression coefficients with the affine offset gives its forbidden bit. One can also evaluate the row on any full preimage of the forbidden anchor. Keep a separate signed clause for every distinct input forbidden coset. The returned chart alone poses no restriction on the width-three SAT problem.

* In the selected chart, find polarity reversals making the resulting CNF Horn. For each pair of literals in each clause forbid both becoming positive; this is a 2CNF on the reversal flags. After a successful reversal solve Horn SAT by forward chaining, undo flags and solve the independent chart equations to recover the source witness. Failure certifies absence of reversals for this basis only. Running this path in a portfolio preserves every pre-existing solved case.
* Alternatively search for a beta-elimination order in the support hypergraph: repeatedly remove a variable whose incident remaining supports are totally ordered by inclusion. If an elimination order exists, any such variable can be taken first, since deleting that variable from a witnessing order preserves each other required inclusion. The support hypergraph in different simultaneous bases is isomorphic: the multiplicity of each membership signature is intrinsic. Thus this test is independent of chart choice. During Davis–Putnam elimination, each non-tautological resolvent at this variable equals its larger parent minus the variable: on the overlap, signs must agree. The number of distinct new clauses is no greater than the number removed, and each current surviving scope descends by restriction from an original support, preserving the nest order. Record removed parents; given a model of the projected formula at most one value for the pivot can be forced by the parents, since contradictory demands violate a resolvent. Reverse the elimination restoring a model or detect the empty clause. This is polynomial in the explicit bit length using pairwise parent comparisons. Gaussian-lift the resulting assignment and check the original source.

A single positive ternary clause, and any conjunction of disjoint positive ternaries, passes this hypergraph test but cannot have a forbidden width-two affine-cylinder representation on its own three-dimensional slice. The extension does not depend on the availability of a zero-rank branch or preprocessing. Overlap and arbitrary parity rows are allowed throughout. No general SAT time bound follows.
