# Simple cubic signed formulas over the three-element field

The [compilation proof](../site-team-01/signed-read-two-cubic-mod3.md) maps each source 3-CNF to a simple cubic graph and then a signed formula with exactly three distinct raw variables in each clause. Each raw variable occurs in two distinct clauses, once with each polarity. At the all-2 point its canonical multilinear extension equals the source model count modulo three. The optional disjoint K₄ adjustment makes the target Boolean model count itself agree modulo three. The map and both outputs have linear size in the declared source variables, clauses and literal occurrences. For example the equality stage has 2e+v links before filling, and the degree-completion stage attaches at most three fixed 23-vertex fragments per vertex of the subcubic graph.

The decision problem proved Mod₃P-complete is whether the residue is nonzero. Counting accepting guesses for Boolean assignments proves membership because the interpolation multiplier is an invertible sign. For the ordinary Boolean SAT decision every nonempty component of the emitted graph has a cycle. Orient that cycle cyclically, orient a spanning forest outward from it and orient all other edges arbitrarily. Every vertex receives an edge. Set each raw bit to satisfy its literal at that edge's receiving endpoint. This satisfies every target clause, even for a contradictory source. The empty graph gives the empty conjunction. Thus an exact zero residue can encode a contradiction in the source while the target remains satisfiable.

**Source dependencies.** The [constant equality signature](read-twice-positive-cnf-projection.md) precedes this refinement. The [earlier balanced point-2 proof](f3-balanced-read-twice-point2.md) already establishes Mod₃P-completeness at width at most three and separately gives a weighted Hamiltonian-cycle projection. The cubic fragment proof adds exact width, a simple clause graph and integer-residue normalization. It makes no external priority claim or extension of the latter symbolic projection to this cubic map. The [general signed evaluator](signed-f3-core-integration.md) has a broader input domain.

**Independent executable check.** The [standalone checker](check_signed_f3_simple_cubic.py) builds source, equality, sign-removal and cubic-completion gadgets and emits ordinary signed clauses. Its contraction reconstructs every edge table from the emitted literal occurrences and the two raw interpolation weights, checks simplicity/width/polarity, and eliminates clause spins over F₃. No gadget signatures or compiler bookkeeping are supplied to the contraction. Only tiny source assignments are enumerated. Cases include a contradiction, a satisfiable zero residue, empty source and empty clause, a duplicate literal, a tautology, an unused declared variable and both normalization choices. The width cap aborts an unsuitable elimination order. No execution is claimed by this source manifest.
