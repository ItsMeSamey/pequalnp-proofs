# Recognizing the ordered selector-free ring image

[recover](read_two_ring_image.py) takes only the four raw fields (n, clauses, point, k) produced by [the ring compiler](read_two_ring_nonzero.py). It returns (a, Φ) on the image, where a is the source arity and Φ is one ordered signed source formula whose recompilation has exactly these fields. It returns None off the image. Clause order, literal order, variable numbering and canonical residue representation are part of the encoding. Lists and tuples represent the same sequence. Syntactically different source clauses may give the same output because the compiler drops repeated literals within each clause while preserving their first occurrence.

Let e,v be the numbers of edges and vertices in the compiler's original weighted graph. Its equality links number L=2e+v. The expanded graph has E=e+6L edges and h=2e+2v+5L clause sites. It uses P=5L+2v private variables with one fresh guard per private. Thus the raw arity and number of rows m obey

    n−1 = 2E + 2P = 46e + 26v,
    m−2 = h + E + 2P = 45e + 27v.

The determinant is 72. These two counts uniquely determine e and v; there is no search over dimensions. Reject negative or nonintegral solutions. Now E=13e+6v, h=12e+7v and a=k−E−1. Require 0≤3a≤min(e,v), before allocating any structure of size a. In particular, an extremely large malformed binary k cannot trigger an exponentially large compiled point.

Scan the first h rows to locate the unique endpoint of each half-edge ID 0,…,2E−1. Edge j joins the endpoint of 2j to that of 2j+1 in that order. A vertex block of original degree d begins at u with a chain of d+2 copies followed by five fresh internals for each of d+1 links. Its first expanded edge goes from u to u+d+2, revealing d. The block has 6d+7 sites and 6(d+1) equality edges. Record the owner of each incidence copy u+1,…,u+d. A degree-zero block has two terminals, one link and no incidence copy. After v blocks, the unconsumed e edges are the original edges in compiler order. The first 3a concern the variables' literal/consistency triangles. Each subsequent edge joins a clause mediator to a literal vertex. The mediator index minus 3a gives the clause number, and the literal owner is 3i for variable i+1 positively or 3i+1 negatively. Collect clauses in this edge order. Isolated mediators recover empty clauses, and opposite literals, unused variables, repeated source clauses and the zero-arity empty source are all allowed.

Finally recompile this candidate with no selectors and compare n, every ordered literal of every ordered clause, every point coordinate and k. Equality gives sound recognition even on input with malformed gadgets or wrong weights. Conversely the size equations and block ordering recover the canonical source from every genuine selector-free output, so the equality test accepts all of them. Membership on a selector-bearing encoding depends only on whether an identical selector-free output exists.

For total bit length B, explicit array indexing and block reconstruction take polynomial time; both decoded arity and occurrence count are O(B). Only one recompilation occurs. The rational baseline products, normalizer and finite-ring inversion operands have O(B) bits, since they use constant bases raised to O(B) powers. The recovered compiler output has at most O(B²) bits. A conservative sequential bit bound O((B+1)^8) covers record scans, schoolbook rational arithmetic, extended Euclidean inversions and full raw comparison. Recognition never evaluates the target multilinear extension.

The total language of raw words on this exact ordered image with nonzero value is NP-complete. A verifier runs recovery and checks a guessed a-bit assignment against the recovered Φ. Its weighted source sum is the unsigned integer #SAT(Φ); the ring precision distinguishes zero from all positive counts up to 2^a. In the other direction compiling without selectors is a polynomial-time reduction from SAT, including the possibility that satisfiable model counts vanish modulo three. These witnesses assign the recovered source variables. The positive target CNF itself has an all-ones Boolean witness on every compiler output, regardless of the modular answer.
