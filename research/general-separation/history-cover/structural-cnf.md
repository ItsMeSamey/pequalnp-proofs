The CNF frontend removes tautologies and repeated literals, then solves all clauses of width at most two by implication-graph strongly connected components with assignment replay. For other inputs, a deterministic minimum-current-degree elimination order cliques each eliminated variable's surviving neighbors. If there are at most w at every step, every currently joined table fits the eliminated bit and those w bits: original clauses had clique scopes and newly projected scopes are filled cliques. Store one value for each accepted boundary row and replay in reverse. The algorithm costs 2^w times polynomial input size. Failure of this cheaply constructed order to certify w says nothing about the optimal order.

If no such order is certified, branch on the three variables of one remaining ternary clause to find a size-k hitting set of all ternary clauses. Search costs 3^k polynomial time. Enumerate its 2^k assignments, simplify all clauses on the same partial assignment, and solve the remaining 2SAT, restoring the pinned bits in the returned witness. This charged criterion is exact for strong backdoors into syntactic 2CNF on the normalized clauses: if a ternary clause is untouched it survives all restrictions to the proposed backdoor. Uncovered inputs retain the complete circuit fallback. All witnesses are checked on the original clauses.

For a connected family with a provable gap between two dispatchers, use ∧_{i<j}(¬a∨¬x_i∨¬x_j) for even n≥2 ordinary x variables. The primal graph is K_(n+1), so every elimination order has width n. All clauses are genuine ternary, and {a} hits them all. For a=0 there are 2^n satisfying assignments; for a=1 there are n+1. This odd total makes the coefficient of the full (n+1)-variable monomial nonzero over F2, and zero plus all unit vectors are accepted. Therefore the degree theorem in complete-portfolio.md implies 2r−h≥n+1 for ANY affine-plus-quadratic odd-fiber representation. A faithful global 2^r-character count dispatcher needs exponentially many characters, whereas the structural decision solver takes polynomial time. This separates representation costs and does not imply a lower bound for every counting method (the displayed count itself is elementary).
