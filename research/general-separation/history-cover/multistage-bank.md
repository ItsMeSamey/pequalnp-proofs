The bank.compress API returns a System on the original n bits and search statistics, or None if the chosen greedy bank prefix leaves no cover within the supplied budget. Stages=0 runs cover search directly. The procedure consumes at least one physical gate at each nonempty stage. It stops the bank immediately before the first operand depending on a still-local gate. Operands can depend on already certified summary bits.

For stage j, let k_j be the number of consumed producers, r_j the rank of all future readouts on those producers, H_j the independent pivot residuals, and q_j twice the number of nonzero entries in H_j. Exactly q_j affine-product occurrences are emitted in the right-hand sides, even counting identically zero terms. The checked definitions assign new variables equal to H_j applied to the actual producer values. Row reduction reconstructs the prefix-dependent part of every later operand from precisely these shared variables. Induction on stages, followed by induction on the suffix gate order, gives a unique joint extension of every raw input and its original output. Product occurrences in the equation system are O(sum q_j + sum r_j + m_suffix + t + 1), including each definition's left side. Variables are n+sum r_j+2t for actual suffix cover size t. The 2^t_budget cover search is a separate additive construction charge. The deterministic theorem-based counting clock uses these actual values; growing cumulative rank can eliminate the gain even when every stage rank is small. A two-bit summary of one stage does not solve unrestricted rank-two histories.

The supplied System API implements exhaustive reference counting or pinned-query witness reconstruction with a caller-provided exact counter. Counting via the fast theorem is not implemented.
