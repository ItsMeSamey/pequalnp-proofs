# A supplied minimum-cost witness and the first undecided ternary digit

Take a simple bipartite graph with M vertices on either side, maximum degree three, and a supplied perfect matching. Make one clause per vertex consisting of all its incident edges as positive variables. Each raw variable occurs in two distinct clauses and the given matching is a satisfying assignment in the original domain. It minimizes the number of selected edges: at least M edges must be chosen to cover the 2M vertices. The [minimum-cost support solver](read-two-min-cost.md) can return such a witness without arithmetic cancellation.

Set every success coordinate to the integer 3, so every failure weight is −2. In a graph with m edges, a satisfying raw assignment with j selected edges contributes exactly 3^j (−2)^(m−j). All satisfying assignments have valuation at least M. Those of valuation M are exactly the perfect matchings, and every one contributes the same unit 1 modulo three after removal of 3^M. Consequently the first precision that can distinguish any nonzero value satisfies

    ML mod 3^(M+1) = 3^M · (#perfect matchings mod 3).

The decision problem restricted to these instances is Mod₃P-complete even with the minimizing assignment supplied. Validity of graph shape and of the supplied matching can be checked in deterministic polynomial time; reject invalid presentations. A nondeterministic machine guesses a subset of edges and accepts precisely the perfect matchings, giving membership. To prove hardness use Valiant's actual integer-matrix identity from Lemmas 3.1 and 3.2. The signed permanent is 4^t times the source model count, so the factor is one modulo three. Standard guess encodings can use unique deterministic gate extensions. Replace each matrix entry by its residue in {0,1,2} as a bipartite edge multiplicity. Add three distinguishable edges in every diagonal position. The resulting matrix agrees modulo three with the signed matrix, gives a known perfect matching, and has no isolated vertices. [Valiant, 1979, §3](https://www.cs.bu.edu/faculty/gacs/courses/cs535/papers/Valiant_permanent.pdf)

For each degree-d vertex replace it by a path of length 2d−2 with the d exterior port sites alternating with d−1 internal spacer sites. Each original occurrence has its own port and only its original external edge. In a perfect matching every spacer consumes a distinct port, so precisely one port must use an exterior edge. Conversely fixing that port leaves two even paths with uniquely forced perfect matchings. This bijects the original and new perfect matchings, including their edge multiplicities. The replacement is simple because formerly parallel edges use distinct ports. Give each path's ports the original shore and each spacer the opposite shore. The new shores both have M=2m₀−n vertices if the original matrix has order n and the post-diagonal multigraph has m₀ edges. Degrees are at most three, the size increase is linear in the explicitly materialized occurrences, and the chosen original diagonal lifts constructively. Applying the displayed identity finishes the reduction.

The permutation count determines the first eligible digit even if the lower bound and an assignment attaining it are both supplied. This does not alter the polynomial-time solvability of finding a minimum-cost witness. For general input precisions and arbitrary coordinates the stronger [modular decision comparison](read-two-prime-power-nonzero.md) uses a different construction.
