# Exact contraction through disjoint nonlinear pairs

An n-bit state starts at a free input. The circuit alternates arbitrary explicitly computable binary affine maps on the state with d layers of disjoint two-bit-to-two-bit maps on matched coordinates. All other coordinates pass through. Acceptance pins a final state bit (or uses a specified affine final predicate). Intervening affine maps may have arbitrary rank; a suffix after a selected cut can be evaluated on any concrete state. This model includes unrestricted affine mixing and shared computations, but does not represent every fanin-two circuit using n state coordinates and few matching layers.

Let m_j count the nonbijective pairs in layer j, T_j=sum_{i<=j} m_i, sigma=log2(4/3), and rho=1+1/sigma. There is a deterministic exact count and witness algorithm with time
  poly(description) 2^{n-S},  S=max(n-T_d, max_j(sigma m_j-T_{j-1})).
Indeed every bijective two-bit map is affine (the affine group has 4*6=24 permutations), and every two-bit map becomes affine once either input bit is fixed. Branching on the first prebit of each nonbijective pair yields at most 2^{T_d} disjoint input charts with an affine state map on a binary affine domain. An inconsistent chart contributes zero. Final acceptance is affine. Compute its preimage dimension by elimination, count the physical inputs, and solve for one when nonempty.

Alternatively choose a layer j. For each nonbijective pair, choose two colliding preinputs; these form an affine line. The other two preinputs are singletons. These three disjoint affine cells all have a definite poststate, though two cells may have the same poststate. Enumerate one cell for each such pair, one preinput for every bijective pair, and one value for every unmatched coordinate. This takes at most 3^{m_j}2^{n-2m_j} cases. Each case defines an affine subset of layer-prestates and a concrete poststate. Evaluate the entire suffix on that state. For an accepting case pull the prestate constraints back through each of at most 2^{T_{j-1}} prefix charts and count by Gaussian elimination. Distinct chart/cell choices describe disjoint physical inputs, so this counts all multiplicities even through singular affine maps. A nonempty preimage gives an actual witness.

Since sigma m_j-T_{j-1}<=S, induction gives T_j<=rho T_{j-1}+S/sigma and T_d<=S(rho^d-1). Together with n-T_d<=S this gives S>=n/rho^d. Thus at d<=c log2 n for fixed c<1/log2 rho the saving in the exponent is at least n^{1-c log2 rho}. The argument does not assume stochastic shrinkage, characteristic-2 count cancellation, or that a nondeterministic guess can ignore states' preimages. A width-n layout with the required nonlinear depth is a genuine hypothesis. The result cannot be applied to arbitrary Bn log n DAGs merely by counting gates.
