# Structural peeling of functional output blocks through shared consumers

Fix a DAG circuit and a subset R of its physical raw input IDs retained for enumeration. Use one binary coordinate for each physical input and gate output. Add all affine gate equations and the required output pin to one affine system E. One may also split a required-true AND into two required-true child pins and a required-false OR analogously. Every accepting evaluation satisfies E. Keep all original nonlinear gates for final validation. Detect an inconsistent E immediately.

Start with R as structurally known. Given known coordinates K, mark a new coordinate v known if its unit vector belongs to the span of the units on K and the coefficient rows of E. Gaussian elimination supplies an affine expression computing v from K (record constants using the right sides of E). Also mark the output of a nonlinear gate known whenever its predecessors are known, recording its physical truth-table computation. Continue until no growth. Computations can be stored as a shared polynomial-size decoder DAG. Parents and outputs may have arbitrary fanout or may also occur in other constraints. This is polynomial time even by recomputing all ranks at each stage. Monotonicity holds for the abstract known coordinate set, and the values computed on any accepting evaluation agree with that evaluation by induction.

If all raw coordinates become known, each setting of R has at most one accepting completion. Construct the proposed raw word and test it in the original circuit. A missing completion is therefore harmless even though known from E means known only on accepting evaluations. Enumerating the retained settings counts exactly, takes poly(s+n)2^|R| time, and returns an ordinary witness when one is found. Starting from all raw inputs and trial-deleting one at a time with closure recomputed until stuck finds an inclusion-minimal retained set for this rule. Enumeration already gives the Williams target clock when n-|R|=Omega(n/sqrt(log n)); no such deficit is guaranteed for general circuits. For explicit raw equations y_i=g_i(x) with g_i computed on retained x and acceptance forcing the equality bits, forward gate evaluation and these equations recover every y_i; shared downstream consumers remain covered by the final original-circuit test. The explicit weighted-sum graph has this form. If the sum block is identified, a proposed R can be verified directly. The greedy rule does not guarantee a minimum seed or preferentially select the advertised x side.

For SAT alone it is sufficient to select one completion per feasible retained state. Verifying semantic selectors for arbitrary presentations is costly even when the relation is total. For each fixed d>=0, take R_F(x,a,y)=not F(x) OR (y=product_i a_i) on d+1 newly introduced physical bits a_i and one y. Every exterior (x,a) is feasible. An everywhere valid degree-at-most-d Boolean selector for y exists iff F is unsatisfiable: if F is empty use zero; if F(x0)=1, fixing x=x0 leaves the degree-d+1 monomial in a, which cannot equal a lower-degree Boolean function. This proves coNP-hardness for recognizing existence of such a selector, including constants (d=0) and affine selectors (d=1). The reduction adds O(d+1) gates and bits, and arbitrary sparse 3SAT circuits can be padded to fit Bn log n for every fixed B. It is not a hardness result for all nonlinear selectors, since the displayed monomial is a valid selector. Requiring a selector to work for every exterior is exactly what is needed to substitute it while preserving SAT under arbitrary later exterior constraints; a single isolated SAT instance can admit easier decisions.

If an external predicate additionally depends on y rather than solely on exterior variables, substitution of a selected candidate need not preserve its SAT status when several y values are valid. The structural closure above avoids this problem by proving uniqueness on accepting evaluations of the full supplied circuit; output-only selection in a partial interface requires accounting for all actual consumers.
