# Existential elimination on the selector-free image

[decide](ring_image_existential.py) takes the four ordered raw fields of the [image recognizer](read-two-ring-image.md), with optional nonnegative max_rows. The outcomes are off_image, zero, nonzero with an original-source assignment, and unknown with reason row_budget. No evaluation oracle or ring inversion is needed after recognition. The deciding fact is the normalization identity: if a variables were recovered, the target value equals (−15)^E times an integer count between 0 and 2^a modulo 3^(E+a+1). Consequently its vanishing is exactly source unsatisfiability. This uses unsigned source counts.

Normalize the recovered clauses by removing tautologies, duplicates and subsumed rows. Split the clause-variable incidence graph into connected components. Counts on disjoint components multiply as ordinary integers with a further power of two for unused variables. Each factor is nonnegative and the product is at most 2^a. Hence nonzero is the AND of component decisions even if some component model counts vanish at precision one. Equivalently, for nonzero counts the sum of their 3-adic valuations, including the unused-variable factor of valuation zero, is strictly less than a+1. There is only one global factor (−15)^E. No extra precision or selector is charged per component.

For each signed variable x, write all clauses mentioning x as x OR P_i and ¬x OR Q_j. Keep the unaffected rows, and replace the incident clauses by all non-tautological P_i OR Q_j; remove subsumed clauses. This computes existential projection: a remaining assignment fails to extend exactly when a false P_i demands x=true and a false Q_j demands x=false. The empty resolvent signifies contradiction. In reverse order take x=true if some P_i is false, otherwise take false. Variables disappearing under subsumption use the current arbitrary default, and the argument applies to every choice satisfying the retained projection. The final check tests the reconstructed assignment on the recovered source clauses including tautologies. Projection need not preserve counts, even for one row x OR y: its projection on y is constant true and the two y assignments have one and two extensions. Thus this calculation legitimately bypasses exact evaluation.

The row cap applies per initial connected component, after antichain reduction. The default is the initial row count r, increased to at least 2b²+1 for an entirely binary component with b used variables. A custom cap also applies to its starting row count. Temporary pivot candidates can contain r²+r rows before pruning; the cap covers retained rows. Prefer variables whose incident unsigned scopes form an inclusion chain, breaking ties by original ID, then try the other variables by ID. Accept the first pivot whose reduced output fits. A component exhausting all candidate pivots returns unknown. A different component proving zero still decides the whole source.

**Guaranteed domain.** Every component of binary width finishes under the default, since resolving binary clauses preserves this bound and there are at most 1+2b+4 binom(b,2)=2b²+1 distinct non-tautological rows of width at most two. Components whose hypergraphs are β-acyclic finish as well, at arbitrary width. Such a hypergraph admits a nest point (vertex with inclusion-ordered incident scopes) in every residual hypergraph formed by variable and edge deletion. For a nest point, consistent opposite parents resolve to the larger parent's literals with the pivot deleted, since the smaller residual's signs must agree on every common variable. Inconsistent pairs give tautologies. Thus each retained new row is one incident parent with the pivot removed. Residual scopes are obtained by deleting that variable and deleting whole hyperedges, so the β-acyclic condition persists and the row count never increases. Mixing the two kinds across arbitrary components is allowed. A large clique in a binary component and a wide nest-point component can both occur. Davis–Putnam and its β-acyclic guarantee are prior work; the result here applies the existential procedure to an explicitly recognized modular target and reconstructs a certificate with a guard on the size of the intervening projections. [Ordyniak, Paulusma and Szeider](https://doi.org/10.1016/j.tcs.2012.12.039)

For recognized input of length B with source arity a, let J be the largest component cap actually used. The probe performs at most a rounds and tests at most a candidate variables per round. Each prospective reduction constructs O((J+1)²) rows of width at most a and performs O((J+1)^4) pairwise subsumption tests. Storing witness parents costs O(a²(J+1)) literal references over all accepted pivots. The normal default gives J polynomial in B. Sequential record scanning, integer comparisons and remaking sets are covered by a conservative poly(B+J) bit clock, in addition to one polynomial-time recovery. For a very large custom J the guarantee is polynomial in its numerical value; the exact implementation does not allocate J rows in advance. No ring points are recompiled at each pivot.

**Countercontrol with both truth values.** Put one Boolean variable on each edge of K₄,₄. At each vertex impose a four-bit XOR equation with a chosen right-hand side, writing eight distinct width-four clauses forbidding exactly the wrong local strings. All-even charges admit the all-zero solution. A charge of one at only one vertex is unsatisfiable because summing the eight equations counts every edge twice. Both sources have 16 variables and 64 pairwise unsubsumed clauses in one component. Every candidate first pivot joins two degree-four vertices. Its elimination deletes sixteen clauses. Within either vertex constraint the opposite parents resolve tautologically: the two bad assignments cannot differ in just the pivot. Across endpoints there are 4·4+4·4=32 non-tautological six-literal resolvents, each with a distinct unsigned-assignment pattern because the endpoint supports apart from the pivot are disjoint and each three-bit projection uniquely determines its forbidden pivot value. No unaffected four-literal row subsumes one: any other vertex has at most one incident edge in the two-star union in this bipartite graph. Consequently every first pivot retains 48+32=80 rows. At the default cap of 64 both images return unknown, one with nonzero value, one with zero value. This is an explicit limitation of this procedure, independent of tie-breaking or a hypothetical complexity separation.
