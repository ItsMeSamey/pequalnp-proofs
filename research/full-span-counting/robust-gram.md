# Unknown sparse outliers for exact violation-polynomial learning

Let H be a fixed-width core. W is the set of variables used by any wide clause, V_i(z) its falsification indicator on a setting z of W, and Q the sum of the V_i. The multiplicity h(z) is the number of H models extending z. Let φ consist of the p nonconstant violation monomials of degree at most d, where p is the sum of binom(m,j) for 1≤j≤d. A vector λ predicts the union indicator by f=λ·φ and gives zero on the all-zero profile. For each z with Q(z)>0 and h(z)>0 the desired equation is λ·φ(V(z))=1. Suppose some vector fails on at most s distinct settings of W, with arbitrarily many short-core completions per setting. Both λ and the exceptional settings are unknown.

For a known excluded set E and partial assignment a on W, compute Q-weighted sums of feature products over H under a, subtracting h(z)Q(z) times the same products for every excluded z extending a. Each original sum is a linear combination of core counts imposing a and at most 2d+1 clause-falsifying pins. Cache each h(z) with a core count. This gives the exact nonnegative residual sum of Q(1−λ·φ)² outside E on every query prefix. Ordinary rational normal equations and a zero-loss test decide whether all remaining equations are consistent. These are the weighted Gram formulas from the compression team, now conditional and with finite deletions.

If feasible, recover some λ. The exact model count is #H minus the sum of f over H models plus sum_{z in E} h(z)(f(V(z))−1). Each excluded setting came from a positive-fault witness with h(z)>0. Unconditioned feature expectations use pinned core counts. No sign or integrality restrictions on λ are required.

If infeasible, extract an actual contradictory subsystem of at most p+1 equations. Starting with an empty feasible list, choose any rational solution λ to the list. The whole system outside E is inconsistent; its positive residual detects a violating setting outside E. Recover one by prefix self-reduction on W, selecting a child whose residual remains positive, updating the excluded corrections under each prefix. Add that row. If feasibility is preserved, coefficient rank strictly increases: an equation whose coefficients are in the prior row span either already holds on every solution or renders the enlarged list inconsistent. At most p+1 witnessed rows reach inconsistency. Every s-outlier explanation respecting prior deletions must omit at least one of them. Branch by deleting each witnessed setting in turn and recurse with budget reduced by one. Increase integer budgets until a feasible certificate is found if the outlier count was not supplied.

For fixed d≥1 and m≥1 the cost is (p+1)^s times a polynomial in n,m,p,s and the original fixed-width counting time. Iterative deepening changes only a polynomial factor. Exact arithmetic at each node has polynomial bit complexity. If s log(p+1) is O(n loglog n/sqrt(log n)) on polynomial-size instances, the native exponent is retained. The guarantee is in the number of exceptional W-settings, not the number of exceptional violation patterns; counting completions for an arbitrary fully specified pattern would itself enforce many unviolated wide clauses.

Conflict branching on infeasible subsystems is a standard approach in optimization with violated constraints. This application supplies otherwise inaccessible rows via conditional squared-residual model counts and returns an exact union size. [Matoušek](https://doi.org/10.1145/177424.178039) The separately proved maximum-spanning-tree learner in tree.md has polynomial dependence on the number of bad full assignments when a tree witness exists, while this statement covers arbitrary low-degree real-coefficient models.
