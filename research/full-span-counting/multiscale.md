# Dense irredundant multiscale factors

Let N be a construction parameter. For each j from 1 to floor(log₂ N/2), use G_j=floor(N/(j²2^j)) independent groups. A group owns 2j+1 private Boolean variables; on them forbid any chosen half of the full assignments by one maxterm each, M_j=2^{2j} in total. To make every clause genuinely wide, append the disjunction of the same N additional positive guard variables to every maxterm. Every group is a hitting formula and can be found by its unsigned scope. Across different groups any one picked violation per group is jointly compatible by setting the shared guards false. Each individual wide clause is essential in the wide subformula: set the guards false, choose exactly its omitted assignment in its own group and choose any allowed assignment in every other group. The total number n of variables is Θ(N), since sum_j G_j(2j+1)=O(N). An arbitrary crossing bounded-width core can be added without changing the compiler's cost.

With two radix digits the number of auxiliary variables is bounded by O(sum_j G_j sqrt(M_j+1))=O(N sum_j 1/j²)=O(n). Thus exact n-variable counting retains the fixed-width native exponent. At j=floor(log₂ N/2) alone there are Ω(N^{3/2}/(log N)²) wide clauses. The number of jointly compatible group choices is 2^{Ω(n)}, already at j=1.

This family also separates a specified mixed baseline. Suppose it either pays one selector per wide clause of each selected group or explicitly enumerates the allowed group-index choices for other groups. Give the selectors any fixed budget Kn, which can be bounded by K' N with K' constant. Choose a fixed j so large that 2^j/j²>4K'. At that one level G_j M_j>2K'N for large N. Even spending the entire budget there pays for fewer than half its groups; the remaining Ω_j(N) groups have jointly compatible choices and their explicit Cartesian enumeration costs at least 2^{Ω_j(N)}. The same conclusion holds if the baseline may pass groups of bounded private width through directly: take j greater than that bound. This is a comparison to those explicit compilation/enumeration strategies, not a lower bound for the formulas. For instance the common guard admits a separate case distinction, and some choices of allowed half-tables may have additional structure. The structural compiler does not need to assume such structure.
