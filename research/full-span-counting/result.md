# Signed lists of full-span cube exceptions

A cube is a partial assignment, with indicator one on its completions. In particular a clause's falsifying assignments form a cube. Suppose an instance consists of a bounded-width core H together with factors f_j that take Boolean values and have supplied identities
[
f_j(x)=\sum_{t=1}^{m_j} s_{jt}\,1[x\text{ extends }C_{jt}],\qquad s_{jt}\in\{-1,+1\}.
]
The empty cube is allowed. Different factors may share all their variables, and cube dimensions and the number of occurrences are unrestricted.

Fix d≥1. For list j encode the term index by d radix digits of alphabet size B_j=ceil(m_j^{1/d}), using one Boolean indicator per value of each digit. Exactly-one is enforced with binary pair exclusions and a uniquely extending bounded-fan-in OR tree whose output is true. Forbid unused index tuples by width-d clauses. For every digit tuple indexing a term and every literal prescribed by its cube, insert the clause that negates the d selected indicators or enforces that literal. Use the same pattern to fix a sign bit to the sign of that term. An XOR chain of the group sign bits fixes the sign of the entire selection. Its even and odd output cases yield two exact model counts, whose difference is the answer. Every chosen tuple of terms consistent with x has a unique extension on the bookkeeping variables. Therefore the signed sum for fixed x is the product of the specified factor values. A zero-length list annihilates the whole output.

The width is max(width(H),3,d+1), and the added variable count is O_d(sum_j m_j^{1/d}), with polynomial construction for fixed d and polynomially encoded lists. The fixed-width exact counter therefore retains its native exponent when this sum is O(n). The analogous o(n sqrt(log n)/loglog n) range for the sum is sufficient for subexponential time in original n, with polynomial input size. Integer term coefficients can use the digit-index summation in rational.md, charging separate digit/sign/addition bits and polynomial calls.

**Hitting groups.** If no two clauses within a group can be falsified together, its indicator is 1 minus the sum of its falsifying cubes. One plus the number of clauses is its signed-list length. This applies automatically to normalized distinct clauses with the same unsigned variable scope, providing a polynomial-time grouping by hashing scopes. For general groups the pairwise conflict promise can be directly checked. Merely overlapping nonnegative, nonsigned lists do not give a Boolean indicator automatically. Hitting formulas and their elementary per-group counting are established. [Filmus et al.](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.ITCS.2024.48)

**Overriding a structured base.** If the base g_j is Boolean and should take a_E∈{0,1} instead on each of pairwise disjoint full-span exception cubes E, then
[
f_j=g_j+\sum_E a_E1_E-\sum_E g_j1_E.
]
Each selected term decides whether the base is active. When active, gate its existing local clauses by one control bit. When inactive, set every private auxiliary to a canonical all-zero assignment and contribute multiplicative weight one. If base evaluation has internal signed paths or digit weights, their inactive signs and selected digit exponents must be zero. All activations are fixed uniquely by the selected term. A rational base with scaled output D_j g_j must contribute D_j on the inactive branch for a uniform external division by D_j. This can be done by charging an integer weight D_j to that branch under the previously derived digit-index method; alternatively encode one fixed dummy weight equal to the usual denominator per inactive transition, retaining its existing bit-length bound, its ordinary digit selection, and its share of the sign/adder network. These two conventions for disabled transitions differ; one must keep exactly one normalization convention. A parsimonious Boolean base requires no scaling. This gives long-span corrections across many independently chosen, possibly overlapping factors. Finite-domain digit splitting and forbidden-tuple encodings have prior literature. [Tanjo, Tamura and Banbara](https://research.ibm.com/haifa/Workshops/cspsat2011/papers/tanjo_tamura_banbara%20.pdf) · [IJCAI finite-domain encodings](https://ijcai.org/proceedings/2011/432)

**Lookup limitation.** Suppose m reusable index states have codes in a bits. For each i, the relation “if index=i then payload bit y is one” is required to have a width-k CNF on those same bits and y, with no query-private auxiliaries. At (code_i,0) a failing clause contains positive y, since evaluating at y=1 passes. Its at most k−1 remaining literals determine a pattern unique to code_i, since all other valid codes pass with y=0. Therefore m ≤ sum_{h=0}^{k−1} 2^h binom(a,h). For fixed k this proves a=Ω_k(m^{1/(k−1)}). The radix construction matches this exponent at k=d+1 in this query model. The result places no lower bound on arbitrary semantic or data-dependent compilers.

The independently written check.py tested the actual CNFs, separately counting positive and negative extensions for every assignment, on 76 formulas including overlapping factors, guarded Boolean bases, unused digit codes and signed cancellations. This is a structural transfer; an arbitrary CNF need not admit a compact signed list factorization, and the result does not resolve P versus NP.
