# Learning and repairing a tree bound for wide clauses

Write V_i for the indicator of falsifying wide clause i and H for the bounded-width core. For an index set U let b_U count the H-models on which all V_i for i in U are one. Compute b_U by consistent pinning of the implicated clause literals and one core count; inconsistent pins give zero. Let N=b_empty. For a tree T on the m wide clause indices define c_T=sum_i V_i−sum_{ij in T} V_i V_j. On a particular assignment this is the number of connected components induced in T by the violated indices, since every induced subgraph is a forest. The empty set has zero components.

Put A(T)=sum_i b_i−sum_{ij in T} b_ij and let M be the unknown number of H-models that violate at least one wide clause. Then D(T)=A(T)−M is the sum of the nonnegative integer excess c_T−1 over nonempty violation profiles. A maximum spanning tree with edge weights b_ij minimizes A and hence also D. This is the classical Hunter maximum-spanning-tree upper bound for a union of events. The equality cases also fit the Euler characteristic framework for truncated inclusion–exclusion. [Hunter](https://doi.org/10.2307/3212481) · [Naiman and Wynn](https://doi.org/10.1214/aos/1176348512)

## Exact recognition and output-sensitive repair

For each pair i,j and internal vertex k on its tree path, compute the path-gap count g_ikj=b_ij−b_ijk. This is nonnegative and equals the count of models with i,j violated and k unviolated. A fault support is disconnected precisely when it witnesses such a gap. Thus all g_ikj are zero iff T is exact. If any exact tree exists, every maximum-weight tree is exact, since D achieves its minimum zero. Therefore this is a complete recognition algorithm for existence of a hidden tree for the actually realized profiles; neither the profiles nor a tree have to be supplied. It uses O(m³) original-scale core calls, each pinning at most three wide clauses. With exact recognition the desired count is N−A(T).

For positive gap counts enumerate the witnessing assignments by Boolean self-reduction. At a partially assigned prefix a the number of eligible completions is b_ij(a)−b_ijk(a), obtained from two additional core calls under those pins. Search only prefixes with nonzero counts. Collect distinct witnesses across all triples. Each is a bad H-model; each bad H-model occurs for at least one triple. Restore the exact answer by adding c_T(x)−1 for each distinct bad model to N−A(T). Before enumeration the exact gross output count sum g_ikj is already known, permitting a data-dependent cost estimate.

Suppose some unknown tree has at most s bad H-assignments. For m≥2 every disconnected support is proper and has excess at most max(0,m−2), so D(T)≤max(0,m−2)s for every learned maximum tree. Each bad assignment contributes at least one unit of excess. The gross number of emitted assignments over all triples is at most O(m³) times the learned bad-assignment count. Thus deterministic exact recovery uses poly(n,m)(1+s) fixed-width oracle calls. In particular the native fixed-width exponent is retained if log(1+s)=O(n loglog n/sqrt(log n)) for polynomial input sizes. Cases m=0 or 1 are direct. If few distinct projections onto all wide variables witness the learned tree gaps, branch only on these variables, deduplicate such projections, and weight each excess by one core count for the projection. The best-tree guarantee above uses H-model multiplicity; a guarantee only on some other tree's unweighted projections does not automatically transfer.

## Several trees and low-degree recognition

If a collection of t trees covers every nonempty profile by a tree in which it induces a connected subtree, prod_T (1−c_T) is pointwise the indicator of zero faults. Its degree is at most 2t. The previously derived weighted Gram algorithm of the compression team therefore detects an exact bounded-degree certificate without seeing a tree cover. Specifically use features consisting of every nonempty violation monomial up to the prescribed degree and Q=sum_i V_i. Minimizing sum_H Q(1−f(V))² over their linear span checks whether the union indicator has that degree. All entries come from pinned counts of degree at most twice the feature degree plus one. Exact loss zero is a certificate. The zero profile evaluates to zero on all features. This also applies under a bound d on the VC dimension of the realized Boolean profiles augmented by the origin: for any index set larger than d a missing projected pattern has a vanishing indicator, reducing its top monomial to lower-degree monomials. Reduce the full OR polynomial repeatedly to degree d. Including the origin preserves zero constant coefficient. A hidden-star family may shatter linearly many leaf indices while its union still has degree two.

For a constructive second-stage test after choosing T, take weight Q(c_T−1)^2. It is positive exactly on T's disconnected profiles and zero elsewhere. Under this weight, compute the same optimal tree and path-gap tests using moment expansions, each term a low-order pinned core count. If the new tree is exact on that residual, the product (1−c_T)(1−c_new) computes the desired indicator globally, even with exponentially many residual assignments. Existence of some two-tree cover does not force the first greedy maximum tree to belong to such a cover; the unconditional fixed-t claim uses the Gram certificate.

## Dense example

Use q² leaf clauses P_ij=(Y or x_i or z_j), with a common disjunction Y on Θ(q) guard variables, and one center C_0=(Y or u). The short core imposes that if u is true each side x and z has at most one false value. A uniquely extending linear-size cardinality circuit suffices. If Y is false and u is true there is at most one violated leaf; if u is false the violated set contains its center. If Y is true nothing is violated. All nonempty violation profiles are therefore connected in the star centered on C_0. Every leaf has an isolated witness by taking u true and its indexed pair the sole zero per side. The center has an isolated witness with u false and all leaf variables true. When u is false and one z is false, varying the number of false x gives Θ(q) distinct multiplicities. Taking disjoint matched leaf indices (i,i) and choosing the corresponding x,z zeros realizes all subsets on those leaf indices; they shatter q coordinates. The tree certificate still has degree two. Arbitrary additional short constraints preserve connectedness but can eliminate individual witnesses. The alternative syntactic factorization of these particular pair clauses means this is a separation of structural guarantees, not a computational lower bound.

The checker check_tree.py compared the objective and correction against every labeled tree through six vertices on 31 examples. The three possible two-vertex subsets of a triangle force a positive correction for every maximum tree.
