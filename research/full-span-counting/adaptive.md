# Conditional profile counts on unknown decision trees

Let L be an exactly recognizable family of restricted counting instances with an exact counting routine. It is hereditary with respect to the chosen tests when restricting a member by either test outcome keeps it in L. Exact degree-d fitting of the clause-violation union on the remaining core models is hereditary, as is an a priori rank bound on the restricted dictionary. The observed violation coordinates may be kept even when some become constant. When dynamically promoting newly short clauses into H, check heredity of the resulting leaf definition separately; it does not follow from a runtime cutoff. Several hereditary leaf families may be combined by union.

**Unknown shallow trees.** For original-variable splits and a depth budget k, memoize all reachable partial assignments of size ≤k. Accept a cell if its leaf test succeeds or some available variable has two accepted children. The accepted count is the leaf count or sum of disjoint child counts. The total bound on different states is the sum of 2^j binom(n,j) for j≤k. Consequently k=o(n) produces subexponential search overhead, and k=O(n/sqrt(log n)) stays within the cited native exponent. This statement requires no heredity, provided the leaf test is correct and its running time on all queried cells is bounded.

**Unknown low-rank trees of unbounded depth.** Take a finite library of M Boolean tests and never repeat a test on a path. A leaf has Strahler rank zero. An internal node has the larger child rank if those ranks differ and one plus their common rank otherwise. Equivalently a rank-at-most-r tree, r>0, is a decision list whose side subtrees have rank at most r−1. This is the classical decision-tree rank studied in learning theory. [Ehrenfeucht and Haussler](https://www.sciencedirect.com/science/article/pii/0890540189900011)

When L is hereditary, trees of rank at most r are closed under restrictions by the same tests. Indeed one may impose the condition throughout the original tree, pruning forced tests and keeping all its restricted leaves valid. To recognize rank at most r, first accept a leaf in L. Otherwise try each unresolved test and both outcomes for a rank-at-most-(r−1) side. Upon finding any such side, add its exact count and continue on the other side with rank budget r. Return failure if no such test exists. Soundness follows by composing the returned list. For completeness on a promised tree, some low-rank side exists at its root; choosing any other certified side is safe because the complementary cell is a restriction of that promised tree and hence still admits rank at most r. This property avoids backtracking. Rank-zero calls use the exact leaf tester. With at most M iterations, 2M side searches each, the cost is (O(M²))^r times polynomial overhead and uniform leaf-test time. Fixed r preserves the native exponent for polynomial M, including M-variable deep trees; r log(2+M)=o(n) suffices for subexponential search overhead. A budget-limited heuristic leaf oracle need not be hereditary or complete. The guarantee requires an actual hereditary promise retained on restrictions, though a sound tester accepting a larger family may still suffice to count promised trees.

Split conditions can be original-variable pins or constant-arity tests from a polynomial-size library. For the latter, append the accepting truth-table clauses of the test or its complement to the bounded-width core. This costs no new variables; all accumulated restrictions have polynomial input size when M is polynomial. More generally a linear-size shared deterministic circuit can expose helper outputs once, after which one may branch on its wires within a linear variable budget.

**Shallow adaptive versus strong static.** Use q addressable blocks of t independent row bits, with N=qt shared column bits b_j constrained by a uniquely extending O(N)-size core to weight 1 or floor(N/2). For each address α, row i and column j, one wide clause is false precisely when the binary address equals α, row bit a_{αi} is true, b_j is true, and a common disjunctive guard Y is false. Use Θ(N) independent guard bits if long widths are desired. There are N² individually essential clauses, witnessed using singleton rows and columns. Read the address and then all t active row bits. If a row i is true, its sum z of violation bits lies in {0,1,floor(N/2)}, and the union is 1−(1−z)(1−z/floor(N/2)); otherwise no clauses fail. Thus a depth of t+ceil(log₂ q) gives exact degree-two leaves. Any single static set of variables producing degree-two leaves must contain at least t−2 row bits in every address block: choose that address, false guards, fixed legal columns, and set tested rows to zero. On the other rows the union is the OR of the unfixed independent bits. Its exact degree is their number. Core helper variables only depend on columns. For q=t growing the adaptive depth is O(sqrt(n)), static size Ω(n). The global profile count and fixed-degree exceptional-profile counts are exponential by the freely variable column supports.

**Low rank versus depth.** Remove the address and use q independent row bits and q columns, with the same column constraint and common guard. Query row bits until the first true one, whose row sum certifies the union by the same quadratic; no true row gives an empty union. This is a rank-one tree with q² essential long clauses. On a false-guard, fixed legal-column, all-zero-row assignment a variable tree with exact degree-two leaves must query at least q−2 row bits before the remaining independent OR has degree ≤2. Hence minimum depth is Ω(n), despite rank one. A long common guard also prevents immediate shortening on paths that have pinned only o(n) guard bits false. No complexity lower bound for other models or source-specific algorithms is asserted.

**Effect of the allowed tests.** Guard each pair of clauses encoding x_i=y_i by the same positive disjunction Y. Sequentially test the XOR of x_i and y_i. If a mismatch is found then its two violation bits sum to the exact union indicator (all faults occur only if the common guard is false); if no mismatch the union is zero. This gives rank one on the two-bit-test library. In contrast, restrict all guards false when lower bounding the rank of *variable-only trees with the fixed degree-d profile leaf predicate*. In a partial cell with u fresh pairs and no forced mismatch, u>d rules out such a leaf by fixing the other pairs equal and one bit of each fresh pair to yield independent faults. A query on a fresh pair leaves u−1 fresh in both children; querying a mate of a half-fixed pair has a matching child with the same u. Induction on remaining variables yields rank at least u−d, hence initially at least q−d. This compares fixed leaf definitions; moving all residual equality clauses directly into the core after removing the guard offers another algorithm.

The independent check_strahler.py matched minimum-rank dynamic programming and counts in 300 hereditary test cases and exhibited a counterexample to the greedy rule for a nonhereditary base. Root order matters for depth: a split that separates one selected inconsistent witness family need not be an optimal first query.
