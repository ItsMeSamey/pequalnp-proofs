# Eliminating four affine exclusions over two binary coordinates

An input consists of binary affine maps to two bits, each with one forbidden value. For a four-guard subset compute the common kernel D of all remaining linear maps after quotienting out the global common kernel. When D has dimension two and all four selected maps restrict invertibly, choose a linear complement with coordinates b. Each selected guard forbids exactly one d=h_i(b), an explicitly computable affine map. Test each of four reference choices. For reference zero, require h_i != h_0 for i=1,2,3 on all feasible boundary assignments. A sufficient efficient test checks that each bad affine flat h_i=h_0 is empty or contained in the bad flat of one unchanged guard, by Gaussian elimination.

Three nonzero binary pairs are mutually distinct exactly when their sum is zero. Translating the blockers by h_0 therefore shows that some d survives exactly when h_0+h_1+h_2+h_3 != 0. Replace the four guards by this one, eliminating D. Back-substitution tries four values. This preserves feasibility and witnesses. The number of surviving d can vary. Without the distinct-from-reference premise, four identical zero blockers disprove the formula. Enumerating four-subsets, doing polynomial-size binary elimination, and repeating at most a third of the original guard count takes deterministic polynomial time and space. This detects the stated full-kernel pivots. Larger kernels need a separate discovery argument.

For ordinary three-coloring represented by nonzero binary pairs, a degree-three vertex has blockers zero and the three nonzero neighbor colors. Replacing its vertex and incident edge guards gives one nonzero neighbor-sum guard. In K4 the three neighbors form a proper triangle, so their sum is zero and the instance rejects. Nonzero permuted neighbor colors work identically for full twists.

For an ordinary finite simple connected cubic bipartite graph with n vertices per shore, eliminate one entire shore. The surviving constraints are c_j != 0 and d_i=(Hc)_i != 0 for the binary biadjacency H. In the independent-syndrome presentation the 2n equations have full rank due to the d variables. Select one first-bit direction from each d block, and one second-bit direction from rank(H) independent c columns. This witnesses transversal rank at least n+rank(H). Thus the new deficit is at most n-rank(H), compared with the original n by the graph deficit formula. Basis rows cover all n nonzero columns and each has weight three, so the bound is at most 2n/3. If H=I+P+P² for cyclic shift P, n>=4 and 3 does not divide n, H is invertible since 1+X+X² is relatively prime to X^n-1. These connected simple cubic instances go from deficit n to zero. This is a presentation improvement on a bipartite graph family. It establishes no general SAT runtime improvement.
