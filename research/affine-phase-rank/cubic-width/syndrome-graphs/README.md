# Gate normalization, cubic width and twin-quotient contraction

Compile each clause using deterministic fan-in-two AND/OR gates and pin its output, giving each model one extension. Solve affine equations over F₂, returning zero on inconsistent equations. Substitute a bijective parametrization of their solutions into the remaining quadratic equations q_j(z)=0. For m remaining equations the exact count is 2^{-m} times the signed sum of (−1)^{Σs_jq_j(z)} over z and s. In particular redundant equations are harmless when each retains its own multiplier. To exploit explicitly encoded AND/XOR relations, recognize complete constant-arity truth-table blocks by direct comparison or take a supplied gate presentation and verify its clauses. Arbitrary compilation of bare CNF into OR gates can give a different width.

For a determined output t=q(z) used in the other equations r_j(z)+a_j t with constant a_j, set s'=s+Σa_j u_j in the old phase. It becomes s't+s'q+f_new where f_new=Σu_j(r_j+a_j q). The restriction t=s'=0 bounds h_new by h_old. Extending an optimal new flat with t free and s'=0 bounds h_old by h_new+1. Affine q leaves the cubic width unchanged. Summing over s',t doubles the new signed sum, accounting for the removed equation.

For binary A with m rows, E columns and rank r, impose At=b and t_e=x_e y_e using deterministic AND and XOR relations. First substitute the AND outputs into the checks. The cubic Walsh phase f=s·b+Σ_e(s·A_e)x_e y_e has width exactly r: fixing r independent forms in s suffices. Freeze all nonbasis private pairs, choose basis column forms as coordinates, and freeze the extra selectors. The restricted cubic part is a sum of r disjoint monomials. Its signed sum with lower-degree terms omitted is 6^r. Every quadratic signed sum on N bits is divisible by 2^{ceil(N/2)} by bilinear elimination. Hence any width h for the pure matched phase must satisfy r≥ceil((3r−h)/2), proving h≥r. Width depends only on cubic terms. The count is 2^{-m}Σ_s(−1)^{s·b} 2^{2E−wt(sA)}. Invertible row operations transform the selector coordinates and preserve width (the transformed syndrome is required). The identity itself is binary-code Fourier duality.

Specialize to incidence A of a finite simple graph G; then wt(sA) is the cut size. Classify vertices by whether transposition preserves the edge set, testing all pairs by sorting or comparing neighbor sets outside the pair. This is an equivalence relation by transposition conjugacy. Classes are cliques or independent, and distinct classes are completely joined or disjoint. Their quotient H has one edge per completely joined class pair. Obtain a tree decomposition of H as a supplied verifiable object, or use a fixed-treewidth recognition algorithm. For class i, write n_i for its order and b_i for the number of syndrome ones. Summing signs over its selector choices of weight k gives
    C_i(k)=[z^k](1−z)^{b_i}(1+z)^{n_i−b_i}.
Its internal cut is k(n_i−k) for a clique and zero otherwise. For adjacent classes i,j the cut contribution is k_i(n_j−k_j)+(n_i−k_i)k_j. Thus assign to each class C_i(k) times 2 raised to 2 times the number of internal edges minus the internal cut; to each H-edge assign 2 raised to twice its number of real edges minus the intervening cut. Contract these unary and binary functions and divide the resulting signed integer by 2^m. Exponents are nonnegative. Intermediate absolute sums are bounded by 2^{m+2E} when each factor is owned once. A standard bag sum-product over the verified decomposition of H requires polynomial overhead times Σ_bag ∏_{i in bag}(n_i+1) arithmetic operations, on O(m+E) bits. Disconnected components can be contracted separately. For a fixed bound on quotient treewidth this is polynomial.

On a path of p≥4 complete classes, each of size p, consecutive classes completely joined, the quotient is the path itself, giving O(p³) arithmetic operations after constructing factors, at polynomial bit cost. The incidence phase has exact width p²−1; the original graph contains a 2p-clique. On K_m the quotient has one vertex, hence m+1 terms for every syndrome. These are explicit examples in which an exponential number of Gaussian cosets can be summed in polynomial time.

Conversely, for any connected bounded-degree graph of large treewidth and minimum degree ≥2 with girth ≥5, there are no twin vertices: adjacent twins would create a triangle and nonadjacent twins would have two common neighbors, forming a 4-cycle. Thus twins and component decomposition leave G itself, and the presented cubic has width |V|−1. A bounded-degree expander with these girth conditions has linear treewidth by the balanced separator property. Private AND variables occur in one AND gadget, each t occurs in one AND and a bounded number of local XOR gadgets; checking parity via local deterministic XOR chains keeps occurrence and width of the CNF bounded. This is a barrier only for the displayed presentation and treewidth/twin algorithms. No lower bound for arbitrary rewritten circuits, SAT decision, or grouped deformed Cauchy nodes follows.
