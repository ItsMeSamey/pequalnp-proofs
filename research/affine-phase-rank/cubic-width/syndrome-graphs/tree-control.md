# Tree rank under extension and gate rewrites

Fix a feasible b in the private-AND code family of the companion. Consider any exact unique-extension encoding retaining the visible x_e,y_e coordinates, even with new auxiliaries and other gate arrangements. Across any bipartition, fixing every y_e=1 and summing out every auxiliary is left/right matrix multiplication of the full solution-indicator flattening. Therefore its rank over any field cannot increase. Unique extension guarantees an indicator after summation even in positive characteristic. The resulting function is 1[Ax=b] on the x_e alone.

Across F|E−F let U and W be the two column spans. Distinct row syndromes in U match column syndromes in b+W. Their intersection is a nonempty coset of U∩W since b is feasible. Removing duplicate and zero rows and columns leaves a permutation matrix of order 2^λ, where λ=rank(A_F)+rank(A_{E−F})−rank(A). Hence the exact visible flattening rank is 2^λ over every field.

Prune all leaves except x_e in any binary tree of the original coordinates; suppress resulting degree-two vertices. Every edge cut in this branch decomposition is induced by some original edge between the same surviving leaf sets. Consequently some original flattening has rank at least 2^{bw(M(A))−1}, with branchwidth in the λ+1 convention. For a cycle matroid of a graph containing a cycle, matroid branchwidth equals graph branchwidth by Hicks and McMurray, https://doi.org/10.1016/j.jctb.2006.12.007 . For bounded-degree expanders the latter is linear: a subcubic tree has an edge balancing edge leaves; the middle vertices separate the exclusive vertex sets. If the middle set is sublinear both shores retain linearly many exclusive vertices by bounded degree, contradicting the vertex-expansion inequality. Thus even arbitrary parsimonious gate additions preserving visible assignments cannot bring the full solution-indicator tree ranks below exponential on this family. This conclusion concerns representations with leaf variables and single-edge rank cuts, not scalar computation or SAT decision.
