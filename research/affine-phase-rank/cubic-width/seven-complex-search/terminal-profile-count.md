# Terminal profiles with five ordinary products

For a seven-ray list with five block-product rays and two exceptional rays, reflection-global-potential.md gives an existence-preserving reduction. In a terminal representative every full cut must be full for both exceptions with the same remote code. Equal-full-remote-terminal.md excludes that case. Consequently both exceptional rays have Schmidt rank below eight at every cut.

Filtering the unresolved rows of two-exception-ledger-v2/two-exception-profiles.csv by this condition leaves 32 simultaneous party-permutation orbits, accounting for 104 labeled unordered profile pairs. For a profile (a,b,c,g), at least one cut is full precisely when max(a+b,b+c,c+a)+g equals three. Profiles record Bell and GHZ counts. The relative local stabilizer encodings within a row are still variable. The matched-syndrome test imposes a further condition on those encodings. The unrestricted rank-seven existence question remains open.

The subsequent exclusion in no-full-double-ghz-simple.md eliminates two of these orbits. The updated count is 30 terminal profile orbits and 100 labeled pairs.

The combined triangle, shared-marker and double-GHZ tests leave 23 profile orbits (83 labeled pairs). The accompanying terminal-23-after-triangle-and-double-ghz.txt gives each surviving pair and its multiplicity.
