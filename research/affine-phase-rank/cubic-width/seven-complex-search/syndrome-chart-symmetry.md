# Clifford symmetries of the syndrome chart

In the control-Walsh chart a W_t vector is c_s (-1)^{q_s(d)}, q_s(d)=sum_i s_i x_i y_i and d_i=(x_i,y_i). The following reversible Clifford operations preserve this subspace, Fourier support size, stabilizer rank, and externality of each candidate ray.

Permute blocks. Translate controls by a binary vector a. Independently at each block, apply d'_i=U_i d_i+v_i+w_i s_i with U_i an invertible binary 2-by-2 matrix and v_i,w_i arbitrary binary pairs. After a block permutation write s'=s+a and accompany this affine permutation with the real diagonal phase (-1)^{q_s(d)+q_{s'}(d')}. The phase is Clifford: (U_i d_i)_1 (U_i d_i)_2 equals x_i y_i plus a linear function since det U_i=1 and binary squares equal themselves. The cubic terms cancel. Data translations use only the same s_i, so the remaining phase degree is at most two. The corrected operation permutes coefficient indices by the specified cube translation/permutation. A further arbitrary control-only fourth-root Clifford phase changes each c_s by a unit phase and preserves W. Each generator and inverse has polynomial-time construction. A candidate need not itself be invariant under any generator.

At t=3 a canonical form of a marked four-index subset is its lexicographically least sorted image under the 48 cube translations and coordinate permutations. Apply the same map to all rays and control coefficients, retaining all unmarked active or unknown indices. Any tested additional column restrictions must transform as well. This is a sound subgroup reduction; no claim is made that it finds every Clifford equivalence.

Within the more general class of control-affine maps s'=A s+a, a common invertible data-linear map L plus affine data translations, and a quadratic sign correction, the control linear part must be a coordinate permutation if the transformation preserves W. Indeed the data-data polar of the correction is fixed across s. Thus the difference polars B_s−B_r and B_{s'}−B_{r'} are congruent via L. Their ranks are twice the Hamming distance, so A is a binary linear Hamming isometry and permutes the unit vectors. Generic affine control changes therefore cannot be used within this class, even though the four-frequency compression proof may decode controls after dropping data pairs.
