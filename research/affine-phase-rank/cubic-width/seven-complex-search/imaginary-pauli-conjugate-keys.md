# Conjugate coefficient constraints for seven imaginary Pauli classes

For the real CCZ cube an odd number of local J labels makes the measured Pauli imaginary. These representatives are IIJ, IZJ, IRJ, ZZJ, ZRJ, RRJ, JJJ. A real Clifford takes any such Pauli to Y on the first qubit: a reversible binary linear map sends the nonzero shift to the first coordinate, the phase has first bit one by odd parity, and controlled-Z gates from that qubit clear all other phase bits. A real Pauli corrects the sign if needed. The transformed target remains real.

Use conjugate Y eigenvectors with positive first coordinate. The two conditional targets are conjugates in a common raw basis. Given ANY r-term expansion of one branch, conjugation gives one of the other; it preserves the unsigned Pauli frame F and conjugates the canonical raw coefficient, since a ray representative with first nonzero coordinate one retains this convention. For a nonzero coefficient class c modulo fourth roots let n(F,c) be the multiplicity. Put m equal to the sum over keys (F,c) of min(n(F,c),n(F,conjugate(c))). The matching formula lifts these two lists to a parent of length 2r−m. Since G3 has rank at least seven, m≤2r−7. In a four-term branch at most one occurrence can match; in a five-term branch at most three can. Every coefficient whose angle is a multiple of pi/4 self-matches. Other classes can match one another within a frame, with the exact bound retaining all multiplicities.

In particular a branch decomposition with at most five terms and only axis or diagonal coefficients is impossible in all seven named measurement cases. The argument applies even if the opposite branch in the putative physical list was not the conjugate list: a shorter alternative parent would already contradict the lower bound. This is a coefficient restriction, not a full case exclusion.
