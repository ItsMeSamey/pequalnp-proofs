# Complex stabilizer rank of three CCZ copies

The exact complex stabilizer rank lies between seven and eight. The lower bound excludes every six-term decomposition. The product construction supplies eight terms. A seven-term decomposition remains open.

The proof uses the exact two-copy rank four, the Bravyi et al. stabilizer-alignment theorem, and a finite three-qubit local Pauli catalogue. The independent whole-proof reviewer reran the catalogue and found 126 exceptional pairs among all 1,953. Run `sha256sum -c rank-seven-manifest.sha256` from this directory to check the proof and its dependencies.
