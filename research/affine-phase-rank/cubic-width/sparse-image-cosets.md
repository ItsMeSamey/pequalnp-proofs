# Dense quotient above a sparse image span

Let C be the d-dimensional binary image code on m two-bit blocks. Construct the span S of all codewords of block weight at most fixed h by bounded-support enumeration and Gaussian elimination. Extend its basis to C. Put e=dim(C/S). Enumerate the 2^e complement tuples. In each coset, the forbidden patterns receive known offsets, and d−e remaining generators have block weight at most h. The sparse-image-basis construction counts each coset in polynomial space and poly(input) times 2^{O_h((d−e)/sqrt(log(d−e+2)))} bit time. Multiply the sum by the kernel size of the original seed map. All cosets are disjoint. Total time is subexponential in d whenever e=o(d).

Visible degree is insufficient for arbitrary affine restrictions. Start with connected four-regular ordinary NAE on n vertices, m=4n/3. Its difference code C0 has dimension n−1. A uniform d=floor((n−1)/2) dimensional linear subcode C contains each specified nonzero word of C0 with probability (2^d−1)/(2^(n−1)−1). At most sum_{j<=δm} binom(m,j)3^j ambient words have block weight at most δm. For a sufficiently small fixed δ>0 this count times the inclusion probability tends to zero. Thus some C has minimum block distance >δm. Linear lifting realizes C by restricting the visible variables of the very same formula to a linear subspace. For constant h its sparse span is zero and e=d. This bounds the recurrence's structural parameter and supplies no lower bound on other algorithms.
