# Coalesced NAE transversal deficit

For a 3-uniform hypergraph, code each NAE(x,y,z) as the single two-bit guard (x+y,x+z) != 0 over F₂. Literal signs change affine offsets only. Let m be the edge count and f(I) the linear rank of the difference rows from edges in I. The image code has dimension f(E). Let A be any full-rank parity check on its 2m output coordinates. For J a subset of blocks, the code shortenings to J have dimension f(E)−f(E−J), since this is the kernel dimension of projection of the code to its complementary blocks. Hence rank A_J=2|J|−f(E)+f(E−J). Rado's maximum partial transversal rank t equals min_J(m−|J|+rank A_J). Subtracting this from rank A=2m−f(E) gives exactly k=max_I(|I|−f(I)). This first identity also covers shared affine input ports with arbitrary binary linear maps.

On ordinary variable ports, the kernel of the differences from I consists precisely of assignments constant on each hypergraph component touched by I, so f(I)=|V(I)|−c(I), with no isolated vertices counted. Thus the maximum adds across components and can be found by polynomial-time linear matroid intersection. The difference map itself has exactly two lifts per incident component, times two per isolated variable.

For connected inputs of maximum degree at most three, every connected edge subset has at most as many edges as touched vertices by counting incidences. Equality forces every touched vertex to use all three incident edges in the subset, so a nonempty connected equality subset is a whole cubic component. Consequently the exact deficit is the number of entirely 3-regular components; components should be solved separately. For connected d-regular inputs with d>=4 the full subset already gives k >= (d/3−1)|V|+1. General bounded-degree tractability and hardness must be attributed to the relevant literature. In particular Darmann, Döcker and Dorn establish NP-completeness for each fixed d>=4 even for linear 3-uniform hypergraphs supplied as d perfect matchings, and polynomial time for d<=3 under their restrictions. https://arxiv.org/abs/2412.03395

The density m=n by itself does not bound deficit. Take any connected dense 3-uniform family with core m₀−n₀ growing, e.g. all triples on t vertices, and attach m₀−n₀ loose edges to one original vertex, each with two fresh vertices. The resulting connected graph has m=n while its core certifies deficit at least m₀−n₀+1. The verifier enumerates subsets and assignments: K₄³ has deficit one and six models, the Fano plane has deficit one and zero models, and AG(2,3) has deficit four and zero models. Deficit is a presentation parameter, not a satisfiability certificate.
