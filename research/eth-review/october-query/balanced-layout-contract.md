# Constructed source layouts, depth preflight and direct CNF driver

The module packet_layout.py installs the original r=64 schedule in variable_packet_machine.py. For each of two shores, assign a vertex one of R=r^a full labels. In the conditional expectation of the sum of squared pair loads, the only label-dependent terms compare an incident edge against an edge of a different vertex already labelled on that shore. The opposite endpoints' conditional agreement probability multiplied by R is R if identical, 1 if distinct and either unassigned, or R/0 according to their known-label equality. Add these integers to the other edge's label bucket, choose a minimum score and assign it; reverse ordered pairs multiply all scores by the same two. Unassigned other vertices on the current shore contribute a uniform constant, and self comparisons are constant. This computes the source's conditional-expectation choice with O(M²) edge-pair operations over both shores, plus polynomial index/vertex/array processing. Parallel edges are distinct physical indices. With max degree Delta, the terminal variance is ≤2M Delta. Emit just the nonempty packets from the source's common padded classes, since an all-dummy packet supplies no port or nonconstant mode. Slot bits select orientation within each unordered-pair pattern; each edge occupies the same slot at both ends. The source inequalities give at most 3M/L packets and at most 3M/r real ports per symbol per shore, hence ≤6M/r edges in every child. No old vertex is split. All addresses, probabilities and grouping labels are integral bit strings of polynomial length; direct sequential emulation of random access costs a polynomial factor.

At the root, lambda=ceil(log2 s), H=ceil(s/floor(sqrt(lambda))) and Delta=ceil(s^(9/10)). The code uses integer root tests. At depth d set U=floor(M0/8^d); for every U>H evaluate u=floor(lambda/(131072·2^d)), a=2 sum_{j≤d}u_j. Explicitly check u^5≥lambda^4, L^1000,D_arr^1000≤s, H+1≥2 D_arr² Delta, H+1≥L D_arr, 2L≤Delta, U(2L−1)+1<s^4, and 1≤u≤H+1. Starting with Pbar=P0, also check Pbar*u≤(H+1)2^(a−u) and 8(a+1)u≤2^(a−u), update Pbar by adding 8ceil(3U/u)L+8U(a+1). These are conservative simultaneous path bounds. For active M≥H+1 the input p≤Pbar; any active shell D_t≥2^(a−u); h=ceil(3M/u)≤4M/u. Therefore p_t≤34 M D_t/u and p_t≤the updated Pbar, precisely what the partition bound needs. When any root test fails, direct enumeration is used instead. For fixed size/precision constants all tests eventually pass: d≤(log2 lambda)/6+O(1), u=Omega(lambda^(5/6)), and 2^(a−u)=2^(a_previous+u) eventually dominates the polynomial-lambda factors in prior precision. The source's H vs Delta and tiny exponents on L,D_arr imply the packing preflight. Finite fallback is mathematically legitimate even though its threshold vastly exceeds examples executable here.

Field construction, direct poly-bit root descriptors, clause normalization, equality paths, subdivision, unused-variable correction and fixed-density root entry are in source_cnf_driver.py. The caller uses e=4lambda and a binary irreducibility test, retains ell=1 for the original Boolean problem, and verifies output lies in the base subring. Each model extends uniquely through equality trees and subdivision nodes. All ten original checks pass including unused, contradictory and repeated occurrence cases. The Csize=O_k(n+m) assumption, degree bound and field size hold for the fixed-width source. The per-level number of children is bounded by s^O(1) exp(O(s/sqrt(lambda))(sqrt(2)/8)^d); multiplying across O(log lambda) depths yields exp(O(s/sqrt(lambda))+O(lambda log lambda)). This statement relies on the manuscript's contraction lemmas together with the explicit packing and precision gates. Immutable descriptors, fresh children released at DFS return, and reusable polynomial-length tape segments give a polynomial mathematical space bound. The Python reference uses interpreter recursion and exact integers. It is not yet an every-prefix visited-cell theorem for compiled Lean code, nor an executed large asymptotic instance.
