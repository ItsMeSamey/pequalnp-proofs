# Density-only Tanner parameters

Fix integer B≥1 and m≤Bn. The 8-port Margulis–Gabber–Galil walk on (Z_j)² exists for every positive j, has one permutation for each labelled port, and normalized second algebraic eigenvalue ≤5√2/8. Add eight labelled identity ports. The symmetric stochastic 16-port walk is positive semidefinite; its nonconstant singular values are ≤(1+5√2/8)/2<31/32. [Original construction](https://doi.org/10.1016/0022-0000(81)90040-4) · [Formalized spectral estimate](https://isa-afp.org/entries/Expander_Graphs.html)

Choose the least positive t satisfying (31/32)^t≤1/[200B(1+4t)]. This uses exact rational comparisons and t=O(log(B+1)). Put D=16^t, H=1+4t, δ=1/(100BH), P=2(100BH)². D≥8B by the stopping rule. If m≥D take j=ceil sqrt(m/D), q=j², d=D, giving m≤qd≤4m. From each left vertex, for each t-letter word in the 16-port alphabet connect to its right walk endpoint. Each word is a permutation and thus labels one port at every right vertex too. Keep parallel edges distinct. The normalized graph adjacency is the t-th walk power, with nonconstant singular values ≤δ/2. If m<D use one vertex on each shore with d=m distinguishable parallel edges and zero mixing error. The case q=1 includes equality m=D.

Use c=ceil(d/(8B)), h=ceil(δd)−1, r=max(1,ceil log₂d). Evaluate powers 0,…,h−1 at d distinct elements of GF(2^r), expand each Vandermonde row into r binary rows and pad with zeros to c. Since hr≤d/(100B)≤c, this fits; independence of any ≤h columns implies local distance ≥δd. At h=0 no nonzero local checks are needed. An irreducible and all maps can be found by ordinary polynomial arithmetic, since 2^r≤2max(2,d) and qd≤4m. The construction uses polynomial bit cost and storage in n,m,B.

At q>1, 2qc≤qd/(4B)+2q≤qd/(2B)≤2m/B≤2n. At q=1, 2c≤m/(4B)+2≤3n. Each row uses ≤D physical clause ports. The original local-distance and mixing calculation yields accepted nonzero word weight ≥δ(δ−δ/2)qd≥m/P. Shortening to m coordinates extends by zero, preserving distance. The polynomial physical shortlist uses the new P and the source's 3n rounds and ≤6n equations.

Thus D=(B+1)^O(1) and P=O(B²log²(B+1)) independent of m. For B=n^o(1), total test scope incidences N₀≤O_k(n(B+1)^O(1)) and degree cap K=O_k(n) give O_k(n log(B+2)) wires. With the original heavy branching, factor and variable groups each have n^(3/4+o(1)) incidences. Degree-array enumeration costs 2^O_k(√n log n); local entry costs 2^{n^o(1)}; both fit the original contract. At fixed k, choosing the size parameter proportional to n log(B+2) yields the density-sensitive exponent O_k(n log(B+2)/√log n) with a polynomial prefactor, conditional on the source contraction theorem. This application only assumes m≤Bn; one can use B=max(1,ceil(m/n)). The dense source's sparsification still yields polylogarithmic B in the worst case, and retains its O_k(n loglog n/√log n) exponent.
