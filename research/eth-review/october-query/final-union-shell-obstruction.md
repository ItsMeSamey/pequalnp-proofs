# An expensive formal shell of the union-subset encoding

Use the connected base graph and negative linear 3-CNF construction of final-query-period-obstruction.md, with base prime p the largest prime congruent to one modulo four below (log q)^(1/4). Dirichlet's prime number theorem for that fixed progression gives d=p+1=Θ((log n)^(1/4)). The graph remains simple and the same spectral estimate holds. Literal degree ≤2d=o(√log n) avoids the manuscript's branching threshold, while m=nd/4 exceeds the direct clause count cutoff. The final Tanner-plus-greedy system must contain every violation cubic somewhere: the assignment supported on its three variables violates it alone. This argument applies to every tie choice. On the branch fixing heavy variables to zero, at most 2dn/√log n hyperedges disappear, leaving Ω(nd) distinct cubics, including one occurrence of each in a remaining row. Unsigned all-negative clauses and linearity prevent cancellation of these untouched monomials. The branch contains the all-zero model.

For each row group g and coordinate group h use b_gh distinct free variables read by g in h. Project repeated occurrences within g to the same Boolean variable. The syntactic union-subset layout reserves ceil(log₂ binom(b_gh,t_gh)) bits on cell gh for the exact-degree array t; direct raw bits cost at least this many. There are O(√n) cells under the original J-by-J layout. The admitted array budget K is at least n in this branch, as follows from ℓ=n+1 and K=k(a+2(ℓ−1)). Write U_g=Σ_h b_gh.

If some U_g>n^.95, allocate t_gh=floor(b_gh/2) on its cells only. The sum is ≤n. For b≥2, log₂ binom(b,floor(b/2))≥floor(b/2), by independently taking one from each of floor(b/2) disjoint pairs. Hence this node has degree Ω(U_g−J), forcing scale s≫n loglog n under the native maximum degree cap s^.9.

Otherwise the base spectral bound in final-query-period-obstruction.md applies groupwise, giving at most 2√d U_g distinct covered surviving triples in group g. Thus N'=Σ_g U_g≥Ω(n√d). In every cell set t_gh=floor(n b_gh/N'). Their sum lies in [n−O(√n),n]. For t>0, binom(b,t)≥(b/t)^t by multiplying (b−j)/(t−j)≥b/t. Each contributes at least t log₂(N'/n) bits. The total is Ω(n loglog n). This holds on some syntactically admissible array for every such variable and row grouping. The same array works for per-cell raw-bit fallback.

This bounds the mechanical shell graph. It proves neither that coefficients on that shell survive nor that an algorithm must process it: degree-profile pruning, changed outer tensor decomposition, scalar tests, and alternative CNF preprocessing are outside the argument. The result addresses exact counting on an easy decision family. The generic projected coefficient oracle may itself cost more after identification, independently of shell wire size.
