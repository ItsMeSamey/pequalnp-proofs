# Gaussian defect sums at the actual t=1 Cauchy evaluation

Use a loopless graph with e edges and v nonisolated vertices, one parity tensor per vertex (an arbitrary fixed XOR target there), and a binary equality tensor for each edge's two column ports. Equivalently use 2e independent row labels y constrained by the v vertex equations and e free edge bits X on the column shore. An optional original character (−1)^(a·(y,X)) is allowed. Real port 2j+b denotes end b of edge j, and ties are by edge identity, not adjacency within a packet. Use a supplied physical layout; the identity holds for any uniform power-of-two L≥2 and thus for every source-legal such layout. The standalone evaluator verifies slot coverage, not the native label/tie-break construction. These are actual parity/COPY input signatures in the general contraction problem, not a claim that all signed OR/COPY SAT networks reduce to them.

At t=1 take T=1+2Lζ with the actual integral coefficient extension and finite precision P. Each coefficient of W_xy(T) in the source shifted expansion is integral. The geometric perturbations are divisible by 2: in the native polynomial product, every q≠1 has v₂(1−q)≤log₂ L, so (1−q+2Lζ)/(1−q)≡1 mod 2 in the integral lift. For offset d=1 the constant C′(1)/C′(0)=−(L+1)/(L−1) is odd. For d≠1 use the missing-factor formula W_d(T)=W_1(T)(T−1)/(T−d); since v₂(1−d)≤log₂ L, this gives a multiple of 2 (also at ζ=0 by the polynomial identity). Thus each real row has base input b_i=X at its immediate successor slot if that slot exists and is real, else b_i=0. Each row form is exactly b_i+Σ_j c_ij X_j with every c_ij∈2R. Sum coefficients of repeated accesses to the same physical X. Residues are evaluated at their creation precision; this statement does not justify changing representatives of arbitrary old tensors. Substitution commutes with reduction modulo 2^P for these original fixed parity/COPY signatures.

The row's weight is 1[y_i=b_i]+(2y_i−1)Σ_j c_ij X_j. Expand, selecting k distinct defect rows and one real source read in each of them. Original row parity is never dropped. On all other rows retain the affine equation y_i=b_i; impose X_j=1 on each chosen read. The signed sum on these affine constraints is evaluated by Gaussian elimination: zero for inconsistent equations or for a character nontrivial on the homogeneous kernel, and otherwise ±2^dimension. The sign character is the XOR of the optional original character with the k marked row bits, and an additional scalar sign (−1)^k. A consistent term has at least e−v free bits: 3e raw bits, v vertex equations, 2e−k unchanged row equations and at most k pins. This dimension count tolerates all repeated reads and missing successor slots. Its coefficient is divisible by 2^k. Consequently every term of order k vanishes for e−v+k≥P. If e−v is negative the same cutoff is conservative.

For P=e−v+s, s>0, sum just k≤min(2e,s−1). The full returned scalar at that P is exact. With polynomial setup, time is bounded by poly(input,L,P,ring-description) times Σ_{k≤min(2e,s−1)} binom(2e,k)L^k, including each affine solve and bit arithmetic; stream choices using polynomial space. When P≤e−v the scalar vanishes without kernel evaluation. For fixed positive s this handles any bounded-degree cubic expander (e−v=v/2), without a small graph separator, including nonzero deformed residues. Field/ring multiplication in the reference uses its original coordinate basis, supports the truncated coefficient ring, and the argument uses divisibility by an ordinary power of 2 throughout. Gaussian elimination is over GF(2) on Boolean label constraints only. There is no planarity or matchgate assumption.

This yields a precise low-precision stripe and can obtain those low digits of a high-precision sample. The canonical Appendix-D working precision P_t is generally far above e−v; a low-stripe result cannot stand in for that full scalar, its ordinary derivative jet, or interpolation. For larger s compare the actual sum bound with direct evaluation and charge each point/layout. Prior root grid valuation facts and native polynomial routines give the mod-two partial shift, while ordinary affine-character summation supplies the cancellation; no unconditional whole-SAT speedup or Pfaffian representation is asserted.

partial_shift_affine.py implements the scalar. check_partial_shift_affine.py compares direct row extensions on a shuffled K4 fixture with dummies. The observed residues are 0 modulo 4, 4 modulo 16, 20 modulo 32 for a nontrivial target/character, and (4,0) at extension-field point (0,1) modulo 16. These are finite physical kernel/slot controls, independent of any canonical full-layout construction.
