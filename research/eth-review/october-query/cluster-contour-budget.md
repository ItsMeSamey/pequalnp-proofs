# Absolute error budget across the full physical contour

Write C for the original number of models and F_j for the physical circle samples. The verified circle formula has weights with sum of absolute values at most 2 and alias error below 1/4. For any independently certified zero samples, discarding those terms leaves C−1/4 ≤ 2 max_j |F_j|. More generally, if a subset E is evaluated exactly, replace C on the left by |C−Σ_{j∈E} w_j F_j|. Every cluster majorant U_j must bound |F_j|. Thus the certificate with polynomial U on all samples, allowing exact zeros, cannot cover a family with exponentially many models. An empty set of nonzero samples implies C=0.

For the connected signed construction in connected-nongrid-zero.md, fix every base vertex to one. Every fresh edge bit is then free, even on the two edges with additional positive clauses. Thus C≥2^|E|. This lower bound applies to EVERY packing; the nongrid-root argument separately requires a supplied packing. The cycle version admits ordinary constant-treewidth model counting; a bounded-degree expander base is a minor of the incidence graph, so source treewidth can also be linear. Neither claim is hardness of deciding these planted instances.

Allow sample scaling by nonzero known factors A_j. Reconstructing F_j/A_j to error ε_j contributes |w_j A_j| ε_j. With the original uniform absolute sample tolerance 1/16 the normalized target is 1/(16|A_j|). Consequently the generic absolute truncation bound depends on log^+(|A_j| U'_j), where U'_j majorizes the normalized scalar; rescaling alone does not improve the bound. A different accuracy allocation may save a sample with tiny weight; for any certified total absolute error budget, the weighted absolute magnitudes still sum to at least C−1/4. A global allocation with normalized majorant/error ratios all poly(M) can only certify polynomial C unless large contributions are computed exactly.

For each sample j and attempted partition charge m_j 2^b_j times polynomial cyclotomic bit costs. If accepted and not returned exact, the generic remaining clock is polynomial times m_j(8D_j 2^s_j)^K_j, K_j=ceil(log2(256(m_j+1)max(1,U_j))). Sum over all required samples, add recognition and any exact subroutines, then repeat on every pinned branch needed for witness extraction (up to n successful binary decisions provided both counts can be obtained). The unpinned promise does not imply the pinned promise. A high K_j in this sufficient-cost formula says nothing about algorithms exploiting known log coefficients, exact scalar prefactors or cancellations between samples.

physical_cluster_sample.py is an exact per-sample certificate checker on a supplied original packet layout. It validates slot uniqueness, sums true OR/COPY factors over private bits, recognizes exact zero and constant blocks, or verifies a conservative supremum bound using the cyclotomic coefficient 1-norm. It does not discover balanced layouts, implement the optional Holder-moment test or evaluate truncated logarithms. An UNKNOWN answer has no decision meaning. For a fixed physical block partition recognition requires exponential time in the largest block input scope. Exact small full-contour controls are validation only.

For the alternative one-embedding acquisition use cluster-primitive-acquisition-clock.md (8d4f0ed3) with the bounded-height coordinate recovery 656d1804. With integral scale A, conjugate bound H, field degree d and absolute target δ, either A U H^(d−1)<1 certifies exact zero by the field norm, or the prescribed recovery precision gives log(U/δ)=Ω(d²). In the latter case use truncation K=O(log(m+1)+log^+(U/δ)) with a sufficiently large explicit additive constant, or exact enumeration over the shared raw bits if cheaper. All candidate preprocessing and private tables are charged. This precision alternative cannot import the multi-sample 1/16 tolerance.
