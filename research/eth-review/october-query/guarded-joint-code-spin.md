# Joint evaluation of shifted scores on the all-positive guard leaf

Take the actual A leaf in guarded-circulant-positive-handoff.md, with one positive guard unit, v base spins and m simple edges, one private bit per edge, n=1+v+m and q=1+m. Let U be the binary span of the actual Tanner and selected rows, r=dim U. Use unnormalized counting. For a mask s the full physical Walsh sum is zero if the guard component is one. Otherwise summing over the guard gives 2. At an edge, summing the private bit gives 2 unless the edge is selected and both end spins are zero, in which case it gives zero. The sum is therefore 2^(m+1) times the number of independent sets of the spanning selected-edge graph, including isolated vertices.

For b=0 or the trial h let Z(b) sum those independent-set numbers over s in b+U with zero guard bit. The exact greedy trial count is 2^(m-r)[Z(0)+Z(h)] by the character expansion of the r prefix constraints and the single trial. This includes dependent and repeated trials. At r=m+1 the power means exact division by two after addition. Put δ=rank of guard restriction to U (zero or one). Each nonempty slice is one affine translate of the same edge code C, of dimension r−δ, since projection onto the edges is injective on zero-guard words. The slice is empty iff the guard bit of b lies outside the guard image of U. Compute a particular shift by binary elimination.

Supply a binary edge-decomposition tree. For subtree edge set A put C[A]={c∈C:supp(c)⊆A}, identified with its restriction, and T_A=π_A(C)/C[A]. Its dimension is λ_A=rank π_A C+rank π_complement C−dim C. Its spin boundary is the set of vertices incident to edges on both sides. At each node tabulate counts indexed by a T_A state and boundary spin assignment. Count each mask restriction in the indicated coset of C[A] once, and each internal spin assignment once. Work on unshifted code representatives and add the known physical shift only in testing an edge. At a leaf enumerate the at most two restricted code bits and the endpoint spins consistent with the boundary. At a join of B,D compute the linear image of C in T_B × T_D × T_A by elimination. For a given parent state sum over precisely its compatible child-state pairs. Any pair of actual child masks at those states glues to an admissible parent restriction of the specified state: start with one witnessing global codeword and add each child's difference separately from C[B], C[D]. Conversely each glued pair has a unique child restriction and parent restriction. Match spins on common vertices and sum newly internal bits once. The root has one state and empty boundary. Multiply once by two per isolated base vertex, if present. Intermediate integers have O(m+v) bits.

With w=max_A(λ_A+|boundary A|) and height H, tabulation takes poly(n)2^(3w) time and poly(n)2^w space. Streaming a single root entry by recursively recomputing children takes poly(n)2^O((w+1)H) time and polynomial space for H=O(log n): enumerate pairs of child indices at each node and query precomputed polynomial-size linear compatibility tests, without building exponential transition lists. Supplied tree and code matrices can be verified and prepared in polynomial time. All shifts within one round reuse this tree and code. For P letter slots there are (2q)^P physical trials; charging each and Z(0) once per round preserves any supplied deterministic enumeration and first tie. Up to 3n rounds multiply the largest round clock by 3n, charging row updates, tree discovery if used, and its verification. Prefix acquisition, sibling leaves and original input construction have separate costs.

For a measured interval of actual prefixes with λ=ceil(log₂ n), H=O(log n), w=O(n/λ²) throughout, the streaming method for every physical trial in the interval costs 2^O(n/λ) polynomial space since P log₂(2q)=polylog(n) for this native schedule. This upper-bound exponent is little-o of n/√λ and hence of the general source benchmark n log λ/√λ. If r−δ and q−r are both Ω(n), literal per-mask enumeration of a nonempty dual slice and literal primal kernel enumeration each visit 2^Ω(n) terms. This comparison is conditional on the same observed prefix meeting the width and rank tests. No such middle-rank prefix is asserted for the native construction. Arbitrary G and prefixes remain exact, with potentially linear w. No lower bound on faster scalar algorithms follows.
