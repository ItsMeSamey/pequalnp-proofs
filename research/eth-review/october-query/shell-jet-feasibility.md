# Exact shell precision feasibility and integer-cost planning

Use the designated Hermite origin functional in quantitative-contraction.tex. Write L=2^a, k_i=a+1−i, and use the complete signed grid [−L,L−1] with zero excluded. Shell i has d_i=2^(a−i) nodes for 0≤i≤a, including the singleton −L. q_i is the uniform multiplicity, allowed to be any nonnegative integer. Precision cap cap_i is a nonnegative integer; a forbidden shell instead has q_i=0. A cap of zero permits an active shell when its entire contribution already vanishes at the target precision. Input degree D is the valid polynomial degree bound and p≥1 is the origin precision. The computation assumes independent integral errors on the supplied jet coefficients.

For t of valuation i with q_i>0, let E_t(T) be the normalized Hermite factor, the product of ((T−v)/(t−v))^q over other active nodes. Its valuation at zero is
```
V_i = sum_{h>i} (h−i) d_h (q_h−q_i).
```
Indeed nodes of lower valuation contribute zero. For each h>i there are d_h higher-valuation nodes and equally many same-shell nodes v with v₂(t−v)=h. The latter exhaust the nonzero losses; this counts inactive higher shells in the coefficient of −q_i. This identity is for complete valuation strata. The outer-representative version uses representatives of the nonzero residues modulo L and disallows the highest residue class of valuation a−1: for i<a−1 set d_i=2^(a−1−i), include h=a−1 of population one in the loss sum with q_(a−1)=0, and retain the same k_i. Distinct surviving representatives have differences of valuation <a. Equal-valuation displaced counts then depend only on their distinct residues. The implementation permits further inactive strata through forbidden caps.

The reciprocal of E_t(t+2LZ) has integral coefficients and constant one. In ordinary Hermite reconstruction the coefficient of the highest requested input has valuation exactly V_i−k_i(q_i−1). Every lower coefficient has valuation at least that much, since every term uses an integral reciprocal coefficient and at most q_i−1 powers of −t/(2L). Arbitrarily signed independent errors at the uniform precision need exactly
```
P_i = max(0,p−V_i+k_i(q_i−1)).
```
Necessity follows by perturbing just the highest coefficient at one active node by a power of two times one. No independence property of physical inputs is asserted. Physical jets can obey additional relations, and other recovery functionals on oversampled data can have different conditioning.

Process shells from highest to lowest. For all previously chosen higher shells store A=sum d_h q_h and B=sum h d_h q_h. Write C_i=sum_{h>i}(h−i)d_h. The tail contribution in V_i is B−iA. The largest allowed q_i, including zero as an option even when no positive multiplicity is affordable, is
```
max(0, floor((cap_i−p+k_i+B−iA)/(k_i+C_i))).
```
Use zero on forbidden shells. The bound is monotone coordinatewise in the higher multiplicities. Choosing these maxima gives a feasible vector dominating every other cap-feasible vector, by descending induction. Exact feasibility with the degree constraint is equivalent to its final mass A exceeding D. Signed integer floor division is required. O(a²) arithmetic operations suffice, with polynomial bit lengths even for large binary caps.

To minimize an additive integer charge rather than maximize available mass, keep the cheapest prefix path per state (A,B) at each shell. Try each permitted q up to the displayed bound. Choose its exact P_i, add d_i times the supplied one-node charge c(i,q,P_i), and update the two moments by d_i q and i d_i q. Inactive shells incur zero charge. At the end minimize over A>D and backtrack. For fixed costs at prescribed caps one can have the cost routine use those caps. For minimum-required precisions this minimizes the specified schedule charge; allowing higher precisions as options when a cost model prices those lower requires a separately priced precision choice. Costs at a node must depend only on these arguments and fixed state-independent parameters. Global setup costs or nonadditive sharing have to be included separately. The optimizer does not identify actual data-dependent child times without an independently justified cost oracle.

With C the largest supplied cap (or zero), q≤C+1 by reverse induction from the bound (B−iA≤C_i(C+1)). Thus A≤2L(C+1), B≤2aL(C+1). The implementation uses O(a² L²(C+1)²) states including backtracking and O(C+2) transitions per state up to polynomial lookup overhead; pay the actual bit cost of each price call and the bit length of accumulated prices. This is polynomial for the explicit native sizes, and pseudopolynomial for arbitrary succinct numeric caps. A cost example is D+1 evaluations per active node in the published ordinary-evaluation method. A finite recursion majorant can charge each node's D+1 sample values, actual precision-dependent weighted-partition estimate, 64 child calls per retained tuple, entry bounds, and polynomial recovery arithmetic separately. The older finite-schedule optimizer searched u with a prescribed linear taper; the valuation minimax lower control concerns exponential tuple counts and still applies on its stated representative grid.

**Strict comparison to every standard linear taper on the full grid.** At a large genuinely active source root u≥6, h=ceil(3M/u). Set q_0=0, retain q_i=h(u−i) for 1≤i<u, and set all others to zero. Every retained V_i and highest-coefficient guard is the same as in the published taper since the removed shell has lower valuation. Its mass is hL(u−2+2^(1−u)), strictly exceeding M(2L−1). It uses L(1−2^(1−u)) active centers, strictly fewer than L. Every nonzero feasible retuned taper q_i=h' max(v−i,0) includes all L odd centers, even if the cutoff v and slope h' are jointly retuned. Thus the new vector strictly reduces the total count of ordinary source sample evaluations relative to every such taper at this same fixed L, each using D+1 evaluation points per active center. This counts calls including all shells but does not imply a better exponential runtime. It does not compare a different layout, packet length, or shifted-shell definition of linear taper.
