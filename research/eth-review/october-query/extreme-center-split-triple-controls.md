# The first possible bit is attained on signed SAT and UNSAT triple families

The bit criterion in extreme-center-first-possible-bit.md is nontrivial at linearly growing order and precision on source-permitted full layouts of width-three signed formulas without units or pure variables. For the UNSAT block take all eight three-literal sign patterns on three variables. For the SAT block omit the all-negative clause; the only model is all ones. Take N disjoint copies with fresh variables. A block contains q=24 or 21 literal occurrences and exactly one all-positive clause of width three. Distinct clauses never subsume each other; every variable has both polarities and degree at least two. Use the fixed-density compilation of quantitative-reduction.tex, including the trivalent COPY trees for all three variables per block. A degree-d variable tree has d−2 trivalent vertices and d−3 internal COPY-to-COPY edges. Thus the number Q of old edges per block is 24+3·5=39 for UNSAT and 21+3·4=33 for SAT. Let E=QN, M=2E, and L=2^a at the actual root s=n+m=(3+#clauses_per_block)N. The older unsplit degree-seven/eight network has qN old edges and is a separate admissible contraction input; it is not this fixed-density compilation.

Take N to be a sufficiently large power of two. For K=64^a possible full vertex labels, K²L divides N by the native small a schedule. Use the admissible paired-packet geometry from normalized-unit-packet-recurrence.md: each external literal edge has its clause row in a full first packet and its ternary COPY row at the identical slot in a twin. For every internal tree edge put either trivalent COPY endpoint first and the other in the twin slot. The two columns share that old edge's unique subdivision bit. First allocate H=E/K² first-packet slots of each ordered full-label pair (α,β), with the same entries in the twin. Such complete packets are constructed by grouping unordered symbol pairs per coordinate and filling every allowed orientation/copy slot uniformly. Divisibility by L makes the counts exact. All loads are equal and each single label-coordinate symbol occurs on 2E/64 physical ports per shore. It remains to enforce consistency for variables and clauses with multiple ports.

Assign exactly N/K blocks to each old-shore label α, on all their clause and trivalent COPY vertices. Across its E/K first-packet slots, the fractions at each extreme slot 0 and L−1 are each at most (127/128)^a. Indeed conditional on α, β is uniform on the K words because all ordered loads are equal. In a coordinate with β equal to α (probability 1/64), the copy bit is uniform; for unequal symbols the orientation bit is fixed under a common symbol-order convention. The β coordinates are independent and all copy bits on equal coordinates occur in equal proportions, independently across those coordinates. Thus the probability of either specified full bit string is at most (1−1/128)^a, also for an extremal α. For sufficiently large a we have 2Q(127/128)^a≤1. Hence every first-packet slot at position 0 or L−1 for a given α can be assigned to a different block of that α. Use any negative literal occurrence of that block for its one designated endpoint. Fill all other first-packet slots with the remaining old edges of blocks of the same α. Thus every internal tree edge occupies an interior slot. Assign each old edge's subdivision COPY2 vertex its slot's β, and place its second endpoint in the twin. This respects all external and internal physical edges at both ends; no block has two endpoint occurrences. The construction supplies a legal layout without asserting fixed tie-break reachability.

At either t=±(L−1) there is one live logical subdivision bit per twin pair, hence b=E/L and f=E−E/L. The live clause row is one of the designated negative literal occurrences, so every all-positive clause is dormant: r=N. Each ternary COPY having a matched row has two unmatched incident rows, since there is at most one designated endpoint edge in its entire block. The baseline Boolean COPY condition therefore forces its matched bit to zero. Every live logical bit is read by such a variable row in the twin, so only the all-zero baseline can survive. At that word all remaining clauses have a negative literal and all COPYs are satisfied.

Each dormant clause has three real nonendpoint row slots. Their opposite single-step wrap reads are distinct outside bits: within each first packet the shift is injective, all logical bits there are distinct, and only the extreme column at the far end is a live bit. Different first packets have disjoint logical bit sets. Thus different dormant clauses have disjoint outside supports, all of size three. The binary Gram matrix is the identity and f≥r. The criterion gives the exact native valuation v₂([Z^N] F(t+2LZ))=E−E/L at both active extreme centers. All lower orders vanish and this valuation is strictly below P_t. Both raw counts 0 and 1 occur. Since r=N=Θ(M), these examples can exceed the separate sufficient r≤2h height threshold. They establish attainment in the full physical scalar on formulas with multiple disconnected blocks, without an algorithmic hardness claim.
