# Exact counts and raw witnesses from affine observation charts

The shared entry point `affine_mst_backend.solve` accepts declared arity, original signed clauses, per-clause scope and cumulative table-word caps, optional observable raw variable IDs and an optional exact counter. Its default enumerates the indicated variables. It returns the exact raw count and a checked raw assignment for positive count. A supplied counter that is total and exact on the original and its required unit-pinned versions suffices for completeness. A partial counter may cause an explicit exception if it declines the raw input or a required raw pin. Count values are trusted under the callback contract. A range check and a checked witness alone cannot validate a positive count.

**Normalization and fibers.** Each normalized signed clause excludes one word on its variables. A full forbidden parity class on one scope yields a sound equation. The compiler removes the clauses for that class and retains the others. Gaussian elimination detects a contradiction or gives d=n−rank independent bits. For every residual clause the complete compiler checks its simultaneous literal-falsity equations for consistency. It drops an inconsistent system's clause; an always-false clause ends the count. For example, the four clauses encoding x⊕y⊕z=0, the two for w=z, and (x∨y∨¬w) have no residual observations. The older stand-alone compiler retained rank two in this example.

Let r be the rank of the remaining observations. A supplied list of r raw IDs must have independent restricted normals spanning exactly the observation space. Their affine offsets shift the literal phases, and the lift enforces values on the actual raw IDs. The automatic route uses an echelon basis. Every observation word has exactly 2^(d−r) lifts, including declared unused bits.

**Which tree is optimized.** In that chosen basis, join the r coordinates and a dummy in a complete graph. An edge's weight counts clauses for which its endpoint coefficient vectors differ. Kruskal minimizes the sum of these weights. The edge bits map bijectively to observation bits by XORing the incident bits of each nondummy vertex. Every edge that changes a literal vector is an essential input of its surviving clause, since flipping it at a feasible all-false word satisfies the clause. Thus the optimized sum is the total of the essential scopes. Each clause with width w charges all 2^w local word visits, including satisfying words. The aggregate table cap applies separately to each chart, including work on earlier clauses if a later clause causes rejection. The preprocessing clock also includes parsing, Gaussian solves, all coefficient signatures and sorting the quadratic-size edge list.

The emitted CNF excludes precisely the falsifying words of each clause. Multiply the chart count by 2^(d−r). For a positive chart witness, the inverse interpretation of the coordinates and a Gaussian solve yield a raw assignment which is checked on all original clauses. Given only a positive count, the shared wrapper uses at most r additional pinned queries on the chart or n on the original. Every witness returned by a pin query is checked against its full pinned CNF. Invalid or oversized supplied charts and declined backend calls are recorded, then the wrapper tries the automatic chart and finally the original formula as applicable.

**Backends and clocks.** The older `affine_mst_complete.solve` enumerates accepted chart words subject also to its chart-word cap. Its optional callback handles only raw fallback. The shared wrapper uses the same backend on compiled and raw inputs. Its default enumeration is complete. If supplied, an exact counter satisfying the October theorem's fixed-width hypotheses yields a compiled-count contribution polynomial in the declared arity and explicit input size times 2^O_w(r log log r / sqrt(log r)) for fixed compiled width w and r≥20. For fixed actual compiled density the exponent becomes O(r/sqrt(log r)). At most r pin clauses preserve bounded width and fixed density. Charge earlier attempts and raw fallback independently. The code does not implement the October counter or call a graphic-matrix recognition algorithm.

**Controls.** In `affine-mst-width-countercontrol.md` every minimum-total-scope tree in the specified seed basis has maximum width r+1 and visits 2^(r+1)+8r table words. A different tree in the same basis has width at most three and visits 16r−4 words. The positive interval family in `affine-incidence-tree-optimizer.md` gives width three in its specified seed basis, available through the supplied-observable interface. The automatic basis is data dependent. The separate `affine-observation-all-bases-distance.md` result forces linear width in every affine basis for its own signed-CNF family.
