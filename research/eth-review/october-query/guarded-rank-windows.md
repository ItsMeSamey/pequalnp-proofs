# Actual early and late rank windows on the guard-true prism leaf

Use guarded-circulant-positive-handoff.md and guarded-joint-code-spin.md. With λ=ceil(log₂ n), B=Θ(λ(log λ)²), q=m+1=Θ(n), the original Tanner row bound gives r₀=O(n/B+1). Since every violation word occurs, each actual minimum increases rank until rank q. Thus r_j=min(q,r₀+j), independent of the physical enumeration's tie choices. Put R=floor(n/λ). For large n the first R−r₀+1 prefixes and all prefixes j≥q−r₀−R have min(r_j,q−r_j)≤R. There are Θ(n/λ) early prefixes and at least that many late ones, including all repetitions after full rank.

The guard-zero edge code C has dimension r−δ and codimension m−r+δ≤q−r, where δ∈{0,1} is the rank of the guard projection. At a cut its state dimension is λ_A(C)=|A|−dim C[A]−dim C⊥[A], by projection duality; hence λ_A(C)=λ_A(C⊥) and λ_A≤min(r−δ,m−r+δ). Group each rung with its two outgoing rails, and build a balanced binary interval tree of columns, refining each bundle into its three single edges. Every edge cut in this tree meets O(1) boundary spins. The joint tables therefore evaluate every physical trial across both windows in 2^{O(R)} total bit time and 2^{O(R)} space. The factor 3n(2q)^P is charged, since P log(2q)=polylog(n)=o(n/λ). This window exponent is little-o of n/√λ.

Polynomial space is also possible at the same exponent on this prism: in the early window enumerate the nonempty affine guard-zero slices of the actual row span (at most 2^r masks per slice), and count independent sets of each selected rail/rung subgraph by a four-state column DP with wraparound. In the late window enumerate all 2^{q−r} physical violation profiles one at a time with guarded-prism-kernel-suffix.md. Both variants retain every ordered physical trial, not only its winning score. The joint-code streaming clock alone guarantees the same late bound for q−r≤n/λ² at logarithmic tree height. Forward Walsh or Cayley traceback can avoid listing every candidate on small-nullity prefixes; they solve a different output problem. These results cover selected windows on the A leaf. No improved clock is established for the intervening ranks or the sibling branch.
