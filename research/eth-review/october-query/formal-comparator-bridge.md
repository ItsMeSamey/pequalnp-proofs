## A concrete 2-adic tape operation

tapered_jet_machine.py implements the manuscript's complete grid S=[−2^a,2^a−1], alpha=2^(a+1), active multiplicities q_t, actual node precisions p_t, and scalar Hermite recovery acting independently on each of the e*ell coefficient lanes. Let Njet=sum q_t≤8ML and B=max(p+g,max p_t,a+2,ceil(log2(Njet+2))). Let v_t=v2(E_t(0)) and choose common guard g=max(0,max_{t,j<q_t}(−v_t+j(a+1−v2(t)))). The source valuation bound gives g≤6hL+4M(a+1). Each local jet is divided by E_t(t+alpha z) by repeated truncated division by 1+c z, c=alpha/(t−q). Scanning ascending j replaces row[j] by row[j]−c row[j−1] using the UPDATED preceding coefficient. Compute c modulo 2^p_t by removing the exact power of two from its denominator and inverting only its odd part, using Newton doubling. No illegal nonunit inversions occur.

Strip the odd unit from the scalar E_t(0) using its signed numerator/denominator product modulo 2^(p+g). Add the jth local coefficient times this odd unit, times odd(−t)^j, left-shifted by g+v_t+j(v2(t)−a−1), to an accumulator modulo 2^(p+g). Every shift is nonnegative and its sum with p_t is at least p+g by the source precision guarantee. Thus arbitrary independent choices of coordinate lifts are harmless. At termination the low g bits vanish by integrality of F(0); discard them and return the next p bits. Individual summands need not be integral without the common guard.

With Njet=N, lanes=e*ell, the repeated linear-factor divisions take at most lanes*N² modular multiply-adds; scalar unit preparation takes polynomially many repeated-squaring and Newton steps (at most O(N² log(N+2) log(B+2))). Schoolbook fixed-width binary addition, subtraction, shifts and multiplication suffice. For an explicit loose single-work-tape budget, store node counters, O(N) local words, and one B-bit accumulator per lane in S=O((N+lanes+1)(B+log(N+lanes+2))) cells, excluding the supplied jet tape. Pack or scan the supplied N*lanes residues in polynomial length J. Each arithmetic step on B-bit words can be implemented by O((S+J+B+1)^3) head moves using indexed scans and schoolbook shift-add. Binary exponentiation and Newton lifting multiply this by at most O(log(N+2)log(B+2)) per scalar inversion/power. A deliberately coarse uniform bound is O((lanes+1)(N+1)^2(log(N+2)+1)(log(B+2)+1)(S+J+B+1)^4) tape steps and O(S+J) visited cells, using a fixed number of tapes. All loops, word widths and positions have ordinary finite binary encodings. No new extension-field multiplication, rational-height representation, denominator product or exponential table is required for this reducer, since its multipliers are rational scalars. The formal library exposes BinaryArithmetic, ModularArithmetic, BitProgram and a guarded compiler; our program is a Python reference plus a direct bit-tape cost bound, not a Lean port.

## Remaining constructive comparator interface

A replacement must supply an actual guarded bit program for BOTH marked and accepted sparse-polynomial query invocations; e.g. NativeLeafContract.local_from_runs consumes outputs of HighQueryProgram.marked and accepted, including output frames/preserved stacks and per-prefix caps. It must compile the incidence-ring network, generate balanced child packs, stream weighted mode profiles, materialize immutable references with creation-time canonical lifts, evaluate the extension-field interpolation values, produce the local jets and run the above recovery. Each nonterminal call at depth d must have at most s^C exp(C s/sqrt(lambda) (sqrt(2)/8)^d) children, independent of description length, lambda=ceil(log2 s); per-call stack caps and input-work factors polynomial in s+description length; leaves pay exp(O(s/sqrt(lambda))) times that polynomial. Summing depth logs charges O(s/sqrt(lambda)+lambda log lambda), since D=O(log lambda). DFS uses only polynomial visited cells when workspace is reused in one fixed address interval; merely bounding simultaneous live data would not prove the formal visited-cell statement.

Use manuscript sparsification schedule sigma=1/ceil(sqrt(log2 n)); do not silently reuse the old outer schedule. It yields 2^O(n/sqrt(log n)) nodes and each leaf has 2^polylog trial calls; each branch's n+1-bit counts and final outputs fit. With s=O(n loglog n), this gives O(n loglog n/sqrt(log n)) in the exponent (and bounded density uses s=O_D(n) via the direct network). Canonical unary encoding gives L_input≥n and ≥m; polynomial conversions to literal lists and n+1-bit little-endian output, finite small-n fallback, preserve the clock. A full machine theorem additionally needs cross-ABI correctness for the implemented subprograms, new schedule coding, per-prefix space proofs and actual kernel checking. None of those assertions follows from the recovery routine alone.
