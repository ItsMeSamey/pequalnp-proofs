# Histogram-free native group summation

The balanced group split from group-budget-convolution.md fixes one mode exponent only at the lowest group-tree split separating its source and target. At a node with remaining strict budget P−a, stream cut exponents of total weight w<P−a. Multiply the two scalar child results (both called at remaining strict budget P−a−w), then add to the node's scalar accumulator. Every globally admissible tuple survives on every path exactly once. Multiplying sums over different subtrees may additionally include overweight tuples: each target packet coefficient for β is divisible by 2 to the sum of its targeted mode weights counted with β multiplicity. Integral source-side factors, retained entries, and assignment summation preserve the resulting ideal. Each mode is targeted exactly once, hence the extra tuple's scalar product vanishes in the original ring at P. This justifies scalar-only accumulation while maintaining the existing 65/96 upper envelope for balanced group paths. In particular dropping the budget entirely on a path has no work guarantee. No child oracle is replaced in this argument.

scalar_group_dfs.py accepts a ring, an ordered group tree (represented by recursively splitting the supplied ordered sequence in halves), source/target/weight/cap per mode, and an incident-only lookup. It streams mixed-radix mode indexes in-place without language recursion in the number of modes. Dynamic storage for scalar return values is O(log r) in a balanced tree in addition to polynomial mode/index storage, input data and child working storage. The histogram alternative uses O(P log r) such entries. The executable returns full coefficient vectors only in a separate tagged audit ring, which incurs its own vector storage.

Precommitted tests are in scalar-dfs-precommit.md; results in scalar-dfs-receipt.txt. The L=2 source kernels are the pinned ordinary polynomial quotients at t+4ζ, with target ORs and equality COPY source vertices summed exactly.
