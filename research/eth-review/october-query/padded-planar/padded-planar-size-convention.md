All bit-time bounds for the padded-planar recognizer include the declared variable count n as well as the explicit clauses. For a binary n field a short list of clauses can leave u declared variables unused. The solver returns the ordinary integer obtained by shifting the used-variable count by u bits. On every recognized unpinned instance this count is positive, so printing it costs at least u+1 bit operations. Equivalently the polynomial bound can use explicit input length plus output bit length for the recognized unpinned class. The asymptotic source family has no unused declared variables. The implementation does not return a succinct factored output. The arbitrary-pins extension remains a proof.
