# All-layout rank of genuine intermediate padded-grid predicates

Use the open square grid and clauses of padded-planar-joint-scalar.md. Write L for the side, b=floor((log₂ L)^{1/8}), n=Θ(L²b) for the number of original bits and m=Θ(nb²) for the number of clauses. On a base matching choose the positive gate clause of each edge, forming T with t=Θ(n/b) clauses. Fix every base spin and padding bit to zero, and every gate bit outside the t chosen positive gates to one. Then the full clause violation word is supported on T and equals the coordinatewise complement of the free gate bits there. This is one simultaneous restriction on original variables.

Let C contain the source's initial Tanner rows, the greedy prefix, and one candidate row. Write H=C[:,T] over GF(2). For μ=floor(log₂ m)+1 the source sets P=20000 B²μ² and D₀=320000 B²μ³. With k=3 the chosen sparsification bound is B=2(1+M+M²), with M=O(σ^{-1}log(2/σ)), σ^{-1}=ceil(sqrt(ceil(log₂ n))). In particular B=O(log n (log log n)²). Set d=ceil(m/P). Every nonzero kernel word of H extends by zeros to an initial Tanner kernel word, so has weight at least d. Here d=Ω(n/((log n)^{15/4}(log log n)^4)), using m=Θ(n(log n)^{1/4}). These are the actual source parameters at commit 42907c9e999cc00d6abe7a50bfc1023250edd1b9, main_full_version.tex, sparse-checks and sparsification lemmas, and quantitative-reduction.tex, arbitrary clause density.

The selected restricted rank starts at o(t) by the Tanner row bound in padded-grid-intermediate-window.md and ends at t since every nonzero violation word supported on T is attainable and the final query rejects it. Each round adds one row. For every integer j from ceil(t/2) through floor(3t/4)−1 there is a selected prefix of restricted rank j. Every trial there, including a discarded one, has restricted rank in {j,j+1}. Its code K=ker H therefore has dimension k'≥t/4 and minimum distance at least d. These trials accept actual nonmodels.

Consider any subcubic tree on the t coordinates as leaves. On a cut A|Aᶜ put λ=rank H_A+rank H_{Aᶜ}−rank H. The syndrome H_A w_A for w∈K takes values in the intersection of the two column images, of dimension λ. Subdivide one edge to root the tree, and suppress degree-two nonroots if desired. Set a=floor(d/2), taking L sufficiently large that a≥2. Proceed bottom-up, detaching the current rooted component at its parent edge whenever it has accumulated at least a surviving leaves. Each detached piece has at most 2a−2 original leaves since each surviving child contributes at most a−1. Treat the root as the final piece without cutting a parent edge. It too has at most 2a−2 leaves. There are at most t/a cut edges, since each detached piece contains at least a original leaves. A duplicated bipartition at the subdivided edge causes no difficulty.

The map from K to the tuple of all cut syndromes is injective. If each syndrome is zero, either side of each cut, masked to zero outside that side, belongs to K. For a fixed piece, the exterior branches across its incident cut edges partition its exterior leaves. Subtract their masked words from w. The remaining codeword is supported on fewer than d leaves, so vanishes. This holds for every piece. Hence k'≤Σ λ over removed edges, giving a cut with λ≥k'a/t=Ω(d). This includes a linear variable order using its caterpillar tree (pendant single-coordinate cuts have λ≤1).

Across any cut the real matrix of the restricted feasibility indicator has entries 1 exactly when the two side syndromes agree. There are exactly 2^λ common attainable syndromes. Each gives a nonempty all-ones block with disjoint row and column supports, so the real rank equals 2^λ. Complementing the free gate bits merely permutes the two matrix indices. For any subcubic layout on all original bits, prune leaves outside the free gate set and suppress degree-two vertices. Every cut of the resulting tree lifts to a cut of the original tree. Pinning yields a submatrix of the original predicate flattening at that cut, so its rank is at least 2^{Ω(d)}. In particular a tree tensor representation of the open predicate on that layout needs a bond of at least this dimension. This result concerns original raw-bit predicates and exact arithmetic over the reals.

Summing the pinned predicate itself gives 2^{k'} by Gaussian elimination. The original unpinned final scalar has the polynomial planar algorithm in padded-planar-joint-scalar.md. Neither statement evaluates all unpinned intermediate scores in polynomial time. The rank bound concerns their open predicates and imposes no general lower bound on computing those scores as scalars.
