# Exact edge-syndrome allocation and its middle-trial cost

For the recognized signed padded grid and actual clause order of [the intermediate window](padded-grid-intermediate-window.md), partition the columns of the supplied binary parity query C by original base edge e. Both private blocks, including their principal clauses, belong to that edge. For any target β, let B_e be a full column basis of C_e and express C_e=B_e D_e. Write r=rank C, r_e=rank C_e, and

    d' = sum_e r_e − r.

The concatenated matrix B=[B_e]_e has rank r. Test B y=β and reject inconsistent targets. Stream its affine solution space by Gaussian parametrization; there are exactly 2^(d') allocations. One vector y_e represents the distinct contribution B_e y_e. This is a parametrization of algebraic allocations; it makes no assumption that every local value is physically attainable.

For one allocation and each edge spin pair, enumerate the two private blocks jointly, evaluate their *actual* violation vector v_e and count D_e v_e=y_e. This yields a nonnegative four-entry spin table. Given the base spins, private blocks of different edges are disjoint, so the product of their entries counts precisely the complete private assignments for this allocation. Sum over base spins by the longer-side median-line grid recursion, then sum over allocations and multiply once by 2 to the number of declared unused bits. Each raw assignment contributes to exactly one allocation, including for nonfinal queries or nonzero β. No final-CNF equivalence enters the argument.

If b_e padding bits belong to each half and L is the grid side, time is 2^(d') poly(input) (sum_e 2^(2b_e+2) + 2^O(L)). Space is polynomial: enumerate one affine allocation and one local assignment at a time, store four integers per edge and traverse the median rectangles in depth-first order. Every partial nonnegative allocation total is at most 2^n. The estimate counts the literal allocation visits before exploiting unavailable local values, repeated scalars or zero factors. The cheaper of this sufficient bound and the independent Walsh bound in the intermediate-window note may be used after charging preprocessing. This note supplies an algorithm and a lower control; it does not report an execution.

**Monotonicity and a genuine source control.** At fixed rows and fixed partition, add one column to an edge block. Its local and global rank increments each lie in {0,1}. A global increment implies a local increment, since the old local span is contained in the old global span. Consequently d' cannot decrease when restoring columns. This is a statement about columns, not about appending parity rows.

Use the source family and matching T of size t in [the late-trial rank proof](padded-grid-late-trial-rank.md). Restrict to exactly one matched plus column per matched edge, discarding all other columns. Every such column is nonzero even at the initial Tanner stage: main.tex lines 3261–3275 imply distance at least m/P, which exceeds one on this family for large n since m is at least linear and P is polylogarithmic. Appending parity rows preserves nonzeroness, including on discarded candidate trials. Thus every retained edge block has rank one and the restricted allocation dimension is precisely t−rank(C_T). Restoring all columns gives d'≥t−rank(C_T).

The initial restricted rank is o(t) and the final rank is t. Each accepted row can increase it by at most one. At every selected prefix of rank k in [ceil(t/2),floor(3t/4)−1], every one-row candidate has k≤rank(C_T)≤k+1≤floor(3t/4). All these trials therefore have d'≥ceil(t/4), while r≥ceil(t/2). They are genuinely intermediate on this source: a nonzero word in ker C_T corresponds to a physically realized exact set of matched violations. The homogeneous target is consistent, so the literal stream traverses at least 2^ceil(t/4) allocations. This argument does not give that fraction for ranks near t; there it gives only t−rank(C_T). It also does not bound an aggregated or pruned traversal, signed Pfaffian methods, or the direct final scalar.
