## Arbitrary pin restrictions of a final count

Use the signed padded-pair class and notation of padded-planar-joint-scalar.md. Let s be the number of distinct consistently pinned original coordinates. An inconsistent pin set gives zero immediately. Replace the free-unused factor by 2 to the number of unpinned unused coordinates. Every private coordinate belongs to a single edge. For each damaged edge integrate both private blocks subject to their pins to obtain a four-entry table H_e(u,v). Specifically try each allowed gate bit z, test its outer clause and sum binomial(f,j) for 0≤j≤min(f,2−z−k) where f is the number of free pad bits and k the number pinned one. The two conditional block counts multiply. Divide the entries by the corresponding strictly positive unpinned table. Include each directly pinned spin as a unary indicator. These at most s factors multiply the original unpinned spin integrand into exactly its required restriction.

Expand each binary factor separately in its four Walsh characters, each unary factor in its two, by the normalized two- or four-entry signed sums. Stream all ≤4^s tuples and multiply their rational weights, combining character supports by symmetric difference. No table on 2s coordinates is needed. The odd spin moments vanish by complement symmetry of the unmodified spin integrand. For an even spin set T, choose in polynomial time a primal edge set J of odd-degree boundary T, for example by peeling a spanning tree. For each primal spin assignment, its T-character equals (−1) raised to the parity of its disagreement-edge intersection with J. The external original dual edges selected by the dimer matching are exactly the complementary set. Flip the sign of each corresponding weight on J and multiply the matching sum by (−1)^|J|. Use the signed Pfaffian of the same oriented skew matrix, times the fixed sign of the oriented matching convention. Determine this sign once on the positive unmodified matrix (nonzero because the empty disagreement set is feasible). Taking a square root of the determinant separately on each signed call loses the needed sign.

The arithmetic requires polynomial bit lengths in n and explicit input size. Each matching matrix has O(e) rows with denominators dividing the original edge denom product; after scaling, Pfaffian minors have polynomial-bit bounds by the determinant bound. Exact rational skew elimination uses minor ratios with row/column pivot permutations; alternatively compute the signed Pfaffian by a division-free polynomial arithmetic algorithm. The denominators of all local coefficient choices divide a common polynomial-bit integer (product over factors of 4 times all local original table denominators after taking ratios). Final sums of up to 4^s signed terms therefore still have polynomial bit length; a single term's spin correlation has absolute value at most the unpinned integer count. The running time is 4^s poly(n+input bits), space polynomial. This counts pin restrictions of the final selected system by pointwise original-formula equivalence. It does not evaluate discarded trial systems. The released unpinned determinant-square-root implementation does not implement this extension.
