## Large restricted rank at genuinely intermediate greedy trials

Use the same fixed padded grid and source B as padded-grid-intermediate-window.md. Restrict each parity row to the columns of the matching T of t=Theta(n/b) clauses. Every binary word on T occurs as an exact original violation word. So the final selected matrix restricted to T must have rank t. The initial restricted rank is at most the total initial row count O(n/(log n)^{3/4})=o(t). Each added greedy row increases this restricted rank by at most one. Consequently the selected trajectory has an intermediate prefix at every integer restricted rank from ceil(t/2) through t−2. At each such prefix EVERY trial has restricted rank at least the prefix rank and at most t−1. Thus every trial still accepts at least one actual nonmodel. Its literal Walsh row-space pass visits ≥2^{ceil(t/2)} characters before final equivalence is reached. This applies equally to discarded trials that are evaluated. This is a lower bound only for extending the literal early-window character iteration through the entire greedy search. It does not bound joint character aggregation, changed search procedures, or direct original model counting.
