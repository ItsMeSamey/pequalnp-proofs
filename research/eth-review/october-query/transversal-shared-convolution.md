# Shared-witness factorization for the Latin-square incidence family

Index three original parts by G=F₂^r, q=2^r. Violation exists iff some A_i=1 and T_i>0 where T_i=Σ_j B_j C_{i+j} is a nonnegative integer. Set H_{u,j}=(-1)^{u·j}, compute U=HB, V=HC and W=H(U pointwise multiplied by V). Expanding and summing over u gives W_i=qT_i by character orthogonality. Impose W_i=0 whenever A_i=1. Integer zero detects any violation without collisions.

A transform uses r butterfly stages of q/2 sums and differences. The initial two have intermediate magnitude ≤q, pointwise products ≤q² and final transform intermediates ≤q³. Signed width 3r+3 suffices; no division is needed. Ripple-carry addition/subtraction uses O(r+1) Boolean gates, schoolbook signed multiplication O((r+1)²). Total gate count and bounded-fanin wire count are O(q(r+1)²). Standard AND/OR/NOT gate equivalences yield O(q(r+1)²) width-at-most-three clauses and auxiliary variables. All original A_i-implies-W_i-zero bit guards use O(q(r+1)) binary clauses. Each original model has exactly one gate-by-gate extension and each nonmodel none. Read A,B,C for recovery.

For the connected sums identifying a common A vertex, reuse that physical bit in every copy. Size O(lq log²(2q)) replaces lq² original clauses. Composition with any additional predicate on original inputs preserves that predicate and the unique-lift property. This is a nonlocal shared-witness escape from the exact same-variable incidence optimum. Its auxiliary variables count toward any downstream variable-sensitive bound. Group structure must be supplied or discovered at separately charged cost. No arbitrary-3SAT clock follows.
