# Deterministic polarity selection for the endpoint precision gain

For a normalized input of m nonempty width-at-most-k, non-tautological clauses on distinct names per clause, flip independent original variables with probability 1/2. The expected number of all-positive clauses is sum_C 2^(−|C|)≥m/2^k. Fix the flips in order by conditional expectation, counting unfinished clauses whose fixed signs still allow every literal to be positive, weighted by 2^(−number of unassigned names). Use the larger of the two conditional sums with deterministic tie-breaking; clearing denominators by 2^k is exact and bit time is polynomial in the original encoding for fixed k. Empty formulas and immediately false cases bypass the route. A common variable flip bijects satisfying original assignments and inverts directly on a recovered witness. The Boolean signed-OR/COPY compiler preserves the numbers of edges and gate/vertex degrees under this polarity change. With those encodings, the exact endpoint proof in original-root-factor.md therefore yields at least ceil(sum_C 2^(−|C|))(a−j) saved bits at EVERY active root shell j, for both SAT and UNSAT. Its relative saving still tends to zero on the native schedule. This improves the physical root scalar evaluation precision guarantee without improving the leading exponent order.
