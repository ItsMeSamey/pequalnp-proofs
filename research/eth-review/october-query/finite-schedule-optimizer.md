# A finite optimizer for the Appendix-D recursion majorant

Keep r=64, λ of order log₂s, Δ=ceil(s^.9), H=ceil(s/floor(sqrt λ)), the source field extension, and packet exponent cap A=floor(4ελ). Write a=2Σu_j, L=2^a. Keep the source packing conditions and λ^.8≤u≤M at active nodes. Only the prescribed shape of the schedule changes.

At (d,M,p,a_prev), try each admissible integer u, a=a_prev+2u≤A. Shell 0≤i<u has D_i=2^{a−i} nodes, h=ceil(3M/u), P_i=p+8hD_i+8M(a+1), c_i=floor(6M/D_i). The exact capacity majorant for mode tuples is B_i=[x^{P_i−1}](1−x)^{-1}Π_{j=1}^{P_i−1}(1−x^j)^{-c_i}. Q=M(2L−1)+1 interpolation values per node. At a leaf V=1. Minimize over feasible u the integer

1+64Q Σ_i D_i B_i max_{0≤m≤floor(6M/64)} V(d+1,m,P_i,a).

An infeasible continuation costs infinity. Taking the maximum over smaller m avoids assuming monotonic optimal values. The root schedule below is feasible at large s; small sizes use direct sum. This optimizes a finite bound on calls, not actual node counts. B_i is computed by polynomially many unbounded-knapsack updates since c_i,P_i are polynomial. All table parameters range over polynomially many states: depth O(log λ), p≤P0+O(s(2^A+A)log λ), M=O(s), a≤A. Logs of finite V values are at most depth times a polynomial in s. Thus even the optimizer uses polynomial bit time and space. It returns a uniform decision table and can run before contraction. A weighted version replaces leaf and internal unit costs by a fixed bit-machine implementation's upper charges (leaf 2^M times entry calls and arithmetic, internal polynomial recovery and work per tuple). The source gives asymptotic entry costs and permits external evaluators; it does not specify exact finite machine constants.

For an analytic comparison set ρ=6/64, w_d=ρ^d, t the number of active depths, B=floor(A/2), f=ceil(λ^.8). Reserve tf=o(B), distribute the remainder proportionally to w_d^{2/3}, round down, then add f. This satisfies the literal floors on every level and the cumulative cap. Hölder gives the exact minimum of Σw_d/sqrt(u_d) under Σu_d≤B in the positive real relaxation as (Σw_d^{2/3})^{3/2}/sqrt B. The clipped schedule approaches this bound within factor 1+o(1). Discrete marginal allocation to the largest w_d(1/sqrt(u_d)−1/sqrt(u_d+1)) solves the floor-constrained separable integer problem; it is a proxy for log branching. Precision induction uses a−u=a_prev+u, M>H, and 2^u dominating every fixed power of λ to give P_i=O(MD_i/u). The cap retains L,D_arr≤s^.001, 2D_arr²Δ≤M, LD_arr≤M, 2L≤Δ, Q<s^4 eventually. Creation-time representatives and immutable entries keep entry time exp(O(s^.9)+O(L log s)) and polynomial space. Leaf cost 2^H and O(λ log λ) logarithmic level overhead are included. Total bit time stays poly(s+description) exp(O(s/sqrt λ)), in polynomial space. Dense fixed-width SAT retains the original sparsification overhead.

Conversely the finite majorant's root odd shell at M=Θ(s) has c=Θ(M/L), P≥24ML/u. All independently chosen binary indicators on c colors in each of the first k=floor(L/sqrt u) weights fit: c k(k+1)/2<P. Hence log B≥Ω(M/sqrt u)≥Ω(s/sqrt λ). This is a matching order bound on the stated optimization objective. It does not assert a lower bound on actual contraction after cancellation or shared evaluations.
