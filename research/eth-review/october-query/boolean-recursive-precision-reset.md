# Resetting all packet and precision scales along a Boolean recursive tree

Assume an original bipartite 0/1 tensor input with m≤CS wires, polynomial description and vertex counts, polynomial-space polynomial-time entry access and bounded degree (more generally the arity and entry requirements below at every expanded scale). Start at p=O(S) with scalar entries and set H=ceil(S/floor(sqrt(log2 S))). Directly sum all calls of size ≤H in their actual requested ring. On a nonleaf m>H use ONE native packing/interpolation/mode split with fresh lambda=ceil(log2 m), u=floor(kappa lambda), a=2u, L=2^a, r=64. For example kappa=2epsilon with source epsilon=1/(128·1024): 2^{24 kappa log2 m}≤m^.001 eventually, 2D_arr² ceil(m^.9)≤m, L D_arr≤m, 2L≤ceil(m^.9). Floors, ceilings and fixed finite exceptions can be handled directly. Old packet degrees ≤2(CS)^{2kappa+o(1)} fit each m^.9 above H. The bounded-degree raw signed fixed-density CNF route meets these assumptions. Arbitrary original degree S^.9 does not automatically do so.

For each actual t,ζ,β and child group g, retain all original tables and birth data, exactly as in quantitative-contraction.tex lines 484–553. Child size ≤rho m, rho=6/64. Each generation adds at most 3m/L potentially non-Boolean packet vertices per child, including zero-arity packet scalars. On one path retain every earlier exceptional vertex still present. The number h of exceptions is ≤Σ_j 3m_j/L_j=O(S^{1−2kappa}) by geometric shrink and L_j=Theta(m_j^{2kappa}). Thus h(log S)^C=o(H) for any fixed C, even with inherited exceptions concentrated in one actual child.

If child m'>H, use sparse-exception-digit-restart.md with its equivalent odd-prime scalar CRT backend (saturated-chunk-restart-accounting.md). Read the actual host birth values, evaluate integer coordinate polynomials of their original unramified/nilpotent axes on the sufficient ordinary integer grid, then reduce exceptionally weighted factors mod small odd primes q. Leave every original 0/1 vertex literal. The new nonnegative integer scalar ≤2^{m'}q^h is reconstructed exactly by a scalar modulus 2^{p'} with p'=m'+h ceil(log2 q)+2, then reduced modulo q. Centered CRT over primes with adequate product recovers the original signed integer for each grid point, and rational interpolation followed by original-ring reduction gives the requested child scalar. Numeric coordinate dimensions, bit heights and prime sizes are poly(S), so log q=O(log S), p'=O(m'), and there are polynomially many numerical queries per child. Fresh scalar nodes have ell=1; only their single native split introduces a new interpolation field. The construction is uniform, with digit/CRT and all physical entry access charged. No canonical lift is distributed over an intermediate contraction. Each fresh numerical query has unchanged topology, exceptional count, scalar initial precision and input type required by the same algorithm. If m'≤H use direct birth contraction instead, so no small-child ratio is assumed.

Store old entries as shared immutable bases with a stack of local word transformations (ring representative, coordinate grid, prime, creation precision). A wrapper reads one specific older word and does polynomial arithmetic, never calling a contraction. A born packet can evaluate its own local kernel and target exponent directly, independent of its incident older tables, in 2^{O(L log S)}poly(S) time and polynomial space. Repeated source powers are computed by squaring. This bounds the cost of all individual descriptors by the previous largest L on the path and polynomial-size wrappers. Branches and coefficient sums stream in depth-first order. All graph and descriptor material held on a single path is polynomial.

At each fresh node p=O(m), u=Theta(log S), D_i=L/2^i≥2^u. The native working p_t=p+8 ceil(3m/u)D_i+8m(a+1)=O(mD_i/u), so the source literal mode budget costs exp(O(m/√u)) via its partition bound. Include all outer Hermite nodes, ordinary point evaluations, mode loops, 64 groups, full CRT grids and prime multiplicity, exact rational reconstruction and entry costs. Path depth is O(log log S); even poly(S) extra branches PER generation total exp(O(log S log log S)), not generally polynomial. Log work along a path is dominated by Σ_j O(m_j/√log S)+O(H)+O(log log S · S^{2kappa}log S), hence the full deterministic bit clock is poly(input)·2^{O(S/√log S)} with polynomial space. The original root exact output requires the usual assignment/edge-count precision. The new independent a per node replaces the old cumulative a rule but does not improve general exponent order. A relaxed schedule surrogate with identical kappa log S budget gives coefficient (1−rho)^{-1} instead of (1−rho^{2/3})^{-3/2}; the hidden bit-machine constants, actual arities and charges differ, so no leading SAT time constant is asserted. Only original-density branches whose explicit roots meet the above entry and arity conditions receive the new internal scheduling theorem. For general fixed-k CNF use the cited source evaluator on any unmatched sparse branch and retain all preprocessing, candidate scores and losing query costs. This preserves the original overall fixed-k clock; the algorithm is a proved recurrence, not an executed all-input driver. The literal root obstruction 35d2d459 is unaffected.

Initial Boolean precision detail: when S greatly exceeds m, the root still has at most 2^m unit contributions including its literal 0/1 isolated factors. For exact counting set p=m+1; for requested precision P0 use min(P0,m+1) and return the appropriate residue or exact value. Thus the original Boolean expanded root can also use p=O(m). Sparse weighted roots need their separate initial treatment.
