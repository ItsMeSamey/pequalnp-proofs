# Signed primal-cover projection and its decision clock

Let $F$ be an explicitly listed signed CNF of fixed width $k\ge2$ on $n$ declared variables. Remove tautological clauses, repeated literals and duplicate clauses; retain any empty clause as an immediate contradiction. Let $\tau$ be the minimum vertex-cover size of the resulting primal graph, where two distinct variables are adjacent if they occur together in a clause. A supplied cover $X$ is checked by scanning the clauses. Alternatively greedily select disjoint uncovered co-occurring pairs and take both endpoints. Once every clause has at most one uncovered variable these edges form a maximal matching. Its endpoint cover has size $a=|X|\le2\tau$, and is found in polynomial time. Bounds in $a$ below also apply in $\tau$ for this automatic choice; an unnecessarily large supplied cover incurs its actual size.

Retain each core-only clause once. For every outside variable $y$ collect the clauses $y\lor A_i$ and $\neg y\lor B_j$, whose remainders use only core literals. Include all nontautological resolvents $A_i\lor B_j$ in the projected core CNF, discarding duplicates. This is simultaneous Davis–Putnam elimination: no resolvent contains another outside variable. On a fixed core assignment, incompatible requirements on $y$ arise exactly when some $A_i$ and some $B_j$ are both false. A one-polarity bucket needs no resolvent. Opposite units produce the empty clause. Consequently the projection contains precisely those core assignments that extend to original models. Raw model counts can differ because different core assignments can have different numbers of extensions.

If the source has $m$ normalized clauses, the pre-deduplication pair count is at most $m^2$; all signs, tautology checks and core IDs have polynomial bit cost. The projected width is at most $\max(k,2k-2)$, fixed for fixed $k$. Apply the October deterministic fixed-width SAT decision bound to this projected formula on $a$ declared bits. For sufficiently large $a$ the resulting bit clock, including projection, is

$$
\operatorname{poly}_k(n+m)\,2^{O_k(a\log\log a/\sqrt{\log a})}
=\operatorname{poly}_k(n+m)\,2^{O_k(\tau\log\log \tau/\sqrt{\log \tau})}
$$

for the automatic or minimum cover. Bounded $a$ is handled directly. The bound uses polynomial working space. To obtain a witness, first check satisfiability and then use at most $a$ further decision queries **on the projected formula**, choosing each next core bit according to satisfiability of its zero restriction. Adding at most $a$ pin units and retaining the same declared core size also works. Given the resulting core assignment, each $y$ is independently forced true by a false $A_i$, forced false by a false $B_j$, or free. Both forces cannot occur; assign free and unused bits arbitrarily and verify the final original model. Polynomial factors absorb these extra solves and writing the declared witness.

Suppose every normalized variable occurs in at most fixed $\Delta$ clauses. There are at most $\Delta a$ nonempty mixed or core-only clauses containing any core variable. Unit-only outside buckets yield either no resolvent by themselves or an immediate contradiction. Every nonempty resolvent can be charged to an input mixed clause containing a core literal, with at most $\Delta$ opposite partners. Hence the surviving projected clause count is $O((1+\Delta)^2a)$ apart from a possible single empty clause. This counting argument includes mixed clauses resolved against outside units. Pin units add at most $a$ clauses to each witness query. The fixed-density October theorem now gives $\operatorname{poly}_{k,\Delta}(n+m)2^{O_{k,\Delta}(a/\sqrt{\log a})}$ time, again with polynomial space. Constants here assume fixed $\Delta$.

For comparison, if every normalized clause has exactly three distinct variables, **all $n$ declared variables occur in this normalized formula**, and occurrences are bounded by $\Delta$, then every clause uses at least two core occurrences. Thus $2m\le\Delta a$. Each outside variable appears in a clause, each clause contains at most one outside variable, and hence $n-a\le m$. Applied to a minimum cover these imply $\tau\ge2n/(\Delta+2)$. The conclusion can fail after adding unused declared variables or permitting shorter clauses. In this all-used bounded-occurrence class, the projection offers no asymptotic parameter separation in $n$ from the existing fixed-density source clock.

The October bound used here is from [the fixed-density and unrestricted-density reductions](https://github.com/openai/math/blob/42907c9e999cc00d6abe7a50bfc1023250edd1b9/preprints/The-Exponential-Time-Hypothesis-is-False-October-25-2026/build/quantitative-reduction.tex). Existential projection by resolution is classical. The [prior private-block projection note](private-projection-decision.md) also treats extension and reconstruction, including a separate test for a 2-CNF representation. The present bound uses the raw cover to preserve fixed width and, when applicable, bounded clause density. The frozen projection/extension adapter [signed_cover_projection.py](signed_cover_projection.py), SHA-256 37cc4e33a052b0bfa17917e077249e40fcd344df148876164e0105915d72aeee, is separate from the October decision engine and the projected witness self-reduction. Its optional pair cap can decline a projection. A universal decision algorithm must continue by an uncapped projection or another exact solver when this happens.
