# Uniform-jet precision and the root mode count

Consider a fixed precision schedule whose decoder is sound for every scalar polynomial in the tapered Hermite interface. The globally consistent pair in joint-jet-adversary.md forces a precision P greater than cML/(u2^i) at some active node in shell i, even with arbitrary joint processing of the input jets. Let D=L/2^i. When jets are supplied by the native uniform-precision extension-field evaluations, at this shell the literal fully padded potential-mode inventory has Θ(M/D) unequal-coordinate tiles. Label symmetry gives the same counts at each coordinate and unequal pairs occupy a constant fraction. Each tile supplies the native potential modes of weights b+1. Choose orders 0 through K−1, where K=floor(c' D/sqrt(u)). All their 0/1 subsets have total weight O((M/D)K²)<P for small c'. Uniformly D≥2^(a−u+1) and a=2u, so rounding is harmless. At least 2^Ω(M/sqrt(u)) tuples pass the weight test, even if a fixed schedule moves its expensive query away from the odd shell. For fixed-density original CNFs with Θ(n) edges this is a limitation on the compulsory fully padded root loop at u=Θ(log s). It does not count physically nonzero terms or limit different summation algorithms, physical-only decoders, coefficient-dependent precision, or adaptive schedules on physical transcripts.
