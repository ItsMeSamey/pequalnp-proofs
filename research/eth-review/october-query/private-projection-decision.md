# Decision by exact private-block projection

Partition some raw variables into disjoint private blocks so each original clause touches at most one block. Treat each remaining core-only clause as its own factor. For block i with p_i private bits and b_i adjacent core bits, tabulate the relation R_i of core assignments admitting at least one private extension. Empty relation immediately certifies UNSAT. Otherwise collect every unary or binary clause on distinct boundary variables valid throughout R_i, by listing the absent patterns in its singleton and pair projections. Test the conjunction on every rejected boundary assignment. If all are excluded then this is an exact 2-CNF description, including for the full relation on an empty boundary. If every block passes, put all resulting clauses into one implication graph and decide SAT by strongly connected components. For a satisfying core the private witnesses extend independently because their variable sets and owning factors are disjoint. For decision the numbers of private extensions never enter; this procedure does not preserve model counts.

Tabulation and verification cost Σ_i 2^(p_i+b_i) poly(local description and boundary size), plus linear time in the binary implication graph for SCCs. Compact relations use up to O(b_i²) clauses each. Input validation and block discovery must be charged. If a projection fails, the implementation enumerates the appearing core variables against the exact local tables; the 2-CNF relaxation alone would be unsound. Local existential elimination is standard propositional forgetting/variable elimination. Resolution on a private variable used once with each sign gives the familiar single resolvent special case. More generally bounded Davis–Putnam elimination on these same blocks also works; this comparison confers no advantage over all resolution solvers. A strong backdoor to 2-SAT or renamable Horn instead requires that *every restriction* on the chosen variables belongs to that class, a different operation.

For a strictly bounded-occurrence control, replace each nonempty signed base clause C of width ≤3 by four ternaries. Use one fresh pair (p,q) solely in this gadget. For every sign pair on (p,q) include a clause consisting of these two signed literals and a single literal of C; distribute the four choices surjectively across C. If C is false, all four private binary clauses are active and mutually unsatisfiable. If C is true at least one of the four clauses is already satisfied, and any proper subset of the four private clauses is satisfiable. Therefore the exact projection is C. All four private sign patterns are necessary; both private variables occur four times with both signs. The code finds disjoint undamaged private pairs from common four-clause incidence lists and checks all signs. Ambiguity cannot change the SAT answer because every inferred decomposition and projected relation is itself checked. The bounded examples are not pure-literal/private-matching simplifications. Each private pair has only two variables for four clauses.

For the minimally unsatisfiable chain (x_1), (¬x_i∨x_{i+1}) for 1≤i<n, (¬x_n), this lifting yields bounded occurrence, no raw unit or binary clause, and minimal unsatisfiability. Deleting any one lifted clause permits the deleted clause's original gadget to be satisfied even when its base clause is false; all other base clauses can be made true by minimality, then all private witnesses chosen independently. A minimally unsatisfiable clause set has no nontrivial satisfying autarky touching a clause: otherwise removing the autarky-touched clauses leaves an unsatisfiable proper subformula. This rules out matching autarkies in particular. Choosing a linear-size disjoint subfamily of alternating implication gadgets shows an Ω(n) lower bound on size of a raw strong backdoor to 2-CNF or renamable Horn: each untouched gadget contains four ternaries and every polarity pattern on the same pair, including two positive literals under every renaming. A restriction assigning no variable in that gadget leaves it intact, even after duplicate and tautological clause removal. The matched positive control changes the final negative unit into a positive unit before lifting; the same decision procedure returns SAT. The proof establishes no lower bound on general resolution, SAT solvers, or backdoor notions permitting extra preprocessing.

The same construction transmits arbitrary bounded-occurrence 3-CNF through four-occurrence signed private variables (each old occurrence is replicated at most four times), so a private-occurrence promise alone does not force all projections to be binary or give tractability. Only the exact projected relation test justifies the fast path. Scripts private_projection_sat.py and check_private_projection_sat.py exercise the original signed clauses, both outcomes, every single deletion on the control chain, and a genuine ternary fallback. No Tanner setup, candidate training or original score trajectory is part of this decision algorithm.
