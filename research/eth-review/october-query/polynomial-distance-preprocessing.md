# Polynomial construction of the native sparse distance checks

Retain the parameters from original_dense_driver.py. For m>P there are d=min(m,320000 B² μ³), μ=bitlength(m), B≥1, q the least power of two with qd≥m, c=ceil(d/(8B)), h=floor((d−1)/(100Bμ)), and ε=1/(200Bμ). The existing proof needs a binary c by d matrix whose kernel contains no nonzero vector of weight ≤h, and, for q>1, d shifts of F₂^{log₂ q} with each nontrivial signed character sum at most εd in magnitude. Both constructions admit deterministic polynomial time and workspace in the native input sizes.

For the local matrix take r=max(1,ceil(log₂ d)), choose d distinct elements of GF(2^r), and evaluate the powers 0,...,h−1 at them. Expand each field row into r binary coordinate rows. Any j≤h columns are independent even over the large field by the j by j Vandermonde determinant using the first j rows; a binary sum vanishing after expansion would give a forbidden field dependence. Since r≤μ and hr≤d/(100B)≤c, pad the remaining binary rows with zeros. Repeated shifts and zero check rows are allowed. An irreducible of degree r can be found by testing the O(d) monic candidates by repeated squaring and gcd. For h=0 use the zero matrix. Distinguish zero tuple and exponent zero in evaluating powers.

For q=1 all shifts are zero and no nontrivial character exists. For q>1, d=320000 B² μ³ and ε²d=8μ. Set ρ=1+ε and a=ln ρ, so ε/2≤a≤ε. Write S_χ for the signed sum on shifts already chosen. The positive rational potential Φ=Σ_{χ≠1}(ρ^{S_χ}+ρ^{-S_χ}) starts at 2(q−1). Under a uniform next shift its conditional expectation is exactly Φ cosh(a), since every nontrivial binary character is balanced. Greedily minimize the resulting rational potential over all q shifts, d times. Consequently a max|S_χ|≤ln(2q)+d a²/2 via cosh(a)≤exp(a²/2). As q≤m and μ=bitlength(m), ln(2q)<2μ ln 2. Therefore max|S_χ| < (4 ln 2)μ/ε+d ε/2 = dε[(ln 2)/2+1/2]<dε. Powers of the rational ρ with exponents between −d and d can share denominator [200Bμ(200Bμ+1)]^d, of polynomial bit length. Enumerating all q−1 characters, q candidates and d steps with exact integer comparisons is polynomial.

The original Tanner wiring, shortening, distance proof, initial check count and row-weight bounds apply unchanged. For m≤P the native distance shortcut remains valid. This removes exponential local-matrix and shift-search preprocessing; it need not produce the lexicographically same sparse rows. Together with the polynomial greedy candidate list fbb6b49a, only polynomially many count calls and polynomial deterministic non-oracle work are needed per density-reduction leaf for check construction/selection. The cost of solving each original sparse check system and the size of the outside sparsification are still charged.
