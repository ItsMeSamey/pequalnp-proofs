# Hierarchical summation of the Appendix D exponent tuples

Fix one active call, interpolation node, residue-field point, creation-tagged tensors and working ring R=A_(p_t). Write p=p_t. Each mode has a fixed unordered pair of distinct group indices, polynomially bounded weight w and exponent beta≥0. The paper's scalar term is a product of r child contractions, where child g depends only on exponents incident with g. This follows directly from the packet-group construction: the target coefficient and source substitution depend only on the corresponding target and source modes. In particular, two parent tuples identical on g's incident exponents specify the same arrays for g, including creation precision and port order.

Build a balanced binary tree on the r=64 group symbols. Given fixed values of all ancestor-split modes with total spent weight z<p, a node U returns a histogram of degree less than p−z, indexed by exact additional integer weight, in R. At a leaf evaluate the actual child for that group using only its incident modes (extend other modes by zero if the existing ABI requires a global tuple) and store the answer at index zero. At an internal node enumerate only exponents on mode pairs separated by its two children. For each feasible assignment of extra weight b<p−z, recursively obtain both histograms at outer budget z+b. Convolve them over the ORIGINAL R, truncate to degree below p−z−b, shift by b and add. Each mode belongs to exactly one group-tree split. Induction shows this is exactly the sum over feasible tuples at every total weight; sum the entries of the root histogram for the requested scalar. Child evaluations continue returning their original canonical residues; there is no division, valuation rounding, witness identification or altered ring homomorphism.

Depth-first iteration uses O(r p) ring elements for histograms and temporary convolution plus polynomial index space, since siblings may be recomputed and only a single child recursion is active. Across native recursion depth O(loglog s) this is polynomial in input bit length. The O(p²) straightforward convolution uses polynomial bit time in s, e, ell and p per visited history. The real-bit evaluations have at most polynomially many node/field-point choices. The time for visiting all histories and invoking child contractions is bounded by a polynomial times the maximum number of feasible assignments on mode bundles cut along a single group-tree root-to-leaf path: extend any partial assignment by zeros down a fixed remaining path. Constants r and group-tree depth are fixed. All raw instance-dependent tensor entry costs stay as in the manuscript and can use the exact terminal CRT restart eceb4739.

In the manuscript's full padded balanced layout every ordered label-pair class receives H_pad physical slots. At fixed coordinate i the number of packets for any unequal unordered symbol pair is identical: there are 2 r^(2a−2) ordered full-label pairs with those symbols in either orientation, each represented in H_pad slots, and fitting L slots per packet. Every such packet contributes 2^(i+1) tiles each carrying one mode of every weight 1,...,p−1, even when some slots are dummy. Thus the total C modes per weight are divided equally among binom(r,2) unordered pairs. An implementation pruning empty tiles may use the full padded envelope for this bound; the description does not require actually emitting dummy modes. A balanced path uses (r/2)^2+(r/4)^2+...+1=(r²−1)/3 distinct pairs. At r=64 this is 1365/2016=65/96 of all pairs. The literal full-list bound is exp(2 sqrt(ζ(2)Cp)) from optimizing θp+ζ(2)C/θ; the hierarchical bound uses (65/96)C in that same expression. More precisely, the corresponding number of colored partitions below budget p gives an exact operation-count envelope with C replaced by 65C/96. This is a smaller coefficient in an explicit bound and genuine changed enumeration, not a time lower bound or improvement of the asymptotic order. For nonuniform supplied layouts, substitute maximum actual path inventory by weight. No stronger claim about the runtime ratio on arbitrary SAT inputs follows.

Within group partitions that enumerate every crossing label and recurse only on physical disjoint group parts, the group-tree pair bound is optimal for powers of two and uniform bundle counts. Following the larger child b of a binary split a≤b costs ab+(b²−1)/3≥((a+b)²−1)/3; equality holds for a=b. This combinatorial statement does not limit other scalar aggregations.

For fixed-width k-CNF on n raw variables and m clauses, read and normalize in polynomial time in the explicit input bits. Conditional on manuscript sparsification and sparse adapter, the outer caller visits 2^O_k(n/√log n) disjoint leaves, polynomially many polynomial-shortlist rounds/candidates per leaf with the checked replacement, and 2^O_k(n/√log n+√n log n) branches and degree arrays per candidate. The resulting Boolean tensor size is s=O_k(n loglog n), or O_(k,D)(n) when original m≤Dn and D is fixed. Local entry evaluation is exp(n^o(1))poly(input) for the sparse adapter, and exp(O(s^.001 log s))poly(description) for created packets. In a native depth-d call M≤O(s)8^(−d), p=p_parent+8ceil(3M/u)(L/2^i)+8M(a+1) is polynomial in s, and group count r remains 64. Write B_d=max over active node/evaluation of 2 sqrt(ζ(2)(65/96) C p).
