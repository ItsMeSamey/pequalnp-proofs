# What full packet scope width certifies on physical signed CNF

At an original fixed-density signed-CNF root, let h_v be one two-valued product-branch variable for each old gate (OR or COPY), and X_e the logical COPY2 bit subdividing each old edge. After summing the physical row bit, an old port of gate v in packet P has one affine row factor on {h_v}∪X(P), where X(P) lists all distinct real column bits in P. Consider the primal graph obtained by making these displayed row scopes cliques. These are declared dense row scopes, not necessarily essential variable sets after evaluating or multiplying factors. The theorem below also applies to bag trees covering these scopes as supersets. It makes no assertion about every possible decomposition of the contraction.

Each old incidence (v,e) puts h_v and X_e in one of those scopes independently of its physical slot and the permitted layout. Keeping only those edges gives the once-subdivided old gate graph as a subgraph. Contract its subdividing paths and contract the connected, mutually disjoint COPY gadgets for each used original variable; the clause vertices remain distinct. This gives the clause-variable incidence graph of the CNF actually compiled, ignoring parallel incidences. Disjoint unused variables can be added as isolated vertices and restore the appropriate free-bit multiplicity. Consequently its treewidth lower-bounds this full-packet primal width under every placement. Deletion restricts every bag; contracting an edge replaces names by one name in the union of their intersecting bag subtrees. Thus a supplied decomposition explicitly produces an equally narrow raw incidence decomposition.

On that raw decomposition ordinary SAT/counting already costs 2^O(w)poly(input) for width w. Put one bit in a bag per live variable and one flag per live clause. In a nice decomposition process each literal edge once at a bag containing both endpoints, ORing its signed truth into the clause flag. At joins identify variable bits and OR clause flags; multiply independent counts and add compatible choices. Sum over variable values on forgetting, and accept only true clause flags on forgetting a clause. Table entries count internal variable assignments conditional on the boundary; initialize flags false. Witness pointers also give an original witness. This comparison applies to the origin count, not acquiring an entire deformation or a high jet. Tautology removal, duplicate-literal normalization, empty-clause termination and external unused factors belong to the source compiler; separate sparsification branches and generated polynomial-query systems need separate comparisons. It is not valid to contract a single leaf graph and thereby bound the original unbranched incidence width.

There is also a placement-independent density bound. With B≤3M/L packets one has ≥L/3 real slots in some packet; a physical logical bit occupies only two slots globally. Hence X(P) for that packet has size ≥ceil(L/6), and the row-scope clique forces width at least ceil(L/6)−1. In a near-full template the corresponding average bound is M/(2B). This can diverge when the raw incidence graph is a forest. Even if free unary COPY1 rows are individually removed and the unit OR1 gate is evaluated as its read, m disjoint positive units give M=2m and at least L/6 active OR1 rows in some packet, hence at least ceil(L/12) distinct physical bits in a surviving row factor. For the true symbolic characteristic-zero polynomial the pooled coefficients of those bits are nonzero, since all real W_d share the same nonzero leading coefficient and pooled duplicate columns add. This is a lower bound for the row-scope presentation. The column-slot incidence graph of an implicit factor, rank or moment factorizations, arithmetic auxiliary variables, parity cancellations, modular reductions, special grid samples and direct algebraic simplifications can evade it. A star around an implicit factor can have low incidence treewidth without making its large table cheap.

One constructive certificate: supply a source-valid class/orientation slot template, a tree of bags on h_v and X_e (check vertex coverage and connected bag occurrences), and per-packet menus U_P of allowed bit names. An old incidence (v,e) may occupy a candidate physical slot s in P if its ordered label class matches, X_e∈U_P and some bag contains {h_v}∪U_P. Build a bipartite matching from all real incidences to these eligible slots. A saturating matching places both ends together, leaves the prescribed surplus dummy per class, and ensures every actual factor scope is bag-contained. This is polynomial constructive discovery on the supplied menus. If half placement or other preassigned side eligibility is required, include such individual restrictions in the matching; coupled requirements such as an unspecified orientation of each COPY pair require a separate selection/check. Conversely every layout whose actual primal graph the supplied bags decompose has such a successful certificate, namely U_P=X(P): each clique is in one bag by the Helly property for subtrees. For empty packets use empty menus. Exhausting unknown menus over all packets costs up to (Σ_{i≤w+1} binom(number of bits,i))^B on a supplied width-w tree, and unconstrained tree/template discovery is additional. No polynomial global optimum algorithm follows.
