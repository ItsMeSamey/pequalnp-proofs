# Exact circuit SAT with prefix compilation and implicit automata

Run `python successor.py input.json`. A netlist uses `{"n":2,"gates":[[2,4]],"output":8}` for the AND of two raw bits. In these affine masks bit zero is constant one, the next n bits address raw inputs, and subsequent bits address previous ANDs. A signed CNF uses `{"n":2,"clauses":[[1,-2],[2]]}`. The unchanged CNF adapter compiles on the original variables. The Python API is `successor.solve(n,gates,output,...)`.

The default `--schedule normalized raw` tries the reviewed squarefree degree-two prefix compilation followed by implicit automata. If that attempt declines, the raw presentation is tried unless identical. Reverse the order to avoid paying for prefix compilation when the raw presentation succeeds. An empty schedule invokes the normalized frozen portfolio directly. The prefix work proxy is m(n+m+1)², with a default cap of 2,000,000. The default automata cell budget of 250,000 applies per distinct attempted presentation, with product rank cap 24. The fixed raw variable order defaults to input order. Python callers may provide a permutation. Per-stage metrics report charged cells, product candidates, maximum widths, elapsed time, and reasons for abstaining as available. Cell counts do not cover all Python bit operations.

After automata abstentions the exact frozen portfolio runs. It can exhaust all original raw words on the normalized circuit. Normalization preserves the scalar pointwise. Every reported SAT word passes an additional original-circuit replay. UNSAT relies on an exact deciding backend. Default caps limit optional effort and do not guarantee uniform savings or limit total wall time. The output cost records all work stages and the measured time from validation to replay.

The 36-input, 31-AND test consists of two 16-entry bit multiplexers sharing four address bits, whose selected outputs are conjoined. Both orders returned raw witness 1048592. Each used 129195 charged cells, 151 operations and 4612 product candidates. The final implicit product reached rank 16 versus formal width 256. Normalization retained all 31 gates. Raw-first avoided the prefix pass on this family. See bench36.json for the complete measurements. The distributive cancellation fixture in check.py exercises the opposite case, where normalization makes an affine decision after a raw abstention.

Run `python check.py` and `sha256sum -c runtime.sha256`. All runtime dependencies are vendored from the frozen portfolio, the reviewed prefix compiler, and the implicit-wire solver. The original portfolio files remain independently usable.
