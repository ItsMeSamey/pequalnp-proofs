# Cographic ports in fixed-marker regular matroid algorithms

A disjoint cycle/cocycle witness consists of vectors in a binary kernel and row space, disjoint on real elements and satisfying t prescribed binary marker labels. A three-sum port is a virtual triangle. On a cographic piece this is a three-edge bond. The cycle and cocycle restrict to a graph-cut trace p modulo 111 and an even graph-edge trace q, with p·q=0.

The good decomposition in Fomin et al., Theorem 3 and Corollary 1, can be computed in polynomial time with graph representations. Its basic-piece tree can have large degrees and cographic interfaces need not be vertex stars. Its extended sums permit degenerate singleton interfaces. [Fomin et al., §4.1](https://arxiv.org/pdf/1710.02300#page=14)

Alternatively decompose along proper 1- and 2-sums into 3-connected summands, treating small cases directly. For every 3-connected regular summand other than R10, Aprile and Fiorini's Proposition 27 gives a decomposition tree in which every interface at a nonplanar cographic basic piece is a three-edge vertex star. Planar pieces can be represented graphically. Bérczi, Mátravölgyi and Schwarcz confirm polynomial construction after Theorem 2.5. Each earlier singleton attachment is a real element of its 3-connected summand and persists in one basic piece after refinement. Joining the refined trees on those slots again produces a tree. [Aprile–Fiorini, Appendix C](https://www.research.unipd.it/bitstream/11577/3421196/7/Submitted_RegularMatroids.pdf#page=17) · [Bérczi et al., §2](https://doi.org/10.1016/j.jctb.2025.10.009)

At a literal cographic star, K4 baseline substitution is a star-to-triangle operation in the primal graph. Distinct star centers cannot be adjacent because interface edge sets are disjoint. In contrast, for the non-star bond of the triangular prism, a triangle-to-star exchange in the planar dual produces M(K3,3), which is not cographic. [Two-port calculation](cographic-gluing.md) · [Counterexample and generalization](cographic-three-bonds.md)

A second algorithm uses arbitrary edge-disjoint three-edge bonds, including crossing bonds. A canonical K4 contribution is linear in p,q plus W times the parity of half the size of q. Unsigned Z/4 edge weights encode this correction on the graph even subgraph. The high bit is a degree-two Boolean function of the fundamental-cycle coefficients. For t target bits, a feasible cycle therefore has a replacement supported on at most 2t fundamental cycles; O(t) prescribed trace bits only change the bound by O(t). The bounded-topology graphic linkage algorithm accepts the additional finite-group path labels. Complementing the cut on any one virtual bond normalizes that trace without changing the other interfaces. [Proof](cographic-k4.md) · [Crossing-bond checks](check_crossing.py)

A parallel template substitutes retained parallel copies for each virtual edge, deleting the element if its class is empty. This is parallel extension on a graphic graph and series extension on a cographic graph. On a degenerate extended singleton join, a loop/coloop child forces its d/c coordinate zero respectively, and its real labels are independent of the remaining free bit. Contract/delete that zero-labeled virtual parent element accordingly. R10 with parallel extensions has rank at most five and handles arbitrary local tables by direct syndrome DP. [Low-rank parent proof](matroid-parent.md)

The complete regular algorithm additionally uses the graphic linkage theorem, small boundary representative, bounded-exception argument and polynomial table traceback. The local tests cover graph identities and do not implement the linkage or decomposition algorithms.
