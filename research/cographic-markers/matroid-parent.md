# Computing bounded-rank parents and finding rooted templates from tables

Let A be a full row rank r binary representation, c in its kernel and d in its row space. On real elements enforce c_e d_e=0. The virtual boundaries are disjoint blocks of size at most three, each supplied with its allowed (trace, child syndrome) table; each syndrome has t bits. For every h in F2^r set d=hA. Independently enumerate all c words on each block and all compatible child entries; ordinary elements are one-coordinate blocks without an additional child contribution. Handle a specified parent trace by treating it as an extra disjoint block. Record the pair consisting of the block's sum of selected representation columns and the block's syndrome (its own genuine labels plus the child contribution). Starting from zero, accumulate these pairs by XOR, retaining Boolean reachability and a predecessor per state. After all blocks keep states with first coordinate zero. This returns exactly the feasible t-bit syndromes, since the only remaining global equation is Ac=0. The cost is n times 2^(2r+O(t)), with polynomial overhead for processing the supplied representation. In particular parallel extensions of rank-five R10 have no dependence on parallel multiplicities except the linear input scan. A dual statement applies to bounded corank by exchanging the roles of c and d and translating the block constraints.

For a child with a specified triangle T in a parallel extension of a 3-connected binary matroid, retain all T elements when simplifying: their three nonzero columns are distinct. If at least four elements remain, T is contained in an M(K4) minor by [Ding and Wu, Lemma 3.1](https://www.math.lsu.edu/~ding/p9.pdf). For smaller simplifications do not assume the minor exists; use the bounded-rank algorithm to evaluate the table, and distinguish that fact from existence of a K4 template. A naked triangle with possibly parallel copies may fail to admit such a template, e.g. when no copies exist the cycle trace modulo 111 must vanish. In a proper coindependent three-sum the naked example cannot be a side.

For the minor claim's constructive use, write the minor as contraction of X and deletion of Y. Lift minor cycles linearly with c_Y=0, and minor cocycles linearly with d_X=0. Such sections exist by the definitions of deletion and contraction. Use the genuine triangle of the ambient matroid as the lift of the triangle cycle (extend it to a basis). Every pair disjoint on the minor spokes thus lifts to a pair disjoint everywhere outside T: on X and Y disjointness holds by the opposite zero restrictions. The real labels of lifted cycles are linear functions on the K4 cycle space vanishing on the pure triangle. Its quotient embeds via the three spoke bits (the kernel of that projection is the pure triangle), so these functions extend linearly to labels on the spokes. Cocycle spoke bits determine the cut completely because the spokes form a spanning tree. Hence the lifted labels can be represented by a choice of six t-bit spoke vectors even if no minor sequence is available.

Given the complete child table, enumerate the 2^(6t) possible spoke labelings, compute their tiny K4 table, and keep any labeling whose whole table is included in the child table. The existence proof above guarantees success under the rooted-minor hypothesis. Any included template has a real child witness for every template entry, available by table traceback. This avoids invoking an algorithm to find the specified rooted matroid minor.

If the nontrivial simplification consists exactly of the rank-two triangle, write S_i for its real elements parallel to T_i. At a leaf of this form replace the three virtual elements T_i of the parent by parallel classes S_i, possibly empty. This is an exact labeled reduction before template compression. Indeed child cyclicity says that the parity vector of the selected real bits on the three classes equals its boundary c word modulo 111. The child's real d bits are exactly q_i on S_i. Since T itself is a parent cycle, its representative can be toggled without changing any parent real bits, and the parent c word can be chosen equal to the actual three class parities. Conversely a row functional on the replaced parent extends to one on the original representation and supplies the missing q_i, including empty classes. These are the cycle and cocycle rules on the parallel-substituted parent. Each real copy retains both of its original labels and its own disjointness constraint. Graphic parents use parallel edges, cographic parents use series extensions in the dual graph, and bounded-rank parents retain bounded rank. Handle separate loops as independent one-element blocks. This argument applies to a rank-two leaf whose remaining coordinates are genuine copies; preexisting child-table blocks on these coordinates require separate accounting.

For a *proper* 3-sum of a 3-connected matroid, the small simplification case is excluded. Each side is 3-connected after removing redundant elements parallel to boundary elements (Seymour's 3-sum structure, (4.3), also stated by [Chun and Oxley, Theorem 2.1 and Lemma 2.2](https://www.math.lsu.edu/~oxley/ccjo.pdf) in its discussion of 3-connected simplifications). A side of size at least seven contains at least four elements outside T. If its simplification were the triangle, two real elements would be parallel, or there would be a real loop. Their one- or two-element cycle survives summation, contradicting simplicity. Hence each side's simplification contains at least four elements and supplies the rooted minor. This argument concerns a cut for which the reassembled full matroid is 3-connected.
