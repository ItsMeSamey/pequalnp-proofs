# Exact wide-clause sums with a bounded-width core

Let H be an unrestricted instance of fixed-width CNF. For each extra, possibly wide, non-tautological clause C_i, let p_i be the signed assignment that falsifies it. Given a total assignment a, the pointwise product of (1−1[a extends p_i]) is the indicator that every extra clause holds. Enumerating compatible sets of rows yields an inclusion–exclusion sum of counts of unary restrictions of H. Compatible families are cliques of the pairwise compatibility graph, since contradictions occur in pairs. With degeneracy d, clique enumeration takes poly(L) times 2^d, by charging each nonempty clique to its first vertex in a degeneracy ordering. Each resulting fixed-width call costs at most the original n-variable time.

## Merging and projection

Maintain a signed integer coefficient for each distinct union of compatible pins. Start with the empty union of weight 1. For each clause retain each state and subtract its weight at the consistent union with that clause, if any. Merge equal keys and remove coefficients of zero. With U distinct consistent unions over all row subsets, all intermediate tables have size at most U. The absolute coefficients need at most m+1 bits. Every minimal set of rows generating a given union has a private signed pin per row. These private pins give an induced matching of size equal to the number of generators in the bipartite graph of rows and signed literals. A maximum induced matching of size b bounds U by the sum of binomial(m,j) for j from 0 to b. No matching search is required by the counting algorithm.

For each variable used in an extra clause but absent from H, project it away after its last extra clause. Multiply each projected weight by 2 per forgotten free variable, and by 1 per forgotten pinned variable. Sum colliding weights. This is exact because no later constraint consults that variable. Track all pins on H variables until the end, then weight each by the count of H under the pins. Variables outside both systems contribute an ordinary power of two. The runtime for a specified order is polynomial in L times (the largest observed intermediate support plus the terminal support times fixed-width counting time), and the weights have O(m+n) bits. Distinct projected unions already give an upper bound on support; signed cancellations sometimes improve it. The unrestricted short core can be highly cyclic.

## Dense families and a limiting example

On a pool of s positive variables use every long clause containing all of the variables except a different pair. The rows are irredundant even as a single CNF: the assignment true only on the omitted pair falsifies just that row. Every pair of rows is compatible. There are 2^binomial(s,2) compatible subfamilies but only 2+s+binomial(s,2) pin unions for s≥4. The omitted sets in intersected complements are the full pool for the identity, a pair, a singleton, or empty. Add any bounded-width short core, including constraints sharing these variables with another s variables. The bound on states survives such additions; essentiality of individual rows may depend on the added constraints.

For any 3-CNF H on x_1,...,x_n (n≥3) add one bit s and q=ceil(log2 n) guard bits y_j fixed equal to s by binary clauses. Gate each original D as (¬s or D). Add one P_ij=(all positive y's or x_i or x_j) per pair i<j and one N_i=(s or all negative x's except at i) per original variable. When s=0 the pair rows demand at most one zero among x, and the N rows demand at least two. When s=1 exactly H remains. The extension is unique, so the number of models is exactly #H. All added wide rows are essential as formula constraints, whether H has models or not: at s=0, exactly two zero variables isolate their P row, while a single zero at i isolates N_i. The pair rows contain an induced matching of floor(n/2) through disjoint pairs and all are mutually compatible. Over the pair rows, the coefficient for pinning the shared guard and exactly a subset S of size at least two is (−1)^|S|(1−|S|). Indeed summing coefficients over every subset of T gives (1−1)^binomial(|T|,2), which vanishes exactly when |T|≥2; inversion yields the formula. This establishes exponential support for that program stage. It does not exclude changing row order, using semantic simplification, solving H directly, or another algorithm.

A separate no-autarky example has private bits x_i and cyclic guards y_j. Add wide (all positive y's or x_i) for each i and the one all-negative-x clause. Include the binary pairs (¬y_j or y_{j+1}), (¬y_j or ¬y_{j+1}) and x_i↔z_i for each i. Any autarky setting y_j true must satisfy conflicting implications on y_{j+1}. Setting any y_j false forces its predecessor false, then all guards false and all x true, contradicting the all-negative clause. Setting x_i false forces some y true, while setting x_i true forces some x false; touching z_i also forces x_i. Hence the only autarky is empty. All wide rows are essential as witnessed by a single x false, or all x true, and guards false. This gives a large private-pin induced matching without a matching autarky. It yields no lower bound on other preprocessing.
