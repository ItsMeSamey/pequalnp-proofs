# Constructive frontier normalization without a leastness assumption

**Dichotomy.** Given a finite simple graph with at least one edge and a binary, reads-back AND/OR circuit C with a valid designated output wire that computes its edge function on the full Boolean cube, the algorithm returns a circuit for exactly the same graph. Either it returns a strictly smaller circuit, or it returns a top-form circuit of the same size whose discrepancy is exactly D(C) + k(C). Neither outcome requires a proof of minimum size. The shorter branch can stop before top form.

Here D is the integer τ + |Ustar| − Q, where τ is minimum cover size and Q is the right-hand side of the 4186 inequality. A clean gate implies the graph function F. A frontier is a dirty OR with a clean input gate and a strict AND descendant. The count k uses gate identities. TopForm prohibits a clean AND from being a strict ancestor of an AND. The checker uses these predicates on the actual graph. [Score and frontier definitions](score.md) · [Implementation](cut199-control-pair/constructive_frontier.py)

## Algorithm and proof

1. Verify that C computes F, then remove gates outside its output cone. If any gate disappeared, return the shorter circuit. Otherwise, if C is already top form, return it. In top form there are no frontiers: tracing a clean operand backward through clean ORs must reach a clean AND, since F rejects every singleton input.
2. Among the clean gates with a strict AND descendant, check for a gate P with two distinct direct readers or a direct AND reader. If one exists, extract it as described below and return the shorter circuit. The test counts reader gates, so two pins of one gate count as one reader.
3. Otherwise every buried clean gate has a single OR reader. Starting at a buried clean AND and following these readers must reach a dirty OR before reaching an AND. Select the clean operand P of any such frontier r. Extract P. Stop if size falls; otherwise repeat from the top-form test.

**The extraction.** In the residual computation, set P to false at every use. An AND receiving false becomes false; an OR receiving false reduces to its other input. The Python sentinel `None` represents an absent constant-false signal internally. Keep the original P and its ancestor cone unchanged. Join P to the residual output with a binary OR, omitting that gate if the residual is false or already P. Trim again. On assignments with P false the residual equals the old output. On assignments with P true the restored output and F are both true. The implementation can append rewired residual gates temporarily: a changed downstream gate lies outside P's ancestor cone, and its old version has no residual use. At most one representative of each original gate survives trimming, plus the optional final OR.

**Why the early branches save a gate.** Every direct reader of P disappears from the residual and lies outside P's cone. Two distinct readers therefore pay for the final OR with at least one gate left over. If a unique AND reader is the output, its residual is false and no final OR is needed. Otherwise that AND's output is false in the residual, and at least one of its own readers also disappears. This reasoning applies whether P is an AND or an OR. If a buried clean gate instead has a unique OR reader with two copies of P, that reader remains clean; following the clean chain in step 3 is still valid.

**Why a size tie has an exact score.** In step 3 the dirty reader has the form r = P OR B with B dirty. For size to tie, only r can disappear and the terminal clean OR must be added. Every retained gate agrees with its old value where F is false, since P is false there. This preserves its clean/dirty classification. The raw inputs that reach P by an OR-only path form an empty set because a singleton input would otherwise make P true. Thus r and B have the same raw OR support. Bypassing r preserves all retained top-operand supports, |Ustar|, and the centreless count. It also preserves lam: the removed r has an empty-support operand, and any qualifying OR-only path through r has to enter via B. Such paths contract across the bypass, and all new paths expand to old ones. The only changed score term is the clean OR count, up by one.

Exactly the selected frontier disappears. Any other frontier remains dirty with its clean input. Its path to its first downstream AND has only dirty ORs as intermediate gates. If that path uses r, it must enter from dirty B, and hence survives the bypass. No new clean operand at a dirty reader or new AND ancestry can arise. This proves the local changes D ↦ D + 1 and k ↦ k − 1 on every tied step, without invoking leastness. The argument must check step 2 again after each extraction. Even if a non-top-form circuit ran out of frontiers in some intermediate state, step 2 would then produce a strict saving. Thus the loop either stops early or executes exactly the initial k tied steps and reaches TopForm. [Score definitions](score.md)
