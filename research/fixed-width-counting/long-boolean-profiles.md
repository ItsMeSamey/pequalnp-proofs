# Arbitrarily many long clauses with few neighborhood unions

For each choice (i,b) let N_i^b be the long clauses satisfied by that setting. Generate their union closure U including the empty union by insertion and deduplication of bitsets. Let K be the final size. For each X∈U allow only variable values with N_i^b⊆X. The bounded-width core counter with these unary domains returns B(X), counting exactly assignments whose hit set is contained in X. In increasing size order subtract exact counts of all proper subprofiles from B(X). The answer is the exact full-profile count, or zero when the full profile is absent. Time O(K² poly(input)+K T_core(n)), space O(K poly(input)) beyond the core solver. The empty long-clause family is handled directly.

Let h be the maximum induced matching in the bipartite graph between signed variable choices and long clauses. Every union has a minimal generating subfamily. Each indispensable column has a private row, so the selected columns with their private rows induce a matching. Thus K≤sum_{j≤h}binom(2n,j). In particular h=o(n) suffices for 2^{o(n)} time with any polynomial clause density and a subexponential core solver under unary pins. No estimate of h is needed. This is an application of standard Boolean-width neighborhood equivalence and its relation to induced matchings, not a new discovery of that graph relation. [Bui-Xuan, Telle and Vatshelle](https://www-npa.lip6.fr/~buixuan/files/BTV_boolw.pdf).

Fix d≥2. For an odd prime q, PG(2,q) has N=q²+q+1 points and N lines, q+1 points per line, a unique line on two different points and a unique intersection of distinct lines. Use two disjoint superblocks of d disjoint point sets each, n=2dN. In each superblock and for EVERY d-tuple of lines include a positive clause consisting in each copy of all points outside the chosen line. Hence 2N^d distinct equal-size clauses of width dq²≈n/2. Adding one common positive guard makes the long incidence graph connected if desired. Every clause has a private violating assignment: set variables of that clause false, all other data true and the guard false. Other equal-size distinct clauses contain a variable absent from the chosen one. Therefore the violation-indicator Gram rank without a core equals the clause count. An arbitrary additional fixed-width core may couple all variables.

Four matched point columns in a single copy would require for each point a line through all three others excluding it. The lines excluding points one and two would both contain points three and four and hence coincide, a contradiction. Thus h≤6d+1 (at most three per copy plus the optional guard), and only polynomially many calls are needed.

The binary signed incidence rank is Ω(n). In a chosen point copy vary its selected line and hold all other chosen lines fixed. Restricting the columns to that copy gives M=J−B for the plane's line-point incidence B. For odd q the N-by-N identity M Mᵀ=I holds over F₂: BBᵀ=qI+J, BJᵀ=JBᵀ=0 since every line has even size, and JJᵀ=J since N is odd. Thus this minor alone has rank N. This separates the parameter from low binary rank. Every data variable occurs positively here; including both all-positive and sign-reversed copies doubles the induced-match bound and permits both polarities throughout.

The fixed-interval criterion also fails with any linear outlier budget. Restrict any proposed signed-literal ordering to the N positive point literals in one copy. Let a_L count adjacent pairs of points both on L. Each consecutive pair has exactly one joining line, so sum_L a_L=N−1. The q+1 points on a line have q+1−a_L runs, and their complement has at least q−a_L. Thus for a p-interval bound with p<q, at most B=floor((N−1)/(q−p)) lines qualify in this copy. Removing other literals cannot increase the number of runs of a clause. Across both superblocks at least 2(N^d−B^d) clauses require exceptions. For fixed p the exceptions number Θ(n^d), while width remains only about n/2 and all clauses are irredundant.

A specialized four-call check is also possible on this family. Within a superblock every long clause holds iff some copy's true points are not contained in a line, equivalently that copy contains a noncollinear triple of true points. Failure of this test is a width-three CNF forbidding every such triple in every copy. Inclusion–exclusion on the two superblock failures gives four bounded-width core counts (the optional guard can first be pinned). The general union-closure algorithm does not rely on receiving the geometry.

The checker long_projective_check.py tested MMᵀ=I and the four-point obstruction on q=3,5, yielding respectively 28 and 64 distinct one-plane profiles. At q=3 each two-copy superblock has 26 variables, 169 clauses, width 18, binary rank 25 and 730 profiles. Two disjoint superblocks double the input counts and multiply profile counts. It also tested exact closure inversion on 3,826 small CNFs, with two independent cores. The general result is a hybrid with a fixed-width counting theorem and gives no unrestricted arbitrary-width polynomial-density algorithm.
