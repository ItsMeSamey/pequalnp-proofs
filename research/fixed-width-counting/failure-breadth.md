# Compatible private-variable witnesses and a pointwise compression barrier

For normalized exceptional CNF clauses let u_j be the signed partial assignment falsifying clause j. A private-variable witness is a mutually consistent family of generators in which each generator specifies a variable omitted by every other generator of the family. Write b for its maximum size, zero for no nonempty generators. Equivalently one can choose a private signed-variable incidence for each chosen clause to form an induced matching in the incidence graph, with the extra condition that all chosen rows are consistent on all their variables.

The number K of distinct consistent unions (empty union included) satisfies

    2^b ≤ K ≤ sum_{i=0}^b binom(m,i).

For the lower bound, arbitrarily including or omitting a member of a witness independently changes whether its private variable occurs in the union. For the upper bound choose an inclusion-minimal generating subfamily for each consistent union. Removing any member strictly changes the union, so some variable is private to that member. There are at most b members. Counting all such possible subfamilies bounds K. This is unchanged by signed literals because only mutually consistent generators enter. For fixed k, b≤k is recognized by checking every (k+1)-tuple for compatibility and private variables: every subfamily of a witness is itself a witness. Thus the dictionary algorithm in cofactor-unions.md, with any prescribed core counter, has polynomial overhead for fixed b. The parameter allows arbitrarily many simultaneous failures among wide clauses. Conversely large b forces the *closure* to be large, but other generators may cancel final coefficients; that distinction matters.

In fact some monotone CNFs defeat all sparse pointwise signed cube expansions. For m≥1 choose pairwise disjoint variables x_1,...,x_m, y_1,...,y_m and a guard G that is the disjunction of g=m more variables. Take all m clauses G OR x_i OR y_i. The CNF has 3m variables, m incomparable clauses of common width m+2, and a connected primal graph. Every subset of the m generators has a different consistent union, so K=2^m and every union has a nonzero signed coefficient (one generating subfamily). As no two clauses subsume one another and each can be violated alone, none can be dropped.

Now allow an arbitrary representation of its satisfaction indicator by a linear combination of subcube indicators, including new mixed-polarity cubes unrelated to the clauses. Set all guard bits to zero and index the resulting truth matrix by X=(x_i) as rows and Y=(y_i) as columns. It is the m-fold tensor power of the two-by-two OR matrix with rows (0,1),(1,1). The determinant of the latter is −1, so the full matrix has rank 2^m over any field. Each surviving subcube factors into a function of X times a function of Y, hence has rank one or zero. Rank subadditivity therefore demands at least 2^m summands, even if arbitrary separable products of X and Y functions are allowed in place of cube indicators. The original formula nevertheless has count (2^m−1)4^m+3^m: any nonzero guard word is unconstrained, and for zero guards each pair has three choices. The barrier is for a pointwise sum representation or a specified rectangle partition, not for scalar exact counting, alternative variable partitions, or more general arithmetic circuits.
