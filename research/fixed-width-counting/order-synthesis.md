# Synthesizing a selector occurrence order

For a simple nonempty graph G with no isolated variables, let a(G) be the minimum alternation-graph treewidth of an occurrence word of its monotone edge CNF, choosing both the edge order and each endpoint orientation. Then tw(G)-3 <= a(G) <= tw(G). For the upper bound attach one edge leaf to a containing bag of an optimal tree decomposition, refine the tree into a binary plane tree (duplicating bags as necessary), prune branches without edge leaves, and replace each edge leaf by its two adjacent occurrence leaves. The label Steiner trees expand only inside nodes carrying their label, by bag connectivity. Alternating labels have intersecting Steiner trees, proving the upper bound. For the lower bound take the optimal interval parse of any such word. Add each edge-clause to the Steiner subtree spanned by its adjacent terminals. At most three edge blocks span the three sector boundaries at any internal node, and incidence edges are covered at leaves. This decomposes the incidence graph with width <=a(G)+3. G is a minor of its subdivided incidence graph.

For q>=1 replace every vertex by a q-clique, joining adjacent cliques completely. The blowup has treewidth q(tw(G)+1)-1. Replicating original bags gives the upper bound. Conversely intersect bag subtrees of all clones of each original vertex, nonempty by clique Helly. Neighboring original vertices have meeting intersection subtrees since all 2q clones form a clique. These intersections give original bags of size at most floor((W+1)/q) from any width-W blowup decomposition. With q=4 the interval for a(G[K4]) is [4tw(G),4tw(G)+3]. Therefore deciding the best achievable width threshold is NP-complete even for monotone graph 2-CNF, with the threshold part of the input. NP membership follows from a guessed ordering and polynomial join-load interval optimization. Starting with cubic graph treewidth, which is NP-complete (https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.IPEC.2023.7), makes every resulting variable occur exactly 15 times. Any fixed two-sided additive error c is also hard in polynomial time on general inputs using q>2c+3 to make the possible width intervals for distinct treewidths disjoint after error. These are synthesis bounds, not counting lower bounds.

## Exact optimization with constrained changes of order

Give each occurrence its own identity in addition to its selector label. Suppose the permitted orders are represented by an acyclic prefix automaton: every state s determines its exact consumed set U_s, each arc adds its labeled single occurrence, and the paths from designated start to finish are precisely the permitted permutations. For an occurrence subset S define B(S) to be the selector labels occurring both inside S and outside it in the full input. For each reachable pair s,t define DP(s,t) as the minimum join load of a binary parse of a path between them. The represented interval contains exactly U_t minus U_s regardless of path. Single-occurrence arcs cost 1. For longer segments try every strict intermediate state u on an s-to-t path; take the maximum of DP(s,u), DP(u,t), and |B(U_u minus U_s) union B(U_t minus U_u)|, then minimize. Child paths concatenate consistently because they share the same full automaton state. Conversely any permitted path and root parse split yields such an intermediate state. Recover both path and parse in polynomial work per triple of states. Subtract one from the load for graph treewidth.

For a fixed sequence of contiguous clause blocks of maximum arity r, allow every within-block literal permutation: prefix states store the preceding complete blocks and a subset of the current block. This has O(m2^r) states for m blocks, yielding 2^{O(r)}poly(input) exact joint optimization. For a precedence poset of blocks with J order ideals, store a completed ideal and at most one partially consumed eligible next block and its subset. There are at most J(1+m2^r) states; completed empty blocks may be processed separately. Fixed block windows of g freely permutable clauses give J=O((m+1)2^g), so this yields FPT in r+g. With unrestricted blocks J=2^m yields an exact exponential decision algorithm, without iterating m! orders.

For genuinely noncommutative word products, an arbitrary clause reordering argument does not apply. Build instead the site dependence poset: retain original order for every pair of site matrices (or group elements) failing to commute at some jointly feasible choice of their shared selector bits, and take transitive closure. All linear extensions give the same product for every selector assignment, since any two linear extensions are related by adjacent swaps of incomparable sites and these matrices commute pointwise. The ideal-prefix optimizer searches permitted commutations without modifying the product. This provides a sufficient reordering rule and need not include every accidental algebraic identity.

At threshold zero, a simple nonempty edge graph admits a nonalternating order exactly when it is a cactus forest. In a nonalternating word draw disjoint variable stars in the disk spanning equally labeled sites, and join each adjacent edge-pair on the exterior boundary. Thus every edge in the resulting embedding is exposed to the outer face. A theta subdivision prevents this because no face borders all three internally disjoint paths. Conversely use a rooted block-cut forest of a cactus. A cycle starting at x has word x a | a b | ... | z x; a bridge uses x y. Glue each child block word before an edge beginning with its attaching x (or use the reversed placement after an edge ending in x). Old labels other than x lie outside the inserted interval and new labels other than x inside. The old x occurrences are adjacent to the attaching boundary x in the projection onto old letters; neither old pairs nor pairs involving a new label acquire an alternation. Concatenate components. The independent checker tested 708 small graphs.

Small adaptive preprocessing can choose a variable, compute both ordinary CNF restrictions, and choose a different optimal permitted order in each branch. Counts add. Searching all depth-t choices takes n^{O(t)} branch trials for fixed t, and each plan is checkable; the variable ordering for each branch may differ. For group words keep sites of pinned selectors as constants and preserve their positions unless algebraically absorbing them by conjugation. The separate finite-group-selectors.md gives a stronger 2^k algorithm when k exceptional selector labels cover all toggles outside a fixed normal tractable subgroup.
