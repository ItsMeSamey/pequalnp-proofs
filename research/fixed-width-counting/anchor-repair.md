# Certified repair after partial anchor selection

For prescribed blocks, form the failed row pairs from relational-fixed-anchors.md. A pair fails if replacing some block of one row by that block from the other makes an absent tuple. Select anchor columns greedily to distinguish these pairs. If a size-t anchor separates all P pairs, greedy leaves at most h>=1 pairs after ceil(t ln(P/h)) choices when 1<=h<=P. Each choice covers at least a 1/t fraction of the residual. Remaining failed pairs are exactly those inside a common anchor slice, because one-block replacements between rows agreeing on all anchor columns still agree there.

In each nonempty slice call a value v of block j universal if replacing block j of ANY row by v yields a row in the slice. Rows whose every block value is universal form exactly the product of these sets of universal values. Indeed all tuples in the product are obtainable by successive replacements starting with any row. The converse is by definition; empty universal sets produce the empty core. Every row outside the core contains a nonuniversal value. Its replacement into a witness row is absent; the pair therefore fails. At most 2h rows in total lie outside all product cores. Enumeration, classification and validation use polynomial explicit input time. Reattach the fixed anchor head for each slice. If projected core factors are short after extracting common single-row factors, the signed product compiler of relational-width-counts.md uses O(g[1+log(m/g)]) variables for its g nonempty cores and one signed switch for each wide exception. This avoids exponential completion of nearly Cartesian relations.

## Recognizing a case with unknown product blocks

On ternary rows join pairs at Hamming distance <=2k. Each legal anchor slice, with fixed-width k nonconstant prime projections, lies in one connected component. Change one independent factor at a time: a differing pair of local clauses occupies at most 2k coordinates in union, and hence admits an edge. One-row factors do not change. If each global component itself passes the prime-width check, any anchor separating across-component pairs is conversely legal: its slice is a coordinate restriction of a single independent product, preserving the width bound. Thus in this recognizable subcase a greedy cover of across-component pairs gives at most (1+ln P)OPT columns for P>0 pairs; if P=0 use the empty anchor. Bounded maximum disagreement Delta also gives a Delta^t branching search. This compares to the true optimum with freely changing factors in the slice, not to a supplied partition. If the component test fails, the across-component distinctions are still necessary.
