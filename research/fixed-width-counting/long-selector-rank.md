# Compressing signed long-clause selectors relative to a short core

For F=B∧C₁∧…∧C_m with bounded-width B, put f_i(x)=1 when C_i is false, as a function on the finite set of B-models. Form the rational Gram matrix G_ij=sum_{x:B(x)} f_i(x)f_j(x). Each entry is the exact count of B on the pinning cube simultaneously falsifying the two clauses, or zero if they conflict. Choose a maximal independent set I of columns of G. Gram positivity implies the corresponding f_i span all violation functions over the rationals. Thus on any B-model, vanishing of every selected f_i implies vanishing of all. B together with the r=rank G selected ORIGINAL long clauses preserves exactly the original models. No coefficient certificate or B-model listing is needed. Entries have ≤n+1 bits; exact rank finding and all pin bookkeeping take polynomial bit cost besides the O(m²) core counts.

Use any exact solver on the reduced formula. In particular the existing signed-selector reduction compiles the r exceptional long clauses, along with the core, into a constant number of ordinary bounded-width counts on n+O(r) variables, independent of their total literal length (construct signed selectors only for long clauses, and encode the global selection parity via a linear XOR chain). Consequently under the fixed-width theorem the overall time is poly(input) times T_w(n)+T_max(3,w)(n+O(r)), and space remains polynomial. The headline exponent gives a sublinear-in-n exponent for r=o(n√log n / loglog n), allowing r to exceed n. If each long clause is uniquely violated on some B-model then the resulting identity minor forces r=m. The converse is not needed. This semantic selector compression and the signed-incidence pivot algorithm need not succeed on the same families. The contribution is a selection test before applying the known reduction, not a new selector gadget.

The same Gram oracle learns degree-d union certificates relative to B. For nonempty T of size ≤d use features f_T=product_{i∈T}f_i. Weight residual squares by sum_i f_i; all required entries are pinning-cube counts of B with at most 2d+1 long clauses falsified, so the zero residual is recognizable in m^{O(d)}poly(input) core calls. A successful test gives #F by subtracting the fitted union sum from #B. This applies with d=o(n/log m) and a fixed-width core even when r itself is large. It does not cover all formulas even for unit clauses on distinct variables.

Sources: [Wu and Wang, section 4](https://arxiv.org/html/2611.02560v1#S4), [OpenAI fixed-width counting theorem](https://github.com/openai/math/tree/main/preprints/The-Exponential-Time-Hypothesis-is-False-October-25-2026).
