# Wide-clause cofactors indexed by consistent unions

Let B be a core CNF, and C_1,...,C_m the remaining clauses. Discard tautologies. Let u_j be the partial Boolean assignment that violates C_j. Write [u] for the indicator of the subcube extending u. Then [u][v]=[u union v] for compatible partial assignments, and zero otherwise. Let K include the empty partial assignment and all distinct consistent unions of subfamilies of the u_j. For clarity K below denotes the cardinality of this set.

Starting with coefficient 1 on the empty assignment, multiply successively by 1−[u_j]. At each step copy the current dictionary and subtract each old coefficient at the key given by the union with u_j when consistent. Delete keys whose coefficient vanishes. This represents the satisfaction indicator of all processed clauses pointwise, by induction. No dictionary has more than K keys. A coefficient is a signed sum of at most 2^m terms and thus needs O(m+1) bits. A deterministic search tree for partial assignments gives polynomial input overhead per key per step and O(poly(input) K) space; a budget on table size can be checked online. Zero coefficients can only reduce the work.

Let a_u be the final coefficients. Return sum_u a_u #SAT(B restricted by u), counting variables in the declared universe outside dom(u), including free variables. A complete assignment is counted with total weight exactly the indicator that every exceptional clause holds, times the core indicator. The running time is O(poly(input) K) plus the sum of core counting times at n−|dom(u)| for nonzero keys. No new Boolean variables or width increase in the core are required. Empty exceptional clauses and contradictory or vacuous cores obey the same indicator identity. In particular if the core is empty, each cofactor contributes 2^(n−|dom(u)|) and the entire count is polynomial whenever K is. A bounded-width core may instead use its chosen bounded-width exact solver. A sum with exponentially many K entries does not carry a polynomial-space guarantee by this implementation.

For a family with many wide clauses, choose t distinct selector strings on ceil(log2 t) bits and, for every selector i, a partial assignment A_i on payload variables. For fixed d produce all clauses whose violating partial assignments are selector i together with A_i restricted to its domain minus a d-element set. Unions between different tags are inconsistent. Within a tag a nonempty compatible union omits only the intersection of the chosen omission sets. Consequently K ≤ 1+sum_i sum_{j=0}^d binom(|dom(A_i)|,j). The clauses are incomparable within each tag by equal size, and different tags conflict. Each can be violated alone (flip exactly its omitted coordinates in A_i), establishing semantic irredundancy for the exceptional family. Yet extending all of A_i violates binom(|dom(A_i)|,d) clauses at once. Taking domain sizes Theta(n) and arbitrary polynomial t gives polynomially many, arbitrarily dense, linear-width clauses. Both construction and state bound permit arbitrary signs on A_i.

For a simultaneous separation from fixed run counts in any single signed-literal order, take k=floor(log2 N), t=2^k, a common padding block of N positive literals, and k further distinguished positive payload literals. Index the t tags by all subsets S of those k distinguished literals; A_i forces false every padding literal and precisely the distinguished literals of S. Keep the above omission family, with N≥d, so one clause for each tag omits d padding literals and retains every member of S. In any total signed-literal order, restrict to the k distinguished positives. Intersecting a union of p intervals with an ordered subsequence gives at most p runs. The traces on this subsequence realize every S, including the alternating pattern with ceil(k/2) runs. Indeed at most 2(k+1)^{2p} patterns have ≤p runs for fixed p. Every remaining tag contains a clause failing that run bound independently of how the signed order was chosen. Padding makes all clauses linear width, and K is still polynomial. This separates the stated certificates on the explicit input representation; it does not exclude alternative preprocessing or prove an algorithmic lower bound.
