# Missing clauses in signed permutation orbits

Use the signed component descriptions in signed-exchangeability.md, with a given and verified completion by whole clause orbits. An external core K can be arbitrary. For assignment cell c (one gauged weight h on each balanced block and a gauged parity on each unbalanced block), define M_o(c) as follows. On a balanced block of size s with p positive and q negative occurrences of orbit o use binom(s−h,p)binom(h,q). The positive literal positions must be chosen from zeros and the negative positions from ones. On an unbalanced component of size s, a partial scope of size r<s contributes binom(s,r), since for each support precisely one sign pattern is false. On a full scope use the parity indicator of the unique false word. Multiply these factors across blocks. This is the number of DISTINCT clauses of the orbit false on every assignment in the cell.

Let D_o be the clauses removed from orbit o and d_o=|D_o|. For x in cell c, let H_o(x) count the missing clauses it falsifies. Then H_o≤M_o, and binom(H_o,M_o) is exactly the satisfaction indicator of the retained orbit. Multiplying and expanding the binomials gives the count in cell c as a sum over subsets S of the union of the holes, with |S intersect D_o|=M_o(c) in every orbit, of the count of K in c with all clauses of S falsified. Every rescued assignment is counted once, when precisely its actual violations are those in S. Inconsistent joint falsifications have count zero; any c with M_o>d_o is dropped. Orbits with no holes act as their exact original constraints. One may process the holes as mutually compatible cliques to suppress inconsistent subsets before the core call.

With empty core each term is computable directly. If b coordinates of a balanced component are fixed, of which a are gauged ones, use binom(s−b,h−a). If f≥1 coordinates of an unbalanced component are free, use 2^{f−1}; otherwise check the fixed parity. Multiply these contributions. With an arbitrary core, each term is a single restriction with additional exact-weight and parity predicates.

The number of terms for a feasible cell is bounded by product_o binom(d_o,M_o(c)), and ≤2^{sum_o d_o} unconditionally. For full-support orbits only M_o of zero or one occurs, so each incomplete orbit contributes at most d_o choices, which can be pruned by conflicting full pins. If all other component factors are nontrivial this last simplification requires M_o itself to be at most one, as when orbit clauses have full support in every involved component. If d is constant (or O(log n)), polynomially many total cells (or a polynomial-time enumeration of feasible cells) and a polynomial restricted-core solver suffice for a polynomial overall algorithm.

An independently supplied partition/gauge can be validated by classifying all observed clauses into their orbit profiles and enumerating the missing clauses when the nominal number is polynomial. For observed families of m explicit clauses and at most d holes this holds automatically in represented profiles (nominal total ≤m+d). Unrepresented profiles require a supplied template if regarded as completely omitted. The raw swap detector on the incomplete input can miss true completion symmetries; restoration or discovery of an unknown group is a separate task.

For unknown completions a bounded search suffices at fixed d. From a current family branch on adding one previously absent image of a currently present clause under any candidate signed transposition (both signs on any distinct variable pair). At depth at most d this has O((1+2n²(m+d))^d) nodes. A promised completion by a transposition-generated group has a branch reconstructing every represented orbit: its graph of clauses linked by applying one true generator is connected, so every nonempty proper subset has an edge to an absent member. Completely omitted orbits have no constraints and can be ignored. Once all partially represented orbits are restored, test exact signed transpositions of the candidate family and run the formula above with inserted clauses designated as holes. Every candidate, including a guessed insertion unrelated to the intended symmetry, still yields the exact original count when its own restored clauses are treated as holes. Polynomial total cell counts or core subproblem budgets can be enforced by aborting candidates exceeding the given resource bound. Recomputing a larger symmetry group on the completed family can only coarsen its assignment orbits.
