# Eliminating hidden variables by their failure profiles

Split each clause as A(V) OR D(H) and write u for the partial assignment required to falsify D. For one hidden block take all distinct consistent unions of these partial assignments, including the empty union, as a dictionary L of K keys. It is computed output-sensitively by iterative consistent union and deduplication. Each complete hidden assignment y has exactly one maximal key U(y): the union of all original tails it falsifies. A tail u is false under y exactly when u is a subset of U(y). For every key T the number of y extending T is 2^{h-|T|}, also equal to the sum of weights w_U over U containing T. Compute weights in descending containment order, using integers of polynomial bit length. Subtracts are of genuine extension counts, so results are nonnegative. Then sum over keys U its weight times the ordinary count on V of the conjunction of all A whose u is contained in U. Empty tails impose their visible clauses on every key. This uses K counts on |V| variables, preserving bounded residual widths, with polynomial overhead in input and K. A chain of distinct nested tails of arbitrary linear maximum width has only h+1 keys and may touch arbitrary crossing visible clauses.

For independent hidden blocks (no clause touches more than one), each key has a hidden multiplicity and requires its corresponding visible conjunction. For each small prime p choose a binary key per block, rejecting invalid codes, and an index z_i< w_key mod p; it has exactly the residue number of extensions. The product of extension counts agrees modulo p with the desired weight for any visible assignment, so one ordinary count per prime suffices. Use polynomially many polynomial-size primes whose product exceeds 2^n and recover the exact count by CRT. This gives |V|+O(sum log(K_i+1)+g log(n+2)) variables if arbitrary clause widths are allowed: use direct forbidden codeword clauses. For width bounded by max(3,k+1) when each visible residual has width <=k, a one-hot key decoder uses O(K_i) bounded-fanin gates; each key conditionally enforces its short visible clauses and sets each of the O(log n) residue bits by binary implications. One comparator per block handles its index. Total variables are |V|+O(sum K_i+g log(n+2)). Walls remain when dictionary sizes grow exponentially. Independent verification is in check_hidden_closure.py.
