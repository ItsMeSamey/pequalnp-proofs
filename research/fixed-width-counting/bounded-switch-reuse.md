# Bounded-occurrence static rank versus ordinary residual isomorphism

Use a fixed-degree d-regular bipartite edge-expander on n data vertices, together with a decomposition into d perfect matchings. Map the q=ceil(log₂ d) code bits onto the d matching labels surjectively; repeated labels do no harm. Give each data vertex v three variables y_v,a_v,b_v. Its active port is a_v when y_v=0, b_v when y_v=1. For each code word s and edge uv of its matching, create private occurrences of each code bit, and for each α,β∈{0,1} add

    [code differs from s] OR [y_u≠α] OR [y_v≠β] OR port(u,α) OR port(v,β).

Here every bracketed bit inequality is a literal, the code guard is their disjunction, and the four clauses reuse that edge's private code copies. For each code index connect all its copies by an equality path, using both binary implications per path edge. One copy per index can serve as the root. The original formula itself has O(n) variables and clauses, width at most q+4 and occurrence O(2^q+q), since d is fixed. For each code choice all its auxiliary copies are uniquely fixed and propagate by units. No counts for unassigned equality copies remain.

For a partial assignment to any prefix of local switches, the y_v=0 and y_v=1 residuals are isomorphic by the ordinary variable permutation swapping a_v with b_v. At that point the two port names carry no other asymmetry. The rejected mode clauses disappear and the retained ones use the selected port. The argument can be repeated at every variable and does not require sign reversal. Counts include all declared free variables, so multiply by two per merged choice of y_v and by another two per unused data port at the end. The residual decomposes into n/2 copies of one positive binary edge, with three assignments per copy. The resulting count is 2^{q+2n}3^{n/2}. After the code has been fixed, reading every y before the ports creates exactly 2^n distinct named residual formulas at that level, because the active port names can be read from the residual matching. They form just one ordinary-isomorphism class, including the free ports. To implement merging it suffices to test the displayed two-name substitution on the two children using hash tables; a general graph canonizer is unnecessary. This yields polynomial time even when checking all such local identifications explicitly.

Every cut with balanced designated a_v terminals still has a matching with Ω(n) crossing edges by expansion and pigeonhole. Pin the code copies to select it, all y to zero, all b to one, and every a outside those crossing pairs to one. The cut flattening contains the tensor power of the invertible OR matrix and has rank 2^{Ω(n)} over every field. Extra coordinates may be placed arbitrarily across the cut. Every prescribed variable order or binary variable tree has such a balanced data cut. This augments the earlier switched matching construction with bounded occurrence and ordinary residual reuse. It separates specifically labeled selector-first frontier size from isomorphism-aware scalar evaluation; other variable orders or direct formula reasoning can also be fast.
