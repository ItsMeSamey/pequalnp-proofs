# Recursive first-violation counting with residual-width pruning

Fix k. In each recursive problem split residual clauses into a k-bounded core B and the remaining long clauses, inheriting their original order. Count B. Subtract for each current long clause j the count satisfying B and every earlier current long clause with j falsified. Recurse on these subproblems after adding j's forced variable values. The subtracted classes partition precisely the B-models that violate some current long clause. Clauses already transferred into B persist there under restriction, so a root-to-node chain has strictly decreasing original indices. Branches only select clauses with residual width >k.

Put the original long clauses in order of nondecreasing normalized width. Form the graph H with a pair adjacent if its two false assignments are compatible and min(|vars(i) minus vars(j)|,|vars(j) minus vars(i)|)>k. Every selected chain is a clique of H. Indeed for i<j in a chain the smaller clause i is still longer than k after pinning j (and possibly further clauses). It has at most |vars(i) minus vars(j)| remaining variables, and this is the smaller of the two one-sided differences. The ordering minimizes the pairwise necessary graph simultaneously at every pair, since other choices can only replace the smaller difference by the larger one. Each chain is uniquely identified by its clique because the order is fixed. Consequently the runtime is O*((number of cliques of H) times max_{r≤n} T_k(r)), including the empty clique. More precisely sum the core count costs on actual feasible chains. DFS uses only polynomial additional space. Note that H is merely a sound pruning graph; the algorithm does not need its clique number to operate.

At m=n^c, clique number h=o(n/log n) suffices for subexponential overhead even at linear degeneracy, regardless of original width profile. Example: take b=√n disjoint blocks of r=√n variables. Within each block include long positive clauses consisting of the same r/2 guards plus any k payload variables out of r/2 (k fixed, k≥2). The total density is Θ(n^{(k+1)/2}). Every pair is jointly falsifiable. Within a block every difference is at most k, across blocks every difference exceeds k. Thus H is complete b-partite with polynomial part sizes and has 2^{O(√n log n)} cliques, but linear-or-higher degeneracy. Raw compatible intersections include 2^{Ω(n)} distinct forced unions, by freely choosing unions of disjoint payload k-subsets within blocks. A connected short core can couple all blocks without affecting H, and arbitrary deletions of clauses per block preserve the upper bound. Within one block any number of compatible clauses fixes at most √n variables, so the simple large-union cutoff can fail. Different blocks may use different guard lengths with the same graph guarantee.

In fully unstructured instances the complete multipartite forbidden-word example from long-cycle.md retains every cross-block edge of H and has 2^{n−Θ(n/log n)} cliques. Thus the bound does not give an unrestricted subexponential algorithm for polynomial density. No novelty claim relative to the branching literature is made.
