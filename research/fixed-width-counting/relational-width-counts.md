# Disjoint Cartesian clause factors

Treat the normalized signed clause list as a nonempty finite ternary relation R, one column per variable. Prime factorization of explicit relations is known (Olteanu, Koch and Antova, https://doi.org/10.1016/j.tcs.2008.05.004). One elementary algorithm fixes a pivot column at an occurring value, projects it away, and recursively factors that single slice. Every original prime disjoint from the pivot survives unchanged as a slice prime. Test each slice prime B for global separation using |R|=|proj_B R| |proj_complement R|. Every passing B is a global prime, since a stricter global splitting would persist in the slice. Everything else, including the pivot, forms the remaining global prime. Uniqueness follows because any two product partitions have a common product refinement: project the second partition onto the blocks of the first and substitute. There are only n recursive calls, with polynomial projection work per call.

In the prime partition the wide CNF equals the OR of its projected CNFs: a clause is falsified exactly when one can choose one false local clause in every factor, because all combinations are rows. All one-row factors combine into one broad common clause D. Remaining projection CNFs Q_i number b<=log_2 m because each contains at least two distinct rows. For arbitrary fixed-width crossing core H, the exact count is #H minus the alternating sum over J subset [b] of (-1)^|J| #(H AND not D AND all Q_j for j in J). Here not D consists only of pins. Thus if all nonconstant prime projections have bounded clause width, this needs at most m+1 bounded-width counts on the original variables. Existence of a factorization with that local width is fully recognized by checking the prime partition: refinement only decreases projected widths. An empty wide family is vacuous. This is an application of existing relation factorization, not a new prime-factorization algorithm.

For a candidate anchor A of t variables split R by its ternary tuple on A, remove those coordinates, and factor each represented slice independently. Each slice l gives a head D_l (its common anchor literals and all surviving one-row factors) and nontrivial projected CNFs Q_li of bounded width k. For its satisfaction indicator introduce a negative-weight switch u_l, with binary clauses requiring that when selected it falsifies every head literal. Each nontrivial factor gets a negative switch v_li requiring u_l and, when selected, every clause of Q_li (width at most k+1). At fixed x the neutral choice u_l=0 contributes one. The remaining contribution is minus the head-failure indicator times product_i (1-[Q_li]); hence the signed sum is precisely the slice's satisfaction indicator. The products across all slices are implemented with independent switches, and one parity chain gives the difference of two width-max(3,k+1) counts. The original core keeps its bounded width. If there are g represented slices and their cardinalities m_l sum to m, there are O(g+sum log m_l)=O(g(1+log(m/g))) fresh variables including parity gates. Enumerating all at most n^t anchors (up to fixed polynomial factors, or binomial sums if t is variable) and testing the prime projections recognizes this representation. For m polynomial, t<=log_3(n/log n), all g<=3^t fit O(n) variables in total, with quasipolynomial deterministic discovery time. A single found anchor suffices.

## Why minimum-anchor discovery differs from prime factoring

For every fixed k>=1, deciding whether there is an anchor of size <=t whose slices have nonconstant prime projection width <=k is NP-complete when t is input. Reduce from Test Cover (rows are items, columns are binary tests; seek t columns distinguishing all rows; see https://arxiv.org/abs/1212.0117). Encode each 0/1 by a negative/positive literal and replace each column by k+1 duplicate columns on distinct variables. A distinguishing set yields singleton slices and hence no nonconstant primes. Conversely, if a slice contains two distinct rows, some original column varies. No clone of that column could be anchored. Its k+1 fully occupied clones are perfectly correlated and must belong to the same nonconstant Cartesian prime: separate factors allow combinations of distinct observed values on the two coordinates. Every clause projected onto this prime has width >=k+1. Thus an acceptable anchor must distinguish the input rows, and dropping duplicate clone selections gives a test cover of no larger size. Verification is polynomial by prime factorization. This concerns recognizing the particular representation. All these full-width CNFs have the elementary count 2^n-m.

If a Test Cover input has duplicate item signatures, it is immediately a NO case and is mapped separately to a fixed NO instance, avoiding duplicate-row normalization in the reduction. For example use two opposite rows on k+1 perfectly correlated columns and anchor budget zero.
