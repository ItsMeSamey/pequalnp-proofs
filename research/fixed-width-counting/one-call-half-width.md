# Uniform half-width encoding with pairwise guard intersections

Normalize clauses to distinct nonopposite literals. For every clause i of size w_i choose a subset B_i of [n] of size w_i. Append the positive guards outside B_i to clause i. This produces width n on 2n variables. Let H be the family of nonempty guard supports contained in some intersection B_i ∩ B_j with i<j. Add one guard-only full-width clause excluding each member of H. For a guard assignment outside H and different from zero, at most one original clause can fail. Write h_i=|{A in H : A subset B_i}|. Then the total count is
#G + (2^n-1-|H|)2^n - sum_i (2^{w_i}-1-h_i)2^{n-w_i}.
The zero guard word reproduces G. All other slices follow by unique possible failure, proving the formula for arbitrary literal polarities.

If w=max w_i, there is a deterministic polynomial-time construction with intersection size O(w²/n+log(m+2)). For a new uniform w_i-sample B, each prior set D has E[2^{|B intersection D|}] = sum_{T subset D} Pr[T subset B] <= (1+w_i/n)^{|D|} <= exp(w²/n). Successively decide membership of each point, preserving an upper bound on the conditional expected sum over previous D by taking a feasible smaller-expectation outcome. Each conditional expectation is obtained exactly from hypergeometric coefficients with polynomial bit lengths. The resulting sum is at most m exp(w²/n), implying the bound on every intersection. First set can be chosen arbitrarily. Enumerating H then costs poly(input) 2^{O(w²/n)} including integer arithmetic and output. For w=O(sqrt(n log n)) this is a single polynomial-size half-width oracle query. For w=o(n) the overhead is subexponential. The old two-query reduction works for all widths. This change only reduces oracle calls.
