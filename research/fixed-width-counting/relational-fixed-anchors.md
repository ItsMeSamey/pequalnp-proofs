# Minimum anchors for a prescribed Cartesian partition

Let R be an explicitly listed relation over fixed finite alphabets, including the ternary signed-clause alphabet, and let B₁,…,B_q be a supplied partition of its columns. An anchor A is good when every represented fiber at a value of A is a Cartesian product across the residual blocks B_i minus A. Enumerate pairs x,y in R. If replacing x on any block B_i by y on that block gives a tuple outside R, add the difference set {j:x_j≠y_j} to a hypergraph. The minimum anchor is exactly the minimum hitting set of this explicitly constructed hypergraph.

Indeed an unhit edge is certified by rows agreeing on A, with a missing mix in that fiber. Conversely a fiber closed under all one-block swaps equals the product of its projections: start with one row and install desired blocks one at a time from rows realizing those individual projections. Since all donor rows agree on the anchor, the full and residual block swaps coincide within that fiber. No test depends on the eventual anchor itself. Duplicate difference sets from the same pair matter only once, so the number v of hyperedges is at most binom(|R|,2). Row hashes give polynomial preprocessing. Greedy set cover approximates within H_v≤1+ln v for v≥1; with no edges the empty anchor is optimal. If each inclusion-minimal difference edge has size ≤D, branch on an unhit minimal edge to obtain O*(D^t) time for budget t.

Conversely take any Hitting Set instance with universe U and nonempty, nonempty edges E. Introduce W with |U|+1 fresh coordinates and the two-block binary relation

    R = {(0_U,0_W)} union ({1_e:e in E} × {1_{w}:w in W}).

Within the second rectangle all swaps succeed. The baseline and a row from the rectangle fail both swaps because e is nonempty and every marker is nonzero. The difference edges are exactly e union {w}. An anchor must hit every e using U or contain all W. Conversely either condition suffices. Mapping all of W to the entire original universe gives a hitting set no larger than the anchor, while an original hitting set is directly a valid anchor. Thus OPT is preserved and this is an approximation-preserving reduction. It also preserves parameter t and gives W[2]-hardness using the standard parameterized Hitting Set classification. The hypergraph construction in the other direction gives W[2] membership. An instance with an empty edge or no edges may be dispatched directly. Encoding the two symbol values by, for example, plus and minus signs yields actual normalized clause rows with exactly the same product tests.

The supplied partition is essential: the test asks that each prescribed block separate after conditioning. Allowing arbitrary slice-specific prime decompositions under a projection-width cap is a different recognition problem.
