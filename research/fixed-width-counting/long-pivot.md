# Signed-incidence pivot cover for arbitrary-width clauses

Split F into a short-clause core B and long clauses L. For each variable i and value b form a binary column indexed by L marking the clauses satisfied by this single variable setting. Let k be the F₂-rank of the 2n columns. More generally, any efficiently encoded field matrix with precisely this nonzero pattern and rank k works. The binary matrix needs no supplied certificate.

For each assignment scan variables in order. Retain an index and value only when its chosen column increases the span of previously retained columns. At most k pivots occur. Conversely guess increasing pivot indices and their values. Require each pivot to increase the current span, and at every nonpivot allow only values whose columns belong to the preceding span. These are unary domains. By induction the resulting cell consists precisely of assignments with that record. Distinct cells are disjoint. A long clause is true throughout any nonempty cell exactly when some pivot is nonzero on its row, since that coordinate vanishes on every pivot exactly when it vanishes on the whole span. This is a support test, not parity cancellation. Test rows and use the short core counter with unary restrictions in each surviving cell, preserving free-variable multiplicities.

The deterministic time is P(n,k) times poly(input) times T_B(n), where P(n,k)=sum_{j=0}^{min(n,k)}2^j binom(n,j) and T_B bounds the pinned-core calls. Search needs only polynomial working space beyond the backend. For k=o(n) the logarithm of P is o(n), by (k+1)(2en/k)^k when k≤n/2. A fixed-width core then gives subexponential time using the stated fixed-width counting theorem, independent of polynomial clause density. Empty and tautological clauses may be handled directly.

long_pivot_check.py verifies 3,976 formulas and 116,120 candidate records, with 28,011 nonempty cells. All full assignments appear once, individual clause truths are constant on each cell and all tested core counts agree.

A stronger support-only variant replaces linear span by the union of clause rows already marked. A value pivots only when its literal adds a new row. Otherwise restrict it to one of the non-adding values and continue. The same disjoint unary cells result. For each pivot choose a row newly hit at that step. Restricted to these rows and pivot columns, the matrix has a triangular nonzero diagonal and zeros on the earlier-column side of it. Thus the number of pivots is bounded by the rank of EVERY realization of the support over ANY field, even without knowing such a realization. The output-sensitive DFS can merge all non-adding Boolean choices at a variable into one branch and keep the selected unary domains. A node is identified by its position and previous signed pivots, so the total is at most n times P(n,k) for any such rank bound. Empty or satisfied suffixes may stop early.

Pivots can alternatively be chosen by greedy set cover. On an assignment choose, among its true literals, the one covering the most uncovered long clauses, breaking ties by fixed order. Stop when no true literal has positive gain. Guessing the next pivot enforces only unary conditions: the pivot is true and every currently better-ranked positive-gain literal is false. The terminal no-pivot case pins every remaining positive-gain literal false. Inconsistent records are discarded. This partitions all assignments into cubes with a fixed final hit profile. The final signed pivot set determines its own greedy order by replay on just that set: at each stage the chosen pivot outranked every still-unselected member in its original execution. Prefix sets determine their order the same way. Thus at most P(n,b) consistent prefix sets occur if every run has at most b pivots. Greedy is applicable without being supplied b. If every assignment's attained union can be covered by c of its true literals, the usual greedy set-cover charging bound gives b≤c(1+ln m) for m≥1. On every path the pivots still give a triangular witness, so either bound applies.

For every fixed d≥2, take d equal blocks of variables indexed by points of F₂^h. Each positive long clause is the union of one affine hyperplane in each block; optionally include the corresponding all-negative clauses too. With n=d·2^h variables there are Θ_d(n^d) distinct clauses of width n/2. Each block's hyperplane indicator is an affine binary form, so stacked signed-incidence rank is at most 2d(h+1). Thus any additional fixed-width core crossing all these blocks remains subexponentially countable under the cited theorem, without one selector per long clause. No guarantee for unrestricted polynomial-density CNF follows.

An independent extension charges only residual ranks after a first violation. Order the long clauses. Starting from #B, subtract for each j the B-assignments falsifying C_j and satisfying every earlier clause. Pin C_j false, drop satisfied earlier clauses, shorten others, and move all clauses now short into the bounded-width core. Apply pivot enumeration on remaining variables/long clauses only, or brute force when few remain. The first-violation classes are disjoint. If j leaves n_j free variables and rank k_j, pay the sum over j of min(2^{n_j}poly(input),P(n_j,k_j)poly(input)T_core(n_j)). Thus small residual pivot entropy or few free variables can suffice even at global linear rank. For example long clauses G OR D for one wide guard G and every d-subset D of independent payload literals have linear signed rank, exponentially many compatible unions, and polynomial density. After falsifying any one, every surviving earlier clause is short. The same principle works whenever compatible pairs have bounded residual width, without a shared guard.

A sharp explicit profile-count control uses g disjoint copies of the binary incidence matrix with nonzero h-bit row and column vectors and entries their dot products. A positive-literal variable may choose its column or zero. Every subspace of F₂^h occurs as a chosen span, and its unhit rows are its orthogonal complement minus zero. In one block the number of distinct long-clause truth profiles is at least 2^{floor(h²/4)}: graphs of all linear maps from dimension floor(h/2) to dimension ceil(h/2) give that many distinct subspaces. The g-block product therefore has 2^{Ω(g h²)} distinct profiles for n=g(2^h−1), k=gh. This matches the k log(n/k) exponent in the regime of growing h. Padding all clauses with one common positive guard of Θ(n) fresh variables makes scopes connected and widths linear with rank increase at most one; setting the padding variables to zero keeps all witness profiles. Padding does not prove a lower bound on computing the scalar count, and ordinary components or a shared-guard split can bypass this family.
