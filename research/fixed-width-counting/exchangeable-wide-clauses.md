# Exact compilation of exchangeable long clauses

Normalize the chosen wide family and remove duplicate clauses. Keep any additional fixed-width core separately. Two variables are twins if swapping them, preserving polarity, preserves the wide clause list. Dictionary lookup tests each variable pair in polynomial time. This gives equivalence classes by conjugation (ik)=(ij)(jk)(ij). All independent permutations inside all classes preserve the family.

In a clause orbit record p_i positive and q_i negative occurrences on twin class i of size s_i. These counts completely identify the orbit. At assignment weights h_i some clause in the orbit fails exactly when h_i is between q_i and s_i-p_i inclusive for every i. Indeed the negative literals can then be placed on ones and the positive literals on zeros by a within-class permutation. Emit the single clause OR_i[(h_i<q_i) OR (h_i>s_i-p_i)], dropping impossible disjuncts.

All weight and threshold features together take O(n) bounded-fanin gates: compress triples in binary columns with full adders (each compression reduces total live wires by one), finish the last two binary numbers with a ripple adder, and decode the binary weight with a tree of binary-prefix tests to get all one-hot indicators in O(s_i) gates. A prefix OR chain yields every threshold. Encode gates by ordinary parsimonious Tseitin clauses. The result has O(n) variables, arbitrary original short core and one clause per orbit. For at most constantly many touched classes per orbit its width is bounded.

More generally pick a set T of classes and split their weights into contiguous intervals on which every used threshold is constant. Across the Cartesian product of intervals, pin each interval using two threshold units and simplify the orbit clauses. If each residual clause has bounded width, the cost is at most product_{i in T} (#intervals_i) bounded-width calls on O(n) variables, with disjoint model sets. Taking all b classes costs at most (1+n/b)^b, subexponential for b=o(n).
