Let t=#non-centreless tops, c=#centreless tops, j=#junk, q=#(orN minus lam), u=#Ustar, and tau=minimum cover cardinality. An actual counterexample requires tau+u>t+2c+j+q and global leastness in the exact binary, earlier-wire AND/OR model on the full Boolean cube.
Each non-centreless top supports a biclique: its OR-reachable leaves on opposite sides jointly activate the top. The sides cannot intersect (a singleton input never contains an edge); a 2-by-2 product gives a 4-cycle. One vertex covers each such star. An arbitrary endpoint per residual edge gives tau<=t+u, so 2u>2c+j+q is necessary.
For any residual edge pair, some AND in the output cone is active. If not, an active raw input can be traced backward through OR gates only to show the function accepts a singleton. Select the earliest active AND in the output cone. Its true operands are reached via OR-only paths from active inputs; if it were clean then it would cover the residual pair as a star edge. Hence u>0 implies j>=1.
In a least circuit, every gate reaches the output by deletion and renumbering. The last junk AND cannot be the output. A direct AND reader must be a clean top with one empty side, whereas a direct OR reader is outside BelowF and has an operand reaching no raw input. Thus j>0 implies c+q>=1, and u=1 cannot yield a strict defect.

Every clean OR has only clean children; raw inputs cannot be clean for a simple graph. All clean OR gates therefore lie above tops. TopForm forbids a downstream AND on the path from a top to the output. Every downstream OR is clean because the output is clean and every gate reaches it through OR gates. Hence the clean aggregation computes the union of T=#tops wires and uses exactly T-1 ORs, by connectivity in one direction and replacement by a tree in the other.
