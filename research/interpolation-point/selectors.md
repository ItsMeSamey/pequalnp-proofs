# Recognizing shared selectors for adaptive trees

Normalize clauses by dropping tautologies/duplicates and represent each by its forbidden partial assignment. Conditioning discards terms contradicted by the assignment and strips assigned literals from surviving terms; deduplicate again. Empty terms certify a zero branch. Use this precise syntactic simplification during recognition. Let a supplied menu of L variable trees be restricted to free variables by deleting fixed leaves (duplicate/empty induced splits harmless). A strong selector S of size ≤e allows every assignment to S to have *some* menu tree of width ≤w, possibly different for each assignment. Zero branches are finished. The following field-rank algorithm also pays attention to this exception.

Try the current S on its at most 2^e assignments. If every branch qualifies, output S and the choices. Otherwise take a failing assignment and for each tree take a cut of rank>w and a nonsingular (w+1)-minor in its pattern matrix. Build a protected-variable set. Include all variables of every nonzero witness cell's full clause. For each zero cell with full pattern P∪Q, identify every strictly extending clause and protect one excess variable of each. If no new selector touches the protection set, all nonzero terms stay unchanged and no zero cell can acquire an entry after restriction. Distinct nonempty row/column patterns remain distinct and nonempty since every row/column has a witness one. After restricted leaves are removed the induced cut still exists. Width k and occurrence Δ bound the set size by L(w+1)^2(k+Δ); every strict extender uses any one fixed literal of P∪Q, so there are ≤Δ parents per cell. Replacing the per-parent choices by a verified hitting set for the excess scopes may reduce this bound.

**Important zero-branch convention.** If a cofactor that produces an empty forbidden term is allowed to pass regardless of rank, a protected rank minor alone need not force failure after every assignment (the residual could be unsatisfiable). Two exact variants are available. (i) Use syntactic cutrank even for branches with an empty term (ignore that internally constant term when taking crossing ranks). Then every extension assignment avoiding the protection set retains the obstruction, and the resulting certificates still suffice for counting; zero branches may be skipped during evaluation. (ii) If immediate contradictions are admissible, protect one variable from every current clause whose entire scope could be selected by the remaining budget, to preclude completion of any fully selected forbidden term on every assignment; this may have an unbounded number of extra guards. A supplied satisfying assignment of the failing cofactor is a cheaper alternative: use its restriction to construct the one extension preserving feasibility. Without such an assumption the stated FPT guarantee concerns the syntactic variant (i), not semantic unsatisfiability tests. Unit propagation/subsumption beyond the prescribed simplifications are not part of this recognition proof.

For variant (i) every successful extension must select a protected variable; branch on each and recurse to depth e. Cost is O((1+L(w+1)^2(k+Δ))^e 2^e poly(N,L)). This fixed-menu result is exact with respect to its recognition definition. With unknown unrestricted trees one can enumerate candidate selectors and optimize a tree independently on every cofactor by the 3^n subset DP in tree.md; no FPT recognition of unrestricted trees follows here.

For structural width measured by maximum matching number of each pattern matrix's support, use w+1 matched terms per failing tree and protect all their variables. Additional edges cannot destroy the matching. Width k gives pool size Lk(w+1), independent of occurrence. A size-w matching bound gives a vertex cover of at most w by bipartite matching duality, hence a w-rectangle star cover and the fast semiring contraction. If the formula is globally unate, even k is unnecessary: for h=w+1 matching terms choose ≤h inside coordinates distinguishing their h distinct inside patterns and the empty pattern. Each informative coordinate refines their partition until all h+1 patterns are distinguished; choose ≤h outside coordinates similarly. A new selector avoiding these ≤2Lh variables may have removed other literals, but choose its one globally consistent assignment that realizes all selected forbidden literals on the new selector. Every matched term survives, with distinct nonempty patterns. Thus FPT(e,w,L) recognizes arbitrary-width unate strong selectors in the syntactic sense.

A growing support is genuinely possible for mixed signs: forbid (all n X bits zero and y_0 zero) and (all n X bits one and y_1 zero). The X|Y matrix is the two-by-two identity. Selecting any one x_i leaves rank at most one on both assignments, so a set meeting every good singleton must contain all n coordinates. This does not rule out a different FPT algorithm.

**Classical hardness for the actual pattern rank.** Take distinct Test Cover item rows R in {0,1}^d, coordinates representing tests. Create two variable copies X,Y of all coordinates and include one full-width clause for every a∈R forbidding (X,Y)=(a,a). Supply any tree containing the root cut X|Y. For a selection of variables on either shore, surviving clauses in a cofactor match the selected column values on R (conflicting duplicate-copy assignments leave none). In a consistent fiber, every pair of surviving rows differs on an unselected original coordinate; both shore copies remain, so the X|Y crossing matrix is a permutation matrix of fiber cardinality if at least two survive. If the selected underlying coordinates distinguish the rows, each cofactor contains ≤1 clause and every cut has rank ≤1 over every field. Conversely a nonseparated pair witnesses a cofactor of rank ≥2 at the root. Thus the minimum shared selector size for threshold 1 equals the minimum Test Cover cardinality, with one supplied tree. This shows classical NP-hardness for unbounded clause length/occurrence even at w=1. It does not show parameterized hardness in selector size. [Test Cover reference](https://doi.org/10.1016/j.ipl.2012.12.008). Numerical test selector_check.py compared rank-one protection branching with exhaustive selector enumeration in 120 two-layout instances.
