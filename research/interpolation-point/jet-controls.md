# Controls for attempts to project from low-precision Cauchy values

Use the exact Appendix D grid S={−L,...,L−1}, α=2^{a+1}, C(T)=∏_{t∈S}(T−t). In k fully occupied packets choose one matching distinguished slot x with both endpoint bits pinned to one and all other columns zero; sum the other rows freely. The resulting genuine tensor contraction polynomial is [C(T)/(C′(0)T)]^k. Its value at zero is 1. It vanishes to multiplicity k at every other grid point, so truncated jets through order k−1 at those centers cannot distinguish this network from a zero input. At a center t≠0 of valuation i, the whole local jet is divisible by 2^{k(a+1−i)} since C(t+αz)/C′(0) is coefficientwise divisible by 2^{a+1} and (t+αz)/2^i has a unit constant and integral inverse as a formal series. Extension-valued random ζ cannot compensate for the lost precision.

A second genuine input uses all even slot columns set to one and all odd slots to zero, with even slot rows pinned one and odd rows free. F(0)=1. At any odd t, every term of each active row has denominator t−y+x odd and numerator C(t+αz)/C′(0) divisible by 2^{a+1}. Thus M/2 active rows make the entire jet zero mod 2^{(a+1)M/2}. This controls only schemes using odd centers; the full source uses multiple valuations.

For a generic polynomial limitation put d=M(2L−1), δ_j(T)=∏_{q=1}^{2^j−1}(q−T)/q and G=∏_{j=1}^u δ_j(T)^{floor(d/(u2^j))}. Its degree is at most d and G(0)=1. At each active center with i=v₂(t), δ_j(t+αz) is integral. For i<j its coefficients are all divisible by 2^{j−i}: the complete mod-2^j difference grid has the same count of valuations as at zero, except the missing t−0 residue of valuation i replaces the excluded zero residue, while the new zero-residue factor has valuation at least j. For i≥j the nonzero factors retain their original valuations. The factor j=i+1 alone shows jet content ≥floor(d/(u2^{i+1})). Hence 0 and 2^{p−1}G are indistinguishable at insufficient precision simultaneously at all active nodes, while they differ at the origin modulo 2^p. This last G is a control for the degree-and-integrality interface; realizability by an actual tensor input has not been shown.

At an actual node one may omit terms using ≥q_t crossing modes before contraction, since each crossing coefficient in the geometric expansion contains z. Its 2-adic weight is ≥a+1−i+b for geometric index b; the source's mode lower bound b+1 is coarser. Local Boolean Möbius degree gives an independent truncation: a row tensor's multilinear extension of cut-active degree d cannot contribute more than d crossing substitutions. Carrying such auxiliary jet variables at every depth can multiply state sizes. These controls provide no uniform polynomial-time recovery from the paper's original evaluations.
