# Deterministic rank-only exact counting for binary CNF

Discard tautologies, repeated literals and duplicate clauses. Let r be minimum symmetric diagonal-completion rank of the off-diagonal quadratic coefficients of the number of violated normalized binary core clauses over a prime field of p≥5 (also works over Q). Each clause on two distinct variables contributes +1 or −1 according to the parity of its falsifying bits. Run 2SAT, return zero on inconsistency, and delete every globally forced variable, detectable by testing both pins. This restricts the quadratic array to its principal subarray. Choose a core model and complement selected free variables to make it all zero. The off-diagonal array changes by an invertible diagonal sign congruence, preserving minimum rank on the remaining coordinates. Keep equality-linked variables distinct during rank analysis.

A pair excludes 11 alone (+1, conflict), 10 or 01 alone (−1, directed implication), both 10 and 01 (−2, equality), or nothing (0). No 00 is excluded since zero is a model. Excluding 11 together with 10 or 01 forces one variable zero, already removed. Keep implication orientation from the clauses. Construct their directed graph including equality in both directions. Compute strongly connected components without building a new quadratic energy; all variables in a component have one bit.

Twin variables i,j have equal off-diagonal entries to every third vertex. Symmetry makes this an equivalence relation, with constant off-diagonal labels within/between classes. A rank-r completion has r basis columns; outside those column indices each row has one of at most 4^r signatures there, determining its entire completed row. Thus t≤4^r+r classes, computable directly in polynomial time without knowing r or any completion.

Process the implication components in topological order. State S is the set of types containing an earlier true variable. A zero component is forbidden if any earlier true type has a negative label to any current member: all between-component implications point forward. A true component is forbidden if its members clash internally or with an earlier true type via a positive label. Otherwise add all component types to S for a true bit, or leave S as is for a false bit. The internal type label is used only between distinct variables. Each clause is enforced by the time both endpoints are processed. Every valid sequence gives exactly one satisfying assignment, including forced variable values.

Time 2^t poly(N)≤2^(4^r+r)poly(N), with polynomial-bit integer counters. Rank after contracting equality or SCC blocks is never assumed small. Arbitrary additional literal pins may be enforced locally on components after translating their signs, so the signed-profile method gives min(2^d,3^s)2^t poly(N) for d further clauses of any width with s signed incidence types. Counts are positive exactly on satisfiable inputs. Parameter bound concerns the normalized unweighted core, not an arbitrary multiplicity-weighted energy.

### Reducing the state bound to 2^O(r³)

At each SCC cut C has prior rows and future columns, so rank(C)≤r. Its entries are 0,1,−1 because equalities cannot cross SCCs. Concatenate indicators (C∘C+C)/2 and (C∘C−C)/2: conflict and implication respectively. Their joint rank is at most D=r+binom(r+1,2), by expanding squared rank-r row/column pairings. Store the canonical row-reduced basis of indicator rows of past true variables. A constraint is active iff the corresponding future coordinate is nonzero on some basis row. Project basis vectors to the new suffix, append indicators of all rows of the just processed SCC if true and reduce. Thus transitions only need the old span. The cross block has ≤3^r distinct rows, using an independent set of at most r cross columns. Any reachable basis is spanned by at most D actual rows, so the number of canonical states is ≤(3^r+1)^D. Runtime 2^O(r³)poly(N); no completion or guessed order is required. This argument does not even require global twin IDs. Labels +1 and −1 denote exact residues, not an order on a prime field. The sharper cross-block proof also holds in characteristic 3 if types of constraints are read from the clauses before SCC formation: the residue collision between equality and conflict never occurs across the cut. Pins carry through this algorithm unchanged. Counting with arbitrary long defects costs 2^O(r³)min(2^d,3^s)poly(N).
