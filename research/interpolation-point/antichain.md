# Two selector reductions with antichain inputs

Reduce Set Cover with budget k. Duplicate all designated private row variables and anchor variables more times than the selector budget. Each nonzero cell is a clause forbidding its row variable equal to zero together with its column pattern; bare anchors are single private variables assigned zero. Terms have width at most three.

**Canonical subsumption, complete supplied tree, rank one.** On X use A and B row types. On Y put one selector per set and private element and reference anchors. Bare reference anchors have A and B; bare element anchors have A only. For every containing set, add both assignments to its selector as extensions of each element anchor on B rows ONLY. Thus the input has no strict subsumption. Each cofactor strips assigned literals, drops incompatible clauses and duplicates, then removes strict supersets of any forbidden pattern. A cover yields bare B clauses for all elements, subsuming all surviving guards. What remains is the complete bipartite bare family X by all anchors, whose rank is at most one on every edge of a tree rooted at X|Y: each proper subtree lies entirely on one shore. Conversely for any selector missing an element, assign all pinned private variables the nonforbidden bit, so no smaller clauses arise from them. An unpinned A and B row plus untouched reference and uncovered-element anchors form a unit determinant. This branch is satisfiable by setting all free X variables to one. Thus minimum shared selector recognition is W[2]-hard at full-tree width one after canonical literal subsumption. Resolving opposite guards would change the problem.

**Deduplication only, antichain input, rank three at one prescribed cut.** Use four X row types. Each set i has two alternative selector variables l_i,r_i, both on shore Y. Bare element vector a=(1,0,0,0). For each set covering that element give the extended pattern with either bit value of l_i the vector b=(0,1,1,0), and with either bit value of r_i the vector c=(0,0,1,1). Add permanent bare reference columns b,c,d=(1,1,1,1). The input is an antichain: bare element a is disjoint from both guarded vectors; reference anchors are separate. The independent references span the hyperplane with normal (1,−1,1,−1) over every field. A bare element becomes a, a+b, a+c or d depending on which families cover it. With both, overlap is deduplicated; with neither or only one, the normal gives one. Remaining guarded columns lie in the reference span. Selecting the same k-cover in both families uses 2k and produces rank three in all assignments. If some family does not cover, choose safe values on all privately pinned variables and retain one surviving copy per type/anchor: that element together with references has rank four. Thus a valid selector gives covers on both sides with total at most 2k, so at least one cover has size at most k. This is a prescribed-cut hardness theorem even in characteristic two; other cuts are not bounded. Neither reduction concerns the semantic truth-table rank. Independent audit computed four integer determinants −1,−1,−1,0.
