# Exact counting from a pure lexicographic footprint

For expanded squarefree Boolean ANFs fix a pure lex order with least-priority variable x in the least significant bit position. Gaussian-reduce the current coefficient rows. A constant-one row proves contradiction. Call a support standard if it contains no pivot support. Write F for the number of standard supports. Every possible leading support of a nonzero row-space element is a pivot column, by echelon form. For the zero row space F=2^D; a constant pivot gives F=0.

After splitting on x, pair parent supports T and T∪{x} for each remaining T. If T contains a pivot S, choose a polynomial with leading S. Its restrictions both retain that leading term: deleting the least-priority bit preserves order except within consecutive pairs S,S∪{x}, and the larger member is absent. Thus T is nonstandard in both children. If T is standard but T∪{x} is not, some pivot S∪{x} has S⊆T. The coefficients at S of its two restrictions differ by one. No greater term occurs in either restriction, so in at least one child S is a leading term and T is excluded. In the remaining case both parent supports are standard. Summing gives F_0+F_1≤F. The argument uses leading terms in restricted row spaces and does not require restrictions of a basis to remain independent.

Every node without a constant-row contradiction has F≥1. Each level has at most the initial F such nodes. Checking dead children adds at most two per live parent. Depth-first traversal computes count and original witness in O((D+1)(F+1)poly(expanded input,D)) time and polynomial space. Restricted original polynomials have no more monomials than before substitution; Gaussian combinations only use their collective columns. Empty systems and constant contradictions have the usual counts. Polynomially generated sound consequences may be adjoined if their representation and construction costs are charged. Enlarging a row space preserves all earlier possible leading terms, hence decreases F. A uniform time-sharing race can take the better time bound of this solver and the graded-border solver; polynomial workspace for the race requires an explicit cap on the border lane and does not follow from lex alone.

For arbitrary-width native CNF a separate unexpanded rule uses F equal to the number of subsets avoiding every clause's variable scope. Drop tautologies and repeated literals. For a subset T of remaining variables avoiding nonincident clauses, let b_0,b_1 indicate whether it also avoids shortened incident scopes in each cofactor. The children contribute b_0+b_1 and the parent contributes 1+b_0 b_1. Thus the same mass inequality gives O*((F+1)) time and polynomial space for ordinary DPLL. A monotone signing excluding the all-one word on each scope has exactly F models. Gaussian or nonlinear consequences can add forbidden supports absent from this CNF-only criterion.

Counterexample for graded order: use priority x<y<w<z, equations xz+yw=0 and y=0. Graded lex gives leading supports xz,y, so F=6. Splitting x leaves graded leading supports yw,y in both children, each with four standard supports, for total eight. The proof therefore cannot be transferred merely by renaming the graded-border footprint. Choosing x highest instead of lowest in pure lex also fails on this example when the other priorities put z below y,w.
