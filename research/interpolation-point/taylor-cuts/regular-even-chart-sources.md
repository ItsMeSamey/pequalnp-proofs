The constructive same-site CSS recognition step uses Theorem 1 and Proposition 3 of the [2026 CSS recognition paper](https://arxiv.org/abs/2610.28737). The connectivity argument uses [Seymour’s uniqueness theorem for connected indexed binary matroids, up to duality](https://www.sciencedirect.com/science/article/pii/0095895688900524). Combining these steps with the even-chart algorithms yields the recognized class and its witnesses.
