# Prime-field witnesses for ordered permutation passes

Use a verified common control order and forward/reverse pass partition as in gram-pass-rails.md. Work over F_p. Instead of summing assignments, store a basis of reachable pure pass tensors, each together with one actual prefix assignment yielding it. Extending by either value of the next control is a linear map on the ambient tensor space. Applying both maps to basis representatives therefore spans all reachable successors. Discard duplicate successors and select an independent subset of the remaining actual candidates, retaining their prefix assignments. No assignment multiplicities enter this process.

For m candidate pure tensors, the following exact rank oracle avoids constructing their exponentially many entries. Start with the span in F_p^m of the all-ones vector. For pass j, each state-matrix coordinate supplies a length-m vector of the corresponding entries across candidates. Take all coordinatewise products of these vectors with the current basis vectors and compute a basis of their span by Gaussian elimination. Inductively this is the span of row vectors of tensor coordinates through pass j: each additional matrix entry multiplies a previous coordinate. The final row space has the column dependencies of the full tensor-coordinate matrix. Its Gaussian pivot column indices select linearly independent actual candidate tensors. This argument does not require the rational positive-definiteness of a Gram matrix, which can fail in finite characteristic. For permutations, summing all target entries at one fixed source gives one on each candidate; thus partial coordinate spans cannot decrease in dimension as passes are processed.

At termination, on a pure basis tensor concatenate its pass permutations in their actual temporal order and apply the given final closing permutation. For any fixed starting state s the diagonal entry at s is linear in the full tensor, since this ordered matrix-product entry is multilinear in the pass factors. It takes value zero or one on actual assignments, including the stored representatives. If it is nonzero anywhere on the reachable set it must be nonzero on some representative. Checking all diagonal entries therefore returns an actual closing start and complete control assignment or certifies that none exists. A supplied start requires only its diagonal entry. No self-reduction or counting modulo p is involved. Under the additional Barrington promise that every full product has either five or zero fixed points, the trace alone is a valid acceptance functional at p=2. Two fixed points in an arbitrary rail can give zero trace mod two; the general diagonal test still works.

For supplied passes, prime p and maximum reachable rank r_p, this takes polynomially many operations in n, pass count, state count and r_p, with polynomial space and field bit sizes. The reference checks primality by trial division, so its preprocessing polynomial-in-log(p) claim would require replacing that check or supplying a prevalidated prime. Fixed p=2 needs no such change. The algorithm addresses existence and witness recovery; exact counts are covered by the distinct rational algorithm. For arbitrary programs a polynomial upper bound on r_p is not established.
