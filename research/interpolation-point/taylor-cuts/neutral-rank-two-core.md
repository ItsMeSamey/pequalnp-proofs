# Constructive reduction to a three-terminal cut-rank core

Let G be a simple undirected graph and T exactly three distinct terminals. A feasible subset contains T and induces even degrees. Let S be any terminal-free subset and M its adjacency toward the exterior E. If M has binary rank k≤2, factor M=L R^T with both factors of full column rank k, writing ℓ_i and r_j for the rows. For fixed exterior bits e, the incoming state is b=R^T e. For selected inside bits x the outgoing state is c=L^T x. Internal feasibility requires degree parity ℓ_i·b at each selected i, and every exterior vertex j receives additional parity r_j·c. Handshake forces b·c=0, including if some exterior vertices are unselected. Equal tables of attainable (b,c) therefore preserve feasibility for every exterior, with a stored local witness for every attained state.

For k=0 delete the shore. For k=1 keep one isolated representative labeled 1. The full orthogonality table is realized by the empty set or a singleton. For k=2 at least two linearly independent nonzero labels A,B occur. An occurring label c is realized by its singleton for any b perpendicular to c. Empty realizes c=0. If all three labels occur use three independent vertices A,B,A+B. Otherwise write C=A+B and let d be the unique nonzero perpendicular to C. Only (0,C) and (d,C) are in doubt.
* For (0,C), select a nonadjacent A,B pair if available. Otherwise A,B classes are completely joined. A zero-label component touching both yields an induced cycle by taking a shortest A-to-B path with neutral internal vertices and restoring the endpoint edge. In absence of such a component, put A and B on opposite shores and assign each zero component to the class it touches or arbitrarily if neither. The cut of any target witness then has an odd number of edges (the product of the two odd class counts), impossible in an all-even graph.
* For (d,C), both A and B labels have mark one and zero labels have mark zero. A component meeting both classes yields a shortest path between opposite labels with all interior labels zero, hence a witness. Otherwise each component has only one type of marked vertex, and handshake prohibits an odd total of either type.
At least one is attained: for any occurrence of A and B a nonedge realizes the first, an edge realizes the second. If only the first holds use two isolated vertices A,B; if only the second holds use two adjacent vertices A,B; if both hold use three isolated vertices A,B,C. Each representative i connects to each old exterior j iff ℓ_i·r_j=1. No operation creates loops or parallel edges. Local stored witnesses and c agree on every exterior incidence, including incidences to terminal vertices.

To discover a strictly reducing shore, enumerate four distinct neutral vertices X. Minimize the symmetric submodular cut-rank ρ(S) subject to X⊆S⊆V minus T. Restriction and fixing X preserve submodularity on the unfixed vertices; each value is computed by Gaussian elimination, so polynomial-time submodular minimization returns a minimizer. A value ≤2 produces at least four vertices replaced by at most three. Conversely every terminal-free shore of size≥4 and rank≤2 contains such an X. Repeat at most n times. To lift a final witness, work backward: compute b from the current exterior and c from chosen template vertices, and restore the recorded original local witness. The empty-shore template needs only c=0. This preserves all pin bits and reconstructs an original witness in polynomial time. All polynomial bounds here are uniform in the input.

At termination either at most three neutral vertices remain, or κ(X,T)=3 for every neutral four-set X, where κ minimizes cut-rank over precisely those constrained shores. The upper bound is from V minus T. Oum's linking theorem identifies this with the existence for each X of a pivot-minor on X∪T retaining cross rank three. This last existence is a connectivity certificate only; it does not assert preservation of all three selected pin states under the chosen pivot operations, nor does it find a common pivot block satisfying the terminal parity targets. No size bound for the reduced core is asserted.

Primary source on cut-rank submodularity and linking: Sang-il Oum, Rank-width and vertex-minors, https://mathsci.kaist.ac.kr/~sangil/pdf/vertexminor.pdf . For polynomial oracle submodular minimization see S. Iwata, L. Fleischer and S. Fujishige, https://doi.org/10.1145/502090.502096 .
