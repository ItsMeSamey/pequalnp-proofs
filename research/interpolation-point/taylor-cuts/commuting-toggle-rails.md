# Counting signed shared controls on cyclic permutation rails

Each gate of a supplied cyclic rail maps its input port to its output port by one of two bijections; a signed, shared Boolean control selects the bijection. State labels may differ by site but each port is indexed locally by its domain. The grouped-table validator checks totality, functionality and bijectivity of each Boolean slice. This assumes that the groups and their input, output and Boolean port correspondences have been supplied; it does not recognize a rail embedding from unrestricted gate networks.

Starting with the identity frame E_0, set E_{j+1}=P_j^0 E_j. In frame coordinates the zero transition is the identity and the one transition is Q_j=E_{j+1}^{−1} P_j^1 E_j. For original start s and normalized endpoint y the closing condition is E_last(y)=s. The final frame need not commute with any toggle.

For two occurrences i<j of distinct controls on the same rail, add an arc from the former control to the latter exactly when their normalized permutations fail to commute. Union the arcs over all rails. Stably sort every rail by topological order of the strongly connected components, preserving all within-component occurrences. Every inverted pair commutes, so adjacent swaps preserve every control assignment's action. Negative controls change which assignments activate a toggle and preserve the swap proof. This allows noncommuting controls in distinct components whenever their precedence is consistent. An undirected noncommutation graph would put all of them in one block along a directed chain.

For each component C, enumerate its 2^|C| Boolean assignments, evaluating the ordered action on each rail. For each tuple of original start states, run a count DP over the tuple of normalized endpoint states, in component order. Merge counts ending in the same state and retain one original control assignment for witness reconstruction. Filter by the final-frame condition, multiply by the free-control factor, then replay each original gate to recover every port. Each accepted start and control assignment specifies exactly one port labeling, including in an empty rail with one port.

With H the product of rail domain sizes and b the maximum component size, the time is O*(H² 2^b), and the reference stores O*(H+2^b) data, including its precomputed component actions. Polynomial factors account for rail descriptions, control masks and count bits. Contradictory orders may put all controls into one component, giving no control-exponent improvement. The implementation validates supplied grouped local Boolean transition relations, independently of any automatic source decoder.

The checker compares 85 signed multi-rail systems with direct enumeration, including independently scrambled site frames, and checks an explicit directed precedence cycle across two rails, an internal cycle, an acyclic noncommuting order, rejection of incomplete or nonbijective tables, and five versus six repeated increments of a mod-six state.
