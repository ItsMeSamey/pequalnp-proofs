# Counting with sparse private-normal elimination

Represent a factor on a binary normal space P by an ordered independent basis, a nonnegative integer default a, and a dictionary of exceptional evaluation tuples and their actual weights. Canonicalize to the shared RREF convention before combining. If two factors have the same scope, their product has default ab and exceptions contained in the union of their exceptional keys. Remove keys that equal the new default.

For a scope P let W span the other live scopes, L=P intersect W, and q=dim P−dim L. If q>0, replace its table by a table on L with default 2^q a. For every explicit old tuple z project its evaluations onto L and add f(z)−a at that key. Delete keys with zero net correction. Every evaluation on L has 2^q lifts to P, and any evaluation on W agrees with exactly those lifts giving its own evaluation on L. Each agreeing pair glues uniquely on P+W. Consequently the replacement sums the q private dimensions exactly. Internally, correction values may be negative while every resulting table value remains nonnegative. Use the separator implementation's scope_split, values, and row_basis operations.

Store a global scale for actual scalar weights and for discarded unconstrained directions. At each round after merging and removing constant factors, multiply by 2 raised to the difference between the current assignment-space rank and the rank of the surviving scopes. Immediately after a private step the current assignment space is W, since the other q dimensions were already summed. This bookkeeping covers unused coordinates, cancelled exceptions, projected constants and zero weights. The residual represents the original partition sum as its global scale times the sum of the residual product over assignments to the residual normal span. A zero scale certifies zero. The default rank budget zero computes the exact count if elimination completes. Otherwise return the weighted residual and an unspecified count; a supplied rank budget b permits enumeration only if the residual rank is at most b.

For each elimination retain W, bases of L and of the private complement, and the exceptions bucketed by their shared evaluation. Given a positive residual assignment, reverse the steps, preserving its evaluation on W. If the original default was positive choose any private tuple except those explicitly assigned zero; testing successive integer codes skips at most the number of exceptions. If the default was zero, select an explicit positive tuple in the bucket. Existence follows from positivity of the projected sum. Solve the resulting linear system in the ambient coordinates. Constant positive factors impose no witness restriction. The CNF adapter stores its XOR chart, so externally supplied positive residual words can also be lifted by lift_original, which checks every original clause and XOR. For scalar weighted inputs this recovers a point of positive weight.

Projection never increases the number of exceptions, and merging takes at most the sum on its inputs. There are at most d private steps in dimension d. Each step and trace costs polynomial input overhead: no table indexed by all 2^q private words is created. A crude bound on intermediate numeric bit lengths is O(d+sum_i log₂(1+max(default_i, all exceptional weights of i))); nonnegative factors originate from disjoint sets of initial factors when multiplied, and at most d binary dimensions have been summed. Actual running time after peeling is polynomial times 2^r only when the caller permits this for residual rank r.

Rank-one residuals already encode hard counting. Given a simple graph with no isolated vertices and n vertices, let B=2^(n+1). Attach the unary factor B^(deg(i)x_i) on each vertex direction and B^(1−(x_i xor x_j)) on each edge-parity direction. All weights are positive integers of polynomial bit length. Every edge direction is a sum of vertex directions, and each vertex direction is a sum of an incident edge direction and the neighbor's vertex direction, so none is private. The product on x is B^(|E|+2 times the number of edges with both endpoints selected). Thus (Z divided by B^|E|) mod B equals the exact count of independent sets. This reduction concerns general positive weighted residuals and does not assert that every such integer weighting arises from a small unweighted CNF. Feasibility is immediate in the example.

The independent checker compares 240 sparse weighted systems and 140 pinned CNFs with exhaustive enumeration, including positive lifts of all residual representatives in the small tests. It checks the independent-set coefficient on a four-cycle and a rank-95 private factor with one exception, solved without enumerating its private words.
