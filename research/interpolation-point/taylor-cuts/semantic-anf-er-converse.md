# ER replays explicitly charged sparse ANF map refutations

**Theorem.** Let F be an explicitly encoded fixed-width CNF. Start with its clause-falsity equations in the Boolean ANF ring. Consider a finite chain of existing decision-edge certificates ending in a system containing the equation 1=0. Each forward map is explicit, and for each target generator the forward certificate gives its pullback as a sum of multiples of source generators. Charge the sparse polynomials, maps, coefficient masks, term-pair products, cumulative support operations, and all intermediate substitution expansions used to check these identities. From such a chain one can construct an ER refutation of F in deterministic time polynomial in this charged size. The reverse directions need not be used in this translation. Together with semantic-anf-er-simulation.md, this gives polynomial equivalence for these explicitly charged refutations on 3-CNF.

**Local ER toolkit.** Extension variables name fan-in-two AND, XOR, and negation gates. The latter two gates have constant-size implementations using conjunctions of literals and literal negation. Constants may be encoded by x AND ¬x and its negation, using any original variable; the variable-free unsatisfiable input already contains the empty clause. Equalities of wires are pairs of implication clauses, fixing a wire value is a unit clause. Any valid consequence on a constant number of wire names of a constant-size set of gate definitions, equalities, or units has a uniform constant-size resolution-with-weakening proof: to prove a clause, set its literals false and branch on the remaining local wires. Each completed assignment falsifies a premise, which weakens to its full blocking clause; resolving the branch tree gives the desired clause. Tautologies may be skipped. Weakening is admissible for refutations under the presentation without explicit weakening, by carrying a derived subclause for each proof line. Thus ER can prove congruence, associativity, commutativity, idempotence of AND, cancellation under XOR, and distributivity at named wires using constant-size local derivations. This argument imposes no Boolean truth-table search on all original variables.

**Canonical sparse values.** Take one named tuple of Boolean values for the current layer's source coordinates. For every monomial required by a verification trace, name its ordered AND of the current coordinates selected by its squarefree mask. The empty mask has value one. Name each polynomial as the XOR of its monomial wires in a fixed mask order, starting at zero. The same list of masks on this tuple has the same designated output. Prefixes can be shared or copied with equality witnesses. All gates have unique definitions from earlier coordinates.

A sparse product of A and B has the following polynomial-size ER arithmetic proof. Introduce output ANDs for term pairs. For each pair of masks M,N prove that its AND is the canonical wire for M∪N. Scan the original coordinate positions (or only the sorted union); the maintained equality relates the AND of the two partial monomial wires to the partial union wire. At the next coordinate each operand either appends that bit by AND or stays unchanged. If at least one appends it the union appends it once. Each equality update follows from the prior equality and local gate definitions by the constant-size toolkit, including the case when both append. The same proof works for repeated coordinates in overlapping masks.

For explicit distributivity, let P_i and Q_j be the running XOR prefixes of the two input lists. First establish that P_a AND Q_b equals the XOR over i of (term_i AND Q_b), by induction on i for P_i AND Q_b. For each i, expand term_i AND Q_b in j using the Q_j prefix recurrence. All recurrence equalities follow by one local distributivity proof and congruence; concatenate the XOR lists by associative prefix rebracketing. This uses polynomial work in the list lengths and their product, including the empty-list case. Replace term pairs by the union wires just proved. Sort the expanded list by adjacent swaps, remove identical adjacent pairs using XOR cancellation, and remove zero constants. A swap or deletion may rebuild an entire suffix of the running XOR and propagate equality forward through it, costing O(t) small gates and derivations for a list of length t. At most O(t²) swaps/deletions suffice. The resulting wire equals the XOR of the canonical support, exactly the coefficient parity of the squarefree product. An XOR sum of sparse polynomials uses the same concatenation, sorting and parity deletion without the product step. These bounds charge pre-cancellation lists, not merely surviving output terms.

**Layer induction.** Assume ER has derived a zero unit on every source generator at its current wire tuple X. This holds initially: each input clause forces its own falsity-evaluation wire to zero by the local lemma since its width is fixed. Define the next tuple Y coordinatewise by evaluating each supplied map ANF on X. These are gates, not new freely guessed values. Evaluate each target generator f on Y. To compare its value with its checked pullback on X, mimic the actual verification schedule. For each target monomial multiply its successive coordinate images on X, certifying the canonical partial-product supports by the sparse product lemma. The AND of the corresponding Y-coordinate wires equals that partial product by congruence at each step. Sum the target terms with the XOR lemma. A zero partial product may skip remaining factors because zero AND anything is zero. Thus f(Y) equals the canonical evaluation of its expanded pullback on X.

Independently evaluate the certificate's sum of multiples Σ h_j(X)g_j(X) on the same X by the sparse product and XOR lemmas. Each product evaluates to zero by the corresponding source unit, so the sum evaluates to zero. The verified canonical supports on the two sides are identical. Consequently ER derives the unit f(Y)=0. Apply this to every target row and advance using Y as the new source tuple. No accumulated map is expanded on the initial variables. At the final row 1=0 these units contradict the fixed truth of the constant-one wire, yielding the empty clause. Ground systems with no variables admit the same argument using constants; an initially empty clause already terminates directly.

**Cost and scope.** A deterministic translator can recompute the sparse traces from the presented edge certificates, then enumerate the local gates, congruence certificates and resolution steps described above. The term-pair enumeration, per-mask coordinate scans, explicit reorderings and repeated wire definitions are all polynomial in charged size even without cross-edge sharing. One may equivalently charge the full explicit input size plus actual bit cost of running the specified sparse checker, whose multiplication loop visits every pre-cancellation pair and whose monomial-mask input is explicit. Explicit coordinates or reindexing the used names avoid dependence on a binary-coded unused universe bound. A tiny symbolic circuit plus uncharged, potentially exponential normalization does not meet this size measure. An unresolved cycle, an oracle decision, a bare semantic implication, or a compact identity verified by a different procedure supplies no such ER refutation through this theorem. This is a comparison of verifiable refutations, not a polynomial-time SAT algorithm or a lower bound for ER.
