# Explicit row and interface certificates in extended resolution

Extended resolution (ER) admits acyclic definitions of fresh Boolean gate variables and resolution on the input and definition clauses. Extended Frege (EF) and ER polynomially simulate one another. See Krajíček, Lemma 4.5.8, for the explicit equivalence statement. A local Boolean consequence on constantly many named gate values can also be established directly by resolving its finite truth table. [Bounded Arithmetic, Propositional Logic, and Complexity Theory](https://www.karlin.mff.cuni.cz/~krajicek/kniha.pdf).

## Finite-field rows

Fix a finite field of order q, with fixed truth tables for addition and multiplication; O_q hides these gate and proof constants. For Boolean inputs name by AND gates the squarefree monomials of degree at most d, in a common order. Put D=Σ_{i=0}^{min(d,n)} binom(n,i). At most O(dD+1) binary definitions suffice. Represent row evaluations in a fixed finite encoding of the field; one-hot values are sufficient. Name a row's running field sums in column order, with its coefficients as constants. Each term is its constant coefficient if the named Boolean monomial is true and zero otherwise. For every asserted row P derive its final sum equals zero.

Given earlier asserted rows P,Q and a verified explicit row R=λP+μQ, let P_j,Q_j,R_j denote the first j column sums. Prove successively that R_j=λP_j+μQ_j. At each step the three recurrences involve only the preceding partial sums, one common Boolean monomial and their successors. The constant-field addition identity and supplied coefficient equality prove the step by a constant-size truth-table resolution derivation on these gate values. The last identity and input zero assertions give R=0. This needs O_q(D+1) gate definitions and derivation lines per elementary row operation. The proof also handles zero columns or a constant-only row. A final nonzero constant asserted zero gives an immediate refutation.

For an input clause of width w, express its violation indicator as the product of its falsified-literal indicators in the fixed field. With Boolean inputs they are x or 1−x. Its expanded evaluation is zero on the clause. One explicit proof branches on the w input bits, using the original clause at its single falsifying corner and propagating gate definitions at all satisfying corners. This costs O_q(2^w times the size of the evaluation circuit on that scope, plus O(w·2^w) literals for branch clauses); the circuit can omit absent terms, using O_q(w·2^w+1) gates. Adding omitted zero columns to align with global running sums costs O_q(D) lines per row. Analogous input encodings require explicit proofs that their row assertions follow from the original CNF.

To form an explicitly listed variable multiple xP, distribute the factor through partial sums using one constant-size local field identity per summand. Each product of a named monomial and x equals the named sorted union monomial; associativity, commutativity and Boolean idempotence of AND give a conservative O(d²+1) sequence of local gate identities per term. Now sort the at most D resulting terms into canonical column order by at most D² adjacent exchanges, reparenthesizing the sum locally, and combine equal monomials with the field addition table. Each swap in a left-fold requires only a constant-size local associativity/commutativity proof at the two affected accumulator positions: the resulting prefix total agrees with the previous one at the end of the swapped pair, so the unchanged suffix reuses its old accumulator gates and their proofs. Equivalently normalize in a sequence of lists of field-valued gate names, sharing the unchanged prefix and using the final accumulator of the pair as the common wire for the suffix once equality is proved. This yields a conservative O_q(D²+d²D+D+1) steps per factor using wire equality forwarding; a literal implementation that rebuilds and proves equality along the suffix after every swap costs O_q(D³+d²D+D+1), still polynomial. A simpler squarefree Boolean multiplication implementation avoids sorting: for each ordered source monomial, insert its contribution into its known destination column and compare source and destination sums by a D-by-D prefix array, using the finite-field associativity identities on grid cells.

Accordingly one safe bound for S elementary linear operations and R explicitly listed generator multiples of at most d factors each is O_q((S+1)(D+1)+R(d+1)(D³+d²D+D+1)+dD+input-axiom costs) named-gate and local-proof steps, assuming all supports encountered have degree at most d. Each line has bounded width except for input-axiom splitting; writing variable indices costs at most a logarithmic factor in the size of the proof and input. Dense Gaussian elimination on R rows uses O(RD) elementary row operations, and row-entry computation is separate polynomial preprocessing. With fixed d and fixed field, and explicitly polynomially many input multiples, this yields polynomial-size ER refutations when the elimination yields a contradictory constant. For varying d the displayed dependence on D matters. A small circuit for an unexpanded polynomial does not supply this explicit input size bound.

## Relational interfaces

For a tree node with interface I, the clause excluding an assignment s to I contains the negation of its assigned value for each bit. Derive such clauses bottom-up. Suppose all local tests and child-interface scopes are contained in a set B of h Boolean variables including I. For every completion on B of an infeasible interface assignment, a directly applicable input clause or an earlier proved child exclusion is falsified. Weaken that clause to the clause excluding the entire completion. Pair and resolve over B minus I to derive the desired interface clause. For all excluded assignments together this costs O(2^h) clause lines and O((h+1)2^h) literal occurrences per node when weakening is available, or the corresponding routine polynomial overhead with pure resolution. At an empty root interface an excluded empty assignment gives the empty clause. In particular a binary composition of disjoint factors meeting only at z has two cases after projecting each factor to its z relation. This gives a short proof if the missing z-values have short factor derivations. A one-bit boundary by itself supplies no size bound on proofs inside the factors. For the forcing-pair example resolving (z∨a),(z∨¬a) gives z, resolving (¬z∨b),(¬z∨¬b) gives ¬z, and their resolution proves contradiction.

A frozen compiler tree need not have any gate computing a row invariant or projected relation; ER permits introducing such gates and reusing proved lines throughout a DAG. An externally proposed lemma is admissible here only with a derivation from the input, or as a conservative definition whose claimed consequences are actually derived. An upper bound for these two explicit certificate classes supplies no general ER upper bound for a checker described only by its running time.

For a direct quadratic-size regrouping proof, index source terms t_i by i and write k_i for their destination. Define A_{i,j} by summing the terms t_l with l≤i and k_l≤j, using the recurrence in i. Define B_{i,j} by the same recurrence with k_l=j. Induction in i proves A_{i,j}=A_{i,j−1}+B_{i,j}; each step uses only a constant-size field identity and the known comparisons k_i<j, k_i=j, k_i>j. At i=D each B_{D,j} equals the combined scalar coefficient in column j times the monomial for that column, by the same recurrence and the already proved monomial identities. Thus A_{D,D} is both the full source sum and the canonical destination sum, using O_q((D+1)²) bounded-field steps. This replaces D³ in the safe bound above by (D+1)² without requiring any implicit suffix reuse.
