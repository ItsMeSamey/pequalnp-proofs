# Reachability certificates for clustered permutation passes

The Boolean certificate verifier fixes the field to F₂. It uses the source passes, common control order, contiguous cluster lengths, closing permutation and optional start pin as the public instance. A SAT proof gives a control word and starting state and is checked by executing the original signed gates. An UNSAT proof gives, at every cut, lists of actual prefix masks separately for each cluster and one list of actual suffix masks for all passes. Masks must be zero outside the appropriate side of the cut. The lists need not be minimal.

The forward verification starts from the identity tensor on each cluster. At each control it forms the two successor tensors of every preceding representative, using the same bit across that cluster's passes. It checks that these columns lie in the span of the advertised actual tensors. The test puts advertised columns first and rejects a pivot among the added candidates. The coordinate-row calculation processes one pass at a time, retaining at most as many rows as columns, without forming the full tensor. Linearity of the bit-conditioned transitions now places every reachable local prefix in the advertised span.

For suffixes, the coordinate functionals are the independent choice of one advertised prefix per cluster, followed by the original closing test for one start. For all-start verification each start is a separate output, so an even number of fixed points cannot disappear by cancellation. The width-bounded matrix-product calculation propagates field row spaces over slots indexed by candidate suffix and boundary state, processing clusters sequentially. Its final pivot test establishes that the observable columns of the extended suffix candidates lie in the span of the advertised columns. Start from the empty suffix and iterate backwards. A one-bit prefix extension at a cut is a reachable prefix at the next cut in each cluster, hence lies in its checked forward span. Multilinearity therefore transports any previously verified observable suffix relation through prepending that bit. At the root every advertised suffix has zero closing indicator for each allowed start. Consequently every full control assignment fails the stated start condition.

The verifier runs in time polynomial in the input and the total explicit list length, including the domain size, using deterministic finite-field elimination. It shares the permutation preparation and row-space kernels with the solver. It checks closure of supplied lists without generating fresh bases or calling the search routine. Proof lengths can grow exponentially. A start-pinned refutation proves failure only for that start. The reference excludes promised scalar-trace mode entirely.
