# Certified simplification before commutator expansion

Reconstruct the signed CNF compiler's balanced source tree from its original ordered clauses and literals. A local hint gives a binary child path, a selected list of source conjuncts, and a signed-renaming branching-DAG refutation of those clauses. The verifier follows the path in the original tree, descends only through conjunctions to collect implied literal disjunctions, and checks each selected clause belongs there. It then verifies the refutation. An unrelated contradictory formula or a proof attached to a different branch does not establish the claim.

Replace a verified contradictory subtree by false. Simplify Boolean constants, identical children and complementary literal children with the AND/OR truth tables. The original compiler realizes true by its target five-cycle and false by identity at every recursive call: its literal rule has this property, conjunction uses a commutator whose target is obtained exactly when both children are true, and disjunction complements both children and the result. Recompilation therefore preserves the original full-assignment permutation pointwise. A constant root needs no gates. This proof is for the supplied CNF and the named compiler's compositional semantics; arbitrary externally supplied rails require separately verifying their provenance.

The optional producer groups clauses of identical support at each conjunction and tests sufficiently populated small groups (default width four). This does not find all contradictory cores. The supplied-DAG verifier is polynomial in explicit source, paths and proofs, apart from any subsequent output expansion. Producer signed-renaming search may use up to 2^d d! renamings per residual on d active variables, and proofs may grow exponentially. No implication is inferred from separate child witnesses for incompatible assignments.

The hostile source with four repeated independent-set clauses H, the four sign patterns G on two fresh selectors, and eight cyclically repeated clauses J on two more selectors compiles to 1,024 gates. A refutation attached only to the actual G child forces the root false before any commutator instruction or rank envelope is constructed. This addresses the behavior after source preprocessing; the frozen instruction-stream rank calculation still concerns that original stream.

## Shared interface of two CNF children

A second proof rule verifies an AND node of two CNF subtrees directly. The checker obtains the two original child clause lists and sorts the intersection of their variable supports. For every assignment to these s shared variables, the certificate names a child and supplies a signed-bijection DAG proving that original child unsatisfiable under exactly those pins. Each joint model restricts to one such assignment, so this proves the parent constantly false. Conversely, if a pinning admits models on both sides, their private variables are disjoint and their shared bits agree; projecting and merging their witnesses supplies a model of this subtree. It need not satisfy enclosing clauses. The empty interface has one case.

The checker enumerates 2^s cases, polynomial overhead per case in the source length and polynomial replay cost in each explicit local proof. The case list and individual proofs can be exponential. No search for a signed permutation is performed by verification. The checker demonstrates the two-clause pair forcing z against the two-clause pair forcing its negation, with both children individually satisfiable. Their joint refutation compiles the original root to the identity before gate expansion. Reordered pins, incorrect child identities, missing cases and false witnesses are rejected on the controls.
