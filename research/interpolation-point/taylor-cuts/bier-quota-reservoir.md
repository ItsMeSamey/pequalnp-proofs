# Many quotas with a changing reservoir

Partition items into disjoint blocks with exact quotas k_i. A feasible selection contains no forbidden subset. Specify reservoir N and outside items so every forbidden subset contains at most one reservoir item; allow unbounded all-outside constraints. For each outside set T of size t≤d respecting quota upper bounds and containing no forbidden subset, put k'_i=k_i−|T∩block_i|. Let p_i count reservoir items of block i that can each be added to T without completing a forbidden subset. Require in each block
p_i−k'_i ≥ min(d−t,k'_i).
This can be checked in n^{O(d)} times polynomial input overhead. With precisely T outside, ANY choice of k'_i available reservoir items in each block is feasible.

Over every field all degree-d evaluation rows are spanned by n^{O(d)} actual feasible solutions. For each T choose a reference reservoir completion and enumerate completions at total distance at most d−t (each swap stays in one block). This is one combined perturbation budget across all blocks. Row reduction or direct evaluation yields witnesses.

For a polynomial vanishing on this list, process its outside monomials x_T by increasing size as in bier-reservoir-span.md. Discard infeasible T by heredity or quota bounds. In the coefficient of degree ≤r=d−t discard blocked inside variables and monomials containing more than k'_i reservoir variables in any block: these vanish on ALL feasible supersets of T. The surviving homogeneous block degrees j_i satisfy j_i≤min(k'_i,r), hence p_i≥2j_i, with Σj_i≤r. The integral Bier basis at level j_i converts each block factor to ballot x_{R_i} times binom(|X_i|−|R_i|,j_i−|R_i|). On a completion containing T, |X_i|=k'_i−q_i, where q_i counts additional outside vertices of block i. Newton-expand each binomial in binom(q_i,h_i). These are elementary symmetric sums on disjoint groups of additional outside variables, and Σ h_i≤Σ(j_i−|R_i|), preserving total degree.

The terms with no additional outside choices combine to a linear combination of products of ballot monomials. This combination vanishes on the radius-r sampled completions with precisely T outside: earlier lower-support terms were removed by identities on every feasible selection. It vanishes throughout this product slice, since from any farther point r+1 independent replacements toward the reference can be chosen across blocks and the alternating sum on that cube vanishes. For each block, ballot monomials through min(r,k'_i) are independent on its k'_i slice, using the lower-half basis or the triangular upper-half complement argument of bier-reservoir-span.md. The tensor products are independent too. All aggregate constant terms for each tuple (R_i) are therefore zero. Only groups for strict supersets T remain. Finite induction through d proves the claim.

In the one-hot case, untouched blocks need two remaining reservoir options for t<d and only one for t=d. No option need be permanently safe. For example, take d+2 reservoir choices in each block, with each outside choice able to block at most one reservoir option of each other block; outside choices can have arbitrary further mutual exclusions. All reservoir options can be blocked somewhere in the input, yet the promise holds. The feasibility constraints alone allow a reservoir-only solution, while a specified low-degree observer need not be nonzero there. General SAT does not automatically have such a reservoir. Integral layer basis: Plaza–Xiang, Theorem 8, https://arxiv.org/abs/1612.08124 .
