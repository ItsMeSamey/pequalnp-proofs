# Independent audit of the vector-residue recursion

Let n denote the number of matching pairs and j the current dimension over GF(3). Start with any base perfect matching, constructed by an ordinary bipartite matching algorithm. On a local subproblem without a perfect matching, return infeasible. Each nonbase arc gain subtracts its tail's base-edge label. The desired full label is reduced by the entire base matching's label.

Choose an integer L≥1 and s such that (3^j−1)2^{−s}<1. Greedily construct disjoint ordered bases of cycle gains. Within a basis, search for a cycle of at most L pairs with gain outside its present span, excluding all vertices used by earlier cycles, including this partial basis. This can be done by shortest paths in the quotient-group lift over every start, minimizing over all nonzero returns. A minimum-length nonzero return has a simple projected cycle, since decomposing a closed walk with nonzero quotient gain must yield a nonzero cycle. A found gain increases span dimension by one.

Upon completing s bases, flip a subset of the selected cycles. To prove that any target is reachable, choose each independently with probability one half. For a nontrivial Fourier character the expectation has magnitude at most 1/2 per complete basis: some basis element evaluates nontrivially, and the magnitude of (1+ω)/2 is one half. The total error in scaled Fourier inversion is bounded by (3^j−1)2^{−s}, strictly below the trivial-character contribution 1. Thus every target occurs. Deterministic subset-sum with predecessors over GF(3)^j returns disjoint original cycles realizing it.

If construction stalls, there were fewer than js selected cycles. Delete their at most jsL vertices temporarily and choose a nonzero functional λ annihilating the stalled partial span. The remaining digraph has no cycle of length ≤L with nonzero λ-gain, since such a cycle would have qualified at the stalled step. The three-sheet split-cover symmetric-multicut argument is applied only to λ, so its cover has at most 6n nodes independently of j. Add its O(nH/L) transversal to the selected vertices, where H=log(2n)loglog(4n), adjusting constants for small n. Outside this union P, every strongly connected component is λ-conservative. A valid P of size O(j²L+nH/L) can alternatively be found by growing-cardinality subset enumeration and testing SCC potentials with this fixed λ.

Enumerate boundary incidences on P and propagate path endpoints along the topologically ordered component DAG. In a component U, let A be heads of external arrivals and B be tails of external departures, including guessed crossing arcs. Reject repeated arrivals or repeated departures, or unequal cardinalities. A vertex in A∩B already has both its incidences filled. Inside U form the bipartite graph on left vertices U minus B and right vertices U minus A. Use every original internal gain arc whose endpoints remain and add an identity edge of weight zero for each available common pair. The identity represents leaving that pair at base. A perfect matching on this local graph supplies all internal paths and cycles, allowing the permutation of path endpoints to be decided locally. Parallel nonbase loops remain genuine labelled choices. Each local matching has the identical λ-component of gain, namely the sum of potentials on B minus their sum on A, by telescoping against the two shore sets.

Choose coordinates (λ,π) giving a linear isomorphism to GF(3)×GF(3)^{j−1}. Invoke the rank j−1 matching procedure on the local graph with the π-projected edge weights for each attainable candidate target under consideration. This recursive instance returns a genuine local matching, which maps to original arc IDs or zero-gain identities. Its fixed λ-component reconstructs the full gain. Intercomponent transitions can therefore retain one predecessor per pending endpoint set and full gain. Combining local matchings and enumerated boundary arcs leaves all original ports either at base or in a directed cycle packing. There is no loss of internal nonzero cycles and no assumption that path identity is fixed. A rank-zero instance is ordinary bipartite matching.

Use L≈√(nH)/j, rounded up. In the range j≤√(nH), the number of portals at rank j is O(j√(nH)). Candidate subset tests and portal routing cost n^{O(|P|+1)} times a factor polynomial in the group order and explicit input size **if routing enumerates endpoints first**. For every chosen directed endpoint pair, precompute its set of edge gains and one representative edge per gain. Independently convolve these sets across chosen portal or crossing arcs, counting any internal portal incidence pair only once. Each chosen arc consumes its own distinct matching ports, so choosing labels introduces no conflicts. Convolution needs 3^{O(j)} time per set and recovers edge IDs. The number of possible endpoint pairs is n² regardless of group size; thus there is no 3^{j|P|} multiplicative enumeration cost. Recursive queries for local labels are alternatives called sequentially; the work bound multiplies per level and adds per-level exponents. Along a branch recursive shore sizes never exceed original n. The resulting time, after preprocessing/deduplicating explicit edges, is exp(O(b²√(nH)log(2n)+poly(b))) with the accumulated group-order exponents O(b²) when using the stated group DP. In particular b=o(n^{1/4}/((log n)^{3/4}(loglog n)^{1/4})) yields 2^{o(n)}. Without endpoint-first batching the valid simpler bound has log n+b in place of log n. Neither estimate is uniform subexponential for unrestricted b.

## Sharper Fourier estimate

Use s=ceil(log₂(4j)) bases. For a character χ and a basis B_i write w_i(χ) for the number of its nonzero evaluations on that basis. Hölder's inequality bounds the sum over all characters of the magnitude of their characteristic functions by

    Σχ ∏_i 2^(−w_i(χ)) ≤ ∏_i (Σχ 2^(−s w_i(χ)))^(1/s)
                         = (1+2·2^(−s))^j < 2.

The equality uses that character coordinates in each basis run over the full ternary cube. Removing the trivial character gives total error below one. This is the prime-three Fourier estimate in the additive-bases theorem of [Alon, Linial and Meshulam](https://doi.org/10.1016/0097-3165(91)90045-I). The elementary argument above supplies the explicit threshold.

Replace the j²L term by O(j log(2j)L), choose L≈√(nH/(j log(2j))), and sum the portal widths over j≤b. With endpoint-first gain convolution the time exponent is O(√(nH) log(2n) b^{3/2}√log(2b)+b²) in the indicated growing-rank regime. A sufficient condition for subexponential time is b³log(2b)=o(n/(H log²(2n))). For instance b=o(n^{1/3}/((log n)^{4/3}(loglog n)^{1/3})) suffices.
