# Certificates shared across signed CNF restrictions

RestrictionCache.query(n,rows,pins) accepts one-based signed literals and returns an original-coordinate witness bitmask or None, together with its canonical residual key. Pins use original positive coordinate numbers. After applying pins, tautological clauses and duplicate literals or clauses disappear. A residual with an empty clause uses one distinguished key. Remaining active variables are renamed and independently complemented to attain the lexicographically least sorted CNF. Thus residuals related by any signed permutation have identical keys, regardless of clause order, inactive variables, or the number of declared coordinates.

SAT cache entries store one witness in key coordinates. The inverse signed renaming maps it to the calling coordinates; variables that disappear receive arbitrary zero values unless pinned. For UNSAT, the empty-clause axiom closes a leaf. Every other node stores its splitting variable and both child keys, each accompanied by an explicit signed bijection. The query certificate also stores its root bijection. The checker recomputes the root from the original formula and pins and verifies both children before accepting. Every cofactor removes the split variable, so a checked edge strictly decreases active-variable count. The checker validates each advertised bijection against the active coordinates, applies it, sorts the clauses and compares the result with the claimed node. It visits each reachable node once and uses time polynomial in input plus certificate length. It never searches for a renaming or checks that any node is globally lexicographically minimal. The certificates concern satisfiability, not model counts.

For K distinct nodes and maximum residual encoding size L bits, storing keys once and representing child references by node numbers takes O(K(L+n log(n+1)+log K)) bits, plus at most the total active-variable count in SAT witness bits. The Python reference uses full key tuples for child references; since outdegree is at most two, stored key data still costs O(K(L+n log(n+1))) bits up to Python object overhead. A key with d active variables costs up to 2^d d! trial renamings, each polynomial in residual length. This intentionally simple exact canonicalizer restricts practical use to small residuals. DAG sharing has no guaranteed compression ratio. A single k-variable query visits at most 2^{k+1}−1 decision-tree positions before sharing.

The independent brute-force checker tests 100 random restricted CNFs, an unsatisfiable cube shared across renamings with inactive variables, invalid permutations, flipped signs on both root and child labels, and a missing proof root. It also disables canonicalization and reruns the verifier. See cnf_restriction_cache.py and check_cnf_restriction_cache.py.
