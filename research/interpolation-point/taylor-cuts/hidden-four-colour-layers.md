# Finding a line layer for arbitrary two-dimensional block projections

Fix a decomposition of the span of the input normal planes into r two-dimensional binary row blocks. A leftover one-dimensional block can be included whole. No row block needs to be an input plane. The target layer W consists of a line in each ordinary row block and the full space of each of a supplied set S of deleted row constraints. Its dimension in the even-dimensional case is r+|S|. The following test decides existence exactly for the selected decomposition and S.

Frame each input plane P_e by a map from a two-dimensional column space; its injectivity follows from its rank two. For each row i let A_ie be the projection of this frame. Meeting P_e nontrivially is equivalent to choosing one nonzero column vector whose projection lies in each chosen row line. Identify nonzero binary two-vectors with their three projective directions. A zero block imposes no condition. Ignore blocks on fully included rows. For all other blocks:

* An invertible A_ie requires that its permutation of the column label equal the row label.
* A rank-one A_ie requires either that the column label be its kernel line or that the row label be its image line.

For the invertible-block subgraph transport the three root labels along a spanning forest. Delete any root label inconsistent with a chord. Empty allowed domains reject. With only invertible or zero blocks, this is precisely the common-fixed-point test for component holonomies. The subgroup may be generated by one nonidentity transposition. Two different transpositions already exclude all three root labels.

Transport each rank-one disjunction to the root variables of the relevant components. Introduce one Boolean atom per possible root label. Use binary negative clauses for mutual exclusion, negative units for forbidden labels, and one positive two-literal clause for each rank-one disjunction. Solve by ordinary 2-SAT. A satisfying assignment can be completed to exactly one root label per component: for a component with no true atom, choose any allowed label. This preserves every positive clause and every exclusion clause. Conversely every valid layer and its witnessing column choices satisfy these constraints. This gives polynomial-time exact recognition for the fixed block coordinates and set S, including arbitrary rank-one blocks. It does not optimize over changes of ambient coordinates or over S.

For each evaluation of the normal forms in W, a forbidden flat whose normal plane is met by W either misses the affine fiber or has residual codimension at most one on that fiber. An entire forbidden fiber is rejected. To avoid a surviving hyperplane one imposes its opposite affine equation. Gaussian elimination on the assignment fiber counts all extensions, including degrees of freedom outside the span of the normals, and recovers a witness on a nonempty accepted fiber. Summation over all 2^dim(W) evaluations counts each original assignment once. This places no restriction on the original affine offsets or their mutual compatibility.

For a strict invertible-block example take three coordinate planes and three further planes with vectors (v,v,0), (0,v,v), and (Tv,0,v), respectively, where T exchanges the two binary coordinates. All six planes are pairwise disjoint apart from zero. The triangular cycle of block transports has product T, fixing the diagonal line. Choosing that line on all three blocks works and its dimension three is minimum because it must meet three summands independently. The last three planes together have rank five: the kernel of the map adding their vectors is isomorphic to the one-dimensional fixed space of T. In a doubled binary representation every collection of planes would have even total rank. Thus this layer does not require a doubled graphic or even doubled binary representation. A greedy plane-basis search presented with these last three planes first encounters rank increment one; that is an obstruction to a doubled representation, not to this layer.
