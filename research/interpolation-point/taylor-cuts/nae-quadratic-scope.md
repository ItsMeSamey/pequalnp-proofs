# Exact quadratic classification and a density obstruction

For all-ternary signed NAE3, the cycle-space phase q is quadratic with q(0)=0 and alternating polar B. Its negative locus is sum-free iff q is linear or q is a split rank-two quadratic vanishing on the radical (equivalently q=u v with two independent homogeneous linear forms). Proof: a bad triple is a pair with q(x)=q(y)=1 and B(x,y)=1. If B has rank at least four, take one symplectic pair and an orthogonal nondegenerate plane. The latter contains a vector w with q(w)=1; add w independently to either member of the pair as necessary to make both values one while preserving their pairing. When rank is two and some w in the radical has q(w)=1, the same modification works. In the zero-on-radical rank-two quotient, the anisotropic plane has all three nonzero vectors negative, while the split plane has exactly one and passes. Linear functions have a sum-free negative coset. This yields deterministic membership by ordinary binary Gaussian elimination and a two-dimensional check, without degree-six ANF expansion.

For any graph with m edges, v vertices and c connected components, write L for its Laplacian modulo two. The radical of the cycle inner-product restricted to the cycle space is the intersection of the cycle and cut spaces. Its dimension is (v−c)−rank L: use the incidence transpose to map vertex potentials into cuts, quotienting by component constants. Hence the polar rank is m−2v+2c+rank L. For the all-ternary incidence graph with n variables and t ternary constraints, L in variable-gate order has diagonal blocks D and I_t, with binary incidence matrix A off-diagonal. Block elimination gives rank L=t+rank(D+AAᵀ). Diagonal D cancels the diagonal of AAᵀ; the remaining entries are parities of shared clauses between distinct variables. Thus

    rank B = 2(t−n+c) + rank_GF2(offdiag(AAᵀ)).

Isolated vertices may be kept consistently in n,c or omitted. In particular every connected all-ternary instance with t≥n+1 has polar rank at least four, so no literal signing on that incidence pattern passes. This is an exact obstruction to this specific positivity recognition, not to satisfiability, arbitrary greedy orders, or signed NAE algorithms.

At t=n for a connected simple ternary hypergraph (no duplicate unsigned scopes), a passing polar forces every variable pair to have even codegree. The link of each variable is then a nonempty simple Eulerian graph with at least three edges. Its average size over variables is exactly 3t/n=3, so each link is a triangle. From one link triangle derive all four triples on its central variable and the three neighbors; all four variables are saturated. Thus connectedness forces the tetrahedron boundary, which is genuinely attainable. On lexicographically ordered scopes (012),(013),(023),(123), negate variable 1 in the first clause and variable 0 in the second; this signing passes and has eight satisfying assignments (direct exhaustive check).
