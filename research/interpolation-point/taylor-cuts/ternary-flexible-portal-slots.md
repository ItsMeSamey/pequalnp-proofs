# Recognizing all scalar targets before computing component profiles

Fix a candidate exceptional port pattern in the near-barrier reduction. Its feasible local completions on disjoint component blocks give compulsory independent gain sets, together with gain sets indexed by the edges of a bipartite assignment graph of ordinary odd blocks versus available splitter vertices. Choosing an assignment selects one independent gain set per chosen edge. Parallel gains on a fixed chosen port pair are additional independent compulsory slots. Empty compulsory sets invalidate the pattern. An empty optional set omits that assignment edge.

Decide emptiness and whether each remaining set is a singleton using deterministic polynomial matching-incidence span over F3 (Lovász, as cited in intrinsic-matching-syndrome-rank.md), with ordinary matching and edge-deletion self-reduction for concrete witnesses. A one-hole assignment slot may range over several neighbors u: union the possible gains of the ordinary cut edge plus a completion on H−u, testing against the same reference gain. A slot is flexible when at least two different concrete gains occur. None of these tests asks for a prescribed ternary gain. Find a perfect assignment maximizing the number of selected flexible slots, using unit scores plus the number of compulsory flexible sets.

If this maximum is at least two, the instance for this pattern admits all three targets. Start with one original witness in every slot of a maximizing assignment. For each of two independently flexible slots take an alternative of different gain; two two-element subsets of F3 sum to F3. Try the four toggles to obtain the requested original witness. Recognition and reconstruction for this case are polynomial in the pattern input, regardless of local component sizes. Enumerating exceptional patterns, if needed, remains charged separately.

Otherwise each assignment has at most one flexible factor. For the all-rigid case solve the rigid-only labelled bipartite assignment after accumulating compulsory singleton gains. For each candidate unique flexible slot, force it if optional by removing its row and column, exclude other optional flexible edges, and require every other compulsory slot rigid. Obtain the attainable rigid complement gains with at most three scalar bipartite matching calls. Empty complement discards the candidate. A varying complement together with the flexible slot covers every target as before. A singleton complement leaves exactly one prescribed-gain question on the one flexible factor (possibly a union over its boundary neighbor options). Enumerating all cases and retaining original-edge witnesses is exact. The last local problem can still be an unrestricted ordinary matching target. The all-rigid case requires all compulsory slots rigid. No polynomial clock is claimed for the full fallback.

For a fixed assignment over F3^b, collect for each slot a baseline gain and actual differences from it spanning the slot's variation; successive avoidance of the current affine span returns such concrete originals. Intersect the partition matroid on tokens (one concrete difference per slot) with the union of s copies of their represented vector matroid. A common independent set of size sb partitions into s bases, with toggles independently realizable. Taking s=ceil(log2(4b)) gives all targets by ternary-additive-bases-refinement.md; a 3^b-state subset DP reconstructs requested choices. This is a sufficient certificate using the realized tokens. Failure to find one on the chosen token lists need not preclude other witnesses or other assignments.
