# Two-label controls

If all selected vertices must have EVEN induced degree, two binary parity labels per vertex permit deterministic polynomial-time search. The zero target has the empty witness. Given a nonzero target t, a vertex labeled t alone works. Otherwise let p,q be the other nonzero labels, whose sum is t. A witness needs an odd number of each. Absent either class, this is impossible. A nonadjacent p,q pair is an independent witness. Otherwise P,Q form a complete bipartite join. Remove all P–Q edges. If a remaining component contains both classes, choose a shortest path over all P,Q endpoint pairs therein. Its interior is neutral and it has no chords; restoring the endpoint edge gives an induced cycle with syndrome t. Conversely, when there is no such component, take the union of components containing P. Its only crossing edges are the complete P–Q edges. Any induced all-even subgraph crosses every cut evenly, but the required class counts give an odd product. This certifies impossibility.

Nonzero marks change matters. In an all-marked four-vertex claw label two leaves independently and require both. Its unique solution is the entire claw; paths and unions of disjoint paths are insufficient. Arbitrary h checks also correspond to h mandatory selected vertices: add one independent vertex per row with neighborhood its support and prescribed degree equal to the target bit. Toggle each old vertex's mark by the parity of its newly pinned neighbors.

For graph G with marks a, let G' have off-diagonal entries G_ij+a_i a_j and zero diagonal. On any feasible S, handshake forces a(S)=0. Hence for selected i, (G'1_S)_i=(G1_S)_i+a_i a(S)+a_i=0. Conversely, all-even S in G' with a(S)=0 meets the original marks in G. Thus h marked checks become h+1 all-even checks with appended row a and zero target. The reverse also works: complement the off-diagonals on the marking set and then drop the appended row, because handshake enforces it. Changing the syndrome basis can create a target-zero coordinate for every nonzero target in dimension ≥2. Consequently general marked h=2 is as expressive as all-even h=3; the two-label all-even algorithm does not address that third row.
