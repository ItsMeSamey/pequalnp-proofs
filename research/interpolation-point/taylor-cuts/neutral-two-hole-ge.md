# Canonical two-hole tables in neutral graphs

Fix an original neutral even graph G with a supplied perfect matching M. A node (K,a) consists of an induced union K of M-pairs and a first hole a in K. Its output lists all reachable gains and matching witnesses on K minus {a,v}, for every second hole v distinct from a. The matching on K is always M restricted to K. Neutrality for every reached K follows by replacing the restriction in the original M.

Put p=mate(a). The graph K−a has deficiency one. In its Gallai–Edmonds decomposition, C has a perfect matching, each D component F is factor-critical, and there are |A|+1 D components. A near-perfect matching exposing v requires v in D. It assigns all A vertices to distinct components other than the component of v. Keep the reference matching on C since all changes there have zero gain by replacement in M. The reference matching M minus ap exposes p in component F0. Each other Fi is joined to a distinct ai in A at endpoint ei. Set e0=p.

For every endpoint x of F needed by a macro edge or second-hole query, let T_F(x) list the realizable perfect matching gains and witnesses of F−x. For x=e the table is the singleton reference gain. Otherwise, enumerate every edge ey within F with y distinct from x. Add its gain to each entry returned for second hole y in the single child table (F−e,x). This is exhaustive by examining the edge covering e in F−x. The child base is exactly M restricted to F−e and the vertex count decreases by at least two.

Treat each component as a macro vertex. For ai assigned in the reference to Fi, each edge ai x into Fj and an entry of T_Fj(x) determines an arc i→j; its gain is the new edge and internal matching total minus the analogous reference macro total of ai. Vertex 0 has no outgoing arcs. A directed simple cycle performs simultaneous reassignment on distinct D components. The result extends to a perfect matching of the original graph with edge ap, so its gain is zero. Every closed walk also has zero gain.

For v in Fd, compute path gains d→0 using the ordinary product with the ternary label group. Delete repeated internal subwalks at zero cost to recover a simple path, retaining source edge IDs. When d=0 use the empty path. Every path yields a feasible reassignment and every reassignment is one such path plus disjoint zero-gain cycles. To the reference near-perfect matching gain add the path gain, then replace the reference exposed-component contribution T_F0(p) with any element of T_Fd(v). This yields precisely the requested gain table.

The cache key is (original induced vertex set K, a). It is independent of the requested gain, second hole, specific macro edge, and witness. Each node has polynomially many child keys and polynomial work times 3^O(b), giving input_size^O(h+1) times 3^O(b) at recursion depth h.

Canonical caching alone can require exponentially many sets. On the even clique K_(2q) with any fixed base and all-zero labels, deleting a leaves one factor-critical component with reference exposure p. The only child graph removes the base pair of a, and every remaining vertex is a queried first hole in that graph. Therefore any subset of the remaining q−1 pairs can be removed in any order. At least 2^(q−1)−1 distinct nonempty graphs occur. Detecting vertex-potential labels separately would solve this fixture immediately. The example is a lower bound on the unmodified recurrence only.
