# A signed-integer marginal certificate for the inconsistent prism

Use the two directed n-cycles and their top-to-bottom matching described in [the prism note](/workspace/scratch/compression/decision-cache-mod3.md). At each vertex v, combine its forbidden-corner clauses on the common five-bit scope into their single relation R_v of legal local assignments. Its members use valid trit codes, a binary matching value and obey the prescribed charge q_v modulo three. Any restrictions on matching bits remove the corresponding disallowed tuples. Treating the relation as a table takes constant work per vertex. Tables for individual corner clauses with only singleton consistency are a different relaxation.

Use one signed integer mass u(v,a) for each a∈R_v. Require sum_a u(v,a)=1 at every vertex. For each oriented edge e and each allowed label k require its mass in the source table at label k minus its mass in the target table at label k to be zero. Eliminating explicit edge variables from the usual singleton marginal equations gives this form. This is a CSP affine integer programming relaxation with no positivity constraints. [Brakensiek, Guruswami, Wrochna and Živný](https://doi.org/10.1137/20M1312745)

**Certificate.** Write the system Au=b with the displayed signs. Give each normalization row multiplier q_v, and each (e,k) marginal row multiplier −k, all modulo three. The coefficient at column (v,a) is q_v minus the outgoing sum plus the incoming sum of its local edge labels, hence zero. The right-hand side is Σ_v q_v. When the latter is nonzero, scale the multipliers by its inverse. This gives cᵀA=0 and cᵀb=1 in F₃. Any signed integer solution would reduce to a solution over F₃, so the certificate excludes every such solution. It works at the unrestricted root and after arbitrary matching-bit pins, without conditioning first. Equivalently one can use just the value-one singleton marginals of each Boolean code bit: k=low+2·high, so multipliers −1 and −2 recover the same identity. Edge-label marginals are still sufficient for other encodings without this coordinatewise decomposition.

**Control and scope.** Setting just one vertical matching flow to one and every other edge flow to zero induces opposite charges at its endpoints. Unit mass on the induced local tuple at each vertex is an integer feasible witness, precluding any F₃ row contradiction. Over any finite abelian group the same cancellation applies directly to group-valued integer linear combinations of local labels. A nonzero total charge contradicts feasibility. For a composite group, reducing only modulo a prime need not see the obstruction (for example charge two in Z/4 maps to zero in Z/2); use the group itself or an appropriate detecting cyclic component. This argument identifies a stronger inference rule than labeled decision caching and GF₂ row reduction on this family.

The [checker](/workspace/scratch/compression/check_affine_cache_aip.py) builds the actual integer matrices and returns normalized F₃ row multipliers. The run replayed 236 certificates for prism lengths 3, 4 and 5, both trit-label and Boolean-singleton marginals, and charges one and two. It also verified six feasible integer controls. Its final output gives the named nonzero multipliers for a reproducible unrestricted triangle-prism example.
