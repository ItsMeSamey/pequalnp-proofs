# A border solver for mixed-degree Boolean equations

Represent every explicit Boolean ANF equation by its squarefree monomials, including the empty support for a constant. All equations must vanish over F₂. Gaussian-eliminate the coefficient rows using descending graded lex order (larger mask first within a degree). Each pivot support m gives a rule replacing x_m by strictly smaller monomials, valid on every model. A constant pivot proves inconsistency. Linear, quadratic and higher pivots may all occur together. Storage for Gaussian elimination uses only the explicitly occurring monomials.

Call a subset standard when it contains no pivot support. The standard sets form a downward-closed family, so an increasing-index extension search lists them with polynomial delay. Let F be their total count, including the empty set. The solver stores only standard monomials and the at most nF distinct border monomials obtained by multiplying each by one variable with idempotent exponents.

Process nonstandard border supports z in increasing graded lex order. Write z=c union {i} with c standard. Any pivot support m contained in z contains i, hence q=z minus m is standard. Multiply its already known unit vector by each term x_a on the right of the pivot equation. Introduce the variables of a one by one. At each multiplication expand each current standard monomial times the next variable using its stored border value. XOR the resulting vectors over all terms. This computes an expression for x_z on every model.

For termination compare first in the ordinary graded lex order before reducing powers. Since |a|≤|m|, every proper prefix has degree less than |z| after multiplication by q. For the last multiplication, multiplying the inequality x_a<x_m by x_q gives x_a x_q<x_z. At every preceding step each generated standard monomial is at most the corresponding ordinary prefix product, by induction on processed border entries. Multiplication preserves this ordinary monomial order. Replacing repeated variables by one copy only decreases degree. Therefore every nonstandard lookup is strictly earlier than z, including when a intersects q. A constant RHS term needs no lookup. Identically zero substitutions simply give the zero vector.

Build the variable multiplication tables. Every genuine Boolean assignment satisfying the equations evaluates the standard monomials to a nonzero common left eigenvector, with the assignment as joint eigenvalue. Split the current subspace into its zero and one eigenspaces for each variable successively; at each level the total dimension is at most F. Verify the resulting assignments directly in all input equations. This returns their exact count and one witness in time polynomial in n, F, and explicit input length. Commutativity of the computed tables and Gröbner confluence are unnecessary for this candidate-and-check argument. A large standard family still permits exponential time.

The direct signed 3-CNF adapter expands each clause's falsity indicator into at most eight monomials. It discards tautological clauses and merges repeated identical literals without introducing auxiliary variables. For example, if each variable triple appears as a distinct three-variable clause support, all cubic columns are pivots: one row for each triple has just that cubic monomial as its highest-degree part. Then F≤1+n+binom(n,2), for arbitrary literal signs and additional width-three clauses. This is a structural sufficient condition, not a bound for unrestricted 3-SAT.
