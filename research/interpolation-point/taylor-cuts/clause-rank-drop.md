# Counting signed CNF with XOR constraints by common rank reduction

Write each clause's falsification as a consistent system of linear equations on the Gaussian seed for the source XORs. Discard impossible falsifications. A rank-zero consistent system rules out the entire seed space. Let k be the minimum codimension of a direction subspace W on which every surviving system's normal map has rank at most one.

When a system has restricted rank r at least two, intersect the current direction space with its kernel. An optimal W loses at most one dimension under this intersection, so the remaining optimum drops by at least r−1. The chosen kernel costs r dimensions. Summing gives total codimension c at most 2k. Enumerate the resulting cosets. Within a coset each surviving forbidden system is impossible, identically true, or a single affine equation. Disallowing all such events therefore gives another Gaussian system, from which one gets its count and a lifted witness. The disjoint cosets give exact counts in O(4^k poly(input)) time and polynomial space. This uses the literal equations directly at arbitrary width. Polynomial work per coset includes projecting all literal equations and reducing their signed right-hand sides. The optional cap on c is a search budget.

For clauses containing h common positive variables and one private variable per clause, with at least two private variables, each event has rank h+1, giving k≥h. Killing the h common directions attains equality. The greedy procedure uses h+1 bits. In particular h logarithmic permits polynomial computation even at growing clause width.

## Affine prepass

Group forbidden systems with identical canonical homogeneous row basis after applying the current global XOR chart. In each group of rank r let P be the explicitly listed forbidden syndromes. If fewer than half the possible syndromes occur, the allowed complement spans the whole space affinely. Otherwise its full truth table has size at most twice the number of listed syndromes. Enumerate the complement and extract its affine hull by Gaussian elimination. Lift any new equations to the input coordinates and repeat. Empty complements imply UNSAT. When every residual forbidden event is inconsistent the remaining Gaussian solution space is exactly the solution set. OPEN retains only sound affine information. At most n successful passes and one terminal pass occur, each scanning at most 2m syndromes and performing polynomially many bit operations. This charges even the work of finding which coefficients or syndromes matter.

The implementations are clause_rank_drop.py and semantic_flat_prepass.py. Sixty deterministic small signed instances with XORs passed direct truth-table comparisons of exact counts, witnesses, and prepass implications. Both methods are optional stand-alone entry points.

## Optimal hyperplane search

Pass `optimal=True` to compute the minimum codimension. On the current primal kernel, choose any surviving normal space of restricted rank r≥2. A feasible extension of the current pinned dual space must kill a hyperplane of these r independent forms, since their image at the end has rank ≤1. Enumerate all 2^r−1 hyperplanes (one for each nonzero binary linear functional in basis coordinates). Each branch imposes r−1 independent forms, and the budget decreases by exactly r−1. Prune before enumerating if the budget is too small. Conversely, every successful branch supplies an actual kernel with only rank-one residual events. This generalizes the three-line rank-two search in affine-nae-grouping.md.

As 2^r−1≤3^(r−1), the decision tree has at most 3^b leaves for budget b, depth at most b, and polynomial per-node and per-child work. Iterative deepening first succeeds at b=k, with O*(3^k) search and polynomial stack space. The shared backend then counts on 2^k disjoint cosets. The cap in optimal mode certifies k exceeds the cap when no kernel is found. Structurally immediate contradictions return the exact zero count without running parameter search. The default greedy strategy remains available. check_clause_rank_optimal.py compares counts, witnesses, and codimensions with exhaustive subspaces on 33 signed fixtures.
