# Vertex potentials and affine owner reports for labelled perfect matching

Input is a loopless undirected multigraph with distinct edge IDs, additive labels in an explicit product of cyclic groups and a target t. Suppose S is a vertex set on whose complement some vertex potentials satisfy ℓ_uv=p_u+p_v on all internal edges. Set the potentials on S itself to zero. The residual g_uv=ℓ_uv−p_u−p_v vanishes off S, and a perfect matching has original target t exactly when its residual sum equals t−Σ_v p_v, since each vertex is covered once. Alternatively, choose S to be every vertex with all potentials zero. This always provides a valid starting point for ownership.

For a fixed S propagate p_v=ε_v x+c_v along a spanning tree of each component of G−S, where ε_v∈{+1,−1}. An edge between opposite signs checks the offsets; each same-sign edge prescribes a value of 2x. Distinct prescriptions must agree. In a cyclic coordinate modulo q, the equation 2x=a is solvable precisely when gcd(2,q) divides a. Choose any solution, or x=0 when unconstrained. This handles nonbipartite components, even moduli, isolated vertices and conflicting parallel labels. Over F3 the equations also admit ordinary Gaussian elimination. Enumerating all S of size at most k takes n^O(k) times polynomial work.

**Owner filtering.** Assign each nonzero residual edge to exactly one endpoint in S. The local report of a vertex in S on an incident edge is the residual label if it owns that edge, otherwise zero. The sum of reports induced by a perfect matching is its residual sum. Fixing all reports filters each incident edge at both modulator endpoints: keep it iff each local report matches the prescribed value. One ordinary maximum-cardinality matching on the resulting graph decides whether this report tuple is realizable. Collapse parallel edges only after filtering and store an allowed original edge ID for each endpoint pair. Recovery checks every original vertex and the unshifted label sum. This is a decision and witness algorithm; counting the collapsed matchings would lose multiplicity.

In any finite product of cyclic groups one may enumerate the possible report alphabets for all owners except the largest. Its report is uniquely forced by the target and the remaining reports. For known S of size at most one this takes at most one matching call. For fixed k recognition and matching remain polynomial even if the group size grows. No modulator within budget yields UNKNOWN in this mode, apart from immediate odd-order impossibility.

**Ternary affine owner rank.** In F3^b compute each exact local alphabet E_v by scanning all incident edges. Include zero only when some incident edge locally reports zero; these alphabets disregard matching extendibility. An isolated vertex excludes a perfect matching. For c_v∈E_v let V_v=span{e−c_v:e∈E_v}. Write v's report in independent basis coordinates of V_v. The target imposes one vector equation on their joint coordinates: sum of these vectors equals the shifted target minus Σ_v c_v. Gaussian elimination either detects inconsistency, ruling out every perfect matching, or returns an affine space of dimension

    κ = Σ_v dim(V_v) − dim(Σ_v V_v).

The independent local coordinates parameterize joint affine reports injectively. Enumerate at most 3^κ points of the solved space, discard points with some report outside E_v, and make one ordinary matching query per remaining tuple. Thus a supplied ownership and potentials yield deterministic O*(3^κ) time without a cardinality bound on the owner set or rank bound on the target group. The linear consistency test alone does not ensure that a candidate tuple is realized by compatible edges; matching remains necessary.

The implementation's kappa_cap is a dimension cap. It considers the first valid small modulator if found and also the all-vertices/zero-potential choice. It tries increasing and decreasing ID and degree priorities for ownership and, on bipartite graphs, either shore as preferred owner. It returns UNSAT if any affine plan is inconsistent; otherwise it uses a plan of least observed κ. A cap miss is UNKNOWN. This is polynomial recognition of the stated finite menu. It does not optimize over all gauges or owners. With no small-modulator search (budget zero) the owner-rank overhead is polynomial. The native ternary_global_rows.solve options potential_budget and owner_kappa decode selected tag IDs and check the original full-support sign equations. Only if all source sign branches are resolved can absence of a matching imply source UNSAT.

For a strict example take K_(r,r), r=3k, with left vertex i, right vertex j and edge label (j mod 3)e_i. Giving all edges to the left makes the report spaces independent lines, their number and total rank r, while κ=0. Each target therefore requires at most one ordinary matching. The pattern of coordinate residues i mod 3 admits the identity matching; the zero target requires every right endpoint to lie in the same residue class and is impossible when k≥1. Small zero-residual modulators need not exist here: k disjoint 4-cycles can use rows and columns 3h,3h+1 in each block. Their alternating sums are nonzero, so at least k vertices must be deleted for a potential labeling, irrespective of gauge.

On a bipartite host, negating one shore's potentials turns the equations into oriented difference equations. Solvability is equivalent componentwise to zero signed gain on every cycle. Modulator recognition is therefore Group Feedback Vertex Set. The group-oracle theorem of Cygan, M. Pilipczuk and M. Pilipczuk gives 2^O(k log k) times polynomial recognition. Only the fixed-k exhaustive recognition is implemented. Parallel edges can be represented by private subdivided paths with the same total gain; any private deleted subdivision vertex can be replaced by deleting an original endpoint without introducing a bad surviving original cycle. FPT recognition by itself does not remove the report enumeration cost. [Primary theorem](https://arxiv.org/abs/1112.6255)

The independent checker covered 220 unrestricted matching fixtures, 170 brute-force modular potential systems, 150 owner-rank fixtures and 55 original ternary source charts. Additional controls recovered the correct parallel edge at rank 41, forced a nonowner endpoint to report zero, and decided both the SAT and UNSAT rank-18 examples with one matching call each.
