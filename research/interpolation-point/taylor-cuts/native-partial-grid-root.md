# An extra grid root in a valid initial SAT packing

Take the CNF consisting of n distinct positive unit clauses on n distinct variables. Every subdivision bit occurs on two ports. Clause endpoints are unary pins at one; variable endpoints have table (1,1), so summation over their output bit gives the neutral factor exactly.

Use three distinguished clauses with subdivision bits a,b,c. In one packet place clause-c at slot 0, clause-a at slot 1 and variable-b at slot 2. In a second place clause-b at slot 1 and variable-a at slot 3. In a third place only variable-c. All other slots in those packets are padding. The kernel numerator is c₀(T)=C(T)/C′(0) and the true gadget polynomial is the sum over a,b,c of
[
 c₀(T)^3(c/T+a/(T-1)+b/(T-2))
 (c/(T+1)+a/T+b/(T-1))(b/T+a/(T-2)).
]
At s=1 the probe is the sole unmatched pinned row. For a word to attain order one the first two rows must be matched, forcing a=b=1. But the probe reciprocal sum is then zero. Hence all words and the true contraction vanish to order at least two. At T=0 only the all-ones assignment survives and contributes one.

Take a sufficiently large dyadic size interval with fixed λ=ceil(log₂ s), where s=2n. Let B=r^a, D=B² and L=2^a be the prescribed root parameters (here a in the exponent denotes the paper's coordinate count). Choose s=D h in that interval, h≡2 mod L. Such h exist as DL=o(s). Then M=s>H and all three active packing inequalities hold. The paper handles only a fixed finite initial range by direct enumeration.

Expose the n subdivision vertices first under the conditional expectation of squared load deviations. All old ports end at distinct degree-one vertices, so each cross-component pair of ports with already equal column labels matches its other label with probability 1/B; within-component matches give a label-independent term. Thus choosing a least-used subdivision label minimizes the conditional expectation. Give each column label n/B subdivisions. Next expose old endpoints: within each column-label class a least-used old label minimizes expected collisions, because any comparison to an unexposed old endpoint has constant probability. The ordered classes finish with h ports each. By ordering the exposures round-robin within these rounds, and choosing allowed minimizing ties, one realizes any balanced prescription: reserve the six special ports all in one ordered class (i,j), then complete its quotas with other disjoint unit components. This is a deterministic implementation of the original minimizing rule; the source does not prescribe the exposure order, tie choice or within-class ordering.

Choose i,j equal in coordinates 0 and 1 and different at every other coordinate. Their unordered-pair orbit uses four copies from each oriented class per packet. Assign orientation so numerical slots 0,…,3 come from (i,j). All classes have h real slots and common padded load h+L−2. For L≥16 each has at least 12 dummies, sufficient to reserve exactly the displayed occupancies in three packets (each consumes only four slots of each class). There are at least three packets in this orbit. Fill all remaining slots class by class. Exact balanced loads, common padding, matching row/column slot identity, per-coordinate orientation, symbol balance, and the number-of-packets bound all follow by the stated construction. Thus these masks occur in a valid initial call under the authors' packing rule. The other clauses use entirely disjoint packets and independent bits; they give a polynomial factor with value one at the origin. The construction makes no assertion about a particular pre-existing implementation's tie breaking.

For any outside word every unmatched outside clause contributes at least one further root at s=1. Thus the entire CNF polynomial has strictly more roots there, counted with multiplicity, than the total count of unmatched pinned rows guarantees. This is a rational univariate divisibility result. Recovering a quotient from finite-precision values still requires allowance for divisibility of the denominator.

The exact order of the isolated gadget is two. Put z=T−1 and divide by c₀(T)^3. The order-(−2) coefficient vanishes wordwise as ab(b−a)=0. Summing order-(−1) coefficients over c gives 0, −1, −5/2, −4 for (a,b)=00,01,10,11. Thus the coefficient of z² is −(15/2)(C′(1)/C′(0))³.

## Aggregate bound for common extra grid roots

For any chosen set of active literal-one rows and arbitrary column identifications allowing the all-ones column word, let E denote the total number of dummy slots across all packets. At a fixed grid node s the order of the gcd exceeds the unmatched-row count by at most E. Indeed take the all-ones word. Each matched row survives. At each unmatched row the real reciprocal sum has derivative −∑_y 1/(s+x−y)^2<0 (a packet with a row has a column), so it can cause at most one extra root. Outside the slot interval the sum has constant strict sign. The remaining possible extra roots inject into the missing slots of their packets via x↦s+x. Sum over the 2L grid nodes to get a bound 2LE. For the paper's active packing E≤D(√(2MΔ)+L). As D≤s^0.001, Δ=ceil(s^0.9), M>s/floor(√λ), and L≤s^0.001, this is o(M). Consequently hidden common grid roots add only o(ML) degree beyond the individual unmatched counts. This bound does not apply to cancellation introduced when summing words.

## A sufficient exactness condition for the summed polynomial

Suppose every occupied packet is an interval with equal row and column shores. At a grid node s>0 every unmatched row has s+x above the occupied interval. At s<0 every unmatched row has s+x below the occupied interval. Thus each unmatched reciprocal sum over a nonempty selected set has strict sign equal to sign(s). Every matched row in a minimum-order word takes the same nonzero value c₀′(s). Consequently all words contributing at the predicted order have the same sign, equal to sign(c₀′(s)) to the number of active rows times sign(s) to the number unmatched. The all-one input attains this order. Any nonnegative rational weighted sum including that input with positive weight has exactly the predicted order even with shared column bits. At s=0 no rows are unmatched. This covers the entire positive-unit CNF polynomial with interval occupancies, since variable rows are neutral and clause rows pinned at one.
