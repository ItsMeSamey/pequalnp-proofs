# Recognizing a regular chart for all-even induced subgraphs

Given a simple labelled graph A, there is a deterministic polynomial-time test for whether an indexed local binary basis change takes its graph Lagrangian to a bipartite graph Lagrangian whose fundamental binary matroid is regular. On success it constructs the target and the indexed basis changes. Composing with locally-regular-even-chart.md decides h-bit marked all-even feasibility and recovers an original vertex set in polynomial time for each fixed h.

Bipartite-chart construction itself is prior work: arXiv:2610.28737, Theorem 1, Proposition 3 and Section VI, constructs it in O(n^4) binary operations on graph-state input. Here is the graph specialization. On each nonempty connected component take a local block diagonal matrix P preserving L={(x,Ax)}, with trace one at every two-dimensional site. Preservation is a linear system in the block entries. Cayley-Hamilton gives P²+P equal to the sitewise scalar det(P_i). A scalar D preserving this graph space commutes with A, so its entries agree across each edge. Consequently the determinant is constant. On one anchor site a trace-one block with diagonal a,1+a has determinant bc. Solve two affine systems, adding b=0 or c=0. Any solution then consists entirely of rank-one idempotents. A bipartite chart supplies such a projector by pulling back a CSS-axis projector. Conversely use the two local eigendirections as an indexed change of basis. Invariance under both P and I+P gives the product C×C^perp, since the graph space is Lagrangian. Choose an information set I of C with generator [identity B]; swap the local axes on sites outside I to obtain the bipartite graph with cross matrix B. This is a coordinate selection on the original labelled set, without site deletion. Empty inputs are immediate. An isolated site forms its own component and the same anchor calculation works.

For regularity, compare any two solutions P,Q on the same component. Put Z=P+Q. Its local blocks have trace zero, so Z² has scalar blocks det Z_i. Thus det Z_i is constant by the same argument. If it is zero, I+Z is invertible, preserves L, and (I+Z)P=Q(I+Z). If it is one, Z is invertible, preserves L, and ZP=(I+Q)Z. These identities follow by expansion and P²=P,Q²=Q. Thus this sitewise invertible transformation bijects the P-image in L onto the Q-image or Q-kernel in L. Every local line has one nonzero vector, so encoding each such vector as the binary symbol one preserves exactly the indexed codewords. The resulting classical row code is therefore unique up to duality independently on each input component. Every bipartite realization arises by this construction (choose its bipartition and undo the indicated site swaps). Changing information set changes the fundamental basis only. Regularity is invariant under matroid duality and direct sums, so testing the explicit binary matroid of one constructed chart by a polynomial regularity test decides existence of ANY regular chart. If a site permutation is allowed it only relabels the matroid and can be tracked or omitted.

For each initial graph-state word the affine offset and transported marker equations are as in locally-regular-even-chart.md. Nonzero-block support is preserved by both local basis changes and their inverses. In particular witnesses are reconstructed on the original vertex set. This is same-site equivalence; reachability by local complementation interspersed with deleting vertices is a different relation. Rejected inputs to chart recognition have no locally regular chart; that outcome need not decide the all-even problem on those inputs.

Primary constructions: https://arxiv.org/html/2610.28737v1 and https://arxiv.org/abs/2608.05688 (CSS-to-CSS local transformations). For binary matroid regularity, Seymour's decomposition theorem supplies a polynomial decision algorithm. The graph-specific affine syndrome and regular-marker dependencies are in the companion proof and research/regular-markers/README.md.
