# Whole-sector summation with the actual sparse SAT input tensors

In the sparse source reduction, put the old clause/equality network on the row side and the binary subdivision equalities on the column side. Each column equality can be written as a sum of two pure products, one pinning both copies to zero, the other pinning them to one. Each row OR tensor is the all-ones product minus the product pinning its falsifying assignment. Each copy tensor is the sum of two point masses, and a free unary row is a single constant product. These are exact integer identities on the original zero/one entries. Thus one selector per old vertex suffices, and each selector has at most two values. Its scalar sign or coefficient is included exactly once.

For fixed selectors the column assignment is completely pinned. At each packet compute its deformed row values h_i from W and those pinned columns. If the selected local unary row factors are a_i, summing over the row bits gives product_i [a_i(0)(1−h_i)+a_i(1)h_i]. This contracts all original mode and Walsh sectors without listing their profiles or assuming bounded occupancy excess. It requires only polynomially many operations in the deformed coefficient ring per packet and selector assignment, with no determinant division or Walsh normalization.

Given a binary tree of actual packets, let w bound the number of selectors touching packets on both sides of each edge. At a packet leaf enumerate the at most 2L different incident selectors, retaining those used elsewhere. At an internal node merge the two boundary tables with common selector values identified and sum selectors that no longer occur outside. Assign each unary selector coefficient to one incident leaf. The total bit cost for one interpolation value is polynomial in input and precision times 2^O(w+L). Table storage is exponential in the boundary width; this is not the polynomial-space guarantee of the published algorithm. A given packet ordering can be handled in the same way by a sequential DP. Generating or discovering a low-width tree must be charged separately. The algorithm is an alternative at the selected parent, so an exact answer at that parent does not require recursively constructing any children. Current implicitly specified packet tensors at deeper calls may not admit rank-two product decompositions of their canonical lifted entries; a verified decomposition is needed to apply the argument there.

At the undeformed origin, each original sparse network edge links a row vertex and a column vertex incident to the same packet leaf. For each original vertex span its incident packet leaves by its minimal subtree. A bag at each tree node consisting of all spanning vertices there is a tree decomposition of the original bipartite tensor graph. Internal sizes are at most 3w and leaf sizes at most 2L. Thus high treewidth of the original graph forces high width in this particular whole-selector algorithm when packets are small. This is an implementation bound, not a bound on other methods for summing sectors.
