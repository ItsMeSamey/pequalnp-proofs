# Exact reduction at arbitrary generalized symplectic rank

Use the affine pair-block and independent-transversal setup of affine-nae-rank-two.md. For maximum deficiency zero produce a witness there. Otherwise choose a maximizing gate subset I, set t=|I|, d=rank F_I and δ=t−d≥1. Every solution on I extends by independent representatives outside. On its attainable direction L⊂GF(2)^(2t), let 2a be the restricted symplectic rank. The restricted Fourier rank is exactly R_I=2(δ+a)≤R.

Symplectic Gaussian elimination selects a subspace L_iso⊂L of dimension d−a whose pairing is identically zero: keep the radical and one vector from each symplectic basis pair. Enumerate the 2^a cosets of this subspace in the feasible affine coset p+L. Extend L_iso once to a Lagrangian by adjoining orthogonal vectors preserving isotropy. Rado's theorem on that Lagrangian yields one independent coordinate functional per site, and local invertible 2×2 transformations give a graph of a symmetric binary matrix in those first coordinates. Removing the affine offset is carried in the second-coordinate intercept and in the parity right-hand side; no shift of the forbidden local pair is allowed. Each coset now imposes h=t−(d−a)=δ+a≤R/2 independent parity equations on the freely designated first-coordinate vector.

As in the rank-two case, write S for positions at which the first bit is zero. In each branch the exact remaining question uses an undirected graph, degree marks b_i∈GF(2), vertex labels λ_i∈GF(2)^h, and target c. Find S such that every i in S has induced degree parity b_i and the XOR of its labels is c. Empty S is allowed and all unselected vertices impose no condition. The construction of all graph data and the map back to the original seed is polynomial per branch. Thus R≤4 reduces to at most two branches with two parity labels (or the one-label case already solved), and no Galois-field or hidden Boolean assignments remain.

Conversely every such graph-state problem with h independent parity checks is exactly an affine NAE3 instance of generalized rank 2h. Form block i as (X_i,Y_i=(G X+s)_i) with symmetric zero-diagonal G the graph adjacency, choosing s_i to realize b_i. Impose the h linear checks on X with target adjusted from its zero set. Each block must be nonzero, which is NAE(0,X_i,Y_i) as an affine literal constraint; realize that constant with a shared reference pinned to zero if required, and expose the two entries as variables with affine defining equations. The attainable direction is isotropic of dimension t−h, so 2h follows from the rank identity. This reverse reduction concerns true Fourier rank, not an upper bound on the number of explicit side rows in a standard incidence formula.

Even at h=2, the reachable syndrome set need not be its own affine hull. For a single graph edge with b=0 at both ends and independent labels, the possible zero sets are empty or one endpoint. Each nonzero linear form on the syndrome can take both values, but syndrome (1,1) cannot occur. Single-label tests alone therefore do not settle the two-label case.
