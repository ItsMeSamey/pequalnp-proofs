# Remote pinning for neighborhood-dependent gauges

In the attached typed-pin obstruction, the three target ports and their six test ports can be made indistinguishable to any rule using the entire rooted colored incidence neighborhood of radius R. Radius counts individual variable–clause incidence edges. Take seven copies of one depth-R+4 full trivalent bipartite tree around the central variable, rounded up to finish at variables. Color edges 1,2,3, each color used once at every interior node. At a variable use literal signs +,+,− in that color order; at a clause use color order for its literal ports. At each variable the induced occurrence order can likewise be realized by genuine clause input order: each star imposes a total ordering on its incident clauses. The clause cliques form a block graph with no cycle through different cliques, so these comparisons can be topologically sorted. Copy the same order in each tree. Caps and external anchors are beyond radius R. Absolute variable names and clause IDs are excluded as colors.

Keep one whole tree neutral. For each of its three central edges make a variable-side bad pin in one other tree and a clause-side good pin in another. In a variable subtree with a parent port, an opposite-signed child always exists. Forcing that child clause's parent literal good forces the variable bad on the incoming port; the other child branch stays neutral. A clause forces its incoming literal good by requiring both its child variables bad. Every neutral branch permits either incoming value since a free child literal can be chosen true recursively. At the frontier, require a variable's desired value by one ternary clause with two fresh Tovey-pinned false auxiliaries. Terminate neutral branches freely. On the opposite side of the designated edge choose only neutral clauses. Thus the open pin supports are exactly the required singleton words, and each closed fixture is satisfiable. Chain fixtures via fresh transparent clauses using exterior neutral leaves, avoiding all open pin interiors. The center has the same ordered colored two-sided R-ball in all corresponding tests, allowing the exact singleton-column/exchange proof of typed-pin-obstruction.md. This holds even when the function from types to matrices is selected after inspecting the whole input, provided equal observed types must share their matrix.

Size is O(2^R), since depth counts individual incidence edges and branching is at most two after the center. Given an arbitrary exact-3/≤4 SAT instance of size n, first apply the connected bridge transformation already recorded and attach a control of depth ceiling((1−epsilon/2)log₂ n)+O(1). For any fixed 0<epsilon<1 the control has o(n) size, while final size N=Theta(n). Its protected radius exceeds (1−epsilon)log₂ N for sufficiently large n. Hence a connected NP-hard satisfiability-equivalent family rules out this specific local representation even for such growing radii. Preprocessing or global relabelings that change the input or using unequal bases on isomorphic balls lie outside the theorem. This is not a SAT runtime lower bound.

check_radius_pin.py independently constructs instances at radii 1–6 and compares all six two-sided ordered rooted neighborhoods using actual input occurrence indices. It checks every planted clause, occurrence cap, and connectivity. At radius 6 the control has 18,175 variables and 12,351 clauses.
