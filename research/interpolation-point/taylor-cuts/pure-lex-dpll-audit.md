# The row-space footprint under Boolean restriction

Work over the Boolean ring over GF(2), representing each original equation by its expanded squarefree polynomial. Order supports by numeric bitmask, with the least-priority variable x in the least significant position. Let V be the span of the rows. Call a subset a face if it contains no support of a leading pivot of V. Write F(V) for the number of faces in the current variable ground set. For b in {0,1}, V_b is the image under x=b, ordered by inherited lex order.

**Claim.** F(V_0)+F(V_1) ≤ F(V).

All possible leading columns of nonzero vectors in a subspace are exactly its echelon pivots. For every support S omitting x, columns S and S∪{x} are adjacent in the full order. If a parent row leads at S then both its restrictions lead at S. If it leads at S∪{x} then the projected coefficient of S differs by one across the two restrictions. Exactly one of these restrictions leads at S. Terms in lower pairs cannot project above or onto S.

For each T omitting x, compare its number of child face occurrences with the number of parent faces among T and T∪{x}. If T is a parent nonface, some x-free pivot inside T survives in both children. If T alone is a parent face, some pivot S∪{x} lies inside T∪{x} and its projection excludes T from one child. Otherwise both parent sets are faces and the bound is two. Summation proves the claim. The argument includes S empty: a constant pivot kills the node, and a singleton pivot at x produces a constant pivot in one child.

**Algorithm.** Branch on the least remaining variable with inherited order, restrict the original rows, and prune when echelon elimination exhibits the constant polynomial 1. Zero remaining equations allow an immediate contribution of 2 to the power of the remaining variable count. With no variables left, contribute one exactly when every equation vanishes. Positive-mass nodes at every depth number at most F(root); zero-mass visited children cost at most two per previously visited positive node. This yields deterministic exact counting in O*((1+F(root))) time and polynomial space by depth-first traversal. Evaluating a partial assignment in the original expanded rows can only remove terms or delete fixed variables from their supports, keeping the number of active columns polynomial in explicit input size. The algorithm never computes F itself.

**Scope.** For degree-lex, give increasing priority to x,y,w,z and take rows xz+yw and y. Starts xz,y leave six faces. Splitting x yields leading supports yw,y on both sides, hence eight faces in total. For pure lex the same example with priority z<y<w<x and a split at highest priority x again gives six versus eight. These examples concern the row span of supplied generators.

Felszeghy, Ráth and Rónyai characterize lexicographic standard monomials of the full vanishing ideal of an explicitly given finite point set through the lex game. The present bound uses only linear combinations of input equations and accounts for a Shannon branching tree by a one-sided inequality. The cited work supplies related precedent and does not establish priority for the claimed generator-row formulation. [The lex game and some applications](https://doi.org/10.1016/j.jsc.2005.11.003).
