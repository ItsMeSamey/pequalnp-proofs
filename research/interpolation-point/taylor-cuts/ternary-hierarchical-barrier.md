# Matching profiles on nested near-barriers

A supplied partition tree has root V of even size. An internal block P is partitioned into a splitter B (possibly empty) and children H_i with no inter-child edge. Edges to ancestors are unrestricted. Put p(U)=|U| mod 2 and d(P)=|B|+p(P)−sum_i p(H_i). Let D(P) be the sum of positive parts of d at strict ancestors, and D the maximum of D(P) over all nodes (include a terminal child for each splitter-only node, or charge its d directly). Precompute a target profile on P for every hole set Z with |Z|=p(P) mod 2 and |Z|−p(P)≤D(P). A profile is the set of gains of perfect matchings on P−Z, with original-edge traceback.

Write k=|Z|, r0=|Z intersect B|, r_i=|Z intersect H_i| and p'_i=p(H_i−Z). In a completion t_i endpoints in H_i are paired to B. Then t_i≥p'_i and p(H_i)−p'_i≤r_i. Consequently
r_i+t_i−p(H_i) ≤ r_i+|B|−r0−sum_{j≠i}p'_j−p(H_i) ≤ k−p(P)+d(P)−2r0.
Thus a feasible child request fits its path-specific cap. The effective connector slack |B|−r0−sum_i p'_i is at most k−p(P)+d(P)−2r0. If negative the profile is empty. Otherwise apply the one-level reduction from ternary-near-barrier.md to the blocks H_i−Z (they need not be connected). Their separating property and parity suffice. Exceptional incidences cost at most 3D/2 endpoints; untouched effective-odd blocks request one additional hole each and are represented by abstract vertices on the opposite shore. Effective-even blocks and positively touched exceptional blocks use child tables directly. Skip candidates whose child query exceeds the stored cap: the inequality only concerns true completions, sufficient for completeness. Independent gain-set addition, at most 3^b calls to the bipartite oracle per output target, and stored predecessors give original witnesses. Child blocks do not call their parent. Nested traceback selects exactly one entry per visited node and all selected original edges form a matching.

For T nodes and largest leaf size s, T N^{O(D+1)}3^{O(b)} times the sum of the maximal bipartite decision clock on O(N) vertices and 2^s poly(input) suffices; use ordinary subset matching DP for leaves. All gain tuples at each entry are computed by repeated target decisions. The bound charges tree construction only when a separate recognizer is specified; in this theorem the tree is supplied and its validity and D are checked directly. The parameter is path-summed positive slack, so numerous zero-slack nested nodes have no effect on the exponent. Perfect matching counts require multiplicities beyond these reachability tables.
