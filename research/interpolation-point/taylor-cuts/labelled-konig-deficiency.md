# Matching deficiency from independent transversals

A perfect matching of m pairs bounds independence number α by m. To recognize δ=m−α, for each d starting at zero omit d pairs and seek an independent transversal on the other pairs. Opposite endpoints of a retained pair are complementary literals. For each original edge forbid selection of both endpoints. The resulting 2-SAT instance describes exactly the independent transversals. Every independent set of size m−d omits exactly d pairs, proving correctness of the first successful d.

Fix the recovered independent set I of size m−δ. In every perfect matching the vertices of I participate in exactly m−δ crossing edges and its complement has exactly δ internally matched edges. Enumerate the δ disjoint interior endpoint pairs, and delete their endpoints. On remaining vertices retain only crossing edges, producing a balanced bipartite host. For each fixed endpoint collection a syndrome DP obtains one tuple of original IDs per attainable sum of parallel-edge labels. Query the bipartite solver for the target minus each such sum. The union of the recovered original IDs certifies the required perfect matching. All choices are covered by this argument.

For label dimension b, independent-set detection costs at most Σ_{d≤δ} binom(m,d) polynomial-time 2-SAT calls. If q is the number of eligible interior endpoint pairs, the search considers at most binom(q,δ) collections with at most 3^b bipartite calls each. At most 3^b states are stored per parallel-label batch. Thus the overhead involves m^{O(δ)} and 3^{O(b)} factors and never one label-vector choice per internal pair. The deficiency cap stops before recognition if no appropriate independent set is found; the portal cap applies separately inside each bipartite residue decision. An absence of perfect matching remains an unconditional UNSAT.
