# Affine edges for an ordered cache of signed cell mixtures

An input function is a rational linear combination of indicators of Boolean affine cells. Condition on variables in a fixed order. Store one raw restricted mixture per nonconstant equivalence class at each depth, where equivalence permits a nonzero rational scale and a rational offset. The empty intersection has mass zero and an intersection of consistent equation rank r has mass 2^(−r) under uniform suffix bits. This computes expectations and all Gram inner products by rational arithmetic on the original cell lists. In particular it needs no value table on the suffix.

For two nonconstant raw residuals f and g, let v,w be their variances and c their covariance. Equality c²=vw holds exactly when f=a g+b pointwise for a=c/w and b=E[f]−aE[g]. Indeed the centered squared residual has expectation v−c²/w. Every suffix point has positive mass, so zero expectation of this square is pointwise equality. Zero variance separately gives a constant leaf. The construction compares each candidate only to raw representatives and, for a newly accepted representative, conditions its raw list on both values. Thus per-representative cell counts cannot grow beyond the original number of terms.

A negative scale interchanges the maximizing and minimizing suffixes, and a positive scale preserves them. Extend each selected suffix witness by the branch bit, compare the two branch values and keep the smaller numerical assignment on ties. Induction gives exact extremal values and witnesses, including constant residuals. If the largest nonconstant layer has W classes, there are O(n(W+1)) processed candidates, each compared against at most W representatives using polynomial-size rank problems. The worst-case W can be exponential. An exact affine relation is required on the entire remaining Boolean cube.

The [implementation](/workspace/scratch/compression/affine_edge_cache.py) and [checker](/workspace/scratch/compression/affine_edge_cache_check.py) handle rational signs, inconsistent cells, additive offsets, negative-scale witness reversal and zero variables. The binary-value function on eight bits has 256 distinct outputs but only eight nonconstant representatives over all levels.
Affine algebraic decision diagrams, their edge labels, and extremum propagation are established methods. The construction here compiles signed affine-cell descriptions via Gaussian inner products. See [Sanner and McAllester, IJCAI 2005](https://ijcai.org/proceedings/2005/181).
