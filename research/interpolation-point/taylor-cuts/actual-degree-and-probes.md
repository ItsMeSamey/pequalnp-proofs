# Cancellation can invalidate the raw degree budget

Let G be a connected cubic graph. For each edge e=uv introduce y_e equal to the OR of x_u,x_v, using the three standard CNF clauses. Split each vertex input into six occurrence clones, tied by one directed cycle of binary implications. Each clone occurs once at a gate and twice in the cycle; each output occurs three times. Contracting clone cycles recovers G as a minor of the primal graph. Cubic expanders give unbounded linear treewidth.

Deform only the input occurrences in gates to (1−T)x. Leave output rows and all cycle rows undeformed. Inconsistent clones contribute zero. On a consistent assignment let a=(1−T)x_u, b=(1−T)x_v. The two Boolean output values contribute respectively (1−a)(1−b) and a+b−ab. Their sum is identically one in the polynomial ring. It follows that H(T)=2^|V| despite nonconstant occurrence degrees. At T=1, one coefficient per node suffices by this actual-degree certificate. Put each output in a singleton gate-owner block and each clone cycle in a size-six owner block. Baselines have no remote demand, and no positive derivative orders are needed. Exhaustive evaluation on K4 at the integers −3 through 4 confirmed 16 each time. This is a direct counterexample to replacing the occurrence-degree budget by the actual degree in the raw-rank/treewidth obstruction. Counting here is easy precisely because unused functional outputs marginalize to one.

For a nonconstant count, observe the output vector by k independent affine tests By=b over F₂. At the Boolean endpoint use OR(x_u,x_v)=x_u+x_v+x_ux_v mod 2. Character inversion gives 2^(−k) times the sum over λ of (−1)^(λ·b) times the quadratic Gauss sum over x with phase Σ_e (Bᵀλ)_e OR(x_u,x_v). To evaluate a quadratic sum, isolate a nonzero pair term ab, writing the phase as ab+aL+bM+R, with L,M affine in the other bits. Summing a,b gives 2(−1)^(LM+R). The residual stays quadratic after Boolean multilinearization. An affine terminal has zero sum if its linear part is nonconstant and otherwise the corresponding signed power of two. This gives polynomial work per character, hence polynomial exact counting for k=O(log input length). Redundant tests can first be removed, rejecting inconsistent right sides. Unique gate extensions in parity checks and equality clone cycles preserve the scalar, as well as width at most three and at most three occurrences after full occurrence splitting. Direct tests on 75 random graph/check pairs matched enumeration. With one independent test fixing each y_e to one, the same family counts vertex covers, showing why the number of independent arbitrary probes matters. At general T, after character expansion, untested gate factors outside the selected character support still cancel identically. There is no assertion that the remaining high-support Taylor polynomial has small degree: the endpoint algorithm uses quadratic phase elimination.

Actual degree may also be zero on an arbitrary hard core while evaluation remains hard. For each original literal occurrence o add a distinct pair u_o,v_o and a clause (u_o OR v_o); use input row x_o+T^L(u_o−v_o) in the original clause, with x_o denoting the original variable. Leave the new clauses undeformed. Every original factor product is multilinear in its distinct occurrence placeholders. The private perturbations are mutually independent and have zero sum over each pair's three allowed choices. The scalar is exactly 3^M times the original count for all T, for M occurrences, although the occurrence-degree sum is ML. This identity simplifies degree certification only; it does not evaluate the original count.

A compositional certificate with observed outputs uses controlled reversible updates. On an ordered state register, a station on distinct bits u,v computes h=x_e AND y_u and y'_v=y_v XOR h, retaining the other registers. Use standard width-three gate CNFs. At the designated gate occurrences deform x_e to p_e(T)=(1−T)x_e, independent of the state. At a fixed Boolean state input, summing the private h with the Boolean XOR constraint produces the formal transition (1−p_e)I+p_e P_e where P_e is the CNOT permutation. For y_u=0 the AND clauses force h=0 with weight one; for y_u=1 their two weights are 1−p_e and p_e. The matrix is therefore doubly stochastic as a polynomial identity; positivity at interpolation points is unnecessary. Products preserve the all-ones row even when successive permutations do not commute and controls are reused. With a uniformly summed starting state and an arbitrary terminal observer f evaluated only on final Boolean wires, H(T)=2^(number of independent controls) times the direct Boolean sum of f. The remaining observer mass must be computable separately. At T=1 each h is pinned zero and each update becomes a wire identity. In particular a nontrivial tractable terminal predicate can be observed despite a large connected interior. On an orientation of a cubic expander, each logical variable's successive versions form a connected path via update constraints; the local AND/XOR auxiliaries connect each pair of these paths joined by an edge, so the expander is a graph minor. Splitting all high-occurrence variables into undeformed equality cycles retains this minor and count. Deform only their intended input occurrences. Forty independently generated ten-gate circuits with signed rational control weights preserved every final-state mass in direct arithmetic evaluation. A fixed or nonuniform starting distribution does not generally enjoy this cancellation.
