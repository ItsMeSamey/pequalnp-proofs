# Explicit clustered-rail zero certificates admit an ER translation

Fix the field F_p. Supply the pass list, ordered selectors, contiguous clusters, actual selected representative tuples at all computed levels, and finite-field coordinates proving every span containment and annihilation used below. Measure size in the combined explicit input and certificate. Matrices of width d have their entries explicitly represented. This yields a polynomial ER proof of the zero observable and an ER refutation when the source has a polynomially proved nonzero-observable implication under its satisfying assignments. No assertion about arbitrary polynomial-time verifiers is needed.

**Closure step.** For each stage j and control symbol z let A_{j,z} be its explicit linear operator. If the columns of U_j span the certified subspace, supply T_{j,z} with A_{j,z}U_{j−1}=U_j T_{j,z}. Name field-valued coefficient wires c_j=Σ_z t_{j,z}T_{j,z}c_{j−1}. By induction y_j=U_j c_j for the corresponding linear recurrence on y. Prove each entry by distributivity, reassociation and the supplied constant equalities. For example a sum of K products can be reordered in at most O(K²) adjacent swaps, each implemented in polynomially many gate-value equalities. The number of terms in a single induction step is polynomial in the explicit operator dimensions; no iteration expands the named c wires. A supplied output annihilator therefore vanishes for arbitrary symbolic field wires t_{j,z}, also when several wires are equal or depend on the same controls. Fixed-field gate operations and local identities have constant-size ER gadgets. All wires used as field symbols must either have a total valid encoding or carry a proved validity invariant.

**Prefix tuple dependence.** For the candidate tuples P^k at a level within one cluster, the coordinate-mask spans use diagonal maps D_{j,r,q}[k,k]=1[P^k_j(r)=q]. Give their closure coordinates beginning with the all-ones vector, and the terminal annihilator for each dependency among tuple columns. To contract a dependency against a physical matrix chain, use a vector y_q indexed by k for each physical state q, separately for each initial state. At local factor j, y'_q=Σ_r D_{j,r,q}y_r, so every y'_q lies in the next certified span. An intervening arbitrary named matrix Z gives y'_q=Σ_r Z[r,q]y_r and stays in the current span. Initial and final intercalations are allowed. This proves the full matrix identity for each dependency with all insertions symbolic, without naming a product-coordinate tensor. Left and right insertions around each fixed factor can be merged at their shared boundary.

**Specializing to actual prefixes.** For cluster J define coefficient vectors c_{J,j} recursively: extend each representative of level j−1 with the actual bit x_j and apply the certified representative coordinates of the resulting candidate. For each target level i and candidate suffix s define a sequence of matrix expressions indexed by j=0,...,i. At j, sum over prefix representatives h of level j with weights c_{J,j,h}. In each pass place h's partial permutation alongside the actual later steps x_{j+1},...,x_i and the fixed suffix s, in the physical order prescribed by the pass direction. Multiply the resulting pass matrices across the cluster. At j=0 this is its true completed matrix. To pass from j−1 to j split on x_j and apply the contracted prefix dependency to each extended parent representative; all later intercalations are independent of the representative index. Sum these identities with the named earlier weights and regroup. At j=i this gives Σ_h c_{J,i,h} B_J(h,s). This argument constructs polynomially many explicit matrix equalities per cluster, target level and candidate suffix; it does not assume tensor equality from a single scalar test.

**Observable dependencies.** At cut i build the observable reach spans on vectors indexed by candidate suffix, physical state and (where needed) diagonal origin. The transition for choosing local basis index h is the corresponding block-diagonal permutation for all candidate suffixes, mapping each suffix block by B_J(h,s). Supply closure matrices and terminal dependency coordinates for the observable columns. Apply the closure step with t_{J,h}=c_{J,i,h}. The preceding matrix equalities identify each resulting observable column with W_i(s;x_{≤i}), the actual global value using that prefix and representative suffix. Shared controls between clusters and repeated selector occurrences do not require independent variables in the proof.

**Backward computation.** The starting suffix candidate at level n is the empty suffix. At cut i replace each candidate column by its proved linear combination of the selected columns. For each selected s, evaluate x_i as a bit to identify W_i(s;x_{≤i}) with W_{i−1}(extend(s,x_i);x_{≤i−1}). Accumulate the coefficients in one named vector per cut using the selected bit. Identical extended tuples share a candidate, with their coefficients added. This preserves the actual observable as the weighted sum at that cut. A cut with no observable pivots has every candidate column zero. This proves the global zero assertion even for early termination. For separately observed starts apply the dependency to each output coordinate required by the chosen observation rule.

Every loop above ranges over explicit levels, clusters, candidates, local alphabet symbols, pass positions or matrix entries. The proof uses a polynomial number of calls to the closure lemma, each with polynomial dimensions. It may be built by separately instantiating the symbolic identities with named gates rather than substituting their formula trees. The implementation's retained pivots alone do not list all coordinates; the needed coordinates can be reconstructed by replaying each finite-field elimination and tracking the coefficients. Size is polynomial in this expanded trace, and replay stays polynomial in the explicit dimensions of a completed rank-bounded run.

**Source bridge.** For the canonical Barrington CNF compiler each literal program's product is its prescribed five-cycle when the literal holds and identity otherwise. Induct over the compiler's gate and occurrence tree, name products, and prove the equivalence for every required permutation entry by the fixed truth tables for permutation composition, inversion, negation and the commutator pair. Inversion of a subword follows by reversing its sequence, composing inverse matrices, and canceling. Differently parenthesized physical products can be reconciled by polynomially many associativity steps. Thus satisfaction gives RHO before closing and identity afterward, with any pinned diagonal 1 and scalar trace 5. In scalar mode use p≠5. For a general rail, zero of all diagonal indicators proves there is no closed trajectory; zero of a scalar trace requires a proved implication from acceptance to nonzero trace. A mere trace-noncancellation promise passed by the caller supplies no ER derivation.
