# Reachable local prefix spaces and suffix observables for permutation passes

Fix a control order, forward/reverse pass certificate, closing permutation, and a partition of the pass sequence into contiguous clusters. Work over a fixed prime field. At cut i of the control order let R_i^j be the span of pure partial pass tensors for all assignments to the first i controls in cluster j. Compute actual pure bases separately in each cluster by the finite-pass algorithm. Their tensor product E_i over clusters allows **independent** local prefix choices. It contains all global prefix tensors; different clusters need not be independent on the real rail.

A suffix assignment acts as an explicit test on E_i. Combine its pass permutations with the prefix tensor and apply the desired closing entry. On a forward pass the full permutation is suffix after prefix; on a reverse pass it is prefix after suffix. The ordered product over passes followed by the fixed closing permutation is multilinear, so each individual diagonal entry gives a linear functional. For all starts retain the vector of these diagonal entries. Trace can replace it under a promise that acceptance implies a nonzero trace in the field, such as five fixed points versus zero over F₂.

Move backwards through controls. At the final cut start with the empty suffix. Extend each retained suffix by either value of the next control. For each extension the prefix transformation sends E_(i−1) into E_i, since it maps each local reachable prefix into the next local space and factors across clusters. Precomposing any linear dependency of suffix tests on E_i preserves that dependency on E_(i−1). Consequently pivot columns among the new candidate tests retain a basis of *all* suffix tests on the new envelope. Keep the actual assignment of each retained test. A zero space certifies rejection. At cut zero the envelope is generated by one all-identity prefix. A nonzero representative supplies an accepting assignment and its closing start, without summing over witnesses.

## Testing a batch without expanding its envelope

Suppose m candidate suffixes are under consideration. For each cluster j, local pure prefix-basis member α and candidate u, explicitly concatenate all full physical pass permutations of that cluster to obtain B_j(α,u). Their full-rail multiplication now follows cluster order. For a fixed start s initialize m copies of its unit state vector. At one cluster, propagate every current row-basis vector through every α, applying the permutation B_j(α,u) to the u-th state block. Gaussian-reduce the resulting vectors in dimension mD, where D is the number of rail states. By induction the final space is exactly the span of the stacked states for all choices of local α. Apply the closing permutation's s-to-s test on each candidate's block. The resulting row space on m coordinates has exactly the column dependencies of candidate suffix tests on E_i. Gauss pivots select actual representatives.

For unconstrained closing starts, repeat this construction separately for each s and take the span of all resulting observable rows. This implements vector-valued acceptance and avoids trace cancellation. When trace is valid, instead initialize separate starting channels simultaneously in dimension mD². Apply the same local α to all channels at once and sum their closing diagonal entries at the very end. These two procedures intentionally compute different spaces.

For fixed p the algorithm takes polynomial time and space in the explicit pass description, D, the maximum local prefix rank and maximum restricted suffix rank. It never enumerates the product of the local basis sizes. For input prime p the reference includes a trial-division primality check; field work is polynomial in log p with a prevalidated prime. No worst-case polynomial rank bound for arbitrary rails follows.

## Separation example

Use three states. For each of n controls create a pair of consecutive passes consisting of an optional transposition (01) and its inverse under the same control. Give each pair its own cluster. All local prefix ranks are at most two. With a closing three-cycle, every genuine assignment has zero closing starts. Even independent prefix assignments per cluster yield identity products at the full cut, so the initial empty-suffix test is zero on E_n. The answer is genuinely UNSAT with largest tested suffix rank zero. With identity closing the answer is SAT, and all-start vector tests have rank one throughout, even when the number of assignments is even.

The raw global prefix space has dimension 2^n at the full cut because each pair independently supplies one of two linearly independent pure tensors. Likewise, if suffix tests at the empty-prefix cut were tested on all formal prefix matrices, they would have rank 2^n for trace. For a prescribed sequence of toggle bits, label the post-toggle state of slot j by b_j equal to the image of 0 under that slot's prescribed toggle. Insert a matrix unit before each toggle sending the preceding slot's b to 0 and annihilating all other states. At the first slot use the image of the last b under the closing permutation as its source. Exactly the prescribed sequence gives nonzero trace, and its trace is one. Thus raw suffix tests can be separated individually, while their restrictions to the reachable envelopes vanish in the derangement example. This comparison concerns specified linear spaces; the pairwise cancellation in this example is visible directly as well.
