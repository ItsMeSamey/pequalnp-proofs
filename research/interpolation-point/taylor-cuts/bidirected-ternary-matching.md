# Prescribed ternary matching residue with bidirected contraction

Fix a bipartite base perfect matching. Contract its pairs and orient each available exchange edge from its left pair to its right pair, labelling the arc by the inserted edge weight minus the tail's base weight. Feasible relative gains are exactly those of collections of vertex-disjoint directed cycles, together with the empty collection. Suppose the loopless contraction has bidirected support, meaning each arc has some reverse arc; opposite labels may be arbitrary. We give a deterministic polynomial algorithm for any prescribed gain t in GF(3). Gain zero is immediate.

When every directed digon has gain zero, the labels of opposite arcs are negatives and parallel arcs with the same endpoints have identical gain. Find any nonzero directed cycle by searching the three-state lift for a nonzero closed walk and decomposing it into simple cycles. One of the cycle or its reverse has gain t. If the search fails, every collection has zero gain.

Otherwise find a nonzero digon C, returning it if its gain is t. Let S consist of its two endpoints. If D−S contains any nonzero cycle, take that cycle alone if its gain is t, and otherwise take it together with C, since both have gain −t. In the remaining case all cycles outside S have zero gain. Within every weak component of D−S, all arc labels consequently have the form φ(head)−φ(tail). To construct φ, take path sums from a root; all paths agree by closing them with a directed return path, which exists by bidirected support.

Enumerate, for each vertex of S, either its omission or a selected incoming and outgoing arc. Keep choices with consistent internal arcs and no duplicate incoming or outgoing incidence at any external vertex. Let A consist of external heads of selected arcs from S and B of external tails of selected arcs into S. External arcs have to be completed by vertex-disjoint paths from A to B in D−S, with unrestricted pairing. Each vertex of A∩B has both its boundary incidences already filled and must give a zero-length path. Delete these vertices and solve the remaining unpaired paths problem by integral max flow with split vertices of capacity one, a super-source attached to each start with capacity one and a super-sink attached similarly to each end. The resulting path gain is Σ_{v∈B} φ(v)−Σ_{v∈A} φ(v), independent of pairing. If feasible and this sum plus all selected boundary arc gains equals t, the paths with boundary arcs form a union of directed cycles and hence the desired matching. Any feasible matching is considered: after dropping cycles entirely outside S (all have zero gain), its remaining cycles specify one of the enumerated boundary choices. The argument uses at most O(m⁴) flow instances and allows arbitrary parallel arcs in the loopless contraction.

With one forbidden feedback vertex z whose deletion leaves a DAG, split z into a pure source and a pure sink. A topological-order DP on (vertex, residue) enumerates path gains and recovers representative paths. Any nonempty cycle packing uses exactly one cycle since all must pass through z. This holds for any fixed finite abelian group, with runtime proportional to its order times graph size once z is known. One can try every z and test acyclicity.

The [Thomas–Yoo group-labelled packing theorem](https://arxiv.org/abs/2009.11266) deals with sums of edge labels on undirected cycles. Its integral statement for groups without two-torsion does not imply a packing or transversal algorithm for prescribed gains in a non-bidirected directed contraction. In particular a half-integral packing allows shared vertices, whereas a matching exchange requires disjoint base pairs.

## A short nonzero cycle in an arbitrary digraph

The same conclusion holds in n^{O(k)} time if any nonzero simple directed cycle C of length k is available, regardless of arc symmetry. One can find a minimum-length nonzero cycle by finding a shortest nonzero closed walk in the three-state lift, minimizing over all base vertices and both nonzero endpoint residues. Such a shortest walk cannot repeat a base vertex internally, since its decomposition would yield a shorter nonzero closed walk. Nonzero loops are covered by k=1; loops of gain zero can be dropped.

It remains to generalize the residual routing computation when C has the wrong gain and D−V(C) has no nonzero cycle. Each strongly connected component U outside C then has its own conservative potential φ_U, as above. Arcs between components can have arbitrary labels. Enumerate boundary choices on V(C) in m^{O(k)}, deleting forced zero-length paths as before. At most k unpaired paths connect external starts A to external ends B.

Process the SCCs in a topological order. A state consists of at most k distinct pending arrival vertices, initially A, and the accumulated gain. At U take the pending arrivals inside U as sources; the others remain pending. All vertices of B in U must terminate a path. Enumerate a set of intercomponent arcs leaving U such that their count plus the number of these ends equals the number of local arrivals. The arc tails and required ends together must be distinct, and new pending heads must be distinct from each other and all previously pending arrivals outside U. Confirm by unit vertex-capacitated flow that those local sources can reach those local sinks disjointly with arbitrary pairing. If a local source equals a sink it must be a trivial path; reserve that vertex before the flow. Accumulate the sink potential sum minus source potential sum, plus the gains of the intercomponent arcs. Carry the new pending arrivals and accumulated gain forward. Accept an empty pending state with the prescribed overall gain after the last component. Any collection of paths yields these boundary states; conversely all local paths concatenate because the component ordering is acyclic and previous components cannot be revisited. Vertex disjointness is enforced at every vertex and no path identity is needed. The number of stored states and transitions is n^{O(k)} times a polynomial in the arc count for simple inputs (or m^{O(k)} for multigraphs). For a fixed short-cycle bound this is polynomial. This bounds the exponent by cycle length, not just the number of cycles.

If a directed multigraph of bidirected off-diagonal support has a nonzero loop, use this algorithm at k=1. Otherwise delete all loops before the bidirected algorithm.
