# Induced even subgraphs through three pins in a line graph

Let G be the line graph of a finite simple undirected graph H. Three specified vertices of G correspond to three required edges P in H. There is a deterministic polynomial-time algorithm that returns an induced even subgraph containing all three pins, or determines that none exists.

For any selected edge set F of H and any uv in F, its corresponding vertex in G[F] has degree deg_F(u)+deg_F(v)−2. Thus G[F] is even exactly when each nontrivial connected component of (V(H),F) has the same degree parity at all its vertices. Different components may have different parities.

## Uniform parity test

For each vertex v, let the allowed total degrees be all even degrees, including zero, for the even test. For the odd test allow zero and every positive odd degree. To force the edges in P, remove them from the available graph, record p_v=deg_P(v), and allow residual degrees j exactly when j+p_v is allowed and 0≤j≤deg_(H−P)(v). An empty list makes that test infeasible. Every nonempty residual list has gaps of length at most one between consecutive feasible ranges. Feasibility and recovery of a factor therefore take polynomial time. With only a decision oracle, optional edges can be deleted one by one whenever feasibility survives. At the end every remaining edge is necessary and together with the pins forms a witness. [Cornuéjols, General factors of graphs](https://doi.org/10.1016/0095-8956(88)90068-8)

## Three pins

If P is a matching then P itself gives the witness. Otherwise try the two uniform parity tests. When P is connected, a feasible F can discard every component that misses P, so these tests are complete. In the remaining case P consists of an adjacent pair and a disjoint edge e. If a witness joins both parts into one component, a uniform parity test finds a witness. If the parts lie in different components, discard all selected edges outside the component of the adjacent pair, except for e itself. The endpoints of e can consequently be removed from H. On the remaining graph apply the two uniform tests to the adjacent pair. On success, restore e. This exhausts the possibilities using at most four general-factor calls if the routine returns witnesses.

When only G is supplied, recognize and invert the line graph in linear time component by component, retaining the correspondence from original vertices to root edges. Any simple root works, including either root of a triangle. The total running time is polynomial in the graph input size. [Roussopoulos, inverse line graph algorithm](https://doi.org/10.1016/0020-0190(73)90029-X)

The class contains irregular, high-degree graphs outside the circle graphs. For example, attach one or more leaves to a vertex of K5 and take the line graph. The result contains L(K5) as an induced subgraph. The open neighborhood of a vertex in a circle graph is a permutation graph, by ordering the crossing chords on the two arcs of the distinguished chord. Permutation graphs are closed under complement by reversing one order. In L(K5) the complement of an edge's neighborhood is C6. In a permutation representation of C6 the segments of one independent shore occur in the same order on both lines. The neighbors of each opposite vertex must be consecutive in that order, but they form all three pairs on three elements, which cannot all be consecutive.

## More pins

Call a component of the required root edges self-sufficient if those edges by themselves have constant degree parity on that component. If all components are self-sufficient, return the pins. Suppose there is exactly one remaining component B and g self-sufficient components. Enumerate the subset of self-sufficient components that will be isolated as their required edges. Delete their vertices, run both uniform factor tests on all remaining pins, and restore the isolated edges. This takes at most 2^(g+1) oracle calls. Completeness follows by keeping the component of an arbitrary witness that contains B, reducing every other component to the required edges it contains, and discarding components without pins. All those retained required-edge components outside B are self-sufficient and have disjoint vertex sets. In particular the method handles every connected pin pattern at any size, and every four-pin pattern except two vertex-disjoint paths of length two. The latter case can still be solved by separate uniform tests if the two paths lie in different ambient components.

The companion verifier compares the returned witness to direct parity tests on induced line-graph subsets. Its general-factor oracle enumerates optional edges subject to the shifted residual degree lists, so the verifier checks the reduction separately from the polynomial-time factor algorithm.

The exhaustive run used every labeled root graph of order two through five, plus 90 deterministic six-vertex samples. All 18,623 three-pin cases agreed (3,719 infeasible, 14,904 feasible). For the additional localization theorem, 17,029 covered four-pin cases and 11,263 covered five-pin cases agreed. Each returned witness was verified directly.
