# Exact completion after SCC peeling

The input is a square bipartite option multigraph with one supplied base perfect matching. Each option has an integer mask for its vector of XOR contributions; parallel options may have different vectors. There may also be independent free vectors. The module returns original options and a free-vector mask on success. The signed CNF frontend is responsible for obtaining the base matching and restoring the original Boolean assignment.

Contract the base pairs and direct each option from its row u to the row v owning that resource. Set g on the arc to the option label XOR its row's base label. Perfect matchings are precisely permutations of the base resources with a particular option chosen on each arc. Every such permutation decomposes into disjoint directed cycles, hence every selected arc lies inside a strongly connected component. Loops include parallel alternatives to the base option.

In each component choose an out-tree root and let p_u be the gain on its path to u. The gains of simple directed cycles span the space D generated by p_u XOR g XOR p_v over the arcs. These adjusted arc gains telescope around every cycle. Conversely, append the same directed return path from v to the root to both the path through u and the tree path to v. The XOR of those closed walk gains is the adjusted arc gain, and closed walks split into directed simple cycles.

Initially U is the free-vector span and every member is attainable. If a component has quotient dimension dim((D+U)/U)=0, the base choices suffice. If the dimension is one, use a linear functional vanishing on U but nonzero on the remaining direction to find a simple directed odd cycle in the parity double cover. Toggling this cycle supplies the new coset. Either choice remains compatible with all previously recorded cycles, whose components are disjoint. U becomes U+D. This enlargement is independent of the selected cycle, and other components' quotient dimensions never increase. Any two maximal legal elimination sequences therefore consume exactly the same components and produce the same final U. A target outside the sum of all component spaces and the free span is impossible even before peeling.

With exact completion enabled, work modulo the final U on each stalled component C of b_C base pairs. Let r_C=dim((D_C+U)/U), and reduce each adjusted arc gain modulo U. The subset DP processes rows in order, recording a used-resource subset, a quotient gain, and one witness for that state. A transition picks an unused resource using an actual option. Every partial gain is in the projected D_C by construction; unadjusted gains of partial matchings need not have this property. At completion, every row and resource appears once, so the potential terms cancel. This gives the exact realizable quotient support S_C with one matching per element in O*(2^{b_C+r_C}) time and space.

Combine these lists successively, retaining one previous combination for each distinct XOR total. For r=dim((U+sum of remaining D_C)/U), direct pair enumeration costs O*(4^r) in total and O*(2^r) accumulated states. The complete time bound is O*(sum_C 2^{b_C+r_C}+4^r), with polynomial factors including the number of components. No product over independent component sizes is needed. Reject exactly if the required residue is absent. Otherwise compute the *actual*, unreduced gain of the recovered options, subtract it from the target difference, and reconstruct the residual member of U using the stored disjoint cycles and free-vector combinations. A residue of zero permits the base choices in all stalled components. This also handles m=0 and an empty free-vector family.

The opt-in backend is peel(..., exact=True) in parity_scc_peel.py. parity_scc_check.py compares both modes with exhaustive matching/free-bit enumeration and includes a rank-two obstruction, a cascading peel, and exceptional choices whose lifts require a correcting peeled cycle or free column.
