# Tree DP for interacting closure generators with a target syndrome

The public entry point accepts signed 2-CNF, binary XOR rows, and a decomposition of the derived generator graph. It uses prepare from two_sat_generator_interaction.py. That reduction finds a baseline model b, translates the 2-CNF to toggles, and records distinct feasible singleton implication closures C_j and pairwise incompatible closures. Each original solution is b XOR the union of some conflict-free selected closures. Conversely a conflict-free union satisfies every translated implication and every unit or binary prohibition. This representation may duplicate source solutions, so the algorithm decides feasibility and extracts witnesses; it does not count models by counting generator selections.

Let l_i be the parity-column vector of toggle coordinate i. Its contribution equals l_i if any selected generator belongs to S_i={j:i∈C_j}, otherwise zero. For each identical nonempty support S combine all such labels by XOR, dropping zero bundles. Thus unmeasured overlaps and exactly canceled interactions create no required graph edges, while the source witness still uses the full union. The generator graph contains each incompatibility edge and a clique on each remaining bundle's support. A bag assignment determines the contribution of any bundled OR hosted there.

Verify the supplied bags form a tree, cover every generator, and have connected occurrences of each generator. Require one bag containing each conflict pair and one containing every complete bundle support. This explicitly checks the needed scopes (the latter also follows for a valid graph decomposition by the tree-subtree Helly property). The verifier accepts any finite bag sizes and tree degrees, including empty bags; even an empty instance may use one empty bag. Root the tree and assign each factor or conflict to one hosting bag, breaking ties by the first rooted traversal index.

Each state is (bag word, accrued syndrome), with a representative for selected generators on the processed region. Initialize from the bag's assigned factors and conflicts. Join each child in turn, matching its word on the separator with the parent's bag word, XORing the two accrued syndromes and taking the union of their selected-generator masks. Running intersection ensures any generator shared between joined regions lies on the matched separator. Therefore the union never combines conflicting assignments; future computations need only this bag word and syndrome. The complete node table is passed upward. At the root require the residual target t (already adjusted for b). Decode the selected-generator bit mask into the actual source solution b XOR union(C_j) and directly check every original clause and parity equation.

For assigned bundle set A of any intermediate region, let U_A span its label vectors and U_out the remaining labels. Keep only accrued values in U_A intersect (t+U_out). Completion implies this membership, so filtering can remove no globally realizable target. If t lies outside the overall span, reject immediately. Otherwise the intersection has exactly 2^w vectors for w=dim U_A+dim U_out−dim(U_A+U_out), though some may be unattainable. Include all actual intermediate regions, from bag-local initialization through every sequential child merge. This corresponds to refining high-degree nodes with copies of the same bag. An original edge cut alone can underestimate the peak. At a star with empty root and 2r singleton leaves carrying e_1,...,e_r followed by the same independent labels, original edge intersection ranks are one, but halfway through that merge order the empty root has 2^r partial labels.

With B the maximum bag cardinality and w the maximum above, tables have at most 2^(B+w) entries. Even testing all pairs at joins takes at most 2^(2B+2w) times a polynomial in supplied sizes, control count and label bit lengths. Storing one generator bit mask per state adds only polynomial overhead. This is a standard separator dynamic program with binary span filtering on a particular signed-2-SAT representation. The theorem does not give a low-width decomposition for every input.

For arbitrary r, take the source clauses (¬c∨¬x_i) and prescribe all r individual x_i parities in a nonzero mixed pattern. The zero baseline yields singleton generators, and their incompatibility graph is a star of degree r. A path of bags {c,x_i} has B=2 and syndrome cut rank zero because every label belongs to a separate coordinate. Both syndrome rank and maximum degree are unbounded while the DP is polynomial here. A second family forces every x_i→y and y↔z. Give y and z equal columns and x_i independent basis columns. The two shared outputs have identical generator neighborhoods and cancel, so singleton bags suffice after bundling; full decoding still sets y,z correctly.

The checker independently enumerated 200 source fixtures and 250 generator-tree fixtures, replayed two rank-40 examples and a high-degree virtual-cut example, and rejected missing conflicts, missing bundle scopes, disconnected occurrences, missing vertices and cyclic bag graphs.
