# Affine NAE3 at true symplectic rank at most two

Gaussian-eliminate the explicit affine side system. If consistent, write original variables x=x0+Tz. Each signed NAE3 requires its two literal-difference outputs jointly nonzero. Thus the attainable word of t two-bit blocks is p+L, L=im F for a known matrix on seed z. Offsets and even degenerate block maps are allowed.

Equip P=GF(2)^(2t) with block symplectic swap J. The Fourier selection space K=ker F^T has quadratic phase with polar J restricted to K (the local sign on nonzero selectors is quadratic with that polar). Write R for its rank. On block subset I let d_I=rank F_I, L_I=im F_I and t_I=|I|. Its Fourier space embeds in K by zero extension. Since the swap identifies ordinary and symplectic orthogonals, and a subspace and its symplectic orthogonal have the same radical, its rank is R_I=2(t_I−d_I)+rank(J restricted to L_I). Hence δ=max_I(t_I−d_I)≤R/2.

To satisfy a gate it suffices for any one of the three nonzero local functionals on its block to evaluate to 1. Their homogeneous pullbacks are the two rows of the block and their sum. Rado's independent-transversal criterion gives δ=t minus maximum size of an independent partial set of such representatives, one per gate. This maximum is computable by linear/partition matroid intersection with all representatives distinctly labeled. To obtain a maximizing I if δ>0, repeatedly delete a gate when the recomputed maximum deficiency stays δ. A final list minimal for this property must itself attain size minus rank δ. If δ=0 impose independent representatives with inhomogeneous RHS values and solve to obtain a witness.

For R≤2, the only remaining case is δ=1. Outside a maximizer I, every gate family H has rank growth d_(I∪H)−d_I≥|H| by maximality of δ. Hence one can choose outside representatives independent modulo span(rows F_I), and ANY feasible block word on I extends by linear solving to one satisfying all outside representatives. It suffices to solve I. There t=d+1, R_I≤2, so rank(J on L)=0 and L is isotropic of dimension t−1.

Extend L by any orthogonal vector outside it to a dimension-t Lagrangian L0. Choose one independent first-coordinate test per block on L0 by Rado, since the analogous rank identity at L0 has zero polar rank and thus zero deficiency. Extend each local test to a dual basis: every invertible binary 2×2 map preserves J and preserves whether the block equals zero. Therefore the affine coset p+L0 is the graph of y=Gx+s, with first coordinates x free and G symmetric by isotropy. The original coset p+L imposes one more parity λ·x=b. Compute all matrices and shifts by linear algebra.

Try x=1. If its parity is wrong, the zero-coordinate set S must have λ(S)=1. Every i in S must have y_i=1 so that its block is nonzero. On the graph of off-diagonal entries of G this says the induced degree at i has parity a_i=1+s_i+(G1)_i+G_ii. If λ_i=1 and a_i=0, take the singleton. Otherwise λ is supported on marked vertices a=1. If a connected component contains marked vertices with opposite λ values, take a shortest path minimizing distance among all opposite-label marked pairs. It is induced, with unmarked interior, so it meets the prescribed degree parity and has λ sum one. If no such pair exists, λ is constant on marks in each component. Handshake forces any feasible S to select an even number of marks in each component, so λ(S)=0 and no solution exists. Convert the word back to original block coordinates, extend via independent outside representatives and solve for a primal seed; verify the original assignment. The entire decision/witness procedure is deterministic polynomial time.

For a signed NAE3 incidence graph, original gate-even Fourier selections before side constraints have zero variable parity. With affine equations Ax=b the variable-parity vector may instead lie in row(A), with its affine sign shift. Thus the old cycle space has codimension at most rank A in the new selection space, and R≤r+2 rank(A). In particular any ONE global XOR row on any original r=0 instance is solved even for dense rows. For unbounded side rank, occurrence splitting reduces unrestricted NAE3 to a forest of individual gates plus XOR equations identifying clones. This falsifies plain rank as the only parameter. Exact counting is already hard at r=0 without side rows. No general fixed-parameter algorithm in R is established here.
