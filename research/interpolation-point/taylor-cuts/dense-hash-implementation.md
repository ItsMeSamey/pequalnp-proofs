# Executable color-coded decision

The callable dense_colored_matching.solve takes an original edge-ID base matching, graph and target. It computes the maximum missing degree on the clean vertices (across a supplied bipartition if present), and supports a supplied set of exceptional vertices. It uses the proved moved-support bound k=min(number of pairs, (Δ+3)|X|+2b(2Δ+3)). Each returned witness is verified in the colorful-port backend. A coloring cap limits the number of DP calls. A capped miss before exhausting a guaranteed covering family returns UNKNOWN. This implementation covers measured maximum defect and deletions; the broader structural bounds in the main theorem require their separate host hypotheses.

Here are details of the explicit perfect-hash construction. For k≤1 or n≤2k use an immediate coloring. Otherwise reduce the index set to q=min(n,4k²). If n>q take a prime p between n and 2n and use all maps x↦((ax mod p) mod q) for a=1,…,p−1. For distinct x,y a collision implies their modular difference is a positive or negative nonzero multiple of q, so the collision fraction is at most 2/q. A union bound ensures every prescribed k-set is separated by some map. If n=q use the identity.

Set t=floor(log₂ k), r=ceil(k/t). On [q] construct a family of colorings with t colors covering all t-element subsets. Start with all t-subsets uncovered; a uniformly random coloring is injective on a fraction t!/t^t in expectation. Fix colors sequentially by maximizing the conditional expected number of newly covered sets. If a subset already has a distinct fixed colors, its probability of being completed injectively is (t−a)!/t^{t−a}. Subsets that contain a collision contribute zero; subsets not containing the current point add a common constant to all choices. Thus the implementation uses exact integer scores. Repeat until the family covers all subsets. At most O(e^t(1+t log q)) colorings suffice. Constructing these by explicit subset iteration takes q^{O(t)}e^{O(t)} time, which is 2^{O((log k)^2)}≤2^{O(k)}.

Enumerate r−1 cuts of the ordered q-symbol range to obtain contiguous blocks. For each planted k-set one can put exactly t successive members in each nonfinal block, leaving at most t in the final block. Enumerate the small family independently for each block and offset its colors by the block's index times t. This separates that k-set using at most rt≤k+t colors. Any smaller set extends to a k-set. There are at most q^{r−1}·O(e^t(1+t log q))^r=2^{O(k)} choices per multiplier, so generation including the polynomial factor in n costs 2^{O(k)}poly(n). Combining with colorful port/cycle DP takes 2^{O(k+b)}poly(input) time. The construction concerns decision/witness recovery, and does not count the resulting confirmations. The underlying method is standard deterministic color-coding (Alon, Yuster and Zwick, JACM 1995).
