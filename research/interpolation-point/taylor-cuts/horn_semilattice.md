# Sparse residual algebra on the model set of a Horn formula

Let H be a Horn CNF over n original variables. Identify assignments with their sets of true variables. Positive implication rules have the usual forward-chaining least closure; if the resulting set contains the body of a purely negative rule, no feasible extension exists. Write cl(A) for the least feasible Horn model containing A or bottom for this failure. An empty negative clause makes every closure fail.

For each actual Horn model C put e_C(X)=1[C⊆X], evaluated only on Horn models. These columns are linearly independent over F₂: the incidence matrix in an inclusion-compatible ordering is triangular with diagonal one. They form a basis of all Boolean functions on that finite domain. No explicit enumeration of Horn models is necessary. A support records the nonzero coefficients of a function in this basis. The constant-one function has the single key cl(empty) when feasible; an empty Horn domain has empty support. On this domain, multiplication of e_C by x_i gives e_cl(C union {i}), with a failed closure giving zero. More generally product with a positive monomial indexed by A closes C union A in one step. Equal outputs are XORed and can disappear. Negative literal factors 1+x_i add the previous support to its x_i image.

Start with constant one and successively multiply by the indicators of the external constraints. For parity equation sum_{i∈M}x_i=b its satisfaction indicator is 1+b+sum_{i∈M}x_i in F₂. Thus a single XOR row takes one pass over the current support per variable in M, plus at most one copy of the support. For an arbitrary signed clause, skip tautologies and remove duplicates. Its violation indicator is the product of x_i over variables occurring negatively and of (1+x_i) over variables occurring positively. Apply these factors to the present support, closing all mandatory variables together, then XOR the violation result with the original support. The empty clause cancels every key. A long positive clause can cost exponentially many terms but need never be expanded in advance. All operations preserve the actual acceptance indicator, including on inconsistent Horn or parity inputs.

Final support is empty exactly when no Horn model satisfies every residual constraint. Every inclusion-minimal retained key C is an actual satisfying assignment: evaluating its expansion at C gives precisely one. Conversely every satisfying assignment contains a support key, hence contains an inclusion-minimal support key which is also satisfying. Thus the inclusion-minimal support keys are exactly the inclusion-minimal satisfying assignments. Choosing a minimum-cardinality key gives a minimum-cardinality satisfying assignment, which is replayed against original Horn, residual CNF and parity constraints. The sum of its columns over F₂ does not itself give an ordinary integer model count.

Fix the multiplication order. Let S be the maximum support seen including partial accumulators and let L measure the row and literal input size. There are O((L+1)(S+1)) keyed closure evaluations and comparable dictionary operations, aside from polynomial overhead for copying and input checks. Each closure is a polynomial-time Horn propagation; identical seeds may be memoized. The reference reports actual distinct closure queries, maximum support, canonical final support and a witness. A support cap raises a distinct error rather than reporting unsatisfiability. The time bound depends on intermediate support, not only final support size.

For a chain x_i implies x_(i−1), every feasible closure is a prefix of the chain, so even the accumulators contain at most n+1 keys. One can impose arbitrary-width residual clauses and independently many XOR rows. At the other extreme, with empty H a single positive clause on n variables has exactly 2^n−1 final terms, while independent constraints x_(2i) XOR x_(2i+1)=1 have exactly 2^r terms for r pairs. Both examples are easy by other methods. These are lower bounds for the explicit support and not for general satisfiability algorithms.

The checker independently enumerates each Horn model poset and Möbius-inverts the directly evaluated desired predicate. It covers all 14 meet-closed domains on two variables (including the empty domain), all 16 residual truth tables and all eight XOR rows, plus larger random nonlinear/negative rules, a long-clause example, a chain and budget controls.
