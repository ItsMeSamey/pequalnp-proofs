# A matching polynomial certifies nonzero scalar evaluations on arbitrary native layouts

At a fixed integer shift t, provide symbolic attenuation z on every matched row bit and zero elsewhere. Call the resulting summed native polynomial Z_t(z), so F(t)=Z_t(h_t). Let p be the number of all-positive clauses and d_i the number of matched ports of positive clause i. All other signed clauses have constant one at zero, as do the equality and unary variable tensors. If some d_i=0 then F(t)=0. Otherwise the coefficient of the least degree p in Z_t is the positive integer N=∑_b∏_i∑_{matched ports k of i} b_{j(k)}. Here b are the m subdivision bits on the old edges. Real row-to-real column routing at one shift is a partial injection, so each bit occurs at most twice across this expression.

Construct a multigraph on the p positive clauses, with one edge ij for each bit read at two distinct clauses i,j. A bit read twice at the same clause gives no graph edge. For a matching S of this graph give each edge ij weight 1/(d_i d_j). Then

    N=2^(m−p) (∏_i d_i) ∑_{matchings S} ∏_{ij in S} 1/(d_i d_j).

Expand the p sums by choosing one matched port per clause. If the choices collide c times (two selected ports use one bit), exactly p−c distinct bits were selected, and their joint sum is 2^(m−p+c). The factor 2^c is the number of subsets of the collisions. Reorder the sum over such subsets. Forced simultaneous collisions use disjoint clauses and thus form a matching. Each forces one particular port at each endpoint. All other vertices retain d_i ways to choose a port. This proves the formula, including parallel edges for distinct bits. A doubled bit inside one clause can be chosen in two ways but a single choice cannot collide with itself.

For input families whose positive clauses have width at most two, this graph has degree at most two. Compute the weighted matching sum with two-state dynamic programming on each path and cycle, handling parallel edges of a length-two cycle as alternatives. This takes polynomial bit time; for instance N≤2^m∏_i d_i and the denominators of intermediate local formulas have polynomial bit size. For unrestricted sign/arity of remaining clauses this already gives a check on the full native scalar: the rational-root theorem for the integer polynomial Z_t(z)/z^p requires the reduced numerator of h_t to divide N if F(t)=0. When divisibility fails the value is certified nonzero. This includes even t and arbitrary legal layouts. Passing the divisibility test leaves the scalar unresolved, and the test addresses rational zero rather than a possible zero residue after rounding.
