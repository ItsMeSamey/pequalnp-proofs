# Single-exponential pin dependence for bounded root degree

Let Δ be the maximum number of distinct neighbors in the supplied loopless root. In the compression argument each fresh odd-support vertex attaches to a previously active vertex along the last edge of its new path. The prescribed odd endpoints must count as initially active, including those isolated in the initial multigraph skeleton. Consequently every fresh vertex admits an earlier parent and at most h≤2k fresh vertices are needed. The parent edges form a rooted forest with the m≤2k initially active endpoints as roots. A root-free instance can use the root reconstructed by the supplied recognition procedure and measure Δ there.

For fixed guessed endpoint parities, order the m roots once. Enumerate depth-first forest traversals, moving to the next prescribed root once the previous tree ends. A step either adds an unused nonforbidden neighbor as a child of the top vertex or pops that vertex. Never add a prescribed root as a new child. For j fresh vertices there are j downsteps and m+j pop steps. The strings of both types have length m+2j and every downstep has at most Δ choices. Thus the total is bounded by Σ_{j≤h} 2^{m+2j} max(1,Δ)^j. Every compatible forest supplies at least one traversal. Test both boundary problems at the completed forests, ignoring duplicate supports if desired. Roots with no fresh descendants contribute a single pop. If there are no prescribed roots, only the empty support is possible.

Overall time is (2+Δ)^{O(k)} times a polynomial in graph input size, including the parity guesses, with polynomial working space when traversals are streamed. This gives fixed-parameter tractability in k+Δ and single-exponential dependence on k for fixed Δ. The parameter is the skeleton degree; the root can have arbitrarily many parallel edges.
