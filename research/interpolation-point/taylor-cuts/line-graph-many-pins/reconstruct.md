# Recognizing the multigraph line-graph class and preserving pins

For an input simple graph G group vertices by identical closed neighborhoods, and take one representative per class. These classes are cliques and their members have exactly the same adjacencies outside their class. If G is the simple line graph of an undirected multigraph, parallel root edges always belong to one such class. Keep the original edges for the chosen representatives and delete the rest. The induced line graph on representatives therefore has a simple root: no parallel originals survive. For roots with loops, first replace each loop at v by an edge from v to its own new private leaf. Distinct edge IDs share an endpoint after this replacement precisely when they shared one before it.

Conversely recognize and invert the representative graph as a simple line graph, using the simple line-graph recognition algorithm cited in the three-pin theorem. If this fails the preceding necessity proves rejection. If it succeeds, replace each representative root edge by parallel copies indexed by all original vertices of its class. Their line-graph adjacencies reproduce G, including all distinctions among forced IDs. Different simple roots of a triangle cause no problem because the blowup needs only the adjacencies in the representative graph. Hence the multigraph pin theorem applies with no root as input. Grouping closed neighborhoods and constructing the root take polynomial time.
