# Finite-field baseline fibers plus Taylor moments

The October measurement design (overview lines 3359–3429 of the official TeX) uses integer block matrices C_g of row absolute sum at most D. An assigned replacement form on other blocks is a rational linear combination of their measurement rows. The source lists tuples of integer measurements. Instead reduce the entire polynomial calculation modulo a good prime; reducing only an integer lookup need not be valid.

Choose p exceeding the point range and Taylor precision and avoiding the raw rational denominators. Over F_p compute directed incoming/outgoing cut bases of all baseline demand rows and, separately, all positive-order correction rows. Extend rank-taylor.md messages at order k by two more indices: parent external baseline values and the exact outgoing baseline fiber of internal assignments. At a sibling merge enumerate both outgoing child baseline vectors. Together with the parent's input these determine the incoming baseline vector of each child by exact restriction maps. Project the two child outputs to their unique parent output. Apply the graded correction-moment merge to those entries, preserving the m+k_B≤q−k_A bound. The fiber partition is exact for the original sum reduced modulo p: all clause factors are rational polynomials and every Boolean assignment contributes in exactly one residue bucket. This does not assert that an arbitrary integer predicate is determined by a residue.

For individual directed baseline and correction ranks at most β and ρ, each node costs polynomial overhead times p^O(β) (q+1)^O(ρ), plus actual leaf integration. Compute every necessary node jet and interpolate over the same field. Reconstruct the original count in [0,2^n] by CRT once the product exceeds 2^n. With polynomial total denominator bit length and polynomial precision, polynomially many polynomial-size good primes suffice. Recomputing bases modulo each prime permits incidental rank drops and avoids unnecessary exclusions of basis-specific denominators. Signed/weighted final outputs need a corresponding separate magnitude bound.

Strict example: adjacent negative binary clauses, n bits, contiguous source blocks of b=Θ(log n). Define L_i=Σ_{j≤i}(b+1)^{block(j)}x_j and M_i=Σ_{j≤i}x_j. For every occurrence set P_i(1+z)=L_i+z M_i+z²(x_i−L_i+M_i), restoring x_i at T=0. Assign each edge clause to its left endpoint's block. At every point the remote source blocks need only popcount and first-bit measurements, hence D≤b and ≤2 rows per block. The popcounts realize at least (b+1)^floor(n/b) tuples; at t=1 a full weighted prefix can distinguish exponentially many integer values. Each interval cut sees only two common prefix patterns plus constantly many endpoint rows, in both directions, for baseline and corrections. Thus the bounds are constant and each leaf has only 2^b polynomially many assignments. Coefficients have polynomial bit length. This is a structured restoration design, not a universal property of the October layout.
