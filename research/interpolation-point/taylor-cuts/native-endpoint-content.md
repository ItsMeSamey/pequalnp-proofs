# Full native endpoint content

Let m be the old-edge count, M=2m, α=2L, b the number of distinct subdivision bits in matched active rows at t, and U=m−b. Neutral rows can be omitted. With P packets b≤P(L−|t|). For any k, [z^k]F(t+αz) belongs to 2^max(k,U) Z_(2). The shifted grid cardinal W_xy has degree-j coefficients divisible by 2^j: every normalized linear factor α/(t−s′) is even and unmatched rows use α/(t−y+x) as their mandatory linear factor. A degree-k term uses h≤k nonconstant row kernels, each reading one bit. Summing the unused bits gives another 2^max(0,m−b−h). At most one distinct shift denominator can have valuation a, so a positive row degree j even gives valuation ≥2j−1. With R active rows a refinement is k+max(0,k−R)+max(0,U−min(k,R)).

Replace unread bits by Y_j/2; the associated row coefficients W_xy/2 are integral at two. In Y_j²=2Y_j apply ℓ(1)=ℓ(Y_j)=1. This implements the normalized expectation (f(0)+f(2))/2. Summing the b ordinary bits and integrating the U new bits gives F(t+αz)/2^U. At residual precision 2^h, 1≤h≤a+1, only slots y≡x+t mod 2^(a−h+1) survive, because a nonmatched coefficient divided by two has valuation ≥a−v₂(t+x−y). Thus ≤2^(h−1) slots appear per row. For h=1 a row reads its matched ordinary bit or its wrapped slot as zY_j if real and unread, and otherwise zero. Repeated normalized bit references obey Y_j²=0 modulo two.

For m independent negative units at t=−L the only surviving row input in the normalized parity model is zY for its own slot, with a distinct bit per clause, and variable rows are neutral. Hence F/2^m reduces to (1+z)^m. For m=2^j−1 every k≤m reaches the bound exactly. This sharpness fixture uses a grid point outside the stipulated active Hermite set. The universal proof includes active nodes.

An implementation can compute the quotient at precision p_t−U and restore 2^U before applying all Hermite weights. U≤M/2 and p_t≥8M(a+1), giving at most a 1/[16(a+1)] fractional reduction by this argument alone. Dividing already rounded quantities costs precision. Child packet tensors need not preserve the independent true subdivision bits; the gain cannot be claimed at every depth. No general asymptotic SAT gain has been proved.
