# Replacing any unpinned shore of cut rank at most two

Partition a simple graph into an unpinned shore A and its complement. Let the binary adjacency matrix across the cut have rank two. Factor it as LRᵀ over the binary field, and give each vertex its corresponding two-bit row label in L or R. For a selected set in A, let c be the XOR of its labels. Let b be the XOR selected on the other shore. The required internal degree parity at a selected vertex of label u is b·u. Conversely, a selected vertex of label v outside sees external parity c·v. Therefore the response of A is completely described by attainable pairs (b,c). Summing internal degrees gives b·c=0. The empty set realizes c=0 for every b; a singleton of label c realizes (b,c) whenever b·c=0.

Since the cut has rank two, at least two independent nonzero labels occur. If all three occur, every orthogonal pair is attainable. Otherwise denote the two present nonzero types by U and V, and put W=U+V. The only remaining question concerns outgoing W. There are two orthogonal inputs, zero and a unique nonzero b*. For b*, vertices of either nonzero type require odd internal degree, while vertices of zero type require even degree.

* At input b*, W is attainable exactly when a connected component of A contains both types. If each component has only one type, the handshake lemma forces an even number of selected vertices of that type. Conversely choose a shortest path between any opposite-type vertices, minimizing over all endpoints. It is chordless and all interior labels are zero, giving the required response.
* At zero input, a nonadjacent pair of opposite types immediately realizes W. In the remaining case all U vertices are adjacent to all V vertices. Then W is attainable exactly when a connected component induced by the zero-label vertices touches both types. A shortest path between opposite types through such a component, together with the direct edge, gives an induced even cycle; take a shortest such path with at least one neutral interior vertex, allowing the closing edge as its only shortcut. If no neutral component touches both types, put each selected neutral component with the one type it can touch. For an outgoing W the numbers of selected vertices of both types are odd. The cut between the two classes then has an odd number of edges, which is impossible in an even graph.

Both conditions cannot fail: without any connected component of A meeting both types, an opposite-type nonedge exists. This yields three representatives. If both tests succeed, use three independent vertices of labels U,V,W. If only the zero-input test succeeds, use two independent vertices U,V. If only the nonzero-input test succeeds, use adjacent vertices U,V. Attach a representative vertex of label u to each exterior vertex v for which u·v=1. A representative W in the first case can be new; its outside neighborhood is the symmetric difference of the U and V neighborhoods. Every feasible state has an original witness given by an empty set, singleton, independent pair, cycle or path as above. Recover the state from any solution of the reduced graph and replace the selected representative vertices with the stored witness.

At rank one the representative is one optional vertex of nonzero label, and at rank zero the entire unpinned shore may be deleted. The reduction preserves existence and yields a witness for any prescribed pins on the other side. It does not preserve counts. Given a cut and its labels, its table and original witnesses take linear time in the shore vertices and edges via component scans and multisource shortest paths; if an opposite pair is missing among edges, a neighbor-marking scan finds one in the same asymptotic time. Rank factorization and updating the exterior take polynomial time for a supplied cut.

In fixed rank-two coordinates there are precisely seven distinct tables: the universal orthogonality table, and six choices removing one state for one of the three nonzero output types. All are realized by the stated representatives. The exhaustive verifier checks all 966,108 labeled rank-two shore instances on two through five vertices. Directly enumerating every vertex subset for every input agreed in every case; the universal table occurred 885,036 times and each other table 13,512 times. [Verifier](check_rank_two_shores.cpp)
