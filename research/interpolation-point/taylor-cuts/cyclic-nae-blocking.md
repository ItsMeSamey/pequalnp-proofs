# Clause-private cyclic NAE gadgets and blocked-clause elimination

Assume tautology-free CNF with distinct variables per clause, widths ≥2. Replace each clause by a network of signed NAE constraints of arity ≥2, exactly realizing the prescribed boundary NAE relation on its literals plus one common reference (b≥3 terminals). Existence of extensions suffices; their counts may vary. Only original variables and the reference are shared between gadgets, no fixed constants, each external terminal exposed once. Gadget topology, cycles, fanout and choice may depend on the full formula.

**Pair lemma.** Normalize the boundary literal signs so the forbidden word is all zero. For any two boundary positions i,j take satisfying extensions A,B of the two singleton-flip words at i and j. At each gate partition literals by whether they change between A and B. Some group contains two opposite values in A. Otherwise the nonempty groups must both be uniform and opposite for A to satisfy, in which case toggling the changing group makes B uniform. Select an opposite pair in the same group. The resulting binary inequalities are satisfied by A and B and imply the original gates. In a binary component the flip status from A to B is constant. Hence no unchanging boundary terminal is in the component of i or j. If i and j were in different components, flipping just i's component in A would satisfy all selected pairs on the forbidden uniform word. Thus there is a simple path of binary constraints enforcing exactly their prescribed opposite boundary-literal values. Keep this path's narrowing steps plus all mandatory original binary gates; other gates stay untouched. Original binary gates cannot impose any relation on distinct boundary variables before narrowing because all pair projections of NAE_b are full. Nor can mandatory binary gates attach a third terminal to the path, since the larger selected system contained both A and B. The partial narrowing's binary subsystem therefore imposes only the desired pair relation on the boundary.

**Forcing a false clause.** Suppose C has distinct other clauses D_l, one containing the complementary occurrence for each literal l in C. Narrow one path in each D_l gadget to force its complementary literal opposite the reference. Choose the original variables so all literals of C equal the reference. Every local binary subsystem admits this assignment on its terminals; disjoint private extensions combine consistently. All untouched gadgets' binary subsystems project freely. Yet C is now false so the full narrowed network is unsatisfiable. A passing sum-free certificate would be preserved under the local incidence deletions, and binary consistency would guarantee satisfiability by signed-nae-arbitrary-arity.md. Contradiction. In every nonempty pure-free linear CNF the opposing neighbors are distinct at every clause. Uniform linear 3CNF satisfiability is NP-complete, as proved by Porschen, Speckenmeyer and Zhao, https://kups.ub.uni-koeln.de/54898/1/zaik2006-520.pdf .

**Consequence.** If C is blocked on no literal, then for each l there is a D_l yielding a nontautological resolvent with C on l. Such a D_l cannot contain the complement of another literal of C, so the neighbors are distinct. Therefore EVERY clause of any formula with a passing gadget certificate is blocked. Each stays blocked after other clauses are deleted (no new opposing partners), so ordinary blocked-clause elimination empties the original formula. Restore clauses in reverse: when one is false, flip its blocking literal; each opposing clause has a true complementary literal from the tautological resolvent. This recovers an original witness. The implication is one-way and pertains to decision/search, not counting. An initial unit propagation pass is permitted; the conclusion applies to its residual. Blocked-clause elimination and reverse repair are discussed in https://fmv.jku.at/papers/HeuleJarvisaloLonsingSeidlBiere-JAIR15.pdf .

**Cyclic example.** NAE(a,b,x), NAE(c,d,y), NAE(x,y,t), NAE(x,y,NOT t) enforces x≠y internally and realizes NAE4 existentially. The boundary-fiber histogram has zero on two forbidden words, four on the four words where both exterior pairs split, and two on the ten other words. For an even exterior selection A,B,C,D put H=A+B=C+D. Let U,V be the first internal gate's x,y selection bits; both t ports equal U+V and the second internal gate uses H+U,H+V. Evaluation gives the split-tree phase A+B+C+AB+AC+BC plus (1+H)(U+V), all in GF(2). Setting U=V=0 recovers the split phase, despite the nonuniform fiber sizes and genuine internal cycle.
