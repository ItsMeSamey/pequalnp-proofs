# Independent audit of Boolean pass certificate replay

Reviewed main verifier SHA-256 4cf03f3cd5201fd13fb866c872c044a44ecd9fb9a4706ffd1c19bc209c7805c6 and statement SHA-256 f7f970b950bf2289d28a453abf9e1c57edc138700d30c126faba8ec6156de50c. Relevant imported sources were cluster_pass_rail.py (8ef6a51ed79c6e306ca595ece09d688803401ebb40fcb9a1109cd08f92479d39), finite_pass_rail.py (708108ae83687b8e1d683808cd0040da4885ade635dc5b4bd534b4b5d2006b50), gram_pass_rail.py (793ad58b6b7836c3b8f2c83329abe7ba5b43e25a1c7c517c90af0dda7ed0a414), and commuting_toggle_rails.py (cfa94386fef240e037af36fa1fe1f3951879ad8878ece3f0f92fc35594da9f31).

For well-formed explicitly encoded rails, verify fixes the field to two, the trace flag to false, and never calls the producer's candidate-selection branch. It uses supplied masks only after cut-domain validation. The forward pivot routine builds coordinate row spaces one pass at a time by masking columns. The suffix routine processes one independent cluster-prefix selection at a time by a block-diagonal permutation update and compresses the reachable linear row space after each cluster. It processes each permitted start separately. Inserting a row eliminates its first nonzero entries by earlier pivot rows until zero or a new pivot, so the sorted resulting pivot indices characterize greedy column independence. Ordering claimed columns first checks inclusion, regardless of redundancy.

If M is the explicit certificate length plus rail description, both the numerical size d of the explicit domain and all list sizes are charged. Each forward rank call has at most O(M) columns and O(M) retained rows, with at most d² newly selected coordinate types per preceding row per pass. Each suffix rank call has O(Md) slots and at most O(Md) retained rows; it performs polynomial work per retained row and supplied prefix choice, per cluster and start. No product of prefix-list lengths or exponential tensor coordinate array is built in the main verifier. Reconstructing gates and masks, and repeating these polynomial routines over all cuts, preserves polynomial time. This does not imply polynomial time for finding short certificates or polynomial length of all certificates. With implicit binary-encoded huge domains the dimension is not bounded by encoding length and the stated size convention is necessary.

The independent fixture checker cluster_pass_explicit_verifier.py imports no production code, executes original signed gates in listed order and computes dense prefix tensor columns by enumerating all input/output coordinate tuples. For suffixes it enumerates the full Cartesian product of each cluster's supplied prefix masks and every allowed start, executes the original gates, and tests column span by separate integer-bitset GF₂ elimination. The intentionally exponential reference is solely a small-domain cross-check. Its test harness imports produce only as a source of candidate certificates and compares every reported answer to exhaustive original gate evaluation. 87 SAT and 33 UNSAT certificates passed. Separate targeted perturbations of nonvacuous suffix closure, cut masks, local prefix coverage and closing permutation failed. No correctness gap was found in the stated well-formed explicit-domain replay theorem.
