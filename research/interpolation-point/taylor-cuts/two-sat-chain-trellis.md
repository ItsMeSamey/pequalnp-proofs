# A chain and syndrome-width parameter for signed 2-SAT with arbitrary XOR rank

Supply an ordered partition into lists of signed literals, using every Boolean variable exactly once. Require that the formula entails each consecutive implication in each list. Verify this in polynomial time with one 2-SAT test per implication by forcing its antecedent and negating its consequent. Thus a feasible list takes one of its length-plus-one monotone threshold patterns. Arbitrary further clauses involving only that list filter the thresholds directly. Chains of length one always exist; finding an optimum partition or ordering is a separate problem.

Form the graph of binary clauses between lists on the original Boolean variables. Pin a supplied vertex cover of size c, or use the endpoints of a maximal matching as a polynomially constructible two-approximation. Each branch turns cross-list clauses into satisfied clauses, unary tests or a contradiction. After the unary tests, the choices on different lists are independent before the XOR constraints are imposed. For each list enumerate its feasible thresholds, their variable values and their contributions to the original vector of XOR rows. Keep one actual local witness per distinct syndrome. Translate one attainable syndrome per list to zero and adjust the target t accordingly.

For the cut after list i let P_i be the span of earlier translated syndrome lists and Q_i the span of later lists. A partial syndrome v can contribute only if v∈P_i and t+v∈Q_i. Store only reachable v satisfying this test, retaining a realizing assignment on processed variables for each v. All completions depend on v alone. Every live set is contained in an affine translate of P_i∩Q_i, hence consists of at most 2^w states for w=max_i dim(P_i∩Q_i). Gaussian elimination supplies the suffix tests and dimension values. At the final cut t survives exactly when the branch is satisfiable. Replaying the stored assignment gives an original signed-CNF/XOR witness.

Taking w as the maximum over pinned branches gives 2^(c+w) polynomial(input) time, since each threshold list has length at most n+1, and 2^w polynomial(input) space. An a priori w bound computed before pinning is also valid: deleting choices shrinks each difference span regardless of which remaining baseline is used. The parameter does not depend on the number or density of the written XOR rows. The core is a multi-choice syndrome trellis, a different approach from enumerating small generating seeds of the Horn closure.

An explicit connected family has twenty two-variable implication chains, nineteen cross-chain clauses forming a star with one-variable cover, and twenty independent XOR rows. First constrain the parity on each pair to one, then mix the row system by the invertible binary matrix J+I in this even dimension. Each resulting row touches 38 variables but the chain syndrome directions are independent, yielding w=0. The solver finds the unique witness.
