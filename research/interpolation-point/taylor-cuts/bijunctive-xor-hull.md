# Constructive affine hull and parity witnesses for 2-CNF

Use the usual implication graph of a 2-CNF, with each clause (a∨b) giving ¬a→b and ¬b→a. Discard tautologies, identify repeats, and handle empty and unit clauses directly. Unsatisfiability occurs exactly when a literal and its opposite belong to one strongly connected component (or an empty clause occurs). On a satisfiable input, negation gives an order-reversing involution on the reachability order of SCCs. Each model chooses an upward-closed set containing exactly one SCC from each opposite pair. A component C is impossible if C reaches its opposite, and forced if its opposite reaches C. All other pairs are free: the closure of either choice is consistent, and any consistent upward-closed pin set extends to a model. Indeed when neither sign of an unassigned variable is fixed, a choice can fail only through an internally inconsistent closure or conflict with an already fixed value. The latter would force the opposite value into the existing closure by contraposition; the former cannot occur for both choices on a satisfiable formula. Repeated greedy closure therefore completes the pins in polynomial time.

For any two models M,N, take a reachability-minimal true C in M minus N. Remove C and insert its opposite. Any distinct true predecessor of C in M would also have to be outside N, contrary to minimality. Any strictly required successor of the newly inserted opposite that was previously false would have its opposite as a distinct true predecessor of C by contraposition. The new opposite cannot itself require C, since N chooses that opposite. Hence the new choice is a model and decreases distance to N by one complementary pair. The graph of models under SCC-pair flips is connected.

There is a concrete, polynomial procedure giving a model pair for every free SCC pair C,neg(C), even when a given baseline does not admit that flip. Force all strict successors of both SCCs. They are consistent: opposite literals among the strict successors of one SCC would force that SCC to imply its opposite. A literal among strict successors of C whose opposite is a strict successor of neg(C) would put that opposite in the SCC neg(C) by contraposition, contradicting strictness. These pins are compatible with C. Complete the pins together with C to a model and flip just this SCC pair; all strict new successors are already true, and all distinct predecessors of the removed SCC are false by contraposition. All assignments here refer to original variables and are recoverable.

Write Δ_C for the binary mask of the underlying variables in this pair. Every model satisfies the forced literal constants and the signed equalities within each SCC. These equations have the affine solution space base + span{Δ_C: free pairs C}, because the masks are disjoint and changing one flips exactly its signed class. The adjacent model witnesses prove that each Δ_C is an actual model difference; hence this space is exactly the affine hull. In particular inequalities remaining in the original implication order impose no further affine equations. For linear label map L (one vector per variable), return L(base) and a Gaussian basis of the vectors LΔ_C. Add a constant offset for affine labels if desired.

For a scalar functional of L, if all these variations vanish then the baseline parity is the only attainable one. Otherwise one adjacent model pair differs in parity, so one of the two explicit endpoints has the requested parity. Combining that endpoint with the baseline on independent variable blocks recovers a full witnessing assignment. These blocks are the connected components of the variable interaction graph (or form weak implication components after also linking complementary literals); weak literal components alone must not be treated as independent choices.

For several target parity bits keep the baseline and an echelon table T of gains from at most one binary whole-block replacement per previously processed component. Every vector in span(T) is attainable relative to baseline because those components are disjoint. If the target difference lies outside the sum of the full block hulls, return UNSAT. Compute the label-difference hull of a remaining block modulo span(T). At rank zero discard the block while retaining baseline; its possible gains cannot increase the attainable span. At rank one choose an adjacent-pair image difference with nonzero quotient. At least one of its two endpoints differs from the block baseline in that nonzero quotient, giving a concrete replacement. Store its actual gain and provenance, then restart the scan. Rank-zero and rank-one processing preserves the exact combined attainable set up to the new span: all gains lie in at most two old-span cosets and both occurring cosets have representatives. If the remaining target lies in T, use elimination tags to reconstruct an assignment. A remaining target outside T with stalled higher-rank blocks is UNKNOWN. For example the single NAND constraint on two variables with identity labels has full hull but lacks target 11. Adding a free third variable carrying the first label makes the NAND block rank one in the quotient and all four targets attainable.

The implementation bijunctive_xor_hull.py computes reachability explicitly and uses exact bit-mask elimination. All computations are polynomial in the explicit instance, label lengths, and number of controls. The separate checker bijunctive_xor_check.py covers all 256 two-variable clause subsets from four unit and four binary clauses and 180 additional seeded systems. It compares hull spans to every Boolean model, replays each adjacent witness, tests scalar parity witnesses and soundness of the partial multi-XOR decision, and checks the stated stalled and successful peeling cases.
