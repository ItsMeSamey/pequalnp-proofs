# Six present labels leave at most one unresolved cell at cut rank three

Factor the cut adjacency over the binary field as LRᵀ. The unpinned shore has vertex labels u in F₂³ given by L. An incoming parity b and outgoing parity c are feasible when a set S has XOR of labels c and each selected vertex of label u has induced degree b·u modulo two. Handshake forces b·c=0. Zero output always works, and any present nonzero output type works at every orthogonal input by taking its singleton.

Suppose the only absent nonzero label is c. Partition the six other nonzero labels into the three pairs {u,u+c}. For fixed b orthogonal to c the two vertices of such a pair have equal prescribed parity b·u. They alone realize c whenever their adjacency is b·u. If the bipartite adjacency between any of the three pairs of classes is mixed, this certifies every input. Otherwise let d_i denote the constant adjacency for pair i. The only candidate for an infeasible input satisfies b·u_i=1−d_i for all three pairs. The representatives project to the three nonzero vectors of F₂³ modulo the line generated by c. Thus an input exists only if the three right sides sum to zero; when it exists it is unique. With two missing types, two intact complementary pairs remain for each missing output, and their projections are independent. Again at most one state per missing output escapes this pair check.

## Exact representative once the exceptional bit is known

For the universal response use seven independent vertices, one of each nonzero label. For the table missing only (0,7), use vertices labelled by binary integers 1 through 6 and edges (1,2), (1,3), (1,6), (2,3), (2,5), (3,4), (4,5). Direct enumeration of the eight subsets with XOR 7 finds none with all degrees even. The complementary pairs are all adjacent, certifying every other orthogonal state. Linear relabelling gives the example for any missing type c. To move the exception from input zero to b orthogonal to c, pick an alternating binary matrix J with Jc=b and toggle adjacency between vertices u,v by uᵀJv. Such a matrix exists by extending c to a basis and setting its first row and column to the required covector in that basis. The change in the selected degree of label u at output c is uᵀJc; the self term vanishes. Singleton certificates for all present outputs remain valid. These representatives preserve feasibility. Recovering an original witness for a feasible exceptional state requires a witness for that instance; a representative by itself does not supply one.

The exhaustive check on all 32,768 graphs with one vertex of each nonzero type except binary 7 found 27,584 universal tables and 1,296 for each of the four possible single-cell deletions. [Verifier](check_rank_three_nearfull.py)

## Why the unresolved bit persists with six types

Start from any three-pin all-even induced-subgraph instance. Give the pins distinct unit labels e₁,e₂,e₃ and all other vertices label zero. Require output c=111 at input zero. Add three vertices d_i labelled c+e_i. Give d_i an edge to every vertex whose label has i-th bit one. This prescribes all three dummy-to-dummy edges consistently, and no loops. In a set with output c, d_i has odd selected-neighbor parity, so no dummy can be selected in an all-even witness. The six-type instance is therefore equivalent to the original three-pin instance. It is exactly the exceptional input of the pair check.

For the reverse conversion take a rank-three, six-type exceptional query, and first remove the incoming marks by the alternating switch above. Let H contain the three independent label rows and choose a nonzero linear combination a of them with a·x=0 required by the target. Retain two rows h₁,h₂ completing a to a basis; their required values are c₁,c₂. Toggle all edges among vertices in the support of a and prescribe internal degrees a_i instead of even degree. On selections of parity a·x=0 the toggle changes each selected degree by exactly a_i; conversely the prescribed-degree instance enforces a·x=0 by handshake. Add three required vertices with neighborhoods h₁,h₂,a+h₁+h₂. Put a single edge between the two pins requiring odd pin-degree, or none if all even, to realize the vector (c₁,c₂,c₁+c₂). For selected old vertices the aggregate pin-degree parity equals a_i, so all degrees in the augmented graph are even exactly on valid selections. The third pin equation follows from the other two and a·x=0. Both directions construct witnesses. Thus the exceptional-bit test is polynomially equivalent to the unrestricted three-pin problem.

One can also fill missing nonzero types in an arbitrary rank-three target-c all-even query without going through the pin representation. Let D be the absent types other than c, so |D|≤3. If c is outside their span, take a functional t with t(c)=1 and t(D)=0. Adjoin one dummy of each type in D and connect it to vertices on which t is one. Dummies do not connect to one another and all have odd degree if selected at output c. Otherwise choose t with t(c)=0 and t(D)=1 at each missing type. The sole obstruction would be an odd subset of D summing to zero or c. A singleton cannot do so. Three types summing to zero span a plane containing c, which would imply one of the three is c. Three summing to c leave the three present nonzero types summing to zero, contrary to cut rank three. With alternating J satisfying Jc=t, connect any dummy u to vertices v according to uᵀJv. The rule agrees on dummy pairs, and each selected dummy has degree parity t(u)=1 at output c. Thus the padded instance retains precisely the same witnesses on that query.
