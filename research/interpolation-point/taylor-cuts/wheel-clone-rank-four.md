# A rank-four target cylinder beyond local Gaussian and low-degree linearization checks

Start with the six-vertex wheel in three-row-obstructions.md, SHA256 42f04f6056fbb515768c9d8c592864cbd11d75dc88ac758da3d41aca2007228c. Write L1 for parity on all rim vertices, L2 for the indicator of vertex 3, L3 for parity on vertices 2,5. In low-bit-first order, even witnesses for syndrome numbers 0 through 6 are, respectively,
```
empty, {1}, {0,1,3}, {3}, {0,1,2}, {2}, {2,3}.
```
The previous note proves that syndrome 7 is absent and its indicator L1 L2 L3 is outside the span of q_i and x_j q_i for q_i=x_i(Ax)_i, Boolean squares reduced.

For any m≥2 replace each wheel vertex by a class of m vertices carrying the same labels. The hub class induces a clique, each rim class is independent, and two classes form a complete join precisely on wheel edges. For any induced even subgraph, project to the set of classes with odd occupancy. At a selected vertex of an odd class, the internal induced degree is even both for a clique and for an independent class. External parity is the number of neighboring odd classes modulo two. Thus every odd class has even degree in the wheel projection. Conversely any wheel witness lifts by taking one representative of each selected class. The entire syndrome image and sole missing point are unchanged. A degree-three certificate as above on the larger graph would restrict, by setting all but one variable in each class to zero, to such a certificate on the wheel, an impossibility.

The row space of the three syndrome forms is class-constant and zero at all hub vertices. For each clone i, its unit vector e_i is not class-constant. At a rim clone its neighborhood row A_i contains all hub vertices, as does A_i+e_i. At a hub clone A_i is the full set except i and A_i+e_i is the full set. Consequently each block of local tests (e_i,A_i) has rank two modulo the syndrome row space.

For a genuine rank-four graph-state chart put a=L1+L2 (its required parity is zero), complement all off-diagonals within supp a to obtain A', give each vertex its mark a_i, and retain the two independent checks L2=L3=1. On any marked witness, handshake forces a(x)=0. For such x, the two marked conditions are equivalent to the original all-even conditions, and L1=L2. Hence the requested target is impossible. By the reverse reduction in affine-nae-bounded-rank-normal-form.md its generalized Fourier rank is exactly four. All blocks have rank two even after the retained parity constraints are imposed, since A'_i differs from A_i by a_i(a+e_i) and a belongs to the old three-row space. Thus simple local degeneracy removal has no applicable gate.

There is also a direct degree-two obstruction in this marked chart. The defining local quadrics are q'_i=x_i((A'x)_i+a_i)=q_i+a_i x_i a(x). The marked graph is connected through its hub vertices. Its only homogeneous linear identity on feasible marked sets is a(x)=0: each unmarked singleton is feasible, and a shortest path between marks with no other mark inside is feasible. Such marked pairs connect all marks after suppressing unmarked stretches of paths, so these feasible vectors span the full even-mark-parity hyperplane after allowing unmarked singletons. The empty set rules out inhomogeneous identities with nonzero constant.

Suppose L2 L3 belonged to the linear span of the q'_i and products of a(x) with any affine forms. Multiply the identity by 1+a(x) and use Boolean squares. On the left (1+a)L2 L3=L1 L2 L3 since a=L1+L2. On the right all multiples of a vanish and (1+a)q'_i=(1+a)q_i. This would give the forbidden degree-three representation for the all-even chart. Accordingly this false degree-two target cylinder has no such certificate, even after adjoining every true linear identity and its products with linear forms. This family tests specific methods; it gives no computational hardness result.
