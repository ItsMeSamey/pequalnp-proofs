# Deterministic original matching from a nearly feasible binary port code

Suppose all original matching projections belong to a nonempty affine code y=y₀+Uz, z independent in F₂^r. Assume on every feasible projection total ternary gain is a specified affine F₃ function of port indicators (checkable by F₃ matching span). Let explicit affine events E_j in z cover every unliftable point, and require an ordinary matching constructor for the others. Let δ=Σ_j Pr(E_j), counting overlaps, using exact dyadic Gaussian ranks.

Over F₃ expand each bit as (1−(−1)^{y₀,e}χ_{u_e}(z))/2, with χ_v=(−1)^{v·z}. For scalar target t form P=1−(g−t)², coalescing Fourier indices by xor. Its support size D is quadratic at most in port count. Orthogonality holds in F₃ since the code's order is a power of two. Therefore P≡0 is an unconditional NO.

For P nonzero retain a basis of at most D actual translates P(z+t_i). Start at P and close the independent coefficient rows under unit-coordinate translations, applying each to each newly retained vector and Gaussian-reducing. Each translation is diagonal multiplication by signs; record its binary shift. The resulting span contains every translate. For every z some retained translate is nonzero; otherwise all translates vanish there, impossible.

When Dδ<1, choose z avoiding ALL translated events z+t_i∈E_j. The expected sum of these event indicators is at most Dδ. Condition the free bits sequentially, always choosing a value not increasing this expectation; Gaussian elimination computes each conditional probability. At the final point the number of events is a nonnegative integer below one. Evaluate the retained translates, lift any accepted one, and check original edge IDs and gain. This uses polynomial time in code, support and event list, independently of 2^r. A nonzero P with larger error bound is inconclusive. Strictness matters: on one bit take P=1+χ and the sole bad event its support. Then Dδ=1 and no good nonzero point exists.

For a graph partition into modules, suppose each intermodule edge joins distinct modules and each port vertex has at most one intermodule edge. The code imposes at each module parity of the number of selected links equal to module order. Given a pattern, delete the selected port vertices and find a perfect matching internally. Internal endpoint-sum edge labels suffice for the affine gain condition, or certify a semantic fit globally. Clique modules realize every local parity pattern. If clique modules all have order at least three, their partition is recovered as components of triangle edges, since a cross edge cannot lie in any triangle. Verify the partition before use.

For arbitrary supplied modules whose internal simple complement has maximum degree h, any even residual of order at least 2h+2 has minimum degree at least half its order and thus a perfect matching (Dirac for orders at least three; order two direct). Enumerate smaller nonmatchable vertex subsets containing all nonport vertices. Each gives an exact local port pattern and hence an affine bad event. This costs n^{O(h+1)} poly(input) without listing every port assignment. For a connected loopless macrograph remaining connected after each vertex deletion, the incident d_i edge bits at module i fill the prescribed parity hyperplane, since remaining demands sum to zero and are solved on a spanning tree of the remaining graph. Each consistent local pattern then has probability 2^{−(d_i−1)}. There are at most Σ_{j≤2h+1} binom(d_i,j) small residual patterns. For fixed h and m links, min_i d_i≥8 log₂(m+2) makes Dδ<1 for sufficiently large m; exponential decay dominates the fixed polynomial uniformly in d_i. For all sizes test Dδ directly. This can succeed when some genuine parity patterns are unliftable. On arbitrary graphs the actual F₂ matching affine hull still gives the polynomial P≡0 negative filter, but nonzero on that relaxation alone is not a positive answer.
