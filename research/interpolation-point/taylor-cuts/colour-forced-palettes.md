# Forced equalities and signed triangle palettes in the graph colour target

The statements apply directly to proper three-colouring, hence to the determinant all-one target on graphs without isolates and to the bijective odd-parity one-hot chart.

**Equality closure.** If a,b are adjacent, every common neighbor has the unique third colour. Therefore all common neighbors of any edge can be identified. A loop created by the identification certifies unsatisfiability. Quotienting by a forced identity induces a bijection of labelled proper colourings, even with additional graph constraints; duplicate edges can be coalesced. Re-scan after every successful merge. A certificate gives the anchor edge and the common-neighbor vertices in the current quotient for each merge, then a loop. There are fewer than |V| nontrivial mergers. Representatives can be used to lift witnesses, with no multiplicity factor. The stopping graph need not be three-colourable. With a literal K4-minus-edge as the only rule, a triangle-free graph permits no initial merger. The contraction principle has prior graph-colouring literature. [Unavoidable contractions in a 3-colouring algorithm](https://pmc.ncbi.nlm.nih.gov/articles/PMC3544923/).

**Parity of triangle frames.** Enumerate graph triangles and label each by three ordered ports. For any pair of vertex-disjoint triangles with three cross-edges matching port k to π(k), every proper colouring induces bijections f_i,f_j from ports to palette. The permutation f_i⁻¹ f_j π has no fixed point; both derangements of three symbols are even. Hence sign(f_i)sign(f_j)=sign(π). All matching permutations can be tested between all triangle pairs in polynomial time. A cycle of constraints with negative sign product is a certificate of infeasibility. Relabeling the ports changes the signs incident to one frame uniformly and preserves cycle products. This test may be used on the original graph or a forced-equality quotient. After passing the sign tests, relations on rotations still have to be satisfied: consistent signs are not a positive certificate.

For each m≥4 take a cycle of m disjoint triangle layers. Use identity matchings between consecutive layers except for a transposition on the closing matching. The signed cycle is inconsistent. This graph is connected and 4-regular and its only triangles are the individual layers: matchings prohibit two vertices of one layer having a common neighbor in another, and the layer cycle has no triangle. In particular it contains no diamond at all, making the frame-parity refutation strictly more applicable on this family. These examples have girth three.

**A distinct fixed-girth template rule.** For any fixed g choose a maximum-degree-six non-three-colourable host of girth at least g, and extract an inclusion-minimal non-three-colourable edge subgraph H, removing isolates. Such hosts exist by fixed-girth conditioning in colour-gate-obstruction.md. Removing one edge st gives a three-colourable two-terminal gadget E_g whose proper colourings all identify s and t: otherwise the deleted edge could be restored. The edge st was on a cycle (a bridge cannot make distinct endpoint colours impossible, by independently relabeling one component), hence the tips are at distance at least g−1 in E_g. The local premise for this stronger contraction rule must itself be certified, e.g. once by exhaustive enumeration for the fixed finite H. Unlike diamond detection, rule recognition can be implemented by enumerating injections of E_g into a graph and checking all template edges. Extra edges can only restrict valid colourings. The polynomial degree and precomputation depend on the template.

Concatenate m copies of E_g by identifying successive tips, and add a single edge joining the two outside tips. Every copy forces equality, contradicting the closing edge. Each cycle lies in a single gadget unless it uses the closing edge, in which case its length is at least m(g−1)+1. Degree is bounded by ten, and size grows linearly in m for fixed g. Equality propagation gives a certificate of length O_g(m) for the supplied copies. If the internal gadget variables are eliminated altogether in an exact count, each fixed-colour realization count must be accounted for. Equality identification retaining the rest of the gadget is already parsimonious. This construction does not prove that small certified gadgets occur in a typical high-girth random graph. For variable girth, the separate template certification and search costs are not uniformly polynomial merely from the construction.

## Exact disjoint-layer implementation

prism_colour_quotient.py accepts a simple undirected graph on vertices 0 through n−1. A supported presentation partitions all vertices into triples inducing triangles; between any two layers there are either no edges or precisely one three-edge perfect matching. Validation accounts for every original edge. A supplied order of the three ports is preserved. Without supplied layers, the solver enumerates graph triangles. Where every vertex lies in exactly one triangle their partition is forced. When transversal triangles give alternatives, the solver searches exact partitions, checking cross-matchings as layers are selected. An exhausted search with no partition returns UNSUPPORTED; an explicit recognition-node cap returns UNKNOWN if the search has not finished. With no cap recognition is exact, although general partition search can be exponential. For example K3 square K3 admits triangles in both directions. After finding one valid partition the solver works with that presentation.

Identify ports and colours with Z/3. Every triangle frame can be written f_i(k)=s_i k+r_i with s_i∈{+1,−1}. A matching π from i to j has π(k)=a k+b. If s_i≠s_j a there is a k with f_i(k)=f_j(π(k)); if the signs agree then avoiding all three equalities is exactly the single condition r_j−r_i≠−s_j b. Propagate signs with root sign +1 per connected component. This loses no feasible instance: negating all colours in a component switches its root sign and preserves every constraint. If propagation fails the result carries a closed cycle of layer indices with verifiably negative matching-sign product. Otherwise there is precisely one oriented gain disequality per base edge. Each feasible rotation assignment with these sign choices lifts to an original graph colouring; independently reflecting components accounts for other sign choices if counting is considered. The function reports decisions and witnesses, not counts.

Peel any base vertex having at most two live neighbors. Restoring it after those neighbors are coloured excludes at most two rotations. An empty residual core therefore yields a witness by greedy restoration. If a nonempty core exceeds the caller's core_limit (default zero) the result is UNKNOWN. Within the explicit cap, enumerate all 3^k core rotations, giving UNSAT only after exhausting that finite set. Every returned SAT witness is replayed against all edges of the original graph.

check_prism_colour_quotient.py passed 400 small random comparisons against exhaustive enumeration of triangle frames, ten growing balanced and unbalanced rings through 500 layers, and a 45-by-45 base grid with 6,075 graph vertices. It also checked ambiguous partitions, unsupported cross-edge patterns and core-budget outcomes. Total measured run time here was 2.392 seconds. The solver is a standalone graph backend and has no effect on the previously hashed default SAT driver.
