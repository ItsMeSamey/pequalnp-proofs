# Field-independent kernel, root-finding and signed boundary joins

Start with the symmetric completion B of rank b≤3r from recognition.md, or reject if its forced disjoint minor exceeds r. A feasible completion B+D of rank ≤r has diagonal correction D supported on at most s=b+r positions since rank D≤s. Peel s+1 disjoint maximal row bases of B, each spanning all rows remaining at that step, and mark their union H. Every outside row lies in the span of every peeled basis. At least one basis is clean (disjoint from supp D). Let T be identity on H, replacing every outside column e_i by a combination of the clean basis with BTe_i=Be_i. Symmetry gives TᵀBT=B. Since all replacement vectors avoid supp D, TᵀDT keeps just the diagonal correction on H. Thus restricting changes to H suffices. Retain H and, as fixed-diagonal guards, one row basis of the outside rows of B. Every discarded row is spanned by those guard rows, and this remains true after arbitrary changes on H. Applying the same linear identities to columns gives exactly the rank of the guarded principal submatrix. Its size is ≤b(s+2)≤3r(4r+2). Fixed guard diagonals are essential. Restriction and witness restoration hold over every field. A second derivation independently checked the congruence and guards.

Over a prime field, introduce one unknown per free diagonal and set all (r+1)-minors of this kernel to zero. Degree, variable count and number of equations are bounded by functions of r. [Chakrabarti, Dwivedi and Saxena, Theorem 1](https://www.cs.columbia.edu/~sayak/files/HNpk_24.pdf) gives randomized search over a specified finite field, in time polynomial in d raised to a function of variable count, number of equations and log p. Use their prime-field specialization k=1. The resulting time is f(r)poly(n,log p), including witness recovery; check any returned completion by elimination. The paper describes Frobenius descent via absolutely irreducible components and lower-dimensional intersections. An F_p point on a non-F_p component must lie on the intersection of its Frobenius orbit, since the point is fixed. Ignoring those intersections can miss isolated rational points, for instance the origin of x²−a y²=0 for nonsquare a and odd p. No deterministic polylog-p search bound is claimed.

A distinct deterministic option uses [Harvey, Theorem 1.3](https://arxiv.org/pdf/1402.3439). Count simultaneous zeros by inclusion–exclusion on nonzero-minor events. For a selected set of events all selected minors are nonzero iff their product is nonzero. Count that hypersurface's zeros by splitting into coordinate zero patterns; each remaining domain is a torus. Homogenize, using its nonvanishing homogenizing coordinate to raise the degree by one if necessary so p does not divide it. Treat zero or constant polynomials directly. Harvey's zeta function gives the number of rational points. Its explicit bounds yield deterministic f(r) sqrt(p) polylog(p) decision after preprocessing. Try up to p values per free diagonal successively to recover a witness in f(r)p^(3/2)polylog(p) time. Therefore for CNF primes p=O(m) even deterministic witness preprocessing is rank-only FPT in ordinary input size. The subsequent sketch count still costs p^(r+1).

For the signed defect profile list of recognition.md, let U_j^i denote the indicator of profile j's pins after the first i variables in a chosen ordering. The rational Gram matrix G_i(j,k)=sum_a U_j^i(a)U_k^i(a) is zero for incompatible suffix pins and otherwise a power of two given by their free suffix count. A row v of coefficients has zero residual function iff vG_i=0, by positivity over Q. Start from the list of signed coefficients. Extend each reachable row-space basis vector by bit 0 or 1 using coordinatewise compatibility masks, then select an independent set modulo ker G_(i+1) and compute transition coordinates by elimination. This is valid on quotient classes because restriction preserves residual-function equality. Its discovered dimensions equal the true rational prefix/suffix flattening ranks, and no suffix assignment grid is enumerated. Basis rows can always be chosen among actual prefix restrictions of the original list. Thus their entries are masked original coefficients, and polynomial bit bounds for rational transition weights follow from minor bounds. Contracting the resulting state transitions with the quadratic additive sketch costs poly(N,L) preprocessing and O(n p^(r+1) max_i(rank_i)^2) rational arithmetic rather than one complete sketch run per profile. Evaluate the joint DP scaling denominators by common per-layer factors to keep polynomial bit lengths. This can save time after preprocessing when rank² is small compared with list length; enumerating an already enormous profile list remains a cost. ETH's learned hierarchy instead verifies polynomial rules for local gates or reconstructs canonical continuation states. No automatic compilation from unmaterialized profile lists is claimed.

Numerical control: gram_check.py compared explicit suffix truth-table Gram matrices and full flattening ranks with the symbolic pin-overlap formula at 72 cuts using exact rational arithmetic. The 50 diagonal-rank tests in rank_check.py concern the greedy 3-approximation; the O(r²) kernel has an independent mathematical proof, not a benchmark for either finite-field root-finding backend.
