# Semantic cut rank of binary CNF: parameterized classification

Input is a 2-CNF, a supplied cut X|Y and width w; use the Boolean truth-table matrix interpreted over a specified fixed field. Write t=w+1. Rank exceeds w iff some Boolean t×t submatrix has nonzero determinant in that field. Enumerate nonsingular binary patterns and name t left and t right assignments with copied variable blocks. For each 1-cell impose the original binary formula on its indicated pair of blocks. To realize a 0-cell one may guess a violated input clause and require its at most two literals false. All remaining constraints are 2CNF. Direct enumeration costs 2^{t²}max(1,m)^{t²}poly(N,t); if either shore has fewer than t assignments reject immediately.

**W[1] membership of exceedance.** For each pattern form the copied 2CNF H for its 1-cells, dropping unsatisfiable H. Create one vertex class per zero cell, with one vertex per possible violated clause whose required unary pins can jointly extend to a solution of H. Join two vertices from different classes if their combined pin bundles extend to H (2SAT). A full multicolored clique implies joint feasibility across every bundle: any minimal obstruction to extending pins in a satisfiable binary formula has size at most two. Indeed existential elimination of other variables by resolution preserves width at most two. A violating pair of pins would therefore already be witnessed in one or two bundles. Conversely a witnessing submatrix supplies vertices of a full clique. Pad the classes of each of the boundedly many patterns to the same number, at least two, with universally compatible vertices attached only within that pattern's instance, then take disjoint union. This is one parameterized Clique instance with ≤max(2,t²) colors, of size f(t)poly(N). Uniformity in arbitrary specified fields requires effective tests of the small Boolean determinants (prime fields allow modular arithmetic; Q is also immediate).

**Hardness.** Given a graph with k colors, the prefix has one selector per vertex. Negative binary clauses forbid incompatible pairs (same color or absent edge). The suffix has only k freely chosen bits y_c. Add x_v⇒y_color(v). Each feasible prefix selects a colorful clique whose color set U has row ∏_{c∈U}y_c. All other prefixes give zero rows. The distinct monomials are linearly independent over every field by the unit-triangular subset zeta matrix. The family of reachable color sets is downward closed; it contains all 2^k precisely when a rainbow clique exists. Hence w=2^k−1 gives a parameterized reduction. Complementing y turns the entire formula all-negative and only permutes columns. For a two-point rank promise, add k disjoint complete colorful (k−1)-vertex graph components, one missing each color, with no links between the original graph and dummy components or between dummy components. All proper subsets are realized, and a full-color clique still requires the original graph (k≥2). Thus exceedance is W[1]-complete and rank at most w is co-W[1]-complete on a prescribed cut, even for satisfiable all-negative formulas and no internal suffix constraints. This does not establish hardness for checking all cuts in a tree promised small away from one cut. It is recognition hardness; a supplied bounded-semantic-width decomposition still supports the representative-state counting algorithm in semantic.md.

**A tractable graph restriction.** For all-negative graph 2CNF with Y independent, semantic rank equals the number of distinct outside neighborhoods N_Y(S) for independent S⊆X, by the same monomial proof. If X is independent too, build unions by adding one variable at a time, stopping as soon as there are w+1. If instead G[X] has a supplied tree decomposition of width a, use a bag-subset independent-set DP, recording the union of Y-neighbors of all selected vertices in the processed part. Every partial independent set is a global independent set after setting all omitted X bits false. Hence any collection of more than w distinct partial unions already certifies exceedance, allowing safe truncation. At a join compatible bag assignments combine by union. Runtime 2^O(a)(w+1)^2 poly(N), including exact rank and neighborhood witnesses when rank ≤w.
