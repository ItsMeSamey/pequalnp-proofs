# Mixed OR, AND and XOR fixed points

Solve all affine XOR update equations simultaneously to obtain an affine set A over F₂. Return zero if empty. For each OR gate let H_i⊆A specify every input literal false; for AND use every input true. These flats are computed before pinning gate outputs and may be empty, equal or ambient. Outside H_i an OR's required output is one and an AND's zero; inside it is the opposite. Build L of all distinct nonempty intersections, including A, by intersecting with each successive H_i and deduplicating canonical affine systems. This takes poly(N,|L|) time. For each F∈L impose pins P_F on ALL nonaffine outputs according to whether F⊆H_i. The fixed-point count is

    Σ_F Σ_{G⊆F} μ(G,F) |G∩P_F|.

Indeed each x is indexed by the intersection of all H_i containing it, default A. The indicated pin set at that unique stratum is exactly its gate test. Möbius inversion for each F filters out smaller strata, always using P_F, including at G. All remaining counts use Gaussian elimination. The Möbius coefficients have O(|L|) bits by the chain formula. Character weights (−1)^(c+a·x) work as well: an affine sum is zero unless a annihilates its direction space, otherwise sign times size. General unary code weights are outside this bound. Laminar flats give |L|≤q+1. Alternatively q nonlinear gates yield 3^q signed affine terms by expanding each gate as default-output indicator plus exceptional-flat indicator times difference of exceptional and default output indicators.

Nontrivial feedback example (n≥2): y_i=OR(x_1,...,x_i) and x_i=x_i XOR y_i XOR y_(i+1), indices on y cyclic. All y must agree. Exceptional flats are nested zero prefixes, and the strongly connected network has 2^(n−1)+1 fixed points (all-zero x or x_1=1). The dependency graph is strongly connected via x_i→y_i→x_(i−1) and x_1→all y.

At the other extreme one unbounded-fan-in AND added to OR gates already yields #P-hard exact counting on strongly connected monotone networks. For a height-two poset use x_i=OR(x_i,g,predecessor bits), g=AND_i x_i. Every upset lifts uniquely: g=0 unless every x is one, in which case g=1. All variables are mutually reachable via g and every listed gate input is locally essential. Self-dependencies may be removed by replacing each poset site with a bidirected OR triangle. The hardness uses unbounded AND fan-in, and syntactic dependency need not survive algebraic inlining. [Provan and Ball](https://doi.org/10.1137/0212053).

Signed graph compilation: a triangle on variable, complement port and private activity −1 vertex sums to the indicator that variable and complement disagree (hard-core edge excludes both true). Complement ports have activity one. Use the hidden OR edge in cyclic-or.md for each OR; use complemented output and complemented input literals to express AND by the same edge. Choose activity −1 on variables output by OR/AND, one on XOR outputs. OR now contributes constant −1, AND constant +1. Each XOR equation has a linear-size parity-chain implementation with uniquely determined auxiliaries, expressed by bounded clauses. An activity −1 vertex adjacent to the true-literal ports enforces each such clause. Thus the signed graph scalar equals (−1)^(#OR) times the simultaneous network count. This mixed transfer assumes supplied equations or verified gadget roles. Independent algebra review checked the stratification and signs; 120 random mixed networks matched exhaustive counts.
