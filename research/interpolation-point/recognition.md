# Recognizing phase dimension

**Polynomial-time 3-approximation over any field.** Greedily grow an invertible off-diagonal P=A[I,J] on disjoint sets, appending distinct outside u,v whenever A_uv−A[u,J]P⁻¹A[I,v] is nonzero. At stopping size t all distinct outside pairs have zero Schur residual. Set every outside diagonal to A[u,J]P⁻¹A[I,u], choose other diagonals arbitrarily, then eliminate P. The residual is covered by t leftover rows J and t leftover columns I. Its rank is ≤2t, giving total rank ≤3t≤3r* where r* is minimum rank. This removes pivot guessing even when p grows with input. The sketch DP uses at most p^(3r*+1) states.

**Exact finite-field kernel.** Group indices whose rows agree outside their pair. Symmetry implies transitivity, homogeneous cross blocks and constant internal off-diagonal c. A rank-r completion has ≤p^r distinct rows so reject if class count exceeds this. Retain ≤r+2 representatives per class. A truncated class has principal block cJ+D with diagonal D of rank ≤r+1, so some retained representative has diagonal c in any rank-r kernel solution. Duplicate its row and column to restore each discarded copy. On the ≤(r+2)p^r kernel enumerate principal pivots and their diagonals as in odd.md. Cost p^O(r²)(r+2)^O(r)poly(n,log p). This is FPT jointly in p and r.

**Compressing many long clauses.** Group variables with equal signed incidence column across d defect clauses after removing tautologies and duplicate literals. Let s be the number of nonempty incidence types. Falsifying a clause pins each touched group wholly to zero or one. Iterate inclusion-exclusion with a map from class-pin profiles (free/0/1) to signed integer coefficients. Start at all-free with coefficient one. Each clause retains a profile with coefficient c and on compatible joins with its falsification pins subtracts c at the resulting profile. Discard conflicts and zero coefficients. The number of profiles is ≤min(2^d,3^s); final coefficients have O(d) bits. Run the quadratic core DP once per surviving profile. Core columns need not coincide inside a class. This can also be parameterized by the measured maximum number of live profiles, checked while running.

**Recognize nonquadratic affine character support.** Given reduced polynomial F with each variable degree <p, compute H={v:F(x+v)−F(x) constant}. Start with the full space and descend j=deg(F)−1,...,1. On the current subspace differences have degree ≤j, and the degree-j part is linear in v since translation preserves the top degree and differences compose by addition after translation. Translate F on a basis and take the coefficient-map kernel. Uniqueness of reduced polynomial functions proves exactness. Complexity is polynomial in the size M of the monomial downset, n, degree and log p; M need not be small for a sparse high-degree input. Constant differences are linear on H. Extend the linear functional, strip that character, then the remaining phase depends only on n−dim(H)=b quotient coordinates. Conversely Fourier inversion shows every shift perpendicular to all support differences induces a constant phase difference; hence b is the minimum affine dimension of Fourier support on the full field. Compute quotient transform in O(b p^(b+1)) operations plus function evaluations, or tally quotient coordinates directly on Boolean assignments. Recognition on the full field gives a sufficient representation on the Boolean cube. Generic odd-order characters still introduce fields on the core.

Classes can be grouped up to negating the entire column by complementing the affected variable's bit convention for the pins; convert each pinned bit back before the core DP. Ignore all-zero columns. The independent audit checked 17,920 assignmentwise profile values. Compared with ../eth-fullspan-20261126/{composition,learned-dag}.md, profile joins require no fitted polynomial, training, exceptional-profile set, or auxiliary wire. The learned hierarchy can compress gates whose functions fit a short polynomial even when signed incidence columns are all distinct. These are complementary parameterizations; neither gives a general polynomial SAT bound.
