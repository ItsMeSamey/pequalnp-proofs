# Odd-prime phase surplus and direct CNF decision

For an explicit odd prime p and primitive root ζ, extract binary tables over Q(ζ) whose nonzero cross ratio Q00 Q11/(Q10 Q01) equals ζ^j, assuming no table entry is zero. Test against p powers exactly and move endpoint factors into unaries. Extracted signs become ζ^q(a), q=½aᵀAa+bᵀa+c over F_p. Binary a_i²=a_i permits arbitrary diagonal entries with a compensating linear term. Minimum rank up to a budget r can be recognized: for s≤r enumerate s-index sets I and their p^s diagonal assignments, retain invertible P=A[I,I], and check all off-diagonal entries against A[:,I]P⁻¹A[I,:], taking the remaining diagonal from that formula. A rank-s symmetric matrix has an invertible principal s-minor by symmetric elimination with one- or two-index pivots. Cost is sum_s binom(n,s)p^s poly(n,log p); using the raw matrix costs only elimination. A uniform clique becomes rank one with a suitable diagonal.

The normalized Fourier transform on F_p^n has support b+im A. For λ in that coset solve Ay=b−λ; the coefficient is p^(−r) G ζ^(c−½yᵀAy), with G=sum_t ζ^(½tᵀPt) over F_p^r, using any invertible quotient Gram matrix P. Complete the square and sum over the kernel. The expansion remains pointwise valid at binary a. Enumerate G once. Each λ multiplies the spin-one weight at i by ζ^λ_i. Cores allowing arbitrary unaries cost p^r evaluations. For surface Pfaffians cover the previous genuine fields, support of b and nonzero rows of A, or use a separate cover per call. Routing θ^a to θ^b via a disagreement-only factor requires θ=θ⁻¹ by the assignments (1,0),(0,1); odd-order phases generically add genuine fields. Arithmetic for rational/integral symmetric core tables, cyclotomic fields and explicitly supplied gauges uses Q(ζ), of polynomial degree in explicit p, with the prior Pfaffian and bit bounds. This does not extend positive-rational recognition automatically to arbitrary cyclotomic core tables.

For a CNF put m clauses of width at most two in a core and d arbitrary clauses in a defect list. The sum of the products of false-literal indicators of the core is a nonnegative quadratic E bounded by m on Boolean inputs. Simplify repetitions using a_i²=a_i. Take an odd prime m<p≤O(m+1) so E=0 mod p exactly characterizes satisfaction. Write E as above, choose pivot set I, and use dynamic programming on r+1 residues, adding each assigned variable's column in A[I,:] and its coefficient in b. At the end evaluate quadratic part as ½(A[I,:]a)ᵀP⁻¹(A[I,:]a). Include/exclude violation events of the d other clauses: each selected event pins variables and contradictory pins give zero. Add the signed integer counts; positivity decides satisfiability. Cost is 2^d p^(r+1) poly(input) plus chosen rank-recognition cost. The d clauses can be arbitrarily long. A small fixed prime without a range guarantee is unsound: p copies of one violated unit clause produce E=p. Different primes need common-witness certification.
