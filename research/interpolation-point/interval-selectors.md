# Protecting zero cells without occurrence bounds

Use syntactic crossing pattern rank on every cofactor exactly as in selectors.md: remove incompatible clauses, strip assigned literals, deduplicate, and keep redundant subclauses and superclauses. No propagation, subsumption or SAT test is applied before measuring rank.

For binary clauses any nonempty crossing cell has at least two variables across its shores. It has no strict extender in a binary core. Thus for a finite menu of L trees and width w the selector budget e can be searched in (1+2L(w+1)^2)^e 2^e poly(N,L) time regardless of occurrence. For a clause support that is an interval of a supplied common variable order, conditioning restricts that order to its unassigned variables, preserving interval supports. Let T be the nonempty support of a witness zero cell. If T has an internal hole, its gap coordinate belongs to every interval containing T, so that one extra guard suffices. If T is an interval, any strictly extending interval contains its immediate predecessor or successor in the restricted order; use both when present. Hence ≤2 guards per zero without occurrence dependence, and the search bound replaces k+Δ by k+2 for max arity k. For the common interval condition alone, fixed k and deduplication already imply a function-of-k occurrence bound, since there are few short intervals through a point; the two-guard proof gives a sharper branching bound. The general certificate is a small hitting set for each zero cell's excess-variable supports. If excess supports form intervals in a supplied order, a minimum such guard set can be computed by repeatedly taking the right endpoint of the earliest-finishing remaining interval. This is a local condition, needed only at the searched witness cells; its measured stabbing number may be small even with high occurrence.

**Width-three parameterized barrier for a specified cut.** Reduce parameterized Set Cover with budget e. The prescribed shores X,Y are fixed. On X make e+1 distinct row variables of type A and e+1 of type B. All row patterns are one variable fixed to 0. On Y put a selector z_i per available set and e+1 private variables y_gt per element g plus e+1 reference anchors. Columns use bare anchor patterns y=0 or extended patterns y=0,z_i=b. Place both row types (every corresponding row variable) on every bare reference. On every bare element anchor put all A rows, no B row. For each i containing g, put BOTH types on each extended element column for both b=0,1. Interpret each nonzero cell as a single clause forbidding the union of its row and column patterns. All clauses have width two or three. The number of clauses is polynomial times (e+1)^2.

A set cover assigns at most e selectors z_i. Under each assignment to them, each bare element anchor receives its missing B entries, while surviving extended columns still have both types. The whole crossing matrix is all ones on its active rectangle, hence rank one over every field. Conversely consider any ≤e selector variables anywhere, including private rows/anchors. If the selected z_i fail to cover g, at least one variable in each of the A, B, g-anchor, and reference-anchor groups remains unselected. Restrict to those particular rows and bare columns: the reference column has both entries, bare g has only A. No extended clause can fill its B entry because every covering z_i is still present; another anchor cannot project to this surviving anchor. The resulting determinant is a unit over every field, for every assignment to the proposed selector. Thus the strong selector exists iff Set Cover does. This is W[2]-hard for parameter e at w=1, even width three, for ONE PRESCRIBED CUT. It does not establish hardness for layouts requiring every cut of one tree to pass: further cuts on the Y shore may retain arbitrary incidence structure after selecting a cover. The clauses contain deliberate syntactic redundancies; their removal changes the recognition problem. Formula satisfiability is trivial by setting all X variables to one.
