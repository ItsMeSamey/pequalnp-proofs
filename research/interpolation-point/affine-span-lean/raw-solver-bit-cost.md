# Bit cost of the raw indexed plane solver

The endpoint is ExactPlaneDeficitSolver.solvePacked, on N indexed sites with d supplied private bits, two tag bits and two gain bits. Write c for the rank of all observed keys minus the rank of keys present at every tag. Ambient coordinates can be dependent. Set m=2d and R=2(c+2)+1. For m>0 put r=⌊log₂(m·2ᴿ)⌋+1, q=2ʳ, s=q², Q=s+s³+s⁵. At m=0 the constructor uses one zero seed and skips the field.

**Cost model.** Use a deterministic bit-cost indexed-memory machine with strict evaluation, sharing of let-bound values, and erased proofs. Input coordinates have array-backed access. Charge lists per traversed or copied cell, finite sets of indices by linear membership and at most quadratic sorting, and persistent array pushes even for full copying. Reads, addresses, natural-number arithmetic and scalar cells are charged explicitly. Allow O(L²) bit operations for each bounded integer/address operation (schoolbook arithmetic); field scalars are binary. This is a source-level model of the named definitions, not a Lean compiler, allocator, or kernel time theorem.

**Bound.** With P=N+d+r+2, O((Q+1)P⁸L²) bit operations suffice, where L=O(r+log₂(P+2)+1) bounds pointer widths and numeric operands on the generated branch. For SmallChartFallback.solve use L=O(d+r+log₂(P+2)+1) because its comparison constructs the integer 2^(2d). Working memory need not be polynomial independently of c: ordered chart generation can retain Θ(Q) list entries. Even counting total allocations gives a coarse O((Q+1)P⁸L) live-bit upper bound in this model. For d>0, m2ᴿ<q≤2m2ᴿ; substituting this band gives 2^{O(c)} times a fixed polynomial in N+d+1. At d=0 the singleton seed gives constant chart count and polynomial total work. The site bound rank(observed keys)+2 is a separate witness theorem.

1. **Deficit.** ComputedDeficit.complete checks each site against all four tags, searching at most N sites for each; private-key comparison checks up to d coordinates. It does not enumerate private keys. keyRank runs twice using the eager original-ID Gaussian basis routine at width d+4, with four trailing zero bits. Sorting, index membership and the two reductions per inserted site are included below. Duplicate site keys are allowed.
2. **Modulus.** FastIrreducibleConstructor.fastConstruct calls DirectDivision.fastFind, not the older multiplication-factor search. It scans ≤q monic candidates, including even ones, and at most 2^(⌊r/2⌋+1)−2 monic proper divisor candidates per trial. IrreducibleSearch.words uses nested Fin.cons, so an access can take O(r). DirectDivision.remWord recurses once per Horner layer and materializes its previous remainder in a List.ofFn value, whose lookup may traverse O(r) cells. Each of O(r) layers tabulates at most r coordinates, each summing at most r terms. Allowing for chained coefficient lookups, suffix closures and finite enumeration, O((r+1)^6) elementary operations per divisor safely suffices. Total O(q√q(r+1)^6 L²). Construction uses the Boolean remainder test; quotient fields, irreducible existence and equivalences appear only in proof terms.
3. **Field rows.** EagerField.prefixTable accumulates concrete vectors. Each multiplication caches r shifted words and materializes every output coordinate; allowing for sum traversals and even copying every pushed array gives O((r+1)^4) operations. The m-power table is built once per field element x, beginning at one even for x=0; allow O(m²) additional pointer copies for that table. Every one of q functionals reads the table for m dot products, with at most r terms per dot and O(r) access for a nested Fin.cons functional. NumericalRows.words binary recursion has polynomial overhead per emitted word. The resulting s entries really are array-backed seed-coordinate rows, including duplicate values. The coordinate dot products exhaust the linear dual without a trace-basis assumption.
4. **Charts.** SuppliedCoordinates.tables turns a seed row into a *function* of the site index. It has not materialized all N chart values. Each call computes two d-coordinate dot products on the original private key. OddChartList.words eagerly constructs ordered words with repetition of lengths 1,3,5; repeated recursive calls within flatMap cost O(Q) up to constant depth/list factors, since each level repeats the preceding computation s times plus its output traversal. Mapping List.sum produces a shallow function with at most five seed terms. Checking a chart charges up to five new dot evaluations per site. Only solvePacked's returned chart is materialized. Even allowing construction of local index enumerations and linked direct-fallback coefficient accesses, O((d+1)^3) elementary operations per site/seed query suffices.
5. **Checking and recovery.** Each candidate filters N sites. EagerBank.check sorts these sites, constructs one eager Gaussian bank and queries five targets against that bank. At most N pivot rows are stored. A row clear examines a pivot bit and can allocate d+4 key and N provenance cells. Pivot selection and append are linear. On success EagerBank.walk recomputes a reduction inside insert and stores original IDs; its local function key can rebuild a packed row separately per coordinate read, so allow O((d+4)^2) for that materialization. Even with quadratic sorting and linear set membership, O(P⁵) elementary work per checked chart and for the one successful recovery pass is sufficient. No powerset is evaluated. Packed result reconstruction reads the successful chart again. The P⁸ envelope absorbs all preceding costs and allocation overhead.
6. **Optional fallback.** SmallChartFallback.solve checks all ambient charts directly only if 2^(2d)≤q². These are coordinate words whose reads can traverse O(d) nested Fin.cons closures; they bypass the odd chart list. The other branch may compute the deficit twice. With packed input reads both paths obey the stated envelope. Arbitrary externally supplied functions can have arbitrary evaluation cost and are outside this model.

Independent controls on the corresponding packed Python field generator checked 6,165 complete affine image systems at m≤5, and all field products and nonzero multiplication permutations at degrees 1–6. These check semantics, not running time.
