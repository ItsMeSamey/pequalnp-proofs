# Choosing the embedding

Bienstock–Monma's constructive algorithm takes the underlying planar graph, the active subset T and a cover budget k. In O(c^k n) time it rejects or returns an embedding and minimum cover. Hence no rotation system, partition or SPQR implementation is needed as an input. The resulting exact scalar uses 2^max(0,k'−1) Pfaffians where k' is the returned minimum. Only recognition uses the unweighted graph; contraction always uses the original weights. This matters because the later SPQR-based polynomial kernel preserves a decision problem. Its replacement subgraphs have no implied scalar identity. [Original constructive theorem](https://doi.org/10.1137/0217004); [SPQR kernel](https://doi.org/10.4230/LIPIcs.STACS.2026.50).

For k=1 add an apex adjacent to every demand and test planarity. Deleting the embedded apex gives the required face. For a supplied partition the same argument uses one disjoint star per nonempty part. If stars end up in the same face a common face still covers their union. Unknown partitions need not be enumerated in the plane. Example: in K_(2,4) write a,b,c,d for the four degree-two vertices. The rotation of the four parallel length-two paths can place a,c opposite (requiring two faces) or adjacent (one face); terminals a,c thereby give a smaller free-embedding minimum than in the first supplied embedding. K4 with all vertices active genuinely requires two faces: one apex yields K5, and two faces suffice.

For a connected graph admitting a k-face witness on orientable genus g with k≥1, add a single universal terminal ghost to the abstract graph. Its genus is at most g+k−1. Indeed draw one ghost star per used face, then add a handle for each tree edge joining the distinct ghosts and route that edge through the handle. Contract these auxiliary tree edges to merge the ghosts. Run a constructive fixed-surface embedding algorithm on the explicit augmented graph, trying genera up to g+k−1. Cap the complementary boundary components of a regular neighborhood if cellularization is needed. One anchored ghost now suffices; apply the 4^h surface Pfaffians with 2h guard bits at the returned genus h. The resulting cost is f(g+k)poly(N) plus 4^h poly(N,p+2h,jet size,input bit lengths). This computes the scalar, not necessarily a minimum k-face witness at the original genus. Both derivation and distinction independently checked by tensor/audit.
[Constructive fixed-surface embedding algorithm, Mohar](https://doi.org/10.1137/S089548019529248X).
