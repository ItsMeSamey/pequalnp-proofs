# The affine hull and one-shore changes on chains of path bundles

Use the bipartite pinned-edge chain-of-bundles graph in the [weighted rooted note](../neutral-radius/rooted-block.md). Each undirected path joins successive mandatory junctions. A nondirect path has a flow bit p, equal to its first and last internal vertex values. If p=1 all its vertices are selected. If p=0 its nonboundary interior is an arbitrary independent set and its first and last interior vertices are unselected. Each bundle has total flow one, with a direct edge contributing one when present. All choices satisfying these affine equations are realizable. Moreover the proof in the linked note derives every affine form constant on the family as its value in degree three, without taking a contrary weight marker as an axiom. In particular even though splitting on a purported opposite marker might only give a higher-degree implication in general, here cubic closure contains the full affine hull equations directly.

Join two feasible selections by a move whenever they agree on one entire bipartition shore. In each odd-length bundle, every nondirect path has both a first and a last internal vertex, on opposite shores. Hence its flow cannot change in such a move. In each even-length bundle all path flows can be redistributed arbitrarily subject to the bundle parity. Indeed both junctions lie on one shore. To change flows, first set every internal vertex on that shore to one on each affected path. On an inactive path these are isolated internal vertices, since the other shore can first be cleared there without affecting any active path. Then on the other shore select all internal vertices along newly active paths and clear them all along newly inactive paths in a single move. The fixed shore keeps the same bits, and the junction guards hold since the flow parity was preserved. For a fixed flow vector all optional isolated interior choices can be reset to zero in two one-shore moves.

It follows that the move components are exactly the fibers of the odd-bundle flow projection. For odd bundles with k nondirect paths, the projection contributes dimension max(0,k−1), independently across bundles. All those coordinates are values of actual vertex bits. The dimension of objectives constant along every one-shore move, modulo objectives globally constant, is the sum of these contributions. For the upper bound, in a component use the canonical representative that takes full active paths, clears all inactive interiors and chooses fixed flow distributions on the even bundles. Its vertex coordinates are affine in the recorded odd flow bits. For the lower bound take individual odd-path flow coordinates.

For example an odd bundle of k distinct three-edge paths parallel to the root edge (the root edge itself excluded from the bundle) gives k−1 independent directions invisible to every one-shore change. Such examples can have unbounded component count at treewidth two. Switching two complete odd paths at once, together with one-shore moves, connects the entire feasible set. This makes explicit the additional exchanges needed to recover all affine hull directions.

## Cubic degree can be necessary for an affine consequence

Use three junctions 0,1,2 and pin the root edge 0–2. The first bundle has paths (0,1), (0,3,4,1), (0,5,6,1). The second contains (1,7,2) and (1,8,9,10,2). The graph is bipartite. Junction 1 is one in every feasible support. A root-edge cut derives its pin at degree three as in the linked proof.

The [checker](check.py) finds six supports and two one-shore components. The dimension of all affine equations, including constant terms, is eight. Closing the native Boolean PC axioms over GF(2) in the squarefree monomial basis yields a degree-two space of dimension 46 with only four affine dimensions. It omits the junction pin. The degree-three space of dimension 226 contains all eight. At each threshold the row basis is ordered by degree so its low pivots span precisely the polynomials of degree below the cap; every such basis row is multiplied by each variable. Any ordinary degree-d inference maps to this squarefree closure, while these restricted products lift to ordinary degree d by Boolean reductions. Thus the junction pin requires exactly degree three as an affine consequence on a feasible instance.
