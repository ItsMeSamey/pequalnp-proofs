# A subfield weak-map test for an exact four-name plane

Consider two-bit equality spanning with a two-dimensional pin space. The inputs are binary physical columns t_e spanning V, offsets o_e and prescribed values on independent u₁,u₂ in V. The equality-active set must contain a physical basis. This is equivalent to recognizing the specified rank-two plane on four independent named elements. [Exact representation and converse](../equality-plane-bridge/README.md)

## Combining the two pins over an extension field

Subtract any linear extension of the prescribed pin values from all offsets, reducing them to zero. Identify the two-bit offset space with the additive group of F₄. Choose λ in F₁₆ outside F₄ and regard the binary columns as vectors over F₁₆. Set p=(u₁+λu₂,0) and let N be the ordinary represented matroid of the columns (t_e,o_e) modulo p. Let M be the binary matroid of the t_e.

**Exact test.** A basis B of M meets both pins under equality interpolation exactly when B is dependent in N. The columns of B give a unique F₄-valued interpolant b on the binary space, extended linearly to F₁₆. The lifted columns on B remain independent before quotienting. They become dependent exactly when their span contains p, equivalently b(u₁)+λb(u₂)=0. The two summands' coefficients b(u₁),b(u₂) belong to F₄ and 1,λ are independent over that field. A successful basis therefore supplies both pinned equalities on the same physical support.

Choose any M-basis B₀. If its interpolant b already vanishes on the pins, return it. Otherwise Δ=b(u₁)+λb(u₂)≠0, and B₀ is a basis of N as well: the whole quotient ambient space has dimension dim V. Normalize both representations on B₀ as [I|A] and [I|C]. In the normalized binary basis the nonbasis column e of C is explicitly

    C_e = A_e + (o_e+b(t_e)) (u₁+λu₂)/Δ.

The binary column coordinates of u₁,u₂ are used here. This follows by subtracting b from the last coordinate so that B₀ lifts with zeros, then eliminating the last coordinate by p. Thus the remaining query is whether every M-basis stays independent in N. In standard terminology a NO answer means the identity from N to M is a rank-preserving weak map. The direction of this containment matters. Lucas's results include equality for a connected image of a binary source; the algorithm below also handles disconnected M. [Lucas, Properties of Rank Preserving Weak Maps](https://doi.org/10.1090/S0002-9904-1974-13386-0)

## A deterministic support criterion

If some entry of A is one and the corresponding C entry is zero, the associated one-element basis exchange gives an immediate witness. Assume henceforth supp A⊆supp C. In a directed bipartite graph put an arc from row to column for each A entry and from column to row for each nonzero C entry. An extra edge is an entry present only in C. Say a C block normalizes to binary if one can scale its rows and columns by nonzero F₁₆ scalars to make every nonzero entry one. Propagating scale factors in the support graph checks this in polynomial time. The full C is normalizable precisely when its represented matroid N is binary: in any binary representation on the reference basis the nonbasis entries are its support bits. On an induced even support cycle, the corresponding square binary submatrix has two perfect matchings and zero determinant. The represented C must also have zero determinant there, so the two alternating products agree. Splitting cycles along chords gives this balance on every support cycle and hence consistent scaling factors. Conversely a successful scaling gives a binary representation, including rescaling the reference basis columns to restore the identity.

Within any binary-normalizable block, a shortest directed cycle containing an extra edge yields a witness. Its forward row-to-column edges form an A matching, its other edges a C matching. Any nonconsecutive C-only chord gives a shorter directed cycle containing that chord. A shared chord has both orientations and splits the original into two shorter cycles, one containing an extra. Thus the selected square C submatrix has exactly its two cycle perfect matchings and is singular after normalization. The A submatrix lacks an edge of the second matching and has determinant one. Exchange its selected reference rows for the selected nonbasis columns. Shortest cycles can be found by breadth-first searches.

If no cycle contains an extra edge, take any square minor having a perfect matching in A. The union of that matching and any C matching of the same minor decomposes into common edges and alternating cycles. A C-only entry in the latter matching would give a directed cycle with an extra edge. Therefore the matching sets of the two minors coincide, and their determinants have equal vanishing status when C normalizes to binary. This proves the complete test for binary N with no connectedness assumption.

It suffices to apply normalization on each strongly connected component of the directed support graph. Every A edge lies within one component, since it is shared. On every A-invertible minor the A matching balances the numbers of selected rows and columns in each component. Every C matching in that minor remains inside those components: pair it with the A matching and use alternating cycles again. Hence the C determinant factors over the indicated component submatrices. A witnessing exchange inside any component extends by the unchanged reference basis outside it. If every component block normalizes, this gives the full deterministic decision and an explicit basis on YES. A component failing normalization can be reported unresolved independently of any resolved YES elsewhere. This test may work even when the entire quotient fails normalization. No determinant over a general characteristic-two extension is inferred from matching parity alone.

## Controls and scope

The implementation uses F₁₆ modulo x⁴+x+1, with the binary encodings 1,6 as an F₂-basis of its F₄ subfield and λ=2. Run `python check.py` with the sibling binary aggregate and elimination helpers. The directed-cycle algorithm agreed with full basis enumeration for 8,192 pairs of normalized binary representations, including 6,998 with witnesses. In 800 separate four-name equality instances, 151 obtained a verified basis and 342 a verified NO. The method left 307 outside the certified cases; brute force found 53 YES and 254 NO among these.

A connected example has T=(1,2,4,8,1,2,3,5,9,12,13), with columns encoded as binary masks, offsets (1,2,0,0,0,0,0,1,1,0,1), and zero pins on (1,2). The seven directions in span(1,4,8) form an F₇ restriction. Relative to the first four columns, no single basis exchange suffices since at least one of the nonzero-offset pin columns would remain selected. The checker returns the basis with zero-based indices 2,3,4,5. This example uses two independent output residuals. Conversely nonbinary quotients can occur on NO inputs, so failure of normalization alone is not a positive certificate. The unrestricted exact four-name plane decision remains open.
