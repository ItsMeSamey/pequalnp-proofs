# 3-SAT as an exact full named kernel on a graphic host

For a 3-CNF with n≥1 variables and m nonempty clauses of at most three literals, construct a connected simple bipartite subcubic ordinary graph G, named binary columns B and a subspace K. The formula is satisfiable precisely when contracting some ordinary edges and deleting the rest yields named kernel K. The number of names grows with k=n+m. The decision problem with a variable number of named columns is NP-complete under deterministic polynomial-time many-one reductions. Gaussian elimination verifies a proposed contraction set. Inputs with no variables or an empty clause can be sent to fixed yes/no cases. Repeated literals and absent polarity occurrences are allowed.

For variable i make two internally disjoint rails joining its private terminals s_i,t_i, one rail for each polarity. Every occurrence of that polarity has two successive private vertices a,b on its rail. Empty rails receive a separate dummy vertex. For clause j introduce a terminal pair c_j,d_j. Join c_j to a and d_j to b for each of its occurrences. All clause and occurrence vertices have degree at most three. To connect different ordinary components, take a new path with one new vertex per component and a single bridge there to a variable terminal in that component. These bridges cannot occur on a simple path whose endpoints are in the same original component. Subdivide each edge once. This preserves vertex-disjoint linkage and yields a bipartite simple graph of maximum degree three. The construction has linear combinatorial size in variables, clauses and occurrences.

Ask for mutually vertex-disjoint paths joining all k terminal pairs. A variable path cannot visit any clause terminal, which is reserved for its clause path. Removing those terminals leaves the two rails as the only possible paths between the variable endpoints after suppressing subdivisions and pendant bridges. Declare the polarity on each unused rail true. Each clause path must begin by reaching a private occurrence vertex on an unused rail, so each clause is true. Conversely route each variable along its false rail and each clause via its own chosen true occurrence using c_j,a,b,d_j. All occurrence positions are private, so the paths are disjoint. Any valid linkage recovers a satisfying assignment. This decision and witness reduction need not preserve counts. Classical linkage theory gives polynomial time when the number of pairs is fixed. [Robertson and Seymour](https://collaborate.princeton.edu/en/publications/graph-minors-xiii-the-disjoint-paths-problem/)

Let A be the ordinary full vertex-edge incidence matrix. A vertex vector belongs to span A_X exactly when it has even parity in every component of (V,X), including isolated vertices. With a named unit-vector column at each terminal and K generated by each pair's two-coordinate sum, exact kernel K means each pair is in one component and no component contains terminals from different pairs. The component parity criterion proves both directions. Choose one simple path in each paired component; conversely use the union of linked paths for X. The unit version uses 2k names. Two alternatives preserve the same equivalence for every X.

* **Actual named edges.** Add one named edge joining each terminal pair plus a named path through the first endpoint of each pair in order. Prescribe that the pair-edge coordinates freely span K and the k−1 anchor path coordinates are independent modulo ordinary contractions. The first condition connects each pair. The anchor path remains independent exactly when its ordered anchors are in distinct components: a repeated anchor component makes a closed subwalk with distinct named edge occurrences and gives a dependence. This uses 2k−1 names and makes the entire augmented representation graphic. The simplicity, bipartiteness and degree bounds refer to the ordinary graph.
* **Fewer dense named columns.** Give the two endpoints of pair i the same distinct nonzero code p_i in h=ceil(log₂(k+1)) bits. Add k−1 anchor bits only at the first endpoints, with their k label rows q_i equal to a basis of F₂^(k−1) followed by its sum. For k=1 use zero anchor bits. These vertex labels are the rows of B. Take K to be the first h coordinate axes. The row space after contraction must be L=0×F₂^(k−1). Anchor sums of all components total zero and must span k−1 dimensions. Consequently at least k components contain an anchor, exactly one anchor each (for k=1 this is immediate). Each needs another terminal to cancel its nonzero short label. There are only k second endpoints, so they pair bijectively and distinct short labels fix the matching. Conversely the prescribed partition has precisely row span L. All named columns have even vertex parity and lie in the span of the connected ordinary incidence matrix. This uses k−1+h names. The matrix serialization is of polynomial size.

## Sharp terminal-label limitation

Suppose one assigns arbitrary b-bit row labels to the 2k terminals, and prescribes one exact kernel, requiring success precisely for the designated pair partition on every contraction forest of the complete graph on those terminals. The minimum b is k−1+ceil(log₂(k+1)). The preceding construction attains it.

For the lower bound write endpoint row labels as a_i,b_i, h_i=a_i+b_i, and L=span{h_i}. The successful row space must be L. Merging any two designated components must lower its rank. A linear functional on L vanishing on the other h's and on h_i+h_j must then take value one on both h_i,h_j. The evaluation code on k positions contains all two-position vectors, so dim L is k−1 or k. In the first case the unique relation among all h_i is their total sum zero. In the second case they are independent. Splitting one pair into singleton components cannot preserve L; hence the common coset of its two labels modulo L is nonzero.

If two pairs have the same coset, crossing their four vertices gives new rows still inside L. Work modulo the span of all unaffected h's, writing x,y for the images of h_i,h_j and D for the image of a_i+a_j. The two crossing options give unordered pairs of rows {D,D+x+y} and {D+x,D+y}. At dimension k−1 we have x=y nonzero, and one crossing retains the nonzero line. At dimension k the vectors x,y form a basis of a plane. The two pairs are its two cosets modulo 〈x+y〉, and precisely the nonzero coset is an independent pair. Either way one wrong crossing preserves L. The k cosets must therefore be distinct and nonzero, proving the lower bound. For k=1, splitting already requires one bit. This bound concerns preservation on every contraction by a terminal-label compiler. It does not constrain arbitrary decision reductions.

## Attempts to share components or change the host representation

The same per-contraction model limits an encoding that assigns many terminals to one specified component on a clique. For any target block of M terminals, its label rows modulo L sum to zero. No nonempty proper subset can sum to zero in the quotient: splitting that subset off would still give two rows in L whose sum is the old row, preserving the full span. Thus the quotient requires at least M−1 dimensions. This applies even to a single large prescribed group. Different graph gadgets may disallow such splits.

There is also a fixed-ground binary obstruction without a graphic-host promise. In rank d≥3 use ordinary columns e_i, all e_i+e_j, and e₁+e₂+e₃. These include a restriction isomorphic to F₇. Every hyperplane is spanned by ordinary columns: for its nonzero normal f, use units on zeros of f and pairs of units on ones, which span the even subspace on that support. The original target with d basis-vector roots is their full kernel, attained precisely by full-rank ordinary contractions. Any replacement with fewer than d named columns, even in a larger ambient space embedding the same ordinary host, has effective named span U' of dimension below d in the ordinary space. Pick a hyperplane containing U'. Contract its spanning ordinary columns. The replacement named kernel is identical to that after full ordinary contraction, whereas the original full-kernel target fails. This excludes a per-contraction re-labeling on the unchanged physical host. An unrestricted compiler may replace the ordinary representation or its interpretation.

## Checks and scope

Run `python check.py` and `python check_limits.py`. Graph-level backtracking on subdivided paths matched truth-table SAT on 102 instances (62 satisfiable, 40 unsatisfiable), and 186 positive named kernels were checked by Gaussian elimination. All three encodings identified exactly the desired partition on all 4,360 clique partitions through four pairs. All 273 assignments with fewer than three bits failed to recognize just the prescribed two-pair partition. The hyperplane check covered 498 hyperplanes in the nongraphic family. These finite checks supplement the proofs. Neither fixed-root NP-hardness nor a polynomial algorithm on this growing-root SAT image follows. A uniform deterministic polynomial algorithm on the complete reduction image would imply P=NP.
