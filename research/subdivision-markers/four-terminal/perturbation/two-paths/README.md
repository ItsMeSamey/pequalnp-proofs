# Two prescribed path components in the balanced-cycle branch

Consider a rank-one additive graphic perturbation as in [the connected-root result](../connected-roots/README.md). The remaining case here seeks a single simple balanced A-circuit containing two vertex-disjoint nonempty prescribed paths P1,P2. This note gives exact subcases and an obstruction to dropping the third measurement. The general three-measurement tree table is not decided by these rank tests. The graph-circuit decision itself is settled for two path components by the [separate root-projection proof](direct.md), which bypasses the tree measurements entirely. The gain-one and the two-odd-cycle branches retain their earlier algorithms for bounded root count.

## Reducing to three measurements on one tree

Write the path endpoints s,t and u,v, respective strict interiors I1,I2, total gains ρ1,ρ2, and per-interior prefix gains a_z measured from s on P1 or u on P2. First test for a balanced cycle containing both prescribed paths, ignoring demands. This requires routing the two remaining vertex-disjoint connections between the endpoint pairs in either cyclic order, after deleting both prescribed interiors and all prescribed edges. Guess their individual binary gains subject to the correct total; the fixed-number signed disjoint paths algorithm applies. If no such cycle exists reject. If the total demand is odd any such cycle suffices. Otherwise search again after deleting each demand outside the two prescribed paths. If successful that omitted demand certifies a valid A-circuit. For the rest of the argument assume every balanced rooted cycle covers all demands D. This preliminary test is part of the reduction.

Delete all prescribed edges and both strict interiors, then insert a distinct virtual edge e=uv with gain ρ2. Retain the relevant connected component containing all four endpoints. Its other vertices include every demand outside the two interiors, by the preliminary tests. Spanning trees T containing e encode all closures: the s–t tree path must use e and have gain ρ1. Expanding e to P2 and adding P1 then gives the required simple cycle. Conversely any closure without P1 extends to a spanning tree using e. If y is the tree potential, the remaining score condition is y·d=b, where

    d=(D minus (I1 union I2)) Δ ({s} if |D intersect I1| is odd)
                              Δ ({u} if |D intersect I2| is odd),
    b=XOR of a_z over z in D intersect (I1 union I2).

Indeed each interior spin is the corresponding initial spin plus its prefix gain. All remaining demands on a correctly signed closure lie on its cycle, and d is even.

Switch γ by a potential ψ with ψ_u+ψ_v=ρ2 so e has zero gain. Adjust the desired first score by ψ_s+ψ_t and b by ψ·d. Contract e to w, combining demands at u,v by XOR. Delete loops from the tree host. On each retained edge give a second sign σ=1 if its incidence at w came from v and zero otherwise. Tree choices are now unconstrained, since expanding w and adding e is a bijection with the spanning trees containing e. For the s–t path in a contracted tree, the sum of σ is one exactly when the path enters and exits w on opposite sides, i.e. the expanded tree path uses e. Thus, writing γ for the switched sign, J_T(a) for the unique tree a-join and d1={s,t}, we need the three-bit vector

    ( γ(J_T(d1)),  σ(J_T(d1)),  γ(J_T(d)) )

to be (ρ1+ψ_s+ψ_t, 1, b+ψ·d_before_contraction). The order of the operations matters: the switch correction uses the demand before contracting e. The two measurements from the connected-root case alone do not ensure that the path uses the second component.

## Local rank conditions and separating the contracted vertex

Decompose the contracted graph into its ordinary edge blocks, bridges included. Each even demand vector projects onto a block by moving every demand outside it to its attachment vertex modulo two. Each block choice of a spanning tree is independent; gluing the chosen trees yields a spanning tree of the whole graph. The restriction of each tree join is precisely the tree join for the corresponding projected demand. Consequently its vector of three scores is the XOR of the block vectors. Compute exact local three-bit tables, store witness trees, and combine by a constant-state XOR dynamic program.

A block has a polynomial table if either of the following ranks is at most one:

* The two local gain rows γ,σ modulo the cut space. Find any dependence by solving the vertex potential equations. A cut row applied to any a-join yields its known vertex-potential dot product with a. Thus the three target equations become at most two moments for one gain and the two projected demands. The [two-moment theorem](../connected-roots/README.md) solves them, also permitting direct tests for inconsistent or constant rows.
* The span of the two projected demands. The nonzero projected demands then equal a single d0, so the nonconstant equations specify at most two gains of the same tree d0-join. Use ordinary signed columns K_e=(B_e,γ_e,σ_e), and ports p=(d0,bγ,bσ), f1=(0,1,0), f2=(0,0,1), enumerating any unspecified bit. A successful tree is equivalent to an ordinary X that spans p and whose span meets span(f1,f2) only at zero. Under this last condition every ordinary cycle in X has both gains zero, so a spanning forest of X retains its K-span and extends to a spanning tree. The port trace for ordering (f1,f2,p) is the line generated by (0,0,1). Replace the ports by (f1,f2,f1+f2+p); the trace becomes the all-ones line, equivalent to a binary circuit through all three new ports by the same minimal-dependency argument. This version needs no matroid dual.

A bridge needs no rank test. A block with a bounded number of nonzero projected demand vertices also has a polynomial table even with independent gains: enumerate both potentials at these named vertices. A minimal tree connecting them has at most as many unnamed branch vertices as names. Guess this tree's topology, branch placements and the two-bit segment gains implied by guessed potentials at the branch vertices; route its segments with disjoint interiors and the prescribed gains, then extend to a spanning tree. Direct named-to-named edges and incident edge IDs may be guessed explicitly before disjoint-paths routing. This uses [Liu and Yoo, Theorem 1.3](https://people.tamu.edu/~yyoo/stoc25.pdf). None of these local bounds restricts demand density or signed-cycle structure elsewhere.

Any block failing both rank-one conditions must contain w (otherwise its σ is zero) and lie on the s–t block chain (otherwise d1 projects to zero). If w is strictly between two successive chain blocks, there is another deterministic algorithm even with no rank restriction. In that case deleting w separates s and t. Only the two components containing s or t, together with w, can occur on an s–t path. Guess which of the two original halves at w the path uses on the s side. Restrict all edges into w from that component to that half, and all those from the t side to the opposite half. Drop any vertices no longer in the common s–t component (reject this guess if there is no common component). Now every s–t path has σ gain one. Reject the guess if some demanded vertex needed for the score lies outside the component: any correctly signed path in this branch would otherwise yield a balanced rooted cycle omitting a demand, which was already tested. The remaining two γ measurements are decided by the connected-root two-moment algorithm. The two half guesses exhaust all qualifying closures.

In particular any unsolved obstruction localizes to a single s–t chain block containing w in which the projected demands are independent and the gain rows are independent modulo cuts. If w lies outside the s–t block chain, no s–t path can use the split edge at all. An additional redundant-measurement case can be recognized even without a block rank bound: before contracting e, test for a signed s–t path of the required gain in the graph minus e that avoids u or avoids v. Exactly these bypasses can belong to a spanning tree that still contains e, since a path containing both endpoints but not their edge would form a cycle with e. If neither bypass exists, the use-of-e condition is automatic in every suitable tree.

## Obstruction to two-moment relaxations

On contracted vertices s=0,t=1,w=2,3,4,5 take edges

    04, 35, 34, 05, 23, 25, 12, 45, 14, 03.

Set γ=1 just on 04,45,03 and σ=1 just on 23. Set d={0,2}. Enumerating the spanning trees yields seven distinct triples, exactly all except (1,1,0), in the coordinate order above. This corresponds to the actual simple graph obtained by moving edge 23 to new endpoint 6 (edge 63), and adding the two prescribed edges 26 of gain zero and 01 of gain one. Demands {0,2} belong to every rooted cycle. There is a balanced rooted cycle (the table attains (1,1,1)), but none passes the demand spin test. In particular, every linear projection onto at most two bits accepts the projected target: its kernel contains a nonzero vector, so the target's fiber also contains another triple, and every other triple is attained. Even querying all such projections separately cannot distinguish this table from the full cube.

The dense compulsory-demand version replaces root edge 01 by a root edge 0'1 of gain one and a zero-gain path from the new vertex 0' to old vertex 0, making the entire path the only way to leave 0' after removing its root edge. Mark an arbitrary even number of its fresh internal vertices as demands, and move the old demand at 0 to 0'. Every candidate rooted cycle covers them, and all spins along the new path are equal, preserving the entire three-bit table. Subdividing either prescribed edge into a wholly prescribed path likewise permits arbitrary prescribed path lengths. This counterexample concerns the balanced single-cycle branch and linear relaxations of its tree table; it is not a lower bound on algorithms for finding a circuit of either net gain.
