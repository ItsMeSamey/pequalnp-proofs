# Net-zero rooted circuits of a rank-one perturbed incidence matrix

Let B be the full binary vertex-edge incidence matrix of a finite undirected multigraph (a loop has zero column), u a nonzero vertex vector with support D, γ an edge row, A=B+uγ, and R a set of k distinct edge IDs. A rooted circuit must contain R. We seek circuits C satisfying γ(C)=0. The graph may be disconnected and D may be arbitrarily large.

## Classification

Since the total A-column sum vanishes, C is an ordinary nonempty even edge set. Consider the ordinary cycle space on C. Its γ-kernel lies in the A-kernel and must be exactly the line generated by C. Hence the ordinary nullity is at most two. Decomposing C into edge-disjoint simple cycles leaves just two possibilities:

1. C is one simple cycle Q, with γ(Q)=0.
2. C is the union of two distinct edge-disjoint simple cycles, each with γ-gain one, sharing at most one vertex. Two shared vertices would give ordinary nullity at least three.

Here a loop and a pair of parallel edges count as simple cycles. Conversely both listed forms have ordinary γ-kernel generated by their full support. It remains to exclude a support X inside C with B1_X=u and γ(X)=1, since these are exactly the additional A-kernel vectors.

The incidence span on C contains u precisely when every demanded vertex is on C and every connected component of C has an even number of demanded vertices. This includes demand vertices in other host components: any such omitted vertex certifies nonmembership. If u is outside this span both forms automatically pass the additional test. For the two-cycle form, if u is in the span, toggling one of the odd cycles changes γ(X) for any initial u-join X within C. Hence the two-cycle form is valid exactly when u is outside. For the single balanced cycle form, let p be any vertex potential on Q with γ_e=p_v+p_w for each edge. If u is in the span, every u-join in Q has γ(X)=p·u. Thus this form is valid exactly when u is outside the span or p·u=0. The dot product in the latter test is independent of the choice of constant on Q because its D count is even.

## Routing the two-cycle form without any restriction on γ

Enumerate templates of two disjoint or one-vertex-intersecting simple cycles with the k mandatory edges designated as direct edges. Mark a shared vertex if present, all mandatory endpoints and a representative anchor for otherwise unmarked cycles. Suppression of degree-two unmarked vertices gives constant size depending on k. Enumerate placements, segment gains and the decomposition into the two cycles. Require odd total γ on each. To certify that u is outside the incidence span run the following branches:

* Delete one demanded vertex and search for the template, repeating for every such vertex.
* Seek a template component with odd D count. Give each traversed edge vw the unoriented weight d(v)+d(w) in Z/4, where d is the D indicator. On a simple cycle the sum equals twice its number of demanded vertices, including for a loop (two incidences). For a figure-eight, summing both cycles counts the shared vertex twice; subtract 2d(v) for the shared vertex before testing for residue two. For distinct components test either cycle.

A candidate found by the second test is valid even if it also omits demanded vertices. These two branches describe all nonmembership cases. Their routing uses a fixed binary sign coordinate and one unoriented cyclic-order-four weight coordinate.

## Routing the single-cycle form with bounded signed odd-cycle transversal

Assume there is a vertex set Z of size at most s such that the signed graph G−Z has no γ-odd cycle. For fixed s it can be found by enumerating Z and solving q_v+q_w=γ_e on G−Z. A negative loop there makes that choice inconsistent. Extend q arbitrarily to all vertices, and put γ'=γ+qB. Every edge with γ'=1 then meets Z. All cycle gains agree before and after switching. The matrix A itself is unchanged in the problem: for an edge set X of boundary u the switched score is γ'(X)=γ(X)+q·u.

First test for a balanced rooted simple cycle omitting some demanded vertex, by deleting each such vertex in turn and routing with binary γ-gain zero. If |D| is odd, every balanced simple cycle qualifies, so in this case just run the same search with no deletion. These steps handle exactly the cases in which u is outside the candidate's incidence span.

For the remaining candidates the target on a chosen γ'-potential p' is p'·u=q·u. Enumerate the set F of positive γ' edges selected by the cycle; its size is at most 2s since each simple cycle has degree two at each of its selected Z vertices. Require |F| even, forbid every other positive edge and require all of F together with R as direct edges. Enumerate a single-cycle template through these edges, with one arbitrary anchor if none is named. Assign a binary spin p' to each named vertex. An edge of F must have opposite endpoint spins, ruling out a positive loop. All other segments consist entirely of zero-sign edges and their endpoints have the same spin. Thus the spin is constant throughout each such segment. The case F empty is included.

For a constant-spin segment with spin b and endpoints extended along a path, collect the unoriented Z/4-sum of the edge weights d(v)+d(w), multiplying its total by b in the template. For a positive direct edge vw add d(v)p'(v)+d(w)p'(w) directly. The sum over the cycle is exactly twice the D-weighted spin sum on its vertices, since every incidence appears once and each selected vertex has two incidences. Impose residue 2(q·u). There is no need to impose containment of every D vertex in this search: if the computed spin test passes on a cycle omitting a demand, that cycle is already valid by nonmembership. For a circuit covering D with even total demand this is exactly the necessary and sufficient switching-corrected test.

## Algorithmic details and scope

The templates have O(k+s+1) segments. Enumerate their required segment weights in fixed finite groups. To implement routing in a multigraph, enforce direct original edges by ID, handle two-edge chains via their reserved intermediate vertex, and on longer chains guess distinct first and last physical edges. Delete template vertices and reserved interiors, checking all remaining interior tips distinct. Apply the fixed-number disjoint paths theorem to connect the tips with their residual unoriented gain requirements. This ensures no cloned socket traverses the same original edge twice in a returning chain. A loop must be direct. A two-edge cycle consists of distinct parallel edges. A component with one named vertex and no roots can be represented by a returning chain. Reconstruction tests the complete original edge set for root inclusion, zero original gain, zero column sum and rank |C|−1 before reporting a witness.

Use Liu and Yoo's published Theorem 1.3 for unoriented finite abelian groups, forbidding the complement of the requested value on each path. The distinction matters because the Z/4 weights used here are unchanged on edge reversal. The resulting decision and witness search are deterministic polynomial time for fixed s,k. The two-cycle case has no dependence on s. With the separately proved one-sided randomized polynomial gain-one solver this yields the full rooted-circuit search on this signed-transversal class; unrestricted net zero is not settled here.
