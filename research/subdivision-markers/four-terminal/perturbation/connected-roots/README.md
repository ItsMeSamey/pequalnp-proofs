# Connected prescribed edges in one additive graphic perturbation

Let B be the binary incidence matrix of an arbitrary finite undirected multigraph, γ a binary edge row, u a nonzero binary vertex vector, and A=B+uγ. The nonempty set R of distinct prescribed edge IDs is connected as an edge subgraph. For fixed |R| there is a one-sided randomized polynomial-time witness algorithm for an A-circuit containing R, for arbitrary u, γ and host graph. To complement the previously proved gain-one and two-cycle branches, the only outstanding candidate is one simple balanced cycle. This note decides that branch deterministically without a bound on the number of unbalanced cycles. The net-zero two-cycle templates and net-one Pfaffian algorithms are given in [gain-zero](../gain-zero/README.md) and [gain-one](../gain-one/README.md).

## Two simultaneous moments of a signed spanning-tree potential

On any connected undirected signed graph H let K have edge column (B_e,γ_e). Let d1,d2 be even vertex sets and b1,b2 prescribed bits. Seek a spanning tree whose binary potential y (tree edge equations y_u+y_v=γ_e) satisfies y·d_i=b_i for both i. Form ports p_i=(d_i,b_i) and f=(0,1). Keep their IDs even when some port is zero or two coincide.

For ordinary edge subset X define L_X={a in GF(2)^3: [p1 p2 f]a lies in span K_X}. The target is equivalent to L_X=span(e1,e2) for some X. Indeed a successful spanning tree excludes f from its column span, since its incident columns are independent after projecting to vertex coordinates. It contains (d_i,b_i) since the unique tree d_i-join has gain y·d_i. Conversely such X spans both p_i and excludes f. Its signed subgraph is balanced: a nonzero-gain even edge set would sum to f. Take a spanning forest of this subgraph; every removed cycle edge is spanned by its tree path in K since the cycle gain is zero (a balanced loop is zero). Extend this forest to a spanning tree of H. Its K-span still contains both p_i, hence the tree realizes the moments. All calculations are over GF(2).

Construct a binary dual representation [K* | P*] of [K | p1 p2 f] by taking a basis of its dependency space as the rows. For complementary ordinary sets X,Y,

    L*_Y = (L_X)^perp.

In fact a dual dependency is a primal row-space vector. For a dual dependency supported on Y and the ports, an ambient linear functional annihilating K_X gives its port restriction. Conversely every vector orthogonal to L_X prescribes a well-defined functional on the port span modulo span K_X, hence extends to the entire ambient space. This proves both inclusions, including all rank degeneracies.

Write a,b,c for the three dual port columns. Replace them by a,b,a+b+c, retaining distinct IDs. The coefficient change sends (1,1,1) to (0,0,1). Thus the target becomes the existence of Y with attainable port coefficients exactly the line generated by (1,1,1). This holds exactly when a binary circuit contains all three new port IDs. A circuit and its ordinary support directly witness the line condition. Conversely a dependency with all three ports exists on Y, and no dependency on Y can use a nonempty proper port subset. Choose an inclusion-minimal all-port dependency there. Any proper subdependency would be port-free, and could be removed, so the chosen dependency is a circuit. This includes the case of a circuit consisting solely of the ports.

Apply Seymour's binary three-element circuit test to the transformed represented matrix. Recover a circuit by deleting ordinary columns while the yes answer persists. Its ordinary support Y gives the complementary X in the original ordinary ground set; spanning forest extension recovers a moment-realizing tree. The dual construction, transformations, and witness recovery are polynomial. [Binary triple theorem, Section 2](https://arxiv.org/html/2611.20960v1#S2)

## The balanced closing cycle

A connected root set can lie on a simple cycle only when it is a path or a simple cycle. In the latter case the sole candidate is R itself, so directly check its gain and A-circuit condition. Loops and parallel-edge cycles are included. Root sets branching or containing a cycle properly cannot lie on a single simple cycle. For a path let its vertices be r0=s,…,rk=t, I its strictly internal vertices, and a_i its signed prefix gains with a_0=0. A closing path P runs in G after removing I and all edges of R; it must be a simple s–t path of gain a_k. If s,t disconnect or no path has this gain, reject. Use the connected component H of s,t in the remainder. A single signed-path query is polynomial, e.g. by the block-chain balanced/unbalanced test or the one-path case of the [Liu–Yoo theorem](https://people.tamu.edu/~yyoo/stoc25.pdf).

Write D=supp(u). On a balanced simple cycle C, a proper A-dependence exists exactly when its edge subsets realize boundary u and gain one. If D has odd size or a demand lies outside C, no subset on the cycle has boundary u. If D is even and contained in C, a u-join exists on the cycle, and every such join has gain y·u for any cycle potential y. Thus the balanced cycle is an A-circuit iff u is not in its incidence span or y·u=0. If |D| is odd, any signed closure suffices. Otherwise try finding a closing path after deleting each demanded vertex outside R in turn (a vertex outside H is already avoided). Any resulting cycle omits that demand and qualifies. After these tests fail, every signed closure contains D outside I, and therefore D outside I is a subset of H. Demands on R cannot be omitted.

On H define the following even demands and target bits:

    d1 = {s,t},                    b1 = a_k
    d2 = (D minus I) Δ ({s} if |D intersect I| is odd, else ∅)
    b2 = XOR of a_i over r_i in D intersect I.

For any spanning tree realizing the first moment, its s–t path is a closing path of the required gain. This path contains every remaining demand by the omission tests. On adjoining R the potentials on the internal r_i are y_s+a_i. Therefore the spin sum over D on the cycle equals y·d2+b2. The second moment makes it zero, proving validity. Conversely, extend any valid closing path to a spanning tree of H. All demands in H lie on that path, so extension does not change either relevant moment (a global flip cancels on even demands). The tree thus realizes both bits. Invoke the two-moment solver and return R plus the recovered tree path. Each reported support may be checked directly on A.

Combined with the separate gain-one and two-cycle branches this proves the fixed-root-count RP claim on connected root sets. The deterministic simple-cycle branch itself is polynomial for arbitrary path length, since it uses merely a linear number of signed path queries and one triple query. With disconnected prescribed edges a single closing path need not suffice. These arguments do not give this result for arbitrary disconnected roots.

check.py tests all four moment targets on 400 seeded connected signed multigraphs, comparing spanning-tree enumeration with circuit enumeration of the transformed dual representation. Separately, direct exact circuit tests on balanced simple cycles are compared against the reduction over 300 multigraph hosts and their nonempty connected root sets through four edges. This verifies the finite reductions; the polynomial binary triple oracle and the other two previously established branches are external to this checker.

The two independent comparisons passed 1,600 and 7,455 cases respectively.
