# Independent audit of the perturbed-incidence circuit template

For A=[B+UΓ;W], bounded d means the union of supports of **all** perturbing columns of U. Restricting to the support of the full candidate's net boundary would not suffice: a proper subdependence can have a different Γ-gain. Keep all d perturbation-row coordinates in the small kernel, even where no selected graph edge is incident. The beta bound is rank(B[C])>=rank(A[C])−k−h. Vertices with a selected loop count that loop twice toward degree. These conventions yield the stated mark/segment bounds and coefficient propagation, including graph-disconnected supports.

Every mandatory edge has both endpoints marked and is assigned by its own ID to a direct length-one segment. This also holds in a component that is a pure cycle. An otherwise entirely unmarked cycle gets one additional anchor; its single returning chain has endpoint-incidence vector zero. A mandatory host loop is a direct returning chain. In a multigraph a length-two returning chain is possible, precisely with distinct parallel edges to the same interior vertex. Such an interior is reserved once. A support need not be induced in the host.

The executable uses edge IDs throughout. With designated branches known, guessing distinct stub edges and treating direct and one-interior chains separately permits an ordinary distinct-terminal disjoint-path call for all longer chains. Remove named vertices (thus all incidences of stubs connecting to them), absent defect vertices, and the reserved interiors of short chains. Require the remaining stub tips to be pairwise distinct. The oracle's vertex-disjointness prevents using any tip as another segment's interior. Unrestricted copying of incident edges at cloned branch vertices alone could falsely use a single original incidence twice for a returning chain. The explicit stub test avoids this. A bare endpoint-sharing prohibition without an edge-ID test would also permit duplicate direct edges between named vertices.

Liu and Yoo's Theorem 1.3 takes a fixed number of pairs, abelian groups and coordinate-forbidden-set size bound. Path totals are sums of edge labels without orientation. Using one binary coordinate per desired gain bit and forbidding its opposite imposes each exact gain with a one-element forbidden set. A dummy trivial coordinate handles no measured gains; with no residual path pairs check the predetermined segments directly. Group operations and comparisons cost constant time for these fixed groups, meeting the theorem's computational hypotheses. The theorem finds the disjoint paths in O(|V|^8+|E|) time with parameter-dependent constants. Its discussion explicitly allows parallel edges. Loops are unnecessary in the middle path oracle because a simple path between distinct tips cannot use one. [Liu and Yoo, Theorem 1.3](https://people.tamu.edu/~yyoo/stoc25.pdf)

check.py independently enumerates every original and reconstructed kernel *vector*, rather than comparing dimensions only. It also compares the complete edge-subset language of stub routing with direct support-to-template recognition on small multigraphs, including repeated endpoints, host loops, parallel segments, separate root-edge IDs, and distinct optional label and rank-check gains. The checker uses exhaustive tiny paths in place of the external linkage algorithm.
