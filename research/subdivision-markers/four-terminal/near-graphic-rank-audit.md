# Row-certificate audit of the near-graphic forest reduction

This strengthens the complexity estimate in near-graphic.md without changing its viable-boundary hypothesis. For nonempty exceptional subset J put K=|J|. If its net boundary support T is empty, only the empty graphic forest is possible and J itself is tested directly. For T nonempty the graphic part F of any circuit using precisely J is a forest of boundary T, since a contained graphic cycle would already be a proper dependence. Let its vertex set consist of endpoints of its selected edges. Assume its boundary and total gain pass their tests.

Define r(v)=(h_j(v):j in J). Make one binary row r(v) for each host vertex outside F and one row sum_(v in C) r(v) for each component C of F. The kernel of this row matrix is exactly the set of coefficient vectors u for which sum_j u_j h_j lies in span F: this span consists of vectors supported on forest vertices with even parity on every forest component. All-ones is in the kernel because F has the specified boundary. Since F is independent, the space of dependencies on F union J has exactly the kernel dimension of the row matrix; given u, the expression in forest edges is unique. The whole support is a circuit exactly when the rows have rank K-1. This also covers K=1 and zero or repeated exceptional columns.

Instead of guessing a vertex or component for every proper subset of J, guess K-1 independent K-bit rows. For each specify whether it comes from a forest component (and which one) or is a type of an unused host vertex. Guess the bounded suppressed template and all needed parity gains along its segments as in the original note. For a component-indexed row, segment internal parity gains plus one copy of each named vertex determine every required coordinate exactly.

Unused vertex identities also need not be guessed. For each requested unused type tau add a fresh source and sink, each adjacent to all unnamed original vertices of type tau, and require an additional source-sink path in the disjoint linkage. Leave all gain restrictions on this path empty (the forbidden sets are empty), and assign zero weights on its new incident edges. Any such path starts at a qualifying real vertex, which is outside the forest because the paths are vertex-disjoint. Conversely an unused qualifying vertex yields a two-edge path. The independent chosen rows are distinct types and thus have distinct witnesses whenever multiple unused types are required. All new edges touch prescribed auxiliary terminals; no forest path can traverse one, as each such terminal belongs to a separate linkage path. The new neighbors are taken only among actual, unnamed host vertices, not among terminal copies or other auxiliary vertices.

For a named forest vertex create one socket copy per incident template edge and replicate each original incidence at every compatible copy. Every copy serves as an endpoint of a prescribed path; no path can transit another segment's copy. The template is a simple forest, so two segments cannot project onto the same original edge between named vertices. An edge with an unnamed endpoint cannot be reused by a different path due to vertex disjointness. Original loops can be dropped in nonempty forest branches. Parallel original edges retain individual gains. Consequently identifying copies yields precisely a subdivision of the guessed forest, with no extra cycles or accidental overlaps.

On any segment xy, put the unoriented edge weight chi(u)+chi(v) in Z4 on each edge uv, where chi is the desired exceptional incidence bit. The path total is chi(x)+chi(y)+2 times its internal parity modulo four. This recovers the parity without orientation signs or endpoint overcount. Liu and Yoo's Theorem 1.3, for fixed group collection, number of pairs and forbidden-set sizes, finds a vertex-disjoint linkage subject to these unoriented gains; their proof of Corollary 1.4 also uses terminal splitting. [Primary paper](https://people.tamu.edu/~yyoo/stoc25.pdf)

If a nonempty forest has c components and l leaves, its sum of deg(v)-2 over branch vertices is l-2c. All leaves belong to T, and every unnamed branch vertex has even degree at least four, since every odd-degree vertex belongs to T. There are at most floor((|T|-2c)/2) unnamed branch vertices to guess. At fixed label dimension, fixed exceptional count k and fixed upper bound s on net boundary size in viable states, all other guesses have count bounded in these parameters. The disjoint-path solver takes O(n^8+m) per call, with constants depending on the parameters; auxiliary incidence edges add O_k(n) edges and socket copies only a parameter-dependent factor. With n=number of vertices and m=number of graphic edges, the nonempty-boundary branches therefore cost

    f(k,s) n^floor((s-2)/2) (n^8+m),

plus polynomial input-matrix work and the separate empty-boundary or purely graphic branches. Interpret this expression only for s>=2. There is still no claim of tractability for unbounded viable net boundary. Direct finite rank checks on 5000 seeded forests plus conditioned even exceptional vectors agreed in all cases (1932 minimal, 3068 nonminimal).
