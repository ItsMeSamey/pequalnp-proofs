# Deterministic polynomial time for a connected prescribed edge set

In an undirected connected multigraph G fix an even demand set D. Seek an inclusion-minimal D-join containing every edge of a prescribed set R; a minimal join is precisely a forest of boundary D. If R is nonempty and its edge-induced graph is connected, this problem has deterministic polynomial search time, including when |D| and |R| grow. More generally one can process the graph's edge blocks independently if their local prescribed sets are connected or empty. The external algorithm here is **unweighted linear delta-matroid parity**, not ordinary matching and not arbitrary-sum Pfaffian PIT.

A prescribed loop or any cycle in R rejects. Assume R is a tree on k+1 distinct vertices A. Pick w in A. In the Cauchy–Binet expansion during Laplace removal of the k prescribed columns, det I[A' minus w,R] is nonzero only for A'=A; every other candidate contains a zero incidence row. The reduced tree incidence determinant at w is one. Thus there is just one surviving Pfaffian in the companion minor-summation proof. Here is a direct proof of its meaning.

Write Δ=D symmetric difference boundary(R), and S=Δ symmetric difference A. Put p=n−k−1. The upper-right block Z=I[V minus A,E minus R] diag(x) I[V,E minus R]^T has p rows and n columns. Form an alternating matrix with zero top-left block, upper-right Z and a bottom clique of unit weights on S. If k+1 is odd add one further bottom vertex, adjoining it to that clique and using zeros in its cross column. Call the resulting constant part K, and the full symbolic matrix K(x).

A coefficient on edge set F can be nonzero only for |F|=p, by expansion of the distinct top matches and Cauchy–Binet. It is zero unless F is a forest with exactly one A vertex per component; the reduced incidence minor on V minus A gives this criterion. Then adjoining the tree R on A connects the components without creating a cycle. The other reduced incidence minors sum over choices of one representative per F-component from S. The unmatched clique vertices, plus the dummy if needed, have an odd number of internal perfect matchings. Thus the coefficient is the product over F-components C of |C intersect S| modulo two, equivalently the indicator that all |C intersect Δ| are even. This means that a unique Δ-join J_F is supported in F. Then J_F union R is a D-join and a forest. Conversely extend any solution forest to a spanning tree T; F=T minus R has the specified properties, since its components contain the edges of the solution outside R. This proves existence iff the single Pfaffian is nonzero.

## Turning its nonzero coefficients into linear delta-matroid parity

For e outside R, let a_e be its upper incidence column embedded into the top indices and b_e its ordinary incidence column embedded into the bottom indices (zero at any dummy). Then the coefficient matrix at x_e is the alternating update a_e b_e^T + b_e a_e^T. Let U be the matrix with consecutive columns a_e,b_e, and construct the constant alternating matrix

    M = [ K    U ]
        [ U^T  0 ] .

Let V0 be the set of base indices belonging to K. The coefficient of product_(e in F) x_e in Pf K(x) equals Pf M[V0 union ends(F)] over F₂, where ends(F) means both column indices a_e,b_e of every chosen edge. Indeed in expanding the original matching, terms using twice the same rank-two update cancel: more generally a principal alternating rank-two minor of order at least four has Pfaffian zero. For a selected update once, the coefficient in the two cleared base rows is its 2-by-2 minor a_i b_j+a_j b_i. In the extended matching these are exactly the two ways of matching its added pair into those base rows. Summing over disjoint allocated rows gives the identity, including constant K edges. Thus seek a nonsingular principal matrix containing all base indices and a union of pairs of remaining indices.

Here is an explicit way to condition on the base. Find any principal nonsingular extension X=V0 union Y. Congruently eliminate the alternating K on its base indices to a nonsingular block plus a zero radical block. After eliminating the nonsingular block, the radical rows pair only with the outside columns of the transformed U. If these cross rows have deficient row rank, a nonzero base-supported vector annihilates all of M; no principal extension exists and one rejects. Otherwise select as many outside columns as radical rows, giving an invertible square cross matrix C. On the selected residual rows the principal block is [0,C; C^T,D'] and is nonsingular for every D'. This constructs such a Y in polynomial time. The congruence operations are only on the full base, retained in all cases.

Take the principal pivot transform M*X and delete the base rows and columns. On the remaining paired ground set, the linear delta-matroid represented by this alternating matrix with twist Y has feasible sets precisely P for which M[V0 union P] is nonsingular. This follows from the principal pivot minor identity since X symmetric difference (V0 union P)=Y symmetric difference P. Apply the deterministic algorithm of Geelen, Iwata and Murota minimizing the number of pairs met exactly once by a feasible set. Optimum zero gives the desired union of pairs with no cardinality restriction on the oracle. The fixed cardinality |F|=p is already enforced by the matrix. The returned set directly gives F; parity propagation on its forest recovers J_F. [Geelen, Iwata and Murota, The linear delta-matroid parity problem, Sections 2–3 and 5](https://www.math.uwaterloo.ca/~jfgeelen/Publications/deltamatroidparity.pdf)

For a connected G, split across articulation vertices into edge blocks, including bridge blocks. For a block B, map each original vertex into B by sending each exterior branch to its unique attachment vertex. XOR these projected demand bits to obtain its even local demand. Indeed the unique whole-tree join, for any independently chosen spanning trees of the blocks, restricts to the unique local tree join of the projected demand. Every solution forest extends to such a whole spanning tree, and the union of correct block forests has the original boundary and is acyclic. Thus solve each nonempty local R by the connected-R algorithm if connected, and unmarked blocks by an arbitrary spanning tree. Disconnected graphs are handled componentwise after checking even demand per component.

Multiple contributing outer Pfaffians can cancel coefficientwise for a disconnected prescribed set in one block; testing each by delta-matroid parity and taking their disjunction is invalid in general. This argument gives no such unrestricted deterministic algorithm.

An additional exact application allows disconnected R of arbitrary size if each tree component of the desired join may contain at most one connected edge-component of R. Add artificial mandatory links forming a tree between chosen representatives of the R components and toggle the demanded set by the links' boundary. The augmented mandatory set is connected. Its union with an original forest is acyclic exactly when all R components lie in distinct trees of that forest: if two are already connected, the links form a tree on the finer R-component partition, and its quotient after identifying any two vertices has a cycle. Conversely linking distinct forest trees according to a tree cannot create a cycle. This gives a sufficient positive test for ordinary disconnected R.
