# Fano obstruction for two positive pins

Let G be any finite simple graph, V a distinguished set of visible vertices, and a,b two distinct auxiliary positive vertex pins. Project to V all vertex subsets containing the pins and inducing even degrees. If the minimum size d of a projected support is positive and finite, its minimum supports form a d-partite d-uniform hypergraph, with each hyperedge meeting every layer once.

Indeed the pins must be adjacent, as otherwise the two pins alone form a witness. For every allowed W⊆V, delete the other visible vertices and edge ab. There is an a–b path in the resulting graph if and only if there is a witness supported on W on the visible side. In one direction ab belongs to a cycle of any induced even witness. In the other, a shortest alternate path has no chords and restoring ab gives an induced cycle. Give visible vertices cost one, all others cost zero. It follows that d is the minimum cost of an alternate path. For every minimum projected support S, delete the other visible vertices, find a shortest alternate path, and note its visible set must be all of S by minimality. Its cost therefore attains the global minimum. At the ith visible vertex of this path, the minimum cost from a to that vertex, counting both endpoints, is i. Otherwise a cheaper prefix would yield a cheaper a–b walk and erasing repeated vertices could only reduce cost. These global distances give the claimed layers.

Take seven edgeless visible vertices indexed by nonzero vectors v of F₂³. Require the affine checks Σv x_v=0 and Σx_v=1. The minimum supports are the seven triples {u,v,u+v}. Every pair of different vertices occurs together in one such triple, so the layer coloring would require seven distinct colors, contradicting d=3. No visible bit is fixed at one, so allowing visible pins cannot help. Zero pins or one pin also allow the empty projection when their only pins are auxiliary. Thus unlimited hidden vertices and edges cannot compile this four-check affine fiber to two positive pins while retaining exact coordinate projection. This also holds if only the upward closure of projected supports must be preserved. Arbitrary affine output observations and three or more pins are outside the proof.

## Three affine checks already suffice for an obstruction

Set h=111, use six visible columns given by the nonzero vectors of F₂³ other than h, and require Σv x_v=h. The size-two supports are exactly three disjoint complementary pairs {v,v+h} and cover all six vertices. There are no solutions of smaller weight. There is a solution {001,010,100} containing no complementary pair.

Suppose two pins realize even the upward closure. Remove ab. Replace each component of hidden vertices (excluding a,b) by a clique on its neighbors among a,b and visible vertices, retaining original edges there. For every allowed set of visible vertices, a–b reachability is preserved by this operation, since a segment through a hidden component can be replaced by a single edge and conversely expanded to a walk. There is no edge ab after this compression, since the empty visible set is disallowed. No visible vertex can neighbor both a and b since singletons are disallowed. Every visible vertex belongs to a feasible pair and therefore neighbors precisely one terminal. Thus all visible vertices belong to A=N(a) or B=N(b). Each cross-edge gives a feasible pair. Every feasible support must contain the endpoints of such a cross-edge, contradicting the displayed three-element solution. Neither pin can be visible because the fiber fixes no coordinate to one.

More generally, if every visible vertex occurs in a size-two minimum projected support, all inclusion-minimal projected supports for a two-positive-pin extension have size two.

## The threshold for edgeless systems is exact

Every consistent affine system Hx=h of rank at most two is an exact projection from two positive vertex pins. Row-reduce and pad with zero rows, then apply an invertible row transform so the two-bit target is either 00 or 11. Make hubs a,b (both pinned) and c (free). Add ab exactly for target 11. Attach each visible vertex to the following pair according to its column: 10 to a,c; 01 to b,c; 11 to a,b; 00 to neither. No further edges occur. Every solution of the graph projects to a solution of Hx=h by parity at a,b. Conversely select all three hubs and the given visible support: its vertices all acquire even degrees, the first two hub equations hold by assumption, and the parity at c is their sum. Thus every consistent affine fiber of rank at most two admits this graph representation, while a rank-three fiber on six variables can fail even for its upward closure. An inconsistent system is represented by a pinned edge with no alternative path.

For an arbitrary consistent k-row system, k≥2, the same upper bound uses k pins and one optional extra hub. Row-transform any nonzero target to a weight-two vector and add the corresponding pin edge. Attach a visible vertex to the pins listed in its column and to the extra hub precisely if that column has odd weight. Pin degrees enforce Hx=h, selecting the extra hub completes any solution, and its parity is the sum of the pin equations. This observation concerns edgeless input graphs.
