# Testing paired fundamental residuals by linear matroid intersection

Let U be the named four-dimensional binary space, H a prescribed plane in U, and split the ambient coordinates so an ordinary column is (a_j,l_j), with a_j private and l_j named. Work in the private span of all columns, of rank r. Choose ordered distinct prospective extra elements e,f and remove them from the candidate basis ground set. If the remaining private columns have rank below r, skip the pair. For each private basis B on the remaining columns let s_B be the unique linear map taking a_j to l_j for j in B. Its paired residual tableau is the four-by-two matrix X_B with columns l_e+s_B(a_e) and l_f+s_B(a_f).

An H-witness exists exactly when some pair and some B have two independent columns of X_B in H. One direction uses the physical set B together with the two extras: all its private relations are generated by those two fundamental dependencies. Conversely, take a maximal private independent subset P of an H-witness. The residuals of its remaining elements span H. Select two independent residuals e,f and extend P to a private basis B avoiding e,f. Their fundamental residuals are unchanged. This applies to dependent private end pairs, including loops.

**Determinant query.** Let A be any two-by-four matrix and K any two-by-two matrix over GF(2). There is a deterministic polynomial decision and witness test for whether some private basis B satisfies det(K+A X_B)=1. Lift every candidate column j to (a_j,A l_j). Append two auxiliary columns (a_i,K_i+A l_i) for i=e,f, using the corresponding column of K. If the auxiliary columns are dependent, the answer is negative. Otherwise contract both in the lifted representation. Seek an r-element common independent set of this contracted representation and the original private representation on the candidate ground set, by ordinary linear matroid intersection. For a private basis B, eliminate its private block from the square matrix consisting of its lifts and the two auxiliaries. The remaining two-by-two block is exactly K+A X_B. Thus a common set of size r is necessary and sufficient. This argument does not assume that A, K or the private end pair has full rank.

A predicate is specified by the row space of [K A] in six dimensions: it tests whether the plane spanned by the columns of [I; X_B] avoids the common row kernel. Dependent rows give the identically false predicate. Row operations preserve nonzero determinant, leaving at most 651 predicates. All computations on the 256 possible tableaux are constant-size.

**What the Boolean transcript can certify.** Let M be the set of all tableaux not excluded by any negative predicate. All realized states lie in M. If M contains no good tableau, the pair cannot serve. A positive predicate whose intersection with M consists entirely of good tableaux yields an actual common basis and an H-witness. More generally, every returned basis can be checked directly. Given only the Boolean answers, if neither criterion applies and M contains a good state, the two abstract state sets M and M minus all good states both realize the transcript. Indeed each positive predicate still contains a surviving bad state and negative predicates miss both sets. This is exact for abstract Boolean transcripts; existence of represented examples realizing each abstract set is a separate question.

**Independent one-dimensional variation.** For each column of X_B, compute its attainable affine hull by querying every one-bit character in both signs. These are determinant predicates: use one row testing the character on the indicated residual, a second row with zero named coefficients, and choose constants so expansion along the second row gives the desired bit test. Suppose the hulls are lines x0+span(u) and y0+span(v) with u,v independent. For each good target tableau (x,y) in their product take A with Au=(1,0), Av=(0,1). Set K=I+A[x y]. On all attainable tableaux the determinant reduces to (1+error_x)(1+error_y), since the two difference columns are multiples of separate coordinate vectors. Thus one query exactly isolates (x,y). If one column is fixed only the other bit must be queried. This gives complete decision for the pair under the stated rank defect, with no bound on fundamental circuit length. For the global algorithm enumerate the O(n²) choices of extras. A NO from all pairs is conclusive when each pair is excluded by a sound criterion; inconclusive pairs elsewhere do not preclude a constructive YES.

**Connected control.** The private candidate columns are 1,2,3,4,8,12,16, with labels 4,0,0,8,0,0,0. The two extras are (17,1),(20,2). The fundamental graph in basis 1,2,4,8,16 is connected. The attainable residual columns lie on 1+span(4) and 2+span(8). For H=span(1,2), the determinant testing its ordered basis (1,2) returns private basis columns 2,3,8,12,16 and both extras give the desired trace. **Separate pivot-distance localization.** For a fixed private basis B0 and a circuit C of the private matroid, its minimum distance to a basis in which it is fundamental is |C minus B0|−1. All but one of its elements must belong to the new basis. Conversely leave a single nonbasis member out, retain the others of C and extend to a basis by inserting the missing members into B0 with exchanges preserving all already retained C elements. This takes exactly the displayed number of exchanges. Thus enumerate at most k+1 nonbasis elements, XOR their B0 fundamental cycles, test that the resulting word is a circuit and that its named residual is nonzero in H. For each such first circuit call the exact three-name mate test after contraction. This is a deterministic n^{k+1} times polynomial algorithm under the promise that a positive admits a compatible first circuit within exchange distance k. It can cover arbitrarily long circuits.
