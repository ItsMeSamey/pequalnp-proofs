# Layered affine options

A supplied layer is a family of blocks on separate output coordinates. Each block always permits its zero vector. Its nonzero options have fixed bit-vector outputs and each comes with one disjunction of affine literal indicators on earlier layers. An option becomes available when any literal in its disjunction is true. At most one option in a block may be used. A terminal asks for b simultaneous affine equations on the complete output. With fixed number H of layers the problem has a deterministic f_H(b) N^{O(H)} witness-search algorithm in the explicit input length N.

## Eliminate a layer

Apply the b terminal row normals to each option's vector to obtain its contribution in the binary b-space. In a witness the total last-layer contribution can be expressed by at most b of the actually selected contributions: take a basis of their span and represent their sum in it. Zero all other last-layer blocks. Chosen blocks are distinct and their individual guards depend only on older layers.

Enumerate q≤b, at most q−1 binary positions from block IDs, q distinct signatures on those positions, and a nonzero b-bit contribution for each signature. Every q distinct block IDs admit such signatures, since adding one distinguishing bit from an unresolved pair increases the number of partition classes by at least one. For q zero or one the empty position set suffices. The number of position choices is at most (1+log N)^b≤f(b)N; the signature and label guesses cost 2^{O(b²)}.

Subtract the sum of guessed labels from the affine terminal right-hand side, restrict the original b normals to the earlier coordinates, and require for each chosen bucket that at least one block in it have an available option with the guessed contribution. This last condition is one disjunction, formed by concatenating the enabling literals of all such options. Different buckets cannot choose the same block. Using clause-projection.md, or individual literal choices when fewer, gives O(4^b L²) systems with at most b additional affine equations for total at most 2b. Here L counts literal occurrences in the generated clauses. They are subsets of the original layer's option literals, so L is polynomial in the supplied description independently of the layer number.

Repeat on earlier layers. At depth j there are at most 2^j b marker rows; all work per elimination stage is f(2^j b) times a fixed polynomial in N. Multiplication over H stages gives the claimed bound. At a successful leaf, recover earlier choices and select one actually enabled option of the guessed contribution from each nonempty chosen bucket. Row reduction and impossibility checks may be used at every level. The implementation solver.py passed test_solver.py on 1,320 targets across 361 systems, independently enumerating all admissible assignments and replaying each returned witness. The target count is fixed-parameter tractable for fixed H; the displayed bound is not jointly FPT in H and b.

## Native unbounded-depth examples

A prerequisite chain of arbitrary length with a common externally gated first vertex permits zero and its path prefixes. Likewise a binary decision tree using the sparse guards of tree-barrier.md has only one path prefix per node and one zero option, with an arbitrary disjunction of affine literals gating the root. Substituting such a block for each option layer allows unbounded elementary dependency depth and arbitrary dense dependencies between layers. An unrelated block's nonzero-coordinate choices cannot affect another block in the same layer.

Implicit blocks also work when a syndrome oracle can, for each b-row query and requested contribution g, return a polynomial-size affine disjunction describing its exact availability on upstream coordinates and later recover a witness. For instance an entire internal unary-parent dependency forest (with just one externally gated root, others internal) can have exponentially many states. Compute attainable g with that root fixed zero and fixed one using the ordinary forest dynamic program. If root-zero attains g, it is always available; else if root-one attains g it is available upon satisfaction of the external gate; otherwise it never occurs. When the root external gate holds the zero-root choice remains possible. These availability rules permit the same elimination, using 2^b queries per block. Zero must be feasible without regard to the upstream values.

## Unrestricted option-layer height is W[1]-hard

Reduce the standard parameterized k-edge-disjoint-paths problem on directed acyclic graphs. Remove trivial demands with equal source and destination. For each edge e=(u,v) create one block with at most k nonzero options. Option i writes its own unit coordinate x_ei and represents assigning that edge to demand i. It is available unconditionally if u is the source of demand i, and otherwise if at least one entering edge f of u has x_fi=1. Use a topological ordering of the underlying DAG. For each demand i require odd parity on the coordinates x_ei of edges entering its destination. This is exactly k simultaneous affine markers.

Given disjoint paths, assign their edges to their respective demands, leaving all other blocks zero. In reverse, odd parity supplies an incoming assigned edge at each destination. Follow eligible predecessors of that color backward. The DAG guarantees that this process reaches the designated source. Different colors cannot use the same edge because the block permits only one option. The resulting paths are edge-disjoint. Distinct demands may have common endpoints without affecting the argument.

This establishes W[1]-hardness for unbounded height in the **abstract exclusive-option model** even when option guards use at most two positive input bits, by the bounded-degree source theorem. The reduction has O(k(|V|+|E|)) size on those inputs. The parameterized reduction and W[1]-hardness classification are unconditional statements. The atomic conjunction of a color choice and its individual enabling condition is a feature of these blocks. No compilation of arbitrary conditional exclusive-option blocks into native zero-fallback affine guards is assumed or established.

[Chitnis, A Tight Lower Bound for Edge-Disjoint Paths on Planar DAGs](https://arxiv.org/abs/2101.10742) · [Slivkins, Parameterized Tractability of Edge-Disjoint Paths on Directed Acyclic Graphs](https://doi.org/10.1137/070697781)

## Arbitrary-height XP by monomial representatives

The forward degree-b span algorithm also works for an explicit multibit option. From a representative prefix state extend by the zero option and by every enabled option. For a particular fixed option vector v, the difference between its degree-at-most-b evaluation vector and that of the all-zero block is supported only on monomials involving at least one new coordinate. On these monomials it equals a constant depending on v times a monomial of degree at most b−1 in the prefix. Multiplying this difference by one affine guard literal yields a vector linear in the degree-at-most-b prefix evaluation vector; when the literal is zero this difference vanishes. Thus the span of actual prefix representatives suffices to span all extended witnesses with that guard, and taking every guard covers every admissible option. Products of b terminal truth indicators detect accepted assignments. With a basis size at most the sum of binomial(n,j) for j≤b, this gives deterministic n^{O(b)} time independently of the number of layers. This matches the classification as an XP parameterization with the W[1]-hardness above. The separate rank example branchbarrier/representatives.md gives a lower bound on the size of a particular shared tensor representation.
