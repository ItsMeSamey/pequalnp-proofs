# Recognizing a two-shore same-side rank budget

For a binary symmetric matrix A with zero diagonal, recognize a partition L,R for which rank A[L,L]+rank A[R,R]≤k. Empty shores and empty bases are allowed. The implementation returns a partition and a nonsingular principal basis on each shore. It visits budgets in increasing order, so a positive answer also certifies the optimum once the lower budgets have been excluded.

A binary alternating matrix of rank r has a nonsingular principal submatrix of size r. One proof pivots on an off-diagonal one together with its symmetric mate. The two-by-two pivot is invertible, and its Schur complement remains alternating. Repeat until the residual vanishes. By the Schur determinant identity the accumulated original principal indices have a nonsingular principal block. This argument also proves that r is even.

Guess disjoint bases B_L,B_R of even sizes with total at most k. For shore s discard a singular guess. Write G=A[B_s,B_s] and C=A[:,B_s]. Compute the symmetric prediction C G⁻¹ Cᵀ (zero for an empty basis). It has zero diagonal: G⁻¹ is alternating because yᵀG⁻¹y=xᵀGx=0 for x=G⁻¹y. Force every member of B_s to shore s. For each unordered distinct pair u,v whose true entry differs from the prediction, forbid assigning both vertices to s. These are 2-CNF clauses. Return a satisfying partition when one exists.

For any shore S containing B_s, block elimination gives rank A[S,S]=|B_s|+rank(A[S∖B_s,S∖B_s]−C[S∖B_s]G⁻¹C[S∖B_s]ᵀ). Thus every feasible solution to the clauses realizes exactly the guessed ranks. Conversely, choosing principal bases of both optimal shores makes all monochromatic predictions correct. Swapping shore names permits enumerating only guesses with |B_L|≤|B_R|.

Let K be the largest even integer at most min(k,n), for k≥0. The number of ordered guesses is bounded by Σ_{j=0}^K binom(n,j)2ʲ before filtering sizes and orientation. In an array implementation each guess takes O(n²(K+1)+nK²+K³) elementary bit operations for its matrix computations and O(n²) for 2-SAT. The algorithm is XP in k, polynomial for fixed k. These bounds do not assert fixed-parameter tractability. The checker uses Python bit-packed row integers, recomputes the right-hand profile for each choice, reuses the left profile, and builds forward and reverse implication graphs in O(n²) Python entries. Rank-one scalar products use integer bit_count. On unbounded rows a Python shift/access can scan O(ceil(n/w)) words, so the elementary array-operation bound is a conceptual bound, not a measured Python instruction or runtime bound. A conservative Python word-operation upper bound per guess is O(n² ceil((n+1)/w) + n² ceil((K+1)/w) + n(K+1)ceil((n+1)/w) + (K+1)³), with ordinary index operations treated as unit cost.

Run `python check.py` to compare every decision and its returned witness with direct enumeration of all vertex bipartitions and independent binary rank elimination.

The audit passed 1,222 graphs: all labeled graphs on orders zero through five, 120 seeded graphs of orders six through ten, and two explicit odd cliques. It made 9,776 budget calls and independently checked the exact shore ranks and inclusion of the returned bases. The numbers of graphs attaining optima 0,2,4,6,8 were 458,710,46,7,1, respectively.
