# Bipartite lift of homogeneous guarded quadratic equations

The source requires x_i(Mx)_i=0 for every i over F₂, together with arbitrary affine markers on x. Fix a partition L,R and permute vertices so L is first. Write the four matrix blocks as A,B,C,D. Choosing the real-real bipartite adjacency X leaves residual rows [A,E] and [C+Xᵀ,D], where E=B+X. Let F=B+Cᵀ, let π be the quotient by im A, and put K=ker Dᵀ. The minimum sum of ranks of these two residual blocks is

    rank A + rank D + rank(π F restricted to K).

Indeed the first rank is rank A + rank πE. The second is rank D + rank((F+E) restricted to K), by applying the first identity to its transpose or restricting the row-combination domain to K. Projecting the latter image to the quotient cannot increase dimension, and πF on K is the sum of the two projected maps, giving the lower bound. For attainment choose any linear projection P onto im A and set E=PF on the whole domain. Then πE=0 and I+P identifies the quotient with a complement, so the second excess rank is exactly the obstruction. Thus X=B+PF works in polynomial time. This minimum concerns independent residual factorizations on the two shores for the fixed partition. It gives no lower bound for different lift architectures.

Factor each residual block as UVᵀ with inner dimension its rank. For every column of U make an auxiliary vertex on the opposite shore from the corresponding real rows, incident to those real vertices whose U entry is one. Add the marker z_j=(Vᵀx)_j. Include real-real edges X. Consequently every selected real vertex sees parity (Mx)_i regardless of any further auxiliary choices.

Add a free hub on the left. For each auxiliary add a private path to the hub, of length two for equal shores and three for opposite shores. To extend a source solution, select the hub and precisely the marked auxiliary values. For every selected auxiliary of odd current induced degree, select all interior vertices on its path. Remaining interiors are unselected. This restores parity at each such auxiliary; selected path interiors have degree two. Initially the selected real vertices already had even degree and the hub had degree zero. The handshaking identity makes the number of selected odd auxiliaries even, so the repaired hub degree is even as well. Conversely any even induced set meeting the markers obeys the real equations, since no spoke contacts a real vertex. The construction preserves the full projected solution set, including all original affine markers, and needs no hub marker.

For final bipartite adjacency H with left rows and right columns, the binary representation [I|H] has cycles (Hq,q) and cocycles (p,Hᵀp). Their coordinatewise disjointness is exactly the induced even-degree condition for the selected left/right vertex masks p,q. The original bits and the auxiliary checks can therefore be read linearly on the cycle/cocycle pair. The resulting binary matroid need not be graphic. The construction preserves existence and projection rather than extension counts.

Run python test_lift.py. The check compares the formula and constructed residual ranks to every cross matrix X for all 2,101 square matrices with ordered cuts through dimension three (counting matrix-cut pairs). A further 300 seeded matrices through dimension six are tested with exhaustive X searches, explicit witness extensions for every source vector, and exhaustive lifted projections when n ≤ 3.
