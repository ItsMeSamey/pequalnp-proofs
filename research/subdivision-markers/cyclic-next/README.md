# Two deterministic cyclic native guard reductions

Each selected variable requires at least one true literal from its list of affine literals. Inactive bits are free of any condition. A terminal affine syndrome of b bits is prescribed. For disjunctive terminals use the marker projection described in ../clause-projection.md.

## Bidirectional response ranks on a supplied tree

Stack all guard occurrences as rows of a single binary matrix A, each row owned by the variable whose guard contains it. For each cluster X in a supplied rooted binary leaf decomposition of variables, let I(X) be its rows. Define r as the largest rank of either crossing matrix A[I(X),outside X] or A[outside I(X),X], over the clusters. Tabulate each possible incoming response from the first matrix against outgoing response from the second matrix and the internal marker syndrome. Feasibility means that the variables in X satisfy their guards for the given incoming response and have the specified outgoing response and syndrome. At a leaf try its two bit values, including any self coefficient and offset in evaluating literals.

For a split into P and Q, the parent incoming response e and child outgoing responses oP and oQ determine both child incoming responses, (e+oQ) restricted to I(P) and (e+oP) restricted to I(Q). They belong to the corresponding column spaces. The two child table entries can be combined precisely under these conditions. Parent output is (oP+oQ) restricted outside I(X), and the syndrome is the XOR of child syndromes. Restriction and addition encode every literal's true cross-cut dependency, which proves the recurrence in both directions. The root has zero incoming and outgoing response. Carry witness pointers or explicit masks. Column spaces and table sizes give deterministic runtime 2^O(r+b) poly(input) and space of the same form. No acyclicity or depth condition enters.

solver.py and test_solver.py compare all attainable marker outputs and validate every returned witness on 600 random cyclic instances. A separate dense 80-variable example has crossing ranks at most one and minimum dependency feedback vertex set at least 79, after dropping self-references. It has every even-weight four-bit syndrome and no odd-weight syndrome.

## Minimum feedback correction rank for a supplied order

Normalize self-references by substituting the bit's required active value one. For each literal owned by i let its future suffix (columns j>i) be specified; allow all other columns to be arbitrary in a correction row. Find a minimum-rank matrix R completing these row suffixes. With A its original coefficient matrix, A+R has no future coefficients. In newly introduced self coefficients of A+R substitute one when evaluating its guard, adjusting offsets.

To compute R, process rows in order of nondecreasing owner. Maintain a basis of completed rows chosen so far. Project those basis rows onto the new row's specified suffix. If the required suffix is already in this span choose any witnessing combination as the row. Otherwise add that suffix extended by zeros elsewhere as a new basis row. An addition is mandatory in every completion because for every earlier row its projection onto the current suffix was specified from the outset. Thus every completion must pay one rank increase at each such position. The algorithm pays exactly for these positions and gives a minimum-rank factorization R=UV. Its running time is polynomial by Gaussian elimination.

Branch on the k-bit syndrome Vx of this rank-k factorization. Substitute the guessed response U(Vx) into the guards, use the acyclic coefficients A+R, and append k terminal equations verifying the guess. The specialized instance is acyclic and agrees with the original for all assignments passing the new equations. Solve by the known acyclic degree-(b+k) compiler for 2^k n^O(b+k) deterministic time with no control on the forward response rank. Any stronger acyclic algorithm applicable to the corrected dependency structure may be used in its place. The factorization may produce earlier edges that influence such additional restrictions.

completion.py computes the optimal correction for arbitrary occurrence order. test_completion.py verifies 300 small matrices against exhaustive completion rank and checks all prescribed suffixes.

For a separation in the displayed order on 2m variables, give every row all off-diagonal coefficients one, except that row m+i omits column i for 1≤i≤m. One literal per guard suffices. Its future suffixes have minimum correction rank one; the all-ones matrix completes them. The early m vertices induce a bidirected clique, forcing a feedback vertex set of size at least m−1. Across the middle cut the later guard rows restricted to earlier variables form J+I, of rank at least m−1. Thus neither feedback-vertex enumeration nor bounded forward response rank in that order accounts for the correction result.
