# Deterministically project b affine disjunctions to b single affine markers

Let a fixed base relation have arbitrary admissible assignments. Terminal clause i is the disjunction of affine truth bits L_ij on an assignment. There are L literal occurrences across b clauses. For b=0 use the base problem. An empty terminal clause causes immediate rejection. Give each occurrence a distinct exponent k=0,...,L−1. Choose a power of two q at least 2^(b+1)L and less than twice that bound. Construct the field of size q deterministically by testing monic binary polynomials for irreducibility. Brute-force trial division fits polynomial time in q.

For each α,γ in that field set the selector of occurrence k to the constant coefficient of γ α^k in a fixed polynomial basis. Replace each clause by the single affine equation saying the sum of its selected literals' truth bits is one. These b affine markers can be tested by any appropriate base oracle. Every successful assignment for a projection satisfies all original clauses.

For completeness, fix an assignment satisfying all clauses. Under independent uniform selector bits, the b selected-literal sums are independent uniform bits: every row is nonzero and uses a disjoint set of selector coordinates. Under the proposed finite-field construction, every nontrivial parity of selectors has bias at most (L−1)/q: it is the constant coefficient of γ P(α) for a nonzero polynomial of degree <L; if P(α) is nonzero the inner expectation over γ vanishes. Every nonempty combination of the b rows is nontrivial. By character inversion, the probability of the all-ones outcome differs from 2^(−b) by at most (1−2^(−b))(L−1)/q, strictly smaller than 2^(−b). Thus some enumerated projection accepts the same witness.

There are O(4^b L²) projections, each produced and applied in time polynomial in the supplied formula size and field bit length. This argument extends any algorithm for b simultaneous affine terminal markers to b terminal affine disjunctions, without parameterizing by the number of literal occurrences or their combined rank. It also applies after the two-port block-gluing algorithm in gluing.md: the projected instance has b linear marker labels, so the child sparsification argument still uses dimension b.
