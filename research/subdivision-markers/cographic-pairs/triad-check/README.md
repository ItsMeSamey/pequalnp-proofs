# Independent three-bond matching verification

The input to check.py is a loopless 3-edge-connected multigraph, a collection of sorted three-bond edge triples with allowed subsets of the four even bit patterns, and optional fixed edge bits. The solver returns the original graph's selected edge mask or None. It enumerates triples of edge indices to find the shores away from vertex zero and orders the constrained shores by inclusion.

Crossing rooted shores would determine four nonempty quadrants A,B,C,D, where the two shores are A union B and A union C. Submodularity and posimodularity of the cut function force all four quadrant cuts to have size three and both diagonal edge counts AD,BC to be zero. Equal boundaries at A and B then imply AC and BD have equal edge counts. Their total is the size of the first shore cut, contradicting its odd size. The constrained shores therefore form a laminar family.

At each node contract maximal child shores to ternary factors. Ordinary vertices are parity cliques: give every incident edge a socket, and add a dummy if needed to make the clique even. For a child select any allowed baseline t. Give each socket a private mate and connect mates i,j precisely when toggling that pair from t is allowed. An external matching edge used at a raw socket leaves its mate unmatched locally. Thus no toggle or one permitted pair can occur. For each baseline-one index insert a new socket with a single edge to the raw socket, complementing its occupancy. An empty child table makes its parent test fail. The even table is applied as the node's own restriction when enumerating outgoing patterns.

An unpinned edge between two factors is a single external matching edge. A prescribed zero suppresses the edge. A prescribed one gives each of its two sockets its own forced leaf, encoding occupancy one at both. A port with an outside endpoint has only one socket, which is clamped to the requested boundary bit in the same way. These constructions preserve the exact edge relation. Each successful table entry stores one actual mask, filling in child interiors according to the external occupancy. The root's zero-boundary entry supplies a global witness.

The matching oracle is NetworkX's general-graph maximum-cardinality matching. The independent reference enumerates every cycle vector using a spanning tree and checks every parity and table directly. All 128 individual gadget signatures and 240 complete systems passed. The graph list includes a three-parallel-edge graph, K4, K5, K3,3 and four successive triangle expansions. The deepest tested chain of proper three-bond shores had length five. Direct tests yielded 160 feasible and 80 infeasible systems. Each returned feasible mask passed independent verification.

Run python check.py with NetworkX installed. In the shared research workspace the same check runs with PYTHONPATH=/workspace/scratch/syn_quotients/tools_lib python check.py.
