# Two signatures on each shore

If the hypotheses of one-signature-exclusion.md hold and each clean shore has exactly two augmented signatures, the ground has exactly eight elements. The eight-element example below shows both directions of uniqueness and the absent target. Free score offsets are handled by quotient first.

For clarity, for ANY number of clean column signature classes, refine each augmented row type by the parities of its N-neighborhood sizes in each column class. Inside any column class, rows of a fixed type have comparable neighborhoods: a 2-by-2 permutation block would allow the forward clean same-type switch. Two rows of the same refined type thus have dot product within a column class equal to their common restricted weight parity. Summing these parities gives zero by even full row weights. The refined type is therefore independent in the Gram graph G=NNᵀ.

Let T be a Gram-induced-even set with the full original row-tag XOR and with every per-column-class row-parity sum zero, as for the whole X because N has even column weights. Starting at the reverse witness (B,A), toggle the dual clean rows x=1_X+1_T and the primal clean columns y=Nᵀ1_T. All row tag, exceptional and primal marker changes vanish; y has even weight in every column class. On clean columns Nᵀx=y, so dual additions there coincide with primal removals. On clean rows Ny=G1_T vanishes on T, so primal additions occur only where the dual was removed. Thus another raw model attains r unless T=X. In particular preserving every refined class parity suffices.

With two column classes the refinement of a row requires only one bit t, since its two parities agree. The full sum of these t bits is zero. If |X| is odd then exactly one of its two coarse row types is odd. Any t=0 row of this odd class yields a singleton T already preserving the coarse XOR and zero t sum. Otherwise this class has only one refined type, and there are at most three refined types in all. The three-independent-class Gram lemma gives a representative of size at most four and the same class parities. Since its total size is odd, |X|≤3. The dual statement holds for odd |Y|.

Write e=|A outside I|, k=|B∩I|. Both are positive and e+k≤3 by the forward witness and missing score. The bicycle shores have even size, so |X|≡e and |Y|≡k. Thus at least one clean shore is odd. The reverse dimensions null(B)=|Y|−rank N, conull(A)=|X|−rank N are positive and sum to at most three by r and missing p. The clean shore lengths differ by at most one. There are at most 3+4+3=10 elements, an even number. Exactly two augmented signatures on each clean shore require at least two clean elements per shore. Since |A|,|B| are positive even and each has at least one exception, both shores have at least four elements.

For size ten the sole chart size up to duality is |X|=4, |Y|=3, e=2, k=1. The two A exceptions split X into odd sectors, necessarily 1+3. These already account for the two augmented row signatures; each sector has one gain. The two column gains likewise have a singleton and a pair. Each shore must have distinct raw gains: if all Y gains agree, L(B)≠0 forces odd |Y|, hence odd k=1 and then the uniform exception trace on Y follows from the B cocycle. This contradicts the one-signature exclusion, and dually for X. Normalize the two A circuit gains and B cocycle gain to 1,2,4 by forward uniqueness. Enumerating disjoint primal/dual supports for all remaining four gains excludes size ten. The checker ../degree/ten-two-signature.cpp tests 13 chart representatives and 702,000 maps. Independently two-signature-ten-check.js fixes both singleton type indices, enumerates 42 labelled even rank-two matrices without quotienting permutations, rejects 30 by actual raw coefficient collisions, and checks 648,000 maps over the other twelve. Neither finds any pair of distinct opposite unique targets, even before requiring a missing score.

At size eight a fundamental chart with rows 11,19,7 in low-bit-first binary on five columns, clean X the first two rows and clean Y the first three columns, has primal gains (8,1,1,1,2) and dual gains (0,4,4). Its histogram at scores 0 through 15 is (7,6,5,5,5,4,2,1,5,5,4,4,1,2,0,1). Forward and reverse targets are 7 and 12, and 14 is absent. See ../degree/two-signature-split.cpp. This is a theorem for two augmented types on each clean shore, not merely two distinct raw scores with extra variable exceptional incidences.
