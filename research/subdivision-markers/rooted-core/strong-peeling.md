# Fixed-partition peeling and opposite score witnesses

For the weak block-triangular condition, each row type by column type rectangle is Ferrers (its rows are linearly ordered by inclusion). The strong condition asks that in every restriction a row be constant within each column type, or a column constant within each row type. The row or column chosen can depend on the restriction. See Hörsch, [thesis](https://uwspace.uwaterloo.ca/items/19529045-7361-4ae2-9773-0a4d86cd6197), Definitions in §1.2 and Lemma 1.2.4. All statements below concern the displayed partition.

**Local recognition.** A weak partition with a row types and b column types that fails the strong condition has a failing restriction with at most 2ab rows and 4ab columns. In any failing restriction keep the two extremal rows of each nonempty type rectangle. Every column still varies in some row type by nesting. For each kept row retain two columns of the same type witnessing variation there. Rows and columns all still vary in their required way.

**One column type and two row types.** In a genuine unique-forward-witness chart whose equal types include all score and exceptional incidences, this partition is strong. In a stuck restriction keep the two extrema of each row type. Encode each column by two digits, each 0,1,2 describing entries 00,01,11 on the extrema for that class. Every column has a digit 1. Both extrema vary, so each digit position attains both 0 and 2. Thus there are columns of types (0,1),(2,1),(1,0),(1,2). The four rows and these four columns have all induced degrees odd, and each row type and the single column type occurs evenly. This gives a clean, score-preserving switch contradicting uniqueness. If one row type is absent all columns would require digit 1 and the extremal rows would be constant. The proof applies to restrictions within larger genuine charts.

**Why three types require more.** In one common column type use row pairs (001,101), (100,110), (010,011). This is a weak three-type chart with no peel. There is no nonempty all-odd switch even on every type. An active pair would require its private differing column inactive, since both row sums must be odd. Conversely oddness in an active column requires its private row pair active because other pairs agree on it. This rules out any active columns and hence any active rows. This tile need not extend to a genuine core.

**Additional reverse-witness test.** In the one-column chart the full row set of the clean Gram graph G=NNᵀ is uniquely induced-even at its augmented type parities (see guard's gram-switch.md). Assume its rows have even weights and the number of columns is odd. Write W=J+N. Then G=J+WWᵀ. Whenever all zero sets of columns of N lie entirely on one side of a row partition S,T, G has complete adjacency across that partition. If T has only one augmented row type then its nested even-weight rows have pairwise dot product zero, so T consists of independent vertices with identical external neighborhoods. Removing any two of them from the full induced-even support preserves induced-evenness and all type parities. Hence |T|≤1. In particular this applies to the isolated gain line from the independent forbidden-triple case of one-column-gains.md when there are no zero-gain rows and that line carries one augmented row type. For a dependent forbidden triple, if there are no zero-gain rows and each nonzero gain has one augmented type, all gain groups have size at most one. These conditions concern augmented types, which include exception incidences. The conclusion need not follow from equality of score bits alone.

The separate check-gram-cycle.py constructs a growing alternating-cycle Gram family that passes the reverse full-type-parity criterion; its forward balanced switch for k≥4 prevents interpreting it as a genuine opposite-unique example. General strong peeling for the two-witness cores remains open here.

**Five-row bound.** In the rank-three case of one-column-gains.md assume no zero-gain rows and each gain has just one augmented signature. In the independent forbidden-triple case the three plane-gain classes form S, and the isolated gain group T contains at most one vertex by the join lemma. If T is empty the three-type bound from gram-switch.md applies. Otherwise write T={t}. In the full Eulerian Gram graph t is joined to all of S, hence |S| is even and every vertex of G[S] has odd degree. The three types of S are independent. We find at most four vertices S' inducing only odd degrees and preserving all class parities. If all classes are even take the empty set. Otherwise two classes I,J are odd, and C is even. Any I–J edge suffices. If there are none, every i∈I and j∈J has odd neighborhood in C. For each pair count the choices of one C vertex adjacent just to i and one adjacent just to j. This yields an induced matching, and its count modulo two equals (1+|N(i)∩N(j)|) squared. Summing over the odd number of pairs gives 1+Σ_{c∈C} deg_I(c)deg_J(c)=1, since each c has odd degree and its two degrees have opposite parity. Some induced matching works. Now S'∪{t} is induced-even and preserves every augmented type parity. Reverse uniqueness implies |X|≤5. For a dependent forbidden triple the join lemma gives at most four rows. With a single exceptional A-nonbasis column its incidence is one on every clean row, hence distinct signatures automatically correspond to distinct gains there.
