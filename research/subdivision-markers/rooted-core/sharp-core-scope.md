# Sharp opposite-core bound

Two individually unique opposite full raw support pairs on the same binary ground set imply at most 2^(t−1) elements with t score bits. At four bits the bound is eight and is attained. Common hidden offsets must be freely available for each raw support pair before quotienting. The seeded constructive consequence assumes the two attaining witnesses and exact score-lifted restrictions. Extracting a core for an unseeded target remains open.

The eight-element example has masks (195,60) when basis coordinates come first and (120,135) when nonbasis coordinates come first. These describe the same ordered witness pair under the change of coordinate order. The earlier 34-element bound additionally assumed a missing score.
