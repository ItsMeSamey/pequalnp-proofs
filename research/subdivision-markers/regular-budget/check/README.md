# Finite audit of two-coordinate boundary budgets

Run python check.py. The checker represents each normal space by its complete set of vectors and enumerates all affine cosets directly as forbidden assignment masks. Repeated flats and parallel clauses are allowed. Boundary feasibility for each side comes from brute-force assignment enumeration.

For each possible interface intersection S in {0,three lines,K}, retain the greatest unconditioned excess of a subfamily whose normal span intersects K exactly in S. This five-entry profile suffices to recover every conditional Rado budget. Combining two pieces with private dimensions assigned disjoint coordinates gives global deficiency equal to the maximum of p_C(S)+p_D(T)+dim(S intersect T). This follows from rank of the sum of their spans; between sides all common vectors belong to the interface.

The enumeration groups side systems only when both their complete five-entry profile and their true four-point boundary table are identical. It then checks every ordered pair of signatures, retaining counts of the represented systems. It independently checks safe-line uniqueness, exact reconstruction when a safe projection is fixed, all five domination inequalities for an exact summary, decision preservation when no safe projection is fixed, outside surjectivity on the hazardous normal, and the outside-full case. Finally, 900 random systems explicitly join the two private-coordinate spaces, enumerate every global subfamily, rederive rank by Gaussian elimination, and brute-force all global assignments. The reported counts are finite comparisons, not the proof of the unbounded theorem.

The control flow uses global deficiency at most one as the admission promise. For a child with empty boundary language it rejects immediately. For a nonempty child and an outside with no extension, a relaxed deletion preserves rejection. A deletion when the child has a non-full boundary language only preserves feasibility against the admitted outside; it does not preserve the child's standalone language.

The completed census found 1,711 admitted ordered gluings with only the two shared coordinates (through three clauses per side). With one private coordinate on each side and up to four clauses per side, 157,774 admissible local systems produced 1,360 signatures and 33,172,839 admitted ordered gluings. They included 664,146 drops of a hazardous-normal line, 3,031,428 drops of a three-point language, 700,560 drops of a full language at child budget two, and 4,225,716 outside-full cases. Of the 900 independently assembled random gluings, 767 met the global budget.

tree_run.py exercises repeated leaf deletion. A bag is a complete graph on its vertices, all bags contain anchor vertex 0, and each tree edge glues its incident bags on exactly a triangle. Rooting vertex potentials at 0 makes edge uv the normal e_u+e_v. A rank-two forbidden flat uses the edge normals of one genuine triangle. For the binary matroid 3-sum presentation one can adjoin a dedicated parallel virtual triangle for each incident tree edge and delete those virtual copies upon gluing, retaining the real represented edge normals. Sharing boundary vertices is the usual graphic realization of this sum. The test directly uses the resulting global coordinates, independently of the general decomposition theorem.

The peeler queries only its current basic bag, checks the conditional Rado budget of every local call, recomputes global deficiency after every removal, and includes the immediate global-decision case where the outside extends all boundary assignments. Its deterministic three-bag example performs two successive relaxed deletions of non-full child languages before solving the last bag. The all-zero parent assignment is a witness after both deletions and violates both original child languages. A separate native run recovers witnesses by zero-pivot self-reduction under one marker pin, solving each residual with a fresh leaf order and validating the reconstructed assignment in the original clauses.
