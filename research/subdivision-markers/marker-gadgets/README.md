# Positive-pin compression for induced even-degree witnesses

Graphs are finite, undirected and simple. Vertices in a positive pin set must be selected. An assignment is the selected vertex set and every selected vertex must have even induced degree.

## All pins implied by a pair

A single pin or two nonadjacent pins imply no further selected vertices because the required pins alone form a witness. For two adjacent pins a,b, let D be the graph after deleting their edge. There is a witness exactly if D contains an a–b path. A shortest such path is induced in D and closes to an induced cycle after restoring the edge. In the other direction the edge ab cannot be a bridge in an even-degree graph: summing the degrees on one side of a bridge gives odd parity.

Provided the pin pair has a witness, a vertex v different from a,b is selected in every witness if and only if deleting v disconnects a from b in D. In fact any witness contains an alternative path, and a shortest alternative path in D−v gives a witness avoiding v whenever one is possible. Thus for a prescribed positive set containing adjacent a,b, discarding all other pins preserves the *full set* of witnesses exactly when every discarded pin lies on the a–b separator chain in D. If ab is a bridge no superset of these two pins is feasible either. A DFS block-cut tree in D computes the separators in linear time. This theorem concerns a pair as the sole remaining constraint; additional affine equations can change its set of implications.

## Locality along the forced chain

Order a=c_0,c_1,…,c_s=b by their appearance on any a–b path in D, including all internal separators. The order is unique, for example by the unique path in the block-cut tree. Any component of D after deleting the chain has neighbors in at most two chain vertices, consecutive when there are two. Otherwise it connects vertices on opposite sides of a deleted intermediate separator. For the same reason a direct edge between chain vertices in D can join only consecutive ones. This limits direct incidence from any unpinned connected component to mandatory check vertices even if extra hidden vertices are allowed.

With all chain vertices selected, require even degrees at all selected interiors of each remaining component. By handshake a component with exactly one attachment contributes zero degree parity to that attachment. A two-attachment component contributes equal parity to the two selected endpoints. For each consecutive gap let its value be the sum modulo two of all such component parities plus the presence bit of a direct gap edge in D. The endpoint degrees after restoring ab force the first and last gap values to be one, and each intermediate chain degree forces its two incident gap values to agree. Hence all gaps must be one. Conversely these local checks suffice at every vertex of the full graph. Distinct gaps involve disjoint components, and the unattached and singly attached components can choose their valid interiors independently. Consequently the full solution set factors, after deleting fixed chain bits, into one relation per gap and one relation for each unattached or singly attached component. Projecting onto any specified original output coordinates preserves this product decomposition. A single gap can have an arbitrarily complex relation.

## Serial encoding of independent marked blocks

Given k disjoint original graphs, each with a single affine parity condition on arbitrary marked vertices, retain all original vertices and edges. Arrange fresh checkpoints c_0,…,c_k, introduce positive pins a,b, and add edges ab, ac_0, c_k b. For block i add edges from each marked vertex to both c_(i−1) and c_i. Also insert the direct edge c_(i−1)c_i precisely when the target bit for this block is zero. There are k+3 additional vertices and exactly two selected pins. All original graphs may be arbitrary internally, including disconnected graphs and isolated vertices.

In any witness the alternative a–b path forces each checkpoint, since blocks have no cross edges. This argument also applies if some gap is empty and disconnects the endpoints: then there is no witness. Once every checkpoint is selected, each selected original vertex acquires zero or two more neighbors, preserving every original guard. The gap parity equals the selected marker parity plus the direct-edge indicator. By the gap criterion every gap must equal one, equivalent to all the original equations. Conversely selecting every checkpoint and both pins extends any original solution. The extension is unique; the reduction gives a bijection of all witnesses, with the inverse simply restricting to real vertices.

In the worst case a single positive pin does not suffice for this projection even with arbitrary hidden structure. Two separate odd marker conditions on disjoint nonempty independent classes require weight at least two in every output. A single positive pin always admits its singleton as a graph witness, whose restriction has weight at most one.

The block-separation condition matters. For two singleton blocks with targets one, add one edge between their original vertices x,y. Original feasibility now fails, as selecting both gives odd degrees. The serial gadget nevertheless has the induced cycle a,c_0,x,y,c_2,b,a avoiding the middle checkpoint. This establishes a concrete failure for direct cross-block edges.
