# Exact named kernels on graphs with uniform binary edge gains

Let each edge e=uv of an explicitly supplied simple graph have the binary column (e_u+e_v,σ_e). Gains may have arbitrarily many binary coordinates. Supply a partition of its vertices into k classes such that each unordered class pair, including a class with itself, has either no edges or all possible edges with one common gain. A direct scan verifies the promise. Let B consist of q arbitrary named columns in the same ambient space. Additional external coordinates can be included as gain coordinates zero on every edge. For an ordinary contraction set X the named kernel is

    K_X = {z in F₂^q : Bz belongs to span(A_X)}.

There is a polynomial-time target-independent reduction to a simple gain graph on at most 4k·4^q vertices. It preserves the entire family of named kernels. A polynomial-time algorithm transports each particular physical contraction witness in either direction. Exhausting contraction sets of the reduced graph therefore decides an exact target in f(k,q) times polynomial input length independently of the ambient gain dimension. The named columns and gain labels still carry their input bit lengths. This extends the ordinary [graphic neighborhood-class reduction](../graphic-root-kernel/README.md) to nonregular hosts.

## Reduction

Let b_v denote the row of named vertex coordinates at v. The refined type of v is its original class together with b_v. Put L=4·2^q. In each type keep all vertices if there are at most L, otherwise keep L or L−1 with the original parity. Take the induced graph with original gains. Restrict each named vertex vector to the retained positions, preserving its entire gain/external tail. There are at most k·2^q types. The optional implementation assumes that the vertex-plus-gain coordinate presentation itself is supplied.

Fix a source contraction mask X and write K=K_X. For a basis of K⊥, extend every prescribed vector of evaluations on B to a linear functional annihilating A_X. These extensions exist by passing to the quotient by span(A_X) and are computable by elimination. Write Λ for their gain-coordinate rows. Color each vertex by its vector of evaluations at that vertex. An edge uv is killed by all the functionals precisely when its two colors sum to Λσ_uv. There are at most 2^q colors. For each (refined type,color) cell preserve its count when 0,1,2; for a larger count preserve parity and retain at least three. In particular an odd large cell first requires three and an even large cell four. The minimum total across one refined type is at most L and has its original parity. Each direction of the reduction can realize that census. Remaining pairs can be put in any originally large cell; if no such cell exists the total type size is at most 2·2^q and never changes. This transfers the colors. All simultaneous dual conditions on B retain their exact values, since the number of vertices of each charge and color retains its parity.

It remains to preserve each primal incidence-and-gain demand Bz for z∈K on the allowed edges. Within every colored cell temporarily use a common representative set of size 0,1,2,3 or 4 as above. Push an allowed edge chain to these representatives by sending every extra vertex to one representative of its cell. For distinct images the same edge with the same gain exists. A collapsed edge lies within one cell. That cell is a complete allowed clique and at least three representatives were kept, since it contained extra vertices. Replace the collapsed edge by a triangle among three distinct representatives. Its boundary is zero and its gain is σ+σ+σ=σ. Each representative receives the correct incidence demand because the number of extra vertices at that cell was even and each carries the same b_v. This pushes the whole demand, including its gain, to the common graph.

For expansion use those representative edges in the destination. Extra vertices come in pairs of the same charge and color. For each pair carrying an odd demand, connect its two members to one common neighbor by two allowed edges of identical gain, contributing zero net gain. Such a neighbor exists. If an occupied other cell is adjacent, use a vertex in that cell. If the cell is internally adjacent, use a representative there. If it has neither, its representatives were isolated in the common allowed graph and could not have carried odd demand. Thus all Bz for z∈K remain realizable. The transported dual functionals exclude every z outside K. Consequently taking *all* allowed destination edge occurrences as the contracting set recovers exactly K. The argument works with either direction as source and imposes no sparsity hypothesis on named demands.

## Nonregular controls

Give all edges of K_m gain 1 in one binary coordinate, with m≥7. Contract edges 01,12,34,56. The three vertex groups 012, 34, 56 then admit two gain choices between every pair. In the quotient the seven ordinary edges 02,03,13,05,15,35,45 are distinct nonzero vectors of rank three. They therefore give an F₇ restriction of the contracted matroid. Unbounded clique size does not make this a regular-host case. The ordinary matroid also has unbounded branchwidth, since appending one gain row changes each ordinary cut-connectivity by at most one in the decreasing direction, and graphic clique branchwidth grows with clique size.

For m≥7 take four mutually independent names e₀+e₁, e₀+e₂, e₀+e₃ and the pure gain. Contracting only 01 gives the gain-coupled line generated by the first plus the fourth name. Deleting the gain labels changes this answer. Contracting an additional disjoint triangle yields the plane generated by the first and fourth names. In contrast the plane generated by the sum of the first three names and the fourth name is unattainable. Its four-terminal vertex demand requires every component to contain an even number of the four marked vertices. Some two marked vertices then lie in the same component. A path connects this pair and the available pure gain cancels any unwanted gain. The pair demand is a further combination of the first three names outside the requested plane.

Run `python check.py` with the sibling unseeded-root-states module available. The checks exhaust 4,121 source contractions and 720 exact target decisions on 45 small hosts, verify the seven-point minor and the positive/negative target controls, and transport 70 larger contractions with dense root demand. The 76-vertex all-negative clique shrinks to 68 vertices with the four marked names and to 16 with two dense/gain names. This is a decision and witness theorem. It does not preserve assignment counts or supply an unrestricted fixed-root SAT reduction.
