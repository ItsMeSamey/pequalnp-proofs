# Binary ternary-choice systems with a full independent transversal

A group offers either no column or exactly one of two columns over the binary field. Its choice labels are distinct even when some columns happen to be equal. For N groups whose columns have total rank N+b and admit an independent representative from every group, the surplus is b.

## Native guards to groups

Suppose hidden bits z_i may always take zero. If z_i=1 at least one guard literal in its clause must be true. There are b terminal clauses, each requiring a true affine literal. Observed bits X are parameters. For every guard literal introduce its own bit w, with a separate block per source guard. Define z_i as the parity of that block. An empty block decodes to zero. Guard each w by its literal with z_i specialized to one and every other z_j replaced by its block parity. For a terminal introduce one bit per literal, guarded by that literal after every hidden substitution, and require odd parity of its block. This gives N bits, one per literal occurrence, and b parity rows H. All new guards are single affine literals.

Every original witness lifts by choosing one true alternative per active hidden bit and per terminal and setting every other clone to zero. Conversely, an odd hidden block contains an active bit with a true specialized guard. Its decoded source bit is one, so this guard is true on the decoded assignment. An even block decodes to zero and needs no source justification. Each terminal has an active clone with a true original literal. These maps preserve the projected hidden and observed relation; multiple lifts may project to one witness. Hidden cycles or input self-references cause no change. If dependency among distinct original hidden bits is acyclic, the clone dependencies remain acyclic in that order, with terminal clones last.

Negate the truth indicator of each clone guard to write its violation factor as p_i(X)+(Mw)_i. Then w is feasible exactly when w_i(p_i(X)+(Mw)_i)=0 for every i and Hw=h, where h is all ones. Offer (e_i,0) and (M[:,i],H[:,i]) in group i. Target (p(X),h) forces the first-column indicators u to equal p(X)+Mw when w are the second-column indicators. Local choice validity is u_i w_i=0. Thus normalized native witnesses and labeled group choices correspond bijectively. The first columns are independent, and quotienting by them leaves columns of H. For nonempty terminal blocks its nonzero rows have disjoint supports and are independent, so the total rank is N+b. Construction is polynomial in literal count and source length, including dense substituted masks.

Any empty terminal makes every observation reject. If exact surplus b is needed in this branch, supply b groups of disjoint independent coordinate pairs in a 2b-dimensional space and target both columns from the first pair. This is impossible, rank is 2b and b≥1. For an empty system the empty choice realizes the zero target. True and false constant literals need no exceptions. The uniform encoding for observations uses an affine target p(X). Fixing observations yields an ordinary target. Existential observations can instead be represented as free native bits if decoding their values is required.

## Groups to native guards

First check membership of the target in the span of the columns. For a fixed target outside this span the answer is negative, independent of the choices. With target inside, use coordinates in this span. Obtain an independent representative column from every group by matroid intersection of the linear and group partition matroids if one was not supplied. Failure to find N such columns reports that the input lies outside the promised class. Label the selected columns first, extend them to a basis of the column span, then transform every group to (e_i,0) and (M[:,i],H[:,i]). In these coordinates transform the target to (p,h). The number of bottom rows is rank−N; H has full row rank since all columns span the ambient space. For a candidate second-column vector w impose the guards w_i⇒[p_i+(Mw)_i=0] and the b terminal equations Hw=h. A self coefficient may be specialized at one for its active test. The unique u=p+Mw completes every witness and inversion of any column swaps restores the original labels. These steps preserve complete ternary witness sets. A change to an arbitrary independent transversal may introduce cyclic dependencies.

For targets depending affinely on observations, projecting the target into any complement of the original column span yields additional observation-only consistency tests if some targets lie outside the span. The exact-surplus parameter statement applies directly to fixed targets in the span, and to affine target families taking values entirely in that span. The forward construction has full ambient rank throughout the nonempty-terminal case.

The executable compares all decoded original hidden assignments in 1,163 seeded observation cases and all labeled choices in 350 seeded basis-change cases. Its native projection checks include empty clauses, self references, constants and cycles. The basis checks also cover ambient spaces larger than the column span; they retain any redundant bottom rows for that test.
