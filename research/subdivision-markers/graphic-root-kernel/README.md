# A target-independent reduction for graphic named kernels

Let ordinary binary columns A have a supplied graphic representation on edge occurrences of a graph with k neighborhood classes. Let B be arbitrary named columns in the same ambient space. For an ordinary contraction set X and deletion of all other ordinary elements, the named kernel consists of z with Bz∈span A_X. Put U=span A∩span B and d=dim U. There is a polynomial-time reduction to at most 2(d+1)k·2^d ordinary vertices and a simple graph on them. The new named columns preserve **every attainable kernel simultaneously**, with polynomial-time witness maps in both directions. The vertex bound excludes the named-column list and its external coordinates. Witness multiplicities may change. [Graphic model and neighborhood components](../macro-root-states/README.md)

Choose a basis of U and transfer it to d vertex-parity vectors using ordinary lifts in the given graph. At each vertex v write h(v) for its d membership bits. In the connected components C of any contracting set X, including isolated vertices, put h(C)=Σ_{v∈C}h(v). For a coefficient vector z in U-coordinates its demand can be met on X exactly if h(C)·z=0 for every C, by the component parity criterion for joins. Thus the ordinary trace W=span A_X∩U in U-coordinates satisfies W⊥=span{h(C)}.

Choose s=d−dim W components whose charge rows form a basis of W⊥. Assign these distinct colors 1,…,s and the remaining vertices color zero. All chosen edges are monochromatic. Every monochromatic component of the graph induced by a color has zero parity in every basis demand of W, since it is a union of earlier components. The total charges of the s distinguished colors span W⊥. Conversely a coloring with these two properties yields the exact W. Solve each basis demand of W on available monochromatic edges and take the union. The per-color charge rows exclude every vector outside W. Consequently at most d+1 colors suffice to describe any attainable trace.

Give each vertex the joint type consisting of its neighborhood class and h(v). For each nonempty type retain all copies up to 2(d+1). Above that limit retain the largest number at most 2(d+1) of the original parity. Use the induced underlying simple graph, and restrict the d basis parity vectors. Every old type remains represented, so the restricted rows stay independent. The underlying component parities are preserved; the restricted vectors lie in the new ordinary span. Isolated independent-class vertices have zero demand individually.

To transfer a coloring, within each type preserve the parity and nonemptiness of the count of every color. At most two copies of each present color suffice for this. The target type has enough copies: if it was truncated its same-parity bound is at least the total minimum requirement; if not, its original multiplicity suffices. Allocate remaining copies in pairs to some present color. The same argument works in reverse. Color availability in each neighborhood class stays fixed. Components spanning multiple classes or a single clique have unchanged total parity. An isolated independent vertex of a demanded type cannot be assigned the offending color, and nonemptiness preservation handles this case separately. Thus the parity and color-span criteria survive. Solving the basis demands on destination edges recovers a physical contracting set with the same W.

To retain B, extend the chosen basis of U to a basis of span B. Write each named column in that basis. Map its U-coordinates to the restricted demands and keep its remaining coordinates on fresh external rows disjoint from the ordinary span. For every z the exterior part vanishes in the same circumstances, and the internal combination then belongs to precisely the matching W. This proves exact named-kernel preservation even for loops, dependent names, and roots outside span A.

## Exact search with a small set of colors

For a requested K, first test B(K)⊆U and dim K=dim ker B+dim B(K). These are necessary and sufficient for K to be the inverse image under B of a subspace W⊆U, where W=B(K). Search for a coloring with s+1 indexed colors as above. For each type class guess its nonempty color set. In the vertex table accumulate d bits of total charge for each nonzero color, evenness of every W basis demand in each connected monochromatic class component, and presence of each color in each class. For a monochromatic singleton independent class, exclude that color at a vertex of nonzero W-demand. At the end test all required parities and occupancy flags, and test that the s charge rows span W⊥. This uses 2^O((k+1)d²) polynomial time for d≥1. The d=0 case is immediate. Neither the reduction nor this decision bound depends on the number of odd vertices in a demand. [Implementation](palette.py)

Run `python check.py` and `python check_palette.py` with the sibling macro-root-states and unseeded-root-states directories available. The tests check 988 forward and reverse contracting-set transfers by recomputing the full named kernel, including loops, parallel edges, dependent and external named columns. K₄₄ and K₂₂,₂₂ examples each reduce to 12 vertices. A separate comparison of the small-color decision procedure against all contracting sets covers 560 requested named kernels. The input requires a validated graph realization and neighborhood partition. It gives no root-count compression for arbitrary SAT reductions.
