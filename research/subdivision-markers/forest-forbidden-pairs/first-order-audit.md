# Supplied order and clone normalization

The canonical first-true construction clones all active literal occurrences before it lays out the graph. For d≥2, cyclic implications force every clone of that source variable to agree; every common truth value satisfies all the implications. Unused declared variables are retained once. Thus restriction of a satisfying clone assignment is bijective, including the empty-input convention. Each clone has one original occurrence, one negative occurrence in its outgoing implication, and two positive occurrences in its incoming one, hence at most four occurrences. One occurrence participates in at most three first-true tests. Thus each cycle has length at most 2 max(2,12)=24, and each clause block has ten vertices. The explicit vertex order groups all vertices of one block followed by that block's two consecutive backbone vertices. Every edge lies in one such cluster or links consecutive clusters. Their sizes are ≤26, so every edge has span at most 51. This is a uniform upper bound and need not be tight.

Run python check_first_order.py after placing it alongside the two existing checkers. It enumerated all 16,605 potential clone assignments from 84 original formulas, including formulas with a variable repeated nine times, opposing repeated units, and unused variables. Per original assignment the fiber count agreed with truth. On the emitted physical graphs it verified every vertex ID occurs exactly once in the supplied order, every forbidden edge endpoint ID is distinct, and evaluated the span of every graph edge. The largest observed span was 19 in this finite suite. With --example it emits the full order, physical edge list, forbidden edge-ID pairs, cloned formula and clone-to-original map as JSON. The test does not infer bandwidth from the unstated existence of an order.
