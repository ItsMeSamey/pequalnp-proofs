# Weighted parity quotients of directed Boolean guard systems

For a loopless directed adjacency matrix A put F_A(x)=x componentwise-multiplied by (1+Ax) over the binary field. Solutions satisfy F_A=0, with optional affine markers. Rows indicate outgoing arcs. Let a linear projection L have column c_v for each fine vertex, and let Q be the target adjacency matrix.

## Exact characterization

The full Boolean-function identity L F_A(x)=F_Q(Lx) holds precisely if

    c_v ⊙ Qc_v=0                       for every v,
    c_v A_vw + c_w A_wv = c_v ⊙ Qc_w + c_w ⊙ Qc_v    for v distinct from w.

Here ⊙ is coordinatewise product. The linear terms Lx on the two sides agree. Evaluating the rest on singleton inputs and then on each pair proves necessity, and these tests determine all coefficients of the quadratic multilinear discrepancy. In particular the unknown fine arc bits for one unordered pair never occur in the cross-equation for another pair.

For an identity only on odd inputs, keep the singleton condition and let d_vw be the sum of the two sides of the pair equation. The criterion becomes existence of vector potentials s_v with d_vw=s_v+s_w for all pairs. Tests on every triple give zero sum on each triangle, equivalent to this criterion on the complete graph of vertex indices by fixing one anchor. Conversely the discrepancy is (1+sum x_v) sum_v s_v x_v as a Boolean function, hence vanishes on the odd slice. This handles orders one and two as well. If a one-marker parity is to be preserved on the two sides, require each c_v to have odd weight. General target marker H on the coarse side pulls back to H L on the fine side.

Suppose there are representative vertices with labels e_i for every coarse index. The injection using just these representatives is a right inverse of L. On its image the vector of fine guard values has support among those representatives, and L simply reads their individual values. Hence the forward identity also proves the reverse implication on that subspace. It yields a projection carrying solutions onto all coarse solutions, including in the odd-slice version.

For PC derivations, substitution y=Lx preserves formal degree, a multiplication by y_i being a sum of ordinary variable multiplications. Boolean axioms pull back to sums of Boolean axioms in characteristic two. Each substituted guard has a degree-two derivation by summing the indicated original guards, adding Boolean axioms to undo multilinearization if needed. On the odd slice also add the corresponding degree-two marker multiples. The reverse substitution sets nonrepresentatives zero. Thus for inconsistent systems the maximum of two and the minimum refutation degree is the same on both sides. It is not safe to omit this floor without more assumptions: a one-vertex edgeless base has a degree-one contradiction with the odd marker, but replacing it by three vertices forming a bidirected clique yields only quadratic guards and has minimum degree two.

## Ordinary disjoint blocks

For c_v=e_i on B_i, full-cube factorization forces each ordered cross-block matrix to be constant with its specified quotient bit: test one selected vertex in each of two blocks. Inside B_i the single aggregate equation requires symmetric internal arcs, since precisely reciprocal arcs cancel pairwise. An arbitrary internal undirected graph is allowed. A single representative per block is a section regardless of internal edges.

On the odd slice with an exterior vertex, the residual entry for a row v in B_i at an external w, namely A_vw+Q_(i,block(w)), must be constant as w varies. Indeed evaluate the aggregate discrepancy on v and two external vertices; with a single external vertex the claim is automatic. Call its value s_v. A triple with two internal vertices v,v' and one external vertex forces A_vv'+A_v'v=s_v+s_v'. Conversely these identities suffice by the product with the odd-marker equation. Thus flipping the off-diagonal entries of rows with s_v=1 makes every external block constant and each internal graph symmetric. For a single block use any anchor and the triangle-potential test to obtain the same internal conclusion. With independent internal blocks, no new nonconstant cross matrix arises even on the odd slice: the s_v must agree within each block containing at least two vertices.

## Catalog of overlapping odd proxies

Start with the unit representatives for a given Q. A new vertex carrying odd support C of size at least three passes its singleton and all unit-representative tests iff the coarse rows indexed by C agree at each target outside C and Q[C] is either empty or a bidirected complete graph. Let κ_C denote that internal adjacency bit. To prove necessity, testing with unit e_j forces the entries Q_ij to be equal for i in C except possibly i=j. For j internal denote that constant by k_j. The singleton condition reads sum_(j in C except i) k_j=0 at each i in C, so all k_j equal; odd cardinality permits either value. The exterior and singleton tests are also sufficient because their remaining component at j can be supplied by the reverse arc bit. To an external representative j the outgoing bit is the common C-row entry at j and the incoming bit is the parity of j's edges into C. To a representative j inside a nontrivial C both bits are κ_C.

For two distinct eligible odd supports C,D, the pair equation is solvable except when they overlap incomparably and their internal types differ. Indeed on C minus D the bit from C toward D must be the common value of (Q 1_D)_i. These rows agree on D minus C, and their entries into C intersect D are all κ_C. The other difference set similarly determines the reverse bit. On the intersection the value of each of those row sums changes by exactly its own κ due to its missing diagonal. Hence the equality there is automatic precisely when κ_C=κ_D. If the intersection has at least two members, the two types already agree on that pair. Disjoint supports require no intersection test. For nested nontrivial supports the common internal type also supplies both bits, since each support is odd; a singleton nested in a larger set was handled by the representative test. Repeated labels require only that their mutual arcs be symmetric. Thus arbitrarily many eligible proxies can coexist if their individual pair tests pass.

## A strict extension beyond unweighted pair merges

Use three base sources, each pointing to all three exterior vertices. Each exterior vertex points only to its own corresponding source. Add a proxy labeled by the three sources. It points to all three exterior vertices, all three point back to it, and it has no arcs to the sources. The resulting seven-vertex graph is strongly connected. The exact weighted quotient recovers the original six-vertex problem by adding the proxy bit simultaneously to the three source coordinates.

No two vertices of the seven-vertex graph can be merged into one disjoint parity block keeping the others as singletons, even after independent outgoing row switches. Within the three sources and the proxy the four incoming patterns from external vertices are distinct, a distinction preserved by row switching. For two exterior vertices their row patterns toward the four source/proxy vertices differ on exactly two entries, and so are neither equal nor complementary. For a mixed pair a different source/proxy vertex distinguishes the pair with its outgoing row. This excludes all two-vertex merges and does not assert that all possible multi-vertex decompositions fail.

check.py compares the direct vector equations with the structural tests on 5,000 base digraphs, covering 124,000 odd candidate supports and 63,227 pairs of individually eligible supports. It also evaluates the concrete quotient on all 128 fine inputs and tries all 128 row switches against every potential unweighted two-vertex merge.
