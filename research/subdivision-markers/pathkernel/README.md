# Native guards at unbounded depth

Each optional bit may be zero, or one when at least one of its affine indicators on earlier bits equals one. A free bit has the constant-one indicator. With k terminal affine equations, charge a k-bit column to each selected vertex and shift the target by the affine constants. The dependency DAG has an arc per pair of vertices whenever the earlier bit occurs in any indicator of the later bit; repeated occurrences across alternatives count once.

## One successor per vertex

Assume every bit influences at most one later guard. There is no restriction on how many terminal equations read it. The DAG is a forest oriented toward its sinks. For each vertex keep two sets of k-bit sums attainable in its subtree, one per root bit. Distinct child subtrees share no variables or guards. To compute the zero state, XOR-convolve all child tables with both child states allowed. For the one state, try each literal of this particular root independently. Extend the convolved vectors by one parity bit initialized at its affine constant. A child with root value s and charged vector v now adds (v, a*s), where a is its coefficient in the current literal. Retain only sums with final parity one, add the root column, and take the union over alternatives. Empty lists give an empty one table. XOR-convolve the unrestricted tables of all component roots and query the target.

Induction on subtrees proves exactness because every one state admits one witnessing literal, and after choosing it the sole coupling between independent child witnesses is its parity. Entry pointers recover a witness if wanted. Direct pairwise convolution costs O*(4^k) time and O*(2^k) space. Arbitrary indegree, number of alternatives and dependency depth contribute only polynomial factors. The accompanying decision implementation was checked on 600 seeded forests, all eight marker targets each, against direct assignment enumeration. Run python test_forest.py.

One can reduce time to O*(2^k) by integer XOR convolution via the Walsh transform on k+1 bits, after each child merge replacing positive counts by one. Counts before thresholding are bounded by 2^(k+1) for a pair of indicator sets, so intermediate integer bit lengths are O(k+1). Multiple possible child values are unioned into the child indicator set before merging.

## f vertices with several successors

Enumerate assignments to all f vertices whose outdegree exceeds one. Substitute their values in remaining guards, markers and in the guards of the fixed vertices. A fixed zero bit generates no obligation. For each fixed one bit require its original guard as an extra terminal disjunction. Removing the fixed vertices leaves a one-successor forest. The marker projection in ../clause-projection.md reduces the at most k+f terminal disjunctions (including singleton equations) to k+f affine markers per projected instance in O*(4^(k+f)) trials. Applying the forest algorithm gives deterministic fixed-parameter time in k+f. Single-marker affine equations may also simply be kept during projection. The algorithm applies to arbitrary terminal affine disjunctions if k is the number of terminal clauses.

## Unrestricted depth and sharing with k fixed

There is a deterministic XP algorithm without the forest restriction. At each vertex locally select either the update zero or the update equal to one named affine guard literal. The reachable assignment set is unchanged. Embed each prefix state in the vector of evaluations of all squarefree monomials of degree at most k, including the constant one. For each local affine update, replacing the new variable in a monomial by that update sends it to a sum of prefix monomials of degree at most k, using x^2=x. Thus each update induces a linear map on evaluation vectors. Maintain a basis of their reachable span, applying every local update to each old basis vector, and take the span of the union. Initially the constant evaluates to one. The product of the k affine indicator bits is a linear functional in the final monomial coordinates, and a witness exists exactly if it is nonzero on the maintained span. Each dimension is at most the sum of binomial(n,j) for j up to k. This is polynomial for each fixed k, with exponent depending on k. For terminal disjunctions, apply the projection above first. This does not establish FPT in k for general DAGs.
