# Discovering a diagonal orbit cover on a graph

Take a supplied connected simple graph on n vertices with ordinary binary cycle-matroid representation; the four named vectors may be arbitrary. Partition the vertices by having identical neighborhoods outside the two compared vertices, so members are true or false twins. These equivalence classes can be computed by pairwise comparisons. Each class induces a clique or an independent set, and between two different classes all adjacencies agree. Thus every permutation within a class preserves the physical graph and acts linearly on its binary incidence space. Write t for the number of classes.

A physical independent (r−2)-set is a spanning forest with three components, including isolated vertices. Its incidence span consists of all vectors that have even sum in each component. Any two spanning trees within a component generate the same space, so their full exterior vectors agree over the binary field. One only needs orbit seeds for the three vertex blocks, not for every tree shape.

Enumerate for each twin class of size m its distributions into three labelled blocks, in binomial(m+2,2) choices. For each combined distribution allocate fixed representatives to each block, reject empty or disconnected induced blocks, and choose a physical spanning tree within each block. Any genuine three-block partition maps to the resulting partition of its distribution by within-class permutations, so its physical wedge equals a generator image of one seed wedge. Adjacent transpositions within classes generate all needed maps. Close the fourth diagonal tensors as in diagonal-orbits.md; a retained representative is always a concrete forest. Given physical labels in another supplied linearly equivalent representation, use the corresponding change of coordinates so the target evaluations remain fixed; names need not be symmetric.

The number of distribution tests is at most (n+1)^{2t}. All subsequent tests and tensor steps are polynomial with an absolute exponent. Thus fixed t supplies a deterministic discovery algorithm even at unbounded graphic rank. For complete graphs only the component-size distributions matter. In K6 the three unlabelled sizes 4+1+1, 3+2+1 and 2+2+2 suffice, although the four-vertex block can have inequivalent tree shapes. The checker starts with these three physical forests, uses only five adjacent vertex swaps, and compares the stable span to every three-edge forest.

The general indexed exchange certificate of diagonal-orbits.md is independent of this graph-specific proof: a single chosen basis of a flat need not see every exchange to adjacent flats. Here coverage follows directly from enumeration of vertex partitions.
