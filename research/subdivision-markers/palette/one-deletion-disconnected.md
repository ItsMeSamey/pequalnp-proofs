# A spanning clean deletion suffices

Assume in the special equality-spanning comparison that M without the rogue e still spans the ambient V and N without e is binary. Choose a clean basis and subtract its interpolant from all labels and pins. A common non-solving basis gives normalized update A_j+w g_j/p with p nonzero, w=p1+λp2 and p1,p2 independent binary pins. Return any witness found by the clean binary comparison. Otherwise no A entry is missing in N and no directed cycle uses an N-only entry. The components of the clean M fundamental graph have disjoint row sectors V_i. Assign each unit basis column to its row, and treat zero columns as individual loop components. A pin component has a nonzero w row; a gain component has a nonzero-gain clean column. An internal N-only arc closes a forbidden directed cycle because all A edges are bidirected. If two components contain both a pinned row and a gainful column, the gain column in each has an N-only arc to the other's pin row. Internal bidirected paths yield a forbidden directed cycle. Thus at most one mixed component exists.

For each component, compute all attainable coefficient relations on (x,o) in binary three-space times O. Merge relations on the same three input bits by retaining (x,o) whenever (x,o1) and (x,o2) occur on the two sides, with o=o1+o2. This is exact since the V_i form a direct sum. There are only constantly many five-dimensional binary subspaces; representatives of each relation recover original material selections. The final relation determines all clean spans on span(p1,p2,a) plus O. Test the exact target graph on the two pins both with no rogue and with the rogue adjoined (try both coefficients on (a,g_e) in the relation). This proves a polynomial algorithm for a spanning clean one-element deletion with N binary on the clean restriction, regardless of clean connectivity.
