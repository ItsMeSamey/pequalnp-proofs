# Discovering strong chordal edge backdoors for exact cographic paired relations

Work on the original vertex-label space. For every pair x,y of binary vertex functions, each joint monochrome connected component must have zero total prescribed two-bit charge. In a connected original this is exactly the compatible indexed cut condition. In a disconnected intermediate graph retain this componentwise criterion WITHOUT quotienting separate vertex constants. Every surviving pair gives its actual original indexed cut pair by the original linear cut map at the end.

For any indexed edge e=uv the feasible pairs are the union of the pairs feasible after deleting e (same vertices and charges), and the pullbacks after contracting e (sum endpoint charges). If the endpoints have different joint labels, deleting their edge affects no monochrome component. Equal endpoints admit contraction with precisely the same component sums. Conversely adding the edge only merges zero-charge components or adds a bichrome edge. A contracted pair lifts by copying its endpoint labels. Loops make identical cases; parallel edges are indexed individually. Taking spans of actual wedges therefore gives a sum of linear images on label wedges. This deletion keeps the abstract vertex charges even when it removes a tagged original edge; retaining the other edge tags without recomputing their boundary would be incorrect.

A strong k-edge set is a set F of at most k indexed original edges such that *every* minor obtained by independent deletion/contraction choices on F has chordal simple shadow. Find it or certify none in (2(k+3))^k poly(N) time. At search prefix S enumerate all its minor assignments. If every shadow is chordal stop. Otherwise produce an induced cycle C in one failing minor. In polynomial time one can enumerate a middle vertex v with distinct nonadjacent neighbors a,b, remove v and its other neighbors, then find a shortest a–b path; if it exists it forms an induced hole with v. For a successful completion F containing S an all-deletion assignment on F minus S must erase an entire parallel bundle of one adjacency of C. Pick one indexed representative of EACH cycle adjacency; F must contain at least one. Moreover contracting all remaining chosen edges within C and deleting all other remaining chosen edges contracts at most k−|S| adjacencies and cannot introduce any chord within the resulting cycle. If |C|>k−|S|+3, this allowed assignment has a chordless cycle of length at least four. Hence reject this search prefix; otherwise branch by adjoining a representative, at most k−|S|+3 choices. Choices refer to original IDs surviving in the bad minor; loops cannot be cycle representatives. Disjoint minor operations commute using identifications (parallel edges can turn into loops). Starting at the empty S maintains completeness by induction along any solution F. This recognizes the strong-set promise, not minimum adaptive decision-tree depth. Iterating budgets to the first success can compute the optimum. No claim about all graphs having bounded optimum.

For each of the at most 2^k terminal assignments, solve independently on its connected components. Any component with nonzero total charge makes this leaf empty. On a connected zero-total chordal component let L_c be the span of actual admissible single cuts and W_c that of compatible cut wedges. Lift through a fixed vertex gauge by integrating indexed cuts and setting one root vertex zero; this map is linear. In absolute labels the first space gains the constant one and the paired space gains all 1∧lift(L_c); each such pair is feasible. All lift(W_c) generators have gauge-normalized actual pairs. On disjoint components eligible label pairs combine independently. The full absolute W is the sum of the within-component exterior spaces and cross terms L_i∧L_j in their ABSOLUTE first spaces. For each cross generator put one actual relation on each of two components and zero elsewhere. This includes independent constant gauges and isolated neutral vertices. Recover L_c with the existing first-space solver or the degree-one connected two-part version of the chordal parent procedure. Local chordal W uses the connected-three-part vector algorithm. Assemble by linear pushforward, selecting independent actual original witnesses. At each leaf apply all contraction pullbacks and then the ORIGINAL indexed cut map, which restores coordinates of deleted original edges. All steps including recognition thus cost (2(k+3))^k poly(N). The theorem currently gives an algorithm, distinct from the native chordal and radial implementations.

A simpler native leaf construction eliminates first-space calls and handles all independent constants simultaneously. After the zero-total check on EACH component, attach a single new neutral vertex z by one fresh bridge to one arbitrarily chosen vertex in each component. On old edges compute two-bit tags with the required boundary in each component (tree flow); all fresh bridge tags are zero. The augmented graph is connected chordal. In every original component, only the monochrome class containing the bridge endpoint could change its connectivity on adding the super-root. Every other monochrome component remains isolated from the new vertex. If all augmented components have zero charge, those other classes have zero charge individually, and the exceptional class has zero charge by subtraction from that component's separately checked zero total. The converse follows by merging neutral classes. Thus the vertex gauge fixing x(z)=y(z)=0 identifies feasible pairs in the augmented graph with exactly all feasible absolute pairs on the old disconnected graph. A single chordal W solve, followed by integration with root z, suffices. The indexed original output includes all restored old cut coordinates even across components disconnected by branch deletion.

**Sharper branching.** Every completion F⊇S must fully contain ALL remaining original indices in at least ℓ−3 of the ℓ cycle adjacency bundles of a bad partial minor. To see this, delete all remaining choices off the cycle and all selected edges in every incompletely selected cycle bundle. Each incomplete adjacency survives due to an unselected indexed edge. Contract the completely selected bundles. If fewer than ℓ−3 were complete, the resulting cycle has at least four distinct vertices and no chord: all merged classes are contiguous arcs of the original induced hole and no outside vertex was contracted. This is an allowed assignment and contradicts strong chordality. Therefore branch over subsets of ℓ−3 complete bundles and add all indices of their union, pruning any over-budget choice. The branch count binom(ℓ,3) is at most 4^{ℓ−3} for ℓ≥4, and budget drops by at least ℓ−3. A root-to-leaf search with budget k has at most 4^k leaves and O(poly(k)4^k) nodes. Evaluating all partial minor choices costs at most 2^k per node. The final deterministic solver thus uses 8^k poly(N), retaining the same native original-pair reconstruction. This supersedes the initial k-dependent branching base.

For a supplied linear observation T, the native solver also avoids computing the full W at each leaf. In the chordal augmentation integrate along a fixed tree rooted at the neutral center: the original indexed cut coordinate e is the sum on the tree path between the images of its endpoints. This gives an explicit linear map P from augmented edge vectors to original edge vectors. Pull T back as T∘Λ²P: for each input column T_ij and distinct augmented coordinates u,v, add (P_iu P_jv+P_iv P_ju)T_ij. The leaf computes a basis of this image using the direct vector-coefficient chordal solver. Between leaves reduce all output columns linearly modulo the echelon span of observations already retrieved, processing every pivot including those below free coordinates. Each new leaf then supplies only independent extensions modulo that span. Actual original edge pairs accompanying leaf representatives are unchanged. If the residual output map is zero, remaining leaves can be skipped. Eighteen finite original-label enumeration controls included duplicated indexed edges, loops and arbitrary three-bit output columns.
