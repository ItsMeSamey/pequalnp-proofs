# Discovering bounded physical fills

In a loopless graph with distinct endpoints u,v and virtual tag b, all physical direct edges and all two-hop u-w-v alternatives cover every endpoint-compatible potential assignment exactly when either a direct physical edge already has tag b, or both links of some u-w-v path carry all four physical tags. Fix c_u=0, c_v=b. For each w the allowable intermediary values form the intersection of the observed tag set on uw with b plus the observed tag set on wv. If no w covers all four, set each c_w to a value outside its own intersection independently. This exhibits an uncovered coloring. If a w covers all four then both tag sets are full and the four physical paths suffice. This criterion applies to searching the complete family of two-hop routes, with no submitted paths or cover oracle.

More generally form the ordinary graph of completely tagged physical links. For every pair at distance l in this graph one may add all four virtual tags using one chosen shortest path. For fixed endpoints/tag, assign arbitrary relative colors to the l−1 internal vertices. Choose one physical representative per needed link tag. The resulting list of ≤4^(l−1) physical routes covers every endpoint-compatible chart. Retain all original physical sites. At distance at most C log N for fixed C, every list is polynomial size. Include all such virtual edges or any explicitly selected subset and run the bounded-hole test on the augmented gain lift. If it passes for fixed b, the earlier dictionary theorem is polynomial with no supplied routes or triangulations. Include the unfilled instance as another recognition attempt: adding edges may create a new long induced cycle in the lift. Larger distances need a charged expansion or a different representation. To avoid an unnecessary inclusion–exclusion step on long route lists, verify this path-of-full-links structure directly before constructing the lists. This search does not certify that no short dictionary exists when it fails.
