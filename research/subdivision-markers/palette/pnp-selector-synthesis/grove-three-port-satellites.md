# Exact interior replacements at up to three ports, including singular inputs

Given a host with a specified core and disjoint strict interiors of satellites, each meeting the core at a nonempty set of ≤3 ports, assign physical edges unambiguously to core or satellites; no edges run between strict interiors. Each satellite component must reach at least one port. Suppose none of the seven target marks is strictly inside a satellite. Replace each satellite by a weighted clique on its ports, combine parallel conductances by addition, and evaluate the resulting core by any exact weighted grove evaluator for a class containing that filled support. For example a central supplied disk with arbitrary nonplanar overlay on q cofacial vertices suffices if the new port cliques are drawable in disjoint faces of the supplied disk, already supported on its core edges, or individually belong to its designated overlay. The satellites themselves may be arbitrarily nonplanar, and may attach to internal faces anywhere.

When a satellite's interior principal Laplacian block has nonzero determinant d, Schur elimination gives a Laplacian on its ports with the effective off-diagonal weights. Every square terminal minor of the original satellite equals d times its corresponding reduced-clique minor. For ≤3 ports all local grove weights are determined by these minors (four-port-response-defect.md): for three ports the only nontrivial case is two blocks with a unique pair, selected by transversal row/column pairs omitting its different endpoints; for one or two ports use the trivial and single cofactors. Thus every port signature of the satellite equals d times the clique signature. Any exterior grove can be counted by gluing local signatures, keeping all original-index forest multiplicities; each local component hits a port or cannot reach a target mark. Consequently the full exact grove value equals the compressed core value times the product of the interior determinants. Charge-free virtual routing is not being assumed; this argument concerns weighted spanning forests.

Singular input weights are handled deterministically using ONE shared interpolation variable t. In each satellite choose a spanning forest rooted at all its ports with precisely one port per tree, by multiroot exploration. Add t to each of the selected physical edges, keeping all other weights fixed. If it has h strict vertices this forest has exactly h edges. Its interior determinant after perturbation is a monic degree-h polynomial by the rooted-forest theorem: the coefficient of t^h requires all h selected indexed edges, hence exactly that one forest. Thus the product of all pivots is monic, of degree at most n. The target grove as a polynomial of the perturbation has degree at most n−3. Evaluate at ≥n−2 good field points by scanning ≤2n+1 distinct elements in a characteristic-two extension containing the input; at most n points can be bad. Compute the exact original value at t=0 by interpolation, even if 0 was a bad pivot. This costs polynomial overhead times one core evaluation per good point and does not require randomized regularization. For fixed finite base field, a sufficient extension can be constructed by enumerating monic irreducibles of degree logarithmic in n, using standard polynomial-time irreducibility tests. For a general represented input field charge for the field extension or work rationally in t.

Actual indexed traceback from a nonzero specialization uses grove-forced-index-trace.md on the ORIGINAL evaluator, so no virtual edge is offered as a physical witness. For 2-bit W this yields a one-sided witness solver via the seven-mark grove reduction whenever each required marked tuple admits such a core/attachment certificate with controlled q and polynomially available construction. A single certificate for a fixed tuple does not imply all arbitrary-form W queries meet this hypothesis.
