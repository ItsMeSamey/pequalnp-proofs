# Interior-aware exact (3,3,1) with a disk core and arbitrary boundary overlay

Supply a split of physical indexed edges into a planar disk core and an arbitrary overlay with both ends of each overlay edge among q cofacial vertices. Supply their actual marked cyclic boundary order or disk drawing; all seven target marks must be among them. The overlay may be nonplanar, with arbitrary loops or parallel edges. Deterministic exact evaluation costs 2^{O(q)}poly(n+M) field operations over characteristic two, including singular weights.

For every noncrossing partition P of those positions let Z_P be the unnormalized weight of spanning forests of the core in which each component contains a boundary vertex and the induced partition is P. A component without any boundary cannot later receive an overlay edge or a target mark. Let I(P),J(P) be respectively the minima and maxima of its j blocks in the linear boundary order. The core Laplacian minor deleting those rows and columns equals the sum of Z_Q over j-block partitions for which each of the two sets is transversal, by the all-minors theorem with signs disappearing. Each contributing Q has its sorted minima coordinatewise ≤I(P), its sorted maxima ≥J(P), by the two transversal bijections. Equality of both tuples forces Q=P: scan from left to right, open blocks at minima, place each site in the most recently opened unfinished block, and close blocks at maxima; using an older block while a newer one is open would create a crossing. Singletons open and close at the same site. Thus the system has diagonal one and all other contributing tuples have strictly greater sum(maxima)−sum(minima). Solve by descending such sum. At most 4^q pairs of subsets encode all noncrossing partitions via the stack. This is circular-planar grove inversion, consistent with Kenyon–Wilson arXiv:math/0608422. No division or normalized response needed.

Collapse the blocks of P in the overlay only. Assign each collapsed vertex to a target group, forcing all seven prescribed positions to their target groups and rejecting conflicts (≤3^q assignments). Multiply Z_P by the product of the three spanning-tree cofactors of the induced overlay graphs on these groups. Take singleton tree weight 1, ignore loops and retain parallel edge sums. Sum over assignments and P. A physical forest uniquely determines its core restriction, its boundary partition, and the color of every block (each final component has prescribed marks). Overlay edges complete the forest iff they form a tree within each target group and no cross-group edge is selected; induced tree cofactors count exactly these possibilities. This proves the stated bound, polynomial with only seven boundary sites even when the full host is not circular planar. Interior core access plus knowledge of individual overlay edges escapes the full-response collision; arbitrary hosts remain open.

For physical search, run fresh randomized deletion identity tests on each indexed edge with amplified per-query error, removing the edge whenever the remaining target polynomial has a nonzero evaluation. Deleting edges retains the supplied layout. A nonzero trial certifies existence; false zero trials may prevent producing a minimal forest. Test the final indexed edge set directly and return only a verified forest. When all decisions are correct an inclusion-minimal support is exactly one forest. Distinct indexed monomials and degree n−3 give the usual field-size and error bounds; zero at a single specialization remains inconclusive.
