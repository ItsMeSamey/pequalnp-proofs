# Deterministic indexed traceback from one nonzero weighted grove evaluation

Let an exact evaluator on a fixed physical layout accept arbitrary weights on the same indexed edges, including zero, and let its homogeneous squarefree target grove polynomial have degree D=n−3. Given one nonzero weighted evaluation, recover a forest deterministically using that evaluator without contracting vertices, changing boundary positions, or invoking further random tests. Maintain a forced set S and excluded set R such that the sum of the original weights of all target forests containing S and avoiding R is nonzero. Compute this sum by assigning zero to R, multiplying each original weight on S by the same new variable t, and extracting coefficient [t^|S|]. Each forest uses each original indexed edge at most once, so only forests containing all S contribute. The polynomial in t has degree at most |S| and the requested coefficient is its leading coefficient at that bound. Interpolate using |S|+1 distinct field points. In a field with at least D+1 available points this costs ≤(D+1) exact oracle calls per original edge. Deterministic evaluation at a small-field specialization can use a characteristic-two extension or a division-free polynomial determinant and exact coefficients; the former presumes the evaluator supports extension weights.

Process a fresh e by computing the conditional sum with e excluded. If nonzero, permanently exclude e. Otherwise force e: multilinearity makes the unchanged sum exactly the sum of the terms containing e, so the nonzero invariant persists. At the end S is one physical target forest of nonzero product, verified directly via original edge incidence, component count and all seven groups. A candidate layout class need only permit scalar reweighting; even edge contractions violating disk order are unnecessary. For randomized existence first perform a single family of ordinary polynomial identity trials using field size >2n and independent indexed weights. On a nonzero trial the rest is deterministic; zero evaluations remain inconclusive. The conditional method applies to the disk-overlay evaluator and to any future exact (3,3,1) evaluator with the stated weight interface.
