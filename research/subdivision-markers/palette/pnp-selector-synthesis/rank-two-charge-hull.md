# Reducing a second charge bit by a recognizable convex hull

Fix a nonzero binary functional λ on the two-bit vertex charges of a connected original cographic host, and let T be the set of vertices on which that bit is 1. For X⊇T require that the neighbors in X of every component of G−X form a clique of original physical adjacencies. Then for any connected vertex set A, its intersection with X is empty or connected: replace each excursion of an A-path outside X by its real boundary edge (discard loops). Begin with T and compute the least such X. If a component violates the condition, choose two nonadjacent neighbors a,b in X and a shortest a–b path through only that component internally. It is induced. Every valid superset Y of X must contain the entire path: any nonempty excursion through G−Y has two nonadjacent endpoints in Y (the path is induced), contradicting the clique condition. Each iteration adds a forced vertex and the final set passes the test. This polynomial construction is the standard monophonic convex hull, characterized here without an external algorithm.

For each of the 3^|X| color assignments to X, find its connected monochrome components in the induced shadow G[X]. Discard this assignment when any such component has odd λ-charge. Contract each of these physical connected components (using a spanning tree); leave outside vertices distinct. The resulting two-bit boundary charges have rank at most one, all having λ=0. Equal labels on each contracted component lift and preserve joint feasibility on the original graph. For completeness the general three-part theorem suffices: in a true neutral three-part partition, its restrictions to X are connected and contain all λ-charges, so each nonempty restriction has even λ sum. The corresponding branch contracts only within each true part. No color restrictions need be imposed after contraction. Thus complete W is spanned by lifted W from these one-bit instances. The minimum least-hull size h over the three nonzero functionals can be found deterministically. Using the one-bit mixed-minor solver gives one-sided verified search on arbitrary hosts in 3^h poly time at fixed failure probability. Each original YES belongs to at least one tested quotient for this query; no factor proportional to the number of quotients is needed in its false-negative probability. For a high-confidence full W basis amplify per adaptive queried form. Original indexed sites and integer field-operation costs are retained; coalesced endpoints yield loops and projected Ω coefficients are added modulo two.

Alternatively pair the even number of vertices in T in every possible way and choose one induced physical path per pair. Contract the union of chosen paths. Each connected component of that union contains a union of complete terminal pairs, even when paths overlap or pass through terminals of other pairs. Thus the λ bit disappears in every quotient. For a true three-part partition, choose mates within each part and paths inside the same connected part; shortening yields induced paths, without any requirement that paths of the same color be disjoint. This proves completeness. If |T|=2 exactly the induced paths of that single pair are needed, and an original edge gives just one call. Induced paths can be generated with polynomial delay by extending a current induced path one neighbor at a time, forbidding previous vertices and all their other neighbors, and testing reachability from the new endpoint to the final endpoint before descent. A shortest completion gives a valid induced continuation. For larger T charge the full number of pairing/path combinations or use the hull route; no universal small bound follows.

Prior art includes Pierre Duchet, “Convex sets in graphs, II. Minimal path convexity” (1988), https://doi.org/10.1016/0095-8956(88)90039-1, and “Complexity results related to monophonic convexity,” https://doi.org/10.1016/j.dam.2009.11.016, which includes the component-neighborhood characterization. The application here is the charge-canceling contractions and resulting RP query on the original indexed host.
