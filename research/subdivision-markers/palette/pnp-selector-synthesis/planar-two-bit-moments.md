# Recovering charge moments and indexed pairs on certified planar duals

Compute the two-bit vertex charges σ of the dual D by taking the boundary of its two tagged edge chains. Total charge is zero. Dual cuts x,y admit a common primal chart iff every component of each of the four color classes has total charge zero, by the plane cut/cycle argument in planar-unbounded-annihilator.md. Every individual x in L has sum σ_v x_v=0. Thus for each functional λ on the two-bit tag space, Ωλ(x,y)=sum λ(σ_v)x_v y_v is alternating on L, independent of face representatives modulo constants, and zero on W. This universally gives up to two annihilators; independence is instance-dependent.

**Routing certificate for completeness.** Let terminals be nonzero-charge vertices. A minimal zero-charge terminal set (a circuit) is a pair of equal type or a triple with one of each nonzero type. Require D 3-connected. For each circuit supply one simple cycle through exactly those terminals and a disjoint cycle through all complementary terminals (omit empty groups). For every two disjoint circuits supply disjoint connected subgraphs spanning exactly the first circuit, second circuit, and rest (omit an empty rest). All certificates are directly verifiable; m terminals give O(m³) circuits and O(m⁶) circuit pairs. General strip constructions may supply these data, but existence is not presumed on arbitrary hosts.

Write X=ker σ in F₂^m before quotienting constants, and N for the span of neutral singletons. Such singletons are realizable. Each circuit lifts using its given cycle vertex set; subtract neutral singletons. Circuits span X, so L/N=X/<1>. Distinct neutral singletons jointly match; so do a neutral z and a circuit's cycle with z removed, since its complementary cycle minus z stays connected. This proves N wedge L lies in W by removing neutral terms. Finally the trees give disjoint terminal circuit wedges in the projection.

**Projected linear algebra.** For a type i let D_i be the even subspace on its terminal set I_i. With at most two types present X is the direct sum of D_i. Disjoint pair tests kill all cross terms. In each D_i, basis vectors e_j+e_r based at one reference r have equal off-diagonal form values by the disjoint-pair test, hence the form is a scalar multiple of dot. For |I_i|≤3 this follows directly in dimensions at most two. The values on up to two independent types are realized by a tag functional λ.

When all three types occur, their parities on X coincide; call this linear functional p. A triple t through one reference r_i per type and the three D_i together span X. Put h_i=dot restricted to I_i plus p tensor p, an alternating form. Disjoint pair wedges again force zero cross terms between D_i and scalar dot on each D_i. Pairs in I_i avoiding r_i are disjoint from t, so the functional Ω(t,·) on D_i is proportional to the coordinate at r_i. If |I_i|≥3, choose distinct nonreferences j,k: the modified triple t+e_(r_i)+e_j is disjoint from e_(r_i)+e_k. This forces the same proportionality as the scalar on D_i. If |I_i|=2 its single proportionality coefficient is enough because dot on D_i vanishes. If |I_i|=1 both D_i and h_i vanish. Thus Ω=sum c_i h_i. If all groups have ≥2 members, two disjoint triples force sum c_i=0 by evaluation. Otherwise choose the coefficient of any singleton type to make the sum zero. The p tensor p terms now cancel, and the three c_i are precisely the values of one tag functional. This upper bound on all annihilators descends to X/<1>; every charge moment was already shown to annihilate W.

**Recovery.** On the certified class W-perp is exactly the span of the two coordinate charge moments. Integrate any physical cycle's bits along a dual spanning tree to get its face labeling relative to the root. This supplies factored bilinear forms without a quadratic-size ambient exterior table. In the one-bit construction choose a charged root and eliminate another charged label by parity: in the remaining m−2 terminal reads d_i the form equals sum_{i<j} d_i wedge d_j. For arbitrary alternating queries with indexed tracebacks enumerate neutral singleton pairs, each neutral versus each given circuit cycle minus that neutral, and every given disjoint pair of circuit trees. These actual pairs span W: the first two sets generate N wedge L and the projected annihilator of the final set is exactly the charge-moment span. A nonzero evaluation immediately yields the actual original matching pair. Full Gaussian output is optional.
