# Disk anchor recovery after boundary identifications

For an indexed host with private kernel equal to the cut space of a supplied connected D, the component criterion follows solely from sum of edge tags on δS equaling total vertex charge in S. Planarity is not required. Thus zero-charge region decomposition, neutral partners, ≤5/packing-two recovery, charge-moment containment and claw-free algorithms apply to cographic private hosts directly under their respective graph hypotheses. Planar graphic hosts use their dual as D.

Suppose supplied a disk patch P with p distinct marked boundary vertices, explicit exterior access and a quotient map identifying only marked vertices. The resulting simple shadow must equal that of D, ignoring parallel multiplicity and loops only for connectivity. All original charged vertices are images of marks. Unmarked vertices have unique preimages. Keep original indexed D for output and for the charge computation.

Pull any feasible pair on D back to the patch. Its monochrome components containing marks are disjoint connected anchors and induce a noncrossing partition. Merge blocks sharing a quotient vertex transitively. Each class of anchor images is connected in D and disjoint from other classes. Every charged vertex is covered. Each class has zero total charge: a monochrome path in the quotient lifts in pieces to monochrome components of the patch, switching between them only at identified marks. Thus a class contains all marked vertices of one monochrome component. A single patch block need not itself be zero charge.

Try every noncrossing partition of all p marks, without initially testing per-block charge. Compute canonical disjoint anchors by the outermost-ear algorithm. Form their equivalence classes under marked vertex identification and check charge once per original vertex in each class. If all pass, the quotient anchors are disjoint connected zero-charge sets covering all charges, so all pairs of labelings constant on each of them are realizable. Single-anchor canonical replacements inside the patch change only one quotient anchor; changed vertices are unmarked neutrals with unique images. For a fixed other anchor B the wedge change is a sum of e_z wedge 1_B, each realizable using the system that avoids z. Therefore W0 computed on the original D plus all original cut pairs of these canonical quotient anchors spans W. Total work 4^p poly under the scalar backend. For a disconnected patch supply the global disk order and each marked access explicitly; separate abstract rotations are insufficient. The current simple-disk executable does not implement this quotient extension.
