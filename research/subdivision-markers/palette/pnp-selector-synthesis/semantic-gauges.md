# Semantic gauges and first relation rank

Let L_g be all binary indexed private relations supported on sites active at chart g; L is their sum in F₂^N. A scalar indexed height change s is chartwise linearly absorbable on every active set exactly when s is orthogonal to L. This is factorization through the private map restricted to active sites. It preserves each private relation's height, stronger than preserving a single decision answer.

Test non-safety of s by giving ordinary columns (k_i,b_i,s_i) the named three-space B⊕F₂ and asking for its exact last axis as trace. A witnessing subset has all private relations mapped to zero tag (so tags extend to a chart), and one relation with s-sum one. Conversely any such active relation witnesses non-safety by the full active set. Prior three-dimensional-traces.md reduces this line query to Seymour's circuit-through-three query. From an exact-line support use Gaussian elimination to recover an indexed violation z; if only decisions are available, delete sites greedily from a positive instance while any selectable witnessing subset remains. At the inclusion-minimal yes instance its whole support is a witness.

Start with no relation rows. Test a basis of the orthogonal complement of their span; an unsafe test adds a new independent z. If every basis test is safe the accumulated span equals L. At most N updates and O(N²) oracle calls suffice, with an additional O(N) decisions per actual witness self-reduction if necessary. This is unconditionally deterministic polynomial using the prior 3-name theorem. The sum of exterior squares of simultaneous relations is a different space.

For two-bit heights solve homogeneous equations from L for each correction and affine equations s_i+s_j=h_i+h_j for any prescribed simultaneous fusions. Alternatively choose r=dim L pivot columns in a basis-row matrix R of L. Each actual height row h admits a recoding on those same r indices alone: solve R h_new=R h with all nonpivot entries zero. Original and new heights agree on every active relation. Support concentration alone does not assert which relations can co-occur.

An elementary practical fallback splits the private column matroid into components, including private loops. Private component spans are direct summands. A local chart extends globally, so L is the direct sum of local first relation spaces. In a component of rank q and nullity v either enumerate 4^q local charts and active relation bases, or enumerate 2^v relations and test tag consistency on each support by Gaussian elimination. Both routes give L. This costs poly(N) times the sum of min(4^q,2^v), separate from the unconditional polynomial route through the previous theorem.

Primary dependencies: [exact three-dimensional traces](../span-separation/three-dimensional-traces.md) and [Seymour, Triples in Matroid Circuits](https://doi.org/10.1016/S0195-6698(86)80044-0).
