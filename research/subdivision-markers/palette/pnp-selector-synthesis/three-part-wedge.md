# Full indexed paired space from connected spanning three-partitions

Let D be a connected undirected graph, with loops and indexed parallel edges allowed, and let the private binary key matrix have kernel equal to its cut space on these actual indices. Integrate the two site tags as the vertex boundary charge σ. Write δA for the original indexed cut of a vertex set A. Two cut words δx,δy have a common active chart exactly when each connected component of each joint label class (x(v),y(v)) has zero total charge. Let W be the span of all such actual wedges.

**Claim.** W is the span of δA∧δC over all partitions of the entire vertex set into three nonempty connected vertex sets A,B,C, each with charge sum zero. The empty span is zero. Any two distinct parts can be used, since δA+δB+δC=0. This identity holds for arbitrary connected D.

In one direction, the two indicator bits of A and C have three monochrome components, the partition parts, so the indexed pair is realizable. In the other direction, contract all monochrome connected components of any actual pair, merging no original sites in the output. Choose a spanning tree of the resulting connected quotient, root it, and use the subtree indicator of each nonroot node. These indicators form a basis of quotient vertex labels modulo the all-ones vector: their coefficients for a given label are precisely its differences along the tree edges. Pull that basis back to original vertices; x and y lie in its span modulo constants. Wedge their expansions and discard the equal-edge terms. For distinct tree edges, deleting them leaves three connected tree pieces. Each lifts to a connected nonempty original vertex set and has charge zero. The two corresponding subtree indicators equal the two leaf-piece indicators modulo independent choices of complement, since cutting each one edge splits off its end piece on the side away from the other edge. Thus their indexed wedge is exactly a generator as claimed. If the quotient has fewer than three nodes the wedge is zero.

**Charged partition algorithms with an actual alternating query.** On an ordered-root parent encoding of a three-part partition, let X_v and Y_v be indicators that v ends in the first and third colors. For physical site i=uv put a_i=X_u+X_v, c_i=Y_u+Y_v. Loops contribute zero, and parallel site indices retain their own form entries. For any explicitly supplied alternating form Ω on indexed words, its tested bit is Σ_{i<j} Ω_ij(a_i c_j+a_j c_i). Over F₂ multiply this degree-at-most-two factor by four affine equalities stating that the two charge bits of A and C vanish. All terms then contain at most six vertex-to-root demands before adding a bounded number of linkage pins. Contradictory demands are zero and equal demands merge. Use the linear substitutions and actual backpointers in ordered-charged-partitions.md (d534e44a). On a chordal shadow, a checked perfect elimination order and three root choices suffice; on a supplied order with connected sink bound r use up to 3r roots and at most 2(3r−3) linkage pins as in that theorem. Every retained prefix vector comes from one physical parent sequence; all factors use that same sequence, so a nonzero terminal bit produces an actual jointly matched original pair. This is deterministic polynomial time on chordal graphs, and n^{O(r+1)} on the supplied-order class. It requires direct access to the parent substitution procedure; an opaque decision oracle for just the charge sums does not itself evaluate Ω.

To recover W, keep independent actual generators in the ambient physical exterior square. Compute a basis of the annihilator of the retained span by Gaussian elimination. Query those basis forms until one returns a witness outside the span, then add it. If all reject, the current span is W. With M=number of physical sites there are O(M²) augmentations and O(M²) queries per round; all matrices and degrees are charged polynomially. Equivalently store the cuts in a fixed independent graphic cut-coordinate basis, checking the original indices when emitting each witness. No rank hypothesis on intermediate Ω. This characterization does not solve the unrestricted connected three-part partition or its arbitrary-form query.

A sharper native recovery uses only binom(M,2) separator queries in total. Start with the coordinate forms. Retain previous NO forms implicitly, since each is now known to annihilate every true generator. Pop a remaining form Ω. On NO mark it known; on YES obtain original wedge w with Ω(w)=1 and replace every remaining form f by f+f(w)Ω. The known NO forms already vanish on w. Thus the known forms together with remaining forms continue to be a basis of the annihilator of the collected physical witnesses. Each step removes exactly one remaining candidate. At termination all residual forms are known zero on W, certifying equality. The native three_part_query.py implements this on a supplied checked perfect elimination order and stores independent original vectors before row reduction. The cyclic parent variant applies whenever the corresponding connected-partition DP can process an additional quadratic terminal factor on the same parent choices (bounded charged feedback parameters are separate from chordality).
