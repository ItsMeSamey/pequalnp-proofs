# A charged decision diagram for sparse physical chart images

Use the supplied order of the n assignment variables. Each original indexed physical site's two tag-mismatch bits are explicit scalar ANFs obtained by XORing the appropriate chart-encoder coordinates and tag constants. Finalize a site just after the last variable in either test, or at stage zero for constants. Charged size includes the explicit tag ANFs.

At each cut store (i) the pair of residual tag ANFs of every unfinished site and (ii) a canonical basis of S=span(enabled finished (k,h)) ∩ W, where W=span(all finished (k,h)) ∩ span(all unfinished (k,h), H). The original tags can be suppressed in this span computation because enabled sites are compatible with the same completed chart. Substitute the next bit, finalize exactly the newly scheduled sites and let A be their enabled vectors. The new boundary trace is (S+span A) ∩ W_new. For the reverse inclusion that needs proof, any old enabled-span summand contributing to the new trace lies in span(all previously unfinished vectors,H): subtract its new A summand from a vector in W_new. It therefore was already in S. At the last cut the trace is the full enabled span's intersection with H. Matching residual tuples and boundary traces may be merged; keeping one prefix per state reconstructs an assignment and then an original-index physical witness.

For each cut let rho be the F₂ rank of the coefficient flattening restricted to nonempty prefix monomials of the unfinished tag-test tuple. Rows index nonempty prefix monomials; columns index a site, bit, and suffix monomial including the empty one. Each prefix assignment yields a fixed origin plus a binary combination of those rows. At most 2^rho residual tuples are possible. If w=dim W then canonical boundary subspaces number at most 2^O(w²), since each has a generating list of at most w vectors in w bits. Both bounds are independently computable in polynomial time for the supplied order. The solver uses poly(input) times max_i 2^{rho_i+O(w_i²)} time and storage. In particular rho_i+w_i²=O(log input size) guarantees a uniform polynomial procedure given that order. The actual number of reachable states can be much smaller. Choosing an optimal order is outside this result.

A small diagram for the union family alone is insufficient. From a 3CNF with n variables and m≥max(2,n) clauses (repeat any nonempty formula's clauses as needed), build m private variable axes e_j with one tag-0 height-0 site each, one closing site at sum e_j of tag 0 and height 1, and a pure height-2 site. Set each chart value on e_j to (the j-th clause's violation bit,0), a sparse degree-three ANF. If every clause is satisfied the axis/closing relation yields height 1. If any axis is inactive, the closing key is outside the available zero-height span, even if its own tag matches. Add n independent fully tagged neutral display axes reading (x_i,0). They affect no height relation but add every singleton variable support to the explicit encoder. The union closure is the full cube, with a linear-size zero-suppressed decision diagram. For the natural full-tag section at least m private directions are absent, so its unconditional bounded-union radius also covers all n singletons. Image acceptance remains NP-complete. This is a reduction to a constrained chart image with an instance-dependent host.

Minato introduced ZDD representations of set families. Knowledge-compilation maps separately charge representation size, supported queries and transformations. Here the new transition state retains physical spans and unfinished sparse encoder tests, and the proof charges their joint reachable width. No general novelty assertion is made for decision-diagram or boundary-subspace dynamic programming.
