# Simultaneously reducing neutral twins for cographic paired space

Use the connected simple shadow and two-bit vertex charges. Partition neutral vertices into twin classes (equal neighborhoods outside the pair); each class induces a clique or independent set. Keep an arbitrary three representatives per class, or every vertex if smaller. Keep all charged vertices. Restrict the shadow and inherit charges; realize these charges with edge tags on a spanning tree. Physical tag realizations and parallel multiplicities need not have twin symmetry. Work first on vertex potentials modulo global constants.

Compute the compressed W with actual pairs. For each map sending each discarded vertex to a retained representative from its class, lift potentials by copying that representative. This linear map induces an exterior pushforward. Every lifted pair is feasible: in each joint color any new component either touches whole old balanced components or consists exclusively of new neutral vertices. The old vertices retain their colors and edges, so none of their old components can split.

Conversely a generating connected balanced three-partition uses at most three labels per class. Independently permute each class so that all its occupied labels occur on the retained vertices. Its restriction preserves nonemptiness, charges and connectivity of every part: replace each removed vertex on any path by a same-color retained twin, suppressing consecutive duplicates. Thus each permuted generating pair is a lift from a compressed chart, and the original generating pair is obtained by undoing the permutations.

For each actual compressed basis pair, its lifted vertex wedge has total degree at most two in categorical choice indicators. Fix one default representative per class. Evaluations differing from the default on at most two vertices span all evaluations by the bilinear expansion about the default. This costs O(n²) actual lifts per basis pair. Retain independent actual vertex-wedge generators, close their span under adjacent transpositions within each class by adding independent actual permuted pairs until stable (at most O(n²) additions). Regauge at the root after each action. The resulting space is exact by both directions above. Trace stored pairs through the original physical cut map, preserving every indexed edge. That map is injective on rooted potentials for connected hosts. Arbitrary projected outputs are computed after full orbit closure since their maps need not commute with permutations. All steps outside the single compressed W computation take deterministic polynomial time. Small-part enumeration can therefore use only the compressed vertex count in its exponent.
