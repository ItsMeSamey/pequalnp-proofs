# Completeness of pairwise joins for locally selected crossing flows

Fix independent unrestricted vertex-potential variables, partitioned by vertex clusters. At the level of the cluster quotient, suppose a physical route from cluster A to cluster B has the same constant boundary at every assignment. Assume the coefficient of each crossing physical site depends only on variables of its two incident clusters, and vanishes whenever the site is inactive. Internal selections can be arbitrary. For each unordered distinct pair I,J let f_IJ be the XOR of the selected coefficients on its crossing sites. The J-boundary equation says sum_T f_TJ is constant. Vary all variables of I alone. Every other summand at J is unchanged, so f_IJ is independent of I. The analogous I-boundary equation makes it independent of J. Thus each f_IJ is constant. Pairs with constant one form a fixed quotient edge set of boundary A+B, and each such pair always has at least one active crossing link. This edge set contains an A–B path. Conversely along a path of universally available pairs, choose the first active crossing in a fixed order separately per pair. All coefficients depend only on the respective two clusters, and arbitrary certified internal routes glue them into a physical chain.

Consequently arbitrary chartwise selection that is local on each crossing pair cannot improve reachability beyond transitive closure of universally available joins in a single fixed partition. For affine crossing selectors depending on each link's own difference and vanishing on all missing tags, the previous affine-inconsistency test is exact for an odd-parity join: a parity-one sum is precisely an inconsistent affine system of linear constraints valid on the missing sets. A universal join may require nonlinear selectors if this affine test fails. Global nonlocal selectors, constrained correlated chart domains, locally chosen pairs of routes with other boundary states and arbitrary exact-plane instances are outside the argument.
