# Direct indexed wedge basis from one vector-valued partition sweep

Under the hypotheses of three-part-wedge.md use the physical exterior square as the coefficient space of the root-demand polynomial. The initial polynomial is the vector δA∧δC times the four zero-charge indicators. Expand it symbolically in at most six root demands per monomial. Its coefficients are vectors, not individual tests. Every physical parent choice transforms the demand component linearly and leaves the coefficient component untouched. For each root tuple (and for each cyclic-frontier state when applicable), retain the span of all reachable vectors in this tensor product by retaining a linearly independent subset of actual images. At a terminal state the only demand is the empty one. Its vector is exactly the projected physical wedge from one valid partition or zero if a charge test failed. Take the span over all root triples: this equals W by the connected-three-part theorem. Every selected output has the actual parent-sequence traceback, so no linear combination is passed off as an original indexed pair.

With B demand monomials and h coefficient coordinates the joint dimension is at most Bh. Every transition, rank check, stored prefix path and coefficient expansion is charged polynomially in n,M,B,h. Here B≤Σ_{j≤6}binom(n,j)2^j for one root per color. With three distinct stopping roots the three parts are automatically nonempty. The native implementation checks a supplied perfect elimination order or constructs one by repeatedly removing a simplicial vertex, rejecting if the current nonempty graph has none. At most n(n−1)(n−2) ordered root schedules are needed. No repeated scalar separation is needed to recover W. If the private first-space L has already been computed with its constructive backend, row-reduce its generators and use an information set of r=dim L physical sites: projection is injective on L and hence on Λ²L, so h=binom(r,2) suffices. Original indexed cuts are still recovered and checked. The optional sites argument of three_part_vector.py requires this property when exact full W is claimed; without it the result is only a basis of the projected image with actual lifts.

More generally a supplied linear query map T from the physical exterior square to F₂^h can be applied to the initial coefficient vectors. The same proof computes a basis of T(W) with original witness preimages in one pass for each root tuple, at polynomial cost in its explicitly encoded coefficients and h. This covers compressed linear observations without presuming any rank restriction on individual alternating forms. For an arbitrary high-rank inspection functional h may equal one. The Python vector code supports general explicitly supplied linear observations and full output. On 32 primary controls, all 224 nonzero scalar projections of random three-bit output maps agreed with independent scalar tests.
