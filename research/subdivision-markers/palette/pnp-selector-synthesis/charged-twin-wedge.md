# Paired cloning for arbitrary vertex charges

In each shadow twin class split by the actual two-bit vertex charge. All permutations within a resulting class preserve the shadow and charge. For each nonzero-charge class of size N keep min(N,6) vertices if even, min(N,5) if odd. Pair the discarded vertices once and for all. Keep up to three representatives per zero-charge class as in neutral-twin-wedge.md. The compressed graph is connected whenever the original is, and the inherited total charge is unchanged.

For any jointly feasible compressed pair, copy each discarded charged pair together from one representative of its own class. Both new vertices are in the same joint color component as the copied representative. In a clique class this follows from adjacency to the representative, and in an independent class the representative must have a same-color neighbor (an isolated nonzero-charge monochrome vertex cannot be balanced), necessarily adjacent to both copies. The two equal charges cancel in that component. Any merged old components were individually balanced. Neutral copies remain as previously. All lifted pairs therefore are feasible on original indices.

In a generating three-partition of the original graph each class has at most three occupied labels. For every occupied label reserve one vertex for an odd count and two for an even count. Their total has parity N and is at most 6 for even N or 5 for odd N. Fill the retained count by adding pairs from occupied labels with unused vertices; enough exist by N≥the retained count. Some within-class permutation moves precisely these representatives to the retained slots, and arranges each predetermined discarded pair within a single label. Project each original part path to same-label representatives to retain its connectivity. Its charge is unchanged because omissions in every charged class have even multiplicity per label. The permuted partition is one of the described lifts.

Potential-level orbit closure, indexed witness retention, and the degree-two categorical sampling argument carry over without change: use one choice variable per discarded pair (or per discarded neutral). Running time is polynomial overhead plus one compressed exact W computation. In particular, on a graph with h shadow twin classes, there are at most 3+3·6=21 retained vertices per class even when the original edge tags are entirely asymmetric. Using small-part-wedge.md gives deterministic 2^{O(h)}poly(n+M) with physical pair traceback and no decomposition supplied. This bound also follows qualitatively from existing intrinsic width approaches on bounded neighborhood diversity only if their parameters are separately controlled; no general improvement over them is needed for the exact reduction.
