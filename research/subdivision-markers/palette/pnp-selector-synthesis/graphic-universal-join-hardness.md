# Universal join recognition with just two fully tagged trees

Given a finite simple graph G with ≥2 vertices, make disjoint left and right copies of its vertices. In each copy choose an arbitrary spanning path and place all four tagged physical edges on every path link. Thus at every color assignment each copy is internally connected by physical active edges. On cross-link L_i R_i place tags 1,2,3. For each ordered-by-index input edge i<j place tag zero on L_i R_j. There are no other cross-links. The graph of fully tagged links has exactly the two supplied paths as components.

At a vertex potential assignment, no cross-link is active exactly when corresponding copies carry the same color and adjacent input vertices carry different colors. Hence a disabling assignment exists exactly when G is four-colorable. The construction has 2|V| physical vertices and 8(|V|−1)+3|V|+|E| indexed sites. Nonuniversality has a polynomial witness consisting of the vertex colors. NP-hardness of four-colorability follows from the usual three-color problem by adding one vertex adjacent to every original vertex. Universal existence of an active crossing between two given full-link components is therefore coNP-complete. Equivalently, two designated opposite poles always belong to the same active connected component precisely when this universal join exists.

The hardness applies with physical crossing tag sets of sizes only one and three. When every observed crossing link has at least two tags, the missing sets are affine, and Gaussian elimination decides universal crossing in polynomial time. The coNP-hard predicate is universal over charts. It neither classifies existential exact-plane decision nor refutes efficient algorithms using the available sufficient joins.

The older selector-degree-colouring.md result establishes a universal-span four-colorability reduction for arbitrary binary private columns. This construction uses only graphic private incidence columns and two explicitly supplied full-link trees and proves the stated two-cluster recognition restriction.
