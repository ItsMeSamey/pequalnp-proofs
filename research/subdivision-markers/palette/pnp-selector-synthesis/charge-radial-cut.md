# Discovering a marked disk patch by a short radial tree

Given a connected cellular plane embedding on the sphere, form its radial graph on original vertices and face centers, one embedded incidence edge per corner. A radial tree S containing all charged original vertices supplies a disk patch: cut the sphere open along S and retain only the original physical graph arcs, marking all copies of original vertices incident to S. No radial links or face centers are routing edges. Original incident edge sectors distribute in cyclic order among the copies. Each original edge persists once because radial edges never cross its interior. Gluing all copies belonging to the same original vertex restores the physical graph. A vertex of degree d in a nontrivial tree occurs d times in the boundary walk of a regular neighborhood. Thus there are exactly |E(S)| marked occurrences, because every radial edge has exactly one original endpoint. The complement of the neighborhood of an embedded tree on the sphere is a disk. Short original edge stubs at tree vertices can be attached to the mark in their incidence sector. Unused copies may be isolated marks; retain these and their global order in the mathematical patch. Empty charges are solved directly.

If k* is minimum radial Steiner tree edge count connecting all charged vertices, compute the shortest-path metric on those terminals and take a metric minimum spanning tree. Doubling an optimal radial tree bounds the terminal metric tour length by 2k*, so the metric spanning tree has weight at most 2k*. Union its realized paths, then take a spanning tree. This is a polynomial constructor of a radial tree with at most 2k* edges. The marked-patch theorem therefore gives deterministic 4^(2k*) poly for arbitrary indexed W without a supplied patch, using the polynomial scalar first-space backend. The parameter may be large for few widely separated charges. If all charges lie on one face its radial center supplies a star with t links. The radial_patch.py constructor checks a spherical simple-shadow rotation, realizes the metric tree and produces a checked disk patch. disk_patch_wedge.py evaluates the quotient with original indexed edges, retaining parallel edges and loops for physical tests. The constructor uses one chosen corner per incident vertex–face pair; parallel radial edges do not affect distances. An original sector between distinct used corners contains an original dart, so the produced simple-shadow patch has no isolated marked copies. Independently supplied patches may include isolated marks.

The exact tree option uses the classical Steiner subset dynamic program on the radial graph. For each nonempty subset A of charged terminals and each root v, store the minimum number of edges of a tree containing A and v. A singleton initializes at its terminal. For other subsets, merge the two proper subproblem costs at each vertex; take the multisource shortest-path closure. In an optimal tree, trace from v to the first terminal or branching vertex; there the remainder splits into two smaller nonempty terminal sets (an encountered terminal can be its own singleton). Conversely merged subtrees and a path produce a connected network of at most the counted length. Shortest-path predecessors and subset splits retrieve actual edges. This costs 3^t poly in time and 2^t poly in memory, for t charged original vertices. Each terminal has a distinct incident optimal-tree edge, so t≤k*. Hence the complete exact construction and paired-space algorithm cost 4^{k*}poly with no supplied cut tree (the input plane rotation remains supplied). Implemented in radial_steiner.py; 141 connected-graph optima were compared to enumeration of added Steiner vertices, with three additional radial integration controls.
