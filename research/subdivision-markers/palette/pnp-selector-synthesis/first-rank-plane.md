# Exact physical plane search in single-exponential first relation rank

First compute the exact first relation space L as in semantic-gauges.md; r=dim L. Enumerate its 2^r indexed vectors u. Test tag interpolation on the support C of u by Gaussian elimination and skip incompatible vectors. For actual heights let h_u be their sum on C and skip zero. For the remaining u set s_i=det(h_u,h_i), where the determinant is over the two-dimensional target H. A second relation v has independent height exactly when its s-sum is one. It must be realizable on the same chart as u.

Force C selected in the scalar three-name test on ordinary columns (k_i,b_i,s_i). The already selected span meets the named space B⊕F₂ only in the desired last axis or zero, since its tags interpolate. In the former case C already contains a private relation v with scalar sum one. In the latter case quotient the represented ambient by that span, keeping all three independent names with their images, and run the prescribed exact-line solver on remaining sites. The quotient test is equivalent to a witnessing original subset containing C: pulling back its named trace recovers exactly the original trace on the sum of the selected spans. From a positive answer the lifted subset has consistent tags, contains C and a scalar-odd private relation. The resulting two height directions certify a full plane in the original physical union; return indices or recover a physical basis and chart by Gaussian elimination.

Conversely every exact-plane witness gives a compatible pair of private relations with independent heights. Its first relation appears in the enumeration, and its second forces acceptance of the pinned test. Total time is deterministic 2^r poly(input), with no restriction on named density or the private matroid. The exponential factor may grow on general inputs. Four-to-the-r pair enumeration with a joint affine tag test is an alternative implementation requiring no per-vector three-terminal query after L has been found.

The same algorithm separates any alternating test Ω on indexed relations using s_i=Ω(u,e_i), after extending Ω from L to the full indexed ambient if necessary. A positive answer returns a simultaneously attainable wedge. Starting with an empty subspace of the exterior square of L and testing a basis of its annihilator yields the full gain-independent span of simultaneous wedges in 2^r poly(input); this does not replace simultaneous compatibility by individual realizability.

For strict parameter controls take arbitrarily many independent private axes with one site per allowed tag in an incomplete palette. Add two indexed copies at existing key/tag pairs, each gaining a different pure height relative to its zero-height original. All active private relations are generated by the matching duplicate pairs, giving r=2. If the pairs use distinct tags on a single axis H is absent despite two independent globally available heights. When the copies use distinct axes both can match. All directions remain incompletely tagged, so the full-tag deficit grows arbitrarily. No general SAT reduction or polynomial upper bound on r is claimed.
