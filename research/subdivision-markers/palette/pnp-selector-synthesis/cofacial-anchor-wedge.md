# Exact indexed two-bit W on a disk with t charged terminals

Assume a supplied disk embedding of a connected dual graph D, with all charged terminals at distinct points on the boundary, all other graph points in the disk. The cyclic terminal order and local embedding are supplied. In particular when choosing an auxiliary edge it may run just outside the disk. No starting 3-connectivity or linkage certificate is assumed. Compute W0=sum_z e_z wedge L[z] over neutral z by the scalar three-name algorithm of five-terminal-plane.md, which does not need a terminal bound for this step. W0 comes with actual original witness pairs.

Every jointly feasible label pair has disjoint connected anchors, one for the terminal group of each charged monochrome component; all groups have zero charge and cover all terminals. Neutral-only vertices outside chosen anchors are free. For fixed nonempty anchor collection P, the face-label space constant separately on each anchor is generated by its anchor indicators and the free neutral singletons. All pairs of such generators are jointly realizable. Consequently, modulo W0 the contribution from P is spanned by pair wedges of its anchor indicators. Replacing one anchor A by any other connected A' with the same terminals disjoint from all unchanged anchors leaves those wedges equal modulo W0. Indeed (1_A+1_A') wedge 1_B for an unchanged B expands into terms e_z wedge 1_B. Each differing z is neutral and avoided by one of the two systems; select that system to verify feasibility. No intersection condition is imposed between A and A'.

An attainable terminal partition is noncrossing by the disk Jordan separation for disjoint connected sets. Every noncrossing partition with at least one block has a block whose terminals are consecutive in the current cyclic order (take an innermost block in a linearized order). Choose deterministically such an interval block B. If only one terminal belongs to a block, the singleton itself is a canonical anchor, though nonzero charged singleton blocks are excluded by charge balance. For each consecutive pair u,v in the linear interval B, remove terminals of other blocks from the current graph, add an auxiliary edge uv just outside the disk along the boundary interval containing no other remaining terminals, and find a simple u–v path on the graph-facing boundary of its incident face. If no graph path exists, reject. If a graph path exists the auxiliary edge is not a bridge; the boundary walk with the auxiliary edge omitted contains a u–v walk. Erase repetitions to get a simple path. The union of these paths is a connected canonical anchor A*. Remove its vertices from the current graph and recurse on the other blocks. Use only the connected component containing u,v for the face traversal; disconnected components do not invalidate the argument below.

If the current partition has any system of anchors, consider an old path P inside the B anchor between these u,v. The auxiliary edge and P form a Jordan curve. The graph-facing incident face lies in its closed ear disk, between the auxiliary edge and P; the chosen canonical path is on its closure. All other-block terminals lie on the other side, and their disjoint anchors cannot enter the ear disk without meeting the auxiliary edge or P. This also holds when P touches extra boundary vertices: a tiny outward auxiliary arc meets the original disk only at u,v, and any original boundary point outside the u–v interval that is not on P can be joined directly to the exterior of the closed curve. Thus A* misses all other anchors, even though canonical paths for the SAME block may intersect. Simultaneously replacing the old B anchor by A* is valid. Continue inductively with removed vertices. Conversely a completed sequence is an explicit system, independently checkable for disjointness, connectivity and terminal contents. The algorithm can be defined solely on the supplied sphere rotation system and cyclic boundary access by retaining the chosen exterior arc conventions.

Enumerate noncrossing zero-charge partitions, compute the canonical system for each, and output all of its original indexed anchor-pair cuts together with the W0 pairs. The equivalence above proves that these pairs span W. There are at most the t-th Catalan number ≤4^t partitions, generable with polynomial overhead per ordinary noncrossing partition before filtering charge. Total deterministic work 4^t poly(input) with the implemented polynomial scalar first-space backend and original witness traceback. With no charges output all root-normalized face singleton pairs. The exponent does not depend on neutral vertex count in the terminal-partition stage. Distinct boundary points and an actual disk embedding are promises; arbitrary interior terminals are outside the proof.
