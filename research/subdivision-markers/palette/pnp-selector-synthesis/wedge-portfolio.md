# W computation without a supplied decomposition

For private keys use the symmetric submodular connectivity function λ(S)=rank(K_S)+rank(K_out)−rank(K). It is exactly the boundary dimension, with polynomial-time evaluation. Korhonen–Oum, arXiv:2601.04756v2, construct a width-k tree or certify that none exists in 2^O(k²) times polynomial input size. Try k=0,1,... until success; this charges 2^O((w*+1)²) poly for optimum width w*. Apply the two-relation branch DP of wedge-frontier.md. The earlier represented-matroid result of Hliněný–Oum (SIAM 2008) also yields parameter-dependent recognition. The implemented path solver uses the given site order; the optimal tree finder is a cited theorem dependency, not part of that Python implementation.

For a complementary recursion, start from exact L. At each state R, let I be the union of its supports. If I admits a common chart, all basis pairs realize exterior-square R. Otherwise find an unbalanced fundamental circuit C by tagged Gaussian elimination. Each feasible pair must omit some common index i in C. Sum the child spaces from R∩ker(coordinate i), merging repeated canonical subspaces. Strengthen each child by computing L' on the support union of the restricted space, using the polynomial three-name first-space oracle. L' contains every feasible pair at that child and is contained in the restriction: each child relation is supported on the previous state and omits i. The parent was the actual first space for its support. Thus L' is an exact stronger representation for recursive use. Cache by L' since compatible relations there can be tested against the unchanged global tag data and no longer depend on the deletion history. At most N child closures are considered per canonical state. If A distinct canonical nonempty or empty states are expanded, time is A poly(input). Charge all queried closure masks, including coincident results. No polynomial bound on A is asserted.

Dovetail the closed recursion, intrinsic-width construction plus DP, and the pinned 2^r solver at elementary-operation granularity. All return W with original compatible witness pairs; the first finished branch suffices. Total abstract time is poly(input) times the minimum of A, 2^r, and 2^O((w*+1)²) with each branch's own polynomial factors. A supplied or cheaply generated path/tree can be an additional branch charged against its measured width. Universal indexed height gauges act only on evaluation against W, preserving actual relation heights and original index witnesses, and do not shrink W itself. Gain-specific YES traceback evaluates against the original indexed heights and interpolates the chart on both supports. Absence follows from vanishing of the alternating height test on the certified exact span.

Controls use capped direct chart enumeration for the first-space oracle. On the 17-site absent-plane control, r=12, W has dimension 33, the supplied path has width 3, the plain conflict DAG explores 362 states, and semantic closure reduces it to 246 canonical states from 279 support masks. The conflicting and independent two-axis controls require 3 and 1 conflict states, with W dimensions 0 and 1. Four seven-terminal dual examples using a 7-cycle with 0–3 chords have r=4, W dimensions 1,1,2,3, conflict-state counts 9,11,13,12 and path widths 1,2,3,4. The target height determinant vanishes in all four. These small graphs retain the seven-terminal parity obstruction; they are not high-connectivity instances. In the full family the same determinant annihilation follows from the exact dual minor parity proof in nonregular-every-target-quotient.md.
