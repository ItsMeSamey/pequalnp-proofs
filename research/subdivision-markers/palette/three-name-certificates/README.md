# Independent nongraphic certificates

The additive adapter is is_graphic_certified in certified_graphic.py. Put this directory and ../three-name-backend on PYTHONPATH and pass functools.partial(is_graphic_certified, executable=path) as the graphic callback. The baseline backend remains byte-for-byte as recorded in its manifest. graphic_or_obstruction returns None on a verified graphic graph and an Obstruction value on verified nongraphic input. Exceptions report inconclusive results.

The pinned CMR 0c42a44deb8262a1f2a400add5d6be80e90eda3c documents that binary nongraphic submatrix retrieval is unimplemented in include/cmr/graphic.h. Its CLI passes NULL. The adapter uses the Boolean decision only to guide original-label deletion and contraction. It tries deletion first, then contraction, keeping a nongraphic child if one exists. Each input label is processed once. If both operations at a label give graphic minors, any further operations at other labels preserve their graphicness by commutation and minor closure. A correctly guided descent therefore ends at a minor-minimal nongraphic binary matroid after at most two additional graphic decisions per original label. The [binary graphic excluded-minor characterization](https://www.sciencedirect.com/science/article/pii/S0167506008708550) gives the four possible targets. The binary representation excludes U(2,4).

The certificate carries the fixed target name and three lists of original positions. The lists partition the graphic recognizer input. The retention list orders the target bijection. minor_check.verify_minor computes a Gaussian basis for the original contraction set and compares all binary dependencies of the at-most-ten retained elements modulo that span to the fixed target's dependencies. The verifier never trusts a CMR claim, an intermediate quotient, or an annotation from the matching routine. A faulty negative or inconclusive run that fails this final check raises an exception. Positive recognition uses the baseline independent full labeled graph-kernel checker. End-to-end exact-line positive witnesses are independently checked on physical original columns. A terminal minor certificate is relative to the padded/reduced matrix given to the graphic recognizer; end-to-end negative line decisions additionally rely on the three-terminal reduction theorem and its separation computations.

Targets use Fano columns 1 through 7; duals retain the primal indexing, and graph edges are ordered lexicographically, with K3,3 parts 0..2 and 3..5. The checker interface is compatible with an independent Lean implementation that enumerates the at-most-1024 target masks.

Replay requires the pinned binary and the baseline package from manifest SHA256 76d60664bdb0719280735978595fe724438e6d78c4d613d60ea5453cea0902ca. Run check_minor.py and then check_certified.py with the binary path, using ../three-name-backend on PYTHONPATH. The four printed obstructions exercise both deletion and contraction of original positions; every successful outer exact-line test uses independent direct subset enumeration.
