# Packed three-name certificate refinement

This directory is independent of the frozen three-name-transcript release. The new certificate values are kernel terms over BitVec with least-significant-bit coordinate zero.

**Split certificate.** A packed row map F fixes every retained column. Its images of every discarded column belong to a printed interface table S. Check that S contains zero, is closed under addition, and each nonzero member occurs at a fresh child label. For equal opposite-shore subset sums, F preserves the retained sum and sends the discarded sum into S. This proves the full-interface copy premise needed by one-direction NO propagation. A sufficient interface cover suffices irrespective of split minimality. The examples use full tables of sizes 1, 2 and 4. The candidate row maps fix the retained span and annihilate a complement of the interface in the discarded span.

**Terminal certificate.** Two packed row maps send each terminal bit vector to its graph incidence word and back, in the original stable label order. Their additive actions on every subset sum prove equivalence of the entire binary dependency kernels. No graphical recognition or Gaussian rank oracle enters this implication.

**Pinned quotient.** Generic linear projection lifts exact-line membership from selected quotient indices R to the original forced indices union R. The Python data use descending most-significant-bit elimination. A supplied table is replayed by the same bit-test/XOR order, every pivot row is justified by an XOR of allowed original pins, and every original pin must reduce to zero. These conditions determine the correct kernel even if an independent Gaussian implementation chooses different representatives. The literal regression includes pin=3 and input=1, giving residual 1 for MSB and 2 for the distinct first-coordinate reducer.

**Generated values.** check_pin_images.py transforms the three-split NO control by inserting a pin, tests all original names before and after reduction, and records literal interface words for all three actual splits. A positive companion restores original indices 0,1,2. generate.py turns the pinned NO transcript into ThreeNamePackedExample.lean. Packed row maps and stable labels may be generated by untrusted code; every split and the terminal graph are rechecked on the emitted values. The typed values also tie the six original padded roots and all optional physical words to their literal quotient images. The generator supports the saved unpinned transcript format and demonstrated one-pin wrapper. Its output is a Lean source file. General JSON parser correctness remains separate.
