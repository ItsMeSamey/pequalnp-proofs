# Two exceptional columns with a nonzero-gain clean core

Use one-deletion-binary.md with a specified deletion set D0 of at most two columns. Require clean M connected and spanning, clean N binary, and at least one nonzero clean discrepancy on interpolation from a clean basis. If a clean basis already solves the problem, stop. Otherwise nonzero clean discrepancy is equivalent to clean labels not forming a linear map. The same binary weak-map comparison either returns a clean witness or supplies the four-sector representation of the clean columns in that proof.

For each rogue j let a^j be its M column and b^j its N column after row-scaling to align the clean matrices. The portion of b^j in V0 is a^j_0; its portion in V_x is s_x(a^j_x+x g_j t_x/p). Let K be generated by all a^j_0,a^j_x and t_x. Each sector's local intersection with K is within span(t_x, all a^j_x), and the last block's is within span(t, all a^j_0). These dimensions are at most three. Blocks are jointly independent modulo K. Compute all clean physical traces W intersect K via rank-three local palettes and subspace sums, storing witnesses.

For each nonempty subset D of D0 with the columns a^j,j∈D independent, test if some attainable W meets their span trivially and some nonzero tuple of GF(16) coefficients c has every binary slice of sum_j c_j b^j in W. This includes a zero field sum. The tests use only W intersect K, since multiplication by a field scalar only mixes slices. Take an independent clean generating set for a passing W. Together with D it is M-independent and N-dependent; extend it to a full M-basis using clean columns and retaining N dependence. Conversely any differing basis involving D has a clean independent subset in both representations and satisfies precisely these tests. Thus the full target is solved on the stated class. Candidate deletion pairs can be enumerated in polynomial time. The same argument works for larger fixed deletion sets if each actual local boundary still has rank at most three. No conclusion for the two zero-core gain outliers follows: that latter class already subsumes the unrestricted question.
