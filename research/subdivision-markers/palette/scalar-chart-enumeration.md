# Output-sensitive alternatives for the full plane

Section 4 of Khachiyan, Boros, Borys, Elbassioni and Gurvich, On the Complexity of Some Enumeration Problems for Matroids (https://doi.org/10.1137/S0895480103428338), gives polynomial delay for a fixed prescribed set of edges in a supplied graphic or cographic matroid. Its general one-prescribed-element result gives incremental polynomial time. Consequently if the exact first scalar lift or its dual has a supplied graph representation, feed its three actual probes to the fixed-set enumerator and run the second scalar feasibility test on each returned chart. Total time is (k+1)poly(n) on that class for k actual admissible charts. This conclusion uses graph structure only for the first lift.

For arbitrary represented binary inputs, a different procedure removes H from the scalar lift, giving ordinary columns (q_e,λo_e) and a single distinguished z=(0,1). Each cocircuit through z determines a scalar map φ on Q whose active columns span Q, using the same graph-of-a-linear-map argument. Enumerate those cocircuits by the one-element result in the dual. Require the corresponding physical v_e=(q_e,h_e) to span Q plus H before applying the second scalar test. Total time is polynomial in input and in the number of these relaxed charts. It need not be polynomial in the number of actual admissible charts. Separately, the same paper allows incremental-polynomial enumeration of all minimal physical sets spanning H, after which the entire U-trace can be checked. These output measures differ.

Here is a regular first scalar lift with one true chart and at least 2^m relaxed charts. The dual is a connected graph with three marked edges aa',bb',cc'. Its ordinary edges are a'b, b'c, c'a, c'b, a parallel copy of bb', and a chain of m diamonds joining a to a' with no other attachment. Removing all three probes leaves the graph connected. Hence the three probes p1,p2,p3 are independent in the cographic primal. Exactly one simple cycle contains all three: both terminals of edges aa' and bb' are already required, so their parallel detours cannot occur, and the old connectors force a'b,b'c,c'a. Thus there is one true chart. Let its hyperplane in the primal be V and put z=p1 and h_i=p1+p_{i+1} for i=1,2. Those two vectors lie in V and are independent; the probe representations are now z,h1+z,h2+z, as needed. The ordinary columns span V in projection because the true hyperplane is spanned by its physical zeros.

Normalized scalar maps with the H pins correspond to all Eulerian edge sets with each of the three probe bits one, since the primal row space is the cycle space of the graph. Relaxed private spanning is equivalent to minimality of the ordinary support among such Eulerian sets. Indeed a difference with all probe bits zero is exactly a private functional. A strictly removable sub-support exists exactly when such a nonzero difference vanishes on all active ordinary columns. Graphically this means the inactive ordinary set contains a nonempty cycle. For every simple path P threading the diamonds, take the inactive ordinary set P together with b'c,c'b. Together with the probes this is Eulerian, and the ordinary subset is a forest. These choices yield 2^m distinct relaxed charts. They have two disjoint cycles with the probes, so are not true charts. They do not constrain an algorithm using the known graphic structure.

Unrestricted prefix branching can require deciding circuits through arbitrarily many specified elements. The variable-terminal hardness results do not classify output sensitivity for three specified roots. The general fixed-three algorithm established here is the n^{k+O(1)} bound of bounded-scalar-charts.md; no general polynomial-delay conclusion follows from deletion self-reduction alone.
