# Cutvertices and weighted rooted supports

For an even rooted support whose component containing the specified edge is a cactus, let C be its induced cycle containing that edge. Every selected vertex outside C adjacent to C belongs to an incident cycle block meeting C at one vertex. Indeed the selected graph has no bridges because all degrees are even, and its nontrivial blocks are cycles. Distinct such petals intersect only at vertices of C. Each petal minus its attachment is an available affine difference between C and its union with that petal. All other selected vertices are individually spectators on C. Thus cycles, cycles with one incident petal, and cycles with one spectator span all such support vectors.

There is a deterministic polynomial algorithm for all weighted even rooted supports in ambient graphs in which each two-connected block is subcubic. Cutvertex degrees can be arbitrarily large. More generally the reduction below works for hereditary block classes with a polynomial exact weighted rooted-edge solver.

A selected support is even precisely when its selection restricts to an even support inside every ambient block (including bridges as two-vertex blocks). Necessity follows by decomposing its selected edges into cycles, each of which lies in one ambient block. Sufficiency follows by summing local degrees. Distinct blocks intersect only at cutvertices, so their local selections may be joined whenever they agree on these shared bits.

Root the block-cut incidence tree at the block containing the prescribed edge. Components disconnected from the root impose no constraint; if any of their vertices has positive weight its singleton can toggle parity freely. For each cutvertex report the attainable parities of total strict-descendant weight conditional on the cutvertex's value e. Both entries are nonempty: the empty selection or the singleton cutvertex is feasible. At a cutvertex combine child-block tables by adding available parities for the same e. Count each vertex weight exactly once, for instance in its parent block; the block below a given cutvertex excludes that vertex's weight.

At a block, select one available child contribution for each cutvertex value. These two binary parities form an affine function of that cutvertex's indicator, so their sum is a constant offset plus a change of the local weights. Apply the local weighted solver to these adjusted weights, subject to the parent cutvertex value or the prescribed root edge. If a child table allows both parities for a value e, test whether the block's own constraint permits that child cutvertex to have value e. The same local solver does this using just the unit weight at that vertex. If reachable, both total parities are feasible because the child can toggle, and if no such value is reachable the initially selected affine contribution is exact. Each step retains witnesses for reconstruction by backtracking.

For a required included parent cutvertex v, enumerate the incident edges vw on which w is also selected, using the weighted rooted-edge solver for each. If v is isolated in the selected block, its other selected vertices are all outside N[v]; an additional odd weight is possible precisely when some such vertex has positive weight, in which case use its singleton. For an excluded parent cutvertex there is no further local anchor, so empty selection or any positive singleton different from v gives all possible parities. These reductions also handle bridge blocks. The [subcubic rooted-edge solver](README.md) supplies the claimed local primitive. As with the local algorithm, repeated orthogonal weight queries construct a basis of the complete global rooted-support affine hull.
