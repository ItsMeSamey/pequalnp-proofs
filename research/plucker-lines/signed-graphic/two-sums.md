# Two-sum reduction for stationary anchored objectives

Suppose the objective ℓ(C)+m(D) is constant on every nonempty fiber with either C or D held fixed. We seek all its global values. In a standard binary two-sum, local cycle words agree on the common virtual element and are projected to the ordinary elements. The same holds for cocycles by duality. Take all virtual-element weights as zero until replaced below. At an interface the two local bits, primal then dual, can only be 00,10,01 if the interface separates a full global pair. Indeed lift the two global words on either entire side of the separation. Their intersection on its ordinary elements is empty, and orthogonality prohibits a singleton intersection at the virtual element. Thus they are disjoint there too; this argument applies separately to every edge of a decomposition tree.

A side with neither root has all three interface states available when the virtual element is neither a loop nor a coloop, as in a proper two-sum. For 00 use two empty words. For 10 use any cycle through the interface and an empty cocycle. For 01 use its dual. These representatives are computable by linear algebra. Every local realization at a given state is connected to the chosen representative through changes of one word at a time. For 10, reset the cocycle to zero, replace the cycle, and leave the cocycle at zero. For 01 exchange roles. For 00 reset both separately. Each step can be glued to the same fixed remainder, since both interface bits are preserved, and it changes only one global word. Therefore every globally accessible completion at that state has the same weight as its representative. The representatives' three weights can be encoded on one virtual element: zero for state 00, its primal label for 10, and its dual label for 01. This folds arbitrary off-path limbs into ordinary additive labels.

Given a two-sum tree, retain the path between the torsos containing s and t, including a single torso when both roots occur there. Compress every off-path component in its entirety by the preceding argument, using its binary representation with its one virtual element. These representations can be formed by equality of interface bits and projection using Gaussian elimination. There are only polynomially many limbs and elements. A separate direct-sum component with neither root may be reset to the zero pair by fiber changes. If the roots lie in different direct-sum components the restrictions on each are single-sided, and the same reset argument leaves a fixed weight in each accessible component.

Each retained path piece has two distinguished elements: its left and right interface, with an actual root substituting for a missing interface at an end. Fix the actual states to 01 at s and 10 at t. Enumerate the constant number of local state pairs. When only primal bits are required, impose the two primal values, including any zeros, by a linear system and use the all-zero dual word. This also handles two zero states. The dual case is identical. When one state is 10 and the other 01 the piece is exactly an anchored opposite-root instance. Its unweighted feasibility is ordinary matroid intersection using the two quotient representations of compatible bases, or one of the direct root degeneracy cases. A Boolean path dynamic program finds all local transitions extendable to a complete feasible path of states.

For an extendable unmixed transition the same single-fiber reset proof justifies the weight of a single pure solution. For an extendable mixed transition the stationarity promise holds on every nonempty local fiber with the two interface states fixed: concatenate each local change to fixed witnesses of the other transitions and to the fixed representatives of all removed limbs. This preserves the states, one word, and disjointness. The compressed objective equals the global objective up to the fixed contribution of the other pieces. A promised solver for that torso therefore gives its complete set of attainable weights. Propagate these one- or two-element tables along the path with XOR addition. Local witnesses and virtual states reconstruct the global pair. This proves a polynomial Turing reduction to the promised problem on individual 3-connected torsos, circuit torsos and cocircuit torsos of a supplied decomposition. Circuit and cocircuit torsos can be handled by direct linear equations for their one-dimensional primal or dual code. The number of off-path attachments per torso is unrestricted.
