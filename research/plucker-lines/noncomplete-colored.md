# Arbitrary shared graph when the colored block contains a nonedge

Use the labels and even-degree target of [the two-sided shared-only problem](two-sided-shared.md). Suppose the colored bipartite block has at least one nonedge. Feasibility and witness search are deterministic polynomial time for an arbitrary shared graph.

## Certificates and threshold neighborhoods

Check for missing matched edges and independent two-colored-one-shared target triples. Thus matched blocks are complete and every deficient colored vertex (one having a colored nonneighbor) sees every opposite shared vertex. Write D_L,D_R for the deficient sets, both nonempty, and U_L,U_R for their colored complements. If the shared block has no edges, use the empty-block theorem.

Every nonisolated shared component contacts all deficient vertices on both shores. Check for a shared component touching same-color colored vertices on opposite shores. The shortest path through the component between the two endpoints closes with their matched edge to give an induced target cycle. Hence D_L has a single color a and D_R the other color b. Every nonisolated shared component has only color-a colored left contacts and color-b colored right contacts.

Orient the complete bipartite graph on the shared shores from left to right on original edges and right to left on nonedges. For universal colored left vertex i, let H be its set of shared right neighbors and T the shared left vertices touching H. If i has color b, H contains only shared isolates so T is empty. For color a, take t in T, its shared neighbor s in H, and any j in D_R. The vertices i,j,t,s form a square. If t misses any shared right h outside H, adjoining h to the square gives a target. Search for this configuration and its mirror. In the absence of this certificate each t in T sees every shared right outside H.

Consequently all arcs between H ∪ T and its complement point out of H ∪ T: every left outside T misses H, and T sees the entire right complement of H. For universal colored right vertices, interchanging shores reverses orientation, giving terminal directed cuts instead.

## Ordered blocks

Topologically order the strongly connected components of this tournament. A nonsingleton component contains both shores. Merge every maximal run of singleton components of the same shore into a pure block; retain each mixed component as a single block. Directed cuts cannot split strong components. Two vertices on the same shore in distinct blocks are ordered by directed paths: if either block is mixed, use an opposite-shore vertex in that block and its strong connectivity; between separate pure blocks of the same shore there is an intermediate opposite-shore vertex. Thus H consists of all shared right vertices before its cutoff, possibly a subset of one pure-right block, and none later. Mirrored neighborhoods are suffixes on the shared left.

Place universal colored left vertices inside their partially included pure-right block, or in a boundary slot after the last included right-containing block if no block is partially included (use the start if H is empty). Place universal colored right vertices inside their partially included pure-left block, or immediately before the first included left-containing block (use the end for an empty suffix). Expand boundary slots into singleton colored blocks. Put D_L,D_R together in a separate first block and distinguish their types. Each deficient vertex sees all opposite external vertices.

Between distinct remaining blocks, shared left sees shared right exactly when the left block is earlier; colored left sees shared right exactly when the colored vertex lies later; colored right sees shared left exactly when the colored vertex lies earlier. Opposite universal colored vertices are completely adjacent. Same-shore pairs never see each other.

Inside mixed shared blocks and the deficient block, incidences are arbitrary between two single-type shores. Inside a pure block they are arbitrary between shared vertices of one shore and partially attached colored vertices of the other, possibly of both colors. Every vertex on a given shore in a block has identical external neighborhoods, regardless of color. Hence every selected vertex on that shore has the same required internal degree parity for a fixed exterior selection.

## Four-vertex representatives inside each block

Consider a bipartite box whose one shore has up to two colors 0,1 and whose other shore has a single type. Use only color 0 for a monochromatic first shore. Let required internal degrees have parity α on the colored shore and β on the other shore. Prescribe colored selection parities p0,p1 and opposite-shore parity q. Any attainable profile can be realized by at most four vertices. Choose the representatives within any given witness.

If p0=p1=0, use no colored vertices. If q is odd, edge counting forces β=0 and an opposite singleton suffices. If exactly one colored parity is odd, write r for that color. For even q, edge counting forces α=0, so a color-r singleton suffices. For odd q, counting gives α=β. A color-r vertex has an opposite vertex with adjacency α because its degree parity is α on an odd opposite shore. That pair suffices.

Suppose both colored counts are odd. For odd q, edge counting gives β=0. If α=1 complement all box adjacencies on the witness: colored degrees change parity and opposite degrees do not. Now some opposite vertex misses one vertex in each color class. Otherwise each opposite vertex sees all of one odd class and, by its even total degree, sees odd numbers of both. Summing the color-zero degrees gives an odd total on the odd opposite shore, contrary to the even colored degrees. Use that triple, undoing complementation if necessary.

It remains that p0=p1=1 and q=0. For α=0 one vertex of each color suffices. For α=1 colored rows have odd weight in the even selected opposite shore. If β=0, some opposite-color pair has both a common neighbor and a common nonneighbor. Otherwise, the numbers of 11 and 00 columns for each pair have the same parity (two odd rows and even length), and at least one vanishes, so every common-neighbor count is even. Yet at each selected opposite vertex the two color-degree parities agree; their product equals its color-zero degree parity. Summing these products over opposite vertices counts pair/common-neighbor incidences and gives odd parity, since the odd color-zero class has all degrees odd. For β=1, some opposite-color pair has incomparable neighborhoods: if all are comparable, every pair has odd common-neighbor count, whereas the product of the two color-degree parities at every opposite vertex vanishes by its odd degree. The contradictions prove the required pairs exist. Choose columns 11 and 00 in the first case or 10 and 01 in the second, together with their two rows.

## Polynomial witness search

For each block enumerate subsets of size at most four and record representatives for all internal parity requirements and local selection parities. There are at most eight global types: the two shared shores, the four universal colors/shores and the two deficient shores (each monochromatic). Guess the global selection parity vector, discarding guesses inconsistent with the target label. Sweep the blocks in order with the prefix parity vector as state. For each candidate local selection parity vector the suffix vector is determined by global, prefix and local vectors. The between-block rules compute each shore's required internal degree parity from the prefix and suffix. Use the local table to test the transition and store a predecessor and representative. Require the final prefix to equal the global guess. This is exact because every exterior degree and marker contribution depends only on the parity vectors. Backtracking returns the selected vertices. The type count is constant, giving polynomial time.
