# Independent audit of the rectangle and component reductions

A rectangle in the exact limb table has primal fluxes a+H and dual restrictions agreeing with eta on J. Every primal flux is annihilated by every dual restriction in the rectangle. Subtracting pairs of those dual restrictions forces all the fluxes to lie in J, and evaluating one restriction there gives eta(a)=eta(H)=0. Thus H lies in J. If a rectangle includes dual restrictions that disagree with lambda on T∩W, intersect its dual coset with the compatible restrictions. When nonempty this replaces J by J+(T∩W), extends eta consistently, and leaves T+J unchanged. This operation preserves the quotient rank. Discarding the entire mixed rectangle without considering this restriction could lose a useful covering cell.

A solution in the exterior quotient by H lifts to a functional on the exterior annihilating H, with its prescribed values on T and J. Its uncontracted exterior flux differs from p+a by some h in H. The rectangle contains the resulting state (a+h,d restricted to W), so an interior solution fills that flux and agrees on the entire intersection. Conversely any matching full solution using the rectangle has a functional killing H and passes the quotient test. No actual column representing a quotient direction has to be contracted. The criterion reduces rank exactly when dim(T+J)−dim(H) is at most three. Empty or incomplete cheap covers do not certify NO.

If W lies in T and the attainable flux set S at the forced dual value contains a nonzero w, the compatible two-point rectangle contains zero and w. Take the disjunction of those tests over all nonzero w in S. If S consists only of zero, the empty selection always supplies that state for the prescribed restriction and the limb may be deleted. This can leave an unresolved four-space outside.

For component decomposition, project the ordinary columns to V/T and partition into the connected components of the represented matroid. Projected loops can be treated as singleton components. Their component spaces form a direct sum in the quotient, so any union of local spaces augmented with T meets a new augmented component space exactly in T. Local functionals agreeing with lambda on T therefore glue simultaneously. Any global selection of total flux in T has a flux in T separately on every component. Conversely its individual flux choices can be realized independently. The attainable target set is the binary sum of the component images.

Write K=ker(lambda) in T. Each image S_i contains zero. For distinct a,b in K every admissible functional already kills a+b. The rank-three query in the quotient by this line returns YES exactly if S_i meets {a,b}. If a negative pair occurs, the union of the negative pairs is precisely the full missing set. If all pairs are positive, at most one element of K is missing. In the latter case a second component supplying an attainable nonzero c gives all targets: query {p,p+c} in the dense component and fill with 0 or c in the second. If a concrete c is needed in a second dense component, query a pair of distinct nonzero possibilities. These arguments work for the stated nonzero lambda with |K|=8. For lambda zero, unrestricted primal span already decides the query. Exactly one active dense component can still leave one target unresolved.
