# Weighted rooted search on partially subdivided graphs

Localize to the biconnected block of the root edge st as in attachments.md. If the block is a cycle the only support through its edge is the cycle itself. Otherwise call its vertices of degree at least three branch vertices. Let k count the branch vertices incident with a direct edge to another branch vertex. The full weighted rooted-support problem has a deterministic 2^k poly(n) witness algorithm. In particular it is polynomial on arbitrary fully subdivided graphs, allowing unbounded degree and treewidth.

First find a shortest root cycle. For each marked spectator candidate h search for a root cycle outside its closed neighborhood. Success realizes both parities by independently adding h. Assume there is no marked spectator. Partition all edges into direct branch edges and maximal paths between branch vertices with nonempty internal degree-two set. Their interiors are disjoint. In any rooted even support, if such a path has two consecutive selected vertices, with at least one internal vertex, the degree-two equation propagates along the path to select every vertex including the ends. Otherwise all its selected internal vertices are isolated in the support. Such isolated vertices are unmarked and can be removed, since they are individually spectators of the rooted component's shortest induced root cycle.

Call a fully selected path conducting. Guess the exact selected subset of the k branch vertices incident with direct branch edges. Select all other branch vertices. To see that this loses no weight, after discarding isolated interior vertices any previously unselected branch vertex outside the k has no selected neighbor: a selected adjacent path interior would force that branch vertex. Such a branch vertex is therefore a permissible spectator and unmarked. Adding all these branch vertices preserves every degree because there are no direct edges among them.

Retain only optional paths whose two endpoints are allowed by the branch guess. Each path's conducting bit is unrestricted unless the root edge lies on this path, in which case force it to one. A direct root edge forces both branch endpoints selected. Other direct branch edges are present exactly when both endpoints are selected. Consequently, at each retained branch impose that its incident conducting bits have XOR equal to its direct-edge degree parity. The total marker weight is the selected branch weight plus the XOR of the internal weights of conducting paths. Add this last linear equation for the desired target. Every solution gives a witness by selecting the prescribed branches and the full conducting paths; all degrees within them are even. Gaussian elimination finishes each branch.

The implementation subdivision.py returns witnesses on biconnected input, and check_subdivision.py compares 4,000 target decisions and all returned witnesses to direct support enumeration. No bipartiteness is needed. Computing an affine basis from the weighted oracle uses polynomially many calls by querying a basis of the annihilator of the differences already found.
