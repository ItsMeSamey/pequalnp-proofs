# An induced cycle through a specified edge with an isolated vertex

**Theorem.** In every finite simple bipartite graph of odd order in which every vertex has even degree, for every edge st there is a vertex h and an induced cycle through st disjoint from the closed neighborhood of h. Constructively, delete st and search for an s–t path outside N[h] for each h. A shortest such path closes to an induced cycle.

Put H=G−st. The edge st lies on a cycle since each component of G has even degrees. Any extra component supplies h immediately. Assume H connected and every s–t path dominates H. We prove even total order. Write ℓ for the length of a shortest s–t path, odd and at least three. Classify vertices by their distances from s and t. The geodesic layer C_i has distances (i,ℓ−i); the off-geodesic layer E_i has (i+1,ℓ−i+1). These exhaust all vertices: each is on or adjacent to a shortest path, so its distance sum is at most ℓ+2, and bipartiteness ensures the correct parity. The indices range from zero to ℓ. Every E_i vertex is adjacent to all C_i vertices. A shortest path containing any given C_i vertex must dominate this E_i vertex, and the distance inequalities allow no other neighbor on that path. Other edges of H only join C_i to C_(i+1) or E_i to E_(i+1), by the two distance coordinates and bipartiteness.

For either family R=C or R=E, take p in R_(i−1) and q in R_(i+1) at internal index i. Their neighborhoods within R_i are disjoint or cover R_i. If they have a common neighbor v, form an s–t path through p,v,q. For C use a geodesic prefix and suffix. For E, connect p and q to C_(i−1) and C_(i+1), with a geodesic prefix and suffix ending and starting there. The resulting path bypasses C_i. Every vertex of R_i must be dominated. Except for the middle vertex, which sees both p,q, its only possible neighbors on this path are p and q.

All subsequent arithmetic is over GF(2). At internal R_i write r for its size parity and w for the size parity of the other family at i. Let a_v,b_v be horizontal incoming and outgoing degree parities. Even degree gives a_v+b_v=w. Write D_i for the edge-count parity from R_i to R_(i+1), so D_(i−1)+D_i=rw. Put t_i=Σ b_u a_v over edges u v from layer i to i+1.

Sum 1+r+b_p+a_q over horizontal two-step paths p,v,q through R_i. The sum is zero: whenever p,q occur an odd number of times, disjoint-or-cover implies their intersection parity is r+b_p+a_q=1 by inclusion–exclusion. The constant contribution is (1+r)Σ_v a_v b_v=(1+r)(1+w)D_(i−1). The b_p contribution is t_(i−1)+w D_(i−1), because b_v=a_v+w. The a_q contribution is t_i+w D_i. Thus t_(i−1)+t_i=(1+r)(1+w)D_(i−1)+rw.

Across the two families D_i^C+D_i^E=1 for every cut: the prefix contains exactly one odd-degree vertex s of H. Put c_i=|C_i| mod 2, e_i=|E_i| mod 2, and U_i=t_i^C+t_i^E+D_i^C. Summing the track identities and using D_(i−1)^C+D_i^C=c_i e_i gives U_(i−1)+U_i=1+c_i+e_i. At the left endpoint all vertices of C_1 neighbor s, giving t_0^C=D_0^C. Every E_0 vertex has horizontal outgoing parity one because it sees s and has even total degree. Thus t_0^E=D_0^E=e_0. Hence U_0=e_0. Reversing the roles of s,t yields U_(ℓ−1)=e_ℓ. Summing the internal identities gives Σ_internal(c_i+e_i)=e_0+e_ℓ since ℓ−1 is even. The singleton core endpoints and two endpoint ear layers give even total order, as claimed.

## Application to complete colored blocks

Consider the bipartite three-marker model with shared-only vertices on either side, no true neutrals, and complete colored-to-colored graph. Any feasible support containing an odd total number of shared vertices admits a witness consisting of one colored vertex on each side, a shared path closing their edge, and possibly one additional shared vertex. Restrict to this support. Delete all colored-to-colored edges, introduce adjacent new terminals s and t, join s to each left colored vertex and t to each right colored vertex. Both colored shore counts are odd, so the graph is bipartite of odd order with all degrees even. Apply the theorem to st. The induced cycle uses exactly one colored vertex on each side, as any additional one would form a chord incident with a terminal. The isolated vertex is shared, since each colored vertex neighbors a terminal. Remove the terminals and restore the edge between the chosen colored vertices. Its induced cycle has an even number of shared vertices. If the two colors match, it gives the required support; otherwise include the isolated shared vertex.

The independent checker exhausts all 663,552 even-degree subgraphs containing a fixed edge in K_(3,8), K_(4,7), K_(5,6). It directly tests for the prescribed path and isolated vertex.
