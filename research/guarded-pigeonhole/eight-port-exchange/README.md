# Rebased eight-port decision and unbounded single-cycle exchange distance

Consider a connected matching-covered simple bipartite cubic multipole with eight distinct terminal holders. Four tips are prescribed blue and four green, two per color per shore. No terminal is prescribed red. Taking red as the matching color sees only one allowed-edge component by hypothesis.

## A second exact polynomial regime

Choose blue or green as the new matching color, remove its four holders, and fix the colors of the two remaining incident edges at each removed holder. There are at most sixteen choices, since these two edges receive the two other colors in either order. Reject inconsistent values on an edge joining two removed holders. In the resulting free graph the half-edges have prescribed colors excluding the chosen base. There are at most six free half-edges per shore: two terminal ends of the remaining original color, and at most four edge ends incident with deleted opposite-shore holders. The color-state matching-component algorithm from [the width-four composer](../pappus-dm/README.md) applies with at most six ordinary frontier wires, hence 64 states per prefix for each assignment. This is exact and polynomial when all the resulting allowed components have at most six ports, or whenever the necessary larger local entries have a polynomial exact solver. If one orientation yields SAT it returns SAT; it returns UNSAT only when all orientations are impossible. The local ≤6-port regime follows by the dominant-color matching test since every color-balanced blue/green boundary of that width has minority count at most two. Both choices of new base may be tried.

## A matching-covered obstruction to bounded exchange search

For n≥1 take n tiles K3,3 minus edges L0R0 and L1R1, where the left and right vertices are indexed 0,1,2. Between successive tiles connect R0,R1 to L0,L1 by two rails. Connect the last R_i to the first L_i for each i=0,1 by a path of length five, with tips on its four internal vertices prescribed blue, green, green, blue in that order.

Every internal edge belongs to a perfect matching. Omitting all rail connections permits arbitrary internal tile matchings and covers every tile edge in some choice. Alternatively use all rail connections at tile ends, leaving only L2R2 to match within each tile. The odd-length return paths realize either of the two required matching phases, so their internal edges are also allowed. Thus the original internal graph is a single elementary block. For odd n it contains a subdivision of K3,3: retain one tile, traverse the others on their two disjoint cross edges L0R1, L1R0, and use the return paths. The n−1 swaps cancel, restoring disjoint replacements of the retained tile's missing edges.

For the blue matching, the four blue holders cannot have any blue internal incident edges. The middle edge of each return path is therefore forced blue. Both end wires of the chain are nonblue, and no intermediate rail can belong to the blue matching: in each balanced tile the incoming and outgoing numbers of matching rails must agree. A full coloring forces each terminal chain wire green, because the blue/green-holder edge immediately beside it has the third color.

Each tile has three internal perfect matchings. One produces nonblue paths pairing L0 with L1 and R0 with R1 (the cap). The other two each pair both left ends through to right ends. If there is a cap, the first cap encountered from the left joins the two left green chain ends through a path with same-shore holders, which would require distinct colors. If no cap occurs both paths run through to the right and have opposite-shore ends, so the coloring extends. All intermediate circuits are even.

Start from the blue perfect matching that uses the cap at every tile. Every single alternating-cycle exchange is confined to one tile: two permissible matchings differ on neither the forced return edges nor the excluded intermediate rails. An extending matching has changed every one of the n tiles. Conversely a cap changes into a through-matching by one alternating-cycle exchange in that tile. Thus the minimum number of exchanges from the chosen matching to any extending matching is exactly n, for a fixed total of eight terminals. This rules out bounded-radius exchange tests around an arbitrary initial matching for this dominant base. It makes no assertion about algorithms that choose their starting matching or switch bases.

Run python check.py with the sibling pappus-dm and subdivision-single-hole packages available. It checks full allowedness, rebased feasibility, the exact component sizes, both tile transitions, and every one of the 3^n blue matching combinations through n=5. Additional cases reach n=12, with 80 vertices.
