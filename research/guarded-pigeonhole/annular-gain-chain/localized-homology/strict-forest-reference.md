# Recognizing opposite-parity references whose every physical completion is a forest

Take disjoint optional three-cycle switches in a closed native network. In an arbitrary chosen physical baseline S choose an orientation for each triple in which the other physical setting is the forward three-cycle relative to S. On the sockets a reference B of opposite local parity chooses one of the three transpositions relative to S at each gate. These artificial references need not be physical settings. Relative to B each physical gate has exactly two distinct transposition options; they share a socket. Mark each option edge by its gate color, with ends on the B-circuits containing its two sockets. Thus each color class is a star, even after circuit identifications. A strict universal forest reference is a B for which every selection of one edge per color forms a forest (loops and parallel-edge cycles count). This is a recognizable sufficient condition for rooted decision; failure of recognition leaves the rooted query undecided.

Write k for the number of S-circuits and n for the number of gates. If some strict reference exists, every physical setting has exactly k circuits and that reference has k+n. Indeed transpositions of a forest merge previously distinct circuits in every order, one merge per edge. Conversely if some strict reference exists, **any** artificial reference having k+n circuits is strict: every physical selection from it ends at k, requiring n decrements in n swaps. A cycle among the selected edges is impossible, since processing its edges first eventually presents an edge whose endpoints are already on one merged circuit. This argument also applies to loops and cycles of length two.

## Find a maximum-splitting reference

Transpositions at different gates act on disjoint sockets and commute. Reaching k+n requires each transposition to split a circuit, in every order. Its chord must have endpoints on the same original circuit (take it first); two interlaced chords on that circle cannot both split (take them first and second). Conversely same-circle noncrossing chords all split: applying a chord divides the circle into its two open intervals with their cut boundaries; endpoints of each remaining chord stay together, and the restricted chord diagrams remain noncrossing. This is independent of where the cyclic order is cut for display.

On each S-circle list sockets in traversal order. An allowed chord uses any two sockets of one gate. A matching automatically uses at most one chord from a given triple, and no triple can supply a same-circle chord on two different circles. Thus independently maximize noncrossing matching size on each list. On a half-open interval [i,j) skip i, or pair it to an allowed partner h with i<h<j and combine [i+1,h) and [h+1,j) plus one. The best of these choices with backpointers gives a maximum. There are at most two partners of i. Summing over circles, value n is exactly the condition for constructing a candidate B with k+n circuits. Smaller value rejects the strict reference condition. Any maximizer attaining n suffices.

## Test the candidate and answer a root query

A selection can contain a cycle precisely when the full option multigraph has a cycle with distinct gate colors: such a partial selection extends arbitrarily. Detect loops immediately. For each nonloop edge uv of color c, remove all edges of color c and seek a properly colored vertex-simple u-to-v path, meaning consecutive edges have different colors. On a vertex-simple path this prevents every repeated gate color because all edges of that color meet one common center. Adding uv gives a distinct-color cycle; the test includes two parallel edges of different colors. Conversely a distinct-color cycle supplies this path for any one of its edges. Use the perfect-matching port/mate/two-hub construction in star-transposition-matching.md, so the total number of matching calls is polynomial. Reject if such a cycle exists. By the choice-independence argument above, rejection certifies that no strict reference exists.

For a passing B, find a properly colored vertex-simple path between the two marked B-circuits (empty when identical). No path gives a rooted NO, since a physical solution can travel only within the components of its selected option graph. A path fixes at most one transposition per gate. Select them, complete all remaining gates with either of their physical options, and apply the selections. Every completion is a forest, hence never splits a circuit, and the marked wires end in the same circuit. This constructs and directly verifies a physical mask.

The companion strict_forest_reference.py implements the recognition, constructs the witness, and cross-checks randomly generated instances against enumeration of artificial references and physical masks. The core uses NetworkX general-graph maximum-cardinality matching.
