# Optional transpositions in an attainable forest reference

Start with a supplied physical triple-gate baseline S and all optional transpositions off; sockets are disjoint. Split one chord per triple on S using the noncrossing chord dynamic program. If it fails, report unrecognized. The resulting opposite-parity reference B has n more circles than S for n triples. The n transpositions returning B to S form a rainbow forest: each joins two components, since the total circle count decreases by n. This supplies a known full completion for the mandatory colors.

Use one edge on the B-circle vertices per physical triple alternative as before. For each optional transposition add one physical edge of a fresh color; it may be a loop. Run the properly colored path matcher on physical edges only. Triple options of one color share a B-circle endpoint, so a properly colored simple path is rainbow; each optional color appears only once. If there is no such path, no choice can join the roots, since a positive choice would connect them by its selected real edges, one per color at most.

For augmentation only, give each optional color an extra dummy edge between two new vertices private to that color. Off is the dummy option and on the physical edge. Take the known mandatory forest for S plus every dummy edge to see that a full-color forest exists. Starting from the witness path, augment by the graphic-closure-preserving exchanges of attainable-forest-reference.md. On removing dummies from the resulting full forest no physical vertices lose a connection to another physical vertex, since dummy components are isolated. The real edges form a forest and their swaps merge all its connected reference circles. Decode each triple's actual physical alternative (accounting for its input baseline), and each optional color as on for a real edge or off for its dummy. This yields a complete verified physical mask. Recognition is relative to the supplied baseline; the argument imposes no global obstacle if it fails.

Run python optional_forest_reference.py. A seeded replay includes zero through three gates of each type, arbitrary disjoint socket positions, passive positions, varied triple baselines and coincident roots. An independent direct action enumerator checks every possible physical mask per sampled network. Across 1,120 root-instance queries, 832 were recognized, with 731 positive masks directly validated and 101 negatives verified by enumeration.
