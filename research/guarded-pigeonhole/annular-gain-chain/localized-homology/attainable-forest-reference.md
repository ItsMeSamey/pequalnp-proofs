# A single forest completion suffices for exact rooted routing

Use the opposite-parity reference B, its option multigraph, and the chord dynamic program of strict-forest-reference.md. Each gate has one color and two mandatory transposition alternatives incident to the same center. Suppose some choice of one option per gate forms a forest. Then the root circuits of B can be physically joined exactly when they coincide or have a properly colored simple path between them. Necessity follows since all possible physical circuits stay within the connected components of the selected option edges. For sufficiency a properly colored simple path is a rainbow forest, having no repeated gate color by the common-center property. The following augmentation extends its *connectivity*, with permission to change path edges, to a full rainbow forest. Applying its selected transpositions then merges the roots.

## Constructive augmentation preserving graphic closure

Let I be any rainbow forest in a colored multigraph. Make nodes for all edges. Start breadth-first search at all edges of unrepresented colors. From an unselected edge e whose endpoints are already joined in I, go to every selected edge on the unique forest path joining them. A loop has no such neighbor. An unselected edge joining different I-components is a target. From each selected edge go to every unselected edge of its color.

If no target is reached, let X be the reached edge set. Its graphic rank equals the number of selected edges in X: each reached unselected edge is a loop or closes a path of reached selected edges. Every edge outside X has a color represented by a selected edge outside X, since unrepresented colors start the search and a reached representative reaches its entire color. Thus any rainbow forest takes at most |I∩X| edges inside X and |I minus X| outside. I is already maximum.

Otherwise a shortest path has alternating form e0,f0,e1,…,f(l−1),el, with e's unselected and f's selected. The color of e0 is new and e(i+1) replaces the color of fi. Toggle membership of the path; the resulting set is rainbow and grows by one. To see its connectivity, first add el to the forest (joining distinct components). For i=l−1 down to 0 exchange fi for ei. The fundamental circuit of ei relative to the original forest contains fi, and contains no fj for j>i because such an exchange arc would shortcut the breadth-first path. All its original forest edges are therefore still present when the exchange is made. Adding ei and deleting fi preserves exactly the current components and preserves forest independence. The final forest spans all old connections. Iteration until every gate color is represented is guaranteed by the hypothesized full forest.

## Recognition and witness

For a supplied physical baseline S of k circuits on n gates, run the chord dynamic program. Whenever it finds a B with k+n circuits, toggling back to S is a known full forest completion: all n transpositions must merge, and any cycle of selected edges would violate this in an ordering that processes that cycle first. Therefore **no universal colorful-cycle test is needed**. Use the properly colored path matching from star-transposition-matching.md, augment its rainbow forest as above, and return the full physical mask. If the DP fails for the supplied S, this test gives no rooted answer.

For exact recognition of the existence of a B with some full forest completion, first use a minimum-orbit physical-setting optimizer to obtain S. Indeed, any candidate B with b circuits admitting a full forest completion has minimum physical circuit count exactly b−n: all masks use n swaps and one achieves that bound. Every optimizing physical S thus witnesses that same B as a maximum split of all n sockets pairs from S. Conversely any DP success supplies a reference and a full forest by the preceding paragraph. This is an exact polynomial recognition reduction to the physical minimum-orbit optimizer plus elementary matching computations. The standalone program starts at a supplied baseline; rebase each gate to its inverse three-cycle where necessary if the optimizer selected the other orientation.

For example, on one gate (0,1,2) with baseline successor (2,0,1), a full forest completion exists although a strictly universal reference does not. In the other direction, with gates (0,1,2) and (3,4,5) and baseline successor (3,4,5,0,2,1), the minimum baseline has two circuits. Each gate's only available same-circle chord is forced, and the two chords alternate. No attainable forest reference exists in that example.

The executable attainable_forest_reference.py imports the matching and chord routines from strict_forest_reference.py. Its replay exhausts the independent subsets on 350 seeded colored multigraphs to verify every augmentation, and compares the recognized native root decisions with exhaustive masks on 1,500 seeded instances.
