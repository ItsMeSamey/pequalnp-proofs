# Conditioning the canonical deficient core

Fix an artificial opposite-parity reference B as in attainable-forest-reference.md. For a subset J of gates, let E(J) consist of both transposition options as edges between baseline cycles, and let r denote graphic rank, counting parallel edges and loops in the usual graphic matroid. Write d(J)=|J|−r(E(J)). The unique inclusion-minimal maximizer K of d can be found in polynomial time. For any gate set U the maximum d(J) over its subsets equals |U| minus the maximum size of a rainbow forest on U by Rado's min-max theorem. Compute this value on all gates and after deletion of each individual gate. The gates whose deletion strictly decreases it constitute K: the maxima are closed under intersections since d is supermodular, so K is itself a maximum.

Contract all edges E(K). For each set J of outside gates its rank in the contracted graphic matroid is r(E(K)∪E(J))−r(E(K))≥|J| by maximality. Therefore the contracted multigraph has a full rainbow forest of all outside gates. Compute one by matroid intersection. For every assignment to K, take the actual pinned reference obtained by performing the chosen core transpositions in B. All resulting baseline cycles stay inside individual components of E(K). Thus the outside option graph on the pinned-reference cycles refines the contracted multigraph, with the same indexed edges. A forest in the latter is also a forest in the former: any cycle would map to a nonempty closed trail of distinct indexed edges. This includes loops and parallel pairs.

On each of the 2^|K| settings recompute the actual baseline cycle of each marked wire, find a properly colored path in the pinned reference, and extend it by closure-preserving rainbow forest augmentation as in attainable-forest-reference.md. Every accepted branch supplies a genuine physical setting extending its pins, and any successful setting is included in an accepted branch. The running time is 2^|K| times a polynomial. The reasoning applies to any explicitly chosen gate set whose contraction admits the outside full forest. The contracted cycle labels alone need not decide the rooted query.

The support size |K| can grow at deficiency one. Take a cycle of n≥3 baseline vertices and give each edge its own gate, with both its alternatives parallel to that edge. A native reference realizes this by placing the gate's shared socket at one endpoint and both alternatives' other sockets at the opposite endpoint, ordering the sockets of each vertex in any cyclic order. The two physical modes differ by a three-cycle; relabeling the triple gives the standard gate. Every proper set of colors has full rank, and all n colors have rank n−1. This demonstrates the distinction for a fixed supplied reference.
