# Product criterion for universal two-root simulation

Write A~B when two nonempty open response tables give the same existential two-closure-wire answers for every cap and every pair of distinct closure wires. By three-track-cap-profiles.md this is equivalent, at arbitrary arity, to preserving all two-root decisions of exteriors with the marks outside the patch. It is sufficient to fix an exterior setting and use the induced return paths; arbitrary exterior feedback and detached trajectories are allowed.

Suppose a target table C preserves a given partition of the channels, after output names are normalized. Its marginal tables are C_i. An independently controlled native three-switch tangle with table T can be equivalent to C only if C~product_i C_i. Indeed, for any two names in different blocks the unpermuted return never joins them under C. Thus every h in T preserves every block (a cycle crossing blocks would violate a pair test). Native-block-factorization.md gives T=product_i T_i. For each block, cap all other blocks internally and query marks only in that block; equivalence yields T_i~C_i. Replacing these marginals one at a time in the product then gives T~product_i C_i. Conversely if C~product_i C_i and each C_i admits an independent native simulation up to exterior two-root equivalence, disjointly assembling those simulations works for C. This equivalence reduces the problem to marginal simulation plus a test on the explicit target; it does not decide arbitrary hidden network marginals.

**Binary correlations are entirely visible.** Fix pairwise disjoint nontrivial cycles γ_1,…,γ_r. For any nonempty code W⊆{0,1}^r, let its table consist exactly of the permutations product_i γ_i^{w_i} with w∈W. Unused channels remain fixed. Every table equivalent to this table is identical to it. In fact any extraneous permutation satisfying every negative test on at most three names must preserve the cycle blocks and select either identity or γ_i in each block. To see this, compare the projected possible traces on those names to the two-point set consisting of identity and the trace of the product of all γ_i. The pair/triple portion of binary-table-four-name-rigidity.md gives the claim, without imposing correlations across different cycles.

Each binary word w, allowed or forbidden, can be uniquely isolated within this product cube by one rooted test. Choose two distinct names x_i,y_i on cycle i, closing every unchosen name by identity. On these 2r remaining names the two modes become off or the transposition (x_i y_i). Define a base cap k fixing x_1 and y_r and swapping y_i with x_{i+1} for 1≤i<r. Its r+1 baseline circles form a path joined by the r possible transpositions. For any subset of active bands the active subgraph is a forest, and its permutation merges precisely the circles in its components. Thus x_1,y_r join exactly when all r bands are active. Precompose the cap on its input side by the product of swaps for coordinates where w_i=0, i.e. use k times that product as the return permutation on the selected names. The tested word now joins exactly for w. This works also with r=1; r=0 has only the identity. Applying the same construction to only d coordinates isolates the corresponding partial assignment, irrespective of the other coordinates. In particular a violated width-d forbidden pattern can be exhibited on 2d names. Combining these separators with the small probes excludes all extra permutations and detects every missing word.

Therefore for such tables an independent native simulation preserving every exterior rooted decision requires W equal to the product of its unary marginals. Conversely for cycles of length two or three every product of individually allowed modes is native: identity or a fixed permutation is a wire arrangement, a three-cycle is the ordinary native optional rotation, and an optional transposition results from feeding back the third channel of a native optional rotation to itself. For a freely varying single cycle of length greater than three, adjacent masks between its two required responses would have to change more than three external paths, impossibly. This classifies the simulation of every explicit correlated-cycle code in this exterior model. The result permits arbitrary internal feedback and hidden wires; instance-dependent encodings outside the universal-exterior model require a separate argument.
