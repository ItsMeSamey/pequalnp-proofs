# Native block factorization with unrestricted feedback

Consider independent optional three-cycle switches in a finite open network, with arbitrary fixed wiring and internal feedback. At a fixed setting each external input follows a simple directed path to one external output: matched incoming and outgoing sockets preclude entry into a closed circuit or a repeated socket. Different inputs use disjoint socket paths. Suppose every setting maps each input block onto the corresponding fixed output block. Then the entire attainable permutation table is the Cartesian product of its marginal tables on these blocks, of arbitrary sizes.

Given a baseline mask x and a mask z yielding a desired permutation on a single block B, start at z. Revert a switch differing from x whenever doing so preserves the B permutation. Restart the scan on success. After at most n reversions and O(n^2) direct traces, the current mask y still attains the target on B, and each of its remaining differences from x is pivotal for B.

Each such gate meets the y-paths of at least two different B inputs. Paths avoiding it persist after a single toggle, and two permutations between the same blocks cannot differ in exactly one image. If the gate also met a non-B external path, three distinct external paths would therefore use all three incoming sockets, one visit per path. Cutting the three matched transitions leaves three upstream prefixes and three suffixes that never return to any socket of this gate. Replacing the three transitions cyclically permutes the output suffixes, since the two allowed local bijections differ by a three-cycle. This transfers a B input to a non-B output, contradicting block preservation. If the third socket belongs to a detached cycle or a second visit of a B path, no foreign external path can meet the gate. These cases exhaust the three sockets.

Therefore none of the differing gates meets any non-B path at y. Restoring all remaining differences simultaneously preserves those entire paths: every one of their transitions is unchanged. This restoration gives x, so y combines the desired B permutation with x on every other block. Iterating over blocks constructs a full target tuple in polynomial time given one marginal witness mask per requested block; containment in the product is immediate.

For any explicit native table, normalize by a baseline permutation and take the orbits of the group generated by the resulting permutations. The theorem shows the table factors on these orbits even if the partition was not supplied initially. If the weaker promise says all settings merely permute an unlabeled partition whose blocks have sizes at least two, the induced permutation of blocks is constant. A one-switch flip can change at most three input images, whereas changing the block permutation moves at least two whole blocks, hence at least four input images. Apply connectivity of the setting cube.

This does not solve the marginal problem itself. Cutting both marked wires of an arbitrary closed network gives a single two-track block, where a swap is attainable exactly if the two marks could be joined. Conversely, cap a promised block-preserving open network by closing each channel to its equally named input after identifying the input/output blocks. The two closure wires of a two-track block join exactly on a swap there; crossing that block's closure tests identity instead. Thus one can solve arbitrary such marginal queries given a native rooted-join oracle, while the one-block case contains the original problem.

The all-settings hypothesis is essential; postselected masks and tied controls do not obey the single independent reversion argument. The result extends the prior acyclic rail-closure obstruction to all internal feedback and detached circuits, while leaving decision-only encodings outside its scope.
