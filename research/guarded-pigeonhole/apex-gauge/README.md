# All linear score changes preserving the selected-apex branch

Let v be the selected apex, H=G−v its core, and N its neighbors. Call x active if selecting x together with v gives an induced even-degree subgraph. For each component C of H meeting N put r_C=1_{N∩C}. The span of all active core indicators is exactly the common kernel of the r_C. This assertion holds for every finite simple undirected G.

Sum the core guards within a component C. Each core edge cancels twice, leaving r_C·x=0. The zero core support is active, as is the singleton at every nonneighbor. On the neighbors in C make an auxiliary graph by joining two whenever a path between them avoids all other neighbors internally. It is connected by splitting any path between two neighbors at its intermediate neighbors. A shortest admissible path has no chord. Together with v it is a chordless cycle and therefore gives an active indicator. Add the singletons on its interior to obtain the endpoint pair in the span. Such pairs on a connected graph span the even-weight subspace on the neighbors. Different components are disjoint. This proves equality and constructs an active basis in polynomial time.

Consequently all additive linear score re-encodings which preserve each individual active score have exactly the form L′=L+Σ h_C r_C, for arbitrary r-bit vectors h_C. An affine recoding preserving the score of the empty core must have zero added constant as well. A common output translation may equivalently be absorbed into the target. This assertion concerns scores on every active support; other selective or nonlinear recodings are outside it.

## Polynomial test of all gauges with two split terminals

Assume H bipartite. First test the original branch with v absent. On the selected branch let s be the required core score. Split v into opposite terminals with a private length-three path as described in ../mixed/apex_mux/README.md. For each of the four terminal sectors write U_j for the possible core scores. In all four sectors the required core guards are independent between connected components. A single selected terminal has zero required external flow in every component by summing the guards. When both are selected the two external flows equal one another in each component, and the private path can supply either common total flow. Thus the global U_j is a sumset of the local U_j.

For each component and each gauge h_C find its bare U_00 by the homogeneous bipartite r-marker oracle, with constant many queries at fixed r. Discard this gauge if U_00 is full, since no final global score can then be isolated. Otherwise choose a bare hole and translate the score of one terminal into it with the other deleted to learn each local mixed range U_01,U_10. Form the three lower-range sumsets by dynamic programming over components, retaining a representative gauge for each of at most 2^(3·2^r) mask triples. For each resulting triple and target s, check for p outside U_01 and q outside U_10 with s+p+q outside U_00. This condition is necessary and sufficient for some assignment of the two terminal score vectors to isolate s from the three lower sectors. If one passes, use the representative gauges and terminal labels in a final ordinary r-marker bipartite query. All active scores survive the gauge, so the answer is exact. If every triple fails, this isolation procedure returns inconclusive. Its running time is polynomial at fixed r even for unboundedly many components, assuming the corresponding fixed-r bipartite oracle.

On the fixed-core-label counterexample in ../mixed/apex_mux/README.md the common neighbor gauge h=2 restores the isolation condition and decides both instances. The gauge-complete procedure still has counterexamples. obstruction.py directly enumerates two connected seven-vertex cores with an eighth apex. The degree-four YES example has bare image missing 7 but every score active. In the degree-five NO example all scores except the required 1 are active. Its original bare image excludes the original target 5. For each example all eight gauges have an empty set of isolatable active scores, not just an unavailable target. This also rules out obtaining a score exclusive to an active realization by changing to any homogeneous two-terminal private gadget with arbitrary private labels: restrict its active selection to either shore or the empty set, and apply the same masking identity as in the two-terminal theorem. It does not assert indistinguishability between these two new instances or exclude adaptive oracle queries on changed core graphs.

## Retaining an apex on one shore

As a separate sufficient reduction, seek corrections D to the core biadjacency C and a new left-neighbor vector a′ for the retained apex, which lies on the right in the new bipartite graph. On the active marker fiber require all left guard differences x_i((Dy)_i+a_i+a′_i) and all right guard differences y_j((Dᵀx)_j+b_j) to vanish identically. Each condition restricts a linear form to an affine fiber with the indexed selector fixed to one. Basepoint and direction evaluations give a linear system. Any solution preserves every individual interior guard, and their sum implies the apex guard in each model. In the core C+D find any unattainable bare score h. Add the retained apex with marker column h+s and request h. The only possible answer uses the apex, and it recovers an original witness without spending a pin. A single Gaussian solution may lack a hole even if other solutions admit one; this is a sufficient application, not general recognition across all possible D. check.py tested 119 hole-forced instances with exhaustive small-graph oracles.

The dynamic program may also search all componentwise bipartition choices. Permit both orders of the two mixed ranges for each component, corresponding to flipping its shores. The state bound is unchanged. Both obstruction cores are connected, so the one possible global swap cannot affect their empty visibility.

A connected nonbipartite degree-four example distinguishes retaining an apex from direct cross-block absorption. With three vertices per shore, take core rows C=[5,4,7], packed marker rows L=[36,1,4] (left selectors low), shifts a=7,b=4, active score s=3 and original bare target 3 (zero apex label). The bare graph misses 3 but the active branch attains it. No direct D absorbs both shifts identically. Retaining the apex works with D=[4,0,0], new left neighborhood 2 and bare hole h=4. strict.py deterministically finds this example.
