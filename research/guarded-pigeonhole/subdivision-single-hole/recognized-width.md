# Finding a layout and the exact SAT control

For a specified partition of the columns of A that keeps pairs local, use the indexed subspaces span(A_B), one per block B. The branch width of this F2 subspace arrangement is precisely the minimum flux width h of a tree on those blocks. Jeong, Kim and Oum give an exact fixed-parameter algorithm that returns a width-k tree or certifies that none exists, for fixed finite field. Apply their algorithm, then the quadratic-blocks counting DP. Distinct blocks remain separate indices even when they span the same subspace. Trivial one-block layouts can be handled directly. [Primary algorithm](https://doi.org/10.1137/19M1285895)

In particular the partition into each forbidden pair plus singleton unpaired columns is canonical; leaf tables in this case can be found by checking at most four bit patterns. Neither recognizing nor exploiting bounded pair-atomic flux width requires a supplied tree.

For the direct ternary SAT parity interface let each occurrence be an atomic pair. The column matroid of the variable's path-difference constraints is a circuit on its occurrences (the singleton case is a loop), and the columns of each odd-witness parity constraint are parallel. These blocks have disjoint row supports. A cut of the occurrence leaves has flux dimension equal to the sum of the contributions of these constituent matroids. A split of the items of a single circuit contributes one by the rank formula, as does a split of a nonempty parallel class; an unsplit constituent contributes zero. Therefore the cut width equals the number of source variables and clauses with occurrences on both sides. The optimum over occurrence-leaf trees equals the usual edge-branch width (maximum middle-set size convention) of the source bipartite variable–clause incidence multigraph. This remains true for repetitions, singleton variables and disconnected formulas. Strict ternary clauses on three distinct variables also have global residual quadratic rank exactly 3m, since the three rows at j have squarefree parts x_a u_j, x_b v_j, x_c(u_j+v_j), are independent at j, and use private u_j,v_j for different clauses.

The equivalence controls both strengths and limits. With bounded incidence branchwidth, strict ternary families have bounded recognizable atomic width despite unbounded global residual rank. General strict ternary instances have unbounded width, e.g. for each edge uv of a grid use a clause (x_u,x_v,y_uv) with private y_uv. The grid is a minor of the incidence graph, via the clause subdivision and deletion of leaves. This example establishes width, without asserting hardness of those particular formulas. The recognition theorem takes the block partition as input and does not optimize jointly over arbitrary coarsenings whose flux-conditioned quadratic ranks are small.
