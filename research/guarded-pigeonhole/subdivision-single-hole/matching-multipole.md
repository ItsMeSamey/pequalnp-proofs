# Fixed boundary colors on a cubic bipartite multipole

Count halfedges with multiplicity. At each vertex insist that its prescribed halfedges have distinct colors. For each color c let A_c and B_c be the counts of its halfedges on the two shores. Every extension requires A_c−B_c=|A|−|B| because each internal edge of that color covers one vertex on each shore.

Choose a base color c and find a perfect matching of the internal graph after removing all vertices carrying a c halfedge. Absence of this matching proves nonextension. Color its edges c. Each original vertex now has exactly two uncolored incidences, including the prescribed non-c halfedges. The residual graph comprises even internal cycles and paths terminating in boundary halfedges. Alternate the two other colors on each component. On a residual path, let s indicate the endpoint shore, and let t distinguish the two other boundary colors. Its ends are compatible exactly if their values of s XOR t differ: the intervening internal path has even length when the holders are on the same shore, and the edge sequence includes both terminal incidences. This includes a path consisting only of two halfedges at one vertex. Reconstruction propagates from one fixed endpoint; a cycle can start with either color.

The balance equations for the two non-c colors imply equal numbers of the two transformed terminal types. With zero or two such terminals, every matching therefore extends. If k≤5, the three color counts all have the same parity as |A|−|B| and hence as k. The only possible count profiles up to permutation are (0,0,0), (2,0,0), (1,1,1), (4,0,0), (2,2,0), and (3,1,1). In every case choose a most frequent color and at most two terminals remain.

At any width, if the transformed types alternate in cyclic order on a disk boundary, every matching extends. Residual paths induce a noncrossing pairing of terminals. The terminals strictly between any paired endpoints on either boundary arc pair internally, so their number is even. Paired endpoints are in opposite cyclic parity classes. The program verifies a facial rotation before applying this criterion: attach separate terminal vertices and a rim in the proposed order, add a hub behind the rim, run a planarity test, remove the hub from the obtained rotation, and require that the rim bounds a face. Suppressing parallel internal edges for the embedding test is safe because their copies can be restored alongside each other. If the returned embedding does not certify the order, the disk shortcut is skipped. A positive coloring is always explicitly verified. Outside these cases unsuccessful arbitrary matching extensions alone can return UNKNOWN.

Six terminals suffice for a failure of arbitrary matching choice. Start with the cycle 0,1,2,3 and append edges 0–4 and 1–5. The boundary vertices and colors in order are (4,4,5,5,2,3) and (0,1,0,2,1,2). The balance tests pass and every color occurs twice. For base zero the matching {01,23} extends, but {12,30} does not. This example distinguishes a failed matching from failure of the prescribed pattern.

The checker compares all port assignments against direct edge-color enumeration for the 16 connected simple bipartite internal graphs of maximum degree three in the graph atlas (up to seven vertices) with at most five halfedges. It also checks all 729 patterns on the six-terminal example, parallel-edge multiplicities one through three, and 106 balanced alternating patterns with at least four non-base terminals on an eight-cycle.

A six-cycle gives a second obstruction. Attach one terminal at each vertex and prescribe colors 3,3,2,2,1,1 in cyclic order. The shores balance for every color. Each color separately admits a unique required matching, but the matchings for colors 1 and 2 both use edge (0,1). The prescribed boundary has no extension.
