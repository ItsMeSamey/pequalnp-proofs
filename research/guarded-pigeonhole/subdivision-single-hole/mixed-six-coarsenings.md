# Red matching tests and the mixed six-port parity constraint

The three A ports and three B ports are ordered separately in a bipartite cubic multipole. Feasible boundary words have equal color histograms on A and B. A rainbow up to palette permutation is a bijection from the A ports to the B ports. For each pair i,j, let h_ij be the two-color word with the two minority entries at A_i and B_j. This word is polynomially testable by fixing its majority matching, leaving only one terminal path. Two rainbow permutations contain i→j; they differ by a transposition.

Fix red at A_i and B_j and reserve all other ports from red. Any red matching leaves four residual tips. If both residual terminal paths run between opposite shores, each such pair must have the same color; this realizes h_ij and the rainbow joining the same two pairs. If both paths run within shores, the two ends of each path must have different colors, yielding both rainbow bijections. In each case the internal residual cycles admit alternating colorings. Thus every feasible red matching realizes exactly two of the triple consisting of h_ij and the two rainbows. If h_ij is absent, testing for a red matching decides both rainbow entries and the same matching provides either witness. If h_ij exists, at least one of those rainbow entries exists. When all nine coarsenings exist, the missing permutations form an independent set of the transposition graph of S3, which is K3,3; thus they have the same parity.

For connected bridgeless internal graphs a missing h_ij produces a 2-edge cut having three original terminals on each side. Delete the two A and two B holders of the majority ports and try to cover all remaining vertices with a matching. The degree assumptions make the holders on a shore distinct. For any violating set S among the surviving B vertices, put d=|N(S)|-|S| using the original neighborhood and let a be the number of deleted A holders in it. Then d<a≤2. Let t_A be the number of original tips in N(S), t_B the number in S, and let C=S∪N(S). Its ordinary cut size is 3d+t_B−t_A. Here t_B≤1 and t_A≥a, while C is nonempty and proper (the two deleted B vertices lie outside C). Bridgelessness gives cut size at least two, forcing d=1, t_B=1, t_A=2 and cut size two. Cutting yields two multipoles each with five tips. Enumerating the nine assignments of the two interface colors and solving both subinstances decides any prescribed original rainbow and reconstructs it. Failure to find a majority matching is equivalent to h_ij being absent because there are only two tips left and they require the same color on opposite shores.

All nine minority coarsenings can be present while any one designated parity class of three rainbows is absent: the theta example in six-port-theta realizes exactly twelve palette orbits. Another small planar block in six-port-five-rainbows realizes exactly one missing rainbow with all nine coarsenings. Neither example requires all its tips to occur on one face.
