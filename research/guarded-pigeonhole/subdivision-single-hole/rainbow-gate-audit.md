# Equal-arity deterministic-sign rainbow interfaces

Take a finite cubic edge-coloring network with exactly m ordered input triples and m ordered output triples, and no other terminals. Edge-color prescriptions, if any, name just one common color. Write τ for the swap of the other two colors (choose any two when there are no prescriptions). A triple is rainbow when all three colors occur; its sign is the parity of its ordered color permutation with respect to a fixed palette order.

Assume every valid coloring with rainbow inputs has rainbow outputs, and any two such colorings with identical named input colors give identical output signs. Start from any valid coloring with rainbow inputs. The subgraph in the two swapped colors consists of disjoint even cycles and paths pairing their terminals. All switches on these components preserve every pin.

There is no path with both endpoints on the output. Switching one whose endpoints lie in different triples would spoil both rainbows. Switching one whose endpoints lie in the same triple would keep its rainbow but reverse its sign, without changing an input. Each side has exactly 2m endpoints; hence every terminal path has one input and one output endpoint.

For input i switch both paths starting there. This keeps all inputs rainbow and applies τ to precisely that input triple. Output rainbow preservation implies both paths end in the same output triple π(i). They use its two swapped-color tips, so π is a permutation. These two-path families are disjoint for distinct inputs. For any subset of inputs, switch their path families simultaneously in the original coloring. This realizes the entire input τ-cube and swaps exactly the corresponding output triples. In bit notation the output sign vector on that cube is its base value plus the coordinate permutation π applied to the input sign changes. The simultaneous construction does not require a priori surjectivity of the network.

Thus if the intended gate is a function of input signs alone and has any valid rainbow input, its action on the entire sign cube is an affine coordinate permutation. Both CNOT and nonlinear reversible gates are excluded. Under determinism only at identical raw input tuples, π and the offset may vary between τ-cubes; no assertion of one global raw-tuple permutation follows. Conditional acceptance with postselection that removes a switched coloring, pins of multiple colors, extra terminals, or unequal arities are not covered.
