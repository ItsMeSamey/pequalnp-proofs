# Rainbow gates with arbitrary prescribed edge colors

Let a cubic network have precisely m ordered input triples and k ordered output triples of boundary ends. Each prescribed pin fixes an edge color, possibly on a boundary edge. Every pin-respecting coloring with rainbow inputs must have rainbow outputs, with their signs determined by the raw input tuple. Fix a transposition of two colors. Let p count pinned edges prescribed either moving color, and put l=m−k.

In any witness, the subgraph of the two moving colors consists of paths and cycles. A component is blocked if it contains a pin on a moving color. At most p components are blocked. Let o count output–output paths. Each must be blocked: switching one would leave inputs fixed and either spoil two output rainbows or reverse the sign of a single output. There are 2k output ends and 2m input ends in this subgraph, so the number of input–input paths is l+o. Mark each input bundle incident with an input–input path or a blocked input–output path. The number marked is at most

    2(l+o)+(p−o) = 2l+p+o ≤ 2(l+p).

Each unmarked bundle has two distinct unblocked input–output paths. Switching both preserves its input rainbow. Since every resulting output must still be rainbow, both output ends lie on a single output bundle. Distinct unmarked inputs therefore use distinct outputs. All these paths are disjoint, so any combination of the paired switches realizes the corresponding input transpositions and exactly the matched output transpositions. Output signs on this subcube are thus distinct copies of the varying input bits, each optionally complemented, together with constants. The statement concerns the chosen orbit of raw input tuples. For a function depending only on signs, it gives a subcube of the sign domain at each attained point.

If every input sign vector is attained and the output signs define a function of those signs, set b=min(m,2(l+p)). Each output bit has certificates of size at most min(m,b+1): fix the marked coordinates at the input under consideration and, if needed, its one copied coordinate. For a nonconstant total Boolean function g the deterministic decision-tree depth is at most C0(g)C1(g). Indeed, query a 1-certificate of an extension of the current restriction. If the answers fail to certify 1, every consistent 0-input has a 0-certificate that conflicts with the queried 1-certificate, reducing its residual size by at least one. Iteration uses at most C0 rounds of at most C1 queries. A depth-D binary tree queries at most 2^D−1 distinct variables. Each output thus depends on at most min(m,2^((b+1)^2)−1) inputs. Constant outputs require none. The bound is per output; partial functions receive only the local subcube conclusion.
