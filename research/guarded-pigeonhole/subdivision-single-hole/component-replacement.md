# Target-specific clause-component replacement

Decode a target into signed active clauses by assigning an arbitrary reference polarity per variable, following its occurrence path differences, and retaining clauses of witness parity one. An occurrence can supply its clause's witness exactly when its signed literal is true, so existential satisfiability agrees. Simplify repeated literals and tautologies, assign pure variables in their satisfying direction, and delete satisfied clauses.

Build a multigraph whose vertices are the remaining clauses and whose edges are the variables with precisely two occurrences of opposite signs. Each such variable can choose exactly one endpoint to satisfy. Residual literals stay attached to the clauses. For any fixed residual assignment, an entire connected component containing a cycle can satisfy every clause: orient a cycle consistently, extend outward along a spanning forest, and set each variable to satisfy the receiving endpoint. Parallel edges form a valid cycle of length two. For a tree component, its edges cover all clause vertices except any designated root using the same outward construction. They can never cover all vertices because the tree has one fewer edge than vertices. Hence existential elimination of all its edge variables produces precisely the disjunction of its residual literals. This may be an empty clause, a tautology, or an ordinary clause of any width. The replacement preserves the complete relation on residual assignments and yields an explicit reconstructed edge assignment from a satisfying root. Iterate until no change; each nontrivial replacement deletes a variable or a clause. The compressed CNF can again be represented by matching guards using one pair per occurrence, path differences per variable, and a witness parity per clause.

In particular the strict one-hole family collapses: all deepest fresh split variables appear in two opposite clauses; resolving those literal-copy halves recovers their parent clause after deduplication. Repeat inward then eliminate the variable edges of the terminal implication tree, producing an empty clause. More generally all instances with at most b variables appearing at least three times after simplification admit a 2^b poly(input) algorithm by branching on these variables and orienting the residual clause graph. This is a degree-two variable elimination rule, not a general SAT algorithm.
