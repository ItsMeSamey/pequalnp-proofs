# Bounded-occurrence obstruction on both satisfiable and unsatisfiable inputs

Let F be a connected bounded-occurrence strict ternary SAT formula on n variables. Create n+1 independent gated copies and require their selector bits to have OR one. For every clause (a OR b OR c) in copy i, use a fresh w and the two strict clauses

    (not s_i OR a OR w),    (not w OR b OR c).

With selector zero, w=0 satisfies both clauses for any original truth assignment. With selector one their existential projection is the source clause. Use a binary tree of OR equivalences and require its root true. Each OR equivalence has one ternary clause and two binary clauses. Replace each binary clause C by C OR z and C OR not-z with a fresh z; apply this twice to pad the root unit. Distribute each selector by separate occurrence copies linked along a path by binary equalities, padded in the same manner. Each copy of a selector serves one use in addition to at most two path links. This gives strict ternary clauses and a constant occurrence bound. The construction uses polynomial size and preserves satisfiability in both directions.

Attach the positive grid from grid-obstruction.md, with L=n+2, by a strict clause (v OR u OR z) on a grid variable v, a control variable u and a fresh z. The attachment is extendible at every selector choice, for example by z=true. The result is connected. Optionally add the private four-clause parity gadget of grid-obstruction.md to each variable in the construction, using two fresh private variables per gadget. This preserves strictness and bounded occurrence and ensures both signs and the neighborhood-expansion bound there. For counting split vertices below, charge each gadget of a variable internal to a gated copy to that copy; gadgets of control variables are control-only.

Fix a tree on the native occurrence pairs of flux at most h. For sufficiently large n relative to h, grid-obstruction.md gives a leaf B containing all but O((h+1)^2) grid occurrences; the touched grid clauses alone give Hall deficiency Ω(L²). Mark a copy if any of its internal variables or clauses is split by B. Internal objects include the original copied variables and w variables, the two clauses per source clause and, if present, the private gadget variables and clauses on internal variables. Selector clones and their private gadgets are control objects. At most h copies are marked. Choose an unmarked copy j and set precisely its selector to one. Freeze the control truth bits, their private gadget bits and their clause witnesses to satisfying choices. Freeze all inactive copies and their gadgets to satisfying choices as well.

Choose a global assignment of parity data (a truth bit per variable and an odd-parity witness triple per clause) to specify a linearly possible B-flux. The control/inactive values can be as just described. Choose all grid variables true, one witness outside B for each split grid clause, satisfying choices for its external gadgets, and a witness on z for the attachment. Active-copy truth bits can be arbitrary; for each first gate clause take an odd witness assignment with the false selector's witness zero. All these are compatible with the linear parity system even if they violate guards at unsplit active clauses. Prescribe the resulting B-flux only: fully internal truth/witness directions remain free.

Each active gate clause touching B is full. Each active internal variable touching B is full. Restrict its first gate clauses to have selector witness zero, so the other two witnesses have odd sum and one free direction. The two quadratic rows have nonzero polar parts in distinct variable–clause summands. Each second gate clause and each full internal private gadget clause has three distinct free truth variables and two independent witness directions, again giving a nonzero polar row for each occurrence. No choice presupposes that the active gates are jointly satisfiable. On the grid freeze exceptional variables and their gadgets as in grid-obstruction.md. All zero-polar rows now vanish identically; every other row has its own variable–clause summand and is linearly independent of the rest. Thus there is no affine contradiction, and Ω(L²) intact grid rows remain. The original leaf fiber has residual rank at least this large by monotonicity under restriction to an affinely surviving subspace.

For every fixed set of thresholds, all sufficiently large outputs on either truth value consequently fail the native mixed-layout criterion. Satisfiability on the resulting bounded-occurrence family is NP-hard. A compiler can recognize and remove the padding or use other semantic simplifications; the claim is solely about layouts and affine absorption on the given native encoding.
