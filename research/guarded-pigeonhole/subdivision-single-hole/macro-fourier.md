# Private quadratic leaves and shared Fourier phases

Let y range over affine domain C0. Equation i is a quadratic q_i(y,z_i)=0 with p_i private bits appearing nowhere else. A partition into shared/private variables may be provided or recognized by counting equation incidences. For fixed y its local count is (2^{p_i} plus the private Walsh sum) divided by two. Whenever uv is a private-private term, write q=uv+uL+vR+Q and sum over u,v, replacing the Walsh character by twice the character of Q+LR. Here L,R are affine in the other bits. After t_i such eliminations the other private bits occur only linearly, with affine coefficients on y. Let H_i impose vanishing of all these coefficients, and ψ_i be the remaining shared quadratic. The exact local count is 2^{p_i−1}(1+2^{−t_i}1_Hi(y)(−1)^ψ_i(y)). Empty and universal H_i are allowed. For p_i=0 the factor of one half yields precisely the Boolean zero test.

Multiplying and summing over y yields one Walsh sum per subset S with nonempty C0∩⋂H_i (i in S), weighted by 2^{−Σ t_i} and with phase Σψ_i; the overall multiplier is 2^{Σ(p_i−1)}. A DFS on increasing indices tests at most mK+1 intersections when K subsets survive: never recurse below an inconsistent subfamily. Each affine intersection or quadratic Gauss sum takes polynomial bit time. An overlap bound c (at most c simultaneously active flats) ensures K≤Σ_{j≤c} binom(m,j), readily verified by testing (c+1)-tuples.

Instead collect partial terms by canonical nonempty affine domain C and quadratic function P on C modulo additive constant. Use RREF in a fixed variable order and parameterize by the ordinary free coordinates; the constant, singleton and pair evaluations determine P uniquely. Carry a signed dyadic coefficient, absorbing the sign from the constant. Each next leaf yields a skip state and an include state. For the latter intersect with H_i, restrict P to the resulting domain, add the leaf phase, normalize, and multiply by 2^{-t_i}. Merge identical keys and drop zero. Equality of functions on C persists upon restriction and multiplication by any next factor, so an earlier cancellation is final. Evaluate one Gauss sum per final state with its exact weight. Running time is polynomial(input) times one plus the sum of the live state counts across all prefixes, including dictionary overhead. The final state count alone does not bound intermediate work. All prefix weights have common denominator dividing 2^{Σt_i}, with numerator using ≤m+Σt_i+O(1) bits. The Walsh magnitude, overall normalization and integer final answer add at most polynomially many bits.

For an unsigned positive count, restrict every terminal state to successive shared-bit pins and reevaluate; no new expansion is needed. Once y has been recovered, solve each private polynomial independently. If its origin fails but a private solution exists, some unit or sum of two units succeeds, since a Boolean quadratic agreeing with its constant on all those inputs is constant. Verify the original assignment. Signed sums cannot support this positivity inference.

For example use q_i=g_i(x)+Σ_j (y_j+a_ij)z_ij, with a distinct address a_i for each i. Then H_i are disjoint, so K≤m+1 even if all g_i on shared x are independent arbitrary quadratics.

In the opposite direction encode 3-coloring of a simple connected graph with an edge. Two shared bits x_v,y_v per vertex and x_v y_v=0 make the indicators x_v,y_v,1+x_v+y_v one-hot. Each edge uv forbids the product of like indicators via three equations. Solutions correspond bijectively to proper 3-colorings. Every bit appears in multiple equations, so the occurrence-defined private set is empty. All H_i are universal. The n+3m polar rows are independent: the cross term x_u y_v identifies the third edge row; then x_u x_v and y_u y_v identify its remaining two rows, and x_v y_v identifies each vertex row. Thus no nontrivial linear combination of the input polynomials is affine. This statement concerns algebraic combinations, not all semantic affine consequences. The common polar radical is zero by the vertex rows. All 2^{n+3m} subsets induce distinct phases modulo constants; they persist with nonzero weights for every processing order. This supplies an NP-hard high-state family with both YES and NO graphs. It tests this particular representation, not every possible compiler.
