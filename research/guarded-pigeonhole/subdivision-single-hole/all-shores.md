# Output-sensitive enumeration of all width-bounded pair-respecting shores

Represent a binary column matroid by a matrix [I|D] in a chosen basis. Let F be the symmetric adjacency matrix of its bipartite fundamental graph (basis vs nonbasis, off-diagonal block D). For a shore S, rank F[S,complement] equals the flux dimension. Indeed the two offdiagonal crossing blocks contribute rank(D[basis in S, nonbasis outside])+rank(D[basis outside, nonbasis in S]); applying Gaussian elimination to the identity columns shows this is rank(A_S)+rank(A_out)−rank(A). Loops and parallel columns require no exception.

For each j≤h choose ordered anchor subsets U,V of size j with U disjoint from V and M=F[U,V] invertible. Force U inside and V outside. The cutrank is j exactly when for every crossing i inside and l outside, F[i,l]=F[i,V] M^{-1} F[U,l]. This is the Schur-complement rank criterion, and every rank-j cut has such an anchor. For j=0 the right side is zero. For every ordered pair violating the identity add the implication i inside implies l inside. Append both implications for every inseparable coordinate pair. Enumerate all Boolean assignments of this implication graph with the forced anchor bits: branch on any remaining vertex, propagate true forward and false backward, prune contradictory branches. A consistent partial assignment closed under both propagations is extendible (set all unassigned vertices false), so delay is polynomial. Deduplicate over anchor choices. Written using canonical subset ordering, enumeration time n^{O(h)}(K+1)poly(n) for K actual distinct shores, and storage polynomial in n and K. Complements and empty/full shores are included.

For arbitrary deterministic polytime leaf qualification, compute feasibility in increasing shore size: a nonempty shore may stop as a qualifying bag, or split as disjoint nonempty accepted shores with this union. The root is the whole set. Pair inseparability holds by construction and every nonroot edge of any admissible layout necessarily corresponds to an enumerated shore. This decides existence over all coarse partitions, with witness reconstruction; it does not assume a tree. Leaf qualification can for example enumerate at most 2^h globally linear fluxes and check post-absorption ranks or certified triangle deficiency. If the qualification is statewise instead, hold tables with exhaustive exact fluxes and interpret acceptance as a state-dependent strategy, not a single common layout. A common layout is chosen once per shore for the uniform qualification. K can be exponential already for rank-one parallel columns. Thus this is output-sensitive and does not by itself bound running time by a function of h times poly(n).

## Complete polynomial recognition for fixed-width bounded-occurrence SAT

In the direct matching-guard SAT encoding a pair-atomic shore is an occurrence-edge shore of the variable–clause incidence multigraph; its flux is the size of the middle set (all split vertices). For a connected incidence graph of maximum degree Δ one can enumerate every shore of flux at most h in n^{O(h)}2^{O(hΔ)} time. For each set X of at most h incidence vertices, enumerate a bit per component of G minus X and per edge internal to X. Assign each other edge the common side of its non-X endpoints' component. Every shore whose middle set is contained in X appears, and every assignment has middle set contained in X. Deleting X leaves at most 1+hΔ components, and there are at most hΔ/2 internal edges counted with multiplicity. Deduplicate. Treat disconnected formula components independently for the counting/decision algorithm (the preceding connected bound is for enumeration of the full shore catalog). The independent enumeration parameter is not the number of candidate subsets of clauses.

Using the preceding bottom-up DP, this exactly recognizes existence of ANY pair-respecting coarse tree with the prescribed flux width and statewise-all-fibers leaf-rank, or mixed deterministic qualification, on connected bounded-occurrence sources. Complete tree reconstruction and uniform-layout testing cost n^{O(h)}2^{O(hΔ)} times polynomial per-leaf criterion with 2^h flux states. For fixed Δ and h this is polynomial on the entire input domain, although a suitable layout need not exist. If a leaf oracle uses a fixed deficiency bound d, its separate randomized witness runtime has additional N^{O(d)} overhead. Thus an NP-hard domain for SAT can have polynomial recognition of this tractability certificate without all instances possessing it.
