# Deterministic root testing with order-sensitive border calibration

Assume k≥2 supplied landmark orbits, exactly one landmark on each orbit for all masks. Work in the untied component of the two roots; if different, return negative. Obtain a safe superset S of attainable ordered DISTINCT pairs of root classes: i must be attainable by the first root and j by the second, and the unordered pair {i,j} must be jointly attainable. Each single-root class test uses the one-tour cap on the root plus all landmarks except the candidate class. Each unordered test uses the two roots plus the remaining k−2 landmarks. Feasibility of each cap is deterministic by linear delta-matroid parity. Certified tighter supersets may also be used.

Add an isolated dummy orbit. Place k+2 marked cuts along it in cyclic order a*,b*,z1*,...,zk*. Draw k+2 transposition spokes to the corresponding original cut points. Separate coincident physical marks by passive subdivisions. Make all these spokes switched off in the untied reference. To obtain a single reference tour from both components use a further connector, switched on in the reference and off at all evaluated settings. Every selected additional spoke is therefore a mandatory matrix index, as is the extra connector. No physical gate tag touches these indices.

With actual physical switches set and all additional spokes off, the routed network has k+1 orbits. Its binary interlacement section has nullity k by circuit nullity. Labeling the dummy zero identifies its radical with k independent original-orbit bits. Each added spoke restricts to the evaluation at the class of its original mark, by the reference jump formula. Consequently the matrix U of these k+2 restricted columns has rank k. At root classes i,j its kernel has basis x=E_a+E_i, y=E_b+E_j, where the a,b subscripts denote separate root spokes and the integer subscripts denote anchor spokes, even when i=j.

With all spokes on, the coefficient of the bordered Pfaffian is a single binary scalar. Eliminating the nondegenerate part of the base alternating form leaves a matrix with blocks [0 U; U-transpose J]. Its nonsingularity is precisely nonsingularity of J on ker U, i.e. x-transpose J y=1. Changing the physical spoke-spoke block by an arbitrary FIXED alternating matrix H therefore adds the scalar

    H_ab + H_aj + H_ib + H_ij.

For the unmodified physical block at distinct classes i,j the value is 1[i<j]. First the k landmark spokes merge all original cycles into the dummy cycle, splicing each orbit at its own landmark. The resulting cyclic order starts with the two dummy root cuts followed by the inserted orbits in increasing landmark order. Activating the last two root spokes leaves one orbit precisely when the chords cross. Relative order of marks within a single orbit can affect the joined value and is not assumed.

Set H_ab=H_aj=0 and H_ib=r_i. Both oriented constraints on one unordered pair are consistent exactly when r_i+r_j=1. Thus if the graph of pairs with both orientations in S is bipartite, assign r by its bipartition. For each unordered pair with a permitted orientation (i,j), set H_ij=1+1[i<j]+r_i. This gives one on every actual split mask. Form a second correction by toggling r_i for all i and toggling all off-diagonal anchor-anchor H_ij. This preserves every split value while flipping every joined value, since H_ii=0. At least one of the two resulting single-pencil envelope identities fails exactly when there exists a joined mask. Apply the deterministic universality test to each and reconstruct by pinning, tracing the resulting physical setting.

The recognized condition holds in particular when the roots share at most two individually reachable landmark classes. The full attainable unordered graph need not be bipartite for the calibration checks to apply. An odd cycle in the bidirectionally permitted graph rules out correction by this single-star scalar calibration on that permitted set; it establishes no generic algorithmic lower bound. Reference-only and algebraic auxiliary operations need not be implementable as native gates.
