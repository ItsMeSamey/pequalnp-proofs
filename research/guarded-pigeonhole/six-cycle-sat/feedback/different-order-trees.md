# Deterministic comparison on two different factor trees

For each of the two raw, physically aligned pencils use its own supplied tree of binary-index factors. Each virtual index is incident with precisely its two ends, and the associated factor graphs are trees. Every physical gate tag indexes one factor in each tree, with the same gate mask convention in both. Constants at bits with reversed conventions can be accounted for by reversing the two local coefficient slices. Assume all local tensors of at most B physical plus virtual bits are explicitly available (or obtain their 2^B coefficients in polynomial time per entry). Such trees arise by whole-pair rank-two splits, using a binary virtual index to select the unbordered or bordered summand. Real indices are partitioned across splits, never duplicated. Distinct trees need not align. If a previously normalized pencil represents an XOR relabeling of physical masks, undo its bit flips locally before comparing.

Root a factor tree with M vertices. At each vertex visit its largest child subtree FIRST, then visit the vertex itself, then visit each remaining child subtree recursively. This order matters: visiting every vertex before its largest child can leave a linear frontier on a comb. All unfinished siblings outstanding from processed vertices occur on descents into nonlargest (light) child subtrees. Each light descent at least halves subtree size. Each such level contributes at most B frontier edges, plus O(B) locally, so each prefix has O(B(1+log M)) crossing binary indices.

Scan factors in this order. States store the values of all crossing indices. At a factor, retain its incoming values, guess its outgoing values, sum internally over the physical bits, and multiply by its table entry. Unroll the at-most-B physical bits as successive unary matrix layers, storing their partial assignment until the factor value is read. For a zero bit use scalar one and for a one bit multiply by that physical variable; there is one variable layer per physical tag. Constant layers can be contracted into neighboring matrices. This yields a white-box read-once oblivious algebraic branching program (ROABP) of width W≤2^O(B(1+log M)), length polynomial in M and the number m of tags, and individual degree at most one. Constructing explicit matrices costs polynomial time in 2^B,M,m,W. All contractions over F2 can also be done in F4 if needed.

Apply the deterministic white-box identity test for a sum of a constant number of ROABPs in different variable orders to the two compiled programs and the width-one envelope ∏(1+h_i). Gurjar, Korwar, Saxena and Thierauf, section 3, prove the result using coefficient spaces over the underlying field; their later large-field condition concerns their black-box hitting sets. The white-box recurrence has T(c,w)≤nw(d+1)T(c−1,w(w+1))+poly(n,d,w). Here c=3, d=1. Time is polynomial in the explicit width for fixed c, hence (M+m+2)^O(B+1) in this binary-index formulation. It is polynomial for fixed local arity. No common order, common tensor tree, favorable characteristic, or generic deterministic PIT is assumed. [Primary paper](https://arxiv.org/abs/1411.7341)

When the sum is nonzero, choose each physical bit by retesting its two coefficient restrictions, taking a nonzero branch. For a layer A+h_iD use A or D; remove the resulting constant layer. The physical variable may sit at a different place in each program. Width cannot increase and each remaining variable still appears in a single layer. At most m additional zero tests isolate a nonzero coefficient, which is traced on the original network. Equality on one translated face gives the existing coarser comparison application; when the full cap functions admit these tree representations the three-program test applies directly.

The hypothesis concerns an explicitly supplied local factor representation, including construction cost. There is no claim that every physical pencil has bounded local arity or that a useful tree is always found.
