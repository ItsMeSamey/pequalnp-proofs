# Rooted trajectories with involutive forbidden turns

In a closed network of ternary switches, number each switch's input and output sockets cyclically. State 0 sends input i to output i, and state 1 sends it to output i+1. Let F send the wire at input i to the wire at output i−1. Every wire has one input and one output socket, so F is a permutation. When F² is the identity, one can decide in linear time whether specified wires r,s share a trajectory, and construct a setting if they do. Equality of the marks is an immediate positive case.

Use the wires as vertices and the six allowed turns of every switch as directed arcs. Pair the turn u→v with F(v)→F(u). Indeed, for an off turn at i its mate is the on turn at i+1. These are distinct arcs at the same switch even with loops or parallel arcs. Among turns in the opposite state, this mate is the only one sharing neither the original input nor the original output. A wire-simple directed path cannot repeat an input or an output. Consequently its turns prescribe compatible settings exactly when it avoids using both arcs of any pair. A physical trajectory through distinct marks supplies such a simple segment. Conversely one can read off the prescribed states, fill all other switches arbitrarily, and follow the resulting permutation from r to s.

For each fixed wire v split it into two mutually conjugate vertices, in and out. Attach incoming physical turns to in and outgoing ones to out, and add two distinct mutually paired parallel arcs from in to out. All other vertices retain conjugation by F. This produces a skew-symmetric graph with fixed-point-free involutions on vertices and arcs. At a split start use out as R and at a split finish use in as S. A simple physical path lifts using one bridge at each internal split wire. Conversely project a regular walk (one avoiding pairs of mate arcs) by collapsing bridges and loop-erasing repeated wire segments. Remaining physical turns form a simple path and still avoid mate pairs.

To request arbitrary endpoints introduce fresh conjugate vertices a,b. Add a→R paired with R′→b, and S→b paired with a→S′, where primes denote conjugation. Keep the arc identities distinct even for parallel arcs. A regular a→b path must enter and exit through different added pairs, since its entry and the exit of the same pair are mates. Its interior thus gives either R→S or S′→R′. In the second case take the reversed conjugate. Any regular R→S path extends in the forward orientation using the two different added pairs. Project, loop-erase, and reconstruct as above.

Testing the involution, constructing both reductions and recovering the mask take linear time. The resulting graph has linear size. Apply the linear-time regular reachability algorithm of Goldberg and Karzanov for skew-symmetric graphs. [Regular path algorithm](https://doi.org/10.1007/BF01261321) · [Linear-time bound, Theorem 2.2](https://web.eecs.umich.edu/~pettie/matching/Goldberg-Karzanov-max-skew-symmetric-flow.pdf)

The accompanying check_involutive_turns.py compares exhaustive physical-mask tracing to a small exhaustive regular-path search in the augmented graph and checks reconstructed settings. It covers all forbidden involutions on one and two switches and a seeded sample on three. The checker uses enumeration for independent validation.
