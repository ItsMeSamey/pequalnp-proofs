# Closed common-trajectory routing is NP-complete with two occurrences per control

The input consists of fixed reversible feedback, two marked tracks, and optional ordered three-cycles. Each independent Boolean control acts at at most two occurrences. Every occurrence applies its specified rotation when its bit is one. Deciding whether some setting puts the marks on a single trajectory is NP-complete. The constructed gate triples even have mutually disjoint track supports. The one-occurrence case remains open.

## Hard source

In an undirected multigraph with terminals s,t, assign disjoint forbidden pairs of edges. A safe path uses at most one member of each pair. Reduce from 3-SAT by putting variable and clause blocks in series. A variable block has two internally disjoint corridors, one per truth value. On each corridor allocate one distinct edge per literal occurrence falsified by this value, using a single unpaired edge if there are none. A clause block has one direct parallel edge per literal. Pair each clause edge with its designated false-occurrence edge at the variable. A simple s–t path picks one corridor per variable and one edge per clause. Safety says each chosen literal is true. Conversely a satisfying assignment and a true literal in each clause give a safe path. The construction is polynomial and every edge occurs in at most one pair.

## Native construction

Give each original edge e an arbitrary direction u to v for naming. Subdivide it at a private vertex w_e. Each forbidden pair gets a new independent bit. Enable the first half u–w_e for its first member at bit zero and for its second member at bit one. Unpaired first halves can be permanently enabled. For each e give its second half w_e–v its own independent optional bit. The active graph remains undirected.

Give every original and subdivision vertex its own baseline feedback cycle with dedicated sockets for all incident halves, and a private mark position if needed. Give each half its own private singleton feedback cycle. Activate a half by a three-cycle on distinct sockets, one at each endpoint and one on that private singleton. Different halves have disjoint triples. Place the roots on private positions at s and t. The physical return is baseline feedback right-multiplied by the product of active rotations. To enable a rotation at bit zero, incorporate it into the fixed feedback and use its inverse as the optional rotation at one. Permanent rotations also go into feedback. Disjoint supports make this exact for every mask. Each pair bit occurs exactly twice; each second-half bit occurs once.

## Correctness

For arbitrary controls, every trajectory stays within a component of the active graph, counting an active half's auxiliary socket with its endpoints and leaving inactive auxiliary singletons separate. This follows because the baseline cycles and active rotations each preserve that partition. If the roots join, a simple connecting path traverses both halves of each original edge it uses. It cannot use both members of a forbidden pair because their first halves require opposite bit values. Contracting the subdivisions gives a safe path.

Conversely choose a simple safe path. Set the pair bits to enable every path edge's first half, and enable precisely the path edges' second halves. Every additional active first half leads to a distinct subdivision vertex with no active second half. The active graph is a forest consisting of the subdivided path, pendant first halves and isolated vertices. Insert its active rotations in any order. Each insertion takes sockets from separate endpoint components and a fresh private singleton, therefore from three different current cycles, and merges them into one cycle. Inductively every active component is a single trajectory with its auxiliary sockets. Hence the marked positions join. The argument needs no converse from connectivity to a single orbit when the active graph has cycles.

A control assignment can be verified by direct tracing, giving membership in NP. The checker constructs explicit feedback after polarity adjustment and compares every physical setting with independent safe-path search. Run python check_two_occurrence_path.py. Across 700 seeded multigraphs, including parallel edges, it checked 78,519 physical settings and found 411 positive and 289 negative instances.
