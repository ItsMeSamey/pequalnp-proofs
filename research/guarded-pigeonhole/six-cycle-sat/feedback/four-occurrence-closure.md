# Closing an open binary routing instance with four occurrences per control

Take n named tracks, an ordered word of independently optional triple rotations, and two fully prescribed binary endpoint vectors. Their one-sets are I at the input and O at the output. Reject unequal cardinalities in the exact endpoint problem, since any setting acts as a permutation. Equivalently send that case to a fixed closed NO instance with two isolated tracks and a root on each. For equal cardinalities, an open setting with track permutation σ is accepting exactly when σ(I)⊆O. This includes I=O empty, which can use a fixed closed YES instance with both marked points on one trajectory.

Use two sheets of the n tracks. On both sheets run the forward word, exchange the two sheets on precisely the tracks labeled by O, and run the reverse word of inverse rotations on both sheets. **The four copies of each gate share one setting bit.** An inverse of a triple rotation is an allowed rotation on the oppositely ordered triple. The sheet exchange is fixed wiring, which may also be absorbed into subsequent track names and final feedback. For any fixed mask, an input (s,i) emerges as

    (s xor [σ(i) belongs to O], i).

Thus the entire word is a product of disjoint switches between corresponding sheet positions. This statement holds for arbitrary O, independently of the cardinality check.

Order the t≥1 tracks of I as i₁,…,i_t. On the 2n output names apply feedback F consisting of the disjoint transpositions (1,i_j) ↔ (0,i_{j+1}) for 1≤j<t. Every other label feeds back to itself. Mark the input arcs immediately before the forward word at (0,i₁) and (1,i_t). A full lap maps input x to F(word(x)). When all sheet switches are off, the t+1 cycles on the selected track pairs consist of the singleton (0,i₁), the successive feedback transpositions, and the singleton (1,i_t). Switch j exchanges successors at positions in the jth and (j+1)st baseline cycles. The corresponding incidence graph is a path. Any active subset is a forest: adding its edges in sequence always splices two current cycles and never splits one. Its trajectory partition is exactly the connected-component partition of the path after retaining active edges. All tracks outside I have separate feedback and cannot connect these roots. The marked input arcs therefore lie on one trajectory exactly when every i in I satisfies σ(i)∈O. Tracing gives both directions per mask and preserves witnesses.

The construction uses 2n tracks, four occurrences per original control, O(n) fixed wiring, and an explicit feedback permutation. Composing it with the open optional-rotation SAT reduction yields NP-hardness for the closed common-trajectory problem with four tied occurrences per control. Direct simulation given the control mask gives membership in NP. This result is specific to shared controls. For example, with one optional rotation (0,1,2), ordered I=(2,1), and O={1,0}, both physical settings fail the open predicate. Setting the forward sheet controls to (1,1) and inverse sheet controls to (1,0) instead joins the closed roots.

The [checker](check_four_occurrence.py) independently simulates the four physical occurrences and the feedback permutation. For 72 seeded words on three through six tracks, it enumerates every switch setting and every pair of endpoint subsets. All 685,440 comparisons match the subset predicate, including 136,080 positive cases and 525,924 unequal-size controls. For unequal cardinalities the closed chain tests inclusion only, hence the separate exact-endpoint cardinality check above. The checker also finds the explicit untied-control false positive.
