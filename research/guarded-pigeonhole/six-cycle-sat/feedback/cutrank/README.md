# Reconstructing rooted switch routes by cut rank

Call routing.route(n, gates, feedback, (a,b), order). Tracks and gate numbers start at zero. The two roots lie immediately before fixed feedback. Each gate either leaves its three distinct tracks alone or moves the occupant of each to its cyclic successor. The return is a physical gate mask or None. The optional order supplies a recursively bisected whole-gate layout. To use a general supplied binary tree on a precomputed paired interlacement representation call rooted_cutrank.solve directly.

The reference tour, twist T, interlacement matrix A and root chord vector c follow ../cycle-parity.md. The program discards components away from the roots. Both switch locations of a gate are in the same untied component because they share one track across consecutive time slices. Inactive components can therefore take all gates off.

At a node U, record incoming syndrome A[U,out]z and outgoing syndrome A[out,U]y, with a representative pair X,y. Require y supported on X, X xor T a union of complete gate pairs inside U, and (Ay + incoming + c) zero on X. At an internal node each child's incoming syndrome is the parent syndrome plus the sibling's output restricted to that child. The parent output is the XOR of both outputs restricted to the exterior. Exact equality at each interface permits retaining one representative. The root witness X xor T decodes the physical switches. With maximum cut rank r there are at most 2^(2r) states per node and the triple loop takes 2^(3r) times polynomial input size. Full witness masks and interface masks cost polynomial bits per state.

Run python check_routing.py. Its independent oracle applies the physical three-cycles directly and traces feedback orbits, without chords or binary algebra. Seed 20261126 checks 200 networks, 3571 settings, 3157 root pairs, 2851 witnesses, and 306 negatives. Run python rooted_cutrank.py for 360 further algebraic tests. Neither suite measures scalability on wide decompositions.
