# Two is the maximum exact sign-bundle size with private false probes

Mark a wire G and p positive and q negative occurrence wires. Require every physical mask of a closed independent ternary-switch network to induce one of two patterns on these marks. All probes of the true sign must belong to G's cycle, while every false probe must lie on a different cycle from G and each other false probe. Both patterns must occur. Then p+q≤2, and every pair of nonnegative multiplicities with p+q≤2 is realizable (with no informative probe when p=q=0).

For a nonempty bundle, follow a path in the mask cube between representatives. At two adjacent masks the induced patterns differ. Write the first permutation as P and the second as P composed with a 3-cycle on three departure wires. A cycle of P avoiding the three departures is unaltered. Every initially false probe must join G and every initially true probe must leave G. Thus the initially false cycles and G's cycle must all be hit: if G's cycle were untouched, its orbit would have exactly the same wires. There are at most two initially false probes, and reversing the argument gives the same bound for the other sign. If there are two initially false probes, the departure positions must hit three distinct cycles, one per probe and one for G. Applying either orientation of a 3-cycle then merges all three entire cycles. Every probe initially on G remains there. Therefore the opposite-sign multiplicity is zero. This proves the bound with any number of auxiliary wires or independently switched gates.

One switch suffices for all nonempty allowed bundles. For two equal signs start with three singleton cycles G,a,b and optionally rotate them; both false probes are distinct when off and both join G when on. For one occurrence, use an unmarked b in the same construction. For opposite signs start with P=(G a)(b), and choose the cyclic order of the switch so that its on permutation is P composed with (G b a), yielding (G b)(a). All constructions use three actual switch sockets. Any renaming of the two Boolean truth values is harmless.

The statement constrains the entire set of physically attainable patterns. It does not exclude constructions that select a correlated subset of masks or test only a rooted condition without requiring distinct cycles for false probes.
