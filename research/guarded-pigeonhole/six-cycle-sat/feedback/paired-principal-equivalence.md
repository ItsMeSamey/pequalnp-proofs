# Recognizing paired pencils reducible to scalar principal-minor equivalence

The star construction of landmark-order-calibration.md gives two pencils P,Q with the same raw tagged edges. Use the original star and the version toggling every off-diagonal anchor-anchor entry and nothing else. Their coefficients differ by H_ij at realized classes i,j, which is one for distinct classes and zero otherwise, regardless of order inside an orbit. Thus P+Q is the separated indicator for arbitrary k supplied protected classes. The common raw tag convention may complement bits but compares with the same all-mask product.

To test that envelope deterministically on a recognizable class, replace h by 1+h. Compare the shifted pencils on each face h_i=0 and check the top coefficients separately, since their sum must be one. This covers every monomial. On a face delete the tagging for that variable, keeping its endpoints mandatory. For exact equality of the two face polynomials, use zero-broken-pair feasibility to find a support monomial of the first; compare directly to the second, with the zero-polynomial case handled symmetrically. To force mandatory coordinates U, dependent rows indexed by U preclude any nonsingular extension; otherwise extend them to a full row basis, pivot that basis, delete U, and retain the residual twist. When the witness monomial is common, its complementary pairs together with all mandatory vertices form a nonsingular index set R in each constant matrix. Principal pivot on R, then delete all original mandatory indices. The new matrices C,D have just named two-coordinate blocks, and their whole-pair principal Pfaffians are the respective coefficient tables after the same mask XOR relabeling.

For each matrix seek nonzero local lines v_i with v_i-transpose C_ij v_j=0 at every pair. Over the binary field each line variable has three values. Rank-two blocks prescribe bijections between values; propagate along a spanning forest, keeping root values consistent with all cycle constraints. Empty domains reject the certificate. Rank-one blocks with factors l_i l_j^t require the kernel line of l_i or the kernel line of l_j. Translate these positive singleton disjunctions to Boolean equality atoms on propagated component variables, adding at-most-one clauses within each component and excluding eliminated values. If all atoms at one component remain false in a 2SAT solution, assign any surviving value: each positive clause already held and only internal at-most-one constraints could be affected. Rank-zero blocks impose no restriction.

Extend each selected line to a local basis of determinant one. The first-first quadrant is zero, so every perfect-matching term of a whole-block principal Pfaffian pairs all first coordinates with seconds. The Pfaffian is the scalar principal determinant of the first-second quadrant in characteristic two. Local determinant-one changes preserve whole-block Pfaffians. When both matrices admit certificates, even different certificates, compare their scalar principal-minor tables deterministically. [Chatterjee–Ghosh–Gurjar–Raj, Theorem 1.2](https://arxiv.org/abs/2410.01961)

The same method applies to the five lines over F4. For binary input they suffice even if a solution is only known over the algebraic closure: a nonidentity projective holonomy over F2 has every fixed line over F4. In a component with only identity holonomies, satisfying any rank-one literal fixes the root to a binary line. If no literal was satisfied there, change arbitrarily to an F4 root value. All positive clauses retain a true literal elsewhere. Normalize each local basis to determinant one.

Failure to find lines may result in abstention. Inequality of scalar tables supplies a differing principal set by repeatedly deleting an index while inequality remains; once every single deletion gives equality the full remaining set must differ. Reverse the mask pivot to obtain a differing shifted coefficient. This coefficient is the parity of the original bad physical masks extending its named shifted monomial. Fix remaining raw bits by direct Pfaffian evaluations with indicator weights preserving that parity, then decode physical bits. This recovers a witness without assuming hereditary scalarizability under physical gate pinning.
