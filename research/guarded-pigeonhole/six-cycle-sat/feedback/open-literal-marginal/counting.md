# Counting settings for one prescribed external transition

Counting the full native switch masks that route one prescribed external input to one prescribed external output is #P-complete under polynomial-time counting Turing reductions. From counting independent sets the reduction uses only one oracle call and one integer remainder. Membership in #P follows by guessing every independent switch bit and tracing the input. The instance is the [open compiler](README.md), with arbitrary feedback and growing external arity.

Let G be a simple n-vertex graph with m≥1 edges. Introduce a variable for every vertex and the clause (¬x_u ∨ ¬x_v) for each edge uv. Its satisfying assignments are the independent sets I. Repeat each edge clause r times, using fresh native gates for every copy; do not duplicate variable stages. The compiler uses 2n+4rm gates. For a fixed independent set I let z(I) count edges with neither endpoint selected.

A successful mask determines one marked-token route, hence one assignment and one chosen true literal per clause copy. Conversely, on these binary clauses all fork and merge settings are uniquely determined by the route: every stage visits its single fork and single merge. If an edge has one endpoint selected, every copy of its false occurrence has its blocker on the variable path, forcing its gate off. Its other occurrence is the sole true choice, so that test gate must be on. This gives exactly one choice. For an edge with neither endpoint selected neither blocker is visited. There are two possible true literal choices per copy, and for each choice the chosen test gate is on while its unvisited partner is completely free. Thus there are exactly four compatible patterns per copy, counting the distinct clause fork/merge bits. Distinct paths are never double-counted, since a full mask determines the path. These factors remain valid in the presence of an internal cycle because unvisited gates impose no constraint on the marked token. An isolated variable contributes two distinguishable assignment routes even though both branches contain no blockers.

The count returned is therefore

    N_r = Σ_{I independent} (4^r)^{z(I)}.

Choose r=n+1. Since 4^r is congruent to one modulo 4^r−1 and the number of independent sets is at most 2^n < 4^r−1, the least nonnegative remainder of N_r is the exact independent-set count. The query and returned integer have polynomial bit length; an edgeless source graph can be counted directly. Counting independent sets is #P-complete already on bipartite graphs by complementation of the vertex-cover result of [Provan and Ball](https://doi.org/10.1137/0212053). This is a weighted-count reduction with numerical postprocessing. It counts complete settings, including those differing only at unused gates. Every oracle instance here has a successful route, for example the assignment selecting no vertices.

The [count checker](check_counting.py) compared per-assignment histograms on 100 compiled graph/repetition instances with symbolic branching along the actual marked socket path, charging every unvisited bit independently. A separate exhaustive trace loop checked 1,125,632 complete masks. The checker also verified the remainder decoding for every tested r=n+1.
