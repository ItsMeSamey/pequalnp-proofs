# One prescribed external transition is NP-complete with native feedback

Input is a finite open routing patch of independent optional cyclic rotations on three sockets, with fixed one-to-one wires. Given one external input s and one external output t, decide whether a setting routes s to t. A mask is a polynomial certificate: at a fixed setting external paths are simple and cannot enter a detached cycle. The following reduction uses one independently controlled gate per switch, including the gates implementing conflicting logical arc pairs.

Use a signed CNF with n variables and nonempty clauses of lengths one through three. Its conceptual directed graph is a series of variable choice stages followed by clause choice stages. In the variable stage i one picks bit b and visits one marked blocker arc for each occurrence of a literal false when variable i has value b. The other branch contains the complementary set of occurrence blockers. In a clause stage one picks exactly one of its occurrences and traverses that occurrence's test arc. Pair each occurrence's blocker arc with its own test arc. No arc belongs to two pairs. An s-to-t path using at most one arc of each pair exists exactly for satisfiable formulas.

For each paired blocker e and test f use a single native gate. Name its three inputs and outputs 0,1,2; off is the identity, on maps j to j+1 modulo three. Use input 0 and output 0 for e, and input 1 and output 2 for f. When a token from either real input attempts its disabled turn it goes to output 1, which is a fresh external sink. Input 2 is a fresh external source. Consequently the token from s cannot use this gate to jump between its two logical arcs. Exactly one of the two arcs is permitted by any setting. Sharing this single physical site between early and late logical arcs may introduce feedback into the gate graph.

Replace each binary fork by a fresh gate with real input 0 and real outputs 0,1. Replace its merge by a fresh gate with real inputs 0,1 and real output 1. Their unused inputs and outputs are distinct external terminals. An empty variable branch is a direct wire from fork to merge. For a clause of length three nest two binary forks and merges; a unit clause needs none. Place fixed directed wires between consecutive stages, exposing only the first input and final output as the marked s,t. Every other untreated socket has its own external terminal. There is no return wiring from an unused output or from t.

If a physical mask routes s to t, this token avoids all fresh sinks. Its real turns therefore project to a directed path in the conceptual graph. Its variable choices give an assignment and every chosen clause occurrence is true, since otherwise the path would require both the off and on choices at its occurrence gate. Conversely route the assignment and one true literal per clause using the corresponding forks and merges. Set every encountered blocker to off and every encountered clause test to on. These prescriptions are consistent; unused gates may take arbitrary settings. This recovers a physical s-to-t path. The other external inputs and outputs are unrestricted, and detached internal cycles are harmless.

For q literal occurrences and d=n+Σ_C(|C|−1), the construction has exactly q occurrence gates, d forks, and d merges. There are 2^(q+2d) physical masks. The external arity is 1+q+3d on each side: each occurrence contributes one padding input and output; each fork/merge pair contributes three on each side. This is linear in the source size. If desired start from bounded-occurrence SAT: replace each variable with one fresh copy per occurrence and add the binary implications that each copy implies the next in cyclic order. These force equality of the copies, with at most three occurrences per copy total. A singleton needs no implication. This uses clause width at most three and does not assert hardness when all clauses are required to have exactly three literals and all variables have at most three occurrences.

The [checker](check.py) builds the physical wiring and traces all 88,600 masks across eight formulas, with 40 accepted masks total. On (x)∧(¬x) the four-gate patch has six inputs and outputs and none of the 16 masks joins the requested terminals. On (x) the three-gate patch has five on each side and mask 3 succeeds. All 65,536 masks on the 16-gate patch for (x∨x∨x)∧(¬x∨¬x∨¬x) fail. These are open single-transition queries; closing arbitrary unused terminals can permit another route to the marked output.
