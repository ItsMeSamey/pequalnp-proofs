# One long forbidden cycle suffices for every closed network

Let an original nonempty ternary-switch network have n wires and c cycles of the forbidden permutation F. There is a linear-time expansion by c−1 switches whose forbidden cycle lengths are n+2(c−1) and c−1 copies of 1. For every setting of the expanded network, suppressing new wires yields exactly the directed cyclic trajectories of its restriction to the original switches. Each original mask has exactly 2^(c−1) lifts. In particular every predicate on the cyclic order or common-trajectory status of original marks has its number of successful settings multiplied by this same factor.

Cut two original wires a and b on different current forbidden cycles. Insert a switch with external inputs 0 and 1 and external outputs 0 and 2, attaching 0 to the downstream part of a and 2 to that of b. Join output 1 to input 2 by a private wire. Keep the original marks on the downstream segments. In state 0 the first external route is direct and the second uses the private wire. In state 1 the first uses the private wire and the second is direct. Both states therefore continue the two original physical wires individually, and neither produces an internal physical orbit.

For forbidden traversal, input 0 exits at output 2, input 1 exits at output 0, and input 2 exits at output 1. Hence the private wire forms a singleton. On suppressing the two upstream segments, the forbidden traversal swaps the destinations of the former predecessors of a and b. This splices their two cycles into one, including when either old cycle was a singleton. The enlarged merged cycle retains both new upstream segments. Attach one representative from each other original cycle to the same downstream representative of the first cycle. This leaves every new private singleton intact. The switch and wire counts give the stated lengths. Inverse output lookup permits each splice in constant time after the original cycle scan. For an empty network return the empty network.

The accompanying one_long_forbidden_cycle.py implements this splice. All 3! and 6! native off-output permutations and 100 seeded nine-wire examples passed. Every original setting and every extension on those examples were compared, for 15,000 mask lifts in 826 networks. The check compares full cyclic sequences of old wire identities and detects any extra purely internal physical cycle.
