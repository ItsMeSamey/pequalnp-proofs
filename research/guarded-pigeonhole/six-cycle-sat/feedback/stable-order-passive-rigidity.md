# Passive single-use readout determines the entire stable order

Fix n independently valued named occurrences and two named anchors G,B. The patch on n+2 channels gives one cyclic successor list G followed by the zeros in order L and one list B followed by the ones in that same order. A fixed passive wrapper may connect channels in feedback, supply external bypasses, relabel inputs and outputs separately, and have detached fixed circuits. Suppose its external permutation on n+2 channels is exactly the stable table for order K for every word with the same occurrence values. Then K=L. The smallest nontrivial obstruction is 12 versus 21.

Let S_i be the inputs whose outputs change upon moving occurrence i from zero to one at the all-zero baseline. These are B, i and the preceding occurrence in L, using G as predecessor of the first occurrence. The three old departures have their outputs cyclically permuted. The target support has size three as well. An affected external input must traverse a changed departure on its baseline route. Baseline input-to-output routes are disjoint on patch input positions, so three changed external inputs must visit three different changed departures. Over all one-bit flips the target supports cover all n+2 external inputs. Thus each external input traverses at least one patch departure at baseline. There are only n+2 departures, so every external route traverses exactly one and every departure is used. All patch outputs are therefore routed directly to the exterior before the next patch call, and all patch inputs receive a fixed external input. The resulting input and output relabelings are independent of the word. In particular the same input bijection transports the support sets for every flip at either uniform baseline.

For distinct i,j, their zero-baseline triples intersect in two labels exactly when the occurrences are adjacent in L. Otherwise their only common label is B. The undirected adjacency path is therefore preserved. At the all-one baseline the reverse flip at i has support G, i and the preceding occurrence, using B as predecessor of the first occurrence. Exactly for the first occurrence are the zero- and one-baseline triples equal. This identifies the first vertex of the path and fixes its orientation. Identity wiring realizes the identical order.

The conclusion extends to independent wrapper switches if exactness is required for every joint setting, since one may fix them uniformly. If the requirement is existential over word-dependent wrapper settings, this proof supplies no obstruction. It uses full permutation readout, individual occurrence flips and one use of the same-arity patch. It does not cover tied copies of a variable or a single rooted observation of the output.
