# Deterministic discovery of protected landmarks

Given a switch network with independently optional triple rotations and n allowed passive arc positions, find a subset hitting every trajectory exactly once for every setting, or prove no such subset exists. No promise on the cycle count is needed. Let k be the baseline number of trajectories, or reject if a separately requested size differs from k. Every possible answer chooses one position on each baseline trajectory.

Retain all allowed positions initially. Choose any surviving position on each baseline trajectory; report impossibility if one domain is empty. Test this proposal by deterministic supplied-landmark recognition. For k≥2 test universal single-tour behavior for one cyclic landmark cap per ordered pair y≠x, chosen to contain the adjacency y→x. A mask with an untouched original trajectory fails every cap. Otherwise if some trajectory has multiple marks the permutation of next marks has some x→y≠x; a cap with y→x creates a fixed point and fails. A valid mask passes all caps. For k=1 the identity cap tests universal one-tour behavior directly. A nonuniversal cap yields an actual failing mask by fixing optional gates one at a time and retesting universality on each restricted physical network, keeping a nonuniversal branch. Fixed-on gates become ordinary fixed rotations. This uses the single-cap deterministic envelope oracle in deterministic-universality.md. Every output mask is verified by tracing the original trajectories.

Walk from baseline to the failing mask by flipping the differing gates once each. Trace until the first setting at which the proposed positions fail. If it has a trajectory count different from k, no universal transversal exists. Otherwise the two consecutive settings each have k trajectories. Outside the flipped gate the trajectory links agree. Cut the three outgoing links there and regard the three resulting directed path segments as indivisible sets of passive positions. The return permutation on the three segments is multiplied by a three-cycle or its inverse. If all three were in different trajectories their number would drop by two. If all three were in one trajectory and the count stays fixed, the set of positions on that trajectory stays the same, contradicting first failure. Thus two segments a,b shared one old trajectory, while c formed a second. On the three segments the old permutation is (ab)(c); after multiplication it is a different transposition. Rename a,b so the new partition is (a)(bc). Every other trajectory agrees before and after.

Any globally protected tuple must choose one position in c (old singleton segment) and one in a (new singleton segment). It can choose none in b, because the old trajectory a∪b and new trajectory b∪c each permit one choice. The current proposal was valid immediately before the flip: its old choice on a∪b must lie in b, since a choice in a would preserve validity. Delete ALL allowed positions of b and repeat. Endpoints can be assigned unambiguously by indexing positions on fixed physical wires or by passive subdivisions before the switch ports. Operationally b is the intersection of the old two-segment trajectory and the new trajectory containing the intact c. Neither the arbitrary choices nor the order of gate flips affect soundness.

Every failed iteration either proves impossibility or deletes at least one position of the proposal, and every deletion preserves every possible answer. Therefore at most n failing proposals and one successful recognition suffice. Each step uses polynomial-time cap testing and physical trajectory traces. This permits variable k, arbitrary candidate domains, and no supplied initial protected tuple. If there are no trajectories, direct inspection of the empty network handles the empty answer.

When all masks have the same trajectory count, the argument also characterizes the entire solution family. Over all adjacent mask pairs, take the union of their transferred segments b whenever two trajectories participate. All protected sets avoid this union. Conversely, selecting one surviving position per baseline trajectory maintains validity across every gate flip by exactly the local proof above; connectedness of the mask cube gives universal validity. Discovery need not construct that full union.
