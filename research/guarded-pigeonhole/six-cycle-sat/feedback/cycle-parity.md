# Optional triple rotations, one orbit, and two marked roots

Represent each optional (a b c) by successive transpositions (a b) and (a c), taking both or neither. Give them distinct time slices, and allow an arbitrary fixed permutation from the final tracks back to the first. Subdivide a passive layer for the two marked track occurrences so their cut locations are distinct from the transposition endpoints. A fixed switch setting is a permutation of the time-expanded states; each of its cycles is one closed trajectory.

## Untied reference and exact full-cycle recognition

Temporarily untie the transpositions. Start with all switches off. In any connected component of the undirected graph consisting of the baseline trajectories and the optional crossing locations, make one reference tour by successively selecting transpositions whose endpoints belong to different current cycles. Equivalently choose the edges of a spanning tree of the baseline cycles. Each chosen transposition merges two cycles, so these choices produce one reference cycle in the component. More than one component precludes a single global tour.

Let T be the reference set of individual transpositions. Draw their candidate locations as chords around the reference tour (including the locations unused in T). Form the binary symmetric zero-diagonal matrix A whose entries indicate interlacing chord endpoints. If the selected physical transposition set is S, put X=S symmetric-difference T. The number of trajectory cycles is exactly

    1 + nullity A[X].

For a direct proof consider binary functions constant around the new cycles; their space has dimension the number of cycles. When walking along the reference, the change at both ends of each toggled chord is the same bit. Closing the two crosswise connections at that chord requires the sum of the changes at interlacing chords to be zero. Thus the change vector lies in the kernel of A[X]. Conversely an initial bit on the reference and any such kernel vector propagate uniquely, giving the formula. The feasible sets F for one tour, before enforcing pair ties, are precisely the twist by T of the nonsingular principal sets of A. This is the binary even delta-matroid of spanning quasi-trees of the associated orientable ribbon graph.

A physical setting is a union of prescribed pairs. Geelen, Iwata and Murota give a deterministic polynomial augmenting-path algorithm minimizing the number δ of split pairs among feasible sets of a represented linear delta-matroid, including twists and characteristic two. Testing δ=0 gives a deterministic single-tour decision and a witness. More generally the minimum number of trajectories in a connected component is 1+δ. Indeed the distance from S to the feasible sets is nullity A[X]: a maximum-rank alternating matrix has a nonsingular principal submatrix of that rank (successively eliminate nonsingular two-by-two pivot pairs); conversely each single-index toggle changes nullity by at most one. For any feasible F its distance to the nearest union of pairs equals its number of split pairs. Minimization in either order proves the assertion and reconstructs an optimal setting by rounding the split pairs of an optimal F. [Geelen–Iwata–Murota, §3 and §5](https://www.math.uwaterloo.ca/~jfgeelen/Publications/deltamatroidparity.pdf) · [Koana–Wahlström, faster randomized algorithms](https://drops.dagstuhl.de/storage/00lipics/lipics-vol327-stacs2025/html/LIPIcs.STACS.2025.62/LIPIcs.STACS.2025.62.html)

There is also a direct Pfaffian decision polynomial. Start with A. For a pair i,j meeting T evenly, add a parallel bypass contribution h to its ij entry. A matching of the resulting alternating matrix uses either the labeled bypass (omit both indices from X) or no bypass (retain both). For a pair meeting T oddly, add one auxiliary vertex attached to i with coefficient 1 and to j with its own variable h; exactly the other index is retained. Use different h per pair. Then each physical pattern has its own monomial with coefficient Pf A[X], 0 or 1 over the binary field. Thus nonidentical zero is equivalent to a physical one-tour setting. Odd total matrix size gives the zero polynomial. Evaluate over a sufficiently large characteristic-two extension and use the usual polynomial identity test. There is no sign or factor-of-two ambiguity in this construction. It is a decision polynomial; binary coefficients do not directly count routings as integers by evaluation at one.

## Rooted orbit without merging other trajectories

First discard components containing neither root, and reject if the roots belong to different untied components. In the retained reference draw a further chord z between the two roots. If c records its interlacements, then for a fixed physical setting

    roots share a cycle  iff  c[X] lies in the row space of A[X].

To see this, toggle the new chord. It splits one trajectory when roots agree and joins two otherwise. The bordered alternating matrix has the same rank if c[X] is in the row space, and has rank two higher otherwise. Apply the circuit-nullity identity before and after toggling. This criterion applies even when A[X] is singular.

It gives a polynomial sufficient certificate using two deterministic parity runs: compare the minima of the trajectory counts before and after the fixed marked transposition. If the latter minimum is one higher, every original minimum routing has the roots together. If it is one lower, at least one original optimum has the roots separate. The latter case leaves open whether another routing joins the roots. The two minima differ by exactly one since every original trajectory count has the same parity (the physical switches are even) and toggling changes the count by one.

The rooted predicate is not equivalent to whole-tour feasibility or ordinary connectivity. On four tracks with identity feedback use the optional rotations (a b c) then (a b d). The switch-incidence component is connected. No even permutation on four symbols is a four-cycle. Roots a,b can share an orbit, already with the first switch alone, while c,d never do: the empty or singleton choices leave at least one of c,d fixed and the two-switch permutation is (a d)(b c). This note does not decide general rooted feasibility in polynomial time.

The independent checker generates time-expanded feedback permutations, constructs reference chords, expands the tagged Pfaffian over binary monomials, and compares every coefficient, every switch setting's orbit count, and all pairwise rooted tests to direct tracing.
