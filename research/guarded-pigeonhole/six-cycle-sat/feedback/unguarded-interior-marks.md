# All physical wire marks in the unguarded signed readout

Take n three-socket widgets (G P)(N) versus (G N)(P). Connect the G output of each widget to the next G input in a linear series, exposing the first G input, last G output and all signed taps. Cap the resulting 2n+1 channels by an arbitrary fixed permutation f. Denote the exposed input indices by 0 for G and 2i−1,2i for the two signs of widget i (i starts at one). Write t_i for the setting-selected signed input at widget i. The source transfer p is the cycle (0 t_1 … t_n), fixing the unselected taps. Physical exterior trajectory membership is therefore computed with f after p.

An interior G wire between widgets i and i+1 is always on the source route FROM t_i TO t_(i+1). It can be represented, for root evaluation at the current assignment, by external input label t_i. This label varies with the assignment. A mark on the input side of the first widget is represented by 0; at the last G output by f(0). Any fixed exterior wire is part of a fixed return path and represented by its destination input. These are all wire types of the primitive. Inserting fixed subdivisions contributes no further nonconstant behavior. Two marks on one return path always join; deterministic detached cycles likewise contribute only constant answers. This characterization concerns exterior rewiring of the exposed ports and arbitrary locations of the two marks on the actual physical wires.

For n=4, add the three conditional labels t_1,t_2,t_3 to the nine fixed input labels. Exhaustive evaluation of every pair and all 9! exterior caps gives 60,080 distinct truth tables (5,456 missing), compared to 56,160 for the nine fixed labels. The two constants already occur. In the table-bit convention of check_unguarded_interior.cpp, mask 311 is newly attainable. A witness is f=[3,6,5,0,2,1,8,7,4] with marks at input 3 and the interior G wire after the first widget.
