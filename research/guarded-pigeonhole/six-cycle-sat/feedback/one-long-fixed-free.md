# Fixed-point-free missing-turn normalization

Start with the construction in one-long-forbidden.md. On each new private fixed wire insert a one-track box with external input I0, external output O2, and internal links O0 to I2 and O1 to I1. Its missing turns send the external channel directly through and place the two residual positions in a separate 2-cycle. Thus the old missing fixed cycle grows to a 2-cycle and we add one other 2-cycle. In physical mode zero the through path visits I0 and I2; in mode one it visits I0 and I1. Each mode adds one detached physical circuit. The original marked trajectories are preserved, and every setting has twice as many extensions per box. Full physical orbit counts change by a known additive number for this one-gate variant.

To remove raw wire self-loops as well, use a five-gate one-track box. Subdivide one edge of K4 by A, giving seven edges, four cubic vertices and one degree-two vertex. Put a physical switch at each vertex. At each switch associate a distinct socket index i to each incidence, each incidence reserving both input i and its missing output i-1. At the two ends (j,k) of an edge place the directed physical wires from the missing output at j to the input at k and vice versa. The one unused index at A supplies the external input and its missing output. Consequently all fourteen internal incidence positions are in seven missing 2-cycles, and the missing external passage is direct. No raw wire has both ends at the same switch. Every physical setting maps the sole external input to the sole external output: injectivity prevents its path from entering a directed circuit and finite termination leaves only this output. Unmarked internal circuits may occur.

First, when necessary, replace each raw self-loop of the input by this five-gate box. Mark one external side of the replacement if the old wire is marked. Merge all current missing cycles via the transparent boxes; each creates precisely one raw self-loop, its private missing fixed wire. Replace each such wire by the five-gate one-track box. The result has exactly one distinguished missing cycle and all other missing cycles of length two, and its directed wires have no raw self-loop. Its size is linear. Each original mask extends by arbitrary independent bits at the added gates, preserving all original trajectories after contracting the physical through paths. Hence the count of settings joining the original marks gains exactly a power of two given by the number of new gates. This establishes an equivalence with unrestricted physical rooted joining, not an NP-hardness result. All counts involving newly detached orbits require separate analysis.

There is a structural restriction on this particular completion method. Consider an open box with one free cubic socket pair at each terminal, taking its external output to be the missing turn of that same input, and pair all other sites into reversed missing 2-cycles. Its undirected incidence graph has a leaf at each external socket pair and freely rotatable cubic internal vertices. Any two distinct leaves in one component can be connected in the specified direction under some physical setting: take a simple undirected path and choose the cyclic rotation at each internal vertex carrying its entering incidence to its exiting incidence. Thus a box of this form that preserves each track separately on every physical setting has at most one external leaf in each component. This explains why disconnected one-track completions cannot be replaced by a single connected transparent completion within the stated class.
