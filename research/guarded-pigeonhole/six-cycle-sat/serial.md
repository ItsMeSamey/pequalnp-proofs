# Hardness with a single displaced token

For a nonempty 3CNF let L=3m be its number of literal occurrences. Replace the fresh verifier pairs in README.md by L+1 tracks z_0,...,z_L initialized to 10...0 and required to finish as 0...01. Occurrence j, indexed starting at one, uses T=z_(j-1) and F=z_j in the same two optional rotations. Its F track is fresh, hence zero before this test. Its T track is retired and required to be zero afterward. By induction T is one before this test, forcing the second rotation. As before, the result exists exactly when one checked bit is zero, both data bits return intact, and F becomes one. This proves the induction and recovers the original exact decision equivalence. Zero-clause formulas can be handled separately or augmented by a tautological clause.

All other tracks have the same fully prescribed source and sink values. Thus Hamming distance exactly two between the prescribed bit vectors suffices for NP-completeness. The register size is 3n+6m+1, still unbounded. The test count remains 2n+10m. Leaving ports unspecified or merely connecting the source and sink of unchanged lanes would impose a different condition; the proof uses their prescribed values.
