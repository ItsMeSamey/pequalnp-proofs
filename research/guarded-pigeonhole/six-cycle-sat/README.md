# 3SAT on acyclic networks of bipartite six-cycle switches

Three binary tracks can undergo an optional cyclic shift. A switch uses one ordinary six-cycle: its three A holders and three B holders each get one exterior wire. Index the holders so the two perfect matchings of the cycle connect the two sides by the identity or the designated 3-cycle. In a proper three-edge-coloring with binary inputs the per-color shore counts force binary outputs. The third color must therefore be an internal perfect matching. The remaining three internal edges form the other perfect matching, whose ends have the same terminal color. Conversely either permutation transports every binary input and gives a full ordinary coloring. Components joined from earlier outputs to later inputs remain bipartite. Binary source values inductively exclude the third color on all time wires; nothing is prescribed internally.

A read-only clause test takes tracks x,y,T,F. Set the source ancillas T=1,F=0 and require their sink values T=0,F=1. Apply optional rotations (x y F), (y T F) in that order, with each occupant moving to the next position. The second rotation must be taken because it alone changes T. If the first is omitted, the second accepts exactly when y=0 and returns x,y unchanged. If the first is taken, its result is (0,x,1,y), so the second returns (0,y,x,1), accepting exactly when x=0. Thus the test realizes NAND(x,y) and every accepting trajectory preserves both bits.

For each of n Boolean variables initialize three wires to 100. An optional forward rotation yields 100 or 010, giving complementary true and false rails. For each of m clauses initialize three private wires to 100 and apply two optional identical rotations, so one arbitrary occurrence carries 1. For each of its three literals place a read-only NAND on this witness bit and the variable rail that is 1 precisely when the literal is false. Give each test its own two pinned ancillas. The three read-only tests pass exactly when the selected occurrence is true. Use two reverse rotations on the clause wires to restore their original 100; after all clauses one reverse rotation per variable can likewise restore its state. Source variables satisfy the CNF if and only if the whole network achieves its prescribed binary sink. Read variable rails immediately after generation to recover a satisfying assignment.

This construction has 2n+10m switches and 3n+9m tracks. Repeated literals, negative literals and tautologies require no restriction. The decision problem is in NP by recording the individual rotation choices. The reduction proves NP-completeness for acyclic, typed binary transport networks built exclusively of simple six-cycle switches, with prescribed binary values only on external source and sink tips. Between any two given switches several wires can connect them, but each switch port is at a distinct vertex, so the underlying ordinary cubic multipole remains simple. The number of prescribed tips and the width grow with the formula. Independent satisfying switch settings can have different multiplicities, so the reduction does not assert exact counting equivalence. This result does not settle fixed-width or fixed-terminal complexity, or P versus NP.
