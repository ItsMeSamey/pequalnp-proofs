# Variable total label dimension is NP-complete even for a one-dimensional target

Start from the standard NP-complete directed Hamiltonian cycle problem on loopless directed graphs on at least three vertices without repeated arcs. Split vertex i into i_in and i_out, joined by an undirected edge of binary label e_i (the i-th unit vector). For each arc i→j add an undirected edge i_out–j_in of label zero. Use graphic incidence as the private matrix and demand the exact named trace span(1^n). This root graph is simple and bipartite. The instance has polynomial size even in a dense encoding of all labels.

For any feasible selected edge set some fundamental cycle has gain 1^n: fundamental cycles span the cycle space and every gain belongs to the specified one-dimensional image. A simple cycle has that gain precisely when it uses all n split edges. Starting in→out along any one split edge, the next edge must be an arc from the current out copy to some in copy. At that copy the cycle must traverse its split edge because that edge is required, and a simple cycle has selected degree two. This establishes a consistently directed Hamiltonian cycle upon contraction of the split edges. Conversely any directed Hamiltonian cycle lifts to a simple undirected cycle containing all split edges, with exact one-dimensional trace. Guessing an edge subset and evaluating the trace by binary elimination gives membership in NP.

An explicit invertible change of named coordinates sends x to (x_1+x_n,...,x_{n-1}+x_n,x_n); it puts the target on the last coordinate alone. Thus a single named height and an input-dependent number of binary tag coordinates suffice. This does not apply when the full named dimension is fixed.
