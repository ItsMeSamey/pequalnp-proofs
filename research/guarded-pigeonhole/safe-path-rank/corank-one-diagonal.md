# Forced diagonals for a binary complementarity system with one parity mark

Fix a zero-diagonal binary matrix A and a vector beta. For diagonal d put M=A+diag(d). Ask for x with beta.x=1 and x_i(Mx)_i=0 for every i. Equivalently, there exists a principal restriction S whose embedded right kernel contains a vector not orthogonal to beta. A right-kernel vector may have zeros: restricting from S to its actual support preserves every equation on its support.

In a one-bit residual of paired binary menus, the baseline choices have columns (e_i,0) and the other choices (M_i,beta_i), with target (0,1). Select the latter on supp x. Their upper output Mx can be cancelled with unused baseline columns exactly when it vanishes on that support. This provides the stated interface. For a general upper target a, replace the diagonal by d+a; equivalently cancel a+Mx instead.

Draw an arc i->j for each A_ij=1. Let R consist of all vertices reachable from a marked vertex. Equations with i in R only involve coordinates in R. Thus projection to R preserves success and extension by zeros outside R preserves success.

For each j in R choose a shortest directed path from the set of marked vertices, written i_0,...,i_L=j. Its only mark is i_0 and it has no arc i_s->i_t for t>s+1. For every prefix ending at i_l, choose the indicator x of the prefix. The parity mark is one. The row for its last vertex evaluates to d_i_l plus the parity of its arcs back to earlier vertices. Rows of earlier vertices in the prefix see exactly one forward arc to their successors. Consequently if a NO instance is possible, induction over prefixes forces
    d_i_l = 1 + sum_(h<l) A[i_l,i_h].
Indeed previous rows then evaluate to zero on the larger prefix, while the last must fail. This also gives a direct checked witness (the first failed predicted bit's prefix) whenever the supplied diagonal disagrees. In particular every NO diagonal agrees on all of R with the unique candidate computed using one shortest path per vertex. Outside R it is unconstrained. The NO set is either empty or this entire coordinate flat. Computing the candidate does not settle whether it itself is NO. This proof needs no hypothesis on backward chords. With beta=0 the answer is NO for every offset.

For the directed three-cycle with all vertices marked the candidate is all ones. Its all-ones support succeeds, so the NO set is empty even though no path prediction disagrees. For symmetric A, a separate characterization settles the candidate: each feasible support has an even number of diagonal-one vertices per component. Each loopless singleton is feasible. A shortest path between two looped vertices cuts at its internal looped vertices into chordless feasible segments. Their indicators together with loopless singletons span every vector satisfying the component parity constraints: pairs of successive looped endpoints can each be generated, and those pairs span the even subspace of the looped vertices. Thus orthogonality to that span decides the single target parity in polynomial time.

For a directed acyclic support graph the span of all feasible words is the coordinate space of vertices reaching a diagonal-zero vertex. In reverse topological order, a new coordinate may be set to zero on every downstream word. It may be set to one exactly when some downstream word has outgoing parity equal to its diagonal. A diagonal zero works at the zero word; a diagonal one works precisely when the outgoing linear form is nonzero on the current span. Subtract the two valid extensions of that word to obtain its coordinate vector in the span.
