# Simultaneous locality in graphic presentations

Let C be a binary matrix representing the boundary columns of a graph with distinct ground-set IDs. For any list L of pairs of nonzero columns (a_i,b_i), append the labeled columns a_i+b_i for i in L. The augmented binary matroid is graphic if and only if the original labeled matroid admits one graphic representation in which the edges in each listed pair share an endpoint.

In the forward direction obtain a graphical realization of the entire augmented matrix and delete the added edges. Every column dependence transfers over GF(2): a relation's support is a disjoint union of circuits, by successively subtracting minimal dependent subsets. Therefore incidence(a_i)+incidence(b_i) is the incidence of the corresponding added edge. Two disjoint nonloop edges have four boundary endpoints and their sum cannot be a graphic column. A pair of parallel edges has sum zero, represented by a loop. Conversely draw each added edge between the two odd endpoints, or as a loop for identical boundaries. This gives precisely the binary representation up to the invertible map on column spans determined by the labeled originals. Standard constructive binary graphic matroid recognition therefore decides this property and supplies a presentation. Discard input loops in the safe-boundary application first.

To transport an arbitrary original boundary T, solve C z=T, declaring infeasibility if inconsistent. In the new graphic representation D put T'=Dz. Equality of the two kernels gives Cx=T exactly when Dx=T'. An output in edge IDs is already a valid original solution. Reconstruct through any earlier free contractions separately.

The minimum over all graphic representations of raw rank of nonlocal differences, or of the optimized rank of the remote menus, is computable in |input|^O(1+k) up to budget k. For the former let each difference menu be the singleton {a_i+b_i}; for the latter use {a_i,b_i,a_i+b_i}. Enumerate all subspaces U generated by at most k options from all menus. Impose locality only for pairs whose menu misses U, by the single graphic recognition test above. If it succeeds, the resulting remote pairs all admit a menu choice in U, proving their rank bound. Conversely, in a successful presentation a basis of the chosen remote differences gives an enumerated U; all pairs whose menu misses it are local there. Rank here is invariant under the representation isomorphism on column spans. Thus rank zero can be recognized by a single graphic recognition (pairs with zero in their menus are automatic). No bound on the number of alternative graph realizations is needed.

For a constructive recognition routine, row-reduce to [I|D] after temporarily deleting zeros and retaining one representative per parallel class. Bixby and Wagner, *An Almost Linear-Time Algorithm for Graph Realization* (1988), solve the tree-path representation problem for D and return the tree. Add each chord at the endpoints of its labeled tree path; reinsert loops and parallel copies with their original IDs. A graphic input may be taken connected for this purpose by gluing one vertex from each component, which preserves the binary cycle kernel. The rank-zero case consists only of loops. https://doi.org/10.1287/moor.13.1.99

For arbitrarily high optimum even after re-representation, take disjoint K4 blocks with one pair of opposite edges per block. Pair the remaining four cycle edges as two adjacent pairs. The added sum for the opposite pair completes the six nonzero rank-three binary columns to the Fano matroid. This has no graphic realization: a simple rank-three graphic matroid has at most six edges (one connected rank-three component maximizes this number). Thus each designated pair is remote in every common representation. Its three differences are nonzero within its own direct summand, giving rank at least the number of blocks for either rank parameter. This is an input-parameter example; the disjoint blocks can themselves be solved separately.
