# Space and treewidth tradeoffs for DAG parity resolution on odd-factor CNFs

Write N for the number of variables in the native odd-factor family in README.md. We use its Ω(√N) bounded-error randomized two-party lower bound for locating a falsified canonical input clause on the stated Alice/Bob assignment promise. A candidate input clause can be checked for actual falsity with two bits: each party checks all of its literals and they exchange the results. The transfer below only needs this search bound, local verification of an input clause, and the proof rules described here.

A proof line is a disjunction of affine GF(2) equations. For every noninput inference, truth of its at most two antecedents implies truth of its conclusion under every assignment. Weakening and ordinary Res(⊕) satisfy this property. Tautological axioms can never be false. A single proof line is false iff each of its equations is false. Splitting its equations by variable ownership thus expresses falsity as equality between two locally computable binary vectors, irrespective of the width or rank of the line. Empty clauses and constant equations obey the same rule. Logarithms below may be taken base two.

* For a configuration schedule of T steps, starting empty and ending with a false empty clause live, let s be the maximum number of simultaneously live clauses. Then s log(T+1)=Ω(√N).
* For any DAG refutation of S vertices whose **undirected inference graph** has treewidth k, (k+1) log(S+1)=Ω(√N). This requires no assumption on the schedule or number of times a shared subproof is used.

Consequently polynomial-length schedules require Ω(√N/log N) simultaneous clauses, and polynomial-size DAGs require treewidth Ω(√N/log N). Fixed clause space or fixed inference-graph treewidth gives size or schedule length exp(Ω(√N)) in its respective statement. These bounds allow arbitrary line width. In the space statement T counts actual operations, including recomputation, so it cannot be replaced silently by the number of distinct DAG vertices.

## Communication primitives

For any publicly listed family of b proof lines, Alice and Bob each form a set of b tokens (line index, local syndrome). The sets meet iff at least one listed line is false. Constant-error public-coin decision costs O(b+1) communication, even when syndrome widths are unbounded. Here is a direct proof. Using fresh public random subsets of the finite token universe, the current sender finds the first set containing its whole current token set, transmits its index with a self-delimiting integer code, and the receiver retains only tokens lying in the named set. Alternate directions until there is an empty set, in which case report disjoint. Intersections can never be erased. On disjoint inputs, conditional on the complete past, the selected subset is still an unbiased independent filter on all receiver tokens: the selection criterion depends only on its bits on the disjoint sender set. A sender of a tokens uses expected O(a+1) bits: its first successful index is geometric of mean 2^a, so its expected logarithm is ≤a by concavity. In pairs of rounds both sets halve in expectation; more precisely each of their expected sizes on its successive turns decays geometrically if terminated sets are counted as empty. Since live senders are nonempty, the expected total communication is O(b+1), including termination flags. Impose a sufficiently large fixed multiple of b+1 as a public communication budget and report intersect if it would be exceeded. Markov's inequality bounds error on disjoint inputs by any desired fixed constant; intersecting inputs always return intersect. Local computation and public randomness are unrestricted.

The smallest-index false line in an ordered list known to contain one can be found with constant error using O(b+1) bits. Repeatedly test its left half, retaining that half when it contains a false line and otherwise retaining the right half. At the jth step reduce the error to at most ε/(j+1)² by O(log(j+2)) independent repetitions, where ε can be any fixed positive constant. The union bound gives arbitrarily small constant overall error. The geometric shrinkage gives total O(b+1) cost; additive per-check overhead costs O(log(b+1) log log(b+3))=O(b+1). Fresh randomness makes these bounds valid conditional on past queries. A single parity clause of rank w also permits deterministic falsity testing in O(w+1) bits after eliminating dependent equations; the randomized bound will be stronger for wide lines.

**Noisy bounded-depth search.** Both protocols below explore a stack of depth at most L. The root is valid. At a valid state, correct tests either provide a locally verifiable output or push a valid child; at an invalid state correct tests pop. Give each step a conditional error probability at most 1/32 using the primitives above. Verify any offered output exactly. A pop from an invalid state matches a distinct previous push into an invalid state, which required an error. A pop from a valid state is itself an error. Any no-progress action also requires an error; this includes a rejected purported output at a valid state if it makes no stack move. Arrange that a rejected output or an impossible internal transition always causes a pop (or a stay at the root). Thus on an unfinished run, the number of pops plus stays is at most the number of errors: charge bad-state pops to their initiating erroneous pushes and other pops/stays to themselves. With J=4(L+1) steps, expected errors ≤J/32. If no output occurs, depth is at least J−2(errors), which exceeds L except on a set of probability <1/3 by Markov's inequality. This does not assume the truth values being searched form a monotone sequence, and it tolerates valid descendants reached through invalid states.

## Live configuration protocol

A configuration is true if all its lines are true on the distributed assignment. The first time stamp is true and the last false. An interval of times is valid if its left endpoint is true and its right endpoint false. Verify both by the token primitive on s lines per endpoint. For a valid interval split at the midpoint, using its truth value to choose a valid half. At an adjacent valid pair a step changed a true configuration to a false one. A deletion cannot do that, and a consequence of available true antecedents is true. Hence this step downloaded a false input axiom. Output it after exact verification. Inferences that simultaneously erase used lines are also sound for this argument because their antecedents were in the old configuration. Batched downloads may first be unrolled into single downloads. The balanced intervals have depth at most ceil(log₂ T); noisy search gives randomized communication O(s log(T+1)), proving the first tradeoff.

## Inference graph protocol

Topologically order all vertices of the proof DAG once. Work within the connected component containing its false conclusion. The initial target t is that conclusion. An active state consists of a connected induced set W and a target t in W. Its outside boundary X comprises the neighbors of W outside W in the undirected inference graph. A state is valid if t is false and all boundary vertices earlier than t are true. This takes O(|X|+1) bits to check with constant error. Initially X is empty.

Write b=k+1. Always maintain |X|≤4b. In the induced graph on W∪X, take one bag of a width-k tree decomposition balancing the number of W vertices, and a second bag balancing the number of X vertices. Such a bag for any nonnegative vertex weights follows by assigning each vertex's weight to one bag containing it and taking a centroid of the weighted decomposition tree. A connected component remaining after deletion of this bag lies entirely on one branch of the decomposition tree, by connectedness of each vertex's bags and the edge covering condition. Let Z be the union of the two bags, of size ≤2b. Each component W' of W minus Z has at most |W|/2 vertices. Its external neighbors are in Z or in X minus Z. All its neighbors in X minus Z belong to the same component of (W∪X) minus Z as W', so there are at most |X|/2 of them. Hence |∂W'|≤2b+|X|/2≤4b. Width-zero, empty-boundary and singleton-W cases all satisfy these bounds. The graph and its decomposition are public; no efficient treewidth computation is needed for this communication simulation.

At a valid state find the earliest false u in (Z∩W)∪{t}, at cost O(b). If u lies outside Z it must be t. Descend into its component W' of W minus Z with the same target: every new boundary vertex earlier than t is true. If u is in Z and is an input axiom, offer it as output. Otherwise find a false antecedent v by testing its at most two parents. Such a parent exists by soundness. It cannot lie outside W because v neighbors W and precedes u≤t, and it cannot be in Z because u was earliest false there. Descend into the component W' of W minus Z containing v and use v as the new target. All introduced boundary vertices earlier than v lie in Z∩W or the old boundary and are true. Either kind of descent preserves validity. Bad query results leading to nonexistent parents or components are handled by popping. Graph-separated sets shrink by a factor two, so the stack depth is at most 1+ceil(log₂ S). Combining constant-error checks with the noisy search gives O((k+1)log(S+1)) communication.

The search lower bound and the construction are inherited from the odd-factor work. The conclusions concern clause space and inference-graph treewidth. They give neither a lower bound for high-treewidth polynomial-size DAGs nor a length bound based on line width alone.
