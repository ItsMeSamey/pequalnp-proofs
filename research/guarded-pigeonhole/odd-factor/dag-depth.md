# One parity query per binary semantic inference

The falsifying assignments of a disjunction of GF(2) affine equations form an affine flat, possibly empty. Let C be the falsifying flat of a derived line and let P and Q be those of its two sound parents. Soundness means C⊆P∪Q. If C is empty the line is unreachable by falsity tracing. If either parent contains C, choose it without communication. Otherwise C∩P and C∩Q are proper affine subflats, each of size at most |C|/2. Their union is C, hence both have half the size and are disjoint hyperplanes relative to C. Two disjoint affine hyperplanes of a binary affine space are parallel complements. Extend their common relative normal to the ambient variable space by linear algebra. Testing this one parity tells which parent is false whenever the current line is false.

Start at the contradiction, and follow false parents down a DAG. Each parity query costs at most two deterministic communication bits under every partition of the input variables, since each party contributes its parity and both can learn the branch. Thus a depth-d proof with unary or binary semantic inferences gives a deterministic protocol for falsified-input-clause search of cost at most 2d, with no dependence on clause width or falsity rank. Leaves and the public node reached along each path identify the output. Restricted to the routed matching and odd coloring inputs in the native odd-factor construction, the output must identify a bichromatic matching edge. The Babai–Gál–Wigderson search lower bound gives d=Ω(n)=Ω(√N). This is a depth bound for DAGs and does not derive a comparable exponential size bound from depth.

For a step with at most k parents, on the currently known affine slice C there is always a parent covering at least |C|/k points. Its intersection has relative codimension at most floor(log₂ k). Test the corresponding equations by global parity queries. If a test fails, the observed answers leave an affine slice avoiding this parent; iterate with one fewer possible parent. The total worst-case query count is at most the sum of floor(log₂ j) for j=2,...,k. Inferences with general nonaffine line falsity need not have this property.
