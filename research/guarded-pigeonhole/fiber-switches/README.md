# Recognizing a bipartite chart on the entire marker fiber

Let A be alternating, F={(x,Ax): Lx=z}=w+U in V=GF(2)^{2n}, and t=rank L after resolving any inconsistent row. Pairs at a vertex are (x_i,y_i), with defect x_i y_i. Use q(x,y)=x·y and its polar symplectic form ω. A coordinatewise affine permutation preserving the local defect for every local input fixes (1,1), so is exactly θ_T(v)=Tv+1+T1 per vertex, with T an invertible local 2×2 matrix. The three other symbols can be permuted freely; optional vertex relabeling adds nothing to recognition.

For fixed t one can recognize and construct any possible transformation of this type taking F exactly onto a codimension-t affine selector fiber in the graph of a bipartite adjacency B. This allows changes chosen using the entire marker system. A successful transformation transports assignments, every indexed guard defect, exactly t marker equations, and witnesses.

**Completion test.** W_A=graph(A) is a totally singular Lagrangian. Find all n-dimensional Lagrangian spaces W with U contained in W and q(w+W)=0 identically. Apply the local-linear CSS recognizer in ../degree/local-css.md to W. If T maps W linearly to W_B=graph(B) with B bipartite, then θ_T(w+W) is a coset c+W_B. Its q vanishes identically by preservation of every local product. Since q|W_B=0, polarization gives c∈W_B perpendicular = W_B. Thus θ_T(F) is a codimension-t affine space inside W_B; selector projection is bijective and Gaussian elimination gives the desired t new marker equations. Conversely any such θ_T making F into a marked bipartite fiber supplies W=T⁻¹W_B; its affine preimage of W_B is w+W, containing F and having zero q throughout. Hence testing all completions is necessary and sufficient in this local-transformation model.

**Only 30 candidates for t=3.** Lagrangian extensions of U correspond to Lagrangians of U perpendicular modulo U, dimension 2t. The translated form q_w(v)=q(v)+ω(w,v) descends to that quotient and is split since W_A/U has dimension t and is totally singular. Only its maximal totally singular spaces are needed. For explicit coordinates write v=(x,Ax+Lᵀc). Modulo U this has coordinates (p=Lx,c), and q_w=(p+z)·c. Thus one can enumerate the candidate spaces directly, retaining t-dimensional isotropic spaces with this quadratic form zero. There are 1 candidate for t=0 and 2 times the product of (2^j+1), 1≤j<t, otherwise. Indeed nonzero singular vectors in hyperbolic dimension 2t number (2^t−1)(2^{t−1}+1); counting vector/maximal-space incidences gives the displayed recurrence. Changing p to p+diag(z)c makes the explicit form standard hyperbolic.

**General chart and PC transfer.** To run the linear CSS test on arbitrary W, let X be its first-coordinate projection. Its vertical kernel is 0×X perpendicular. Choose an information set I for X and swap axes outside I. The new first coordinates are independent on W: x_I=0 gives x=0, and then y outside I zero with y∈X perpendicular gives y=0. This gives a symmetric graph chart; shear away the diagonal and use the local recognizer, composing all linear maps before lifting affinely. Native PC simulations in both directions preserve degree d up to max(2,d). Substitute the affine first coordinates of θ_T(x,Ax) for the target selectors. The discrepancy between the resulting Bx' and second coordinates is affine, zero on the marker fiber, thus a linear combination of marker rows. Its product with x'_i costs degree two. Local defect preservation holds modulo Boolean axioms, target marker rows also pull back into the source marker span, and affine substitutions preserve degree. Use the inverse local action for the reverse simulation.

**Obstruction.** If L_i=0, then u_i=(e_i,Ae_i) belongs to U. Any locally CSS completion has a coordinatewise trace-one idempotent P that preserves W. Hence ω(Pu_i,u_j)=0 for neutral i,j. With P_k=[[p_k,q_k],[r_k,1+p_k]], for i≠j this means Aij(p_i+1+p_j)+Σ q_k Aki Akj=0. Every neutral edge with no common neighbor in the full graph forces p_i+p_j=1. An odd cycle of such edges excludes every local completion. Take the neutral 5-cycle 0,1,2,3,4,0 and add the path 0–5–6–7–1. Assign independent marker columns only to 5,6,7, target all ones. This biconnected instance is feasible via the induced cycle 0,5,6,7,1,0, yet has no same-vertex local completion. This is not an obstruction to auxiliary-variable reductions or different existential encodings.

## A fully varying indexed obstruction

A stronger counterexample retains genuine variation at every site. Take the neutral 5-cycle and add the ear 0–5–6–7–8–9–10–2. On its six internal vertices put columns e₁,e₂,e₃,e₁,e₂,e₃, target (1,1,1). All eleven selectors and all eleven indexed defects are nonconstant on the 256-element marker fiber, which contains 16 witnesses. For example selecting only 5,7,9 is feasible. The graph is biconnected; the neutral 5-cycle still obstructs every local completion.

Indeed in this example there cannot even be an arbitrary affine selector change on the fiber that maps into a bipartite chart, has an injective fiber map, and preserves all indexed defect values. For each site the original and transformed affine pair maps have equal, nonempty proper inverse images of the defective symbol 11. The direction of that inverse image is the kernel of each pair map. Thus the pair maps have the same kernel, and identify their affine images by an affine isomorphism fixing 11. Extend that isomorphism to an affine permutation of the local plane fixing 11. The resulting coordinatewise action agrees with the proposed arbitrary affine change on the entire fiber, which the neutral odd-cycle obstruction precludes. The transformed fiber has the same dimension automatically as the global pair maps are injective under this local action. No claim is made when the indexed defects may be mixed or only existence is required.

The executable completion.py returns the bipartite graph, exactly t marker rows and new target, and all local linear matrices. To invert a witness, apply the inverse affine lift vertexwise to its graph pairs and read the original first coordinates. check_completion.py checks entire fibers, not only accepting supports.

## A neutral induced minor

Let N consist of zero marker columns. For any completion W restrict x_i=0 outside N, then project away all pairs outside N. The result is isotropic since the deleted pairs contribute zero to the symplectic pairing. It already contains every direction (e_i,A[N]e_i), i∈N, hence equals graph(A[N]). Under a local transformation these restrictions become one linear measurement per removed pair, giving the three local Pauli deletions, i.e. vertex-minor operations up to local equivalence. Therefore every completion graph has A[N] as a vertex-minor up to local equivalence. This obstructs conversion to a vertex-minor-closed target class whenever A[N] is outside that class.
