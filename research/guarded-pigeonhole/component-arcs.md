# Affine export on directed networks of terminal-rich reciprocal components

Absorb each diagonal coefficient into the linear coefficient b_i over GF(2), so the guarded row is x_i(b_i+sum_{j != i} A_ij x_j). Draw an undirected edge for A_ij=A_ji=1 and let its connected components be C. Draw an arc i→j for A_ij=1, A_ji=0. Assume that every arc joins distinct components, each unordered pair of components is joined by at most one arc, and each component contains at least two terminals (vertices with b_i=1). The directed graph of components can contain arbitrary directed cycles.

For each component with no outgoing arc, the parity sum of its terminal bits vanishes in every solution: summing that component's guarded rows cancels every reciprocal term. These linear forms generate every affine consequence of the unmarked network. Consequently degree-two PC computes the exact affine hull, and a single affine marker can be decided in polynomial time with an explicit witness.

To prove completeness consider a homogeneous candidate form l. (The zero support is feasible.) A component supported alone is symmetric. Its unmarked singletons are feasible, and a shortest path between opposite-labeled terminals, minimized over all opposite pairs, is induced with no interior terminal. If l vanishes on all nonterminal singletons but has different labels on two terminals of a component, this path is an odd-marker witness. Thus any outstanding l is proportional to b on each component, with coefficient c_C. For any feasible x, summing the weighted rows then gives

    l(x) = sum_{i→j} c_{C(i)} x_i x_j.

If all components with c_C=1 lack outgoing arcs, the initial component sums prove l=0. Otherwise select an arc i→j with c_{C(i)}=1. In the target component find a symmetric feasible assignment containing j: if j is not a terminal use its singleton, else take a shortest path to another terminal. In the source component flip b_i (because x_j=1) and find a symmetric feasible assignment containing i in the modified system. This succeeds: if i becomes unmarked use its singleton, otherwise at least one other marked vertex exists. Set all other bits zero. The only arc with both endpoints in the two selected components is i→j by hypothesis. Thus both local assignments obey every guard in the whole network, and the displayed identity gives l(x)=1. All operations use elementary graph searches. The locally symmetric SCC theorem need not apply: a directed cycle of three reciprocal components gives a strongly connected nonsymmetric network. This is a positive subclass, with no restriction on width or degree except as specified.
