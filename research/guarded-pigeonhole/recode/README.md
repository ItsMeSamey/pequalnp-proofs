# Three arbitrary selector rows versus a faithful split witness

Take the connected bipartite tree a–i–j–b with additional edges i–p and j–q. Add an apex v adjacent to i,j,p,q. Its degree is four, and the graph is nonbipartite. Give weights a=1, b=2, i=v=4, others zero, and request score 7. The core score map has rank three. Both a and b must be selected, forcing their unique neighbors i,j unselected. The remaining marker bit forces v selected. Vertices p and q each see exactly v and cannot be selected. The original graph has the unique witness {a,b,v}; its apex-off branch is infeasible.

In the standard bipartite split with terminals l,r linked by a private length-three path, the unique faithful lifted witness is X={a,b,l,r}. All attached neighbors vanish, and either selected terminal forces its adjacent path interior to zero. There are no edges within X, so every one of its 16 subsets is a legal split assignment. Restrict any three affine rows, with arbitrary coefficients on every lifted selector, to the four-dimensional selector space on X. If they accept X, their kernel contains a nonzero direction on X, giving a distinct accepted subsupport. Every deletion retaining X retains that subsupport. A positive selector row is included in the three rows. Thus an unisolatable witness occurs even with rank-three core, connected bipartite base, unique original witness, and infeasible baseline. Four rows suffice by pinning all four vertices after restricting to X, or by the usual split equality and three original rows. cube.py checks the native enumeration. This is a sharp limitation of exclusive-query witness isolation; arbitrary adaptive decision is a separate question.

More generally, let X be a genuine split witness and W a linear space of directions supported on X such that every X+w is a legal split assignment and no nonzero w gives a true lift. Every isolating affine query retaining X needs at least dim W rows. A certificate can use the adjacency matrix induced by X: if W lies in its binary kernel and that matrix kills the all-selected vector, all these subsupports are valid. A non-edgeless dimension-four example is in ../degree/marker-query-deletions.md.

## Distinguishing the earlier fixed-score pair

On the degree-four pair in ../joint/README.md, one positive core selector plus two original joint rows suffices without deletions. Require core vertex 0, the split terminal seeing its shore, and the middle score bit all to equal one (terminal names in ../audit/apex/deletions.py). The N=226 instance admits the support consisting of core vertices 0,2 and that terminal; N=225 does not. Two rows suffice if the second row is arbitrary: require x_0=1 and the parity of the neighbors of vertex 0 in the N=225 split graph to equal one. This contradicts its guard, but {0,that terminal} witnesses the query in N=226. These observations distinguish transcripts; they do not decide arbitrary original target instances.

With unrestricted linear re-encodings, two-row witness queries reconstruct even a hidden adjacency matrix without deletions. For each i pin x_i=1 and start from known support e_i. On the other coordinates compute the annihilator of differences from that support. Maintain the span D of differences returned and a space T of tested annihilating functionals. Pick a functional in D-perp outside T, ask whether it takes value one with i selected, and add either its returned difference to D or the forced-zero functional to T. The gap dim(D-perp)−dim(T) drops each time. At convergence the pinned-span theorem in ../apex-gauge/README.md identifies neighbors of i as the union of supports of a basis of T. This takes O(n²) two-row witness queries; it reconstructs the graph, not weighted feasibility. With named deletions, retaining just i,j and pinning both tests whether ij is absent.

## Every homogeneous two-terminal replacement has the same isolation obstruction

Keep the usual identification of two opposite-shore terminals as the apex: an active faithful lift has both terminal selectors one and its core selectors must equal those of an original witness. Replace the private length-three path by any homogeneous bipartite gadget meeting the core only through these two terminals at the routed apex neighbors. Consider any faithful lift X. Its core support is still {a,b}, which has no edges to the private graph. The selected private set S must be even internally. Denote its two nonempty shores by U,V; each contains the corresponding terminal. The four sets ∅, U, V, S are valid private supports because each individual shore is independent. Together with the choices of a and b there are 16 valid subsupports of X, forming a binary subspace with disjoint generators 1_a,1_b,1_U,1_V. Only the full corner projects to the required original witness. Thus three arbitrary affine selector equations cannot isolate a faithful outcome for any such gadget or any of its witnesses. If the replacement has no true lift it cannot realize the target in the first place. This argument permits arbitrary sizes, auxiliary coefficients, and induced deletions. Four rows suffice for the standard path, making the general obstruction sharp there.

## A three-row branch that removes a whole false-twin class

In a four-marker bipartite graph, take an independent class C with identical external neighborhoods N, representative c and score columns ℓ_i. Let D be the span of the differences ℓ_i+ℓ_c. Conditional on y=1_N·x=0, all class guards vanish. The exterior guards depend on the class selectors only through their total parity p. At fixed p their possible scores form exactly pℓ_c+D: the binary vectors e_i+e_c generate the even-parity directions. Consequently identify C with a single representative carrying its original score, project the four marker rows and target modulo D, and add y=0. If dim D≥2, at most three independent rows remain. A positive witness lifts by solving for the class bits with the specified total parity and actual missing score, with all exterior bits untouched.

If the branch is negative, every target witness must have y=1, forcing every class selector zero. Delete C; any solution of the smaller four-marker instance extends by zeros without any extra y=1 row. Thus each eligible false-twin class yields one polynomial query and, if needed, a strictly smaller four-marker instance. Iterate until terminal rank is at most three, a known graph class is reached, or no eligible class remains. This is a complete polynomial solver whenever the terminal case is tractable. For one apex, apply it to the four-row equality lift; in particular independent twin blocks of the original core whose members have identical incidence to the apex remain eligible if their score differences span dimension two. The test also applies for smaller D whenever the actual combined rows of the collapsed branch have rank at most three. twins.py compared 2,448 targets and verified actual witness lifts; 52 feasible targets genuinely needed the zero-class residual branch.

For example, put three independent core vertices of weights 0,1,2 on the left, adjacent only to a right vertex b of weight 4. Let an unmarked apex be adjacent to all four vertices and request 5. The bare branch fails since b is required and excludes the entire left class. The active branch succeeds via the triangle formed by the weight-1 vertex, b and the apex. An arbitrary bipartite neutral subgraph may be attached at b, with any additional apex edges to its new vertices; setting those new selectors to zero preserves the witness and the bare impossibility. Its width and the apex degree are unbounded. The rich twin class persists, and removing it leaves marker rank at most three in the equality lift.
