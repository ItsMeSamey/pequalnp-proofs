# Independent checks on the classical incidence upper bound

Pair a point p of PG(2,q) with its polar line c_p for the ordinary nonsingular dot product, and define z_p=r_p OR c_p. Incidence on distinct observed labels is symmetric. A diagonal call on p is handled with its original two flags if p is absolute. There are O(q) such exceptions: in odd characteristic the normalized chart (1,a,b) has at most two b values per a; the other charts have at most q+1 points. In characteristic two the absolute points form the projective line x+y+z=0. Thus one AND per absolute point and an output disjunction suffice.

Use t a power of two with N^(3/8)≤t<2N^(3/8). Encode distinct labels as distinct edges of a bipartite C4-free host with t² vertices on each shore and t³ edges. Its edge (x,y,m) joins point (x,y) to line (m,y−mx) over GF(t); vertical lines need not be used. Pick the embedding by applying a uniform reversible affine permutation on GF(t³) to the ranks 0,...,N−1, using any fixed binary vector isomorphism to the three GF(t) coordinates. Scalar-affine maps are transitive on ordered pairs of distinct edges. Each edge shares a host endpoint with exactly 2(t−1) other edges. The expected number of colliding positive unordered pairs is therefore at most N(q+1)·2(t−1)/(t³−1)=O(N^(3/4)). Deterministically select a good map by enumerating the O(t⁶) scalar-affine maps and counting collisions; one need only encode the chosen map for evaluation.

For each host vertex OR the selected incident z flags, paying at most 2N binary joins in aggregate. For each exceptional unordered positive pair add its own AND of the two z flags. When there are four active endpoints, the two labels had no shared endpoint and give two distinct points and lines. By C4-freeness only one of the two possible perfect matchings consists of host edges; that matching is precisely the original pair. Decode both labels by the inverse affine map. Invert the normalized projective-point ranking (q² points (1,a,b), q points (0,1,b), one point (0,0,1)), and evaluate their dot product. These are fixed finite-field operations on O(log N) bits, implementable in polylog N bounded-fanin Boolean gates using schoolbook arithmetic and fixed field representations. An unused host edge within a wrong matching cannot matter since the valid matching is unique.

At most four endpoints are active on every promised input. Compute thresholds up to four for each prefix and suffix of the M=2t² host flags in O(M) monotone gates. On the four-endpoint slice a negative rail for each flag is supplied by threshold four among the other flags. This needs constant work per omitted flag using the prefix and suffix counts. An overall threshold-four guard suppresses any Boolean simulation off this slice. With both rails available on this slice, dual-rail De Morgan simulation replaces each bounded-fanin Boolean gate by O(1) monotone gates. Min and max active indices in each shore recover its two endpoints. A tree over 2^d-sized segments computes a nonempty flag and the two d-bit extreme positions by Boolean multiplexers; each such segment costs O(d), and summing over tree levels costs O(M). Values on empty segments are arbitrary; the nonempty flag determines which child's extremes to use. Together the N pooled variables, the ≤2N endpoint joins, and all exceptions, guards, decoding and collectors cost ≤3N+O(N^(3/4)). Combined with projective-plane-basins.md the size is 3N+O(N^(3/4)) for classical projective planes.
