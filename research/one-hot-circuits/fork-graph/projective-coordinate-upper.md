# A direct coordinate upper bound for classical projective incidence

For q a prime power and N=q²+q+1, the point–line incidence matrix of PG(2,q) has a monotone one-per-shore circuit of size at most 3N+O(q). In combination with the separate physical lower bound, its size is between 3N−O(N^(3/4)) and 3N+O(sqrt(N)). The construction is deterministic and needs no auxiliary incidence host.

Use the dot-product polarity to associate every line to its projective normal. Normalize labels in charts A=(x,y,1), B=(x,1,0), and C=(1,0,0), with x,y in F_q. Index them consistently on both shores. Form z_i=row_i OR col_i in N gates. On a diagonal input only label i is lit; include row_i AND col_i for every absolute point to settle such inputs. There are O(q) absolute points: in odd characteristic each fixed affine x permits at most two y satisfying x²+y²+1=0 and only q+1 labels lie outside that chart; in even characteristic the equation is a line.

Use two endpoint families. A label has one endpoint in each family, storing its first and second coordinates, respectively, each tagged by the chart. A-coordinates run over q values per family. B-coordinates run over q first values and a single second value. C has one endpoint per family. Each coarse endpoint class admits a bipartition with no edge between two distinct incident labels in the same color. Indeed at fixed affine x, adjacent distinct labels have yb=−1−x². If this scalar is nonzero then b is uniquely determined by y, giving a matching after ignoring loops. If it is zero, the graph is a star with center y=0. The same applies at fixed affine y. In B the single second-coordinate class has positive pairs xa=−1, again a matching; B first-coordinate classes and both C classes are singletons. Chart tags keep different charts separate. Fix a proper bipartition of each class and split the corresponding endpoint into at most two colored endpoints.

For each colored endpoint compute the OR of labels z_i wired to it. Total OR cost is at most 2N, since each label feeds exactly one endpoint on each side. There are O(q) such indicators. One label lights exactly two; a positive distinct pair lights four since the two row-side coordinates are either in different classes or correctly colored apart, and likewise for the column-side coordinates. A negative distinct pair may light fewer than four, which is harmless.

Guard the remaining output by at least four colored endpoints. On the promise this means exactly four, two per coordinate family. The negative rail for each colored flag on this guarded face is given by at least four lit among ALL OTHER endpoint flags. All negative rails and the guard cost O(q) monotone gates using prefix/suffix threshold counters through level four and the five splits around each omitted position. Constants can be folded. Both rails then support ordinary Boolean decoding with constant-factor monotone overhead. Coarse endpoint flags can be recovered by OR of their colors. Extract the minimum and maximum coarse identifier in each family (equal if a coordinate repeats). Balanced trees storing interval-relative first/last lit indices and nonemptiness cost O(q): height-h nodes cost O(h+1), summed against a geometrically decreasing node count. Identification order is by chart first and coordinate encoding second.

If the chart tags agree for the two active labels, no pairing of the x and y entries is needed. In A test the sum of the two coordinate products plus one; indeed the dot product between (x,y,1) and (a,b,1) is xa+yb+1, invariant under interchanging y,b. In B test xa+1. Two distinct labels in chart C are impossible. If chart tags differ, the tag identifies which first coordinate is paired with which second coordinate; recover both vectors and test their ordinary dot product. The computation of equality to zero and field products has Boolean size polynomial in log q by polynomial-basis arithmetic, absorbed by O(q). The guarded decoder is exact on every input with four lit flags, including negatives. With fewer flags the only possible positives are the absolute diagonal cases already handled on the original raw wires. Counting the final collector and the O(q) absolute terms yields 3N+O(q).
