# A one-fork monotone circuit permits at most two induced disjoint P4s

The positive graph of a row–column Boolean matrix has one vertex for each row and column and one edge for each positive cell. In a live binary monotone circuit on d used raw flag wires, at most d gates permit at most one extra outgoing occurrence: for g gates the excess is 2g−(d+g−1)=g−d+1. A circuit with at most one such occurrence is a formula or has one twice-used wire H, which can itself be raw. Its dedicated ancestry is a read-once tree; every raw in that tree affects the output exclusively via H. All other raws occur only once in the outer formula with H exposed twice. This is a structural statement about the original number of used raws. Restricting to a subset of rows and columns and simplifying can only decrease the number of forks, even when it changes the number of used variables.

Work first on any submatrix with no universal row or column, meaning every row and every column contains a zero. Each individual flag alone is rejected by monotonicity below a negative cell. This argument does not require all flags to be used. Any logical zero constants on restriction can be simplified.

A read-once monotone formula rejecting singleton inputs has positive components on row–column pairs that are complete bipartite. At an OR root both disjoint child formulas reject their singleton inputs, and the pair graph is the disjoint union of theirs. At an AND root the two nonconstant child trees have disjoint raw sets and vanish on empty. A positive pair therefore has one singleton in each child, accepted there. This yields at most two vertex-disjoint bicliques according to the orientation of the two singleton shores. The empty graph and isolated vertices cause no difficulty.

Partition the flags into the inside of H's dedicated tree and the outside. Unused flags may be placed outside. On the inside–inside block all outside flags vanish and the final function is a monotone unary function of H. If constant the block is zero (a constant one would accept the empty input). Otherwise it agrees with the read-once tree H, which then rejects each inside singleton. The components in that block are thus complete bipartite. On the outside–outside block set H=0 and simplify: the remaining formula is read-once and singleton-cold, so its components too are complete bipartite.

For an outside row x and inside column y, the outer tree sees x and H(y). On setting H=0 it must reject, since x alone rejects. Its unary function of H is thus either zero or H; the choice depends only on x. The entire band is a single biclique, with column side the inside columns hot as singletons at H, and row side those outside rows enabling the unary identity. The transposed band is also a single biclique. Empty bands are allowed. Each nonempty cross band lies wholly within one connected component. Any component using no cross edge is already complete bipartite by the two diagonal blocks. There can therefore be at most two components that are not complete bipartite.

If the matrix contains an induced disjoint union of three copies of the four-vertex path P4, retain just their rows and columns. The submatrix has no universal vertices and all three components are non-bicliques, contradicting the preceding result. More generally one may use any induced submatrix with no universal vertex and three non-biclique components. This proof concerns induced disjoint unions; merely exhibiting three vertex-disjoint paths in the original graph does not suffice.

The component bound is sharp. On four rows and four columns, take H=c0∨r2, A=c1∨r3, B=r0∨c2 and C=r1∨c3. Output ((H∨A)∧B)∨(H∧C). The eight-gate circuit has one doubled wire H and reads all eight flags. Its positive cells are 00,01,10 and 22,23,32. It realizes precisely two disjoint P4s.
