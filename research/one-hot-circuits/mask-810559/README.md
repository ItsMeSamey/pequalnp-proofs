# Exact size ten for mask 810559

The standalone Lean file imports `PEqualNP.Defs` and proves both that a nine-gate representation is impossible and that ten gates suffice on all 24 one-per-shore inputs. The compiled object is compressed. Decompress it in this directory before running `sha256sum -c SHA256SUMS`. The two declarations' axiom reports appear in `axioms.log`.
