# Register search on the four-by-four weighted quotient

Little-endian cell 4r+c uses quotient indices (0,3,4,default) on both shores. The target is 43333. Flags 0 through 3 are row indicators and 4 through 7 column indicators. Each used default flag costs one gate before the decoder. This package certifies the weighted quotient; applying it to arbitrary original five-by-five circuits requires an independent normalization.

All sixteen row/column pairs are enumerated. The rows and columns of the target are respectively pairwise distinct, so at least three indicators per shore must occur. Their 25 possible live supports are covered. For support f paying p for its default flags, a size-nine design with t NOTs has at most b=9−p−t decoder binaries. With n live inputs, n−1 binaries are necessary to connect them to one observer; all budget combinations satisfying that inequality were tested. Smaller designs fit the cap.

The register state contains the sorted live 16-bit truth functions. A topological traversal of any irredundant decoder admits exactly this description: consume the operand at its last use or retain it if needed later. For NOT there are two choices, and for a binary gate four. Introduce the output as a fresh register. A set of k current live signals in a minimal traversal needs at least k−1 future binary merges to reach the sole observer. This justifies the budget test after each transition even when the unused budget is slack. Omitting constant or duplicate values preserves completeness when all supports are examined: in a least-size witness, a constant Boolean function may be propagated and a recomputation of an available register may be redirected to that register. No two distinct nodes need compute the same function; removing a dependency might shrink the input support, which is also searched. Identical binary operands cannot occur in a minimum. Merging two states with the same live-function multiset and the same remaining budgets preserves all possible completions. Each positive/negative cell pair must be distinguished by some live value. The union of these separation signatures must therefore be complete at every prefix. The unsigned 64-bit signature suffices since any partition of 16 cells has at most 64 cross pairs.

Build register.cpp with C++17. The four arguments are target, binary cap, NOT cap and input flag mask. pilot.py uses /dev/shm/official-7879121-register. Its sole repeated key is the initial six-flag binary-7 NOT-2 pilot. For the adjacent control run the same executable on 43269 8 1 119. Run audit.py from this directory to regenerate the 75-key ledger and validate both positive traces on all 16 cells. The unrestricted search recovered size ten for 43333 and size nine for its one-bit neighbor 43269.
