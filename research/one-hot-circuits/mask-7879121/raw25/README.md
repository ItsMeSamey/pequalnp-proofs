# Original-domain live-frontier check for the five-by-five table 7879121

Truth bit 5r+c records the value on raw row r and column c. Bits 0..4 of an input support select the five row flags. Bits 5..9 select the five column flags. Supplied controls and target computations use the original 25 assignments.

Enumerate every nonempty support of the ten physical flags. A support survives if every two assignments with different target bits differ on at least one selected flag. There are 49 surviving supports. For each such support of size d and each nonnegative NOT cap t, use binary cap b=9−t provided b≥d−1. This gives 147 distinct direct physical keys. Every live circuit of size ≤9 is covered by its actual support and actual number of NOT gates because unused binary budget can remain. A live circuit joining d input nodes into one observable output needs at least d−1 binaries. Unaries do not affect this inequality.

The search retains the sorted truth masks of pending wires. Choose one operand for NOT or two for AND/OR. Each operand may be consumed (last use) or retained (future use). A remaining budget of b binaries can merge at most b+1 live wires. A least-size counterexample would have no recomputed available function and no constant gate, since substituting equal functions or propagating constants preserves the observed truth table. Any loss in used input support from these simplifications is allowed by the exhaustive support loop. All candidate gates have exact 25-bit semantics. Memoization includes both remaining budgets. A positive/negative pair that all pending wires fail to distinguish remains indistinguishable in every completion.

The separation mask has three 64-bit words, enough since a 25-point table has at most 156 opposite-color pairs. For each pair (p,n), a wire's separation bit equals its p-bit XOR its n-bit. Three disjoint chunks of wire coordinates contribute those two endpoint bits to lookup tables; XORing the three table entries produces the separation mask. ORing those signatures over pending wires tests whether all target-opposite pairs are separated. No row/column identification, twin permutation, quotient substitution or derived flag is used.

Compile register25.cpp with C++17 and install the temporary executable at /dev/shm/register25. run.py derives and writes the keys, runs the native solver for each, then optionally searches for two larger positive controls. resume.py continues all missing negative keys from the recorded log. audit.py independently regenerates key coverage using raw cell pairs and replays the separately supplied ten-gate DAG from control10.json on all 25 cells.
