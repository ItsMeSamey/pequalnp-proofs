# Validating the fixed odd-selector compiler for signed DNF

Index the explicit DNF's raw terms (including duplicates and subsumed terms). For each false literal impose that the sum of its terms' selector bits equals zero. Require an odd total number of selected terms. Any true term gives a unit selector. Validate that the converse holds for all assignments. If physical sites for the two signs of a variable are used, they have complementary values; enforce this semantically in the validation domain or count an explicit affine copy equation per complementary alias. This is universal compiler correctness, distinct from satisfiability of one compiled instance.

Fix an assignment to all k variables used with both signs. R is the matrix of all their false literal rows on the ORIGINAL selectors. Each raw term's remaining unate variables form a column in A. Let W={Ae: Re=0, 1.e=1}. At a remaining assignment the compiler accepts exactly when some w in W is supported on the true unate variables. A term survives if its column in R is zero. Its remaining term vector belongs to W via its unit selector. If a surviving term is empty, this fiber always succeeds. If no terms survive, correctness is equivalent to W being empty (consider all remaining variables true). Otherwise let C be the inclusion-minimal distinct surviving terms.

For any inclusion-minimal hitting set b of C, each i in b has a private term with intersection exactly {i}. Hence the projection of the affine W onto b contains all unit vectors, and consequently all odd vectors. If any w in W has even intersection with b then the projection is full, including zero, and there is a spurious acceptance with false-literal set b. Conversely any semantic NO has a false set containing a minimal hitting set. Thus validity amounts to b.w=1 for every minimal b and w in W. Since C is included in W, every member of C must intersect every minimal b oddly. This is the standard definition of a binary clutter. Lehman's triple criterion checks it in polynomial time: every symmetric difference of three distinct members must contain a member. See Lehman, A solution of the Shannon switching game (https://doi.org/10.1137/0112059), Seymour, The Forbidden Minors of Binary Clutters (https://doi.org/10.1112/jlms/s2-12.3.356), and Cornuejols, section 6, proposition 6.1 (https://www.andrew.cmu.edu/user/gc0v/webpub/ideal.pdf).

For binary C make a matrix with rows indexed by its terms, one incidence column per remaining unate variable, and another column p of all ones. Circuits through p have exactly the form {p} union b for minimal hitting sets b: any b hits all terms oddly, and any solution of the matrix equation contains a minimal hitting set. A minimal-support solution is therefore just such a hitting set. In the component of p, the circuits through p span its binary cycle space. Here is a direct proof. Take a basis containing p, and a shortest alternating path from p to a nonbasis column j in the fundamental graph. For each prefix ending at a column, sum the fundamental circuits of the prefix columns. This contains p and is itself a circuit. Any subcycle could use only those prefix columns, and every intermediate basis row cancels, forcing equal coefficients at the two adjacent columns; no other prefix column is adjacent there because the path is chordless. Thus only zero and the full sum are possible. Successive prefixes express the fundamental circuit of j as a sum of circuits through p. Components outside p are irrelevant.

Test the condition by checking orthogonality to a fundamental cycle basis of this component. For an affine base point w and directions v of W test (w,1) and all (v,0). Equivalently test (Ae,1.e) over a whole basis of ker R, once an odd e exists. This also handles every original nonminimal term. The raw unate validity test is polynomial time. The signed test takes 2^k times polynomial time; falsely fixed terms must remain as selector slots. Alternatively keep the distinct rowspaces span(R) which arise by successively selecting one of each pair of bipolar rows. A rank-q span of all these rows permits at most the number of subspaces of F2^q per layer, at most 2^(q²/4+O(q+log(q+1))). This gives another fixed-parameter bound.

When k is unbounded, universal validity is coNP-complete even for consistent, inclusion-minimal signed terms of width at most three. Given a signed 3DNF F, add on fresh variables the disjunct ac OR ab OR bd. If F is tautological, any input admits a unit witness. If not, use a false input of F and a=b=0,c=d=1. The odd selector on the three fresh terms passes both failed rows 110 and 011 although the full DNF is false. Remove duplicates, inconsistent terms and subsumed original terms before the reduction. An original empty term is a trivial tautology and can be sent directly to a fixed faithful instance. A spurious input and odd selector are a polynomial NP certificate of invalidity. This lower bound uses complementary-literal tying, and asserts no SAT hardness for the fixed positive marker by itself.
