# Two symmetric matrices on the same Boolean diagonal

A common Boolean diagonal making symmetric binary A and B nonsingular is deterministically findable in polynomial time if one exists.

Independently choose Y with M=A+diag(1_Y) nonsingular. Extend leading principal blocks: toggling a new diagonal changes its determinant by the already nonzero preceding minor. For S=X symmetric-difference Y put C=I+M^{-1}; the determinant lemma gives det(A+diag(1_X))=det C[S] because det M=1. Set d=diag C, K=C+dd^T alternating, and H=[[K,d],[d^T,0]] with extra index p.

For even |S| the rank-one determinant formula gives det C[S]=det K[S]. The adjugate correction has zero cross terms by symmetry, and its diagonal cofactors are odd alternating determinants, zero. Handle empty S directly. For odd |S|, det K[S]=0, so the correction equals the bordered determinant det H[S union {p}] in characteristic two. Thus X is successful exactly when X with the extra bit p=|X symmetric-difference Y| mod 2 is feasible in the even binary delta-matroid represented by H twisted by Y. For the second matrix's reference Y', flip p on one side by |Y|+|Y'| mod 2, making p agree for the same physical X. Test intersection of these two represented even linear delta-matroids via the deterministic Geelen-Iwata-Murota delta-parity algorithm on their paired direct sum. Deficiency zero means a union of intact pairs, hence the same feasible set in each copy. See section 4.2 of https://www.math.uwaterloo.ca/~jfgeelen/Publications/deltamatroidparity.pdf . No maximum-cardinality common set is needed.

Independently an explicit multivariate GF2 generating polynomial retains all indexed physical witnesses. Write h_i=y_i²/(1+y_i²) and t_i=y_i/(1+y_i²). Then
    sum_X det(A+diag(1_X)) det(B+diag(1_X)) product_(i in X) y_i²
    = product_i(1+y_i²) det([[A+diag h,diag t],[diag t,B+diag h]]).
Symmetric determinants in characteristic two sum over involutions: reverse the first long cycle to cancel everything else. Fix internal transpositions in each layer. The binary bit under formal weights 1,y_i² has normalized first and second moments both h_i. If both copies are monomers, their joint weight equals (A_ii+h_i)(B_ii+h_i)+h_i+h_i², where the correction is t_i² and is realized by the cross-layer transposition. If fewer than two are monomers there is no correction. Multiplying normalizers gives the identity. Extension-field evaluations exclude y_i=1; a pinned bit has h_i=bit, t_i=0 and unit normalizer. Different successful X have distinct monomials. The support oracle above does not compute coefficients of an arbitrary XOR of several such witness families. Likewise the generic independent three-matrix hardness says nothing directly for correlated principal neighbors or nonsymmetric mixed boundary minors.
