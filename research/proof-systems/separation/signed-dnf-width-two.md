# Sharp width threshold for universal selector validity

Use the signed odd-selector compiler and complementary-literal semantics of signed-dnf-validity.md. For terms of width at most two, collapse duplicate copies of the same literal within each term. An empty term makes the DNF tautological. Make an undirected graph on literal vertices with one edge per two-literal term; represent every unit term by an edge between its literal and a common always-true vertex. Duplicate edges are harmless. A model of the 2CNF negation of the DNF is a semantic NO, whose false literal vertices form a vertex cover. If the negation is unsatisfiable, the compiler is faithful because true terms supply unit selectors.

Fix such a model. For this input to reject the odd-selector test, the all-ones edge vector must be in the span of incidence rows of the false vertices. Equivalently there must be binary labels c_v vanishing on true vertices, with c_u+c_v=1 on every edge. A nonbipartite component prevents this for every semantic NO. On a bipartite component the two possible labelings exchange the shores, so the labeling exists exactly when all true vertices on that component lie on a single shore. This includes isolated vertices and the always-true unit dummy.

Thus one 2SAT test for a semantic NO and at most quadratically many further tests suffice: for each opposite-shore pair on a common component ask whether both vertices can be true in a model of the 2CNF. Any satisfiable test gives a concrete spurious original assignment, and binary elimination yields the odd selector. An alternative implementation preprocesses reachability in the satisfiable implication graph. A pair of requested nonconstant units is compatible exactly if no requested literal implies the negation of any requested literal (including itself); this follows by closure and contraposition in 2SAT. No enumeration of bipolar variables is used. signed-width-two.py checks 2400 random signed instances against input enumeration. The width-three coNP-hardness in the companion note consequently gives a sharp complexity boundary for this fixed universal validity test.
