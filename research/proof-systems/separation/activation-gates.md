# Compiling signed gates with physical activation rows

A site u supplies one row u L=0, with L affine over F2. Global affine equations count as readouts. An input bit may be stored in either polarity; this is a change of data coordinates. Adding a separate site forced to be its complement requires an explicit affine equation.

For z=AND_i x_i, store w_i=1+x_i. Use data rows w_i z=0, new rows e_i(1+w_i)=0, and the affine readout z+sum e_i=1. The output site's row is free. If z=1 all w vanish and all selectors vanish; if z=0 an odd set of selectors exists exactly when at least one w=1. This gives both directions for every original input. Dependencies are e→w→z. For an unused physical output row the consumer may choose its storage polarity: the producer only reads its affine logical value. A zero-readout variant stores v=1+z and consumes its output row as well: w_i(1+v)=0, e_i(1+w_i)=0, v(1+sum e_i)=0. These equations say v=OR_i w_i. For positive fanin the nontrivial dependency component includes all 2s+1 sites for s inputs.

In a read-once signed AND/OR formula, present each OR via negated conjunction and assign each wire the storage polarity needed by its sole consumer. Each gate uses its input rows and fresh selector rows; its output row is available to its parent. The m gate readouts and an optional final output pin are explicit, and all dependency SCCs are singletons. This preserves the complete logical wire assignment relation, not just a YES answer. For a general DAG, t uses of a physical signal can be split with t-1 fresh occurrence sites and t-1 affine copy equations including the chosen polarities; those equations are extra readouts. For parallel disjoint gates with m outputs required to remain free for later consumers the m global rows are tight in this external-module model. At zero physical data all data guards vanish. Treat the m outputs as free parameters. At the required baseline output choose a global affine auxiliary section through an accepting physical witness: support T and the invertible diagonal correction construction give such a map for every input parameter. Restricted to this section, d affine readouts cut out an affine flat containing that output of codimension at most d. A uniquely determined output vector forces d>=m. If h output rows are instead consumed internally, choose one vanishing linear factor from each such guard at the witness; this gives d+h>=m. This interface bound makes no assertion for a single SAT decision bit.

For an unate DNF let S_i be the set of term indices using literal i and use w_i for the falsity of that literal. Each term has a free selector e_j. Use w_i sum_(j in S_i) e_j=0 and the sole marker sum e_j=1. If the sets S_i are laminar this exactly recognizes DNF membership at every data assignment, despite unbounded fanout: any valid term gives a unit selector; in a NO assignment the active occurrence sets cover all terms, and the distinct inclusion-maximal active sets are disjoint, so their row sum is all ones. The sets are visible from the formula and pairwise laminarity is polynomially checkable. The encoding decides the positive DNF query; permitting the zero selector does not produce a deterministic output bit. Mere interval occurrence sets fail: in the irredundant formula ac OR ab OR bd, at a=b=0, c=d=1 the false rows are 110 and 011, and selector 111 spuriously passes. Thus combining multiple conflicting uses of a physical input by XOR is not a generic fanout compiler.
