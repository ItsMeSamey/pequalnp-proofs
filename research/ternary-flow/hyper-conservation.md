# The same perfect-hypermatching contradictions have short GF(3) proofs

Use the construction and notation of hypermatches.md. Give terminal (v,e,s) weight epsilon_{v,e} s in F3, where epsilon is the signed incidence. Edge connector hubs have weight zero. At vertex v assign its common hubs weights with total b_v. All terminals of that star together have weight zero, since 0+1+2=0 in F3. The deleted terminals of each valid pattern sum to b_v, hence each selectable macroedge E_X has total weight zero. Every connector triple has total zero because the incident signs are opposite.

Extend the weights into each splitter. Number its ports cyclically with weights p_i. Set all filler weights w(f_i)=0. Choose weights R_i satisfying R_i-R_{i-1}=-p_i around the cycle, possible since the p_i sum to zero. Set w(r_i)=R_i and w(q_i)=-p_i-R_i. The weight of every active, inactive, and filler triple is zero, and the sum of the new private weights is minus the sum of the port weights, hence zero. The total weight of all vertices is therefore sum_v b_v, which is nonzero.

For a cover bit y_A per triple, the exact-one constraint at each vertex gives L_v=sum_{A contains v} y_A-1=0 over F3. Then sum_v w(v)L_v is the nonzero constant -sum_v b_v. For bounded vertex degree the L_v are derivable from direct truth-table CNF or standard at-least-one and pair-exclusion clauses in constant degree and constant monomial cost each. Summing them in a balanced tree uses constant degree and O(N log N) total printed monomial occurrences by the support bound across levels; a linear number of inference lines suffices (expanded occurrence cost does not follow from line count alone).

In contrast, each target bit is a Boolean function of a bounded number of source edge symbols, and each target factor vanishes on the source local law. Thus the bounded-local decoding theorem in [the bounded-local Fourier argument](odd-export.md) applies to the hypermatching instances themselves. For sufficiently small linear budgets d and k the binary PC_d exports, written as forbidden-pattern clauses, simultaneously admit the real SA_k witness. Constants depend on the fixed source degree. This is a separation on bounded-degree 3-uniform perfect-hypermatching with one bit per triple. No native deficiency-one encoding is implied.
