# Ternary hypermatching signature of a fixed-charge mod-three star

For a vertex of arity d with signed incidence over F3, take three distinct terminals for each of the d edge symbols. Its signature accepts a deletion pattern X exactly when X contains one terminal per incident edge, and the indicated symbols sum with signs to the required charge.

For each accepted X, make one selectable set E_X containing the other 2d terminals and k common internal hubs. Choose k from {1,2,3} so that L=2d+k is divisible by three. In a set partition covering the remaining terminals and all hubs, one common hub requires exactly one set; it then covers precisely the undeleted terminals.

Realize each set of L ports by an independent 3-uniform gadget. For cyclic i=0,...,L−1 take private vertices q_i,r_i,f_i, active triples (port_i,q_i,r_i), inactive triples (q_i,r_(i−1),f_i), and filler triples partitioning the L distinct f_i into groups of three. The degree-two constraint on q_i forces exactly one phase at i. Coverage of r_i then equates this phase with the phase at i+1. In the active phase all ports are covered and every filler triple is selected. In the inactive phase no port is covered and no filler triple is selected. Extensions are unique.

For a whole bounded-degree flow instance, make one such gadget per vertex with private terminals. For each edge uv, introduce an edge hub and three possible triples (hub, u's terminal for s, v's terminal for s), indexed by its symbol s. Exactly one external triple chooses the common edge symbol. The local signatures now enforce the signed charges. This gives a parsimonious reduction of bounded-degree mod-three flows to bounded-degree 3-uniform exact cover with linear blowup. A selected connector triple is a source edge-symbol bit. Every internal triple is a local Boolean function of one star: its active phase and fillers are selected exactly for the realized allowed tuple, and the inactive phase uses its complement. On a violating star define the corresponding tuple indicators by the same tests; its own source axiom excludes that case. Consequently every exact-cover factor under projection is implied by a bounded number of constant-width source factors in a bounded neighborhood, also at a common hub with multiple internal clauses. This supports constant-factor lifting of local-distribution width (project by local functions) and constant-factor PC degree simulation for constant-width Boolean encodings (substitute constant-degree tuple indicators, derive each substituted axiom by a truth-table derivation). A field-specific source lower bound must be proved for the chosen mod-three encoding. Transfer from this 3-uniform exact-cover language into the original one-guard-per-coordinate language remains a separate step.
