# Counting signed affine clauses by variable cuts

Run `python -B -m unittest -v` here. Each clause requires at least one row to disagree with its supplied right-hand side. Masks use bit zero for the first variable. An empty conjunction of clauses accepts every assignment. An empty clause rejects every assignment.

For fixed assignment x let I_j indicate that all rows of clause j agree. The product of (1 − I_j) indicates acceptance. Expanding the product explains the negative coefficient when selecting a newly opened clause and the positive coefficient when skipping it. For each guessed bit, subtract its contribution from each selected live right-hand side over GF(2). Gaussian elimination retains the branch exactly when a common suffix satisfies its residual systems. A rejected branch has no completion. A clause can be forgotten after its last variable because the same check certifies that its remaining zero rows agree. Equal live states admit identical future transitions, so their signed weights add. These operations sum the expanded product over all full assignments. Inconsistent forbidden systems can be removed during preprocessing.

After a cut let S be a subset of live clauses. Stack their rows and split columns into prefix P and suffix F. The residual belongs to both the translate d + im(P) and im(F). Their intersection is empty or has cardinality 2^(rank(P) + rank(F) − rank([P F])). Summing these cardinality bounds over S gives a state bound B for that cut. Residual ordering is fixed by opening order.

At position i, with o_i openings, the intermediate dictionary can grow to T_i = B_previous × 2^o_i states, even when the following cut has few live clauses. Set the initial bound to one. There are at most 2 T_i bit transitions. With m total clauses and R total rows, each transition uses O((R+1)(min(R,n)+1)) row operations plus O(R+m+1) state handling under unit-cost integer operations and expected dictionary access. Opening expansion also fits this per-position time bound since each opening doubles the dictionary and the resulting sizes sum geometrically. Space for both generations is O((T_i+B_following)(R+m+1)) integer slots plus input, opening lists and scratch space. Exact Python costs also depend on bit lengths: masks use up to n bits, while signed weights have O(n+m+1) bits by counting prefix assignments and subset choices. Preprocessing runs once and includes Gaussian elimination separately on each clause.
