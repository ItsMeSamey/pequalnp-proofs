# Two binary markers on arbitrary represented binary matroids

Let H have real columns indexed by E. We seek x in ker H and y in row H with disjoint supports and Ax+By equal to a given element of F₂². The following algorithm handles arbitrary represented binary matroids in deterministic polynomial time.

Compute the two individual image subspaces. Any target in either image is witnessed by taking the other vector zero. Reject any target outside their sum. In every remaining case the images are distinct lines, and the target is the sum of their unique nonzero vectors. Apply linear functionals to the marker outputs to obtain scalar edge coefficients a,b such that the outstanding test is a·x=b·y=1.

Append terminals e,f and use the matrix whose top block is [H | 0 | Hb] and bottom row is [a | 1 | 0]. Real columns here include their new bottom entries. The requested pair exists exactly when some real subset X spans e but does not span f. Indeed e in the span supplies coefficients x with Hx=0 and a·x=1. A linear functional zero on X and nonzero on f has two blocks (u,s). It may not yet give the requisite y=uH since s could equal one. But e belongs to the span of X and equals the bottom unit vector, so s=0. Thus y vanishes on X and b·y=1. Conversely the support of any x supplies X and (u,0) witnesses exclusion of f.

### Testing span inclusion and exclusion

For a binary matrix with distinguished columns e,f and remaining real columns, first test whether there is a basis with f in it and e outside it. This requires f nonzero and f together with the real columns spanning the whole representation. Any successful X extends to such a basis by taking a basis of X, adding f, and greedily extending with real columns. In any basis of this form let B be its real portion. An answer is affirmative exactly when some such basis has e in span B. Necessity follows by that same extension; sufficiency uses X=B.

Choose a compatible basis and its binary fundamental graph, with row vertices for basic elements, column vertices for other elements and edges for nonzero standard-form entries. If fe is absent, return B. If fe is present, an affirmative answer is equivalent to this edge lying on an undirected cycle. If there is no alternate path, removal of fe separates its two endpoints. Every basis exchange avoiding these endpoints stays on one side of that separation. Pivoting toggles edges between neighbors of the internal pivot endpoints, which stay on that same side. Thus fe remains the unique crossing. All compatible bases are connected by these exchanges, since their real portions are bases of the restriction to real elements after contracting f and deleting e.

If there is an alternate path choose a shortest one in the graph minus fe. It is chordless there. When it has length three, pivot its middle edge; the binary pivot toggles fe to zero. When its length is at least five, pivot on the first edge of the path whose endpoints are both internal, then drop these two vertices from the path. The pivot supplies the required shortcut from f to the third path vertex and leaves the remaining suffix edges unchanged by chordlessness. It does not toggle fe in this step. The two pivot vertices need not be deleted from the graph. Repeat with a shortest alternate path in the updated graph. This constructs the desired basis in polynomial time and Gaussian elimination recovers witnesses.

The accompanying two.py compares this two-terminal predicate with direct subset-span enumeration in 2,500 random binary matrices. Its small-instance span enumeration is only for verification. The decision procedure above uses elimination and ordinary graph searches.

### More markers

With t markers write the real dual score as Bᵀy and primal score as Ax. Use the matrix with block rows [H | 0 | HB] and [A | I | 0], where both terminal sets have t coordinates. For a proposed split p+q equal to the target, prescribe terminal cycle (p,0) and terminal cocycle (0,q). A solution is equivalent to some minor on precisely those terminals, contracting a subset X of real elements and deleting its complement, having that cycle and cocycle. The cycle lifts exclusively on X and the cocycle exclusively on its complement, by the standard restrictions and projections for minors; conversely choose X equal to the support of the real cycle. This reduces arbitrary fixed-marker instances to a bounded-terminal rooted minor search. The two-terminal argument does not solve general bounded-terminal rooted minor search.

### A dense odd-demand graphic specialization

Suppose a fixed branch in a one-column extension of a connected graph incidence matrix prescribes an even demand set T. Seek a T-join J disjoint from a cut, with prescribed scalar sum of one edge weighting on J and another on the cut. If the first weighting is nonzero on cycle space, the empty cut and toggling a suitable cycle suffice. Otherwise all T-joins share their score, giving an immediate answer for zero residual score. For residual one let U be the odd-degree vertex set of edges of cut weight one.

The residual problem is equivalent to a bond having a T-even, U-odd shore. Given a successful cut, contract all components of its two shores. Each contracted part is T-even, and some is U-odd. A spanning tree of the quotient has a fundamental cut with odd U-parity, since otherwise the parity of each vertex would be even by summing its incident fundamental shore parities. Pulling back gives connected shores both T-even. Conversely each connected T-even shore admits an internal join. In the incidence matrix append two named columns with supports U and U△T. A desired bond is the support on real edges of a cocircuit containing both appended elements. The hyperplane of zeros of such a cocircuit is spanned by original columns because both added elements are outside it, and hence its intersection with the original representation is also a hyperplane. The converse uses the same hyperplane. A common cocircuit through the two elements exists precisely when they belong to one matroid component, decidable in polynomial time using a fundamental graph. This incidence extension is the two-constraint case of the construction in Chen, Ding, Yu and Zang, “Bonds with parity constraints,” Lemma 2.2. [Primary source](https://www.math.lsu.edu/~ding/bonds.pdf)

### Reproducible checks

solver.py implements the two-marker witness algorithm using integer-encoded binary columns, Gaussian elimination and shortest pivot paths. solver_check.py exhaustively checks all four targets and the returned witnesses on 1,200 small seeded binary matrices. terminal_check.py compares all split target traces for 130 further matrices with one to three markers against direct disjoint-pair enumeration. Run these scripts in this directory alongside two.py.
