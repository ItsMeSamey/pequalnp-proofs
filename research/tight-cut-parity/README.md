# Prescribed parity signatures through tight cuts

Let the edges of a matching-covered bipartite graph have labels in the binary vector space of dimension t. Given its edge-labelled tight-cut decomposition tree, all numbers of perfect matchings at each XOR signature can be computed in O(2^t poly(n) + t 2^t) time whenever each brace admits polynomial-time integer-weighted permanent computation, uniformly over the class. This includes Pfaffian braces interspersed with arbitrarily many non-Pfaffian braces of bounded order, or more generally, fixed bounded perfect matching width. For integer input weights with polynomial bit length, the same conclusion holds for the weighted sums. Existence follows from positive counts in the unweighted case.

A tree edge glues one virtual vertex from each adjacent block by a specified bijection of incident edge copies. Retain parallel cut edges as distinct labels. A perfect matching of the two contracted sides glues uniquely when their cut edge identities agree. Conversely tightness gives a unique such pair for each full matching. Induction proves the bijection for the whole tree. The copies of any original edge form a connected path, and along it the selections agree. Choose one copy anywhere on the path to own its input weight and label. At any other copy give that edge unit weight and zero label.

For each Walsh character indexed by h, replace an owner's weight w by w times the sign (-1) to the power of the binary dot product of h and its label. Root the tree. A message from a nonroot block is indexed by the individual edge e selected at its parent-facing virtual vertex. Once child messages are known, multiply the current weight of each edge by the child's entry for that edge at each child-facing endpoint. If both endpoints face children, use both factors. For each outgoing e compute the weighted permanent with all competing edges at the parent port set to zero. At the root simply compute the weighted permanent. Expansion over local perfect matchings and the gluing bijection show that the result is the global weighted Walsh transform value. Invert the transform on all t bits by the usual butterfly, then divide by 2^t. Negative weights cause no issue. With a Pfaffian bipartite signing, calibrate the determinant's global sign from one reference matching in the original local graph and retain that sign even when some weights are zeroed. Parallel edge weights may be summed in a signed matrix entry only after imposing any forced physical edge identity.

A cubic bipartite multigraph partitions into three perfect matchings by regular bipartite edge coloring. Each meets a tight cut once, hence such a cut has three edges. Consequently three forced local permanent calls per nonroot block suffice per character. With unbounded degree the total port size is still polynomial. Counts of partial configurations have polynomial bit length, since each is a signed sum over tuples of matchings of the blocks and the decomposition has polynomial total size; input weights occur only once. The decomposition can also be found in polynomial time.

[Giannopoulou, Thilikos and Wiederrecht, §6.1 Lemma 6.7](https://arxiv.org/pdf/2212.09348#page=47) already reduce labelled bipartite perfect matching generation to edge-conditioned evaluation on braces. Lemma 6.5 supplies a bounded-perfect-matching-width oracle and Proposition 6.8 the Pfaffian oracle. Specialization to Walsh signs gives the stated application. [Vazirani and Yannakakis](https://ics.uci.edu/~vazirani/VY-Pfaff.pdf) prove that the whole graph is Pfaffian exactly when every brick and brace is Pfaffian. Splicing arbitrarily many copies of K3,3 at opposite-colored vertices with any incident-edge bijections gives a cubic bipartite family containing non-Pfaffian braces. Every splice cut is tight by the unit color-class imbalance on a shore and the fact that all crossing endpoints there have the same color. It is a matching-covered splice because every constituent edge can be used and a matching on one side can be completed on the other with the identical crossing edge. This supplies unbounded examples beyond global Pfaffian signing. Containment of these examples in any separately specified geometric guard graph family requires its own representation proof.

Run python verify.py. An independent enumerator assembles the physical graph by joining edge-copy paths, enumerates its perfect matchings, and compares all eight signature totals against the tree computation. Cases cover the six-cycle, a three-parallel-edge graph, two through six K3,3 blocks, and a root edge with two child-facing endpoints. Each of the seven fixtures has twelve deterministic trials including signed integer and zero weights.
