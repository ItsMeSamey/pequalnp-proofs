# Contracting binary tensor trains against a short CNF

Suppose a CNF on n variables is supplied as a constant-width core H and groups of additional clauses. Group j has w_j distinct variables in a specified order. Require max w_j ≤ C log n and sum w_j = O(n); overlaps between groups are allowed. The assignment must satisfy every group. Exhaustive construction of each group's Boolean truth tensor takes polynomial time. Let R≥1 bound ranks over GF(2) of its prefix/suffix flattenings at the checkpoints used below. These are ranks of the 0/1 truth function, not of a complex phase. They can be computed from the tables.

**Binary path representation.** For a prefix cut, take a basis of actual prefix rows, viewed as functions of the remaining variables. For every basis row and every assignment to the next block, its restriction lies in the next prefix-row space: the original basis prefix followed by this block is itself a prefix. Solve for its coordinates in the next basis by binary Gaussian elimination. This gives a 0/1 transition matrix per block assignment. The first space is generated by the full table and the last by the bit 1, with an identically zero table handled separately. For a fixed global assignment, summing the number of compatible index paths modulo two gives exactly the group's truth bit by matrix multiplication. Each internal path index occupies at most ceil(log₂ R) bits. This is a finite-field implementation of the standard unfolding construction for tensor trains. [Oseledets](https://doi.org/10.1137/090752286)

**Decision fingerprint.** Form the polynomial over characteristic two whose terms are the distinct squarefree monomials prod_{i:x_i=1} z_i corresponding to the global models x. It vanishes identically precisely when there are no models. For one evaluation choose independent uniform field elements alpha_i in GF(2^t), where 2^t ≥ 4n. Choose a binary basis containing 1. Split the n global variables into blocks of at most b, independently of the groups, assigning each variable to exactly one field block. Given its local assignment a, a block multiplies its incoming value by the product of alpha_i over its true bits. Compute the t-by-t binary matrix of this field-linear operation on the chosen basis. A second path over coordinate indices starts at 1's coordinate and finishes at coordinate j. The parity of its compatible paths for x is the jth bit of x's scalar monomial.

For each output coordinate count modulo two the assignments satisfying H and all of the following local path predicates: the chosen GF(2)-train transition exists in each group, and the field-coordinate transition exists in each global block. Predicates are written as truth tables in CNF, which also exclude invalid binary index encodings; endpoints are fixed. For fixed x the path counts multiply because internal indices are private to their respective networks. Summing over x recovers exactly the jth coordinate of the fingerprint. Repeating for t coordinates gives its full value. Unsatisfiable inputs always give zero. The polynomial degree is at most n, so a satisfiable input has zero evaluation with probability at most 1/4 by Schwartz–Zippel. An exact fixed-width counter supplies the required parity oracle. A decision oracle on the path encoding alone would fail because path counts can be positive and even.

**Resources.** Put b=max(1,ceil(log₂ R),ceil(log₂ t)). Use blocks of b successive variables (and a possibly shorter final block) within each group and for the global field-weight path. The number of internal group checkpoints is at most sum_j w_j/b. The global field path has at most n/b internal checkpoints. Total variables are O(n) and maximal clause width is O(b) plus the fixed core width. Tables are polynomial size in the regime below. Decisions do not need an a priori rank bound: a safe maximum over all cuts is polynomial-time computable. Alternatively, for a tight blocked-only bound, test candidate b values and the ranks at those actual cuts. Finite field construction in this regime is polynomial, including exhaustive testing of binary monic degree-t polynomials for irreducibility when t=O(log n).

With the uniform fixed-width #SAT oracle bound poly(L) times 2^{O(k² n loglog n / sqrt(log n))}, the resulting one-sided randomized decision algorithm has exponent O((log R+loglog n)² n loglog n/sqrt(log n)). In particular it is subexponential if log R=o((log n)^{1/4}/sqrt(loglog n)). Repetition reduces the false-negative probability. The uniform oracle dependence on width is necessary for the growing b conclusion.

**Deterministic promised counting.** Let S be a supplied polynomial upper bound on the number of global models. Write e(x)=sum_i 2^i x_i, using indices 0 through n−1. Test 1+n binom(S,2) distinct primes p. At least one prime divides no nonzero difference between two model exponents, since each such difference is smaller than 2^n and has at most n distinct prime factors. For each p, substitute z_i=Y^{2^i mod p}. Its univariate degree is at most n(p−1). Evaluate at sufficiently many points of GF(2^t) with 2^t>n(p−1) using the same coordinate paths, and interpolate coefficients. Every coefficient is the parity of a bucket of models, so support size never exceeds the true count. For a separating prime all degrees are distinct modulo p, hence distinct as integers and support size equals the true count. Return the maximum support. All loops are polynomial for polynomial S, keeping t=O(log n) and the same exponent as for decision. Good-prime collision avoidance is an established sparse interpolation technique. [Arnold and Roche](https://arxiv.org/abs/1401.6694)

**Separation of representations.** On a local scope of w variables use a quadratic Boolean function given by the parity of x_u x_v over edges of a graph. Across a cut it equals a function of the left input plus a function of the right input plus x_L^T A x_R, so its GF(2) truth-matrix rank is ≤rank₂(A)+2≤w+2. The real sign matrix has rank exactly 2^{rank₂(A)}: removing row and column signs leaves characters indexed by distinct vectors A^T x_L, which are orthogonal. Thus the real 0/1 truth matrix has rank at least 2^{rank₂(A)}−1 by the relation between the truth and sign matrices. Choosing bounded-degree edge expanders gives rank₂(A)=Ω(w) for every balanced cut: the crossing bipartite graph has Ω(w) edges and bounded degree, contains an induced matching of Ω(w) by greedily removing at most O(1) conflicting edges per selection, and its induced submatrix on matched endpoints is an identity. A table encoded by one canonical maxterm per false assignment is an ordinary polynomial-sized CNF for w=Θ(log n). Taking many groups with total scope occurrences O(n) leaves an arbitrary short core crossing the groups. This example separates representations across all orders. The sparse expander polynomial itself also has a linear-size XOR/AND circuit, so it gives no complexity-theoretic separation or evidence against alternative exact algorithms. Larger dense local quadratics also satisfy the GF(2) upper bound.

These results concern explicitly grouped inputs. The rank and total-scope hypotheses can fail for unrestricted polynomial-density CNFs. The randomized result is for decision, while the deterministic exact-count result uses a supplied bound on the number of models. Neither proves P=NP or its negation.
