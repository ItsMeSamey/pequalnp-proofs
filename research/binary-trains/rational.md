# Exact rational contraction with logarithmically many digit-index bits

Take the same grouped CNF, cost parameters and short-core oracle as in result.md, now measuring the block unfolding ranks over the rationals. Integer cancellations make the path expansion equal the Boolean indicator as an integer, so exact counting works for unrestricted numbers of satisfying assignments.

## Integer weight compiler

Suppose a network has T local transitions, with signed integer lookup weights of absolute bit length at most B. For each realized transition of weight w, guess a single position 0 ≤ j < B where |w| has a 1 in binary, and record its sign. A weight zero has no valid choice. For any fixed path the signed sum of the terms 2^{j_1+...+j_T} over all independent digit choices is exactly the product of its weights. This identity also holds after summing over all paths and model assignments. Add the chosen binary indices with a balanced tree of ripple-carry adders; gate outputs are uniquely determined. Level l has O(T/2^l) adders of width O(log(B+1)+l). Summation over levels gives O(T log(B+1)) gates, including carries and a tree for the sign parity. Repeat exact ordinary counts with the final sum fixed to J and the sign fixed, for 0 ≤ J ≤ T(B−1). Restore the integer scalar by summing 2^J times the positive-minus-negative counts. There are polynomially many calls for polynomial T and B. All bit-integer arithmetic has polynomial length. Each local lookup is a predicate on its input, path endpoints, one sign bit, and ceil(log₂ B) guessed digit bits. Thus it can be enforced by a truth table, with width equal to the total number of these bits and no per-table-entry variables. Handle the empty network and B=1 in the natural way.

Classical weighted-to-unweighted model counting already has polynomial reductions, including Chakraborty et al. for literal-weighted instances. The digit-index identity here uses a polynomial number of counts stratified by an additive statistic. Its resource claim is about auxiliary bit count for factor lookups; no priority claim is made. [Chakraborty et al.](https://ijcai.org/proceedings/2015/103)

## Rational truth tensor

For each local Boolean table, form prefix-row bases consisting of actual 0/1 rows. At a cut of rank r choose r suffix columns giving an invertible r-by-r 0/1 minor A in that basis. A prior basis row restricted to a block assignment remains an actual prefix row at the new cut. Compute its coordinates in the new basis using the sample columns and Cramer's rule. All transitions to the same cut share denominator |det A|; numerator signs include the sign of det A. Every determinant in this calculation has absolute size ≤r^{r/2} by Hadamard's inequality. Hence B=O(1+R log(R+1)) bits suffice for all the signed integer weights in a train of rank at most R. Denominators are independent of indices and input, so divide the final scalar by one global product of step denominators. No loss of precision is needed. An identically zero local truth function immediately forces total count zero. The representation is an exact algebraic version of tensor-train unfolding. [Oseledets](https://doi.org/10.1137/090752286)

Set b=max(1,ceil(log₂(R+1))). Process groups of at most b variables directly by ordinary width-b clauses from their truth tables; these groups create no weight counters. Every other group has O(w_j/b) transitions. With sum w_j=O(n) there are T=O(n/b) charged transitions. Each needs O(log(R+1)) bits for its endpoints, sign, digit index and its share of the adder circuit. There are O(n) variables including the originals and all auxiliaries, and clause width O(b) (or the unchanged constant short-core width). All scope tables are still polynomial for scopes w_j=O(log n). A polynomial number of fixed-width counts therefore computes the exact number of models in time poly(L) times 2^{O((1+log R)² n loglog n/sqrt(log n))} with the cited uniform exact oracle. For fixed R the native fixed-width exponent is retained. For growing log R=o((log n)^{1/4}/sqrt(loglog n)), the algorithm remains subexponential. This covers arbitrary short cores crossing the local scopes and does not assume a small number of models or a small nonnegative factorization. The coordinate algorithm in result.md provides a separate one-sided decision result when the ranks are small only in characteristic two.

A modular variant uses transition entries in the standard range 0,...,p−1 and reduces the reconstructed integer modulo p at the end. If enough polynomial-size primes give valid small ranked representations and their product exceeds 2^n, CRT recovers the exact count. For common cuts and sufficiently small ranks this can overlap the rational criterion: a nonzero bounded integer minor cannot vanish modulo a product larger than its magnitude.
