# Width preservation for one dirty gate at size 34

Assume C(13)≥32 and any fourteen-input threshold-two monotone circuit of size ≤34 with exactly one singleton-dirty AND D. The global 34 lower bound from terminal-clean-regularization.md makes every intermediate size-preserving rewrite globally optimal. Define width here as the number of distinct physical AND input occurrences reachable from D through paths with only OR internal vertices. With a sole dirty AND, all such input occurrences belong to clean gates.

Every promotion of a nonterminal clean AND C appends at most one OR, and replacing C by zero at its old outgoing occurrences deletes every direct reader. Optimality forces exactly one such reader H. It must be an OR: if H is an AND, H becomes zero, hence a downstream reader disappears too; if H was the observed output, the appended OR simplifies to C. Both would give a strict reduction. Thus the only removed gate is an OR. With H=C∨P, the rewrite bypasses H to P, leaving no new OR-only path between any two surviving ANDs: the P branch already passed through H, and the final OR adds no downstream AND. Identifying surviving input ports by their gate and pin, the reachable port set of D can therefore only shrink. On each singleton C was zero, so the singleton evaluations of all surviving ANDs remain exactly unchanged.

Similarly in a sole-raw-reader relocation H=x∨P, P is independent of x and false on every other singleton, as proved in normalization.md. It is zero also on the x singleton (all its own inputs zero). Thus H coincides with x on every singleton. Replacing H by x in old uses and adding the final OR with P preserves every old AND's singleton evaluations. Only an OR is removed and any further saving would contradict optimality. A path from D to an old AND through a live remaining branch cannot be new: it cannot use x as an intermediate gate, and the appended OR feeds no AND. Hence this operation also creates no new reachable AND input port of D.

Through the complete promotion and regularization D remains the sole dirty AND, the AND count is unchanged, and its reachable first-port set only shrinks. In a live circuit a singleton-hot D cannot reach the observed output through ORs alone, since its hot singleton must be rejected. Following any path from D to the observer therefore encounters at least one downstream AND, implying positive width. If the initial width is one, the final width remains exactly one. The physical-width-one-traces.md argument and the arity-independent state minor now apply to the resulting representative. Individual raw masks and state-exclusive counts can change in transit; the conclusion is existence of a normalized representative satisfying the count constraints.
