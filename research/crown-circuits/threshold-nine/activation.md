# A paired raw receiver can be redirected to an equal dirty activation

In a switched reverse circuit, U_j denotes the direction mask reaching AND j. R_i denotes the full direction mask of paired input z_i. If the forward AND is true on singleton z_i, then U_j is a subset of R_i. Indeed each resolved circuit dominates every original gate. A direction reaching a gate true on z_i must produce output true on z_i. The masks R_i are pairwise incomparable, since the direction preserving the false diagonal k belongs to every R_i with i distinct from k and does not belong to R_k.

Suppose U_j equals R_i. In the actual reverse computation U_j is available before switch j consumes it. Move the receiver tap for paired input i to this incoming activation wire. Every complete 32-direction mask and the order of reverse operations are unchanged. A resolved output still accepts exactly the same raw pairs and the same diagonals at the same directions. Since a monotone circuit equals the intersection of its resolved disjunctions pointwise, the represented function is preserved. Transposing the modified network back introduces no additional gates: the total number of taps, splits and unions is unchanged. Unused gates may be pruned. In a trimmed paired network with a splits, g unions and 12 receiver taps, the forward OR count is at most (2g+a+12)−(1+2a+g)=g+11−a, with a forward ANDs and twelve initial pairing gates.

In the forward graph z_i is now attached downstream of gate j. Its signal cannot reach either input of j, so j rejects singleton i. Gate j cannot be true on any other singleton k, because that would imply U_j⊆R_k, contradicting incomparability. Thus j is diagonal-clean in the modified circuit. Any previously terminal clean AND has full reverse activation, and it stays clean: otherwise some R_k would contain every direction, contradicting rejection on diagonal k. In the terminal normal form every previously clean gate was terminal.

Reapplying terminal normalization yields no increase in the number of dirty gates. Consequently among representations of fixed bounded size one minimizing the number of dirty ANDs has no dirty activation equal to a paired receiver. The argument transfers existence to a smaller number of dirty gates; it need not exclude the original syntactic class in isolation.
