# Unrestricted nine-flag decoder with eight ANDs and seven ORs

The three full hosts are K4 with five-vertex mask 255 or 507, and a four-vertex diamond with mask 511. The large component uses the triangular edge number j(j−1)/2+i for i<j. No pure or mixed vertex roles are imposed: all nine flags are free gate inputs. The tests reject each of the fourteen edge masks. Distinct edge-pair unions must accept; by monotonicity it suffices to retain the inclusion-minimal unions. This gives 61, 62 and 59 positive rows, respectively. Any larger feasible raw assignment contains a pair union. The all-zero input rejects by monotonicity below each edge. Thus this decoder test is exact for an arbitrary downstream monotone decoder on these flags; a feasible decoder would still need to meet any separately imposed fanout or flattening conditions before reuse in a narrower architecture.

Each of fifteen gates independently selects AND or OR and two previous nodes. The nodes include all nine flags and every earlier gate. Only commutativity orders the two operands. Duplicate operands are allowed, so any circuit with at most eight ANDs and at most seven ORs can be padded to exactly both counts by appending identities. Shared signals and mixed OR/AND predecessors are unrestricted. Unused constants in a gate-count candidate can be simplified on these nonconstant test rows. The last gate is the output.

host_nine.py writes the CNF only. nine-preflight.sha256 binds the generator and the emitted CNFs. With --control39, the script reads the physical 39-gate scalar witness, recovers the nine flag wires after the first nineteen ORs, and extracts the actual twenty-gate decoder (nine ANDs and eleven ORs). Its independent evaluation matches all 16,384 raw inputs. The script constructs a satisfying assignment to every clause of the pinned positive CNF, completing the cardinality auxiliaries by unit propagation. --residual507 checks the separate four-AND/four-OR five-flag witness on all 32 valuations. Neither control provides a target-budget witness. No native solver has been launched on these three full CNFs.
