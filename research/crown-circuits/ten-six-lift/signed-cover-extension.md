# A complete family of formal receiver masks prevents inserting another raw label

In a binary monotone AND/OR circuit let a be the AND count. The formal mask R_x of a raw x consists of the signed AND operand slots reachable from x along only ORs before the first AND, including direct raw operands. The two signs of one axis index its two operand slots. This definition is independent of which AND gates are dirty. A consistent mask selects at most one sign per axis and determines a cylinder of full sign assignments extending all its signs.

Assume some set of existing raw inputs has consistent masks whose cylinders cover all 2^a assignments. No further raw z outside this set can be part of a threshold-two circuit with these formal masks. Evaluate z alone; its output is false. For each AND with exactly one true operand, select that already-true sign. For every other AND select either sign. By coverage there is an old raw x all of whose signed incidences match the choices. Now add x. If any AND switches on, take the earliest such gate in topological order. Earlier AND outputs have not changed, so all changes at its operands arise from x along OR-only paths. If both operands were false before, x can supply at most one by consistency. If one was true, x cannot supply the other, by the sign choice. A previously true gate cannot newly fire. Thus no AND changes. Any change to the output would now require an OR-only raw-to-output path from x, contrary to rejection of x alone. The purported circuit therefore rejects x+z, a contradiction.

For a full binary-coordinate grid expanded by arbitrary binary split trees, the original signed masks cover: each assignment to the coordinate comparison axes selects a cell, and the choices on its split-comparison axes guide a descent to an old raw whose entire mask matches. Linking previously computed AND outputs into other operand or collector OR networks preserves these OR-only raw masks so long as the original raw-to-first-AND incidences stay exactly the same. Under that condition no number of such links or new-label OR injections can add even one independent label. This proof applies equally to circuits with nested ANDs and multiple dirty gates. A candidate lift must therefore have an incompletely covered starting family or change an old raw's formal mask so coverage fails.
