# Threshold star saving on the regular minimum

The native star pin constructs a physical circuit D on k inputs. For a shared root of degree k≥2 activating t other shared roots, D.size + (2n−k) + t + 1 ≤ B.size. The resulting cap is k+t+2n ≤ B.size+3 for each shared root of the regular minimum B.

The original compiler reported the three standard axioms for both endpoints. The portable manifest pins 145 sources, including 109 shared with the adjacent sharp square-root package. The independent clean rebuild recorded there covered those 109 sources. Its receipt does not cover the 36 added modules.
