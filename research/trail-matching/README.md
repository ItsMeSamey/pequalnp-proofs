# A deterministic parity-perfect-matching solver for native guards

Write row i as x_i(b_i+M_i·x)=0 over GF(2). A single arbitrary affine marker prescribes the parity of a chosen set of pivot bits. Regard row i as the directed mask edge M_i→M_i△{i}. Its before and after state values differ by x_i. The underlying undirected mask graph is a forest: a cycle would XOR distinct unit vectors to zero, although every coordinate labels only one edge globally. Even when the original variable-dependency digraph has cycles, the mask graph does not. Self coefficients in M_i cause no problem.

At each mask maximally pair incoming edges with outgoing edges. The pairs form a partition into directed trails. A mask S starts exactly max(outdegree(S)−indegree(S),0) trails. Every directed trail decomposition must have at least that many starts at S, so this pairing minimizes the start multiplicity of every mask simultaneously. Distinct occurrences of an identical start are counted separately. First suppose every pivot index occurs in at most one start mask, counting multiplicity. We now build a polynomial-size unweighted general graph.

* Make a three-terminal transition gadget for every row with ports B,X,A (before, pivot, after) and one interior vertex d. Include the edge BA. Connect d to X and also to B when b_i=0, or to A when b_i=1. A terminal deletion (equivalently choosing an external connector at that port) is feasible exactly for 000,101 and respectively 011 or 110, in port order B,X,A. Indeed the empty deletion is matched by dX and BA; for a pair of deleted ports the lone survivor must be adjacent to d. Odd deletions are impossible. This signature is exactly A=B XOR X and X=1 implies B=b_i.
* Connect successive A and B ports on each trail. At its start attach a separate clique parity gadget enforcing B XOR XOR_{i in S} X_i=0: use one terminal per participating wire and one private padding vertex if needed for even total order. Deleting an even number of terminals leaves an even clique, which always has a perfect matching (including the empty graph). Connect the starting B port with its clique counterpart. Connect each X port to its unique start occurrence if it has one.
* Every remaining free port (final A and any X with no start occurrence) gets one matching connector to a distinct reservoir terminal. Put all reservoir terminals in a clique, with a single extra private vertex if needed to make the TOTAL constructed graph even. The reservoir allows every choice consistent with the preceding gadgets: their own perfect matchings force the parity of the number of selected reservoir connectors to equal the number of nonreservoir vertices modulo two. The parity adjustment then leaves an even clique.
* Mark the connector of X_i red exactly when i appears in the marker. Each X_i has exactly one connector. All other edges are blue. Given a guarded solution the true parity of each mask supplies all state bits and all designated connectors extend to a perfect matching. Conversely, the start equations and transitions force the state values on every trail to be the actual mask parities of the decoded x. Thus duplicate occurrences of intermediate masks, and a variable used in its own start, automatically agree. No independent consistency assumption about repeated masks is needed.

The required matching has the marker's prescribed red parity. Section 4, Corollary 22 and Theorem 19 of [El Maalouly, Steiner and Wulf, ISAAC 2023](https://drops.dagstuhl.de/storage/00lipics/lipics-vol283-isaac2023/LIPIcs.ISAAC.2023.28/LIPIcs.ISAAC.2023.28.pdf) give deterministic polynomial-time decision and witness recovery on unrestricted general graphs. Their constructive reduction deletes optional edges while the parity decision remains true. Enforce a pivot pin by forcing or forbidding its one connector and adjusting the parity and graph after a forced edge. No count preservation is claimed since a clique can have many matchings. The matching graph has polynomial size, including explicit clique edges.

## Repeated start-mask patterns

Let P(i) be the set of start occurrences containing pivot i, and let t count the distinct patterns P(i) of size at least two. For each such group (all i with the same P), branch on the parity of its pivot bits, not on those bits individually. Enforce the guessed parity using one clique on all group ports, with padding chosen so a deletion is feasible at the desired parity. Replace the group's contribution in each affected start by the guessed bit, updating that start's parity requirement. The remaining instance has a unique X connector for every bit, including one connector to the new group gate for each repeated-pattern bit. The same reservoir parity adjustment works even when some groups or start gates have odd order. This gives a deterministic 2^t poly(input length) marked solver. The class t=O(log input length) is polynomial. Maximal pairings give the same pattern list up to relabeling start occurrences. For this fixed orientation, increasing any mask's start multiplicity cannot reduce t: projecting occurrence patterns to the original multiplicities cannot merge two originally distinct patterns or remove their repeated status.

The unmarked native zero assignment is feasible. To find the entire affine hull, maintain the span of solutions found. Query a basis of its annihilator for an odd marked solution. Add a returned witness and restart until every query fails. Each restart increases the dimension, so at most O(n²) marker queries suffice. The same approach yields an affine hull on a pinned face by translating about one found solution and adjusting the marker constants.

## An exact limitation of the start connector interface

Suppose the start device alone must present the entire relation s_j=parity(S_j∩x), with all x_i and s_j separate external ports on a single perfect-matching gadget. Even allowing further optional free ports, the start interface can realize this exact signature only if every P(i) has size at most one. Necessity follows by symmetric exchange. Extend any two feasible external patterns to complete gadget matchings including any free ports. Starting at a changed external port and following the alternating matching-difference path either changes one more specified port or ends at a free port. Toggling that path changes only the first port and possibly one other specified port, leaving the result feasible. Apply this to 0 and to x=e_i with all s_j indexed by P(i) set. If |P(i)|≥2, toggling x_i from the zero pattern requires at least two s ports to toggle simultaneously, contradicting exchange. Sufficiency is supplied by the clique construction, allowing free ports as above. This limitation concerns the signed external-wire presentation of the start equations; it supplies no general impossibility for other matching encodings.

The standalone checker exercises primitive gadget composition against direct assignment enumeration. It uses an independent exhaustive matching routine, so it checks the reduction and is not a polynomial-time implementation of the cited general parity matching algorithm.
