# Physical size when reused derived clauses can be tested by parity

Use the exact BPHP 5 2 rules in ProofComplexityLin.lean. Retain the ancestor DAG of one empty-clause occurrence, choosing one inference per retained line. Count parent incidences with multiplicity. Axioms can be reused arbitrarily.

Suppose each derived vertex with at least two users has a falsity set testable with one affine parity. This includes affine hyperplanes. Query these vertices in prerequisite-first chronological order. On the first false result, enter that vertex's component; on the all-true branch enter the empty root's component. Form components by cutting references to reused derived vertices and materializing each axiom incidence as a separate leaf. Each component is a tree: every internal nonboundary derived vertex has just one user.

Starting at a false root, a pivot query leads to a false parent, and a false semantic weakening leads directly to a false parent. Thus no cut exit can be reached on the selected inputs: its vertex occurs strictly earlier and was already certified true. Prune infeasible branches on the promise of 240 unique-collision inputs. Each component occurs just once in the assembled parity tree because each predicate has only one continuation for its true branch. All surviving leaves are physical axiom incidences. The independently checked exact minimum is 100 leaves on this promise (../geometry/tree.md).

In the trimmed DAG let A,B,W count the axiom, binary and unary vertices and s_a,s_d sum number of users minus one on respectively axiom and nonroot derived vertices. A≥40 since every axiom has an assignment uniquely falsifying it. Counting edges gives B=A−1+s_a+s_d. Since A+s_a≥100, total length A+B+W≥139+s_d+W. Repeated material axioms are allowed. This is a restriction on hypothetical short DAGs, not an unconditional increase of the known 112.

For each fixed duplicated hole, it also suffices that falsity of each reused vertex on assignments satisfying earlier reused vertices equals an affine parity on this restricted 60-point promise. Different holes may use different parities; for a supplied proof check each condition by binary linear equations with at most sixty rows. Each successful hole requires at least 25 material incidences labelled by that hole, since the traversal must output its unique falsified axiom. Other holes each require ten incidences. Consequently g successful holes imply length at least 79+15g+s_d+W, restoring the full bound if all four succeed.
