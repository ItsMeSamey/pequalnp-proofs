# Multiple reusable units and a single other reusable clause

In the ancestor DAG of an empty clause, order all multiply used derived vertices by prerequisites first. Test whether their clauses are false, one at a time. If a test finds a false vertex, traverse its component to a false axiom; if none does, traverse the empty-root component. The components cut every reference to a multiply used derived vertex. Each component is otherwise a tree with material axiom references duplicated as leaves. Each backward traversal uses the exact resolution pivot and follows unary semantic weakenings. All cut exits of a selected component refer to earlier true clauses, so no path on its specified inputs needs such an exit. Pruning impossible branches leaves at most as many leaves as physical axiom incidences p. Every component was attached once along the first-false scan.

A clause's falsity set is an affine flat, possibly empty or full. If at most one distinct reused derived clause has falsity of codimension at least two, the decision tree has at most one affine-flat membership query, with unrestricted parity queries elsewhere. This one query may occur below the root. For each fixed duplicated hole, special.cpp exhausts parity trees where either the root asks a flat query and both subtrees use only parities, or the root asks a parity and at most one subtree retains the flat-query allowance. It enumerates all traces of affine predicates by intersecting with binary affine halfspaces. The trees may depend on the duplicated hole. The calculation rejects 22 leaves, and 23 are achieved even when the flat query is the root. Restrict the global tree separately to each hole; each remaining leaf is associated with an axiom labelled by that particular hole. The four counts are disjoint. Hence p≥92.

Counting premise incidences, the number of binary inferences in the ancestor DAG is p−1+s_d, where s_d sums the excess number of uses over one for each nonroot derived vertex. At least forty axiom vertices are necessary by exclusive falsifiers. With W unary steps, the total is at least 131+s_d+W. With at least one reused derived clause this is at least 132. With none the 100-leaf ordinary-parity bound gives at least 139 instead. Consequently any refutation of at most 127 lines must reuse two distinct derived lines with falsity flats of codimension at least two. The unrestricted lower bound is not determined by this condition.
