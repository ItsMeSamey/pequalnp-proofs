# Counting with minimum-rank cross-component anchor completion

Over GF(2), guard i allows xᵢ=1 precisely if Mᵢ·x=cᵢ. Associate one edge i from mask Mᵢ to Mᵢ+eᵢ. The mask graph is a forest because each coordinate labels just one edge, while a closed walk traversing each edge of a nonempty simple cycle once would change each used coordinate. For state bits s_u=u·x one has xᵢ=s_u+s_v. On each edge discard the single forbidden pair with unequal states and s_{Mᵢ} unequal to cᵢ. Conversely, recover x by taking edge differences. A single equation s_{R_j}=R_j·x for the chosen root mask R_j of each tree ensures s_u=u·x throughout that tree by propagation. Thus legal anchored tree states are in bijection with models.

Let H have rows the root masks R_j and assign each edge column to its own tree. Mark the entry of each column in its owner row as free. All its other entries are invariant under changes of roots, because paths inside a tree use only its own coordinates. Define d as the minimum possible rank of an entrywise completion over GF(2). This is invariant under root choices and can be computed in O(2^d poly(n)) time. Each column offers exactly two complete vectors. At each node keep a subspace W, initially zero. A pair whose two members lie outside W forces any feasible completion span extending W to include one of them. Branch by adding each, increasing dimension by one. If every pair intersects W, select such representatives. At depth k reject any remaining missed pair. Iterative deepening yields the minimum and a factorization H'=UV, with U carrying d columns. Gaussian span membership gives polynomial work per branch. The small checker explicitly enumerates span members for convenience. For d≤1, mark all rows and columns incident to a prescribed 1. A rank-one completion exists iff no prescribed zero lies at a pair of marked endpoints. This also covers zero rank.

Given t marker equations Lx=b, enumerate the d-bit value σ=Vx. In a tree T the anchor now becomes s_R = U_Tσ + (H_T+H'_T)|E(T) ·x_T. Process the rooted tree bottom-up, keeping the state bit, this local residual parity, V_T x_T, and L_T x_T. A child bit determines the edge difference together with its parent's bit, hence both legality and all parity increments. Convolution merges child totals. Filter the root by the adjusted anchor. Across trees XOR-convolve the incremental d+t outputs, and retain global feedback equal to the guessed σ. Each valid assignment contributes exactly once. Backpointers or conditional counts recover witnesses. The number of trees and their maximum degree are unrestricted.

This gives 2^O(d+t)poly(n) bit operations. More explicitly, for each σ and character of the outgoing d+t-bit group, a weighted tree calculation needs just the root/child state bit and one local residual parity bit. Multiply the corresponding local Fourier transforms. Inverse Walsh transform supplies totals with feedback value σ and each marker output. All signed counts and inverse transforms have polynomial bit length. This gives O(2^(2d+t)poly(n,t)) time using fast Walsh transforms, together with the recognition cost. The included implementation uses direct integer XOR convolution. The tests compare all answer counts on 630 seeded systems and verify the exact minimum rank on 300 independent random completion instances by enumerating all completions.

# Counting without a bound on coupling

Counting all singleton-guard models over GF(2) is #P-complete under polynomial-time metric reductions, even with no marker, constant-true source guards, and one layer of optional children with two-variable parity guards. Count membership in #P follows by testing an assignment. For hardness use counting vertex covers, equivalent to monotone 2-CNF counting. [Valiant](https://www.math.cmu.edu/~af1p/Teaching/MCC17/Papers/enumerate.pdf)

For a graph G with m edges, create one free source bit per vertex and one free apex bit g. For every edge uv take all three edge occurrences of the triangle (g,u,v) in a multigraph F, retaining parallel copies. For each occurrence of an edge ab of F create k=|V(F)|+1 independent optional leaf bits, each enabled iff its two source bits agree. Write B=2^k. The number of model extensions for a source assignment is B^j where j counts uncut edge occurrences of F. Thus the answer is the base-B integer with digit j equal to the number of such source assignments: every digit is at most 2^|V(F)|, strictly less than B.

Every triangle has one or three uncut edges. Exactly m uncut edges means every triangle has one; equivalently at least one endpoint of each original edge lies opposite g. For either fixed apex value these opposite vertices form a vertex cover and determine every source bit. The mth digit is twice the vertex-cover count. One exact count and polynomial-time integer operations recover it. The resulting system always has the all-zero model, so no decision lower bound follows.

## Symmetric alternating matrices on bipartite graphs

The metric hardness also holds for counting vertex subsets inducing even degree at every selected vertex in a simple bipartite graph, without prescribed vertices. In the construction above put the source vertices in the left part and optional leaves in the right part, joining each leaf to its two original sources. Add a left hub p and one distinct right repair vertex zᵢ adjacent exactly to p and source i. First consider models where p is selected. Any optional leaf can be selected precisely when its two source bits agree. A repair vertex is selectable only if its source is selected, since it already has the selected neighbor p. For any choices of sources and eligible optional leaves, each selected source uniquely determines its own repair bit as the parity of the number of its selected optional neighbors. An unselected source has repair bit zero. The sum of repair bits is even, because every selected optional leaf with any selected neighbors has exactly two. The hub therefore also has even induced degree. This establishes a bijection on conditioned models.

Let N be the number of vertices so far, and attach K=N+1 fresh pendant vertices exclusively to the hub. When p is selected, no pendant can be selected. When p is unselected each pendant is free, and the other vertices have unchanged degrees. The total count is C₁+2^K C₀ where C₁,C₀ are the two prior hub-conditioned counts. Since C₁<2^K, reduction modulo 2^K exactly recovers C₁. The graph is simple and polynomial in the size of the source graph. Thus one evaluation of the unconditioned bipartite induced-even-subset count recovers the vertex-cover count with polynomial-time arithmetic. The underlying unmarked existence question always accepts the empty set.
