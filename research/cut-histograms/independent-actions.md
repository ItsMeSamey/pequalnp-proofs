# Independent primary actions in word equations

Let G=N⋊H be fixed with N,H nilpotent. For each Sylow subgroup H_r let B_rs be its action image on N_s, s≠r. Assume the joint image equals the full product of these B_rs, and every B_rs is generated by abelian normal subgroups. There is no condition on the action on N_r. An explicit word equation with constants in unrestricted group variables admits deterministic polynomial-time decision and witness recovery.

Fix abelian normal subgroups of each B_rs generating it. Their product in any fixed order equals the group by normality. Give each original variable independent cyclic-coordinate parameters for each of these subgroups, taking their ordered product as the B_rs element. Combine these elements over s using the full-image hypothesis, and lift into H_r by a fixed set section together with an independent local choice of kernel element. Further primary digits independently parameterize N_r. The resulting parametrization is surjective; redundancy is harmless. A block comprises all variables' parameters for one such abelian normal subgroup, or all kernel or N_r digits for a given r.

Hold all but a single r-block fixed. For the home output project to N_r⋊H and rewrite this group as (N_r⋊H_r)⋊H_other; H_other fixes H_r under conjugation. Move the frozen H_other components in the word product to the right. This leaves a product inside the r-group N_r⋊H_r, each factor a fixed-domain lookup on the local variable's varying digits, acted upon by a frozen H_other prefix. Apply inverses locally before rearrangement, so the argument includes repeated inverse letters. The home target indicator has bounded iterated-difference degree over characteristic r by augmentation truncation (group-programs.md). This uses no commutativity of H_r.

Only one foreign output s can vary. In its action image, while varying a parameter from an abelian normal A, each projected letter is a variable A-element times a constant. Its A-element depends affinely on the local cyclic coordinates: multiplication by the other fixed factors entails conjugations by fixed elements, automorphisms of A. An inverse letter has the same form using additive negation and a fixed conjugation. Sliding all constants to the right shows the prefix action is an affine map into A followed by a constant. Other source Sylow actions are frozen and commute with H_r's image. Each conjugated N_s factor is a fixed lookup on boundedly many affine r-coordinates. In a fixed splitting field of characteristic s it has bounded character sparsity. The augmentation expansion in the fixed s-group N_s gives a target equality indicator of sparsity L^O_G(1), where L counts expanded word length. All other foreign outputs are constant on this slice. For kernel and N_r blocks every foreign output is constant.

Apply the explicit input-oblivious primary-domain hitting theorem of other-alphabets.md independently on each block. Uniform bounds on every frozen slice allow causal replacement of each block of any witness without losing feasibility. There are a constant (group-dependent) number of blocks of dimension O_G(L); each has an enumerable hitting set of polynomial size in L with group-dependent exponent. Enumerate the product, evaluate via the fixed sections and local parameter tables, and multiply the actual word in G. Return the actual group assignment for any match. For an equation of two words concatenate the first with the inverse second and test identity.

Every class-two r-group is generated by abelian normal subgroups: the normal closure of each g lies in the abelian subgroup generated by g and its central commutators. This permits nonabelian cross-action images. For instance Q8 acts faithfully on (C3)^8 by regular coordinate permutations. A mixed-prime example is C15⋊Q8 where the two factors of the abelianization Q8/{±1} independently invert C3 and C5. Their lifts need not commute. By contrast a single common involution acting by inversion on C15 supplies only the diagonal cross-action image; dihedral-overlap.md describes the exact equivalence of that group's expanded words to unrestricted affine modulo-15 score tests.

[Idziak et al., ICALP 2022, Theorems 2 and 4](https://doi.org/10.4230/LIPIcs.ICALP.2022.127) discuss a conditional centralizer-product lower bound and an RP upper bound for nilpotent-by-nilpotent groups with at most two prime divisors (under CDH for arbitrary complements, unconditional for abelian complements). No conditional lower bound is used in this proof. The conclusions are for unrestricted expanded words on the fixed stated groups; shared-operation circuits and arbitrary variable lists are separate problems.
