# Exact recognition of small coordinated substitutions on a fixed circuit frontier

Choose a block of physical gates with prescribed incoming wires X, outgoing wires Y (all externally used block signals and the output when relevant), and a valid global schedule in which replacement outputs can depend on X. For example use a contiguous interval in a topological ordering. For multiple blocks require an acyclic quotient with respect to their selected interfaces, or verify the final augmented DAG. All external consumers of the old exits must be redirected to their specified new exits.

For full-cube recognition take all input assignments, or all formal assignments to X for a stronger portable test. For promised-sample recognition use ONE common test list with its positive and negative rows. Record each frontier wire's Boolean evaluation vector. Starting from the set of incoming vectors, enumerate sequences that insert the coordinatewise AND or OR of any two available vectors. A vector already present need not be inserted: within this test list the old representative serves all uses. A step can supply multiple eventual exits, and every vector remains freely reusable. After at most d insertions accept if each y can choose an available output vector. In exact mode require equality. In promised mode require at least the old y on all positive rows and at most the old y on all negative rows. Retain witness parents for each insertion.

This criterion is exact for existence of a d-gate monotone replacement over the given X satisfying those interface conditions. Any accepted sequence describes the replacement. Conversely a replacement's topological order gives such a sequence, skipping repeated signatures. It is finite but no efficient bound is asserted. The interface criterion is sufficient for preserving the final function on the test list; it need not detect every contextual replacement whose errors are masked downstream.

For simultaneous substitutions in an acyclic interface order, monotonicity extends the positive and negative inequalities to rebuilt boundary inputs by induction. Cost is the count of previously live gates that cease to reach the output minus the number of fresh gates now reaching it. Reused old producers that still reach a replacement input remain live. This ledger counts physical gates once regardless of block size or reconvergence. Full-cube evaluation on all formal patterns also certifies the identity after arbitrary upstream substitutions.

Independent audit verified the signature-set search and composition. Include constant vectors initially only if free constants belong to the circuit model. The live-gate cost formula presumes an initially trimmed circuit; charge any reactivated old dead gate if that assumption is removed.
