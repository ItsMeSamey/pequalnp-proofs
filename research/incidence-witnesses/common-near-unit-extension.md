# A common set of clean extensions after probabilistic normalization

Suppose a monotone normalized circuit retains every singleton flag, and fails on at most an ε fraction of the original uniformly chosen maximal q-query negatives. For each query set Y of size q that maximal input selects its lines and all points outside their union. This assumption controls these actual dense-point negatives; a sparse bounded-mask correctness statement without this error bound is insufficient.

Select W uniformly from the (q−1)-subsets of all N lines, and put P* equal to the points not hit by W. The expected number of lines l outside W for which Y=W∪{l} is a failed maximal negative is (N−q+1)ε by uniform double counting. If Nε=o(1), with probability 1−o(1) all these extensions are correct simultaneously. For such a choice, for EVERY chain W_i⊆W, every test Z in near-unit-feeder-intervals.md is below the clean terminal maximal input on W∪{l}. For P=W_i+p take any l' outside W avoiding p (there are at least N−(q−1)−(q+1)>0 for q≥2). Then P is below the same clean maximal input on W∪{l'}. F=W_i+p+l is true by upward monotonicity from its flag. Hence the entire disjoint-OR and interval conclusion holds on the normalized physical circuit for this common W.

The untouched-point probability is C(N−q−1,q−1)/C(N,q−1)=exp(−1+O(1/q)). For two distinct points the number of lines hitting either is 2q+1, so their joint untouched probability is C(N−2q−1,q−1)/C(N,q−1)=exp(−2+O(1/q)). The product formulas give these estimates by summing log(1−u)=−u+O(u²) over q−1 factors with u=O(1/q). Consequently E|P*|=(1/e+O(1/q))N and Var(|P*|)=O(N²/q). Chebyshev and the common good-extension event give whp |P*|=(1/e+o(1))N and all near-unit tests correct. Every such point has all q+1 neighboring query lines outside W. No additional normalization is performed along the chain.
