# First failing weight of all anchored subfield-square checks

Let s=4^j with j positive and q=s². The nonzero affine field residuals partition into s+1 colors, the sets t F_s^* in F_q^*. Attach zero to each color in any membership test. Require one active affine anchor p and, for every ordered pair K,T of distinct colors, a square of the kind in alternating-trace-square.md using that same p as its first point. Its second point and two query lines may depend on the colors. Add exact boundary terms for all vertical/infinity queries and direction points. This is a concrete binary monotone function by enumeration and sharing; an efficient overall realization is not claimed.

Every genuine flag passes. In a negative a passing anchor must see every nonzero color among its residuals, since it must provide the first diagonal and off-diagonal entries for every ordered pair. Each active ordinary query provides only one nonzero residual at this point. Therefore no negative with at most s active queries can pass, even allowing arbitrary payload.

For the converse take D={d : d^(s+1)=1} in the nonzero multiplicative group. It has s+1 elements and intersects F_s^* only at 1, because gcd(s+1,s−1)=1. Thus it meets each color once. For distinct e,f in D let z=e/f. The norm of e+f is z+z^(-1); if this were 1 then z²+z+1=0, requiring a nonidentity element of order 3 in D. Since s≡1 mod 3 this is impossible. Therefore D is sum-free.

Activate the s+1 horizontal lines y=d indexed by D, and every affine point outside them (the full independent projective payload may also be used). With common anchor (0,0), for each K,T use the horizontal lines given by their representatives e,f∈D. The second point (0,e+f) is active by sum-freeness. In characteristic two the residual matrix then has diagonal entries e and off-diagonal entries f. Each color pair has a witness, yet all active points miss all active queries. The smallest failing number of queries for this actual anchored circuit is exactly sqrt(q)+1, strictly within the original cap q. The claim concerns scalar Boolean semantics independently of physical gate count.
