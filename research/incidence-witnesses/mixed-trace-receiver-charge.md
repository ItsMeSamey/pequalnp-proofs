# Physical charge after mixed trace pruning

**Directed token lemma.** Let a binary monotone circuit have designated signals g_i, and sets T_i contained in S_i of its raw labels. Assume g_i accepts each bare singleton from T_i and rejects the input consisting of all labels outside S_i. Suppose |T_i intersect S_j|≤t for i distinct from j, with t≥1. Then the original circuit contains at least sum_i (ceil(|T_i|/t)−1) distinct physical OR gates (rows with empty T can be omitted). Gate fanout is unlimited and AND gates may occur anywhere.

Fix i. Begin at g_i with all tokens T_i. Traverse downward in reverse topological order, merging requests at the same wire. Each demanded token is accepted there as a bare singleton and each used wire is false on the complement of S_i. At a site with at most t demanded tokens stop. At an AND choose one child false on the complement, which accepts all demanded tokens. At an OR each child is false on the complement; send each demanded token to one child accepting it. Raw leaves carry at most one token. Token labels at the resulting sinks cover T_i, so there are at least ceil(|T_i|/t) sinks. A connected rooted DAG with outdegree at most two has at least the number of sinks minus one split nodes (count edges versus vertices). Every split is an actual OR handling >t distinct tokens of T_i. Its raw singleton support is contained in S_i by complement rejection. It cannot occur in the charge for another row j: being used there requires rejection on the complement of S_j, yet it accepts >t singletons of T_i. No restriction from different rows was added to another.

**Application.** Consider a query-to-point update using a homogeneous linear quotient Φ of the affine residual y−ax−b with image of size B in F_q (as a vector-space quotient) and kernel of size q/B. Even after previous arbitrary mixed computations, suppose each updated point signal (1) retains each genuine flag at that point on its singleton payload and query and (2) requires some active raw query passing this projected residual. Require (2) on all query masks, as holds for literal existential trace updates, even if arithmetic and prior filtering are jointly reimplemented. Freeze every payload point to one and all nonordinary query labels to zero. For each affine x take one y in each quotient class. These qB point signals have T_xy = {(a,y−ax):a in F_q}, |T|=q, accepted by monotonicity from flags. Signal rejects all queries outside its band S={(a,b):Φ(y−ax−b)=0}. For x≠x′, the q genuine lines of T_xy intersect S_x′y′ exactly q/B times since a↦(x−x′)a is bijective. Rows with common x and different y classes have empty intersection. Apply the token lemma with t=q/B. Hence at least qB(B−1) physical OR gates are necessary regardless of prior mixed pruning, shared arithmetic or rewriting the transfer completely, provided these per-point output semantics survive. The reverse direction exchanges (x,y) and (a,b) after signs and has the same bound. The common input fixing is done once per application. The projective sparse promise alone does not require every carrier to reject arbitrary dense complementary masks; this is an additional algorithmic property of the projected update. This proof also subsumes the earlier exposed-OR lower for a singleton bucket when its addressed semantics hold on the dense controls.
