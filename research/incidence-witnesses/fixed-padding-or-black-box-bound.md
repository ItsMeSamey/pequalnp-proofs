# Fixed-padding OR reductions need at least N/2 oracle calls

Let N=q²+q+1 for a projective plane of order q≥2. A black-box oracle D is an arbitrary monotone Boolean function of a point mask and a line mask that agrees with incidence whenever its line mask has size exactly q. A fixed branch chooses point labels A, line labels Q, and a padding line set T, and calls D(P∩A,(Y∩Q)∪T). It may AND the answer with either or both presence tests P∩A≠∅ and Y∩Q≠∅. The argument also allows the corresponding global tests P≠∅ and Y≠∅. The output is an OR of these branches. The same chosen branches must work for every such D and every input with |Y|≤q. No extra direct flag gates, content-dependent masks, or tests on the oracle outputs are included in this model.

Use two monotone oracles: D₋ is incidence AND the query-cardinality threshold ≥q; D₊ is incidence OR the threshold >q. Both agree on the promised slice. Every one of the N(q+1) flags must be accepted by a branch under D₋. Every branch under D₊ must reject every independent input in the target promise. These need not be the same oracle outside the slice; universality of the fixed reduction is the reason the two tests apply together.

For a branch let S=Q outside T. At singleton flags D₋ acceptance requires the point p∈A, even without a point-presence guard. On nonempty singleton tests let L=Q if a local Y∩Q presence test is imposed, and let L be the set of all lines otherwise. Thus every flag it covers has its line in L. A line in S adds one label to T. For any line in L outside S, the oracle sees exactly T and all imposed presence tests pass when p∈A.

* If |T|<q−1, the branch covers no flag under D₋.
* If |T|=q−1, only flags on lines of S can be covered. For each p∈A at most one line of S can miss p: two such lines together make an independent two-line input whose oracle call exceeds q, so D₊ would accept. For |S|≤2 the flag count is at most 2(q+1). For |S|=3, each eligible p meets at least two of the lines; at most three intersection points qualify. If the lines are concurrent there is one such point, and otherwise each of the three points contributes two flags. Thus there are at most six flags. For |S|≥4 two eligible points would lie together on at least |S|−2≥2 distinct lines, impossible. The single remaining point contributes at most q+1 flags.
* If |T|=q, D₊ forces A×S to be contained in incidence. For lines in L outside S, the value at p∈A is exactly whether p is incident with any line of T. Thus (A∩N(T))×(L outside S) is also contained in incidence, where N(T) is the union of the padding lines. These two rectangles cover every branch flag under D₋. Each nonempty incidence rectangle is a star by codegree one and has at most q+1 edges. With both local presence guards the second line set is simply Q∩T.
* If |T|>q, D₊ forces A×L to be an incidence rectangle, again of size at most q+1.

Every branch therefore covers at most 2(q+1) distinct flags under D₋. Covering N(q+1) forces at least ⌈N/2⌉ calls, even when their physical computations could share gates. This is a uniform fixed-padding OR-reduction lower bound. It neither lower-bounds the size of a particular oracle circuit nor excludes reductions that exploit extra correctness of a specified oracle.
