# Sparse row extraction from producer components

Let G be the incidence graph of a projective plane of order q≥2, N=q²+q+1. A scalar binary monotone circuit computes the incidence predicate whenever at most q lines are selected, for arbitrary point masks. Drop unused gates and normalize constants, copies and coincident parents. All 2N variables are essential. Write s for its gate count, e=s−2N+1. Keep one outgoing wire per nonoutput node, obtaining a rooted tree. Replace other uses by ports, then sever the retained outgoing wire of every producer of such a port, replacing that use by a port too. Each component is a read-once formula on its local ordinary input variables and incoming port occurrences. Every nonoutput component has a distinct producer as its root, and every exterior use of a local variable passes through that root exit. No local variable can influence an entering port, since a path from exit back to inlet creates a directed cycle. There are at most e nonoutput components, by counting excess fanout.

Fix a polarity: a query is a point and data are lines, or conversely. Globally set all query inputs to zero and evaluate every gate as a shared line-only (respectively point-only) baseline, at cost ≤s and one shared zero. For a component C, these global incoming baselines equal its inlets when the only selected query is local to C. They also do not depend on any local data variable. For a local query x the component exit under specialization of x alone is a read-once formula F on local query variables, local data, and those entering baselines. Compute a context for x by multiplying (Boolean AND) all sibling baselines on its path at AND gates; OR gates impose no factor. For every data assignment T, F(x,T)=F(0,T) OR context_x(T). If all AND siblings are one then setting x to one makes the root one. If some AND sibling is zero then changing x cannot affect the root. All local contexts at once are computed top-down, passing the parent's context unchanged through an OR, and conjoining it with the sibling baseline at an AND. The root context is one.

For every incident singleton y the original exit(x,y)=1 and exit(0,y)=0: the global output distinguishes x+y from y, and their exterior variables agree. Hence context_x(y)=1. We use the following cases for negative masks.

1. For the output component the exit is the global output. If C contains any internal incidence, its internal pair is accepted with exterior variables zero, so exit=1 suffices for global acceptance with any exterior inputs. In either case a negative (x,T) gives zero exit (hence zero context), for every promised T.

2. Suppose C has no internal incidence and at least two local query variables. For x choose another such variable x' and a data variable y0 incident to x' but not x. It exists by the plane degrees and the common-neighbor bound, and is exterior. If a disjoint T of size ≤q−1 gives exit(x,T)=1, the assignment (x,T∪{y0}) then dominates the accepted (x',y0) at the exit and all exterior variables, despite being a legal negative. This contradiction works even when T contains local data variables. No local data zeroing is used here.

3. Suppose C has exactly one local query x, no internal incidence, and at least one local data variable z. In this one-query case, compute the context only after setting all of C's local data leaves to zero, retaining its original global port baselines. Evaluating the modified context on T agrees with evaluating the ordinary context on T'=T minus all C's local data, because none of these inputs reaches an inlet. Every incident singleton y is exterior (no internal incidences), so positivity persists. For a disjoint T of size ≤q there is a query x' incident to z and avoiding T': its q+1 neighbors are covered by at most |T'| distinct intersections with other data vertices. This x' is exterior. If exit(x,T')=1 then ({x,x'},T') dominates accepted (x',z) at the exit and in every exterior variable. This is a legal negative: for point queries the right mask has size ≤q and for line queries at most two lines are selected. This forces zero modified context.

A query is thus extractable unless its entire local ordinary variable set consists of precisely that single query in a nonoutput component. In cases 1 and 2, the simultaneous top-down construction uses ≤2 gates per original component gate, alongside the global baseline. In case 3, compute the AND siblings for the unique x path using local data zeroing. These sibling subtrees are disjoint. Recomputing them from baseline ports costs at most their own gate counts, and forming their conjunction costs at most one new gate per AND on the path. Their total cost is at most the component's original gate count. Thus simultaneous extraction per polarity costs ≤3s+2, allowing shared zero and one constants. Every extractable query accepts its q+1 incident singleton inputs and rejects all disjoint data masks of size ≤q−1. The sparse boundary lemma gives ≥q−1 local gates per output, with different queries' local-gate classes disjoint. Constant true is not local since its singleton support is the entire data universe. If a pure AND/OR/zero model is required, replace true in the constructed circuit by the OR of all data: throughout nonempty tests this agrees, and at the empty mask it can only decrease outputs. Alternatively prove the sparse boundary count directly allowing true and zero as inputs (which cannot be local and have support-defining behavior on singletons); this adds no OR-construction cost. The original semantical counting proof applies verbatim to the latter model.

Let G_P,G_L count extractable queries per polarity. Then (q−1)G_P≤3s+2, (q−1)G_L≤3s+2. The remaining 2N−G_P−G_L variables belong to distinct nonoutput producer components, each consuming at least one unit of e. Therefore
    (q+5)s ≥ (4N−1)(q−1)−4.
In particular s≥4N−O(q), and for 2≤q≤393 integer arithmetic confirms 100s≥Nq.

## The LCA operation and sharper gate count

In fact the lowest common ancestor of every pair of ordinary local variables in a component is an OR. For two points, select their common line and fix all other inputs outside the two target bits to zero. For two lines, select their common point instead. In each case the residual two-bit function is OR. For a point x and line z, choose a different point p on z, and a different line l through x excluding p. Such a choice exists also when x is not on z since at most one line through x contains p. Select p,l and fix the other non-target bits to zero: p is not on l but toggling x or z creates an incidence. Again the residual function is OR, using at most two selected lines on all four assignments. In the read-once component, after fixing other variables both LCA-child functions are unary on their sole unfixed leaf, as is the rest of the path to the exit. The final scalar output is also unary on the exit. A genuine OR specialization requires all of those monotone unary maps to be identities; the LCA must be OR. If x,z were incident, the zero background would give the residual AND, impossible at that fixed LCA. Thus no component contains an internal incidence.

It follows that an AND has at most one child with a local ordinary descendant. Its sibling in an extracted context has no local ordinary descendants at all. The sibling value is therefore already known from the global no-query baseline and is independent of all local data. In particular the case-3 context is identical before and after setting local data leaves to zero. Propagate contexts only on paths to desired query leaves. The added gates per polarity are at most A, the number of AND gates, as each AND has at most one relevant child. Write O for the number of OR gates, so A=s−O. In the two global baselines together at least N original gate occurrences disappear: assign to each of the 2N essential input variables any directly consuming gate, counted in the orientation where that variable is set to zero. Each chosen occurrence in a given orientation eliminates its gate by constant propagation, and an original gate has just two operands. Aggregate extraction costs through both polarities are at most 2s−N+2A+4 = 4s−2O−N+4. The earlier inequalities thus strengthen to

    (q+3)s ≥ (4N−1)(q−1)+2O+N−4.

For completeness the OR count O≥2N−2q−1 follows from a maximal rejecting input: take q distinct lines through one point as T and all uncovered points. Exactly q²+1 points are covered, while N−q lines are unselected. Any missing point can be added to create an incidence. Any missing line has at least one uncovered point (if it is the remaining pencil line it contains q such points; every other line meets the q selected lines in at most q points). Thus every one of these at least 2N−2q missing variables is essential at this input. A rejecting proof selects a zero child at each AND and both at each OR; it must reach all missing variables. Otherwise flipping an unvisited missing variable would preserve rejection, contrary to acceptance by monotonicity of incident pairs. A binary rooted proof DAG with m distinct leaves and only OR gates of outdegree two contains at least m−1 such gates by edge counting. Substitution now gives s≥627678 at q=397, whereas the requested integer threshold is 627288.
