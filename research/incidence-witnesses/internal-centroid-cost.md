# Smaller centroid preprocessing budget

In centroid-star-extraction.md let m be the number of binary gates of the output fragment. Preprocess only the tree on its m INTERNAL nodes, retaining parent-child edges when both nodes are internal. For an edge associate the unary map z -> z AND a or z OR a, where a is the other child's baseline signal. In a centroid component compute the path map from each descendant up to its centroid and from the centroid up to each ancestor, storing A,B for z -> A OR (B AND z). Only comparable vertices on paths contained in this component are required. Extending a composite by ONE primitive on either end costs at most two binary gates: an inner AND changes only B, an inner OR changes A to A OR (B AND a); an outer AND multiplies both A,B by a, and an outer OR changes only A. Each visited comparable noncentroid vertex is reached by one such extension. At most m vertex extensions are needed per level, and after floor(log2 m) centroid divisions every remaining component is a singleton. Thus preprocessing costs at most 2m floor(log2 m). A path between internal ancestor and descendant endpoints passes through the first centroid that separates them or equals an endpoint, so propagating a changed wire value along it costs at most four gates.

For a singleton query with r changed frontier/raw leaves, use the virtual tree on changed leaves and their branching LCAs. There are at most r-1 branches, 2r-2 inter-node paths, and one final path up to the old output. Use a path to propagate only to the child of the next branch; then evaluate that branch's true binary operation when both changed children are known. To start a path at a raw or feature leaf, peel its first edge to the parent, costing at most one gate IF the target is above that parent. If target equals the leaf, no peel is needed; if target equals the parent one peel suffices. The sibling on a peeled or precompiled path is unchanged by construction. Thus the whole query costs at most 4(2r-1)+(r-1)+r<=10r. Queries with r=0 reuse the baseline.

As in the companion note, evaluate all upstream gates at zero query input and compute the output-fragment baseline at its chosen defaults using at most s gates in total. Include the per-feature exceptional-incidence corrections at cost at most sum_g |E_g|, computed once per distinct signal. For the occurrence-weighted total K of changed leaves this gives
    Nq <= s + 2m floor(log2 m) + 10K + sum_g |E_g|.
If s<=646424, m<=s and floor(log2 m)<=19. In particular when all E_g are empty and K<=6(m+1), the right-hand side is at most 99s+60 <100s for s>=61, while 100s<Nq. This rules out such a circuit at order 401. The compulsory 2N distinct essential raw inputs ensure s>=2N-1. The one-shore case has K<=m+1. The bound uses only change counts and permits different signals on different shores.
