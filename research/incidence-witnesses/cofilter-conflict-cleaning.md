# Physical cost of simultaneously cleaned cofilters

Suppose named physical heads C_p accept d_p distinct neighboring singleton lines with payload {p}, and reject at that payload every query set Y of ≤r lines missing p. Arbitrary shared mixed circuitry is allowed. The native hypothesis follows for a row p∧H_p∧C_p forced on its own flags when H_p can be turned on by adjoining other points while preserving independence on every such Y. In the normalized square-order example of random-chain-linear-mixed-row-bank.md, for affine p use the q nonvertical neighbors, and test off-star Y within the subdomain of nonvertical query raws. With r=q−2, at least 2q affine points avoid Y, hence two lie in one column. Adjoining them activates the bank H while keeping the payload independent. This proves the required native rejection. The same restriction and conclusion hold if the flags require a separate additional exact boundary branch only on vertical or infinity queries.

For each p let D_p be any set of external point labels such that, when they are absent, adding any subset of remaining points to {p} preserves native rejection on all the indicated negative tests. Native positive tests persist automatically by monotonicity. Join p,z as an undirected edge when z∈D_p or p∈D_z, on the m named owners only. For any independent vertex set I fix the common payload to I throughout the original physical DAG. Each p∈I now has a query head rejecting all its disjoint masks of size ≤r and accepting at least d_p native singletons.

For clarity these simultaneous tests cost at least Σ_{p∈I}w_p gates, where w_p=min(r,max(0,d_p−1)). In the common query restriction mark for p gates whose singleton support lies in its star and has at least two labels. A nontrivial contributing head is marked. If its connected marked ancestors number a<w_p, there are ≤a+1 boundary wires. Thin boundary wires cover at most a+1<d_p incident labels. Pick an uncovered accepted neighbor. Every boundary wire it activates must have an outside singleton, since otherwise the wire would be marked. The ≤a+1≤r outside labels jointly dominate the selected neighbor at this entire boundary, contradicting the required rejection. Distinct p have disjoint marked gates by codegree one, even for reconvergent heads. Constants may be folded. This is the sparse partial-rank charge in the present single-head case.

Random independent priorities yield an independent set of local minima, giving s≥Σ_p w_p/(deg(p)+1). In the equal-weight case s≥w m²/(m+2Σ_p|D_p|) by convexity. For m=Θ(N), w=Θ(q), linear size requires Ω(Nq) directed external dependencies.

More generally specify a family of forbidden external configurations E_p, each a nonempty subset of other point labels, such that avoiding all these configurations suffices to preserve native rejection. Minimal sets corrupting any native negative are one canonical choice. Choose each named owner independently with probability θ, then drop every chosen p whose sampled exterior includes any forbidden set. The remaining I is good for every surviving p, since deletion cannot introduce a conflict. Thus
```
s ≥ Σ_p w_p θ Pr[no E∈E_p lies in the sampled exterior]
  ≥ Σ_p w_p θ max(0,1−Σ_{E∈E_p} θ^|E|).
```
One can also use θ times the product of (1−θ^|E|) by positive association of decreasing events. Configurations involving unnamed labels that are always zero may simply be omitted. When all forbidden configurations have ≥j labels, m=Θ(N), w_p=Θ(q), and H counts the directed configurations, the sum gives a constant multiple of q(θ m−θ^(j+1) H) whenever positive. With fixed j, s=O(N) thus requires H=Ω_j(Nq^j), by optimizing θ in [0,1].

Row-specific errors on the query shore are also allowed. If at a common payload the head for p rejects every disjoint ≤r-mask avoiding a set of e_p outsider labels, mark it and its ancestors only when they accept >e_p+1 star labels and ≤e_p outside singletons. The head satisfies the outsider bound by testing singleton queries. Distinct owners cannot both mark a gate: its >e_p+1 labels in the pencil of an owner with larger e_p would leave >e_p outsiders for the other. For a marked component with a<min(r,ceil(d_p/(e_p+1))−1) slots, thin boundary wires cover <d_p labels, and each activated thick unmarked boundary wire has >e_p outsiders, allowing an outside label beyond the exceptional set. The same domination contradiction applies. This permits individual nonnegative weights max(0,min(r,ceil(d_p/(e_p+1))−1)) in the cleaning bounds.

## Why directed pair count alone does not pay physical slots

In a genuine exact completion choose for each point z one incident line l_z. Form the shared detector E=OR_z(z AND l_z). Replacing every C_p by C_p OR E costs only O(N+m) additional gates. It keeps all independent inputs unchanged, can only increase already-positive outputs, and preserves the native sparse query function at each p. Yet for every z with l_z missing p, the new C_p(p+z,{l_z}) is true while its native C_p(p,{l_z}) is false. Thus a family of all N full native stars acquires at least N(N−q−1) directed singleton conflicts at merely linear overhead. On a subdomain excluding some lines choose each l_z from the retained star, where available. These particular conflicts all require an actual incidence at the alien point z. A stronger size argument would need to distinguish such harmless positive-background corruption or charge the physical detector separately.
