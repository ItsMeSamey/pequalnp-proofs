# Scalar reverse sweep for a unique query occurrence

Trim the constant-free binary monotone scalar DAG to its output. Every one of its 2N raw variables is necessary by removing either endpoint from a singleton flag. Write O for OR count and s for gate count. Let D_Y denote the flags with some accepting proof having a single query leaf occurrence but arbitrarily many payload leaves. Then |D_Y| ≤ s+O−N+1.

Evaluate all baselines B_g(P) with queries zero. In reverse topological order seed the output coefficient to one, send a coefficient unchanged through either OR operand and AND it with the other operand's baseline on passing an AND. OR contributions at a common wire. The resulting coefficient H_l of a query raw is true precisely when a root proof uses that query as its sole query occurrence and all remaining leaves lie in P. Indeed such a proof singles out a path to that leaf and zero-query proofs for each AND sibling along the path. Conversely these data form such a proof upon unfolding; reconvergent wires may use different proofs at different occurrences.

All H_l together require ≤O baseline ORs plus ≤s−2N+1 reverse ORs. There are 2s pin contributions and all s+2N−1 nonroot sites receive at least one. This remains true for tied pins, and multiplying by AND siblings adds only AND gates. H_l accepts the singleton points in D_Y at l and rejects the entire point complement of l: otherwise the original output accepts those points with query l, an original legal negative. Apply the mixed token lemma of mixed-trace-receiver-charge.md to the new common circuit: distinct lines intersect in one point, so at least |D_Y|−N physical OR gates are necessary. This proves the bound without a row interface assumption.

**Dual with bounded query multiplicity.** Reverse instead about zero payload, obtaining H_p(Y) with the same OR budget. Fold constants. For k≥1 and 2^(k−1)≤q, retain only coefficient proofs of AND-depth ≤k−1 by using k layers per OR (same-budget operands), and one lower layer for AND operands (zero if budget is zero). A flag with one payload occurrence and ≤k query leaves gives H_p a proof with ≤k raw query occurrences: the chosen path's sibling baseline subproofs account for exactly those occurrences, with constant-one multiplications folded. Its AND-depth is at most k−1. The truncated H_p cannot accept the whole off-pencil query complement, since any acceptance has a subproof on at most 2^(k−1)≤q off-pencil queries and implies an illegal scalar acceptance with singleton point p. The dual token charge thus bounds the number of such flags by N+k(O+s−2N+1). The depth truncation applies to the derived circuit only.
