# Exactly q common split ORs for every site and every independent negative

Let F be any exact monotone scalar donor on arbitrary point subsets and at most q query lines of PG(2,q). Set N=q²+q+1. There is a binary monotone circuit of size |F|+O(N) for the same predicate, containing one fixed tree of exactly q physical ORs. At every site, on every independent negative containing that site, its q+1 native flag tokens are forced to branch at all q of these same ORs. This includes all maximal negatives for all legal query sets on both shores. The construction also preserves a full-cube donor's correctness. It controls the cost of these split starts, not that of F.

## Native colors

Write the underlying three-dimensional vector space as the field of order q³ and label its one-dimensional subspaces by the powers of a multiplicative generator α modulo scalars. The labels are i modulo N. Fix a nonzero linear functional f and represent line j as the kernel of u↦f(α^(−j)u). These N lines are distinct. An element fixing the two-dimensional kernel and lying outside the base field would make that kernel invariant under the whole degree-three extension, since there is no strict intermediate field. The kernel contains exactly q+1 one-dimensional subspaces. Write D for their indices. Thus a native pair (i,j) is incident precisely if its modular difference i−j belongs to D. Each difference δ∈D meets each site in exactly one native flag.

Build monotone C_δ that on singleton pairs tests this difference. Put w=ceil(log₂ N) and M=2^w<2N. For each shore pad its raw array to M and build the interval-OR tree, costing ≤M−1 gates. At depth h, each prefix interval fixes bit h. To produce both rails of this bit combine the intervals with each of the two bit values using ≤2^h gates. Summing h=1,…,w gives <2M; hence both shores' index rails together cost <6M<12N. Empty cells are folded constants. At singleton inputs the two rails of each bit are complementary. A w-bit binary subtractor computes i−j mod M and its borrow. Add N to the wrapped result when the borrow is set, dropping the final carry, to obtain i−j mod N. Two ripple passes and a binary selector cost O(w): for example two XORs (≤4 binary gates and 2 negations each) and three carry gates per bit suffice per pass by propagate/generate; choosing each final result bit uses at most three further binary gates after complementing the borrow. Dualize both rails by De Morgan, swapping them for NOT. Thus ≤50w+O(1) binary monotone gates suffice for arithmetic. Comparing the result to every δ costs (q+1)(w−1) binary ANDs. AND each comparison with the OR of all query raws to force zero on the empty query, costing q+1 gates using the existing query encoder root. Hardwired constants fold away. The resulting C_δ need only be correct on singleton pairs.

## Exact scalar and signed splits

The simplest version ORs the q+1 terms F AND C_δ. Every independent input kills F. Any positive dominates a native flag so monotonicity makes at least that flag's color high. On a native flag precisely its color term fires.

To use F itself only once, fix a point p₀. Write P′ for the OR of all other points and U for the AND of all q+1 points on one geometric line. Form G=(F OR U) AND P′. It misses every native flag of p₀ and accepts the all-points empty-query negative. For each δ let l_δ be the unique δ-colored line at p₀ and build

    T_δ = (G AND C_δ) OR (p₀ AND l_δ).

On any independent mask with a nonempty query, U=0 because each active line meets U's line. On the empty query all C_δ vanish. The additional products are genuine edges. Thus every T_δ is false on every independent mask. On a native flag exactly its own T_δ fires, including at p₀. Monotonicity proves correctness throughout the donor's domain. Beyond the color decoder and donor, this version costs at most (N−2)+q+2+3(q+1)+q gates, including the scalar collector. No requirement on donor internals is imposed.

On the q+1 flags of any site, each leaf of the fixed collector tree has a different private row. Its internal ORs have genuine opposite private signs, one from each child. All tree gates are false on every independent mask. Backward flag-to-negative comparison must follow the row's unique color at each OR under every tie rule. Thus for every site active in a given negative, all q branch starts occur in the same q physical OR gates. At each leaf only one flag for that site remains. Traces from different leaves may reconverge in the donor or decoder and split again. The exact q count concerns the common collector, not the entire circuit or all splits of any complete trace. A binary traversal separating q+1 rows requires q distinct branching vertices when its terminal discrepancies must be distinct; the count is sharp for these signed-split obligations. More negative masks do not make those already shared starts distinct. In the Fano case one can take D={0,1,3} in Z/7Z. This does not give a lower bound on minimum circuits or a subtarget construction without the exact donor.
