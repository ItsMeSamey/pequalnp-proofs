# Exact formula size on sparse line masks

For a projective plane of order q≥2 with N=q²+q+1 points and N lines, every binary monotone formula passing the sparse incidence tests has at least N(q+2) variable leaves. The usual formula that takes the OR over points p of the conjunction of x_p with the OR of its incident line variables attains this count. The minimum number of binary gates in a formula is therefore N(q+2)−1. Constants can first be folded away.

Write d=q+1. For each incidence e=(p,l), use its two selected coordinates as the positive input. Define the negative input S_e by selecting the points on l other than p and the lines through p other than l. Each selected line meets l only at p. Thus S_e contains no incidence and has exactly q lines. Monotonicity and the specified negative test for this line mask force rejection. The argument uses only these incident-pair positives and these particular negatives.

On a pair (x,S_y) of these inputs, start at the formula root. Maintain a node that evaluates to one on x and zero on S_y. At an OR choose the first child that is one on x. At an AND choose the first child that is zero on S_y. Each choice depends on just one input, and both choices preserve the invariant. At a leaf the variable labels a coordinate in x absent from S_y. As the formula is a tree, the pairs reaching a given leaf occurrence form a rectangle in the row index x and the column index y. These rectangles are disjoint. This is the monotone Karchmer–Wigderson traversal. The proper-neighborhood inputs and formula rank argument build on [Jukna, Theorem 5.1](https://eccc.weizmann.ac.il/report/2004/005/download/#page=12).

Orient each edge y toward the endpoint returned on the pair (y,S_y). Both endpoints are absent from S_y. For a vertex v with star of size d, restrict rows and columns to this star. If x≠y share v, the other endpoint of x belongs to S_y. Hence v is the unique possible return value. Let t_v count the edges oriented away from v. The matrix indicating return value v on the star square is all ones except for the t_v diagonal zeros. Every leaf occurrence labelled v contributes the indicator of one rectangle, of real rank at most one, on this square. Disjointness ensures the ordinary sum is the indicated matrix. The number of occurrences of v is therefore at least its real rank.

If t_v<d, choose one all-ones row. Subtract it from each diagonal-zero row to obtain t_v distinct negative coordinate vectors. The all-ones row is independent of these because it is nonzero in an unaffected column. These rows span, giving rank t_v+1. If t_v=d, the matrix is J−I. It is invertible over the reals for d≥2, since any null vector has each coordinate equal to the sum of all its coordinates and hence is zero. The rank in both cases is t_v plus one whenever v receives an edge, and t_v otherwise.

Summing t_v gives exactly the number Nd of incidences. The vertices receiving at least one edge cover every edge. Each covers at most d edges, so at least N vertices receive an edge. Summing the occurrence bounds now gives Nd+N leaves.

For a circuit with sharing, the proof applies to the tree obtained by unfolding its output. If each internal gate has at most m directed wire paths to the output (counting parallel wires separately and the output's length-zero path), a circuit with s internal gates unfolds to at most ms internal occurrences. Thus ms≥N(q+2)−1. Arbitrary circuits can have many paths through a gate, so the unrestricted size question remains open.
