# Simultaneous pinning and semantic reoptimization in a genuine native minimum

Let C be gate-minimum for the original plane incidence promise and D a set of query labels. Choose any internal addresses H for which the ORIGINAL evaluation of each h is one at every maximal negative (outside(Q),Q) with |Q|≤q and Q disjoint from D. Here outside(Q) is the set of points avoiding all active queries. In one edited circuit force all H to one, set all D queries to zero and perform any sound semantic reoptimization; write r for an achieved physical gate count. On each native negative (P,Q), project Q to Q'=Q minus D. It remains independent and P is contained in outside(Q'). At the maximal mask (outside(Q'),Q') all H already equal one, so simultaneous pinning leaves every original wire unchanged, even for comparable addresses. Monotonicity now implies the projected edited circuit rejects (P,Q'). True flags whose query is outside D remain true since forcing internal gates to one can only increase outputs on that flag. Adding the ordinary point star for each deleted query needs at most (q+2)|D| gates including its join to the edited output. Constants, if retained as outputs after simplification, can be folded in the joins. The result is valid on every original native test. Consequently
    s ≤ r + (q+2)|D|
in every genuine minimum. If using literal pinning/forwarding and any fixed cleanup, this bounds the number of ORIGINAL removed gates, with arbitrary overlapping and nested pinned cones. No cost is assigned to a pin per separate experiment.

One sufficient condition uses original zero-query singleton supports. If for each h and every retained Q there is a p outside Q's covered points with h(p,0)=1, monotonicity gives the required maximal evaluation. For a common such singleton p0 take D to be all q+1 queries through p0. For a common whole line d of accepted singletons take D={d}: any other q lines cover only q of its q+1 points. More generally pin simultaneously all addresses whose supports include a whole line in D. They and every additional physically discarded row jointly cost at most (q+2)|D| in a minimum. These hypotheses are checked on actual gates. The latter conclusion also applies to all-query-AND siblings accepting the complete singleton point star of one of the selected lines.

For a root conjunction A AND B with A(p0,0)=1 this gives s≤r_B+(q+1)(q+2), where only B with its incident-to-p0 queries zeroed needs to be realized. The entire private A computation disappears; retain any shared ancestors still needed by B exactly once. In particular two macroscopic separate checker branches of this form, both with private cost larger than (q+1)(q+2), violate global minimality.
