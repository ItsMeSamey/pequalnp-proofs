# Joint cleaning of labeled point–query corruption

Use the native cofilter hypotheses of cofilter-conflict-cleaning.md on all N points, with all q+1 native flags per owner. Let J be a fixed graph between point labels and query labels. Assume that whenever Y misses p, |Y|≤r, and C_p({p}∪S,Y) becomes true, some pair in S×Y belongs to J. Here S excludes p. The graph need not be a subgraph of incidence. When the row bank can be warmed on every independent extension, the entire true incidence graph is one such explanation; the lemma quantifies how much smaller it can be. If there is enlarged-payload corruption with Y empty, no explanation graph can exist. Conversely in the absence of any such corruption the complete bipartite graph is an explanation, since a corrupting S must be nonempty by native rejection. If no corruption exists take J empty.

Select points for I independently at rate θ in (0,1). Delete query labels l having any J-neighbor in I. At the common payload I, every C_p for p∈I rejects every native-negative mask of ≤r undeleted queries, and retains the surviving native flags by monotonicity. On the same physical DAG the query partial-rank argument charges at least min(r,max(0,d_p−1)) gates per head, where d_p counts its surviving native flags. Distinct heads have disjoint marked gates as before. This bound allows empty I, empty retained query sets and zero-degree heads. For r≥q−2 the per-head bound is at least d_p−3. A native edge p,l outside J survives exactly when p is selected and no J-neighbor of l is selected. These conditions are independent. Native edges in J cannot survive. Consequently the size is bounded below by
```
θ Σ_l [q+1−|N_inc(l)∩N_J(l)|](1−θ)^deg_J(l) − 3θN.
```
For a restricted collection of owners or lines use its actual number of named incident owners, and charge the minus-three term only on the selected named owners. A negative displayed bound is vacuous.

Let μ=|J|/N≤(q+1)/4. At least half the lines have J-degree at most 2μ, and each has at least (q+1)/2 uncovered native edges. Taking θ=1/(4(1+μ)) gives (1−θ)^(2μ)≥1/2: at integer line degree j≤2μ use Bernoulli's inequality (1−θ)^j≥1−jθ≥1/2. Thus s≥θN((q+1)/8−3). If s≤CN then μ≥((q+1)/8−3)/(4C)−1, or alternatively μ>(q+1)/4. Both alternatives imply |J|=Ω_C(Nq) for large q. In particular globally shared pollution through O(N) labeled pairs leaves an Ω(Nq) physical cofilter cost, even though such pollution can cause Ω(N²) directed owner–owner dependencies.

For the genuine incidence explanation, if a corrupted off-p input contains no real incidence then it is potentially still independent after adjoining a payload witness that warms the row head. A guaranteed independent warm extension would make the actual row and its cofilter true, contradicting exactness. Hence whenever this extension property holds on all enlarged independent tests, every corrupting test must already contain a genuine incidence between S and Y. The above conclusion then applies to every subset of true flags hitting all those witnesses.
