# Physical incidence restrictions and the order-401 interface

The Lean modules record physical zero restriction, operand counts, forward pinning and preservation results for restricted masks. The official-type wrapper derives the fixed-order conclusion **assuming ScalarLower401**, which retains the original sparse one-sided promise before normalization. The mathematical order-401 lower bound and the completed numerical lemmas are documented in the parent directory. The arguments connecting every original circuit to the final inequalities still require formalization.

The source manifest lists the modules in this snapshot. The producer directory records each source hash, object hash and printed axiom report. Repository modules imported under Research are in lean/Research at the same commit.
