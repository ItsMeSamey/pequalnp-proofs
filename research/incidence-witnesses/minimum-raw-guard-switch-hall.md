# Simultaneous Hall expansion at raw-guarded switches in a gate minimum

Select a size-minimum physical scalar circuit for the original plane promise minimizing the sum of c_e from alternation-switch-charge.md. Fix ONE minimizing consistent proof DAG for each native flag. Fix a raw vertex y, and consider private marked ORs g_i, each with one reader slot feeding h_i=g_i∧y. Put P_i equal to the set of opposite endpoints x whose chosen flag proof visits h_i. Every positive proof visiting h_i must have raw y active. Each h_i is required on at least one native flag by size minimality (pinning h_i to zero otherwise preserves all flags and removes it; negative outputs only decrease).

For every nonempty subset S of these switches,
|union_{i∈S} P_i| ≥ 2|S|+1.

Indeed, write U for the union. Replace all uses of all h_i in S by one common new signal y AND (OR_{x∈U}x), which costs |U| binary gates for nonempty U, including the AND. Redirect the scalar output too if needed and delete the |S| old h_i and their |S| respective private ORs. These are all different physical gates. The common signal is false on every independent mask. Relative to clamping all affected h_i to zero, evaluation on negative masks is identical, hence stays zero. On every flag truncate its chosen proof at the first replaced nodes: a visited h_i guarantees (x,y) has x∈U, so graft a proof of the new star. Other surviving proof choices remain consistent even under reconvergence.

No OR can gain marked status: the new ORs have only raw ancestors, and any old OR downstream of the replacement that now has the new AND as ancestor already had an old h_i as AND ancestor. Any surviving old-to-old path through the replacement would have to enter from a raw input, so old ORs gain no AND descendants. Each translated proof has at most its old count c_e, and a proof visiting some replaced h_i loses at least one marked g_i: it visited its private g_i before, which no longer exists, and no newly marked node replaces it. Since the family is nonempty, at least one chosen proof visits an affected gate. If |U|≤2|S| then size decreases, or size stays equal and the secondary optimum improves. Either is impossible.

Hall's theorem on two copies of each switch gives two distinct assigned flags per switch, with no reused flag within one fixed guard raw. Guard raws on a single shore have disjoint flag stars, so the same packing works across the whole shore. Across both shores an incidence can be used at most twice. Equivalently the number of such switches at y is at most floor(q/2). The expansion lower-bounds required positive duties; it is not an upper bound on flags per physical switch. It requires actual minimality under the stated secondary cost and does not count multiple negatives as separate gates.
