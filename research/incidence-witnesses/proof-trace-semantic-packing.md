# One-sided proof traces and common semantic separators

Fix one upstream signal library as in semantic-bank-mincut.md. On every native flag e fix one accepting output proof: descend through one true OR operand and both AND operands. On every same-query maximal negative n fix one refutation: descend through one false AND operand and both OR operands. The one-sided choices can extend a fixed KW rule. Let P_v,Z_v list the tests whose chosen proof or refutation visits v. A monotone tap recipe exists on the dictionary values iff no positive signature in P_v is componentwise below a negative signature in Z_v, allowing constants in this abstract criterion. The OR of conjunctions of positive signature supports proves sufficiency. For an actual constant-free basis use physically implemented, nonempty terms, discard those activating Z_v, and test coverage of P_v. Cost every added gate once.

The physical mincut and integral path packing from semantic-library-path-packing.md hold unchanged with these reduced recipe obligations. For any joint deletion, truncate each root proof or refutation on each path at its first deleted gate. Each such tap meets the chosen trace obligation, and its recipe is computed from unaffected signals. Induction through the retained proof yields true on the flag; the dual induction yields false on the maximal negative. Monotonicity covers all smaller independent inputs. One ledger therefore covers arbitrary reconvergence, without requiring replacements to approximate old truth values on tests never using that gate in the chosen proof. Two-sided KW visits alone omit some children needed at a positive AND or negative OR.

Select one actual physical raw pin at each of a set H of distinct high-rank sites. The consumer gates give at least ceil(|H|/2) distinct starts by binary fan-in. If all starts are deletable and a finite-recipe separator T meets all their forward paths to permanent readers or output (starts in T count), minimum size implies ceil(|H|/2)≤k+Σ_T c_t. This uses one shared library price k and the same global proof ledger, even when paths merge. No degree or rank cap is asserted for arbitrary gates.
