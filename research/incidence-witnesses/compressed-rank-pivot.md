# A forced rank-r pivot with logarithmically many direct uses

In any plane choose a pivot p, a line y0 through it, a point a on y0 other than p, and a query d through a missing p. Select r=2^k other pencil queries y_i, 4≤r≤q−1, with distinct k-bit indices i, and ui on y_i other than p. Build g=p OR a. Define the honest matching-and-pivot scalar B=OR_i[(p OR ui) AND y_i]. For bit position t and value b let Y_tb be the OR of y_i in that bit class, and U_tb the OR of ui in that bit class. Starting from C_{k+1}=B, define C_t as the OR for b=0,1 of

Y_tb AND (g OR U_tb) AND (C_{t+1} OR U_t(1−b)).

The main term is C_1 AND H, with H=B OR [y0 AND OR_j(uj AND AND_{i≠j} yi)]. Add the separate term g AND d AND (a OR y0) for the native flag (a,d). Complete all other flags except the established (p,yi),(ui,yi),(a,d) by an ordinary unshared formula.

The main term is sound. On any negative B is false. If H is true then y0 is present, some uj is present, and every yi other than yj is present. Independence excludes p,a, every ui except uj, and yj. Consequently on the displayed inputs the recurrence sees g=false, the unique point index j, all other working query indices, and B=false. Descending from C_{k+1}=false, if the b bit matches j then the continuation clause is false; if it differs then g OR U_tb is false. Thus every C_t is false. Conversely (p,yi) passes all levels with g and the continuation, and (ui,yi) passes using its own U bit and the continuation. The auxiliary term is safe because d meets a and y0 meets p. It accepts (a,d). This proves exact incidence on the entire cube.

For KW rows ei=(p,yi) and the corresponding proper-neighborhood negatives Sj, only the main term accepts ei and H is true on each Sj. On the row the only possible bit branch is b=bit_t(i). On any Sj both Y_tb are true because r/2≥2, and exactly one point index uj is active. If i and j differ in this bit then only g OR U_tb is false and KW must visit g; if they agree only the continuation clause is false, and KW must visit C_{t+1}. Upon reaching the base with i=j only yi can be returned (ui is high on Sj). At g the row forces the physical p pin. Thus the approached-pair matrices at g and its p pin are J−I, rank r, for every tie rule. This uses just 2k+1 direct physical readers of g. Replacing g by just a loses a pivot flag; replacing it by just p loses (a,d). The native flag support of g is contained in no single raw star.

To see there need not be a jointly safe shared coalition, implement each appearance of a bit OR as a separate formula, and implement three separate B formulas (two last-level uses and one occurrence in H). Choose two complementary indices h,j. Compute the all-other query products in H using prefix/suffix ANDs of the r−2 indices outside {h,j}; append the necessary one or two exceptional raw factors in private final chains. Thus any shared gate of this query bank depends by AND solely on indices outside {h,j}. All other shared internal gates are g and some C_t for 2≤t≤k. The negative with payload {a,uh,uj} and all working queries except yh,yj makes g and all the shared query-bank gates true. At the last bit take any present query and use the opposite live U bit instead of the base. This makes C_k true; earlier C_t then stay true. Hence this one legal negative activates all shared gates, each of which misses some flag. The extra circuitry costs O(r log r) gates beyond the ordinary full-plane bound.

This is not a minimum circuit: in particular the multiquery-only arms of H never witness a native flag and may be removed while preserving all promised positives and negatives. It refutes inference of r physical immediate readers from rank r and shared dirtiness alone. It does not refute linear total physical cost in r or a stronger normalization.
