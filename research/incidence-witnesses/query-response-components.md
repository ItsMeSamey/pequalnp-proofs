# Batched extraction through every shared-gate component

Cut the original DAG into formula definitions rooted at every shared internal gate and the output. These components have m_C gates with sum s. Process them in topological order. For each possible query label l the inputs of each component are the raw payload, that singleton-query assignment and earlier components' already-constructed response wires. For each earlier shared signal g choose the most frequent function among its N actual singleton-query responses as the common default. This representative was computed for a previous query, hence is available to descendants; no equality test has to be implemented in the constructed circuit. Let delta_g be N minus this largest multiplicity. Payload raw inputs are unchanged; each raw query occurrence changes once from its zero default. Compute a component's baseline using its own leaf defaults in at most m_C gates. It need not equal any of that component's actual query responses.

Use internal-centroid-cost.md independently within every component. A query whose input wires differ from their defaults on r leaf occurrences costs at most 10r, or zero if r=0. Each intercomponent wire from g contributes delta_g changes, yielding the general inequality
    Nq <= s + 2 sum_C m_C floor(log2 m_C) + 10(U_L + sum_shared f_g delta_g).
There is no restriction on the types of shared gates or their locations. Since the construction gives exact responses to all singleton queries on all payload assignments, apply it in both orientations on the original promise using the sparse simultaneous-star lower bound. At q401, s<=646424 implies floor(log2 m_C)<=19 and each orientation requires U_L+sum f_g delta_g>=3943187. Summing orientations gives sum f_g(delta_g^P+delta_g^L)>=7239949+F.

Alternatively use common all-query-zero baselines, so every singleton-query change increases its signal pointwise. Put delta_g^0 equal to the number of query labels with a response different from this baseline. Represent a changed wire by its baseline OR a delta wire. At an OR with one changed child transmit that child's delta unchanged; at an AND multiply it by the opposite baseline. The unary path map therefore needs only an AND-product, with at most one new gate per extension and at most two per query path. At a virtual branching node, compute the new value from both new children (two joins with baseline and one gate), then take that value as a valid delta. Rejoin the baseline at the root. Over r changed leaves the internal-path and branch costs are at most 2(2r-1)+3(r-1)+1. Peeling the first raw-leaf edge costs nothing for a changed query literal, whose new value is one; a changed incoming feature needs at most one gate on this peel. The elementary bound also applies to any emptied baseline cases. Thus
    Nq <= s + sum_C m_C floor(log2 m_C) + 7 U_L + 8 sum_shared f_g delta_g^0.
These response statistics must not be confused with number of accepted line singletons: general mixed gate responses are functions of all payload bits. Neither inequality settles the unrestricted problem.
