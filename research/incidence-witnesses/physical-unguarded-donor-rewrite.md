# Reusing physical donor gates after unguarding

In a native scalar circuit of s gates choose an original address d accepting every incident flag (for instance an AND-root child). In its fanin select OR addresses h=x_h OR K_h and redirect each to its indicated original operand x_h. Apply all redirects in topological order, retaining sharing, then trim to d. This constructs R with r reachable remaining physical gates, with no external donor wire or new internal gate. If d loses any flag then some original K_h accepted it: when every original K_h is false on that input all substitutions reproduce the original values by induction. Compute the actual lost set L by evaluating R on the incident flags.

R must separately be certified to reject original independent negatives: lowering an AND operand d does not alone imply safety of a standalone replacement. One sufficient certificate is a shared OR assembly of terms dominated by genuine stars p AND (OR of queries incident to p), or their dual. Domination of a monotone term by each factor can be checked at the maximal assignment where that factor is zero. One can instead test all maximal original negative masks. Repair the actual missing flags by assigning each to an endpoint in a minimum vertex cover of L. A group of j flags needs j−1 neighbor ORs, one AND and one join to R. Thus native minimum implies s≤r+|L|+tau(L). For empty L the replacement uses exactly the r retained gates.

For dense-dirty-branch-packet-residual.md redirect every A-branch raw proxy to its actual, unshifted raw. The surviving gates consist of qN point-bank ORs, N line-star products and N−1 collectors. Each term is literally its original native line star, so R is safe and L is empty. The exact physical cost is r=E+N−1, requiring zero added gates.

To count the saving fix the displayed separate physical binary banks, sharing the named raw proxies and global guards. Let u,v be the pure threshold circuit gate counts after constant folding; t the number of retained packets; and c the number of point labels needing a nonempty completion term. The filler star costs q+1, two guard ORs cost two, and there are 2N raw proxies in each branch.
