# Charging physical query slots in disjoint cold-pool regions

For each query l use its anchor n_l=(all points outside l, query l). Process the original DAG in a common topological order. Maintain for l a disjoint-set partition of its q+1 points and an OR wire for every current block. At each cold gate on n_l the nonempty accepted singleton payload set S is inside one current block. This holds for raws. A cold AND inherits coverage from any cold operand. A cold OR either inherits it or merges the two different operand blocks by one OR. Later merges only enlarge blocks. At the output the entire line lies in one block, so exactly q unions occur per line. Each charged OR accepts at least two distinct actual singleton payloads under query l. Every common order incurs Nq charges.

For OR g let L_g be its charged labels. If |L_g|≥2 then its zero-query singleton payload support lies in each charged line: a point outside the line is already active in the cold anchor. Distinct lines meet in at most one point. For each charged l choose an accepted singleton p(g,l) outside that zero-query support. Thus g changes from zero to one on that fixed singleton payload when query l turns on.

Choose pairwise disjoint sets R_g of physical gates, one for each selected multi-charge g, with g in R_g. A boundary wire is an internal gate outside R_g used by a gate in R_g. Let B_g consist of l in L_g for which a boundary wire changes between (p(g,l),0) and (p(g,l),l). If l is not in B_g then a gate in R_g reads raw query l directly. Otherwise all external inputs would be unchanged, and induction inside the region would keep g unchanged. The charged raw slots are distinct across labels inside g and across disjoint regions. Hence sum_g (|L_g|−|B_g|)≤U_Q, the physical raw query operand slot count (ties counted). Selecting every multi-charge address gives Nq≤O+U_Q+sum_g |B_g|, where O bounds the number of singly charged OR addresses. Region choice and singleton witnesses may be optimized jointly. O+U_Q≤3s; a corresponding 97s aggregate bound on boundary responses suffices for the target. Boundary labels are not counted as distinct physical wires. One shared intermediate may respond to many tested labels and enter several regions. The statement uses arbitrary DAGs, with no global-minimality assumption.
