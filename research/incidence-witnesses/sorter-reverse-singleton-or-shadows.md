# Positive-only shadows for actual sorter pseudocomplement networks

Consider a standard comparator network sorting the raw query bits Y. For each target cardinality k≥1, use fixed complementary rank constants at the sorted outputs and recover complements in reverse. At a comparator with inputs a,b and outputs u=a OR b, v=a AND b, the two recovered wires are

    bar(a) = bar(u) OR (b AND bar(v))
    bar(b) = bar(u) OR (a AND bar(v)).

The complement computation agrees with Boolean negation on input masks of cardinality k. A downstream monotone circuit may read the positive input bits and any physical forward, reverse, or partial-product wire. Several target cardinalities may share the forward network. No point-dependent wires are fed into this network and no externally perturbed complement bits are used in its recurrence.

## Terminal outputs

Every monotone signal equal to NOT Y_i on the exact k layer is forced globally to equal [|Y outside i|≥k]. Below k, extend the mask to a k-set containing i; above k choose a k-subset avoiding i. Together with the exact layer these force the two values. Thus every terminal complement for k≥2 vanishes on every singleton query. When an entire monotone circuit accepts all incidence flags and rejects all required negatives, such terminals may all be set to zero in the downstream circuit: no flag trace changes, every legal positive contains a flag, and the substitution only decreases the function. The k=1 complements are exactly the ORs of all query labels except i. All N of those can be supplied by fewer than 3N positive-only binary ORs, via subtree ORs and outside-subtree ORs in a binary tree. Sorted positive rank outputs beyond the first likewise vanish on every singleton query.

## All internal taps

For a query-only gate g define its positive-only shadow by g(empty) OR the union of all raw labels l for which g({l})=1. A nonzero empty value means the shadow is constant one. This is a pointwise lower approximation, agreeing exactly on the empty mask and on every singleton. For general ANDs its construction could require expensive intersections of distinct raw support sets. The actual reverse sorter admits shadows with no such intersections.

The forward network preserves one-hot state at every layer, and maps the empty mask to the all-zero state. Thus every lower comparator output has shadow zero. Every upper comparator shadow is obtained from a single OR of the input shadows. Now process the reverse recurrences, starting from their fixed rank constants. At an intermediate product b AND bar(v), the positive forward operand b is zero at empty. On any singleton for which b=1 the entire current layer is exactly the same state, with one at the wire b. Every forward signal in the suffix is therefore fixed on this set of singleton inputs. Every reverse value in the suffix is determined by those forward states and the fixed terminal rank constants. In particular bar(v) has one common value across all singleton labels reaching b. So the product shadow is either zero or exactly b's forward shadow. This choice is a fixed wiring decision; it can also be found by simulating one reaching singleton if there is one. The product a AND bar(v) is identical in form. Taking the indicated OR of shadows now computes each reverse output's shadow. This works for each cardinality separately, with the forward shadows shared. A rank constant one represented by nonemptiness instead is still constant on every one-hot state; its empty value is handled by the same shadow rule.

The result is a simultaneous OR-only representation for all tapped wires, using no more slots than the original forward upper and reverse OR gates plus the original constant sources. Every positive flag has exactly its old tap vector; every negative has componentwise smaller tap values. Any downstream monotone circuit already exact on the full original promise remains exact with these taps replaced, regardless of sharing and regardless of the point payload. This does not turn a circuit correct only on the k-slice into a sparse decoder; input flag correctness is necessary. The postprocessor may still perform nontrivial mixed computation using the positive OR taps, including raw label information.

## Optional constant-only replacement

When only terminal complements are exposed, one may additionally set the k=1 complements to one. After the k≥2 zeroing this preserves all flags and is still correct on negatives with at least two queries. In any projective plane fix a line d, restrict this circuit to points off d, and AND its output with the OR of queries other than d. On a singleton negative with query l≠d the retained payload also misses d. Adding d gives a negative with two queries, so monotonicity enforces rejection already at l. With no queries or only d, the external gate rejects and there is no retained flag. Complete with the exact stars of the q+1 removed points, using O(N) additional gates shared across all readers. This variant assumes q≥2 and one cardinality-independent incidence target. For ordinary removal of sorting machinery, the direct outside-OR implementation above suffices.
