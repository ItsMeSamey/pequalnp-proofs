# Reverse contexts with globally forced pivots

At zero query inputs evaluate the payload-dependent baseline of every original gate. Reverse-propagate a context of one from the scalar output. OR sends its context to both children; AND sends to each child the context times the sibling baseline. OR all incoming contributions at each internal wire and raw query input. A raw query context is exactly the existence of a parse using that query once and no other query occurrences. If D counts raw payload uses and A counts ANDs, aggregation takes at most (2s−D)−(s−1+N) gates, since every nonoutput gate and every raw query input receives at least one contribution. With D≥N, the baseline, the at most 2A transmitted AND contributions and B exceptional flag repairs cost at most 2s+2A−2N+1+B. Each repair adds the flag's payload endpoint to its query output. No disjoint payload mask is falsely accepted. SparseQueryCut.simultaneous requires only disjoint payload masks through size q, so both orientations are valid on the original sparse-line promise.

For each chosen internal pivot h compute Q_h(P) by setting the queries to zero and forcing every use of h to one. Add Q_h as another seed into the reverse OR at h. One may substitute any known lower approximation to Q_h. A path from this pivot certifies a once-query parse of h and Q_h(P)=1. On the actual singleton query the pivot is therefore true and the true output dominates the forced all-query-zero computation. Multiple seeds, including nested ones, work in the original single reverse pass because its transfers distribute over OR. Charge at most one joining OR per pivot in addition to the actual cost of its seed, then count only the flags still missing. For a shared shield (H OR a) AND (H OR b) with a AND b implying H, the seed Q_H is constant one. It restores all once-query parses in H even when the outer conjunction duplicates every one.

Single-pivot forcing remains incomplete when all internal pivots are available. Take a point a and an incident line b. Build two branches with disjoint internal slots: U is incidence with point a deleted, OR the raw point a; V is incidence with line b deleted, OR the raw line b. Their conjunction is exact incidence, since the branches are F OR a and F OR b. On every flag avoiding the markers, both branches need the query line and neither is true on the point alone. Forcing any internal signal of either branch leaves the opposite baseline zero. The root seed reproduces the original derivative. Thus no one-pivot seed recovers these flags. In contrast, compute once-query outputs for U and V separately and AND them coordinatewise. Using standard star formulas within the branches, these paired outputs recover all flags avoiding the markers.

For any finite pivot set S, the joint forced baseline C_{S=1}(P,0) times a certified lower approximation to every h(P,{l}) for h in S is sound: if all factors are true, the actual evaluation dominates that forced baseline. This can require several reverse passes and per-query ANDs; their costs must be included.
