# Matching two-shore raw reads to anchored cold-pool mergers

Use the physical mergers in cold-pool-private-cone-debit.md. In every line l, pick one actual positive singleton point in each of the two operand blocks whenever they merge and join those two points by an edge labelled by its original OR address. These q edges form a spanning tree: every addition joins distinct components and the output contains the entire line. Root the tree anywhere. Assign to every merger its edge endpoint farther from the root. These assigned flags (p,l) are distinct globally: in each row the nonroot points are used exactly once.

Exempt singly charged addresses, at most O. For every remaining event e=(g,l) form two sets of possible *physical operand slots*. In the point set include slots reading either actual operand witness p at that merger from which a changing path reaches g under the paired tests (empty,l) and (p,l). A changing path means each gate on it has different Boolean values on the two tests and the first gate is the reader of the specified slot. Both witnesses are possible: the empty payload is dominated by the rejected anchor, and the chosen singleton is accepted. In particular the distinct oriented flag above supplies one eligible point label per event. In the query set include slots reading l with a changing path to g on (p,0) versus (p,l) for ANY actually accepted singleton p at g. A point giving a query change always exists at a multi-charge address because its zero-query singleton support lies in the intersection of its charged lines. In both cases a changing path exists by following a changed operand backwards, eventually reaching the unique raw that changed. All tests use actual original gates. The two path sets need not share a witness.

Build the bipartite graph of nonexempt events and their possible raw slots on both shores. Its Hall deficiency d=max_S(|S|−|neighbors(S)|), allowing S empty, is precisely the minimum number of these events left unpaid by any injective choice of raw slots. Hence Nq≤O+U_P+U_Q+d. In a trimmed scalar DAG with s gates, at least s−1 operand slots read internal gates, so U_P+U_Q≤s+1 and Nq≤2s+1+d. No internal route capacity, path disjointness, or charge for an entire shared wire is asserted. The finite graphs depend on selected physical order and actual endpoint witnesses; choices can be optimized jointly before measuring d. This inequality does not bound d by a constant times s. A proof of d≤98s−1 for one globally minimum candidate would suffice.

The criterion concerns proof of payment, separate from discovery: each potential query and point path can be computed by topological traversal on the paired input evaluations. The maximum matching can then be found in the finite explicitly given graph, without tests of equality of arbitrary monotone functions.
