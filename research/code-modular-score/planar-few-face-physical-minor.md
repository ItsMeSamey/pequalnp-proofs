# Bounded physical patches for labels covered by finitely many faces

For fixed q, b≥1 and f, a connected plane patch whose nonzero local labels and ports lie on f supplied simple facial cycles has a connected signature-preserving physical minor of size bounded by a computable function of q,b,f. It is found in polynomial time for fixed parameters. This transports all augmented kernels to any exterior, including nonplanar exteriors, by planar-physical-patch.md.

First perform the simultaneous contractions in planar-face-contraction.md. There are now t≤b+f(2hN+1) distinguished vertices carrying all charges and all ports (h=q+b−1; N is the number of local table states). Give each of them its own permanent index. Any zero labels elsewhere can be forgotten. A partition of these t vertices is realizable if and only if its blocks can each be joined by pairwise vertex-disjoint connected subgraphs. Extend these to a spanning partition by adjacent attachments. Conversely an arbitrary forest may have components with no distinguished vertices; these contribute zero, so retaining only its components containing distinguished vertices gives the same row image. Thus the family of realizable distinguished partitions determines the full augmented table. A particular partition is exactly the rooted minor test for an edgeless graph with a vertex for each block and with each of the t root indices placed at its block vertex.

Now repeatedly simplify loops or parallel edges, contract an edge without merging distinct distinguished vertices, or delete an edge that preserves connectivity, whenever that step preserves the distinguished partition family. Each equivalence check is polynomial at fixed t, by testing finitely many rooted minor models (or through the fixed-terminal disjoint-Steiner-trees algorithm). Each step is physical, with zero unmarked labels and the markings on the surviving vertices unaltered. Track its original edge operations. Any connected minor model respecting all t distinct marked vertices can be obtained by these types of steps: extend its disjoint branch sets to cover all vertices of the connected host, contract their spanning trees, then delete undesired edges. The family of realizable rooted partitions only decreases under such minors. Thus the greedy output is minor-minimal among connected graphs preserving that marked partition family.

For each fixed t, there are finitely many such minor-minimal connected marked graphs across all partition families. Otherwise there is an infinite antichain in one family, contrary to the finite-label graph minor theorem with t distinctly marked vertices. It suffices to use the labelled planar graph version (Graph Minors XIX, https://doi.org/10.1016/j.jctb.2003.08.005 ; alternatively encode each vertex mark by two differently and uniquely labelled pendant edges at that vertex in the published edge-labelled surface theorem; the branch set meeting both retained edges must contain their common original neighbor, and pendant vertices cannot mediate any ordinary adjacencies). The graph minor application concerns ordinary graphs with finitely many distinguished vertices, preserved separately; it makes no claim about group-labelled or binary matroid well-quasi-ordering.

For computability of a size bound, use Theorem 1.3 in Cavallaro et al., Optimal Bounds for the k-Disjoint Paths Problem (https://arxiv.org/abs/2605.14902). The rooted-minor convention on page 15 permits repeated indices in the pattern. Every distinguished partition is an edgeless rooted minor of detail zero. If treewidth exceeds the computable threshold β(t,t,0), the theorem gives a vertex outside the t distinguished vertices whose removal preserves every rooted 0-folio test. Here the bidimensionality of t vertices is at most t. All marked vertices still lie in one component because the one-block partition remains feasible. Retain that component. The resulting connected strict minor has the same partition family, contradicting minimality. Thus the greedy output has bounded treewidth depending computably on t.

On graphs of this bounded width, connectedness, t distinct labels, occurrence of any of the finitely many rooted partitions, and failure of every eligible one-edge simplification to preserve all these tests are MSO2 predicates. For contraction a candidate edge can be required in the relevant connected branch set or, equivalently, evaluate the predicate on the graph interpreted after contracting the distinguished edge. Restrict to simple planar graphs, also MSO2-definable. Bounded-treewidth finite-tree automata decide whether such a minimal graph with more than n vertices exists. Increment n until this language is empty; termination follows from the finite antichain argument. This precomputation shows a computable bound, without being required by the physical greedy algorithm.
