# Recognized branch-width of mixed Walsh predicates

For each of arbitrarily many predicates let a sparse finite list represent f_i(y)=Σ_a c_(i,a)(−1)^(a·y), with coefficients in an odd-characteristic field and common binary message y. We require f_i(y)≠0 simultaneously; fields may differ. Merge duplicates and reject empty lists. Multiplication by a listed character preserves nonvanishing and moves that frequency to zero. Let V_i be the binary span of the translated frequencies. For indexed predicates S, write W_S=Σ_(i∈S)V_i and B_S=W_S∩W_(complement S). All predicates in S only see a linear functional on W_S.

On a binary branch tree of the subspaces, store precisely the linear functionals on B_S extendible to a functional on W_S satisfying S. At a leaf with fixed B_i values, choose a basis complement to B_i inside V_i. Replace each frequency by its complement coordinates and multiply its coefficient by the specified boundary sign. Combine identical keys. The restricted function is nonzero somewhere exactly if the aggregated list is nonempty, since the binary Walsh character table is invertible in odd characteristic. A witness is obtained by repeatedly fixing the next free coordinate on a branch whose restricted list remains nonempty. Constants, singleton-frequency predicates, and zero-dimensional separators are included.

At a join of disjoint L,R with S=L∪R, always W_L∩W_R⊆B_L∩B_R and B_S⊆B_L+B_R. For the latter, if b=l+r∈B_S, then l=b+r∈W_(outside S)+W_R and similarly r∈W_(outside S)+W_L. Enumerate pairs of accepted child boundary functionals agreeing on B_L∩B_R. Their common extension to B_L+B_R determines the parent state. Any witnessed child functionals then agree on W_L∩W_R and define a functional on W_S by addition. Conversely every feasible parent restriction arises this way. Keep a pair of predecessors for each accepted state. Following predecessors from the empty root boundary, recover full leaf functionals, glue on the tree, and solve for a physical y via binary elimination.

For width w there are ≤2^w states per cluster and ≤4^w tested pairs per join. [Jeong, Kim and Oum](https://doi.org/10.1137/19M1285895) construct a width-w tree of the input subspaces in fixed-parameter time or certify that none exists. Thus both recognition and witness-producing decision on explicit spectral lists run in f(w)poly(total input), with no bound on the number of factors or on their individual spans. This is a parameter of a predicate presentation, not of the physical code alone.

For odd primary modular score constraints, form one Walsh indicator per coordinate using the local Lucas expansion in README.md. For maximum cyclic order Q the preprocessing is input^O(Q); the subsequent fixed-parameter complexity in w has an absolute polynomial exponent on those lists, independent of the number of coordinates. A path of predicates supported on span(e_i,e_(i+1)) has a bounded-width interval tree while the sum of all leaf intersection spaces has unbounded dimension. Taking each predicate to be the indicator of both local bits zero gives exactly those spans. All global binary affine equations can first be eliminated. For 2-primary leaves for which sparse Walsh support over an odd field is unavailable, use their unnormalized raw mask span instead; an exact local code oracle with binary pins suffices at the leaf. For fixed maximum 2-primary order, the bounded-exponent algorithm in regular-bounded-two.md supplies this oracle on arbitrary affine binary messages.

Global width is essential for unrestricted numbers of predicates. Local frequency difference-span at most one gives a polynomial algorithm with no width bound: each predicate is constant or it specifies an allowed subset of the two values of a single parity, hence at most one affine linear equation. In contrast, local dimension two is NP-complete even with at most four Walsh terms per predicate over F₃. Reduce from [positive one-in-three satisfiability](https://doi.org/10.1145/800133.804350). For each triple impose its XOR equals one and forbid each of its three pairs from both being one. The former are affine linear equations; solve and substitute them first. The latter are now NAND predicates of two affine parities, each having a Walsh list of length at most four with binary frequency difference-span at most two. All hold exactly for an exact-one assignment. Membership in NP follows by evaluating the input. An independent finite check of the branch-tree join on 200 random small mixed-field instances reproduced both brute-force feasibility and valid witnesses.
