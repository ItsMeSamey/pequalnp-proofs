# Conservative vertex charges, switching minors, and a positive WQO

Fix a finite abelian group Γ. A spanning charged minor of a connected graph partitions every vertex into nonempty connected branch sets and sums its vertex charges in each set. Contract each set, retain required edges between sets, and delete surplus edges. Fixed distinguished vertices must land in their prescribed branch sets. Ordinary graph minors with finite vertex colors do not impose this branch-sum requirement.

For nonzero target plane on the rank-four, zero-total graphic instance the three-vertex edgeless charged target (u,v,u+v) in this spanning model is equivalent to exact named-kernel feasibility: contraction sets give component charges and the rank lemma reduces to three components. Allowing removal only of zero-charge isolated vertices gives the same existence test on connected inputs and nonempty targets. In such a minor recipe the branch sets ultimately discarded have individually zero total; in the original connected graph they can be annexed whole to surviving branch sets, one by one along the connected adjacency quotient, without changing scores or losing target edges. In contrast Oum's graft minor definition (§5) permits removing even an isolated *marked* vertex. A four-coordinate version allowing this deletion forgets charged leftover components. For independent x,y,u,v the seven-vertex path with successive charges y,x,u,v,u+v,x,y has the desired three isolated charged vertices after unconstrained deletions. Every proper nonempty prefix has projection y or x+y modulo span(u,v), so no spanning connected tripartition realizes that plane. Its reorder u,v,y,x,u+v,x,y is YES, has the same rank and total, and is the same underlying tree. All edge-gain assignments on a tree can be switched to zero (even fixing one vertex potential). Thus applying an edge-gain decoration on the same unrooted tree cannot distinguish them.

Geelen and Gerards posed WQO and fixed-target minor recognition for finite abelian *edge*-gain graphs. Huynh's thesis describes the WQO as an announcement; the November 2026 linkage preprint gives deterministic fixed-target testing under edge gains, switching, deletion, and contraction of edges of gain zero. These are different operations from conservatively summing charges of all physical vertices. The statement here does not rule out an auxiliary-gadget reduction or a useful genuine surface dual. It does not assert a general connected charged WQO from any unpublished matroid result.

## Exact positive scope on connected graphs of bounded feedback vertex number

For fixed k and Γ, connected simple Γ-vertex-charged graphs of feedback vertex number ≤k, with any fixed number of distinguished vertices, are well-quasi-ordered by the spanning charged minor relation above. Here is a specialization of Kruskal's labeled-tree theorem and Higman's lemma. Encode each distinguished name by one extra bit present at that one host vertex; group equality guarantees correct eventual placement.

First consider rooted trees. Add to each node's finite label the total charge of its rooted descendant subtree, and any finite local adjacency colors that are to match on the representatives. Use rooted homeomorphic embeddings with exact label matches. These trees are WQO by Kruskal. Restrict to a fixed total charge. For an embedding of a target into a source tree, cut the parent edge of every image of a nonroot target vertex. These cuts produce a connected region for each target vertex containing its representative. Their contracted tree has the required adjacency because the rooted embedding preserves ancestor order and incomparable branches. The charge of each nonroot region is the matched total at its root minus the sums at its target children; for the residual root region use the fixed whole-tree total minus the children's totals. This is precisely the original target charge. Thus all source vertices participate. The target root need not map to the source root.

Now choose and order a feedback vertex set in each graph; pass to a subsequence with the same cardinality ≤k, the same induced apex graph, and the same apex charges (including name bits). If that cardinality is zero use the single-tree argument. Otherwise each component tree of the remaining forest has an edge to an apex by connectedness. Give it an owner chosen among these adjacent apex indices. Root each component arbitrarily. Give each forest node a finite local label recording which ordered apices actually neighbor it, in addition to the descendant sum. Classify the component tree by its owner and total charge. The tree WQO survives this finite product. Pass to an infinite subsequence fixing the aggregate charge, for each owner, of all its component trees. List each forest's component trees in any order. By Higman there is a pair with an injective component matching respecting tree embeddings and both finite attributes. Each matched tree contracts spanning with correct charges, and the representative of every target vertex preserves every required edge to the corresponding apex. Each unmatched tree may be contracted into its own owner apex, using its stipulated edge. For each apex the sum of unmatched tree weights is zero because both the owner aggregate and the matched totals agree. All resulting apex charges and name bits therefore agree. Delete surplus edges to obtain the target graph exactly. Empty forests and apex-only graphs pose no exception.

Fixed-target recognition on these bounded-feedback inputs is separately effective by enumerating a feedback set of size ≤k and using a bounded-treewidth finite-state DP, or by CMSO over finite vertex labels and bounded treewidth. Quantify one connected nonempty branch for each fixed target vertex, partition the entire physical vertex set, and test the requisite edge adjacencies, named vertices and charge sums. This algorithm does not need to enumerate an unknown set of WQO obstructions.

If one permits disconnected inputs and forbids deletion of nonzero isolated vertices, general WQO already fails on edgeless graphs: take two isolated copies each of e2,e3,e4 and 2n isolated copies of e1. Rank four, zero total and named kernel zero hold throughout this antichain. No edge contraction, edge deletion or zero-isolate deletion converts any of these into another. This counterexample has no bearing on whether all connected conservative vertex-charge graphs are WQO.
