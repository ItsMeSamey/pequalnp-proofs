# Physical reduction for large twin classes and finitely many dense names

Fix binary query dimension p, let L be the number of subspaces of F₂^p, and put D=(p+1)^L. In any connected graph, any specified true or false twin class of size greater than P+D(2^p+1), where P is the number of individually protected ports, admits a strict physical reduction preserving the complete named-kernel catalogue and all ports. The output graph can be the induced deletion of nonport members, with the original charges on all remaining vertices.

For each attainable kernel fix one partition witnessing its orthogonal span using at most p+1 connected parts, numbering parts independently. Give each nonport twin its vector of part numbers; there are at most D vectors. In a large class choose a vector occurring more than 2^p+1 times, and reserve one such twin. Among at least 2^p other vertices find a nonempty zero-XOR subset by prefix sums (there are more prefixes than possible group sums). Remove that subset. Each witness part stays connected: a path using a removed vertex can replace its passages through the class by the preserved twin, dropping repetitions. All deleted vertices lie in the same part in each witness; its sum stays fixed. Thus all earlier kernels persist. Conversely this deletion is a physical charge-conservative minor: contract the deleted vertices into one common neighbor of them outside the removed set, then drop surplus edges. True twins can use the reserved twin as receiver. For independent twins, connectedness ensures an outside common neighbor. Every physical partition of the reduced graph lifts to the original via these connected branches; including possible deleted extra edges within components does not interfere because selection is arbitrary. Hence no new kernels arise. Ports keep their identities throughout.

If the graph is given by clique-width or split terms, each fixed-dimension witness partition can be extracted by counting MSO on the terms. Otherwise the statement is an existence reduction, or can use exhaustive search. The p=0 case uses one part and zero-dimensional charge. If physical charges include further independent information, replace 2^p in the prefix step by the size of the entire finite charge group. This result bounds the multiplicity of each fiber of a supplied twin blowup, without requiring all fibers to have equal size.
