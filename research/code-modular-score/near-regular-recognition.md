# Finding a nearby regular reference at bounded host branch-width

Let C be a represented binary linear code, viewed as the cycle space of its binary parity-check matroid, and let w be the branch-width of that matroid. For supplied integers a,b one can decide in f(w,a,b)poly(input) whether there is a regular cycle space R on the same coordinates with dim C−dim(C∩R)≤a and dim R−dim(C∩R)≤b, and if so construct its full binary representation. No candidate reference is required.

Quantify physical subsets P_1,…,P_a and T_1,…,T_b. Form D={z∈C: |z∩P_i|=0 mod 2 for all i} and R=D+span(T_1,…,T_b). The indicated distance bounds follow because D⊂C∩R. Conversely any permissible R admits precisely such a presentation by selecting a basis of the annihilator of C∩R inside C and extending each functional to the ambient space, then selecting generators of R/(C∩R); redundant slots are zero. Thus it suffices to recognize which existential choices make R regular.

The predicate z∈C is definable in counting monadic second order logic: z intersects every cocircuit evenly. Cocircuits are definable from independence, for example as inclusion-minimal sets meeting every basis. Membership in R is likewise a formula: take the finite disjunction over subsets of the b shifts and test that the resulting symmetric difference lies in D. Test the forbidden binary minors F7 and its dual directly. For each of seven ordered distinct survivors and each disjoint contracted set K, delete the other elements. Each of the 128 patterns on the survivors occurs as a minor cycle exactly when a member of R matching it vanishes on the deleted positions, with free values on K. Compare these answers with the fixed Fano or dual Fano cycle table. Their exclusion is equivalent to regularity for a binary matroid.

The finite-field bounded-branch-width model checker for counting monadic logic [including cardinality modulo predicates](https://doi.org/10.1016/j.dam.2011.02.005) applies to the input matroid, using its constructible parse tree. The free-set annotations can be recovered by automaton traceback, or pin their membership bits sequentially on the existing colored leaves and rerun the existential test. Only fixed formulas and a parameter-bounded number of label types are needed for the pins. From the sets reconstruct D and R by Gaussian elimination. The result addresses recognition under a host-width hypothesis and does not imply recognition at unrestricted host width.

## Removing regular appendages of unbounded width

If C=C_good⊕C_bad with C_good regular, puncture any prospective reference to the bad coordinates. Puncturing a regular cycle code is a regular matroid contraction and neither relative codimension increases under a common projection. Conversely the direct sum of a reference on the bad part with C_good retains the same distances.

Suppose more generally C=P⊕₂N is a proper represented 2-sum and P is a regular pendant summand. Recover N as a specified physical minor of C, with the virtual port e relabeled as one physical element. Pick a circuit of P through e, delete all other side elements, and contract all but one real element of that circuit. The side-with-port is reduced to a parallel pair U_(1,2); on its survivor the trace is exactly the e bit. Apply this minor sequence to any prospective regular reference. Common shortening (intersection with a coordinate subspace) and puncturing cannot increase either relative codimension. Thus a regular reference exists on N at no greater budgets. Conversely glue a regular reference S on N's coordinates to P by equalizing their port bits then removing the port. This is the same restriction/projection on P×S and P×N and cannot increase either distance. The result is a regular 2-sum if the port is nondegenerate. If e is a coloop in S its bit is forced zero; the result is a direct sum of deletion minors. If e is a loop its bit is free independently, so the result is a direct sum with P punctured at e. Small disconnected cases use the component containing e and carry the other components along. Thus all distance budgets are preserved exactly. Iterate on a proper decomposition tree. The host-width bound is needed only on the nonregular core left after all such regular pendant pieces are removed. Actual regular references are recovered by reversing the operations.

The fixed proper unary-port gluing is isometric for both directional codimensions on input pairs: the contraction/deletion reduction to the parallel pair is its nonexpansive left inverse on all port codes. A 500-instance random check verified the transports on a triangle circuit branch.

A comparable unrestricted ternary gluing need not preserve candidate regularity. Take a regular side with virtual triangle T and three real edges respectively parallel to its members, in the rank-two triangle matroid. Its cycle rule is that the virtual and real port patterns differ by either 000 or 111. Gluing to arbitrary S therefore gives S+span(111_T), retaining the real copies as named positions. On S=M(K5) use T={01,02,34}. In the reduced incidence matrix the three-column sum is h=e1+e2+e3+e4. Adding this cycle relation quotients the columns by h. The images of the four singleton columns and the six two-element columns now realize all seven nonzero vectors of F₂³, so simplification gives F7. Adding a further physical parallel edge on the regular side, if necessary for side cardinality, preserves the obstruction by deletion. This example addresses a candidate in which T has no promised triangle structure; it does not impeach ordinary regular 3-sums.

For any ground partition S,T write λ_C=dim C−dim C[S]−dim C[T], using subcodes supported in the indicated parts. Under codimension-h restriction the first dimension falls by h and each other by between zero and h, so |λ_C−λ_D|≤h. Via C∩R we obtain |λ_C−λ_R|≤a+b at every cut and the corresponding bound for branch-width. On a positive input promised to have a nearby width-w0 reference the algorithm finds some regular reference within f(w0+a+b,a,b)poly(input) time; the returned reference can have width up to w0+2(a+b).

Small distance alone does not bound the nonregular core width. To a reduced binary incidence matrix of K_(n+1), whose columns are the singletons e_i and pairs e_i+e_j, append h=e1+e2+e3. The seven nonzero vectors on the first three directions give a Fano restriction. The new matroid is a simple single-element extension of the old 3-connected graphic matroid, and is 3-connected: a possible new 2-separation would induce one in the deletion unless h lies on a two-element side; this side would have to be a parallel or series pair. Simplicity excludes the first, and an old element in series with h would become a coloop in the complete-graph deletion. Its width is unbounded because the complete graph is a minor. Yet imposing x_h=0 on the cycle code gives a codimension-one regular subcode consisting of graphic cycles with a coloop appended. Thus budgets (1,0) can occur without any usable width bound on the connected nonregular core.
