# Exponent four counts and an exponent eight counting obstruction

Parameterize a represented affine binary code injectively as x=x0+Lz after eliminating all binary score constraints. For each of the 4^k characters h of Z4^k the scalar phase q(z)−q(0) has polarization 2B over Z4: each parity bit ℓ changes polarization by −2ℓ(v)ℓ(w), with the baseline sign for complemented bits. The symmetric F₂ bilinear form B splits orthogonally by congruence. A nonzero diagonal vector splits a one-dimensional block; if the form is alternating any nonzero cross entry splits a two-dimensional hyperbolic block, leaving radical lines when all entries vanish. The refinement adds across orthogonal blocks. Sum i^q exactly over each block of size two or four, multiply the Gaussian integer sums and restore the constant phase. Inverse character summation times i^(−h·target) divided by 4^k gives an exact nonnegative integer. All intermediate quantities need O(dim z+k+1) bits. This is deterministic 4^k times an absolute polynomial in input length. Pinning physical bits recovers witnesses. See [Guan and Regan](https://arxiv.org/abs/1904.00101) for quadratic Gauss sums.

Even for unweighted simple graphs, exact counting of even supports with cardinality zero modulo eight is #P-complete under polynomial-time Turing reductions. Attach a disjoint cycle of length at least three congruent to −r modulo eight and subtract the count without that cycle to obtain N_r. Hence all evaluations W_G(ζ)=Σ_even ζ^|X| are available at the primitive eighth root ζ. Replace each edge by t parallel copies. The parity-even and odd local sums are E_t=((1+ζ)^t+(1−ζ)^t)/2 and O_t=((1+ζ)^t−(1−ζ)^t)/2. Their ratio O_t/E_t is a fractional linear function of ((1+ζ)/(1−ζ))^t; that base has modulus 1+√2, so none of the denominators vanish and the points are distinct. Each copy can be realized by a private path of length nine, since its forced even-support choices preserve cardinality modulo eight.

From a bipartite graph with n vertices per shore add one hub with a spoke to each vertex. Thicken all original edges with one parameter and spokes with another, divide out the products of E factors, and interpolate the bivariate even-support enumerator using polynomially many degree-plus-one grid evaluations. Its coefficient with n original edges and all 2n spokes counts perfect matchings: each old vertex has positive odd original degree and their degree sum is exactly 2n. The hub parity is automatic. All field computations are exact in the fixed degree-four field Q(ζ). Entries and products have polynomial bit sizes; rational determinant bounds also give polynomial bit sizes for the interpolation coefficients and intermediate fractions using exact linear solving. Graphs have polynomial size, and counting is in #P. This proves a counting obstruction only. For one Z8 target on an arbitrary affine binary code, its indicator is a Boolean polynomial of degree ≤7: Lucas digit polynomials have degrees 1,2,4 in repeated parity coordinates. Explicit multilinear expansion decides its nonemptiness in polynomial time for that fixed modulus.
