# Limit of low-boundary trees with affine or bijunctive leaves

Use a fixed presentation by graph-edge clauses forbidding 11, grouped into leaves in any binary tree. Let w be the largest dimension of the shared normal spans across its cuts. On coordinate factors this counts vertices occurring on both sides. Let each leaf's model set be a union of at most 2^t affine flats. In a leaf of maximum degree Δ, take a maximal induced matching of k edges. Setting every other variable to zero leaves 3^k choices. Each restricted affine flat has projections of size at most two on each edge, because a two-dimensional affine projection would include 11. Consequently 2^t≥(3/2)^k. The closed neighborhoods of the matched endpoints cover all leaf edges and have ≤2Δk vertices. Thus the leaf graph has a vertex cover C of size ≤2Δt/log₂(3/2). For the narrower syntactic rule that a t-dimensional conditioning subspace meets every edge plane, its echelon pivots already give a cover of size ≤t.

Construct a tree decomposition of the original graph: each internal node holds the union of the boundaries of its incident tree edges, size ≤3w. At a leaf with parent boundary B attach a bag B∪C, and for each other vertex v attach B∪C∪{v}. These bags cover edges, and the boundaries connect all occurrences of each vertex along its Steiner subtree. Therefore graph treewidth is at most max(3w−1,w+max|C|). This proves the linear tradeoff for bounded-degree expanders under every grouping, without appealing to a particular balanced cut. Equivalently if every leaf has sublinear mass then a balanced tree edge exists, but invoking this observation is unnecessary. A global invertible affine change of seed coordinates preserves row-space dimensions and transports affine covers. Graph-edge clauses are themselves 2-CNF; this lower bound concerns certification by affine leaves, not their SAT decision.

### Strict ternary controls admitting native-coordinate 2-SAT leaves

Let G be a simple connected cubic graph of linear treewidth, e.g. a cubic expander. For each edge e use nine variables x(e,i) indexed modulo nine. At a vertex with three ordered incident edges a,b,c, use all 81 triples (x(a,i),x(b,j),x(c,i+j)). Two different triples share at most one variable, each variable occurs in exactly 18 core triples, and the whole core has six times as many clauses as variables. Its primal graph contains the line graph of G on the zero-index layer. G is a minor of its line graph: orient a spanning unicyclic subgraph with each vertex owning an edge directed into it, assign every remaining edge to an endpoint, and use each vertex's clique of owned edges as a disjoint branch set. Every original adjacency is represented.

For the satisfiable control use all-negative core clauses. At every core variable x attach six private variables, using x as local index 0. Gadget triples are 012,034,056,135,146,236,245; their sets of negatively signed variables in that order are 01,4,6,5,1,23,24. Setting all six private variables to zero satisfies every gadget regardless of x. Every variable now has both signs. Direct evaluation of the 128 assignments gives 42 models (18 at x=0 and 24 at x=1), full six-dimensional private affine hull at x=0, and no renaming of variables under which every gadget clause is Horn. No variable is shared by all scopes. The construction remains linear and connected. There are no unit/binary clauses, pure literals, blocked clauses or equal-scope pairs. Indeed, for each literal there is an opposite occurrence on a different clause with no second shared variable, so the resolvent cannot be tautological. Each clause's seven-point relation has full affine hull and every two-coordinate projection is full, hence that relation is neither an affine equation nor expressible by its binary projections. The displayed rank-three input planes are coordinate spaces whose pair-wedge supports are disjoint, so the existing shared-wedge rank-three lift uses at least one auxiliary per clause. Native projective-layer recognition requires rank at most two on input. These observations concern the specified local preprocessing rules.

For any macro leaf let m_i be its number of core triples. The intersection graph of its core triples has degree at most 51. Greedily select k≥m_i/(1+51²) triples at mutual intersection-graph distance at least three. Unselected triples meet each selected triple in at most one vertex by linearity, and meet at most one selected triple by separation. Set all private variables and all other core variables to zero. Every attachment is satisfied and only the k selected core clauses remain active. There are 7^k surviving patterns. An affine flat contained in this family projects on each triple to at most four points. A bijunctive (ordinary-coordinate 2-CNF) relation is closed under coordinatewise majority, as are its restrictions and coordinate projections, including projecting auxiliary Boolean 2-SAT variables. Each triple projection therefore has at most six points: the only seven-point possibility omits 111, while the majority of 110,101,011 is 111. Each component of a union of affine or bijunctive model sets thus covers at most 6^k points. A cover with 2^t_i components requires t_i≥k log₂(7/6). The count applies even to overlapping covers. The 2-CNF statement fixes the physical coordinates; an arbitrary linear projection of a bijunctive relation need not remain bijunctive.

For a decomposition of all augmented factors of outer width w, build internal bags of the three core-vertex cut boundaries (each ≤w) and leaf bags containing every core vertex of that leaf's core triples (size ≤3m_i). Core occurrences satisfy running intersection by the same subtree argument. Hence the core primal treewidth is at most max(3w−1,3 max m_i−1). The expander minor forces max(w,max t_i)=Ω(|V(G)|). In particular unrestricted choice of macro grouping alone does not provide polylogarithmic certificates of these kinds on the displayed satisfiable inputs. The formula admits other easy decision methods, including recognizing and eliminating the indicated attachment assignment; this is not an unrestricted algorithm lower bound.

For an UNSAT partner keep *all* scopes including the same gadgets. Choose the sign pattern of each core triple independently uniformly among its eight forbidden words. The expected number of core solutions is 2^N(7/8)^(6N)<1, where N is its number of variables. Therefore an unsatisfiable signing exists; a deterministic but inefficient description chooses the first such signing. This is an existence control, not a supplied efficient generator or a computational refutation. The syntactic strict-width, unique-scope, no-purity, no blocked clause and wedge-cost claims still hold. No affine-cover lower bound can hold on the UNSAT model set when arbitrary leaf grouping is allowed: the entire empty relation has a constant contradictory 2-CNF or empty affine cover. Distinguish this information-theoretic fact from the algorithmic cost of verifying emptiness.
