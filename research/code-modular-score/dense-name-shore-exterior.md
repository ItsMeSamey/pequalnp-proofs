## New compositions with dense named columns

Fix an explicitly represented binary ordinary shore A, an exterior E and named matrix T. Put V=span(E,T) and W=span(A)∩V. For an exterior choice X and shore choice Y write J=span(Y)∩W. The vectors in span(X,Y)∩V are exactly span(X)+J. Indeed, both the sum and the exterior summand lie in V, forcing the shore summand into W. Using only span(E) to define the interface fails on the two-edge path with independent edges e₁,e₂, sole name e₁+e₂, and shore containing only e₁. The actual interface is the line of e₁ although the intersection of the ordinary edge spans is zero.

1. **Bounded-deficit graphic exterior with arbitrary binary shore.** For dim W≤3, compute every shore trace and its contraction witness by the existing three-dimensional solver. Append a basis of W as extra named columns on the *ordinary exterior*, without introducing virtual ordinary gadgets. Enumerate its exact kernels N on the enlarged named list by graphic deficit recognition followed by named-kernel dual routing. For each J produce the full kernel {x : (x,j) lies in N for some j in J}, with j in basis coordinates. Both witnesses use original ordinary columns. The runtime is polynomial for fixed named count and fixed exterior deficit. The graph and an incidence-coordinate identification must be supplied, or the latter must be recovered and checked by linear algebra. Extend the isomorphism from the ordinary span to V using additional zero incidence rows from isolated vertices if necessary. The branch handles names of arbitrary support. A hundred random exhaustive comparisons with seed 431 matched the entire directly enumerated kernel families.
2. **Four named dimensions with attachments inside the named space.** For a requested two-dimensional coefficient kernel K, require T injective with image in span(E), and W≤im T of dimension at most three. For each attainable J, reject the branch if J is outside the required physical trace T(K), meaning J is not a subspace of T(K). For J nonzero, quotient E and im T by J and solve for trace T(K)/J using the dimension-at-most-three algorithm. For J zero, call the deterministic six-plane method on the original exterior. Its small-spectrum promise is imposed only on E. With names and exterior both the four coordinate vectors, exactly six planes occur. Adding the shore vector e₁+e₂ gives exactly eight planes by enumeration. A single rank-two shore with columns e₁+e₂ and e₃+e₄ gives exactly eleven, since each plane is the span of a pair of its six physical points. This verifies the scope extension and does not assert hardness outside the earlier promise.

Multiple shores admit this treatment if their private spans form a direct sum modulo V. In the first construction their combined boundary span must stay bounded. Accumulate their attainable J values by subspace sums with backpointers. Pairwise disjoint private spans alone do not imply their direct sum. These two deductions were cross-checked against the underlying algebra and sent to the relevant leads. Searching for arbitrary qualifying decompositions remains a separate obligation.

### Removing the exterior promise on target-compatible attachments

Let S=im T, dim S=4, and let H=T(K) be the desired plane. Take any family of named-space attachments as above. If their aggregate spectrum contains a nonzero J₀⊆H, it suffices to test the nonzero aggregate states J⊆H. Indeed, if an original solution uses a zero shore trace, its exterior choice X already has physical trace H. Replace all shore choices by any choices attaining J₀. Since J₀⊆H⊆span(X), the union retains trace H. Every positive solution formerly using a nonzero J is already tested. Thus on this checkable class the exterior needs *no* small-plane-spectrum promise. If H has an ordinary exterior component outside the ordinary span in the quotient, the three-dimensional trace solver still applies: test exact trace of the specified subspace against the projected columns directly. The injectivity and exterior spanning hypotheses are needed for the cited four-root filter in the zero-only case, not for a nonzero branch.

There is a canonical way to find applicable attachments. Represent ordinary columns modulo S and form the connected components of that represented matroid, counting each loop as its own component. A basis and its fundamental circuits give these components in polynomial time. For each component C compute W_C=span(C)∩S. Quotient spans of distinct components form a direct sum, so cancellation of private coordinates occurs inside each component separately. Include every C with dim W_C≤3 as a cheap attachment. Compute all its local traces and original choices using the at-most-three-space solver. Aggregate by subspace-sum DP over the 67 subspaces of binary four-space. The other components form the unrestricted exterior. If every component was included, the DP alone gives the complete spectrum. If any full-rank component remains, its span contains S, so the spanning hypothesis for the small-spectrum exterior fallback holds automatically. Construct witnesses by concatenating original columns found by the local oracles and the original column labels returned by the quotient oracle. The fallback need only be invoked if H admits no nonzero aggregate trace. The direct-sum decomposition of quotient matroids is standard; the composition uses it specifically for exact four-dimensional named trace targets.
