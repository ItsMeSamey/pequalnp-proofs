# Physical catalogue representatives for finite flips of bounded-treewidth graphs

Fix w, a symmetric Boolean template F on a finite alphabet, finite abelian charges, protected ports and a finite family of vertex-set CMSO queries including connectedness and the complete binary named-kernel catalogue. Suppose a connected G is supplied in the form G(x,y)=H(x,y) XOR F(type(x),type(y)) for distinct vertices, with a width-w tree decomposition of H. Then G has a computably bounded physical conservative spanning minor G' with the same query answers, presented by the same template over an ordinary minor H' of H. The two minor models are distinct. In particular this handles a complement of a path, whose displayed path layout has cut-rank ≤2 and transverse rank one across internal vertices. The displayed virtual path edges are absent from that graph.

Use the marker/sunflower chain from bounded-treewidth-additive-catalogue.md (SHA be0ff664287ff5acb5025674a911e554d22f5db696d30885c42b4e6e103b8350) and the Menger recursion from rank-two-real-separator-pumping.md (SHA 512840b237bb4131418e88084f371158e66b3ef721cf7e7cfa9dc0f8ba0e0eba), with two modifications below. All cuts and path searches for that recursion are in H−X; its paths initially certify only sparse-layer connectivity.

**Bounded permanent receivers.** For each type u take min(w+1, number of u vertices) physical representatives into X. For any type with w+1 representatives, add all common H-neighbors of these representatives outside them to X. There are at most w such vertices: w+1 common external neighbors would give K_{w+1,w+1} in H. Add the bounded sunflower core as usual (choose spacing and chain thresholds for the enlarged bound). For any vertex x outside X with a physical background edge to a vertex of type u, x has such an edge to some permanent u-representative. Here a physical background edge means F=1 and H=0. If all occurrences were taken the claim is direct; otherwise x is not a common H-neighbor and F depends only on types. All remaining non-background physical edges belong to H. This makes it possible to absorb unseeded components after genuine physical lane paths have been obtained.

**Restoring physically connected lanes.** In a chunk with separators of size ≤k and k disjoint H−X paths through its end separators, label the paths once. They meet each intervening separator in one vertex in order. Colour every pair of distinct cut indices i<j by the tuple of type sets appearing on each of the k path segments between those cuts inclusive. Finite Ramsey gives, from a sufficiently large chunk, as many ordered cuts as desired whose pairs all have the same colour. In particular each elementary interval between successive chosen cuts has, on each specific path, the same alphabet as all the other elementary intervals on that path. Use groups of 30 consecutive elementary intervals as the pumping tiles, sharing their common endpoint cut. On a given path within a group, every original H-edge that remains physical is usable directly. For an H-edge xy on this path missing from G, put t=type(x),u=type(y), so F(t,u)=1. Its endpoints lie inside one elementary interval, allowing shared boundary vertices. Choose two other elementary intervals in the group, each separated from that interval and from one another by at least two full intervening intervals. Select a type-u vertex y' on the first and a type-t vertex x' on the second, on the same path. The homogeneous alphabets guarantee both. Each of the ordered pairs (x,y'), (y',x'), (x',y) is separated by an intermediate H−X separator containing neither endpoint. Hence none is an H-edge, each is a physical template edge, and the H-edge xy is bypassed within this path's own vertex set. The initial path segment induces a connected subgraph of G even when every H-edge on it was virtual. Different paths keep disjoint vertex sets. This argument also works for t=u. For k=0 no path restoration or Ramsey selection is needed.

Each group slab now has k genuinely connected, disjoint receiver paths (meaning connected sets on the original H-path vertices), and the vertices X as additional permanent seeds. Grow disjoint branches to include every unassigned slab vertex using actual G edges; a component failing to reach any seed in the induced graph on the closed slab and X would, by connectedness of G, have a physical edge to the exterior. An H-edge exiting the slab meets a seeded separator or X. A non-H physical edge gives an actual permanent receiver by the previous paragraph. Thus no component fails. Charge each vertex newly assigned in this slab only once, excluding incoming anchors and X. Whole-group assignments compose since adjacent slabs overlap only on the k named anchors and X. As in the separator lemma, compare the cumulative (k+|X|)-vector and the CMSO type of the prefix of H with its ordered named roots and X, charge labels and template types. Equal tags permit a contraction preserving individual receiver charges; enough Ramsey-homogeneous consecutive groups give the repetition. If a candidate Menger chunk lacks k disjoint sparse-layer paths, its smaller separator and the lower-order recursion apply exactly as before, with the enlarged linked-chunk threshold. Progress guarantees a strict physical size decrease.

For clarity on output edges, form H' by gluing the sparse left and right sides along the identified separators and X, and define G' as H' XOR F on distinct vertices. For two surviving private vertices on opposite sides, both before and after splicing the H-edge is absent, so any required template edge is directly physical. For pairs lying in a retained side, away from the shared boundary, the required edge is witnessed in that original side, using the right endpoint of a matched lane when appropriate. For a pair of boundary vertices H' uses the union of incidences from the two retained sides. If F=0, a positive edge needs a witness in only one side. If F=1 and the output edge is required, then both retained H sides lack it, so the corresponding physical template edge exists. Equal rooted types ensure matching template colours. Extra physical quotient edges are freely deleted. H' independently has an ordinary H-minor model by keeping the original disjoint H-path segments for identifications and deleting unused middle vertices; virtual edges are used only in this separate certificate. Vertex-set CMSO types compose under gluing, and XOR with F is a quantifier-free interpretation. This proves preservation of all specified queries and protected ports. The smaller presentation has the same treewidth bound, so the marker-chain argument can be iterated, giving the asserted computable size bound and constructive polynomial-time reduction at fixed parameters on the supplied representation. This result imposes a bounded-treewidth flip presentation; it does not establish a kernel for all rank-width-two graphs.
