# Split-tree embeddings and uniform twin expansions

A conservative spanning minor assigns every source vertex to a nonempty connected branch set of a target vertex. Each branch set has the prescribed total charge in a fixed finite abelian group. Each target edge needs a physical edge between its branch sets. A representative in each branch set can be required to carry the target's finite label. Each fixed distinguished vertex can be tracked by a separate binary charge coordinate.

## Two limitations of split-tree embeddings

In a clique–star split tree, the physical vertices are the leaves. Two leaves are adjacent if the path between them traverses adjacent markers at every internal node. At a star, the path can pass between a center and an arm. An arm-to-arm passage blocks accessibility. See [Gioan and Paul, Split decomposition and graph-labelled trees](https://arxiv.org/abs/0810.1823).

Consider a target whose split tree consists of two stars A and B joined center-to-center, with three physical leaves on each star's arms. It represents the complete bipartite graph K₃,₃. In the source split tree replace that central edge by the path A–C₁–S–C₂–B. Keep A's and B's center markers facing this path. Each Cᵢ is a three-marker clique with one extra physical leaf, respectively p and q. The center of the three-marker star S faces its extra physical leaf x, so both incidences along the path are arms. The representation is reduced since consecutive internal nodes have different types. Give all physical vertices charge zero.

The target tree embeds topologically into this source tree, preserving local types, the first and last marker on the path that replaces every edge, and every subtree charge. Yet the target graph is not an ordinary minor of the source. On the A side the represented source graph consists of the edge xp and three independent vertices each adjacent to both x and p. The B side has the same description with q. These two graphs meet only at x. Bags consisting of x, p, and one A-side leaf give a width-two decomposition of the first graph, and the corresponding bags for the second graph can be joined along x. The target has treewidth at least three: it has a K₄ minor obtained by pairing two disjoint opposite-shore pairs and retaining the two remaining singleton vertices. Treewidth is minor-monotone. Thus checking marker orientations only at the ends of routed split edges loses essential interior information even under zero charges.

At the other extreme, suppose all matched nodes preserve their incident marker types on the relevant edges and every routed target edge avoids blocked passages at skipped source nodes. For each pair of matched physical leaves, a blocked passage exists on its source path exactly when one exists on its target path. The represented target therefore embeds as an induced subgraph on the matched leaves. This condition cannot give a WQO proof for all finitely labelled distance-hereditary graphs: paths with their two endpoints individually labelled and other vertices unlabelled form an induced antichain. An induced connected subgraph containing both endpoints of a path is the whole path. This is an obstruction to the proposed embedding criterion. It leaves conservative minor comparability open.

## Uniform twin expansions

Suppose a connected graph class is WQO by conservative spanning minors for every fixed finite abelian charge group and every finite alphabet of representative labels. Fix a positive integer k. Replace each base vertex by a fiber of exactly k vertices which is either a clique or an independent set. Replace each base edge by every edge between the corresponding fibers, and add no edges between fibers of nonadjacent base vertices. The resulting class is again WQO by conservative spanning minors with the same charge and representative requirements.

Choose an ordering in each source and target fiber. Charge each base vertex by the ordered k-tuple of its physical charges in the product group. Label it with the fiber type and the ordered tuple of representative labels. In an infinite sequence of such graphs, the base hypothesis gives a forward conservative embedding respecting these labels. For each target base vertex v, let Bᵥ be its connected base branch set. The branch set for its ith clone takes clone i of every vertex in Bᵥ. The k sets cover that fiber expansion of Bᵥ disjointly. Each is connected, since adjacent base vertices supply every cross-fiber edge. The tuple charge identity gives the required sum on each set. A physical edge realizing a target base edge supplies all k² clone pairs across its two branch sets. Within a target clique fiber, the base representative has a clique fiber and supplies all needed edges and all clone representatives. Within an independent fiber no internal target edges are required. This also proves the assertion with distinguished ports encoded in separate charge coordinates. A singleton base with an independent fiber gives a disconnected expansion when k>1; it can be omitted when restricting to connected graphs.

The block-graph conservative WQO therefore supplies this result for fixed uniform twin expansions of connected block graphs. Such expansions with connected output are distance-hereditary: block graphs are distance-hereditary, and the expansion can be built by successive true- or false-twin additions. The proof requires a common fixed k in each fiber. It does not decide the conservative WQO question for all distance-hereditary graphs.
