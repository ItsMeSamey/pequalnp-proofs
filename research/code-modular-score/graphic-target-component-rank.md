# Component count for dense graphic named columns

On a connected graphic host with full incidence matrix A and vertex rows of B, the sum s_i of B-rows over each component of contracted edges is a row of the resulting named representation: an ordinary boundary vector is in the span of these incidence columns exactly when its parity is zero on every component. Consequently the rows s_i span the orthogonal complement of the named kernel K.

Every attainable K has a contraction forest whose connected partition has at most 1+dim K⊥ parts, with no sparsity restriction on B. From a feasible contraction set keep a forest joining each part. Merge adjacent parts whenever replacing their rows s_i,s_j by s_i+s_j preserves the row span. When a merge would strictly reduce that span, a linear functional separates s_i from the span of all other rows and s_i+s_j. It takes value one on both i and j and zero elsewhere. In a minimal partition the evaluation code thus contains the edge-incidence vectors of every adjacency of the connected quotient graph. Its dimension is dim K⊥, whereas the edge vectors of a quotient spanning tree are independent and number one less than the number of parts. Every successful kernel can therefore be witnessed by a spanning tree with at most dim K⊥ distinguished edges omitted. This is a structural reduction; choosing the spanning tree subject to the component score tests is a separate problem.
