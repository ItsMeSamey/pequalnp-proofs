# A physical catalogue kernel on bounded-treewidth graphs with additive dense edges

Let G be connected and supplied as H together with all edges of a fixed symmetric template on finitely many unary vertex types. H has bounded treewidth w and is an actual subgraph of G. At fixed w, template, finite abelian conserved group, protected port count and finite family of vertex-set CMSO queries (including the binary named-kernel catalogue and connectedness), there is a computable uniform bound on the size of a same-query conservative spanning minor. The algorithm supplies its physical branches, and the smaller graph again has a presentation over an ordinary minor of H with the same template. In particular H=G gives this finite physical kernel for arbitrary bounded-treewidth connected graphs. This does not establish a conservative WQO.

The hypothesis needed only finitely many spaced cuts, with all constants computable from the fixed parameters, so a uniform computable terminal size follows.
