# Parameterized hardness for odd scores on unrestricted represented binary codes

Prescribed unsigned score feasibility on an arbitrary binary linear code is W[1]-hard when parameterized by group order, even for a single odd cyclic prime-power score. Reduce from k-Clique on an n-vertex graph. Encode k ordered candidate vertices by binary blocks of b=ceil(log2 n) independent message bits. Use k unary violation predicates for invalid IDs and one binary predicate for each pair of positions for a nonedge, including an equal pair. Their integer sum lies in [0,t] with t=k+binom(k,2), and vanishes exactly for an ordering of a k-clique.

Choose q to be the smallest power of three exceeding t. Then q≤3(t+1). For any one predicate F on h≤2b bits, compute its Walsh expansion over Z/q. Its character transform is invertible since 2^h is a unit there. Write each character as 1−2 times its parity bit. We obtain a constant plus at most 2^h=O(n²) weighted binary parity forms whose sum is equal to F modulo q at every message. Sum these lists across predicates, encode every listed parity form as a coordinate of a represented binary linear code, and set the requested score to the negative of the accumulated constant. Optional zero-weight identity coordinates make messages distinct. The score condition is exactly zero total violation modulo q, equivalent to zero integer violation count. The construction has f(k)poly(n) bit complexity and target group order O(k²). This proves the parameterized reduction. A variant with one F₃ coordinate per predicate uses a fixed exponent of three and group order 3^t, still bounded in the parameter. In either presentation the hardness does not apply to a single fixed group; deterministic n^O(t) or n^O(q) algorithms remain consistent.

Exhaustive local Walsh and full score checks on (n,k,q)=(3,2,9),(5,3,9),(6,4,27) agreed with the candidate-order counts, including invalid padded IDs and repeated vertices. The construction uses arbitrary represented binary codes. It does not furnish a graphic or regular code reduction.

Parameterized Clique is W[1]-complete by [Downey and Fellows, Corollary 3.2](https://homepages.ecs.vuw.ac.nz/~downey/publications/2.pdf). For the unweighted scalar version, replace each coordinate of residue weight w∈{0,…,q−1} by w equal physical code coordinates. This preserves all scores and costs a factor at most q in length; zero-weight coordinates may instead be omitted when only existence matters.

Choosing a prime t<p≤2t (for t>1) instead gives a single prime modulus of order O(k²). If codeword counting is desired, q equal copies of each message identity coordinate restore injectivity even with unit weights and contribute zero modulo q. The number of target codewords in this construction is exactly k! times the number of k-cliques.
