# Exact named kernels with a supplied graphical cycle supercode

Let A and B be ordinary and named columns in a common binary vector space V. The p named columns have a prescribed kernel K after contracting any physical set X and deleting its complement Y. Suppose a graph H indexed by the physical columns satisfies C=row(A) contained in Z(H), with codimension γ. Elimination checks this condition. H can be disconnected or have loops and parallel edges. A need not be an incidence representation.

Put U=Bᵀ ann(im A). Reject unless U is contained in K⊥. A linear map L:C→F₂^p/U sends Aᵀf to the class of Bᵀf; any two lifts differ by ann(im A). For C_Y consisting of the words of C supported on Y, the row space of the resulting named minor modulo U is L(C_Y), since its row functionals lift exactly to f annihilating A_X. Thus the target is L(C_Y)=K⊥/U of dimension d.

Among all successful Y choose one inclusion-minimal. If nonzero c in C_Y has Lc=0, choose e with c_e=1. Every available score has a representative zero on e by adding c when needed, contradicting minimality. Thus dim C_Y=d. Every edge of Y occurs in a word of C_Y, since any unused edge could be discarded, so H[Y] is a union of cycles. Its cycle rank is at most d+γ since Z(H[Y]) maps into Z(H)/C with kernel C_Y. This holds for d=0, where Y empty suffices.

Construct γ edge labels Q by extending the quotient map on Z(H) linearly to the full edge space. Extend L arbitrarily from C to edge chains. On any support Y calculate the span of L-sums on combinations of cycles having Q-sum zero. Enumerate bridgeless cores of cycle rank at most d+γ, including isolated cycles and omitting isolated vertices. Suppression bounds the remaining vertices and slots by O(d+γ) using degree excess. Subdivide every pattern slot and every host edge into three links to make simple graphs; place each old host label on just one link. Enumerate all joint labels (Q,L) on the pattern links, testing the required exact span by elimination. Test for a subdivision with these link labels by applying Liu–Yoo Corollary 1.4, with singleton accepted sets in a fixed finite binary group. Any model has minimum degree two, so a used subdivided host edge is used in full. Its physical edges give Y and its complement gives X; verify by elimination. Conversely the bounded witness supplies an enumerated core with some labeling. An alternative implementation guesses pattern-vertex placements and uses the endpoint-cloned fixed-terminal routing from the independently reviewed graphic-target-dual-routing.md. This gives deterministic polynomial time at fixed p,γ with either implementation. H and its physical edge bijection are supplied certificates. This contains the cellular dual argument for graphic A and ordinary cographic row spaces (γ=0), and also works for arbitrary represented A satisfying this inclusion. Finding an unknown graph H is a separate problem.
