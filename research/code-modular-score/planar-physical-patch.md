# Dense planar patch replacement by a bounded physical minor

A connected plane patch meets an arbitrary exterior only at b≥1 distinct vertices s0,...,s(b−1). Assign the labels at shared vertices to one side only. Split each of q globally even demands into its local restrictions and add its local parity at s0 on each side. The two resulting demands are even and sum to the original. Append the b−1 transfers e(si)+e(s0) to both lists, giving h=q+b−1 coefficients. For a patch choice F let K(F) contain (x,t) exactly if its augmented demand is spanned by F. Define the exterior table the same way. The global kernel for two choices is the set of x such that some (x,t) lies in both kernels: cancellation between two local representations is supported on the ports and even, hence belongs to the transfer basis. Full patch table equality suffices for every exterior.

Use the planar dual routing procedure of graphic-target-dual-routing.md to compute the table. T-joins for the h local demands give h-bit edge gains on the plane dual D. For any F the orthogonal of K(F) is the gain image of the dual cycles supported off F, by incidence duality. This handles dependent names and all exact kernels.

For fixed h,k one can recognize and extract a connected physical minor preserving the entire table with dual cycle rank at most k. Enumerate all bridgeless multigraph cores of cycle rank ≤k, with no degree-two vertices except a single anchor on a cycle component. They have O(k) edges and vertices by handshaking. Enumerate all h-bit gain assignments, including the empty core. Retain the candidates whose supported cycle-image table equals the patch's. Test each for a gain-preserving subdivision in D. Guess distinct branch images and distinct incident physical stubs. Treat direct edges or loops and empty residuals explicitly, subdividing input edges at private zero-gain stubs if needed (split gains to sum to the original). For the remaining disjoint paths exclude the other branch images and subtract the chosen stub gains. This uses fixed-size terminal enumeration and the abelian labelled linkage algorithm (https://people.tamu.edu/~yyoo/stoc25.pdf). A loop on an anchored cycle can equally be guessed by fixing one edge and searching for the remaining path avoiding it.

Delete dual edges outside the subdivision, then contract a forest to suppress its chains. Switch along this forest to make forest gains zero, transferring the original path sum to each surviving edge. These are physical primal contractions followed by deletions. The latter correspond to an independent dual forest and preserve primal connectivity. A merged pair of ports would make a nonzero pure transfer vanish for every local choice. But the original empty choice realizes the ordinary nullspace of the whole naming matrix, excluding this port-pair vector. Full table equality thus precludes a port merger. Retain branch-tree and physical contraction records for traceback.

Conversely, lift one signature-preserving bounded-rank dual minor by using its surviving edges and a connecting tree inside each contracted branch set. Contracting these disjoint trees restores the minor, so this joint carrier has cycle rank at most k. Its supported images lie between the original and minor tables, hence are exactly the original ones. Trim bridges and suppress degree-two paths to obtain one of the tested subdivisions. No bound on the rank of a union of independently chosen witnesses is used.

A sufficient certificate is a collection of mutually vertex-disjoint dual cycles, one for each nonzero gain in the full dual cycle-space image. Their union attains every subspace of that image by selecting basis cycles, and therefore preserves the entire signature. After suppression it has one dual loop per cycle. A universal bound k for all large walls is open.
