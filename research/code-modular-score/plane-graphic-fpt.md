# Unrestricted odd prime plane on graphic cycles

For arbitrary unsigned scores in F_p² on graph edges with p odd, the proposed deterministic FPT decision proceeds as follows. Test each scalar projection for a bounded edge modulator killing its scores using quiet-recognition.md. If one is found, use quiet-ports.md with that quiet coordinate and any complementary active coordinate. The latter is scalar F_p and accepts additional elementary binary markers. The two factors need not be coprime in this branch.

Otherwise the edge form of odd-group nonzero-cycle Erdős–Pósa supplies arbitrarily large parameter-sized edge-disjoint families of scalar-nonzero simple cycles for every nonzero scalar (set the tested bound as a function of the required packing size). Pigeonhole one packing to obtain edge-disjoint row cycles all of full gain a≠0. Choose an independent gain b among a packing for a scalar annihilating a, obtaining edge-disjoint column cycles of gain b. Finite bipartite Ramsey yields arbitrarily many rows and columns with a common F_p² gain c on each pair's common edge set. If c=0, each XOR of row and column choices simply adds their gains and fills the plane. Otherwise interchange roles so c is outside the span of b. Let χ annihilate b but not c.

Suppose some target is absent. The universal-collinearity result in grid-active-rank.md retains at least four column cycles J whose increments are pairwise collinear at every binary cycle baseline; retain at least three rows. At a given baseline all but O_p(1) column increments must lie on one line as sufficient multiplicities in two independent directions would fill the plane by disjointness. Every pair ever noncollinear is so on an ε(p) fraction of all baselines, by the F_p⁴ joint signed-increment score and the proper-binary-class fiber-density theorem. Double counting bounds the number of potentially noncollinear pairs linearly; an independent subset of any desired parameter-only size follows.

For a fixed j∈J put η_j equal to the scalar χ-weight on the edges of C_j and zero elsewhere. Whenever a baseline avoids another C_k, its k increment is b, so its j increment is in the line of b. The χ-value of this increment is minus twice η_j of the baseline, hence η_j vanishes on all even supports of G−E(C_k). Each row, however, has η_j=χ(c)≠0.

Construct a bipartite incidence graph Y with one ordinary vertex per connected component after deleting all column edges in J, and one hub for each column, adjacent to every ordinary vertex touched by that connected cycle. Removing hubs models exactly the component partition on original vertices after removing those column edge sets. For any two distinct hubs k,l the corresponding cographic evaluation spans D_k,D_l intersect nontrivially: if disjoint, a linear baseline could copy a row's evaluations on k and zero on l, giving noncollinear increments b−2c and b. The intersection dimension equals c(G−C_k−C_l)−c(G−C_k)−c(G−C_l)+c(G) by dual rank, with edge deletion and all isolated vertices counted. It is the same difference for hub deletion in Y. Two nonadjacent nodes in different biconnected blocks of Y have additive component splits under their deletion, giving zero (by the block-cut forest). Thus hubs k,l belong to a common nontrivial block, so no other vertex separates them. For fixed j all remaining hubs lie in one component D of Y−j.

Form G_j on the edges of C_j by contracting each connected component of G−C_j to one vertex. An edge subset on C_j extends to an even support in G iff it is even in G_j, by pairing its boundary inside each contracted component. Each row's restricted edges therefore contain an η_j-nonzero simple cycle L_i of G_j, by decomposition; the L_i are edge-disjoint across rows. Each L_i must visit vertex D since other hubs all belong to D and deletion of any one must prevent an even extension. Its two half-edges at D have ordinary endpoints s_i,t_i in the incidence graph D, with two ends also for a loop. For each other k∈J these endpoints must be separated by hub deletion D−k: otherwise the L_i remains even on the refined component graph, and so would extend avoiding k despite its nonzero score.

All the other hubs thus occur as separating articulation nodes on the path between s_i,t_i in the block-cut tree of D for EVERY i. Pick one k strictly between two flanking hubs, using the endpoint path of the first row. Every endpoint path includes these flanking hubs, so all pairs s_i,t_i lie one on each of the SAME two components of D−k. On the refined component graph, every L_i has the same two boundary defects. Any pair XOR consequently lifts avoiding k, and its η_j score is zero. Because the L_i are edge-disjoint this says their nonzero scores are pairwise opposite, impossible for three elements of an odd-order group. This proves all-high saturation. Exact decision gives witnesses by greedy physical edge deletion, adding only a fixed polynomial exponent.

All Ramsey sizes, Erdős–Pósa bounds and density thresholds depend only on p; they are needed for the branch threshold rather than as constructive packing or subfamily subroutines. This argument does not by itself assert the corresponding higher-rank result or allow additional constraints.
