# Maximum cycle packings can require unbounded replacement

Take m rings of g disjoint triangles, joining consecutive triangles by an edge at distinct incoming and outgoing ports. Mark one internal edge per triangle by e1 and one external edge per ring by e2, all other edges zero. Named triangles have signed increments ±e1 at every baseline and leave a matching after removal. Any other simple cycle traverses an entire ring, displacing g triangles. Choose paths avoiding the internal e1 edge at each triangle to obtain m disjoint cycles of gain e2. At most one edge-disjoint cycle can use each triangle, proving maximum cardinality. The number g of displaced named cycles is unbounded.

For simple cubic 3-connected hosts start with a sufficiently large simple 3-connected cubic base of girth ≥g. Existence follows from Wormald's results on [short cycles](https://www.sciencedirect.com/science/article/pii/S0095895681800226) and [connectivity](https://www.sciencedirect.com/science/article/pii/S0095895681800214). In an n-vertex cubic graph any feedback vertex set has size ≥n/4 by edge counting, so the ordinary cycle packing-cover theorem supplies m vertex-disjoint cycles as n grows. Replace each vertex by a triangle with one incident base edge at each port. Deletion of ≤2 vertices destroys ≤2 base edges, keeping surviving triangles internally connected and nonempty. Base 3-edge-connectivity proves expansion 3-connectivity. Give one edge of each triangle gain e1, and one external edge per chosen base cycle gain e2, others zero. Each selected cycle lifts avoiding all e1 edges. Every nontriangle simple cycle projects to a connected nonempty 2-regular subgraph of the base, since each triangle uses two external ports by parity and the three-port bound. It therefore displaces ≥g named triangles. In an edge-disjoint packing each triangle can serve only one cycle, proving maximal cardinality. The actual spectrum is full for large m by reserving some disjoint base cycles for e2 and triangles on other selected cycles for e1. The counterexample only bounds the size of a direct packing exchange.
