# Exclusions in exact supported-image recognition

Let C be a binary cycle code, σ a linear score and T a desired image. Write C′=C∩σ⁻¹(T). A portfolio on C′ uses one primal lane for each basis vector of T, with that exact score. For each basis covector λ of the annihilator of T in the score space, use a dual lane of C′ required to represent σᵀλ modulo C⊥ (extend σ linearly to ambient coordinates). This coset constraint is a linear score on C′⊥. For a support Y with the desired image, every σᵀλ vanishes on the shortened code C_Y. The elementary identity (C∩F₂^Y)⊥=C⊥+F₂^{E−Y} gives the required dual representative supported off Y. Conversely choose Y the union of primal supports. Every d in C_Y is annihilated by every selected dual representative, hence by every σᵀλ, proving equality. The homogeneous solver applies whenever the actual C′ represents a regular matroid.

Precise obstruction on the prism substitution is due to the matroids lead. For C=Cut(K3,3) label nine edges in row-major order, low bit first. Take λ(c)=c01+c10 and μ(c)=c02. On Y with mask 78 the only supported words are 0 and 78, with (λ,μ)=(0,1) for the latter. The normalized C′=C∩ker λ punctured on its first two coordinates has parity checks 15,54,85 on its seven remaining coordinates, giving all seven nonzero three-bit columns and therefore F7. For disjoint physical blocks use λ_total equal to the sum of the block λ's and μ only on the first. Shortening all other blocks yields each block's local normalized code; further puncturing produces F7 on disjoint surviving coordinate sets. Thus no bounded strong regularity backdoor on the normalized host follows even for these feasible prism instances with just two bits.

There is nevertheless a direct deterministic algorithm on every binary input when the actual image σ(C) has rank at most two. Zero and full targets are immediate and any target outside the image is impossible. For a target line with generator t, an inclusion-minimal attaining support shortens C to a one-dimensional subspace with full support, hence consists of a circuit. Conversely any circuit of score t suffices. Consider each connected matroid component separately. In rank-one score components an appropriate fundamental circuit exists when the component image contains t. In a rank-two score component construct a fundamental basis. If t is absent among fundamental cycle scores, the two remaining nonzero types a,b must appear. Choose a shortest path in the fundamental bipartite graph between any opposite types. Every interior nonbasis vertex has zero score, else the path was not shortest. If the path starts e–x–z–x′, pivot the zero-score nonbasis element z into the basis in exchange for x. Every other fundamental cycle either stays the same or gains the old cycle of z, preserving its score. The new fundamental cycle of e is adjacent to x′ since the old path was chordless, and the path suffix retains its edges. The new nonbasis x has score zero. Repetition gives opposite-colored fundamental cycles sharing a basis coordinate. In the restriction to the old basis plus these two nonbasis elements there are precisely three nonzero cycles. The symmetric difference omits the common coordinate and contains both nonbasis elements, so contains no other nonzero cycle properly. It is the desired circuit with score a+b=t. All operations are polynomial and return the physical support directly.
