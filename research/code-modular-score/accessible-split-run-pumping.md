# Charge-conservative pumping on accessible runs of a clique–star tree

Consider an oriented sequence of internal nodes on a clique–star split-tree path, with a retained nonempty exterior subtree at each end. A site is one path node together with every hanging subtree branching off the path there. Assume that each node transmits between its two spine markers: it is a clique, or one of those two markers is the center of its star. The physical vertices are leaves and two leaves are adjacent exactly when each intervening node transmits on their unique tree path. Use a fixed finite abelian group Γ for their charges, augmented by one binary marker coordinate for each protected port if applicable. These are vertex charges, independent of the marker orientations used to represent edges. The representation may temporarily be noncanonical. See [Gioan and Paul](https://arxiv.org/abs/0810.1823).

**Physical contraction.** Fix the same left-to-right direction throughout. Each hanging subtree, completed by adding a dummy leaf on its parent marker, represents a connected graph. This follows inductively by composing connected marker graphs along paired markers: every physical component after a marker is removed has a neighbor of that marker, and across the split the two nonempty sets of such neighbors are completely joined. Thus every physical component of the hanging subtree contains a contact accessible from its parent marker. A hanging marker at a spine clique sees both spine directions; at a transmitting spine star it sees the direction of the center. Assign each hanging component entirely to an allowed direction, using a fixed choice when both are allowed. Sum its charge into that site's ordered pair in Γ².

For any nonempty contiguous subinterval, splice the two exterior incidences directly and delete the sites inside. Every previously existing adjacency among retained leaves is unchanged: an exterior path crossing the interval traversed only transmitting turns. Pick one physical contact accessible from each exterior incidence, which exists by the completion argument. Every removed component assigned left has a physical neighbor at the chosen left contact, since all intervening spine turns transmit. The same holds on the right. A subinterval whose pair of charge totals is (0,0) can therefore be contracted onto those two actual contacts, restoring their original charges, keeping all other retained leaves as singleton branches and deleting surplus edges. No bound on the number of active exterior leaves is needed. With unique marker bits included, a removed interval with zero totals contains no protected port.

**Finite-state refinement.** Fix in advance finitely many CMSO properties of the whole interpreted labelled graph. For example, at fixed binary named dimension take the finite list of tests for attainability of each named kernel, using the connected-partition bound from modular-width-conservative.md. Include all fixed augmented port query coordinates when that is the requested catalogue. Adjacency of two physical leaves is MSO-definable in the split tree by inspecting the two incidences of each node along their path and testing the star-center condition. Finite labels on nodes and incident edges encode marker types, charges and names. Root and arbitrarily order the split tree, using a ranked binary encoding of the ordered children. This gives a deterministic product bottom-up tree automaton A with finite state set Q for the translated properties. To make the composition explicit, root the representation on the left exterior, retain the marker type of each child incidence at its parent (and likewise its type at that child), and store these endpoint marks locally in the node/child list rather than inferring them from adjacency. Each oriented site together with its hanging subtrees is then a one-hole context for the right continuation subtree in the tree-of-child-lists encoding. Choose the continuation first in the child order, or use a child-list cons cell with separate child and tail arguments, so substitution does not alter the siblings or incidence decorations. Neighboring site contexts compose. The empty run is the identity context. Implementations that store the incoming marker type on the child node keep that label with the child under substitution.

Each site induces a function Q→Q by varying the automaton state at its hole and fixing all other inputs. For each prefix record the pair of cumulative direction charges and the composed state function for its context (earlier prefix outside later sites). At most |Γ|² · |Q|^{|Q|} such records occur. A run of at least this many sites has two equal prefix records, counting the empty prefix. Deleting the intervening sites preserves both charge totals by cancellation in Γ². It preserves every automaton result because the two prefix functions agree on every possible right continuation state: any remaining suffix and any enclosing left context give the same result. The functions can be computed by trying each hole state, so this is an effective reduction for fixed properties. Allow arbitrary valid clique–star representations when forming the automaton; splicing may make neighboring nodes eligible for normalization but does not change the interpretation. The test with charges alone gives only a conservative minor. The prefix-function equality supplies the reverse catalogue implication. If port vectors were included, equality of that augmented catalogue gives exterior graph gluing preservation by the shared-boundary cancellation lemma of modular-width-conservative.md.

A blocked passage is excluded: a star entered and exited on arms can prevent a required cross-face adjacency from existing. Long transmitting runs can be reduced by this argument even if both ends have many active leaves. It supplies no bound on the number of blocked sites in a general split tree.
