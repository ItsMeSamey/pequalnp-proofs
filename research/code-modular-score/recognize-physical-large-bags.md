# Recognizing small bags mixed with highly connected physical bags

Fix b,s,K with K>b and s≥b. For an ordinary graph decide whether there is a tree decomposition of adhesion at most b where every bag has size at most s or is physically K-connected on its induced edges; return the tree. Connected components can be joined by empty adhesions.

Call two vertices compatible if no set of at most b other vertices separates them (self and adjacent pairs compatible). For each pairwise compatible seed set R of size b+1 form X(R), the vertices compatible with all seeds. Retain distinct sets of size greater than s with physically K-connected induced graph. On a valid input these are exactly its bags of size greater than s. Indeed if the seeds lie in such a bag B, its vertices all qualify. For x outside B the first tree edge from B toward the occurrence subtree of x separates x from a seed outside its adhesion, which misses x. Conversely every retained X is pairwise compatible. If two vertices have disjoint occurrence subtrees, an edge between the subtrees separates them via an adhesion missing both. Subtree Helly therefore puts X in one large bag containing R, which by the first argument is X.

Fill the retained sets into cliques in auxiliary J. The promised decomposition covers J. Repeatedly split each piece at any clique separator S of size at most b into two pieces sharing S with both open sides nonempty. Each split consumes a distinct nonedge between open sides: neither child contains this pair, and a nonedge cannot occur in both child pieces as the intersection is a clique. Hence at most n choose 2 splits. Any terminal piece contains all of a given large clique or meets it in at most b vertices (the first split away leaves at most its separator). On a valid input a terminal piece A containing all of large bag B equals B: otherwise choose x outside B in A. The first tree edge from B toward x's occurrence subtree in the promised decomposition has adhesion in B. Its intersection with A is a clique separating x from some vertex of B in J[A], contradicting termination. A piece without a full large bag inherits the promised tree restricted to the piece, with all large bags shrunk to at most b vertices; it admits small bags of size at most s and adhesion at most b.

Keep a terminal piece equal to a candidate as one bag. For any other terminal piece L use a bounded-bag/adhesion DP. Its state is a component C of L−S with S=N_L(C), |S|≤b, asking for a decomposition on C∪S rooted at a bag containing S. Choose S⊆B⊆S∪C, |B|≤s, with B meeting C. For each component D of C−B require |N_L(D)|≤b and solve (N_L(D),D), joining its root to B. To see completeness, start from a feasible tree rooted at a bag containing S. If the root misses C, connected C lies in one branch and every vertex of S must persist toward it. At the first C-bag B one therefore still has S⊆B. Every D occupies one branch off B and all its neighbors (in B) must belong to the first branch adhesion. The restriction of that branch to D∪N_L(D) witnesses the recursive instance. Start each connected component with S empty. There are at most n^{b+1} states and n^{O(s+1)} choices per state.

Reassemble in reverse clique-split order by joining a bag covering S in each side; these bags exist because S is a clique and occurrence subtrees have Helly. Verify original graph coverage, running intersection, bag sizes/physical connectivity and adhesion on the resulting tree. Positive answers are certified on all inputs; completeness on every valid input gives exact recognition. Enumerating seeds and clique separators and solving all small atoms takes polynomial time for fixed parameters. The artificial fill is used strictly for recognition. This result supplies a decomposition-recognition entry point for the existing connected-sum solver on physical bags; it does not recognize general virtual-torso layouts.
