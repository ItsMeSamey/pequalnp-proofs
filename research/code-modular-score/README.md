# Modular scores of dense affine binary forms

Let y range over a binary vector space and let d_e=b_e+⟨a_e,y⟩ over GF(2). Each bit contributes d_e times an unsigned group weight w_e to an ordinary sum in a finite abelian p-group G=∏_j Z/q_j, q_j a power of the same prime p. For any fixed such G there is a deterministic polynomial-time test for a given target, returning y. This applies to arbitrary represented binary cycles, cocycles and affine translates. Additional binary affine equations on y can first be eliminated by substitution. It does not impose disjointness with another unknown codeword.

For odd p, use the group algebra over F_p with basis symbols X^a and multiplication X^a X^c=X^(a+c), the exponents adding over GF(2). At input y the symbol evaluates to (−1)^⟨a,y⟩. Its Walsh matrix is invertible because the message space has size a power of two, a unit in F_p. Thus a Boolean-domain function is zero exactly when its Walsh spectrum is zero. A bit d_e has expansion (1−(−1)^b_e X^a_e)/2.

For a single coordinate with modulus q and target 0≤t<q, compute the following coefficient in this algebra using representatives 0≤w_e<q:

    [z^(q−1)] (1+z)^(q−1−t) ∏_e (1 + d_e ((1+z)^w_e − 1)).

After evaluation at y the product including its prefactor equals (1+z)^(q−1−t+Σ w_e d_e). Lucas's theorem shows its coefficient of z^(q−1) is precisely the 0/1 indicator of the target residue, reduced modulo p. Multiply these indicator spectra across all coordinates. The resulting spectrum is nonzero precisely when the joint target is attainable. Restrict y one bit at a time, substituting the corresponding basis character by +1 or −1, to preserve some nonzero coefficient and obtain a witness.

Truncate each coordinate's computation to degrees below q. A nonconstant z factor costs at least one degree, so an occurring frequency is a sum of at most q−1 input masks. Across all target coordinates at most D=Σ_j(q_j−1) input masks occur in any such sum. Sparse arithmetic with XOR frequency keys costs n^{O(D+1)}poly(input length) for fixed G, where n is the number of input forms. For p=2 use ordinary Boolean multilinear polynomials in the message bits: affine d_e then already have degree at most one, and the same z truncation produces an indicator of degree at most D. Testing message vectors of weight at most D suffices by Boolean Möbius inversion. The reference implementation covers odd p and checks all evaluations and reconstructed witnesses for 375 seeded systems with p=3,5,7, including modulus 9 and two simultaneous ternary coordinates.

The odd-characteristic method also works for contributions of bounded-arity gates on affine binary forms. A truth table on s input bits has at most 2^s Walsh coefficients, and substituting affine parities maps each frequency to another frequency with a sign. In the coefficient formula replace the bit factor by its given truth-table expansion. For arbitrary group-valued gate outputs, for each z-degree expand the truth table of the corresponding binomial coefficient on the gate output. The resulting algorithm is polynomial for fixed G and s.

## A boundary of support compression

Take the binary affine-function evaluation code RM(1,k) on all 2^k points. Its codeword weights are zero, 2^(k−1), and 2^k, three distinct residues modulo 3. The last residue forces the all-ones codeword. Its restriction to its support has dimension k+1, even though the maximum packing of nonempty disjoint circuits is two: the nonzero minimal codewords are the affine hyperplanes, all of size 2^(k−1), and any one has a complementary hyperplane. Every information-set message for this forced codeword is all ones, so its indicator has Boolean degree k+1. This distinguishes the odd-characteristic Walsh algorithm from a bounded Boolean-degree test or graph-specific bounded-cycle-rank witness.

## Finite-group FPT with a supplied perturbation of a graph incidence matrix

Suppose the input code is the row space of D=D₀+UVᵀ, where D₀ is the vertex-edge incidence representation of an undirected graph (a loop has zero column), and U,V have s columns. These aligned matrices are supplied. Choose binary shore bits f for the rows. Enumerate b=Uᵀf. In this branch the coordinate d_e=(fᵀD)_e is the usual cut bit on e XOR the known offset (Vb)_e. A flipped coordinate changes its group-weight contribution from w times the cut bit to w minus that contribution, so the sum remains a group-valued Boolean quadratic. Enforce all dense parity conditions Uᵀf=b by adjoining their binary values to the output group G×GF(2)^s; these coordinates are linear in f over their own output factors. The [finite-group quadratic image algorithm](../group-quadratic-image/README.md) therefore gives deterministic time F(|G|,s)poly(input length) for any finite abelian G. It requires neither an odd prime nor a regular input matroid. It does require a supplied aligned representation and concerns the score of one unknown codeword.
