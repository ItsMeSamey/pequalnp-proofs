# Compressing charged subdivisions in every exterior

Let a graph carry vertex charges in a finite abelian group A. Its catalogue consists of the subgroups generated by the sums of the connected components of each spanning edge subset. Let a path strand have distinct endpoints, distinct unprotected internal vertices of degree two, and no other incident edges at those internal vertices. Protect both endpoints. One can physically shorten the strand to at most |A| edges while preserving the catalogue for every possible exterior graph, exterior vertex charges, and fixed choice of exterior edges.

Orient the strand. Give each edge its prefix value, the sum of charges on internal vertices strictly before that edge. Choose one occurrence of each distinct value, e.g. its first. Contract all unchosen edges, summing vertex charges; a chosen edge remains, so the endpoints stay distinct. Different branches carrying a protected endpoint are disjoint. Endpoint charges can absorb internal charges, according to the ordinary contraction rule.

To prove preservation, work on the original graph. The edge subsets using all unchosen edges are precisely those induced by edge subsets after contraction. Fix an exterior edge subset and any strand edge choice. If every strand edge is used, keep this choice. Otherwise let P be the set of prefix values of unused strand edges. Replace those unused edges by just the chosen occurrence of each value in P. In both choices the strand fails to connect its endpoints. Include all exterior vertices, endpoints included, when computing the exterior components: the components at the two endpoints can coincide.

If the successive old unused edges have prefix values p₁,…,pₖ, the detached internal intervals contribute p₂−p₁,…,pₖ−pₖ₋₁. Their generated subgroup D is generated by all pairwise differences of elements of P, by telescoping. It is identical for the replacement sequence, which can reorder and remove duplicate values. The endpoint components receive contributions p₁ and S−pₖ respectively, where S is the total internal charge. Each endpoint contribution has the same residue modulo D after replacement. When the endpoints share an exterior component their contributions add. All other exterior components have unchanged charges. Since D itself is already contributed by detached intervals in each configuration, the subgroups of A generated by all component sums are equal. This remains valid for one cut (D=0), zero charges, and adjacent cuts. Conversely every choice in the contracted graph lifts using the contracted edges, with identical component sums.

Independent strand reductions may now be performed successively; the universal exterior assertion lets each reduced exterior serve as the next context. A subdivision of a loopless h-vertex m-edge multigraph has a simultaneous representative on at most h+(|A|−1)m vertices, computable by scanning the strands. Parallel edges in the suppressed graph cause no issue. Split strands at further protected internal vertices first. For total-zero F₂³ charges on any subdivided K4 the bound is 46, without requiring an initial catalogue witness or any promise about the charge distribution. The result preserves score subgroups even with fixed exterior edges. The ordered list of individual component sums need not be preserved.
