# Fixed maximum 2-primary exponent on graphical, regular and nearby codes

Write T as a product of cyclic orders 2^(e_j), e=max e_j, and A for an arbitrary odd abelian group. For any affine binary code (after all binary pins are eliminated), each digit b of the jth score is a Boolean polynomial of degree at most 2^b, by Lucas's theorem applied to the elementary symmetric polynomial in repeated edge bits. Thus every XOR of digits has degree ≤D=max(1,2^(e−1)). The target indicator has degree ≤H=Σ_j(2^(e_j)−1), by multiplying the individual equality tests. If nonzero it has uniform density ≥2^(−H) by the Boolean polynomial minimum-weight bound. Its real Fourier expansion on the output digits has coefficient absolute sum one. Hence it suffices to fool each digit parity sign to expectation error <2^(−H−1).

Enumerate [Viola's sum of D independent small-bias generators](https://www.khoury.northeastern.edu/home/viola/papers/d.pdf), choosing parameter-only constituent bias to obtain that accuracy. Each seed has length O(log(d+1)+log(1/bias)) for d free binary variables. Thus the support size is f(T)(d+1)^O(D); direct tests return a witness. This is uniform across group ranks at each fixed e, and does not give an absolute input exponent across different e. At e≤2 exact counts are obtained by fourier-four-eight.md, whose refinement has even cross coefficients.

Use this auxiliary witness oracle in odd-coprime-lift.md for joint graphical A×T targets. For represented regular codes combine regular-score-dp.md and child-hashing.md. The ternary replacement exposes x,y,x XOR y; twice the indicator for a prescribed pair of bits is an integer affine combination of those three. Each of at most |A×T|−1 occurrence slots thus uses one Z4 coordinate, independent of the bag degree. Binary parent pins use F₂. Default G weights come from a linear section and physically use those same three wires, without division in G. Cographic bags use the separate arbitrary finite-group Boolean quadratic image theorem, and R10 is bounded. The tree queries already computed child tables. With the properly refined constructive decomposition this gives f(A,T)·input^O(max(2,2^(e−1))) and full traceback. For exp(T)≤4 the polynomial exponent is absolute. An affine translate uses physical sign flips and target subtraction.

For arbitrary binary C with supplied regular reference R on the same ground coordinates, compute U=C∩R. Put a=dim C−dim U,b=dim R−dim U. Enumerate 2^a cosets of U in the prescribed affine translate of C. Translate each representative to zero, describe U inside R by b independent binary side constraints, and use the regular oracle with these extra binary labels. Witnesses undo the offset. The parameters increase only by a,b. This includes aligned rank-s perturbations of regular generator or parity-check matrices: restriction to the kernel of the perturbation (respectively its transpose) shows both codimensions are at most s. Recognition of an unspecified nearby regular reference is outside this reduction.

For constructive normalization, [Bérczi, Mátravölgyi and Schwarcz, discussion following Theorem 2.5](https://doi.org/10.1016/j.jctb.2025.10.009) describe polynomially many oracle operations refining each 3-connected piece. First split off proper 1- and 2-sums, then refine each 3-connected piece while retaining singleton virtual elements in their local bags.
