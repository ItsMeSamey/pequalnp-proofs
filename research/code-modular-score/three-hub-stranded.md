# Absorbing residual components into switches

The three-hub certificate admits components of G−T with no chosen anchor. Given at most 2d toggles, their color pairs and three anchors, compute all these stranded components. Reject a guess if a stranded component contains any vertex required in a hub (including a rare vertex or required neighbor contact). In a connected host each stranded component neighbors some toggle. Assign it wholly to one of its neighboring toggles. Each toggle and its assigned components form a connected switch, retaining its two core contacts. The switches are disjoint.

For each stranded component compute its label XOR in S. Dynamic program on the ordered tuple of effective switch charges, initialized by the toggle labels. Each step adds the component XOR to one neighboring switch. There are at most 2^{d|T|} states. For each final state test rank 2d of the designated effective pair transfers, with backpointers. This replaces the raw pre-absorption rank test. All anchor-containing components are covered by growing their cores as before. Starting with any endpoint assignments of the resulting whole switches and then correcting the two deficits over the binary field gives the requested partition. No unlabeled leftovers are assumed. All data used by the dynamic program are computed before choosing hub routes. The search is polynomial for fixed d,p.

For example, give the eight switches of the preceding full-rank example charge zero. Attach one pendant leaf to each, carrying its original switch charge. For these same switches every leaf is stranded and its sole available absorption restores the eight independent transfers. The comparison concerns those fixed switches and hubs.
