# Simultaneous gain-aware lifts of prescribed quotient cycles

Contract disjoint connected branch sets in a physical graph. Retain every designated external edge with its physical identity and two endpoints, allowing loops/parallel edges in the quotient. Suppose k edge-disjoint simple cycles in the quotient are prescribed. For a fixed finite abelian group Γ and a target gain per cycle there is a constructive parameterized test for lifting them to k edge-disjoint closed trails with those exact external edge sets and gains. Gains can first be signed by any supplied baseline; the following then uses ordinary unsigned addition of the resulting physical labels.

At each branch set, each visiting quotient cycle contributes exactly one terminal pair, the physical incident ends (including both ends of a loop); no cycle has two visits to this branch set since the quotient cycle is simple. For every possible tuple of local gains, use [Liu and Yoo, STOC 2025, Corollary 1.13](https://people.tamu.edu/~yyoo/stoc25.pdf) on the internal graph. Prescribe each local gain by forbidding all other elements of Γ. That result constructs edge-disjoint trails with possibly repeated terminals, in time with absolute graph-size exponent eight plus linear edge dependence, for fixed terminal/group parameters. Explicitly allow a trivial length-zero local trail when its two terminals coincide and prescribed gain is zero; enumerate the subset of such choices if necessary before invoking the solver on the others. Zero-label subdivision can realize physical multigraph edges in simple solver input. Preserve distinct loop walks by private subdivisions.

Combine all successful local tuples by dynamic programming in Γ^k, reserving the external edge contributions and treating absent coordinates as zero. Save predecessor indices and local trail witnesses (or recompute them once). A global closed trail with the prescribed trace restricts to these local trails; conversely concatenate the internal trails and the fixed external edges in cyclic order. Internal branch sets are edge-disjoint, and so are the external prescriptions. The result therefore respects physical edge disjointness, with score evaluated in ordinary original coordinates or converted to an increment by the chosen sign convention. Runtime is f(k,|Γ|)poly(input), with fixed graph exponent independent of path lengths. This assumes the quotient cycles are supplied and does not search over their identities.

If independent gains over a scalar space F_p^k are enough, decompose each returned trail into edge-disjoint simple physical cycles. A nonzero k-row minor of the trail gains expands multilinearly into minors of choices of one constituent per trail, so one can choose such simple cycles greedily, preserving a nonzero minor against the remaining trail sums. Those selected physical cycles need not follow the prescribed quotient trace. If the trace is required, a decomposition has precisely one constituent using the entire prescribed simple quotient cycle, since its external projection is even and no proper nonempty subset of a simple circuit is even. The other constituents lie wholly inside branch sets. Exact trace-preserving simple-cycle gains survive this extraction when those internal cycles' signed gains are zero.

A single contracted wire can prevent simultaneous lifts even before score constraints. Contract uv, with k internally disjoint paths of length three from u to v as the only other edges. In the quotient the k paths form k edge-disjoint triangles. Each triangle's unique even lift with the prescribed exterior edges uses uv, so no two can lift edge-disjointly. Combining j triangles by XOR charges uv only if j is odd. This obstruction survives arbitrary sign translations; one can set the wire's label to zero so scalar image is preserved even as all disjoint-lifting claims fail. It does not contradict a saturation theorem based on indirect four-bundle arguments.
