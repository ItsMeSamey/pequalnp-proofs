# Physical reductions preserving every named-kernel answer

Let G be a connected finite simple graph with p binary row labels per vertex. For any contracted edge set X the row space on names is spanned by the label sums of the components of (V,X); all other physical edges are deleted. Preserve the whole set of attainable row spaces, equivalently their orthogonal named kernels. Physical minor operations sum labels on each contracted branch; arbitrary charged vertices may not be discarded. A fixed number of protected vertices can additionally be marked by distinct one-hot label coordinates.

## Explicit linear bound in the cycle rank

Take a spanning tree and retain its g=|E|−|V|+1 other edges as named columns temporarily. A chord contributes a bit at each endpoint, i.e. its incidence column. For each tree edge e compute the expanded (p+g)-bit sum a_e in its descendant subtree, using an arbitrary root. For every subset D of tree edges left uncontracted, the attainable expanded row space is precisely the span of the total expanded charge and the a_e for e in D. Indeed each retained cut is a union of final components. Conversely, in the quotient tree each final component sum equals its incoming subtree sum (or the total at the root) minus the subtree sums at its children. Thus keeping one edge for each distinct nonzero a_e and contracting all others gives exactly the same expanded row spaces, with no lost or new possibilities.

Return all surviving chords to physical status, preserving their identities even if they become parallel or loops. For any original choice of contracted chords J, restrict the expanded named row space to vectors vanishing on J, then discard all chord coordinates. This is exactly the original named row space after contracting J and deleting the other chords; the order of operations is immaterial. Thus the physical coarsening preserves the full p-name catalogue at once. One-hot name bits ensure that if two designated vertices were physically separate, a retained edge still separates them: every original tree edge separating the two has different corresponding name bits across its cut, and any other edge with the same expanded sum also separates them.

The chord portion of a_e is zero outside the tree spanned by the at most 2g distinct chord endpoints. Suppress internal unmarked degree-two vertices of this Steiner tree. Each resulting segment has a constant chord-crossing vector as no chord endpoint occurs in its interior. With h≥2 endpoints there are at most 2h−3 such segments. Including the zero pattern gives at most max(1,4g−2) different chord vectors. Hence a single coarsened graph with at most 1+2^p max(1,4g−2) vertices suffices regardless of input order. This bound uses p including any extra one-hot protected-coordinate bits.

## Effective bounded-feedback-vertex core

For any fixed k,p and a fixed bound on protected names there is a computable universal size bound for a same-catalogue physical spanning minor on connected graphs of feedback vertex number ≤k. Use the conservative spanning WQO proved in xor-spanning-minors.md. Protected vertices are represented by extra bits or explicit predicates when testing a candidate graph.

For clarity the effective basis argument is distinct from simply invoking a WQO. There are finitely many possible signatures (full named-kernel catalogues). Every individual signature test is expressible in counting monadic second-order logic: for each desired subspace U quantify a partition into at most p+1 connected nonempty vertex sets whose sums span U. This realizes a contraction witness, and every attainable U has such a partition by the component-merging rank lemma. Enumerate finite lists of group values, using parity of counts in each input label class; negate the formula for unattainable U. A fixed candidate H being a conservative spanning minor is also expressible: quantify one nonempty connected part per candidate vertex, require their partition of ALL input vertices, exact charges, preservation of designated names, and at least one physical edge for each candidate adjacency. Unneeded edges are deletable.

For each possible signature maintain a list of candidate graphs of that signature. Repeatedly decide whether there exists a connected graph of feedback vertex number ≤k with this signature that avoids all current candidates as conservative spanning minors. This is an effective finite-tree-automaton emptiness problem on bounded-width graph terms: deleting k feedback vertices leaves a forest, hence width is at most k+1, and the feedback and connectedness promises themselves are logical formulas. Satisfying graph terms provide explicit witness graphs. One can also use forest terms with ordered apices directly: a forest node carries its finite charge and its actual adjacency mask to the apices. A fixed number of connected-part colors, their boundary connectivity, adjacency flags and modular sums are finite bottom-up states; finite boolean combinations are effective. If uncovered, add a witness and repeat. Infinite continuation would give an infinite bad sequence within the bounded-feedback WQO since later witnesses avoid every earlier candidate. Thus this search terminates for each of the finitely many signatures and gives a computable library and size bound.

Given a bounded-feedback input, compute its signature by bounded-width DP and find a stored candidate of that signature by the same fixed-pattern connected partition test; the recovered branches give a concrete physical minor. Beyond the size bound this is a strict size reduction. No explicit reasonable growth rate is claimed for this second bound, and no WQO or recognition theorem for all connected vertex-charge graphs is assumed.
