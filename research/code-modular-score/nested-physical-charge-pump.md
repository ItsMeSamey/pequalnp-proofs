# Pumping nested linked port cuts with arbitrary interior vertex charges

Let P0⊂...⊂Pm be connected nested patches in the same vertex-charged graph, each with a distinct ordered b-vertex interface B_i separating its private interior from all the rest. Adjacent interfaces are disjoint. For each consecutive layer the shell meets the already included patch only at B_i and the remaining exterior only at B_(i+1). Specify b disjoint paths across each shell matching equally indexed ports, and suppose every remaining shell vertex can be attached to these paths to form b disjoint spanning branch trees. Connectedness of each shell component to a rail suffices. The exterior of Pm may be arbitrary. Own all charges on B_i on the inside when computing the table of P_i.

For each shell record its q-bit charge newly delivered to each corresponding old port when these b trees are contracted; omit vertices of B_i in summing and include B_(i+1). Compute the cumulative b-tuple C_i of these records up to P_i by index-wise XOR, starting at zero. Independently compute the full augmented transfer table Σ_i of P_i, referencing ordered port zero for evenification, as in planar-physical-patch.md. It has h=q+b−1 coefficient bits. If (Σ_i,C_i)=(Σ_j,C_j) for i<j, contract all intervening branch trees to the corresponding innermost ports and delete the other shell edges (retaining original P_i edges). The original outer interface B_j is now mapped bijectively to B_i. At each port the total additional charge is exactly zero by the equality of cumulative vectors, so this inner graph has precisely its original table Σ_i, now equal to the table required of P_j. Full exterior behavior, all actual ports and physical witness traceback are preserved. Nontrivial shells are removed without freely discarding any charge.

Consequently more than 2^(qb) 2^s cuts, where s counts the subspaces of binary h-space, guarantee a repeat. Tables can be computed on plane or bounded-genus patches or supplied on other topologies. This requires ordered linked cuts of bounded size. Huynh's group-labelled linkage pumping (arXiv:2611.34307, Lemma 4.1) likewise uses rail-indexed bounded separators but preserves a requested linkage by rerouting; the physical table here concerns every choice of exterior and conservative vertex charges at every surviving port.
