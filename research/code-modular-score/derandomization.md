# Deterministic hitting and a graphic routing improvement

Let P_R assert that no R-dimensional axis-aligned subcube has singleton intersection with a nonempty fiber S in {0,1}^n. The minimum cardinality of a universal deterministic point-query hitting set for all such S is exactly D=sum_{j<R} binom(n,j), with out-of-range terms zero. The upper bound takes every input of weight <R, since a minimum-weight point of S otherwise contradicts P_R. For the lower bound, multilinear Boolean polynomials of degree <R form a D-dimensional space over F₂. Each has parity zero across every R-subcube, because every restricted monomial omits some free coordinate. Fewer than D evaluations leave a nonzero polynomial vanishing on every queried point. Its nonempty support has P_R and avoids the query set. Considering the all-zero response transcript gives the same bound for adaptive deterministic black-box queries distinguishing emptiness. This only bounds the use of P_R in isolation.

For represented unsigned-score fibers with the relevant density bound 2^(1−R), there always exist smaller nonuniform universal hitting sets. Fix group G, basis dimension n and m physical coordinates. There are at most 2^((n+1)m) |G|^(m+1) choices of linear forms with offsets, weights and target. Independent uniform points numbering O(2^R((n+1)m+(m+1)log(2|G|))) miss no nonempty fiber in the class with positive probability, by union bound. These points yield advice of FPT-polynomial size. This proof gives no uniform FPT construction.

## Graphic connected components

For an undirected graph build a port graph: each vertex becomes a clique on its incident half-edges, with zero edge weights; each original edge becomes one weighted wire between its two ports. Loops have distinct ports. Subdivide each wire into a length-three path to ensure the host simple, including for loops; put the full weight on one segment. An Euler tour of a nonempty connected even subgraph lifts to a simple cycle: traverse each selected wire and use the clique edges joining its consecutive half-edges. No port repeats. Conversely a simple port cycle using any wires projects to an even connected physical edge set. Indeed projection contracts clique edges to stationary steps, and each wire on the closed walk occurs once. A cycle using no wires contributes zero. Vertex-disjoint port cycles project to edge-disjoint even physical sets, which may share vertices. Conversely the actual connected components of an even physical support lift disjointly.

For B components test disjoint subdivisions of B loops in the port graph by Liu and Yoo Corollary 1.4, with unsigned component scores guessed in G and constrained to sum to the target. Run this for 0 through B loops. The resulting even set has at most B components, and every feasible such set is represented. This costs f(g,B) n^{O(B)+O(1)} for input size n (the host is of polynomial size). It is deterministic FPT in g for every fixed component cap, and the exponent is independent of the witness cycle rank. In an inclusion-minimal fixed-score witness B<g by the prefix-sum argument. This gives linear dependence on g in the overall polynomial exponent for graphic matroids; the earlier skeleton search had O(g log g) anchors.

Reference: https://people.tamu.edu/~yyoo/stoc25.pdf . Its unrooted-subdivision Corollary 1.4 has exponent |V(H)|+8; its discussion after Corollary 1.12 leaves the removal of this exponent open.

In regular-score-dp.md the graphic bag has one G target plus b≤3g prescribed physical bits. A minimal witness has at most b components containing a forced-one edge. All other components have zero pin-vector, so there are fewer than g of those by the same prefix-sum argument in G itself. Therefore B≤4g−1 and the port-cycle argument costs f(g)n^{O(g)+O(1)} even in these bag queries, despite their auxiliary score group size g 2^b. Together with n^{g−1} exceptional choices and the FPT cographic bag oracle this yields deterministic f(g)n^{O(g)+O(1)} decision and witness on all represented regular matroids.

## Uniform FPT after contracting the 2-torsion columns

This algorithm holds for every binary linear checking matrix D, offset b, and arbitrary finite abelian score group G. Let T consist of columns with 2w_e=0, A be the remaining columns, and r=rank(D)−rank(D_T). Reject if b is outside im D. Choose a linear projection P:im D→im D_T that is identity on im D_T. Identify ker P with F₂^r. Choose a linear right inverse L of D_T on im D_T. All these choices use elimination. The map s_T(x)=sum w_i x_i for i in T is a homomorphism into G[2], since each weight has order at most two. Compute K=s_T(ker D_T) by taking the image of a kernel basis and closing the generated subgroup.

For free A-bits z a T-completion exists precisely when (I−P)D_A z=(I−P)b. Then x_T=L(Pb+PD_A z)+y, y in ker D_T. Its score ranges over s_T(L(Pb))+sum_e s_T(L(PD_e)) z_e +K. Thus run ordinary independent-item subset-sum DP in (G/K) × F₂^r: each e in A has first weight w_e+s_T(L(PD_e)) modulo K and second weight (I−P)D_e. The target is the prescribed G-score minus s_T(L(Pb)), modulo K, together with (I−P)b. Keep subset predecessors, recover the missing element of K using generator predecessors, and then use the associated kernel basis vectors to recover x_T. This costs O(|A| |G| 2^r) table updates plus polynomial preprocessing in the represented input and |G|. Thus the uniform algorithm is FPT in (r,|G|) on arbitrary codes, including affine cosets and mixed group orders. For graphic incidence matrices, r is the number of connected components in the spanning 2-torsion subgraph minus the number of components in the original graph. In particular a spanning 2-torsion forest makes r=0.

The dual elementary parameter is rank of the projection of ker D onto A: enumerate all possible physical patterns on non-2-torsion coordinates and then solve the remaining affine system and 2-torsion score linearly. One may take the smaller of these two parameters.
