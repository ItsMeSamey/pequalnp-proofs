# Ordered physical blocks and one-dimensional regular extensions

For an ordered partition E_1,...,E_m of the ground set define C_j by shortening C on every earlier block and then projecting onto E_j (puncturing all later blocks). These are physical minors. Define R_j,J_j similarly for an arbitrary regular reference R and J=C∩R. The kernel of the j-th projection on the earlier-shortened code is the next earlier-shortened code, so Σ dim C_j=dim C, and likewise for R and J. Since J_j⊆C_j∩R_j,
Σ_j(dim C_j−dim(C_j∩R_j)) ≤ dim C−dim J,
and likewise in the opposite direction. This works without any separator or connectivity condition. The inequalities need not be equalities: C=span(11), R=span(10) and order 1,2 have the same two graded pieces while C and R differ in both directions.

Each R_j is regular by minor closure. Therefore choose any effective necessary feasible-budget upset per block; the Minkowski sum of these upsets is necessary for the full input. Up to a cap k, a two-dimensional dynamic program on {0,...,k}² computes the truncated sum in polynomial time per block and parameter-dependent time in k. Multiple flag lower bounds and the common-physical-minor lower can be intersected. They must not be added when they charge overlapping original coordinates or incompatible flags. Intersect also across orientations through the bounded-width ∀orientation∃compact-reference formula of local-port-orientations.md, keeping the two global budgets outside the universal quantifier. Upper witnesses use the separate existential compatible-reference test and are lifted. Equality of the resulting objective lower bound with a verified full upper witness certifies exact optimality; no orientation list is enumerated. A supplied regular reference gives another independently verifiable upper.

## Exact projected-minor tests on all one-dimensional candidates

Let C=ker H, H binary with row rank r. The pure supercode search at distance at most one asks for v∈F₂^r (v=0 allowed) for which quotienting the column representation by span(v) yields a regular matroid. Each solution gives R=H⁻¹(span(v)) with its physical coordinates unchanged.

A witness template specifies seven survivors in a fixed order and a disjoint contracted set K, with all remaining coordinates deleted. Let U=span H_K and W=U+span H_survivors. Work in W/U, dimension ≤7. If v∈U or v∉W the ordered survivor minor does not change from its unperturbed representation. Otherwise it is the survivor minor in W/U quotiented by the corresponding nonzero binary coset. Compute whether each such answer is F7 or its dual, testing all 7! permutations if necessary. A regular extension must pass (neither obstruction occurs) on every template. The allowed indicator is an integer linear combination of at most 130 affine-space indicators: enumerate the at most 128 classes α+U inside W, and if the unchanged outside class passes add 1−1_W. These terms have small exact integer coefficients. This includes obstructions created by projection, which a search checking only the original obstruction list would miss.

With t discovered templates, expand the product of their allowed indicators. Count each resulting affine intersection by binary elimination, obtaining either zero or a power of two. Time is 130^t poly(input,t) and integer lengths O(r+t). If positive, recover an admissible vector by successive coordinate pinning and recounting. Test regularity after applying its quotient. If rejected, a forbidden template can be extracted by greedy deletion/contraction preserving nonregularity, calling the polynomial-time regularity oracle. At a minimal nonregular binary minor the seven surviving elements and its contracted set give the next template. It rejects the current vector and thus cannot be redundant on the current candidate set. Empty candidate set certifies nonexistence of any regular one-step supercode; a supplied list of t templates certifying emptiness can be checked by the same exact count without trusting the discovery order. Orthogonal complementation gives the dual search for one-step subcodes.

Termination is finite since each rejection excludes its chosen vector. Complexity depends on the number of templates actually used before termination; it is not claimed FPT in the minimum conceivable certificate length or in distance alone. All tests and witnesses are unconditional, do not presume bounded branch-width or a supplied nearby reference, and address only the stated one-sided distance-one problem. When original host Fano templates suffice, an immediate additional reduction is to intersect their W spaces, since every successful v must lie in each W and outside its U. If this intersection dimension is logarithmic, enumerate it directly even when all the original contraction witnesses have large rank.
