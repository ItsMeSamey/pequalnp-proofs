# Exact named kernels by routing the dual boundary

Let A be a full undirected vertex-edge incidence matrix of G and B an arbitrary binary matrix with the same vertex rows and k named columns. Find ordinary contractions X so that deleting remaining ordinary edges gives exactly the named kernel K. Put U=K⊥. There is a deterministic XP decision and witness algorithm at fixed k for planar graphic references, including dense named columns. Given a cellular embedding of bounded Euler genus the same holds with the genus an additional parameter. More generally it suffices to supply a graph H with the same identified edges, cut(G)⊆Z(H), and bounded δ=dim Z(H)−dim cut(G), checked by elimination.

First assume G connected. For b_v its named vertex rows let τ=Σ_v b_v. Toggle τ at one root to obtain adjusted rows summing to zero. Solve k boundary systems on a spanning tree to obtain edge labels λ with these adjusted boundaries. For every vertex set S its original row sum is the λ-sum on δ(S), plus τ when S contains the root. The span of incidence columns X consists of the boundary words even on every component of (V,X). Thus U_X, the row span on the names after contraction, is generated by the component row sums, including isolated vertices. With J the complement edge set,

    U_X = span(τ, λ(D) for D∈cut(G) supported in J).

Indeed cuts supported in J arise from exactly the unions of components. This tests the full span, not just the existence of a chosen collection of vectors.

By graphic-target-component-rank.md an attainable target has a witness with c≤dim U+1 components. Add every intra-component edge to X. Each remaining edge belongs to a component cut supported inside J. Thus H[J] has no bridges (ignore isolated vertices), and its cycles belonging to cut(G) form an exactly (c−1)-dimensional space, by the component indicator description. Compute edge labels η∈F₂^δ extending by Gaussian elimination a linear quotient map of Z(H) by cut(G). Restricting to J shows that β(H[J])≤c−1+δ. In a planar dual δ=0. On a connected closed cellular surface each vertex cut is a dual even set, as a dual face boundary. Euler's identity yields δ equal to the Euler genus, including nonorientable surfaces over F₂.

Enumerate bridgeless cores with β≤dim U+δ, suppressing degree-two vertices, keeping an anchor on each pure cycle and omitting isolates. A connected b-cyclic component has degree excess sum 2(b−1), so the number of remaining vertices and chain slots is parameter-bounded, even with loops and parallel slots. Include the empty core. Replace each host edge by a private three-link chain, placing its (λ,η) label on one link (a loop becomes a triangle). Add two distinct interior markers on each pattern slot; the stretched host provides room and the pattern is now simple. Guess injective placements of pattern vertices and the combined group sum on every subsegment. Clone each placed host vertex once per incident subsegment, copying incident edges, and route all prescribed subsegments as mutually vertex-disjoint paths between assigned clone pairs. All clones are terminals. Upon projection, paths share only intended endpoints. A direct edge between placed vertices cannot repeat because the subdivided pattern has no repeated endpoint pair; an edge meeting an unplaced vertex cannot repeat by vertex disjointness. The constructive Liu–Yoo theorem over the fixed finite abelian group applies by forbidding the opposite bit in each coordinate. The placement enumeration gives XP. [Liu and Yoo, Theorem 1.3](https://people.tamu.edu/~yyoo/stoc25.pdf)

On the abstract core compute the η-kernel on its entire cycle space. Accept precisely when its λ-image together with τ spans U. Suppression and subdivision preserve the cycle labels. Since the routed subgraph has minimum degree two, any used stretched host edge occurs in full. Take X to be the complement of its projected edge set, and verify by elimination. The span formula proves soundness regardless of the number of components of this reconstructed X. The bounded witness proves completeness.

For disconnected G with component embeddings solve separately for every component row subspace of F₂^k. Combine attainable spans by finite-state sum DP with backpointers, each component using its own τ. This allows bounded individual genera. For a global supplied H not respecting that split, adjust one root per component, include all fixed component totals, and use the same global argument: the incidence vectors of edges of quotient spanning trees in the merging proof of graphic-target-component-rank.md are jointly independent, so Σ_i(c_i−1)≤dim U. The dimension of the supported cutspace on J is this sum, again giving β≤dim U+δ. This is a kernel recognition algorithm on the stated hosts, not a mobility criterion asserting that every plane is attainable.
