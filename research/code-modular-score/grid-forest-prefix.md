# Conservative compression of monotone residual cells

Fix h, the port count and bounds on the number of row and column bands. Allow arbitrary charges on boundedly many exceptional complete rows and columns. In each occupied residual band cell suppose the nonzero support is a monotone chain: its points may be ordered monotonically in both coordinates, with either direction and with ties allowed. Make a bipartite graph whose vertices are row and column bands and whose edges are their occupied cells. If this graph is a forest, the complete charged grid has a bounded-size physical rectangular minor preserving every augmented kernel. A greedy polynomial algorithm for fixed parameters finds it; this argument establishes finiteness of the size bound without an effective numerical value. In particular, matrices of charge bits inside a cell can have arbitrarily high rank.

This uses the word-order idea behind forest grid classes of permutations (Murphy and Vatter, https://arxiv.org/abs/math/0310321; Albert et al., https://doi.org/10.1090/S0002-9947-2013-05804-7). The construction here handles multiple support points in a row or column, finite vector charges, and the cumulative values needed for physical interval contraction.

Use the rectangular prefix matrix of physical-grid-prefix-patterns.md. Give every row band and column band a direction so the support events in each occupied cell can be read along the chosen directions of both its axes. Each cell imposes only a relative sign; on a forest propagate signs from an arbitrary root. A chain with only one direction nonconstant allows either compatible choice on the constant axis.

In an occupied cell arrange its events in this joint order. A cut after physical index i of either axis defines a threshold t: if the direction is increasing, count events with index ≤i; if decreasing, count events with index >i. These counted events form an initial interval in the chosen order. Decorate that cut's token with the XOR up to this threshold. A single token has one such register for each incident cell, a bounded number. Record each whole cell's total as finite global data. For each cell interleave its two band token sequences by their thresholds, keeping the chosen axis order on ties. The two sequences are the respective band subsequences of this merged word. Amalgamate all the cell words into one word: as one adds a leaf band in a tree component, its cell word overlaps the existing one only on the complete identical ordered sequence of its neighbor band. Interleave the other tokens inside the intervening gaps. Disconnected components can be concatenated.

Two cut tokens suffice to decode a prefix matrix entry. Earlier row and column bands contribute each cell's full total; a cell in a later band contributes zero if excluded on either axis. If only one cut is internal to a cell use its unary register, complemented by the cell total for a suffix. When both cuts belong to the same cell, each admitted part of the event list is a prefix or suffix, according to the chosen direction. The two thresholds are ordered by the positions of their tokens in the master word. Thus the XOR of the intersection is known from the two register values and the cell total (two prefixes use the earlier register; a prefix and suffix use their difference if they overlap). An equal-threshold tie gives the same value under either order. Sum the cell contributions. Extra charges on exceptional rows or columns give bounded-rank bit matrices, whose prefix features can be appended to the same tokens as in physical-grid-matrix-rank.md.

The finite token alphabet records the band of each index, both endpoint cuts, band-boundary cuts, and the cuts straddling each port. Cut index zero can be marked separately as it has identically zero prefix. A band's subsequence runs in its designated direction; physical global row or column order is recovered by orienting each band's subsequence and concatenating the indexed bands. Consequently Higman subsequence comparability gives actual order-respecting rectangular contractions with identical prefix entries, despite possible interleaving or reversal of distinct bands. Greedily test adjacent within-band full-axis contractions, keeping port positions and exceptional singleton axes distinct. The inherited decoder still works on any selected submatrix. Table monotonicity and the fixed-alphabet well-quasi-order give bounded output as in physical-grid-matrix-rank.md. No long interface is discarded or independently summarized.

More generally, the forest hypothesis can be replaced by a checkable compatible ordering certificate. Try the finitely many band directions; for each compatible choice order the tokens within each band and impose cross-axis precedence whenever one incident cell threshold is strictly smaller than the other. If these constraints admit a topological ordering, use it as the master word. This includes some cyclic occupied-cell patterns. Failure of this sufficient test is not a lower bound on physical minors.

The checker independently compares both cumulative evaluations at 23,022 pairs of cut positions from 160 labelled forest layouts, including tied physical coordinates and mixed orientations.
