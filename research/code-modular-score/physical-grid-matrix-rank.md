# Physical rectangular reductions from bounded charge-matrix rank

Let a complete n by m grid carry h binary augmented demand bits, with b protected labelled ports at supplied vertices. For fixed h,b,R, suppose each of the h binary coordinate matrices of the vertex charges has rank at most R (ordinary binary matrix rank, not the dimension of the charge-vector span). There is a polynomial algorithm for fixed parameters constructing a grid minor preserving the complete augmented kernel table whose size is bounded in h,b,R. The proof gives a finite bound and does not assert a uniform computable numerical bound.

Factor each coordinate matrix over F₂ as an n by R matrix times an R by m matrix, padding by zero positions. Concatenate the h row factor vectors to give a row feature a_i of length hR, and similarly a column feature b_j. One fixed bilinear map B outputs the h blockwise dot products. Thus λ(i,j)=B(a_i,b_j). For consecutive row and column intervals I,J the total charge in their Cartesian branch set is B(XOR_{i∈I}a_i,XOR_{j∈J}b_j). Contracting adjacent complete rows or columns therefore yields a physical grid minor, with every charge pushed onto its rectangular branch set and parallel edges simplified.

On each axis write the sequence of all prefix sums of its feature word, including the initial zero and final total. Mark the two endpoints and the cuts immediately before and after each protected port row, combining tags at coincident cuts. Use distinct tags per port index and do the same for columns. These are finite alphabets at fixed h,b,R. Higman's subsequence lemma for finite labelled words and the product well-quasi-order imply that in any infinite sequence of such grids, for some earlier and later grid the earlier pair of decorated prefix words occurs as subsequences of the later pair. Endpoints and all distinguished cuts match. Taking differences of successive matched prefixes gives the features of the smaller grid as sums on consecutive nonempty intervals of the larger one. Adjacent tags around each port force its row and column to remain singleton at the corresponding labelled locations. Bilinearity gives exactly the smaller charge at each matched grid position. Thus the marked grids in this class are well-quasi-ordered under these conservative rectangular contractions.

Compute the full table by planar dual routing. Greedily contract one pair of adjacent rows or columns, preserving the table and leaving every port row and column untouched, until no such step exists. The algorithm uses polynomially many table queries. The bit matrix ranks cannot increase under interval aggregation. Any strict rectangular contraction preserving protected axes factors into allowed elementary contractions. The attainable kernel families shrink monotonically along these physical minors, so equal tables at the two endpoints force every intermediate table to agree. Since there are finitely many possible tables for h coefficients, unbounded greedy outputs would yield infinitely many pairwise incomparable marked grids in one table class. This contradicts the preceding well-quasi-order argument. Physical branch sets and port tags give traceback and permit arbitrary exterior gluing.

In particular apply both scans of square-grid-charge-combs.md. When EVERY intersection of the certified row and column spans vanishes on the residual rectangular arrangement, all labels are supported on f exceptional rows and g exceptional columns, f+g bounded in h. Every bit matrix has rank at most f+g: keep its exceptional rows as one summand and leave a second supported on at most g columns. Thus this entire failure branch admits bounded connected physical grid minors despite arbitrary interface lengths.

This rank bound does not follow from one-dimensional residual charge spans. For even n put bit e1 on (i,i) for 3≤i≤n−2 and bit e2 at opposite corners. Both demands are even and independent, both scans fail, and the bulk contains an identity submatrix of unbounded rank in its one-dimensional charge span.
