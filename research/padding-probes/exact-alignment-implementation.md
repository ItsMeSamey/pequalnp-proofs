stack_align_pins.py normalizes all unary occurrence pins to signed underlying values before traversal. Conflicting values make an empty chart. The computed chart has no other filter. Every surviving canonical prefix consistent with the signed aliases can be completed by choosing arbitrary unbound IDs and copying their normalized signs.

stack_align_exact.py stores the current logical alias top in finite control, separately from the physical stack top; marked frames save the prior logical top. It checks the normalized close bit before classifying a stack mismatch. An unaligned verdict includes a completed raw word replayed to its first bad edge. The universal pass does not stop when two outputs have been found. Exhaustively explored empty fibers are vacuously synchronized. A cap can return unknown. Pin normalization, table validation, all saturation/graph operations, completion, byte parsing, replay and any external callback must be charged separately; caps cover the recorded search work only. The earlier stack_align.py uses conservative recognition. Neither an arbitrary filtered DAG nor an external black-box heuristic inherits the exact canonical recognition guarantee.
