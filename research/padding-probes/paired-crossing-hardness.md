# Two uses per alias suffice for fixed-DFA disagreement

Start with m strict 3-clauses. For each occurring source variable v having r occurrences, make distinct occurrence IDs x₁,…,xᵣ and distinct link IDs c₀,…,cᵣ, all private to v. Emit the r equality triples (c_{j−1},x_j,c_j), meaning that all three bits must agree. The two end links are distinct even when r=1. Taken together these tests force exactly the common truth value of v on its occurrence IDs, and either value extends uniquely through its links. The total number of equality triples is 3m.

Form m OR triples from the occurrence IDs in the source clause order, negating the appropriate signed aliases. Append 2m dummy OR triples, each using three fresh positive one-use IDs, disjoint across dummies. They can always be satisfied; equality to a constant is unnecessary. Interleave the 3m equality triples with these 3m OR triples in any respective fixed orders, equality first in every pair. Append one fresh enable bit. Every occurrence ID now appears exactly twice, every internal link twice, each end link once, and every dummy or enable ID once. The order may have unrestricted crossings. The compact input is polynomial, and each raw word is the actual empty-challenge codec output with n=18m: the DIMACS header has 72m+6 declared variables and 18m+9 clauses, including the eight immutable contradiction clauses. All physical words therefore encode unsatisfiable CNFs.

A single fixed byte DFA skips the header and the eight contradiction lines and records one bit per later marker, from whether its first byte is minus. At completed groups of three it alternately checks all-equality and ordinary OR. It remembers the conjunction of checks already completed. At a terminal line boundary it accepts precisely when those checks passed, it expects an equality triple next, and it has consumed exactly one bit of that would-be triple with value one (the enable). This is finite control independent of the source size. Equivalently, postpone each test until all three bits arrive; no end-of-input lookahead or extra delimiter is needed. The signed literal offset changes only a marker's bit, not the scanner.

The common assignment to a positive word's occurrence IDs satisfies every source clause. Conversely each satisfying source assignment extends to a positive word by setting its links to the same values, all dummy bits true and the enable true. The zero-enable slice always supplies a negative word. Disagreement is thus NP-hard already with alias multiplicity at most two and a fixed DFA; guessing two words via consistent alias assignments gives NP membership. A witnessed disagreement yields a source SAT witness by choosing its positive side and decoding one occurrence per variable. For example, on three distinct variables take all eight strict clauses, one forbidding each of the eight assignments. This source has no satisfying coloring of the eight clause truth requirements, so every attainable word has output zero despite both signs being available for each individual occurrence. With disjoint fresh dummy triples, there are 7^{2m} choices of dummy bits per satisfying assignment and unique link and enable extensions. Thus decision and witness projection survive; raw positive-word counts include this factor (and omit unused original variables).

The separate two-occurrence safe-path theorem uses paired controls in a reversible switching network and asks whether two marked tracks share a trajectory. Here the machine is fixed and reads canonical CNF bytes, paired aliases communicate the choices, and the target is disagreement. Neither construction supplies the other's encoding or implies hardness for noncrossing pairs or charts of bounded live width.
