# Decision on the normalized paired chart

stage6_normalized_solver.solve accepts the frozen solver's source and budget arguments. Every physical call fixes the underlying IDs in compile_source(...).dummy_bits in addition to the source anchor pins. For m prepared clauses the open construction fixes all 6m independent dummy IDs to one. The cyclic construction fixes 2m d IDs and m f IDs to zero; each signed dummy triple reads (0,1,0). The enable bit remains free.

Each satisfying assignment to the occurring source variables determines every occurrence bit. Equality along its open chain or closed ring fixes every link bit, including a singleton closed ring. The positive predictor requires enable one, and all dummy choices are fixed. Thus each satisfying assignment on occurring variables has exactly one normalized positive physical word. Every positive word conversely projects to that assignment. Setting enable zero always gives a negative anchor on a consistent pinned chart. Unpinned inactive source variables have no physical representation and each contributes a factor two when converting a physical count to a full source model count. This decision function does not report model counts.

Physical replay checks the dummy values as well as the original table, signs, CNF and source pins. sparse_witness is a sorted tuple of true one-based source IDs, with unlisted bits zero. It supplements the packed mask and does not remove that mask's bit-length cost. dummy_pins counts the normalized IDs. Earlier freezes are untouched. Structural bounds for a pinned residual apply under their own eligibility and codebook hypotheses; refusal of a solver branch is not a lower bound on every backend.
