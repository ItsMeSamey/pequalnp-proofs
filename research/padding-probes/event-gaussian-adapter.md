# Physical Gaussian solver interface

The public function is event_gaussian_solver.solve. Supply the same native canonical challenge, aliases, real-time byte table, state, bottom symbol, outputs, backend selection and signed pins used by event_auto.solve. Choose raw byte events or whole-marker macro events explicitly. Schedule refusal gives unknown. A macro schedule refers to the first byte of each marker while a raw schedule refers to absolute byte positions. No hidden raw fallback occurs.

Codebooks may be supplied as a partial per-vertex mapping, or as a factory receiving a read-only view with domains, constraint relations, event edges, slot indices and the output index. The factory receives the unpinned record universe so it can use machine meanings and the actual source-specific record fields. It may capture data from the caller, including pins. Entries are injective nonnegative integers per vertex. The generic backend enforces coverage of surviving records for each supplied vertex. Codes for original records subsequently removed by pins are retained in the width accounting. Unspecified vertices use the core's default enumeration. With set-derived record domains the default numbering should not be assumed to be a cross-process canonical chart. Solutions and replayed physical values remain valid across charts; whether a limited omission budget suffices may vary.

The local relation on each scope is represented by its affine hull and the explicitly budgeted missing points inside that hull. The exception cap is a recognition/search parameter, not permission to accept a relaxation. The branch cap belongs to the global exact exception search. An exhausted budget may give unknown. With supplied codebooks no search over all input encodings or proof of a minimal-exception chart is implicit. Charge a factory's actual runtime, reading the codes and their full bit lengths, validating injectivity, copying/validating the table, actual raw or macro construction (including rejected schedules), explicit materialization and filtering of record pairs, Gaussian bit operations, excluded-point generation within the core cap, and both independent physical witness replays. Branch caps do not bound this preprocessing. The adapter reports compiler and Gaussian metrics separately from codes supplied and maximum supplied bit length. An early refusal's zero counts refer to uncompleted stages.

On each returned original-record witness, reconstruct a canonical byte word, reparse the challenge and signed repeated IDs, check pins, and execute the original stack machine again with its true initial state and bottom symbol. The emitted sample contains the physical bytes, packed key, underlying assignment and prediction. Mathematically inconsistent pins on a successfully compiled chart give empty. A one-output result certifies constancy only if the complete backend search proves the other output unattainable.
