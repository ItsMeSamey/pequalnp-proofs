# Compressed-count and projected-decision physical interfaces

Both public functions accept the existing raw/macro backend, schedule, signed occurrence and ID pins, and optional per-variable codebooks or a factory on an unpinned read-only event view. Neither recognizes all possible codebooks. Supplying large binary codes or a costly factory changes preprocessing time independently of the search caps. Singleton domains after pinning retain the supplied code-width convention. Schedule rejection returns unknown. Each returned witness is decoded into canonical raw bytes and checked against the original aliases, pins and machine output.

event_compressed_solver.solve calls event_compressed_ie.solve with omission_cap, state_cap and work_cap. These optional nonnegative budgets respectively limit the sum of local holes, the compressed dictionary size during construction, and counted intersection/count work including prefix recovery. Charge separate costs for generating the original relations, computing affine hulls and codebooks, bit operations in each Gaussian meet, integer coefficient accumulation, reconstruction and replay. The generic layer returns original record assignments and catches low-level caps, including construction-time cap metrics. For complete results the physical layer verifies both the positive support and the total number of canonical words across the two output classes. event-ie-physical-counts.md proves the needed word/record bijection. No counts are reported for unknown.

event_flat_solver.solve calls event_affine_flat.solve with omission_cap, dimension_cap and max_flat_rank (default two). This is a decision/witness interface; it does not extrapolate projection witnesses to source counts. Polynomial paired-literal recognition and any fallback enumeration should be charged under the generic core's own metrics and eligibility rules. Original code records are reconstructed and replayed on every reported output. A success on one core or chart does not imply eligibility for the other. Earlier executable files remain frozen.
