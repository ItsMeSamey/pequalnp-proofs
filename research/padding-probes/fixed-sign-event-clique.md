# A fixed raw-byte predictor with unbounded event treewidth

For every t≥5, use the header, two clauses (1,−2,3),(−1,2,n), eight contradiction clauses and signed key slots emitted by padding_cnf. Every raw file encodes an unsatisfiable carrier. The response discussed below is produced by a supplied fixed deterministic byte machine.

The primary machine has eight states. It stores a line-start flag, the parity of the zero-based line index, and a running bit initialized to zero. On a minus sign at the beginning of an odd-indexed line it toggles the running bit. LF advances the line index and restores the start flag; every other byte clears that flag. Output is the running bit. This specifies a total function on all bytes, and its table is independent of t.

Write E=binom(t,2). Each edge uv of K_t, u<v, owns two logical IDs e and f. In vertex u's consecutive block place +e,+f for this edge, and in vertex v's block place −f,−e. The order of neighboring vertices in each block is increasing. Each ID occurs exactly twice and each vertex block has even length. A final singleton is the enable key slot. Header and challenge occupy lines 0,1,2. The second challenge clause begins with minus on line 2. The contradiction occupies lines 3 through 10, negative first literal exactly on lines 4,6,8,10. Thus the fixed prefix contributes zero. The first marker starts on line 11 and the enable starts on line 11+4E, so both are watched.

Each edge contributes the first sign of its earlier pair and the first sign of its later pair, namely z_e and 1 XOR z_f. The original predictor output is therefore the parity of E, enable and every logical edge variable. Pin enable to one and the negative later copy of edge 01's primary ID to physical zero. This fixes z_01 to one, leaving 2E−1 free logical bits, every one of which changes the result. Each output occurs on exactly 2^(2E−2) original physical keys. In particular t=5 gives 262144 per output.

The contiguous slot blocks give disjoint connected branch sets. Either ID link for each uv joins the two branch sets, giving a K_t minor and treewidth at least t−1. The same contraction works after expanding slots to their consecutive byte intervals. At a fixed raw event, canonical bytes determine the line-start and line-index flags independently of the bit choices; both spellings have the same length, LF positions and line boundaries. The incoming parity and current marker bit uniquely determine the event record (prefix records are fixed). Within a marker its sign choice repeats. Successive parity bits obey an affine update and opposite-polarity aliases obey a complemented equality. Every relevant domain and adjacent joint relation is therefore affine in those two coordinates, including after pin restrictions. The same argument applies to macro records spanning a full line.

An alternative four-state machine watches every line, omitting the line-index bit. Use +e,+e within the earlier vertex block and −e in the later block. Each edge contributes 1 XOR z_e. The prefix contributes one and the pinned enable contributes one. With z_01=1 pinned there are E−1 free variables, giving 2^(E−2) keys per output. Consecutive alias links still cross between blocks. Both physical variants are generated by stage4_fixed_event.py (5cd2c55d); the original Stage4 sources are separate.
