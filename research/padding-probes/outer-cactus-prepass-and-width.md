# Initial recognizers on the actual outer cactus source

Use the literal edge-variable CNF F of the common-source paper: one positive incident-edge star per vertex of the cactus, one binary negative conflict per pair of its incident edges, and one positive marked demand per original row of the inner source Q. The cactus is simple, has minimum degree two and has a degree-three vertex. Every edge variable occurs with each sign. The initial formula has no units and is not binary. At a degree-three vertex, a Horn renaming of the positive star requires at least two incident variables to be flipped. Each incident negative conflict forbids flipping both its variables. No such renaming exists. Thus the Stage7 unit/pure plus binary/renamable-Horn source prepass returns UNKNOWN. The zero assignment violates a star and the all-one assignment violates a conflict.

There is also an obstruction to the original physical width-three branch. In the incidence graph of F, for each phase ring collect its own cycle-edge variables and the negative conflict nodes joining consecutive cycle edges. These are connected, disjoint branch sets independent of any bridge. Contract them, keep one distinct marked-demand node per row of Q, and discard unneeded structure: the resulting graph contains Inc(Q). For the private guard construction, each original graph edge uv has a private variable a_e in a row guarded at u and another row guarded at v. Choose these two distinct rows. The path x_u–row_u–a_e–row_v–x_v has interiors disjoint across graph edges, so the host graph G is a minor of Inc(Q). Finally, in the uncompacted or macro fixed-DFA physical graph, collect each equality triple as a connected path of sites and connect the equality triples for a source variable of F using its private link edges. The real OR triples give separate connected branch sets for the F clauses; matched occurrence edges connect variable and clause branch sets. Padding a short clause by repeating a literal only adds occurrences. The raw byte graph contracts internally to the marker graph. These facts show G is a minor of the original paired physical event graph. Hosts of unbounded treewidth therefore exclude any certificate of width at most three, including the per-block apex-deletion recognizer.

The graph result concerns the archived original physical compiler and its graph-retaining pins; more general coalescence, elimination of irrelevant factors, semantic projection, guessing a model early, or other algorithms can change the situation. Fixed-DFA normal-rank and rectangle proofs elsewhere additionally require a feasible core for their positive sections. These facts do not lower-bound running time of the entire portfolio or show a separation of complexity classes.
