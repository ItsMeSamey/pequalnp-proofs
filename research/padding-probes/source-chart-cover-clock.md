# Sparse chart recognition before complete source search

source_chart_cover_portfolio.solve accepts signed clauses of width at most three, its declared arity in binary, and the Stage 7 keyword options. Clause and pin iterators are materialized once. Well-formed pins become additional unit clauses only for the chart call. All GS masks use dense indices for occurring or pinned labels; the sparse front end never constructs a word of the binary declared arity. Its normal imports require the sibling pnp-general-separation directory in addition to the Stage 7 module paths.

A GS zero result is an exact UNSAT certificate. A GS unknown result makes one ordinary Stage 7 invocation with the original rows, pins, stages and cap. A GS nonzero result is checked on the original rows and pins. All appearing or pinned original names, including names assigned zero, then become pins for one replay invocation. Unit/pure simplification removes every satisfied clause under this full pinning. The replay call uses prepass=True, stages=(), node_cap=0 and must return the same sparse true names and original verified physical bytes. Other declared names remain false. No broad search is required to validate the chart's SAT result.

The GS call is polynomial in the explicit source encoding length L here. Every local scope and each projected forbidden relation has rank at most three (including the added units), so its local cube has at most eight words. Each successful Gaussian closure pass increases global rank, and the binary cover search considers at most quadratically many chosen coordinate pairs per scope with constant-sized local pattern enumeration. Gaussian operations, the final binary solver, sparse source validation and fully pinned physical replay are polynomial in L. An unsuccessful chart adds this polynomial cost to Stage 7, preserving its default complete bound poly(L) (3/2)^v 2^O(v loglog(v+2)/log(v+2)) and polynomial space, with v and custom budget caveats as in source-cover-portfolio-clock.md. A user node cap can still yield UNKNOWN. Pin replay is charged separately and does not silently consume the caller's cover-node budget.
