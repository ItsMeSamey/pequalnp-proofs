event_solver.solve takes the actual physical challenge, signed marker aliases, predictor transition table and terminal outputs, plus a supplied set of bags and tree edges. The schedule of byte-level push, pop and stay operations can be supplied or inferred. Before pin filtering, a forward control/top approximation must identify a common operation at each byte. Failure gives unknown; the method does not choose a favorable run or search for an unrestricted decomposition.

Each byte record includes the physical byte and marker choice, and the control and top before and after the transition. Within one marker line, path relations propagate the same sign choice. Consecutive occurrences of each underlying ID are linked with offset-corrected equality. A long constraint equates the pre-push top to the post-pop top at its matching return. A terminal bit is attached to the terminal control. The solver checks the bag tree, variable and relation coverage, and connectedness of each variable’s bag occurrences. It reconstructs a full assignment per attainable bit, decodes its original bytes, verifies actual aliases and pins, and replays the original full-stack predictor. No external predictor equivalence or guaranteed generically small width is assumed.

Let D be the largest record domain size, T the bag count and w the actual verified width. The bag stage tries at most T D^(w+1) rows, with indexed separator projections. Charge source compilation, explicit candidate relation-pair tests and retained pairs, bag checks, enumeration, traceback, original bytes and physical callbacks. The wrapper reports maximum domains before/after pins, record totals, alternative pairs tested/stored, width and bag counters. Its optional caps cover bag evaluation, not compilation. Bounded-width finite-domain CSP is classical [Freuder](https://cdn.aaai.org/AAAI/1990/AAAI90-001.pdf).

The fixture-specific decompositions cover the whole event graph in the stated supplied byte order. A bounded-degree expander is a minor of another valid compact slot path plus two-occurrence alias links: group the incident occurrences contiguously by vertex, connect the two slots of each edge, and contract vertex blocks. Consequently width can grow linearly in the number of slots even for an idle predictor. This does not imply computational hardness on that one-state example; the separate fixed-DFA hardness applies without any bounded-width promise.
