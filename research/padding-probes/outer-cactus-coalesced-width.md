# Width after coalescing positive equality-chain aliases

On the ordered private-guard source Q and its literal outer cactus F, the coalesced event compiler still has the graph host G as a minor. For each edge variable of F all equality-chain, link and real OR occurrences now bear a single signed anchor ID. Consecutive occurrences of that ID are linked by physical alias constraints. Thus all sites of that variable, including real OR sites, form a connected branch set disjoint from the other variables' sites. Consecutive positions of each real OR triple are adjacent on the time path. Contracting the variable branch sets therefore gives an edge between successive distinct variables in every row of F. For a padded binary conflict the order is (a,b,b), so a and b remain adjacent.

Contract each inner phase ring using the adjacencies supplied by negative structural conflicts between successive cycle edges. Each marked demand in F is an ordered row of Q: hence the resulting graph contains adjacencies between successive phase variables in that row. Choose for each graph edge the two guard rows (−a_e,b_e,−x_u) and (a_e,−b_e,−x_v). Their middle private variable b_e gives the path x_u–b_e–x_v. The interiors are disjoint across graph edges. The unbounded treewidth of an expander host G excludes a width-three certificate in this coalesced event graph as well. Raw byte paths contract within sites. Filtering pins while retaining declared edges does not change the proof.

This relies on the specified marked literal order and the actual graph-retaining coalesced compiler. It does not apply to the separately projected positive semantic factors, arbitrary row reorderings without a new proof, or preprocessing that deletes these vertices and edges.

The two special private rows admit an order-independent extension. If both graph endpoints occur in the middle of their own rows, they are each adjacent to a_e. Otherwise in at least one row the two private variables are consecutive, making {a_e,b_e} connected. In both rows their respective graph endpoint is adjacent to at least one private variable. This supplies the same host edge minor under any separate permutations of those two rows. The argument is about the named private scopes; it does not permit arbitrary semantic rewriting of the rows.
