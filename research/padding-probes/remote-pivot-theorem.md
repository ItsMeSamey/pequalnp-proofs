# Remote pivots for original ternary clauses

Write F = B ∧ C₁ ∧ … ∧ Cₘ after removing tautologies and repeated literals. B contains the original units, binary clauses and pins. Number only the v occurring source identifiers densely internally, and decode returned assignments on the original sparse identifiers. An unused variable can be fixed to zero.

For C=(l₁∨l₂∨l₃), take D equal to B alone or B with one original pivot pinned. For i=1,2,3 test the singleton assignment on the scope making exactly lᵢ true, using a pinned 2SAT call on D. If the i-th test is infeasible, C and the binary clause obtained by dropping lᵢ agree on every model of D. Conversely, if all singleton tests have full witnesses, the coordinatewise majority of those three witnesses satisfies D (each binary clause is majority-closed), and falsifies C. Hence D∧C is not majority-closed and has no exact binary representation, even after existentially quantifying additional Boolean variables (projection preserves majority). This argument needs a bijunctive background. For example, on three variables the nonbinary background “exactly one true” realizes all three singletons and entails their disjunction.

Resolve every row reducible under B alone. For each remaining clause C find every occurring pivot w for which both pins yield binary replacements. Each name in C qualifies, and names elsewhere may also qualify. Pick a cover of the remaining clauses by pivot names and assign each covered clause to one such pivot. For every word on the h selected names form a 2CNF with the ORIGINAL common B, the word's units, and the selected replacements under those pins. All replacements agree pointwise with their original clauses on the same pinned B. Their conjunction is exact even when scopes overlap or pivots occur in other clauses. A satisfying assignment lifts directly, while UNSAT requires exhausting every branch. Budget exhaustion can return UNKNOWN. Join feasibility matters: e.g. individually satisfiable residual rows (x) and (¬x) have no joint model.

The basic complete candidate table requires at most 3m+6mv pinned 2SAT checks. Deterministic sorted-ID compression, graph construction, greedy coverage and replay have polynomial bit cost in encoded source length L; each selected branch costs one further 2SAT call plus verification. Thus full search is polynomial preprocessing plus O(2^h poly(L)), with polynomial working space. No bound of h by the OPTIMUM is presumed; greedy Set Cover gives the standard harmonic approximation. A direct exhaustive fallback remains available to a caller.

## Exact optimization barrier

Take a Set Cover instance on elements i with sets S_j whose union is the universe. Use private ternaries (a_i∨b_i∨c_i), and for each incidence i∈S_j add (¬q_j∨¬a_i) and (q_j∨¬b_i). All formulas have a model with all c_i true and all other private variables false. Every incident q_j resolves that element, as do its three original variables. For a nonincident q_j either chosen pin extends each singleton on i: set incident q's all zero for a_i alone, all one for b_i alone, and arbitrarily for c_i alone. All private variables elsewhere may stay false. For any name of a different private triple, its zero pin gives the same three extensions, so it cannot resolve i. Each private pivot can be replaced by an arbitrary set containing its single element. The minimum resolving pivot count is therefore precisely the minimum set-cover size. The usual W[2]-hardness of Set Cover parameterized by solution size transfers to this particular optimization problem on always-satisfiable inputs. It gives no decision lower bound for these formulas.

For one single set containing all m elements the incidence graph is connected and one remote pivot resolves all m disjoint clauses. A syntactic backdoor hitting every ternary variable scope needs m variables. These example formulas are otherwise easy (their all-c_i-true assignment is explicit), so the separation concerns the two backdoor parameters.

## Faster shared reachability calculation

For a satisfiable 2CNF, any inconsistent family of pinned unit literals contains an inconsistent singleton or pair. This follows either by pairwise existential projection of the majority-closed model set or by implication-graph reachability: inconsistent implications from pins p,q give p→z, q→¬z, hence p→¬q. After the three initial tests on an unresolved clause, each singleton sign word extends B. For a feasible pivot literal p, a singleton word stops extending precisely when its three prescribed literals include a literal l for which p reaches ¬l in the implication graph. An infeasible pivot literal makes every singleton unavailable. One traversal per signed pivot followed by scanning the three local words for every unresolved clause thus suffices: O(v(v+|B|)+vm+m(v+|B|)) indexed operations for the tests including initial per-clause 2SAT checks; RAM for one traversal plus the recorded incidence table suffices. For infeasible p in a branch any replacement may be chosen. This is an optional construction; use the executed checker's stated backend when reporting measurements.
