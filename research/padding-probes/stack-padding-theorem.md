# Finding disagreement by parsing the original physical predictions

A linear-size acyclic byte graph describes all DIMACS strings on one fixed marker fiber. Emit the immutable prefix, fork on each entire legal marker spelling, and rejoin after that clause. Independent sign decisions within one marker would admit invalid strings. The white-box heuristic is an explicit complete deterministic real-time pushdown transition table consuming these bytes. Its initial control and bottom symbol are specified. Rules depend only on control, byte and top; replace the top by at most two symbols, preserve bottom under normal transitions, and output a bit determined by terminal control even if stack symbols remain. Checking the finite table's totality, determinism and format is part of the work. There is no equivalence promise when the supplied transition table is itself the executed predictor.

For each outcome take the product of finite control with byte graph position. Only at the final position may a control giving the required bit drain its remaining stack, including bottom. A summary (p,A,q) records a path from paired state p at top A to q after removing A, without disturbing its suffix. Immediate pops seed facts. Replacement by B depends on one child fact. Replacement by BC depends on two facts sharing the intermediate control at which B has been removed. Finite monotone saturation computes the least fixed point. Induction on path lengths and derivation heights gives soundness and completeness. Save the first successful derivation and recover original bytes, ignoring artificial drains. Raw paths have length at most V−1 on a V-vertex acyclic byte graph; push length at most two makes even the expanded accepting derivation length polynomial in V (each original transition consumes one byte, final drain removes at most V+1 stack cells). Replay both physical words and compare predictions. If one result alone is attainable, its bit is constant on the nonempty fiber. Report an empty fiber separately from incomplete resource-capped search. A table claimed to model an external black-box routine requires independent equivalence evidence before inferring constancy of that routine.

With N reachable product control/vertex pairs, stack alphabet Γ and M_i product rules replacing a stack symbol with i symbols, at most |Γ|N² facts and M_0+M_1 N+M_2 N² fully instantiated Horn rules exist. Indexed joins or straightforward polynomial fixed point suffice; explicit bit cost includes graph construction, rule checks, pointer sizes, successful/unsuccessful joins and witness replay. Standard normalized context-free reachability also yields O(gV³) word operations for grammar size g and separately charged conversion. This is an application of classical context-free reachability, not a new generic parsing bound. [Yannakakis](https://doi.org/10.1145/298514.298576) and [Chistikov et al.](https://arxiv.org/abs/2102.13095).

For a quantitative control on the original DIMACS sign-marker scheme, take n input pairs (a_i,b_i), followed by n bits y_j in the order requiring y_{n+1−i}=NAND(a_i,b_i), and the final enable bit. Encode each NAND relation as four 3-clauses, one per forbidden triple. A pushdown predictor on the actual markers pushes one NAND result per pair, then compares and pops the expected bits. All 2^n stacks are reachable and require distinct y suffixes, so deterministic finite-state reading in the specified order needs width at least 2^n. Each local Boolean indicator is (1−χ_y (−1)^{ab})/2, with five nonzero real Walsh frequencies on distinct characters; consequently the enabled-slice spectrum has size 5^n. Disagreement density from a zero anchor is 2^(−n) on the enabled slice; a nonzero degree-d Boolean-cube polynomial has support density at least 2^(−d), so any supported certificate has d≥n. Enabling contributes one additional linear support constraint on the full physical key. The natural monotone clause presentation includes both polarities of a raw variable, making both uniform observation endpoints infeasible even after invertible affine recoding. These bounds are on the physical read order, sparse spectrum, support degree and the supplied clause representation. They do not rule out a different monotone DAG optimized for this function, nor a different program for finding one error. Positive physical predictions are false positives because of the immutable contradiction block. No general SAT refuter follows.

On the enabled slice, the exact cover number of the NAND graph by affine flats is 2^n, even allowing overlaps and arbitrary invertible affine recoding. On a contained affine flat the mixed second difference of ab in any two directions must vanish because the output coordinate is affine. Thus each (a_i,b_i) projection has rank at most one. Joint projection to all inputs is injective on the graph, so each contained flat has dimension at most n; 4^n accepted input words require at least 2^n flats. Fixing all a_i attains this bound. This is a cover result; it does not preclude a two-point existential certificate.

The native implementation factors the saturation differently from the textbook grammar conversion. It indexes reachable frame entries (v,p,A), local paths within each such frame, pop-return summaries, and child/caller waiters. New return facts join old waiters and new waiters join old return facts, including after the child was previously explored. A concrete prefix for each entry suffices to witness every reachable terminal state at any stack depth. If C entries are reached and N=|V||Q|, storing O(CN+C²) summaries/waiters, scanning O(C|Q||E|) potential transitions, and O(C²N) return joins suffice besides preprocessing and replay. Dictionary operations use expected word-RAM lookup cost; deterministic polynomial bounds remain with conservative linear dictionary costs or balanced maps. Actual resource caps abstain; the constant-output flag requires treating the supplied machine as the true predictor. No compact translation of general SAT heuristics into this class is assumed.

Native scope: table validation covers every graph byte for all declared controls/top symbols. Rejecting defaults extend it to all other bytes. The implementation admits stay, push one preserving the former top, and pop a non-bottom symbol. When no external callback is supplied, a native sample records the derived terminal output without separately running the table again. The independent checker performs replay. An optional callback checks sampled words only. Constancy requires promised=True in the API even if the table defines prediction. Saturation caps exclude input validation, flattening and callback execution, all of which must be separately charged.

## Distant repeated key identifiers

The base canonical graph forks once per independent logical marker. It is not an exact graph for an input chart that binds several distant markers to one signed ID. The alias_dag successor fixes the physical marker order and tracks values of all IDs occurring both before and after each cut. At the first occurrence it chooses a value, subsequent choices are forced after applying each occurrence's sign or offset, and the last use forgets the stored value. Every label branch writes a whole marker line. Thus a path is exactly a byte encoding of a consistent underlying assignment, and every assignment yields such a path. decode_alias checks every sign occurrence against the full parsed bytes and reports both underlying assignment and actual physical key; inconsistent repeats reject. The expanded graph has O(L 2^b) edges, where b is the maximum number of live repeated IDs across cuts, and L bounds the encoded base byte length. Compilation and subsequent pushdown saturation must be charged at this expanded size. For first occurrences of b distinct IDs followed by their repeats, at least 2^b middle vertices are necessary even for a nondeterministic acyclic byte DAG: sharing one vertex on paths for different values permits an invalid splice. This lower bound is for the specified physical order. It does not rule out a different representation that tracks equalities outside the byte graph.
