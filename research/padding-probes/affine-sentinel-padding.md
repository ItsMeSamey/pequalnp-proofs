# What decision-preserving padding detects about a semantic affine-flat heuristic

For a satisfiable relation S on N supplied free Boolean coordinates let c(S)=N−max{dim W: W affine, W⊆S}. Take c(empty)=infinity. For fixed R≥0 let D_R accept iff c(S)≤R. On an explicitly given conjunction of affine exclusions of rank ≤w this is decidable in (2^w−1)^R poly(input,R) time for w≥2. Starting in the supplied ambient space, skip exclusions disjoint from the current flat V; if all are skipped accept. For one remaining exclusion, its bad observation point lies in the affine image of V. If the image has dimension zero the whole V is forbidden. Otherwise any sought nonempty flat W⊆V avoids that point iff some nonconstant linear functional on the image takes throughout W the bit opposite its value there. This follows by translating the affine image of W and separating the missing point from the resulting linear span. Enumerate at most 2^w−1 such hyperplanes; restricting V consumes exactly one codimension. At exhausted budget, return NO if any exclusion still meets V. Each step is Gaussian arithmetic, with no semantic-hull recognition assumed. For w=1 the equation system is directly Gaussian. This is a semantic yes-certificate algorithm for SAT and an exact decision algorithm for the stated bounded-codimension property.

Invertible affine changes, equivalent presentations on the same named space, and free variable factors preserve c. Any finite fixed suite of sentinels is answered correctly by taking R at least their largest arity. The satisfiable conjunction of m disjoint NAND clauses has c=m: every satisfying affine flat projects into a proper affine subspace on each pair, hence has total dimension ≤m; equality is attained by setting one variable in every pair to zero.

A different closure rule holds for decision-preserving products. For arbitrary nonempty relations c(S×T)=c(S)+c(T). Project a contained affine flat onto the two shores for the lower bound on codimension, and take products of largest flats for equality. A single strict 3-clause omits one point; c=1, since its relation is proper yet contains an affine hyperplane. Adding b disjoint signed strict clauses on fresh triples therefore raises c by exactly b independent of the signs. D_R gives identical answers across all keys in such an equal-size fiber. Comparing the base to fibers of growing size can expose an error: start at the true empty carrier; try b=1,2,4,..., each time with an explicit all-true satisfying assignment for positive clauses. The first NO is a certified false negative and occurs by b<2(R+1), with O(log(R+2)) physical calls and O((R+1)log(R+2)) total printed size by geometric growth. Every predictor that restricts all YES answers to c≤R is caught, even if R is not supplied; prediction clocks must be added. In contrast, the status-preserving products are not affine recodings or free-coordinate paddings. This is a refuter for the specified family of heuristics only.
