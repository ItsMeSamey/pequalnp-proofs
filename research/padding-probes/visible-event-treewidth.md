# Exact disagreement on a bounded-width graph of physical events

Consider a fixed canonical DIMACS fiber with two possible complete spellings for each sign marker, a fixed header and immutable contradiction clauses. Some markers are bound, with specified offsets, to the same physical Boolean ID. The predictor is its actual explicit finite-control stack transition table, not a substitute fitted on observed words. This method finds legal words for both terminal predictions or proves which predictions are absent on the fiber. A positive prediction on the always-unsatisfiable carrier is an actual error.

## Fixed event axis

Serialize the original header and carrier bytes. For each marker reserve a local block at least as long as either canonical spelling. At block entry choose exactly one bit. Carry it in finite control for the entire block and emit precisely the corresponding spelling, padding the shorter spelling with synthetic no-ops at its end. A no-op does not feed a byte to the predictor, change its finite control, or modify a stack. Block boundaries and all byte alternatives are read from the actual codec. The marked physical bit is the block choice, not a separate choice per printed minus sign. One may instead use an equal-length codec when available. Let L count the full padded event positions, including all prefix and choice events.

For each stack and event require a known operation type: push preserving old top below the new symbol, pop of a nonbottom symbol, or stay. The operation type is fixed, but the new control and pushed symbol can depend on current control, actual byte and tops. Verify the schedule by scanning every allowed local spelling/byte choice and every transition-table entry for its possible controls and tops. Synthetic no-ops require stay. This simple sufficient verifier may reject a harmless mismatch at an unreachable entry. Use a rejection sink for invalid source transitions as specified by the physical machine, or prohibit invalid transitions if that is the source semantics. A verifier may instead exclude entries with a separately proved unreachable-state invariant. Different satisfiable candidate schedules cannot simply be discarded before a constancy claim. At a failed schedule check the procedure abstains.

Match scheduled pushes to pops by a separate ordinary stack per predictor stack. A pop below the initial bottom violates the checked schedule. The original source may permit nonempty terminal stack; then unmatched pushes are legal and do not need return edges. Otherwise check the required terminal heights or symbols. With a single predictor stack there is no second stack unless the supplied source has one. Alias consistency itself needs no stack in this construction. If allowing several stacks, they can be updated synchronously by the explicit local table; the number of stacks is charged in the state domain.

## Pair constraints with saved tops

Use one variable per event. Its possible records contain a legal local input choice, the before/after finite-control state, the before/after top of each stack, and any saved/restored symbols required by the event. The persistent control also carries the current marker choice inside its block. Local records are generated from the actual transition table, with initial state/tops and terminal output enforced at the endpoints. Explicitly disallow popping the bottom. A stay preserves the top unless a top rewrite is actually specified by the source, in which case its change is recorded locally.

On a push the record stores the **old** top and sets the new top to the pushed symbol. On a pop it inspects the current top and guesses the restored top. Equate that guess with the saved old top of the matching push. Adjacent events must agree on all control and top registers. The same rule applies independently to every stack. A finite induction on nested matched intervals shows these registers exactly reproduce the real stacks. Within an interval all later pushes are popped internally before the matching return, and its underlying symbol remains precisely the old top. This remains valid in the presence of a stay that rewrites only the top. This method assumes the stated stack instructions, not arbitrary multi-symbol rewrites.

For each repeated physical ID, link its marker choices with a binary equality after removing the supplied sign offsets. Consecutive occurrences in the occurrence list suffice, even if there are more than two; transitivity gives full consistency. For a pair this is one edge and interval crossings are unrestricted. Singletons need no edge. Invalid alias metadata is rejected at compilation. Multiple constraints on the same pair of events are conjoined.

Every legal physical assignment and its deterministic run give a satisfying record assignment for exactly the corresponding outcome. Conversely a satisfying assignment selects one spelling per marker, enforces every alias, follows the original transition table on every real byte, and restores exactly the held symbols on pops. No artificial no-op is present in the reconstructed physical word.

## Tree decomposition and cost

The constraint graph has the event path, the signed alias links, and one long edge per matched push/return requiring a saved symbol. All constraints are unary or binary. Let D be the maximum number of actually enumerated records per position, N the number of variables plus constraints, and T the encoding size of the supplied tree decomposition. D must include finite-control, top and spelling registers, possible restoration values and simultaneous stack cases. No constant-alphabet cost is asserted for varying tables. Charge separately the cost of reading the codec, constructing padded blocks, generating records, checking the visible schedule, and generating every constraint. For example, explicitly tabulating allowed record pairs costs O(N D²) pair checks; evaluating a constraint on demand avoids this storage.

Verify the decomposition, including tree structure, vertex coverage, edge coverage and connected occurrence subtrees. Its width is w if each bag contains at most w+1 positions. A supplied and checked decomposition suffices; searching for one is an additional cost. Use a rooted nice decomposition with O((w+1)T+N) bags after assigning each constraint to one covering bag. Introduce extends a surviving assignment by one record; forget projects with existential OR; join intersects two tables on the same bag assignment. Check assigned constraints at their bags before retaining rows. In each bag there are at most D^(w+1) rows; with indexed tables and direct enumeration of larger-bag assignments, projection and joins need no extra factor D beyond this bound. A conservative combined time is preprocessing plus O((T+N) poly(w,record size) D^(w+1)), for each of the two terminal outcomes, with analogous table storage. If an implementation precomputes all pair tables add its explicit O(N D²) preparation. Infeasible partial rows may be pruned only by the exact local tests or child tables. Resource caps or unverified decompositions yield UNKNOWN, not a negative prediction.

Keep child references for retained states at forget and join nodes. Following a successful root row yields an original event record for every position. Extract and unsign the physical marker bits, check aliases and form the canonical original byte string with the actual codec. Drop synthetic events and replay the original deterministic machine on those bytes. Two different terminal values yield two attained original words. Constancy is justified only after complete exploration for the absent outcome under the verified schedule and true-table hypothesis.

## Separating boundary families

Take n distinct physical IDs, first occurrences 1 through n followed by second occurrences in the same order, with an idle predictor stack. All n aliases are simultaneously live at the midpoint and every two intervals cross. On the compressed marker axis let a_i,b_i be the corresponding events. The graph is a ladder with rungs a_i b_i and an additional path edge a_n b_1. An explicit width-two decomposition of the ladder uses alternating bags {a_i,b_i,a_(i+1)} and {b_i,a_(i+1),b_(i+1)}. Add b_1 to all bags to cover the extra edge, giving width at most three. A longer physical block with just one choice event subdivides an axis edge into a path; such subdivisions preserve width at most max(2,w) by hanging a chain of three-vertex bags at a bag containing both former endpoints. Prefix/suffix paths, including a fresh enable marker, also preserve the bound. Thus the method can process arbitrary crossing and unbounded live-ID count without materializing the midpoint frontier.

For unbounded height skew, order first occurrences 1 through n followed by second occurrences in reverse order. The alias checker viewed as a stack reaches height n, while the predictor can stay at height zero throughout. The path and these nested alias links form an outerplanar graph of width at most two. If two explicit predictor stacks are desired instead, let one visibly push n times and pop n times, the other stay throughout, and use independent or identically nested alias links. The same width bound holds while the height difference is unbounded. Neither example implies a bound on all compact paired charts. In particular the unrestricted fixed-DFA alias hardness result makes no promise of a small event-graph decomposition.
