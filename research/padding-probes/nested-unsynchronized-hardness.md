# Properly nested paired aliases with an independent real-time byte DPDA

Finite problem: the input is a compact alias chart, a complete explicit deterministic real-time byte DPDA and a polynomial-length native marker layout. Ask whether two consistent underlying assignments yield different predictions on the resulting actual DIMACS strings. This is NP-complete even when each repeated alias has two positive occurrences, all alias intervals are properly nested or disjoint, and the predictor stack is empty except for bottom at the end of every well-formed transition pair.

**Reduction.** Given a strict 3-CNF F, use a fixed deterministic one-tape verifier with a designated, polynomial-length initial tape layout containing F, a guessed assignment to its occurring variables, and otherwise fixed symbols, head and start state. Its running time T and sufficient tape length S have fixed polynomial upper bounds in |F| already accounting for one-tape simulation; choose T,S from those bounds, with protected left and right sentinels. Pad both halting states by identity transitions. Encode each tape cell in a fixed number k of bits, using the finite alphabet of symbols, some marked with the verifier state to record the head. On a valid configuration, the next symbol (and head mark) at a position is determined by the three neighboring old cells. The table performs the ordinary write/move operation and handles the ends by fixed boundary symbols. From the legal initial configuration local correctness inductively guarantees a legal one-head configuration at every time.

There are T consecutive blocks Aᵢ Bᵢ, 0≤i<T. Aᵢ lists kS bits of a candidate configuration in forward order; Bᵢ lists kS bits of its candidate successor in the exact reverse bit order, including reversal inside a cell. Pair each bit of Bᵢ to the same coordinate of Aᵢ₊₁ for i<T−1 using one fresh ID. The bits of Bᵢ are encountered in order N,…,1 (N=kS), then their mates in order 1,…,N. Thus the pair opened last closes first, and different boundaries use disjoint adjacent half-blocks. No Aᵢ bit is reused in Bᵢ: their cross-time relationship is checked by the predictor. A₀ and B_{T−1} bits are singletons. Add one final singleton enable e. All aliases are positive. With n=2TkS, supply the original codec with empty challenge. Its header is p cnf (4n+6) (n+9), followed by eight immutable contradiction lines and n+1 canonical marker lines. The parameters in parentheses denote decimal integers. Encoding uses O((n+1) log(n+2)) bytes, and all physical CNFs are UNSAT.

**Machine.** Skip the header and eight fixed carrier lines by counting newlines. On each subsequent line observe whether its first literal starts with a minus (one) or a digit (zero); both spelling branches consume the same logical marker position. Consume the rest of the line without changing the stack. Use a finite position counter up to 2TkS+1, and track line start/interior. At each Aᵢ first-literal byte push the observed bit by replacing top U with bit,U; at each Bᵢ first-literal byte pop a bit. The Bᵢ order matches the stack order, so the popped old and observed successor bits form aligned cell pairs when read right-to-left. Buffer finitely many bits to decode both cells (in reverse code order). With one-cell delay check the successor at the middle old cell of each old triple; use the known border at the ends and perform outstanding border checks in finite control at the last cell. Check cell-code validity. During A₀, verify the entire prescribed initial tape with guessed positions restricted to legal Boolean symbols. During the final B block remember whether the accepting head mark has occurred. Require its presence. Underflow or malformed control transitions can enter a rejecting sink. Provide an entry for every control, byte and top, retaining bottom on any invalid pop. Mark output one only after the newline of the final enable line, with the checks passed and enable one; further bytes can reject. No epsilon event or end-of-input pop is needed. The finite control uses O(TkS) positions times a fixed product of flags, buffered finite cell codes and byte modes; alphabet {bottom,0,1} suffices. Thus the entire explicit table is polynomial-time constructible. Exact validation of decimal fields by the DPDA is unnecessary because only canonical bytes are attainable.

The paired aliases identify Bᵢ's successor with the next Aᵢ₊₁. A positive key therefore describes an accepting computation on F and a witness assignment read from its first configuration. Conversely each satisfying assignment supplies a legal padded computation and a positive key with e=1. Independently e=0 always gives an attainable negative word. Disagreement is equivalent to SAT; constancy is coNP-complete. For membership guess two polynomial lists of alias values, generate the raw original words and run the supplied real-time machine; heights grow by at most one per consumed byte. This is a finite polynomial-word reduction, not a reduction to unbounded cyclic reachability or an undecidability claim. It does not require a fixed universal predictor; the finite control and initial-position checks depend on F.

**Boundaries.** With only one independent underlying alias bit, however often repeated, two complete runs decide disagreement in polynomial time. Likewise a constant number d of independent bits permits 2^d runs. These are bounds on the total number of independent IDs, distinct from the construction's one bit *per* ID. A finite-state predictor with a properly nested signed equality chart can instead use a single alias stack on the independent-marker byte DAG; synchronize value comparisons there. Hardness arises because the constructed predictor stack is independent of that stack. Both stacks are empty after the entire word, which alone gives no skew guarantee at intermediate bytes.

For two assignable LIFO alias stacks, bounded skew and bounded context count have incomparable coverage in the physical order. The order A₁…Aₙ B₁…Bₙ Aₙ…A₁ Bₙ…B₁ admits four single-stack contexts; its crossing graph K_{n,n} forces the A/B split, so intermediate skew reaches n. Interleave the openings A₁ B₁ … Aₙ Bₙ and close as Aₙ Bₙ … A₁ B₁ instead. The A/B split has skew at most one, but every Aᵢ,Bᵢ crosses, forcing a stack switch within each adjacent opening pair in every valid split. These are structural separations, not separate decision lower bounds.

An implementation enforcing the schedule on every syntactically canonical tableau candidate may record data failures in a sticky reject bit while continuing the prescribed pushes and pops through the end of each transition pair. Thus the native stack returns to bottom at pair boundaries even for inconsistent candidate configurations. This does not change the accepted words.
