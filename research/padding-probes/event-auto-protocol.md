# Automatic physical event-tree solver

The public entry is `event_auto.solve(challenge,n,aliases,table,initial,bottom,outputs,*,backend="macro",schedule=None,occurrence_pins=(),id_pins=(),state_cap=None,step_cap=None)`. Input validation rejects malformed pin names, offsets and caps. Occurrence pins describe printed marker sign choices; ID pins describe the underlying Boolean assignment. All pins on a repeated ID are combined after XOR with the occurrence offsets. Consistent compiled inputs with contradictory pins return empty.

Choose either macro or raw explicitly. The macro backend replays the immutable prefix, enumerates one whole-spelling choice per marker, and verifies a uniform operation on its first byte and stay on its remaining bytes. Its optional schedule uses marker positions. The raw backend uses one record per padded byte, a byte-indexed schedule, and a conservative forward approximation of reachable control/top/spelling choices with return symbols taken from the paired push. Both may abstain on a mismatch in an overapproximated state. The wrapper does not silently drop a branch or invoke an unmeasured fallback. A raw fallback is a separate explicit call with byte-indexed metadata.

Pin restriction is applied to the conditional record domains before tree evaluation. The automatic graph routine first attempts degree-at-most-two elimination with neighbor fill, then retries after deleting each candidate apex. A successful result supplies a checked decomposition of width at most three. A failed attempt sequence yields unknown. The output variable is an explicit Boolean endpoint. Tree DP computes both reachable output values jointly. The wrapper reconstructs each retained sample, decodes the canonical source, checks its challenge, key, underlying aliases and all pins, and independently runs the actual deterministic table over the original nonpadded bytes. A failed replay yields unknown. The statuses pair, constant and empty refer only to legal words on the pinned chart.

All preprocessing matters. Charge reading and validation of the source and transition table, generation and layout of actual spellings, prefix replay and marker/byte simulation, creation of each candidate domain record, and materializing allowed endpoint pairs (at most the sum of pre-pin domain products over CSP edges). The raw and macro builders have different state spaces and refusal conditions. The nested compiler metrics report what each builder exposes. The domain and pair totals in the wrapper describe completed construction; zero counters on an early refusal are not a claim that construction was free.

For V event vertices and E event edges the automatic routine tries at most V+1 elimination runs. Each trial can copy the graph, eliminate every vertex and add at most one fill edge per removal; expected hash-table work per trial is O(V+E). A successful trial additionally returns O(V) bags. Charge decomposition verification, constraint-to-bag hosting (including occurrence-set intersections), copying relation tables, and storing/reconstructing witnesses. If the post-pin domains are D_v, the prepruning bag-row clock is the sum over bags B of the products of |D_v| for v in B. The DP further pays its local relation and child-separator lookups per tried row; reported states and steps track trials and such checks. This is polynomial on the recognized width-three class for an explicit variable table, but for unrestricted width the exponent on a variable domain depends on width. For fixed table/stack alphabet and bounded marker choices the domain bound is constant. Replaying and emitting each concrete witness costs at least its individual physical length. The wrapper's replay_bytes sums these lengths; both builder-level replay and wrapper replay must be charged. Its state and step caps govern tree DP only.
