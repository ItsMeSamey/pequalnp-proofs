# Independent vertex deletions in different physical blocks

The input is a byte predictor with an explicitly checked visible schedule on a paired-marker padding language. Construct the finite event CSP using the raw or whole-marker compiler. The following recognition step takes only its physical primal graph. A loop adds no adjacency requirement. All constraints between the same two event records are enforced together.

Compute the biconnected blocks, counting individual bridges and isolated vertices as blocks. On each, try partial 2-tree elimination first, and then repeat after deleting one candidate vertex at a time. On success add that vertex to every local bag. Use a bag containing each articulation as its local attachment. The block-cut forest permits gluing all incident attachments in a star without introducing a cycle or disconnecting any occurrence subtree. Connect components by arbitrary bag-tree edges. The existing independent decomposition checker revalidates these bags on the original CSP. Unsupported blocks or schedule refusals yield unknown. Contradictory signed pins on a certified input give the empty fiber.

This recognizes every graph in which each block has its own witness for deletion to a partial 2-tree. The witnesses in different blocks need not coincide. The resulting bags have at most four vertices. The method is incomplete on arbitrary width-three graphs.

For a physical separation concatenate h=3 crossing marker ladders so that only the execution path links one ladder to the next. Signs and identifier offsets are local to the ladder; every matched push/return is local as well. In the six-marker graph each ladder consists of a six-vertex path and the three edges (1,4), (2,5), (3,6). Contract edges (1,2) and (5,6); the four remaining branch sets are pairwise adjacent. Multiple ladders give vertex-disjoint K4 minors separated by bridge edges. Any single global deletion leaves at least one untouched K4 minor when there are two or more ladders. Each local ladder, however, admits deletion to width two. The raw event graph retains the minors by contracting within markers. The physical fixture exercises the predictor's restored top and signed pins; this is a strict recognition separation on actual records. It is independent of any lower bound on deciding the particular instance.

Computing one sample per reached output bit is sufficient for the stated constancy/disagreement problem. Two opposite predictions on equisatisfiable strings establish disagreement; independently known truth of the underlying formula identifies the erroneous sample. The algorithm gives no multiplicities or model counts.
