# Recognizing synchronization on the complete canonical signed-pair fiber

This is a theoretical successor to the conservative executable. Assume the input is the canonical independent-marker graph, every accepted branch spelling is total, the signed alias intervals are nested, each pair has exactly two occurrences, and there are no extra key pins or constraints. Every paired event is on the very first edge committing its sign, never a later edge. Each prefix of a marker line has a unique spelling choice once its sign branch has been taken. Every prefix whose already chosen physical signs respect past pairs can be extended to some complete legal word: finish the current spelling, choose arbitrary still-unbound names, and copy each pending normalized value at its last occurrence. This property would require a separate proof for a filtered graph.

Before the first misalignment, augment the synchronized product's finite control by the current logical alias top, either empty or its identifier and normalized bit. On a tagged push, save the old cache on the marked frame and replace it with the pushed value. On a matching tagged pop restore the saved value. Ordinary predictor pushes/pops of neutral frames leave the cache alone, so the pending semantic bit is accessible even beneath neutral frames. At a tagged close, check the physically chosen normalized bit against this cache *before* checking whether the actual physical top is the right frame or whether the predictor is about to pop. Reject an inconsistent branch as infeasible. Any failed operation on a remaining branch is an actual reachable first schedule mismatch on an alias-consistent prefix. At an open or unmarked byte no pending equality must be discharged, so the previously checked prefix suffices.

Perform ordinary one-stack reachability for existence of a first mismatch over all prefixes; do not stop this global recognition pass merely after finding a disagreement pair or first target output. If a bad prefix exists, the extension property gives a full legal word witnessing misalignment, independently of the predictor's subsequent behavior. To output such a word, parse the retained byte prefix into chosen signs, fill pending/future occurrences as above, finish the remaining canonical bytes, and replay the prefix to certify the first mismatch. Conversely any complete legal word that misaligns has a first mismatch and its earlier legal signs and operations are explored by the product; it is therefore detected. Thus exhaustive polynomial-time recognition decides the exact universal synchronization condition on this chart. The cached ID/bit and saved prior value increase both control and stack alphabets by at most polynomial factors in the number of alias names. The proven synchronized evaluation and its original-word witnesses can then be used as before. Without these restrictions the conservative status of the released implementation remains unchanged.
