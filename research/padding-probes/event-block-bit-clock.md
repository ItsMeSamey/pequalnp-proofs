# Bit cost and depth of the block recognizer

Let S be the total encoded bit length of the explicit input graph, including all vertex names and repeated edge occurrences, plus two. Actual event names are bounded-depth tags and binary integer positions. More generally suppose identifiers are strings, integers, or fixed-depth tuples with polynomial-time canonical equality. For strings, integers and fixed-depth tuples, O(S²) name comparisons costing O(S) bits each suffice to intern all names. User-defined Python hash and equality callbacks have no general bit clock.

After interning, all graph operations use indices of O(log S) bits. Deterministic list scans can implement each set/dictionary operation in O(S log S) bit work. The indexed operation count is O(N+M+sum_B(n_B+1)(n_B+m_B)), with bridges and isolates counted as blocks. Each removed vertex adds at most one edge and enqueues at most two neighbors. The incidence graph of blocks is a forest, and the total block vertices and edges are O(N+M). This gives a conservative O(S^4) deterministic bit bound including normalization, lowlink, per-block elimination, and writing the returned named bags. It uses no favorable hash function assumption. For a hash implementation, probing a table can instead be charged to its full capacity, bounded at all times by initial entries plus all insertions on the pass. Costs exclude compilation and the following DP.

For the binary CSP, include explicit domain records, relation pair tables, decomposition and all incident constraints and child lookups per candidate bag row. Let U bound the encoded size of these materializations and this complete operation count, including widths of keys, counters and backpointers. A conservative O(U³) bound implements O(U) comparisons/lookups with O(U) candidates of O(U) bits, plus separately charged table certification, byte simulation and every physical replay. In particular charging just the maximum bag size omits real work. For fixed small bags and a fully explicit finite predictor table, this is polynomial; the generic D^(w+1) estimate is XP when table and width both vary.

All graph-depth traversals are iterative. Lowlink stores frames and pending edges, elimination uses a deque, and bag traversal plus original assignment traceback use explicit lists. Physical replay walks the original byte string using an explicit predictor stack. No call stack grows with graph depth. Large memory or time requirements remain possible, and the numerical row/step caps apply only in bag DP. Width controls this algorithm's cost; it does not bound the intrinsic complexity of prediction or SAT from below.
