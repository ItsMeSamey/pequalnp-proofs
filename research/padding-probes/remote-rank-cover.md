# Rank-aware original-clause pivots

For each residual ternary C use its GF(2) failure indicator f_C restricted to models of the common binary background B. Let Z be all rows reducible to binary already on B, and R_w those reducible on both B cofactors of w. For chosen K enforce E=Z ∪ ⋃_{w∈K}R_w. The simultaneous linear certificate exists iff rank(E)=rank(all). Under each assignment to K, solve B plus one binary replacement per enforced row. These agree with its exact original clause on that branch. Vanishing of every enforced failure forces all original failures to vanish; in the opposite direction every original witness satisfies the corresponding 2CNF. Stream branches and check each SAT witness on original signed names. An incomplete search can abstain. Equal ranks characterize this certificate, not semantic redundancy.

Switch one model of B to the zero word (inconsistent B is immediate). Then B consists of implications, negative units and incompatible pairs. Expand each switched signed ternary failure into at most eight squarefree monomials. For each used support S compute its implication closure H. If H violates a negative unit or a forbidden pair the term is zero. Otherwise H is an actual model and the term is the indicator [H⊆X] on every model X. Distinct feasible H produce independent functions since evaluating on those same H in size order gives triangular inclusion matrix with unit diagonal. Combine identical keys by XOR. At most 8m coordinate keys occur, including the possible empty one, for m residual triples. No degree-three support catalogue or enumeration of all binary models is necessary. A fresh model gives the same procedure on any pinned B.

Subtract rank(Z) from each reachable rank. This monotone integer submodular function is zero on the empty selection: each marginal is the dimension added by a fixed group of failure rows. For full additional rank r, an optimal h* groups have combined individual gains at least the current deficit d. Thus greedy gains at least d/h* and uses at most h*H_r groups by harmonic charging. If r=0 no pivots are needed. Search over all groups, not one arbitrarily fixed row basis. Greedy discovery and repeated Gaussian eliminations cost polynomially in the input length L. For instance with v active names and t≤m the total rank, at most (t+1)v(m+1)(t+1) masks of length ≤8m need to be reduced/XORed in a basic implementation, besides closure computation and 2SAT relation preprocessing. Sorted sparse-ID encoding gives polynomial bit cost in L. Given h greedy pivots the decision phase uses ≤2^h polynomial-cost 2SAT calls and polynomial working space. Charge any resource caps separately. On the Set Cover encoding of remote-pivot-theorem.md all ternary failures are independent: take a_i=b_i=0 and vary c_i. The optimum thus remains Set Cover hard even on always-SAT sources.

The connected strict-residual positive and negative separation is in rank-pivot-cycle.md. With no binary constraints or pins and all clauses strict, optimal rank-cover cannot improve ordinary scope hitting: the degree-three coefficient of a missed scope is unique to rows on it. Do not conflate this optimum with a particular greedy sequence.

For supplied K one may instead check each of its 2^|K| fibers and use a different basis there; equal rank on each pinned domain need not yield a single global span. One can even build the pinned binary core plus retained replacements G and test G∧¬C by 2SAT for every omitted C. This exactly checks entailment by G and can succeed without any rank identity. No greedy submodular discovery claim for these adaptive variants follows. Other source simplifications can also resolve the displayed families.

Prior ingredients: Jansen–Pieterse constraint sparsification (https://arxiv.org/abs/1606.03233), Mastrolilli on Boolean CSP ideals including majority (https://doi.org/10.4230/LIPIcs.MFCS.2020.13), and Wolsey on greedy submodular cover (https://doi.org/10.1007/BF02579435). The source specialization and charged original-witness composition give no universal SAT exponent improvement.
