# Shared Boolean coordinates for exact physical records

Compile the complete signed physical fiber with the raw or macro visible-schedule compiler. Give each variable its own explicit injective codebook, used unchanged on all incident factors. Enforce each record domain as a unary factor and each actual allowed pair as a binary factor. For self-pairs keep only the diagonal. Restrict the domains by any supplied pins. The output target gets the code assigned to that output. A rejected chart does not exclude another chart. Arbitrary codebook factory computation is separately charged.

For a nonempty set S of distinct l-bit rows, translate a member to zero and compute a basis of differences of rank d. The set is affine exactly when |S|=2^d. Orthogonal-complement equations describe its hull without enumerating it. Empty factors give infeasibility. Embed each equation in the shared global block of each participating variable. Missing codewords cannot yield spurious witnesses because domain factors undergo the same tests as pair factors. On an affine input, solve both output systems by Gaussian elimination, decode, check the original pairs and replay the original physical bytes.

The omission parameter k is the sum of 2^d−|S| over all factors. Compute it and compare to the cap before listing any missing local words. Enumerating the hull costs only |S|+k_i entries for factor i once the check succeeds. Each omitted tuple excludes one affine cylinder. When a Gaussian witness hits a cylinder, split by the first locally differing bit. Those disjoint branches cover the complement. No descendant hits that same cylinder twice. With L the largest local code width, at most two times the sum from j=0 through k of L^j Gaussian calls cover both outputs. Incomplete searches return UNKNOWN unless both actual outputs already have checked witnesses. The primary API requires a nonnegative integer exception_cap. This branch bound is XP in k when L grows.

After encoding and deduplication, local elimination takes O(sum_i (|S_i| l_i²+l_i³)) bit operations. Add the costs of original table construction and checking, embedding into global U-bit masks, checking/transporting codebooks, and all raw replays. An E-row Gaussian solve costs O((E+1)(U+1)²) bit operations by elementary elimination. Lists of restrictions, witnesses, and O(k) omitted-tuple tests per Gaussian result contribute a further polynomial in the charged tables, U and k. Deterministic finite scans can replace hash operations. The all-affine case is polynomial on explicitly encoded event CSPs and requires no bound on the primal graph width. Affine Boolean constraint solving is classical; the physical compilation and witness correspondence are essential here.

In the high-width family there are t contiguous blocks connected internally by the execution path. Each pair of blocks shares a signed repeated identifier. Contracting each block yields a K_t minor even on the compact marker representation. The actual predictor propagates a position and a parity; at a fixed position an event record is specified by incoming parity and marker sign. All domains and relations are affine in those coordinates. This family separates the new recognition rule from the preceding width-three front end. Width alone gives no intrinsic hardness result for predictor error or SAT.
