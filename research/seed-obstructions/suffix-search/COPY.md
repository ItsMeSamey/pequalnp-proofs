# Copy-normalized completion search

Both seeds are impossible after freezing their first 15 recipes and allowing 18 further gates. The exhaustive search rejects 2,450 starting supports for seed 18968 (3 of size 17, 120 of size 18, 2,327 of size 19), and 1,861 for 21968 (2 of size 17, 86 of size 18, 1,773 of size 19). Run `python3 verify_copy.py 18968 15` and repeat with seed 21968. The hitting-set argument and theorem blob are described in README.md.

## Wire copies

For a cone using d distinct available starting signals and at most g binary gates, insert an explicit copy operation for each additional use of a wire. Now every binary gate consumes both operands and produces one wire, and every copy replaces one wire by two with the same column. Counting the active wires from d to one gives at most g+1-d copies. Any such straight-line computation is within the search.

Between two copies, all binary gates consume both operands. One may schedule all gates producing the next copied wire before the copy and postpone independent gates until afterwards. In this order the only active gate result made since the previous copy, at the instant just before the next copy, is the wire to be copied. If the wire is already available when the phase begins, there need be no intervening gates. The verifier marks every gate result in the current phase, removes marks when operands are consumed, and clears the marks after a copy. It permits a copy of any wire when there are no marks and of the unique marked wire when exactly one remains. Binary gates can be taken in any order. A final phase can end at the output without a further copy.

## Private pairs and tree conditions

A positive-negative pair is private to an active wire if it has exactly that wire as a positive-to-negative separator. Write P(i) and N(i) for the positive and negative rows appearing in private pairs for wire i. For every other positive-negative pair, either an untouched wire still separates the pair or both operands of the gate separate it. In the latter case either gate operation preserves the separation. Therefore AND(i,j) retains all separations exactly when j is true on P(i) and i is true on P(j). OR(i,j) retains all separations exactly when j is false on N(i) and i is false on N(j).

At any active state one can regard its wires as independent formal inputs to the remaining computation, even when columns coincide on some observed rows. For a private pair (p,n) for i, turning off i at p makes its vector coordinatewise at most n, and turning on i at n makes its vector at least p. Both changes flip any correct monotone output. If a positive row belongs simultaneously to P(i) and P(j), flipping either true operand there must flip the output to false. In a read-once tree the lowest common ancestor of the two leaves must therefore be AND. An OR ancestor could not be changed by both individual flips, since it has two distinct child branches. A common negative row in N(i) and N(j) similarly requires an OR ancestor.

For zero spare copies, construct two graphs on the formal inputs, one for mandatory AND pairs and one for mandatory OR pairs. The root of a feasible read-once tree cannot separate any pair requiring the opposite label. Thus at least one graph is disconnected. Conversely, splitting off one connected component of a disconnected graph introduces no edge of that graph across the split. Compatibility on each part is necessary for a feasible tree, since restricting a labeled tree to a subset preserves its pair labels. This gives a recursive necessary test. A state where both graphs are connected on a subset of at least two wires is impossible.

With one copy the copied wire is the output of a read-once subtree, possibly a single input. In the remaining formula, write that subtree as one formal variable repeated twice. For two inputs inside the subtree, a private pair forces the subtree value to change. At a common positive or negative witness, the respective necessary AND or OR ancestor applies within this subtree. Two inputs outside the subtree each occur once in the remaining formula, so the same ancestor argument applies to them there. As a result a pair requiring both AND and OR must have one endpoint inside and one outside. The graph of pairs requiring both labels has to be bipartite. A computation with no copy satisfies this test as well. The verifier uses these tree tests only while the surplus is zero or one, and still performs exhaustive gate and copy enumeration for every surviving state.
