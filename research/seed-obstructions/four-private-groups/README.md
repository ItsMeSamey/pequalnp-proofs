# Four disjoint pair-safe groups require thirteen paid point gates at width eleven

On the residual L-meta-18968 sample, take any bank of eleven physical point-side boundary signals that covers the raw point separation obligations. Suppose four distinct residual target lines each have their own disjoint set of these physical slots. The AND of the slots in each group accepts all four singleton points of its target and rejects every pair of distinct points outside it. Then the original purely point-side program requires at least thirteen binary union/intersection gates. The claim permits unused, raw-redundant and duplicate-signature slots, including physically distinct slots computing the same singleton signature.

Run `python verify.py` with Python 3 and a C++20 compiler supporting native unsigned 128-bit arithmetic. No solver library is needed for this replay. The separate ../../seven-neighborhoods/README.md gives the prior 3k projection theorem, including its own dependencies and finite proof.

## Guard groups

Write the singleton signature of a guard as a thirteen-bit set. For every pair of exterior points of T, some guard in its group must have a signature disjoint from that pair. Otherwise every guard would accept the pair by monotonicity. In particular, intersecting the guards' singleton sets gives exactly T. If a group contains a signature equal to T, retain just that one mask for this combinatorial test. This retains the required mask property. Otherwise each guard has some exterior point. A group with one or two strict supersets fails the exterior-pair test, since one exterior point from each member hits all the members. Thus a normalized group either has size one and equals T, or has at least three strict supersets. For three members their exterior parts are nonempty and pairwise disjoint. Sharing of an exterior point between two parts would let that point and one point from the third part hit all three.

To compute T from m given group masks, at most ceil(m/2) operands suffice. Partition the group into two parts whose sizes differ by at most one. If both intersections contain an exterior point, one such point from each part hits every member of the group. For m=1 use the existing exact mask. In all cases at most floor((m−1)/2) additional binary intersections suffice. This claim uses the singleton signatures alone after normalization.

## Input and symmetry checks

The Python driver decodes the 676-row statement, checks its fingerprint, derives the 28 required positives and 245 maximal negatives, and computes all 24 joint point and line coordinate permutations preserving those samples. It derives five orbits of target quartets. The orbit union of the 31 free point-primitive masks has size 55. Allowing all 55 simultaneously makes the cost bound invariant under the 24 permutations. Every one of them is a transversal of the seven targets.

For a positive with singleton point a and a negative with point set b, take the pair (a,b) whenever the negative contains all the positive line coordinates. The possible point boundary signatures X that separate it have a in X and b disjoint from X. For each a retain the maximal b. This gives the independently reconstructed 1,323 rows. Every feasible bank must cover these rows. The verifier admits slots that cover no row uniquely.

For each quartet a seven-row incompatibility clique is supplied and validated. The first four anchors each require a whole target T and exclude an exterior pair. They are satisfied by a slot chosen from the corresponding private group. The last three anchors are required raw rows. Distinct rows in the clique cannot be satisfied by the same signature because some required point of one row is forbidden by the other. The seven anchors therefore label distinct slots. The four remaining slots are unanchored. Enumerate the assignments of all seven slots other than the first four to the four groups or to the unused class. The unanchored slots are ordered by class, and then by numeric value within a class. Within a class an anchored slot uses the least compatible available signature in preference to an unanchored slot. Each signature can satisfy at most one anchor, so this choice eliminates only alternative labellings.

The bitwise search maintains forced presences and absences for each slot. It propagates raw rows that can be covered by only one slot. The search branches both ways on a remaining bit. It rejects incompatible role assignments, groups of size two, five simultaneously exact distinct canonical lines and incomplete raw coverages. Five exact targets would need at least fifteen point gates. It enforces that nonsingleton groups have strict supersets, enforces the disjoint-exterior condition for three members, and enforces every exterior-pair condition in larger groups.

## The projection bound

For each subset J of target lines project every point mask to the union of J. This commutes with both gate operations. All masks meeting every line in J at most once may be taken for free in the 3|J| bound. A known paid boundary output that becomes such a transversal can have its construction gate removed and its projected mask used for free. If several known paid boundary signals become the same projected mask, retain the earliest and delete the others. For every partial state the checker greedily selects a subset of certainly paid slots whose allowed mask intervals are pairwise disjoint. They must arise from distinct paid gates, while repeated signatures cannot double-charge. The search uses conditions that hold throughout a partial interval of possible signatures.

If the remaining circuit can recover each target of J using d further gates, and h paid gates have been deleted by projection, its original cost is at least 3|J|−d+h. Three singleton unions per target give a default construction. A known clean pair on T saves one gate. A clean triple, two complementary clean pairs, or two full-bearing masks intersecting exactly in T save two. An existing full clean T saves three. Clean means that all exterior points disappear on the chosen projection. The half-group argument above gives additional recoveries for the four private targets on every projection that retains them. Independent improvements for the same target are combined by taking their maximum. The counter computes the bound for all 128 subsets of the seven targets and excludes a bank if any lower bound reaches thirteen.
