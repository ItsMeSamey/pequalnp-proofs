# Ten point signatures extending an irreducible nine-signature basis

Run `python3 verify.py PATH_TO_SIXTEEN [OUTPUT_DIRECTORY]` with Python 3 and a C++20 compiler. The sixteen directory supplies the raw theorem, its existing sample decoder, and the hash-pinned list of 16,924 inclusion-minimal nine-signature families. An optional existing output directory receives the representative lists for the mixed verifier. This module filters candidates for at most 16 pure point gates. The downstream mixed computation is separate.

## Reconstruction from original rows

The verifier derives every distinct pair (p,n) of point masks in a positive and a negative whose line masks are ordered, as in the preceding sixteen-gate verifier. Every p is a singleton. A point boundary signature s can separate this pair only if it contains p and avoids n. If only one feature can separate, monotonicity forces its actual function to reject n and every two-point subset of n.

For each of the nine base features, collect these unique obligations. For a fixed pair of outside points e, take all obligations whose negative contains e. If there are none, these implications cannot certify rejection of e. Otherwise after adding a tenth signature x the implication survives unless x separates every obligation in this list. This happens exactly when x contains the union of the positive bits and avoids the union of the negative masks. The code enumerates those x as a Boolean subcube. A feature becomes unavailable for a target T if any exterior pair loses its certificate. The tenth feature is never uniquely responsible since the original nine already meet every obligation. Omitting any additional safe features only weakens the lower bound.

For each residual target T, compute the minimum number c of surviving pair-safe submasks and raw singleton points whose union is T. Append c−1 OR gates to recover a pair-safe full target. Let b = 21−Σ(c−1) and d = 16−b. The seven-target charge theorem gives b as an original point-gate lower bound. The augmented circuit has size at most 21+d. When b=16 the seven OR-tree equality theorem additionally requires every nonprimitive mask to belong to one of the seven disjoint target trees. Its required masks must be laminar. The maximal required subtrees on each target need, in total, at least the sum of their cardinalities minus one per subtree. The code discards families exceeding 16 original gates. An added empty signature is always removable by lowering it to constant zero everywhere. Positives have singleton point inputs, and all negatives decrease monotonically.

## At most two extra gates

Apply the charge theorem to the seven augmented outputs. Let h count gates whose singleton mask is not contained in any of the thirteen projective lines. Let q count target lines having exactly two charged gates. All other targets have at least three. The theorem gives augmented size at least 21+h−q. For each exceptional target T it exhibits three distinct exterior gates containing T, whose three pairwise intersections equal T. Each exterior pair is counted for at most one T. The first charged gate for an exceptional target requires two earlier exterior supersets of T.

Neither of the first two exterior gates can contain any exceptional T. Before the first charged gate for T, nonexterior signals each meet T in at most one point. The first exterior gate therefore meets T in at most two. The second can combine it with at most one new point, so meets T in at most three. The first charged gate cannot intervene before two exterior supersets exist. Thus 3q ≤ binomial(max(h−2,0),2).

When d≤2, h−q≤2 and q≤7. For q>0 these inequalities leave only h=9,q=7. In that case every edge among the last seven exterior gates belongs to one of seven edge-disjoint triangles. Each vertex lies in three of those triangles, hence each of these exterior gates contains three whole target lines. All seven targets are exceptional and the gate count 21+h−q exhausts the budget, so there are no uncharged paid gates. Before the third exterior gate there are no charged gates, since the first two exterior gates do not contain any exceptional target. The third exterior gate therefore depends on at most four raw primitive masks, and its singleton mask lies in their union. The verifier enumerates all such unions and confirms that each contains at most two complete target lines. This contradiction proves q=0 and h≤d for all uses of the geometric filter. The implementation passes every b≤13 candidate through without using this argument.

## Original point gates

When q=0, the original circuit has at least 4−c paid charges for target T, since at most c−1 of its three required charges could have been appended. Distinct target charges are disjoint. Any required nonprimitive mask outside all seven target lines and outside the exterior class requires a separate uncharged gate. The code enumerates h from the number of required distinct exterior masks through d. If h plus the count of required uncharged gates exceeds d, the augmented gate count is impossible.

Independently, compute how many original charges each target needs for its required boundary masks. Grant all of its singletons for free. A clean OR with a nonsingleton result can only combine two clean operands. A clean AND with a clean parent yields a subset of that parent, so the dynamic program generously allows any single-input restriction. If both AND inputs are dirty yet their intersection is a clean nonsingleton, they must both be exterior: any projective line carrying two points of T is T itself. Each pair of exterior gates can introduce such a signature for at most one target. For ordinary targets the 2,048-state dynamic program on the eleven nonsingleton submasks computes the least number of unions and restrictions covering all required masks. For up to binomial(h,2) exceptional targets in this local calculation, replace this by the count of distinct required nonprimitive masks. For each target take the maximum with the reconstruction lower bound 4−c, and relax the largest improvements. This lower bound counts disjoint original charges, exterior gates, and required uncharged gates.

If h=1 and a particular exterior mask must occur, its gate is the OR of two earlier nonexterior masks. The verifier enumerates every possible operand pair among all submasks of the thirteen projective lines. It adds any necessary uncharged gates and requires any additional target-local operands in that target's dynamic program. Cases with repeated boundary masks retain both entries for mixed verification, while charging a given required singleton signature only once.

## Finite checks

The distinct nonzero tenth masks give 138,472,168 instances. The screen retains 26,754 instances in 1,713 canonical mixed families. The zero and repeated tenth masks give 169,240 instances, leaving 1,122 in 65 families. Canonicalization uses 24 simultaneous point/line permutations checked directly against all 28 positive and 245 maximal negative column patterns. Geometry is applied before mixed canonicalization, so only the actual mixed row symmetries are needed. The verifier checks the byte hashes of both sorted representative lists.
