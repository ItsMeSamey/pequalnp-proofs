# Switching-prime clique quotient yields a physical one-tag witness

Use the original rank-four alternating one-tag reduction of one-tag-graphic-quotient.md. Compute its indexed quotient q, four rows f and one odd word b. Supply a simple complete-graph edge identification with n vertices under which ker q=C⊕<z>, C the cut space. Verify on the original matrices that b annihilates C and b(z)=1. The four named rows f have rank four on C if [q;f;b] has the required five more independent rows than q: a relation annihilating C can be canceled on z by adding b, yielding a row of q. This can also be tested directly.

Add a cut to z to make all edges incident with one anchor a zero and use this normalized representative. Let H consist of the one-labeled edges on V minus a. Require that H have no proper module of size at least two. Test this by starting from every pair and adding any exterior vertex distinguishing two present vertices; each closure is the smallest module containing the pair. Accept iff all closures reach V(H). For tiny n use direct enumeration instead.

For a switch X choose gauge X(a)=0, set w=z+δX, and let G_X contain precisely the edges on which w vanishes. If disconnected, take a partition P,B of vertices into two nonempty unions of components with a in B. Then w_ij=1 for every i in P,j in B. In particular X_i=1 for all i in P from j=a. Thus for each j in B minus a the values z_ij on i in P are identical. If both sides had at least two vertices, P would be a proper nonsingleton module of H. Consequently a disconnected graph must isolate a vertex (e.g., use a connected component as one side). Isolating each fixed vertex forces a unique switch modulo global complementation. At most n switches are bad.

Solve f(z+δX)=0 by elimination with the anchor pinned. It has 2^{n-5} solutions. If this exceeds n, examine at most n+1 distinct solutions to find one with connected G_X. The complement support S of G_X then contains no nonzero pure cut. It contains w with names (0,1); its entire q-kernel is exactly <w> (two distinct translated words would differ by a nonzero pure cut). Thus the five-name trace of S is precisely the pure odd line. For any one nondegenerate projection plane, solve the original dual-lift system on these same physical coordinates. The resulting physical kernel vectors have Omega=1 and a common chart. Replay all conditions and, where requested, trim and pad via the original construction. For n≤8 use direct original support enumeration, a fixed constant because the indexed ground size is n choose 2. This proves a complete search algorithm under the stated promise. Above threshold every valid input has a witness.

These hosts exist as actual physical inputs. Choose q with specified kernel, choose four rows f independent on C and b vanishing there with b(z)=1. Let the physical private kernel be the span of the indexed rows [q;f;b], with q taken full row rank. Choose the physical tag functional zero on [q;f] and one on b. Define Omega on [q;f] by a nonsingular alternating form on the four f coefficients and zero on all q coefficients. Extend it arbitrarily as an alternating form on the ambient indexed space by completing a basis. These choices recover exactly the required dual quotient, five named rows and physical bad word; original indices are the same throughout. The normalized H may be any module-prime graph. This result uses a rank-one defect whose marker is REQUIRED in the target, the opposite regime from marked-cut-defect-triangles.md.
