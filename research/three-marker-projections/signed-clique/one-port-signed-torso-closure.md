# Uniform one-port signed torso closure

Fix global defect dimension k, r names, supported coefficient guess T of dimension t and p=h−t+1 parts. Use vertex state (i,x), i a part and x a t-bit switch. Edges are inactive for equal part and πd_e=x_u+x_v. Full inactive cycles have gain in T-perp. Exact trace prescribes part charges, total switch moment, all p parts connected, and cycle gain span containing T-perp. These global parameters remain fixed at every node.

Supply an arbitrary depth tree of connected edge-disjoint torsos with one shared vertex across each cut; verify supports. The local oracle on ONE torso accepts unrestricted r-bit vertex charges, a prescribed set of used colors, exact part and switch moments, fixed states at ≤1+p+k+rt actual vertices, connectedness of each used part and a LOWER bound H≤T-perp on the inactive cycle span. The torso parameters are independent of depth. For biconnected bounded-degree expanders use signed-expander-traces.md adding the bounded fixed pins to its initial pin budget; its abstract moment DP already takes the general targets. Require only the image of H in the skeleton, and still insert rooted cycles spanning L∩T-perp. This is necessary for every H-feasible witness after projection, and sufficient because differences lying in L belong to L∩T-perp. Use p as its own fixed parameter and restrict to the specified colors. Small torsos are direct. Other classes require a separate pinned-oracle verification.

At each child attachment v store the required state at v, exactly which parts occur, tensor moments on all child vertices EXCLUDING v, and a certified lower bound on the combined inactive cycle space in gain coordinates. All used parts must be connected in the child; nonattachment colors can occur nowhere on the parent's side. This is a constant-size table as a function of k,r,p. Count the parent boundary charge at its parent, not in the current torso's own intrinsic vertex contribution. Folded descendant charges at that boundary still count.

Each child has a default assignment for any root state (i,x): all vertices have color i; choose projected potentials along a fixed spanning tree of the entire child rooted at v. Its nonboundary moment equals total nonboundary charge tensor (e_i,x) plus a fixed offset only on switch sums. Its inactive cycle span is independent of i,x. Precompute these values and actual assignments on the original edges; even quadratic total work is polynomial.

In a true assignment, any child using another color than its attachment contains that whole other color off the torso (every route out must pass v). These extra colors are disjoint across children, so ≤p children are multicolored. The torso intersection of each part present there is connected because child excursions can only return at their entry. The inactive cycle-gain space is the sum of those from the individual children and torso, since all interfaces are single vertices. Keep all multicolored children and ≤k more children whose cycle spaces together with the torso and kept children generate the old span. For each remaining monochromatic child its actual-vs-default moment discrepancy has only rt switch bits. Keep ≤rt children with discrepancies summing to the total discrepancy of all remaining children; this is possible by choosing a linear basis and representing the total. Reset the rest to default. All moments and connectivity persist, and any extra cycles only help a lower-bound state.

Enumerate ≤p+k+rt exceptional children, their table entries and attachment states. Pin the chosen attachments consistently. For all others fold the default total charge into the attachment and account separately for the constant switch offset and default cycle subspace. Add actual exceptional entries directly. Guess the torso's used colors, enforce disjointness of child extra colors from torso and from each other, and check the parent's exact used colors. Guess a torso lower cycle space which together with all known child credits spans the required lower subspace. Call the pinned torso oracle with the remaining moments and pins. Gluing a positive oracle witness realizes the whole table entry; the sparse-exception argument proves completeness. Evaluate each child table once bottom-up, so the polynomial exponent and interface size do not compound with depth. Restore actual original assignments and verify the trace.

This covers trees of biconnected expander torsos and bounded-size torsos. For a connected Δ-bounded α-expander, the unsigned graph's centroid block expands by ≥α/Δ and every off-block attached component has bounded order (cographic-auxiliary/expander-arbitrary-labels.md). This new signed argument thus handles arbitrary pendant gadgets in that expander case. No decomposition into such pieces is asserted for arbitrary graphs.

Translate every returned switch back before gluing children. Part colors, part charges and full cycle gains are invariant.
