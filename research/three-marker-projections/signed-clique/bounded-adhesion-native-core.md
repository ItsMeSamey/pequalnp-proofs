# Fixed adhesion with highly connected native torsos

Fix adhesion a, original defect rank k, names r, global translation guess T of dimension t and p parts. Supply an edge-disjoint rooted tree of actual connected regions, with each boundary comprising ≤a original vertices and with running intersection. Require each torso's NATIVE graph on its vertices before inserting ANY virtual child edges to be sufficiently highly vertex-connected as a function of a,k,r,p, or to have bounded order (see bounded-order case below). This stronger premise is essential. There is deterministic polynomial exact trace recovery for arbitrary depth and arbitrary number of children without increasing a,k,r,p in recursive states.

**Rooted states and marking.** Store the port states, used colors, nonport tensor moments, and lower credits in the relation {(b,g): some inactive edge subset has full gain g and boundary b solely on ports}. Require every vertex of a color meeting ports to connect to some port of its color, and every nonempty port-free color to be connected. A full actual relation is generated by its cycle space in gain coordinates plus chains with a pair of odd ports, e.g. a spanning forest per component's ports. For child summaries enumerate such pair-generator choices, i.e. a forest on port subsets with a full gain for each pair edge, together with a zero-boundary lower subspace. A realizing parity chain might include cycles beyond its connecting path; the chain itself witnesses its full gain and its odd boundary witnesses a real path. Extra actual paths/cycles only help. Every full actual relation admits this form. Boundary parity and full gain dimensions are globally ≤a+k.

For a required parent relation, pin its ports on the native torso. Within each class of equal-color parent ports add a temporary tree of artificial edges, one independent marker coordinate per edge. Give the edge an old-coordinate gain projecting to its ports' switch difference. It is always inactive. Requiring the augmented whole part connected expresses exactly the parent rooted condition. For required boundary b with even parity in every port color there is a unique marked tree subchain with boundary b. Map (b,g) to the augmented cycle gain obtained by adding that chain, recording its edge indicator in the marker coordinates. This linear map turns lower relation requirements into cycle credits. Reject impossible b. No child uses any parent marker bit. Pins' intrinsic charges are counted once (omit the parent boundary's own charge in its outgoing table).

**Defaults.** Choose a spanning forest rooted at ALL ports of each child, each tree exactly one root. Default all tree vertices to its root color, use projected tree potentials from its root. Every interior then attaches to an actual same-color port. Its total nonport moment folds as a charge per root plus a constant switch offset. Ignore ALL default port-to-port connections and internal cycles in the abstract local test. They are allowed to appear physically. Children with no ports are handled separately as disconnected components, or excluded under the connected decomposition. For a fixed bounded-order native torso the argument below can instead regard every torso vertex as a named node, and use no native routing or localization.

**Bounded essential child list.** Run the subgroup localization of signed-high-connectivity-traces.md on the native graph alone using its original k-coordinate labels, obtaining L and P0. Include all parent ports in P. Switching the native graph into L outside P must transform pins, moments and virtual child gain labels consistently: a pair-chain gain is shifted by the two endpoint potentials; a cycle gain is invariant. Evaluate default moments on inverse-shifted original states. Equivalently extend the native gauge arbitrarily over child interiors. No recurrence changes original labels.

In a true full assignment collapse native vertices outside P to bins (part,x modulo πL). Form an abstract graph on ≤B=|P|+p2^k nodes comprising the bins and individual hole vertices. Each actual inactive native edge outside P is a zero-gain loop modulo L. Include actual zero hole contacts and the artificial parent trees. Replace each child by its full port pair-chain forest and its zero-boundary cycle credits. Colors occurring exclusively inside a child and not on its ports are confined to that single child; mark all such children, at most p. Ignore these closed colors for native torso connectivity. The abstract graph for every remaining used color is connected by original augmented rooted connectivity. Its cycle-gain span modulo L (markers appended, original L embedded with zero marker) together with the separate child cycle credits contains all required augmented gains. Contraction is valid for this direction even if an original bin was disconnected.

Retain a spanning forest of this abstract graph (≤B edges) plus ≤k+a further edges whose fundamental cycle labels, together with ≤k+a actual child cycle credits, span the total quotient gain space. Choose greedily in a space of dimension ≤k+a. Mark the children supplying any such edges or credits. At most B+2(k+a) additional children are marked. Endpoints of actual nonchild hole-to-bin edges used can be recorded as bounded native portals; alternatively include one actual representative per hole/bin/full-label type. For every other child compare original nonport moments with its default at the ORIGINAL port states. Keep ≤r(p+t) more whose discrepancies sum to the total discrepancy. Reset the remainder to default. This only establishes abstract feasibility: some original connections inside a bin may have been lost. They are produced afresh by native routing below. Thus no many-port path saturation is presumed.

Enumerate these ≤e=p+B+2(k+a)+r(p+t) exceptional children, their lower summaries and consistent actual endpoint states, pinning ≤ae outside endpoints in their assigned bins. These bounded pins stay in their bins; moving them into P and recomputing the child-exception threshold is neither necessary nor justified. Enforce exclusivity of all child-only colors. Each exceptional child provides its nonport moment, its cycle credit and its selected port-pair chains as actual finite SKELETON arcs. A pair of ports may belong to different bins of the same part. Do not insert virtual edges into the native linkage graph. Fold every remaining child default into its individual port charges/offset. Guess surviving native part charges/switch moments or use the target tensor with these offsets. Check the abstract finite skeleton's connectivity, its quotient cycle credit plus known child cycle credits, and native moment feasibility. Keep true pinned representatives for every used hole-bin edge; each outside endpoint of any exceptional virtual arc is already pinned.

**Lift.** Use the native high-connectivity construction: fixed actual pins/portals attach to their designated bin roots with prescribed projected switches, charge-reserve sites have both options, and internal rooted cycles generate L∩T-perp. The group for native linkage is still the original L. All artificial marker bits are zero on native edges; thus the kernel that must be generated inside L is exactly L∩T-perp. Grow remaining native vertices by a multi-source forest and correct native tensor moments. Every inhabited native bin is connected. Every skeleton arc has an actual path for connectivity and an actual chain for full gain modulo L (include the two bin-root paths as necessary). Marked parent arcs are fixed and artificial; remove them from a chain using its prescribed marker bits to recover the parent boundary. Contributions from virtual arcs lift via the exceptional children's actual chains. Quotient cycle credits lift up to L∩T-perp, supplied by rooted cycles. Therefore the original rooted lower relation and connectivity hold. Each default child attaches every new vertex to a port and has exactly its folded moment. Restore original assignments, deleting all artificial objects before replay.

For the bounded-order torso case every native vertex is explicitly assigned; replace the bins by the actual vertices, use no quotient, and check the forest/credit and moment conditions directly. The same bounded exceptional-child count applies with B bounded by torso order.

**Uniformity.** If subgroup localization returns |P0|<d, use B≤d+a+p2^k above. Bounds on exceptional pins ae, native portals, roots, charge reserves, prescribed linkage and required retained model order are functions solely of d and original parameters. In the backwards Geelen–Gerards size recurrence use this new bound at each localization stage as in signed-high-connectivity-traces.md; upon larger subgroup the recursion has depth ≤k. The original assumed vertex-connectivity exceeds the final computed bound. Per tree node there are N^{e} guesses times finite state choices and one fixed-parameter polynomial native computation. Every child table is evaluated ONCE with the original a,k,r,p; all temporary parent markers are local. This gives a genuine transition for large native torsos and constant adhesion, not just a finite-state claim on their cuts. It does not assert all graphs have such a decomposition, nor that virtual completion edges alone can supply the needed native group linkage.
