# Fixed-rank perturbations on robust bounded-diameter cographic hosts

Use the mixed-defects exact trace algorithm with the following changes. For constants r,k,D≥1 there is an explicit B below. Supply and check the indexed simple connected host graph G and the representation ker q=cut(G)⊕Z of dimension k modulo cuts. Promise that after deleting any at most B vertices, every nonempty remaining graph is connected of diameter at most D. For fixed B,D this promise itself can be verified in polynomial time. If n is bounded in B,D,k,r, use literal exhaustive search instead. Larger graphs of minimum degree at least εn and vertex connectivity ≥B+1 satisfy the promise for D=ceil(6/ε)+3 once n≥2B/ε: along a shortest path the open neighborhoods of every third vertex are disjoint and each remaining degree is at least εn/2. This includes the previously treated clique and bounded-complement-degree classes for all sufficiently large n.

At each global localization stage P,L use packs of disjoint simple cycles of length at most g=2D+1 with linearly independent gains in L. On the eligible graph (delete P and every used pack vertex) a BFS spanning tree has depth ≤D. Its fundamental cycles have length ≤g and generate the entire cycle space. Searching those cycles or enumerating short cycles therefore finds an independent gain if any exists. If the attempt fails, add the used pack vertices to P and reduce the labels modulo the last partial gain span by a vertex potential derived from the spanning tree. All other localization details, templates, projections, moment tests and original-ID semantics are as in signed-clique-mixed-defects.md. In particular all P-to-bin and P-P portal checks now require the actual edge to exist. The graph is never completed by adding edges.

A fresh pack of l=dim L cycles realizes any required full gain in L between two prescribed eligible vertices. Choose two distinct vertices on each cycle. Join start to the first entry, consecutive exits to entries, and last exit to destination using paths of length at most D. At each join forbid all of P, all reserved or pinned outside vertices and roots, and all vertices in all kept packs and all already selected internal join vertices, except the two endpoints needed in this join. This ensures internally disjoint joins avoiding cycles and special sites, and all edges have labels in L. Traverse either of the two arcs of each cycle: their gains differ by its chosen independent full gain. Concatenation realizes any full gain by solving in this basis. For a closed request start and destination are the same root, and the resulting route is a simple cycle (l≥1). For L=0 a distinct-endpoint request uses one length≤D path under the same avoidance rules; no rooted cycles are required. If in a closed request with one cycle both joins would use the root internally, keep it forbidden on every join for which it is not the designated endpoint. All initial endpoints are outside P: incident P edges are separate actual portal/skeleton edges.

For the default assignment of all remaining ordinary vertices, retain their induced graph together with one reference-bin root, discarding all other fixed vertices. This graph is connected by the promise. Put each ordinary vertex in the reference bin and set its projected switch potential along a rooted spanning tree starting at the chosen root. All edges are outside P with gain in L, so these give valid menu entries. This replaces direct attachment to a clique root. The moment-reserve argument permits different initial potentials at different ordinary vertices. After the reserve corrections the entire tree stays attached. The proof of the final inactive cycle-gain space, supported translations, exact named trace and witness replay is unchanged.

**Uniform constants.** As in the clique proof, J=(r+1)2^k, N(b)=J+bJ2^k+(2r+1)r for b=|P|. Choose M(b)=3N(b)+k+1. Set b_0=0, b_{j+1}=b_j+gkM(b_j) for 0≤j<k, and b=b_k. Safe deletion budget
B = b + gk M(b) + 2N(b) + (D+1)(k+1)(2N(b)+k+1) + 10.
It bounds every BFS exclusion, all fixed pack/portal/reserve vertices, all join internals over at most 2N+k requests, and the bounded set excluded for the final spanning tree. This is computable before reading G. The full algorithm runs in polynomial time for fixed k,r,D. By adding boundedly many private-coordinate checks as named rows and filtering the augmented trace subspaces, the result extends to all bounded two-sided code perturbations of the supplied cut space.

No claim is made for arbitrary low-connectivity or large-diameter cographic hosts. The hypothesis concerns the underlying vertex graph; large graph or matroid width is allowed.
