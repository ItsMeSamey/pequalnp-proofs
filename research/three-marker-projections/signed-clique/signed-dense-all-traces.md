# Fixed-name exact traces on signed dense graphs without a width expression

Extend signed-clique-all-traces.md to any supplied connected indexed simple graph G of bounded maximum complement degree d. Verify ker q=cut(G) ⊕ <z> as before; r≤6. Use the same injective shrinking and the same two exhaustive cases.

In the pure case the internal components induce subgraphs: after shrinking to the union of the supported cuts, all selected edges cross components. An internal odd-z cycle is necessary. A shortest odd cycle has no chord (one side of a chord is odd), so its length is at most d+3 since each vertex misses all but two of its cycle neighbors. Guess this cycle, contract it, sum its original vertex charges and invoke the dense-cographic exact connected partition algorithm. The quotient after simplification still has complement degree at most d: contraction introduces a nonneighbor only where all contracted vertices were nonneighbors. Restore original crossing edges. The guessed internal cycle excludes every supported translate.

In the translate case enumerate h charges, hyperplane and translated gain as in the clique proof. Use its abstract charge DP, reserves T,B_i,R, and charge correction. Before building the h cores, forbid these reserves and all nonneighbors of R. This excludes only a bounded number of vertices. Seek an odd cycle in the remaining induced graph. If one exists, choose a shortest one (or enumerate length up to d+3). Its internal switches include at least three distinct normalized connected zero graphs: any prescribed single nonzero cycle edge gives consistent vertex bits, with the other cycle edges a spanning path. Grow this core until its size exceeds d and the number of connected switches exceeds r (two new common neighbors suffice for the latter). At every growth step choose a remaining vertex adjacent to the entire current core, also outside all initially forbidden and previous core vertices. Failure to find one because of size implies bounded n: at most d times current core size vertices outside it miss some core edge. All core size bounds depend only on d,r. For each common neighbor the doubling-minus-one bound continues to hold. Remove the core and repeat. If no odd cycle remains at any stage, z is a cut on the remaining graph, componentwise even if disconnected. Switching yields a defect supported incident to a bounded set P (initially forbidden and used cores); see the explicit fallback below. Otherwise every core is adjacent to every reserved switch vertex and dominates all other vertices by its size >d. Now the clique construction of the partition and switch works verbatim. It produces a selected set consisting of all existing crossing edges and the translated word, preserving parent edge IDs.

**Bounded defect-cover fallback on an unbounded-width graph.** Retain the pure branch. For the translate branch, normalize z to zero on edges outside a bounded vertex set P. Enumerate part and switch labels of every vertex of P. Outside P a vertex belongs to one of 2h bins (part j, switch bit x). Within a part two distinct bins have no zero edges between them, and each bin induces its entire graph as zero edges. Enumerate the exact memberships of all bins of size ≤2d; declare the other bins large. Force every declared large bin to size at least 2d+1 by recording its capped size in a vertex DP. Each such bin is connected because two nonempty nonadjacent sides would each have at most d vertices. For all remaining vertices, guess their large bin by DP transitions and record (i) each part charge sum, (ii) total switch charge sum, (iii) for each large bin the subset of P with at least one zero edge into that bin inside the same part, accumulated by union. These data per transition are computed from the actual vertex's adjacency and z label to P. Initialise with the fixed P and small-bin vertices. Require the specified part sums and Aδx=u+A(z). For connectivity, form in each part the finite graph of its P vertices, its small-bin vertices, and one node per large bin. Use actual zero edges on P and on fixed vertices. Large bins have edges only to P among other nodes; mark these by (iii). Check this finite graph is nonempty and connected. It is exactly the contraction of the known connected bins in the within-part zero graph. Backtrack assignments; select all existing between-part edges plus supp(z+δx), then test original trace by elimination. This is exhaustive for every injective translated witness, using its actual component partition and switched word. No assumption about underlying clique-width is needed. Complexity is polynomial for fixed d,r including enumeration of bounded small bins. The fallback also yields an elementary implementation option for d=0 in the clique theorem.

This gives one-/two-tag physical rank-four search whenever the derived indexed q meets the supplied dense rank-one cut-code promise. The direct proof above is for simple connected host graphs; no implicit edge completion, sign normalization on added edges or recognition claim is used.
