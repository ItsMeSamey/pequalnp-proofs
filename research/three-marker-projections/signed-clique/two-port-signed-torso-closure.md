# Uniform two-port signed torso closure

Fix global k,r,p,T,π with t=dim T. Supply a tree of edge-disjoint connected pieces where each oriented cut shares ≤2 physical vertices. Verify real separators, disjoint interiors and running intersection. Torso adjacencies include the two-port child port pairs. Across each cut store its exact port states, used colors, nonport tensor moments and a LOWER relation on (port boundary parity, full gain) realized by inactive chains even on interior vertices. For each part containing ports every vertex must reach some port of that part. Every used part having no port must be internally connected (and globally exclusive). Active requirements mean same part and projected gain equal switch difference on each inactive edge. Interfaces have ≤k+1 independent relation vectors; recursive parameters never change.

**Saturating defaults.** In each full two-port descendant choose a two-root spanning forest with one tree per port u,v. Require crossing edge gains (transformed by adding the two incident tree paths from their roots) to project onto every possible projected simple u-v path gain. A supplied forest can be verified using prescribed gain paths. This forest always exists for t≤1: if one gain occurs, split the u-v path of any spanning tree. Otherwise use two simple paths P,Q with differing parity; obtain via the prescribed-gain path theorem. Compare each excursion of Q between consecutive visits to P with the P segment between its endpoints. These discrepancies sum to the discrepancy of the entire paths by telescoping on P, so one ear forms an odd cycle with its P segment. Take P plus this ear. Remove one edge from each of the two arcs between the ear endpoints; the resulting two trees retain the u and v tails of P respectively. Extend them greedily to a spanning two-root forest. The two removed edges' transformed gains differ in projection. Thus for k≤1 every T admits the defaults. No automatic saturation claimed for t>1.

Assign each tree its root's part and its root potential plus projected tree path gain. Fold each tree's nonport total charge into its own root and add the fixed switch-moment offset. Nonforest edges within a tree give constant cycle credits if their transformed gain projects to zero. Crossing edges produce a virtual port-pair bundle with the actual full transformed gains. Remove duplicate full gains. This gives precisely the default inactive relation by contraction of the two inactive trees. If an old assignment connected u,v, a simple inactive path had the prescribed projected gain, so at least one default option still connects them. One-port descendants have the prior single-tree default.

**Sparse exceptions.** At a torso ≤p children use colors absent at both of their own ports: each such color is entirely confined to that child because all parent ports lie on the torso side. Keep those children. Each other child's vertices reach ports of their color. Default assignment preserves the children's required connection of same-part ports and attaches all new interiors. Fix ≤k+1 original parent chains generating its required boundary/gain relation. In each other child use empty default chain for zero restricted boundary. For two odd ports, the original chain contains an inactive port-to-port path; use a default path whose projected gain matches those endpoint switches. Thus restricted boundary is preserved for every chain. Record per child's discrepancies of these full chain gains and its whole nonport moment, at most k(k+1)+r(p+t) bits. Keep ≤that many children whose discrepancies sum to the total of all discrepancies, by representing the total in an actual basis. Reset all others. All parent chain gains, connectivity requirements and tensor moments persist. This does not bound the length of any traversal.

Enumerate ≤e=p+k(k+1)+r(p+t) exceptional child IDs, their entries and consistent pin states. Enforce that their nonport-only colors are disjoint from torso colors and other exclusive children. An exceptional child contributes its actual moment and the cycle credit of its zero-boundary relation. If its relation contains ((1,1),g) add one port-pair edge of gain g, otherwise omit it. Differences between such gains are already credited. The realizing chain need not be a simple path of gain g: its physical boundary guarantees SOME real path and its full gain realizes the desired algebraic chain. This suffices for both connectivity and substitution of any virtual edge in a parity/gain calculation. Full actual child relations may be chosen for completeness; extra physical paths under lower relations cannot hurt.

**Uniform local rooted test.** The complete virtual torso now has folded local vertex charges, fixed offsets, lower internal cycle credits H0 and fixed states at ≤2e+2 vertices. For the parent boundary whose ports a,b have equal color, add ONE local edge between them with full gain (g*,1) in a temporarily augmented group F2^{k+1}, where πg*=x_a+x_b. Give all other edges zero new coordinate and let projection ignore the new bit. The special edge is therefore inactive. Connectivity of each used color in the augmented torso is exactly connectivity in the sense that all vertices of this common port color can reach a port, and all other colors are connected. Map every required relation vector (β,g) to (g+βg*,β), where β=1 denotes parity at both ports. A zero-boundary physical chain yields an augmented cycle with β=0. A parity-one chain plus the special edge yields one with β=1. Conversely remove that precisely marked edge wherever its coefficient is one. If port colors differ, a parity-one relation is impossible and no extra edge is needed; each port color must be connected. The same simple cycle-only treatment covers ≤1 port. All cycle statements are linear even when a realizing chain is disconnected.

Enumerate a local torso cycle lower space such that together with H0 (embedded with marker zero) it spans the transformed required vectors. The local oracle receives connected parts, exact adjusted moments, fixed states and this lower cycle target. Its parameter k may increase by ONE only inside this independent call; child table entries everywhere use the original k. Any local gauge shift must update the pinned potentials and target switch moments with FOLDED charges and be inverted before glue (as in one-port-signed-torso-closure.md). Restore original child assignments and evaluate original support at the root.

**Applicable class.** The local oracle must handle parallel gain options, boundedly many adjacency deletions and at most one extra marked edge. On uniformly bounded-degree vertex-expanding simple torso skeletons this follows from the connected expander result via one-port closure and signed-expander-traces.md. Distinct options per adjacency ≤2^{k+1}; retaining labelled parallel edges leaves the degree/expansion proofs on the underlying simple graph, keeps true edge choices for each clone, and is permitted by the subgroup-model and disjoint-path theorems. Constant loops can instead contribute their inactive cycle subspace directly. Before exception guessing every nonempty connected two-port child has a crossing edge in its forest, so its pair remains adjacent. Exceptional summaries remove at most e adjacencies. Adding the one marked edge raises simple degree by at most one. In every resulting connected component the vertex expansion bound is positive uniform: for X of size ≤half its component every old exterior neighbor lost costs a deleted edge; |N_new(X)|≥α|X|−e, and nonempty proper sets in a connected component have ≥1 neighbor. Hence use α/(2e+2). If several components remain, allocate disjoint nonempty used colors, moment totals and cycle credits to them (at most p if feasible). The oracle for a connected component may solve its own one-port block decomposition with fixed local parameters; it never invokes this two-port recursion. Bounded-size pieces are immediate.

Evaluate the constant global state table once per tree node. At most N^e choices of child IDs are considered per entry, times constant state guesses and one uniform polynomial torso computation. Thus there is one fixed polynomial exponent independent of tree depth. This covers every k≤1 exact named trace on the supplied two-port trees of such torsos, including all five/six-name targets and their original physical reductions when the indexed code presentation is verified. More generally it works at any fixed k provided the saturated forest for every translation guess is verified. It does not establish the existence of these trees or forests for arbitrary high-rank inputs.

When the connected-expander local oracle calls the nested one-port closure, preserve its bounded externally prescribed vertex set Z: retain every child containing any Z pin in its strict interior (≤|Z| additional exceptions), enforce pins on the torso directly, and give each child table only the subset of this SAME original Z inside it plus its one attachment state. Temporary pins chosen for a parent's exceptional children are not recursively expanded into new external pin lists. Equivalently use the centroid block and bounded pendant components in one level. The bound stays independent of tree depth.
