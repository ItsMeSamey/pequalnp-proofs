# Decision-only composition on color-routable physical interfaces

Fix p,r,D,a. A connected graph is supplied with a polynomial tree decomposition of adhesion ≤a and each completed torso in a subgraph-closed class with a polynomial witness algorithm for connected spanning partitions into any fixed number of colors with boundedly many pins and an arbitrary bounded-degree GF₂ site-indicator nonvanishing test. The oracle may be one-sided randomized with verifiable witnesses. For a child side with contact T, define its support graph J_T on T by making N(C) a clique for each component C of the actual strict child side, using original physical contacts only. If there are separately owned contact-contact physical edges, retain them as actual bag edges; repeated use as connectivity edges is harmless in this decision-only argument. Require that for EVERY coloring of T, all connected components of the monochromatic subgraphs of J_T can simultaneously be connected inside that side by vertex-disjoint connected sets with the specified ports and colors. Singleton roots stay available. This is a polynomially checkable hypothesis at fixed a using rooted-minor containment on a fixed edgeless pattern; flood uncolored sites from the connected root sets, since each strict component has a neighbor in T. Store one actual default extension for every assignment on T, independent of the unknown global solution.

For a≤3 there is no additional routing hypothesis. In each C choose its repeated neighbor color if any, otherwise a fixed first neighbor's color. Since |N(C)|≤3 there is at most one repeated color. Giving all of C this color realizes simultaneously each required equal-color pair in N(C); same-color connections along chains through equally colored contacts compose. No contact is required to reach every strict component. This includes a physical claw on three independent leaves. For larger a the test may fail (a four-leaf star and two equal-color pairs), and only verified interfaces are asserted.

Use the actual regional records in joint-spqr-moments-clean.md: whole palette, boundary colors, open/closed status, guaranteed terminal joins (extra joins allowed), strict-interior binary score totals, actual degree-D moment bases. At a bag freeze the colors of an arbitrary feasible regional witness. Reserve all children with a color closed inside (at most p). Any remaining child can reset to its stored physical default: every former monochrome excursion between boundary contacts projects to a same-color walk in J_T, and all such joins are preserved by the chosen default. The global palette remains and all new strict vertices connect to a contact. The product of a separating degree-D test and the desired binary score indicators has degree ≤D+pr in independent child reset bits. An accepted mask of minimal nondefaults therefore has at most D+pr more exceptional children by the Boolean point-indicator degree argument. Replacing each exception by an actual row in its exact record preserves the test one at a time and cannot lose required joins.

A partial region may have several components of one open color reaching different parent contacts. In the guessed local core, form a SKELETON palette of connected components of each bag color, splitting that physical color into separate labels. Use one label per connected component of the projected witness on the bag with default support edges and true exceptional child joins. Every such component of an open parent color must reach a parent contact: any path in the original region between two bag sites projects through owned children, and after defaults and true exceptional joins all required connectivity is retained. A parent-closed color meeting the bag has a single projected component. Thus at most a+p nonempty skeleton labels are needed. Closed colors appearing only inside a child are handled as before. Guess the map from skeleton labels to physical colors, pins on parent and exception contacts and one representative of each skeleton label. Substitution of a physical-color indicator by a sum of its skeleton-label indicators is linear. Enforce each required boundary join by assigning its endpoints the same skeleton label; permit extra joins and validate the reconstructed actual record. Open labels must be pinned to at least one parent contact; absent boundary colors are closed and allowed at most one skeleton label. A subpalette of one color is allowed.

The local graph contains actual bag edges, all J_T edges of default children, and only guaranteed true same-color joins of exceptions with bag colors pinned. It is a subgraph of the completed torso. Require connected parts only in the skeleton labels. The original projected components give a connected-label witness there, even when the physical bag restriction was disconnected. Conversely such a skeleton partition expands to a valid regional physical coloring: default virtual edges used within a skeleton color have a realizable physical route for the underlying color by the stored policy, even if this joins other labels mapped to that same physical color. Exceptional joins similarly use certified paths. Open strict components all reach their boundary labels and closed colors are checked globally. Every default strict site has a prescribed color as a function of ≤a contact colors, hence its one-hot indicator pulls back as a polynomial of degree ≤max(1,a). Fix the exceptional interiors. Multiply the original separating test by all the requested score-bit indicators first and use the local solver on degree ≤max(1,a)(D+pr) with explicit pins. These larger degrees and the ≤a+p temporary labels live only INSIDE the local oracle. Child DP always builds degree-D rows for the fixed original p labels; no growth with depth occurs. Standard linear separation recovers actual row bases in each score/record bucket with polynomially many oracle calls. One-sided randomized calls can be amplified to inverse-polynomial miss probability per adaptive call and all final witnesses verified.

A fixed orientable genus base supports every fixed p,r,D and bounded pins: expand the polynomial times all score indicators into sums of fixed-mark grove conditions with one prescribed root per color, assign roots explicitly by enumeration, and use the arbitrary fixed-mark surface evaluator in grove-three-sum-tree.md, with edge variables and one-sided PIT exactly as in the existing indexed grove reduction. All precolored sites are added to every marked condition. The earlier charged-modulator-lift.md extends to boundedly many vertex additions of arbitrary neighborhoods with fixed p,D (require the base on all bounded new color counts). A bounded modulator may also be found by enumeration and the fixed genus embedding algorithm of Mohar, https://doi.org/10.1137/S089548019529248X . Therefore claimed decision and physical traceback apply to trees of completed bounded-apex bounded-genus torsos with adhesion at most three, or with any fixed adhesion passing the physical joint-connection tests. The entire graph need not have a bounded global apex set or genus. This is a decision-and-witness consequence, not an exact grove count for apex torsos.
