# Single-occurrence lookup for two shared inputs

Let x,y be named Boolean inputs and let D_ij, 0≤i,j≤1, be four disjoint private two-port circuits, where true gives a swap and false gives identity. Give each vertex in K2,2 a terminal and two incident stubs. One native switch chooses a transposition of the terminal with either stub, reflecting the other. A fixed transposition and an optional three-cycle realize the two alternatives. Between the facing stubs for i,j insert D_ij. A swap transmits to the other side, identity reflects.

A terminal follows its selected stub. If D_ij reflects it returns immediately. If D_ij transmits but the neighbor did not select this stub it reflects there and returns across the same edge. Otherwise it reaches the mutually choosing neighboring terminal. Thus the external first return is exactly the matching of mutually chosen true edges, even if all four tests pass. Detached private circuits do not affect this trace.

Place a marked pointer on R_x by a module with baseline (R0 m) and one data-controlled three-cycle that changes this permutation to (R1 m). Tracing out private m leaves the row paths unchanged. Do the same for C_y. Close the four terminal tracks. The two pointer marks join iff their terminals are matched, which some independent terminal choices attain exactly when D_xy is true. For disjoint existential private circuits one uses swap attainability in the same argument.

A CNF with arbitrarily reused x,y and all other variables private to individual clause tails has a linear-size assignment-faithful compiler using each named switch once. Drop tautologies and duplicate literals. A clause containing both hubs requires its tail on exactly one hub assignment. Group by that cell and AND the tails for its D_ij. Empty groups are true and empty required tails false. OR within tails and AND within groups are read-once deterministic two-port operations: to AND, compose the child swaps on successive edges of a path, close the carriers, then cut the two endpoint marks; the new return swaps exactly when all path edges are present. Negate by a fixed swap and apply De Morgan for OR.

Clauses containing just one hub yield a private AND for the affected row or column. Put each pointer on a separate leaf baseline cycle joined to its terminal iff that unary group passes. The matching with any such leaf edges is a forest, and the two marked leaves join precisely when both selected groups and D_xy pass. Combine a disjoint unconditional AND for clauses with neither hub by cutting the two final marks and conjoining the resulting return. Private inputs appear exactly once because the tails are disjoint. All original assignments and all auxiliary configurations are covered. This is distinct from enforcing two arbitrary marked predicates that share a network.

Strict ternary clauses containing both hubs and distinct private variables already contain K2,m as an incidence subgraph, so the source family has unbounded hub degrees and cycles. It excludes arbitrary repeated private inputs. Physical checkers are check_guarded_square_lookup.py and check_partial_lookup.py in the guard feedback directory.
