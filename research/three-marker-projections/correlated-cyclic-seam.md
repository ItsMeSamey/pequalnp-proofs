# Correlated binary seam actions can encode 3SAT

Input consists of distinct two-port switch sites and fixed directed permutation wiring, with two physical marked wires. Each site returns identity or the transposition. Restrict the simultaneous action vector to a supplied binary linear subspace L; in the following construction L only identifies specified occurrence bits. Decide whether some allowed vector joins the marks.

Create one site per literal occurrence of a 3CNF. Its action represents false by identity and true by transposition. Use a fixed transposition for each negation. To AND two disjoint child circuits, connect their two-port interfaces onto consecutive path edges (0,1),(1,2) of three rails in sequence, forwarding the third rail at each stage. Close all three rails, then cut just before seam sites 0 and 2. The closed reference product joins 0 and 2 exactly when both path transpositions are present. Directly following the two cut inputs now yields swap precisely when the marks were joined, else identity. Detached internal circuits do not change this first return. OR follows by De Morgan. Recursively realize the formula tree, then close its final output and observe the two distinct output seam wires. Circuit size is linear in formula size. If a physical implementation of binary swaps is needed, one optional native rotation with one private feedback channel supplies the two actions.

Give variable i the generator of L that is one exactly at its own occurrence sites. When each variable occurs, the supports are nonempty and disjoint. Hence parameters are unique, any allowed action vector decodes by reading one representative bit per variable, and every assignment encodes one allowed action vector. The final marks join if and only if that original assignment satisfies the formula. The reduction is parsimonious in distinct seam action vectors; free unused source variables should be deleted for decision or separately counted. NP membership follows by testing linear membership and tracing the candidate permutation. Thus decision is NP-complete and the exact count is the ordinary #3SAT count on these instances.

The restriction L is a genuine external coupling in the input. The result does not establish hardness for independent native switches. If an independent open native network preserves each of several fixed boundary blocks for every setting, its complete boundary action table is a Cartesian product, as shown in native-block-factorization.md. In particular it cannot have the proposed nontrivial repetition relation as its exact simultaneous image across distinct blocks.
