# Bounded vertex deletion to chordal, with unrestricted attachments

Consider p nonempty connected spanning colors on a connected indexed graph G. The acceptance test may be either (i) nonzero of an explicitly supplied bounded-degree polynomial P over a field in the vertex-to-color indicators, or (ii) prescribed sums of labels in a fixed finite abelian group Gamma. In (i) coefficients and representation size are charged; fixed binary sums and an explicit alternating-form test on two indexed cuts are examples. Suppose X consists of k sites with H=G−X chordal. For fixed k find such a set by enumeration and chordality testing. There is no restriction on adjacency to or among X. If X is empty use the prior chordal theorems, or add any physical site to X.

Choose a PEO in each H-component ending at a designated gateway adjacent to X, possible since a prescribed vertex can be last in a chordal PEO (repeatedly remove a simplicial site other than it; a noncomplete connected chordal graph has two nonadjacent simplicial sites). G is connected, so every component has a gateway. Order the H-components first and all of X last. Define defaults in H by its earliest later neighbor; at each gateway default to an adjacent site of X. On X put default stops. These physical defaults are acyclic.

**First compression, before requiring an increasing witness.** Take any true partition, and any spanning tree per color directed toward a chosen root. Protect these p roots and all X. Start with all sites retained, then minimize the size of a subset S closed under these true tree parents, containing the protected sites, whose induced filling still accepts. Fill each omitted site by following the default to its first retained site; all default stops are protected. Retained sites keep their original colors via their retained trees. This is always a connected partition: each omitted site's physical path ends in the tree of its assigned color. No order is assumed for the true tree arcs.

The leaf-basin lemma of abelian-parent-skeleton.md applies to the unprotected leaves. Their next retained default contacts exist; the graph on unprotected leaves pointing to these contacts when they are leaves is a forest. An independent set of at least half the leaves can be removed in any combination; their disjoint basins move to fixed surviving successor colors with no secondary changes. For group totals this bounds the number of unprotected leaves by L=2(|Gamma|^{p−1}−1). For a test of degree D use L=2D instead: on independent deletion bits each vertex-color indicator becomes a constant or an affine function of just one bit. Thus P on those bits has degree at most D after multilinearization and is nonzero at the all-zero choice. If it vanished at all other Boolean points it would equal a nonzero multiple of product(1−x_i), of full degree by multilinear uniqueness. With more than D bits a successful nonempty deletion therefore contradicts minimality. This reasoning uses actual full-color tests, not independent per-monomial witnesses.

**Bounded number of increasing roots.** Total retained leaf count is at most L+k+p. Deleting X from the p retained trees leaves at most p+k+(L+k+p) forest components: removal adds at most the sum of the numbers of retained children at sites of X, bounded by k plus the sum of positive (child count minus one), itself at most total leaves. Each remaining component is a connected vertex subset in H and may be reoriented using any physical edges inside it monotonically in the chosen PEO toward its maximum. Put each X site in its own singleton tree. Between all the resulting fragments of each original tree keep spanning physical edges from the original retained tree, for example after contracting its component fragments and the singleton X sites. No original leaves, charges or acceptance terms were moved in this reorientation. Every omitted site continues along its old default to the same retained site; this also increases in the chosen H-then-X order. Consequently the full filled coloring is now described by a genuine increasing parent map with t≤L+3k+2p stopping roots, and t−p physical links between trees of the same color. These roots include every site of X. Pin both endpoints of each link to their respective tree roots. The new trees need not have few leaves; only their root count is asserted in this step.

Enumerate the root tuples, their colors, and all actual intertree links/pins requiring them to connect the roots of each color. The common-choice linear-span algorithm in ordered-charged-partitions.md tests (i) multiplied by the pins, with all factors applied to one physical parent map. A positive map plus the links connects precisely its p colors. This costs n^{O(D+k+p)} for fixed field arithmetic and an explicit polynomial of polynomial size. If no true partition existed a successful connected coloring cannot be returned.

For (ii), apply the monotone group leaf-basin lemma AGAIN to each rooted and pinned query, now protecting every stopping root and pinned endpoint. It makes the number of its retained path sources bounded in k,p,Gamma. Enumerate sources and their required roots. Precompute U comprising all X, and within H all earliest-later ancestor chains of the guessed non-X sources, roots and pins. Any increasing physical step within H jumps to an ancestor, every step out of H lands in X, and X are all stopping roots. Thus every retained path stays in U. For an omitted H site outside U follow the default to its first U contact, including through the gateway into X if its whole H-component is untouched. No stop occurs outside U. Accumulate all these charges at their contacts. In the induced sweep on U the internal H defaults cross each cut in at most one position per source chain, and other default heads lie in X. With these boundedly many heads the exact group-flow buffer of abelian-parent-skeleton.md constructs the physical parent choices and checks joint sums. Restore every off-closure physical default path. Runtime is polynomial for fixed k,p,Gamma, with no mixed-field assumption. Imposing a bounded-degree predicate over an incompatible field jointly with this arbitrary-group version is not claimed.
