# A signed three-sheet network for the four-direction ternary syndrome

Write U=a+c+d and V=b+c−d in F₃. The network below uses each full trit a,b,c,d exactly once. It admits one common native routing that joins three specified marks if and only if (U,V)≠(0,0). The two-mark version with the first two of these marks recognizes exactly (U,V)≠(0,0) OR a=2.

Use base vertices P,Q with three sheet indices x in F₃. The edge stages send $(P,x)$ to $(P,2a-x)$, $(Q,x)$ to $(Q,2b-x)$, $(P,x)$ to $(Q,c-x)$, and $(Q,x)$ to $(P,x+d)$, respectively. Each stage is one rotation by its input and fixed slot permutations. For example, x↦2a−x is x↦−(x+a) in F₃. A dense affine score in disjoint physical variables can be substituted by serial rotations on its three rails. At each of the six sheet vertices put an independent two-input two-output router allowing both permutations. One optional native binary three-cycle with the third socket feeding itself realizes this router. Thus the directed network is balanced: indegree and outdegree are both two at every sheet vertex. Use as marks the three fixed inputs to the a stage, one for each P sheet. In any weak component there is an Euler circuit using every directed edge. Choosing local routers according to such circuits places every fixed arc of each component on one orbit; no router connects distinct components.

Traversing edge stages in either direction gives affine bijections of F₃. Each component's sheets over P form an orbit of the subgroup induced by closed walks in the base. This subgroup contains the reflection x↦2a−x, whose only fixed point is a. A common fixed sheet exists precisely when selecting index a at P and b at Q agrees with both link bijections, that is b=c−a and a=b+d. These equations are equivalent to U=V=0. In that case the subgroup is the order-two group generated by the reflection at a, so the orbit partition at P is {a}, F₃\\{a}. Otherwise the subgroup contains that reflection and an element moving a, hence is transitive (in fact all of S₃). This gives both asserted native predicates, with a single common physical setting for the three marks. The two-root false positives on the zero fiber are exactly the three words with a=2.

For comparison an anchored undirected construction has vertices X,P,Q. Put a fixed reflection x↦−x at X and use labelled links X→P of translation a, X→Q of translation b, P→Q of x↦c−x and Q→P of x↦x+d, treating every link as traversable in either direction. A fixed sheet of the reflection at X must be index zero. It extends consistently precisely when the same two syndrome equations vanish. Therefore X sheets zero and one are connected precisely when the syndrome is nonzero. This anchored construction uses the two fixed marks directly; its base degrees at P and Q are odd, so orienting its four full three-sheet bundles cannot yield a balanced closed native wiring. The balanced construction above supplies the stated three-root result.

A fixed binary choice on every sheet router gives a deterministic permutation. In the accompanying checker there exist two deterministic settings that individually reject all nine zero words and whose union covers all 72 nonzero words; at the recorded marks each setting accepts 54. Choosing those two full settings under one native existential controller, without enabling unwanted intermediate settings, is a separate obligation.
