# One joined orbit can police only the data blocks it visits

Consider an open native network of independent three-socket switches. All settings preserve a supplied partition of its external input and output channels. Close the boundary with fixed feedback and observe two physical wire arcs, possibly internal. At a fixed setting joining those marks, let C be their physical closed orbit. Call a physical flip export-changing on block B if it changes the open boundary permutation of B in that same setting. Call it rejecting if it separates the two marks under the fixed closure.

If a flip is both export-changing on B and rejecting, C must meet an old open path from an input in B. Indeed a changed block permutation differs on at least two input images. Each changed path encounters at least one of the gate's three altered departures. Distinct old input paths have disjoint departures. Further, separating two marks on C needs at least two altered departures on C: cutting at most once preserves the whole old marked cycle as one contiguous chain, with the marks on passive subdivisions if necessary. If C contained none of the B paths, these requirements would consume at least four distinct departures. With fixed closure an old open path is entirely contained in one closed orbit, proving the assertion.

If fixed feedback closes each block to itself, C meets open paths of at most one block, or none when detached. More generally it can police only blocks visited by its itinerary. Auxiliary switches may be arbitrary in number. For a predicate defined by existence of auxiliary controls, freeze any accepting witness; a rejected neighboring named input has to reject also at those unchanged auxiliary settings.

In particular suppose two independently flippable named bits are separately exported by two invariant blocks, with the flip of each bit changing its own exported action at every setting, and feedback closing each block separately. No two-mark test with existential independent auxiliaries can accept exactly when those bits agree. At a witness for 00, both independent one-bit flips would reject and change their two respective exports. C cannot visit both blocks. The same argument applies whenever two rejected neighbors change separately robust data outputs, irrespective of the specific Boolean predicate. A test may still jointly read and check data without exporting both of them, may use cross-block feedback, or may encode a data change in multiple coordinated flips.
