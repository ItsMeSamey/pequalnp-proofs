# Every four-input Boolean predicate has a native closed physical realization

For every Boolean function on four input bits there is an explicit permutation wiring with one fixed marked pair and at most eight independent native three-cycle switches. Four switches are designated logical inputs. At each input word, at least one setting of the remaining switches joins the marks exactly when the function accepts.

The full catalog supplies 402 physical wirings, one per orbit under input permutation and bit complementation. Rows list the hexadecimal truth mask, two marked sockets, and the wiring as socket images. Each gate rotates its three consecutive sockets forward by one exactly when set. Apply the fixed wiring after these rotations. A logical complement is implemented by absorbing a constant rotation into the wiring and reversing that gate's orientation by a local socket relabeling. The checker traces every physical setting of every listed wiring, projects only its auxiliary bits, and verifies that the disjoint signed input orbits cover all 65,536 functions. The supplied witnesses use four switches for 63,072 functions, five for another 2,448, and eight for the remaining 16. The eight-switch bound does not assert minimality.

The last orbit is represented by accepting weights zero and two. Use three rails each for the independent ternary sums a=x1+x2 and b=x3+x4, and marking wires 6,7. Each pair of input rotations operates serially on its three rails. On tracks numbered from zero apply fixed wiring (5,7,4,2,6,1,3,0), followed by independent optional rotations (2,7,3), (0,7,3), (0,5,6), (0,3,6) in that order, then close the tracks. The accepted trit pairs are (0,0),(0,2),(1,1),(2,0). After wire suppression the 24-socket version has roots 14,15. The numbers of joining auxiliary words in binary input order are 1,0,0,4,0,3,3,0,0,3,3,0,6,0,0,0. The file lift_trit_observer.py independently derives this wiring and checks those counts.

A four-input library does not supply a reduction for unbounded SAT. A shared input switch cannot be assumed to provide separate copies of its rotation to independently closed cells. The catalog verifies a whole four-variable predicate with one fixed marked pair.
