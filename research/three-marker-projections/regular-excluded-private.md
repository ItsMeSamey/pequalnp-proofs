# Single-excluded-minor regular private matroids

For fixed binary named gain dimension, exact supported cycle image and an indexed support witness are decidable in polynomial time on arbitrary represented regular PRIVATE matroids N with no M*(K3,3) minor. The structural input is prior: Mayhew, Royle and Whittle, Proposition 2.13 (https://arxiv.org/pdf/0902.0837), states that the only 3-connected regular non-cographic matroid without M(K3,3) minor is M(K5). This is equivalently obtained using Seymour's splitter theorem (7.5) in Decomposition of regular matroids (https://web.math.princeton.edu/~pds/papers/regular/paper.pdf). Taking duals, each 3-connected regular private matroid without M*(K3,3) is graphic or M*(K5).

Compute an indexed proper 1/2-sum decomposition into 3-connected components, treating the usual circuits and cocircuits as graphic pieces as well. This requires no forbidden-minor oracle: from a binary matrix one may repeatedly find 1/2-separations by minimizing the span intersection cut function with two ordinary anchors imposed on each side for a 2-separation. With only unary exterior ports use the standard 2-sum tree (Cunningham–Edmonds); its 3-connected torsos are minors. On an exact 2-separation of represented columns the one-dimensional intersection supplies the virtual column on each side. Original integer site IDs and their named column gains remain attached to their unique real leaf appearances; shared virtual columns are bookkeeping with no original gain. A component that is not graphic must be the size-ten exception under the promise, so exhaustive indexed support enumeration handles it. For all other components reconstruct an indexed graphic matrix and use the graphic supported cycle image solver. Apply research/code-modular-score/supported-image-sum-tree.md to the dual row code, which equals the private cycle code and has the same unary gluing tree. Its supported response includes outgoing bit and complete gain image. Its zero-trace exception and linear-map correction keep the number of enumerated exceptional children parameter-bounded; copied local physical sections and stored predecessors reconstruct actual original supports. In particular, separate attainable gain directions are not accepted on different supports. No 3-sum theorem or universal matroid structure hypothesis enters this consequence.
