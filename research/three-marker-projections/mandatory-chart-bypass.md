# Mandatory chart anchors also supply silent primal corrections

Write each physical column as (a,t,h), where a is private and t,h are the two binary tag/height planes. Let E0 be mandatory, L0 its full physical span, D0 its private projection, C0=L0 intersect (T+H). Assume a compatible tag chart exists, so C0 lies in H. Such charts are exactly the extensions to private space of the linear map on D0 taking a to the tag t of a representative in L0. Therefore if these columns alone fix the value on every v in V for a private subspace V, then V<=D0: any vector outside D0 permits two different linear chart extensions.

Taking an L0 representative (v,t(v),h(v)), the named residual modulo C0 is a well-defined linear function on V. Its kernel consists exactly of vectors v such that (v,0,0) is already in L0. In particular, if anchoring forces t(v)=0 throughout V and C0 is a one-dimensional height line, this map has rank at most one. In a graph edge/control simulation aiming to pin all vertex potential differences to zero with this second backbone, take V generated by vertex boundary pairs. Fix a base vertex s. The images of the boundaries of s+v take at most two values. Any pair u,v in the same class has (boundary(u,v),0,0) in the mandatory span before a literal is used. Hence a fully faithful path interface cannot distinguish more than two silent-access classes. The assertion concerns forcing by the anchor set itself; correlations imposed by other selected columns are a different construction.

More generally, testing extension of a prescribed compatible E0 whose trace C0 is one height line reduces exactly to contracting L0: the named space in the quotient is (T+H)/C0 and the desired trace is H/C0. Indeed a further selected physical span has exact quotient trace if and only if its sum with L0 has exact original trace. This is a three-name one-line instance.

An arbitrary first-height choice need not extend. Give parallel s-t paths tag 00 and heights 0,e1,e2. For each of the three other tag words give two parallel paths heights 0 and a different nonzero height, covering all three height lines. The first group is a feasible theta. Each other group has a circuit with its assigned height line; once selected it fixes p(s)+p(t), so it permits only that group of complete paths and cannot yield the full height plane. Even requesting one witness of each first-height line can return three incompatible choices. Parallel paths may be made length two with distinct interior vertices for a simple graph.
