# Joint finite abelian charges on all chordal graphs

Use the physical skeleton theorem abelian-parent-skeleton.md. On a connected chordal G choose a perfect elimination order. In its reference tree F let each nonfinal site v point to its earliest later neighbor f0(v). This neighbor exists by repeated simplicial elimination preserving connectedness. Every later neighbor w of v is an F ancestor of v: if w is not f0(v), the two are later neighbors of v, hence adjacent; induction from f0(v), which precedes w, proves the claim. Compute this reference tree without suppressing any arcs at guessed stopping roots.

For fixed colors and prescribed group totals enumerate stopping roots, one per color, and optional boundedly many site-to-root pins. At each nonroot use f0 as default; at a guessed root the default stops. Valid guesses necessarily include the final site. A true solution exists under these parent directions because each connected color has a PEO maximum reachable from all its sites. The bounded-leaf lemma gives a retained physical parent forest whose unprotected leaves number at most L=2(|G|^{p−1}−1); here |G| denotes the order of the charge group, not graph size. Guess the leaf sources, all stopping roots and all pinned sites with their specific target roots.

Let U be the union of the reference-tree ancestor chains of all these sources, including the chains above guessed stopping roots. Each possible selected parent edge increases the order and goes to a reference ancestor. Therefore every feasible retained path from the guessed sources lies within U, even when an arc jumps over a stopping root. Every physical site outside U has a default path to a first contact in U, without stopping outside U since all roots belong to U. Add its charge to that first contact and retain the physical default path for the eventual lifting. Histories rooted at other sites cannot be lost: the retained forest of the normal form is entirely generated by its leaves (each protected leaf is already a source).

Run the bounded-path-walker construction on U with these aggregated charges, the actual increasing physical arcs, and the reference defaults stopped only at the actual roots. A cut of the increasing order crosses at most one reference arc per source ancestor chain, so at most L+p+number-of-pins different future buffer heads are needed. This bound is independent of the total reference-tree branching and of its uncompressed width. Traceback gives a single physical parent map, reattaching every omitted original site along actual default edges, with exactly its eventual color and original contribution. All group coordinates are tracked together by ordinary finite-group addition. The resulting algorithm is deterministic polynomial for each fixed number of colors and each fixed finite abelian group on arbitrary chordal graphs. Nothing requires a mixed-characteristic polynomial indicator.

The same proof works for an order with a physical increasing spanning reference forest such that every admissible increasing arc jumps to an ancestor in that forest, provided the connected parts can be certified with a bounded number of stopping roots and physical links between same-color rooted trees (then include all guessed bridge endpoint pins). A reverse depth-first order with its parent forest has the ancestor property in undirected graphs, but the number of required color roots need not be bounded. Ancestor containment alone does not give a general graph solver.

Independently of order, the bounded-leaf *existence* proof applies on any graph to any true rooted connected partition with a rooted physical forest of default arcs terminating in the stopping set. Retain subtrees closed under the true parent map. Outside sites follow only the acyclic defaults until first hitting the retained set, and then follow the true retained trees. Deleting independent leaf basins works unchanged since only the default successors need to be acyclic. Constructing such a bounded-leaf forest with all charge contributions on an arbitrary graph still needs an algorithm.
