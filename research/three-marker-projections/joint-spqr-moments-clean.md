# Joint charged moments on a recognized class of graphs with two-vertex separators

Fix p, a finite abelian group G, a field and a degree D. On connected graphs compute actual degree-D moment bases of connected spanning p-partitions in each ordered G-score bucket. The following recognition test suffices. Compute block and SPQR trees, refining polygon nodes into a path of three-vertex bags. Require each rigid skeleton to be small (fixed bound) or vertex-connected to the threshold below. Series, parallel and articulation nodes are unrestricted. This is a polynomial recognition algorithm using ordinary block/SPQR decompositions and vertex cuts. There is no prescribed layout. More generally the algorithm accepts a supplied tree of bounded or sufficiently highly connected physical/surrogate bags with the following disjoint edge certificates. This extends the binary ordered-sum theorem in research/span-separation/cographic-separators.md to simultaneous finite group scores and arbitrary single-field moment tests.

Use adhesion ≤2. At a rigid skeleton root the decomposition; omit a virtual parent edge. Every virtual child edge carries a simple path between its ends using only the interior of that side of the split (or an actual edge). Grow from a split of that path to assign every interior vertex to an endpoint along an actual connected branch; components attached at articulations follow the branch owner. Single-contact limbs use the one owner. For each virtual edge reserve just one child with this certificate. Owners are fixed before assigning colors. Separate child regions meet only at bag sites. The two owners give a physical monochromatic realization of the virtual edge whenever endpoints are equally colored. Real edges belong to their skeleton position; no endpoint pair represents several distinct capacities in a simple rigid skeleton. Polygon-refinement artificial diagonals need no certificate at bounded bags. With a block-cut tree an off-block articulation subtree shares a singleton only. A parent interface of a rigid node which enters from another block can be a singleton; its internal SPQR tree can be rooted at a bag containing it. Each other attached block attaches at a chosen bag containing its cutvertex.

Keep the actual color of each boundary vertex, the whole region palette, ordered strict-interior scores, the colors closed inside, and a guaranteed partition into same-color connected groups on boundary vertices. For an open color every component touches the boundary; each closed color is one connected nonempty component with no boundary occurrence. Empty colors are distinguished. For each record store a spanning list of actual degree-D moment rows (one-site indicator monomials) with backpointers. A coloring with more true connections can certify any weaker boundary relation consistent with these rules. For a bounded bag ordinary boundary gluing takes the union of connections, rejecting stranded pieces, and counts every site once. Reduce rows after each child join; any exterior degree-D test restricts linearly to a moment row when other sites are fixed. Choose newly forgotten sites' contributions only once.

Here is the local algorithm at a rigid bag. Put h=|G|^(p−1), F=p+(D+1)h−1. Enumerate at most F exceptional children, their records, actual rows and all colors on their interfaces and the outgoing boundary. Guess the palette of the bag and pin one site per color to witness its use. Forbid other colors on the bag by working over the chosen color alphabet. Account for all site scores exactly once by folding each default interior to its owner site and subtracting the fixed exceptional contributions; boundary scores can be restored/subtracted using the guessed boundary colors. Form the residual graph from physical bag edges plus the reserved virtual edges of default children only. Its vertex connectivity is at least that of the skeleton less F+1. Use the graph-only joint cube algorithm common-outside-joint.md on this graph with the folded weights. Additional pin indicators for ≤2F+2+p sites increase D to d=D+2F+2+p. Substitution of the exceptional sites' constants and default sites' owner color into a separating polynomial never increases its degree. For each physical partition output by the cube algorithm with correct pins, palette and score, expand the owners and chosen child witnesses, verify the requested record, and retain independent rows. One can enumerate whole bounded cubes once per choices, as their scope depends only on parameters. When the bag palette has one color the connected residual graph suffices directly.

For completeness take any actual partial-region coloring of the requested record that passes a specified nonzero degree-D separating test. Initially retain children containing any genuinely closed child color; there are at most p, as a child-closed color cannot coexist elsewhere in a valid coloring of the current whole region. Freeze the bag colors. Resetting any other child to its default gives a score change in a group of order h (total charge fixed). Among valid masks of resets that preserve the score and nonzero polynomial choose one with the fewest nondefaults; no connectivity is required during this step. If ≥(D+1)h eligible nondefaults remain, extract D+1 disjoint nonempty zero-sum packets of size ≤h by successive partial sums. Reset arbitrary packets. Every site indicator depends on one packet bit at most, so the restricted test has degree ≤D. A function nonzero at zero and zero everywhere else on D+1 Boolean coordinates has degree D+1 over any field. Hence more resets are possible, a contradiction. Every remaining nonclosed child color originally touches the bag with that color. Default colors copy existing bag colors. Retain all palette representatives and interface colors as above. Every chosen exceptional witness may now be replaced, one child at a time, by an actual moment representative in its exact score and original boundary record keeping the separating polynomial nonzero. The possibly disconnected original bag coloring still witnesses unrestricted satisfiability of the folded score and pin-multiplied polynomial. Joint cubes thus give a connected partition of the residual bag passing them. Every open child component attaches, each closed child color stays unique, each default color is connected to its bag owner, and all required outgoing connections are met. Palette is preserved. The whole palette, closed colors, boundary colors and strict scores suffice; separate strict-interior palettes are unnecessary. After expansion, actual rows adequate for each separating polynomial span the full row space for each record.

For each p'≤p, substitute d into the bound b=(|G|+1)K in common-outside-joint.md and take the maximum. Sufficient rigid-skeleton connectivity is F+1+max(2,b)+10p(max(2,b)−1), with the trivial one-color case handled directly. Fixed parameters give polynomial field-operation and graph-operation counts; effective GF(2) has ordinary polynomial bit cost. The enumeration never queries the full host recursively for missing global colorings. The resulting graph-only union when weights vanish consists of physical partitions and is reusable for all degree-D tests. Severe global cuts, unbounded block count and unbounded rigid skeleton rank are allowed. This criterion does not handle arbitrary three-connected skeletons.
