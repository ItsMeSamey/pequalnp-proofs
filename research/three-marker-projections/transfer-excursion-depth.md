# Unbounded exchange depth for a complete catalogue of other states

For n≥5 take the graphic fan with spokes s_i=r v_i of vertical lift 00, path edges v_i v_(i+1) of lift (0,1), and a special parallel spoke s'_n=r v_n of lift (1,0). Delete the root incidence row. The two target inputs are e1 and the all-ones column. The projection is connected by the spoke-path triangles and the parallel pair. The residual gains of the ordinary spoke basis have rank two and so do the target inputs. Physical ordinary bases are spanning trees.

For a tree let c_i be the second gain on its root-to-v_i path and Φ=sum_i (-1)^c_i. Tree paths give the physical representations of the individual coordinate vectors. Hence the second coordinate of the all-ones input is the parity of sum_i c_i. The first coordinate on e1 is one precisely when its root path uses the special spoke. Then the entire path vn to v1 is required, using all n tree edges with the spoke. There is one such tree F; its c_i alternate, so |Φ(F)|≤1.

In a basis exchange, removal of one edge detaches a connected component J from r. This is a path interval because its internal tree edges cannot be spokes. The c_i alternate on J. Reconnection changes all these c_i by one common bit and leaves the other c_i unchanged. Flipping an even interval preserves Φ. Flipping an odd interval changes Φ by two in magnitude and changes the second coordinate on the all-ones input. Thus any walk with k transfer-changing exchanges changes Φ by at most 2k, allowing arbitrarily many free exchanges.

Write a,b,c for the second e1 output, first all-ones output and second all-ones output. For every choice of these three bits start with all ordinary spokes. If a=1 replace s1 by v1 v2; if b=1 replace s_n by s'_n; if c XOR a=1 replace s3 by v3 v4. These independent changes realize the requested bits with first e1 output zero and at most two vertices of second gain one. Each seed has Φ≥n−4. The entire actual image consists of these eight states and the one transfer of F. From ANY supplied seed, every physical basis walk to the omitted transfer needs at least (n−5)/2 nonzero transfer changes, including walks revisiting previously known states. This statement uses these specified representatives, not every possible choice of representative per state. The omitted transfer can be found directly on this fan or by the affine scalar oracle, so this is no hardness or running-time lower bound.
