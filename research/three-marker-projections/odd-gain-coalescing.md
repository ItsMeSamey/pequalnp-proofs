# Physical gain corrections for two-tag single-word synthesis

Let Q have indexed columns q_i with arbitrary two-bit tags and two-bit gains. A solution has one q-dependency m of a prescribed nonzero gain b whose entire support agrees with a single linear two-tag chart. Delete private loops carrying nonzero tag as impossible; zero-tag loops are allowed. Partition the rest into classes of equal private key AND equal two-bit tag. Whenever one site matches a chart, every site of its class does.

For each class C compute the linear subspace V_C of two-bit gains of EVEN subsets of the class and an actual subset for each direction. An even subset is a private dependency and has even tag sum. A matching chart exists for the whole class (nonzero key or zero tag at a loop). The reachable gains of ODD subsets form the affine coset g_C+V_C for any one member's gain g_C. Select any such representative together with an actual odd subset, use its gain on one virtual class site, and retain original q and tag. A matching word on this coalesced host lifts by substituting those odd subsets on its support. The lifted private sums and gains are exact and the original chart matches all expansions.

For each nonzero c∈V_C handle its explicit even subset a. If c=b, a itself is a witness. Otherwise test whether there is a chart with all of supp(a) active admitting a dependency y whose gain has nonzero value under the functional ℓ annihilating c. Since ℓ(b)=1, toggling y by a if necessary produces exactly b. Conversely any actual solution in a chart enabling C passes the test, since a uses only sites enabled in that same chart. This is a polynomial two-tag SINGLE-output query, by the supplied-anchor argument in two-tag-rank-one-defect.md. Explicitly first test internal dependencies on supp(a) that the scalar detects. Otherwise the scalar gain and the two tags each factor through the private span of the forced sites (tags agree there in a chart). Shift each by such a private linear functional, project the outside private columns modulo that span, use the three-name pure-line oracle on the residual two tags and scalar, then correct the private sum by physical forced sites in the same chart. Verify the resulting indexed gain, adding a only if required.

If no above test succeeds, every actual solution occurs in a chart where all enabled classes have V_C=0, since otherwise the nonzero correction above would detect it. Coalescing the parity of the physical chosen sites in each class therefore preserves the gain. Thus the full local problem reduces to polynomially many constructive three-name queries and ONE two-output query on coalesced data. It does not split the two desired gain bits across independent charts.

A deterministic polynomial recognition criterion removes that final two-output call. For each nonzero functional h on gains solve for a linear functional f on private keys and β on the two tag coordinates. Require h(g_C)=f(q_C)+β(tag_C) only in classes with h(V_C)=0. In all other classes either scalar value is attainable by a physical odd subset, so once f,β are fixed choose that subset to satisfy the same equation. This is necessary and sufficient for these physical default choices to reduce the gain in direction h to a private plus tag row. Every matched coalesced dependency then has h(gain)=0. If h(b)=1 the coalesced instance is negative; correction branches above still run. If h(b)=0, a second functional taking value one at b detects it within ker h, by a genuine two-tag single-gain trace on the coalesced sites. Expand the returned support by actual odd subsets. The entire solver works with arbitrary private width and tag rank and does not require absence of four independent original tag/gain rows. It is a sufficient recognizer, with no conclusion upon failing the normalization equations. It extends an ordinary rank-at-most-three row test by allowing the scalar values of the physically realizable odd defaults to change.
