# Universally spanning a named direction with one exceptional tag

Given binary physical keys and a single tag bit, call a site active under g when g(key) equals its tag. For a supplied direction u, deciding whether EVERY chart's complete set of active sites spans u is coNP-complete, even in a connected represented binary matroid with just one site tagged one.

From a graph G, use one independent coordinate u and vertex coordinates e_i. Supply one exceptional physical site u with tag 1; for every ordinary edge ij give the site u+e_i+e_j tag 0. Work in their private span, since all chart functionals extend to the displayed ambient space. If g(u)=1, u is immediately active. Otherwise the active sites are precisely those ordinary edges whose endpoints have equal bits g(e_i),g(e_j). Their span contains u iff a subset of these edges has zero binary incidence vector and an odd number of edges. An even-degree subgraph decomposes into cycles, hence this holds precisely if the monochromatic subgraph contains an odd cycle. Thus some chart misses u exactly when the vertices can be split into two sets each inducing a bipartite graph. This is exactly proper four-colorability, with the partition as first bit and its two bipartite colorings as second bit. Any chart missing u is a polynomial certificate checked by Gaussian elimination.

For connectedness start with any connected instance of three-colorability having an edge, and adjoin one universal graph vertex. The resulting G is 2-vertex-connected and nonbipartite, and is four-colorable exactly when the source is three-colorable. Three-colorability on connected instances follows from usual three-colorability by joining separate components with arbitrary bridges, using independent color permutations. In the private matroid contraction of the distinguished site u gives the connected cycle matroid of G. The site u is neither a loop nor a coloop (it is the sum of the ordinary sites on an odd cycle). Thus the full private matroid is connected.

The very same hosts have an elementary exact algorithm for any alternating-form paired query: tag-zero relations never use the exceptional site, while every remaining site is active simultaneously in the zero chart. The entire indexed W is the exterior square of the ordinary private kernel after deleting the exceptional site, embedded by restoring its zero coordinate. Gaussian elimination gives arbitrary-query original witnesses. The hardness concerns universal membership in the full active span, a different predicate from existential common-support detection or computed aggregate first/paired spaces.
