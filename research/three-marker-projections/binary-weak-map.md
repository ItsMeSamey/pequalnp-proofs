# Deterministic base containment for two equal-row-rank binary matrices

Given binary matrices A,C with r independent rows and the same n labeled columns, decide whether every A-basis is a C-basis. This applies to the GF(16) single-zero-test reduction when its gate matroid has a binary realization. A rank-deficient gate already rejects any A-basis.

Write X=diag(x) with independent commuting variables. Cauchy-Binet over GF(2) gives P=det(AXA^T) with coefficient one exactly on the A-bases, and R=det(AXC^T) with coefficient one on the common bases. Thus containment is P=R. Find an A-basis J; if C[J] is singular it is a counterexample. Put X0=diag(1_J). Then D=AX0A^T, E=AX0C^T are invertible binary matrices with unit determinant. Translating X to X0+Z, the determinant lemma gives the two polynomials det(I+ZK) and det(I+ZL), where K=A^T D^(-1)A and L=C^T E^(-1)A. Their coefficients indexed by S are the principal determinants on S. K is symmetric.

Compare diagonal entries and all principal pairs. Failure certifies inequality. If they agree, every off-diagonal one of K is present in L in both directions, and any additional L arc is one-way. The principal minors agree exactly if every additional arc joins distinct strongly connected components of L. Sufficiency holds because determinant permutation cycles stay in strongly connected components, where the matrices agree. For necessity, take a shortest directed cycle containing any additional arc. Its length is at least three. It has no chord joining nonconsecutive vertices: an additional directed chord creates a shorter cycle containing itself, while a bidirected K chord splits the cycle in two, one containing an additional arc. On this vertex set every permutation using an additional arc must contain a full cycle by minimality. For length three or longer the chordless support has just the clockwise and reverse candidate full cycles, and at least one missing reverse arc forbids the latter. Exactly one extra term occurs, so the two principal determinants differ. All other terms are shared. This is a deterministic polynomial test using only matrix arithmetic, pair tests, and one SCC decomposition.

When containment fails an actual violating A-basis can be recovered by repeatedly discarding any ground element whose deletion still permits failure. Keep the original threshold r; rank below r in A means failure cannot persist, while C rank below r leaves every A-basis violating. The final inclusion-minimal ground set admitting such a basis is itself a violating basis.

To test binary representability of a given characteristic-two matrix of full rank, normalize any basis to obtain [I|D]. Scale rows and nonbasis columns to make each nonzero entry of D one; a forest traversal in the weighted bipartite support graph gives candidate scalings and checks every edge. Restore the basis columns to I by column scaling. If this fails, there exists a chordless cycle with multiplicative imbalance (nonunit product of alternating ratios), since chord decompositions express any imbalance through smaller cycles. The corresponding square submatrix has exactly two perfect matchings. Its determinant over the given field is nonzero whereas the zero-one support determinant vanishes in GF(2). That support matrix is the only possible binary standard representation on this basis, by the fundamental exchange tests. Thus failure correctly certifies nonbinary. Global base containment when the gate fails this promise is not decided here.
