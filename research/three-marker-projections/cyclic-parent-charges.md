# Parent maps with a bounded backwards frontier

On undirected G supply a digraph D on the same sites with at least one of the two directions of each physical edge and no nonphysical arcs. Supply a total order. For prefix P let J(P) consist of sites in P which could be chosen as parent by some unprocessed site (i.e. heads in P of arcs whose tails lie outside). Set w=max |J(P)|. Width is directly checkable.

Fix t stopping roots with known colors, force a root to stop, and allow every other site one outgoing arc in D. Require the chosen functional digraph to contain no directed cycle, so all sites reach a physical root. Use the score-and-pins polynomial from ordered-charged-partitions.md. With k demand factors and p colors its basis consists of conjunctions of at most k site-to-specific-root demands. Keep separate spans of actual polynomial vectors for each prefix summary described below.

For each j in J(P) remember its exit: follow its chosen arcs in the prefix until the first unprocessed site or an absorbed root. These two outcomes are tagged distinctly, including when a fixed root is still unprocessed. Reject any prefix cycle. On processing v, its exit is its absorbed identity if a stopping root, its chosen future parent if pointing forward, or the old exit of its chosen earlier parent (which is in J(P)). In the last case reject exactly when that exit is the unprocessed site v. Indeed every newly completed cycle must contain v, and the old prefix had no cycle. Update all old summary entries ending at unprocessed v to the new exit, keep v's own exit if needed, and drop sites not in the new frontier. Every old processed site newly needed was already in J(P); thus no forgotten exit is required. At most (n+t)^w summaries occur per layer.

On the polynomial vector perform the exact same substitution at v: forward its demand to the future exit, coalescing conflicts, or evaluate it against the absorbed root. Conditional on the summary and physical decision this is one linear map to another fixed summary. Propagate spans independently per summary and select independent *original* image vectors for traceback. By induction, each span is exactly the span of actual reachable vectors with that summary. At the end no unprocessed cycles are possible and all choices terminate. This gives deterministic n^{O(k+w+1)} time for fixed t,p,d, including a complete physical map. With one root per color and k=d(p−1) this checks whether G has a charged partition routable along D.

A polynomial sufficiency test makes this a graph partition algorithm on a recognizable supplied orientation class. Require each connected induced subdigraph to have exactly one sink strongly connected component. Then within any connected part every vertex can reach any chosen vertex of that sink; shortest directed paths give a cycle-free parent choice. Conversely if some connected induced subdigraph has two sink components, choose a shortest underlying path between these two sets within that induced subgraph. Its endpoints each have a one-way incoming terminal arc along the path: a reverse arc would leave the corresponding sink component. The distance cannot be one because the physical edge then supplies an outgoing arc at one endpoint. The path is induced in G. Conversely an induced path of length at least two with both end arcs one-way toward the endpoints has two distinct sink singleton components. Detect such a path by guessing nonadjacent endpoints u,v and terminal one-way arcs a→u,b→v, allowing a=b, deleting every other neighbor of each endpoint, then removing u,v and testing whether a,b survive in one connected component. A shortest middle path is induced and has no unwanted endpoint chords. Guess roots and run the polynomial algorithm if the condition passes. This recognition concerns the supplied D and order, not construction of an optimal pair.

This width can remain bounded where every purely forward order has unbounded hereditary sink count. Take m five-cycles sharing a site a, ordered by successive petals then a. Orient every edge into a and bidirect all other petal edges. Every connected subset containing a can reach a, and subsets missing a lie on one bidirected path. Only a single four-site petal has backward-active sites at any cut. A clique of arbitrary size can additionally be glued at a, placing its other vertices first and orienting clique edges by the order toward a. The property and bounded width persist, while treewidth is unbounded. For any alternative ordinary order choose in each cycle a-b-c-d-e-a the path a,e,d,c when c is later than d and a,b,c,d otherwise. Their connected induced union has a separate sink in every petal.
