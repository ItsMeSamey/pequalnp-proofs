# Gluing admissible parent directions without carrying clique interfaces

Use a rooted graph tree decomposition into connected induced bags with actual clique adhesions. Assign each site to its highest bag. Its native sites in torso A are A minus its parent adhesion B. For a physical edge between natives of different nodes the nodes are comparable and the ancestor endpoint occurs on the descendant torso's parent adhesion, by running intersection.

Supply an order and mixed orientation on each native graph, with every increasing arc and hereditary unique sink. Additionally require for each b in B and connected induced native set J touching b that every vertex of J reaches b within J union {b} with contact edges oriented toward b only. This is polynomially checkable via cyclic-parent-charges.md on the natives and on each native graph supplemented with one b. Alternatively apply the LP of cyclic-parent-recognition.md to the torso, with B last, forbidding all reverse contact and B-clique arcs. This one test is equivalent: if a connected set meets B, each native component meets a selected b and can reach it, and all selected B vertices reach their maximum. All-bidirected native edges with forward contacts are feasible. The cost is purely native.

Visit nodes in postorder, preserving their native orders. Include native arcs and direct ALL cross-node edges from descendant toward ancestor only. No completed different node can be a backwards head of an unprocessed site; the global frontier is bounded by the maximum native frontier.

For connected induced U, among its owner nodes there is a unique highest t and all lie below it. Along a physical path owners of successive sites are comparable; to leave the descendants of a shallowest owner would require a site owned strictly above it. For a proper descendant u with selected natives, every connected component J of its selected native vertices touches the selected parent adhesion: take a U-path towards t up to its first visit to that adhesion. Shortcut each excursion from the torso through a child interior by the physical clique edge between its two contacts. This gives a native path from J to a selected adhesion site b. The local orientation routes J to b. Iterating strictly towards the root reaches the native sites selected at t. Their induced graph is connected by these same shortcuts, since no parent adhesion of t is selected. All reach a common sink there. Thus global D is admissible, and the shared physical parent-map span solver applies with no interface size in the exponent.

Arbitrary mixtures of chordal entire bags and native interiors of bounded supplied pathwidth qualify. For a chordal torso take a PEO ending in the specified clique B, forward arcs only: any connected J union {b} has maximum b. For a native path decomposition of width k, order by first occurrence of sites in its bags. A processed site with an unprocessed neighbor must occur at the position of the most recent first occurrence, so there are at most k+1 such sites (including ties). Bidirect natives and direct contacts toward B. This is a guarantee for the selected decomposition.

A limitation holds for max-degree Delta: every prefix component C has at most omega(G)+Delta w external neighbors for an admissible orientation of frontier w. Among later neighbors sending no arc into C no two can be nonadjacent, since their shortest mutual path through C has incoming one-way arcs at both extremities. All others neighbor one of the at most w active heads in C. The elimination width of this order is at most this bound: the filled later neighbors at each elimination are the external neighbors of its prefix component, since filled adjacency represents a path with interiors already eliminated. Hence treewidth is at most omega(G)+Delta w, independently of the choice of order. This excludes constant backwards width on bounded-degree graphs of unbounded treewidth without implying decision hardness.
