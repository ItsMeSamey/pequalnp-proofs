# Single-exponential representative routing tables

Given a native circuit with independent finite local menus and two fixed wire marks r,s, supply a binary tree with each physical gate as exactly one leaf. Suppose each subtree cut has at most k crossing wires in either direction. The local menus are explicit (the implementation supports three-socket cyclic sites). There is a deterministic 2^{O(k)}poly(N) decision and original-witness algorithm. Here N includes the physical circuit, tree and menus. For coincident marks every allowed setting succeeds.

At a node X expose the set C_X consisting of all crossing wires and both fixed marked wires, even when a mark is distant from X. Its size d≤2k+2. For a fixed local setting retain, at each exposed wire entering a gate of X, the next exposed wire reached. This local table can be composed with any setting of the complementary gates. On C_X these two tables form the first-return permutation P. The same-orbit predicate equals nonvanishing of the cofactor deleting row s and column r in 2I−P, since its inverse is the convergent nonnegative permutation walk sum up to a positive factor. Its determinant is a product of positive factors 2^length−1.

Remove the prescribed row and column and take the exterior product of the remaining rows determined by X. The coordinates are their minors on every column subset of the matching size. The cofactor expansion is a linear functional of this vector for every fixed exterior table: all remaining rows depend on the exterior alone. Thus a basis of local feature vectors represented by actual local settings preserves existence of a joining setting for every fixed exterior. A zero vector can be discarded. At most 2^{d−1} actual states remain regardless of the number of local permutations. Determinant signs or cancellation in a linear combination cannot turn an all-zero basis evaluation into a nonzero original evaluation.

At a leaf enumerate the allowed site settings. At an internal node form each pair of retained child states. A parent's exposed start in its child is always an exposed child start. Trace the child first-return tables until reaching a parent exposed wire, retaining marks along the way. This always terminates: the pair is realized by an actual local permutation, and a directed path from an incoming boundary cannot enter a detached closed orbit. A marked orbit wholly in the node returns to its marked point. To prove that the candidate pairs suffice, fix an actual successful completion of the parent. Replace the left child using its representative property against the fixed right child and outside, then replace the right child against the new fixed left child and outside. Reduce resulting candidate states by feature independence, storing original child witnesses for each retained row. At the root all remaining rows are local and the single feature is the cofactor itself. Recover any retained original setting, or report that no setting joins.

Each normalization has at most 2^{2k+1} columns and at most a product of two such numbers of candidate rows, besides explicit leaf menus. Compute features by sparse row exterior multiplication. Entries before elimination are minors of matrices with absolute entries at most two and dimension O(k), so have O((k+1)log(k+2)) bits. Exact rational rank can be computed in polynomial bit complexity in the feature matrix size; fraction-free elimination with primitive integer rows controls growth by determinants of submatrices of this feature matrix. This still costs 2^{O(k)}poly(N). The reference Python program uses sparse integer wedges, primitive-row elimination, iterative tree traversal, and explicit original witnesses.

Together with native-assignment-cut.md this yields a concrete limitation on transferring the width solver to shared clauses. Bounded-degree expander independent-set CNFs force linear width for every assignment-faithful native wiring reading each original Boolean variable at one physical site: every leaf tree with n unit-weight original gates has a subtree containing between n/3 and 2n/3 of them (descend until neither child has more than 2n/3; use the larger child if the parent still exceeds that threshold). Decision-only reductions or altered witness representations are outside this conclusion.
