# Exact-plane decision when the common one-row uplift is binary

Let B be the private matrix, h1,h2 its binary height rows. Reject if their rank modulo B is less than two. Put Q=[B;h1+a*h2] over GF(16) with a of binary degree four, and M=Q+e with e the last unit. Binary representability of Q is recognizable by binary-weak-map.md. Assume it holds.

For connected B, uplift-graphic-scope.md proves that M is connected and nonbinary, both M/e=B and M backslash e=Q are binary, and the canonical 2-sum piece containing e is U(2,4). Graphicness was only used after that conclusion. Its three other elements partition the physical indices into branches E1,E2,E3: a real central element forms a singleton and a virtual element represents its entire neighboring side. Standard 2-sum decomposition is polynomial on represented matroids; 2-separations can be detected by minimizing connectivity with two distinct elements pinned to either side, over polynomially many choices.

In the linear representation each branch span intersects the rest, including e, in its port line (for a real singleton use its own line). These three lines and e are four distinct lines in a two-dimensional K-space by the central U(2,4). Indeed a represented 2-sum has one-dimensional span intersection and a representing vector for that line forms its virtual marker. No individual branch spans e. After contraction, all three port lines project to the same binary line through a nonzero b. The private span V_i of each branch meets the span of the others in exactly that line, also seen directly from the 2-sum with central U(1,3). Rational private matrices have the same subspace intersection dimensions over GF(2) and over K. Compute b by binary elimination. Thus tuples x_i in V_i with sum zero are exactly x_i=c_i b for binary c_i summing to zero.

Branch i's height is a linear function on V_i: no branch alone spans e, so its private dependencies have zero h1+a*h2 and hence both binary heights zero. Evaluate this map on b to get v_i. Its lift (b,v_i[1]+a*v_i[2]) generates the corresponding central line, because the projection is injective on the branch span. Distinct port lines give three pairwise distinct v_i. The resulting height map from even triples to H, (c_i) to sum c_i v_i, is an isomorphism.

Feasibility is equivalent to a common tag word u such that each branch independently admits a private independent expression for b with tag u. On a solution, all even triples must occur by height surjectivity, so each selected branch spans b. Local private dependencies have zero tag, and all representations of b inside that branch have the same tag. Every pair of branches forms a global relation, forcing equality of these three tags. Passing to a private basis preserves each expression's value. Conversely choose one independent expression per branch and discard any unused columns. Local kernels vanish; all even triples are realized, have no tag, and span H in height.

For branch i add a virtual physical column with private vector b and tag zero. Give it a third named bit one and leave that bit zero on every physical branch column. Test for exact line (u,1) with the existing three-name solver. A witnessing fundamental circuit of that nonzero gain must contain the virtual element; its other indices give the required independent expression. Conversely any independent expression with nonzero coefficients plus the virtual element is such a circuit. Try all four u and keep the actual original physical witnesses.

For disconnected B call a private component active if some private dependency there has nonzero height. If there is only one active component, both directions occur there and the connected proof applies. Other components cannot change its private dependencies and have no height. If two or more are active, for each active i find a private circuit D in a different active component with nonzero height. Its Q columns are independent but sum to a nonzero multiple of e. Contract all but one column of D and keep the remaining physical column as proxy. The resulting Q minor on E_i and the proxy represents Q|E_i+e: independent private components originally meet only in the bottom direction, and the contracted proper subset of D does not span that direction. Thus this matroid is binary. For connected B_i the fundamental scaling argument in uplift-graphic-scope.md then forces height rank at most one on its private kernel. Test each such active component by retaining both tag bits and one height bit nonzero on its unique height line; the three-name target is (0,0,1). Exactly the nonzero tag-balanced attainable height lines are found. A full solution exists iff these lines span H across the components, since all private relations decompose componentwise. Two witnesses of independent heights suffice.
