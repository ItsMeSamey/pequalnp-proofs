# Shared binary equality with one full ternary read

For any n≥2 let x₀,…,xₙ₋₁ be independent native binary rotation bits. One additional group of disjoint binary inputs contributes to a ternary affine score t. For 58 of the 64 relations R on {0,1}×F₃, a single native two-root closed test recognizes exactly the words where all xᵢ have the same value s and R(s,t) holds. The remaining six relations are the two-point sets {(0,a),(1,b)} with a≠b. Their realizability with further auxiliaries is open here.

On tracks 0,…,n+1 use stage i to swap consecutive tracks i and i+1 when xᵢ=0, or i+1 and i+2 when xᵢ=1. The quotient of these two swaps is a 3-cycle, so a fixed transposition and one native binary site implement each stage. Compose in the order giving the image-array update that exchanges the entries at the two indicated positions. Keep the four boundary tracks 0,1,n,n+1 in this order. Close the other tracks with identity feedback and take first returns. Under the all-zero word the boundary permutation is (012), under the all-one word it is (123). Every mixed word breaks at least one internal edge because the two neighboring sites either use it twice consecutively and cancel, or omit it. The remaining swaps form a forest, incapable of connecting track 1 to track n. The boundary map therefore belongs to {id,(01),(23),(01)(23)}. All four possibilities actually occur already at length three. This calculation permits a controller to read the common state while verifying equality in the same rooted trace.

For a finite table let the bus act on labels 0–3, the cycle (456) act to exponent t, and labels 7,8 carry fixed marks. Follow these actions by the recorded feedback image vector. Each row of bus_trit_profiles.txt gives a six-bit relation code followed by nine feedback images. Bit 3s+t tests the common state and score. Exhaustive fixed permutation enumeration yields 52 distinct safe codes, exactly all codes outside the two-point matchings and their complements. For each listed row a direct checker suffices: trace both uniform returns and all four possible mixed returns for each of three scores. The search also permits marks on the arcs of the components, since passive mark labels can be inserted on these arcs.

Code 46, the complement of the two-point matching with code 17, uses wiring (0,4,7,2,5,1,8,3,6) and an independently optional cycle (0 5 6) applied to the images after the wiring. The union over its two settings is code 46, with all mixed returns rejecting on both settings. Every complement of a two-point matching follows by permuting the values of t; the six affine maps t↦±t+c give the full symmetric group. This yields 58 relations. Disjoint trit contributions compile by serial ternary rotations, an exponent −1 uses the reversed socket order, and an offset uses fixed feedback. For n=1 one may use the existing two-trit catalogue or substitute the two fixed uniform boundary permutations using the same binary switch only if separately justified; the theorem here states n≥2.

Most simply this gives equality of arbitrarily many binary selectors together with a clause such as (s=1) OR (t=0), using each original input at one site. Several clauses reading the same s would require a further composition theorem.
