# A path of native trit tests with shared binary state

For each length n≥1 there is a fixed permutation and two marked entrances with n unrestricted ternary rotation sites, n binary auxiliary rotation sites, and n+1 binary state sites. For a fixed state word s and trit word t there exists an accepting auxiliary mask exactly if s is nonincreasing and, at every equal neighboring state pair, the intervening trit equals the common state. A downward step permits every trit. All sites have three sockets and the switches act on mutually disjoint triples.

On seven ports use transpositions (01)^L,(23)^R and rotation (456)^t, followed by the wiring with image vector (4,5,3,6,2,1,0), followed by optional rotation (403). Mark immediately before input 0 and after output 2 of the two read transpositions. Tracing all twelve words in index order 4t+2R+L gives masks 515 and 672 for the two auxiliary settings. Their union is precisely the stated local condition.

Cut the two marked wires of each cell. Its permutation on those cuts is a transposition precisely when the marks joined. Splice the right marked wire of cell j with the left marked wire of cell j+1 by exchanging their successors. The endpoint test is the AND of the local tests: the exterior tracks form a path, and transpositions on any subset of its edges form one orbit on each component. This last fact follows by leaf removal, or by inserting forest edges in multiplication order, each joining two disjoint orbits. Each cell is visited once per pass on its track in the open-return description. The equivalent proof by adding cells inductively uses the fact that the splice joins exactly the two cycles that contain its cuts.

After splicing there is literally one direct wire from right read output 2 to next left read input 0. With the common bit off, the three remaining inputs (old 2,old 3,new 1) map respectively to (new 0,old 3,new 1). With the common bit on their outputs are (old 3,new 1,new 0). Thus replacing these two reads by one physical rotation preserves every external trajectory. Endpoint transpositions use a 3-cycle with its third socket fed back. This proves the formula for every n. The accompanying compiler returns the actual native wiring and marked entrances and checks all 3768 fully specified configurations of lengths 1–3. The same local proof allows independent offsets or reversals of each trit coordinate.

Closing the path into a ring changes the endpoint argument. Removing one edge from the cycle retains a spanning tree, so one failed cell can leave every exterior vertex joined.
