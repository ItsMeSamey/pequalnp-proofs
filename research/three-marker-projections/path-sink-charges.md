# Testing sinks only on physical paths

Fix a vertex order on connected G. Let s be the number of sites with no later neighbor in G. Let r bound the number of sinks in the induced graph on the vertex set of any simple physical path; the path itself need not be induced. For fixed r the bound is checkable: try r+1 sites, delete the union of all their later neighbors, reject that tuple if a site was deleted, and check whether a single simple path through every listed site remains. Equivalence follows from the definition of an induced sink. The last check uses fixed-size undirected disjoint paths: guess the order of marked sites along the path, crop to its first and last marks, then guess for every segment its direct adjacency (length one), one common private middle (length two), or two distinct private neighbors of its ends (length at least three). All private proxies across segments are distinct and avoid all marks. Delete marks and dedicated length-two middles and route the remaining prescribed proxy pairs vertex-disjointly. A single mark needs no linkage. This tests actual visitation, not merely containment of each mark in a branch set of a path minor.

For any full degree-D nonzero acceptance predicate on vertex-to-color indicators and p connected spanning colors, protect one true root per color and all s global sinks. Default any nonsink to a chosen later physical neighbor, stopping at global sinks. Apply the arbitrary-tree leaf-basin compression of chordal-deletion-charges.md, yielding a successful retained forest with at most 2D unprotected leaves and at most L=2D+p+s total leaves. Each retained rooted tree is covered by its leaf-to-root paths (including a singleton tree as one path). A sink of the induced graph of a retained color tree must be a sink on the vertex set of every such path containing it. Thus at most rL sites, jointly over retained trees, can be sinks there. Reorient within each retained tree's vertex set to these sinks along increasing physical arcs, choosing an arbitrary later neighbor of the same retained tree wherever possible; connect the rooted fragments back by a spanning forest of physical intra-color edges as before. Default arcs outside the retained set are increasing (all their stopping sites are protected inside). The resulting full coloring is unchanged. Use the ordered parent-span algorithm with at most rL guessed roots and the corresponding physical bridge endpoint pins. Deterministic polynomial time holds at fixed r,s,D,p. This certification may succeed even when arbitrary connected induced sets have unboundedly many sinks.

For example put m chordless five-cycles through a single common site a. Every simple path uses vertices of at most two petals, hence r≤9 under every order. A reverse spanning-tree order pointing toward a has s=1. Yet in each petal a-b-c-d-e-a select a,e,d,c if c is later than d and otherwise a,b,c,d. The union is connected and has a different sink per petal. Thus these order promises differ even in one series-parallel family.

If the order comes with an increasing physical reference forest whose ancestor relation contains every increasing edge, use the independent group leaf-basin lemma with 2(|Gamma|^{p−1}−1) in place of 2D. After the fragment roots and bridging pins are fixed, apply the second monotone group pruning and the ancestor-closure flow-buffer solver from chordal-group-closure.md. For example reverse depth-first order of any connected undirected graph supplies such a forest and has s=1, though the path-sink parameter r still needs checking. This yields joint arbitrary fixed finite-abelian group totals under the stated additional structure, not by multiplying predicates across fields.
