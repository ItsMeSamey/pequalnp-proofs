# A nonfree auxiliary for the exceptional four-trit plane

Number the input sockets 0 through 11 in four consecutive triples. At data word w, socket i exits at the socket of local index i+w[floor(i/3)] modulo 3 in the same triple. Follow with one independently optional rotation (9 10 11), then fixed permutation p with image list (3,7,5,4,6,8,9,0,11,1,2,10). The destination is the free hub containing that image socket. The hub partition, written as twelve-bit masks, is (1,72,144,288,514,1024,2052). The marked root hubs contain departures 0 and 10 respectively. Each hub is balanced because p and both possible auxiliary maps are permutations. A zero-length marked loop at each root can instead be an ordinary directed loop with its own port on each side. Each data trit has one physical rotation site, and the binary auxiliary has only its two designated settings. All remaining independent auxiliaries implement the free hub choices.

For either helper setting on a fixed word, joinability at the free hubs equals weak connectivity. Enumerating all 81 words and both helper settings rejects the nine words Z defined by a+c+d=b+c−d=0. Of the remaining 72 words, 66 are accepted. The six missed words are exactly (a,a+1,1−a,d) for d in {0,1}. On an accepted word choose a successful helper setting and traverse the Euler circuit of the marked component for physical router witnesses. On all rejected words neither helper setting permits such a circuit.

The nonfree helper cannot be treated as an unrestricted hub. For a minimal control, close one such site by feedback (01) and mark 0 and 2. The two return permutations are different transpositions, both separating the marks, although the weak graph of an unrestricted replacement is connected. In the four-trit fixture the helper is immediately adjacent to the last data rotation, so granting both nonidentity helper powers would instead make the predicate invariant under the fourth coordinate. This example is a sound partial detector.
