# Field and neighborhood-count scope of the physical moment construction

For a shore A in the supplied tree write b(A) for the number of distinct physical neighborhood unions into its exterior, over all subsets of A. The proof of mim-partition-moments.md uses mim-width only to upper-bound this number. For any integer cutoff B, enumerate these unions starting from the empty set and processing singleton neighborhoods: keep all old unions and their unions with the new singleton neighborhood. Exceeding B at any stage certifies excess on this cut, since old unions persist. Thus a layout with every b(A)≤B is verifiable in polynomial time in n and B even without any constant bound on cross induced matching.

For a field of fixed positive characteristic l, give every actual monochrome component one of l auxiliary subcolors and fix each pinned anchor's subcolor to zero. Count local choices IN THIS FIELD separately for all tuples of neighborhood unions of the p*l subcolors. Compatibility with any fixed exterior auxiliary assignment means adjacent sites with the same original color have identical subcolor. The combined count is l^{sum_i(cc_i−1)}, yielding 1 for a connected anchored partition and 0 otherwise. The linear factorization, tensor with the actual degree-D site moments, physical-row selection and witness reconstruction from mim-partition-moments.md are unchanged. The feature dimension is B^{p*l} times O((np+1)^D). Runtime is polynomial in this dimension and the input for fixed parameters and effective field operations. In particular polynomial B (logarithmic Boolean-width) suffices even for layouts with growing mim-width. Gamma totals may use unrelated primes and are kept in their own buckets. This claim uses a single auxiliary field; previously known connectivity algorithms on Boolean-width layouts already cover ordinary constraints.

The parameter distinction can be visible in a connected graph: take two cliques of size 2^k each joined by exactly k pairwise disjoint matching edges, and use a layout splitting first between cliques and subsequently inside each. The main cross induced matching has size k, but at every cut inside a clique all nonempty subsets see the whole opposite portion of that clique and at most a subset of the k matching endpoints. All neighborhood counts are O(2^k), polynomial in graph size. This distinguishes the stated layout conditions, without asserting an optimal-width separation for all other layouts.
