# A single-row GF(16) base-containment gate for the unrestricted exact plane

Write every physical column as (private,h1,h2,t1,t2), with H the required two-dimensional named subspace on the h coordinates. The private row rank is r. Define A by the private rows and the two h rows. Work over K=GF(16) with element a of binary degree four. Define C by the same private rows followed by h1+a*h2 and t1+a^2*t2. The binary matrix A and its K representation with last rows h1+a*h2,h2 have the same bases. This K representation differs from C in one row.

For an A-basis B of size r+2 the private rank is r and the two private dependency vectors of binary height (1,0) and (0,1) exist uniquely. Denote their tags by (u,v) and (w,z). Restricting the last two output rows of C to this private kernel gives columns (1,u+a^2 v) and (a,w+a^2 z). Their determinant is w+a u+a^2 z+a^3 v. Since 1,a,a^2,a^3 are binary-independent, this vanishes exactly when all four tag entries are zero. Hence B has the required physical trace if and only if it is a basis of A and dependent in C. Conversely any witness extends to an A-basis by first retaining a full-column basis of its span, then adding physical columns with new private projections until private rank r is reached. The target trace does not change. If A has rank below r+2, reject the original instance. This rank-one extension-field gate is only required to discriminate planes over H in the A-basis chart. For example the complementary named plane with zero heights also has determinant zero in C, but fails the A gate.

More generally a common private-plus-one-row matrix Q over K has its bases lifted by two last rows f,g. If Q has one fewer independent row than the intended basis size, an f-lift basis B has exactly one Q-circuit on its support, carrying nonzero f value. It fails the g gate iff its circuit relation has zero g value. Conversely a Q-circuit y with nonzero f and zero g extends to such a B by extending a basis of its Q-span to full Q-rank using other physical columns. Thus the unrestricted difficulty is whether one particular elementary-lift circuit class is contained in the other, for a Q of this special form. Arbitrary Q-kernel vectors cannot replace circuits in this test.
