# Essential switches on two ternary singleton spines

Fix a rooted native circuit with full ternary rotation inputs and optional binary rotation auxiliaries. Suppose the existentially recognized trit code has minimum Hamming distance at least three. Fix two codewords with auxiliaries chosen at minimum Hamming distance among masks licensing these particular words. In the claims about a one-bit neighbor being empty, choose the two productive masks at minimum distance among all masks with *different* licensed words, or assume the code contains only those two words. Distinct productive masks may license the same word. Write h for the chosen mask distance and d for the number of changed trit coordinates.

By the ternary radius-two singleton theorem, each productive mask licenses only one word. After absorbing that word into the local wirings, its first return on the two marks and three sockets of each ternary input consists of an oriented tour from the first mark along all trits to the second mark and back in reverse order, plus one singleton socket at each trit. Suppress passive wire segments and identify the three sockets of each trit to form a vertex. The resulting undirected multigraph is a path from mark to mark with two oppositely directed arcs in every gap and one directed loop at each trit vertex. The corresponding raw segments may contain many fixed auxiliary transitions.

For any fixed auxiliary mask, there exists a successful trit word if and only if the marks are weakly connected in the graph in which each full trit admits free passage. Insert passive marked vertices on the designated arcs. The graph after suppressing fixed transitions is directed and balanced, so weak components are strongly connected. A simple directed path between the marked vertices visits each trit at most once. Each requested input-to-output transition is attainable by precisely one of its three cyclic rotations. Completing unspecified sites arbitrarily gives a permutation in which both marks share a cycle. This proves the assertion in both directions.

If h≥2, toggling a single differing auxiliary at the first mask must make that free-passage graph disconnected between its marks. Otherwise the neighbor licenses either the same word at smaller distance to the second mask, a different word at distance one from the first, or the second word directly at distance one. Each outcome contradicts the minimum assumption. The analogous assertion holds at the other endpoint. Consequently that auxiliary must cut both opposite directed segments of some single gap of the first spine. If every gap retained one of its two uncut directed segments, the old underlying undirected path would still exist. The three physical cuts can cover both segments of at most one gap.

Each changed trit's old private loop segment must meet a differing auxiliary. Otherwise the raw return on its old loop socket is unchanged between masks in the first word's coordinates. At the second word, the single unchanged raw loop arc still connects that trit vertex to itself, but its new nonzero relative rotation prevents this arc being a singleton socket orbit. Since the new spine has exactly one same-vertex arc at that trit, it cannot have the required singleton there. Each differing auxiliary already uses two cuts on a gap, leaving at most one for a private loop. Hence h≥d when h≥2.

For the two-word code differing at all n≥2 coordinates, suppose h=d=n and different auxiliaries occupy different gaps of the first spine. Each gate cuts its own gap's two opposite wires and a distinct private loop. These raw segments are disjoint between gates. Denote the gap endpoints by A,B and loop vertex by C. On the three cuts the initial directed arcs are A→B, B→A, C→C. A cyclic reassignment either creates A→A plus opposite arcs between B and C, or creates B→B plus opposite arcs between A and C. Call the endpoint turned into a loop X, and the other endpoint Y. A single flip disconnects the old marked ends, so C must be on Y's side of that gap and X≠C. At the high mask each discarded X accounts for a loop. There are exactly n high loops, one per data vertex and none at the marks, so the discarded X's run through all data vertices once. The donors C do likewise. In path order direct each discarded vertex X toward C. The leftmost data vertex points right and the rightmost points left. At an adjacent change from right to left, both corresponding gates occupy the same gap, contradicting distinctness. Thus a tight arrangement must have at least two helpers on a common gap. Interchanging the two endpoint masks proves the same at the second spine.

This necessary condition permits arbitrary feedback and hidden passive links. It does not rule out multiple auxiliaries on one gap or extra auxiliaries. The finite three-input test with target {000,111} is a separate search.
