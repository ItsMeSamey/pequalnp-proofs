# Translation lifts across private clause components and shared extension ports

After original Latin pins and signed occurrence identification, use the explicit residual CNF. Mark as ports all names of clause-occurrence degree exceeding a fixed threshold. Remove port vertices from the bipartite clause–name incidence graph. Each remaining component, including an isolated port-only clause, sees a set S of boundary ports and private names disjoint from all other components. Require at most k total boundary and private names per component, otherwise this recognizer abstains. Port choices may also be supplied. Enumerate all 2^k assignments to obtain the integer table f_C(s) of private extensions and ordered lists of their private assignments. The product of the component counts equals the global fiber count at every fixed port assignment. Multiply tables with equal scopes pointwise, retaining component lists for mixed-radix witness indexing. Isolated unconstrained names are recorded separately.

For each grouped table f on S, list every shift v on S satisfying f(u)=f(u+v) for every u. These translations form a binary subspace. Impose the Gaussian equations requiring the restriction of a global shift to S to lie in this subspace. Their joint kernel T is computed from the raw residual CNF, including shifts of shared ports that happen to be extension wires. For each g in T and each port word x, the fibers at x and x+g have equal size and admit a constructive bijection: in each separate equal-scope group retain the same lexicographic or mixed-radix ordinal in its enumerated private fiber. This works even if no fixed physical polarity flip of private bits realizes the bijection. Shared variables have one global shifted value. Selecting pivot columns of a generator matrix of T gives port positions I on which restriction is an isomorphism; fixing them to zero keeps one representative per orbit. Every model of the restricted instance and each g lift to a distinct model of the original via these bijections, covering all models. Exact counts multiply by 2^dim(T). The residual problem with those pins need not be easy. Runtime is 4^k poly(input length); list entries and grouped counts have polynomial bit length, and component-wise mixed-radix indexing avoids expanding a Cartesian product.

For a local shear around a port p, further allow unaffected factors reading only p among shifted coordinates: they need not preserve a flip of p. For a chosen g with g_p=1 use new port names z_i=x_i+g_i x_p for i different from p. Enumerate the subsets of the d groups whose scope contains p, designating them fixed or changed. Fixed groups impose g=0 on their scope except p; changed groups impose their table stabilizer. All groups omitting p also impose their stabilizer. To ensure strict progress try a changed group and another named coordinate in it forced to shift. Each test is Gaussian. Changed groups can drop p by using the p=0 table in the new coordinates; fixed groups retain their original table; groups outside p need no additional arguments. The private indexing convention lifts witnesses back for either value of p. Thus one pass costs 2^d 4^k poly(input), and every successful pass reduces total scope size. This does not decide semantic equivalence of arbitrary hidden-variable modules.

An NP-complete family guarantees substantial preprocessing by the global method, including shared extension wires. For each active logical bit z_i introduce distinct w_i,p_i,h_i,a_i,b_i and enforce h_i=w_i+(a_i b_i). Replace a literal z_i either by w_i+p_i or by h_i+p_i+(a_i b_i), with the original sign. Both interpretations agree once the linking table holds. Use the decorated expression in multiple clauses if desired; original source clauses may be doubled with the two interpretations to ensure h_i is shared. The relation projects onto the original formula exactly, with z_i=w_i+p_i on extraction. The i-th simultaneously flipped triple (w_i,p_i,h_i) leaves each of these bounded-scope tables unchanged. The translations are independent for distinct i. The conjunction may retain the entire original 3SAT difficulty after pinning.

Compile each bounded-scope table into one long clause for each falsifying tuple, then split each long clause into 3CNF with unique private prefix-OR values: define u=(l1 or l2) by the three usual clauses and continue with (u or remaining literals). Private prefixes appear in at most five clauses each. For every port attach at least six fresh, individually forced equality leaves; this ensures its degree exceeds five and contributes exactly one private extension at any port value. Use the signed-star isolated Latin encoding of the resulting ordinary CNF. After sign and pin substitution, the degree test recovers the intended port set, and the component enumeration produces the individual long-clause tables. Grouping by their full scopes reconstructs the original check tables, possibly multiplied together when scopes coincide. Equality-leaf factors are constant one. Each logical triple flip therefore belongs to the computed global kernel, which has dimension at least the number of actual original active variables. No supplied module partition, provenance, or guessed interior assignment is needed. Duplicate clauses may be retained as native separate occurrence slots; if removing duplicates, private equality leaves remain distinct. This example is an NP-hard input class where linear many gauge coordinates are automatically fixed, not a polynomial solver for its residuals.
