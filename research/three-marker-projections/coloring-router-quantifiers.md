# A coloring witness under universal native routing diagnostics

Distinguish binary data switches and independent binary router switches. Ask whether a common data setting keeps two fixed physical roots in different orbits for every router setting. On the explicitly presented graph family below this problem is NP-complete. The construction uses a linear number of native binary three-cycles.

Four-regular planar graph 3-colorability is NP-complete by [Dailey](https://doi.org/10.1016/0012-365X%2880%2990236-8). Connectedness can be imposed if the transformed graph may be nonplanar. For two or more original components, split one vertex of each into nonadjacent p,q, distributing its old neighbors two to each. Add adjacent vertices x,y, both adjacent to p and q. This diamond forces p=q, and either ordering of the other two colors at x,y extends a common color at p,q. Join y of each component to x of the next component in cyclic order. This restores degree four and connects the graph. Permute colors independently in each component so x,y have prescribed distinct colors. The new graph is colorable exactly when the old one is.

Orient an Euler tour of the connected four-regular graph. Replace each directed edge uv by three tracks from (u,j) to (v,j+g), j in F₃. Choose its gain g=1 or 2 by one fixed rotation and one optional native rotation. At each vertex-sheet an independent binary router chooses either permutation between two incoming and two outgoing tracks. One optional three-cycle with third socket feeding itself implements it. Mark sheet-zero and sheet-one entrances of a fixed outgoing edge at the root. For n vertices these are precisely 2n data switches and 3n router switches.

For fixed gains the two marks can join for some router setting exactly when their sheets lie in one weak component. Every component is balanced, hence admits an Euler circuit; choose its actual transitions at the sheet vertices. Conversely each physical orbit remains in one component. The reachable sheets over the root comprise the subgroup of F₃ generated by closed-walk gain sums, traversing an arc backwards with its negative gain. This subgroup is either zero or all of F₃. It is zero exactly when gains are vertex-potential differences: integrate on paths from the root in one direction and telescope in the other. Every gain is nonzero, so a protecting mask recovers a proper coloring. A proper coloring supplies a protecting mask by its edge differences. Fixing root color zero gives inverse witness maps. Polynomial-time component verification of a guessed data mask puts the presented family in NP. The checker constructs the full native permutation, produces the Euler router witness, and compares protecting masks to normalized colorings.

## An explicit table of short diagnostics

Add a new base root r with one fixed zero-gain loop and mark its sheet-zero and sheet-one inputs. For every vertex v provide a pair of independent full-ternary spokes r→v and v→r with gains c(v),d(v). Two binary rotations in series realize each full ternary choice. For each graph edge uv include one arc each way with independently chosen nonzero gains. The base is balanced. At each vertex-sheet use a polynomial-size fixed fabric of optional two-track swaps realizing every port permutation, for instance the reversal of a fixed bubble-sort comparator schedule with the individual swaps selected to produce that permutation. Each optional swap is a native binary rotation with its third socket feeding itself.

For every v make a deterministic diagnostic trail consisting of the common loop and r→v→r. For every directed edge uv take the loop and r→u→v→r. Pair the incoming and outgoing ports along that trail in cyclic order. Distinct edge ports give an injective partial pairing at each vertex; extend to a permutation, and program it identically on all sheets. The root orbit advances by exactly the trail gain each time it returns to the common loop. Separation of the two fixed root sheets therefore tests zero gain. Spoke tests force d(v)=−c(v); edge tests then force gain c(v)−c(u), which is nonzero exactly for unlike endpoint colors. These O(n+m) explicit rows universally separate under one common data setting exactly when the graph is 3-colorable. Each trail traverses at most three data-bearing edge blocks, at most five physical data switches. The two reverse gains and the spoke choices start independent; the diagnostics enforce their consistency.

The universal-router construction and explicit common-data table keep their stated quantifiers. Obtaining one existential rooted join that enforces every diagnostic remains open here.
