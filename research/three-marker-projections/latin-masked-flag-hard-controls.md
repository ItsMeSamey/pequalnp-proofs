# A masked shared-port refinement and its explicit escape

Fix h as in latin-patch-hard-fixed-points.md. Start from 3SAT, replacing each occurrence with a new variable and forcing each copy cycle equal via directed binary implications. This ensures v active names and O(v) clauses and recovers the original model. Take a deterministic bounded-degree expander of order n=Theta(v) small enough to use at most v-10 edges, and complete a K5 on five of its vertices. Sources of bounded size can be padded by active irrelevant variables occurring in tautological clauses. Deterministic expanders and the balanced-separator proof are in latin-patch-flag-hard-controls.md.

For each edge e=uv form NAE(x_u,x_v,p_e) with fresh p_e. Assign edges injectively to active actual logical bits. Wherever that bit occurs, including the copy implications, replace it by w_e XOR p_e. Do not retain a separate copy of the replaced bit. Expand each original clause by its falsifying assignments on at most six actual checker bits into constant-size CNF, and apply ordinary existential 3CNF chains. Convert the checker to positive NAE using a reference f: at f=0 a 3-clause is NAE(a,b,c,f), encoded by NAE(a,b,t), NAE(not t,c,f). Repeated literal padding handles short clauses. Complementary representatives are enforced by NAE(v,n_v,n_v). On extraction first complement all colours if f=1. Keep the original graph NAE constraints intact. In particular x_u appears only in its incident graph edges, at bounded degree.

Fix any satisfying source model. Every graph x vector extends: choose p_e as required by its edge, set w_e to recover the true logical bit, and extend the checker auxiliaries. Conversely any combined model recovers a source model. The checker alone permits EVERY p vector in the satisfiable case. The graph alone forbids p=0 along a 5-cycle of K5 and p=1 on its complementary cycle: zeros among the five vertices must form an independent set in the first C5, ones an independent set in the second, each of size at most two. Thus deleting the graph changes the joint projection onto its actual shared ports. It does have a model, for instance x=1,p=0 everywhere.

Apply the distant-terminal equality-gadget occurrence expansion to the entire positive NAE hypergraph, followed by full clone blowup, signed clause pairs and the isolated Latin embedding. The proof in latin-patch-hard-fixed-points.md gives no nontrivial fixed-h binary patch on either verdict. To identify a physical port cut, put x-equality devices on the graph side and p-equality devices on the checker side, exposing the edge occurrence of p (all its clones). The checker with a source solution extends every uniform vector of these port clone values. First-clone restriction on the graph side recovers the K5 impossibility, so eliminating that side while forgetting its physical port relation is unsound.

Within each x_u chain of equality devices choose a reference colouring for terminal bit zero and its complement for bit one. Its occurrence vertices are linked by a connected branch set of O_h(1) primal-graph vertices: the designated terminals of each device are in the same component, since otherwise flipping one component violates equality. Distinct branches use disjoint names, each of value x_u plus a fixed bit. Choose the first physical clone in each class and select a positive first-clone clause witnessing each within-branch primal adjacency and each original graph edge. One leaf may witness several primal adjacencies on at most three names. The graph of these adjacencies has the expander as a minor by contraction. For any arity-four clause tree, unions of four child separators and leaf bags of up to three endpoints form a tree decomposition as before. A cell therefore has Omega(n) actual separator names, all on these branches, observing Omega(n) distinct x_u values. On YES this gives exponentially many genuinely extendible keys under all valid binary pruning; on NO the actual binary background is empty but no key extends globally. Any address relabeling preserving distinct clause leaves is allowed.

The triangular coordinate change (w_e,p_e) to (z_e=w_e XOR p_e,p_e) is globally invertible and exactly factors the original checker-port relation from the graph before introducing helper variables. After projection of the existential Tseitin/equality/clone witnesses the same factorization holds on the normalized uniform source section; there is no asserted bijection between arbitrary nonuniform clone assignments. A decision decoder sets all x=1,p=0, chooses w=z and constructs the local witnesses. With the reduction trace the factorization is explicit. On a supplied flattened checker CNF with specified candidate pairs one can also certify it syntactically: normalize and hash the clauses, check closure under simultaneously negating both literals' variables for each pair. Each such flip preserves the conjunction; after the triangular change these independent flips vary only the p variables, so setting p=0 computes the quotient exactly. Truth-table expansion of each masked source clause has this symmetry; one can equivalently check individual bounded-support blocks. Finding the checker/port split and a faithful pre-Tseitin checker from arbitrary raw Latin occurrences is not established by this test.
