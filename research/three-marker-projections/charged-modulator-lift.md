# Lifting a charged connected-partition oracle across a vertex modulator

Let p be fixed and Gamma a fixed finite abelian group. An oracle on connected base graphs solves for any fixed number of ordered nonempty connected spanning parts with prescribed Gamma totals and a bounded number of indexed vertex-to-part pins, returning an actual partition. The lifted problem has the same interface. Optionally, if that oracle also accepts a supplied fixed-degree nonzero polynomial P over a single effective field in the site-to-part indicators, so does the lifted algorithm. Work over F₂, or with polynomial bit complexity for the field linear algebra used below. Without a polynomial test set P=1, degree D=0.

Suppose X is a nonempty k-site modulator of a connected G whose components H_i after deleting X individually support the oracle. Choose a spanning tree of each H_i rooted at an arbitrary gateway adjacent to one chosen owner in X. Defaults in that component point along the tree to its gateway and then to its owner; default stops occur in X. The graph on X need not be connected or a clique. Every incoming physical pin is protected, as are all X sites and one root per true color.

Start with arbitrary true spanning trees of the parts. By the arbitrary-tree version of the joint leaf-basin lemma, some accepted g-closed retained subforest S needs at most L=2((D+1)|Gamma|^{p−1}−1) unprotected leaves. Outside sites follow their fixed defaults to the first retained site, and the resulting full partition still meets the scores, polynomial and original pins. Total leaves are at most ell=L+p+k+number of incoming pins. Delete X from these retained trees: at most M=p+k+ell connected tree fragments remain, because the sum of positive (number of children minus one) in the forest is at most ell. Call a component H_i active if it meets these fragments. There are at most M active components. X sites are counted individually.

Expand each retained fragment in H_i by all omitted sites of H_i whose first retained default contact is in that fragment. This gives a connected local part with exactly the global color of that fragment. The remaining sites of H_i (if any) follow defaults all the way through the gateway into X before hitting S. They form one connected local part containing the gateway, since the tree path from each of them to the gateway also has no retained site. Its color is its owner's. Consequently every active component is spanned by connected local parts, with at most 2M local parts IN TOTAL. Every inactive component is completely monochromatic in its owner's color. Moreover, all same-color macro-vertices (the local parts of active components and individual X sites) are connected by actual edges: the retained g-trees already connect their fragments and X sites, and each extra gateway part has its actual owner link. Inactive components are not needed to realize these connections. Each global color has at least one macro-vertex, because its original root was retained.

Algorithmically guess the at most M active component indices, the bounded number of local parts on each, the colors of those parts and of X, and the precise Gamma target per local part. Charge all inactive sites once at their owner, as actual assigned vertices, and enforce the global totals. Original pins at inactive sites must agree with their owner. Guess physical edges joining the correctly colored macro-vertices into one tree per global color, specifying the local part of each incident endpoint. Check the X endpoints plus all global pin requirements. There are boundedly many such links, chosen on actual sites without using any virtual clique completion. On every active H_i solve for precisely its ordered local parts and all resulting endpoint and original pins. It is safe to accept any local witness when only scores are prescribed. Glue the local assignments, X singleton colors, and every inactive component to reconstruct a physical connected spanning partition. Completeness follows from the fragment construction. Soundness uses the actual local connectivity, the physically pinned joining edges and the inactive owner adjacencies. If X is empty use the base solver.

For the optional global P, a single arbitrary witness per local query is insufficient. For each feasible local score/pin/part specification, let each actual local partition have its row of evaluations of all indicator monomials of degree at most D (include 1). Use the base polynomial oracle to learn a linear basis consisting of actual rows: given the current span, queries for a basis of its annihilator either produce an outside witness or certify completeness. Dimension O((n times local-part-count+1)^D) bounds the process. Substitute constants for X and the inactive colors, and expand global site colors on active components as sums of their allowed local part indicators. Each resulting global monomial factors by components. Its value, and hence P's value, is multilinear in the chosen local evaluation rows (using the local constant coordinate for absent factors). If any actual tuple has nonzero P, expansion in the stored actual row bases shows some tuple of stored physical witnesses does. Enumerate their products: there are at most M active components, so the product search is polynomial for fixed parameters. This is not an intersection of independently satisfying marginal queries.

Thus fixed-size vertex deletion to arbitrary many connected base graphs preserves polynomial decidability and indexed recovery, with dependence on the number of colors, pin count, degree and group order allowed in the exponent. Given a base recognition test, enumerate X of size at most k for unsupplied modulators. Repeating lifts through a fixed number of rounds gives the same conclusion for bounded elimination distance to the base class; each level may introduce a bounded number of new parts and pins, so this is a fixed-depth statement. No bounded adhesion is needed between X and a component. The conclusion need not hold for black-box tests restricted to exactly three parts or incapable of checking the required physical pins.
