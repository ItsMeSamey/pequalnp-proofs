# Counting induced even subsets modulo any fixed integer

For every fixed integer k≥2, counting vertex subsets of a simple bipartite graph whose induced degrees are all even, modulo k, is #ₖP-complete under a one-query reduction with an invertible output factor. The empty set qualifies. Connectivity is unrestricted. No marker is imposed.

Use the #ₖP-completeness of counting independent sets modulo k, even on bipartite source graphs. [Faben, Theorem 3.7](https://arxiv.org/abs/0809.1836)

A pendant path on ℓ new vertices gives multiplicities F_(ℓ+2) and F_(ℓ+1) according as its attachment vertex is absent or present. On a path the selected vertices must be independent: any selected consecutive segment terminating down the path would have a selected endpoint of induced degree one. When the attachment is selected, the first path vertex is necessarily absent for the same reason. Thus a path contributes only a weight and leaves the guard at an active attachment unchanged. The claim includes ℓ=0, with F_0=0 and F_1=1. The Fibonacci recurrence on ordered residue pairs is invertible modulo k. Choose T≥3 with F_T=0 modulo k by following the finite orbit of (0,1). Put B=F_(T−1). Then B is invertible modulo k by coprimality of consecutive Fibonacci numbers. Length T−2 gives weights (0,B), pinning its attachment to one modulo k. Length T−3 gives weights (B,−B). The path lengths are constant for fixed k.

Give the source graph G one left vertex per source variable, and introduce a left hub p. Pin p to one by a pendant path. For each variable i use one right repair vertex adjacent to p and i. For each edge uv introduce a left vertex w, right vertices a,b, and edges wa, wb, ua, vb. Pin w to one by a pendant path and attach a path of length T−3 to a. Paths of either length preserve bipartiteness.

Sum over paths first. In every surviving term, p and all w are selected. The selected w enforces a=b, because its path neighbor is absent. A selected a then requires u selected, and a selected b requires v selected. Thus a=b=0 is always available. The option a=b=1 is available exactly when u=v=1, and its relative weight is minus one. For fixed source bits the edge's factor is B²(1−uv), including the weight of w. The hub contributes B. Given a choice on each edge, a repair at source i is forbidden for unselected i and otherwise uniquely chosen to make i have even degree. The hub has even degree because each active edge option contributes twice to the total repair parity. It follows that the target count is B^(2|E(G)|+1) times the independent-set count modulo k. The multiplier is a unit. Membership follows by guessing a vertex set and checking its degrees.

The checker constructs complete constructed instances with explicit bipartitions and independently counts them by trying all assignments on one side and computing the number of linear solutions on the other side. It passed 208 constructions across prime and composite moduli. This hardness concerns raw modular counting; an unmarked existence query always has the empty witness. The graph polynomial quantity is the normalized global interlace evaluation Q(G,4)/2^|V(G)|. This identity and the consequent invariance under local complementation predate this work. The normalized parity differs from evaluating Q(G,4) modulo two. [Aigner and van der Holst](https://doi.org/10.1016/j.laa.2003.06.010)

Degree parity refers to every selected vertex, distinct from imposing only an even total number of induced edges. Parameterized results on fixed-size induced subgraphs also impose a cardinality condition absent from the count here. [Roth and Schmitt](https://doi.org/10.1007/s00453-021-00894-9)
