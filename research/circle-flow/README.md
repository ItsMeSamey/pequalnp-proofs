# Supplied chord word with bipartite interlacement

Run `python -B check.py` with Python 3.10 or later. The checker compares exact integer determinant/Fourier counts with independent arc-subset enumeration and compares positive label classes with direct guard-support enumeration. The input is a nonempty cyclic word containing each vertex twice, with vector labels encoded as nonnegative integer bit masks. Pass the word, a vertex-to-label mapping, and the marker bit width to `counts`.

Let A be the zero-diagonal binary interlacement matrix. For the guard x_v(Ax)_v=0, toggle the tour arc bit across each occurrence of v exactly when x_v=1. Once the initial bit is chosen these transitions close, since each vertex appears twice. At an active vertex the two toggles have opposite directions exactly when the number of active occurrences strictly between the two visits is even. This parity equals (Ax)_v because fully contained pairs cancel. Thus precisely the guard solutions arise as the toggle vectors of binary circulations on tour arcs.

Replace each vertex by a four-cycle K₂,₂ between its two incoming and two outgoing ports. Join the ports of each tour arc by a wire and subdivide each wire twice. Its three-edge path has two matching states: the two outer edges represent an included wire, while the middle edge represents an omitted wire. The omitted wires encode selected circulation arcs. Each locally balanced selection with k incoming and k outgoing selected arcs admits k! local matchings. Thus the label count weights each circulation by 2 to the power of its number of vertices with k=2. A positive count decides label feasibility.

Embed the tour on a circle. Draw chords of one color inside and chords of the other color outside on the sphere. Same-color chords have disjoint interiors since no two interlace. Thicken each chord and its two endpoints into a disk. The four tour ports around its boundary alternate incoming and outgoing, in visit order for one color and reverse order for the other. Join adjacent ports around the disk to form the four-cycle. The code constructs this rotation system and verifies Euler's sphere identity. Subdivision avoids loops or parallel port edges when two occurrences are consecutive.

XOR each vertex label onto the incoming and outgoing arcs of its first visit. Their sum over selected arcs is the toggle label. The sum over all arcs is zero, so the included wire set gives the same label. Mark only one outer edge of each three-edge path. On each face of length 2s, choose edge signs with product (−1)^(s+1), counting repeated edge traversals. The planar bipartite determinant signing gives every perfect matching a common determinant sign. Evaluate the signed biadjacency determinant at every binary character, using the sign of the trivial-character determinant to fix the common orientation for all evaluations. The all-included wire configuration supplies a perfect matching, so this normalization is defined. Fourier inversion recovers each label count exactly.

For n vertices the determinant matrices have order 4n. The checker uses a fraction-free cubic determinant per character and direct quadratic-time Fourier inversion over the 2^b marker classes. Integer arithmetic is exact. The reduction assumes the chord word is supplied and its interlacement is bipartite.
